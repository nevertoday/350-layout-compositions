# 多语言约定

目标：网站有 11 种语言，内容（分类、350 种版式的名称和海报文字）和界面都翻译。海报图片本身不翻译。翻译用 Gemini 4 Neon（agy CLI，`gemini-4-neon-high`）。

## 语言

| code | 地址 | `<html lang>` | 方向 | 名称 |
| --- | --- | --- | --- | --- |
| zh | `/`（源语言） | zh-CN | ltr | 简体中文 |
| zh-Hant | `/zh-hant/` | zh-Hant | ltr | 繁體中文 |
| en | `/en/` | en | ltr | English |
| ja | `/ja/` | ja | ltr | 日本語 |
| ko | `/ko/` | ko | ltr | 한국어 |
| es | `/es/` | es | ltr | Español |
| fr | `/fr/` | fr | ltr | Français |
| de | `/de/` | de | ltr | Deutsch |
| pt | `/pt/` | pt | ltr | Português |
| ru | `/ru/` | ru | ltr | Русский |
| ar | `/ar/` | ar | rtl | العربية |

这张表只在 `src/i18n/locales.js` 里写一次，别处都从那里取。

## 文件

```
src/i18n/locales.js          语言表（上面那张）
src/i18n/ui/zh.json          界面文字的源：{ "key": "文字，可以有 {n} 这样的占位" }
src/i18n/ui/<code>.json      译文，键和 zh.json 一模一样
src/i18n/content/<code>.json 内容译文（zh 没有这个文件，内容的源就是 atlas.js）
.cache/i18n/source.json      翻译的输入，由 scripts/i18n-source.mjs 从 atlas.js 和 ui/zh.json 导出
```

`content/<code>.json` 的形状，数组和源一一对应（长度、顺序都一样）：

```json
{
  "taxonomy": {
    "01-composition-logic": { "name": "…", "blurb": "…" },
    "classic-rules": { "name": "…", "blurb": "…" }
  },
  "layouts": {
    "001": {
      "name": "…",
      "summary": "…",
      "points": [{ "title": "…", "body": "…" }],
      "usage": { "title": "…", "items": ["…"] },
      "keywords": ["…"],
      "notes": ["…"]
    }
  }
}
```

- 源里是空字符串的地方，译文也是空字符串。
- 海报上印的英文（要点下的英文小字、关键词的英文、海报英文名）不翻译，站点照旧从 atlas.js 取。
- `en` 的版式名称用海报上印的英文名（atlas.js 的 `nameEn`）；海报上没有英文名的才翻译。
- 代码（CSS、HTML 片段）原样保留。

## 谁写什么

- 翻译流水线（`scripts/i18n-source.mjs`、`scripts/translate.py`）只写 `src/i18n/ui/<code>.json`（code ≠ zh）、`src/i18n/content/*.json` 和 `.cache/i18n/`。
- 站点只写 `src/i18n/locales.js`、`src/i18n/ui/zh.json` 和页面、脚本、样式。
- 站点在某个语言的译文文件还没有时也要能构建：缺的语言先不生成页面，构建时打一行提示。
