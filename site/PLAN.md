# 350 种排版 · 网站规划

目标：给 350 种排版做一个小小东自己的网站，让人**快速找到一种版式，看清楚，拿去用**。界面用 xxd-ui-kit。

## 参考站做得好的和不够的

参考：https://layout.namooca.com/（用了本项目的图，Astro 静态站）。

| 做得好，照着做 | 不够好，我们换掉 |
| --- | --- |
| 每张海报的文字抄成了结构化释文（定义、要点、用法、关键词），能搜、能读 | 详情页海报只有 460px 宽，海报上的小字看不清，要另开 CDN 才能看 |
| 详情页有面包屑、上一张 / 下一张、同主题 | 首屏是杂志封面（宋体大号「350」+ 竖排标语），找东西要先往下翻一屏 |
| 分类、主题、搜索三种筛选；亮 / 暗两套 | 图鉴页 350 张大卡一列四张，没有按主题分组，很长 |
| | 按钮是一排同样分量的 `[想学] [已学] [收藏] [自测] [复制 MD]`，看不出哪个重要 |
| | 偏「学习打卡」（测验、复习队列、研习路径），做设计的人真正要的「拿去用」没有：没有下载、没有可以直接贴进 AI 作图的构图提示词 |

我们的定位：**拿来就用的版式工具箱**。打开就是图鉴本身；点开一张能看清全图；每张都能一键下载、复制构图提示词、收藏。

## 栏目

只有三个页面，外加 350 个详情页：

| 地址 | 栏目 | 内容 |
| --- | --- | --- |
| `/` | 图鉴 | 像会员站的一个栏目页：开头左边标题、一段话、「开始浏览」和 GitHub，右边一张大海报（每个主题的第一张里随机一张）；三句事实（有什么、每张能做什么、许可）。然后是图鉴：工具条是分类标签（含「全部」「收藏」），右端一个小搜索框和「显示」；选了分类才出二级主题。下面是按分类排的海报，每组只有一行标题 |
| `/001/` … `/350/` | 详情 | 左边大图（能放大看全图），右边编号、中英文名、定义、要点、用法、关键词。操作：**下载高清图**（主）、复制构图提示词、收藏、复制链接。←/→ 翻上一张 / 下一张，下面列同主题 |
| `/001/play/` … | 互动版 | 有互动页面的那几种（`interactive/`，只有中文）：打好的单文件网页原样放在这里，不套外框。详情页下载那排按钮下面一行「互动版」，别的语言写明是中文页面；图鉴卡片的编号前有个小手势图标 |
| `/about/` | 关于与下载 | 这是什么、怎么用、全部图片 zip、数据目录（CSV / JSON）、CC BY 4.0 署名写法、GitHub、小小东会员站与联系方式 |
| `/404` | 找不到 | 回图鉴 |

所有页面套着小小东会员站的外框（`src/data/frame.js`）：左边会员站的图标导航（首页、开源、小玩意、工具箱、好物推荐，当前是「开源」），顶栏是这个站的栏目（图鉴、关于与下载、项目地址 ↗，当前的带图标和一条墨线），右边 GitHub、「更多」（外观亮 / 暗 / 跟随系统、语言）和「下载全部」。没有站名标志，在哪个栏目看标签。手机上图标导航变成底部标签栏。

**「显示」**：访客自己调图鉴的样子，存在浏览器里（`xxd-layout-view`，`src/scripts/view-prefs.js`）：视图（网格 / 海报墙 / 列表）、每行几张（宽屏 2–6，缺省 4；手机 1–3，缺省 2；键盘 − =）、分组（按分类 / 按主题 / 不分组），一键恢复默认。

**不做（第一版）**：测验、复习队列、研习路径、并排对比。它们服务的是「学」，我们先把「找、看、用」做好；以后真有人要再加。

**多语言**：11 种语言，简体中文在根上、地址不变，别的在 `/<语言>/` 下；海报图片不翻译，海报外面的字（界面、分类、名称、释文、构图提示词）都是页面的语言。约定见 `I18N.md`。

## 细节

- **筛选状态全在网址里**：`/?c=05-web-ui&s=grid-systems&q=网格&fav=1`，能分享、能后退。
- **搜索**：名称、英文名、编号、定义、要点、用法、关键词一起搜，边打边筛。搜索框只在图鉴的工具条上；详情页的关键词链接到 `/?q=…#atlas`。
- **收藏**：存在浏览器里（`localStorage`），「收藏」标签只看收藏的，可以一键复制收藏清单（编号 + 名称），做项目时攒候选很方便。
- **构图提示词**：由海报文字拼成一段，适合贴在作图提示词的末尾，例：`构图：三分法构图（Rule of Thirds）。将画面用两条横线和两条竖线平均分成九宫格……要点：主体落在交点；平衡留白；视觉引导。`
- **第二版**：11 种有两张图，详情页用分段控件切换「第一版 / 第二版」。
- **动效**：从网格点进详情时，缩略图平滑放大成大图（浏览器原生的跨页过渡，View Transitions）；减少动效时关掉。
- **图片**：网格用 480 宽 WebP，详情用原尺寸 1086 × 1448 WebP；下载给 WebP，另附 GitHub 原始 PNG 链接。图片不进 git，由脚本从 git 里的原图生成。
- **释文的来源**：用两个模型分别逐张抄录海报上的文字，逐字段比对，不一致的人工看（`scripts/extract-text.py`）。只抄写，不补写。

## 技术

- Astro 静态站，和小小东 VPS 教程站同一套：`site/` 目录，xxd-ui-kit 拷进 `public/xxd`。
- 数据只从一个地方读：`src/data/atlas.js` 读 `v2/catalog.json`、`v2/taxonomy.json`（分类说明，由 `scripts/import-350.py` 导出）和 `src/data/poster-text.json`（释文），还有译文 `src/i18n/ui/*.json`、`src/i18n/content/*.json`；`atlasFor(语言)` 给出那种语言的同样形状的数据。用别处的一套译文试：`XXD_I18N_DIR=<目录> npm run build`，检查时也设上。
- 互动版只认 `interactive/dist/<id>-<slug>.html`（`000` 是样例，不上站）：`npm run build` 先跑 `npm run play`（就是 `interactive` 的 `npm run build`，按输入做了缓存，没改过就是秒过），保证 dist 是新的；`atlas.js` 读这个目录给每种版式 `play`（`/<id>/play/` 或 null），`src/pages/[id]/play/index.html.js` 原样输出。
- 部署：Cloudflare Workers 静态资源，域名 `layout.xiaoxiaodong.ai`，`npm run release`。上线前要你点头。
