01

一个 X，定住横竖节奏

ONE UNIT X, DUAL-AXIS RHYTHM

很多人第一次听「等距网格」，会把它和 201 方格网格 混为一谈。其实两者锁死的对象不同：方格网格锁的是格子本身的宽高 1:1，而等距网格锁的是水平列缝与垂直行缝共用的间距单位 X。哪怕你的卡片是 16:9 横卡或 3:4 竖卡，只要横竖沟道严格相等，版面就立刻成立稳定节奏。

如果把 196 模块化网格 允许不同行缝和列缝的自由度收紧到 row-gap = column-gap = X，人眼在横扫与纵览时遇到的停顿时长完全相同，视觉阻力一下子降到最低——这就是原海报说「间距一致，节奏稳定」的真正机制。

点旁边解剖镜里的三个状态，再试着打开「纯留白透视」把卡片内容藏起来：你会发现眼睛最先读到的其实是沟道切出的白色十字网格。

02

整倍阶梯与跨缝公式

INTEGER MULTIPLES & SPAN MATH

「统一使用 X」不等于页面里所有空白都写成同一个死数字。实战里通常选 4px 或 8px 作为基础步长 X，用它的倍数搭出清晰的空间阶梯：内部小元素空 0.5X，卡片内边距给 1X，卡片之间的主沟道给 2X，大分区留 3X 或 4X——每升一级都稳守内紧于外。

一旦需要重点内容横跨 k 列，宽度绝不是 k × W，而是必须把吞掉的内部沟道一起加回来：跨列宽 = kW + (k − 1)X。漏算那一条 X，整张版的右边界就会立刻缺出一截。

海报核对 · 中英有出入

原海报「使用建议」第三条中文写了「围绕内容建立模块，让内容服务于结构」，但紧跟其下的英文写的是：

“Build modules around content, not the other way around”

意思是「围绕内容建模块，而不是反过来」。实际排版里英文这句更准确：先摸清文字长度、图片比例与卡片体量，再决定基数 X 与跨列数；让结构替内容兜底，不要硬裁内容去迁就方格。

05

什么时候用，什么时候别用

WHEN TO USE & WHEN TO SKIP

最适合的四类场合

  • 信息卡片与图文矩阵：商品流、课程目录、图鉴标本墙，模块不断增减也能自动守住整齐呼吸。
  • 网页与应用看板：仪表板、多指标统计区与设计系统组件库，一套 X 阶梯直接落进代码变量。
  • 高频协作的团队产品：多个设计师同画几十个页面，共享同一个基数 X 就能消掉大部分间距争议。
  • 理性展览海报与信息看板：需要冷静、可靠、可快速定位信息的公共导视与学术展讯。

什么时候别硬套

  • 长篇连续文学或专著阅读：段落靠版心与行距流动，套进等距方阵只会切碎语流，应看 194 手稿网格 或 195 分栏网格。
  • 追求强烈戏剧反差的海报：等距天生克制中立，要制造爆发力与破格张力应转向 200 非对称网格、210 破格网格 或 211 解构网格。
  • 向心汇聚或环形叙事：以中心向外发散的结构属于 203 放射网格 与 204 极坐标网格，不宜压扁成直角等距。
  • 超窄屏死守宽像素缝：360px 手机上还死扛 24px 多列沟道会把内容挤没，必须配合 208 流体网格 或 209 响应式网格 降档倍率（复杂双系混排另见 199 复合网格）。
