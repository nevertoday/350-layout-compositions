# 208 流体网格（FLUID GRID）页面方案

## 1. 一句话道理
流体网格用相对比例（`%`、`fr`）替代写死的像素值，让列宽随容器连续伸缩、始终保有主次节奏与视觉秩序；再配上 `minmax()` / `max-width` 护栏与窄屏重排，便能在极宽屏不拉爆行长、极窄屏不压成针眼。

## 2. 开场玩具
- **命名与形态**：承袭 208 原海报深靛紫底（`#1C1156`）、六档紫粉比例带（`10% 10% 20% 30% 20% 10%`）、虚线圆角容器框与珊瑚粉波浪导流箭头的 **「弹性流体水槽 · 比例流道调谐台」**（2D Canvas，`data-perf-drag`）。
- **核心操作**：
  1. 直接在画布上左右横拖容器右壁的珊瑚粉弹性拉伸柄（或在标尺/空白区横拖 `data-perf-drag`），将容器宽度在 `320px–1600px` 间连续伸缩，实时驱动刊头底部 6 段流体比例条同步伸缩，并联动槽底「桌面 1440 / 平板 960 / 手机 390」三端实时映射带。
  2. 直接在画布上拖拽任意相邻两列之间的竖向分界线，现场重新分配两列百分比/份数权重（总和自动守恒 100%）。
  3. 切换三类题材（原海报 6 列比例带 / 编辑图文版面 / 数据看板），并在下方与原海报一致的 `.fluid-grid` 活体代码舱中切换单位（`固定 px` / `纯百分比 %` / `弹性份数 fr`）、栏距（`0px` / `16px` / `28px`）以及两条工程护栏（`小屏重排 <768px`、`行宽护栏 minmax/max-width`）；支持方向键 `←/→` 精调容器宽度。
- **开场初始状态（非答案）**：容器开场停在 `960px`（平板横屏），且刻意处于三重真实错态——① 单位写死 `固定 px`（总宽锁死 1280px，现场向右破壁溢出 `+320px`，底部珊瑚波浪流线断裂为红虚线）；② 列宽权重极端失衡（`4% · 6% · 12% · 62% · 10% · 6%`，外侧边列被压成针眼、主列拉爆）；③ 关闭小屏重排与行宽护栏，导致三端映射中手机 `390px` 缩成 6 条 unreadable 细缝。
- **双向可玩错机制（由 `model.js` 单真源实算）**：
  - `固定 px` 缩窄时溢出破框（`+XXXpx`）、拉宽到 `1560px` 时右侧出现大块闲置空带；
  - `纯百分比 %` 开启 `gap > 0` 时现场演示 CSS 经典暗礁：**`100% + (n-1)×gap` 溢出爆框**；
  - 任意一列宽度在桌面压到 `< 64px` 或权重 `< 8%` 时报「窄列塌缩成针眼」；
  - 主列实际渲染宽度超过 `680px`（约 `> 75 ch` / 中文超 42 字行长）时报「超宽拉爆行长，回行迷路」；
  - 手机 390px 视图下关闭自动重排时，单列跌破 `56px` 报「小屏硬塞多列无法阅读」。
  - 接受多组合法解：原海报无缝 6 列解（`%` + `0px gap` + 重排 + 护栏）、现代 `fr` 带缝 6 列解（`fr` + `16px gap` + 重排 + 护栏）、四列不对称解、四列均衡解均可通流达标。
- **与近 12 页的明显区别**：207 是浅樱粉固定像素标尺拼版台（摆模块落格）；206 是电光蓝 12 列父子轨道对齐晒图板；248 是电光蓝切换器游标控制台；039/038 是海浪与丝带构图；本页独创「直接扯动容器弹性壁面 + 拖拽列间分流缝 + 实时暴露 `% + gap` 爆框与三端联动的深靛紫流体水槽」，别的编号完全无法套用。

## 3. 版式骨架
- 忠实转译 208 原海报的 **「深靛紫通栏纵向流体堆栈 × 虚线圆角视口槽 × 左代码右诊单底舱」**（零独立导航栏黑箱、不锁 `100svh` 避开平板大空洞）：
  - **1440×900**（主宽 `1380px`，2560×1440 舒展至 `1720px`）：顶沿无框刊头（左「流体网格 + 活体 6 段比例条 + FLUID GRID + 总述」× 右原海报标志珊瑚粉波浪飘带/圆点/十字/点阵装饰 + 三题材切换与实时视口宽度徽）→ 全宽虚线圆角「弹性流体水槽」2D Canvas 主舞台 → 下接原海报风格左 46% 活体 `.fluid-grid` CSS 代码与物理拨片舱 × 右 54% 单真源流体诊单与四枚珊瑚粉核心原理实时徽（`%` / `~` / `~` / `⤢`），首屏干净落满约 `850px`。
  - **1024×1366 / 768×1024 平板**：自然垂直流排，不锁 `100svh`，零上下大空洞。
  - **390×844 手机竖屏**：刊头压紧为单行（「流体网格」+ 实时宽度徽 + 三题材短签），总述后置至舞台下，全宽弹性水槽画布稳占首屏 ≥ 46% 屏高（等比不压扁），画布下方紧接核心诊单首句与单位切换键。
  - **844×390 手机横屏**：切换为左 56% 弹性流体水槽画布 × 右 44% 紧凑刊头、诊单与核心单位拨片并行布局。
- 正文七节采用 **冷薰衣草浅纸 `#F6F4FC` / 纯雪白 `#FFFFFF` / 03 深靛紫暗室 `#170E4A` / 柔樱雾纸 `#FAF4F8` / 淡紫砂纸 `#EEEAF8` / 纯白练习场 `#FFFFFF` / 07 深靛紫原海报展墙 `#180F4D`** 的明暗交替节奏。

## 5. 节目录
- `01` **流体从哪来**（Origin）：从 2000 年网页弃纸宣言到 2009 年比例公式与现代 CSS Grid；内嵌「Marcotte `target ÷ context = result` 实时公式换算器」（数值步进控件）。
- `02` **比例与暗礁**（Ratio & Gaps）：逐条拆解原海报四条核心原理，温和修正「无固定间隙」说法；内嵌「`%` vs `fr` 含缝溢出实时剖面图」（SVG 双轨开关对照）。
- `03` **行长与护栏**（Measure & Clamps，深靛暗室）：解释为什么纯流体不能无限拉宽；内嵌「活体阅读行长隧道」（滑块拖视口 + 裸奔流体/护栏流体对照，实时测算中英文每行字数与回行距离）。
- `04` **四大真场景**（Real Scenarios）：还原原海报网页布局、数据看板、卡片列表、内容排版四场景；内嵌「真实 CSS Grid 可缩橱窗」（四档屏幕尺寸按钮驱动真 DOM 网格重排并露出对应 CSS）。
- `05` **什么时候别用**（When Not To Use）：界定流体网格的边界，并以一句话链接到 207 固定网格、209 响应式网格、206 子网格、198 基线网格、200 非对称网格、210 破格网格等；内嵌「三例项目分诊判断卡」（二选一分诊翻牌）。
- `06` **小练习**（Quick Check）：四选一单变量辨析题（中性标签方案 A/B/C/D，只差列轨与护栏写法）。
- `07` **原海报展柜**（Original Poster，深靛展墙）：展示 `poster.webp`（点击灯箱缩放拖拽、`Esc` 关闭）与原海报寄语、核心关键词。

## 7. 练习
- **题目**：某资讯站在桌面采用 `1 : 1 : 2 : 3 : 2 : 1` 六列流体比例，要求栏距 `20px`，并同时保证 `390px` 手机不挤成细条、`1920px` 宽屏正文不拉成百字长行。下列四个只差列轨与护栏写法的 CSS 方案，哪一项站得住？
- **四个选项（单变量递进，标签仅写方案 A/B/C/D + CSS 规则）**：
  - **方案 A**：固定像素 `width: 1200px; grid-template-columns: 120px 120px 240px 360px 240px 120px; gap: 20px;`（变量误差：未比例化）
  - **方案 B**：纯百分比加固定缝 `width: 100%; grid-template-columns: 10% 10% 20% 30% 20% 10%; gap: 20px;`（变量误差：`100% + 5×20px` 必爆框且缺护栏）
  - **方案 C**：裸奔份数 `width: 100%; grid-template-columns: 1fr 1fr 2fr 3fr 2fr 1fr; gap: 20px;`（变量误差：已解栏距爆框，但缺超宽上限与小屏重排）
  - **方案 D（正确）**：`width: 100%; max-width: 1440px; grid-template-columns: 1fr 1fr 2fr 3fr 2fr 1fr; gap: 20px;` + `< 768px` 折为单列 `100%`（用 `fr` 吸收栏距、用 `max-width` 锁住行长上限、用断点重排保住小屏可读性）。
