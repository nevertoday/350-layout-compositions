# 159 浮动块版式（FLOATING BLOCK LAYOUT）实现方案

## 1. 一句话道理
浮动块版式并不是把卡片随意洒在纸面上，而是**先松开刚性方格边框，再用「留白通道 + Z 轴分层（投影与叠压次序）+ 克制倾角/错落 + 主焦锚定」四件事协同**，把读者从刻板的等格扫描解放出来，顺着设计好的轻重节奏逐块读完；一旦留白窒息、叠压遮字、倾角狂甩或高程平权，版面会立刻从「自由呼吸」塌成「杂乱贴纸堆」。

## 2. 开场玩具（活体 2.5D 浮动排布台 × Z 轴侧视浮升剖面槽）
- **玩法**：
  1. **上方开放浮动排布画布（2D Canvas，无封闭硬边框）**：直接 1:1 承袭 159 原海报的 4 张特色浮动卡（深靛主焦卡、白底引言卡、淡紫浮力要点卡、白底几何结语卡），可切换三套真实题材（原海报四卡 / 建筑季刊跨页 / 新品发布首屏）。
  2. **直接手势操作**：在画布上按住任意一张卡片拖移 `(x, y)`（拿起时产生真实的动态抬升阴影），拖动选中卡的角部旋转耳柄调节倾角（`-24° ~ +24°`），点击画布上的纠错红签就地纠错，或点击 Z 轴层级按钮/卡片角标将任意卡提至 `L3 / L2 / L1 / L0`；键盘支持 `Tab`/`1–4` 选卡、方向键微调位置、`[`/`]` 调倾角、`+`/`-` 调层级。
  3. **下方集成「Z 轴侧视浮升剖面槽」（标 `data-perf-drag`）**：用建筑剖面视角把 4 张卡片悬在 `z = 0dp` 纸面之上的真实高度与顶光投影锥画出来；在剖面槽上左右横拖即可连续调节「浮升分层强度（0% 贴平死格 → 55% 轻盈分层 → 100% 黑脏重影）」，画布上的四张卡投影、偏移和视线丝带逐帧联动。
- **开场初始状态（0/4 贴纸撞车错态，绝非答案）**：
  - 淡紫要点卡与引言白卡直接压在深靛主焦卡上方，经精确旋转多边形交集（SAT + 多边形裁剪）实测遮盖主焦正文区约 30%；
  - 四张卡倾角乱甩（`-16° / +19° / -13° / +15°`），读起来费眼；
  - 所有卡片压在近似平权的低高程且主焦卡被次卡压在底层；
  - 四张卡挤在画布中部导致有效留白窒息，柠檬黄视线引导路径发生交叉打结。
- **怎样算玩错（单真源 `model.js` 从实绘几何坐标、多边形重叠率与高程统一算出 8 类错态）**：
  1. 盖字撞车（两卡重叠超小卡面积 16% 或侵入下层文字安全区）；
  2. 散纸狂斜（任一卡倾角 `|θ| > 9°`）；
  3. 主焦被压 / 层次平权（主焦卡不在最高 Z 层，或高程跨度 `< 6dp`）；
  4. 锁回死格（四卡排成齐平 2×2 网格、0° 且零高程差，退回区块网格）；
  5. 留白窒息（卡片总占幅超 66% 或贴边碰撞）；
  6. 孤岛失联（卡片被甩到四角导致彼此间距断裂）；
  7. 黑脏重影（浮升强度超过 86%，投影发黑发脏拖泥带水）；
  8. 视线打结（`1 → 2 → 3 → 4` 视觉引导折线自交）。
- **多组合法解**：支持手动拖出任意合理布局，另内置 3 组风格迥异的参考解：**原海报经典解**（微斜错落）、**轻叠画册解**（边角轻吻 6% 不盖字）、**水平错落解**（0° 无倾角，纯靠错位与 Z 层浮起，破除「浮动=斜贴」误区）。
- **与最近 12 页的区别**：区别于 158（有机图文扫描线绕排）、035（Z 轨四站眼动）、202（等距网格沟道）、285（分步表单）、073/071（透视投影）、243（垂直堆栈）、118（残笔闭合）、034（V 形光束）、157（撕边校注）、323（扇弧定向）、284（表单眼动）；本页聚焦**二维错落自由排布 + 旋转多边形叠压检测 + Z 轴剖面高程投影**。

## 3. 版式骨架
忠实承袭 159 原海报「冰薰衣草云白全开放纸面 × 左 31% 锚柱与自示范浮起大标 × 右 69% 无框开放浮动舞台 + Z 轴剖面槽 × 四角原海报深靛/淡紫几何压角与柠檬黄细丝线」的非对称空气感编辑架构（零深色顶眉、零圆角仪表盘黑箱、不锁 `100svh` 避开平板空洞）：
- **1440×900（2560 舒展至 1760px）**：左 31% 自示范浮动标题（`浮·动·块·版·式` 五字基线与柔影随当前状态实时起伏）+ 5 枚原海报紫罗兰圆徽实时状态列 + 轻浮白卡单真源诊单；右 69% 紧凑场景/预设栏 + 无框开放浮动排布画布 + Z 轴侧视浮升剖面槽 + 选中卡微调条；两栏同收于 ~760px，首屏完整可见、无长短腿。
- **1024×1366 & 768×1024**：自然流式折排，顶部紧凑刊头 + 全宽开放排布台与 Z 轴剖面槽 + 下方双栏并列诊单与五要点实况。
- **390×844 竖屏**：压紧单行刊头与一排快选按钮，保持等比 4:3.3 开放浮动画布 + Z 轴剖面槽稳占首屏 ≥48% 高度，下方直接露出白卡诊单标题与首句。
- **844×390 横屏**：切为左 57% 浮动画布与 Z 轴剖面槽 × 右 43% 精简刊头、诊单与快控并行。

## 4. 配色和字体
- **配色（逐像素采自 159 原海报）**：
  - 冰薰衣草云白原纸：`#F8FAFE` / 纯白浮卡 `#FFFFFF` / 淡紫雾纸 `#F0EFFC` / 淡薰衣草卡 `#EEEDFD`
  - 深皇家靛蓝主墨与主焦卡：`#2B338D` / `#353B90` / `#4844B3` / 紫罗兰徽标 `#5A4CC7` / 深靛暗室（03 节）`#1A1F59` 与暗舱 `#242A6E`
  - 淡薰衣草装饰体：`#D2CBFB` / `#D9D5FA` / `#BFB5F2`
  - 标志电光柠檬青黄（原海报短杠、光点与细丝）：`#DCEC80` / `#DCED6C`（浅底文字绝不用浅黄，仅用于色条、丝线与深靛暗底高亮，浅底高亮字用深靛 `#2B338D` 或深橄榄 `#4A5F00` 保证对比度 > 6）
  - 语义辅助：克制绯赤 `#C2273A`（暗底 `#FF8E9D`）标错态；松青 `#136B60`（暗底 `#73E5C4`）标通畅。
- **字体搭配（全库唯一、与 157/158 零西文重合，三款西文在近 12 页全部 0 次使用）**：
  - `Noto Sans SC`（400/500/700/900）—— 现代中文标题与正文
  - `Syne`（600/700/800，近 12 页 0 次）—— 宽展前卫几何无衬线，用于英文主标与节标
  - `DM Serif Display`（正斜体 400，近 12 页 0 次）—— 高反差编辑衬线，用于节号与引语拉字
  - `Space Mono`（400/700，近 12 页 0 次）—— 几何等宽，用于高程 `dp`、倾角、重叠率与 CSS 读数

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节不复用同控件）
- **01 · 为什么“浮”得住**（`WHY FLOATING WORKS`）：拆解原海报 5 要点与「浮动的力量」，温和修正「打破固定网格」为「松开可见边框、保留暗网秩序」；交互：**暗网透视拉帘**（横向拖帘或三态切换对比表层浮动、隐藏对齐暗网与真散乱反例）。
- **02 · 三层阴影与 Z 轴**（`ELEVATION & DEPTH`）：讲解本影、半影、环境光三层阴影与色调分级如何决定高度感；交互：**三层光影开关与高程阶梯台**（勾选开关独立拆显三层影，点击 `0/4/12/20dp` 实时抬升实体卡并生成对应 CSS）。
- **03 · 五种翻车现场**（`FIVE FAILURE MODES`，深皇家靛蓝暗室节）：呈现 5 类高频失误标本；交互：**病历解剖卡片墙 + 一键急救变形**（点选病历并一键切换「病态 ↔ 急救后」实时观察几何修复）。
- **04 · 从构成主义到悬浮卡片**（`LINEAGE & HISTORY`）：梳理 1919–2021 真实设计脉络；交互：**五时代标本时间轴**（切换 5 个历史节点，同步重绘该时代版面构成的矢量解剖图）。
- **05 · 什么时候用，什么时候别用**（`WHEN TO USE & AVOID`）：给出清晰适用/禁用清单与同小类 153–158 一句话区分链接；交互：**多屏折叠退化测试器**（在 1280 / 768 / 375px 三档切换，展示窄屏为何必须解开倾角与叠压）。
- **06 · 挑一张真“浮”得住的版**（`LAYOUT CHECKPOINT`）：单变量四选一图文测验（仅改变 Z 轴层级与叠压关系，中性标签 A/B/C/D）；交互：**四方案视觉判题卡片**。
- **07 · 原海报与关键词**（`ORIGINAL POSTER`）：展示原海报（点开缩放拖拽放大镜，`draggable="false"`，Esc 关闭）、原海报全部箴言与英文标签 + 标准页脚。

## 7. 小练习设计
- **题目**：以下四版使用完全相同的文案、配色与卡片尺寸，**唯一变量是四张卡片的 Z 轴层级与叠压方式**。哪一版既突出核心观点，又保持呼吸感与可读性？
- **四个中性选项（只差 Z 层级与叠压一个变量）**：
  - 方案 A：四张同居 L1（4dp），等距分开互不触碰、投影深浅一致；
  - 方案 B：深靛主卡升至 L3（18dp），两张辅卡居 L2（8dp）仅在装饰边角轻触 6% 不盖文字，底卡居 L1（2dp）；
  - 方案 C：深靛主卡与白底引言卡同升至 L3（20dp），两卡在正文区重叠 24%；
  - 方案 D：四张均配浓黑大投影（模糊 36px），且淡紫次卡反盖在深靛主卡正上方。
- **正确答案**：方案 B。理由：明确建立 `L3 > L2 > L1` 三级纵深让主焦最先入眼，边角 6% 轻叠既制造空间前后关系又不损伤正文可读性，同时保留通畅留白走廊。
