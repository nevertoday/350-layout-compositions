# 158 环绕图版式 · 设计与实现方案

## 1. 一句话道理
把最具辨识度的主体轮廓当作版面磁石，让正文沿着平滑外包轮廓保持均匀呼吸距流动，做到「围而不堵，聚而有序」——既打破呆板矩形框对图文的生硬隔断，又守住行宽与行首齐整的阅读底线。

## 2. 开场玩具
- **名字**：活体有机绕排排版台（Organic Contour Wrap Bench）
- **怎么玩**：在 1:1 承袭 158 原海报暖砂纸面与青绿/梅紫/陶粉有机卵石主体的 2D Canvas 活体杂志跨页上：
  1. **横拖/直拖画布主体**（`data-perf-drag`）：实时移动有机图形在版面中的水平与垂直停靠位，扫描线引擎逐行重新折算真实中文正文的换行与左右缩进；
  2. **拖曳青绿虚线绕排光圈把手**：直接扩缩轮廓呼吸距 `0px–42px`；
  3. **画布内直接点击纠错标签**：点击红框「矩形死框 / 碎缝残行 / 咬边碰撞 / 凹坑陷字」提示签或下方梅紫波浪控槽，切换绕排边界（矩形死框 / 贴合轮廓 / 凹坑陷阱）、栏式（双栏跨脊 / 单栏绕排 / 原海报六点）与三大题材（原海报·山月卵石、器物特写·青瓷瓶、杂志人物·剪影侧影）。
- **开场状态（0/4 错态，绝不先给答案）**：开场停在典型的 4 重绕排翻车现场——① 误用「矩形死框」导致四角留下巨大楔形死空洞；② 轮廓安全距仅 `2px`，字缘直接咬住图形边界；③ 图形停在偏右尴尬位（单栏偏心 `x = 64%`），正文横跨图形左右穿桥且右侧挤出 3–4 字无法顺读的碎缝残行；④ 图形体量偏大（54%）压缩正文呼吸空间。
- **怎样算玩错、读数怎么说「为什么」**：全部读数由 `model.js` 同一套逐行扫描线求交排版引擎单真源实算，主动识别并白话诊断 9 类真实失误（矩形楔形死角、贴边咬字、护城河过宽脱节、单栏居中穿桥劈句、残行碎缝 `< 7` 字、左缘深凹锯齿行首失锚、凹坑嵌字落井、体量臃肿挤边、体量过微失焦），同时接受多组合法解（双栏跨脊居中解、单栏贴右舒展解、单栏轻靠左平滑解、原海报六点环绕解）。
- **与最近 12 页的区别**：157 是宣纸书页+右侧垂直边注卡上下对锚；156 是 68:32 竖刃裁切分栏；201 是 8×8 方格拼装；284 是真实 DOM 表单；323 是暗夜扇弧定向；322 是江岸三翼画卷；242 是深靛三槽容器宽度；070 是包豪斯长廊一点透视。本页唯一以**真实扫描线逐行动态重排汉字绕过有机轮廓**为核心物理动作，别的编号完全无法套用。

## 3. 版式骨架
忠实承袭 158 原海报「暖砂原纸通幅展开 × 右上深梅紫有机波浪（竖感四句标语 + 淡出点阵）× 中央全幅活体绕排跨页舞台 × 梅紫/青绿交替六点实况带 × 底部深梅紫有机波浪单真源诊单与四维控槽」的上下波浪夹抱开放架构（零深色圆角仪表盘侧栏、不锁 `100svh` 避开平板空洞）：
- **1440×900**：主宽 `1380px`（`2560×1440` 舒展至 `1760px`）。顶部轻盈单层刊头（左自示范绕排微廓标题，右深梅紫波浪四句标语）→ 中央全宽 16:7.5 活体绕排跨页画布 → 紧接六枚梅紫/青绿交替实况徽标条 → 底部无缝衔入深梅紫有机波浪诊单与控槽，首屏完整可见。
- **1024×1366 / 768×1024**：自然流式展开无空洞，全宽活体舞台下接深梅紫双栏诊单与 3×2 六点带。
- **390×844 竖屏**：刊头压紧为紧凑标题与题材快选行，让等比活体绕排画布稳占首屏 `≥ 46%` 屏高，并在画布紧下方优先露出深梅紫波浪诊单主句与操作提示（六点徽标条顺延其下）。
- **844×390 横屏**：切为左 `56%` 活体画布 × 右 `44%` 紧凑刊头、深梅紫诊单与快控并行，零挤压、零横向溢出。

## 5. 节目录（01–07）
- `01` **围而不堵的六股力** — 原海报总述与六点拆解 + 可点击切换的矢量轮廓力学解剖图 + 温和补充「毛刺轮廓需先简化」。
- `02` **绕距与残行红线** — 真实 DOM CSS `shape-outside` 活体排版对比舱：切换四种常见落位（左锯齿 / 单栏穿桥 / 右稳锚 / 双栏跨脊）并拖曳栏宽测试 Bringhurst 行宽底线。
- `03` **从雕版到 CSS Shapes**（深梅紫暗室）— 1499《寻爱绮梦》→ 1934–1958 Brodovitch → 1988 PageMaker 3.0 → 2014 W3C CSS Shapes 四段演变交互微标本 + 同小类 153/154/155/156/157/159 一句话分工链接。
- `04` **轮廓简化与退底工艺** — 独立顶点简化交互台：四档多边形顶点数（64 噪点 / 18 细廓 / 8 顺滑 / 4 死框）实时对照字缘平整度与视觉贴合度。
- `05` **什么时候用，什么时候别用** — 六种真实项目场景筛查卡（点开逐项翻阅判词与窄屏降级策略，明确窄屏、法律报表、多语种自动翻译等禁用红线）。
- `06` **挑出真正顺眼的绕排** — 两道单变量控制视觉小练习（A/B/C/D 中性选项，分别专考「落位与行首稳定」和「边界简繁与呼吸距」）。
- `07` **原海报与完整文字** — 单次引用 `poster.webp` 可点击放大拖拽灯箱 + 原海报标语、金句与关键词。

## 6. 来源与核实
- Aldus Manutius（印行）、Francesco Colonna（归属）、Francesco Griffo（字体），*Hypnerotomachia Poliphili*（《寻爱绮梦》），威尼斯，1499 年 12 月，172 幅木刻插图。核实：The Metropolitan Museum of Art (`https://www.metmuseum.org/art/collection/search`)。
- Alexey Brodovitch，*Harper's Bazaar* 艺术总监，1934–1958 年，以退底裁剪（cutout）与跨页节奏革新现代杂志版面。核实：Encyclopaedia Britannica (`https://www.britannica.com/biography/Alexey-Brodovitch`)。
- Aldus PageMaker 3.0，1988 年，引入桌面出版自动绕排与可调多边形自定义绕排；后续发展见 Adobe InDesign Text Wrap（Detect Edges / Alpha Channel）。核实：Adobe HelpX (`https://helpx.adobe.com/indesign/using/text-wrap.html`)。
- Robert Bringhurst，*The Elements of Typographic Style*，Hartley & Marks，1992 年初版（单栏 45–75 拉丁字符、约 66 字符舒适行宽经验参考）。
- W3C *CSS Shapes Module Level 1* Candidate Recommendation，2014 年 3 月 20 日（Vincent Hardy、Rossen Atanassov、Alan Stearns 编），定义 `shape-outside`、`shape-margin`、`shape-image-threshold`。核实：W3C (`https://www.w3.org/TR/2014/CR-css-shapes-1-20140320/`、`https://www.w3.org/TR/css-shapes/`)、MDN (`https://developer.mozilla.org/docs/Web/CSS/shape-outside`)。

## 7. 练习
- **题 1（单变量：图形在单栏/双栏中的停靠位与阅读起点）**：相同 16px 轮廓绕距、相同 34% 面积占比。A：单栏紧贴左缘绕排（行首随曲线大幅起伏）；B：单栏居中置图，左右同排一行形成跨图跳读；C：单栏贴右缘绕排，左缘保持笔直齐整且右缘顺廓舒展；D：单栏偏右停靠，右侧残留 4 字孤缝。正解 C（兼顾笔直左起点、无穿桥、无残缝）。
- **题 2（单变量：绕排边界形状与呼吸距）**：相同双栏跨脊居中构图与图形体量。A：矩形外框 + 16px 边距（楔形死角明显）；B：简化平滑多边形 + 16px 呼吸距（顺廓均匀）；C：未简化高噪锯齿轮廓 + 2px 紧贴（咬边跳动）；D：简化平滑多边形 + 44px 过宽留距（图文割裂且挤窄文字栏）。正解 B。
