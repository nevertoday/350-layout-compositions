# 211 解构网格（DECONSTRUCTED GRID）方案

## 1. 一句话道理
解构网格不是把版面砸碎乱放，而是先把完整的底层网格沿断层切分、错位、拉开层级，再凭隐形对齐回声、视觉压舱与清晰的主次尺度重建秩序——**结构可以拆散重写，核心意义与阅读路径绝不崩塌**。

## 2. 开场玩具：活体断层切割与语义重构台（Fault-Line Deconstructor）
- **核心动作（源于解构网格本身，区别于 210 破格网格）**：
  210 破格网格保持 5×6 整网不动、拖单个块出格；211 解构网格直接**劈开网格骨架本身**。1:1 承袭 211 原海报的淡青建筑描图纸、5×5 断续细线网格、空心校准圆、青碧大方块、珊瑚红横条与小块、纯黑压舱块、右侧虚线交叉框及中央银灰语义板（`STRUCTURE IS FLEXIBLE, MEANING IS NOT.`）。
  - **画布直操（`data-perf-drag`）**：直接在画布横拖（触屏 `touch-action: pan-y` 保留纵向滚屏）连续拉动**断层滑移量**（将已切开的网格板块沿水平/垂直断层错位滑开，同步显影原网格断口残影、位移动线与实时坐标尺）；直接拖动或点按画布内两条**断层切线（横切 H / 纵切 V）**改换切分位置；直接点击画布上的红标错点可单步纠偏；键盘 `←/→` 调断层滑移、`↑/↓` 调切线黄金偏移、`L` 切语义层级、`1–3` 切题材、`R` 复原错态。
  - **画布底沿联动原海报 3 步「视觉重构示意」**：`01 完整整网 → 02 分解错位 → 03 层级重构` 三个微缩框实时映照当前几何状态，点击任一阶段可直接跳转演示该阶段。
  - **三套题材切换**：`原海报构成`（Structure is flexible, meaning is not.）、`建筑双年展`（Form fractures, space holds.）、`实验音像刊`（Break the grid, keep the signal.）。
- **开场状态（绝非答案）**：
  刻意停在初学者最常见的反面误区——**「盲目粉碎・语义被掩埋」**：碎片切得过碎（9 碎块过度解构）+ 断层过度滑移（88%）+ 语义板层级塌陷在底层被青/红碎块压遮 + 三色压舱同堆右偏导致重心失衡、阅读动线来回打结。
- **双向可玩错 & 单真源读数（由 `model.js` 从实绘碎片矩形、断层坐标、语义板包围盒与 48×40 覆盖栅格单真源计算）**：
  1. **语义受损（遮挡 > 3%）**：青碧/珊瑚/黑块压住核心文字区——读数实报遮挡比例并解释「结构喧宾夺主，读者先看见色块撞字而非信息」。
  2. **过度粉碎（9 碎块）**：网格被切得太碎、失去大块呼吸基准——解释「拆得只剩碎屑，眼睛找不到任何停留节奏」。
  3. **退回死板整网（完整未拆 或 滑移 < 12%）**：反向玩错！把断层全部推回 0% 变成工整表格——解释「零分解零位移，退回 196 模块化网格，完全失去解构张力」。
  4. **对称均切（H/V 切线同时落近 50%）**：一刀正中平分——解释「对称切口消解了非对称动势，四象限重量雷同」。
  5. **层级拍平（语义板无破层反差）**：文字板退进底层与网格线平权——解释「失去前景主语锚点，眼睛在断线里迷路」。
  6. **重心倾覆（色块重心偏离平衡区）**：青/红/黑挤在同侧无对角压舱——解释「拆开后缺少重构压舱，版面像向一侧倾斜倾倒」。
  7. **断联飞散（滑移 > 78% 或净留白失控）**：板块甩离过远导致视线跨越断沟折断。
- **多组合法解**：不绑定单一标准答案——原海报经典重构解、双片建筑留白解、窄缝纵切杂志解，或用户亲手拖出的任意满足「有效非对称断层 + 语义零遮挡破层 + 压舱平衡 + 呼吸留白」的几何组合，皆实时判定成立。
- **与最近 12 页的差异**：近 12 页无任何一页以「切割网格断层并沿断层滑移整块网格板块 + 实时联动三步视觉重构演变条」为核心玩法；也完全不同于 210（固定 5×6 整网拖拽单块出格，开场 0 破格锁死态）。

## 3. 版式骨架
忠实转译 211 原海报的**建筑描图纸错层版面 + 右上四符图例 + 底沿方框四栏核心逻辑 + 波浪线收脚**（零深色顶栏、零圆角仪表盘箱、不锁 `100svh` 避平板空洞）：
- **1440×900（主宽 1400px）**：
  - 顶沿错层刊头带：左置自示范错位粗黑大标 `解构网格` + `DECONSTRUCTED GRID`；右置 1:1 复刻原海报的四符活体图例（`■ 分解` / `● 位移` / `+ 重构` / `■ 层级` 实时亮灯）与三题材切签。
  - 中段主工作台：左 68% 开放无厚框建筑描图 2D 画布 + 紧贴画布下沿的 1:1 三步 `视觉重构示意` 互动条；右 32% 银灰描图建筑诊单（`#DEE2E3` 0px 直角细线卡）与紧凑断层控制架（碎片档、断层切轴、滑移轨、语义层级、压舱、三合法解与三试错态）。
  - 底沿通栏 1px 炭墨细框四栏 `核心逻辑 CORE LOGIC` 实况条（1:1 复刻原海报 4 枚方形图标）+ `● 结构可变，意义不变` 与波浪线收脚。
- **2560×1440**：主容器舒展至 `1760px`，画布与栏宽同步放大，杜绝两边大片空洞。
- **1024×1366 / 768×1024 平板**：自然流排，绝不锁 `100svh`，主工作台下方平滑接续 01 节，零空白断层。
- **390×844 竖屏手机**：压紧单行刊头与题材条，后置总述，让等比建筑主画布稳居首屏 ≥ 46% 屏高，紧接同屏可见单真源诊单首句与一键试修/滑移控轨。
- **844×390 横屏手机**：左右双栏并排（左 56% 主画布 × 右 44% 紧凑刊头、诊单首句与关键按钮），零横向溢出。

## 7. 小练习设计
- **题干**：为「空隙建筑双年展」设计一张解构网格主视觉海报，必须完整传达主标「空隙建筑」、展期「10.12–11.20」与副标导语。下列四版采用完全相同字体与色系，仅在结构组织上相差一个变量——哪一版真正做到了「结构可变，意义不变」？
- **选项（中性标签 `方案 A` / `方案 B` / `方案 C` / `方案 D`，绝不透露优劣）**：
  - `方案 A`：5×5 工整全对齐，仅把色块填成青碧与珊瑚红（错因：未解构，只是常规模块化填色）。
  - `方案 B`：做了非对称断层切分，但青碧色块跨压遮住了主标后两字、展期孤悬对角（错因：结构破坏了语义可读性）。
  - `方案 C`（**正确**）：非对称断层拆解滑移且保留隐形对齐回声，银灰主标层净空破层零遮挡，青碧与珊瑚红对角压舱平衡，视线「主标 → 展期 → 副标」单向清晰。
  - `方案 D`：所有板块任意旋转 ±24°–35° 并密铺堆叠，隐形基准轴彻底消失、留白塌陷（错因：失控堆砌而非重构秩序）。
