# 113 流动节奏组织（FLOW RHYTHM）互动页方案

## 1. 一句话道理
人眼遵循完形「良好延续（Good Continuation）」本能，会顺着切线平顺、无断口的曲线自然滑行；当曲率张弛有度、沿途拍点错落呼吸、且末端切线稳稳送进视觉焦点时，静态版面便生出连绵向前的生命力。

## 2. 开场玩具
- **名称**：活体丝带河道雕塑台（2D Canvas 1:1 化用 113 原海报深紫夜幕、珊瑚粉流势丝带、五枚交替拍点圆、虚线气流轨与右上象牙明月焦点，叠加实时「视线浮标」惯性试游引擎）。
- **怎么玩**：
  - 直接在画布上横向/自由拖拽（`data-perf-drag`）弯道塑形节（入弯 / 中腰 / 收弯），实时重塑 S 曲线的弯曲度与转角；
  - 直接点击画布中段带警示虚线的断口处将其弥合（或主动切开测试断流）；
  - 通过画布下沿精简海报控台调校弯道顺滑阶（硬折断流 / 柔弯贯通）、拍点呼吸（扎堆撞拍 / 机械等距 / 张弛有度）与终点落点（失焦溜边 / 偏靶滑过 / 明月收束），并可一键切换「原海报丝带 / 浮世绘浪势 / 长页叙事流」三套场景。
- **开场初始态（0/4 翻车错态，绝非答案）**：
  1. 弯道为「硬折拐角」，中段出现 > 90° 锯齿折角，视线浮标撞角打滑停滞；
  2. 丝带中段存在 22% 物理断口，流势半路断裂；
  3. 5 枚拍点圆扎堆挤在下弯同一侧，丧失张弛有度；
  4. 右上象牙明月缩小至 0.42× 且收尾切线偏靶滑向顶边，视线无处落脚。
- **怎样算玩错与读数怎么说**：
  - 全部由 `model.js` 从实绘样条点列、弯曲比 $L/D$、最大局部转角、断口占比、拍点沿弧分布熵、出口切线靶距与终点视觉权重单真源核算，能诊出 8 类失误：`硬折断流`、`半路断桥`、`死水僵直`、`过密蛇行`、`拍点扎堆`、`机械等距`、`终点溜边`、`失焦过弱`。
  - 接受多种合法解（原海报经典 S 势、宽摆舒缓势、紧凑灵动势等，只要满足平滑无折角、弯曲比落入 1.14–1.68 经验甜区、连续无断口、拍点有呼吸、出口入靶且焦点够稳即通过）。
  - 读数以白话解释「为什么会这样看」（例如：撞上 108° 折角时视线必须急刹重算方向，惯性当场归零），不写死常量，经验带标明「经验参考带」。
- **与最近 12 页的区别**：
  - 112 是钴蓝斜升阶梯/柱阵调跨度与破拍；111 是朱红四轨点翻 A/B 调相位；317 是青灰横卷展幅调地平线；028 是圆窗移轴；066 是月洞门视差穿框；195/196/234/235/279/150/151 分别为分栏/网格/固定定位/粘性滚动/日历/谜面/拼贴。
  - 113 独有「直接弯折连续曲线脊柱 + 实时视线浮标惯性碰撞/滑行模拟 + 弥合中段断口 + 切线收靶」，且是近 12 页唯一的深夜紫 + 珊瑚粉 + 明月流势舞台。

## 3. 版式骨架
- **忠实承袭 113 原海报的「无框深紫夜幕对角流势整幅骨架」**（无通用深色仪表盘圆角侧栏、不锁 `min-height: 100svh` 避开平板大空洞）：
  - **1440×900（2560 扩宽至 1820px）**：顶眉细线之下，整张开场铺在统一的 `#170627` 深紫夜底上；左 35% 开放排布沿柔和波形基线起伏的示范大标「流动节奏组织」、`FLOW RHYTHM`、短粉杠、`曲线 / 引导 / 连绵 / 动势` 实时状态条、左侧粉竖线总述与白话单真源诊单；右 65% 无缝展开巨幅对角 S 丝带画布（嵌原海报 5 组折线标注与右下 6×6 粉点阵）；底部接一条贴合原海报气质的细线控台条。
  - **1024×1366 / 768×1024 平板**：自然高度不拉空，顶刊紧排 + 全宽等比 S 丝带画布 + 双栏并排诊单与控台。
  - **390×844 手机竖屏**：压缩单行刊头（约 60px），紧接 5:4 等比无遮挡夜幕丝带画布（稳占首屏 ≥ 46% 屏高，圆点保持正圆），同屏可见快速校准键与白话诊单主句。
  - **844×390 手机横屏**：左 56% 丝带画布 × 右 44% 刊头、诊单与快捷开关并排。
  - **正文 8 节底色节奏**：夜幕深紫（开场）→ 象牙浅宣（01）→ 淡紫雾纸（02）→ 深紫暗室（03 溯源）→ 暖羊皮纸（04 节奏家族）→ 象牙浅宣（05 真实版面）→ 淡紫雾纸（06 禁用边界）→ 深紫工坊（07 练习）→ 象牙浅宣（08 原海报与页脚）。

## 7. 小练习设计
- **题干**：夜展海报要把视线从左下入口顺畅引向右上象牙明月主焦点。以下四版完全同色、同字号、同终点位置，仅调整曲线连贯与收尾流势，哪一版最能做到「连绵前行、自然落点」？
- **四选项（仅标中性标签「方案 A / B / C / D」）**：
  - **方案 A**：硬折锯齿 + 中段断口（撞角急刹、流势中断）
  - **方案 B**：过密三连急弯蛇行（弯曲比 > 2.0，眼晕打转失前驱力）
  - **方案 C（正确）**：顺滑 $C^2$ 大 S 弯（弯曲比 ≈ 1.34）+ 五拍错落呼吸 + 切线直指明月
  - **方案 D**：同样顺滑的 $C^2$ 曲线，但上弯切线偏左滑向画框外缘且拍点扎堆底部（焦点孤立）
- **为什么难倒蒙题者**：C 与 D 同样丝滑，B 与 C 同样连通明月，必须同时理解「顺滑连续 + 弯曲适度 + 拍点张弛 + 出口入靶」四件事才能选对。
