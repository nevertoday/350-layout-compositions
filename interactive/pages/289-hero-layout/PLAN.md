# 289 主视觉布局（HERO LAYOUT）设计方案

## 1. 一句话道理
人眼在打开网页的前几十分之一秒就会先做视觉定调、再在首屏折叠线之上判断「这东西跟我有什么关系」与「下一步点哪」；主视觉布局把 **主视觉（Hero）→ 信息聚焦（Message）→ 行动引导（Action）** 压进同一块首屏视口里，用一条不绕弯的视线路径代替满屏堆料，让访客一屏看懂、一步行动。

## 2. 开场玩具
- **名字**：首屏聚光剧场 · `H / M / A` 活体首屏编排台 + 0.5 秒盲闪测验
- **怎么玩**：
  - 舞台是一块带真实「首屏折叠线（Above the Fold）」和下方裁切阴影区的活体网页视口（2D Canvas，标 `data-perf-drag`）。
  - **左右横拖画布**：连续推拉主视觉占比（14%–84%）并同步挥动 289 原海报的明黄聚光切角与钴蓝斜楔，实时看到视觉体量扩大/收缩如何挤压文案区或把行动按钮顶出首屏。
  - **点按画布内三个活体区块**（`H 主视觉` / `M 标题文案` / `A 行动按钮`）或下方 `H / M / A` 控台：切换三种真实题材（`海报母题 · 设计工坊` / `声学硬件 · 极光耳机` / `效率工具 · 秒记白板`）、四种构图骨架（`海报斜切` / `左文右图` / `全出血暗罩` / `居中宣言`）、轮播干扰开关、三档信息文案（空话套话 / 抽象口号 / 一句话价值主张）、四档行动按钮形态（折线下失踪 / 四钮打架 / 灰字隐身 / 主次分明），以及三档视口折叠线高度（560px 矮笔记本 / 720px 常规桌面 / 844px 手机）。
  - **特色动作「⚡ 0.5 秒盲闪测验」**：模拟首屏初见闪映，按当前实绘框体几何与对比度直接给出「第一眼抓到了什么、卡在了哪里」。
- **初始状态（刻意错态）**：开场不是答案——主视觉缩到 22% 且开启「自动轮播」干扰；标题是 28 字空泛企业套话；主按钮被顶在首屏折叠线下方且并排 4 个同权按钮。右上「阅读顺序 ①→②→③」虚线箭实时标红。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - `model.js` 单真源按实绘坐标（`visualRect`、`messageRect`、`ctaRect`、`foldY`）和背景/文字真实相对亮度比（WCAG 2.1 公式）核算 9 类错态：视觉失权（<34%）、画面霸屏挤掉行动（>74% 或压过折线）、轮播横幅盲视、空话套话、口号无解释、叠字对比度不足（<4.5:1）、主按钮掉出首屏折叠线、多按钮决策内耗、按钮低对比隐身。
  - 读数绝不造「吸引力 94%」类假精确分数，只报实测几何值（主视觉占比 %、按钮距折线 px、实算对比度 `:1`、标题字数）配白话「为什么」与质性档位（如「一秒入眼 / 视线迷路 / 按钮藏在折叠线下」），并接受斜切海报、左文右图、全出血暗罩、居中宣言等多组合法解。
- **与近期 12 页的差异**：近期多为几何原理绘图板或左右两栏诊单仪表盘（如 288 暗黑影音配对、246 桃纸圆点聚类、287 冷灰三栏设置窗）；本页紧贴 Hero 本身「首屏折叠线裁切 + 50ms/首屏扫视 + H/M/A 三段转化」动作，做真能切设备折线、测盲闪、改叠字对比度的活体首屏网页剧场。

## 3. 版式骨架
忠实转译 289 原海报的**构图主义暖象牙纸 × 钴蓝斜切角 × 顶右竖向阅读顺序虚线箭 × 全宽首屏舞台 × 下方双联细钴框（左 `H / M / A` 操控框、右 `好的 Hero 布局 = 3 个关键` 实测三栏）× 底沿通栏钴蓝标语带**（零暗色顶栏、零左右圆角侧栏、绝不写 `min-height: 100svh`）：
- **1440×900**：主宽 1380px（2560 舒展至 1760px）；紧凑刊头（左巨幅钴蓝 `Hero` + `主视觉布局`、右实况阅读顺序 ①②③ 与盲闪钮）→ 宽幅活体首屏剧场（~450px 高）→ 原海报双联细框（左 `H/M/A` 控台、右三关键实测）→ 全宽钴蓝底带，整套首屏刚好自然落在一屏内。
- **1024×1366 / 768×1024**：不锁 100svh，首屏结束后自然接 01 节，零纵向空洞。
- **390×844**：压紧单行刊头与题材切换，让等比活体首屏剧场稳占首屏 ≥47% 高度，紧跟一行首屏结论与 `H / M / A` 快捷按钮，总述文字放后面，圆和几何图严格等比缩放。
- **844×390 横屏**：切换为左 55% 活体首屏舞台 × 右 45% 紧凑刊头、结论与快捷控台的并行双栏。

## 4. 配色和字体
- **配色（逐像素实采自 289 原海报）**：
  - 暖象牙原纸 `#F9F2E2`（亮纸 `#FFFBF0`、暖砂纸 `#EFE6D1`、淡钴雾纸 `#EBF0FA`）
  - 标志国际钴蓝 `#0C32AB`（展示蓝 `#0C2FA7`、底带蓝 `#0D30A8`、03/07 暗室深钴 `#081D66`、暗舱 `#0E287A`、细框灰蓝 `#6E78A3`）
  - 标志明黄聚光 `#F9B81A`（横杠 `#F9B619`，浅纸绝不作文字色，浅纸暖黄字压深为赭金 `#8A5300`；暗钴底上 `#F9B81A` 对比度 >8:1）
  - 主墨 `#1B1C19`、次墨 `#474942`；克制以绯红 `#B91C2E`（暗底 `#FF8A96`）标错态、松翠 `#0E6B4F`（暗底 `#6CE6B8`）标通畅。
- **字体（全库唯一，且三款在近 12 页均为 0 次使用）**：
  - `Outfit`（500/700/900，近 12 页 0 次）：巨幅几何展示 `Hero`、`H / M / A`、`HERO LAYOUT`
  - `Smiley Sans`（得意黑 400，近 12 页 0 次）：呼应原海报倾斜粗体标语「让设计第一眼就解决问题」及展示强调
  - `DM Mono`（400/500 + italic 400，近 12 页 0 次）：首屏几何读数、对比度、折叠线像素、`SEE · UNDERSTAND · ACT`
  - `Noto Sans SC`（400/700/900）：清晰几何黑体中文标题与正文（中文段落内人名/年份统一正文体，不跳字号）

## 5. 节目录（7 节，每节 h2 ≤ 10 字，相邻节控件不重样）
- **01 三步链条：看、懂、做**：拆解原海报三大要点与阅读顺序，交互为「三段视觉权重排序器」（点选 4 种顺序对比 SVG 视线动线，温和补充信任证明的位置）。
- **02 剧场、报摊与首屏研究**：梳理 Hero Prop / Hero Shot / Above the Fold 渊源与 2000–2018 实证研究，交互为「50ms → 10s 注意力时间节点检视器」与 2010→2018 首屏停留对比。
- **03 四种骨架与跨屏裁切**（深钴暗室）：对比斜切海报、左文右图、全出血暗罩、居中宣言四种骨架，交互为「骨架 × 设备高度（1440 / 1280×720 / 390）跨屏裁切器」，顺带一句链接 272 便当盒与 288 媒体对象。
- **04 叠字对比与首屏加载**：解决大图叠字看不清与 LCP 性能陷阱，交互为「遮罩方案与实时 WCAG 测光滑杆」（实算主光斑处对比度并动态输出可用 CSS 与 `<link rel="preload" fetchpriority="high">` 写法）。
- **05 什么时候别用主视觉**：列出 4 类典型反例（高频工作台、搜索检索页、轮播分赃墙、100vh 假底部），一句链接 273/283/286/274/269/276/275/270，交互为「四类产品首屏分诊卡」。
- **06 小练习：四选一首屏**：纯中性标签 A/B/C/D 四张同产品 SVG 线框，每张只改一个变量（完整正解 / 按钮掉出折线 / 四钮平权内耗 / 标题空泛套话），选后拆解因果。
- **07 原海报与关键词**（深钴展墙）：原海报点击放大/拖动/Esc 关灯箱 + 原海报关键词与口号。

## 7. 练习
- **题目**：同一款「云端字体协作工具」的首屏，四套方案在视觉风格、配色与字号上都干净工整，只有一个关键结构变量不同——哪一套最符合主视觉布局的首屏要求？
- **四项差异**（仅中性编号 方案 A / B / C / D）：
  - **方案 A（正解）**：右侧 54% 主视觉 + 左侧 11 字明确价值主张 + 1 枚高对比主按钮 + 折叠线内微露次节眉线。
  - **方案 B**：仅改变主视觉高度撑满首屏，把主按钮刚好挤到首屏折叠线下方 `-24px`。
  - **方案 C**：仅把单一主按钮换成 4 枚同等权重的并排按钮，引发选择内耗。
  - **方案 D**：仅把具体价值主张换成 20 字抽象品牌口号配四行密文，扫不出产品用途。
