# 260 圣杯布局（HOLY GRAIL LAYOUT）互动页方案

## 1. 一句话道理
圣杯布局用「满宽页眉 + 满宽页脚 + 两侧定宽功能翼 + 中央流式主区」五区耦合框架，把导航、核心正文与辅助信息各安其位，既在宽屏维持稳定秩序与等高平衡，又能随视口收缩按优先级逐翼折收、守住主内容阅读区。

## 2. 开场玩具
- **名称与载体**：圣杯五区响应伸缩与等高承重台（Holy Grail Five-Zone Responsive Frame，2D Canvas，标 `data-perf-drag`），1:1 承袭 260 原海报深梅紫圆角顶底双梁、淡紫左右侧栏与暖象牙白主内容区，并内建「原海报·综合门户 / 技术文档系统 / 课程学习平台」三套真实界面标本。
- **怎么玩**：
  - 在画布中横拖（或拖右边缘标尺把手）连续拉伸/收缩模拟视口宽度（`360px ↔ 1360px`），实时看五区宽比、逐行折行字数与断点响应；
  - 直接拖画布内左右两条浅紫栏界轨独立调左侧栏与右侧栏宽（`100px–340px`），或直接点两翼顶角折叠钮一键隐藏/展开侧栏，观察中央流式区如何自动吸满空位；
  - 切换「等高与粘底锁」「响应式折翼」「正文篇幅（短/标准/长）」「页眉高度」及「HTML 源码优先序」，按 `Space` 开关源码阅读流透视线（①→②→③→④→⑤ 发光路径）；方向键 `←/→` 微调视口宽、`↑/↓` 调双翼宽。
- **开场初始态（绝非答案）**：刻意停在 `0/4` 复合破局态——视口 `880px` 下双翼各占 `256px`（合占 60% 夹扁中间主区仅剩 `312px` / 约 17 字/行）+ 短文关闭等高锁导致三列底沿落差且深梅紫页脚悬空 + 响应式折翼关闭 + 源码左栏优先抢位。
- **怎样算玩错 & 读数怎么说「为什么」**：`model.js` 从实绘五区矩形与实测逐行字数单真源核算 8 类双向错态（夹心窒息、双翼过胖、侧栏过窄折字、无翼超宽长行、页眉臃肿夺屏、三列参差与页脚悬空、窄屏硬撑三列、源码序倒挂）；每种错态都直接讲清「这样摆会怎样打断读者视线、读屏路径或屏效」，并认可原海报经典三列解、收起右翼文档解、820px 平板降级解、390px 手机单列解及任意合法自调组合。
- **与最近 12 页的区别**：338 是双卡天平、137 是跨页书脊、218 是直排转盘、259 是双极分屏、258 是单侧边栏推拉、173/172 是网格拼块；本页独创「整台五区网页实时视口连续缩放 + 双翼独立折叠 + 三列等高粘底物理承重 + DOM 源码阅读流透视」，换到同小类任一编号都无法套用。

## 3. 版式骨架
- **1440×900（主宽 1360px；2560 舒展至 1640px）**：忠实转译 260 原海报「上二分细竖线刊头（左自示范比例条巨标『圣杯布局』+ 总述 × 右『核心概念』与四枚淡紫圆徽活体探针）→ 中区建筑剖面舞台（左 16% 原海报三段虚线圆点外挂标尺 `头部 HEADER / 主体 BODY / 底部 FOOTER` × 右 84% 场景切签 + 开放圆角深梅紫五区画布 + 紧贴单行精控轨）→ 齐底双联单真源诊单与多解舱 → 原海报底沿五列细竖线结构要点条 + 淡紫双引号宣言与 5×4 点阵横幅」。绝不锁 `100svh`，避免 1024×1366 平板竖屏大空白。
- **390×844 竖屏**：顶行压紧单行刊头（`NO. 260` + `圣杯布局` + 状态章），总述与四圆徽后置到诊单下方；等比画布稳占首屏 ≥ 46% 高度且不压扁，折线内直露场景切签、活体画布、深梅紫诊单首句与一键校准按钮。
- **844×390 横屏**：切换为左 56% 等比五区画布 × 右 44% 紧凑刊头 + 单真源诊单 + 快捷校准并行。

- `02 · 五区如何各司其职`（FIVE ZONES IN CONCERT）：展开原海报四要点并温和校正「适应多种内容」的边界；交互为「五区功能职权装配体检盘」（点选或错配真实模块看视线跳转与认知负荷）。
- `03 · 从桌面到手机的折翼术`（RESPONSIVE COLLAPSE）：深梅紫暗室，讲三端断点降级次序与源码主区优先；交互为「宽尺同步三端渲染与源码读屏流对照台」。
- `04 · 与同族骨架怎么选`（CHOOSING THE RIGHT FRAME）：精准区分 255–268 同小类并附一句话外链；交互为「三问决策滤镜」实时点亮推荐骨架与外链。

## 7. 练习
3 道单变量辨析题，选项均为 A / B / C / D 中性参数与配图（绝不泄露好坏词）：
1. **1280px 文档页三栏像素配比**（只差 `L / Main / R` 宽度：320/640/320 vs **220/820/240** vs 110/1060/110 vs 400/480/400）→ 选 B：双翼刚好容纳目录与提纲不折行，中央 820px（扣内边距后约 34–40 中文字/行）阅读最从容。
2. **820px 平板断点折叠策略**（只差收折规则：同比硬缩三列 vs **保留左栏 210px 并把右栏下沉至正文下方** vs 藏左留右 vs 三列横向滚动）→ 选 B：先卸次要右侧辅助栏，既保留导航定位又把约 70% 宽度还给主内容。
3. **短文帮助页的源码顺序与页脚定位**（只差 DOM 顺序 + 高度约束：左栏先出+自然高 vs 右栏先出+100vh 裁切 vs **主内容靠前/配跳过导航 + min-height 满屏推底页脚** vs 页脚置顶+绝对定位）→ 选 C：兼顾读屏键盘效率与不悬空不遮挡的稳固底梁。
