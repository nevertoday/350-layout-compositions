固定网格的第一要务是先立一把干脆的整数尺：公式 W = 2m + n·c + (n−1)·g 算不出整数列宽时，屏幕渲染容易发虚，设计师与工程师报尺寸也总差 1 像素。

先校准对称整数尺，再把偏轨模块吸进樱粉列线。

固定网格是一种预先设定好列、行和间距的版式系统，所有内容在同一套规则下进行对齐与排列，建立稳定、可控的视觉秩序。

01

一套尺子，
四条支柱

Four pillars of order

原海报的定义一句话点穿了固定网格的根基：「通过统一的列宽、间距和行高，将版面划分为固定的模块单元，所有元素在模块中定位与组织。」

它和只放单栏长文的 194 手稿网格 不同，也不只是纵向分栏的 195 分栏网格；它最核心的承诺是「绝对尺规不变」——不管这一页放一篇深度访谈、下一页换三张摄影大图，列线、栏距和页边距都停在同一个毫米或像素坐标上。读者翻页时不需要重新适应页面结构，团队交接时只需报出「占 4 列、栏距 24px」就能精准还原。

第 1 页专题导读：左侧 2 列放导语与页码，右侧 4 列放跨栏主图与副栏正文。列宽 92px、栏距 24px、边距 24px 丝毫不改。

02

从瑞士画板
到 960 像素

Where it comes from

固定网格并非屏幕时代的发明，它先诞生于纸张开本绝对固定的书籍与印刷世界，在 20 世纪中叶被瑞士平面设计师数学化，又在 2008 年借着 960 像素骨架彻底改变了早期网页开发。

  1. 13C / 1975
    古典书籍版心构造

    13 世纪法国建筑师维拉尔·德·奥内库尔（Villard de Honnecourt）的手稿已出现几何分格法；字体设计师扬·奇肖尔德（Jan Tschichold）在 1975 年结集的《书的形态》（The Form of the Book）中系统考证了这类在固定纸张开本上以对角线锁定版心与边距的构造规矩。

  2. 1964
    把版式写成「程序」

    瑞士设计师卡尔·格斯特纳（Karl Gerstner）由尼格利出版社（Arthur Niggli）出版《设计程序》（Designing Programmes），提出与其为每一页手工想一个答案，不如制定一套固定比例与规则的「程序」来容纳未知图文。

  3. 1981
    网格系统的经典手册

    约瑟夫·米勒-布罗克曼（Josef Müller-Brockmann）同样由尼格利出版社推出德英双语名著《平面设计中的网格系统》（Grid Systems in Graphic Design），详述了 8 至 32 格的固定网格构造法，成为全球排版教学与多栏 196 模块化网格 的共同起点。

  4. 2008
    960 Grid System 统治早期桌面网页

    网页设计师内森·史密斯（Nathan Smith）发布 960 Grid System：面向当时主流 1024×768 屏幕，将容器锁死在 960px，提供 12 列（每列 60px）与 16 列（每列 40px）、固定 20px 栏距与左右 10px 边距，让前端工程师第一次摆脱反复手算小数的痛苦。

  5. 2009–2010
    从纯固定走向流体与响应式

    随着手机屏幕涌现，伊桑·马科特（Ethan Marcotte）在 A List Apart 先后发表《Fluid Grids》（2009）与《Responsive Web Design》（2010），用相对比例把固定网格升级为跨屏体系；W3C 的 CSS Grid Level 1 则至今仍保留了固定长度轨道（如 px）作为精确控制手段。

为什么当年全世界的网页都锁在 960px 或 1200px？

切换总宽、边距与栏距，看固定公式 c = (W − 2m − (n−1)·g) ÷ n 在不同列数下能否切出干净整数。

03

基线秩序与行高

Baseline & leading anatomy

横向对齐靠列线，纵向节奏靠基线。原海报左下专门画出了一张 Ag 四线解剖图，提醒我们：只有所有栏里的文字共享同一把行高尺子，左右栏才不会越往下读越错位（专门的垂直节奏系统见 198 基线网格）。

原海报经验值：建议行高 1.4 – 1.6 倍字号

这是面向中英文正文的通用经验区间，字号越小或行长越宽时可略微上浮。

信息对齐，阅读有序

所有文字基于相同基线与行高，形成统一的阅读节奏。当左侧有标题介入时，标题总占位必须等于正文基线步距的整数倍。

如果左栏标题行高随意写成一个零头像素，右侧正文从第一行起就会和左侧悄悄错开几像素，读到页底时两栏底边就会一高一低，破坏固定网格的秩序感。

典型场景与边界

Typical uses & a caveat

原海报列出了固定网格最常发挥威力的三类作品。点击下面任意一张场景卡，查看该媒介里真正落地的固定尺规参数：

印刷固定开本 A4 (210×297mm) · 6 列 · 栏距 4mm · 基线 12pt

说多了一点

固定网格本身，并不自动带来「响应式适配」

原海报在第二张场景卡里写着「网站 / APP 界面：模块化布局，利于响应式适配」。实际工程里，如果只用纯固定像素网格（例如写死 width: 960px），小屏手机根本塞不下、只能横着拖滚动条，超宽显示器又会在两侧空出大片白边。

真正支撑现代多端界面的，是把固定网格的列跨度思维与步距规范放进断点容器里，在断点之间配合 208 流体网格 与 209 响应式网格；局部卡片和复杂组件内部，再借助 205 嵌套网格 或 206 子网格 继承全局轨道。

05

什么时候别用它

When not to use it

固定网格假设「容器画幅是确定不变的」。一旦画幅尺寸无法提前锁死，或者内容本身拒绝规矩切块，死守固定像素尺子就会立刻适得其反。

A · 纯固定网格（锁定 960px） 右侧溢出 +570px
B · 流体比例对照（按百分比伸缩） 占宽 92% · 零溢出

多端未知尺寸网页
同一套页面要从 360px 手机横跨到 2560px 大屏时，纯固定宽会两头受罪；改用 208 流体网格 与 209 响应式网格。
情绪张扬的先锋海报
音乐节、实验展览需要打破呆板节奏制造张力时，可主动转向 200 非对称网格、210 破格网格 或 211 解构网格。
向心圆盘与雷达图表
围绕一个中心向外辐射的仪表、星图或唱片封套，硬塞进直角列行只会扭曲结构，应使用 203 放射网格 或 204 极坐标网格。
纯连续文学长篇
小说和散文最重要的是沉浸流畅的连续行文，过度切割成多列多块反而打断呼吸，单栏稳妥的 194 手稿网格 往往更合适。
