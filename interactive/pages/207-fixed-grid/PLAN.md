# 207 固定网格 FIXED GRID · 方案

## 1. 一句话道理
固定网格先用整数像素或毫米把「总宽、列宽、栏距、边距、行基线」钉成一把不变的尺子；所有图文模块按整数跨度落进这把尺子，换内容、换页面时骨架不动，从而把对齐判断变成可复用、零歧义的工程规则。

## 2. 开场玩具
- **名称**：固定网格拼版台 · 原海报 6 列活体落格器（2D Canvas，`data-perf-drag` 绑在主画布上，中心正对原海报核心焦点「信号朱红实心圆」）。
- **怎么玩**：
  1. 1:1 承袭 207 原海报的樱粉列带、暖白栏缝、虚线行格、顶部 `MARGIN ← COLUMN → MARGIN` 工程尺寸标尺，以及 6 枚真实可操作模块（大深紫方块、深紫大 ×、中央信号朱红圆、右中紫方、左下紫三角、右下深紫三横杠文块），可切「原海报几何 / 杂志内页 / 960 网页原型」三题材。
  2. 直接在画布上拖拽任意模块移动位置（中心横拖即平滑拖移信号朱红圆，满足 `data-perf-drag` 连续重绘测试），开启「磁吸格线」时靠近列线与行线轻吸并显示对齐轨；也可用键盘方向键微调选中模块、切换模块跨列（1/2 列）。
  3. 左侧尺规装配槽可调固定网格尺子本身：列数（4/6/8/12 列）、总宽（720/740/960/1200px）、栏距（0–64px）、文本行高倍率（1.1×–2.0×）、模拟视口宽（360–1440px），并可点「跨页复验（第 1/2/3 页）」查看同一固定网格容纳不同页内容时的稳定性。
- **开场状态（0/4 失序错态，绝不先给答案）**：
  - 总宽误设 `740px`、6 列、栏距 `22px`、左右边距不等（`18px / 38px`），算出亚像素列宽 `95.67px`（尺子本身碎裂不整除）；
  - 顶部大方块左偏 `+17px` 压断栏缝，中央朱红圆骑跨第 3/4 列栏缝偏移 `+14px`（破缝脱轨）；
  - 右下文本块行高 `1.15×` 脱离基线步距，底边戳出网格行线（基线失序）；
  - 重心与跨栏未锁，诊单显示 `0/4 待校准`。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 由 `model.js` 从当前实绘模块矩形与网格公式 `W = 2m + n·c + (n-1)·g` 单真源实时核算 7 类真错态：**亚像素碎尺**（列宽非整数或左右边距不均）、**骑缝脱轨**（模块边缘偏离列线或压进栏缝，报精确像素差）、**栏距挤死/散架**（`g = 0` 粘连或 `g ≥ c` 版面碎成孤岛）、**模块叠撞**（两块真实矩形相交）、**重心偏倾**（全部模块堆到单侧致视觉失衡）、**基线失锁**（行高越出 1.4–1.6× 建议带或非基线步距）、**固定宽窄屏溢出**（模拟视口 `< W` 时右侧出红线报溢出像素，亲手体验固定网格的物理边界）。
  - 每次报错都讲清「人眼会怎么看、为什么坏了」，并接受多种合法配置（如原海报 6 列 720px、经典 12 列 960px、4 列刊物格等不同摆法）。
- **与近期 12 页的明显区别**：
  - 206 是全幅克莱因蓝 12 列子网格父子继承控开关；205 是暖燕麦绿脊拖单条橙分界线；247 是深松青竖脊拖右壁测 flex-wrap；122 是包豪斯左右双室剥离杂件；207 是**浅樱瓷粉 + 深桑葚酒紫 + 朱红焦点圆**瑞士拼版台，核心动作是**亲手把多枚模块拼装进固定像素尺、调出整数整除网格、切页复验同格复用、并在视口缩放下撞见固定宽溢出边界**。

## 3. 版式骨架
- 忠实转译 207 原海报「无深色顶眉黑箱、1px 锐利直角建筑细线、左文右图对开结构（不锁 `100svh` 避开平板空洞）」：
  - **1440×900（主宽 1360px）& 2560×1440（舒展至 1720px）**：首屏上区为等高双栏——左 44%（标志酒紫顶杠 + 自示范等格大标「固定网格 FIXED GRID」+ 原海报总述 + 1:1 复刻原海报左下的 1px 细框单真源「定义与实时诊单盒」+ 紧凑尺规装配槽）× 右 56%（顶部活体 `MARGIN ← COLUMN → MARGIN` 工程标尺 + 大幅 2D 活体拼版画布 + 底沿跨页复验与多解/试错快钮）；紧接一根贯穿全宽的 1px 玫瑰细线，下方直承原海报「核心优势 KEY BENEFITS」5 列实时状态横带。
  - **1024×1366 & 768×1024 平板**：顶刊头 → 通栏活体画布 → 双栏诊单与尺规 → 2×2 核心优势，无任何 `100svh` 空洞。
  - **390×844 手机竖屏**：压缩为单行紧凑刊头（标题 + 达标徽），后置总述文字，第二顺位立刻呈现等比大画布（稳占首屏 ≥ 48% 高度），其下同屏直见单真源诊单首句与一键校准辅助。
  - **844×390 手机横屏**：切为左 54% 拼版画布 × 右 46% 紧凑刊头、诊单与核心快钮并行。
