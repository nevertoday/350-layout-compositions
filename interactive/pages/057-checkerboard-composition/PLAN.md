# 057 棋盘构图（CHECKERBOARD COMPOSITION）方案

## 1. 一句话道理
将画面等分为正交方格，依靠相邻模块在「实与空、深与浅、密与疏」上的规律交替建立稳定节拍，再通过**唯一一处破格焦点**（或清晰跨格主标）打破全盘均质，让观众既有秩序可循、又有明确入口。

## 2. 开场玩具：活体棋盘落子与错缝排演板（2D Canvas，`data-perf-drag`）
- **形态**：1:1 承袭 057 原海报的 4×5 建筑方格矩阵（含原海报 2×1 跨格主标槽、深森林绿实块、5×5/4×4 点阵、虚线方框绿圆、黑菱形、3×3 迷你棋盘、45° 绿斜线、纯黑巨圆、嵌套同心方框与唯一琥珀金圆洞焦点格），支持「原海报 · 几何韵律 / 画册跨页 · 图文交替 / 品牌展墙 · 展品陈列」三套实景脚本。
- **怎么玩**：
  1. **直点方格落子**：点击画布任意可编辑方格，在「留白浅格 → 深绿实格 → 琥珀金焦点」间循环（或选定笔刷直落）；相邻同色结块的共享边实时亮起朱红预警锯齿缝。
  2. **左右横拖画布（`data-perf-drag`）**：连续滑动偶数行「正交错缝相位」（`-50%` 砖墙半格错缝 ↔ `0%` 正交锁正 ↔ `+50%`），偏离 `0%` 时纵轴断裂并触发红虚线错轴告警，拉近 `0%` 轻吸附锁正。
  3. **滑轨微调**：同步控制「偶数行错缝相位」与「模块缝宽（0–14px）」，支持键盘方向键移格、Enter 落子、Space 释放跳格视线节拍演播。
- **一打开的状态（0/4 破局态，绝不预给答案）**：偶数行右偏 `+24%` 错缝断轴 + 10 条实格共享边粘连成团（交替率 50%）+ 同时亮起 2 枚琥珀金格造成双焦内讧 + 实格占比达 67% 过满压闷。
- **怎样算玩错 & 读数怎么说「为什么」**：由 `model.js` 从实绘 20 格数组与相位参数单真源核算 4 项几何律（正交对位 / 交替完整 / 疏密均衡 / 唯一焦点），双向检出 8 类错态（砖墙错缝、同色结块、纯棋眩晕 0 焦、多焦内讧 ≥2 焦、过满窒息 >61%、过空散架 <33%、单边条纹化、复合错态），每次用白话讲清观众视线为何会打结或眩晕，并给出一步可执行的调整动作；同时认可原海报解、反相棋盘解、大留白疏棋解及用户自行落出的任何 4/4 合法解。
- **与最近 12 页的区别**：最近 12 页覆盖净单人清场、普通流单列折行、排印字阶、石碑重力水平仪、右轴配重、向心箭头、空白页留白、左对齐修边、3D 广场机位、旁注字阶、星爆射线、杂志斜切裁图——没有一页做「正交方格落子 + 行相位错缝滑动 + 邻格交替边实时检错」的棋盘编排板。

## 3. 版式骨架
- 忠实转译 057 原海报「0px 锐利建筑方格纸页 × 交替方格刊头 × 2×2 棋盘探针 × 底部四词竖线标尺」骨架（零通用暗灰仪表盘、绝不锁 `100svh` 避平板大空白）。
- **1440×900（2560×1440 扩宽至 1680px）**：顶部单行棋盘格刊头（绿方编号 + 4 格交替自示范主标「棋盘构图」+ 三脚本格 + 状态/演播格）→ 左 53% 等比 4×5 棋盘主画布 × 右 47% 齐底编排阵（顶栏单真源诊单 + 中部 2×2 原海报四要点交替探针格 + 底部笔刷/相位/多解试错条）→ 底部 1:1 复刻原海报「棋盘构图的核心」与四枚竖线几何徽标。
- **1024×1366 / 768×1024 平板**：自然文档流满宽画布 + 下方双栏齐底诊单与 2×2 探针，零垂直留白黑洞。
- **390×844 手机竖屏**：压缩单行刊头与三脚本签，等比 4×5 正方棋盘画布稳占首屏 ≥ 46% 屏高，折线内直露单句白话诊断、一键校准/演播双键与错缝相位主轨，绝不压扁方格。
- **844×390 手机横屏**：紧凑顶眉下切左 50% 等比画布 × 右 50% 诊单与相位快控并行。

## 5. 节目录（7 节，相邻节控件绝不重复）
- **01 · 交替为何能稳住视线**：借格式塔与明度恒常原理解释邻格对比；交互为「棋盘阴影明度剥离验证台（SVG 同色灰桥开关 + 有无交替边界切换）」。
- **02 · 原海报四条结构铁律**：逐条引述原海报四条要点并温和修正「自带焦点」过头处；交互为「四要点高亮解剖蓝图（点四条原则在原海报矢量结构图上联动透视对应图层）」。
- **03 · 从浮世绘到瑞士网格**（深森林绿暗室）：考据 1741 市松模様、1919 蒙德里安棋盘画、1981 瑞士网格手册与 1995 棋盘阴影错觉；交互为「四时代档案切片 + 2D Canvas 结构复现画板」。
- **04 · 三招跳出瓷砖墙纸感**：实战讲解单格跳色、跨格并槽、三级疏密，并一句话链接同一小类 058–064；交互为「真实 CSS Grid 活体跨页编排开关板（跨格/单焦/肌理/移动端 2 列预览）」。
- **05 · 什么时候别用棋盘**：剖析长文阅读、严格时序、全景冲击、细密眩晕四类忌用场景；交互为「四张双面案例诊断翻卡（踩坑棋盘稿 ↔ 对症改版方案）」。
- **06 · 实战眼力小练习**（深森林绿考场）：两道单变量盲测选择题（中性标签方案 A–D，聚焦破格焦点数与正交/疏密比例），选完实时揭晓几何依据。
- **07 · 原海报典藏与关键词**：原海报高清灯箱（点击放大、拖动平移、Esc 关闭）+ 原海报核心原文、四枚关键词几何章与同小类导航链接。

## 7. 练习设计
- **第 1 题（单一变量：焦点破格与局部交替）**：4 组完全同尺寸、同字号、同配色、同 2×1 跨格标题槽的 4×4 展览海报微缩图（中性标签 `方案 A`–`方案 D`）：A 为 0 枚琥珀金的纯均等棋盘（眩晕无入口）、B 为严密交替 + 2×1 跨格标题 + 唯一 1 枚琥珀金焦点（正解）、C 为 3 枚琥珀金焦点互抢、D 为 1 枚琥珀金但左下 2×2 深绿粘连结块。
- **第 2 题（单一变量：正交对位与疏密比例）**：4 组同一作品集 4×4 网格（`方案 A`–`方案 D`）：A 为偶数行错缝 40% 失纵轴、B 为 81% 实格过满压闷、C 为 19% 实格退化为散点、D 为 50% 严格正交交替 + 唯一琥珀金入口（正解）。
