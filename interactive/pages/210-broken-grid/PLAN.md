# 210 破格网格 BROKEN GRID — 互动页设计方案

## 1. 一句话道理
破格网格不是抛弃网格，而是先让底层网格的秩序清晰可见，再只为 1–3 个核心焦点做干脆的跨栏、偏移、越界或斜切，靠「守序的大多数」托住「出格的少数」，制造聚焦与张力。

## 2. 开场玩具（5×6 活体破格排印张）
- **核心动作**：1:1 承袭 210 原海报的 5×6 虚线模块网格与红/黑/蓝构成语言，画布上直接放置 6 个可独立选中的真实排版模块（主标块、右上朱红圆、纯黑斜块、朱红横块、克莱因蓝 × 标、底层网格正文组），支持「原海报构成 / 当代建筑展 / 独立杂志页」三题材切换。
- **怎么玩**：
  - 直接在画布上拖曳任意模块（`data-perf-drag`），把它推出原本锁死的虚线网格槽，或拖回格线附近磁吸归格；拖动时显示原格残影与红/蓝跨线偏移标尺。
  - 点击画布下方的四项排版拨片（跨栏放大、错位偏移、斜向切入、一键归格）或用方向键 / `[` `]` / `R` / `G` 精细操作当前选中模块；也可一键开关/扰乱底层基础网格，亲自验证「没有底格就没有破格」。
- **一打开是什么状态（绝非答案）**：刻意停在「全员锁格（0/6 破格 · 常规网格平庸态）」——所有 6 个模块端端正正锁在网格槽内，朱红圆缩在格里、黑块垂直平摆、红块只占 1 格，页面毫无视觉主角与动态张力。顶部自示范大标「破格网格」的「格」字此刻也齐平锁死，直到用户破格成立才同步下沉破出基线。
- **怎样算玩错、读数怎么说（单真源 7 类双向失误）**：`model.js` 从当前帧 6 个模块的真实绘制边界框（含旋转 OBB）与 48×40 覆盖栅格单真源核算，能识别并清晰解释 7 类双向错态：① 全员锁格（0 破格平庸）、② 破格失控（≥4 块同时破格，秩序瓦解）、③ 底格塌陷（辅助模块散乱失齐，无秩序可破）、④ 压字失读（破格几何块遮盖核心文字区 ≥18%）、⑤ 余白窒息（画布净留白 <26%）、⑥ 半步微偏（仅偏出格线 2%–10%，像没对齐的失误而非有意破格）、⑦ 重心偏坠（元素堆向一角失衡）。读数直接用白话说清「眼睛此刻怎么看、为什么不对」，并接受多组合法解（原海报经典解、单点出血解、跨栏巨标解、双块对角张力解及用户任意自排合法解）。
- **与近期 12 页的明显差异**：近期多为视口宽度/断点拉条（209/250/208/292）、单根分栏尺（164）、自由粒子场（125）、3D 仰拍（078）、半透方屏（328）、杂志缩放/出血裁刀（163/124）、折线拐点（040）、容器定高（249）；本页完全不拉视口宽度、不放准星，直接让用户在 5×6 印刷网格上亲手搬动、跨栏、斜切各个独立模块并做底格秩序对抗。

## 3. 版式骨架
- **忠实转译 210 原海报暖米纸印刷版式**（无通用深色导航栏、无圆角仪表盘黑箱、不锁 `100svh` 避平板空洞）：
  - **1440×900（主宽 1380px，2560 舒展至 1720px）**：右边缘常驻原海报标志的 34px 竖排等宽宣言脊 `ORDER IS THE BASE. BREAKING IS THE MOVE.`（`BREAKING` 朱红高亮）；顶部跨越虚线边界的自示范粗黑刊头「破格网格」→ 左 34% 编辑总述、单真源破格诊单与原海报四枚核心逻辑几何圆徽实时灯 × 右 66% 5×6 虚线破格主印张与底沿紧凑排印拨片 → 底部通栏 1:1 复刻原海报国际蓝八角星公式条（可见的秩序 + 有意的破坏 + 清晰的目的 + `↗` 箭头）。
  - **390×844 竖屏**：压紧顶行单栏刊头并将长总述后置，5×6 等比排印画布稳占首屏 ≥46% 高度且同屏直见诊断首句与主操作钮；竖排边条收为顶/底横向装饰细标不挤宽度。
  - **844×390 横屏**：切换左 56% 排印画布 × 右 44% 刊头、诊单与手法快切并行，首屏零裁切。
  - **正文 7 节明暗节奏**：亮米纸（01）→ 暖砂纸（02）→ 工业纯黑暗室（03）→ 亮米纸（04）→ 净白纸（05）→ 国际克莱因深蓝暗室（06）→ 暖米原纸原海报展墙（07）。

## 5. 节目录（7 节，标题均 ≤12 字，相邻交互不重复）
- **01 先建格，再破格**（`Build First, Break Later`）：解释原海报四大核心逻辑与「可见秩序」前提。交互：**双栏底格显影推杆**，左右刮开真破格 vs 随手乱排背后的隐藏参考线。
- **02 四种破格招式**（`Four Breaking Moves`）：拆解跨越、偏移、延伸、倾斜/重叠四种具体手法。交互：**手法切卡 + 活体 CSS Grid 坐标高亮蓝图**（附常规/破格闪烁对照钮）。
- **03 破格的临界线**（`The Breaking Budget` · 纯黑暗室）：讨论破坏比例与负空间经验区间，并温和辨析原海报「规则是用来打破的」（标「说多了一点」）。交互：**破坏配额步进拨盘（0/8–8/8）与留白压力联动画布**，实时绘制视线跳点与张力档位。
- **04 从巴塞尔到二维网格**（`Where It Came From`）：梳理 1961/1981 瑞士网格、1968–1972 巴塞尔实验、2002/2017 破格专著与 2017 CSS Grid 原生落地，并一句话链接 196/200/209/211 同小类页面。交互：**四年代标本切换器**，SVG 版面结构随年代演进变形。
- **05 什么时候别用**（`When Not to Break`）：划清编辑表达 vs 高频工具/表格/表单/无障碍阅读的适用红线及移动端归格原则。交互：**四类真实场景常规/破格即时切换筛查台**。
- **06 挑出成立的破格**（`Spot the Working Break` · 深蓝暗室）：A/B/C/D 四选一建筑展封面眼力小测，选后叠显底层网格并逐项解释。
- **07 原海报与关键词**（`Original Poster`）：`<img id="poster" src="poster.webp">` 可放大拖拽灯箱 + 原话摘录 + 关键词 + 同类网格快链 + 页脚。

## 7. 练习设计
- **题目**：同一场「当代混凝土建筑年展」封面（同样 4×5 底层网格、同样红黑蓝视觉元素），四张方案只差「破格策略」一个变量，哪一张真正成立？
- **四个中性选项（仅写 A/B/C/D + 中性结构描述）**：
  - **A**：全要素贴合 4×5 网格边界（常规对齐，缺重点与节奏变化）
  - **B**（正确）：底层 4×5 辅栏齐整，仅主视觉红圆向右上越界、展名跨 3 栏，留白充裕且不压文字
  - **C**：六组元素中五组同时偏移与倾斜（破格比例过高，底层网格参照消失）
  - **D**：仅单块巨型朱红块斜切破格，但中心压盖在展名与展期正文上方（牺牲信息可读性）
