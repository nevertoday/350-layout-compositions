# 197 层级网格（HIERARCHICAL GRID）互动页方案

## 1. 一句话道理
层级网格不追求把页面平均切给所有元素，而是先排出内容的轻重次序（主视觉 → 次要承接 → 辅助说明 → 补充细节），再用悬殊的面积比例、分区位置与字色对比把这条优先级链固定下来，让视线无需思考就能顺着强弱阶梯自然流过。

## 2. 开场玩具
- **名字**：活体 A/B/C/D 比例切割台 × 右侧「重要性 高→低」联动标尺。
- **怎么玩**：
  - 画布忠实复刻 197 原海报暖燕麦厚框内的 A（陶粉珊瑚）/ B（暖燕麦）/ C（古铜金赭）/ D（深森墨绿）四区虚线格局。
  - 用户直接拖动画布内三道活体虚线界墙：主纵墙（`data-perf-drag`，调 A 与右侧 B/C 的宽度比）、右横墙（调 B 与 C 的高度比）、底横墙（调底部 D 注释带的高度），或用键盘方向键微调选中界墙。
  - 右侧无缝联动原海报标志性的「重要性 高 ↑ ↓ 低」竖向重力标尺：四根水平折线将 A/B/C/D 的实测面积实时投射到轴上；一旦次要区比主区大，连线会当场交叉变赤红警报。
  - 顶部可切换 5 套真实内容皮肤（原海报 A/B/C/D 解剖、案例一封面页、案例二图文页、案例三数据呈现页、案例四长文阅读页），下方精简槽可切换字阶对比档位、区缝留白与角色对调。
- **开场初始态（0/4 翻车错态）**：A 区被压在左侧仅占约 22%，比 C 区（30%）和 D 区（27%）还小，形成权重倒挂与右侧连线交叉；四区面积相近陷入平权；D 区细节带喧宾夺主；字阶对比锁在「平权同号 1.0×」。
- **怎样算玩错与读数反馈**：全部指标由 `model.js` 单真源从 `(splitX, splitBC, splitD, gapMode, typeMode, swapAC)` 实算，可识别 8 类错态（权重倒挂、四区平权、主区气短、主区吞并、脚注喧宾、辅区挤扁、同号平权、区缝失控），在底部虚线圆角诊单中用白话讲清「为什么这样摆会让视线卡壳或走偏」，并接受多组合法比例解（如 A 占 44%–66%、D 占 7%–17%、面积顺位不倒挂、主次面积比 ≥ 1.65×）。
- **与最近 12 页的差异**：196 是浅纸搬运等大 X×X 方砖与拉角跨格；195 是蓝白拖多栏竖缝；278/279 是看板与日历；233/234 是坐标与滚页。197 独创「区隔虚线界墙切割面积 + 右侧重要性竖轴连线防交叉」双联动装置，完全从 197 原海报生长出来，别页无法套用。

## 3. 版式骨架
- **1440×900（桌面）**：深森墨绿全出血海报主场（主容器 1360px，2560 宽屏舒展至 1780px，不锁 100svh）。顶眉 34px 后为左 36%（含实时 A/B/C/D 宽占比示范条的厚重暖燕麦大标「层级网格」+ 陶粉副标 + 金杠总述 + 原海报 01–05 五条圆章图标实况原则列）× 右 64%（5 场景切签 + 活体四区切割画布与右侧重要性竖轴 + 精简操控槽），首屏底沿通栏接原海报同款暗金虚线圆角诊单带（嵌陶粉灯泡圆章与四项实测读数）。
- **1024×1366 / 768×1024（平板）**：自然流动不锁屏高，上方横向刊头，中段满宽画布与竖轴，下方双列原则与通栏诊单。
- **390×844（手机竖屏）**：单行压紧刊头，场景切签后立刻进入等比活体四区画布与右侧紧凑重力轴（稳占首屏 ≥47% 屏高），紧接快捷控参和诊单首句；五条原则顺延在下方，不把玩具挤出第一屏。
- **844×390（手机横屏）**：切为左 56% 活体画布与重力轴 × 右 44% 紧凑标题、快控与白话诊单并行。

## 4. 配色和字体
- **配色（逐像素实采自 197 原海报）**：
  - 深森墨绿底 `#021A11` / `#011C13` / 暗室卡底 `#0B2A1F`
  - 暖燕麦羊皮纸 `#EFE5D6` / `#EADCC8` / 大标 `#F3E4D2` / 浅宣纸 `#F7F1E7`
  - 陶粉珊瑚红 `#DE8E86` / 暗底亮珊瑚 `#F2A298` / 浅纸高对比深陶红 `#9E362E`
  - 暖古铜金赭 `#C49C60` / 暗底亮金 `#DFB878` / 浅纸高对比深古铜 `#7A561D`
  - 灰苔石绿 `#727C6D` / 深松绿 `#113328` / 浅雾苔纸 `#E5E8E2`
  - 克制校准色：达标青碧（暗底 `#72D6B4` / 浅底 `#0F6349`），错态朱赤（暗底 `#FF8A7A` / 浅底 `#B52B22`）。
- **字体搭配**：`Noto Sans SC`（中文主标与正文 400/700/900）+ `Fraunces`（A/B/C/D 大字母与展示数字 400/700，**近 12 页 0 次**）+ `Bricolage Grotesque`（英文副标与小节眉题 500/700，**近 12 页 0 次**）+ `IBM Plex Mono`（面积百分比与比例标尺 400/500/600，**近 12 页 0 次**）。全库唯一且与 196 零重合西文。

## 5. 节目录（7 大节，相邻不用同类控件）
1. `01 为什么面积会说话`（暖燕麦纸）：眯眼模糊测试滑杆（0–14px 实时高斯模糊对比「均分四宫格 vs 层级比例」）。
2. `02 视线阶梯怎么走`（浅宣纸）：2D Canvas 视线路径动画演示器（4 种拓扑切换按钮 + 播放/重放眼动轨迹，标明示意值）。
3. `03 打破均分的五把尺`（深森墨绿暗室）：5 枚独立层级通道拨片（面积/字号/留白/色彩/位置），可叠加测试并触发「五维全满过载」警示。
4. `04 四类版面的真实切法`（暖燕麦纸）：原海报四案例（封面/图文/数据/长文）大卡，支持「骨架比例% ↔ 实排成品」透视切换与一键载入顶部实验台。
5. `05 从瑞士网格到内容优先`（浅雾苔纸）：核实史料时间线 + 同小类兄弟网格一语辨析链接表。
6. `06 什么时候别用层级网格`（深森墨绿暗厅）：温和辨析原海报「说多了一点」之处 + 4 组「错用场景 vs 对症网格」切换卡。
7. `07 挑一挑：哪张最立得住` + 原海报鉴赏与页脚（暖燕麦纸 + 深森墨绿展框）：四张仅差比例变量的微型网格单选题 + 可放大拖动原海报灯箱。

## 7. 练习
- **题干**：某建筑展数字专刊首页要排布四项内容（主视觉展名、展期导语、策展人导览时间、票务与版权小注），四套方案配色与字族完全相同，仅四区比例切分不同，哪套最立得住？
- **四选项（标签仅写 方案 A / B / C / D，只差面积分配这一变量）**：
  - 方案 A：28% / 24% / 24% / 24%（四区平权，无主次入口）
  - 方案 B：54% / 21% / 15% / 10%（正确：A>B>C>D 顺位严密，主区镇场、辅区承接、细节退底）
  - 方案 C：38% / 16% / 14% / 32%（脚注喧宾夺主，权重倒挂）
  - 方案 D：82% / 7% / 6% / 5%（主区吞并过度，辅区挤扁难以承接）
