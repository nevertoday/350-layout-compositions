01

为什么面积会说话

PROPORTION & VISUAL WEIGHT

人眼扫过一张版面，在前零点几秒里根本不读字，只处理面积、明暗和位置三件事。谁占地最大，大脑就先把它判为「头号消息」。

当四个板块被切得差不多大（比如各占 25%），视觉信号互相抵消，读者被迫逐个读完标题才能判断轻重，这就是均分平权陷阱。层级网格反其道而行：用经验上 1.65 倍以上的主次面积差，把“先看谁”直接刻进几何骨架。

0px 原貌 6px 轻眯眼 14px 只剩色块

把滑杆拉到 8px 以上，模拟设计师常用的「眯眼检查法」：滤掉全部文字细节，只看骨架谁先跳出来。

05

从瑞士网格到内容优先

ORIGINS & GRID FAMILY

它从哪来

  1. 1981
    约瑟夫·米勒-布罗克曼《平面设计中的网格系统》

    瑞士出版社 Verlag Arthur Niggli 出版德英双语首版（Grid Systems in Graphic Design），将网格升格为理性的视觉秩序工具，奠定了用几何比例组织信息的基础。

  2. 2002
    蒂莫西·萨马拉《网格的构建与打破》

    Rockport Publishers 首版（Making and Breaking the Grid）将常见网格系统化为手稿、分栏、模块化与层级网格（Hierarchical Grid），明确指出层级网格不靠等距重复格子，而是从信息本身的视觉权重与需求生长出来。

  3. 2004
    艾伦·拉普顿《字体设计思维》

    Princeton Architectural Press 首版（Thinking with Type）将字体层级（Hierarchy）与网页语义层级同网格空间并置，说明字阶与区域比例必须协同工作。

  4. 2017–2022
    W3C CSS Grid 与当代界面实践

    W3C CSS Grid Layout 规范带来不等比轨道（fr）与命名区域模板（grid-template-areas），网页端得以直接写清 A/B/C/D 分区；2022 年尼尔森诺曼集团（Kelley Gordon）亦将层级网格列为界面设计三大基础网格之一。

什么时候别用层级网格

WHEN NOT TO USE IT

说多了一点

原海报底语：「先定内容权重，再定空间分配；主区大胆、辅区节制，层级越清晰，信息越有力。」

前半句非常到位，但「层级越清晰，信息越有力」容易被误解成层数切得越细、反差拉得越猛越好。实际排版中，单屏给到 3–4 个层级（A/B/C/D）往往已经是人眼顺畅区分的经验上限；一旦硬切出六七档比例和五六个字号，页面反而碎成噪音。此外，还有四类天然讲究「平等或匀速」的场景，本来就不该硬套层级网格：

硬套层级 · 错配

硬套层级网格 → 读者怀疑「放大的是广告」

在电商货架、作品集索引、员工名录里，每张卡片天然平等。强行把某几项拉大成 3 倍 A 区，会破坏横向比较的公平预期。

对症改用 · 196 模块化网格

换回更合适的结构

改用等大重复的模块化方格，让每件商品站在同一起跑线上，靠筛选和排序而非面积偏心。
