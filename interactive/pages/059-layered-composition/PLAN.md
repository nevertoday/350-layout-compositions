# 059 层叠构图（LAYERED COMPOSITION）交互页设计方案

## 1. 一句话道理
人眼在二维平面上认出空间纵深，靠的不是画透视线，而是「谁压住谁（遮挡与 T 形交点）」与「谁更实谁更虚（明暗、投影与空气透视）」两组线索方向一致、彼此不打架。

## 2. 开场玩具：四层纸雕景箱 × 侧剖层轨编排台
- **怎么玩**：舞台直接化用 059 原海报中央的四层剪纸景片——**远山暖日（远景底幕）**、**叠扇中峰（中远山脊与半圆扇）**、**深咖拱门（中近建筑竖板）**、**焦糖主盘（前景焦点圆盘）**。用户能做三种层叠本体的动作：
  1. **排层序（Z1→Z4 层片插槽轨）**：点击两枚槽位互换、拖动层签、或用槽内左右移位按钮与方向键，调整四片剪纸由远到近的前后次序；
  2. **调咬合（画布直拖层片 + 底沿「咬合错位游标」`data-perf-drag`）**：控制相邻层片的横向错位与压边比例，并在画布上实时标出 T 形交点或危险切边；
  3. **定虚实与侧剖检视**：切换「同频平贴 / 近实远虚 / 远实近虚」三种明暗与投影分配，随时点击「掀开侧剖 38° / 正面视图 0°」把四张纸片在 3D 斜透视里拉开检查物理间距与投影落点。
- **开场状态（非答案）**：开场刻意停在「失序 · 平贴散开」错态——层序打乱为 `[远山暖日, 焦糖主盘, 深咖拱门, 叠扇中峰]`（前景主盘被压在中段后面），咬合度偏散（约 6%，多处擦边未咬合），虚实处于「同频平贴」（零投影、全层同明度对比），原海报四枚圆徽 0/4 未亮。
- **怎样算玩错、读数怎么说为什么**：全部状态与几何裁切由 `model.js` 唯一数据源实时算出，按严格优先级单报一条主错，并说明视觉成因：
  - **大底反盖 / 过度压死**（某层可见面积 < 35% 或平均交叠 > 62% 经验值）：前片把后片轮廓吞掉，眼睛认不出被遮物是什么，纵深坍塌成单块黑影；
  - **层序倒置**（大块底幕压在小主体前，或主盘/拱门沉到中远层之后）：空间次序与体量层级打架，视觉主角被挡住；
  - **切边碰线**（相邻边缘距离落在 ±2.5% 经验切边带内）：两层边线刚好相切不交叉，大脑一时判不出谁前谁后，画面发僵；
  - **零遮挡散开**（平均有效交叠 < 12% 经验值）：四片各自漂浮、形不成 T 形交点，画面退回平面拼贴；
  - **远实近虚（线索倒挂）**：遮挡关系说 Z4 在最前，明暗反差却把 Z1 往前拽，两组深度线索互相拆台；
  - **同频平贴**：顺序和压边对了，但四层缺乏明暗梯度与层间投影，交界处容易粘成一片。
- **与最近 12 页的区别**：不同于 058（四级台阶高差）、270（卡片网格外距）、309（宽银幕轨道机位）、225（CSS 流根印章）、142（封面字号裁切）、102（四组形状对比）、020（镜像轴反射）、269（S 轨信息流）、129（报版四格调位）、187（标点凸排）、296（窄屏重排）与 240（双断点切刀），本页专注纸雕多层 Z 序重排、T 形咬合面积实测、空气透视极性检验与可掀开的 3D 斜剖纸箱。

## 3. 版式骨架
- 紧跟 059 原海报的「烟梅红墙面 + 叠压纸卡」结构，无独立侧栏仪表盘，不锁 `min-height: 100svh`：
  - **1440×900 & 2560×1440**：顶部左置奶白叠深咖偏移的示范大标卡（右上嵌焦糖四分之一圆与微点阵），右置原海报四枚细线空心圆徽作实时达标灯；中段满幅铺开纸雕景箱主舞台（1440 宽约 1280px、高约 450px；2560 放宽容器至 1880px，舞台同步舒展）；底沿呼应原海报底部的双卡布局——左下深咖诊断卡（读数与白话解释）× 右下奶白控制卡（Z1–Z4 层片槽 + 咬合游标 + 虚实三态）。
  - **1024×1366 / 768×1024 平板**：自然顺排，不强撑全屏高度，避免竖屏大片空洞。
  - **390×844 手机竖屏**：压缩顶栏与叠纸标题卡，让等比景箱舞台首屏占 ≥ 45% 屏高，紧接咬合游标、Z1–Z4 槽位钮与深咖诊断卡同屏可见；横向拖拽轨设 `touch-action: pan-y` 保证页面自由纵滚。
  - **844×390 手机横屏**：切为左 56% 景箱舞台 × 右 44% 紧凑控件与诊断并行。

## 4. 配色和字体
- **配色（实采自 `059.webp` 并校准无障碍对比度）**：
  - 烟梅陶红墙底 `#8E4F53` / `#9A595D`（深版 `#5A2F34`）
  - 暖宣奶白纸面 `#F4E4D8` / 次级柔沙纸 `#EAD9CD` / `#E5D1C8`
  - 深焙咖墨 `#3A2827`（正文墨色 `#2C1E1D`、次要暖褐 `#5E4441`）
  - 焦糖陶橘主强调 `#D87C65` / `#BB664E`（浅底高对比文字色 `#A8452E`、深底提亮色 `#F2A78A`）
  - 玫瑰雾山阶梯 `#EBD1C5` / `#BF9087` / `#A77370`
- **字体搭配（全库唯一，且两款西文均在最近 12 页从未用过）**：
  - **`Chivo`**（400 / 700 / 800 及 400 italic，最近 12 页未用）：英文大标、节号与细线圆徽英签；
  - **`DM Mono`**（400 / 500，最近 12 页未用）：层号 `Z1–Z4`、交叠率、可见面积与视角读数；
  - **`Noto Sans SC`**（400 / 500 / 700 / 900）：中文建筑感大标与统一中文正文（正文中西文与年份沿用正文体防跳动）。

## 5. 节目录（01–08，每节标题 ≤ 12 字，相邻控件不重复）
- **01｜遮挡一落，前后就分明**：引用原海报「原理解析」与四要点，配「分离 / 危险切边 / T 形咬合」三态切换与 SVG 局部放大镜。
- **02｜五把拉深画面的尺子**：拆解遮挡、比例、明暗雾化、投影、锐度五条线索；用五枚独立开关拨片实时控制 2D 画布，观察线索合力与单线索倒挂。
- **03｜从北宋山水到多平面镜头**：按 1072 郭熙、1651 达·芬奇《绘画论》、1937 迪士尼多平面摄影机、1954/1974 阿恩海姆与 2014 Material Design 梳理脉络；配 1937 玻璃画片「机位横移」视差滑轨。
- **04｜四种场景，层叠怎么干活**：对应原海报四场景（海报 / 插画 / 产品 / 界面），用场景切签 + `L1–L4` 逐层剥离台查看每层职责。
- **05｜它和七位邻居的分工**：一句话界定同小类 057、058、060–064 并附在线版链接，配静态「压叠强度 × 规则队列」二维坐标图与点击高亮卡。
- **06｜什么时候别用层叠**：温和修正原海报「层层叠加必更丰富」的说法（标「说多了一点」），配三类真实场景（财务报表 / 紧急提示 / 长文阅读）的「强行叠层 vs 老实平铺」正反切换对比。
- **07｜练一练：哪版层次最清楚？**：A/B/C/D 四张同色同构图海报小样，仅差单一变量（切边碰线 / 正确咬合与虚实 / 远实近虚倒挂 / 过度压死），点选后显出图面批注与拆解理由。
- **08｜原海报与关键词**：内联 `poster.webp`（点击放大、拖动平移、Esc 收起）+ 原海报四枚关键词几何章（重叠 / 深度 / 层级 / 层叠）。

## 7. 小练习设计
- **题目**：同一套「暖日远山 + 叠扇 + 拱门 + 焦糖主盘」四层海报，仅改变一个层叠条件，选出空间纵深最清楚的一版。
- **四个选项（中性标签 A / B / C / D，外观同样精致，无好坏字眼）**：
  - `A`：层序与明暗都对，但前景圆盘边缘与拱门竖边刚好零间隙相切、太阳也擦着山脊（单一变量：**切边冲突**）。
  - `B`（正确）：Z1→Z4 顺序正确，相邻交叠约三成形成清晰 T 形交点，明暗由远淡近实逐级递进并带克制投影。
  - `C`：几何位置和交叠比例与 B 完全相同，唯独把远山刷成最深浓墨、前景圆盘淡化成浅粉（单一变量：**明暗与遮挡倒挂**）。
  - `D`：层序与明暗与 B 相同，唯独把四层往中心硬挤，前景圆盘与拱门吞掉后层大半轮廓（单一变量：**过度压死**）。
