# 094 多重焦点构图（MULTI-FOCAL COMPOSITION）设计方案

## 1. 一句话道理
人眼一次只能用中央凹看清一处细节，读图本质上是「注视—跳视—再注视」的序列旅程；多重焦点构图通过**明确的主次权重梯阶、形态与明暗对比、非交叉的视线路径、以及围绕隐形支点的重量平衡**，把多个抢戏的孤岛编织成一条「既分散单点压迫、又有序漫游」的视觉星图。

## 2. 开场玩具：星图巡航编排台（Multi-Focal Orbit & Scanpath Director）
- **形态与素材**：2D Canvas（标 `data-perf-drag`），1:1 承袭 094 原海报的深空午夜蓝星场、中央同心轨道与银灰平衡支点球、四枚焦点（从 `#poster` 原图实时裁剪出 A 山峰圆、B 灯塔圆、C 城影六边形、D 纹石圆，并自动修补边缘叠章；同时内置「信息图·数据星图」与「杂志·跨页展板」两套真实应用语境）、弯弧虚线引导箭与四向引注。
- **怎么玩**：
  - 直接拖拽任意焦点（A/B/C/D）改落位，实时驱动中央平衡支点球位移与力矩计算；
  - 在画布中心星场空白处左右横拖，可如转动星盘般连续扫动整组星图方位与主次对比差（同时满足手机触屏顺手滑控与性能拖动实测）；
  - 拖焦点外圈虚线环或下方推杆调节面积与对比度，点击切换形状（圆 / 六边形 / 方 / 菱形）以打破雷同；
  - 切换引导路径拓扑（断链 / 顺轨 / 回环 / 交叉死结）或增减焦点数（2–6 枚）；
  - 按 `Space`（或点「放飞视线巡航」）依据单真源权重与拓扑运行真实的「注视—跳视」扫描路径模拟。
- **开场初始态（绝不先给答案）**：刻意停在 `0/4 · 四王均权` 复合错态——四焦几乎等大等亮（权重比 1.08×，谁也不是起点）、重心整体左偏塌方（质心偏移 > 18%）、引导路径交叉打结成 X 死结、四焦全为同形圆且对比扁平。
- **怎样算玩错、读数怎么说**：由 `model.js` 从实绘几何坐标、半径、明暗对比与线段交点单真源双向检出 9 类错态（均权争霸、退回 093 单焦垄断、焦点粘连碰撞、重心失衡倾覆、挤边裁切、孤岛断链、路径交叉死结、形态对比雷同、六焦过载），每一错态都用白话指出「观众眼睛此刻会怎样被打断」并给出下一步可执行的调整建议；同时认可多种合法解（原海报四星解、三角主从解、长卷五焦解及任意手动摆出的达标构图）。
- **与最近 12 页的明显区别**：不重复 091 破框延展、090 斜轴倾角、054 离心抛射、057 棋盘翻格、056 四象限十字轴、055 同心圆校准、308 清场剪影、222 文档流折行、141 排印字阶、089 石碑水平仪、177 右终线配重、053 向心汇聚、093 单焦暗房压噪；本页的核心动作是**多焦共生编排**——给 4 枚真实焦点排梯阶、配重心、连路径、做形态反差，并用扫描路径验真。

## 3. 版式骨架
- **1440×900（主宽 1380px，2560 舒展至 1660px）**：忠实转译 094 原海报的「深空星图全幅开放舞台 + 底部 29% 实心紫罗兰渐变核心诊单卡 | 71% 细线四列实时探针槽 + 胶囊应用场景条」骨架（不做左右侧栏仪表箱，不锁 `100svh` 避开 1024×1366 平板竖屏大空白）。顶部单行精炼非对称自示范刊头 + 全宽宽幕星图画布 + 紧底单行调焦操轨条 + 底部 1:1 复刻的紫卡诊单与四列图标实时读数，全部自然落在首屏内。
- **390×844（手机竖屏）**：压紧单行刊头与三语境切签，让近方等比高清星图画布稳占首屏 ≥45% 屏高（所有圆保持严格正圆，绝不压扁）；折线内直露精简紫卡诊单首句、主次梯阶快滑轨与「校准原海报解 / 放飞视线」双键；详细节点面板与 2×2 四探针顺流接续其下。
- **844×390（手机横屏）**：切为左 54% 等比星图画布 × 右 46% 精简刊头、紫卡诊单与快捷按钮并行，一屏即可完整观看并拖拽操作。
- **正文七节明暗节奏**：Hero 深空午夜蓝 → 01 亮星雾白 → 02 柔薰衣雾 → 03 深空暗室 → 04 亮星雾白 → 05 柔薰衣雾 → 06 深空考场 → 07 亮星雾白原海报展墙 + 极深午夜页脚。

  - `Manrope`（400/600/700）— **近 12 页未用**：用于等宽感数字读数、坐标标尺与紧凑标签

## 5. 节目录（7 节，相邻节不用同一种控件）
1. **01 为什么多焦点不等于散乱**（`HIERARCHY BEFORE DISPERSAL`）— 展开海报「分布注意力」「对比与变化」原话，温和补正「平均分散会引发跳视疲劳」；交互：**四轨竖向权重推子混音台 + 实时注视落点分配条**。
2. **02 四种路径，织出阅读节拍**（`PATHWAYS & RHYTHM`）— 展开「节奏与路径」「平衡与统一」及原海报在三圆中嵌入六边形的用意；交互：**4 套路径拓扑卡片切换 + 交叉死结故障拨片 + SVG 动态走线验算**。
3. **03 从散点长卷到眼动扫描路径**（`ORIGINS & SCANPATH`）— 溯源《清明上河图》《尼德兰箴言》、阿恩海姆平衡支点、雅布斯与诺顿-斯塔克扫描路径及塔夫特微/宏观可读性；交互：**四时代典藏时间轴切换 + 致敬雅布斯的「阅读任务切换」眼动扫描路径演示**。
4. **04 五个应用场景，落地怎么摆**（`FIVE APPLICATIONS`）— 对应海报底栏「信息图表 / 产品展示 / 杂志版式 / 海报设计 / 数据可视化」五大场景；交互：**5 场景切换 + 左右推拉式 X-Ray 焦点骨架透视滑门**。
5. **05 什么时候别用多重焦点**（`WHEN NOT TO USE IT`）— 明确适用边界并一句话链接同小类全部 7 个兄弟页面（087–093）；交互：**三问项目诊断单选树（停留时长 / 信息维度 / 展示尺寸）即时输出构图处方**。
6. **06 小练习：挑出成立的多焦点**（`PRACTICE LAB`）— 3 题单变量四选一盲测，实时判分并展开解析；交互：**纯图形 SVG 盲测卡片四选一 + 逐题解剖**。
7. **07 原海报与核心关键词**（`ORIGINAL POSTER`）— 展示 094 原海报、核心要点原文、四枚关键词与规范页脚；交互：**全屏灯箱缩放/拖拽查看器（支持 Esc 关）**。

## 7. 小练习设计（单变量控制，全中性标签 A/B/C/D）
- **题 1（仅改变主次权重比例）**：四图位置、形态、连接线全同，仅变化四个焦点的大小与明暗（A 均权争霸 / B 单焦垄断 / C 清晰阶梯 A>B>C>D / D 双焦撞主）。选 **C**，理由：既保留多焦点分散压迫，又给第一眼明确入口与阅读序。
- **题 2（仅改变重心位置分布）**：四图权重梯阶、形态全同，仅变化节点落位（A 全偏左塌方 / B 围绕支点错落平衡 / C 贴死边缘 / D 主次焦粘连重叠）。选 **B**，理由：视觉重量质心落在画面平衡区内且彼此留出呼吸净隙。
- **题 3（仅改变路径与节奏连接）**：四图坐标与大小全同，仅变化连接路径与异形节奏（A 交叉死结 / B 无路径孤岛 / C 顺畅非交叉路径+异形节奏 / D 方向外指脱框）。选 **C**，理由：曲线与异形节点把视线按序引完闭环，不折返、不滑出画框。
