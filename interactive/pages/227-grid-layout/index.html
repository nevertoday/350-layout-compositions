01

轨道与线号，二维的骨架

TRACKS & GRID LINES · 2D COORDINATE SYSTEM

原海报 · 轨道 TRACKS

「建立垂直基准线，对齐内容边缘。」

说窄了一点

印刷书刊常先立竖向分栏线，所以海报把轨道概括成「垂直基准线」。到了网页的 CSS Grid，核心突破在于把垂直列轨与水平行轨放进同一张坐标系：两条相邻网格线之间才叫一条轨道（Track），而内容块不是按「第几格」定位，而是按起止线号（1 到 N+1，末尾可用 -1 倒数）卡死边界。

也正因如此，网格和 226 弹性盒布局 分工清晰：弹性盒一次只管一条轴，换行后的第二行管不着第一列的宽窄；网格则让上下两行天生共用同一批列线。其中最关键的单位是 fr（fraction）——它只瓜分扣除固定像素与 gap 之后的剩余自由空间。

原海报 · 间距 SPACING

「控制间距与留白，提升可读性。」

正文行高倍频（16px 基准）
两栏列沟槽（column-gap）
串行风险 · 沟槽窄过行距 沟槽 / 行高 = 0.42×（经验值建议 ≥ 1.0×）

网格里最容易被低估的不是线条，而是夹在两列之间的空白沟槽。只要沟槽比同一行字上下两行之间的距离还窄，眼睛读到行尾时就很容易直接横向跳进右栏。

把行高设为基准步长后，段间距、栏沟槽与上下页边距跟着取它的整数倍或清晰大于行高，两列文字才会各自稳稳抱团。

在 CSS Grid 中，column-gap 与 row-gap 无需再靠负外边距或给最后一列清零来硬凑——沟槽只出现在轨道之间，绝不会往容器外缘多挤出一像素。

换句话说，间距不是事后补缝的装饰，而是把信息分清「同组」还是「相邻」的第一道分界。

10px

当前列沟槽只有 10px，比正文行高 24px 窄了一半以上。按格式塔接近律，左栏行尾离右栏行首比离自己下一行还近，阅读极易跨栏串行——把沟槽切到 28px 立刻对比。

04

命名地图与矩形铁律

GRID-TEMPLATE-AREAS · RECTANGULAR RULE

CSS Grid 有一项别的布局都没有的独门语法：grid-template-areas。你可以直接用英文名字在代码里画出一张「字符平面图」。但 W3C 规范写死了一条铁律：每一个同名区域必须是完整实心的矩形——只要涂成 L 形或拆成两块孤岛，整条属性声明会立刻作废。

从瑞士图纸到网页标准

            
WHERE IT CAME FROM · 1964 TO 2017

          

        


        

          

            
            
            
            
          


          

            

              
            

            

              PRINT SYSTEM · 瑞士国际主义风格
              
卡尔·格斯特纳与约瑟夫·米勒-布罗克曼

              
1964 年，瑞士设计师 Karl Gerstner 出版《Designing Programmes》（原德文 Programme entwerfen，Arthur Niggli 出版），提出用规则程序生成可变版面；1981 年，Josef Müller-Brockmann 由同一出版社推出德英双语经典《Grid Systems in Graphic Design》（Raster Systeme für die visuelle Gestaltung），系统整理了 8 格到 32 格的平面与三维空间网格法，奠定了现代网格设计的共同语言。

              
纸张尺寸是固定的，设计师用毫米和活字点就能算清一切；但屏幕宽度千变万化，网页整整晚了三十多年才拥有同等优雅的原生二维网格。
