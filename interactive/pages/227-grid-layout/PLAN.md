# 227 网格布局（GRID LAYOUT）互动版方案

## 1. 一句话道理
网格布局不是给页面套死格子，而是先用看不见的纵横二维轨道和统一间距立住共享坐标，再让不同体量的内容区域锁进同一套基准线里——哪怕隐去辅助线，信息层级、边界对齐与扫描秩序依然牢牢成立。

## 2. 开场玩具：二维网格蓝图排布台（2D Blueprint Grid Composer）
- **玩法**：一座直接建在真实 `display: grid` 上的 6 列 × 4 行建筑蓝图排布台（辅以同源 2D Canvas 网格坐标线、线号 `1..7` / `1..5` 与碰撞警示斜纹层）。台上放着 4 个形态各异的真实网页功能区：**01 导览栏（nav）**、**02 主视觉（hero，鹅黄主焦点）**、**03 正文栏（main，白条正文区）**、**04 侧注卡（aside，鹅黄点缀块）**。
  - **拖顶部鹅黄轨道比例游标（`data-perf-drag`）**：沿第 3 号纵线左右连续拖动，实时修改真实的 `grid-template-columns: repeat(2, <A>fr) repeat(4, <B>fr)`，顶标尺同步读出每列实测像素宽；
  - **直接拖动/缩放二维区域**：在蓝图上选中任意区域，可拖主体换位、拖右下二维手柄（`⤢`）跨列跨行，或用配套的坐标步进钮与键盘方向键精确修改 `grid-column` / `grid-row` 起止线号；
  - **调沟槽 `gap`**：在 `0px / 8px / 16px / 28px` 间切换，并可随时点「隐形秩序」藏起白色辅助线检验无网格线时的真实观感。
- **开场状态（绝非答案）**：刻意停在「重叠 + 零缝 + 轨道偏斜 + 孤洞」四料错态——主视觉（`col 1/5, row 1/3`）与正文栏（`col 3/7, row 2/4`）在中间 2 格真实重叠并触发斜纹冲突警报，导览栏被挤在左下角（`col 1/2, row 4/5`），侧注浮在右下孤岛，`gap` 为 `0px`，左侧两列轨道被压窄至 `0.55fr`（约 0.45× 右侧列宽）。原海报 5 枚要点标（轨道/区域/模块/间距/秩序）初始仅 0/4 通过。
- **怎样算玩错 & 读数怎么说**：由 `model.js` 单真源按严格优先级只报当前最致命的一条主错，并说明人眼为何出戏：
  1. **区域重叠**：任两区共享同一网格单元 → 标出冲突格数与具体区名，说明内容互压遮挡；
  2. **零缝粘连 / 沟壑切碎**：`gap = 0px` 报区块边缘粘墙、栏间易串读；`gap = 28px` 报沟槽过宽、整体版面被切成散岛（经验甜区 `8–20px`）；
  3. **轨道失衡**：拖顶部轨道游标把左右翼列宽比拉出 `0.65×–1.50×` 经验稳区（由真实 DOM 列宽实算）→ 报左翼挤扁或右翼塌缩；
  4. **主次倒置 / 孤洞散碎**：把侧注拉得比主视觉还大时报错「主次倒置」；覆盖格数 `< 20/24` 或留出死洞时报错「孤洞散碎，秩序松散」。
  - 四项全部通过时，顶部 5 枚原海报图标同步点亮鹅黄，解锁「原海报 227 范式对比」并引导用户关闭网格线体验「看不见的秩序」。
- **与最近 12 页的差异**：
  - 区别于 **270 卡片网格**（圆角米白书展同质卡片 + 间距卡尺 + 焦点数控制）：本页零圆角、纯建筑蓝图制图语言，操作的是**异构二维页面区域**（跨不同列数与行数、可真实重叠碰撞）与真实列轨比例线；
  - 区别于 **226 弹性盒**（红框一维单行顶栏 + 伸缩角色按钮）：本页同时控制列轨与行轨两个维度，且无拉杆缩宽容器的套路；
  - 区别于 **225 流根 / 142 大标题 / 102 形状对比 / 020 镜像**：完全围绕 CSS Grid 独有的线号、二维跨区、轨道比例与隐形秩序展开。

## 3. 版式骨架
承袭 227 号原海报「外框连续细白线切分建筑蓝图」的整幅图纸骨架（零圆角 `0px`，1px 白色实线/虚线构图）：
- **1440×900 / 2560×1440**：不锁 `100svh`。顶部细条元信息下直开连续白框蓝图主表（1440 宽 `1360px`，2560 扩至 `1860px`）：
  - 上栏两格（左 58% 示范级白字大标「网格布局」四字各压入隐约四列基线格 + 总述；右 42% 实底鹅黄 `#FFD00F` 蓝墨诊断与实时 CSS 代码牌，带原海报 6×6 钴蓝点阵）；
  - 中栏两格（左 67% 巨幅 6×4 二维 CSS Grid 蓝图排布台 + 顶沿滑动鹅黄轨道游标；右 33% 坐标控制台：选区、移位/跨列/跨行、沟槽、`隐形秩序` 开关与错版切换）；
  - 底栏 5 等分细框（还原原海报「轨道 / 区域 / 模块 / 间距 / 秩序」五枚几何图标，随实验台状态实时点亮）。
- **390×844 手机竖屏**：压缩刊头为单行紧凑标题，紧接满幅 6×4 蓝图台与顶沿鹅黄滑柄（稳占首屏 ≥ 45% 高度），其下是紧凑鹅黄主诊断条、触控 ≥ 42px 的两行坐标操控条与五枚状态图标条。
- **844×390 手机横屏**：顶栏压至 34px，下方切左 57% 蓝图排布台 × 右 43% 鹅黄诊断与控件并行，零裁切零溢出。
- **正文八节**：在制图冰白纸（`#F4F7FF`）、淡蓝方格图纸（`#E6EEFF`）、标志蓝图钴蓝（`#063ED1`）与深蓝晒印暗版（`#041A5B`）间交替推进。

## 4. 配色与字体
- **配色（实采自 227 号原海报）**：
  - 蓝图主底：`#063ED1`（原海报钴蓝）；深蓝晒印暗底：`#041A5B`；蓝图细线：`rgba(255,255,255,0.52)` / 虚线 `rgba(255,255,255,0.34)`
  - 建筑鹅黄主强调：`#FFD00F`（配深钴墨字 `#041B5E`，对比度 > 10:1）
  - 纯白字与线框：`#FFFFFF`
  - 正文浅纸交替底：制图冰白 `#F4F7FF`、方格淡蓝 `#E6EEFF`，深蓝墨正文 `#071A4B`，浅底主强调 `#063ED1`，冲突警示红 `#D63316`（蓝底警示牌配白底或深蓝底保对比度 ≥ 5:1）
- **字体**：`Space Grotesk`（500, 700）+ `DM Mono`（400, 500）+ `Noto Sans SC`（400, 700, 900）。
  - **最近 12 页均未用过**：`Space Grotesk` 与 `DM Mono` 两款西文字体在最近 12 页中零出现，且三者组合全库唯一、与相邻 226（`Unbounded + JetBrains Mono + Noto Sans SC`）完全区分。

## 5. 节目录（8 节，每节标题 ≤ 12 字，相邻控件不重复）
1. **01 轨道与线号，二维的骨架**（`TRACKS & GRID LINES`）：拆解原海报「轨道」（温和指出原海报只提垂直基准线说窄了一点，CSS Grid 实为纵横二维轨道与线号体系）；交互：**真实容器宽度滑块 + 4 组 CSS 轨道公式切换**（`1fr` / `px+fr` / `minmax()` / `auto-fit`），实测各列 DOM 像素宽。
2. **02 三种网格，三种叙事节奏**（`THREE GRID ARCHETYPES`）：展开原海报三枚关键词（列网格 / 模块网格 / 层级网格）及「区域 / 模块」；交互：**三枚原海报线框卡片切态 + 蓝图骨架/真实图文透视开关**，让同一组 5 块内容在三种网格间实时重组。
3. **03 沟槽与行距的阅读刻度**（`SPACING & RHYTHMIC SCALE`）：致敬原海报底左巨幅 `A` 与「上边距 / 行间距 / 段间距 / 下边距」虚线标尺，展开「间距」；交互：**双组刻度按钮（行距档 × 列沟槽档）驱动真实双栏排版与巨幅 `A` 标尺**，实测 `column-gap / line-height` 比值，直观揭穿「沟槽窄过行距必串行」。
4. **04 命名地图与矩形铁律**（`NAMED TEMPLATE AREAS`）：深蓝暗版专讲 CSS Grid 独门语法 `grid-template-areas`；交互：**3×3 单元格点涂画板**（选区域画笔直接涂格子），合法矩形即刻生成真实 Grid 预览与代码，涂出 L 形或断裂块则即时触发 W3C 矩形失效警报。
5. **05 从瑞士图纸到网页标准**（`ORIGINS & TIMELINE`）：核实史实（1964 Karl Gerstner → 1981 Josef Müller-Brockmann → 2011 W3C 首稿与 IE10 → 2017 三大浏览器同期原生支持）；交互：**四代演进时间轴切片器**驱动 2D 蓝图对比画布（瑞士印刷网格 / Table 与 Float 拼凑 / 2011 草案 / 2017 CSS Grid）。
6. **06 什么时候用，什么时候别用**（`WHEN TO USE & WHEN NOT TO`）：引入原海报「网格的作用」三条并讲清反例边界（一维导航去 226、长文流去 229、高差图片墙去 236、视觉重排别破坏 DOM 键盘序）；交互：**4 组场景选型卡 + 键盘 Tab 焦点跳跃轨迹实演开关**。
7. **07 小练习：挑出立得住的网格**（`BLUEPRINT QUIZ`）：四张外观同为蓝黄配色的 6 列 2 行新闻首页蓝图（中性标签 `方案 A/B/C/D`），选完在四张图上叠出真实对齐激光线与逐项理由。
8. **08 原海报与关键词**（`ORIGINAL POSTER & KEYWORDS`）：可点击放大、滚轮缩放、拖动平移、Esc 关闭的 227 号原海报，配三枚关键词与原海报鹅黄点阵金句牌。

## 7. 小练习设计
- **题目**：同一份新闻专题首页要摆 5 个模块（上行 2 块，下行 3 块），以下四版蓝黄草图都只用直线和纯色块，哪一版真正建起了二维网格秩序？
- **四个选项（仅用中性名 `方案 A` / `方案 B` / `方案 C` / `方案 D`，各差单一网格变量）**：
  - **方案 A**：上行两等分（50/50）、下行三等分（33/33/33），纵缝彼此错位——退化成两排不共享列线的各自排版；
  - **方案 B（正确）**：全页共享 6 列基准线（上行 `4+2`、下行 `2+2+2`），纵缝上下贯通、行轨齐平、`16px` 沟槽大于行距且主视觉面积居首；
  - **方案 C**：同样共享 6 列基准线、主次清晰，但把列沟槽压到 `4px`（窄过正文行距），相邻两栏文字边缘粘连易串行；
  - **方案 D**：同样共享 6 列基准线、沟槽合度，但把右下辅助块拉成跨行大块反压主专题，造成区域面积与信息层级倒置。
