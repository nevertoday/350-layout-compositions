# 037 S 形构图（S-SHAPED COMPOSITION）设计方案

## 1. 一句话道理
S 形构图依靠**一条含唯一拐点（曲率由正翻负）的双反弯连续曲线**，把人的视线从入口经两处节奏缓弯自然引入画内深处与终点：它借完形「良好连续律」省去直角折返的急停感，借平滑弧度带来舒展亲和的叙事韵律，但弧度过直会失掉节奏、过急会堵死留白、同侧翻弯则会退化成单弧。

## 2. 开场玩具：活体 S 河道修曲台（S-Curve River & Inflection Sculptor）
- **核心动作（专属于 S 形构图本身）**：直接在 037 原海报深松夜绿开放画布（2D Canvas，`data-perf-drag`）上雕塑发光水青—青柠双色 S 河道：
  - **横向直拖河道弯脊（`data-perf-drag`）**：实时连续调节上下两弯的弯曲摆幅（映射 1753 荷加斯 1–7 号弧度谱），并同步联动左上刊头活体大字「S」的曲线张力与中央圆窗山溪内的河流形态。
  - **直拖上弯柄 / 下弯柄**：可自由翻转正 S / 反 S，甚至把下弯拖到与上弯同侧，亲眼看到曲线失去拐点、退化成 C 形单弧；也可拖近直轴测试过缓退化为直线，或拉到发卡急弯看水流光粒减速卡顿。
  - **直拖 4 枚信息站圆徽（入口 / 上弯 / 下弯 / 出口）**：检测核心节点是否贴合曲线关键点、是否扎堆挤在一侧、是否倒置叙事流向；直拖出口向角测试「画内回收」与「甩出画角」。
  - **调节留白呼吸（元素体量）** 与 **一键切换三题材**（原海报山溪动线 / 茶道展讯竖幅 / 盘山公路风光），底沿原海报 4 步导流带可点选高亮对应构图层。
- **开场初始错态（绝不先给答案）**：一打开停在 **`0/4 待疏通`** 的复合失误态——① 上弯甩成 44% 过急发卡弯且下弯失衡；② 核心节点「节奏起伏」脱轨悬在右上空洞；③ 出口切线直冲左下画角把视线甩飞；④ 河岸信息体量挤占留白至 19%。
- **怎样算玩错、读数怎么说「为什么」**：`model.js` 对当前分段三次贝塞尔河道实时采样 120 点，单真源实算曲率 $\kappa(t)$、拐点个数、最大曲率、4 站距曲线最短距离、出口画内收敛度与有效留白率，可捕获 8 类真实几何错态（无拐点退化成 C、过缓退化成直线、过急发卡弯、上下弯严重失衡、节点脱轨、节点扎堆、出口甩飞、留白堵死）。右侧实时画出 **$\kappa(t)$ 曲率符号波形条**，并用白话解释「视线走到这里为什么卡住/滑走/折返」，同时接受正 S、反 S、微弧轻 S 及任意满足四项几何准则的自定义解。
- **与最近 12 页的差异**：036 是晨空浅蓝单弧 C 开口定向台、035 是奶油红蓝折线 Z 跨度台、203 是深青金星对称放射轮盘、158 是暖砂有机绕排文本、324 是朱砂裁景刀窗；本页首次以「深松夜绿双反弯河道曲率雕塑 + 实时曲率正负翻号波形 $\kappa(t)$ + 圆窗实景河流同步变形」为核心动作，完全无法套用到其他构图编号。

## 3. 版式骨架
- **1440×900 & 2560×1440 桌面**：忠实承袭 037 原海报的全出血深松夜绿开放展面（零独立暗色导航条、不锁 `100svh` 避开平板空洞），主宽 `1380px`（2560 舒展至 `1720px`）。左上非对称巨幅自示范活体「S 形构图」主标配短水青横杠与总述，右上青柠「构图原理」与实况状态徽呼应；主体左 57% 为无重箱束缚的纵贯活体 S 河道画布（含原海报中央圆窗溪山），右 43% 上承单真源流态诊单与 $\kappa(t)$ 曲率波形、下承 1:1 复刻原海报青柠细框圆角「应用要点」互动卡与精控轨；底沿通栏复刻原海报双叶「让 S 形为你服务」虚线箭与 4 步导流条。

## 5. 节目录（共 7 节，每个 h2 ≤ 12 字，相邻节交互不雷同）
1. **01 为什么弯一下更好看**（暖米宣纸）：引原海报四要点并白话拆解认知机理（良好连续律 + 曲线亲和效应），温和辨析「海报说多了一点」之处；交互为**四线眼动对照赛跑台**（直线 / Z 折线 / C 单弧 / S 双反弯四轨并行播放与进度拖动，附同小类 031–040 一句话外链）。
2. **02 从山水到美的线条**（溪水青纸）：梳理 1072 郭熙《早春图》、1584 洛马佐《绘画、雕塑与建筑艺术论》蛇形体、1745/1753 荷加斯《美的分析》、1923 韦特海默与 2006 巴尔/内塔研究；交互为**时代石碑切换 + 透视 S 骨架叠加开关**。
3. **03 荷加斯七条弧度尺**（深松夜绿暗室）：展开原海报「控制曲线弧度」；交互为**7 枚并列竖向蛇形线标本选尺 + 杂志跨页排字实时映射**，每选一号由几何模型实时算出最大曲率与安全栏宽。
4. **04 四站排兵与留白账**（淡芽米黄纸）：展开原海报「起点终点 / 主次内容 / 留白呼吸」及四步实操；交互为**海报四站位卡牌互换与干扰开关装配台**（点换站位、开关同大字号与挤压留白，观察层级串联成败）。
5. **05 什么时候别用 S 形**（暖米宣纸）：列出多列对照表、急读导视公告、庄重对称礼仪三大忌用场景；交互为**翻车 vs 换骨架三组对比翻牌器**。
6. **06 眼力小测：哪幅最顺眼**（溪水青纸）：4 个仅差单一几何变量的中性标签方案 A/B/C/D 矢量实景测验，作答后逐项给几何理由并可重测。
7. **07 原海报与关键词**（深松夜绿展墙）：原海报可点开灯箱放大拖拽与 Esc 关闭，附完整原海报要点索引、同小类 9 篇横向导览与标准单行页脚。

## 7. 小练习设计
- **题目**：同一张「秋季溪山茶会」竖版展讯（主题、字号层级、配色与山溪主视觉完全一致），四张方案仅在「S 曲线骨架与节点落位」这一个维度不同，哪一幅真正发挥了 S 形构图的引导力？
- **选项（全中性标签：方案 A / 方案 B / 方案 C / 方案 D）**：
  - 方案 A：单侧同向弯弧（缺失反向拐点，实为 C 形半包围，视觉重心单边倾斜）。
  - 方案 B（正确答案）：双反弯柔和 S 线（贴近荷加斯 4 号弧度），入口右上、主视觉稳坐中央拐点、副信息落左弯、出口收在左下画内，留白约 42%。
  - 方案 C：双反弯但弧度过急（类似荷加斯 6–7 号发卡弯），弯腹逼近画框挤压两侧留白，视线急刹。
  - 方案 D：曲线弧度本身柔和，但信息节点偏离曲线贴靠画框外角，出口箭直指右下角把视线甩出画面。
