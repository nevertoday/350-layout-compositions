# 213 横 排 右起（RIGHT-START HORIZONTAL LAYOUT）设计方案

## 1. 一句话道理
把视觉重心与对齐基准锚定在画幅右侧，再借字号反差、留白与中段牵引把次要信息向左有序展开，能在习惯左起扫读的环境里制造鲜明的右侧停顿点，让短横幅、对页眉注与右起文字体系形成清晰而克制的阅读秩序。

## 2. 开场玩具
- **命名**：横幅右锚与波点牵引编排台（Right-Origin Banner & Halftone Pull Composer），2D Canvas 实时渲染，承袭 213 原海报中部「版式示例」暖白横幅、漆黑大标、左侧三组服务图标与标志性的向左渐变绯红波点阵（画布标 `data-perf-drag`）。
- **怎么玩**：
  - 在画布中直接左右拖动 4 类实体模块（① 焦点主标、② 引导角标与副标、④ 辅助服务列，以及 ③ 中段渐变波点阵的牵引范围），或在画布空白处左右横拖推拉主视觉重心；
  - 切换模块对齐方式（右对齐 / 左对齐 / 居中）、调整波点阵牵引方向（向左渐散 / 无牵引 / 向右逆拉）与主次字号权重；
  - 支持原海报「臻选好物」、美术馆「新锐器物展」、节气茶礼「秋分白茶」三套横幅文案实时切换；
  - 键盘 `1`–`4` 选板块、`←`/`→` 精细挪位、`Space` 触发视线光珠按当前实测顺序演练一遍。
- **开场状态（绝不先给答案）**：
  - 开场刻意停在「原点左偏 + 辅助抢右 + 左齐散边 + 波点逆拉」的复合错态：大标滑到左中区（重心落点偏左）且用左对齐，辅助信息反客为主挤在右侧，渐变波点左浓右淡往回反推；上方 1:1 复刻原海报的 `④ ← ③ ← ② ← ①` 阅读流程带立刻点亮故障节点并给出实测断层提示。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 由 `model.js` 从 4 块实绘矩形边界（像素坐标、面积×墨度视觉重心、右缘对齐散差、模块交叠像素、权重比、波点梯度方向）单真源核算 **7 类双向真错态**：① 原点偏左/中悬、② 辅助抢占右侧原点、③ 右缘未齐（左齐或居中使右锚散架）、④ 模块碰撞压字、⑤ 波点逆向反拉或死板平铺、⑥ 主次权重拉平抢焦、⑦ 紧贴右边界窒息（留白不足 4%）。
  - 读数不仅报出实测位置与散差，还直接用白话说明「眼睛第一眼会撞去哪、为什么在画面里左右折返」，并接受多组合法解（原海报经典解、宽境留白展签解、紧凑商品卡解）。
- **与最近 12 页的区别**：
  - 彻底不同于 212（钴蓝纯多行文字左推齐与回扫弧线）、081（透视走廊）、332（四圆镜气韵）、298（3D 折页）、167（黑底引语断行）、253（Z 轴卡片浮层）、042（金字塔叠阶）、130（五层蛋糕扫描）、211（网格碎块切割）、297（蓝图优先级阶梯）、166（九格图录对比）、331（朱红透视双扉）。213 专注「横幅级右侧原点、模块空间排布与半调波点向左拉动」。

## 3. 版式骨架
- 忠实转译 213 原海报的「右锚巨标 + 左侧导流 + 通栏横幅」结构，绝不锁 `100svh`，不用通用深色顶栏与圆角仪表盘黑箱：
  - **1440×900（主宽 1360px，2560 舒展至 1680px）**：樱粉原纸底 `#FEECED` 与右上出血蔷薇巨圆弧 `#FCDBDF`；顶部非对称双翼——**右翼 30%** 钉住竖落折行特粗大标「横 / 排 / 右起」与右上绯红原点圆锚，成为整个页面的第一落点，**左翼 70%** 向左展开总述与 1:1 复刻的 `④ ← ③ ← ② ← ①` 实时阅读流程带；中段全宽开放「横幅右锚编排台」画布；下方 1px 樱灰线分隔「左单真源白话诊单 + 右场景/对齐/波点精控台」；底沿 4 栏虚线竖隔原海报「设计要点」实时指示带。
  - **1024×1366 / 768×1024 平板**：自然流排不留空洞，主画布维持宽幅比例，诊单与控台上下紧接齐整。
  - **390×844 手机竖屏**：顶行压紧右置紧凑大标与锚徽（总述后置），使紧凑流程条与等比宽幅编排画布稳占首屏 ≥ 46% 高度且同屏直见诊单首句与纠错动作。
  - **844×390 手机横屏**：切为左 56% 全高编排舞台 × 右 44% 紧凑刊头、诊单与快捷按钮并行，不压扁不溢出。

## 5. 节目录（7 大节，h2 均 ≤ 12 字，相邻控件零重复）
- **01 右锚为什么也能站稳**（`WHY RIGHT-START WORKS`）：拆解视觉权重如何克服左起惯性，建立由右向左的有序展开；交互为「四拍视动分步解剖器 + 三种横幅结构切卡」。
- **02 两种右起，别混为一谈**（`LAYOUT VS. SCRIPT`）：辨析「现代版面级右锚」「古建匾额一行一字右起」「阿拉伯/希伯来语天然 RTL」三者本质区别；交互为「真实 DOM 三轨标本显微镜（含 `dir="rtl"` 逻辑属性与镜像清单）」。
- **03 从哪来：匾额到网页规范**（`WHERE IT CAME FROM`）：深绯暗室展陈，串联东亚传统匾额、1942/1952 日本公文左横书改革、1955/1956 中国报刊横排改制、1992 Bringhurst 偶页右齐、Unicode UAX #9 与 2019 W3C CSS Writing Modes；交互为「年代卷轴抽屉与微缩历史标牌」。
- **04 什么时候用，什么时候别用**（`WHEN TO USE & AVOID`）：温和纠偏原海报结语的适用边界，说明长正文右齐为何伤眼、中文倒序为何致误；交互为「行数与体裁实时回扫压力测试仪（滑块 2–12 行 + 左缘锯齿方差实测）」。
- **05 做好右锚的四条硬规矩**（`FOUR CRAFT RULES`）：围绕原海报四要点给出可验证的工程经验值；交互为「四枚独立体检拨动开关实时联动迷你茶礼横幅」。
- **06 眼力练习：选出站稳的一张**（`PRACTICE`）：四张「素瓷新器」横幅仅差一个变量，纯中性标签 A/B/C/D，选后逐项解析。
- **07 原海报与关键词**（`ORIGINAL POSTER`）：点击放大并支持拖拽/缩放/Esc 关闭的原海报灯箱 + 1:1 复刻粉白交替 6 枚关键词胶囊 + 212–221 同小类链接索引 + 规范页脚。

## 7. 练习设计
- **题目**：为「素瓷新器」茶具新品制作宽幅横幅，要把焦点锚在右侧并向左展开三项工艺亮点。下面 A/B/C/D 四个方案每张仅改了一个结构变量，哪一张真正成立？
- **四项差异（各只差一个变量，标签全中性）**：
  - **方案 A**：结构与权重均在右，唯独主副标题用了**左对齐**，导致右侧锚线散架。
  - **方案 B（正确）**：主副标锚在右侧且严齐右基准线、留有右侧呼吸边、波点从右向左衰减、左侧辅助轻巧退让。
  - **方案 C**：右对齐与波点流向正确，唯独左侧三条辅助标签**放大加底色抢焦**，与右侧主标争抢第一落点。
  - **方案 D**：主副标与左侧辅助权重正确，唯独中段波点矩阵**左浓右淡反向牵引**，视线方向与信息流互相拧着。
