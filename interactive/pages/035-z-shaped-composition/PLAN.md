# 035 Z形构图 · 方案（PLAN.md）

## 1. 一句话道理
Z 形构图不是让画面硬画一个字母 Z，而是顺着左至右、自上而下的阅读习惯，用**左上入口 → 右上承接 → 对角视觉桥 → 左下转折 → 右下终点**的四站权重梯度，把视线在有限停留时间里完整带到核心行动点。

## 2. 开场玩具
- **名称**：Z 轨眼动编排台（2D Canvas，1:1 化用 035 原海报奶油暖象牙纸底、实心朱橘红 Z 轨带、白色虚线方向箭、四枚红圈白底蓝图标圆徽与斜切浅暖灰标注带）。
- **怎么玩**：
  - **画布横拖（绑定 `data-perf-drag`）**：在画布上左右拖动，实时拉展/压缩 Z 形横跨张度（28%–86%），同步联动四站水平间距、对角斜桥倾角与刊头巨幅橘红 `Z` 的倾斜呼应。
  - **直拖四枚圆徽节点**：可微调 P1–P4 站位，也可拖至另一站互换角色，或点按交换按钮重排四站顺序。
  - **直点画布缺口/干扰块**：点中路红框「抢戏干扰块」一键清场；点断裂的「对角视觉桥」一键接通实心斜带。
  - **题材与键盘**：支持切换「原海报四站图 / 爵士夜海报 / SaaS 首屏」三套真实题材；键盘 `←/→` 调横跨、`↑/↓` 调纵距、`1–4` 选站、`Space` 开关干扰块、`R` 复原错态。
- **开场初始状态（绝不先给答案）**：停在 `0/4 断流错态`——Z 跨度压扁至 34% 缩成窄竖柱、首尾站位倒置（右下靶心与左上入口互换）、对角斜桥断裂、中路塞入一个抢戏红块截胡视线。
- **怎样算玩错 & 读数怎么说**：`model.js` 用同一套实绘四点几何坐标 + 显著性引力跃迁方程实时算出真实预测扫视路径，能明确玩出 8 类错态（窄柱退化、斜桥过平、角色倒置、中路截胡、断桥跳角成「7」字、四站平权拉锯、终点失重滑框、文字过密塌缩成 F 形），每种错态在画布上直接画出真实的错误跳转红线，并在诊单用白话讲清「为什么眼睛没走到终点」以及下一步怎么改；同时接受「原海报经典解」「宽幕横幅解」「紧凑竖海报解」等多组合法解。
- **与最近 12 页的区别**：034 调 V 形双翼夹角聚底焦、033 调 L 形柱宽底厚、117 捋交叉点列折角、284 填真实表单、201 校 8×8 正方格、242 拖三槽容器宽、070 扳透视射线回消失点、323 转扇弧发射角、322 拨曲河道、156 裁主侧栏刃、157 排边注锚线、283 拖软件工作区——本页专做**四站权重排序 + 对角桥贯通 + 真实眼动跃迁求解**，是 Z 形构图独有机制。

## 3. 版式骨架
- **忠实转译 035 原海报的「Z 形横扫导视骨架」**（零暗色仪表盘框、不锁 `100svh` 避开平板空洞）：
  - 顶部 3px 红蓝跑道细线直接入奶油原纸：左上自示范双色大标（巨幅橘红 `Z` 随画布倾角联动 + 钴蓝「形构图」+ 英文 + 橘杠 + 总述），右上呼应原海报「构图原理 / COMPOSITION PRINCIPLES」与题材/状态胶囊，刊头本身完成第一横扫。
  - 中段 100% 满幅开放画布，左右交替嵌入原海报标志性的斜切浅暖灰底带；画布下方紧接斜切左蓝右红的单真源白话诊单条与紧凑单行控槽。
  - 首屏底沿 1:1 复刻原海报 `1.5px` 皇家钴蓝细圆角四栏实况框（4 枚蓝图标随状态实时亮灭）与底沿标语 `▶ 一条 Z 形路径…… >>>`。
- **响应式**：
  - `2560×1440`：主宽舒展至 `1720px`，开放大气。
  - `1440×900`：主宽 `1360px`，首屏完整见大标、画布、白话诊单与底沿四栏框。
  - `1024×1366 / 768×1024`：不锁 100svh，自然流排零大块空白。
  - `390×844`：压紧单行刊头，让等比画布稳占首屏 ≥ 48% 屏高，同屏可见白话诊单首句与快修按钮；所有圆徽严格按物理等比绘制。
  - `844×390`：切为左 56% 活体 Z 轨画布 × 右 44% 刊头、诊单与快控并行。

- **配色（实采自 035 原海报）**：
  - 纸面：奶油暖象牙 `#FBF4E8`、亮宣纸 `#FFFBF2`、斜切浅暖灰 `#F0EBE1`、细界线 `#DDD6C8`。

- **字体**：`Noto Sans SC` + `Anton` + `Outfit` + `JetBrains Mono` + `Libre Baskerville`（正斜体）。

## 5. 节目录（7 节，h2 均 ≤ 12 字，相邻节控件各异）
1. **01 四站是怎么接力的**：原话拆解海报四要点；交互为 4 枚原海报圆徽步进剖析卡 + 联动 SVG 眼动能量弧。
2. **02 从古腾堡图到屏幕扫视**（从哪来）：溯源 1956 Arnold、1954/1974 Arnheim、2003 Lidwell 与 NN/g 眼动研究；交互为三模型切换 + 左→右/右→左阅读方向镜像器。
3. **03 对角桥为什么会断**（深钴暗室）：拆解右上到左下的逆向斜切如何搭桥防跳角；交互为 2D 暗室 2 秒一瞥模糊扫视实验台（无桥 / 几何斜带 / 剪影朝向 / 斜光束）。
4. **04 真 Z 与假 F 的分界线**：温和修正海报「说多了一点」之处，辨析 Z 与 F 及同小类 031–040；交互为字数密度连续滑杆，实时看 Z 轨坍缩成 F 扫视。
5. **05 什么时候用，什么时候别用**：给出四宜四忌清单；交互为 6 张真实项目派单分诊卡（点击翻判宜/忌与理由）。
6. **06 挑出真正走通 Z 的那一版**（小练习）：四版「城市爵士夜」同题海报 A/B/C/D，仅差单变量，选完叠加真实扫视轨与解析。
7. **07 原海报与关键词**：可放大拖拽的原海报（`draggable="false"`）+ 海报四组关键词与底语 + 页脚。

## 7. 练习设计
- **题目**：同一张「城市爵士夜」演出海报（含标题、时间场馆、萨克斯乐手剪影、右下购票码），四个版本只差一个关键结构变量，选出最能让视线顺畅走通 Z 形并落在右下购票区的一版。
- **选项（只标 A / B / C / D，无好坏暗示）**：
  - **A**：四角均分同等字号与橘红色块（变体变量：无权重梯度 → 四站平权拉锯）。
  - **B**（正确）：左上强标题 → 右上轻日期 → 乐手剪影与斜向管身自右上斜指左下看点 → 右下橘红购票码收口。
  - **C**：把大号橘红购票块放到画面正中（变体变量：中路截胡 → 视线死在中央、四角失联）。
  - **D**：斜线与乐手朝向改为左上直指右下且左下角留空（变体变量：断桥跳角 → 视线走成「7」字直接跳过第三拍）。
