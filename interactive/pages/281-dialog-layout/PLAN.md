# 281 对话布局（DIALOG LAYOUT）设计方案

## 1. 一句话道理
人脑天生用「空间轨道 + 轮次相邻对」处理对话：把两位发言者分置左右两侧、用差异气泡锚定身份，并用紧窄组内间距与宽松换轮间距切分「提问 + 回应」，阅读者无需反复回看署名就能顺着自然的 Z 形动线听懂一整场交流。

## 2. 开场玩具
- **玩法**：一个真实可操作的「活体对话剧场」（1:1 化用 281 原海报《设计问答》六条真实对话，并可切「客服退换排查 / 教学排版诊室」两套场景，底沿带真实快捷追问栏可发出新的一问一答）：
  1. **顶沿 2D Canvas 气泡宽度与节拍标尺（`data-perf-drag`）**：鼠标/触屏/方向键左右横拖，实时改变真实气泡的最大宽度（`28%–96%`），气泡与中央 2D Canvas 视线动线层同帧联动重绘。
  2. **画布内直点对话气泡**：点击错序或错边气泡即可原地对调轮次（`↕ 调顺轮次`）或拆分塞成文字墙的长气泡（`✂ 拆短气泡`），也能故意点乱来压测跨行回找。
  3. **底部一体化对话槽（非右侧仪表盘）**：调控角色区分（同侧同色 / 左右交替 / 左右+双色气泡 / 五彩盲乱）、轮次间距（粘连无界 / 成对分组 / 问答脱节），并可点快捷追问芯片真实发出一轮带 `• • •` 思考脉动的新对话。
- **开场初始状态（0 / 4 待理对话，绝不先给答案）**：
  1. 角色塌陷：双方全部挤在左侧且同为灰白平块，丢失左右双轨与色彩区分；
  2. 轮次打结：第 2、3 条错序导致出现连续同侧堆叠与跨行答非所问，中轴动线标出红色回找弧线；
  3. 宽墙越界 + 话痨塞团：气泡宽度拉至 `88%` 越过中轴，且第 4 条为 80+ 字密实长段；
  4. 轮间粘连：组内与换轮间距同为 `6px`（比值 `1.0×`），三轮「提问 / 解释 / 总结」糊成一块。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - `model.js` 单真源实时核算 8 类失误：同侧混边、五彩噪点、轮次错配、宽墙越界（>76% 横向重叠）、瘦条折行（<44% 每行碎字）、话痨文字墙（单条过长）、轮间粘连（比值 <1.5×）、问答脱节（组内距反大于换轮距）。
  - 每次出错不仅报实测几何值（宽 `%`、估算每行字数、组间/组内间距比、相邻对匹配数），还用白话说明视线为什么会卡壳、读者的注意力被什么打断；同时支持「原海报双色解」与「极简黑白空间解」等多组合法解。
- **与最近 12 页的区别**：
  - 280 是三栏树形目录与级联卡，279 是 7 列月历网格拖事件，235 是粘性滚动手账，234 是固定视口剖面，152/151 是暗房蒙太奇与撕纸拼贴，112/111 是高饱和渐进/交替图形，028/066/318/196 是构图与模块画布；281 独有「气泡即标题 + 左右双轨活体聊天剧场 + 顶沿气泡宽标尺直拖 + 气泡内原地调序拆段 + 真实追问交互」，无法套到任何其他编号。

## 3. 版式骨架
- **1440×900 桌面端**：主容器宽 `1360px`（2560 下舒展至 `1680px`）。承袭 281 原海报骨架：顶眉下为「左纯白大气泡示范标题（带左下尾角与右上三枚珊瑚打字点）× 右蓝竖杠总述与 5 枚原海报关键词实时检核标」；下方全宽展开冰蓝圆角对话剧场（顶沿 2D Canvas 宽度标尺 + 左右双轨与中央虚线阶段轴 + 底部双栏一体化诊单与对话控槽），不锁 `100svh`，首屏干净完整。
- **1024×1366 / 768×1024 平板**：自然流式排布，不出现 `100svh` 空白洞；对话剧场保持全宽舒展，底部诊单与控槽按宽自适应两列或整齐叠放。
- **390×844 竖屏手机**：压缩单行顶眉与紧凑气泡标题，让对话剧场与 `48px` 高的宽度标尺直落首屏占 `≥ 48%` 屏高，同屏可见单真源诊单首句；所有圆头像锁 `1:1` 比例不被压扁，按钮不换行、触控区 `≥ 40px`。
- **844×390 横屏手机**：切换左 `56%` 活体对话剧场与标尺 × 右 `44%` 紧凑气泡刊头、实时诊单与快控并行。

## 4. 配色和字体
- **配色（逐像素实采自 281 原海报）**：
  - 冰天蓝纸底渐变：`#E2EDFB` → `#EDF5FE`（辅以 `#F4F9FF` 浅雪白与 `#FFFFFF` 纯白气泡）
  - 设计师钴天蓝：主色 `#1171FD` / `#005FFF`，头像浅蓝 `#96BEFC`，浅底高对比深钴字 `#0A50CC`
  - 阅读者暖杏珊瑚：气泡底 `#FFF2E6`（描边 `#F6D2B6`），头像柔粉 `#FFE1D9` + 珊瑚橙 `#FE754F`，浅底高对比深赭珊瑚字 `#B23812`
  - 深海午夜墨：主墨 `#091334`（采自海报 `#000018`/`#020622`），次墨 `#3A4A6B`，03 节深蓝暗室底 `#0B1739` / `#132352`（采自海报底带深蓝 `#2A2E5A` 深化）
  - 状态克制色：错态赤红 `#C22D2D`（暗底 `#FF8A80`），达标翠青 `#0D735C`（暗底 `#66DFC2`）
- **字体搭配（全库唯一；三款西文在近 12 页全部 0 次使用）**：
  - `noto-sans-sc` (400, 900) — 中文界面主体与气泡大字
  - `manrope` (500, 800) — 圆润几何无衬线，用于 `DIALOG LAYOUT`、英文角色标与等宽表格数字（近 12 页 0 次使用）
  - `fraunces` (400, 700 + italic 400, opsz 72 / SOFT 50) — 温润编辑衬线，用于节号、引文与编排注记（近 12 页 0 次使用）
  - `chivo` (400, 700) — 利落新怪诞无衬线，用于微标签、年代与参数刻度（近 12 页 0 次使用）

## 5. 节目录（共 7 节 + 页脚，每节标题 ≤ 12 字，相邻不用同类控件）
- **01 为什么左右交替好读** (`WHY ALTERNATION WORKS`)：讲清空间轨道预注意编码与相邻对机制，引用原海报核心原则；**交互**：三态结构解剖切换（纯文本日志 / 单侧媒体对象流 / 左右双侧气泡）+ 实时 SVG 眼动跳转路径对比。
- **02 气泡里的五个零件** (`ANATOMY OF A DIALOG`)：拆解抽象头像、尾角指向、双色语义、中轴阶段锚点与连发折叠；**交互**：放大标本气泡的 5 处可点选热点解剖针 + 「连续发 3 条：逐条重复 vs 连发合并」对比开关。
- **03 宽屏、窄屏与群聊** (`SCALE & GROUP CHAT`)：用数据讲行宽、手机/超宽屏像素封顶，并温和补正原海报未涵盖的多人群聊与 AI 长回答边界；**交互**：2D Canvas 屏宽与人数动态演练台（切换二人私聊/五人群聊/长答 AI + 390/768/1200 视口 + 气泡封顶滑杆）。
- **04 对话布局从哪来** (`WHERE IT CAME FROM`)：按核实史实梳理 1974 轮次分析 → 1983 Unix `talk` → 1988 IRC → 1997/2002 Jens Alfke 与 Apple iChat → 2007 iPhone 短信线程 → 2020s 现代对话界面；**交互**：年代标本切换机，同一段问答在 5 个历史界面里实时变形重演。
- **05 什么时候用，什么时候别用** (`WHEN TO USE & AVOID`)：结合原海报 5 大应用场景与 4 类典型误用（多字段表单、密表格、深层级文档、单向长文），链接同小类兄弟页；**交互**：6 张场景分诊卡，点击逐一查看判定结论与替代布局入口。
- **06 眼力小练习：挑出好对话** (`VISUAL DIAGNOSTIC QUIZ`)：两道仅差单一结构变量、全中性标签（方案 A/B/C/D）的视觉挑错题，选完揭示实测几何线与理由；**交互**：四选一图卡诊断测验 + 切题器。
- **07 原海报与关键词** (`ORIGINAL POSTER`)：展示原海报（点击打开可缩放、可拖拽、`Esc` 关闭的大图看图器，`draggable="false"`）与原海报五词及五类场景徽标。

## 7. 练习设计
- **题目 1（成对间距与宽度边界）**：四张缩微对话卡（方案 A/B/C/D，内容、配色、角色全相同，不出现评判标签）：
  - A：组内距 26px > 组间距 8px（问答拆散、跨轮粘连）
  - B：四条气泡均匀 14px（失去轮次分组边界）
  - C（正确）：同轮问答 8px 紧贴、换轮 26px 拉开，气泡宽 62% 留出清爽对向留白
  - D：间距正确（8px / 26px），但气泡拉宽至 92% 越过中轴导致左右边界糊成一块
- **题目 2（五人群聊角色编排）**：四张群聊界面卡（方案 A/B/C/D，完全中性标签）：
  - A：按发言顺序轮流放左放右（同一人一会儿在左一会儿在右，身份锚点崩溃）
  - B（正确）：所有他人统一居左并靠头像+署名区分，仅「我」居右（稳定自我参照系）
  - C：五个人全放左侧且共用同一蓝色气泡、不显示姓名（彻底无法分辨发言人）
  - D：五个人分配五种高饱和彩虹底色并随机左右对齐（色噪干扰正文且位置不固定）
