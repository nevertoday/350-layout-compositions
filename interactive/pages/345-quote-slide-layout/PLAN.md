# 345 引语页幻灯片版式 · 方案

## 1. 一句话道理
把一整段话删剩唯一能击中人心的十几字，借大字弯引号与大片情绪留白按下演讲的「暂停键」，让观众 3 秒内扫完抬头继续听你讲，并把这句话与可信的署名一起刻进记忆。

## 2. 开场玩具：「演讲台删词雕琢与翻页静场仪」
- **怎么玩**：
  - 舞台中央是一张 1:1 承袭 345 原海报雾紫水墨美学的 16:9 活体幻灯片画布（2D Canvas，标 `data-perf-drag`），顶沿挂 3 页演播胶片条（`01 密字铺垫页 → 02 引语页（本页）→ 03 行动结论页`），四周直接环抱原海报 4 条细紫虚线引注（**引语 / 重点句 / 情绪留白 / 署名**）。
  - **横向拖动画布或删词提纯尺（也支持 `← / →` 键）**：实时把一整段 70+ 字的原始摘录逐句提纯——被删去的赘词化作淡紫微雾漂散，留下的核心句同步放大字号、张开象牙白半圆环与雾紫留白；继续往右过度拖动则会「删过头」变成残缺碎词，触发反向报错。
  - **直接点击画布元素或四周 4 枚原海报虚线引注**：
    - 点左上引号切换「打字机直引号 `""` → 象牙弯引号 + 半环 → 喧宾夺主巨压引号 → 现代左齐竖杠引线」；
    - 点引文任意短语独立切换紫粉笔触高亮（可 0 处平铺、1 处聚焦或满屏乱划）；
    - 点留白外环切换「贴边满铺杂讯 / 舒朗留白 / 缩成米粒孤岛」；
    - 点底部署名切换「无署名 / 含糊头衔 / 清晰可信署名 / 署名压主三行履历」。
  - **按 `Space` 或点「实境翻页」**：先快速闪映上一页高密度论述幻灯片，再切入本页运行 3 秒观众凝视光环，实测听众能否在 3 秒内扫完并把注意力交还给演讲者。
  - 提供三套语境：原海报示例（附「原话核查」温和提示）、产品发布用户访谈原声、书籍真实原句（Nancy Duarte《slide:ology》2008）。
- **开场初始态（绝非答案）**：0/4 失焦念稿态——74 字未删减长段塞满 5 行 + 打字机直引号 `""` + 无核心词高亮且背景杂乱（有效留白仅 33%）+ 含糊署名「—— 某设计师」。
- **怎样算玩错与读数说明**：由 `model.js` 单真源从当前真实字数、折行数、实绘文本包围盒留白率、高亮字数占比、引号形态与署名规格同步计算，双向检出 10 类正反错态（字墙念稿 / 过度删空 / 直引号失格 / 引号压字 / 平铺无焦点 / 满屏乱划 / 留白窒息 / 米粒孤岛 / 署名缺位 / 署名压主），并用白话直指「观众此刻在台下会怎样反应」；同时认可原海报居中圆弧解、左齐竖杠现代解、极简高留白剧场解三组合法方案。
- **与最近 12 页的差异**：摒弃仪表盘式「固定画框 + 右侧三段按钮」与 341–343 的矩形色块排版，采用「词句实时删繁提纯 + 演讲翻页 3 秒凝视验真 + 四角原海报放射虚线直控」的演讲台专属玩法，别的编号无法套用。

## 3. 版式骨架
- **整体语言**：1:1 转译 345 原海报「雾紫丁香宣纸通幅展页 · 中央悬浮 16:9 幻灯片 × 四角细紫虚线探针环抱 + 底沿薰衣草水墨远山 + 右上 3×3 紫点阵」，绝不锁 `100svh`。
- **1440×900 / 2560×1440**：主宽 1360px（2560 舒展至 1620px）。轻盈浅紫刊头带自示范大标（巨型象牙白弯引号轻托 + 绯粉水彩笔触下划「引语页」）；中段左 18% 双虚线引注（引语 / 署名）× 中 64% 活体幻灯片 × 右 18% 双虚线引注（重点句 / 情绪留白）；下方齐宽单行导演坞（左白话诊单 × 右删词滑尺与直控键，两栏严丝齐底）；底沿过渡淡紫水墨远山进入正文。
- **1024×1366 / 768×1024 平板**：自然文档流，满宽 16:9 幻灯片下方排 2×2 四桩探针横条，再接齐底双栏导演坞，零大片空白。
- **390×844 手机竖屏**：压缩单行顶栏与紧凑标题，等比 16:9 幻灯片画布顶置占首屏 ≥ 46% 高度，折线内直露删词主滑尺、白话诊单首句与「一键提纯 / 实境翻页」双键；四桩详细引注置后。
- **844×390 手机横屏**：左 56% 等比幻灯片画布 + 删词轨 × 右 44% 紧凑标题、诊单与双主控键并行。

## 4. 配色和字体
- **配色（逐像素实采自 345 原海报）**：
  - 雾紫丁香宣纸底 `#ECE3F6` / 亮薰衣草读纸 `#F7F3FC` / 淡紫雾带 `#E7DCF3` / 远山紫晕 `#C3AFD5` `#AE97C5`
  - 极深墨紫主字 `#140726` / 次墨 `#3D275C`
  - 核心鸢尾紫 `#53237C` / 重点词高亮 `#6E3DA6` / 高对比浅底深紫字 `#4A2270`
  - 象牙白引号与半环 `#FFFCFC` `#FFF7FE`
  - 绯粉水彩笔触 `#EC9DC5`（深底提亮 `#F4B6D7`，浅底作小字标用高对比深莓紫 `#8E2E63`）
  - 放映厅暗室（03 / 06 / 页脚）：深宵紫墨 `#160C26` / 暗舱 `#22143A` / 极深页脚 `#0F071B` / 暗室暖白字 `#F7F1FC` / 亮丁香 `#D4B5FA`
- **字体**：`Noto Serif SC`（400/700/900）+ `Young Serif`（400，**近 12 页 0 次使用**，专司巨型弯引号与英文展示）+ `Outfit`（400/500/600/700，**近 12 页与 340–344 均 0 次使用**，用于 `QUOTE SLIDE LAYOUT` 与界面控件）+ `DM Mono`（400/500，页码与计时读数）。全库 0 重复，中文段落内西文/年份跟随正文同族避免跳动。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻节交互不重样）
- **01 拆解四桩支柱**（`FOUR PILLARS`）：引用海报四项原话，配四节点剖面高亮切换器 + 原海报「原研哉原话核查」温和纠偏卡。
- **02 多少字才够停**（`THREE-SECOND RULE`）：讲清 Mayer 冗余原则与 3 秒读完经验值，配可调字数的「6 秒演讲字幕 × 观众阅读双轨抢夺模拟条」。
- **03 放映厅暗室对照**（`AUDITORIUM LAB`）：深宵紫暗室，提供「三构图（居中圆环 / 左齐竖杠 / 剪影双栏）× 双场地（明亮会议室 / 昏暗礼堂）」切灯对比台（人像仅用侧影剪影，绝不画五官）。
- **04 从哪来**（`ORIGINS & LINEAGE`）：核实过的标点传统、PowerPoint 1987、Tufte 2003、Reynolds & Duarte 2008 脉络，配四节点可翻阅版式演进卡尺，并一句话串联同小类 344/346–350。
- **05 什么时候别用**（`WHEN NOT TO USE`）：四类失效边界，配「4 个演讲场景红绿灯速检翻转卡」。
- **06 眼力小练习**（`QUICK CHECK`）：深宵紫考场，2 道单变量四选一 SVG 幻灯片盲测（选项只标 A/B/C/D，绝不剧透）。
- **07 原海报与索引**（`ORIGINAL POSTER`）：原海报点开可缩放拖动（`draggable="false"`、Esc 关）+ 四要点与同小类索引 + 规范页脚。

## 7. 练习设计
- **第 1 题（内容密度、重点与署名比例）**：A 68 字 5 行密字原稿（仅差字数过载）、B 16 字 2 行 + 3 字紫粉重点 + 65% 留白 + 清晰克制署名（**正解**）、C 16 字 2 行但整句全部高亮（仅差满屏强调失效）、D 16 字 2 行但署名比引文更大且占 3 行（仅差署名压主）。
- **第 2 题（引号形态与出处真实性）**：A 直引号 `""`（仅差打字机引号失格）、B 实心巨型深紫引号盖住首字（仅差装饰压字）、C 轻盈弯引号但署名只写「某知名设计师」（仅差来源含糊）、D 轻盈弯引号 + 清晰可核实的作者与书名年份（**正解**）。
