# 076 轴测构图（AXONOMETRIC COMPOSITION）方案

## 1. 一句话道理
轴测构图把视点推到无穷远，用平行投射线一次性展开物体的三个空间维度：平行边永不收敛、同轴尺度处处可量，既保留了立体体积感，又像工程图纸一样清楚呈现内部构造与装配层级。

## 2. 开场玩具：精密装配体爆炸轴测解剖台
- **视觉母题**：1:1 承袭 076 原海报午夜普鲁士蓝工程图纸、左上 45° 切角青蓝标题框、中央沿 Z 轴展开的四层机械组件（顶板圆孔盖板、工业蓝 U 形主体、圆柱销 L 形连接件、双圆孔空腔底座）、垂直虚线装配导轨、右侧金色圆点引出标注、右侧竖虚线独立工程参数栏及底沿 01–05 绘制步骤带；支持在「原海报·机械装配 / 现代主义·建筑剖析 / 精密光学·镜组拆解」三套真 3D 矢量装配模型间一键切换。
- **怎么玩**：
  - 在主画布（`data-perf-drag`）左右横拖（或按左右方向键）连续旋转视角方位角 `yaw`；上下拖拽或推拉画布下方的「爆炸层距」滑轨，把四层组件沿 Z 轴从压死状态丝滑拆开；
  - 直接点击画布上被红框标出的偏轴「连接件」（或点「归位偏轴件」），让它咔嗒归回 Z 轴装配导轨；点击任意零件可高亮剖析其结构说明；
  - 可调节「透视渗入」验证平行投影与透视畸变的分界，开关「装配导轨与隐藏虚线」，或点右侧工程栏三枚原海报蓝色小立方体直达「等轴测 / 二轴测 / 三轴测」三套国际标准解。
- **一打开是什么状态（绝不先给答案）**：刻意停在 **0/4 闷死错位错态**——① 爆炸层距 `0%`（四层组件压成一团，内部圆柱销连接件完全被遮没）；② 视向退化在近正面死角（`yaw = 14°`、`pitch = 9°`），顶面和侧面被挤成窄缝，失去三维可读性；③ 连接件沿 X 轴脱出主轴 `+0.72` 且装配虚线与隐藏线关闭；④ 透视渗入开启 `44%`（前端棱比后端拉大，平行线正在收拢）。
- **怎样算玩错、错了读数怎么说**：全部状态由 `model.js` 从真实 3D 投影矩阵与屏幕实绘顶点坐标单真源核算：
  - 爆炸过紧（`< 30%`）报「层间闷死遮挡」，爆炸过散（`> 85%`）报「炸散脱节失联」；
  - 视向贴近正立面或正俯视（任一轴夹角 `< 95°` 或 `> 165°`，或俯角不在清晰三维可读窗）报「视角塌面退化」；
  - 存在透视收敛（前后同长棱比 `> 1.02×`）报「透视渗入·量测失真」；
  - 零件脱轴或缺少导轨与隐藏虚线，报「轴向偏离」或「缺少虚实层次」。
  - 读数每次都说明**视觉后果**（为什么读者看不清装配顺序或误判尺寸）并指明下一步；且**接受等轴测、二轴测、三轴测及清晰可读窗内的多组正轴测合法解**，实时判别当前流派并验算正轴测欧几里得铁律 $p^2 + q^2 + r^2 = 2.000$。
- **与最近 12 页的明显区别**：
  - 区别于 075（薄荷青纸上等角搭积木、只认 120° 唯一对称解）：076 是午夜工程蓝图上的**机械四件套沿轴爆炸分解与隐线剖析**，重点拉开「等轴测 / 二轴测 / 三轴测」广义轴测三流派差异，并温和指出原海报把 120° 等长当成全部轴测的「说多了一点」；
  - 区别于 074（暖米纸单一正面斜向拉深）、203（深绿星盘放射）、119（深藏青图底双关）、324（朱砂红裁景刀窗）等其余近期页，在题材、交互手势、结构骨架、色盘、字体上完全独立。

## 7. 练习设计
- **题目**：为一台带内部阀芯与定位销的精密组件绘制装配说明，要求读者一眼看懂零件上下咬合顺序与内部导槽，下面四张只改了一个构图变量的蓝图，哪一张最清楚？
- **四个选项（中性标签「方案 A / 方案 B / 方案 C / 方案 D」，均在同一视向角与同一组组件下绘制）**：
  - **方案 A**：爆炸层距为 `0%`（所有零件压在一起重叠，内部销轴被遮住）
  - **方案 B（正确）**：适度沿 Z 轴爆炸分离 + 垂直虚线装配导轨 + 外粗内细与隐藏虚线，轴向统一
  - **方案 C**：爆炸层距拉到过度飞散且拆掉导轨，组件互不呼应、看不出装配位置
  - **方案 D**：同一张图里各组件轴向角度各自偏斜（破坏轴向一致原则）
- **判定理由**：选任意项后立即展开该方案的具体几何剖析与正误对照，并允许切换查看其余方案。
