# 146 蒙德里安 版式（MONDRIAN LAYOUT）设计方案

## 1. 一句话道理
蒙德里安版式靠**正交粗黑线**建立清晰的非对称网格骨架，再用**大面积暖白留白承托少量高饱和原色块**，借「面积 × 色彩视觉重量 × 距中心力臂」达成**非对称的动态平衡**，让读者一眼抓住主次与节奏，同时避免均分棋盘的死板与满屏涂色的窒息。

## 2. 开场玩具：「蒙德里安纸带工作台」（Mondrian Tape & Color-Weight Studio）
- **怎么玩**：
  - 模拟蒙德里安在画室用黑纸带与彩纸片推敲构图的真实动作：画布内置 2 条可拖竖黑带、2 条可拖横黑带（主竖黑带柄标 `data-perf-drag`，支持鼠标/触屏拖移与键盘方向键微调）；
  - 画布内提供 2 段可点击开关的「局部 T 字黑线」（把通栏井字格拆成原海报式的 T 字非对称主次大格）；
  - 左侧明黄「蘸色盘」可选红（重锚）/ 蓝（深稳）/ 黄（轻亮）/ 暖白（留白），点击任意画布格子即可涂色或洗白（连点格子亦可快速上色），并支持切换「纯构成 / 展览海报 / 杂志封面」内容落位透视，直观检验文字在暖白大格中的透气度。
- **开场初始态（0/4 翻车态，绝非答案）**：
  - 全贯通 3×3 均分井字棋盘（面积比 1.0×，2 段 T 字线全部锁死）；
  - 红、蓝、黄、红、蓝 5 格密集挤在左侧与上排（暖白留白仅 44% 过载），二维视觉力矩重心严重偏坠左上（示意偏移 ΔX -25%）；四枚原海报关键词灯（网格 / 比例 / 对位 / 平衡）初始为 `0/4`。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 由 `model.js` 单一几何与力矩源实时计算并区分 7 类错误：
    1. **死板等距棋盘**：最大/最小格面积比 < 2.2×，读数说明「格子一样大，眼睛没有第一落点，像空白表格」。
    2. **彩色瓷砖过载**：暖白留白 < 52%（原色面积 > 48%），读数说明「强色铺太满，信息与留白无处透气」。
    3. **纯白无锚**：原色块全部洗白或占比 < 8%，读数说明「拿掉原色就退化成普通黑框表格，失去了蒙德里安的视觉配重」。
    4. **全贯通无 T 字主格**：两段局部线全闭合形成死井字，读数提示点击中段黑线拆成 T 字交接、合出主角大格。
    5. **静态镜像对称**：重心虽居中但左右/上下近乎对称（非对称度 ≤ 0.12），明确揪出「这是死板镜像对称，不是蒙德里安追求的非对称动态平衡」。
    6. **重心偏坠**：加权质心偏离画布中心超出稳态圈，具体指出偏向哪一象限（示意配重模型：红 1.00 > 蓝 0.85 > 黄 0.55 > 白 0.08），教用户用远端小块冷/亮色拉回力矩。
    7. **窄缝压扁**：某格宽或高 < 11%，提示粗黑线粘连成团、装不下内容。
- **与最近 12 页的差异**：
  - 与 145（多面板分镜：改 5 格大小 + 换槽位理顺 ①→⑤ 阅读路径）彻底不同：146 不排叙事先后，核心动作是**点格蘸红黄蓝三原色配重 + T 字黑线开关 + 实测二维色彩力矩平衡 + 揪出静态镜像对称与彩色瓷砖过载**；
  - 与 144（拆框/内距呼吸）、227/228（CSS Grid 轨道与 subgrid）、105（双联并置天平）等均无玩法重叠。

## 3. 版式骨架
忠实承袭 146 号原海报的**零圆角 6px 纯黑粗线三列非对称错位格墙（Edge-to-Edge Mondrian Grid Wall）**，不锁 `100svh`、无深色仪表盘卡：
- **1440×900（及 2560×1440）**：顶行极细眉栏（左三原色方块徽 + 类目，右 `NO. 146`）；下方主体由粗黑线切成三列非对称格（1440 版心 1400px，2560 舒展至 1880px）：
  - 左列 26%：上暖米白示范大标格（蒙德里安/版式 + 副标 + 短黑杠 + 总述）、中明黄原色蘸笔调色格、下双分格（题材切换与复原错版）；
  - 中列 48%：上巨幅 2D Canvas 活体蒙德里安工作台（主竖黑带与 T 字开关直嵌画布），下接原海报同款细虚线四关键词实测栏（网格/比例/对位/平衡）；
  - 右列 26%：严格呼应原海报右侧红/白/蓝叠层——顶纯红状态格、中暖米白二维力矩象限仪与白话诊单、底深钴蓝实时结构指标格。
- **1024×1366 / 768×1024（竖平板）**：顶排左暖米白大标 + 右红/黄状态与调色双格，中排满幅活体画布（保持近似 4:3 不压扁），下排四德栏 + 暖白诊单与钴蓝指标并列，自然收紧无空洞。
- **390×844（手机竖屏）**：单行压紧顶标（左大标 + 右红状态章 ≤ 104px），紧接满宽等比活体画布占首屏 ≥ 45% 屏高（约 366×385px），同屏下方立见明黄蘸色条与首行实时诊断。
- **844×390（手机横屏）**：切左 54% 等比活体画布 × 右 46% 紧凑顶标、调色与诊单并行，无横向溢出。

## 5. 节目录（7 大节，标题均 ≤ 12 字，相邻节控件完全不同）
1. **01 · 打破均分，比例才有主次**（浅暖白）— 展开原海报「用几何网格建立比例秩序」与「比例」；交互：**三套网格基因对比切换器**（三等分棋盘 / T 字非对称 / 黄金递进），带实时面积倍数条尺与视线第一落点叠层。
2. **02 · 非对称平衡：大白对小红**（暖米纸）— 展开「对位」与「平衡」；交互：**2D Canvas 几何杠杆配重天平**（源自原海报「平衡」图标），调右臂色相（红/蓝/黄）、面积与力臂距离实时看横梁倾角配平。
3. **03 · 黑线的分量：骨头与空气**（深墨暗版 `#111214`）— 含「说多了一点」温和提醒（黑线可化细/化白缝、三原色可换品牌色，关键是秩序与留白预算）；交互：**4 档线型 × 3 套配色双维实景折页对照台**。
4. **04 · 从画室纸带到广告版式**（洁净暖白）— 「从哪来」完整历史脉络（1917 莱顿《风格》→ 1920《新造型主义》与 1921/1930 经典油画 → 1942 纽约去黑线 → 1965 圣洛朗针织拼缝 → 1967 纳尔逊广告教科书定名）；交互：**6 节点胶带时间轴 + 右侧几何结构微缩演变图**。
5. **05 · 什么时候用，什么时候别用**（暖灰米纸）— 明确 4 类拿手场景与 5 个「别用」红灯，并一句话链接同小类 140/141/143/144/145/147/151；交互：**4 份真实设计需求委托自检卡**（点选切换适配诊断与替代推荐）。
6. **06 · 挑一张稳得住的版面**（暖米纸）— 小练习；交互：**四版同骨架 SVG 方案单选卡**。
7. **07 · 原海报与关键词**（浅暖白）— `<img id="poster" src="poster.webp">` 点开放大灯箱（支持缩放、拖动、`draggable="false"`、Esc 关闭）+ 原海报四关键词几何徽标与页脚一行。

## 7. 练习设计
- **题目**：同一场「荷兰现代设计展」海报，四版共用完全相同的非对称 T 字黑线骨架、标题字号与三原色色值，**仅改变「原色块落位与覆盖面积」这一个变量**。哪一版最符合蒙德里安的平衡与留白原则？
- **选项（仅标中性编号与客观落位描述，绝不剧透好坏）**：
  - **方案 A**：左下红 · 右上蓝 · 右中黄（留白 68%）— **正解**：斜对角原色彼此拉住视觉力矩，大块暖白留给主标题与展讯，兼顾留白呼吸与动态平衡。
  - **方案 B**：左上红 · 左中黄 · 左下蓝（留白 52%）— 错在**单侧堆重**：三原色全挤在左列，整版向左偏坠。
  - **方案 C**：六格满涂红黄蓝 · 仅右下格留白（留白 8%）— 错在**原色过载**：高饱和色块满铺互相打架，缺乏中性白底承托文字。
  - **方案 D**：左中与右中双红 · 左下与右下双蓝（留白 67%）— 错在**静态镜像对称**：虽然留白充足且标题在白格里，但左右镜像对称锁死了动态张力，偏离蒙德里安的非对称对位原则。
