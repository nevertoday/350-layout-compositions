# 154 区块式版式（BLOCK LAYOUT）互动页方案

## 1. 一句话道理
人眼面对成片文字时无法一次消化，必须先通过闭合边界与强对比把画面切分为 3–5 个主次分明的视觉区块（共同区域分组 + 认知组块），读者的视线才有一眼可认的落脚点与扫读路线。

## 2. 开场玩具
- **玩法**：**「活体区块排版压机与眯眼实测台」**（2D Canvas 复刻 154 原海报炭黑「区块式版式示例」展示舱与四款核心骨架）。
  - **画布横向直拖（`data-perf-drag`）**：直接在画布上左右拖动，实时撬开或压紧炭黑区块沟槽与内边距（`0px` 堆叠粘连 → `10–22px` 清晰成块 → `28–40px` 过厚割裂），顶沿微缩色面图与四项单真源读数 60fps 同步重算。
  - **画布直点区块换极性**：直接点击画布上任意一块，在 154 原海报四色面（暖骨纸 / 信号橙焦块 / 电光青导引 / 炭黑锚块）间切换涂装，配流畅墨幕扫过动画。
  - **画布直点红标归组**：点击错位信息签把混装在错误区块里的条目归回所属语义组；支持切换「原海报四例（顶通焦块 / 上图三格 / 左侧青轨 / 橙面点阵）」与「三套真实题材（展讯海报 / 建筑年鉴 / 城市导览）」。
  - **眯眼 3 秒实测开关**：开启实时高斯模糊滤镜模拟离屏 2 米眯眼观感，直观检验脱去字形细节后区块层级是否依然成立。
- **开场初始状态（0/5 堆叠失序错态）**：
  - 沟槽 `0px` 零边界粘连、四块面积接近 `1.05×` 平权均分、2 处信息条目错组混装、全幅同为淡米纸缺乏对比焦块、外框边缘错位散架。
- **怎样算玩错、错了读数怎么说**：由 `model.js` 从实绘矩形像素几何单真源实时诊出 **9 类失误**（无界堆叠、过厚割裂、错组混装、平权均分、全淡无焦、多焦互抢、正文过刺、错位散架、切块过碎），底沿炭黑诊单用白话讲清「为什么人眼看这里会卡住」以及「下一步怎么调」。同时接受多组合法解（四例骨架 × 10–22px 沟槽带 × 多种单焦配色组合均可达成 `5/5 区块成序`）。
- **与最近 12 页的区别**：不用独立顶/底标尺条（区分于 153 视口卡尺、152 胶片轨、235 滚卷轨、280 缩进尺），不拖分割墙调面积（区分于 197 层级网格），不拼 X×X 格阵（区分于 196 模块化网格），不做双轴四象限（区分于 029），不做叠层遮挡（区分于 067）或瀑布流（区分于 236）；核心动作紧扣 154 独有的「化堆叠为有界区块、涂装色块对比、语义归组与眯眼验层」。

## 3. 版式骨架
忠实承袭 154 原海报「0px 锐利直角互锁色块」建筑出版骨架（无圆角深色仪表盘侧栏、不锁 `100svh` 避开平板空洞）：
- **1440×900（宽 1380px；2560 扩宽至 1780px）**：
  - 极细 30px 分类顶眉 →
  - 上带互锁刊头（左 56% 实心信号橙块嵌随状态动态收束的示范大标「区块式版式」与白字 `BLOCK LAYOUT` 及三行总述 × 右 44% 暖骨纸 6×4 黑点阵 + 炭黑实时色面配比微图与四例切签 + 右下电光青出血小方）→
  - 中带互锁工作区（左 33% 暖骨纸原海报五原则活体账本——带五枚原款方黑几何图标与实时检核签，下接紧凑快控键与右舱齐底 × 右 67% 炭黑「区块式版式示例」主工作台画布与单真源四数条）→
  - 底带通栏原海报金句诊单带（左 96px 实心电光青双引号与达成度块 × 右炭黑实时白话诊单、原海报青字金句与 6×4 青点阵）。
- **1024×1366 & 768×1024**：自然流式堆叠无空洞，炭黑主画布全宽居上，紧接青黑诊单带，下方双栏收束五原则账本与快控键。
- **390×844（手机竖屏）**：压紧单行信号橙刊头，让等比炭黑主画布直落首屏并稳占 ≥46% 屏高，同屏即见青黑诊单首句与快控键；三行总述与五原则账本顺落下方。
- **844×390（手机横屏）**：切为左 56% 等比炭黑主画布 × 右 44% 紧致橙标刊头、实时诊单与快控键并行。

## 4. 配色和字体
- **实采自 154 原海报像素色系**：

  - 电光青导引 `#15B5D1`（浅纸可读深青墨字 `#006B7D`；暗底提亮 `#22C9E6`）

## 5. 节目录（每节 h2 ≤ 12 字，相邻两节交互控件不重复）
- **01 共同区域：眼先认框再认字**（`COMMON REGION`）：拆解 Palmer 1992 共同区域与 Miller/Cowan 组块上限；交互为「三态分组错觉切屏 + 块数负荷档位切钮」（SVG 视觉分组对比）。
- **02 原海报四例：四种区块骨架**（`FOUR SPECIMENS`）：逐一解剖原海报炭黑框里的 4 组经典区块图式；交互为「2×2 活体标本矩阵（点击透视阅读路径 + 抽象图式/真实落稿变形 + 一键送入开场压机）」。
- **03 边界四阶：从留白到墨框**（`BOUNDARY SPECTRUM` · 炭黑暗室）：区分留白、细线、色底、实色重框四级边界强度，揭示「框套框」陷阱；交互为「四档步进滑杆 `<input type="range">` + 区外/区内间距比实时压测双联版面」。
- **04 从哪来：百年区块演进**（`LINEAGE · 1917–1992`）：按 1917 风格派 → 1928 新字体排印 → 1956/2001 认知组块 → 1981 瑞士网格 → 1992 共同区域脉络梳理出处；交互为「五纪元时间轴选项卡联动几何图式演进」。
- **05 何时用区块，何时该拆框**（`WHEN TO USE & AVOID`）：温和纠偏海报金句（「说多了一点」），讲清适用与禁用场景，并一句话链接同小类 153/155/156/157/158/159；交互为「四份真实命题分诊卡（点选即显适配诊断与强切后果微图）」。
- **06 挑一版：哪张区块更清楚**（`VISUAL QUIZ`）：两轮单变量四选一盲测（第一轮只差面积主次与沟槽宽度，第二轮只差色块对比分配），标签严格中性（方案 A/B/C/D）。
- **07 原海报对照与色卡检索**（`ORIGINAL POSTER`）：呈现 154 原海报大图（点击打开可缩放、可拖拽、Esc 关闭的灯箱，`draggable="false"`）、实采四色卡与原海报五要点检核。

## 7. 练习设计
两轮单变量盲测，四项均标「方案 A / 方案 B / 方案 C / 方案 D」，绝不泄露好坏：
- **第 1 题（唯一变量：区块面积主次与边界沟槽）**：同文案、同配色、同对齐；A 四块均分平权、B 主块 46% + 14px 清晰沟槽（正解）、C 主块 46% + 2px 过窄粘连、D 主块 46% + 34px 粗黑厚壁挤字。
- **第 2 题（唯一变量：区块色面对比策略）**：同骨架、同 14px 沟槽；A 全暖纸缺焦块、B 主标与正文双橙互抢且正文刺眼、C 橙主标 + 青导引 + 暖纸正文（正解）、D 四面满铺实色无呼吸浅纸。
