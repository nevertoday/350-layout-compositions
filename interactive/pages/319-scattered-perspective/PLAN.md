# 319 · 散点透视（SCATTERED PERSPECTIVE）设计方案

## 1. 一句话道理
散点透视撤销了单一固定灭点的垄断，让多个独立视点在同一张画布上各自展开完整空间，再依靠重心分布、疏密节奏、主次分级与关系连脉把分散的视觉中心织成一张通透而完整的整体秩序。

## 2. 开场玩具
- **命名**：五视点黑漆星图编排台（1:1 承袭 319 原海报黑曜漆底 + 中央象牙/宝蓝波纹中枢块 + 视点 A–E 五枚同心虚线圆环 + 虚线呼应路径 + 青碧/象牙点阵与 `+` 定位星标）。
- **怎么玩**：
  - 在主画布（标 `data-perf-drag`）上**直接拖拽任意视点圆环（A–E）**排布位置（支持鼠标、触屏水平/节点拖动与选中后方向键微调）；
  - **点击视点圆环**选中后，可切换该视点的**权重分级（主锚 / 次点 / 微应）**与**独立观看姿态（平视 / 俯瞰 / 仰观）**；
  - 切换**视角语法（单灭点锁死 ↔ 多视点独立）**，亲眼对比强行把多点扯向单一消失点所造成的边缘压扁畸变；
  - 切换**关系连脉（断开孤岛 / 曲径串联 / 主辅呼应 / 全连蛛网）**，以及 3 套共享同一 `model.js` 坐标真源的画卷母题（原海报星图 / 汴河长卷 / 夜宴五屏）。
- **一打开的状态（0/4 待统筹错态，绝不先给答案）**：
  1. 仍锁死在「单灭点透视」下，五视点被迫朝单一灭点拉扯畸变；
  2. 五个视点团挤在画面中偏左（视点 C 卡在正中 `0.50, 0.50`，方便直接上手拖散），覆盖跨度极窄且重心塌偏；
  3. 五个视点权重均分（20/20/20/20/20 平权抢戏），缺乏主锚；
  4. 关系连脉处于「断开孤岛」状态，元素零散孤立。
- **怎样算玩错（8 类实算错态，全部由 `model.js` 从实绘几何与参数单真源核算）**：
  - `locked_single`（单点锁死畸变）、`clumped`（团挤塌心，最小间距过近或跨度过窄）、`grid_rigid`（排成机械等距方阵或直线，疏密变异系数过低、失去节奏）、`lopsided`（加权重心偏移过大、半边空洞）、`edge_clip`（视点贴边被画框裁断）、`flat_weights`（五点等大平权抢戏）、`monopoly`（单点权重超半数退回单中心）、`disconnected` / `web_chaos`（关系连线全断成孤岛，或全连成交叉蛛网破坏留白）。
- **读数说什么「为什么」**：不仅报实测最小间距、疏密系数 CV、重心偏移与主次比，更用白话直指视线会怎样撞车、迷路、滑出画框或失去呼吸感，并给出下一步可验证的操作线索；接受多组正当解（原海报五点解、长卷 S 脉解、对角呼应解或用户任意自排达标解）。
- **与最近 12 页的明显差异**：
  - 对比 318（暖宣紫靛双游标权重尺 + 3D 金字塔）、317（青灰素宣横向展卷轴）、112（满幅电光蓝渐进阶梯）、235（奶油手账粘性滚卷）、196（暖乳模块化网格拖块）、028（熏衣草灰圆窗移轴）、234（深海蓝固定导航浏览器框），319 是近 12 页唯一的**纯黑曜漆底 × 电光宝蓝 × 松石青碧 × 暖象牙星图**，互动本质是「在无单一灭点束缚的平面上自由布置多视点星座、划分主次并编织关系路径」。

## 3. 版式骨架
忠实承袭 319 原海报「左 34% 冷静竖向导览栏 × 右 66% 巨幅黑漆五视点星图舞台」的双栏开放海报骨架（0px 锐角几何线框、不锁 `100svh` 避开平板空洞）：
- **1440×900（2560 舒展至 1840px）**：34px 极细顶眉下，主栏宽 1380px；左列自上而下排活体错落示范大标「散点透视」、宽距英文副标、双色分隔杠、总述、原海报三枚可实时反映诊断状态的几何圆环图标（靶环/点阵环/波浪环）、白话诊单匣与 `KEYWORDS` + `+ + ● +` 底脚；右列等高铺开题材/透视切换条、巨幅 2D Canvas 星图舞台与紧贴底沿的两行紧凑控槽。两栏自然等高、首屏完整呈现无空洞。
- **1024×1366 / 768×1024 平板**：双列紧凑刊头（左标题总述 × 右三枚圆环状态胶囊）→ 全宽 16:11 星图舞台与底槽 → 全宽白话诊单条，紧凑流式无大片空白。
- **390×844 手机竖屏**：极紧凑单行标题头（≤ 105px）→ 等比真圆不压扁的大幅星图画布（占首屏 ≥ 46% 屏高）→ 快捷核心控钮与白话诊单首句，首屏一开就能直拖中心视点 C。
- **844×390 手机横屏**：切为左 56% 巨幅星图与精简操作条 × 右 44% 紧凑标题、三环实况与白话诊单并行。

## 7. 练习
- **题目**：下面四张构图方案使用完全相同的五个城市节点（中枢广场与四处分景）、完全相同的配色和画幅，只改变了节点的位置分布、主次比例与连接方式。哪一张真正做到了「多点清晰、疏密有致、整体成脉」的散点透视？
- **四个选项（中性编号，零剧透）**：
  - 方案 A：五点权重均分、严格等距排列成规则十字方阵（错：退化为机械网格，无主次与疏密节奏）。
  - 方案 B：五点强行收束向右上同一灭点，远端节点透视急剧缩小重叠（错：被单点焦点透视绑架，远景信息丢失）。
  - 方案 C（正确）：中枢偏右下立为主锚，其余四点疏密错落、三级权重递减、不贴边且总重心稳在画心附近，由克制流畅的虚线曲径串联。
  - 方案 D：虽有大小区分且各具独立朝向，但节点聚压左半边、无连脉牵引，右侧留出大片失衡空洞（错：重心塌角且散而不联）。
