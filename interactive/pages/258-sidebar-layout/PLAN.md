# 258 侧边栏页面（SIDEBAR LAYOUT）互动页设计方案

## 1. 一句话道理
把高频跳转的导航或辅助信息稳定安放在主视口一侧，把连续、完整、低干扰的中央空间还给核心内容，从而在「一眼定位」与「专注阅读」之间建立持久的结构秩序。

## 2. 开场玩具：活体侧边栏工作台（Interactive Sidebar OS Bench）
- **玩法**：直嵌于 258 原海报标志性「暖米微圆角示例卡」内的 2D Canvas 活体迷你网页（标 `data-perf-drag`），1:1 承袭原海报朱红侧边栏 + 暖米主内容 + 双峰日轮插画 + 三张暖沙模块卡，支持「课程学习 / 平台后台 / 数据报告」三场景。
  - 横拖分隔轨（或在画布开放区左右拖动）实时连续推拉侧边栏宽比（6%–48%），主内容区卡片列数、中文行宽与导航文字截断实时重算。
  - 直接点击侧边栏内 4 枚导航条目，真正切换右侧主内容区显示的模块（导航概览 / 重点内容 / 知识模块 / 参考支持）。
  - 点击侧栏顶角折叠钮在「完整侧栏 ↔ 图标轨 Rail ↔ 移动抽屉 Drawer」间变形；在主内容区上下滚读（或拖动滚动滑块）实测 `static` 随滚丢导航与 `sticky` 锚定伴随；点击侧栏底部刺眼杂物红叉清场；支持切换桌面 1200px / 平板 820px / 手机 390px 模拟视口与左/右侧置位。
- **开场初始态（0/4 四重坏态，绝非答案）**：
  1. 侧栏过肥（占 42% / 504px），喧宾夺主挤扁右侧主内容；
  2. 当前章节未开启高亮指示，点完不知身在何处；
  3. 滚读停在文档 52% 中段且未开启 `sticky` 锚定，顶部导航项已经滚飞失联；
  4. 侧栏塞入冗余促销横幅杂物，与主内容抢夺焦点。
- **怎样算玩错 & 读数怎么说为什么**：由 `model.js` 从实绘矩形坐标与字符测量单真源实时核算 7 类双向错态（过肥侵占主区、完整模式过窄截断文字成 `…`、手机窄屏硬撑固定侧栏压死正文、未高亮迷航、滚读丢导航、侧栏杂物抢焦、宽主导航右置违背左缘扫读惯性）；每次诊断都先点破画面几何实测数据，再白话说明「这样摆会让读者怎么看、为什么会迷路或阅读吃力」。接受「经典左导解 / 高效图标轨解 / 右置辅助大纲解 / 移动抽屉解」多组合法解。
- **与最近 12 页的差异**：256 调双列配重与中缝、257 调三列双缝、336 改幻灯片图文母版、134 排多栏栅格跨度；本页聚焦侧边栏独有的「导航可点切换 + 宽窄临界截断 + 滚动锚定不丢失 + 宽窄屏形态退让（侧栏/图标轨/抽屉）」，换给别的编号完全套用不了。

## 3. 版式骨架
- **1440×900（2560 舒展至 1680px）**：忠实转译 258 原海报自身的「左 24% 极深焙黑通高侧边栏（红圆黑星芒徽标 + 四项实况导航锚点 + 朱红点阵 + 四枚朱红圆环布局要点实时探针） × 右 76% 奶霜暖白主工作面（左上自示范巨标『侧｜边栏 页面』与总述 + 右上 1:1 包豪斯四分之一圆几何拼贴 + 核心活体工作台 + 细朱红线下双列齐底单真源诊单与精控台） × 底沿暖麦沙贯穿宣言卡（反色黑圆红星芒）」架构。不锁 `100svh`，左右两翼齐底无空洞。
- **1024×1366 / 768×1024 平板**：1024 保持窄深焙黑左侧轨 + 主舞台自然流排；768 将深焙黑侧栏自动变形为顶部深焙黑横贯导览带，四要点 2×2 齐底，零空白黑洞。
- **390×844 手机竖屏**：极简一行深焙黑刊头（红圆黑星 + NO.258 + 侧边栏页面 + 实时状态徽）→ 场景切签 → 等比活体工作台画布稳占首屏 ≥ 46% 屏高 → 折线内直露白话诊单首句与一键纠偏；总述与四要点后置到玩具下方。
- **844×390 手机横屏**：左 55% 场景切签 + 等比工作台画布 × 右 45% 紧凑深焙黑刊头与诊单精控并行，零横向溢出。

## 4. 配色和字体
- **配色（逐像素采自 258 原海报）**：深焙咖黑 `#211006`（暗室 `#180B04` / 暗舱 `#2B160A`）、招牌珊瑚朱红 `#F66041`（浅纸安全深朱字 `#B83318` / 暗底亮珊瑚 `#FF8A70`）、奶霜暖白 `#FAF2E7`（亮象牙 `#FDF9F3` / 暖米卡底 `#F8EBD8` / 浅杏雾 `#F5ECE1`）、暖麦沙 `#E2C3A2` / `#E8D2B5`；克制以松青绿标通过、赤红标错态。
- **字体搭配**：`Noto Sans SC`（400/700/900）+ `Syne`（600/700/800，近 12 页 0 次使用）+ `Chivo`（400/600/700，近 12 页 0 次使用）+ `JetBrains Mono`（400/600）。全库唯一组合，与 256/257 西文及等宽 0 重合。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻控件完全不同）
- `01 为什么分置一侧`：展开原海报 4 项布局要点与 4 项效果价值；交互：**2D 眼动扫读路径对比模拟器**（点选目标章节，对比顶部多行堆叠 vs 左侧垂直列表的视线跳次）。
- `02 黄金宽比与锚定`：拆解宽比跷跷板与滚动不丢导航；交互：**可手动滚读的 CSS Grid 蓝图对照台**（切换 static 同滚 / sticky 锚定 / 缺独立滚动截断，联动真实 CSS 代码高亮）。
- `03 从哪来：五十年侧轨史`：深焙暗室回溯侧边栏演进；交互：**包豪斯四节点历史轨迹切换器**（1980–1983 Smalltalk-80 → 1995 Netscape `<frameset>` → 2003 Mac OS X Panther Finder → HTML5 语义地标与现代轨，联动年代线框图）。
- `04 多端变形与兄弟页`：响应式三态退让 + 同小类 13 个兄弟页一句话链接；交互：**360px–1440px 连续视口拉伸变形滑轨**（实时看同一页面在抽屉/图标轨/完整侧栏间自动切换）。
- `05 什么时候用与别用`：原海报 4 场景 + 4 类禁用反例 + 温和批注原海报「说多了一点」之处；交互：**4 项业务特征开关诊断器**（点选开关输出选型建议与对应兄弟页直达）。
- `06 小练习：挑出好侧栏`：深焙暗室双题可视化评测；交互：**两道单变量 4 选 1 缩微界面对比题**（中性 A/B/C/D 标签，选完展开 SVG 错因拆解）。
- `07 原海报与关键词`：原海报点击放大/拖拽/Esc 关灯箱 + 海报全部原词（含温和标注原海报「导航导航」重字）+ 核对清单 + 规范页脚。

## 7. 练习设计
- **第 1 题（桌面端侧栏比例与焦点权衡）**：1280px 课程学习页，4 张同题材缩微 SVG（中性标签方案 A/B/C/D），只变「侧栏宽比与层级高亮」：A 过宽 38% 塞满卡片抢主区；B 22% 稳比例+当前朱红锚条高亮+主区舒展（正确）；C 强压到 11% 硬塞文字截断；D 22% 比例对但无高亮无分组致定位丢失。
- **第 2 题（手机 390px 窄屏响应）**：同课程页落到 390px 竖屏，4 张缩微手机框（中性标签方案 A/B/C/D），只变「侧栏折叠方式」：A 硬留左栏压死正文；B 展开全目录占满首屏推飞标题；C 折叠为清晰顶部入口按需拉出抽屉（正确）；D 直接删除全部目录只留上一页/下一页导致无法跳章。
