# 093 单一焦点构图（SINGLE-FOCUS COMPOSITION）设计方案

## 1. 一句话道理
人眼的前注意视觉系统会优先被唯一跳脱于环境的特征捕获；把面积、色彩、明暗与视线方向这四份视觉预算集中到同一个主角身上，同时主动压低所有次要元素，观者就能在半秒内毫不犹豫地读懂核心信息。

## 2. 开场玩具：焦点独裁·光学暗房台（Single-Focus Saliency Darkroom）
- **交互动作**（100% 源自单一焦点构图自身的「压噪弱化 + 色彩/对比独裁 + 消除竞争焦 + 视线收束」，不拖主体坐标、不用十字靶心、无 Home 归中）：
  - **画布横向拖动（`data-perf-drag`）**：像推拉暗房压噪滤镜玻璃，连续调节「次要背景压噪度（0%–100%）」，实时看到高噪山海、群鸥、杂色天空褪成静谧暖米雾与低对比炭墨——推太低（<38%）背景喧宾夺主，推太满（>92%）过度压黑吞没灯塔顶棚轮廓。
  - **画布直接点击**：点击左侧赤红信号船/浮标或右上亮橙风暴日等「抢戏竞争焦」，在「抢戏 → 弱化配角 → 移除」间切换；点击主角「灯塔」切换/增强钴蓝饱和与明暗凸显；点击下方海岸浪弧翻转「视线引导方向（逆向外拉 ↔ 顺势指向灯塔）」。
  - **空格 / 按钮「0.5s 视线验真」**：按真实绘制演员的面积、饱和度、相对亮度比与引导线指向，由 `model.js` 单真源计算显著图（Saliency Field）与前 3 跳「胜者通吃（WTA）」注视路径 `#1 → #2 → #3`。
  - **三套真实语境**：`原海报 · 钴蓝灯塔` / `产品发布 · 单品舞台` / `编辑海报 · 孤舟独焦`。
- **开场初始态（0/4 焦点分裂，绝不预给答案）**：
  - 2 处高饱和竞争焦同时抢戏（主次焦比 S1/S2 仅约 1.06×，滑向 094 多重焦点构图）；
  - 主体灯塔发灰失色（钴蓝强调仅 18%）；
  - 背景次要压噪仅 16%（高对比云浪、彩岩、密鸥吵闹抢眼）；
  - 海岸引导浪弧逆向朝左下角外拉。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - `model.js` 从实际绘制演员的几何包围盒、占幅比、WCAG 相对亮度对比与色度差单真源双向检出 8 类错态（既检不足也检过头）：`双焦抢戏`、`主体发灰`、`背景喧宾`、`过度压黑吞没轮廓`、`主体巨物窒息（>44%）`、`主体过小失权（<10%）`、`引导线外拉`、`显著优势不足`。
  - 每次报错都用白话讲清观者第一眼为什么被带偏，并给出下一步可做的动作；同时认可「原海报灯塔解」「极简独焦解」「宏伟特写解」及任意达标组合。
- **与最近 12 页的区别**：
  - 091 破框延展、090 斜轴倾角、054 离心抛射、057 棋盘落子错缝、056 十字四象限、055 同心环校轴、308 净单人清场月轮、222 普通流栏宽、141 排印字阶、089 石碑水平仪、177 右终线配重、053 向心楔形——本页独创「光学暗房压噪 + 主次视觉资源独裁 + 0.5s 显著图注视路径验真」，别的编号无法套用。

## 3. 版式骨架
- **忠实转译 093 原海报「极黑剧场画框 × 暖米大弧开窗 × 钴蓝灯塔 × 底沿极黑引号诊单与三枚活体微缩方框图解」**：
  - **1440×900（2560 舒展至 1700px）**：顶部 44px 极黑剧场条（同心蓝徽 + 三语境切换 + 视线验真键 + 右上 3×4 钴蓝点阵）→ 暖米大弧开窗内左 31% 无框海报刊头（`单` 反白聚焦自示范大标 + 4 枚原海报纯黑底钴蓝圆徽与虚线引注）× 右 69% 开放式暗房画布 → 画布海岸岩缘无缝衔接底沿极黑剧场控制台（左 36% 蓝引号单真源诊单 | 中 34% 暗房滑轨与多解试错 | 右 30% 原海报三枚实绘联动方框图解 + 极淡钴蓝同心环）。绝不锁 `100svh`。
  - **1024×1366 / 768×1024 平板**：自然流排布，无大片死白：紧凑刊头 → 通宽 16:10 画布 → 2×2 四圆徽 → 极黑剧场台（诊单 + 滑轨 + 三方格）→ 顺接 01 节。
  - **390×844 手机竖屏**：极紧凑单行极黑刊头（~46px）+ 单行语境条（~36px）→ 近正方形高清画布（`1 / 1.02`，占首屏 ≥ 46%）→ 折线内直露极黑诊单首句、次要背景压噪主滑轨与校准/验真双键；总述文字、四圆徽、其余滑轨与三方格顺排在折线下方。
  - **844×390 手机横屏**：左 54% 等比画布 × 右 46% 紧致刊头、诊单首句、主滑轨与双键并行。

## 5. 节目录（共 7 节，每节标题 ≤ 12 字，相邻两节交互不重复）
- `01` **一眼锁定的视觉经济学** — 讲前注意凸显效应与胜者通吃显著图；交互：**真实计时视觉搜索实验**（选单特征独焦 / 双焦分流 / 混杂干扰与干扰数 12/28/48，点击找目标并记录实测毫秒）。
- `02` **四个杠杆造出唯一主角** — 展开海报四要点与三图解；交互：**100 点视觉资源配额盘**（`+ / -` 步进分配预算，实时看均摊与 80/20 押注的层级差）。
- `03` **次要弱化的三把手术刀**（暗室节）— 拆解低饱和、小比例、低对比如何托出主角；交互：**独立三刀滤镜开关 + 可拖动前后对比幕帘**。
- `04` **从暗室明暗到物件海报** — 「从哪来」历史脉络（卡拉瓦乔、维米尔、伯恩哈德、鲁宾、阿恩海姆、特里斯曼与伊蒂）；交互：**年代案例切换 + 图底/热峰透视叠加**。
- `05` **什么时候用，什么时候别用** — 温和修正「少即是多」的适用边界，明确何时切向 094/088/087 等同小类页面；交互：**4 个真实设计需求分诊卡片**（点击评估是否该用单一焦点并看线框后果）。
- `06` **四张海报，挑出真独焦**（暗室考场节）— 单变量四选一小练习（中性标签 A/B/C/D，仅差层级处理，附实绘缩略图与选后解析）。
- `07` **原海报与三个关键词** — 高清原海报（点击放大、拖动、`Esc` 关闭）+ 原话总述与三关键词 + 页脚。

## 7. 小练习设计
- 题目：海滨建筑展 3 秒街头海报，四版（A/B/C/D）主角位置、构图框架与文案完全一致，仅差主次视觉资源分配。
- A：左下展期圆章放大并涂高饱和朱红（双焦内讧）；
- B（正确）：钴蓝灯塔独占高饱和与明暗核心，次要元素低饱和缩比例，浪线收束指向灯塔；
- C：全画面统一低饱和中灰，主体仅略大（失去前注意凸显）；
- D：灯塔膨胀占满 78% 挤顶四边，文字压在塔身（失去呼吸留白与清晰轮廓）。
