# 127 · F 型扫描模式（F-PATTERN SCANNING）方案

## 1. 一句话道理
人眼中央凹清晰视野只有约 2°，在信息密集的网页里无法逐字通读，会本能地按「首行长横扫 → 次行短横扫 → 沿左侧纵向下滑」的省力轨迹寻觅关键词；好排版不是逼人画一个 F，而是把结论与高信息气味的词放进前两横与左锚点，再用小标题与列表把盲目略读升级为高命中扫读。

## 2. 开场玩具
- **命名**：6 秒眼动扫读与活体文案改稿台（2D Canvas 1:1 承袭 127 原海报细框网页线框 + 朱红 ①②③ 通道红带 + 白箭白眼 + ④ 浅红行动框，标 `data-perf-drag`）。
- **怎么玩**：
  - **横拖画布（`data-perf-drag`）**：直接推进/倒放 `0.0s–6.0s` 模拟眼动扫读时间轴，实时观察 2° 中央凹视圈与注视热力沿 ① 长横 → ② 短横 → ③ 左侧纵扫 → ④ 寻落点滑过真实中文网页，实时累加 4 条目标信息的命中与漏读。
  - **直接点击网页 4 块内容区，或点击右侧 1:1 复刻原海报的 4 条红点虚线边注（首屏钩子 / 次级横扫 / 左侧锚点 / 行动位置）**：原地改写每一块的文案结构与落位（首行空话/结论前置/结论埋尾；次行长句埋右/前 5 字亮核/留空；正文文字墙/分段左符号前置/居中失锚/满屏全加粗；按钮右下盲区/左下朱红主钮/首行塞满 3 红钮）。
  - **切换**：3 个真实网页题材（效率工具落地页·原海报结构 / 退换货政策长文 / 职位说明列表）、3 种观察模式（原海报 F 红带 / 眼动热力雾 / 纯净盲测）、以及书写方向（LTR 左锚 F / RTL 阿拉伯语镜像反 F）。
- **开场初始状态（绝非答案）**：刻意停在「0/4 高漏读文字墙错态」——首行空泛套话、次行关键词埋在右侧行尾、正文糊成无小标无项目符的文字墙、行动按钮藏在右下冷灰文字链，6 秒扫读命中核心信息仅 0/4。
- **怎样算玩错、读数怎么说**：由 `model.js` 从当帧实绘关键词像素矩形与 F 热力场积分单真源核算，支持 7 类双向真错态：
  1. **首行空话 / 结论埋尾**：第一横扫在左侧最强、右侧衰减，空话或行尾结论让读者首秒失去继续扫读的理由；
  2. **次行关键词埋右**：第二横扫通常比第一横更短（约 55%–65% 宽度即折返），埋在右半段的要点会被跳过；
  3. **整块文字墙**：无小标题与项目符号时，左竖扫读缺乏停靠点，正文关键参数掉进中下盲区；
  4. **居中对齐失锚**：每行起点参差不齐，打破左侧垂直锚线，视线来回折返消耗大增；
  5. **满屏全加粗过载**：所有文字同等强调等于没有重点，视觉噪声让信息气味失效；
  6. **行动按钮落右下盲区**：F 扫读末段集中在左下，右下淡色文字链极易被彻底忽略；
  7. **首行过早塞满多按钮（过早劫持）**：用户还没读完核心价值就被多个红钮打断，主次冲突。
  读数同步解释「为什么眼睛跳过它」并驱动原海报底部 2×3 最佳实践清单 6 个格子实时亮灯；接受多组合法解（原海报经典 F 顺应解、高命中精简解、RTL 镜像解）。
- **与最近 12 页及同小类的明显差异**：
  - 不同于 126（几何色块分群）、125/329（点阵密度）、164（目录拉尺）、208/209/250/292/293（调视口/列宽）、128（深海夜蓝 Z 节点）、129（2×2 报版对调）：127 是本库唯一把**真实网页文案改稿**与**实时 6 秒眼动时间轴热力采样**融合在原海报 ①②③④ 红点虚线解剖图里的互动工具，别的编号无法套用。

## 3. 版式骨架
- **1440×900**（主宽 `1360px`；`2560×1440` 舒展至 `1680px`）：完全忠实 127 原海报「燕麦暖白纸无框开放排布（零深色顶眉、不锁 `100svh`）」——顶沿左 66% 自示范朱红 F 大标 + 英文 + 朱红短杠 × 右 34% 原海报原话与三场景切签 → 中段左 66% 细框网页眼动画布（集成顶部时间进度条）× 右 34% 四条红点虚线直连原海报四段边注及原地改稿药丸 → 下沿左 36% 扫描路径图例与单真源诊单盒 × 右 64% 原海报 2×3 最佳实践清单实时体检格。
- **1024×1366 / 768×1024 平板**：自然流排，不锁视口高，绝无中间空白带。
- **390×844 手机竖屏**：压缩刊头为极紧凑两行（标题 + 场景切签，总述后置），让等比活体网页眼动画布稳占首屏 ≥ 48% 屏高，并在首屏折线内同时直见诊单首句与关键改稿/时间轴入口；四条边注与 2×3 体检格自然顺排，点击热区 ≥ 42px。
- **844×390 横屏手机**：切为左 56% 活体眼动画布 × 右 44% 紧凑刊头、场景切与白话诊单并行。

## 7. 练习
- **场景**：机场快线退票规则页，赶时间旅客需在 4 秒内读出「起飞前 2 小时内退票扣 20% 手续费」并找到「提交退票」入口。
- **四选项只差「文案落位与对齐策略」一个变量**（中性标签 `方案 A / B / C / D`，绝不写好坏提示）：
  - **方案 A**：左对齐短句，但每条以冗长套话开头，核心数字压在行尾右侧，按钮在右下角。
  - **方案 B**：首行结论直给 + 三条要点均关键词前置 + 左对齐锚点线 + 主按钮稳落左下锚点起点（**正确**）。
  - **方案 C**：关键词前置，但整页居中对齐且全篇加粗放大，破坏左侧垂线与层级对比。
  - **方案 D**：左对齐且有项目符号，但把核心费率埋进第 2 段 6 行连续长段中右下，首行放装饰欢迎语。
- **理由**：方案 B 同时守住首行钩子、前 4 字信息气味、左侧垂直锚线与左下行动落点，4 秒 F 扫读即可全中；其余三项各自触发行尾盲区、居中失锚+全粗过载、文字墙埋词。
