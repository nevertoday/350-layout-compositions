# 209 响应式网格 RESPONSIVE GRID · 设计方案

## 1. 一句话道理
同一份内容在不同屏幕宽度下，不能靠死锁像素溢出、也不能靠把桌面硬缩成蚂蚁字，而是用相对弹性单位配合内容驱动的断点，让列数与模块结构在恰当宽度完成拓扑重排，在每一种视口里都守住舒适行宽与主次层级。

## 2. 开场玩具
- **命名**：三屏同源 · 断点跃迁总控台（2D Canvas 活体三联设备矩阵，承袭 209 原海报桌面/平板/手机三屏并列 `→` 演进结构，画布带 `data-perf-drag`）。
- **怎么玩**：
  - 在舞台顶沿的 `320px–1440px` 连续断点标尺或画布本体上左右横拖（`data-perf-drag`），实时推动测验视口游标跨越两个断点（`BP1` 移动→平板、`BP2` 平板→桌面），亲眼观察同一套页面内容从 4 列左文右图 → 2×2 上图下文 → 1 列箭头列表的瞬时拓扑重排；
  - 直接拖动标尺上的 `BP1` / `BP2` 两把实体断点切刀改写断点阈值，联动桌面（1280px）、平板（820px）、手机（375px）三台实时同屏设备同步验伤；
  - 切换适配策略（固定 px 锁死 / 整页等比微缩 / 响应式 `fr` + 断点）、三端列数矩阵、小屏 Hero 排法（左右硬拼 vs 垂直堆叠）、层级顺序（主角居首 vs 四卡压顶），并在 `原海报样例` / `线上书店` / `产品发布` 三题材间切换；
  - 点击画布上任意故障红标可就地单步纠偏，支持键盘 `← / →` 微调当前视口宽。
- **开场状态（非答案）**：
  - 刻意停在「固定 1280px 无重排 + 过低断点 420/580px + 小屏硬挤 4 列 + 左右硬拼 Hero」的复合错态：手机端向右溢出 `+905px`、平板端溢出 `+460px` 且正文坍缩，三端体检单直接点名错因。
- **怎样算玩错、错了读数怎么说（单真源双向验错）**：
  - 由 `model.js` 按当前策略真实算出桌面 1280 / 平板 820 / 手机 375 以及当前测验视口的真实容器宽、单卡净宽、Hero 文区宽度、等效字号、估算行长（注明经验值）与横向溢出像素，识别 6 类双向真错：
    1. **固定 px 横向溢出**：报出精确溢出像素（如 `+905px`），直指违背 WCAG 2.1 1.4.10 无双向滚动要求；
    2. **整页等比微缩**：虽无横向滚动条，但 375px 等效正文字号跌至 `4.7px`，报出「缩成蚂蚁字，被迫双指缩放」；
    3. **窄屏硬挤多列（断点过低）**：手机或平板单卡净宽 `< 135px`，报出「单卡被压成窄条，图标与标题碰撞」；
    4. **宽屏僵化单列（断点过高）**：桌面 1280px 仍锁 1 列，估算单行飙升至 `70+ 汉字`，报出「宽屏未展开，长行扫读易串行」；
    5. **小屏 Hero 左右硬拼**：手机端正文区 `< 160px`，报出「正文被主图挤成竖条，每行仅剩四五个字」；
    6. **小屏层级倒挂**：四张特性卡压在主标题与行动钮上方，报出「视觉主角落出首屏，层级失守」。
  - 接受多组合法解（原海报经典 `4→2→1` 解、平板三列 `4→3→1` 解、宽裕阅读 `3→2→1` 解）。
- **与近期 12 页的明显差异**：
  - 不同于 208 深靛紫连续流体比例水槽（208 讲单套比例条连续拉伸，209 讲三台实体设备跨断点拓扑变身：4列→2×2→1列列表）；
  - 不同于 249 包豪斯暖米单封面容器高度调弹簧（209 是纯明黄全幅 + 三联白屏设备矩阵 + 底部纯黑圆角提示胶囊）；
  - 不同于 291/292 的单视口流道或竖柱重力下落，209 让桌面/平板/手机三端同台联检，改动一条断点立刻看到三端连锁后果。

## 3. 版式骨架
- **总体**：1:1 转译 209 原海报「信号琥珀黄全幅底面 + 零独立暗色导航栏 + 无左舞台右仪表盘侧栏 + 不锁 `100svh`」节奏：
  - 顶沿无框刊头（左自示范大标「响应式网格」配随断点动态变列的活体网格条 × 右原海报淡白点阵 + 6×6 活体亮黄网格徽 + 三题材切签）；
  - 中央 100% 全宽三联设备断点跃迁舞台（顶附连续断点轨道尺，直接浮在明黄底面上）；
  - 下接双联瓷白 2px 黑框工程台（左单真源三端体检诊单 × 右断点策略控台与活体 CSS 预览）；
  - 紧接原海报「核心原理 CORE PRINCIPLES」四列虚线实况横带；
  - 首屏底沿以原海报纯黑圆角胶囊条（灯泡图标 + 设计提示 + 三台亮灯设备线框）收口。
- **1440×900 / 2560×1440**：1440 主内容宽 `1380px`，2560 舒展至 `1720px`，三联设备等比宽舒不缩中。
- **1024×1366 / 768×1024**：自然流式纵向推进，不锁 `100svh` 避开大空洞；768 下双联工程台折为单列。
- **390×844 竖屏**：压紧单行刊头、总述后置，画布自动切入「当前高亮设备大画幅 + 底部三端联动缩略带」布局（杜绝三台设备挤成三条细缝），使交互舞台稳占首屏 ≥ 48% 高度并同屏直见诊单首句。
- **844×390 横屏**：切换左 56% 交互舞台 × 右 44% 紧凑刊头、体检首句与快捷修复并行，无横向溢出。

## 4. 配色和字体
- **实采自 `209.webp`**：
  - 信号琥珀黄主底 `#FCC300` / 亮格黄 `#FFD615` / 浅白纸高对比深琥珀强调字 `#855800`
  - 工业纯黑主墨与暗室 `#0B0B09` / 暗室底 `#11110E` / 暗舱 `#1B1B16` / 暗底明字 `#F5F2E8`
  - 瓷白设备屏面 `#FFFFFF` / 卡片微灰 `#F7F5F4` / 浅工程灰纸 `#F4F3EE` / 淡暖黄纸 `#FFF7DC`
  - 功能态：告警朱红（浅 `#C0261D` / 暗 `#FF7366`）、通过深翠（浅 `#0F6B43` / 暗 `#58E09B`）
- **字体搭配**：`Noto Sans SC` + `Bricolage Grotesque` + `Outfit` + `DM Mono`
  - 全库唯一组合；其中 `Bricolage Grotesque`、`Outfit`、`DM Mono` 三款西文/等宽字体在最近 12 页全部 **0 次使用**，与相邻的 207、208 零西文重合。

## 5. 节目录（8 节，标题均 ≤ 12 字）
1. **01 断点该由内容决定** (`CONTENT-DRIVEN BREAKPOINTS`)：拆解海报「1280/1024/768/480」经验断点并温和补充内容驱动法则；交互：宽度滑轨测破点 + 自定义插旗断点对比死背机型断点。
2. **02 重排不是把块乱打散** (`LOGICAL REFLOW`)：12→8→4 列阶梯整除逻辑与 CSS `order` 键盘焦点陷阱；交互：三端列网透视切换 + SVG 实时 Tab 顺序轨迹图。
3. **03 从百分比到容器查询** (`FROM % TO @CONTAINER` · 暗室)：三代 CSS 响应式网格机制（`@media` → `auto-fit/minmax` → `@container`）；交互：把同一张卡片搬入「宽主栏」或「窄侧栏」对比视口查询与容器查询。
4. **04 小屏不该丢掉主角** (`MOBILE-FIRST HIERARCHY`)：移动优先的内容排序如何锁定跨屏焦点；交互：四模块上下重排优先序，同步预览三端首屏折线落位。
5. **05 响应式网格从哪来** (`WHERE IT CAME FROM`)：2000–2023 六个可核实历史节点，串联 195/196/205/206/207/208/210；交互：年代节点切换卡配演进微缩架构图。
6. **06 什么时候别硬套响应式** (`WHEN NOT TO USE`)：识别二维关系不可拆散、固定幅面印刷等边界；交互：四类真实产品形态分诊翻牌判定。
7. **07 挑出真正成立的方案** (`SPOT THE SOUND GRID` · 暗室)：中性四选一练习，只差断点重排策略一个变量；交互：四套 SVG 三联缩略方案择优并即时详解。
8. **08 原海报与关键词** (`ORIGINAL POSTER` · 信号黄展墙)：完整原海报高清灯箱（可缩放、拖动、Esc 关闭）+ 四枚原海报关键词解码 + 规范页脚。

## 7. 练习设计
- **题目**：同一份含「头图导语 + 4 项特性卡」的产品介绍页，要同时服务 1280px 桌面、768px 平板与 375px 手机，下面哪一套网格重排方案最合理？
- **四个中性选项（只差断点与列数重排规则一个变量）**：
  - **方案 A**：固定 1200px 四列容器，三端结构一致（桌面正常，平板与手机溢出需横向滑动）。
  - **方案 B**：1280px 左文右图 + 4 列 / 768px 上图下文 + 2×2 / 375px 垂直堆叠 + 1 列列表（**正确**）。
  - **方案 C**：1280px 与 768px 均保留 4 列，375px 保留 2×2 与左文右图（窄屏断点滞后，卡片与文区严重挤压）。
  - **方案 D**：1280px、768px、375px 全端统一 1 列纵向堆叠（手机可读但桌面端单行超长且大屏空间浪费）。
