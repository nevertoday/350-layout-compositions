# 133 双栏 版式（TWO-COLUMN LAYOUT）设计方案

## 1. 一句话道理
把过宽的版面沿垂直栏距（Gutter）拆成左右两列，既能把每行字数压回眼睛回扫最稳的区间，又能借横向空间并置建立「图与文」或「甲与乙」的即时对照——成败全系于栏距是否宽过行距、栏宽是否各得其所、基线与阅读路径是否毫不打架。

## 2. 开场玩具：双栏排印桥·跨栏串读与图文对照工坊
- **怎么玩**：
  - 2D 蓝图排印画布（标 `data-perf-drag`），1:1 承袭 133 原海报深蓝底面、贯穿全高的双虚线栏距通道（`⋮ ↔ ⋮`）、琥珀金半调点阵块/圆/对照方与天蓝 S 形阅读路径矢（`●╰───→`）。
  - **直接横拖画布中央双虚线栏距通道**（或画布主体区域）连续推拉左右栏宽配比（22%–78%），左右两栏真实中文/双语内容逐字实时折行重排并实测每栏字数。
  - **拖栏距双虚线边轨或调栏距滑块**实时张合中央栏距（4px–140px），直观触发或消除「跨栏串读」红色虚线跳行弧。
  - **直点画布内三大视觉模块 / 抢焦冲突块**可切换主次锚点、锁定或打散跨栏基线对齐、切换「无栏线 / 细蓝虚线 / 粗硬栏线」，并支持一键演播天蓝 S 形阅读路径光珠。
  - **三套真实双栏标本**：① 原海报·图文双栏（左文右图三段琥珀模块 + S 形动线）；② 书刊连读·双栏专稿（左栏底无缝接右栏顶 N 形连读，验证跨栏串读与碎栏）；③ 左右对照·工艺参数（甲/乙平行对照，验证等宽权重与基线同步）。
- **开场初始错态（0/4 复合错态，绝不预给答案）**：
  - 栏距塌缩至 `6px`（vs 行距 `24px`，仅 `0.25×`）→ 实绘红色虚线跨栏弧直接从左栏第一行串进右栏；
  - 栏宽失衡至 `74% : 26%` → 左栏偏胖而右栏被挤成窄碎条；
  - 跨栏基线错位 `+10px` → 左右两栏水平节奏上下错牙；
  - 双栏顶部抢焦冲突（或粗硬红/重栏线割裂）→ 阅读起点打架，无清晰先左后右路径。
- **怎样算玩错（8 类双向真错态，全由 `model.js` 从实绘几何边界单真源核算）**：
  1. 栏距过窄（`< 0.95×` 行距）→ 跨栏串读；
  2. 栏距过宽（`> 14.5%` 版宽或 `> 3.6×` 行距）→ 双栏裂谷、割裂失联；
  3. 左栏过胖（连读/图文 `> 68%`，对照 `> 56%`）→ 右栏挤碎锯齿；
  4. 右栏过胖（连读/图文 `< 32%`，对照 `< 44%`）→ 左栏挤碎或对照失权；
  5. 基线错位（`|drift| > 2px`）→ 横向扫视上下跳动；
  6. 起点抢焦（两栏顶部同权争宠）→ 视线无入口；
  7. 粗硬栏线劈断（栏线过重）→ 强行切断图文关联；
  8. 窄栏短行锯齿（实测任一文字栏 `< 9` 汉字/行）→ 词组被切碎。
  - 接受多组合法解：原海报图文解（46:54）、黄金主副解（38:62 / 62:38）、等宽对照/连读解（50:50）。
- **读数说什么「为什么」**：每项实时指标与左侧四枚原海报图标探针均由同一 `evaluate()` 几何模型算出，不只报像素和百分比，而是用白话讲清格式塔亲密性如何把眼睛拉跨栏距、为什么回扫失准、以及调整后视线怎么走。
- **与最近 12 页的明显区别**：
  - 区别于 132（暖米纸全宽单栏、调外边距与清侧栏）：133 聚焦「两栏之间的关系」——中央双虚线栏距通道、跨栏串读物理临界、双栏基线同步与左右角色分工；
  - 区别于 298（松林绿 3D 折页开合角）：133 是平面出版蓝图排印台，操作的是栏距、栏宽比、基线与跨栏视线流；
  - 区别于 212（钴蓝左起对齐单栏文字行）与 168（暖米轴线建筑透视）：133 是深午夜蓝双栏对照蓝图，视觉与机制零重合。

## 3. 版式骨架
- **忠实转译 133 原海报「深午夜蓝双栏建筑蓝图 × 中央贯穿双虚线栏距通道」骨架**（零深灰通用顶栏、零笨重圆角灰卡片、不锁 `min-height: 100svh` 避平板大空白）：
- **1440×900 & 2560×1440**：主容器 1440 宽 `1380px`（2560 舒展至 `1720px`）。开场直接自示范双栏结构：左栏 `36%` 放原海报式刊头（`NO. 133` + 实况徽章、自示范双栏裂距大标 `双栏 / 版式` + 右指细蓝箭 `───→`、总述、原海报四枚线绘图标实况探针、单真源白话诊单，与右栏齐底无大空白），中间由 133 招牌双虚线栏距细缝分隔，右栏 `64%` 为全幅蓝图排印画布 + 紧贴底沿的紧凑制图控带。
- **1024×1366 & 768×1024 平板**：自然流排布，不锁 `100svh`，避免垂直大空白；768 下转为单列顺流，画布居上、四探针与诊单紧接其下。
- **390×844 手机竖屏**：顶沿压成一行紧凑刊头（`NO. 133 · 双栏 版式` + 标本切签），总述与四探针后置，让等比蓝图画布稳占首屏 ≥ 46% 高度且折线内直见实时诊单首句与栏距主控。
- **844×390 手机横屏**：左 `56%` 蓝图排印画布 × 右 `44%` 紧凑刊头、单真源诊单与核心控轨并行。
- **正文 01–07 节节奏**：蓝图霜白 `#F5F8FD` → 暖羊皮纸 `#F8F4EA` → 03 午夜蓝暗室 `#061B44` → 浅蓝测绘纸 `#EBF1FA` → 暖羊皮纸 `#F8F4EA` → 06 午夜蓝考场 `#001438` → 07 深蓝原海报展墙 `#041330` 与单行页脚，明暗交替、0px 锐利制图线框。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节不重用同种控件）
- `01` **为什么分成两栏**（*Why Split Into Two*）：拆解「清晰分栏，建立对照，引导阅读，提升效率」的光学依据（回扫距离与行宽测度），并温和补充「海报说满了一点」：双栏在宽页省力，但窄屏或超长滚动网页未必更快。交互：**视口宽度三档切换 + 单栏/双栏回扫步距对比动画器**。含一句话链接至 132、134。
- `02` **栏距决定生死**（*The Gutter Law*）：用格式塔亲密性讲透「栏距必须宽于行距」及 `column-gap` / `column-rule` 的边界。交互：**4×4 行距×栏距实时二维矩阵网格 + 真 CSS 活体中文双栏排印标本**（配无栏线/虚线/实线切换）。
- `03` **四种双栏分工**（*Four Archetypes*）：深蓝暗室呈现等宽连读、平行对照、主副图文、导航+正文四类分工。交互：**四模式建筑蓝图切卡 + 活体 SVG 比例权重与眼动路径图解 + 实时 CSS Grid 配方**。含一句话链接至 135、136。
- `04` **双栏从哪来**（*Origins of Two Columns*）：从 4 世纪《西奈抄本》诗歌双栏、约 1455 年古登堡四十二行圣经（B42），到 1981 年约瑟夫·米勒-布罗克曼网格系统与 1992 年罗伯特·布林赫斯特测度准则、现代 W3C CSS 多栏规范。交互：**四时期比例缩微版芯切换检视台（含真实宽高比与版芯线框）**。
- `05` **什么时候别用双栏**（*When Not to Use It*）：拆解长网页爬顶滚动陷阱、多栏表单跳行漏填（NN/g & Baymard 研究）、窄屏挤碎文字、以及全景大图被中缝劈开四大禁用场景。交互：**真实屏宽无级拉杆（360px–1080px）+「硬保双栏 vs 响应式退单栏」实景压力测试机**。含一句话链接至 132、137、138、139。
- `06` **动手练一练**（*Spot the One Variable*）：深蓝考场两道单一变量版式诊断题（第 1 题只变栏距，第 2 题只变对照栏宽比），四选项中性命名 `方案 A/B/C/D`，选后在缩略图上显影实测倍率并给出白话判词。
- `07` **原海报与关键词**（*Original Poster*）：展示 `<img id="poster" src="poster.webp">`（点击开启可缩放/拖动/Esc 关闭灯箱，`draggable="false"`）、原海报四组关键词与口号、同小类 7 页快捷导览与标准单行页脚。

## 7. 练习设计
- **第 1 题（栏距单一变量）**：同一段 840px 宽书刊双栏、26px 行距、50:50 等宽，四张缩略图只改栏距：`方案 A` 10px（0.38×）、`方案 B` 20px（0.77×，强干扰项）、`方案 C` 42px（1.62×，正解）、`方案 D` 156px（6.00×）。理由：栏距须大于行距才在格式塔亲密性上切断横向跨栏，又不能大到把两栏拆散。
- **第 2 题（对照栏宽单一变量）**：同一份甲/乙工艺参数对照页，栏距与基线完全锁定，只改左右栏宽比：`方案 A` 26:74、`方案 B` 38:62（适合主副图文但对照失衡，强干扰项）、`方案 C` 50:50（正解）、`方案 D` 70:30。理由：并列对照依赖均等视觉权重与等高行对齐，50:50 最利横向速览。
