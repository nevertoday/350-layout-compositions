# 299 自适应网格（ADAPTIVE GRID）设计方案

## 1. 一句话道理
自适应网格把「屏幕宽窄」转化为一套公开可算的轨道约束——用最小可读列宽守住内容下限，用弹性列宽吃掉余白，用统一间隙稳住归属，再用按需跨列建立主次节奏，使同一组内容在任何容器宽度下都能自己重新找到平衡。

## 2. 开场玩具
- **命名**：瑞士明黄·活体容器拉尺与网格装箱工作台（2D Canvas 高帧率真实 CSS Grid 装箱模拟，标 `data-perf-drag`）。
- **怎么玩**：
  1. **直接横拖画布或拖动虚线 `CONTAINER` 右缘黑杠拉杆**：在 `320px–1240px` 间连续改变容器宽度，顶部原海报三道工程标尺 `COLUMNS (列)`、`GUTTER (间隙)`、`CONTAINER (容器)` 实时跟着跳数，卡片在列数阶跃时以平滑 FLIP 补间自动重排。
  2. **直点画布中任意一张纯白卡片**：循环调整该卡片跨列数（`SPAN 1 → 2 → 3 → 4`，亦可用上方/右侧直控键增减或设安全跨列钳制 `min(span, cols)`），实时感受跨列对主次层级与行尾空洞的连锁影响。
  3. **在右侧原海报同款 4 条黑点牵引注记旁微调规则**：调整最小列宽 `minCol`（`72px–260px`）、统一间隙 `gutter`（`0px–48px`）、切换 `auto-fill / auto-fit`、`稀疏 row / 密排 dense`、是否钳制超宽跨列，以及切换 **原海报 8 卡 / 组件画廊 / 编辑台** 三套题材。
  4. **点按下方原海报四屏实时缩略预览（360px / 640px / 768px / 1200px+）**：四台设备始终同步演算同一套网格规则，点哪一台就把主容器推到那个宽度；最底沿原海报奶油淡黄「自适应逻辑流程」5 步胶囊实时亮出当前每一步的真实中间算值。
  5. **键盘支持**：焦点落画布时 `← / →` 调容器宽、`↑ / ↓` 调选中卡 `span`、`Tab` 或 `[` `]` 切换选中卡。
- **开场初始状态（明确坏态，非答案）**：
  - 容器 `860px` + 最小列宽 `86px`（低于原海报 `≥ 120px` 底线，硬塞出 9 列，单列仅 `92px` 挤碎内容）+ 间隙 `4px`（贴死粘连）+ 第 2 张卡被强设 `SPAN 6`（在当前 9 列中撕出 2 处醒目行内红斜线空洞，且在 360px 手机端直接撑爆容器右边界标红溢出）+ 跨列钳制关闭。开场直接呈现 4 处结构待修态。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 全部诊断由 `model.js` 从真实装箱几何坐标、实际列宽、溢出量、空洞格数单真源算出，覆盖 6 类双向错态：
    1. **列宽过挤**（实测列宽 `< 120px`）：字行被压短、图标与文字互挤，眼睛扫行频繁折返。
    2. **跨列撑爆**（某卡 `span > cols` 且未钳制，或在 360px 窄屏验算中撑破容器）：网格被迫生成隐式超宽列，出现恼人的横向滚动条。
    3. **间隙双向失衡**（`gutter < 10px` 粘连糊墙，或 `gutter > 32px` 割裂散架）：间隙窄过内边距会让邻卡内容认错归属，过宽则把同组模块拆成互不相关的孤岛。
    4. **行内空洞与尾行失衡**（大跨列卡折行留下的空白格率过高，或末行孤零落单）：画面出现突兀缺口，打破网格的均衡节奏。
    5. **平权单调**（列数 ≥ 4 且全员相同 `span 1` 无任何层级区分）：页面退化成均质货架，缺少视觉起点。
    6. **密排乱序隐患**（开启 `dense` 填洞且真发生回填跳序时）：画面洞补上了，但视觉先后与 DOM/Tab 焦点顺序脱节。
  - **多组合法解**：只要列宽 `≥ 120px`、间隙 `12–28px`、无跨列溢出、空洞率可控且保留适度跨列层次，无论在 `1040px`（原海报 8 列平衡解）、`768px`（平板 4 列平衡解）、`640px`（横屏 3 列解）还是 `900px`（6 列画廊解）都可成立，系统解释为何此刻平衡。
- **与近 12 页的不同**：
  - 298 是双折页开合透视；297 是优先级排序阶梯；253 是 Z 轴浮层剥离；252 是横向惯性卷轴；211 是断层切割拼贴；167 是引语断行气口刀；166 是图录尺度比与 VS 槽；042 是四层石阶筑塔。
  - 本页核心动作是**拉宽容器触发真 CSS Grid 自动算列 + 点卡改跨列 `span` + 实时同步验算 4 档设备宽度与 5 步逻辑流水线**，其他任何编号都无法照搬。

## 3. 版式骨架
- 忠实转译 299 原海报的瑞士明黄工业海报结构（无深色顶眉盒、无通用仪表盘侧栏、不写 `min-height: 100svh` 避平板空洞）：
  - **1440×900（宽屏 2560 舒展至 1720px）**：满幅电光明黄 `#FDCE05` 展墙，主体宽 `1380px` 居中。顶眉左置「自适应网格 ADAPTIVE GRID + 粗黑短杠 + 活体动态列尺 + 总述」，右置无框 5 行原海报关键词实时标尺；中段左 71% 虚线容器活体网格画布 + 右 29% 原海报黑点实线牵引四条印刷注记与紧致微调阀；细黑线下左 38% 核心规则单真源诊单 × 竖线 × 右 62% 响应式四屏实时缩略预览（360/640/768/1200）及双虚线标语箭；底沿原海报奶油淡黄 `#FFFCCA` 圆角 5 步实况逻辑流程条。
  - **1024×1366 / 768×1024（平板）**：自然流排，虚线网格画布占满全宽，4 条黑点牵引注记紧贴画布下方排成 2×2 整齐双栏，底栏「核心规则」与「四屏预览」对齐上下铺开，零单栏截断空白。
  - **390×844（手机竖屏）**：压紧单行刊头（编号 + 标题 + 实时状态签），把总述与 5 关键词挪至画布之后，让等比活体网格画布稳占首屏 ≥ 48% 屏高，并在首屏底部直接露出单真源白话诊断首句与容器宽快滑条。
  - **844×390（手机横屏）**：切为左 56% 活体网格画布 × 右 44% 紧凑刊头 + 单真源诊断与快调轨并排。

## 5. 节目录
- `01` **列数自己算的秘密**（`AUTO-FILL & AUTO-FIT`｜极净白纸）：拆解列数下限公式与 `auto-fill`/`auto-fit`/`min(M, 100%)` 差异，温和补充原海报「≥120px」的语境边界；交互：**卡片数量步进器（1–6 张）+ 轨道策略切签 + 真 DOM CSS Grid 透明空轨透视槽**。
- `02` **跨列层级与填洞代价**（`SPAN & DENSE FLOW`｜淡奶油黄纸）：剖析跨列 `span` 带来的主次层次、窄屏爆框风险与 `grid-auto-flow: dense` 填洞引发的视觉/焦点乱序；交互：**可播放「Tab 焦点顺序循迹」演练台 + `稀疏 row` / `密排 dense` / `安全降阶` 切签**。
- `03` **间隙撑起呼吸与归属**（`GUTTER RHYTHM`｜深墨黑暗室）：以格式塔接近性讲清统一 `gutter` 与卡内边距 `padding` 的黄金比例关系；交互：**双轨联动参数台（间隙 `gutter` × 内边距 `padding`）实时判定分组归属与视觉张力**。
- `04` **从瑞士铅字到 CSS Grid**（`ORIGIN & TIMELINE`｜暖灰制图纸）：梳理 1981 瑞士网格、2010 响应式设计、2011 微软提案、2016–2017 CSS Grid 标准与 2018 内在设计脉络；交互：**五年代可点标尺卡组，切换呈现各时期代表语法与网格行为微缩图**。
- `05` **什么时候用，什么时候别用**（`USE & AVOID`｜极净白纸）：明确自适应网格边界与 4 类典型反例，一句话链接同小类 291–300 兄弟页；交互：**6 场景交互分诊卡，点击逐条检验是否应采用自适应网格或切换同类模式**。
- `06` **小练习：挑出平衡解**（`PRACTICE · VISUAL QUIZ`｜深墨黑暗室）：四选一实战小练习，选项只标中性参数与等比 SVG 微缩图，互差单一变量；交互：**四选一实时算式拆解小练习**。
- `07` **原海报与关键词**（`ORIGINAL POSTER`｜淡明黄展墙 + 纯墨黑页脚）：展示原海报（点开支持放大、拖动与 `Esc` 关闭）与 5 组原海报关键词及核心规则索引。

## 7. 练习
- **题目**：6 张带图标与两行标题的知识卡片放进 `720px` 宽容器（卡内边距固定 `16px`，每列需保留至少 `150px` 易读宽度，且不能横向溢出）。以下四组 CSS Grid 参数（均含首尾两张重点卡跨列）哪一组最合理？
- **选项（纯中性参数描述，只差单变量）**：
  - **A**：`minmax(96px, 1fr)` · `gap: 16px` · 首尾卡 `span 2`（仅改小 `min`：排成 6 列每列仅 `106px` < 150px，文字严重挤碎）
  - **B**：`minmax(160px, 1fr)` · `gap: 16px` · 首尾卡 `span 2`（**正确答案**：720px 恰好得 4 列，每列 `168px` ≥ 150px；`gap 16px` 与卡内边距持平、归属清楚；6 卡总跨列 `2+1+1+1+1+2 = 8` 恰好占满 2 整行，无空洞、无溢出）
  - **C**：`minmax(160px, 1fr)` · `gap: 44px` · 首尾卡 `span 2`（仅放大 `gap`：超大间隙把列数压成 3 列且卡间割裂，总跨列 8 在 3 列中留下 1 格行尾缺口）
  - **D**：`minmax(160px, 1fr)` · `gap: 16px` · 首卡 `span 5`（仅放大 `span`：4 列容器中硬写 `span 5` 强生第 5 隐式列，触发横向溢出爆框）
