# 286 搜索结果布局（SEARCH RESULTS LAYOUT）互动页方案

## 1. 一句话道理
搜索结果布局的本质是**用稳定的视觉层级与查询相关的信息气味（Information Scent），替用户把“逐条点开试错”前置成“扫一眼即可筛掉无关项、锁定最相关答案”**。排序决定谁先落入注意力高位，层级决定眼睛先看标题再核来源，动态摘要与高亮给出“为什么匹配”的即时证据。

## 2. 开场玩具
- **玩法（「活体搜索结果页 × 摘要密度与注意力衰减游标尺」）**：
  - 直接还原 286 号原海报的真实可用搜索引擎界面：顶部是**真能打字搜索的输入框**（预填原海报查询「如何提高专注力」，可自由输入关键词实时触发前端倒排匹配与重排，也可一键切三条不同搜索意图：原海报信息型「如何提高专注力」、导航型「FocusLab 官网入口」、学术对比型「番茄工作法 实证」）。
  - 搜索栏正下方嵌一条 **2D Canvas「摘要预算窗 × 首屏衰减游标尺」（标 `data-perf-drag`）**：横向拖拽连续调节单条摘要字数预算（0–155 字），实时重绘查询词命中分布、单卡高度占用与 #1–#5 首屏注意力分配柱，并同步驱动下方 5 条真实结果卡的摘要裁切与高度变化。
  - 结果列表支持直接操控四维结构：**排序策略**（时间乱序 / 相关性排序 / 广告霸屏 / 全员加框）、**层级顺序**（平级灰字 / 标题>链接>摘要 / 链接面包屑>标题>摘要）、**匹配反馈**（静态无高亮 / 关键词高亮 / 高亮+标签 / 过度涂亮）、**卡片节奏**（图文乱跳 / 首位强化+统一结构 / 纯文紧凑），还可直接点击任意结果卡的「↑ 置顶」或点击标题测试“能否一眼点中目标”。
- **开场初始状态（0/4 迷路错态，绝非答案）**：
  - 默认停在「时间乱序 + 层级拉平 + 静态首段零高亮 + 148 字长摘要墙 + 卡片图文左右乱跳」：最相关的原海报首位文章被埋在第 4 位，首屏仅挤下约 1.6 条结果，读者一眼看不出哪条最相关。
- **怎样算玩错、错了读数怎么说（单真源 `model.js` 实算 10 类错态）**：
  - 从同一份实算结果与几何估算模型输出：首位相关度分、主次视觉对比比、摘要字数与信息气味命中数、首屏可见条数（经验估算）。
  - 可主动踩出 10 类具体失误：最相关结果被埋、推广广告劫持首位红框、全员套红框致主次比归 1.0×、标题与摘要平级无辨识、摘要拖太短（<20 字）缺信息气味、摘要拖太长（>115 字）挤爆首屏、静态首段无查询词高亮、过度高亮（>45% 噪点淹没焦点）、卡片图文左右乱跳破坏纵扫节奏、以及**导航型查询下摘要过长反而拖慢直达速度**（Cutrell & Guan, 2007）。
  - 接受**多组合法解**：原海报经典解、现代面包屑优先解、导航型纯文紧凑短摘要解。
- **与近期 12 页的差异**：
  - 285 是分步表单字段切分轨，284 是表单眼动探针，243 是垂直堆栈间距尺，242 是三槽容器调宽墙，其余多为几何/透视/构图画布；本页是**真实可输入检索的活体 SERP 界面 + 意图敏感的摘要预算窗**，别的编号无法套用。

## 3. 版式骨架
- **忠实承袭 286 原海报的开放暖米纸双栏编辑骨架**（不加深色顶栏，不锁 `100svh` 避免平板空洞）：
  - **顶部开放刊头**：左列超粗黑体大标「搜索结果布局」（自示范：首二字嵌随找寻度变色的检索命中框）+ `SEARCH RESULTS LAYOUT` + 焦陶短粗杠接细线 + 总述；右上角原海报招牌焦陶大圆弧 `#B6481E` 叠 4×4 炭黑点阵。
  - **主体 1440×900（主宽 1360px；2560 舒展至 1720px）**：左 27% 为原海报三要点脊（`扫描节奏 SCAN` · `主次排序 PRIORITY` · `摘要密度 SNIPPETS`，配原海报红褐图标与波浪虚线向下箭头）+ 单真源找寻诊单；右 73% 为活体搜索结果页工作台（搜索框 + 统计排序栏 + 2D 摘要游标尺 + 5 条实时结果卡，首位带红褐细框与右上折角星标）；底沿紧接原海报暖砂色四栏 `布局要点 KEY TAKEAWAYS` 实况条。
  - **1024×1366 / 768×1024 平板**：自然流排，活体搜索区满宽居中，下方三列横排三要点与诊单，无大片空白。
  - **390×844 手机竖屏**：单行压紧刊头，紧接真实搜索栏、2D 摘要游标尺与 #1/#2 活体结果卡，交互主体稳占首屏 ≥ 50% 高度并同见诊单首句。
  - **844×390 手机横屏**：左 58% 搜索栏、摘要游标尺与结果卡 × 右 42% 精简刊头、诊单与四维快控并行。

## 5. 节目录（8 节，相邻节控件各异）
- `01` **海报拆解：四条底座**：引出原海报三要点与四条布局要点，并温和修正「Z 型路径」说法（实证为 F 型与弹球模式）；交互：**四层结果卡 X 光剥离解剖器**（点击标题/链接/摘要/辅助四层单独透视权重）。
- `02` **眼睛怎么扫：从 F 到弹球**：讲清信息气味、首位偏置、F 型与弹球扫描；交互：**2D Canvas 三代眼动扫视路径播放器**（切换纯链/首位强化/富媒体混排 + 时间轴滑杆观察注视落点示意）。
- `03` **摘要切几字：意图定密度**（深钴暗室）：对比静态首段与查询词动态摘句（KWIC）及信息型 vs 导航型差异；交互：**查询词动态抽句对比台**（点选不同查询词并切换提取方式与搜索意图，实时高亮原文抽取片段）。
- `04` **从哪来：三十年演进**：梳理 1995–2019 搜索结果页关键节点；交互：**五代搜索结果标本切换器**（点选年代直接变换线框标本结构）。
- `05` **什么时候用与别用**：界定适用边界与 6 类不适用场景，一句话链接 269/270/271/274/275/280/281/282/290；交互：**四类真实业务场景分诊器**（点选业务题面给出推荐版式与取舍原因）。
- `06` **工程落地：空态与宽窄屏**：拆解零结果兜底、超长网址防爆框、筛选折叠与键盘可访问性；交互：**极端数据压力切换器**（切换正常/零结果/超长标题与 URL/390 窄卡并对照实时 CSS 规则）。
- `07` **小练习：哪版更好扫**：中性标签四选一视觉判断；交互：**双题中性对比测验**（仅差单一变量，作答后给出原理解析）。
- `08` **原海报与关键词**：展示 286 原海报大图与灯箱缩放拖拽 + 海报要点关键词徽标。

## 7. 练习
- **题 1（信息型查询「咖啡萃取 过萃 原因」）**：四张卡片标题、网址、排序、缩略图完全一致，**只差摘要生成与高亮方式**；选项仅标 `方案 A` / `方案 B` / `方案 C` / `方案 D`。
  - **A（正确）**：查询词动态摘句（约 64 字两行）+ 仅高亮命中词「过萃」「原因」+ 2 枚主题签。
  - **B**：等长静态导语（约 64 字），不出现查询词也无高亮。
  - **C**：查询词动态摘句但拉长到 5 行（约 155 字），单卡撑满首屏挤压后续候选。
  - **D**：等长两行摘句，但把 12 个泛词全部涂亮制造噪点。
- **题 2（导航型查询「Figma 价格页」）**：验证意图切换后「精简短摘要 + 清晰来源层级」胜过长摘要墙。
