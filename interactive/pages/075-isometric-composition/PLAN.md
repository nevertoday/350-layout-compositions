# 075 等距构图（ISOMETRIC COMPOSITION）实现方案

## 1. 一句话道理
把三条空间坐标轴在平面上均分为 120°、沿三轴采用相同缩放比（严格投影 $\sqrt{2/3} \approx 0.816$）并取消透视消失点后，同一标准模块放在近处与远处尺寸完全一致，整个画面就能像可无限拼装的精密积木系统一样清晰、稳定、可扩展。

## 2. 开场玩具
- **名称**：等角模块化搭积木 × 三轴校准台（Live Isometric Voxel Architecture & Tri-Axis Orthographic Stage，纯 2D Canvas 实算 3D 平行/透视投影矩阵，零 WebGL 依赖且离线 60 FPS）。
- **视觉承袭**：1:1 化用 075 原海报的薄荷青底等角三角网（`#92F7DF`）、奶油顶面（`#FAF5CE`）× 电光紫左面（`#7C28E6`）× 翡翠绿右面（`#3DB698`）× 午夜靛蓝深影（`#141842`）模块立方体塔，正面立面上用真实 2D 仿射矩阵实时投射原海报的「等」「距」「构」「图」立体字块，右侧配原海报阶梯与左角拱门；右上嵌入与画布联动的原海报细虚线圆角「等角原理 120° 实时三轴量角器」。
- **一打开是什么状态（0/3 错态，绝不给答案）**：
  1. **透视汇聚未归零（`p = 48%`）**：前后同款 1×1×1 方块体量比显著畸变（约 `1.28 : 1`），延伸辅助线向画内有限消失点收拢，模块无法跨深度复用。
  2. **三轴不等角（方位角 `27°`、俯仰角 `19°`）**：屏幕上三条坐标轴夹角偏斜为约 `99° / 123° / 138°`，三轴缩短比失衡（顶面被压扁、左右两面宽窄不一）。
  3. **偏轴游离块**：右前角有一枚电光紫立方体脱离三轴网格、偏转 `+18°` 且悬空错位，破坏「所有线条平行于三条等角轴方向」的等距逻辑。
- **怎么玩**：
  - 直接在画布上拖曳（`data-perf-drag`；桌面支持双向自由轨道旋转方位角/俯仰角，触屏采用横向拖曳旋方位角以保页面纵向顺滑滚动）把三轴转回等角位（4 个对称等角象限 `45° / 135° / 225° / 315°` × 俯角 `35.26°` 均为合法多解，靠近时轻柔磁吸）。
  - 直接点击画布上标红的偏轴游离块将其一键归位到等距晶格；点击任意模块的顶/左/右侧面即可就地**加块（叠装标准 1×1×1 模块）或删块**，并实时标尺比对最前排与最远端新落模块的屏幕像素高度，亲眼验证「近远等大」。
  - 拖曳「透视汇聚」滑轨把消失点推向无穷远（`36% → 0%`），并可切换三套模块题材（原海报「等距构图」塔 / 阶梯展馆 / 像素工坊）或点击试错（强广角透视 / 正视平拍 / 2:1 像素二等轴测）。
- **怎样算玩错 & 读数说什么「为什么」**：
  - 由 `model.js` 从实绘 3D 顶点与投影矩阵单真源核算 7 类状态：透视未归零、三轴偏角、2:1 像素二等轴测（底边 26.6° 而非真等角 30°）、单面压扁平拍、游离块偏轴、仅满足部分条件、以及 4 象限完全达标；每次报错都指明哪条物理规律被破坏及为何导致模块体量失真。
- **与最近 12 页的区别**：
  - 074 是 2D 斜投影拉后角手柄；073 是 3D 单点移轴门楼；071 是两点透视双灭点；202 是平面 2D 网格拉缝；243/244 是垂直卡片堆栈与 CSS 盒模型。本页独有「实时 3D 平行投影轨道 + 120° 联动三轴量角器 + 直接点击积木面搭建/拆除 1×1×1 模块并实时测前后像素等比」，任何其他编号都无法套用。

## 5. 节目录（8 节，相邻不重复同种控件）
- `01` **120° 与 0.816 的由来** — 从 45° 偏航 + 35.264° 俯仰推导三轴等角与 $\sqrt{2/3}$，对比严格投影、1:1 简法与 2:1 像素二等轴测（交互：三档制图标准切换 + 像素网格放大镜实绘）。
- `02` **无汇聚换来什么** — 拆解「无透视汇聚」为何赋予近远一致的测量尺度与资产复用力（交互：前后深度传送带滑轨 + 透视 vs 等距双窗实体像素卡尺）。
- `03` **标准模块与三面光影** — 结合原海报四条绘制提示，验证晶格对齐与「顶亮、左深、右中」三面明暗纪律（交互：4×4 等距地块点击印章建造台 + 三面明暗纪律切换）。
- `04` **深度歧义与不可能图形**（深靛蓝暗室） — 揭示等比平行投影的光学暗面：视线重合导致的悬空错觉（*Zaxxon* 投影解法）与彭罗斯不可能三角（交互：地面阴影显影开关与高度推杆 + 彭罗斯三角 3D 视角拆穿滑轨）。
- `05` **两百年源流与演变** — 核实梳理 William Farish（1820/1822）、Oscar Reutersvärd（1934）、Penrose 父子（1958）、*Zaxxon* / *Q*bert*（1982）与 ISO 5456-3（1996）（交互：四站历史年代卡片切换对应蓝图剖解标本）。
- `06` **适用领域与什么时候别用** — 展开原海报四大应用，温和校订海报过满的口号，列出四类明确失效场景并附同小类兄弟页单句链接（交互：四大行业卡片筛选 + 「30° 斜贴字 vs 水平标注」可读性对比开关）。

## 7. 练习设计
- **题目**：同一组 4 座模块化展馆与一座悬空连廊，四个方案仅在单一视觉规则上有差异（中性标签 A / B / C / D），请选出唯一严守等距构图秩序且空间关系清晰的方案。
- **选项单一变量差异**：
  - `方案 A`：三轴 120°、零汇聚、模块对齐，但三面明度几乎无差（失辨反例）。
  - `方案 B`：三面明暗分明、模块对齐，但混入约 28% 透视汇聚（后排展馆缩水且平行边收拢）。
  - `方案 C`（正确）：三轴 120°、零汇聚、三面光影明暗分明、所有模块贴合晶格，且悬空连廊投下清晰地面投影消除高度歧义。
  - `方案 D`：三轴 120°、零汇聚、三面分明，但右侧一座展馆底面偏转 +16° 脱离三轴平行网格。
