# 165 索引版式（INDEX LAYOUT）设计方案

## 1. 一句话道理
索引版式把原本藏在全书各处的知识点抽出来，按确定规则分桶、分层并用定位码和交叉引用串成网，让带着关键词来的读者不必线性通读，通过「选类 → 查词 → 溯联」两跳直达目标。

## 2. 开场玩具（辞书书口切口索引台 × 实测查词路径仪）
- **怎么玩**：在 1:1 承袭 165 原海报浅灰暖石纸 × 翡翠松绿的 2D Canvas 活体索引摊页上，用户既可以**左右拖动画布/底沿拇指翻槽游标（`data-perf-drag`）**沿 A–G 七个书口切口连续扫查、实时翻起右侧立体绿脊切口并追踪每个词条到其关联词的贝塞尔路径，也可以**直点右侧书口 A–G 切口**、**直点任意词条**查看左下活体示例卡、**直点画布红标排错**、**切换查词目标**、在「原海报·排版词典 / 植物图鉴 / 医学术语」三套 21 词数据集间切换，并用 4 组结构控件（分类与切口、词条层级、定位列与引线、交叉引用网）实测重构索引。支持键盘方向键与字母键 A–G。
- **开场初始状态（绝不先给答案）**：停在 `0/4 · 失序泥潭` 复合错态——21 词条按录入先后乱序平铺、无 A–G 书口切口、层级全拍平为同色灰点、定位码无引线紧黏、交叉引用断开且保留类似原海报示例卡错码的死链隐患；画布实时绘出查找目标词（如「留白 → 网格」）时不得不从首行一路线性盲扫十几行并在文末报错断开的红色眼动折线。
- **怎样算玩错 & 读数怎么说**：四项维度均设**双向陷阱**（不是点满即过）：
  1. 分类/切口过粗（无分类乱序）→ 必须逐行线性扫查；过碎（14 碎类）→ 切口本身超过 10 个，光扫书口就耗去近半步数，反倒不如不切。
  2. 词条层级过平（全同级）→ 核心与次级混成灰墙；过载（全绿实心高亮）→ 到处都是重点等于没有重点。
  3. 定位引线过弱（紧黏无引线）→ 词条与编码黏连易读混；过强（粗黑实线）→ 产生密集斑马条纹，抢走词条主体。
  4. 交叉引用过缺（孤岛断开）→ 查完一词无处延展；死链错码（如把网格错标为 G01）→ 校验检出无效编码；过密（全网滥连）→ 每词连出 5+ 条弧线织成蜘蛛网。
- **读数说什么「为什么」**：全部由 `model.js` 从当帧实绘词条坐标、桶大小、引线墨量与图论死链检查单真源计算，用白话解释「为什么要这样排，眼睛会怎么扫」，并接受「原海报切口点线解」「芝加哥书后缩进紧随解」「紧凑词典解」多组合法解。
- **与最近 12 页的区别**：164 讲书前目录的线性分组与横向串行（拖竖分栏尺）；其余近 12 页聚焦视口拉阔、出血裁刀、透屏穿插、仰拍透视、粒子磁聚、折线锐度、列下落与封面高度。165 独占**「书口切口拇指翻找 + 非连续两跳查词路径 + 图论交叉引用死链校验」**，别的编号完全无法套用。

## 3. 版式骨架
忠实转译 165 原海报的**「右缘通高 45° 斜切翡翠绿书口切口脊 × 左窄边注卡片带 × 中央活体辞书索引摊页」**（绝不锁 `min-height: 100svh`，无深色顶栏，无圆角仪表盘箱）：
- **1440×900 / 2560×1440**：主工作区宽 `1380px`（2560 舒展至 `1720px`）。顶沿紧凑刊头（左绿圆放大镜 + 粗黑大标「索引版式」+ 翠绿 `INDEX LAYOUT`；右原海报三原则实时灯带与三题材切签）→ 主体三栏：左 24% 单真源诊单卡 + 原海报同款活体「图例 / 示例」边注卡 × 中 72% 活体索引画布 + 四阀结构控槽 + 原海报同款底栏「关联推荐」路径带 × 右 4% 45° 斜切通高翡翠绿 A–G 书口切口脊（滚动至 01–07 节后亦可作为全页书口导航感视觉延续）。左右栏内容等高匹配，不留空洞。
- **1024×1366 / 768×1024**：自然流排，画布与右侧切口全宽展开，下方诊单卡与活体示例/图例双栏并排，无空洞。
- **390×844 竖屏**：压紧单行刊头与三题材切，等比活体索引画布（内置右侧紧凑 A–G 书口触控带）稳占首屏 ≥ 46% 屏高且不压扁，画布正下方立即可见单真源诊单首句与四阀控钮。
- **844×390 横屏**：左 56% 活体索引画布 × 右 44% 紧凑刊头 + 诊单与关键控件并行。

## 4. 配色与字体
- **配色（逐像素实采自 165 原海报）**：
  - 典籍浅石纸主底：`#ECECEC` / `#F0F0F0`；索引卡纸面：`#F7F7F3`；亮石阅读纸：`#F5F6F5`；薄荷雾纸：`#EBF2EE`；柔和警示米灰：`#F4F0EB`；
  - 标志字典书口翡翠松绿：`#0C7854`（浅纸高对比深翠字 `#095C40`，对比度 > 7:1；03/07 深翠暗室底 `#0B3828` / `#082D20`，暗舱 `#114935`，暗底亮薄荷 `#7BE4BC`）；
  - 极锐纯墨主字：`#0E1110`；次墨 `#454E4B`；细格线 `#C8D0CC`；
  - 语义报错朱赤：`#B83227`（浅纸） / `#FF8F85`（暗室）。
- **字体搭配（全库唯一，三款西文/等宽在近 12 页全部 0 次使用）**：
  - `Noto Sans SC`（400–900）：中文标题与辞书词条正文；
  - `Archivo`（400–900，**近 12 页 0 次使用**）：英文厚实辞书大标、A–G 书口切口字母与节号；
  - `Libre Baskerville`（400–700 正体 + 400 斜体，**近 12 页 0 次使用**）：书后索引 *see* / *see also* 斜体指令与出版典籍注记；
  - `Space Mono`（400 / 700，**近 12 页 0 次使用**）：`A01–G03` 等宽定位码与实测读数。

## 5. 节目录（全部标题 ≤ 12 字，相邻节绝不重复交互控件）
- **01 · 为什么翻索引比目录快** (`WHY INDEXING WORKS`)：拆解顺序阅读与非连续随机检索的区别；交互：**双栏步进竞速模拟器**（按钮步进 + 词库规模滑杆，实看线性扫查 vs 切口两跳）。
- **02 · 索引是怎么长出来的** (`ORIGIN & EVOLUTION`)：梳理 1230s 圣谢尔的休《圣经》全词索引、1615 梅膺祚《字汇》214 部首与 1716《康熙字典》、1863–1870s Denison 书口切口、1925 王云五四角号码、1975/1996 ISO 999 与 CMOS；交互：**横向年代切口书签 + 动态版面结构 SVG 标本视窗**。
- **03 · 一套好索引的四根骨架** (`ANATOMY OF AN INDEX`，深翠暗室)：展开原海报「检索 / 分类 / 关联」与 ISO 999 / CMOS 规范；交互：**排印解剖切换台**（对比缩进式 vs 接排式、左齐右不齐 vs 强制两端对齐的窄栏字间河流），并温和剖析原海报示例卡错码的校对启示。
- **04 · 同类出版页怎么分工** (`EDITORIAL FAMILY`)：一句话厘清 160–167 八类出版功能页边界并加在线链接，不重讲别页重点；交互：**读者意图分诊卡片点选高亮**。
- **05 · 什么时候用与别用** (`WHEN TO USE & AVOID`)：厘清工具书/文档适用面与短篇、线性叙事、低维护能力下的禁用红线；交互：**四项工况勾选自查器**，实时给出是否该建索引的白话建议。
- **06 · 挑出一张好用的索引** (`PRACTICE QUIZ`)：四张等字号窄栏 SVG 排印样张单变量辨析；交互：**A/B/C/D 单选练习 + 逐项解析**。
- **07 · 原海报与全部索引词** (`ORIGINAL POSTER & KEYWORDS`，深翠展墙)：完整原海报高清缩放暗箱（`draggable="false"`、拖动、Esc 关）+ 21 枚原海报中英索引词可点回跳开场台 + 温和勘误注记。

## 7. 小练习设计
- **题干**：为 320 页设计术语工具书编排双栏窄列（每栏 52mm）书后索引，以下四张样张词条与顺序完全一致，哪一张最利于快速扫读与准确落位？
- **四项只差排版结构变量（选项仅标 A/B/C/D + 中性短语，不泄底）**：
  - **A（正确）**：齐左右不齐 + 1em 缩进子目 + 紧随等宽页码 + 斜体 *see also*（符合 CMOS 16.24/16.26 与 ISO 999：窄栏无字间撕裂、层级一眼可辨、紧凑不添视觉噪音）。
  - **B**：强制两端对齐（其余同 A）→ 窄栏中拉开大段空白洞（“字间河流”），扫读易卡顿。
  - **C**：取消缩进与层级区分（其余同 A）→ 主词条与子词条齐平同重，读者误把子目当新词条。
  - **D**：强加粗黑连续实线把页码推至右缘（其余同 A）→ 窄栏里粗线压倒文字形成斑马噪点，并拉大水平眼跳。
