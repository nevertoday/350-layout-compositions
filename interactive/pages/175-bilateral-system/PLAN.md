# 175 双边系统（BILATERAL SYSTEM）互动页设计方案

## 1. 一句话道理
双边系统以一条清晰的垂直中心轴把文字与图形组织成左右对等的两翼，利用人眼对垂直镜像对称的极速识别（Wagemans, 1997），在稳定与克制中建立起秩序感、视觉平衡与跨轴对话。

## 2. 开场玩具：双翼对轴排印台（Bilateral Axis Typesetter）
- **形态与载体**：1:1 承袭 175 原海报的暖米宣纸、深松墨绿双半圆、炙柿橘红对望双核、外侧橘红点阵、底沿双翼四道排印线与贯穿垂直虚线中轴（2D Canvas，标 `data-perf-drag`），并内置三种双边排印标本可即时切换：`原海报 · 双半圆对话`、`古典扉页 · 轴心居中排印`、`双栏对谈 · 展册镜像`。
- **怎么玩**：
  1. **横拖画布（主手势）**：连续调节左右两翼之间的中缝对话距；关闭「镜像联动」时可单独推移右翼，亲手打破或重建左右对称。
  2. **拖移中央虚线轴柄**：直接平移垂直对称轴（30%–70%），感受哪怕 8% 的偏轴如何让双边版式立刻显得「排歪了」。
  3. **拖移右翼体量控制缘 / 上下拖右翼**：实时改写右翼视觉体量比（45%–155%）与纵位错差 ΔY（-48px 至 +48px），在「左沉右浮」与「光学配平」之间来回测试。
  4. **直点双橘核 / 对齐按钮**：点按画布上的炙柿橘红圆核可切换「向轴对望 / 外背失联 / 中心粘撞」；一键切换「向轴居中 / 靠轴对望 / 单向左齐（破轴）」排印语法；按 `Space` 从虚线中轴向左右同时发射对称脉冲波，观测两翼是否同拍回响。
- **开场初始态（0/4 复合错态，绝不给答案）**：
  - 中轴右偏至 61%（偏离画心 +11%）；
  - 右翼体量缩至左翼的 58% 且向上错位 -32px，左右失衡；
  - 双橘核翻到外侧背对（失联），且中缝拉扯过宽导致对话断裂；
  - 两翼排字采用单向左齐，逆着中轴拉扯视觉重心。
- **怎样算玩错、错了读数怎么说（单真源双向校验）**：
  - `model.js` 从画布实绘的左右两翼几何包围盒、实绘墨色面积积分、中轴位置、纵差与中缝像素占比单一真源计算，覆盖 9 类双向错态：`轴心偏左 / 轴心偏右`、`左重右轻 / 右重左轻`、`纵位错牙`、`中缝塌撞（<4% 粘死）`、`中缝撕裂（>24% 割裂）`、`橘核外背失联`、`单向左齐破轴`、`零层级僵死`、`边沿过满窒息`。
  - 读数既给白话结论也讲「为什么」：例如中轴偏右时说明「人眼把近垂直中心轴当成天然天平支点，偏离超过 3% 会被读成失误而非刻意不对称」；中缝过宽时说明「超过两翼宽度耦合区后，左右不再对话，退化成两张互不相干的半幅海报」。
  - 认可多种 4/4 合法解：`原海报经典解`、`舒展留气解`、`异形光学配重解`（左右形状不同但视觉重量对等，呼应奇肖尔德 1965 年观点），以及用户任意手工调出的达标组合。
- **与最近 12 页的差异**：050 是环形光圈雕琢，087 是极坐标放射星盘，260 是圣杯五区视口缩放，138 是印前裁纸铡刀，219 是竖排立柱字步，174 是四屏透视光流过渡，339 是 A/B 方案维度连线配对，304 是多层剪纸群像景深，049 是弯弧拉弦，086 是 3D 纵深走廊，338 是两项内容幻灯片明暗卡片配重，137 是跨页书脊接缝。本页聚焦「单一垂直对称轴 × 镜像两翼光学配重 × 居中/靠轴排印对话」，并与同小类 `168 轴线系统`（单轴不对称挂靠推进）严格区分。

## 3. 版式骨架（1:1 忠实转译 175 原海报）
- **视觉母题**：告别「左标题+右面板」的通用双栏模板，完整复刻 175 原海报的**居中仪式感双边刊头骨架**：居顶居中特粗大标「双边系统」（自带贯穿虚线中心轴自示范对称）→ 宽字距英文 `BILATERAL SYSTEM` → 招牌橘红横线与中心橘点 `──── ● ────` → 三栏居中关键词状态柱 `对称 SYMMETRY | 平衡 BALANCE | 对话 DIALOGUE`（活体连接单真源状态，点击高亮画布对应维度）。
- **1440×900（2560 舒展至 1680px）**：居中紧致刊头 → 全幅开放双翼对轴排印画布 → 底部 1:1 复刻原海报下沿的非对称双联收束区：左 58% 上下虚线分隔双条（上深松绿竖杠实时白话诊单 + 合法解/试错预设，下炙柿橘竖杠精控滑轨与对齐切换）× 右 42% **活体圆形双边徽章**（随状态倾斜或归正的中心标尺+橘珠支点）与四项实测读数卡，左右严格齐底。不锁 `100svh`，平板 `1024×1366` / `768×1024` 自然流排零空洞。
- **390×844（手机竖屏）**：单行压紧刊头与三词微标，标本切换一行收拢，等比例排印画布稳占首屏 ≥46%，折线内直接露出深松绿竖杠诊断首句、一键校准与核心滑轨，详细控台与圆徽顺接其下。
- **844×390（手机横屏）**：左 56% 排印画布 × 右 44% 紧致刊头与实时诊断并行排布。

## 5. 节目录（7 节，相邻节控件绝不重复，h2 ≤ 12 字）
- **01 `对称、平衡与对话`**（亮宣纸）：原话引用海报双语总述；交互为**三词解剖切换签 + 联动 SVG 几何剖析图**，拆解对称、平衡、对话三层结构并引入 Wagemans（1997）关于垂直镜像对称的认知发现。
- **02 `从石碑到现代扉页`**（焙暖宣）：交互为**四时代历史标本步进器（1499 阿尔杜斯 / 1818 博多尼 / 1958–1975 奇肖尔德 / 2007 伊拉姆）**，点击切换对应年代的真实双边版式微缩样张与文献出处，并一句话链接同小类 168–174 各页。
- **03 `居中也会排歪的秘密`**（深松暗室）：交互为**扉页断行轮廓与光学配重活版台**，可切换「等宽僵砖 / 孤字断尾 / 语义收束花瓶」三种断行策略，并开关「几何居中 vs 光学修正」（解决标点与字形空缺造成的目视偏斜）。
- **04 `两翼如何展开对话`**（暖米原纸）：交互为**双翼角色配对矩阵（双语展签 / 对比参数 / 诗文注疏 / 图文提要）+ 中缝耦合滑尺**，直观演练「左翼右齐、右翼左齐、共守中轴」的跨轴对话法则。
- **05 `什么时候用，什么时候别用`**（浅砂纸）：双栏对照「适用场域」与「禁用红线」，内嵌**「一秒看清长文居中灾难」开关**（实测长段落居中后每行左侧回扫落点剧烈抖动），并设**「说多了一点」**温和补正框，拆解海报里「左右对等」的真实边界。
- **06 `挑出成立的双边版式`**（深松暗室）：交互为**两轮单变量视觉辨析考场**（4 枚中性标签方案 A/B/C/D，每轮只差一个核心变量，选完现场叠加重心线与解析）。
- **07 `原海报与关键词`**（暖米原纸 + 极深松页脚）：完整展示 175 原海报（点击放大、滚轮/按钮缩放、拖拽浏览、`draggable="false"`、Esc 关闭）、原海报三关键词、实采色卡与规范页脚。

## 7. 小练习设计（单变量、零提示标签）
- **第一题（扉页断行与轮廓节奏）**：完全相同的文字、中轴、字号与留白框，四个选项仅差「断行轮廓与层级收束」：
  - 方案 A：末尾落出单字孤行，中段臃肿；
  - 方案 B：头重脚轻倒块且主副标题字级拉不开；
  - 方案 C：按语义收束成经典微收花瓶轮廓，主副层级分明（正确答案）；
  - 方案 D：强行逐行拉成等宽长方砖，失去双边排印的轮廓韵律。
- **第二题（双栏双语对谈的中轴语法）**：完全相同的中英展板文案与 50% 中轴，四个选项仅差「两翼朝向与中缝配重」：
  - 方案 A：两翼挤撞中缝仅剩 2px，左右粘连；
  - 方案 B：左右两栏同时硬左齐，左侧文字远离中轴造成右侧视觉空洞；
  - 方案 C：右翼字号与体量轻了近一半，视觉重心明显左坠；
  - 方案 D：左翼靠轴右齐、右翼靠轴左齐，留出清晰中缝且光学墨重相当（正确答案）。
