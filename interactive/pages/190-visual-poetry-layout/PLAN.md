# 190 图形诗排版（VISUAL POETRY LAYOUT）设计方案

## 1. 一句话道理
图形诗排版不靠预设边框或配图，而是把文字本身的行长、方向、疏密与大片留白拧成同一个意象，让读者「先一眼看见画面，再顺着版面节奏读完诗句」。

## 2. 开场玩具：诗形雕版台（Live Visual Poem Typesetter）
- **载体与素材**：直接承袭 190 号原海报的满幅姜黄版画纸面（`#F2B72C`）与原诗正文——山峰部分《山是沉默的句号 / 风从远方来 / 掠过棱线 / 带走云影 也带走喧嚣 / 只留下光 在石上 呼吸》，溪流部分《水向低处流动 / 流向更远的地方》，配唯一一枚可拖动的哑光朱陶落日（`#B95A1D`）。
- **开场初始态（刻意错态，非答案）**：打开时落在「意象塌陷 · 0/4 成立」——原诗全部被压平为 0° 左对齐普通段落、字距紧挤、溪流拉直成一条僵硬横杠，朱陶落日压在字块背后，画面退化成一块闷堵的普通文字，完全看不到山与水。
- **怎么玩**：
  1. 直接在 2D Canvas 舞台（标有 `data-perf-drag`）左右拖动拉开/收拢**山势坡角**，拖下方曲流弯曲**河道弧度**，或直接拖移**朱陶落日**调整空域重心（触屏 `touch-action: pan-y` 保页面竖滑顺畅）；
  2. 也可通过精调滑杆与按钮调「山势坡角（0°–64°）」「水句曲度（0%–100%）」「字距与留白（0%–100%）」，并切换「山水原形 / 平排段落 / 斜雨错配」三种排法、开关「透视骨架」与「复原错态」。不设一键通关钮。
- **怎样算玩错 & 读数怎么说「为什么」**（全部由 `model.js` 单一真源根据真实字符包围盒与坐标实算，标注经验值）：
  1. **形意打架**：选「斜雨错配」去排「山是沉默的句号」，诗句在说沉稳山峦，字阵却向右下斜坠——形式背叛语义。
  2. **意象塌陷**：坡角 `< 14°` 或选「平排段落」，文字看起来像普通说明文，山峰与走势消失。
  3. **过陡断读 / 急弯叠字**：坡角 `> 44°` 或水句曲度 `> 88%`，实测字符包围盒碰撞（`N 处叠字`）或斜角过陡迫使读者歪头破译——造型压死了可读性。
  4. **字密憋闷**：字距过紧或素底留白 `< 62%`（经验舒适带 66%–84%），墨字粘块、没有诗的停顿呼吸。
  5. **散成星尘**：字距拉过头或素底留白 `> 87%`，格式塔接近律失效，字散不成词、形散不成山。
  6. **落日压字 / 偏重**：朱陶圆日压住诗句文字包围盒或贴死边缘，干扰辨认且打破留白重心。
  7. **4/4 成立**：山势（18°–38°）立起且顺读 + 曲流（42%–82%）无急弯叠字 + 留白呼吸（66%–84%）+ 落日悬于空域且形意合拍。
- **与最近 12 页的区别**：
  - 189「形状文字」是把长文灌进闭合翡翠水滴壳体调字号防溢流；190 完全没有外框容器，靠诗句自身的双坡倾角、阶梯行长、S 形流水与落日负空间「长出」山水画面。
  - 188 是五栏白底基线对齐，104 是深靛九宫弹射，227 是蓝图网格轨道，022 是三柱移轴建筑，271 是瀑布流砌墙；190 独有满幅姜黄无框版画诗页、直接雕琢诗行几何与形意核验。

## 3. 版式骨架
- **1440×900 桌面**：忠实延续原海报无重边框、无圆角仪表盘的满幅姜黄（`#F2B72C`）开放版画骨架：顶栏极细单行眉线直入三段式诗页舞台——左列（27%）排示范大标「图形诗排版」（五字随山脊微微错落、带微型朱陶日点）、短黑横杠、原海报总述与精调控件；中列（51%）无边框铺开全高山水图形诗活体画布；右列（22%）复刻原海报标志性的「黑点 + 竖细线（•|）」悬垂设计笔记与四项实时体检。
- **2560×1440 宽屏**：版心自然放宽至 `1920px`，中幅开放诗画按等比同步舒展，不缩成中间一小条。
- **1024×1366 / 768×1024 平板**：不锁 `min-height: 100svh`，自然纵排避免大片空洞。
- **390×844 手机竖屏**：压缩单行顶标与标题，紧接满幅无框山水诗画舞台（占首屏 ≥ 46% 屏高，圆日严格等比保圆），下接横向精调滑杆与紧凑设计笔记诊单，首屏即见画、可拖、见读数。
- **844×390 手机横屏**：切为左 56% 全高诗画舞台 × 右 44% 紧排标题、滑杆与实时诊断。
- **正文七节底色交替**：暖宣纸白 `#FAF4E2` → 浅赭米纸 `#F2E4BA` → 深墨研石 `#171410`（金字反白诵读节拍仪）→ 暖宣纸白 `#FAF4E2` → 柔姜黄 `#F5DE9B` → 暖宣纸白 `#FAF4E2` → 浅赭米纸 `#F2E4BA`（原海报与关键词）。

## 4. 配色和字体
- **配色（实采自 190 原海报）**：
  - 姜黄海报主底 `#F2B72C` / 柔姜黄 `#F5DE9B` / 浅赭纸 `#F2E4BA` / 暖宣纸 `#FAF4E2`
  - 印刷浓墨 `#120F0A` / 研墨深底 `#171410` / 暖墨次字 `#3F3629`
  - 朱陶落日 `#B95A1D`（仅作圆日/图形/描边）；文字用深焦陶 `#823306`（宣纸上对比度 > 8:1，姜黄底用 `#5E2405` > 6.8:1）、深底高亮金 `#F2B72C`（> 9.8:1）、深松绿成立态 `#1B5530`。
- **字体搭配（全库唯一，且含三款最近 12 页未用字体）**：
  - `Noto Serif SC`（400 / 700 / 900）：大标题与中文正文（段落中人名年份同字体不跳动）
  - `LXGW WenKai`（霞鹜文楷，400，**最近 12 页未用**）：画布与标本中的诗歌正文，建立温和书卷与手植诗行气质
  - `Outfit`（400 / 600 / 700，**最近 12 页未用**）：英文副题与章节小标，贴合原海报 `VISUAL POETRY LAYOUT` 干净几何感
  - `IBM Plex Mono`（400 / 500，**最近 12 页未用**）：角度、留白比与节拍等宽读数

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻控件不重复）
- **01 · 字即画面，空即呼吸**（Words as form, silence as ground）：拆解原海报设计笔记「方向、密度、节奏」与「补一句实在话」；交互：**三诗四形活字变形台**（切元稹《茶》宝塔 / 斜落雨丝 / 对称羽翼，一键在「普通正文」与「图形诗」间平滑变形对比）。
- **02 · 两千年的跨海脉络**（Two millennia of shaped verse）：东西方图形诗与具象诗史（西米亚斯、苏蕙《璇玑图》、元稹《茶》、赫伯特、卡罗尔、马拉美、阿波利奈尔、贡林格与 Noigandres）；交互：**历史书页标本切片台**（点选年份卡片切换对应时期的真实版式示意图，含《璇玑图》回文路径与《Silencio》中心留白高亮）。
- **03 · 留白不是空，是节拍器**（Whitespace as a musical rest）：深墨研石底面，解析字距与空行如何直接改变默读速度与呼吸停顿；交互：**可点插空拍的诵读节拍仪**（直接点击诗句字间插入/收回留白停顿，按「默读一遍」看金光游标按空间宽窄真实变速走读）。
- **04 · 形意同构与三位邻居**（Form, meaning & neighbors）：一句话区分并链接至 189 形状文字、191 路径文字、192 垂直文字排版、181 非对称字体排版；交互：**脱壳剥离三栏对照镜**（勾掉辅助图形与路径线，直看三种排法谁靠壳、谁靠线、谁靠字本身立形）。
- **05 · 何时惊艳，何时翻车**（When to use, when to avoid）：适用场景与四大禁用雷区（长文回行迷路、高频工具界面、信息拥挤公告、强行拟物）；交互：**四场景翻车试纸**（诗歌展海报 / 文学书封 / 航班登机牌 / 药品说明书，一键对比图形诗排法与常规排法的扫读体验）。
- **06 · 练一练：哪版排对了落雪**（Practice · pick the best setting）：四版同诗不同单变量的落雪图形诗选优练习；交互：**四选一中性版式卡 + 揭晓几何诊线**。
- **07 · 原海报与关键词**（The original poster）：原海报点按放大拖动查看（`draggable="false"`，Esc 收起）+ 原海报五枚关键词（意象、留白、节奏、文字即图、诗性）与设计笔记原文。

## 7. 练习设计
- **题干**：三行短诗「雪落无声 / 盖住旧石阶 / 只剩一阵微白」，想表现轻落与沉静。以下 A、B、C、D 四版仅差一个排版变量，哪一版最成立？
- **四选项（仅标 A/B/C/D，中性无暗示）**：
  - **A**：三行字距挤紧且压贴纸面左下角（单变量偏差：疏密憋闷与落势空间被底边堵死）
  - **B（正解）**：自右上向左下轻缓错落，上行微疏如飘雪、下行趋平落定，留白约 78% 且倾角温和（约 12°）易顺读
  - **C**：保留位置与留白，但把三行整体倾斜至 58° 陡坡（单变量偏差：倾角过陡断读，刺破沉静意象）
  - **D**：保留轻盈，但将字距拉宽至 1.4em 铺满四角（单变量偏差：过疏瓦解格式塔接近律，词句散架）
- **正解理由**：图形诗同时守住形意合拍、大片留白舞台与流畅可读；B 借轻斜与上疏下稳的节奏演活了「落雪无声」，而 A 闷挤、C 过陡断读、D 散架成孤字。
