# 280 树形浏览布局（TREE BROWSER LAYOUT）设计方案

## 1. 一句话道理
树形浏览布局把信息按「包含与从属」叠进可逐级展开的树状目录，通过**按需披露**隐藏当下无关的枝叶、用**缩进与引导线**标出归属层级，让用户既能在大信息量里保持空间方位感，又不被一次性倾泻的列表淹没。

## 2. 开场玩具
- **玩法**：1:1 承袭 280 原海报「知识库 Knowledge Base」的活体三栏树形浏览器（左：深青墨顶栏真实 WAI-ARIA 树形目录 + 嵌于顶沿的 2D Canvas「缩进与层级地形标尺」`data-perf-drag`；中：随选中节点实时连动的三级联详情卡片与动态 SVG 肘形连接线；右：单真源实算白话诊单 + 精简四维控参 + 可反查高亮左树的五项「结构要素」）。
  - 用户可直接点击每个文件夹的 `−`/`+` 按需展开或收起、用真实 WAI-ARIA 方向键（`↑`/`↓`/`←`/`→`/`Home`/`End`）穿梭节点、点击「↑ 提级去套娃」消除冗余空壳层、**左右拖拽 `data-perf-drag` 缩进标尺**在 `4px`–`40px` 间实时重排缩进并观察右侧截字警戒线与 60fps 引导线拓扑变化、点击中栏卡片反选左树节点。
- **开场初始态（0/4 待理树，绝非答案）**：四维同时翻车——
  1. 层级过深套娃（6 层，含 `体系规范` / `界面资产` 两层无意义单子空壳）且缩进仅 `4px` 糊成平表；
  2. 全树 100% 强制展开（16 个节点同时倾泻淹没主干）；
  3. 命名退化为模糊编号（`分类 01 / 子项 1-2`）且统一灰色圆点无容器/文档区分；
  4. 盲态无反馈（藏起 `±` 按钮、树形引导线、选中薄荷高亮、级联连线与面包屑）。
- **怎样算玩错 & 错了读数怎么说（双向可错，多合法解）**：
  - 层级/缩进：深于 4 层判「套娃过深」；摊成 1 层判「扁平失序，失去分类归属」；缩进 `<12px` 判「缩进糊成平表，人眼分不清父子」；缩进过大导致右侧标签截字判「右侧梯田截断（实算溢出像素与截断节点数）」。3 层或 4 层搭配 14–26px 且 0 截字均合法。
  - 展开策略：展开过多（`≥12` 可见节点或展开率 `≥75%`）判「全树摊开过载」；全部收起仅剩根节点（`≤1` 可见节点）判「全收失踪，看不见一级主干」。展开根节点并按需打开任意 1–2 条查阅路径（可见 5–11 节点）均合法。
  - 语义明确：模糊编号判「信息气味断裂，只能盲点猜内容」；整句长名判「节点名过长挤垮扫读」；去图标区分判「分不清容器还是叶子文档」。
  - 状态反馈：盲态判「方位迷失，看不出当前在哪与能否展开」；全层高饱和彩虹底色判「视觉噪音压过选中焦点」。
- **与最近 12 页的差异**：最近 12 页里 279 是 7 列月历拖拽排期台、278 是 5 列泳道看板、317 是平远水墨手卷、195 是瑞士分栏拼版、150 是四格看图猜成语、233 是酸黄 CSS 绝对坐标盒、110 是紫粉橘渐变坡面、065 是 3D 前中后景玻璃盒、027 是对称山水天平、316 是玄夜重门剖深、194 是手稿边距裁定、149 是巨型字母骨架。本页做的是**唯一真实的层级树形浏览器 + 动态肘形级联卡片 + WAI-ARIA 键盘与缩进截字实测引擎**，玩法与版式骨架均无法移植到任何其他编号。

## 3. 版式骨架
忠实承袭 280 原海报「温润米白刊头（左嵌入活体层级枝徽的示范大标与青绿竖杠总述 × 右植物回路树徽与 3×4 薄荷点阵）→ 三栏连动主工作区（左 44% 深青顶栏活体树窗口 × 中 33% 三级联详情卡与活体肘形连接线 × 右 23% 单真源诊单、四维控参与五项结构要素）→ 底沿浅薄荷五柱原则实检带 + 深青使用场景与关键词条」的现代产品图录骨架，不锁 `100svh` 避开平板空洞：
- **1440×900 / 2560×1440**：主容器 1380px（2560 舒展至 1780px），三栏自然齐底，右侧五项「结构要素」与中栏三卡等高落位。
- **1024×1366 / 768×1024**：收为左 58% 活体树窗口 × 右 42% 级联详情与诊单双栏，「结构要素」横向五格铺底对齐，无半边空洞。
- **390×844 竖屏**：压紧单行刊头（隐去大号植物插画，保留迷你枝徽与状态胶囊），让深青顶栏活体树窗口与 2D Canvas 缩进标尺直落首屏稳占 ≥ 48% 屏高，并在首屏下沿同见白话诊单首句。
- **844×390 横屏**：切为左 56% 树窗口与缩进标尺 × 右 44% 紧凑刊头、诊单与四维操控并行。

## 4. 配色和字体
- **配色（逐像素实采自 280 原海报）**：
  - 纸底体系：暖米白底 `#F8F7F1`、洁象牙卡 `#FCFBF7`、浅雾薄荷节 `#EDF3EE`、浅青灰卡片 `#EEF3EF`、底带柔和薄荷 `#E4ECE7`、选中行柔绿 `#E0F0E6`、细边框 `#CADBD4`。
  - 主墨与暗室：深青石油墨 `#022D3C`（标题与正文主墨）、窗顶栏深青 `#01333F`、结构徽与页底条 `#003E48`、03 节无障碍键盘暗室 `#052834` / 暗舱 `#0B3947`、次墨青灰 `#3E5C64`。
  - 强调与语义：海报青碧绿 `#0A968F` / `#00AAA2`（文件夹图标、竖杠与连接线）、浅底高对比深青字 `#0A6E6B`（对比度 > 5.7:1）、暗底亮青薄荷 `#5CE0D2`；克制以暖赤陶红 `#C43E2F`（暗底 `#FF8E7E`）专标错态与截字警戒。
- **字体搭配（全库唯一；三款西文字体在最新 12 页全部 0 次使用，其中 Inter 在开工前与当前近 22 页均 0 次使用）**：
  - `Noto Sans SC`（400 / 600 / 800）：中文主标、树节点与正文，保持产品 UI 清晰平实且中文段落内不混换异体字。
  - `Inter`（400 / 600 / 700，**近 22 页 0 次使用**）：英文副标、英文节点名与模块眉题。
  - `Space Mono`（400 / 700，**最新 12 页 0 次使用**）：路径面包屑、深度标尺、ARIA 属性、键帽与数据读数。
  - `Young Serif`（400，**最新 12 页 0 次使用**）：章节大序号 `01`–`08` 与历史年代大号展示。

## 5. 节目录
- `01` **广度与深度的代价**（Breadth vs. Depth）：用 64 叶子 2D Canvas 拓扑实验室对比 `2⁶ / 4³ / 8² / 64¹` 四种树形，引用 Kiger (1984) 与 Larson & Czerwinski (1998) 并温和修正「≤ 4 层」经验边界。
- `02` **五种结构要素拆解**（Anatomy of a Tree）：五枚独立「X 光图层拨片」（引导线/缩进/类型图标/计数徽/展开符）剥层验证视觉线索缺一不可。
- `03` **键盘与无障碍操作**（WAI-ARIA Tree Mechanics，深青暗室节）：真实键盘 + 屏幕键帽操练 W3C WAI-ARIA APG 游走焦点与方向键协议，同步输出 DOM 属性与读屏播报。
- `04` **从大纲到多栏演进**（Lineage of Tree Browsers）：1968 NLS → 1980 Miller/Smalltalk → 1991 System 7 → 1995 Win95 → 1998 IA 简史 + 同一数据的「大纲树 / 米勒分栏 / 双栏级联」三态切换对比。
- `05` **小屏幕怎么不挤扁**（Mobile Adaptation Lab）：可切视口宽度的手机模拟器，支持真实关键词搜索对比「孤岛过滤 vs 保留祖先路径」，及钻取面包屑与抽屉折叠切换。
- `06` **什么时候别用树形**（When NOT to Use It）：4 类真实产品数据结构分诊台（可体验把多维商品硬塞进单父树导致重复死循环），并一句带链指向同小类兄弟页（270/272/273/274/275/277/278/279/285/286/287/290）。
- `07` **实战挑树小练习**（Practice Quiz）：两题各四联中性方案（仅变单一变量），即选即评并解释原因。
- `08` **原海报与关键词**（Original Poster）：`<img id="poster">` 可缩放拖动灯箱 + 五大关键词中英注释 + 规范页脚。

## 7. 练习设计
- 第 1 题（层级与展开策略）：同一套 32 篇「产品设计规范」，四个方案仅在层级深度与默认展开策略上不同，选项只标「方案 A / B / C / D」加中性结构说明：A（5 层细拆、默认全收）、B（3 层分组、仅展开当前路径并附子项计数，**正解**）、C（3 层分组、默认全展开 32 项）、D（1 层按日期平铺 32 篇）。
- 第 2 题（小屏适配策略）：同一套 4 层知识库移至 375px 手机端，仅在导航呈现上不同：A（保留 28px 缩进横向滚动）、B（压成 2px 缩进并去图标）、C（面包屑 + 单层钻取 + 留路径搜索，**正解**）、D（隐藏子目录仅留一级长文页）。
