# 272 便当盒布局（BENTO BOX LAYOUT）互动版方案

## 1. 一句话道理
把异质信息装进大小不等、边界清晰的独立仓位里，再严丝合缝拼成一个完整外矩形——用「共同区域边界」隔断干扰防止串味，用「仓位面积差」一眼分清主次，让人在单屏内轻松打包扫读。

## 2. 开场玩具：活体便当装盒台（4×3 实仓拼盘 + 同步 2D 蓝图透视）
- **怎么玩**：舞台是一只承袭 272 原海报木框与抹茶底的 `4 列 × 3 行 = 12 格` 活体 CSS Grid 便当内胆盘，内含原海报 4 大核心仓位（`大标题区`樱粉、`重点提示区`米白、`内容主体区`杏桃、`补充说明区`青绿）加 1 枚轻配仓（`快捷入口区`浅鹅黄）。
  - 直接拖动仓位隔板/右下角扩缩手柄（中央 `col 2` 竖隔板柄标 `data-perf-drag`，拖动时 2D Canvas 实时绘出像素级橡皮筋预览、格数标尺与重心点）改变任意仓位的 `宽 × 高`；
  - 拖动仓位本体可移入空槽或与他仓互换位置；也可点击选中任一仓位，用键盘方向键（`Arrow` 移位、`Shift+Arrow` 扩缩）或配菜签里的 `宽 ± / 高 ±` 按钮操作；
  - 调节盒缝档位（`4px 粘连 / 14px 舒朗 / 28px 散架`）与 `格栅与重心透视` 开关；右上原海报同款微型便当饭盒插画随拼盘状态实时同步变格，底沿原海报四步法（`分仓 / 组合 / 强调 / 轻松`）实时点亮。
- **开场初始状态（0/4 翻车态，绝不先给答案）**：
  - `补充说明区`（青绿轻配角）错误霸占左上 `2×2`（4 格）主菜位，右隔板恰落水平居中 `50%` 处；
  - `大标题区`（樱粉主角）和 `内容主体区`（杏桃图文）被挤进右上 `1×1` 小格；
  - 底部整排 `4` 格露空（填满 `8/12` 破盒漏风），盒缝停在 `4px` 粘连态。
- **怎样算玩错 & 读数怎么说「为什么」**（全由 `model.js` 单一真源从实算格阵与 DOM 尺寸算出，设「复原错态」不设一键代答）：
  1. **破盒漏风**（填满 < 12 格）：指出具体缺几格，说明便当盒外框缺口会让眼睛在空洞处打滑、失去打包收口感；
  2. **喧宾夺主**（配角面积 ≥ 大标题区，或大标题区 < 3 格 / 非视觉主角）：点出具体哪块配角抢了大标题焦点，解释面积即视觉音量；
  3. **均分平权**（最大/最小仓面积比 < 2.0×）：指出各仓一样大已退化成卡片网格，看不出先读哪一格；
  4. **巨兽霸盒**（单仓 ≥ 8 格，占 67%+）：指出单一仓位吞并过半盘面，其余信息被迫缩成边角碎条；
  5. **体量错配或畸形条**（内容主体 < 2 格图文窒息，或出现 1×3 过细长条）：说明内容复杂度须与仓位面积匹配；
  6. **盒缝失当**（4px 粘连串味，或 28px 盒散成孤岛）：说明盒缝须在经验甜区（10–20px）内，既隔断又不散架。
- **与最近 12 页的区别**：270 调均分卡片外距与焦点色，271 调瀑布流排布引擎与高宽比上限，226 调一维 Flex 伸缩，059/143/058/188/309/310 均属图像构图或文字对齐；本页直接执行便当盒独有的「二维离散格栅拼盒装填 + 角色面积匹配 + 外框严丝合缝收口」动作，别的编号完全无法套用。

## 3. 版式骨架
- **1440×900**：忠实承袭 272 原海报的抹茶青满幅便当托盘骨架。顶栏极简编号 + 左置原海报大标总述 × 右置活体同步迷你便当盒插画；中段无暗色仪表盘框，左 `71%` 铺开暖木框 `4×3` 活体便当盘，右 `29%` 竖叠两枚同高米白便当仓（选中仓操控签 + 实时诊单，严格齐底零空洞）；底沿通栏置原海报米白圆角四步法验收条，整屏约 860px 完整收束。
- **2560×1440**：主容器舒展至 `1760px`，便当盘与仓内插画同步放宽充实，不缩在中间留大片空边。
- **1024×1366 / 768×1024**：不锁 `100svh`，配菜签与诊单自然转置盘下双列并排，无空洞。
- **390×844**：压紧顶标（标题与迷你便当盒同行，总述下移盘后），让 `366×396px`（≥ 45% 屏高）的 `4×3` 便当盘稳占首屏主体，紧接一行大触控快捷调格钮与实时诊单。
- **844×390**：压成 36px 单行顶带，切换左 `59%` 通高便当盘 × 右 `41%` 快捷调格与实时诊单双栏并行。

## 5. 节目录（8 节，h2 均 ≤ 12 字，相邻节不复用同控件）
- **01 · 为什么分仓就轻松**（`COMMON REGION`）：讲清共同区域律与原海报四仓角色；交互：**边界显影推窗**（横向拉幕对比无仓界串味 vs 有仓界成组）。
- **02 · 面积就是音量**（`AREA AS HIERARCHY`）：对比均分卡片与瀑布流，温和修正原海报「灵活组合」边界（标「说多了一点」：文字暴涨会撑破硬框）；交互：**三档面积比切牌 + 溢文压力开关 + 视线落点连线**。
- **03 · 从漆盒到网格**（`ORIGIN & EVOLUTION`）：深漆盒底讲述 1600s 松花堂昭乗、1933 湯木貞一松花堂弁当、2010 Metro 磁贴、2017 CSS Grid 与 2020 iOS 14 小组件；交互：**四时代骨架切换 + 实时 `grid-template-areas` 字母蓝图**。
- **04 · 窄屏怎么不散架**（`RESPONSIVE REPACK`）：讲清跨端重排策略（4列→2列→1列重编区域而非等比硬缩）；交互：**可拖拽视口夹板宽度机（320–1200px）+ 错法/正解切换**。
- **05 · 什么时候别用**（`WHEN NOT TO USE`）：四类失效场景并单句链接 269/270/271/274/275/284/285；交互：**四类真实内容「试装入盒」翻车模拟器**。
- **06 · 盒缝与同心圆角**（`CONCENTRIC CORNERS`）：讲清 `R_外 = R_内 + 内边距` 与外缝/内距比例；交互：**2D Canvas 45° 同心圆角显微放大镜（双旋钮实测壁厚差）**。
- **07 · 挑一盒好便当**（`QUICK PRACTICE`）：四方案中性对比单选练习；交互：**四卡点选即揭晓面积比与单变量诊断**。
- **08 · 原海报与关键词**（`ORIGINAL POSTER`）：放大可拖原海报 + 四枚原海报关键词 + 同类链接 + 页脚。

## 7. 小练习
- **场景**：为一款「AI 录音笔」做单屏卖点总览，须装入 5 个模块（`AI 降噪`主角、`声波试听`主体图文、`32h 续航`重点指标、`28g 轻巧机身`补充注释、`立即预订`快捷入口），盒缝与配色完全相同，**只改变分仓面积与收口结构**。
- **四选项（仅标 A / B / C / D，绝不剧透好坏）**：
  - **A**：全员 `2×1` 均分，右下余留 `2×1` 空洞（单变量错：平权无主次且缺口未收口）。
  - **B（正解）**：12/12 完整收口，`AI 降噪`占左上 `2×2`，`32h 续航`占右上 `2×1`，`声波试听`占右下 `2×2`，`28g 轻巧机身`与`立即预订`各占左下 `1×1`（收口、层级、体量匹配三全）。
  - **C**：12/12 完整收口且有 4:1 面积差，但将 `2×2` 主位给了补充注释 `28g 轻巧机身`，把主角 `AI 降噪` 挤进 `1×1`（单变量错：角色与面积倒挂）。
  - **D**：12/12 完整收口且 `AI 降噪` 居左上，但独吞 `3×3`（75% 盘面），其余四项被挤成右列细碎 `1×1` 堆叠（单变量错：单仓霸盒失去多仓平衡）。
