# 277 时间线布局（TIMELINE LAYOUT）设计方案

## 1. 一句话道理
人脑把「时间的先后」映射成「空间的朝向」：当节点按严格时序排布、由连续有向主轴串起、以清晰焦标区分「已走过 / 正在走 / 未开始」并用宏阶段收束记忆块时，读者一眼就能看懂事物的来龙去脉与当前所处位置。

## 2. 开场玩具
- **怎么玩（活体时间轴编排台 · Live Timeline Sequencer）**：
  - 舞台复刻 277 原海报的「播放起点帽 `▶` → 红到杏橙五枚圆形图标徽章 → 下挂五张阶段卡（01 启动 / 02 规划 / 03 执行 / 04 优化 / 05 复盘）→ 底部三段宏阶段带（准备 / 实施 / 收尾）」。
  - **连续直拖（`data-perf-drag`）**：主轴本身是一条全宽 2D Canvas 编年游标轨，鼠标或手指直接在主轴上左右拖动红色时间游标（Day 1 ↔ Day 60），实时扫过每个里程碑、驱动进度条与 `>>>` 推进脉冲、同步点亮下方对应卡片，并在节点乱序时现场画出赤红「时间倒流折返弧」。
  - **直接操卡改序**：点击任意两张节点卡（或点击卡上 `←` / `→` 移位钮、或键盘方向键）调换先后顺序。
  - **四组结构切换**：主轴连接（断链散卡 / 无向连线 / 有向进度轴）、节点粒度（2 站过粗 / 5 站海报 / 7 站详版 / 9 站碎片）、时间刻度（失真挤堆 / 节奏均分 / 断轴压缩）、焦标与归组（关闭/开启当前焦标、关闭/开启底部三段阶段带）。
- **一打开是什么状态（0 / 4 待理顺，绝不预先给答案）**：
  1. **顺序倒流**：`04 优化（Day 42）` 与 `02 规划（Day 14）` 位置颠倒，拖游标时主轴显露刺眼赤红倒流弧。
  2. **主轴断连**：处于「断链散卡」态，无主轴线也无方向箭头，五张卡退化成一排散卡。
  3. **失真挤堆且无焦标**：时间刻度处于「真实日期不均挤堆」态（前 4 站挤在左 36% 撞肩、右侧空出大片荒原），同时关闭进度焦标，五站同色平权。
  4. **缺阶段归组**：关闭底部「准备阶段 → 实施阶段 → 收尾阶段」三段宏阶段带。
- **怎样算玩错、错了读数怎么说**：
  - 节点任意乱序 → 读数实报逆序对数与时间倒流天数（例如「第 2 站跳到 Day 42，第 4 站倒退回 Day 14，倒流 -28 天」），说明空间朝向与时间逻辑冲突。
  - 只连线不加方向（选「无向连线」）→ 仍不通过「连续与方向」，说明无起止锚点与 `>>>` 指向时读者分不清推演方向。
  - 节点过少（2 站）→ 报「过程塌缩，退化成前后对比」；节点过多（9 站）→ 报「超负荷碎片拥挤，超出 5–7 站舒适带」。
  - 选「失真挤堆」→ 实算最小节点净距撞车与右侧荒原占比；「节奏均分」与「断轴压缩」为两种合法解法。
  - 关焦标 → 报「五站同色平权，看不出当前进度停在哪一站」。
- **与最近 12 页的不同**：
  - 不做轮播露边（276）、不做横/竖排文字校样（193/192）、不做分叉树嫁接（063）、不做 CSS 浮块（231）、不做画廊比例尺（275）、不做母砖织机（108）、不做马戏团字号压杆（147）、不做透视消失点（025）、不做景深视差（314）、不做表格列宽（230）、不做星场推波（062）。
  - 核心交互是「时间轴游标扫读 + 时序倒流诊断 + 节点调序 + 刻度挤堆与阶段归组」，纯属时间线布局独有动作。

## 3. 版式骨架
- 忠实承袭 277 原海报的「暖杏宣纸编年长轴通幅」版式（零深色仪表盘侧栏感，不锁 `min-height: 100svh` 避开平板空洞）：
  - **1440×900**（内容宽 `1360px`；**2560×1440** 扩宽至 `1760px`）：34px 极细暖宣顶眉 → 上部非对称刊头（左 68% 深漆红示范大标「时间线布局」+ 随舞台联动的迷你 5 点进度副标线 + 总述 + 原海报 5 枚椭圆关键词实况胶囊；右 32% 原海报同心圆环深红日点与 4×3 渐变点阵 + 实时编年读数戳）→ 中部全宽无框暖杏时间轴舞台（2D Canvas 游标主轴 + 5 张下挂阶段卡 + 底部三段红-珊瑚-红阶段带）→ 下接原海报同款浅桃杏圆角说明板（虚线竖隔：左 46% 原海报深红时钟轴徽 + 实测白话诊单 × 右 54% 四行紧凑操控槽）与底部原海报 TIPS 虚箭条。
  - **1024×1366 / 768×1024**：自然流式排布，不锁全屏高；五卡横排保持比例清晰，底板自然收紧不留一侧空洞。
  - **390×844（手机竖屏）**：单行压紧标题与态标，隐藏右上装饰环，将总述移至舞台之后；活体时间轴舞台（等比圆形徽章主轴画布 + 紧凑五站触控卡带 + 三段阶段带）稳占首屏 ≥ 48% 屏高，并在首屏同见白话诊单核心句与首批操控钮；节点触控区 ≥ 40px，零横向溢出。
  - **844×390（手机横屏）**：切为左 58% 紧凑主轴画布与五卡带 × 右 42% 缩微标题、诊单与核心按钮并行。

## 5. 节目录
1. `01` **一条线里的四条规矩**（`THE FOUR ANATOMY LAWS`）— 原海报四条布局要点拆解 + 四层可独立开关的 SVG 结构透视剖析台（切换显隐层，非滑块）。
2. `02` **刻度与节奏：等距为何会撒谎**（`SCALE & RHYTHM`）— 深酒红暗室 + 2D Canvas 连续刻度变形滑杆（0% 真实日期比例 ↔ 100% 等距节奏）与断轴 `//` 开关，实测撞车与失真率。
3. `03` **超过七站时怎么收束**（`CHUNKING BEYOND SEVEN`）— 温和修正原海报「5–7 个为佳」TIPS（标「说多了一点」），结合 Miller (1956) 与 Cowan (2001) + 15 节点两级阶段折叠手风琴实操。
4. `04` **横轴还是纵轴，看屏宽与场景**（`HORIZONTAL VS VERTICAL`）— 原海报四大适用场景（项目管理 / 产品路线图 / 事件回顾 / 学习路径）+ 模拟视口宽度切换与横/左纵/交替纵排实测。
5. `05` **时间线从哪来**（`WHERE TIMELINES CAME FROM`）— 深红暗版编年史：从尤西比乌斯表格到 Barbeu-Dubourg (1753)、Joseph Priestley (1765/1769)、Karol Adamiecki (1896) 与 Henry Gantt (1910s/1919) 再到 W3C ARIA；点击四纪元切签重绘历史图谱 SVG。
6. `06` **什么时候别用，顺手测一题**（`WHEN NOT TO USE · QUIZ`）— 四大不适用边界（一句话链向 278 看板、279 日历、280 树形、270 卡片网格、274 数据表格、285 分步表单、269 信息流）+ 单变量四选一图文诊断小练习。
7. `07` **原版海报与五个关键词**（`ORIGINAL POSTER`）— 可点击放大拖拽与 Esc 关闭的原海报 + 原海报五枚英文关键词精读与 TIPS 收口。

## 7. 练习
- **题干**：某产品团队发布「年度新品上线路线图」，含 5 个关键节点（1 月立项、2 月原型、4 月内测、5 月预售、9 月量产），目前推进到「4 月内测」。以下四个桌面横排方案文案相同，每项只改了一个排版变量，哪一个最符合时间线布局原则？
- **四个中性选项（标签仅写 方案 A / B / C / D）**：
  - **方案 A**：带方向主轴与均距节奏，但 5 个节点全部同一深红，不区分已完成、进行中与未开始。（变量：缺当前进度状态层级）
  - **方案 B**（**正确答案**）：带向右方向主轴、视觉均距配清晰月份标注，并以实心/高亮/描边清晰区分已完成、「4 月内测」进行中与未开始。（兼顾方向、连续、状态与清晰刻度）
  - **方案 C**：带方向主轴与进度状态，但严格按 1–9 月像素等比排布，导致前 4 站挤在左半叠边、5–9 月间大片空洞。（变量：未做断轴处理的线性挤堆）
  - **方案 D**：区分了已完成、进行中与未开始色阶且均距排布，但抽掉了节点间的连接主轴与方向箭头。（变量：断链失去连续性）
