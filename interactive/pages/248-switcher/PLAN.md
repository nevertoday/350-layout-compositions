# 248 切换器 SWITCHER · 互动页方案

## 1. 一句话道理
切换器把「多个互斥视图」收进同一块空间里，靠「明确高亮当前项 + 下方内容即时同步」让用户随时知道自己在哪、还能去哪、点完立刻见效，不必来回跳页或记忆隐藏路径。

## 2. 开场玩具
- **玩什么**：把 248 原海报正中央的「顶部 4 格大圆角胶囊切换栏（亮黄高亮 + 向下三角尖角） + 细白圆角外框里的 4 张联动卡片」做成一块真实可玩的 2D Canvas 活体切换控制台（`data-perf-drag`）。
  - 直接在画布上**左右横拖**顶部亮黄游标滑轨（模拟移动端 Segmented Control 手指滑动切换），或直接点击切换栏选项 / 下方卡片 / 键盘 `← → Home End Enter Space` 切换视图；
  - 点击右上角原海报招牌**白色大拨动开关**，在当前视图状态下直观对比「联动开启 / 脱节冻结」；
  - 点击底部 1:1 复刻原海报的**6 枚微型状态标记**（选中 / 未选中 / 悬停 / 聚焦 / 加载中 / 完成），在主舞台当场触发该状态的真实视觉与动效演示；
  - 可在三个真实题材间切换：`原海报 · 4 项组件`、`云文档 · 视图切换`、`商品后台 · 数据维度`。
- **一打开的状态（刻意停在 0/4 坏切换器错态，绝不先给答案）**：
  1. **当前高亮失焦**：高亮色退成弱灰描边、尖角锚定关闭，选中/未选中背景亮度对比度实测仅 `1.18:1`（低于 `3.0:1`），肉眼看不出当前在哪个项；
  2. **内容脱节冻结**：顶部切项时下方内容区不同步更新（错位/冻结），违背「内容联动」；
  3. **超载双排折行**：强行塞进 8 项拆成两排，单片宽被压扁且点击上排导致空间归属断裂；
  4. **静默高延迟**：切换延迟 `1400ms` 且关闭加载中（LOADING）与焦点环（FOCUS）微状态，点完像卡死。
- **怎样算玩错、错了读数怎么说**：由 `model.js` 从当前选项数、每项实绘像素宽、行数、选中/未选中 WCAG 相对亮度对比度、当前激活索引与内容面板映射关系、响应延迟与微状态开关，单真源核算 9 类错态（高亮对比不足、缺失归属尖角/锚点、内容冻结脱节、内容错位映射、双排折行、单排过度拥挤触控区过窄、单一项无意义切换、慢响应无加载反馈、缺失键盘焦点环）。读数不报干数字，直接讲「用户眼睛和手会怎么迷路」并给下一步可操作提示。
- **接受多组合法解**：原海报 4 项信号黄即时解、2–3 项高对比深蓝反白极简解、5 项含「更多选项」溢出收敛 + 慢数据配 LOADING 与手动激活专业解，都能 4/4 通关。
- **与最近 12 页的区别**：区别于 247 侧栏拉伸、246 簇群聚散、287 三栏设置预览分界拖动、288 影音配比拖动、205 嵌套网格中缝拖动，本页没有「拖准星/挪主体/调栏宽」玩法，而是真正去**操控并修好一个有状态机、有游标滑轨、有微状态反馈、能切题材也能玩坏的活体切换器组件**。

## 3. 版式骨架
- **1440×900（2560 舒展至 1680px）**：忠实承袭 248 原海报「满幅国际克莱因电光蓝垂直控制台」骨架（绝不锁 `100svh` 避平板空洞）：
  - 极紧凑电光蓝双区刊头（左超粗白大标「切换器」+ `SWITCHER` + 三要点标 × 右上活体拨动开关大徽与原海报总述）
  - 中央全幅 2D Canvas 活体切换器舞台（内绘原海报标志性圆角胶囊切换条、向下尖角、细白圆角外框 4 张联动卡与三段信号脉动带）
  - 紧接其下：左 42% 单真源白话诊单卡 × 右 58% 原海报 `① 状态切换 / ② 当前高亮 / ③ 内容联动` 三联实况槽与精控拨片
  - 底沿通栏：1:1 复刻原海报底部细白圆角「微型状态标记」6 态活体探针带
- **1024×1366 / 768×1024**：自然纵向流排，无 100svh 空洞。
- **390×844（手机竖屏）**：压紧单行刊头并将总述移至画布下方；活体切换器等比画布稳占首屏 ≥ 46% 屏高，首屏底部直接露出诊单核心标题与首句。
- **844×390（手机横屏）**：切为左 56% 活体切换器画布 × 右 44% 紧凑刊头 + 单真源诊单与快捷按钮并行。

## 5. 节目录（01–08，每节不同交互）
- `01 三步闭环：切、亮、动`（冷白纸）：拆解原海报 ①②③ 要点，内置「响应时序脉冲示波器」实测 120ms 即时 / 600ms 加载态 / 1400ms 假死的心理落差。
- `02 六枚微状态与键盘规矩`（冷银雾纸）：真实可 Tab、可 `←/→` 操控的六态活体按键矩阵，对照 W3C WAI-ARIA 的自动激活（Automatic）vs 手动激活（Manual）与 Roving Tabindex 实况监视器。
- `03 四种形态：同一原语的不同外衣`（深钴暗室）：复刻并展开原海报 4 张卡的真实产品形态（分段控制 / 标签页 / 视图切换 / 溢出更多），切换同一份 6 条数据看空间代价与呈现差异。
- `04 同名双义：布局里的切换器`（纯白纸）：温和点破 248 编在「布局原语」小类的深层联系——演示 *Every Layout* (2019) The Switcher 的无孤行 CSS `flex-basis: calc((threshold - 100%) * 999)` 真实拉伸对比，并链接 243/246/247/250。
- `05 从索引卡到分段控件`（浅蓝图纸）：年代标尺切换器（1982 WordVision → 1980s Boeing Calc → 1995 Windows 95 → 1997 Mac OS 8 → 2007 NN/g & iOS → 2019 Every Layout & W3C APG），实时重绘各时代视觉标本。
- `06 什么时候用，什么时候别用`（柔黄警示纸）：6 个真实业务场景诊断切换卡，点选即判「适合用切换器」或「应换别的原语/组件」并链接 247/252/253。
- `07 小练习：七项怎么放进窄屏`（冷银雾纸）：A/B/C/D 四选一单变量测验（仅差「超出单排容量的组织方式」），选后给完整拆解。
- `08 原海报与关键词`（电光蓝展墙）：248 原海报可点击缩放拖拽灯箱 + 9 组中英关键词与观察札记。

## 7. 练习
- **场景**：375px 手机宽的数据看板顶部，需要容纳 7 个同级视图（总览 / 流量 / 转化 / 留存 / 收入 / 渠道 / 报障）。
- **单一变量**：其余配色、高亮、字体与面板完全相同，只改变「超过单排安全容量后的组织策略」。
- **四项中性对比**：方案 A（双排 4+3 折行）、方案 B（单排硬塞 7 项截断成单字）、方案 C（单排保留 3 项高频 + 第 4 格「更多 ▾」溢出入口且选中溢出项时显式高亮当前名）、方案 D（全部收进右上角纯图标下拉菜单）。
- **正解**：方案 C，既遵守单排不折行与 ≥44px 触控底线，又保留最高频视图的一眼可达性，完美印证原海报第 4 张卡「更多选项：展开更多可选项，保持界面简洁」的价值。
