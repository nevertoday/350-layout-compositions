三步闭环：切、亮、动

STATE · ACTIVE · RESPONSE LOOP

原海报底部画了三条最基础的机制：① 状态切换、② 当前高亮、③ 内容联动。三件事缺了任何一件，切换器都会退化成一块让人心虚的装饰条——点了没亮，以为没按到；亮了没动，以为死机了；动了没亮，回头一看忘了自己在哪。

六枚微状态与键盘规矩

MICRO-STATES & WAI-ARIA ROVING TABINDEX

只画「选中」和「未选中」两种皮肤，鼠标党勉强凑合，但键盘用户、触屏用户和弱网环境立刻露馅。W3C 的 WAI-ARIA Authoring Practices Guide 为标签切换器定下两条核心规矩：用 Roving Tabindex 让 Tab 键只落到当前激活项（再按 Tab 直接跳进内容区），并用 ← → / Home / End 在选项间游走。

布局原语里的同名切换器

THE OTHER SWITCHER · EVERY LAYOUT (2019)

补足一笔

细心的读者会发现，248 号编在「布局原语」小类里，旁边紧挨着 243 堆栈、244 盒子、245 居中器、246 簇群、247 侧栏原语 与 249 封面原语。原海报把 Switcher 讲成了「交互态切换组件」，而在前端排版经典著作 Every Layout（Heydon Pickering & Andy Bell，2019）里，同名的 The Switcher 原语指的则是另一种结构：不依赖屏幕媒体查询，当容器宽于阈值时所有子项横排并列，容器一窄过阈值就全体同步切成满宽竖叠——绝不留下「上二下一」的尴尬孤儿行。

06

什么时候用，什么时候别用

WHEN TO USE · WHEN TO WALK AWAY

切换器最迷人也最危险的地方，在于它「一次只让人看见一面」。这让它极度省空间，但也注定了它绝不能用来藏需要同时对照的信息。点选下面六个常见界面需求，检验该不该上切换器。

适合用切换器

四条稳妥边界（经验与规范汇总）

  • 单排 2–5 项：Apple HIG 与 Material Design 3 均建议移动分段切换器控制在 5 项以内（桌面宽屏最多 5–7 项），再多就收进「更多选项」或换导航。
  • 同一上下文、互斥单选：每个选项必须是同一层级、同一语境下的互斥视图，不混进「删除 / 导出」这类动作按钮。
  • 字面简洁等重：每格控制在 2–4 个汉字，尽量不要在同一个分段条里一边只放图标、另一边又放长词；需要图文混排时请参考 254 图标文字组合。
  • 绝不跨两排堆叠：一旦换行，上排高亮项会被下排切断，无法和下方内容区形成清晰视觉归属。

四种该立刻换掉的信号

  • 用户需要左右对照：把要比较的数据藏进两个标签里，等于强迫读者靠脑子背数字。直接并排展示。
  • 实质是跨站大导航：十几项一级页面跳转应交给 247 侧栏原语，而不是硬塞进顶部切换器。
  • 长列横向媒体流：如果是几十张平等卡片要滑着逛，用 252 横向卷轴；临时筛选弹层则配 253 悬浮层。
  • 前后有严格步骤依赖：表单分步填写必须有「上一步 / 下一步」与校验锁，不能让用户靠切换器乱跳。

读图笔记：这张海报自己就是一个切换器

整张海报用极高饱和度的国际克莱因电光蓝（#0031ED）做舞台底色，把「选中态」压进明快信号黄（#FFCA1C）与极净纯白卡片（#FEFEFE），把其余三张退进冷银灰（#E5E5E7）。你不用读一个字，就能在 0.3 秒内读懂「谁亮了、谁退了、尖角指着谁」。

最下方的六枚微型状态标记虽然只占一条窄带，却是新手最容易漏画、上线后最容易让产品显得「没手感」的细节——把它们全做出来，才算真正完成了切换器。
