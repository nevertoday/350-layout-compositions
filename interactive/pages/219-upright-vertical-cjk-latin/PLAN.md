# 219 直排中西文直立（UPRIGHT • VERTICAL • CJK & LATIN）设计方案

## 1. 一句话道理
直排时让西文与中文一样保持 `0°` 直立，能把中西文收束到同一根纵向视觉主轴里，避免读者反复歪头或切换阅读姿态；但这件事只有在大写等高、居中对准纵向中轴、步距均匀且词段克制时才成立，否则字母会塌成歪斜难读的垂直梯子。

## 2. 开场玩具：「立柱排字台 · Vertical Upright Pillar Typesetter」
- **载体与形态**：1:1 承袭 219 原海报的哑光鼠尾草绿纸面（`#A8B490`）开放式 2D Canvas（标 `data-perf-drag`），画面直接呈现出原海报的左括号 `[ 字面保持直立 ]`、中文直排虚线方格列、右侧直立西文列、暖奶油纵向主轴柱与底部暖奶油视觉锚点方块（`■`）；支持 **「原海报·双轨碑」「书脊·同列混排」「建筑·竖招牌」** 三套真实直立标本。
- **怎么玩**：
  - 在画布或西文列上**左右横拖**：连续推移西文的**纵向中轴偏距**（左缘硬齐锯齿 ↔ 居中铅垂轻吸附 ↔ 右缘偏漂），亲眼看窄字母 `I/L/T` 与宽字母 `W/M/O` 怎么被一根铅垂线收稳。
  - 在画布上**上下纵拖**底部奶油锚点或西文列：像拉合铅字排字架一样连续伸缩**纵向字步**（挤撞糊死 ↔ 均匀呼吸且底脚齐平锚点 ↔ 散裂断节）。
  - **直接点击**西文列切换**大小写与姿态**（小写直立 / 大写直立 / 侧转 90°），点击分隔符切换**断词方式**（无分隔连黏 / 圆点 `•` 断词 / 气口留白），调节**中西字面比**；按 **空格** 或点按钮释放暖奶油纵读视线光带，实测眼睛自上而下顺读还是卡顿跳行；键盘 `←/→` 微调中轴、`↑/↓` 调纵向字步、`C` 切姿态。
- **开场初始态（绝非答案）**：刻意停在 **0/4 四重坏态**：① 西文设为小写直立（`g/p/j/l/i` 升降部高低参差），② 左缘硬齐偏轴 `-28%`（窄字母靠左产生锯齿脊线），③ 纵向字步压到 `0.94×` 且无词间分隔（字符贴撞、单词粘成一串，尾脚远高于底部奶油锚点），④ 西文字面比例偏小失衡（`74%`）。
- **怎样算玩错 & 读数怎么说「为什么」**：`model.js` 从画布实际绘制的逐字包围盒、中心横坐标、相邻字净距与列底脚坐标**单真源**实时核算 9 类双向真错态：
  1. `sideways-90`（西文倒成 90°）：破坏直立统一感，属于 218 号「直排中西文转向」的做法；
  2. `lowercase-jagged`（小写直立）：上下伸部打破方块节奏，列边高低起伏；
  3. `axis-left` / `axis-right`（中轴左偏或右偏）：窄宽字母失去共同铅垂轴，形成锯齿；
  4. `step-crushed`（纵向挤撞）：字间净距过小导致上下粘连；
  5. `step-shattered`（纵向散裂）：步距拉得太散，单词碎成孤立字母并冲出底锚；
  6. `no-word-break`（无词间分隔）：多词连成一串难以切分语义；
  7. `scale-small` / `scale-large`（西文过小弱化或过肥撞轨）：与中文方格量级脱节；
  8. `foot-mismatch`（尾脚悬空或溢锚）：未能与中文列及底部奶油锚点形成统一竖块。
  系统认可多组合法解（原海报经典双轨解、宽气口呼吸解、紧凑碑刻解、书脊同列解、建筑招牌解），只要由实绘几何算出的 4 项维度全部达标即通过。
- **与最近 12 页的区别**：218 是暖米宣纸上的朱红圆盘旋转 90° 分度台；217 是薄荷纸上的居中穿翼横带；137/136/135 是跨页装订/杠杆/镜像；172/173 是网格/模块拼版；258/259 是侧栏/分屏 UI；303/085/048 是构图。本页以**原海报三列建筑竖碑骨架**呈现鼠尾草绿纸面上的**直立西文铅垂中轴与纵向字步排字台**，色彩、骨架、玩法、字体全部彻底区隔。

## 3. 版式骨架
- **1440×900（宽屏主宽 1380px；2560×1440 舒展至 1660px，不锁 `100svh`）**：
  忠实转译 219 原海报的「鼠尾草绿开放三列建筑竖碑」骨架（零深色通用顶栏、三列严格等高齐底、零一侧悬空大片空白）：
  - 左列 23%：原海报左上黑圆点 `●` + `NO. 219` 刊头 + 大标 `直排中西文直立` + 原海报中英总述（上）× 原海报左下 `应用要点` 四枚定制几何线框实时探针（下，齐底）；
  - 中列 49%：三标本切换签 + 开放式竖碑排字画布 + 底部紧凑双滑块与姿态控制条；
  - 右列 28%：深松墨单真源实测诊单卡（上）× 原海报右侧三枚 `[` 括号原则条（中，可点高亮联动）× 多解/双向试错按钮与右下奶油色标图例（下，齐底）。
- **1024×1366 / 768×1024（竖屏平板）**：自然流排不锁屏高：全宽精炼刊头 → 满宽等比竖碑画布与控条 → 底部双栏齐底（左：深松墨诊单卡；右：四枚几何探针 + 三括号原则与多解）。
- **390×844（手机竖屏）**：压紧单行刊头（黑圆点 + 编号 + 标题 + 实时状态徽章）+ 紧凑标本签，让等比竖碑画布稳占首屏 ≥46%，且第一屏折线内直接露出深松墨诊单首句与「一键归正」按钮；总述、控条、探针与三原则顺排其下，绝不压扁变形。
- **844×390（手机横屏）**：切为左 56% 竖碑画布 × 右 44% 紧凑刊头、深松墨诊单与快捷按钮并行。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节交互不重样）
- **01 `先看清中轴与底线`** (`CENTRAL AXIS & BASELINE`)：引原海报「基线对齐」原话并温和标「更准确地说」，讲清竖排直立靠纵向中轴收住窄宽字母、并排双列靠顶底边锚定。*交互：SVG 字格剖视切换器（左缘硬齐 / 字框居中 / 光学中轴 + 网格显隐开关）。*
- **02 `为什么必须用大写字母`** (`WHY ALL CAPS STACK`)：拆解小写升降部如何撞碎纵向节奏，以及几何无衬线与高反差衬线直立叠排的差异。*交互：大小写 × 字体风格双维矩阵 + 纵向步距游标，实时标出升降部碰撞区与步距方差。*
- **03 `从碑刻招牌到现代标准`** (`ORIGIN & STANDARDS`)：深松暗室。梳理东亚竖排书脊、竖排剧场霓虹招牌到 JIS X 4051（1993/1995/2004）、W3C JLReq（2009/2012/2020）、CLReq（2015）、Unicode UAX #50（2017）、W3C CSS Writing Modes Level 3（2019-12-10）的真实来路。*交互：年代时间轴卡片 + 真实浏览器 CSS `writing-mode: vertical-rl` & `text-orientation` 实码切换标本。*
- **04 `同列混排与双轨并置`** (`INTEGRATION PATTERNS`)：展开原海报「信息整合」，对照双轨并置与同列直立混排，并一句话链接同小类姐妹页（212–221）。*交互：真实载体切页预览（精装书脊 / 茶罐竖签 / 展厅立柱），切换双轨或同列排布并实测奶油锚点收束。*
- **05 `什么时候用，什么时候别用`** (`WHEN TO USE & AVOID`)：温和标「说多了一点」修正「一律易读」的误区，给出可落地的字数经验边界与转用 218/217 的决策线。*交互：英文词长压力测试滑杆（2 字母 `AI` → 36 字母长句），实时演示列高膨胀与逐字扫视负担（标「示意」）。*
- **06 `眼力自测：稳的那一列`** (`PRACTICE QUIZ`)：深松考场。双题单变量盲测，四选项统一中性标签 `方案 A/B/C/D`，选后显现光学铅垂线与完整原理解析。*交互：盲测四选一卡片 + 换题器 + 答案辅助线透视。*
- **07 `原海报与关键词`** (`ORIGINAL POSTER & KEYWORDS`)：鼠尾草绿原底展墙，展示 219 原海报（点击放大、拖拽平移、滚轮缩放、Esc 关闭）、原海报两大关键词「纵向主轴」「视觉锚点」与四项应用要点；底部单行页脚。

## 7. 练习设计
- **第 1 题（单一变量：纵向字步节奏）**：四个卡片完全同文（`筑 境 研 究 社` + `DESIGN • LAB`）、同大写、同居中中轴、同字号色值，仅改变西文纵向步距：`方案 A` 过挤 `0.92×`、`方案 B` 均匀 `1.38×` 且底脚齐平锚点（正确）、`方案 C` 过疏 `2.05×` 词块碎裂、`方案 D` 按横排字宽折算导致步距忽密忽疏。
- **第 2 题（单一变量：纵向横轴对准）**：四个卡片完全同文（`极 简 空 间 志` + `MINIMAL • III`）、同大写、同均匀步距，仅改变字母水平对准方式：`方案 A` 贴左轨硬齐、`方案 B` 贴右轨硬齐、`方案 C` 全部居中于同一纵向中轴（正确）、`方案 D` 宽窄交替偏摆。
- 所有标签仅写 `方案 A / B / C / D`（无任何暗示好坏的词），选后立即在四张卡片上叠出测量线并讲清唯一正确项为何胜出。
