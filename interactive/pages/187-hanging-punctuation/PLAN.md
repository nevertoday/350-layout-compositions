# 187 · 凸排标点（HANGING PUNCTUATION）互动页方案

> 所属分类：字体、网格与东亚文字 / 对齐、缩进与文字造型  
> 原海报总述：「将标点微微置于版心之外，修正视觉边界，使文本更整齐。」

---

## 1. 一句话道理

眼睛判断文字边界直不直，看的不是看不见的矩形字符框，而是**每一行真实落墨形成的视觉边界（光学墨边）**；引号、逗号、句号、连字符的墨面积远小于实心汉字或字母，若把它们死锁在版心框内，这一行就会像被啃出一角而向内塌陷；把这些轻小标点**微微推出版心线之外**，虽然字符框参差了，肉眼看到的垂直字墙却能绷成一条笔直线，中文两端齐行栏文里还能借行尾挂一个点号免去禁则推字或字距挤压。

> **对原海报的温和补充（正文 01 节以小签说明）**：187 号原海报用五行参差诗句作图解，直观亮出了左引号 `“` 悬于左虚线外，以及第四行满行「足以极视听之娱，」的逗号微探出右虚线；需要温和补充两点实操边界：① 原海报五行是参差行，只有第 4 行碰到了右边界——行尾右缘凸排真正发力的场景是 [179 两端对齐](https://layout.xiaoxiaodong.ai/179/play/) 或 [177 右对齐左参差](https://layout.xiaoxiaodong.ai/177/play/) 这类存在硬右壁的栏文，[176 左对齐右参差](https://layout.xiaoxiaodong.ai/176/play/) 本身没有笔直右墙可修；② 据 W3C《中文排版需求》（CLREQ §6.1.3），「绝大多数的中文出版物没有悬挂行尾点号的惯例」，中文里它常用于大字引语段首开引号与避免行首禁则推字/挤压的密排单点号。原海报五行诗巧融了陶弘景《答谢中书书》「山川之美，古来共谈」与王羲之《兰亭集序》「游目骋怀，足以极视听之娱，信可乐也」，本页将其留作书扉示范与 01 节剖析，开场校直台则换用真实两端齐行的《兰亭集序》栏文。

## 2. 开场玩具：活字边界校直台（Optical Margin Plumb-Line Bench）

- **单标本纯净台面（彻底去掉多标本切签与双镜头开关）**：
  - 舞台是直接铺在 `#010B17` 玄夜墨蓝底面上的**无外框 2D Canvas 书页校样**，贯穿左右两条原海报同款垂直虚线（`版心左边界` / `版心右边界`），只放**唯一一套真实两端齐行的中文栏文标本**——王羲之《兰亭集序》两段齐行栏文（`“此地有崇山峻岭，茂林修竹，又有清流激湍，映带左右。”` 与 `「是日也，天朗气清，惠风和畅。仰观宇宙之大，俯察品类之盛，所以游目骋怀，足以极视听之娱，信可乐也。」`），由 `model.js` 的**真实中文行排器**按字号实时排布：**桌面 14 字/行（6 行）、手机 10 字/行（8 行）**，栏宽由字号直接推算，令文字块稳占台面约 **60%** 宽度，两侧留出充裕外廊承载凸排标点、常驻墨边剖面与原海报圆点引线。
  - 西文凸排标本移至 **02 节**，多语种报刊栏移至 **04 节**，开场彻底不堆砌切签与开关行。
- **怎么玩**：
  1. **直接抓拖任一金黄标点跨线**：多行以 `“` / `「` 开头、以 `，` / `。` 结尾；按住台面上**任意一枚**左缘金黄开引号（`“` 或 `「`）向左拖跨 `版心左边界`，即统一设定该类左标点在全部对应行上的凸排量（百分比定义为**该标点在当前字体里的实际字宽 `advPx`**，绝不默认 `1em`）；按住**任意一枚**右缘金黄点号（`，` 或 `。`）向右拖跨 `版心右边界`，即统一设定行尾单点号在全部对应行上的凸排量。
  2. **中文真实重排（免推字 + 免挤压）**：`0%` 未凸排时，命中行首禁则的 `畅。`、`娱，`（手机端为 `湍，`）因不能落到下一行首而被迫**推字**，令该行只剩 13 字（手机 9 字）在栏内被明显拉散；当用户把右缘任一金黄点号向外拖过行排器实测拟合阈后，被推走的汉字与点号当场**回弹上行（免推字）**并挂出单点号，继续拉至实测最优值时残余微挤压彻底归零（**免挤压**），行内字距恢复自然均匀。连续双标点（`。”`、`。」`）按 CLREQ 规范永不整体挂出。
  3. **常驻墨边剖面 + 眯眼看边**：每行首字与末字的实测光学墨边折线**常驻绘制在左右两条虚线上**作为实时读数，无需开关；**长按台面空白处**或**按住空格键**触发低频光学虚化（眯眼看边），松手即恢复锐利。
  4. **键盘与触屏**：台面左右标点均配原生可聚焦 `<button>`（首枚左引号标 `data-perf-drag`），支持 `← / →`（步进 `5%`，`Shift` 细调 `1%`）、`0` 归零、`Space` 眯眼；触屏仅在紧凑标点柄锁 `touch-action: none`，台面其余区域保持 `pan-y` 不挡竖滚。
- **一打开是什么状态（绝不先给答案）**：
  - 默认停在 **`0%` 未凸排 · 框齐眼歪**：`“` 与 `「` 被死锁在 `版心左边界` 内侧，首字墨边剖面在两条引语首行明显向内凹陷；右缘 `，` 缩在 `版心右边界` 内侧且第 3 行（手机第 2 行）因避头禁则发生推字拉散，两侧常驻墨边折线与圆点引线一眼暴露真实偏差。拖近实测光学直边区间时轻轻吸附，继续拉过实测上限则进入「过度凸排 · 字墙外凸」（实字本身被拉出虚线），体悟原海报的「**微微**」二字。
- **读数说什么「为什么」（全部由 `model.js` 字形墨边实测导出）**：
  - 状态仅存 `{ leftHang, rightHang, squint }`；所有标点实际字宽 `advPx`、每行首末实字的光学墨边坐标、墨面积比、最优凸排量 `optLeft / optRight`、吸附半宽、四档定性判定阈（`框齐眼歪` / `半凸未齐` / `光学齐边` / `过度凸排`）、动态金黄圆徽标出界线长度及底部两行白话诊断，全部由 `model.js` 离屏 Canvas 像素扫描真实加载字体导出，绝无拍脑袋常量或假精确分数。
- **和最近做完的页不同在哪**：
  - 区别于 **185 悬挂缩进**（无 4 标本签 + 3 透镜外壳，且 185 动整段缩进标尺，187 直接拖单个轻标点跨虚线）；区别于 **186 首行缩进**（186 从字盘拾蓝色铅空插段首，187 不增删空白块，直接抓拉标点本身配合常驻墨边剖面与长按眯眼，并现场演示中文行尾单点号挂出后的免推字/免挤压重排）。

## 3. 版式骨架

忠实承袭 187 号原海报的**无外框玄夜书碑纵轴骨架**：

- **1440×900 桌面端（及 2560×1440 超宽屏）**：
  - 顶沿极简刊头眉（左分类，右 `NO. 187 · 视觉边界修正`）。
  - **书扉示范头（~112px）**：沿贯通向下的左界基准排出示范型大标 **`“凸排标点”`**（金黄 `“` 真挂于左虚线外，粗体「凸」字严齐左缘），右侧平齐排宽字距 `HANGING PUNCTUATION`、原海报短粗金黄横杠与原海报一句话总述——零切签、零开关条。
  - **中央无外框校直台（宽 `min(1320px, 92vw)`，2560 放宽至 `min(1680px, 84vw)`，高约 `450px`）**：左右无框敞开，栏宽按字号实排为 `14 字/行`，文字块占台面约 **60%** 宽；两条冷灰垂直虚线常驻叠绘实测墨边剖面；左右外白直接沿用原海报「`版心左边界 ──●`」「`●── 标点微微超出边界`」圆点引线承载实时 `%`（按该标点实际字宽）与实测偏移量。
  - **底沿细横线 + 动态金黄圆徽标诊断带（~112px）**：左侧实时联动原海报金黄圆徽标（圆内竖虚线 + 横向黑线出界针），右侧两行白话「为什么」诊断配 `按实测校齐` / `归零重校` 轻钮及 `长按台面或按住空格眯眼` 轻提示，最底沿横贯原海报同款细金黄正弦波浪线。
- **390×844 手机竖屏**：
  - 顶栏压紧至 ~84px（示范大标 `“凸排标点”` + 细英标 + 一句总述）。
  - 满宽 2D Canvas 校直台（`10 字/行`，8 行齐排，高约 `390px`，稳占首屏 **≥ 46% 高度**，字形等比不压扁，两侧外廊各留约 18–20% 宽承载标点拖动、常驻墨边剖面与点击区 `≥ 44×44px` 的原生按钮）。
  - 下紧贴细横线、紧凑版动态金黄圆徽标（44px）与 2 行实时诊断，一屏完整看见标题、校直台、标点拖柄与「为什么」。
- **844×390 手机横屏**：
  - 单行薄眉（~44px）；下方切紧凑左右双列——左 `63%` 满高 `~286px` 校直台（`12 字/行`），右 `37%` 排动态圆徽标、实测读数、两行诊断与校齐/归零钮，零遮挡、零横向溢出。
- **1024×1366 竖屏平板**：
  - 不锁 `min-height: 100svh`，保持上书扉 + 中校直台 + 下诊断带自然垂直衔接，无大片空带。
- **正文八节节奏**：
  - 在 **玄夜墨蓝 `#010B17`**、**深墨灰蓝 `#081628`** 与两段 **暖米宣纸 `#F2E6CA`**（03 历史考据、05 网页工程）间交替；双栏左文列配 `position: sticky` 或改为上文下全宽展台，杜绝一边先结束留空。

## 7. 小练习设计（严格单变量控制，全由 `model.js` 实测判定）

- **题目**：下面四张书评引言卡的栏宽、字体（Noto Serif SC 600）、字号、行距、文案与**右缘排版规则完全相同**，答题前隐藏参考虚线，**唯一变量是段首左引号 `“` 的凸排幅度**（分别设为该引号在当前字体中实际字宽的 `50%`、`75%`、`100%`、`125%`）。哪一版的左缘视觉边界最直？
- **四个选项（标签仅写 `A` / `B` / `C` / `D`，零暗示）**：
  - **`A`（`50%` 字宽）**：左引号只探出一半，首行首字墨边仍明显向内退缩，左上角留出缺口。
  - **`B`（`125%` 字宽）**：左引号拉出过头，把首行首字一并拽出了左边界，左上角向外凸出一截。
  - **`C`（`100%` 字宽 — 由 `model.js` 实测胜出）**：左引号完整落在左界外侧，`model.js` 像素扫描算出的首行首字左墨边与第 2–4 行首字平均左墨边偏差最小，四行首字连成一条笔直垂直墨墙。
  - **`D`（`75%` 字宽）**：接近对齐但首行首字仍比下方各行微缩四分之一格，强干扰项，需细看左缘直度才能分辨。
- **揭晓方式**：提交后四张校样同步叠上**垂直虚线 + `model.js` 实测墨边剖面折线与偏差数值（`em`）**，用真实测量结果证明 `C` 偏差最小，直观印证「差四分之一格」在墨边剖面下如何无处遁形。
