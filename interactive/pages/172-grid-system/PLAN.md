# 172 · 网格系统（GRID SYSTEM）设计方案

## 1. 一句话道理
网格不是把画面框死的铁笼，而是一套隐形的二维坐标骨架（列轨 × 水平挂线 × 栏距）；当多数元素的边缘锁在少数几条共用轴线上，眼睛不必逐块重新定位，信息立刻显得清晰、统一，又有疏密节奏。

## 2. 开场玩具（2D 网格拼版台 · 坐标对齐与挂线校准）
- **玩法**：直嵌在 172 原海报暖米展纸中央、满宽 6 列 × 2 行蓝虚线坐标蓝图内的 2D Canvas（标 `data-perf-drag`），1:1 承袭原海报的 6 枚瑞士几何与排印模块（钴蓝主视觉块、`清晰的秩序 / 高效的沟通`大标、四行正文块、朱红主圆、6×4 钴蓝点阵、二行朱红方块与配套图文块），支持「原海报·瑞士构成 / 美术馆展讯 / 期刊跨页」三套标本：
  - 直接在画布上拖移任意模块（桌面支持二维自由拖移，触屏用 `touch-action: pan-y` 保证纵向可滚动、横向拖移顺滑改写选中块列位），靠近列轨或水平挂线时弹出蓝虚线贯通对齐激光线；
  - 点选任意模块可调整其跨列数（1–3 列）或一键贴合挂线；可直接拖移中腰蓝色水平挂线（Hangline）调上下区比例；
  - 切换列数底座（4 / 6 / 8 / 12 列）、调节栏距 Gutter（0–56px）、开关「网格吸附」体会肉眼手摆与贴线吸附的手感差异、开关「透视网格骨架」检验隐藏辅助线后隐形秩序是否依然稳固。
- **开场状态（非答案态）**：刻意停在 `0/4 · 手摆失序` 坏态——吸附关闭、栏距压窄至 `4px`（粘连）、钴蓝主块向右偏离列轨 `+18px` 并压撞标题区、大标与正文左缘错牙 `+22px`、朱红圆骑缝悬空并擦碰点阵、二行红方块跌出下挂线 `+19px`。
- **怎样算玩错 / 读数怎么说**：`model.js` 从实绘每个模块的像素包围盒 `{x, y, w, h}` 与真实列轨/挂线坐标单真源核算 7 类双向错态：
  1. 模块互压重叠（`overlap > 0`）→ 提示具体哪两块压在一起、遮挡面积；
  2. 列轨脱线（最大边缘偏移 `> 4px`）→ 报出最大错牙像素值及读者视线为何左右晃动；
  3. 挂线参差（上下基线脱离水平挂线 `> 4px`）→ 解释横向扫读为何上下跌宕；
  4. 栏距过窄（`< 10px`）→ 报出粘连风险，提醒左右列串行；
  5. 栏距过宽（`> 40px`）→ 反向错态，版面被劈成孤岛、整体感散架；
  6. 均分僵化（最大/最小模块面积比 `< 1.45×`）→ 反向错态，网格沦为呆板表格；
  7. 塞满或空散（实绘墨面占比 `> 78%` 或 `< 26%`）→ 提示失去呼吸留白或过散无节奏。
  接受原海报经典 6 列解、右重反转解、8 栏精密解及任意满足全部四项秩序门槛的用户自定义排法。
- **与最近 12 页的明显区别**：
  - 不同于 134 多栏版式（绿底左台右舱、只调一维栏跨度），本页采用 172 原海报自身的**满宽蓝图画布 + 顶部右侧三关键词竖脊 + 底部三联齐底支柱带**，玩的是**二维列轨 × 水平挂线磁吸校准与透视骨架**；
  - 不同于 256/257（推拉 2–3 条固定文字栏缝）与 046（拉长宽比切嵌套框）和 171（随机散点胶带贴纸）。

## 3. 版式骨架
- **1440×900（主宽 1380px）**：严格转译 172 原海报结构——顶带左 78%（`NO. 172` 钴蓝方章 + 自示范按列轨落位的巨标 `网格系统 / GRID SYSTEM` + 原海报中英文总述）× 右 22%（原海报标志右上钴蓝方块 + 竖排右对齐三枚带蓝底线的活体关键词探针 `对齐 / 秩序 / 节奏`）→ 满宽 2D 网格拼版蓝图画布（含单行制图工具栏与外延蓝虚线角标）→ 满宽钴蓝细横线 → 底部 3 列严丝齐底支柱带（`1. 列` 单真源白话诊单、`2. 模块` 实测几何指标与选中块跨列精控、`3. 对齐` 多组合法解与反向试错）→ 底角原海报蓝三角+红半圆与 3×2 `+` 十字套准标。
- **2560×1440**：主容器舒展至 `1680px`，满宽蓝图画布与三联底带同步放大，主体充实无两侧空洞。
- **1024×1366 & 768×1024**：绝不锁 `100svh`，自然流排；画布满宽保持健康宽高比，底部三联栏在 1024 保持三列齐底、768 折排为满宽诊单 + 下排 50/50 齐底双舱。
- **390×844（竖屏手机）**：压紧单行刊头（标号、标题、状态印与三标本切换），总述与右侧关键词竖脊顺移到画布与诊单之后，使 2D 网格拼版画布稳占首屏 ≥46% 高度且比例舒展不压扁，折线内直露单行工具条、诊单首句与一键对齐按钮。
- **844×390（横屏手机）**：左 58% 画布与紧凑栏距工具条 × 右 42% 紧凑刊头、白话诊单与一键纠偏并行。

## 4. 配色与字体
- **逐像素实采自 172 原海报**：
  - 暖米档案展纸 `#FCF6ED`（主纸）、亮棉宣纸 `#FDFBF6`、冷雾列灰蓝 `#EEF1F6`（列带 `#E4E8F0` / 模块瓦 `#DCE1ED`）、暖沙纸 `#F4EDE0`；
  - 瑞士深钴蓝主色 `#0A4EC0`（浅纸安全深钴文字 `#0840A2`、蓝虚线 `#3B6AC6`、03/06 深钴蓝图暗室 `#0B1A3A` / 暗舱 `#122652` / 暗底亮蓝 `#7FB2FF`）；
  - 招牌朱陶信号红 `#E53E32` / `#D93324`（浅纸安全深红字 `#B82318`、暗底亮红 `#FF867A`）；
  - 瑞士炭墨黑 `#0C1016`（次墨 `#3D4657`），克制以蓝青松绿（`#0F6B4A` / `#5CE0A8`）标达标。
- **字体搭配（全库 0 重复，三款西文字在近 12 页 0 次使用，与 171 零西文/等宽重合）**：
  - `Noto Sans SC`（400/500/700/900）— 中文正文与瑞士厚实无衬线主标；
  - `Space Grotesk`（400/500/700）— **近 12 页 0 次使用**，几何新怪诞西文副标与界面标签；
  - `Chivo`（400/700/900 + italic）— **近 12 页 0 次使用**，锐利报刊西文标题与关键数值；
  - `DM Serif Display`（400 + italic）— **近 12 页 0 次使用**，章节大序号与史料引文点缀；
  - `IBM Plex Mono`（400/500/600）— 像素坐标、列数比例与 CSS Grid 代码。
  - 正文中文段落内的西文人名与年份保持同属 `Noto Sans SC`，避免中英混排忽大忽小。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻不重控件）
- `01` **为什么看不见的线管用** — 引原海报总述与三柱要点，用「拉幕透视对比器」左右揭开同版面的隐藏坐标轴，量化展示齐线把 11 条散乱边缘收敛成 4 条共用锚线。
- `02` **栅格解剖：五件骨架** — 交互式 SVG 蓝图解剖器（点击/键盘切换 5 层：边距、列轨、栏距、水平挂线、模块与空间区），单层高亮并同步输出对应 CSS Grid 规则与经验值提醒。
- `03` **四类网格与整除节奏**（深钴暗室） — 对比单栏、多栏、模块、层级四类网格（并一句话链接同小类 168/169/170/171/173/174/175）；控件为「列数整除拆解器 + 响应式三屏断点推演器」（4/5/6/12 列整数分割与桌面/平板/手机跨列重组）。
- `04` **从哪来：百年网格谱系** — 经核实的 1928–2017 网格演化史；控件为「年代切卡 + 动态迷你历史网格图版」，逐期呈现奇肖尔德、*Neue Grafik*、格斯特纳、维涅利 Unigrid、米勒-布罗克曼、伊拉姆与 W3C CSS Grid。
- `05` **什么时候用，什么时候别用** — 温和修正「网格等于绝对好看」的过度概括，给三类适用与三类不宜场景；控件为「守格 / 单点破格 / 全员散架」三态破格开关板，直观验证「80% 守格才衬出 20% 破格的张力」。
- `06` **小练习：挑出最稳的一版**（深钴考场） — 两道四选一纯中性标签（A/B/C/D）单变量图形考题，分别考「列轨对齐与栏距平衡」和「有节制的破格尺度」，作答后逐项解析。
- `07` **原海报与关键词** — 展示可点开缩放、拖拽、Esc 关闭的 172 原海报，完整呈现海报三大要点、三枚关键词与标语，接深钴蓝页脚。

## 7. 小练习设计
- **题 1（基础结构：对齐与栏距单变量）**：同内容同配色的 6 列展览页，A（齐线但栏距 4px 粘连）、B（齐列齐挂线 + 1.25× 行高栏距 + 右留白透气，正确）、C（栏距合理但中栏与正文错牙离轨）、D（6 块强行等宽 1:1 塞满零留白）。选项只标 A/B/C/D 与中性结构编号，不泄露好坏。
- **题 2（进阶掌控：破格的边界）**：6 列海报里哪版破格最有张力？A（全员各自偏离列轨 12px）、B（5 块锁死 6 列与中挂线，仅主红圆跨出一列破格，正确）、C（零破格且把留白全填满灰条）、D（仅红圆在列内，标题正文随机斜散）。
