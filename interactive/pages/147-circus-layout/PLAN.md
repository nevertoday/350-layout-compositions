# 147 马戏团 版式（CIRCUS LAYOUT）设计方案

## 1. 一句话道理
马戏团版式把「字号落差、反向倾角、活跃元素与留白节奏」拧成一股受控的舞台张力：先用绝对主角在 1 秒内截停路过的眼睛，再靠强弱交替的跳步节奏把人带进关键信息——热闹但绝不是无主次的乱喊。

## 2. 开场玩具：马戏团木活字排戏台（LIVE BILLBOARD PRESS）
- **玩法**：
  - 2D Canvas 活体复古马戏海报舞台（默认「大篷夜演」，可切换「周末市集」「独立音乐节」验证跨题材通用性）。
  - 底沿「字号跳跃倍率压杆」（标 `data-perf-drag`，支持触屏、鼠标拖动及键盘 `←/→`）实时拉开最大字号与最小说明字的倍率（`1.1×`–`5.8×`）；同时支持直接点选并拖动舞台上的 5 组模块（主标、燕尾蓝缎带、踩球无五官团长剪影、时间票章、说明文），微调位置与单块倾角。
  - 三组戏台控制：倾角节拍（全 0° 死直 / 同向滑坡 / 反向互锁 / 狂转难读）、聚光主次（全员抢戏 / 聚光主次 / 失色冷淡）、热闹道具密度滑条（0%–100%，控制彩旗、彩球、芒星与条纹浓度）。
  - 画布右上自带原海报同款无五官高礼帽踩球马戏团长剪影，随构图平衡度实时倾斜或稳立；可开关 ①→②→③→④ 弹簧视线跳步透视与碰撞红框。
- **开场初始状态（0 / 4 翻车态）**：
  - 停在「又平又吵的失败传单」：字号跳差仅 `1.18×`（标题与细目一样平）、全员 `0°` 死直、五块全挂高饱和底色抢戏、道具噪音开到 `92%` 压住文字且纸白留白跌破 30%。
- **怎样算玩错，错了读数怎么说**：
  - `model.js` 单真源实时检测 7 类翻车并同步更新画布红框、团长摇晃角与检票票根诊单：
    1. 平码无跳（`< 2.4×`）：像物业通知，找不到第一落点。
    2. 巨字压框（`> 4.6×` 或模块 OBB 真实撞车）：大标压死蓝缎带或票章。
    3. 死直僵硬（全 `0°`）：横平竖直像表格，缺马戏摇摆动势。
    4. 同向滑坡（主标与蓝缎带同向歪斜）：视觉重心集体溜边。
    5. 狂转难读（绝对倾角 `> 17°`）：读者要歪脖子认字。
    6. 彩屑淹字 / 过于冷清（道具压字、留白 `< 36%` 或道具 `< 18%`）：前者沦为牛皮癣噪音，后者退化成冷淡极简。
    7. 全员抢戏 / 失色冷淡：头号主角领先差 `< 10%` 导致五口齐喊，或撤掉三原色失去街头吸引力。
- **与最近 12 页的区别**：
  - 146 拖正交黑纸带蘸色、191 捏贝塞尔路径、229 拖多栏报宽、273 遥测时间轴仪表盘、106 径向清场、061 引力成簇、312 片场机位环轨、145 粗黑分镜隔板、228 CSS Subgrid 穿轨、023 高速斜轨罗盘、190 图形诗山坡、105 双联中缝天平——本页专攻马戏团独有的「字号跳差压杆 × 反向倾角咬合 × 道具噪音呼吸 × 聚光争抢 × 无五官踩球团长平衡」，无法套用到其他编号。

## 3. 版式骨架
- **整体气质**：忠实承袭 147 原海报的大篷红白放射顶幔、斜挂三色三角彩旗、红黑跳色斜扬示范大标、斜贯深蓝燕尾缎带、波浪蓝檐与复古马戏检票撕口票根骨架，不锁 `100svh`，彻底摒弃深色仪表盘卡模板。
- **1440×900（2560 扩至 1840px）**：极细顶眉下，主首屏按 42 : 58 戏院海报双区排开，中缝作复古检票齿孔撕线——左 42% 放跳色示范大标、斜蓝燕尾缎带、检票票根诊单与原海报同款 4 枚红蓝黄蓝实心圆徽；右 58% 铺满带大篷顶幔的 4:3 活体木活字排戏台与一体底沿字号跳跃压杆、三组戏台控件。
- **1024×1366 / 768×1024**：顶区左右紧凑排招牌与票根四徽，下区满幅展开活体排戏台，无空洞。
- **390×844 竖屏**：压紧单行跳色马戏招牌与检票章，紧接等比 4:3 活体排戏台画布 + 字号跳跃压杆，稳占首屏 ≥45% 屏高且同屏可见诊单摘要与主控按钮；说明与四徽顺接下方。
- **844×390 横屏**：切换为左 54% 活体排戏台 + 压缩跳跃压杆，右 46% 招牌诊单与三组拨键并行。

## 4. 配色和字体
- **实采自 147 原海报色板**：
  - 暖奶油海报纸 `#FDF2DC`（亮象牙 `#FFFBF2`、淡奶油金 `#F8EAC8`、复古宣纸 `#F5E9D0`）
  - 帐篷朱红 `#DA3515`（浅底可读深红 `#A62208` / 暗底亮珊瑚 `#FF6E4E`）
  - 戏台钴蓝 `#004EAE`（深蓝 `#003880` / 03 节夜篷深蓝暗版 `#0A2452` / 暗底亮天蓝 `#7AC0FF`）
  - 聚光金黄 `#FBC314`（浅底可读深琥珀 `#875500` / 暗底明金 `#FFD33D`）
  - 礼帽墨黑 `#0D0C10`
- **字体搭配（全库唯一，4 款在最近 12 页零使用）**：
  - `zcool-kuaile`（站酷快乐体，全库首次使用，仅用于已检字形的展示招牌大字）
  - `anton`（最近 12 页零使用，19 世纪窄粗木活字风格英文大标与蓝缎带字）
  - `young-serif`（最近 12 页零使用，复古马戏粗衬线英文副标与节序）
  - `dm-mono`（最近 12 页零使用，票根编号与实时倍率读数）
  - `noto-sans-sc`（400 / 700 / 900，清晰正文与展示字兜底，中文段落内西文年份/人名一律跟随正文同字体不跳动）

## 5. 节目录（01–07）
- `01` **字号跳三阶，眼先有落点**（`SCALE JUMP & ENTRY POINT`）— 讲清字号跳差如何建立街头第一落点，温和补充「夸张对比」的前提；交互：**街头海报墙 1.5 秒眨眼测验 + 三档字号标尺热区**。
- `02` **热闹与凌乱，只差一条红线**（`LIVELY VS. CLUTTERED`）— 拆解「受控无序」的三道护栏（主角权重、纸白气口、三色上限）；交互：**戏院幕布左右掀幕解剖镜 + 隐形骨架透视开关**。
- `03` **暗篷拆四柱：跃、夸、拍、吸**（`FOUR PILLARS IN THE RING`）— 深蓝夜篷暗版，逐一白话拆解原海报四枚彩圆图标；交互：**四柱舞台聚光点检台**（点击四徽标切换聚光图层与鼓点/磁力线解析）。
- `04` **从木活字大海报到教材定名**（`FROM WOOD TYPE TO TEXTBOOKS`）— 核实历史脉络（1827 Darius Wells 铣刀、1834 Leavenworth 缩放仪、1895 Strobridge 彩石印马戏海报、1890s 报刊 circus makeup、1967 Roy Paul Nelson 教材定名、1969 Rob Roy Kelly 专著）；交互：**木活字年代抽屉标本集**。
- `05` **什么时候进篷，什么时候绕道**（`WHEN TO USE — AND AVOID`）— 明确适用与禁忌，温和标注「传播力看场合」；交互：**6 张真实委托单快检器**（逐张判用/绕道，并一句链向更合适的同族编号）。
- `06` **考眼力：哪张海报没演砸？**（`SPOT THE WORKING CIRCUS`）— 盲选小练习；交互：**四张微型矢量海报单变量对比盲选**（A/B/C/D 中性标签）。
- `07` **原海报与同小类十二邻**（`ORIGINAL POSTER & SIBLINGS`）— 展示 147 原海报（可放大、拖动、Esc 收起）、原海报四关键词与同小类其他 12 页的一句话外链。

## 7. 练习设计
- **题目**：同一份「夏日复古游园会」活动文案，排成 4 张马戏团海报（方案 A / B / C / D），只改了一个版面变量，哪一张真正成立？
- **四项唯一变量差异**（配色、图标、文案完全一致）：
  - **方案 A**：字号跳差压缩到 `1.25×`（头标、副标、日期几乎同大，失去入口）。
  - **方案 B**：装饰星屑与彩球塞满画布并压字，奶油纸白跌至 21%（噪音吞字）。
  - **方案 C（正确）**：`3.4×` 跳跃字号 + `-6°/+4°` 反向咬合倾角 + 单主次焦 + 45% 纸白呼吸。
  - **方案 D**：四块核心文字同向 `+16°` 过度右斜，视觉重心集体溜向右下角且难读。
- **理由**：选定后展开每张海报的唯一失衡变量，印证马戏团版式靠的是「可控的落差与互锁」，不是越满越斜。
