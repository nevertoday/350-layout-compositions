# 340 仅标题 幻灯片版式 · 页面方案

## 1. 一句话道理
演示时屏幕与演讲者共用观众的语言工作记忆；拆掉副标、要点、装饰与页脚，把画面留给一句有分量的大标题和大片呼吸留白，才能让观众一眼锁住主题，然后立刻抬头听人讲。

## 2. 开场玩具
- **命名与定位**：「削字上屏台 · 3 秒投影实测」（Title-Only Subtraction & Projection Deck，2D Canvas 标 `data-perf-drag`）。1:1 承袭 340 原海报冷白画廊纸面 `#F3F2EF`、墨黑大标 `#070908` 与瑞士信号朱红 `#D6322B` 45° 斜引线、圆点与短横杠。
- **开场初始态（绝非答案）**：打开时停在 `0/4` 的典型「伪仅标题」臃肿会议页——32 字公文长标题（22px 怯弱字阶）外加 4 块冗余附着物（副标解释、三条要点、装饰图徽、底部页脚），实测留白仅约 36%，3 秒上屏模拟在后排直接读不完。
- **怎么玩**：
  1. **直接点击画布上的 4 块冗余元素**（副标 / 要点 / 配图 / 页脚），像贴纸一样将其逐一剥离到「归口述区（交还演讲者口播）」；点托盘可随时贴回对照变差过程。
  2. **横向拖动投影台（`data-perf-drag`）**，像拉动版式字阶标尺一样连续缩放标题字号（18px–112px），实时观察留白比例、边距安全带与原海报红斜线气场的变化。
  3. **点击画布标题块（或点选提纯阶）**，在 4 档文案间切换：`32字公文长句` → `18字解释句` → `8字核心主张` → `2字空洞口号（反例）`。
  4. **切换构图轴线**（原海报左齐非对称 / 光学居中 / 高桥冲屏 / 贴边反例）与 3 套演讲剧本（原海报宣言 / 产品发布 / 复盘破局）。
  5. **按 `Space` 或点「3 秒上屏实测」**：调暗场灯进行 3.0 秒倒计时后排 15m 清晰度实测，直观检验哪些字被瞬间抓住、哪些字根本读不完。
- **怎样算玩错 & 读数如何讲「为什么」**：由 `model.js` 从实际渲染的标题分行包围盒、冗余块面积与画框边距单真源核算，双向检出 7 类错态：
  1. 冗余未清空（违反梅耶冗余原则，观众低头读字不听讲）；
  2. 标题过长超 14 字或折成 3 行以上（变成微缩段落，3 秒扫不完）；
  3. 文案削过头成 2 字空洞口号（极简退化成没信息量的标语）；
  4. 字号怯弱（占空过轻，在空旷画布上像漏排、后排看不清）；
  5. 字号爆框挤死留白（留白低于 58% 或距边不足 7%，呼吸感变压迫且投影易裁边）；
  6. 标题贴边失衡（偏离光学重心、破坏安静场域）；
  7. 叠加复杂底纹（背景噪声破坏字底对比）。
  同时认可多组合法解：原海报左齐非对称解、光学居中宣言解、高桥流极限短句解，以及任意自定义达标状态。
- **与最近 12 页的差异**：摒弃近期高频出现的「4 滑块队列 + 底部深色诊单仪表盒」结构；玩法是演示文稿独有的**冗余逐项剥离 + 文案四阶提纯 + 横拖字阶标尺 + 3 秒暗场投影实测**，别的编号无法照搬。

## 3. 版式骨架
忠实转译 340 原海报「瑞士美术馆展页」骨架（绝不锁 `100svh`，避免平板大片空洞）：
- **1440×900 / 2560×1440**：顶沿原海报双角微标栏（左 `340 · 版式原则 / —`，右 `让标题独自发声 / +`）→ 非对称双栏展页（左 32% 原海报级自示范大标 `仅标题 / 幻灯片版式` + 动态 45° 红圆斜线 + 短红杠 + 白纸细红左线单真源诊单 + 底部四竖线关键词实时探针，右 68% 开放式 16:9 投影舞台与紧贴式单行剥离/提纯操控坞），左右严格齐底且一屏尽览。1440 主宽 1380px，2560 舒展至 1680px。
- **1024×1366 / 768×1024（平板竖屏）**：自然流折排，顶沿刊头 + 满宽 16:9 投影舞台 + 齐底双联白纸诊单与四竖线探针，零垂直空洞。
- **390×844（手机竖屏）**：首屏压紧单行刊头（`340 仅标题 幻灯片版式` + 状态徽章），总述与四竖线后置；画布采用 1:0.96 复合竖屏比例（上部严格等比 16:9 幻灯片绝不压扁，下部嵌归口述托盘与 3 秒读条），稳占首屏 ≥46% 高度，折线内直露诊单首句与一键削字/3 秒上屏按钮。
- **844×390（手机横屏）**：左 58% 投影舞台 × 右 42% 紧凑刊头、白话诊单与核心按钮并行。

## 4. 配色和字体
- **配色（逐像素采自 `340.webp`）**：
  - 美术馆冷米白主纸 `#F3F2EF`（亮宣 `#FAF9F6`、温石展纸 `#EFECE7`、灰白展纸 `#EAE8E3`）
  - 极深墨黑 `#070908`（正文主墨 `#161817`、次墨 `#52504D`、发丝竖线 `#C6C3BC`；02 与 06 演讲厅暗室 `#0B0D0C`、暗舱 `#151816`、页脚 `#090B0A`）
  - 瑞士信号朱红 `#D6322B`（图形红圆、45° 斜引线、短横杠、焦点印记；浅底小字安全红 `#B2231D` 对比度 >5.5；暗底亮朱红 `#FF635B` 对比度 >6.4）
  - 达标辅色克制用冷松墨 `#146652`（浅底）/ `#5AD1B0`（暗底）
- **字体搭配（全库 0 重复，与 339 西文等宽 0 重合，其中 3 款在近 12 页全部 0 次使用）**：
  - `noto-sans-sc`（400, 600, 900）— 原海报级极重黑体大标与纯净中文正文
  - `chivo`（400, 700, 900）— **近 12 页 0 次使用**，利落新怪诞无衬线，担纲 `TITLE-ONLY LAYOUT` 及英文标牌
  - `space-grotesk`（400, 600, 700）— **近 12 页 0 次使用**，几何展陈无衬线，担纲大数字与节标英文
  - `ibm-plex-mono`（400, 500, 600）— **近 12 页 0 次使用**，瑞士索引编号、坐标刻度与单真源实测读数

## 5. 节目录
- **01 为什么少字反而更响** (`COGNITIVE FOCUS`)：拆解海报原话与梅耶一致性/冗余原则；交互：**口播与屏幕双通道同步演播器**（对比满屏要点 vs 仅标题口播时的视觉/听觉通道冲突波形）。
- **02 留白与字阶的临界线** (`SCALE & BREATHING ROOM`，暗室)：温和修正海报「留白有力」（标「说多了一点」），剖析字太小怯场与字太大压死呼吸的双向区间；交互：**后排 3m–18m 视距清晰度检验仪 + 字阶/留白二维坐标图**。
- **03 从高桥流到标准母版** (`WHERE IT CAME FROM`)：讲清 2001 高桥流、2003 塔夫特反符号批评、2006 OOXML `titleOnly` 与 2008 禅意演示脉络；交互：**四帧历史胶片标本切换带**（点击展开对应微缩结构图）。
- **04 一句话压住全场四式** (`FOUR COMPOSITIONS`)：对比左齐非对称、光学居中、高桥冲屏、压底留天四种仅标题实战排法，并一句话链接 335/337/341；交互：**四格联动活体构图墙**（选句或改句，四块 16:9 展板实时重排并标出视觉重心）。
- **05 什么时候用，什么时候别用** (`WHEN TO USE & AVOID`)：区分高能演讲转折与无口播自读报告/数据论证，一句话链接 336/338/339/342/343；交互：**6 场景职场分诊翻牌台**。
- **06 练手：哪一页能撑起转折** (`PRACTICE`，暗室)：两道单变量盲测练习题（选完才揭晓测量标尺与理由）。
- **07 原海报与关键词** (`ORIGINAL POSTER`)：原海报灯箱（放大、拖动 `draggable="false"`、Esc 关闭）+ 四竖线关键词点击对应原海报视觉构架。

## 7. 练习设计
- **第 1 题（严格单变量：字阶与留白占比）**：同一句 11 字发布会转折结论「今年起，所有产品默认离线」，全部零冗余、同一左齐骨架、同一配色，仅标中性标签「方案 A / B / C / D」：
  - A：22px 偏小字号，留白约 90%（气场怯弱，后排吃力）
  - B：58px 两行舒展，留白约 72%，安全边距 10%（**正确**：兼具一眼压场的体量与从容留白）
  - C：94px 巨字撑近画框，留白约 44%，边距仅 3%（压迫且有投影裁边风险）
  - D：32px 单行偏细，留白约 84%（干净但缺乏全场转折重量）
- **第 2 题（严格单变量：标题信息提纯度）**：同一场演讲转折、同一左齐与 70% 左右呼吸布局，仅标「方案 A / B / C / D」，对比 28 字公文句 / 17 字带条件从句 / 8 字明确主张（**正确**）/ 2 字空洞口号。
