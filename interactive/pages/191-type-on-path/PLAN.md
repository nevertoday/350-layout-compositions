# 191 路径文字 · Type on Path 方案

## 1. 一句话道理
文字沿着平滑连续的曲线基线旋转排列时，每个字的切线方向首尾相接，利用格式塔良好延续性把一串字符织成自带速度与去向的视觉动线；但曲线同时会按曲率半径 $R$ 改变字顶弧长（外凸撑松、内凹挤撞），所以路径文字成败的关键是在「动势弯度」与「曲率安全带、顺读朝向、字距补偿」之间取得平衡。

## 2. 开场玩具
- **名字**：活体贝塞尔路径排字台（2D Canvas 开放竹纸舞台 + 原海报同款 S 形深黛绿曲线轨 + 双控制柄与朱橘起点圆）
- **玩法**：
  - 直接在画布上拖拉两个贝塞尔曲率手柄（P1、P2）任意弯折或拉直整条 S 轨；
  - 拖拉左下朱橘大圆点滑动文字沿轨起点；
  - 拖拉底沿原海报同款朱橘箭头式「弯曲幅度」拨珠（标 `data-perf-drag`，同步缩放 S 弯张力）与「字距松紧」轨；
  - 切换 3 种路型（原海报 S 曲流 / 圆徽双弧 / 波浪丝带）、切换「外侧 / 翻到内侧」、开关「法线扇形透视」、支持键盘选中控制点微调及复原错态。
- **开场状态（非答案）**：故意停在 `0 / 4` 的「急弯撞字 · 陡坡失衡」错态——S 轨中段拧成险峻折弯，最小曲率半径过小导致拐点内弯发生真实字符 OBB 重叠（标红碰撞框），局部切线倾角超 65° 甚至倒挂，且起点偏后让句末冲出箭头截断。
- **怎样算玩错、读数怎么说**：
  - 所有读数由 `model.js` 单一弧长采样 + 旋转包围盒 SAT 碰撞引擎实算，绝无假精确常量：
    1. **内弯撞字**：相邻字符 OBB 重叠 > 0 处 → 红框标出相撞字对，说明曲率半径小于字高 2.2 倍时内凹弧长短于字宽，字顶必然互啃。
    2. **退化直线**：用户若把曲率拉成接近 0 的平直线 → 报错「退化为平排直线」，说明没有有效弯曲就失去了路径引导与运动感。
    3. **倒挂/过陡**：任意字符切线倾角超 90°（倒立）或超 58°（歪头吃力）→ 标出倒挂字，说明路径局部折返打断了从左到右的顺读习惯。
    4. **出轨/挤缩**：末字溢出箭头或整句挤缩不到路径 62% → 提示拖动橙色起点圆或放宽字距让整句落满主弧段。
- **与最近 12 页的区别**：
  - 190（图形诗）是满幅姜黄纸上调水平诗行的阶梯坡角与落日位置；189（形状文字）是在薄荷绿水滴壳内逐行水平灌字；105/060/311/272/144/104/227/022/271/059 分别是双联天平、瀑布叠卡、平面调度、便当盒、框线、动静九宫、网格蓝图、移轴立面、瀑布流与叠纸景箱。191 是唯一让用户**亲手捏塑贝塞尔曲线、看着单字沿切线实时旋转并用几何 SAT 碰撞与法线扇形检验曲率可读性**的路径排字台。

## 3. 版式骨架
忠实承袭 191 原海报的「淡竹宣纸开放通幅双翼骨架」（零深色仪表盘卡感、不锁 `100svh`）：
- **1440×900（2560 扩宽至 1840px）**：极细单行顶眉下，左翼 33% 呈原海报左对齐排版（微弧示范大标「路径文字」、`TYPE ON PATH`、朱橘短横杠、总述、灰绿细线、五关键词与轻量路型开关），右翼 67% 直接在竹纸底铺开无框大画布（含原海报左灰绿半圆弧+4×4 点阵、右下朱橘半圆弧+7 竖线、活体 S 轨），底沿接朱橘细箭头拨珠轨与右下原海报同款「基线方向 →」活体诊断签。
- **1024×1366 / 768×1024**：自然纵落不留空洞，上标题、中大画布、下拨珠轨与四项实测体检。
- **390×844**：压紧单行顶眉与紧凑弧形标题，说明文移到画布下方；等比大画布稳占首屏 ≥ 46% 屏高，同屏露出「弯曲幅度」朱橘拨珠轨、四枚紧凑达标灯与一句话白话诊断。
- **844×390（横屏）**：切左 56% 等比 S 轨画布 × 右 44% 标题、拨珠轨与诊断并行。

## 5. 节目录
- **01 基线弯了，字怎么转**（纯暖竹白）：展开原海报「基线方向」要点；交互为「法线扇形放大镜」（切换直排/外凸/内凹/急弯与基线对齐位置，直观观察外弧撑松与内弧撞字，并温和剖析原海报 S 弯拐点碰字实例）。
- **02 从古币铭文到矢量路径**（浅豆绿纸）：梳理可查实的历史脉络（古希腊罗马硬币环铭 → 1796 塞内费尔德石版印刷与 1818《石版印刷全书》→ 1962/1975 伊姆霍夫地图注记准则 → 1988 FreeHand / 1990 Illustrator 3.0 与 2001 SVG 1.0 `<textPath>`）；交互为「四时代路径标本拨盘」。
- **03 圆徽下弧，为什么会倒立**（深孔雀松黛暗版）：拆解圆形徽章最常见的倒字与双环错位陷阱；交互为「双轨圆徽翻面器」（一键对比单圆倒字 vs 拆轨反向 + 基线偏移 + 字距补偿）。
- **04 弯曲，是在画一条视线**（淡竹宣纸白）：讲清路径文字与 [189 形状文字](https://layout.xiaoxiaodong.ai/189/play/)、[190 图形诗排版](https://layout.xiaoxiaodong.ai/190/play/)、[182 轮廓绕排](https://layout.xiaoxiaodong.ai/182/play/)、[192 垂直文字排版](https://layout.xiaoxiaodong.ai/192/play/) 的分工；交互为「动势轨迹扫视台」（4 种应用场景，播放朱橘光点沿基线扫视对比直排与路径排的视流牵引）。
- **05 什么时候别用路径文字**（纯暖竹白）：明确长正文、数据界面、小字锯齿与紧弯汉字四大禁区（链接至 [176 左对齐右参差](https://layout.xiaoxiaodong.ai/176/play/) 与 [193 水平文字排版](https://layout.xiaoxiaodong.ai/193/play/)）；交互为「三场景可读负荷对比切换」。
- **06 练一练：四枚圆章，哪枚最顺读**（浅豆绿纸）：A/B/C/D 中性四选一实战题，选完显出同心圆辅助环、方向箭头与字距碰撞标记并给出理由。
- **07 原海报与关键词**（淡竹宣纸白）：可点击放大/拖拽/Esc 关闭的 191 原海报，以及「曲线 / 引导 / 运动 / 节奏 / 路径」五枚关键词卡片。

## 7. 练习
- **题目**：同一枚 80mm 咖啡豆圆标（上弧「山谷烘焙工坊」，下弧「ROASTERY 2026」），四版只差一个关键处理，选出最顺读、最工整的一枚。
- **四个选项（标签仅标 A / B / C / D）**：
  - **A**：单条闭圆连续绕排，下弧英文倒立（头朝下）。
  - **B**：上下拆轨均正向可读，但下弧未做基线外移，导致下弧悬在圆环内侧、上下视觉半径不重合。
  - **C（正确）**：上下拆轨正向可读，下弧基线外移对齐同一中轴环带，且对内凹下弧适度放宽字距，松紧平衡。
  - **D**：上下拆轨且环带对齐，但下弧未作字距补偿反而紧排，内凹处字符顶部拥挤发黑。
