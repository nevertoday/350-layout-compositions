# 070 一点透视 ONE-POINT PERSPECTIVE · 制作方案

## 1. 一句话道理
当被观察空间有一组正面严格平行于画框时，横线守水平、竖线守垂直，唯有垂直于画面的纵深平行线全部收束进视平线上唯一的消失点——眼睛会顺着这套无分叉的几何漏斗，被自然而然地吸向画面的视觉中心。

## 2. 开场玩具
- **怎么玩**：1:1 化用 070 原海报「包豪斯朱赤红斜墙 × 奶白建筑长廊」的活体廊道校准台（真实 3D 针孔投影数学 `model.js` 单真源驱动 2D Canvas 矢量精绘，可切换「原海报长廊 / 教堂餐室 / 地铁站厅」三套空间）。
  - **核心手势（与最近 12 页全部不同）**：直接点选并横向拖拽长廊中三件脱靶的建筑构件（① 左侧落地长凳、② 右侧朱红高门、③ 走廊前景展台），像拿着直尺把歪斜的透视延长红虚线一根根扳回尽头的唯一消失点（画布本体标 `data-perf-drag`，横拖流畅实时改变当前选中错构件的纵深收束偏角并在接近 0° 时轻吸附；若三件全齐，横拖无缝切为调整观者在廊道中的水平站位，保证每一帧交互都在真实改数重画）。
  - **联动验证**：同时支持上下/左右移动走廊尽头的消失点（改变视平线高度与左右站位），观察**已对齐构件会随新消失点自动联动成立，未对齐构件继续脱靶穿帮**；并可点击下方纯黑原理带四格（单一消失点 / 视线焦点 / 空间纵深 / 线条汇聚）高亮对应的透视检验线层。
- **一打开是什么状态**：刻意停在 **0/3 错构未齐态**（忠实映射原海报右下「常见错误」三条）：
  1. 左侧落地长凳纵深棱线向上漂移 +14°（线条未汇聚到同一消失点）；
  2. 右侧朱红高门收束进偏低 18% 的错视平线（视平线位置混乱）；
  3. 前景展台水平偏转 +20° 且竖边微斜（物体透视方向不一致）。
- **怎样算玩错、错了读数怎么说**：用户把任意构件扳偏超过容差（> 2.5°）、或用压测按钮触发「双视平线分裂」「反透视倒张」「前景倒缩」「灭点出界」，单真源 `model.js` 实时判出 **7 类具体错态**（多点分叉、视平分裂、构件偏航、反透视倒张、前景失重、灭点逼边、单构未齐），诊单用白话说明人眼此刻看到的错觉（如「长凳的顶面看起来像一块翘起的斜坡，跟地面粘不到一块」「红门像整扇往下滑坠」），并指明具体修正方向。全部三件归位后，居中对称解、高视平线俯视解、低视平线仰视解、偏心走道解均记为有效成立解。
- **与最近 12 页的区别**：069 是室外混凝土广场拖红蓝灭点、073 是移轴转头看匾额梯形、072 是 3D 高楼俯仰仪、031 是双楔剪刀开合、238 是固定宽浏览器压测；070 独创「包豪斯廊道逐构件透视射线扳正 + 视平联动检验」，换到任何其他编号都无法套用。

## 3. 版式骨架
- 忠实承袭 070 原海报「斜切朱赤红左墙刊头直接咬合长廊 × 通栏纯黑四柱核心原理带 × 暖米白下方建造与纠错」的包豪斯海报一体化骨架，零通用圆角仪表盘侧栏，不锁 `100svh`。
- **1440×900（及 2560×1440）**：30px 极细工程顶眉下，主框宽 1380px（2560 舒展至 1840px）。首屏上部左 31% 为斜切进入右侧画布的招牌朱赤红刊头壁（黑体大标「一点 / 透视」自带微收束红虚线自示范 + 副标 + 紧贴底部的暖米白单真源白话诊单卡），右 69% 为全幅建筑长廊 2D Canvas 主舞台；紧接下沿铺开原海报标志「纯黑四柱原理实况横带（4 枚朱红线框图标 + 实时状态读数）」及紧凑的暖米白三构件微调轨。
- **1024×1366 / 768×1024（平板）**：自然流式不留空洞——顶部紧凑双栏朱红刊头与诊单 → 全宽 16:10 长廊主舞台 → 2×2 纯黑原理实况格与控条。
- **390×844（手机竖屏）**：单行极紧朱红刊头条（≤ 60px）→ 4:3 等比全宽长廊主舞台（圆点与几何比例严格等比不压扁，首屏占 ≥ 46% 屏高）→ 紧贴下沿同见单真源诊单首句与三构件快修按钮。
- **844×390（手机横屏）**：左 58% 长廊主舞台全高铺开 × 右 42% 竖排紧凑朱红刊头、白话诊单与三构件按钮并行。

## 4. 配色和字体
- **配色（逐像素实采自 `site/public/p/070.webp`）**：
  - 招牌朱赤红：`#E54616`（左斜墙、右门、消失点、底脚斜纹与色带）；浅纸高对比文字用压深赤陶 `#B82E08`；黑底亮朱橘 `#FF6B3D`。
  - 暖米纸基调：`#F2EBE2`（海报暖米纸）、`#FAF6F0`（洁亮稿纸）、`#DDD9D3`（原海报常见错误灰盒）、`#E8DFD3`（浅砂隔段纸）。
  - 纯黑结构块：`#070908`（原海报纯黑原理横带 / 03 节暗室）、`#0F0F0F`（天花黑板与标题墨）、主墨 `#141413`、次墨 `#4A453F`。

- **字体（全库唯一，与 069/072/073 零西文重合，Big Shoulders 与 Cormorant Garamond 在近 12 页全部 0 次使用）**：
  - `Noto Sans SC`（400, 500, 700, 900）：厚黑标题与中文正文（正文西文人名/年份统一跟正文无衬线，不跳字）。
  - `Big Shoulders`（700, 900，**近 12 页未用**）：芝加哥建筑招牌式窄高硬朗展示体，用于英文建筑大标、节号与工程小标。
  - `Space Mono`（400, 700）：坐标、偏角与视平线百分比等宽读数。
  - `Cormorant Garamond`（600 正/斜体，**近 12 页未用**）：文艺复兴历史典籍名与作者注斜体点缀。

## 5. 节目录（7 大节，每节标题 ≤ 12 字，相邻节不复用控件）
- **01 哪条线才汇聚**（`WHICH LINES CONVERGE`）：温和勘误原海报「与视平线平行」措辞，厘清 X 水平 / Y 垂直 / Z 纵深三组线；交互：三线组独立点亮按钮 + 「微转 20° 破正交」对照图（一句话链向 071 / 073）。
- **02 五步起一座廊道**（`FIVE-STEP BUILDER`）：1:1 活化原海报「构成步骤」五步并补足距点定砖法；交互：5 步绘图仪步进器 + 分步自动绘线播放画布。
- **03 视点与前景杠杆**（`EYE LEVEL & FOREGROUND` · 纯黑暗室节）：验证原海报「实用小贴士」三条（对称/偏心、俯仰视平、前景放大）；交互：二维走廊截面观者站位拖动板 + 前景框深度切档 + 实时人物背影剪影与天花/地面面积条（链向 066 / 068）。
- **04 三种错法怎么破**（`THREE CLASSIC BREAKS`）：对应原海报「常见错误」灰盒逐条剖析；交互：三张建筑实景卡配备「红线照妖镜 / 一键校直」双态对照开关。
- **05 从礼拜堂到走廊镜头**（`FROM FLORENCE TO CINEMA`）：梳理单消失点从文艺复兴祭坛锁定主角到现代电影长廊压迫的谱系；交互：年代档案卡切签联动矢量构图几何线框。
- **06 何时用与何时别用**（`WHEN TO USE & WHEN NOT`）：讲清一点透视的适用边界与反例；交互：4 项设计任务场景单选决策卡，输出选型建议与同小类（065–076）直达链接。
- **07 眼力小测与原海报**（`EYE CHECK & POSTER`）：四选一隐蔽单变量透视找错题 + 原海报可放大拖拽灯箱与核心关键词。

## 7. 练习
- **题目**：同一座美术馆正门直通主展墙的一点透视平视草图，四张候选稿只差一个不易察觉的几何细节，挑出唯一透视严格成立的一张。
- **四个选项（中性标签 方案 A / B / C / D，只差一个变量）**：
  - 方案 A：左侧壁挂画框的上沿纵深线偏离唯一消失点 +6°（微幅脱靶）。
  - 方案 B：墙、门、壁挂、天窗全部精准收敛到唯一消失点，且地砖横缝遵循真实 1/z 递减压缩（**正确答案**）。
  - 方案 C：墙面与画框收束正确，但地砖横缝按均匀等距平分（丢失透视进深压缩）。
  - 方案 D：墙面与地砖收束正确，但右侧独立展台以偏转 18° 的斜向绘制，与房间正交方向不一致。
- **理由反馈**：选定后四张图同步叠加红色透视检验辅助线，直观揭示每张错稿唯一的破绽所在与正确稿的几何闭环。
