# 109 节奏组织（RHYTHMIC ORGANIZATION）页面方案

## 1. 一句话道理
节奏不是机械平铺，也不是随手乱摆，而是**在有序重复的骨架里，通过间隔的疏密收放控制视线快慢，再用克制的重音拉出阅读主次**，让眼睛有进、有快、有停、不断线。

## 2. 开场玩具：全幅 16 拍斜轴活体视觉乐谱（Full-Width Diagonal Acoustic Sequencer）
- **玩法**：直接化用 109 号原海报标志性的左下→右上 30° 上升电光钴蓝竖柱与冰青圆点脉冲带，横贯整幅曜黑画幅（无仪表盘外框）：
  - **画布直操**：鼠标悬停显示拍位高亮，点击任意竖柱循环切换「中 → 重音 → 弱 → 休止」，鼠标在竖柱上按住上下拖动可直接雕塑柱高（休止 0 / 弱拍 1 / 中拍 2 / 重音 3），触屏保持 `touch-action: pan-y` 顺滑滚屏；支持左右方向键选拍、上下键改强弱、空格启停视线扫拍光标。
  - **底沿全宽间隔张力调速轨（`data-perf-drag`）**：横向推拉连续调节间隔疏密跨比（`1.00×` 等距节拍器 → `1.45×–3.15×` 疏密呼吸带 → `4.0×+` 断层撕裂），画布上的光学视线光标同步按实际间距加速/停顿，右下角开放黑三角区实时重写原海报同款「`疏 → 密 → 疏 → 强`」节拍谱句与微缩珠链。
  - **原海报双钴蓝框原理舱**：底部三栏将白话诊单与原海报标志性的两枚钴蓝框（「重音塑造层次」「间隔决定节奏速度」）拆开落地，每枚框内嵌与当前状态实时联动的原海报同款微缩 SVG 图示（柱列重音图 & 渐变圆点速度箭），按钮精简无冗余（不设一键通关作弊钮）。
- **开场初始态（0/4 错态，绝非答案）**：16 根柱全锁在中拍平高（重音高差 `1.00×`，0 处重音）、间隔张力停在 `1.00×` 机械等距，画面呈一排死板等高的栅栏，视线速度毫无起伏。
- **能玩错 & 读数说清「为什么」**：`model.js` 从画布真实绘制的 16 拍坐标与柱高单源实算 7 类失误——① 等距平拍（机械催眠）、② 重音哑火（无主次落脚）、③ 重音通胀/全员高呼（强拍超 36% 或 3 连喊导致层次重新拉平）、④ 节拍器单调（有重音但疏密跨比 < 1.45×）、⑤ 间隔断层（最大间距超过中位间距 2.45× 或 3 连休止，格式塔邻近律断裂）、⑥ 拍位粘连（过密挤压成色块）、⑦ 无序杂讯（强弱与空拍全无周期呼应）。用户可用四拍呼吸、三拍轻扬、渐密强收或手雕自编节拍等多种合法解通过 4/4。
- **与最近 12 页的差异**：276 是浅米横滑轮播卡、193 是暖米横排眼动校样、063 是宣纸横向分叉树、231 是冰蓝浮块排字台、275 是深梅画廊策展墙、108 是深绿 2×2 母砖织锦、147 是奶油马戏团木活字、025 是深蓝暖宣单点透视廊、314 是暖纸多平面景片剧场、192 是宣纸竖排立卷、230 是深梅表格账本、062 是黑底十元散点星场；本页是全库唯一「全幅无框曜黑 30° 斜轴 16 拍脉冲柱列 × 底沿全宽疏密调速轨 × 原海报双钴蓝框活体图示舱」的时序视觉乐谱。

## 3. 版式骨架
- **承袭 109 原海报的无框曜黑全幅斜轴与底部双钴蓝框基因**，不锁 `100svh`，抛弃「左画框 + 右侧栏仪表盘」模板：
  - **1440×900（2560×1440 扩宽至 1840px）**：34px 极细顶眉下，全宽开放曜黑舞台纵贯三层——① 开放无框刊头（左置随节奏态联动字距的示范大标「节奏组织」与总述，右置斜杠分隔的四词实况带 `间隔 / 重音 / 速度 / 连贯` 与扫拍开关）；② 全宽无外框 30° 斜轴活体乐谱画布（右下开放三角区嵌动态谱句与珠链）无缝衔接全宽底沿钴蓝调速轨（`data-perf-drag`）；③ 下接三栏曜黑实测与原理舱（左 38% 白话诊单与 4 项单源读数 × 中 31% 钴蓝框「01 重音塑造层次」含活体 SVG 图示 × 右 31% 钴蓝框「02 间隔决定节奏速度」含活体 SVG 图示），整座首屏收于 ~840px 内一屏完整落定。
  - **1024×1366 / 768×1024**：全宽斜轴乐谱与调速轨 → 全宽诊单 → 两枚钴蓝原理框并排双列，零大片留白。
  - **390×844 竖屏**：刊头压成紧收两行，四词实况压缩为 2×2 紧带，全宽等比斜轴画布 + 44px 触屏调速轨 + 诊单首屏稳占 ≥ 48% 屏高，圆点严格正圆。
  - **844×390 横屏**：切为左 58% 紧凑标题、斜轴画布与调速轨 × 右 42% 四词实况、诊单与快捷编排并行。

## 5. 节目录（8 节，h2 均 ≤ 12 字，相邻不撞控件）
- **01 为什么平铺不是节奏**：三态对照显影拉幕（机械均分 / 节奏组织 / 失序散乱）+ 示意视线速度曲线，讲清重复与节奏的分野，一句话链接 107 与 108。
- **02 间隔决定节奏速度**：直接引用原海报要点；9 拍互动间隔切句板（直点 8 处实测宽度的间距铰链切 窄 22px / 中 36px / 宽 60px / 断 108px，读数与渲染像素 1:1 对齐），实时看格式塔邻近律如何切出停顿与乐句，一句话链接 110 与 112。
- **03 重音塑造阅读层次**：直接引用原海报要点；四维重音通道切签（高度体量 / 粗细字重 / 高亮冰青 / 留白孤立）+ 重音个数离散挡位（0/2/3/6/10），直观验证「重音通胀」如何让层次重新变平，一句话链接 111。
- **04 节奏组织从哪来**：1894 Bolton 主观节拍化 → 1923 Wertheimer 邻近律 → 1925/1930 Paul Klee 包豪斯与《Rhythmisches》→ 1944 Kepes → 1967 Emil Ruder → 1992 Bringhurst；年代切换卡 + Klee 1930 三拍切分破格开关。
- **05 放进真实版面怎么用**：真实 DOM 排版双题材沙盒（杂志专题目录 / 信息流卡片列表）× 三种节奏排布切换 × 逐行像素对齐的原海报蓝色脉冲骨架透视层。
- **06 什么时候别强求节奏**：4 类「别用」场景点击切换 + 内嵌正反微缩版式对照图 + 对原海报说法的温和补注（「前提要补一句」）+ 同小类 107/108/110/111/112/113/114 一句话索引。
- **07 练一练：哪条节奏立得住**：四条中性标签（方案 A/B/C/D）12 拍蓝青序列**严格单变量**辨析练习，选完给出四项完整拆解。
- **08 原海报与视觉词典**：原海报大图（点击开模态框 1×–4× 缩放、拖拽平移、Esc 关闭）+ 原海报要点与四关键词 + 页脚。

## 7. 小练习设计（严格单变量）
- **题干**：四条 12 拍蓝青竖柱带使用完全相同的画幅、底色与基础柱宽，每次仅变动一项节奏条件。选出同时成立「间隔变化」「重音层次」与「连贯不断层」的一条。
- **四个中性选项（每项错解仅破坏单一变量）**：
  - 方案 A：保留与正解相同的 3 处冰青重音（25%），但 11 处间距全部锁死为 1:1 等距（仅缺失**间隔变化与速度起伏**，沦为机械节拍器）
  - 方案 B：3 处克制重音（25%）配合约 2.1× 疏密呼吸循环，不断层（**正确**：三条核心条件同时成立）
  - 方案 C：保留与正解相同的疏密呼吸间距，但 8/12 拍同时拉成高柱（67%，仅破坏**重音克制**，重音通胀抵消主次）
  - 方案 D：保留与正解相同的 3 处克制重音，但第 5–6 拍间拉出超过 4.4× 空洞（仅破坏**格式塔连贯**，间隔断层截断视线）
