# 193 水平文字排版 · 设计方案（PLAN）

## 1. 一句话道理
水平文字排版之所以高效，不只是「符合习惯」，而是它把阅读拆成了两拍稳定节律：行内顺着人眼不对称的水平预视窗向前扫视，行尾借固定左锚线与足够行距完成一次不迷航的对角回扫（return sweep）。

## 2. 开场玩具：横排眼动校样台（Live Horizontal Eye-Flow Proof Bench）
- **载体与动作**：直接把 193 原海报中段的「暖米横排样张卡片（左赤陶色块 + 右横排正文流与 `让信息清晰流动 ───────>` 长箭头）」做成活体 2D Canvas 校样台。用户直接在校样纸面上**左右拖动**（`data-perf-drag`，触屏 `touch-action: pan-y` 保留竖滑滚动，桌面亦支持方向键 `←/→` 改行长、`↑/↓` 改行距、点击任意行跳转视点），实时拉伸或压缩每行字数，画面上的真实断行、行长箭头、以及模拟人眼扫视的「不对称预视窗 + 行尾回扫斜线」逐帧同步重算。
- **开场状态（0/4 错版，绝不先给答案）**：开场停在四重错态——单行长达 **44 汉字**（超舒适带）、行距压扁到 **1.12×**（回扫倾角跌破安全坡度，画面上能亲眼看到赤陶回扫光弧落错行、弹出「回扫串行」标）、段落采用 **居中对齐**（左缘每行抖动 `±68px` 失去盲落锚点）、段距归零 **0.0em**（成灰墙粘连）。
- **如何玩错与白话诊断**：全部 4 个维度都能往两端玩坏，由 `model.js` 单一真源结合实排断行坐标判定 6 类错态：
  1. **长行回扫迷航**（中文 >33 字 / 英文 >76 字符，或回扫倾角过平）：读数直指眼睛跨过漫长空白时容易重复读同一行或跳过下一行；
  2. **窄行碎片折行**（中文 <17 字 / 英文 <40 字符）：刚起速就被迫折返，语义碎成短截；
  3. **行距压扁串行**（低于当前行长耦合所需的最小安全行距）：宽行必须配更厚行距，否则上下行笔画粘连；
  4. **行距散架断流**（>2.15×）：行与行裂成孤立横条，失去段落整体感；
  5. **左缘失锚盲找**（居中或右齐正文）：每行起点左右漂移，眼睛回扫无法凭肌肉记忆盲落；
  6. **段距粘连 / 过度割裂**（0em 灰墙或 ≥2.6em 断层）：破坏信息分段与层级节奏。
  支持随时切换 **中文横排 / English LTR / 中英混排**，亲眼验证原海报「20–30 汉字 / 45–75 英文字符」经验带。
- **与最近 12 页的明显区别**：不重复 192 的宣纸立卷与底部拉轨、不重复 229 的多栏 CSS 报样与右侧竖拉柄、不重复 230/274 的数据表格、不重复 313 的片场剪影推轨、不重复 107/146/062/106/024 的点阵或几何构图台——而是以「纸面直接左右拖改行长 + 真实人眼扫视与回扫弧线」为核心动作。

## 3. 版式骨架（承袭 193 原海报，不锁 `100svh`）
- **1440×900（桌面）与 2560×1440（宽屏，内容放宽至 1840px）**：
  - 极细 32px 深海墨蓝顶眉 → 紧凑双色刊头（左分色示范大标「赤陶 `水平` + 暖骨白 `文字排版`」，字形自带基线/水平轨道参考线；右原海报赤陶圆日 + 6 条水平速度细线 + 态标与语种切换）。
  - 中段全宽铺开原海报标志性的 **暖米色横排校样大卡（#E9DFD0）**：左侧 28% 为原海报同款实心赤陶竖块，直接承载高对比度白话诊单与 4 项单源实测光学读数；右侧 72% 为活体眼动校样画布、动态长箭头与原海报四词状态底条。
  - 校样卡底沿紧接极简深蓝单行排字操控带（行长步进、行距档位、起行锚线、段距节奏、眼动透视开关、复原错版）。
- **390×844（手机竖屏）**：顶眉与标题压紧到单行双色，总述退至交互之后；校样画布等比高阔排在首屏核心位置（占屏高 ≥46%），同屏即见紧凑操控带与赤陶诊断摘要。
- **844×390（手机横屏）**：切左 56% 活体眼动校样画布 × 右 44% 紧凑标题、操控带与赤陶诊断并行，零裁剪、零溢出。
- **1024×1366 / 768×1024（平板）**：不设 `100svh`，自然纵排收紧，紧接 01 节无空洞。

## 5. 节目录（8 节，相邻控件完全不同）
- **01 眼睛为什么要往右走**（`THE HORIZONTAL GAZE` · 暖宣米纸）：阐释原海报要点 1–2 与不对称感知广度（Rayner 1998 / Inhoff & Liu 1998），温和修正「并非所有横排都从左到右（阿拉伯语为 RTL）」。交互：**逐字注视预视窗步进器**（中 / 英 / RTL 方向对比）。
- **02 行长与回扫的生死线**（`MEASURE & RETURN SWEEP` · 深海墨蓝）：阐释原海报小贴士 20–30 汉字 / 45–75 英文与 Ruder、Bringhurst、WCAG 1.4.8，讲清行长与行距的斜率耦合。交互：**4×4 行长×行距倾角热力矩阵**（点格直切样张与回扫斜率图）。
- **03 横排里的秩序与节奏**（`ALIGNMENT & RHYTHM` · 洁净象牙纸）：阐释原海报要点 3–4（基线对齐、左缘锚定、行段距级差与中英混排微隙），一句链接 176/178/179/188。交互：**多选 X 光排版解剖层开关** + 失调/校准切换。
- **04 横排从哪来：千年转向**（`HOW HORIZONTAL WON` · 深海暗板）：古希腊牛耕式→公元前 500 年左起横排；1915《科学》月刊首开中文横排；1955《光明日报》与 1956《人民日报》全面横排；W3C `horizontal-tb`。交互：**四年代活体印刷标本台**（含可逐行折返阅读的牛耕式演示）。

- **07 练一练：哪版最耐读？**（`PRACTICE · PICK THE BEST` · 洁净象牙纸）：盲选四版同文横排卡，选后解锁实测标尺与原因。交互：**单变量四选一盲测卡**。

## 7. 小练习设计
- **题目**：四张同宽中文短文卡片，哪一版长读最省眼？（标签仅写 `A` `B` `C` `D`，零暗示）
- **四项单变量对照**（与基准最优版 **A** 相比，B/C/D 各自只坏掉一个横排核心变量）：
  - **A（正确）**：每行约 26 字、行距 1.72×、左对齐、段距 0.9em。
  - **B（单错行长）**：字号缩小导致每行拉长到 42 字，其余保持行距 1.65×、左对齐、段距 0.9em——长距离回扫易丢行。
  - **C（单错行距）**：每行同样 26 字、左对齐、段距 0.9em，唯独行距压紧到 1.16×——上下行挤成铁板、回扫通道被掐断。
  - **D（单错锚线）**：每行同样 26 字、行距 1.72×、段距 0.9em，唯独改用居中对齐——每行起读点左右乱跳，眼睛回扫失去垂直锚点。
