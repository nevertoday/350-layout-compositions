# 181 非对称字体排版（ASYMMETRIC TYPOGRAPHY）设计方案

## 1. 一句话道理
对称排版靠「左右镜像相等」稳住页面，非对称字体排版靠「不等的视觉重量跨过整块留白互相拉住」——打破中轴后，大字重、隐性挂轴、斜势动线与对角配重一起把读者的视线从第一眼重点带向全文。

## 2. 开场玩具
- **玩具名**：活体排印盘·非对称字组编排台（Asymmetric Type Composer，2D Canvas 标 `data-perf-drag`）。
- **怎么玩**：
  - 1:1 承袭 181 原海报蜜桃粉纸、超大粗黑主标、右上破框电光钴蓝巨圆 + 6×6 朱橙点阵、朱橙短横杠、右中 -22° 斜置导语与细橙线、左下三枚几何徽标，以及右下破框倾斜巨字与朱橙圆点；备「原海报·字重对话 / 包豪斯·1923展贴 / 瑞士·建筑书封」三套真实排印语境。
  - **画布空白处左右横拖**：连续推动版面偏轴张力与字组挂线错位（向右建立偏左挂轴+右翼对角呼应，向左建立反角非对称，拖回中央退回对称死锁）。
  - **直接拖移画布上的文字/配重元素**：可独立拖动主标题改变挂靠轴（可故意拆散与正文的隐性挂轴，靠近时轻微磁吸）、点击或拖动斜置导语块旋转倾角（-28° 顺势引导 / 0° 水平静排 / +18° 反向外推）、拖动右上钴蓝圆或右下破框巨字调节对角视觉力矩（拖到同侧会触发单边塌方，拖到字上会触发元素撞车）。
  - **微调滑轨与按键**：调主次字号级差、对角配重体量、斜势导语倾角；开关「隐性挂轴线」「光学重心与留白场」；按 `Space` 从实绘包围盒与视觉重量数组放出真实光学扫视动势箭流验真。
- **开场初始状态（不是答案）**：停在 `0/4 · 对称平权僵局`——主标与正文锁死在 50% 中轴居中排布、主/正字号级差压平至 1.22×、斜置导语 0° 呆板平躺、钴蓝圆与破框巨字退缩且未形成对角配重。
- **怎样算玩错、错了读数怎么说**：由 `model.js` 从实绘几何包围盒、隐性挂轴偏差、墨量视觉力矩与负空间面积单真源实时计算，双向检出 8 类错态：
  1. `对称死锁`（全员压在中轴，退回 178 居中排版）
  2. `层级压平`（主次级差 < 2.0×，第一眼抓不住重点）
  3. `单边塌方`（打破对称却忘了对角配重，左右力矩严重倾覆）
  4. `隐性轴散裂`（主标与正文各飘各的，沦为随手乱摆）
  5. `元素撞车`（字组与蓝圆或破框巨字重叠挤压）
  6. `喧宾夺主`（破框巨字或蓝圆压过主标第一眼权重）
  7. `留白窒息`（活跃负空间不足，文字重块失去留白对话）
  8. `动势阻滞/逆折`（导语反向把视线推出画框，或缺乏贯通节奏）
  同时认可多组合法解：「原海报典范」「瑞士静势（0° 理性直排靠隐性纵轴与大留白成立）」「先锋反角（右挂主标+左下巨字对角平衡）」。
- **读数说什么「为什么」**：不仅给偏轴%、级差倍数、留白%和示意重心位置，每次诊断都用白话指出人眼此刻先停在哪里、为什么发闷或倒向一边，以及一步可做的调校建议。
- **与最近 12 页的区别**：最近 12 页多为构图力学/几何画框/棋盘/星图/天平杠杆；本页是纯粹的「字体排印动作」（挂轴对齐、字号级差、斜置导语倾角、超大破框汉字配重、真实文案语境重排），颜色是近 12 页零出现的蜜桃粉纸×电光钴蓝×热朱橙×漆黑。

## 3. 版式骨架
- **1440×900 桌面端**：1:1 承袭 181 原海报破框现代主义展板（绝不锁 `100svh` 避平板留白）。主容器宽 1380px（2560 下舒展至 1660px）。Hero 右上角嵌破框电光钴蓝巨弧与 6×6 朱橙点阵（容器内 `overflow: clip` 零横向溢出）；主体左 45% 为原海报左侧转译（`NO.181` 蓝签 + 随偏轴实时微错位的自示范大标「非对称 / 字体排版」+ 朱橙短杠 + 原海报总述 + 0px 锐利线框单真源诊单卡 + 原海报同款三枚几何状态探针 `● 不对称 / ■ 层级 / ▶ 视觉动势`），右 55% 为三语境切签 + 开放式高清活体排印画布 + 紧贴底沿的双行字排操轨条，左右严丝齐底，一屏完整可玩。
- **1024×1366 / 768×1024 平板**：自然文档流折为单列，顶行大标 + 满宽高清画布 + 操轨条 + 双列齐底诊单与三几何探针，零大段空白。
- **390×844 手机竖屏**：顶部压紧单行刊头（`NO.181` + 状态章 + 紧凑标题），总述与三几何探针后置；等比排印画布（约 1 : 1.08）稳占首屏 ≥ 46% 高度，折线内直露白话诊单首句、偏轴主滑轨与校准/验真双键。
- **844×390 手机横屏**：左 53% 等比排印画布与右 47% 紧致刊头、诊单首句、偏轴滑轨及快捷双键左右并行。
- **正文七节明暗纸色节奏**：亮蜜桃纸 (`#FFF6F2`) → 柔蜜桃雾 (`#FDE8E0`) → 03 深靛夜幕暗室 (`#0D142B`) → 亮蜜桃纸 (`#FFF6F2`) → 柔珊瑚雾 (`#F9DCD2`) → 06 深靛夜幕考场 (`#0D142B`) → 07 原海报蜜桃纸展墙 (`#FCDCD2`) + 极深靛页脚 (`#070B18`)。

## 4. 配色和字体
- **逐像素实采自 181 原海报**：
  - 蜜桃暖粉底纸 `#FCDCD2` / `#FEDBD0`（亮读纸 `#FFF6F2`、柔粉雾 `#FDE8E0`、暖珊瑚卡 `#F9DCD2`）
  - 招牌电光钴蓝 `#1F48D5` / `#1845D7`（浅纸深钴字 `#1334AD`、暗室亮蓝 `#7BA2FF`）
  - 招牌热朱橙 `#FD550E` / `#F1541A`（浅纸深焦橙字 `#B33400`、暗室亮朱橙 `#FF824D`）
  - 极纯墨黑 `#050407`（正文深墨 `#17151C`、次墨 `#4C4552`）
  - 深靛夜幕暗室 `#0D142B`（暗舱 `#152042`、极深页脚 `#070B18`）
  - 辅助状态色：松翠通过绿（浅 `#0D6B44` / 暗 `#5EE0A6`）、警报朱红（浅 `#BE1F1F` / 暗 `#FF7B7B`）
- **字体搭配（全库 0 重复，三款西文字体近 12 页全部 0 次使用）**：
  - `Noto Sans SC`（400 / 500 / 700 / 900）：中文厚实标题与正文
  - `Syne`（600 / 800，近 12 页 0 次使用）：前卫宽体现代主义展示英文与节号
  - `Instrument Serif`（400 正体 + 斜体，近 12 页 0 次使用）：古典书籍衬线对照与历史引文
  - `IBM Plex Sans`（400 / 600 / 700，近 12 页 0 次使用）：精准瑞士工业无衬线刻度与读数

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻节不重复控件）
1. **01 对称与非对称之差**（`SYMMETRY VS. ASYMMETRY`）：同一份信息在中轴对称与非对称偏轴下的直观对照 → 交互：**卷帘双幕对照器 + 3 套真实文案切换 + 视线/留白叠层开关**。
2. **02 重量与留白的对话**（`WEIGHT & WHITE SPACE`）：拆解原海报导语「让文字的重量与留白的轻盈形成对话」，展示面积、墨量、饱和度与破框如何配平视觉力矩 → 交互：**四要素独立开关矩阵 + 实时四象限墨量力矩平衡仪**。
3. **03 隐性挂轴与斜势动线**（`HIDDEN AXIS & MOTION` · 深靛暗室）：为什么非对称不是乱摆，揭开偏心对齐轴与斜势引导的底层骨架 → 交互：**X-Ray 透视切层按键 + 4 种非对称骨架独立 2D Canvas 活体动线板（含拆轴乱摆反例）**。
4. **04 从包豪斯到瑞士网格**（`WHERE IT CAME FROM`）：1923 莫霍利-纳吉 → 1928/1935 奇肖尔德 → 1946 论战与 1947 企鹅反思 → 1967 鲁德尔与 1981 米勒-布罗克曼 → 交互：**四时代时间轴切换 + 实时重排历史排印标本卡**。
5. **05 什么时候用，什么时候别用**（`WHEN TO USE & WHEN NOT TO`）：温和修正「打破对称就一定更好」的误区，给清适用场景与四类禁区（长篇连续阅读、庄重礼仪、密集数据核对、极窄画幅）→ 交互：**场景分类筛选 + 可展开「硬用反例与替代建议」诊断卡**。
6. **06 动手挑一张好版面**（`QUICK QUIZ` · 深靛考场）：两道递进单变量选择题，四张微缩 SVG 海报只标中性方案 A/B/C/D → 交互：**单选作答 + 逐项对齐线与力矩拆解反馈 + 切题重练**。
7. **07 原海报与关键词**（`ORIGINAL POSTER` · 原海报蜜桃展墙）：原海报可点开灯箱缩放拖动（`draggable="false"`）、原话摘录、三枚几何关键词徽章与同小类编号外链导航。

## 7. 练习
- **题 1（版面诊断）**：为「秋季现代字排展」挑选一张 3:4 非对称海报。四个选项配色、文案、几何元素完全相同，只标中性标签 `方案 A / B / C / D`，各自只差一个排印结构变量：
  - **方案 A**：中轴对称锁死（四组信息左右镜像居中，上下均分）
  - **方案 B**：只破对称不做对角配重（全员挤在左缘，右半整片死空塌方）
  - **方案 C（正确）**：左挂隐性纵轴 + 明显主次字号级差 + 斜势导语串联 + 右上蓝圆与右下破框巨字对角平衡留白
  - **方案 D**：隐性对齐轴散裂 + 主次字号压平（各字组乱飘在四角，缺乏挂线与层级）
- **题 2（边界判断）**：为一本 360 页的长篇经典小说内文与扉页选排版思路，四个中性选项分别对应「每页换偏轴斜排」「全书固定单栏对称/沉静版心（正确）」「每段首字破框跨页」「正文全向右偏轴并加巨圆配重」，强化「何时别用非对称」的边界意识。
