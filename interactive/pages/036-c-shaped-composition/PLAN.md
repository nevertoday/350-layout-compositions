# 036 C形构图 · 互动版方案（PLAN）

## 1. 一句话道理
C 形构图不是用闭环把主体锁进笼子，而是用约 175°–265° 的连续柔和弧线先替主体筑起三面怀抱（依托格式塔良好连续性与闭合倾向、以及人类对曲线轮廓的亲和偏好），再刻意留出一扇朝向画内开阔留白的开口，让视线先绕弧停留，再顺开口走向画面深处与故事余韵。

## 2. 开场玩具：「C 弧抱环·开口定向台」
- **交互手势**：
  - 在开放式 2D Canvas 主画布上**左右横拖（`data-perf-drag`）**连续拉展或收拢 C 弧包裹角（65°–350°），同步驱动刊头自示范大字母「C」随当前包裹角与开口方向实时变形旋转；
  - **直接拖动橙红视觉焦点大圆**调整主体在弧怀内的位置（可故意拖出弧外测试脱抱）；
  - **直接拖动晴空蓝「开口导向」箭标手柄** 360° 旋动开口朝向（自动计算开口前方画内延伸余白深度与 6 束放射蓝虚线箭的折射/撞壁状态）；
  - **直接点击开口前的红色虚线「挡口抢戏块」**将其移出（或在控槽中复放测试堵口憋闷）；
  - **方向键微调**包裹角与开口朝向，点击左侧四枚骑脊要点或底部纯白胶囊关键词高亮对应结构；
  - 一键切换 **原海报图谱 / 海岸灯塔摄影 / 展讯海报编排** 三套真实皮层。
- **开场状态（0/4 失序错态，绝不预给答案）**：
  - 弧角停在 `330°`（几乎封死成 O 形死圈，只剩 30° 窄缝），开口斜怼向近边方向，门口堵着高对比赤红挡口块，焦点圆也偏离弧心滑到弧边缘。四项单真源指标全部亮红待调。
- **怎样算玩错 & 读数怎么说「为什么」**（`model.js` 单真源从实绘几何坐标实时核算 8 类错态，接受右开、左开、上开、斜开等多组合法解）：
  1. `> 290°` **闭口成 O**：弧线合拢把视线困死在封闭环内，开口导向消失，观者只感到局促压迫；
  2. `< 150°` **浅弓散怀**：弧度过短不足以形成半围合场，眼球滑过即散，主体失去庇护感；
  3. **主体脱抱**（焦点偏出弧怀或落到弧背外侧）：弧线背对或抛弃主角，变成与主体无关的装饰背景；
  4. **主体顶壁**（焦点紧贴弧壁挤伤缓冲）：缺少弧内呼吸缓冲，主体与框架粘连；
  5. **开口撞壁**（开口朝向画框近侧，前方画内余白 `< 24%`）：6 条放射视线刚离开主体就撞上画框边缘反弹，故事被硬生生截断；
  6. **堵口憋闷**（开口廊道存在高对比挡口块）：视线通道被杂物卡死，延展感失效；
  7. **偏心失衡**（弧心压边导致整弧被画框裁断）：弧脊残缺，连续性断裂；
  8. **合规多解**：四维全部进入合理区间时，按当前开口朝向（右开顺读 / 左开回望 / 上开升腾 / 下开庇护 / 斜开流动）输出对应心理与叙事读数，而非只认一个固定姿势。
- **与最近 12 页的明显差异**：
  - 区别于 035（横向四站 Z 轨拉跨）、034（暗紫双直翼夹角聚光）、323（漆黑角落扇面射线）、201/202（8×8/4×3 方形网格）、284/285/243（表单与堆栈）、157（撕边宣纸边注）、118（双舱残笔补全）、071/073（建筑灭点与移轴）；036 紧扣「弧度包裹 × 开口余白 × 焦点归怀」三者耦合的弧形构图独有机制。

## 3. 版式骨架
- **忠实承袭 036 原海报**：晨空浅天蓝开放图谱底纸（零深色仪表盘侧栏、不锁 `100svh` 避开平板空洞）→ 左上巨幅联动活体「C」+「形构图」与右上橙蓝「构图原理」呼应 → 主舞台左 33% 贴弧四要点实况脊 + 洁白清纸白话诊单 × 右 67% 开放式 C 弧抱环活体画布与紧凑单行控槽 → 底沿 1:1 复刻原海报纯白大圆角「核心要点」胶囊长条。
- **1440×900 / 2560×1440**：主容器 1380px（2560 舒展至 1740px），主体弧台视觉体量充沛、两侧不留大片空洞。
- **1024×1366 / 768×1024 平板**：自然流式折排为「紧致刊头 → 全宽等比画布 → 左诊单右四要点双栏 → 纯白胶囊条」，绝不产生大片留白空洞。
- **390×844 竖屏手机**：压紧单行刊头与题材钮，等比大画布稳占首屏 ≥ 48% 屏高（正圆严格等比不压扁），同屏可见白话诊单主句与核心快控。
- **844×390 横屏手机**：切换为左 55% 活体弧台画布 × 右 45% 刊头、诊单首句与快解钮并行。

## 5. 节目录（7 大节，相邻节不同控件）
- **01 为什么弧线能抱住眼睛**（`WHY THE ARC HOLDS`）：展开原海报四大要点（包裹主体 / 视觉停留 / 柔性框架 / 节奏引导），配 4 枚要点切换解剖卡 + 动态对比 SVG（硬直角框 vs C 形柔弧）。
- **02 从浅弓到闭口 O 圈**（`THE OPEN-ARC SPECTRUM`）：单滑块连续扫描 90°–350° 弧角区间，联动 2D 眼动扫视模拟画布，实证「太浅抱不住、太满成死圈」的拐点。
- **03 开口朝哪，故事往哪长**（`OPEN DIRECTION` · 深海暗室）：四向罗盘卡片（右开顺读 / 左开回望 / 上开升腾 / 下开庇护）切换，在电影感剪影剧场画布上直观体验开口朝向如何改写叙事心理（人像均用无五官侧影/背影）。
- **04 它从哪来：巨浪与格式塔**（`ORIGINS & PERCEPTION`）：按时间轴梳理葛饰北斋《神奈川冲浪里》（约 1830–1832）、Poore（1903）、Wertheimer（1923）、Arnheim（1954/1974）、Bar & Neta（2006），附交互式《神奈川冲浪里》风格矢量弧线解剖图层开关。
- **05 什么时候用，什么时候别用**（`WHEN TO USE & AVOID`）：上半展开原海报四大场景（摄影、海报、视频、产品）并温和修正原海报的泛化表述；下半列出四类「别用 C 形」反例警示卡，并一句话链接同小类 031/033/035/037/038/039。
- **06 小练习：挑出成立的 C 弧**（`VISUAL CHECK`）：4 选项盲测（中性标签 A/B/C/D，只差弧度与开口空间单一变量），选后当场叠绘视线解析与得分反馈。
- **07 原海报与核心要点**（`ORIGINAL POSTER`）：内联 `poster.webp` 点击放大灯箱（支持滚轮/按钮缩放、鼠标/触屏拖动、Esc 关闭）+ 原海报 4 个核心要点对照胶囊与标准页脚。

## 7. 小练习设计
- **题干**：为一张海边孤岛灯塔横幅海报选构图方案：画面里灯塔是主体，外侧有弯曲堤岸与浪弧，哪种安排最符合 C 形构图的「柔和包裹 + 开口引导」？
- **四项只差弧度/开口关系这一个变量（中性标签，不泄露好坏）**：
  - **方案 A**：弧度 340° 堤岸将灯塔几乎全圈围合，右侧只留 20° 窄缝；
  - **方案 B**：弧度 220° 堤岸朝右开口，但灯塔与弧口贴近右边框，开口前方仅余 11% 窄边；
  - **方案 C（正确）**：弧度 225° 堤岸居左半抱灯塔，开口朝右敞向 38% 开阔海面；
  - **方案 D**：弧度 95° 浅弧贴在左缘，灯塔孤立在弧背外侧的空白区。
- **正确答案理由**：只有方案 C 同时满足约 175°–265° 的柔性半围合、焦点稳居弧怀内腹，以及开口前方充足的画内延伸留白；A 退化为闭口 O 圈憋闷，B 犯了开口撞壁，D 弧度过浅且主体脱抱。
