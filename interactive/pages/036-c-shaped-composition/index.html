01

为什么弧线能抱住眼睛

WHY THE SOFT C-ARC HOLDS THE EYE

海报把 C 形构图拆成了四个相连的动作：包裹主体、视觉停留、柔性框架、节奏引导。它们并不是四个孤立形容词，而是同一条半开放弧线引发的连锁心理反应——相比生硬的直角相框，连续弧线既让大脑感到安全亲和，又把目光从直线冲刺放缓成环绕驻足。

对照解剖 · 包裹主体 直角硬框 vs C 形柔弧

左侧硬直边框把主体框成孤立标本，四角生硬截断视线；右侧 225° C 弧从三面温柔聚拢，既守住主角，又留出右侧通透呼吸口。

02

从浅弓到闭口 O 圈

THE OPEN-ARC SPECTRUM

并不是画上一条弯线就叫 C 形构图。弧度拉得太短，只是一弯留不住目光的浅弓；弧度收得太满，就会合拢成把视线关死在里面的 O 形牢笼。推动下方标尺，观察模拟眼动轨迹在 85° 到 350° 之间如何翻脸。

C 形舒适带 · 175°–265°

三面柔抱 + 一面敞口，停得住也走得远

弧线超过半圆却故意不合拢：大脑一边用「闭合倾向」认出它是个完整怀抱，让目光在主体停留；一边顺着留出的豁口把情绪送向画内余白。

03

开口朝哪，故事往哪长

OPEN DIRECTION SHAPES THE STORY

原海报单独把「开口导向 OPEN DIRECTION」提在右侧作为核心概念——因为决定 C 形构图情绪基调的，从来不是弧脊在哪，而是那扇没合上的门朝向哪里。切按四枚方位罗盘，看同一套包裹结构如何切换成四种叙事气氛。

OPEN RIGHT · FORWARD FLOW 海湾码头与望向远方的观海人（侧影）

中文与英文横排都习惯从左往右阅读。把弧脊放在左侧挡风托底，开口朝右敞向开阔留白，眼睛进画毫不费力，先抱住人物与灯塔，再顺势望向未完的远方。

典型适用：横向海报主视觉、网站 Hero 头图、公路/海岸风景、人物面朝右的肖像。

04

它从哪来：巨浪与格式塔

ORIGINS IN ART & PERCEPTION

「C 形构图」这个简称来自现代摄影与平面教材的字母速记法，但背后的视觉法则早在浮世绘版画、古典绘画构图学与二十世纪格式塔心理学里就已被反复拆透。

《神奈川冲浪里》里的双层 C 弧

葛饰北斋 · 约 1830–1832 年 · 构图结构矢量拆解

双弧叠抱富士

左侧巨浪卷成一道巨大的顺时针 C 弧，把远方矮小的富士山稳稳包在怀中；下方的押送船也弯成一条更柔的内弧。试着勾选「抹平浪弧」，富士山立刻失去压迫与聚焦。

  1. ca. 1830–32

    葛饰北斋《神奈川冲浪里》

    出自《富岳三十六景》（大都会艺术博物馆藏 JP10）。左侧高耸浪峰弯成钩状巨弧，将远景小巧的富士山圈进弧怀，同时把波涛势能敞向右侧海天。

  2. 1903

    Poore 提出「圆形观察」

    美国画家兼理论家 Henry Rankin Poore 在《绘画构图与画作评判》（Pictorial Composition and the Critical Judgment of Pictures）中系统论述：直线容易把眼睛带出画外，而圆弧与椭圆路径能以连续旋涡把松散元素收束成整体。

  3. 1923

    Wertheimer 格式塔连续与闭合

    Max Wertheimer 在《格式塔理论研究 II》（Psychologische Forschung, Vol. 4）中确立良好连续性与闭合性原则：即便只画大半圈弧线，大脑仍会自动延续弧势并将其感知为包裹场。

  4. 1954 / 1974

    Arnheim 剖析圆弧的向心与外张

    Rudolf Arnheim 在《艺术与视知觉》（Art and Visual Perception）中指出，画面里的每一条曲线都携带结构张力——半包围结构既在弧心聚拢向心力，又在缺口处释放出指向画内余白的矢量。

  5. 2006

    Bar & Neta 证实曲线情绪亲和

    Moshe Bar 与 Maital Neta 在《Psychological Science》发表实验，证明相较尖锐折角触发的潜意识防御，人类对流畅弯曲轮廓具有显著的快速亲和偏好——这正是 C 弧「柔性框架」舒适感的心理根基。

什么时候用，什么时候别用

WHEN TO USE & WHEN TO AVOID

原海报列出的四个拿手场景

实景核查

摄影构图

「主体环绕布置，营造空间层次。」

用湾岸、弯道、拱门、垂枝或被摄者抬起的手臂构成前景柔弧，把主体托在弧怀里，并让被摄者面朝开口侧留足目光空间。

海报设计

「突出主题，引导信息阅读。」

用粗大弧形色带、弯曲标题或半圆光环托出主视觉，把日期、地点、副标题顺理成章排在开口吐出的留白区里，不跟主体打架。

视频画面

「环形动线引导，聚焦核心内容。」

半环绕运镜（Arc Shot）或前景弧形遮挡切入主角，镜头停在开口一侧为下一个入画角色或转场方向预留视觉走廊。

产品展示

「环绕式展示，增强包裹与质感。」

用泼溅液体、飘带、光晕或配饰围出半圈怀抱，把瓶身或硬件安在弧心，开口侧干净放型号与卖点文案，画面立刻柔和且高级。

说多了一点

海报总述提到 C 弧「增强主体存在感与故事感」——但前提是弧线得是场景或版面里顺理成章的视觉元素，并且开口前面真的留了空间。如果把主体硬塞进一条生硬画上去的粗色环，或者开口死贴画框边缘，非但生不出故事感，反而会像贴了一枚廉价装饰贴纸。

这四种情况，别硬用 C 形构图

反例避坑

需要冷峻纪律与网格秩序

建筑立面、金融报表、精密仪表界面需要横平竖直的客观感。强加柔和弧线会削弱权威感，此时更适合稳固直角或网格骨架。

双主角平等对峙的画面

C 弧天然偏心于唯一被包裹的中心。如果画面要表现两方势均力敌的冲突或并列比较，单 C 弧会让另一方被冷落成配角，不如改用对称或 031 X 形构图。

多入口并列的信息墙与导航

需要用户快速按顺序扫视四到八个并列卖点时，弧形围合会拖慢阅读效率。多站信息递进交给 035 Z 形构图 更顺手。

极窄细长条幅被强行塞进横弧

细长画幅里横向空间太短，如果还硬排左抱右开的 C 弧，不是弧背被裁断，就是开口立刻撞壁；要么把开口转朝长边（上开/下开），要么改走纵向动线。

同小类分界一眼看清： 要稳稳托住直角边缘但不追求柔弧感，看 033 L 形构图； 如果曲线需要正反双向折返拉出深远纵深，看 037 S 形构图； 如果全画由多条不固定形态的流畅曲线编织，看 038 曲线构图 或重复律动的 039 波浪形构图； 需要尖锐折返冲劲则看 040 锯齿形构图。

原海报与核心要点

ORIGINAL POSTER & KEY TAKEAWAYS

回头看 036 号原海报本身，就是一堂无声的 C 形示范课：整张画把暖橙大圆与厚实 C 弧推在偏右腹地，用左侧四枚骑脊圆徽锚住说明文字，右侧留出透气的浅天蓝空间供六条蓝虚线放射箭展开，最后在底沿用纯白圆角胶囊条温柔兜住全页。

海报核心要点对照

包裹主体 ENCLOSE
弧度落在约 175°–265° 经验区间，从三面护住主角，不滑向浅弓，也不合拢成死 O 圈。
开口导向 OPEN DIRECTION
开口必须对着画内留足余白的开阔侧（建议 ≥ 24% 净延伸空间），不要死怼近侧画框。
视觉停留 VISUAL HOLD
主体安稳居于弧怀内腹，让视线顺曲线减速停顿，延长停留在核心内容上的时间。
柔性框架 SOFT FRAME
优先借用场景里的自然弯曲元素（海岸、枝叶、拱廊、衣袖、光晕）成弧，柔和而不造作。
