# 043 倒三角构图 · 方案（PLAN.md）

## 1. 一句话道理
倒三角把宽阔的主体与呼吸留白置于上方，借两侧向内收拢的斜线将重力势能导向底部单一高对比落点——它不是正三角那种「四平八稳」，而是依靠**上方开阔 + 双向收束 + 重心垂线下的强锚点**撑住的「失衡中的平衡」。

## 2. 开场玩具（冰山吃水漏斗 · V 翼收束与落点托衡台）
- **怎么玩**：直接浮于 043 原海报深渊黑曜底上的开放 2D 画布（标 `data-perf-drag`）。
  1. 在画布开放区左右横拖（或直接拖动顶角两枚发光青色箭头 `↖ / ↗`），连续调节**上方展翼宽度与底口收束度**（从直筒散框 / 正梯形退化，穿过理想倒三角，再到过锐针刺或过扁浅碗）。
  2. 直接拖动**底部发光落点 `●`**，观察视觉重心垂线与力矩偏角——偏离上方主体重心锥时画面倾覆告警、水面涟漪偏斜断裂。
  3. 拖动或调节**吃水线 / 上方留白高度**，验证压顶窒息与主体下沉；切换**底部落点光影强度**（隐没弱点 / 柔和微光 / 强对比落点 / 过曝夺主）；一键直切原海报四大应用场景（自然风光冰山 / 戏剧舞台聚光 / 运动瞬间跳水 / 产品展示棱瓶）及原海报三构图对比（居中式 / 三角形 / 倒三角）。
  4. 完整支持键盘操作（`← / →` 调收束、`↑ / ↓` 调吃水留白、`[` / `]` 挪落点）与触摸横向拖动不阻塞页面纵向滚动。
- **开场初始状态**：刻意停在 `0/4 · 直筒散框` 复合错态（顶宽偏窄 44%、底口敞开 46% 未收尖、吃水线偏高致顶边窒息仅 7% 留白、底部落点暗淡无锚且偏左），用户必须动手收束底口、拉开上方空间并锚定落点。
- **怎样算玩错 / 读数说什么「为什么」**：由 `model.js` 从实绘多边形顶点、上下半区面积比、加权视觉重心 `(cx, cy)` 与底角 `θ` 单真源核算 8 类双向真错态：
  1. **直筒散框 / 反倒塌**：底口未收拢或下宽上窄，视线无向下加速感；
  2. **锐刺窒息**：底角 `< 34°`，两侧斜壁夹切上方主体，丧失「宽阔空间」；
  3. **扁碗泄势**：底角 `> 108°`，坡度太平缓，视线向左右溜走；
  4. **顶边窒息**：顶部留白 `< 11%`，主体顶死上沿，没有呼吸与开放感；
  5. **主体下沉**：视觉重心跌破 `48%`，退化为下重上轻；
  6. **偏心倾覆**：底部落点偏离视觉重心垂线 `> 11%`，上重下轻结构真实失衡倾倒；
  7. **悬空漏底**：底部落点隐没无对比，视线沿 V 槽滑下后直接漏出底边；
  8. **底大夺主**：底部光斑过曝抢戏，反压顶部主体。
  同时接受**原海报经典解**、**宽境俯冲解**、**险峻动势解**多组合法解；稳态与张力按档位并标注`（示意）`，不造假精度百分比。

## 7. 小练习设计
- **题目**：同一张极夜冰川考察海报，上方冰山体量、两侧收束斜线与画面高宽完全一致，**唯一不同的是底部探照灯营地落点的位置与尺度**。哪一帧真正立住了「失衡中的平衡」？
- **四个中性选项（上方冰山与对称 V 翼完全一致，仅差「底部聚焦落点」单一变量）**：
  - `方案 A`：底部探照灯落点向左滑出 V 翼交汇尖端与重心垂线 → 视线顺斜线滑至底端却扑空，焦点与收束轴分裂、画面左倾失稳。
  - `方案 B`：底部只留淹没在暗水中的微弱暗记，缺乏高对比 → 视线顺 V 翼滑下后漏出底边。
  - `方案 C`（正确答案）：落点正对上方主体重心垂线、卡在 V 翼交汇尖端且体量克制 → 稳托上重下轻并形成强烈收束。
  - `方案 D`：底部落点放大为横铺底端的宽亮光带与巨型光晕 → 底端体量反压顶部主体，失去尖端锐度。
