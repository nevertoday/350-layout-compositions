# 049 弧形构图 ARC COMPOSITION · 制作方案

## 1. 一句话道理
圆与椭圆靠「闭合」把视线锁在圈内，而弧形构图靠一道**两端开放、曲率顺滑、粗细有致的单向大弯**，利用格式塔连续性与凹侧包围感，把眼睛从画面边缘自然滑送进弯心焦点，再顺势延展向画外。

## 2. 开场玩具：「弓弦弯弧 · 挥弧造势台」（2D Canvas，`data-perf-drag`）
- **怎么玩**：
  - 直接在开放的暮湾弧窗画布上**按住大弧脊线或空白处横拖「拉弓弯弧」**：连续改变主弧曲率与拱向（从僵直拉平、舒展升弧、上拱穹顶、下凹托盘，直到过弯封口成闭环）；
  - 直接**拖拽焦点的杏桃落日与孤舟**（或桥灯/展讯焦圆），亲手把它移进凹侧弯心、压上弧脊拦腰斩断、或甩到凸背弹飞；
  - 直接**拖拽弧尾或箭头弧尖**拉缩跨幅，或点击弧体/底部 4 枚原海报 TIPS 模式键切「顺滑连贯 / 粗细韵律 / 断续割裂 / 僵直拼角」；
  - 按 `Space` 或点「放行视线流」释放杏金色视线光彗，真实沿实绘弧脊滑行：顺滑连贯且焦点在弯心时彗星绕焦减速并优雅冲出箭头；有折角或凸背时彗星当场撞折卡顿或直接滑偏飞出；
  - 支持三套对应原海报「应用示例」的场景切签：`原海报·暮湾归舟`、`建筑·石拱长桥`、`海报·流光展讯`。
- **一打开是什么状态（绝不先给答案）**：
  - 开场停在 **0/4 四重反例错态**：① 弧体被压扁（包角约 30°）且中段带直段硬拼折角（对应原海报底沿 TIPS 第 4 个 × 图示）；② 跨幅仅 ~44%，缩成局促小括号；③ 落日焦点落在凸背外侧（凸背弹飞）；④ 均粗死线（粗细比 1.0×，无书法收锋与韵律回响）。
- **怎样算玩错、错了读数怎么说**：
  - `model.js` 从实绘采样折线单真源核算实测包角、实测跨幅占比、最大转角突变、焦点相对弧线的有向法距（凹侧弯心 / 弧脊斩焦 / 凸背弹飞 / 深埋贴边）以及起止粗细比，识别 **8 类双向错态**：折角断流、拉直失弧（<32°）、过弯封口（>195° 退化成闭环）、跨幅局促（<55%）、弧脊斩焦、凸背弹飞、焦点出窝、均粗呆板。
  - 每种错态都在底沿深靛 TIPS 诊单栏用白话说明「眼睛此时为什么滑偏或卡住」并给出具体纠偏手势。
  - 认可**多组合法解**：`原海报升弧解`、`穹顶上拱解`、`托盘下凹解`，以及用户手弯出的任意 4/4 连续舒展大弧。
- **与近期 12 页的明显区别**：
  - 047 是闭合星盘绕圆心排卫星、048 是闭合斜椭圆调长短轴与双焦点 F1/F2、136/135 是对开书脊配重与镜像折叠、217/257/258/172 是网格与栏宽、302/303 是人物站位与机位、085 是透视压平、337 是胶片翻页；
  - 本页 049 独创**开放曲线「拉弓弯弧 + 书法粗细收锋 + 折角撞停光彗 + 凹侧弯心判别」**，完全属于开放单弧自身的几何动作，别的编号套用不了。

## 3. 版式骨架（1:1 承袭 049 原海报「深靛外框 × 淡紫雾纸 × 弧形错列五圆徽 × 深靛底沿 TIPS 栏」）
- **1440×900（2560 舒展至 1680px，绝不锁 100svh 避免平板大空白）**：
  - 外层为深暮靛蓝框垫（`#261556`），内托大圆角淡紫雾纸面（`#EFE6F3`）；
  - 上半三区非对称横贯舞台：**左 24%** 自示范大标「弧形构图」（底部一条随主弧曲率实时弯动的杏桃色 SVG 活弧）+ 总述 + 原海报五枚深靛胶囊关键词（可点选联动高亮画布几何层）｜**中 52%** 开放无重框暮湾弯弧 2D Canvas 舞台与单行场景/TIPS 模式条｜**右 24%** 沿真实淡紫虚弧逐级错列排布的五枚杏桃/薰衣草圆徽实况探针；
  - 底部无缝承接原海报同款通宽深靛圆角 **TIPS 诊单与精控坞**：左列白话单真源诊单 + 一键纠偏 + 四枚实测读数；右列弯度/跨幅/粗细精控与三合法解/四双向试错。
- **1024×1366 / 768×1024（平板）**：顶行紧缩刊头 + 五关键词横排，中行满宽开放弯弧舞台，底行左右双栏齐底（左五圆徽探针、右深靛 TIPS 诊单与精控），无大块留白。
- **390×844（手机竖屏）**：顶栏压成单行「NO. 049 弧形构图 + 状态徽标」，紧贴着给出等比不压扁的开放弯弧舞台（稳占首屏 ≥47% 高度），折线内直接露出深靛 TIPS 诊单首句与一键弯弧/视线流按钮；总述、五胶囊关键词与五圆徽顺流后置。
- **844×390（手机横屏）**：左 55% 等比弯弧舞台 × 右 45% 紧凑刊头、白话诊单与快捷切钮并行，零横向溢出。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节交互不重样）
1. `01` **为什么弧线能带住眼睛**（`WHY ARCS GUIDE THE EYE`）— 拆解五原则与格式塔连续性；**交互**：仿 Field–Hayes–Hess 1993 的「关联场短棒探测台」（SVG 36 枚短棒 + 切向抖动滑杆 + 路径截断开关）。
2. `02` **四个方向，四种脾气**（`FOUR ORIENTATIONS, FOUR MOODS`）— 对比上拱穹顶、下凹托盘、斜向升弧与侧抱弯湾的心理落差；**交互**：「360° 拱向罗盘」可拖拽圆盘转盘 + 实时海报线框重心重排。
3. `03` **从浮世绘到界面弧线**（`ORIGINS & PERCEPTUAL SCIENCE`，深靛暗室）— 溯源 1753 贺加斯、1830–32 北斋、1923 韦特海默、1993 关联场与 2006/2007/2013 神经美学；**交互**：「名作弧骨透视抽屉」四幕策展切幕 + 实时变形结构透视图。
4. `04` **四类实战与粗细节奏**（`FOUR APPLICATIONS & RHYTHM`）— 还原并展开原海报四格「应用示例」与 TIPS 粗细律动；**交互**：「四景弧律对照卡」场景页签 + 单调死弧 ⇄ 韵律活弧翻拍对比开关。
5. `05` **什么时候别用弧形**（`WHEN NOT TO USE ARCS`）— 温和修正原海报「包裹感/越连贯越舒适」两处说多了一点，剖析高密表格、硬派警示与多弧互撞三大禁区；**交互**：「禁用场景压测台」三份真实排雷稿件 + 强套弧形 vs 克制解切换。
6. `06` **小练习：挑出成立的弧形**（`SINGLE-VARIABLE PRACTICE`，深靛练习考场）— 3 道单变量视觉辨析小练习（分别只变：焦点相对弧位 / 曲线连续性 / 开放跨幅与闭合度）；**交互**：A/B/C/D 中性选项作答 + 即时几何归因讲评。
7. `07` **原海报与关键词**（`ORIGINAL POSTER & KEYWORDS`）— 原版高清海报（点击弹层放大/拖拽/`draggable="false"`/Esc 关）+ 五枚关键词原词条 + 同类构图直达链 + 完整规范页脚。

## 7. 小练习设计（单变量、零提示标签）
- 每题 4 张同构 SVG 版式标本，标签严格只写 `A / B / C / D` 与中性编号说明：
  - **题 1（焦点位置）**：同弧同色，只改落日焦点位置（A 凸背外侧 / B 压脊拦腰 / C 凹侧弯心留净空 ✓ / D 贴边窄角）。
  - **题 2（曲线连贯）**：同焦同色，只改弧线质量（A 中段硬折拼角 / B 大段虚断 / C 几乎拉直 / D 顺滑起粗收细连贯弧 ✓）。
  - **题 3（开放跨幅）**：同凹侧焦点，只改弧的跨幅与闭合度（A 32% 短括号弧 / B 235° 过弯近闭环 / C 76% 开放延展大弧 ✓ / D 双反向夹死漏斗）。
