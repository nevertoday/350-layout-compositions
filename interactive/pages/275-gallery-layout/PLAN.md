# 275 画廊布局（GALLERY LAYOUT）设计方案

## 1. 一句话道理
画廊布局把「扫全局选对象」交给缩略图阵、把「细看品质与情绪」交给大主视觉，再用统一的画框留白和色温稳住气氛，让人不跳页面就能完成「扫一眼 → 点一下 → 细看 → 对比」的闭环。

## 2. 开场玩具（活体画廊策展墙）
- **形态与操作**：在原海报同款深梅紫展墙上搭出一个真实可用的 8 件现代几何作品画廊——点任意缩略画（或按 `← / →` 键）切主画展示，点主画「放大看展」按钮或按空格进灯箱精看（`Esc` 退出）；主画框与缩略区之间嵌入一条通栏横向 **主次比例尺（`data-perf-drag`）**，左右直拖实时重算主画与缩略图面积比并重绘 2D Canvas 展画与比例标注；左栏提供三组策展开关：**预览形式**（无提示截断 / 仅圆点盲翻 / 4×2 全览 / 余量胶片带）、**选中联动**（脱节无标 / 珊瑚焦框联动）、**展墙氛围**（杂色无框 / 惨白融边 / 深梅卡纸 / 暖石细框）及复原错态。
- **开场初始态（0/4 错态）**：主次面积比停在 `1.6×`（主画矮小平权）、预览停在「无提示截断（只露 4 格、悄悄藏掉 4 幅馆藏）」、选中态「脱节无标（大画与缩略图无珊瑚框呼应）」、氛围停在「杂色无框（撤掉暖米卡纸且 8 幅作品底色互撞、画缝贴死）」。
- **怎样算玩错、错了读数怎么说**：
  - 主次比 `< 4.2×`：报「平权退化」，指出主图与缩略图差不多大，画廊退化成普通卡片网格、失去聚焦锚点；
  - 主次比 `> 14.5×` 或单缩略 `< 36px`（向右拖爆）：报「主画吞噬」，指出缩略图被压成极小窄片、既看不清构图也难点击；
  - 预览选「无提示截断」：报「隐蔽截断」，指出藏起 4 幅作品却无任何提示，用户会误以为全馆只有 4 张图；
  - 预览选「仅圆点盲翻」：报「盲翻失明」，指出圆点只能数张数、不能预看内容，逼人盲点试错；
  - 选中关「脱节无标」：报「定位断联」，指出切换大画后缩略区无高亮框，观众分不清自己正看到第几幅；
  - 氛围选「杂色无框」或「惨白融边」：分别报「杂色贴撞」与「白墙融边」，说明没有统一卡纸留白与色温时，邻画彼此抢戏或画边溶进白墙。
  - **多解达标**：面积比落入 `4.2×–14.5×`（经验舒适带且单枚缩略 `≥ 36px`）、预览切「4×2 全览」或「余量胶片带」、开启「珊瑚焦框联动」、氛围切「深梅卡纸」或「暖石细框」皆可 4/4 达标，不把答案锁死在单一配色或单一排列。
- **与最近 12 页的差异**：最近 12 页分别是财务数据表（274）、圆点印版矩阵（107）、深夜平行线谱（024）、宽银幕横向人物调度（313）、蒙德里安纸带格墙（146）、贝塞尔路径排字（191）、多栏报样排版桌（229）、三层遥测仪表盘（273）、径向清场红圆展墙（106）、引力成簇画布（061）、片场三角取景（312）、粗黑五面板分镜（145）。本页是唯一以**深梅紫美术馆展墙 + 真实可点击换展的 8 件作品画廊界面 + 横向主次比例尺直拖**为核心的页面。

## 3. 版式骨架
- **1440×900（桌面）**与 **2560×1440（宽屏）**：严格承袭 275 原海报骨架，不锁 `100svh`。极细顶眉下，桌面宽 `1360px`（2560 扩至 `1840px`），左 34% 为深梅紫策展墙签栏（珊瑚 L 型挂画框包住「画廊 / 布局」双行大标 + 动态微缩主次图解 + 原海报总述 + 三组策展控件 + 实时展签诊单 + 原海报四点长箭头指向右墙），右 66% 为双层活体画廊展墙（上大主画 Canvas 展框 → 中横向比例尺 `data-perf-drag` → 下 8 幅缩略图阵）；底沿通栏承接原海报同款 4 栏原则检核带（预览 / 浏览 / 选择 / 氛围）。
- **1024×1366 / 768×1024（平板）**：自然上下分段，左刊头与控件收拢为紧凑两栏顶带，下方满宽铺开活体展墙与四栏原则带，不留空洞。
- **390×844（手机竖屏）**：顶标压成单行紧凑刊头（约 52px），把活体主画 + 比例尺 + 缩略阵直落首屏顶部，占首屏 ≥ 48% 屏高，同屏可见主控按钮与一行白话诊单；原海报导语退到交互区之后。
- **844×390（手机横屏）**：切左 56% 活体展墙（主画 + 比例尺 + 缩略带）× 右 44% 紧凑控件与诊单并行，无横向溢出。

## 4. 配色和字体
- **配色（像素实采自 275 原海报 `site/public/p/275.webp`）**：
  - 展墙深梅紫 `#3F1935`（深阴影 `#2D1026`，墙签浮层 `#4C2040`，暗节展厅 `#3A1731`）
  - 暖米卡纸与主字 `#F7E3CE`（高光 `#FDF4EA`）、柔粉桃 `#F1B6A8`、米杏 `#EED4C2`
  - 珊瑚焦点红 `#F07868`（高亮缩略框 `#F69B83`，浅纸可读深珊瑚 `#B83B2E`）
  - 细线玫灰 `#A76C79`
  - 正文浅纸交替：暖象牙 `#FDF8F2`、暖卡纸 `#F7EDE2`、柔粉纸 `#F3E2D8`、梅墨正文 `#35142C` / 次墨 `#6A4158`
- **字体搭配（全库唯一，且两款西文在最近 12 页均为 0 次使用）**：
  - `noto-sans-sc` (400 / 700 / 900) — 中文主体与海报大字
  - `space-grotesk` (400 / 600 / 700) — 最近 12 页未用；英文字标、展签、等宽感读数
  - `playfair-display` (500 / 700 + italic 500) — 最近 12 页未用；博物馆目录编号、策展导语装饰数字

## 5. 节目录（共 8 节，每节标题 ≤ 12 字，相邻不用同类控件）
- **01 一大一小，怎么替眼睛分工**（OVERVIEW & FOCUS）：引用原海报 4 要点，拆解「缩略总览 + 主图聚焦」认知分工；交互：**2D Canvas 目光跳步对比器**（三模式按钮切换并观察查找第 6 幅作品的眼动路径与实际点击步数）。
- **02 缩略条最隐蔽的坑：悄悄截断**（TRUNCATION TRAP）：基于 Baymard 研究讲清隐蔽截断为什么让用户漏看细节；交互：**寻宝式 8 图商品条实验**（在「硬切藏 4 张 / 露半边 +4 提示 / 4×2 全览」三态下实际翻找尺寸图与材质图）。
- **03 画幅裁切与挂画气口**（FRAMING & MAT）：深梅紫暗版展厅，讲原海报「氛围」背后的卡纸留白与混排画幅策略；交互：**混排画幅装裱台**（卡纸厚度滑杆 + 3 种装裱裁切单选，直看 16:9 / 3:4 / 1:1 作品边缘构图是否被切头）。
- **04 三种缩略位，按屏换阵**（RESPONSIVE TOPOLOGY）：拆解缩略图放底部、左侧或胶片带在不同屏幕下的面积账；交互：**多端视口变形矩阵**（3 设备 × 3 缩略位点选，实时核算主图屏占比与单枚缩略图可点尺寸）。
- **05 画廊布局从哪来**（ORIGINS & LINEAGE）：串联 1929 MoMA 眼平单行挂画、1976《白盒子之内》、暗房接触印样、1996 Shneiderman 信息可视化总诀、2005《Designing Interfaces》与 Lightbox JS；交互：**4 时期策展演进图谱切换器**（点击年代卡片让展墙微缩示意同步变形）。
- **06 什么时候用，什么时候别用**（WHEN TO USE / AVOID）：温和提醒原海报「沉浸氛围」的屏占代价，并一句话链接到 270、271、272、273、274、276、277、288、289 等同小类页面；交互：**三问选型判别器**（切换 3 个是非场景开关，给出对应布局建议与直达链接）。
- **07 小练习：挑出最稳妥的展墙改法**（CURATORIAL QUIZ）：4 张中性编号（方案 A/B/C/D）的微缩展墙图，仅差「主图与 8 张缩略图的尺幅与露出方式」一个变量，作答后给出具体理由。
- **08 原海报与关键词**（ORIGINAL POSTER & KEYWORDS）：内联原海报 `<img id="poster" src="poster.webp" draggable="false">`（点开可缩放、拖动、`Esc` 关闭），配原海报四枚关键词及单行页脚。

## 7. 练习设计
- **题目**：你要为一间手作陶器工作室做商品详情画廊，共有 8 张不同角度与尺寸标注的实拍图。下面四套排法配色、卡纸和第 3 张珊瑚高亮框完全一致，只差主图与缩略图的尺幅和露出方式，哪一套最不容易让访客迷路或漏看？
- **四个选项（标签仅写「方案 A / B / C / D」，视觉图自证差异）**：
  - 方案 A：主图高度只占 24%，下方 8 张缩略图排成等大 4×2 网格（面积比 1.3×，退化成平权卡片网）。
  - 方案 B：主图高度占 64%，下方 4×2 完整列出 8 张缩略图，主图约为单枚缩略图 7.4 倍面积（正确答案）。
  - 方案 C：主图高度占 64%，下方仅齐平裁出 4 张较大缩略图且无滚动/余量提示（悄悄藏起 4 张，隐蔽截断）。
  - 方案 D：主图高度占 88%，下方 8 张缩略图挤成极细一条窄片（主图吞噬缩略区，看不清也点不准）。
