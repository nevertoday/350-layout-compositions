# 023 对角线构图（DIAGONAL COMPOSITION）互动页方案

## 1. 一句话道理
人眼初级视觉对水平（0°）与垂直（90°）最稳妥、最敏感（Appelle 1972「斜线效应」），线条一旦偏离横竖稳态坐标，就会在视知觉中产生持续的倾倒势能与方向拉力；再加上矩形对角线天生比边长更长，配合近大远小的疏密梯度与对侧配重，就能把静止画框变成一条有起点、有速度、又不至于翻车的视觉跑道。

## 2. 开场玩具：「斜轨导引与配重调度台」
- **怎么玩**：直接在 16:10 活体斜切画布上拖拉「信号黄斜轨角度把手」或推动画布底沿的「斜角罗盘拨轨」（`data-perf-drag`，范围 `-72°` 至 `+72°`，同时涵盖左下→右上「上冲 ↗」与左上→右下「俯冲 ↘」两种动势），直接在画布上拖动「对侧配重锚点（Counterweight）」调整视觉力矩平衡，并切换沿线「疏密大小梯度（等大均分 / 逆向卡顿 / 近大远小）」与三套题材（原海报高速铁道 / 山地急弯骑行 / 斜切几何海报）。支持键盘方向键微调角度与配重。
- **开场状态（0/4 三重错态，绝不先给答案）**：
  1. 倾角刻意落在 `+5°` 伪水平溜斜态（既不稳也不动，像拍歪了）；
  2. 节点节奏锁在「等大均分」（无速度加速度与纵深感）；
  3. 对侧配重锚停在 `(0.22, 0.72)`，和主车头挤在同一侧导致画面左重右轻力矩翻车。
- **怎样算玩错 & 读数怎么说**：
  - `|θ| < 14°` → 报「错态 · 伪水平歪斜」：告诉用户眼睛正按水平基准纠错（像歪掉的 021 水平构图），还没进入对角张力域；
  - `|θ| > 64°` → 报「错态 · 过陡趋近垂直」：告诉用户线条已逼近 022 垂直柱列，像随时倒塌的高杆；
  - 节点选「等大均分」或「逆向卡顿」 → 报「错态 · 均分板结」或「错态 · 逆向卡顿」：等大节点把斜线拉平、没有由近及远的加速节奏；
  - 配重压在主斜轨上（垂直距离 `< 0.10`） → 报「错态 · 配重堵路」；配重偏向同侧导致加权视觉质心偏移 `> 0.085` → 报「错态 · 一端过重失衡」，实时指出偏重方向与偏移量。
  - 上冲（`+16°` 至 `+62°`）与俯冲（`-16°` 至 `-62°`）皆可成立，但读数会分别阐释「攀升推进」与「俯冲压迫」的不同情绪。不设「一键通关」，仅设「复原错态」。
- **与最近 12 页的区别**：不同于 022 的垂直移轴拨尺、021 的气泡水平尺、058 的阶梯步高、309 的俯拍滑轨和 143 的开窗裁景，本玩具专攻「主斜轴倾角扫动（含正负双向）× 沿线加速梯度 × 二维视觉力矩配重」三维联动，别的编号无法套用。

## 3. 版式骨架
- 承袭 023 原海报标志性的**「净瓷白左上刊头 + 斜切翡翠深绿右翼 + 主舞台与深绿核心作用立柱」**骨架，不锁 `min-height: 100svh`。
- **1440×900 / 2560×1440**：极细 34px 顶眉下接斜切双色刊头（左净瓷白排自带前倾笔势的得意黑大标与随倾角联动的信号黄斜锋线，右斜切翡翠深绿放题材切签与校准徽章）；中段左 72% 为 16:10 活体斜轨画布及一体底沿斜角罗盘拨轨，右 28% 为原海报同款深翡翠绿「核心作用 KEY POINTS」立柱，排布四枚白/黄交替实测圆徽与黄签诊断盒（2560 容器扩至 1840px）。

- **03 疏密与配重稳住画面**：还原原海报实践要点 2、3 的视觉力矩原理；交互 = 三枚独立图层勾选开关（大小递减 / 间距压缩 / 对侧配重）实时合成海报与质心标靶。

## 7. 练习设计
- **题干**：为「城市夜间半程马拉松」设计 16:10 预告海报，四套方案使用完全相同的跑者剪影、配色与文案，只改变对角斜线组织与力矩配置。
- **四个选项（仅标方案 A / B / C / D）**：
  - A：主赛道倾角仅 `+6°`（伪水平微歪，单变量：倾角不足）；
  - B：主赛道 `+36°`，但跑者等大均分且标题压死右上终点（单变量：无疏密梯度且同侧超载）；
  - C（正确）：主赛道 `+36°`，跑者近大远小由疏到密拉出加速度，左上克制文字块作对侧配重，右上留出冲线余白；
  - D：主赛道 `+74°` 逼近竖直并叠加底部左右对称重块（单变量：过陡且对称抵消斜势）。
