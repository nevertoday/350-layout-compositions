# 331 开合构图（OPEN-CLOSE COMPOSITION）设计方案

## 1. 一句话道理
用局部边界向内「合」出围护感以锚定主体，同时刻意留出通往画外的「开」口释放视线——有合无开则逼塞憋闷，有开无合则浅露涣散，开与合的张力才造就空间纵深与呼吸节奏。

## 2. 开场玩具：「双扉开合·纳景泄气台」
- **交互机制**：直接融在 331 原海报暖米原纸上的无框 2D 透视折门舞台（纯 2D 解析三维透视投影，无 WebGL 降级差异，`data-perf-drag` 挂在主画布上）。1:1 承袭原海报左右两扇向内折入的巨幅朱橘红透视门翼（「包围 → / ← 包围」）、中央受护朱红主体圆与上下两条虚线吐纳口（「打开 ↑ / ↓」），外加实时视线吐纳射线流（撞上门翼折回护心，穿过开口逸向画外）。
- **怎么玩**：
  - 在画布左右门翼或空白中庭直接**横向拖动**，像推开真实双扉或屏风一样连续改变门翼张角与中庭开度；
  - 切换**「联动双扉 / 独扇偏开」**，单侧推拉左扉或右扉，实测对称正局与传统山水「左合右开 / 偏开一隅」；
  - 直接点按画布顶部与底部的**「打开 / 封口」**虚线闸门，开闭天口与地口；
  - 切换三套题材：**原海报·朱圆门庭** / **宋画·峡谷云门** / **书封·折门海报**；支持方向键（`←/→` 推拉门扉、`↑/↓` 切换纵口、`Space` 切联动）和画布内单步纠偏热签。
- **开场初始态（绝非答案）**：刻意停在**「四面逼塞 · 气脉锁死」**复合错态——左右门扉向内掩合过深、几乎夹逼主体圆缘（中庭净宽过窄），且上下气口同时封死，视线射线在狭盒内反复撞壁逃不出，直观再现王原祁「开合逼塞浅露则生病」的「逼塞」一端。
- **怎样算玩错、错了读数怎么说（单真源实绘几何）**：`model.js` 从当帧真实投影的左右门翼四角、上下封闸与主体圆边界坐标，直接核算中庭净宽比、围合面积占比、门锋净空、纵口开放度与双翼偏衡，覆盖 6 类双向错态：
  1. **四面逼塞（只合不开）**：中庭被挤窄或四向全封，读数点明视线困死盒内、气脉无法延展；
  2. **夹挤焦心（门锋割主）**：门翼内缘逼近甚至擦碰主体边缘，读数指出「合」已变成压迫而非保护；
  3. **四散浅露（只开不合）**：门扉完全摊平撤离且四面敞口，读数点明主体失守漂浮、视线直滑出框；
  4. **纵口封死（闷顶闷底）**：左右门扉虽已推开，但上下气口仍全封，读数指出只围出走廊死胡同，仍需开一口吐纳；
  5. **单翼倾覆（偏压失衡）**：独扇模式下单侧深压越界而对侧几乎消失，读数说明半边护持反把主体挤偏；
  6. **开合温吞（张力平淡）**：门翼既不够立势、开口又不干脆，读数指出对比反差偏弱。
- **接受多组合法解**：原海报双开正局、上开下承天窗立轴解、独扇偏开一隅解、宽庭大开大合解。
- **与近期 12 页的差异**：330 拖三圆比体量、329 拖点阵看疏密波、079 抬俯拍角、078 蹲地仰拍摩天塔、251 拉裁切比例框、293 对开双端切换、165/164 书口索引与目录分栏、126/125 群组与粒子、041 拉三角顶点；本页独创**「透视双扉门扇推拉 + 上下闸口启闭 + 视线折返/外逸光流」**，直接源自 331 原海报的折门母题，任何其他编号都套用不了。

## 3. 版式骨架（1:1 转译 331 原海报通栏建筑双扉展幅）
- **1440×900（主宽 1340px；2560 舒展至 1660px）**：零深色顶栏、零侧边圆角仪表盘、不锁 `100svh`。顶部非对称刊头（左 58% 自示范开合字距巨标「开合构图」+ 宽字距英文 × 右 42% 朱红短杠「核心概念」总述与三题材切签）→ 居中全宽无框暖米纸双扉透视画布（430–460px 高，直接浮于原纸）与单行紧凑操轨 → 1px 墨线通栏下 1:1 复刻原海报双栏底账（左 48%「● 知识要点」实时单真源诊单 + 原海报三要点活体标 × 1px 竖墨线 × 右 52%「● 设计价值」四枚原海报朱红线绘图标与实测读数）→ 1px 墨线下「TIP」朱红胶囊脚条与右角门枢徽。
- **1024×1366 / 768×1024 平板**：自然流排，画布等比缩放（绝不拉扁圆盘），不设 `100svh`，首屏下紧接 01 节零空洞。
- **390×844 竖屏手机**：压紧单行刊头、后置概念总述，使等比双扉舞台稳占首屏 ≥ 47% 高度，下方同屏露出操作提示与诊单首句。
- **844×390 横屏手机**：切换左 55% 折门画布 × 右 45% 刊头、题材切换与实况诊单双列并行。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻控件零重复）
- **01 开与合，缺一不可**（亮宣白）：解剖原海报三条要点，并温和校准「被包围，受保护」并非四面封死。交互：**四向边墙独立开关板（上/下/左/右 16 态拓扑矩阵）**。
- **02 为什么开合能稳住视线**（暖砂纸）：讲清 Jay Appleton（1975）瞭望—庇护理论与视觉场域降噪原理。交互：**前后对比滑帘（Split Curtain 拖动比较无围合 vs 双翼开合）**。
- **03 从哪来：画论里的开合**（玄墨朱漆暗室）：王原祁《雨窗漫笔》、沈宗骞《芥舟学画编》（1781）、北宋郭熙《早春图》（1072）考据，并一句话链接同小类 326–334。交互：**通幅大开合 × 分股小开合层级透视切换与热区点检**。
- **04 四类真实场景里的开合**（亮宣白）：对应原海报 TIP 四场景（封面/海报/摄影[纯剪影无五官]/版式）。交互：**四场景实景样张选项卡 + 单变量景深/门翼收放滑杆**。
- **05 什么时候别用开合构图**（浅朱霞纸）：并列对比表、极窄手机卡片、全景地图、极简纯留白四类反例。交互：**三张反例卡片独立「硬套围框 ↔ 撤框还原」即时对照开关**。
- **06 小练习：哪一张开合得法**（玄墨朱漆暗室）：单变量视觉判断。交互：**四选一中性标签视觉卡片（A/B/C/D）+ 全项对比复盘**。
- **07 原海报与关键词**（暖米原纸）：原海报点击缩放/拖动看图灯箱（`draggable="false"`，支持滚轮与 Esc）+ 原海报四关键词与同小类导览。

## 7. 练习设计
- **题目**：四张展讯海报的主体圆盘大小、上下开口高度、色彩与字号完全一致，**仅改变左右围合门翼的合拢幅度与对称关系**，选出同时兼顾「合得住主体」与「留得住呼吸空间」的一张。
- **选项（纯中性标签 `方案 A / B / C / D`）**：
  - `方案 A`：双翼极薄贴边（单侧仅 5%，中庭 90%），过开浅露；
  - `方案 B`：双翼压入过深（单侧 34%，中庭 32%），逼塞压迫主体；
  - `方案 C`（正确）：双翼各占 21% 向内折入（中庭 58%，与主体留有舒展护持净空），合中有护、开中有度；
  - `方案 D`：左翼 36% 紧逼主体而右翼仅 6%，偏压失守。
