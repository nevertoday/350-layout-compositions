# 151 · 拼贴 版式（COLLAGE LAYOUT）互动页方案

## 1. 一句话道理
拼贴版式不是把杂物往纸上乱粘，而是利用**前后叠压（Z 序）、材质冷暖粗细反差、克制的元素数量与留白呼吸**，把几件不同来源的平面材料拧成一个有情绪、有主次、有触觉深度的整体画面。

## 2. 开场玩具：活体拼贴手工台（Craft Collage Desk）
- **怎么玩**：在 2D Canvas 手工台面上，直接按住拖拽每一片带手撕毛边、胶带与投影的真实纸片（`data-perf-drag`）；点击选中任意纸片，在下方手工工具槽里调它的**叠放前后（置顶 / 上移 / 下移）**、换它的**材质纸样**（哑光手撕蓝纸 / 细格手账纸 / 炭黑粉笔纸 / 报刊铅字 / 圆点卡纸 / 芥黄圆片）、或把它**撕掉丢回纸篓 / 从纸篓夹回台面**；支持键盘方向键微移、`[` `]` 调图层、`Delete/Backspace` 撕片；支持切换「原海报·静物手账」「建筑概念情绪板」「黑胶巡演概念页」三套题材。
- **开场初始态（0 / 4 翻车态「乱堆废纸摊」）**：
  1. 焦点银盐静物相片（位于台面中央附近，兼作 `data-perf-drag` 首个直拖目标）被压在底层，遭到上方哑光纸与杂物遮挡超过 40%；
  2. 多张衬底纸片被设为同质平涂米纸，缺乏光滑照片 × 粗糙彩纸 × 印刷纹样的材质反差；
  3. 台面被塞入 10 片杂碎纸片，留白跌到 20% 以下，沦为杂乱公告栏；
  4. 重块堆向一侧导致光学重心偏沉失衡。
- **怎样算玩错 / 读数怎么说「为什么」**：全部指标由 `model.js` 从画布上每一片纸的真实几何包围框、实际重叠面积、主角被遮挡比、相邻叠压材质对、实时栅格化留白占比与光学重心单真源实算，可检出 8 类错态——「主角被埋」「散片孤贴（重叠 0% 退化为散乱便签）」「死叠闷堆」「同质糊脸」「高频纹样互殴」「废纸爆满（留白不足）」「片数过稀（不成拼贴）」「重心侧翻」。读数不只报数字，还用白话点出观众眼睛会怎么迷路、下一步该拖/移/撕什么。支持多组正当构图过关（非唯一答案），玩对后再把主角压回底层或加回废纸也会立即重新报错。
- **和最近 12 页的区别**：最近 12 页涵盖谜语四格、CSS 坐标盒、看板五列、渐变坡面、3D 多平面、中轴天平、3D 重门、手稿四边距、字母笔画、时间轴、16 拍乐谱与网络拓扑；本页是全库独有的**物理手撕纸片剪贴手工台**（直拖纸片 + 真实 Z 序叠压 + 纸材替换 + 撕片/纸篓增减），不可能原样套用到任何其他编号。

## 3. 版式骨架
忠实承袭 151 号原海报的手工拼贴杂志跨页语言（暖棉纸全出血底、手撕毛边纸块、半透明美纹纸胶带、银色回形针、深靛蓝标签条、零深色仪表盘侧栏、不锁 `100svh` 避开平板空洞）：
- **1440×900（2560×1440 舒展至 1800px）**：34px 极细纸尺顶眉下，左 36% 为原海报手撕标题纸片（牛皮纸衬底 + 胶带 + 示范叠层大标「拼贴 版式」+ 灰粉撕条 `COLLAGE LAYOUT`）接原海报手撕总述、带银色回形针的实时诊单索引卡与原海报四枚虚线分隔彩色关键词实况徽；右 64% 为题材切签 + 大幅 2D Canvas 拼贴手工台 + 紧贴底沿的精简图层/纸材/纸篓操作带，左右双栏自然齐底。
- **1024×1366 / 768×1024 平板**：顶置紧凑双列刊头，中段满宽手工台，底段并排诊单索引卡与操作带，不留大块空白。
- **390×844 手机竖屏**：极紧单行刊头与压缩手撕标题条后，等比 6:5 拼贴手工台与快捷操控条直落首屏并稳占 ≥46% 屏高，同屏可见实时诊单首句；下方接材质/纸篓与四枚关键词。
- **844×390 手机横屏**：左 56% 拼贴手工台与快捷条 × 右 44% 标题、题材切换与实时诊单并行，零横向溢出。

## 4. 配色和字体
- **逐点实采自 151 原海报**：暖棉纸底 `#F1EADF`（亮棉纸 `#F7F3EA` / 手撕纸 `#EBE3D8` / 索引卡 `#E7DBC4`）、牛皮纸 `#BD9B73`、美纹纸胶带 `#E3D4B8`、牛仔钴蓝撕纸 `#406A93`（浅底深钴字 `#294E73`）、芥末黄圆片 `#DCB151`（浅底深赭字 `#7B5811`）、灰粉撕纸 `#DAA4A3` / `#E2979D`（浅底错态深梅红 `#9B3441`）、云杉绿撕纸 `#517A67`（浅底深松绿字 `#2E5745`）、炭黑粉笔纸 `#141414` / `#181817`（03 节暗房底，暗底暖象牙字 `#F2ECE0`、亮芥黄 `#E8C163`、亮粉 `#F0A3AA`、亮松绿 `#88C9A9`）、设计要点深靛蓝签 `#2F3A78`。
- **字体搭配**：`Noto Sans SC`（400/700/900，承接原海报重黑印章体标题与清晰正文）+ **`Bebas Neue`**（400，最近 12 页 0 次使用，忠实还原 `COLLAGE LAYOUT` 窄高大写海报字）+ **`Libre Baskerville`**（400 正斜体，最近 12 页 0 次使用，还原海报右侧报刊书页残片衬线）+ **`Space Grotesk`**（400/600/700，最近 12 页 0 次使用，承接清爽数据读数与纸尺标签）。三款西文在最近 12 页全部零使用，全库唯一组合。

## 5. 节目录（7 节，相邻节绝不复用同种交互控件）
- **01 拼贴为什么有层次**（`Why layers feel alive`）：引出原海报总述与三条要点；配**五层轴测剥离滑轨**（拉动单一滑杆把底纸、纹理辅纸、主色衬纸、银盐主图、胶带标注五层沿轴测拉开，直观理解物理厚度的由来）。
- **02 材质反差定情绪**（`Material contrast sets mood`）：展开原海报第一条要点「对比材质与色彩，突出重点内容」；配**双列纸样对撞板**（点击左列衬底纸样 × 右列主体介质，实时比对肌理反差度与视觉抢戏风险）。
- **03 暗房：数量与留白线**（`Count and breathing room`，炭黑纸暗房版）：展开原海报第二、三条要点；配**逐片加贴压力测试器**（点 `+ 加一片 / - 撤一片` 从 1 片贴到 12 片 + 切换胶带/回形针收口，亲眼看画面越过 7 片后如何从丰富变杂乱）。
- **04 从贴纸画到杂志跨页**（`Where collage came from`）：核实史料讲透 1912 立体主义、1919–1921 达达与 Merz、1970s 朋克独立志、1992–1995 *Ray Gun*；配**四站档案标本签页**（每站附定制历史构图 SVG 示意）。
- **05 什么时候用，什么时候别用**（`When to use and avoid`）：配**六种真实场景翻转体检卡**（点击揭晓适合/禁用理由，温和点出拼贴牺牲扫读效率的边界，并用一句话链接同小类 140–150、152 全部 12 页）。
- **06 练一练：哪张拼贴成立**（`Practice · pick the sound collage`）：四张纯中性标签 `A/B/C/D` 同题材迷你拼贴，每项仅改一个变量，选后叠加诊断标注。
- **07 原海报与关键词**（`The original poster`）：`<img id="poster" src="poster.webp" draggable="false">` 可放大/拖动/Esc 关灯箱，并完整呈现原海报四枚彩色关键词徽章与三条设计要点。

## 7. 练习设计
- 题目：同一个「陶瓶与枝叶」概念情绪板，四张拼贴版面（标签仅写 `A` / `B` / `C` / `D`），哪张层次最稳？
- 四个选项各只差一个变量：
  - **A**：仅破「叠压关联」——6 片素材散开互不重叠（0% 重叠），退化为分散贴纸。
  - **B**：仅破「材质反差」——6 片全用密排格纸与报刊文字做底，高频纹理直接抢戏压死主图与标题。
  - **C（正确）**：6 片克制数量、手撕哑光钴蓝纸衬托置于顶层的银盐静物照，冷暖粗细纸材对撞清晰，留白约 41%，重心稳妥。
  - **D**：仅破「数量与留白」——同样好材质与主角置顶，但硬塞进 11 片素材，留白被压到约 11%，满版窒息。
