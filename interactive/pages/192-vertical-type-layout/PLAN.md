# 192 垂直文字排版（VERTICAL TYPE LAYOUT）设计方案

## 1. 一句话道理
汉字是等宽方块字，天然适合沿纵轴自上而下排成一列，再借由古籍简牍延续下来的「由右向左」列序与「行距明显宽于上下字距」的格式塔邻近分组，把节奏从横扫的效率切换成纵流的沉静秩序。

## 2. 开场玩具：宣纸立卷排字台（活体 2D Canvas 书卷 + 卷轴行距拉尺）
- **玩法**：忠实化用 192 号原海报右侧整幅宣纸立卷（深松绿半圆、赭金圆月、竖向「阅读起点」细线、乌丝栏竖虚线、朱红方印与原海报诗句《山川有声 · 岁月成诗》），并加入真实竖排日期落款（`春分 · 03月20日`）与可选第二题材（原海报《听雨 · 诗集》）。
  - 拖动卷轴底沿标尺拉柄（`data-perf-drag`，支持触屏、鼠标与键盘 ←/→，亦可直接在画布上左右拖动卷轴）连续拉合**行距（列间距 Leading）**；
  - 拖动纸卷下沿地脚拉柄或滑杆调整**单列字数（4–20 字/列）**；
  - 调整**字距（上下字间 Tracking）**；
  - 点按切换**行序（由左向右 / 由右向左）**与**标点混排（横标躺数 / 竖标＋纵中横）**；可开关视线与格式塔邻近透视层。
- **开场状态（0/4 错版，绝非已解）**：
  1. 行序颠倒：错误设为「由左向右」，主标落到最左，正文顺序倒读；
  2. 行字比倒置：行距压窄至 `1.14×`（列间净空 `0.14em`）而上下字距拉宽至 `+0.40em`，画布亮起朱红横向串行桥接线；
  3. 单列过长：拉到 `19 字/列`，超出原海报短卡/海报 `6–12 字` 舒展区，朱印紧逼底边；
  4. 横标躺数：逗号句号留在字格左下角、引号未转直排、日期 `03`/`20` 侧躺 90°。
- **怎样算玩错、读数如何解释「为什么」**：
  - 所有读数（行序、最长列字数、列间净空、上下字缝、行缝/字缝比、标点与数字状态）全部由 `model.js` 单一几何源实时算出，无假精确分数；
  - 玩错两头都会触发精准白话诊断：行距过窄报「横向串行（列间净空小于上下字缝，格式塔邻近律把左右字拉成横行）」；行距过宽（`>2.30×`）报「列散断气（像几根互不相干的孤柱）」；列长过短（`<6 字`）报「碎步断句（频繁换列打断语流）」；列长过长（`>12 字`）报「长柱憋气」；行序搞反报「入口倒置」；标点未竖排报「横标躺数」。
- **与最近 12 页的明显区别**：
  - 191 是贝塞尔路径控柄、229 是水平多栏报样拉宽、190 是全幅姜黄三栏图形诗、105 是粉绿对称天平、060 是瀑布叠卡。192 独有「由右向左」的东亚卷轴开合逻辑：把示范大标放在**右上**呼应阅读起点，主舞台是真正检验「列间净空 vs 上下字缝」「由右向左列序」「竖排标点与纵中横」的宣纸立卷排字台，别的编号无法套用。

## 3. 版式骨架
- **1440×900（桌面）与 2560×1440（宽屏）**：不锁 `100svh`。极细单行刊头下设「右启式」顶眉（右上置 3 列×2 行竖排示范 `<h1>`「垂直文字排版」与待校朱印，左上置原海报总述、题材切签与复原错版）；中段左 31% 为细双线古籍牌记风「立卷校勘签」与紧凑控参区，右 69% 为无重框宣纸大卷舞台与底沿一体化「行距卷轴拉尺（`data-perf-drag`）」。2560 下版心舒展至 `1820px`，画布按宽等比放大不缩成中条。
- **1024×1366 / 768×1024（平板）**：自然纵排不锁屏高，顶眉下接满幅等比立卷舞台与底沿双栏控参+校勘签，无缝衔接 01 节。
- **390×844（手机竖屏）**：单行压紧刊头与右上紧凑大标，首屏直接展示等比宣纸立卷（占屏高 ≥46%，圆月与半圆绝不压扁）+ 44px 卷轴拉尺 + 核心切换与实况诊单，说明文字退后。
- **844×390（手机横屏）**：切为左 44% 紧凑标题+诊单+速切 × 右 56% 立卷画布与拉尺，单屏全见不溢出。
- 正文八节在暖宣白（`#FBF8F2`）、宣卷米（`#F2EBE0`）、03 节深松绿暗室（`#133A35`）与原海报米纸（`#F7F3EB`）间交替展开。

## 4. 配色与字体
- **高保真像素取自 192 原海报**：
  - 外底米宣纸 `#F7F3EB`、浅宣白 `#FBF8F2`、内卷宣纸 `#F2EBE0`、浅石分隔 `#E7DFD1`
  - 深松墨黑 `#161B19`、次墨灰绿 `#46524E`
  - 深松石青绿 `#1E5F57`（原海报大弧与图标圆徽）、暗室深松 `#133A35`
  - 赭金圆月 `#E1AD54`（浅底文字加深为焦赭 `#855A0E`，暗底提亮为 `#E8B85F`）
  - 朱红方印 `#A93931`（暗底提亮为 `#F28277`，专作印章与错态警示）
- **字体搭配（全库唯一，且三款在最近 12 页零使用，不用 Noto Sans SC）**：
  - `zcool-xiaowei`（站酷小薇，窄长标题宋——近 12 页未用，用于示范大标、宣纸立卷大题与展卡标题）
  - `noto-serif-sc`（思源宋体 `400/700/900`——正文与竖排主体，正文内西文年份跟正文同字体防跳动）
  - `cormorant-garamond`（正体 `500/600` + 斜体 `500`——近 12 页未用，用于独立英文副标与刊眉）
  - `dm-mono`（`400/500`——近 12 页未用，用于读数刻度、年份牌与 CSS 声明）

## 5. 节目录（8 节，每节标题 ≤ 12 字，相邻控件不重样）
- **01 为什么先右后左？**（`Why right-to-left`）：4 步「简牍展卷」分步按钮动画 + 原海报 5 则深松绿圆徽要点拆解（串联 188 基线对齐、187 凸排标点）。
- **02 从竹简到屏幕**（`From bamboo to CSS`）：点击式年代碑签切换（商周秦汉简牍 → 1955–1956 报刊横排转向 → 2011 标点国标 → 2019 W3C 竖排标准），呈现不同时期的微缩字样与史实脉络（串联 193 水平文字排版）。
- **03 行距与字距别叫反**（`Leading vs. tracking`）：深松绿暗室；**二维平面相位坐标板（点击/拖动二维矩阵）**直观标定红区横向串行、金绿纵流带与灰区孤柱散架，并温和补正原海报底沿「字距」标注方位与 `6–12 字` 经验适用边界。
- **04 标点数字与西文**（`Punctuation & mixed script`）：**真实原生 CSS `writing-mode: vertical-rl` 可选字试验盒** + 三组胶囊开关（横标/竖标、数字侧躺/纵中横/汉字、英文正立/顺转 90°）+ 实时 CSS 代码条。
- **05 原海报三套应用**（`Poster applications`）：还原原海报底沿《茶之本味》《展览邀请》《听雨·诗集》三张竖排实景卡，配「一键翻成横排对比」翻面按钮。
- **06 什么时候别用竖排**（`When to avoid it`）：三组「翻车现场」场景签切换（代码报错 / 价格参数表 / 窄屏长文）体验强行竖排的阅读障碍，并指路 193、176、190、191。
- **07 练一练：四份展签**（`Practice · pick one`）：同一内容四张中性编号展签（甲/乙/丙/丁）点选作答，仅差单一变量，选后浮现结构检视标与原理解析。
- **08 原海报与关键词**（`Original poster`）：点击放大拖动、Esc 收起的原海报大图 + 行距/字距关键词 + 原海报小贴士。

## 7. 小练习设计
- **题目**：同一份茶事展签（《春山茶事 · 04月18日 / 听风煮茗，坐看云起。》），四种竖排法仅差一个变量，哪一张阅读最顺畅？
- **四项差异（中性标签：甲 / 乙 / 丙 / 丁）**：
  - **甲**：行距、列长、标点均合格，唯独**由左向右**反排，主标困在左侧、正文倒读；
  - **乙**：由右向左、标点合格，唯独**行距窄于上下字距**，格式塔邻近把相邻两列拉成横行串读；
  - **丙（正确）**：由右向左、主标立于右上阅读起点、单列 8 字、行距约 2.1× 明显宽于上下字距、标点右上移位且 `04`/`18` 纵中横正立、左下朱印收束；
  - **丁**：由右向左、行距列长合格，唯独**沿用横排标点**（句号顶在列首并贴左下）且数字与英文硬拆歪斜。
- **理由**：选定后逐卡显示红/青结构标记线，说明竖排成立必须同时满足「右起列序 + 行宽于字 + 适中列长 + 竖排标点与纵中横」。
