# 251 比例框 RATIO FRAME — 页面方案

## 1. 一句话道理
比例框把容器的宽高比与内部素材的原始尺寸解耦：先锁定画幅骨架（`aspect-ratio`）预占空间并统一视觉节奏，再以无畸变裁切（`object-fit` + `object-position`）装填内容，既消灭卡片参差与慢网跳屏（CLS），又避免素材被强行拉扁拉瘦。

## 2. 开场玩具
- **命名**：三框联动·比例装裱与裁切工坊（2D Canvas，标 `data-perf-drag`）。
- **视觉承袭**：1:1 转译 251 原海报的暖杏米纸（`#F7EDE3`）、绛红细线框、外圈虚线裁切安全框与四角 L 标、五重霞山落日矢量画幅、三大副框对照（主框 + 同源三卡联排）以及底沿「常用比例速查」对角虚线框与「窄 ← —●— → 宽」绛红实体滑尺。
- **怎么玩**：
  1. 在主画布（`data-perf-drag`）直接左右横拖，或拖动底沿原海报同款「窄↔宽」红点滑尺（支持键盘 `←/→` 微调），在 `9:16 (0.56)` 到 `21:9 (2.35)` 间连续推拉主框宽高比；
  2. 直接点击下方 5 枚带对角虚线的常用比例线框（`9:16` / `1:1` / `4:3` / `3:2` / `16:9`）切换目标画幅；
  3. 切换「统一比例框 开/关」、填充方式（`fill` 拉伸 / `cover` 满框裁切 / `contain` 留边完整）、取景焦心（`居中` / `偏上` / `偏下` / `右上落日` / `边缘偏切`），并可在三题材（`原海报 · 霞山` / `画廊 · 侧影`（纯剪影无五官） / `器物 · 拱窗`）间切换；
  4. 点击画布内红标警报可单步纠偏，点击「模拟慢网测 CLS」可在主画布与下方三卡联排处现场回放图片延迟加载时的布局下坠位移（`ΔY` px）。
- **开场初始状态（非答案）**：刻意停在复合坏态——「未启用统一比例框（三卡按原图高度参差错落，差高 66px，慢网下跳屏）+ 主框被硬塞成 `2.35:1` 极扁裂条 + `object-fit: fill` 强行拉伸（落日圆被压扁，形变比 `1.76×`）+ 焦心偏左」。
- **双向可玩错（绝不是随便点满就过）**：
  - 关闭统一比例框 → 下方三张混源原图（3:4 竖图、1:1 方图、16:9 宽图）高度参差，实算差高 `ΔH` 与慢网跳屏位移 `ΔY` 报警；
  - `fill` 强塞且框比偏离原图 > 12% → 实算纵横畸变率 `1.xx×`，报警「素材被压扁/拉瘦」；
  - `cover` 下比例过窄（< 0.72）或过宽（> 2.10）→ 实算画面裁失面积超过 45% 或核心主体（落日/人像头肩/主器）被切出框外（可见率 < 85%），报警「过度裁切」或「主体被切出框」；
  - `contain` 下比例与原图差距过大 → 实算空边（黑边/白边）占画框超过 28%，报警「留边空洞过宽」；
  - 偏心焦心把主体推出框外 → 实算主体可见率下降报警。
- **多组合法解**：打开统一比例框、无形变且主体完整、裁失与留边在合理区间内，均被 `model.js` 判为合法解，并按所选画幅给出对应语义评价：`1:1` 方正均权、`4:3` 平衡通用、`3:2` 摄影自然、`16:9` 宽屏舒展。
- **与最近 12 页的明显差异**：250 是绿底网格拉容器宽度看折列、249 是黄底拉高度看 flex 居中、208 是紫底拖列缝、163 是杂志跨页缩放、207 是粉底拖块落网格、077 是 3D 鸟瞰绕飞；251 是独一无二的**「多图同框装裱裁切与 CLS 占位检验台」**，动作完全源自 `aspect-ratio` + `object-fit` + `object-position`，无法原样套给其他编号。

## 3. 版式骨架
忠实转译 251 原海报「左 35% 画廊展签脊 × 右 65% 比例装裱工坊」暖杏红印版画双栏结构（零深色仪表盘顶栏、零圆角浮窗堆砌、绝不锁 `100svh`）：
- **1440×900 桌面**：主宽 `1380px`，左列（自示范破框绛红大标「比例框」+ 右下绯红圆印 + `RATIO FRAME` + 原海报三枚方框要点实况灯 + 绛红满底关键词横幅 + 原海报 `NOTE` 浅腮红单真源诊单与实时 CSS 匣）× 右列（动态大号比例标头 + 主框与三卡联排 2D 画布舞台 + 底沿 1:1 复刻「常用比例速查」线框与红点滑尺），两列自然平齐。
- **2560×1440 超宽屏**：容器放宽至 `1720px`，画布按比例宽阔展开，左右两列舒展不留空洞。
- **1024×1366 / 768×1024 平板**：自然折排为紧凑刊头 → 全宽画布与速查滑尺 → 双栏并排三要点与 `NOTE` 诊单，零垂直空洞。
- **390×844 手机竖屏**：顶部压紧为单行破框小标 + 实时状态签（约 70px），直接呈现等比主画布（占首屏 ≥ 46% 屏高，圆不压扁），紧跟红点滑尺与 `NOTE` 诊单首句，三要点与详述后置。
- **844×390 手机横屏**：切为左 55% 装裱画布与红点滑尺 × 右 45% 紧凑破框标题与 `NOTE` 诊单并行。

## 7. 练习设计
- **第 1 题（填充策略单变量）**：新闻流三列混源卡片（原图含竖图、方图、宽图），四个选项均为 `4:3` 外框，仅在 CSS 策略上不同：`A. aspect-ratio: auto`、`B. aspect-ratio: 4/3 + object-fit: fill`、`C. aspect-ratio: 4/3 + object-fit: cover`、`D. aspect-ratio: 4/3 + object-fit: contain`。正确答案 `C`（兼顾三列等高、零畸变与无空边）。
- **第 2 题（折中比例单变量）**：混装 3:2 横拍与 4:5 竖拍的混合画廊卡，四个选项均用 `object-fit: cover`，仅比例框不同：`A. 21:9`、`B. 16:9`、`C. 4:3`、`D. 9:16`。正确答案 `C`（4:3 离横竖两端裁失都最温和，不会像 21:9 切光竖图或 9:16 切光横图）。
- **第 3 题（作用边界单变量）**：带标题与摘要的商品/资讯卡，四个选项结构相同，仅 `aspect-ratio` 施加位置不同：`A. 只加在顶部封面容器`、`B. 加在整张图文卡片且 overflow: hidden`、`C. 同时写死 width: 320px; height: 260px; aspect-ratio: 4/3`、`D. 不写比例框也不写宽高属性`。正确答案 `A`（媒体容器定比、下方文字区自然流展，避免截字、规则失效与 CLS）。
