        01
        

          
框定边界，不压扁画面

          
DECOUPLE FRAME FROM SOURCE DIMENSIONS

        

      


      

        

          
原海报把比例框的三条价值写得极简：统一裁切（建立标准构图边界）、媒体适配（多平台稳定呈现）、视觉秩序（增强信息层级与稳定性）。落地到真实网页里，这三句话解决的是同一件事——把容器的形状权，从上传图片的随机尺寸手里收回来。

          
后台运营或用户传来的图从来不会整齐划一：手机竖拍是 2:3 或 3:4，社交封面是 1:1，横幅剧照是 21:9。如果让页面迁就原图高度，卡片墙底边立刻高矮错落；如果只锁死宽高却忘了管填充方式，浏览器默认 object-fit: fill 会把圆压成椭圆、把人拉成纸片。

          
比例框原语的解法干脆利落：外框只管 aspect-ratio 钉牢几何骨架，内图交给 object-fit: cover 按自身原比例放大铺满、干净裁去多余边缘。切换旁边四种真实 CSS 规则，看三张真实 DOM 卡片如何响应。

        02
        

          
常用比例从何而来

          
FROM 35MM FILM TO CSS ASPECT-RATIO

        

      


      

        

          

            
等面积同心框实验（Kerns Powers, 1984）

            
勾选几组历史标准比例：它们的面积完全相等，叠加在同一个中心点上，外包络与内切核恰好指向 16:9。

          

          
          

            
            
            
            
            
          

          

        


        

          

            
            
            
            
            
            
          


          


          
          

            说多了一点 · 细读原海报
            
原海报右上写着「重点推荐 4:3 · 平衡 · 经典 · 通用」，但在今天并不是所有场景都该无脑选 4:3：视频封面与电脑宽屏早以 16:9 为主流，35mm 摄影与图册多守 3:2，移动端竖屏短视频则以 9:16 或 4:5 为先。4:3 真正突出的，是在「混装横竖原图」时的折中耐看。

            
另外，原海报底部「常用比例速查」顺手把 3:2 排在了 16:9 右边；其实按宽高比由窄到宽算，1:1（1.00）< 4:3（1.33）< 3:2（1.50）< 16:9（1.78），3:2 比 16:9 更紧凑。本页顶部的速查标尺已按真实数值修正排序。

① 慢网加载对照：先立框，不踹字

              
网络稍慢时，图片总比 HTML 晚到半秒。「无比例框裸图」先让正文顶在顶部，图片蹦出来一瞬间把按钮狠踹下去（产生累积布局偏移 CLS）；「锁定 aspect-ratio: 4 / 3」提前占位，按钮纹丝不动。

② 一图四端：用 object-position 护住主体

              
同一张竖幅人物侧影（或霞山原图），要同时分发到 16:9 宽屏、4:3 列表、1:1 头像和 3:4 竖卡。切不同焦心，看哪一端会把人物头肩切掉。

            

            

              
              
            

          


          

            
            
            
            
          


          

            
          

          

        

      

    

  


  
  

    

      

        04
        

          
比例框与相邻原语

          
CSS EVOLUTION & PRIMITIVE COMPOSITION

        

      


      

        

          

            

              
              
            

          

          

          

          

            

              
aspect-ratio

              
钉牢外框宽高比，只锁宽或高一边（另一边保持 auto）才生效。

            

            

              
object-fit

              
决定媒体怎么塞进框：展示卡片多选 cover，图表与原作保留用 contain，避免 fill 强拉。

            

            

              
object-position

              
裁切发生时控制画面重心，人像常设 50% 18% 护住头肩。

            

          

        


        

          
原语分工：比例框只管「画幅壳」

          
在「网页与 UI / 布局原语」这一小类里，每个原语只做好一件小事。点选常见组合，看比例框和邻居如何叠套，绝不越权：

          

            
            
            
          

          


          
    
            
  • 243 堆栈：管纵向兄弟元素的均匀间距，比例框常作为其中一项。
    • 
            
  • 244 盒子：管容器内边距与边框厚度，包裹比例框与文案。
    • 
            
  • 245 居中器：锁住页面最大行宽并居中，不干涉媒体纵横比。
    • 
            
  • 246 簇群：管标签、按钮等行内小件的自然折行。
    • 
            
  • 247 侧栏原语：管固定侧栏与弹性主栏的分栏切换。
    • 
            
  • 248 切换器：在容器够宽时横排、够窄时整组切为竖排。
    • 
            
  • 249 封面原语：靠 min-block-size 与自动外边距让整屏主标垂直居中。
    • 
            
  • 250 自适应网格原语：自动决定一行放几列，每列里的封面交给比例框对齐。
    • 
            
  • 252 横向卷轴：让等高媒体条横向滑动，每张滑块常用比例框定形。
    • 
            
  • 253 悬浮层：管弹窗、角标等覆盖层级与定位。
    • 
            
  • 254 图标文字组合：管微小图标与单行文字的基线对齐。

        07
        

          
原海报与核心关键词

          
ORIGINAL POSTER & SPECIMEN

        

      


      

        

          
        


        

          

            NOTE
            
「比例框是构图的骨架。先确定框，再填充内容，让画面在不同场景中保持一致与平衡。」

          


          

            

              FRAME
              框定边界
              
先以 aspect-ratio 划定画幅疆界，不让随机原图撑破版面节奏。

            

            

              SCALE
              控制比例
              
宽度随容器流动，高度按比例锁定，无论桌面还是手机都不变形。

            

            

              CONSISTENCY
              保持一致
              
跨卡片、跨终端、跨慢网加载阶段，始终维持统一齐整的视觉秩序。
