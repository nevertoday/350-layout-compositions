# 161 章节扉页（CHAPTER OPENING PAGE）互动页设计方案

## 1. 一句话道理
章节扉页是书本内部的「视觉门框」：通过打破上一章密排正文的灰阶连续性（拉开天头沉降、大幅留白、撤除旧书眉、立起明确章标与氛围提示），让读者的工作记忆自然归档旧章节、重置注意力，带着预期走进下一板块。

## 2. 开场玩具
- **命名与核心动作**：**翻页推门 · 活体双页章节扉页排印台**（纯 2D Canvas 摊开书本对开双页，`data-perf-drag`）。
- **怎么玩**：
  - **画布横向拖动（`data-perf-drag`）**：在摊开的书页上左右横拖，像真翻书一样连续擦动三联跨页流——往左掀回「上一章末页密排正文」对照灰阶断层，居中停在「本章扉页跨页」做编排，往右掀进「本章正文起页」检验过渡承接；每一帧重绘真实卷页折光、书脊阴影、拱门门扇开合角与顶部实时「跨页灰度落差仪」。
  - **画布直点纠错**：直接点掉书页上用朱红标出的违规旧书眉、顶角页码、接排旧尾段或过载剧透字块。
  - **四维排印控轨 + 三题材切换**：调节天头沉降（0%–62%）、切换开章落位（接排同页 / 另起新页 / 左空右启 / 跨页门扉）、开关书眉/页码/首段顶格、切换内容提示态（平灰无号 / 精炼引语 / 剧透长墙 / 空壳无锚），并在「原海报 · 拱门书卷」「文学精装 · 沉降素扉」「年报画册 · 板块扉页」三题材间切换。
- **开场初始状态（不能已是答案）**：刻意停在 **0/4 混排失序错态**——新章直接接排在上一章末页下半截（未另起新页），天头沉降仅 4%、净留白仅 28%（与上章正文灰度落差仅 4%，几乎看不出分章），页顶仍挂着上一章旧书眉与顶角页码、首段照常缩进，章题与正文仅 1.15× 糊成一片。
- **怎样算玩错、读数怎么说**：由 `model.js` 从实绘双页坐标、实时墨水覆盖率（Ink Density %）、天头沉降比、字号比与中缝压字边界单真源核算 **9 类错态**：
  1. 接排粘连（未另起新页）；
  2. 灰阶落差不足（扉页太满、未形成呼吸重置）；
  3. 天头零沉降（标题顶死天头）；
  4. 天头沉底挤爆（> 52% 把标题与导语压出下缘）；
  5. 旧书眉/顶角页码窜章（仍伪装成普通正文页）；
  6. 层级平灰（章标/正文比 < 1.9×，找不到新章入口）；
  7. 剧透文字墙（塞入长段摘要沦为提要页）；
  8. 零锚点空壳（清光一切导致读者不知身处第几章）；
  9. 文字压脊吞字（跨页排版时关键标题横跨书脊装订沟）。
  - 读数不仅报实测值，更直白说明「读者翻到这一页时眼睛会怎样卡住/漏看」，并接受多组合法解：**原海报跨页门扉解**、**精装左空右启解**、**平装另起沉降解**。
- **与近期 12 页的区别**：
  - 不同于 160（黑绒暗室三栏 + 书店 2.5 米封面验视镜）、326（白墙删杂物）、325（宣纸折枝三联）、159（浮卡 Z 轴）、246（圆点簇群）、287（三栏设置 UI）或 075/076/204（三维投影/极坐标），161 做的是**唯一只有章节扉页才成立的「摊开双页书本翻阅流 + 跨章灰度断层 + 出版排印四尺」**。

## 3. 版式骨架
- **设计语言直承 161 原海报**：暖牛皮书纸底（`#EFDAC1`）× 无通用深色顶栏 × 拱门排印诊单 × 底沿 100% 全幅**手撕毛边深松绿纸带**（`#384435`）承载五枚陶红圆环实时关键词；绝不锁 `100svh`，彻底避免平板竖屏空洞。
- **1440×900（主宽 1380px；2560×1440 舒展至 1740px）**：单行书眉细线 → 紧凑双栏刊头（左：自示范「章节扉页」大标 + 随达标进度推开的微型松绿拱门徽 + 原海报总述；右：三题材切换 + 跨页灰度落差实时波形仪）→ 主区左 66% 摊开双页活体排印画布与翻页轨 ｜ 右 34% 拱顶排印标本诊单与四尺控轨 → 全幅手撕毛边深松绿五词实况带。
- **1024×1366 / 768×1024**：自然流排，刊头 → 全宽等比双页书台 → 左右并列诊单与控轨 → 手撕绿带 → 紧接 01 节，零空洞。
- **390×844**：压紧单行书眉与单行大标，题材切精简成单排，等比双页书台直占首屏 ≥45% 屏高，首屏下方立即可见单真源诊单首句；总述后置。
- **844×390 横屏**：左右并排（左 55% 等比双页画布 × 右 45% 紧凑刊头、诊单首句与核心控轨）。

## 4. 配色和字体
- **配色（逐像素实采自 `161.webp`）**：
  - 暖牛皮书纸 `#EFDAC1`、门内暖奶光 `#F4E7D7`、净读象牙纸 `#FAF3E8`、温砂暗影 `#D7C0A5`
  - 深松绿拱门与撕纸底带 `#384435`（深暗室 `#1F271E`、浅纸深松墨 `#2B3B28`）
  - 墨黑主字与门扇 `#121417`（次墨 `#3B4339`）
  - 陶红细弧/四角星/圆环 `#D7968F` / `#E8A69C`（暗底高对比亮陶红 `#F0B6AD`，浅纸安全窑红字 `#8C3227`）
  - 克制状态色：警示朱红（浅 `#A62626` / 暗 `#FF968E`）、通畅松青（浅 `#1D6344` / 暗 `#84DFB2`）
- **字体搭配（全库唯一，与 160 零重合）**：
  - `Noto Serif SC`（400 / 600 / 900，典雅书籍正文与大标）
  - `Cormorant Garamond`（400 / 600 / 700 正斜体，**近期 12 页 0 次使用**，章节罗马数字、英文引语与书卷衬线）
  - `Archivo`（500 / 700 / 800，**近期 12 页 0 次使用**，原海报气质宽稳英文副标与按钮）
  - `JetBrains Mono`（400 / 500，**近期 12 页 0 次使用**，天头沉降、灰度落差、页码等宽读数）

## 5. 节目录
- `01` **一页扉页，做完五件事**（Five roles of an opening）：五枚原海报关键词交互剖视器——点击任意陶红圆徽，高亮对应书页结构区；一句话链接区分 [160 封面版式] 与 [162 栏目开启页]。
- `02` **从红墨起句到天头沉降**（Where it comes from）：中世纪朱笔起首 → 活字右页沉降 → 契歇尔德/布林赫斯特/亨德尔的书籍建筑观 → 2006 门框效应；4 时代活体标本版面抽屉。
- `03` **跨过那道门：灰度与重置**（Resetting the reader's eye，深松绿暗室）：解释 161 拱门隐喻与页间灰度落差；交互「24 页书口速翻节律仪」（滑轨调扉页呼吸等级 + 3 秒速翻模拟），并温和补充「说多了一点」（区分扉页与 [164 目录版式]/[165 索引版式]）。
- `04` **四把排印尺：排稳一页扉页**（Four typographic levers）：沉降比、奇偶页、去书眉顶格与跨脊防吞；交互「印张页耗与中缝安全测算台」（章节数 × 起页策略双维实时演算）。
- `05` **五种出版物，五副扉页骨架**（Five publishing contexts）：小说 / 教材专著 / 艺术画册 / 年报提案 / 电子书五联结构蓝图切换；顺带一句话链接 [163 特写跨页]、[166 图录版式]、[167 引语主导版式]。
- `06` **什么时候别用章节扉页**（When to skip it，深墨暗室）：门比屋大、字典索引、严控印张、短屏网页四大禁区；交互「四场景对比切换器」（对比硬加扉页 vs 轻量分段）。
- `07` **练一练：哪张扉页真正成立？**（Practice · pick the strongest opener）：同题同纸四份第二章扉页，仅标 A/B/C/D，单变量差错；选后在四图同步显影沉降线、书眉告警、灰度值与脊沟区。
- `08` **原海报与五个关键词**（The original poster，深松绿展墙）：可点击放大、拖动、Esc 关闭的 161 原海报与五枚陶红圆环关键词及规定页脚。

## 7. 练习设计
- **题目**：同一本建筑随笔集进入第二章《纸页间的停顿》，四份双页打样（方案 A / B / C / D，标签全中性）只差一个排印变量，哪一份真正成立？
- **四选项单变量区分**：
  - **方案 A**：天头零沉降且顶行仍保留上一章旧书眉与顶角页码（其余层级、留白与中缝均正常）。
  - **方案 B**：沉降、无书眉、右页起章皆对，但在扉页硬塞 6 条细碎摘要与双栏小图，净留白骤降至 31% 沦为提要页。
  - **方案 C（正确）**：左页轻留白、右页 30% 天头沉降、撤除书眉并将页码下沉底心、章号与标题层级分明配一句精炼导语、首段顶格起笔，跨页灰阶落差充足且避开中缝。
  - **方案 D**：沉降、无书眉与净留白都干净，却把主标题横跨书脊中缝排布，关键字被装订沟直接吞折。
