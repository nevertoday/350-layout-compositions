# 256 双列页面（TWO-COLUMN LAYOUT）互动方案

## 1. 一句话道理
当视口变宽，单列长行会让视线折返疲劳，也难以同时并置两组信息；把画面沿一条清晰的中缝纵分为两个平行区域，靠顶沿/基线对齐、克制的栏间中缝、视觉配重平衡与明确层级，就能同时缩短单行阅读跨度并建立高效的对比与并行秩序。

## 2. 开场玩具
- **命名**：双列脊线与配重排印台（Two-Column Spine & Balance Loom），纯 2D Canvas（标 `data-perf-drag`），1:1 承袭 256 原海报暖米亚麻底、深林松绿、灰豆青与暖琥珀日轮的双语应用示例（支持「原海报·双语对读 / 产品方案对比 / 图文专题页」三题材切换）。
- **怎么玩**：
  - 在画布上**左右横拖**（或拖中央竖向分栏脊线）连续调节左右栏宽比（22:78–78:22），两栏真实中英文内容同步逐行重排，并在左侧原海报同款「二分圆徽标」上实时联动；
  - **直接点击**画布内的图块（拱窗山水图 / 几何太阳卡 / 要点列表）把模块跨中缝在左栏 ⇄ 右栏之间调换位置，亲手改变左右两栏的视觉墨量与高度配重；
  - **上下拖右栏顶沿对齐钮**（或用方向键 `↑`/`↓` 与对齐控条）制造或修正跨栏顶沿/基线错位（-44px 到 +48px）；
  - 调节**栏间中缝宽度**（0px–92px）与**标题层级反差**（拉平 / 分明 / 双核抢戏），并可叠加显示浏览扫视视线与基线标尺。
- **开场初始态（刻意处于 0/4 复合错态）**：
  - 栏宽比停在 **72 : 28**（左栏过宽、右栏被挤成碎字窄条）；
  - 栏间中缝仅 **6px**（跨栏文字紧贴，产生横向穿栏串行）；
  - 右栏顶沿下沉 **+36px**（顶线与对照行全面错位）；
  - 两幅主图同时堆在左栏，左栏实测视觉分量约 **66%**，右栏失重悬空，且标题与正文层级拉平。
- **怎样算玩错、错了读数怎么说（model.js 单真源，双向错态）**：
  - `对齐 ALIGNMENT`：右栏下沉（>+8px）或上翘（<-8px）均判错，读数直接报实绘像素落差，并说明平行对照锚点断裂；
  - `平衡 BALANCE`：栏比过偏左（>66%）挤碎右栏、或过偏右（<34%）挤碎左栏，以及实绘左重（>63%）或右重倒挂（>63%）均判错，说清视觉重心如何倾斜；
  - `浏览 SCAN`：中缝过窄（<16px）触发「跨栏串行」并画红虚线错读路径；中缝过宽（>68px）触发「双栏割裂」成两座孤岛；均给出视觉原理；
  - `层级 HIERARCHY`：标题与正文尺度拉平（无入口）或双栏同时满额粗大（双核打架）均判错。
  - 接受多组合法解：**50:50 对等对比解**、**60:40 主次阅读解**、**38:62 图文并置解**。
- **与最近 12 页的区别**：
  - 255 单列页面是拖单一内容走廊宽度与纵向模块排序；299 自适应网格是拖外容器看多列自动装箱与 SPAN；256 聚焦**两个平行区域的互相挤压、跨中缝调换模块配重、跨栏基线对齐与中缝串行/割裂临界**，视觉与操作都无法套用到单列或三列网格。

## 3. 版式骨架
忠实转译 256 原海报自身的「左 35% 概念与要点栏 | 1px 通高竖线 | 右 65% 双列应用示例与深绿提示带 + 底沿通栏豆青宣言条」结构（零深色通用顶栏、零独立圆角仪表盘侧箱、不锁 `100svh` 避平板大空白）：
- **1440×900**（主宽 1380px，2560 舒展至 1680px）：左栏自示范双行大标「双列 / 页面」+ 活体二分圆徽标 + 4 枚深林/豆青圆徽「设计要点 KEY POINTS」实况灯，右栏顶三题材切签 + 活体双列排印画布 + 原海报同款深松绿灯泡单真源诊单带 + 精简操轨，底沿通栏圆角豆青宣言条与合法/试错快捷预设；两栏底部齐平无空洞。
- **1024×1366 & 768×1024**：自然流排，顶紧凑双列刊头（大标配二分圆徽）→ 满宽活体画布与深松绿诊单带 → 2×2 齐底设计要点网格 → 豆青底条。
- **390×844**：单行压紧刊头 + 题材切签，等比活体双列画布稳占首屏 ≥ 46%，紧接深松绿诊单首句与一键纠偏钮，总述文字与四条要点置后，零挤压变形、触控区 ≥ 40px。
- **844×390 横屏**：左 56% 题材切签与等比双列画布 × 右 44% 紧凑标题与四项设计要点并行。

## 4. 配色和字体
- **逐像素实采自 256 原海报**：
  - 暖米亚麻纸 `#F9F1E6`（亮象牙 `#FDFBF6`、豆青浅雾 `#EDF2E9`、暖砂纸 `#F3EBD8`、线框浅底 `#F3EFE1`、竖隔细灰线 `#ACA9A1`）；
  - 标志深林松绿 `#255739` / `#1C4529`（03/06 暗室底 `#143321` / `#173824`、暗舱 `#1D442D`、浅纸深墨绿字 `#194129`）；
  - 标志灰豆青 `#B1C3A6` / `#C3CFB4` / `#95AE8F`（暗底亮青字 `#B9D4B0`）；
  - 标志暖琥珀日轮 `#EDB146` / `#F5BA53`（浅纸安全深琥珀 `#8A5600`、暗底亮琥珀 `#F7C768`）；
  - 纯炭黑主字 `#141714`（次墨 `#474E46`），克制以陶朱赤 `#B23322`（暗底 `#FF8A7A`）标错态、松翠 `#1B6B46`（暗底 `#6EE0A8`）标通过。
- **字体搭配**（全库唯一，与 255 零西文/等宽重合，`EB Garamond` 正斜体在近 12 页 0 次使用）：
  - `Noto Sans SC`（400 / 500 / 700 / 900）中文标题与正文
  - `Sora`（400 / 600 / 700）英文几何无衬线标题与小标
  - `EB Garamond`（400 / 600 正体 + 400 斜体，近 12 页 0 次使用）独立英文典籍引语与历史年代标饰
  - `IBM Plex Mono`（400 / 500 / 600）栏比、中缝像素、标尺与 CSS 代码

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻节不复用同款控件）
- `01` **为什么两栏比宽单栏好扫** (`WHY TWO COLUMNS BEAT ONE WIDE TRACK`)：对比宽屏单栏折返疲劳与双列并行优势（一句话链接 255 单列页面）；交互：三任务场景切卡 + 实时视线行程对照动画画布。
- `02` **比例、中缝与对齐铁律** (`RATIO, GUTTER & ALIGNMENT BLUEPRINT`)：拆解 50:50 / 60:40 / 38:62 分栏分工（一句话链接 258、259、267）与中缝防串行法则；交互：原海报同款线框蓝图 4 项结构切开关 + 实时 CSS Grid 声明。
- `03` **眼动偏左与扫描陷阱** (`LEFT BIAS & SCANNING TRAPS`)：深林暗室，温和修正原海报「顺应从左到右」说法，引入 NN/g 左半屏偏置与 Zigzag 降效实证；交互：三模式眼动热区回放画布与分步帧进器。
- `04` **双列版式从哪来** (`FROM CODEX FOLIO TO CSS GRID`)：1455 古腾堡 42 行圣经 → 1981 米勒-布罗克曼网格系统 → 2010 马科特响应式网页 → 2016–2017 CSS Grid Level 1；交互：四纪元横轴切页与可切换结构演变图纸。
- `05` **什么时候用，什么时候别用** (`WHEN TO USE & WHEN TO AVOID`)：适用场景与四类禁用边界（重点指出顺序表单误用双栏的隐患，链接 255 / 257 / 260 / 268）；交互：视口宽度拉尺 + 「硬撑双栏 vs 响应式折单列」实时对比器。
- `06` **小练习：哪版双列最稳** (`TWO-COLUMN PRACTICE · PICK THE STRONGEST`)：深林考场，四版订阅对比双栏单变量排错练习；交互：A/B/C/D 独立图框选项卡与即时结构解析。
- `07` **原海报与关键词** (`ORIGINAL POSTER & SIBLING PATTERNS`)：可放大拖动的 256 原海报、双语关键词与同小类 255–268 导览链。

## 7. 练习
- **题干**：桌面端产品定价页要用双列并列对比「标准版」与「专业版」，以下四版草图内容相同、均为 50:50 等宽，但在**中缝、顶沿对齐与视觉配重**上各变动一个变量，挑出最稳的一版。
- **四选项（中性标签 A/B/C/D + 同句式纯参数描述，各只差一个变量，答案在 C）**：
  - **A**：中缝 6px · 顶沿齐平 · 左右配重 50:50（仅中缝过窄 → 跨栏串行）。
  - **B**：中缝 32px · 右栏下沉 44px · 左右配重 50:50（仅对齐破坏 → 价格与要点无法横向直扫对比）。
  - **C**：中缝 32px · 顶沿齐平 · 左右配重 50:50（**正确**：有清晰纵缝隔断、横向对照行齐平、视觉重心稳定）。
  - **D**：中缝 32px · 顶沿齐平 · 左右配重 78:22（仅配重失衡 → 左栏叠放双图与附注、右栏仅留三行文字，视觉左倾）。
