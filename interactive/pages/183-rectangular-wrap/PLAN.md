# 183 矩形绕排（RECTANGULAR WRAP）互动页方案

## 1. 一句话道理
矩形绕排用规整的直线边界把图块与正文隔开，既能把图片、色块或信息盒稳妥地嵌进文字流，又能为眼睛保留平直、可预测的换行起止边缘与网格秩序——前提是守住避让距、行长底线，且不让同一句话被居中图块拦腰劈断。

## 2. 开场玩具
- **名字**：活体蓝图排印台（Live Modular Wrap Blueprint，2D Canvas 标 `data-perf-drag`）。
- **怎么玩**：
  - 在 1:1 承袭 183 原海报深松绿底（`#01473F`）与暖金矩形块（`#FEC43E`）的开放排印画布上，直接**拖动黄金矩形图块**改变停靠位置（贴左 / 居中 / 贴右 / 上下跨行），直接**拖拉图块左右/四角尺寸柄**改宽窄与高度，或直接**拖动外围虚线避让框**调节避让距（水平拖画布空白区/图块均可流畅推动图块停靠与宽度，兼顾触屏竖向滚动与 `data-perf-drag` 帧率测试）。
  - 顶部可切三套真实语境：**原海报·黄金色块**（完整还原 183 原海报正文）、**杂志内页·建筑摄影**、**课件页面·要点信息盒**。
  - 下方精控排印尺可切四种绕排几何（**跨栏单流 / 贴边单侧 / 双栏夹图 / 跳行排布**）、调节横向与纵向避让距、切换左齐右参差（176）与两端对齐（179）以及基线网锁（188）。
  - 旁侧（宽屏右侧虚线隔栏，1:1 还原原海报）实时联动 **SVG「绕排示意」蓝图**与三行图例，动态点亮或告警四条顺时针虚线箭头；按 `Space`（或点「视线验真」）发射按实绘行段坐标行进的阅读扫描光束，肉眼可见跳槽断句、牙签回扫与啃边撞字。
- **开场状态（刻意停在错态，不先给答案）**：`0/4 · 啃边劈栏`——原海报语境下，48% 宽黄金矩形停在正中、`跨栏单流`把每一句都劈成左右两根约 5 字的牙签条、避让距仅 `2px` 啃边碰撞、底部未锁基线。
- **怎样算玩错、读数怎么说（单真源 `model.js` 从实绘行段数组双向检出 8 类错态）**：
  1. **居中劈栏跳槽**：单段文字被图块拦腰分成左右两截，读数直指「同一句话被迫跨越图块跳读，读者会分不清先读左栏还是跨图续读」。
  2. **啃边碰撞（避让距 < 8px）**：字脚贴死图块金边，读数说明图底边界发黏、失去呼吸感。
  3. **牙签窄行（侧边行长 < 9 字/行）**：图块太宽把文字压成短促碎行，读数提示回扫频次翻倍，并建议缩窄图块或切「跳行排布」。
  4. **留白漏气（避让距 > 38px）**：避让过宽导致图块像孤岛脱离正文，压缩有效版心。
  5. **窄栏白河**：侧边不足 14 字仍硬开两端对齐（179），读数提示字距被拉出明显空隙。
  6. **孤行卡边**：图块上缘或下缘仅留 1 行孤立碎行。
  7. **图块过微（面积占比 < 18%）**：缩成小邮票失去核心锚点作用。
  8. **基线失锁**：图块下方续接正文偏移整倍行距，跨区节奏脱节。
- **合法多解（不只一种答案）**：贴右稳排解（左缘全程笔直）、贴左稳排解、双栏夹图解（揭示原海报用两段独立短栏夹图的真实结构）、大图跳行解（宽图超过 60% 时干脆上下排布）。
- **与最近 12 页及邻号差异**：
  - 邻号 182（轮廓绕排）是乳白棉纸 + 柿红有机剪影（陶瓶/龟背叶）的曲线贴边；本页 183 是深松绿全幅蓝图 + 黄金直边矩形的停靠、宽窄、四边避让、跨栏单流 vs 双栏夹图 vs 跳行排布的工程排印台，且独有联动 183 原海报标志性的「绕排示意」顺时针虚线箭头蓝图。
  - 与 181 蜜桃粉偏轴盘、180 冷灰强拉筋、097 宣纸天平、099 炭黑巨日、098 象牙比例尺、096 陶红主次盘、094 午夜星图等在玩法、色彩、骨架与字体上全部彻底区分。

## 3. 版式骨架
- **忠实转译 183 原海报「深松绿双区建筑蓝图展板」骨架（不锁 `min-height: 100svh`，避免平板留白）**：
  - 顶部刊头 1:1 复刻原海报「左 66% 自示范巨标『矩形绕排 / RECTANGULAR WRAP』| 细竖线 | 右 34% 三行导语与短横杠 + 三语境切签」。
  - 主舞台 1:1 复刻原海报「左 68% 开放式活体排印画布 + 底沿精控排印尺 | 细竖虚点线 | 右 32% 活体『绕排示意』蓝图与三行图例 + 单真源白话诊单卡」，严丝齐底。
  - 底沿细横线承接原海报五枚斜杠关键词 `区块 / 模块 / 留白 / 环绕 / 秩序` 并接入实时状态探针。
- **1440×900 & 2560×1440**：1440 下主宽 1380px，首屏完整呈现刊头、70/30 双区画布与绕排示意、排印尺与底沿五词；2560 下舒展至 1640px，绝不缩在中间。
- **1024×1366 & 768×1024**：自然流纵排，满宽等比画布配下方等高双列（左蓝图示意、右白话诊单），零大段空白。
- **390×844（手机竖屏）**：压紧单行刊头与三语境切签，将导语与图例后置，让等比画布稳占首屏 ≥ 46%，折线内直接可见诊单首句、主滑轨与校准/验真键。
- **844×390（手机横屏）**：左 56% 活体排印画布 × 右 44% 紧凑刊头、诊单与核心快捷控制并行，无压扁溢出。

## 4. 配色与字体
- **实采自 183 原海报色值**：
  - 深松绿底场 / 暗室：`#01473F`（原海报主底）、`#00453E`（微深层次）、`#01352F`（03/06 暗室）、`#002823`（页脚极深松绿）
  - 招牌暖金琥珀块：`#FEC43E` / `#FFC540`（矩形图块核心、蓝图框线；浅纸高对比深赭金字 `#8A5600`）

  - 节制功能色：错态告警珊瑚红 `#FF6B57`（深底）/ `#B52B1D`（浅底）；稳态松翠 `#5CE0A8`（深底）/ `#0B6B4D`（浅底）

  - `Noto Sans SC`（400 / 500 / 700 / 900）：现代几何黑体，呼应原海报平切大标与正文可读性
  - `Rubik Mono One`（400，近 12 页 0 次使用）：方块感全大写等宽展示字，用于 `RECTANGULAR WRAP`、`NO. 183` 与节号 `01`–`07`
  - `DM Serif Display`（400 正体 + 斜体，近 12 页 0 次使用）：高反差杂志衬线，用于英文副题与刊头装饰韵味

## 5. 节目录（每节 h2 ≤ 12 字，相邻节不重复控件）
- `01 为什么矩形最耐看`（MODULAR VISUAL ORDER）：引用原海报总述，温和说明原海报居中双侧 5 字短行属于概念示意；交互为「直缘 vs 阶梯：左缘回扫散点对比仪」（SVG 对比切换）。
- `02 四边避让与基线锁`（STANDOFF & BASELINE）：展开原海报第三段，讲避让距经验值、帽高齐顶与基线落底、对齐搭配；交互为「排印显微四边游标尺」（四向独立偏置微调 + 2.5× 蓝图放大镜 + 实时 CSS/InDesign 映射）。
- `03 单栏、双栏与中缝`（COLUMNS & GUTTER）：展开原海报「杂志内页、信息图表、课件内容页」三场景，讲跨中缝与模块跨栏；交互为「网格积木铺排台」（1/2/3 栏切换 + 直接点击网格单元放置图块验真）。
- `04 从铅活字到 CSS`（WHERE IT COMES FROM）：梳理 1493/1499 木刻活字锁版 → 1981 瑞士网格 → 1988 PageMaker 3.0 自动绕排 → 1996 CSS1 `float` 与后续标准；交互为「四代排印工艺解剖卡片轨」。
- `05 什么时候别用它`（WHEN NOT TO USE IT）：讲窄屏强绕、拉链交替、不规则剪影（链 182）、列表缩进（链 185/186）、跨栏大标（链 184）等边界；交互为「栏宽挤压压力测试滑轨（720px → 320px）」对照硬绕翻车与断点全宽堆叠。
- `06 四选一：哪一版最稳`（PRACTICE · SPOT THE WRAP）：3 题递进式单变量四选一测验，全中性方案 A/B/C/D 配实时绘制的微缩版式图，作答后给出具体视觉理由。
- `07 原海报与关键词`（ORIGINAL POSTER）：原海报可缩放拖动灯箱 + 五个原海报关键词释义 + 同小类相邻编号导航与页脚。

## 6. 核实来源
- **1499《寻爱绮梦》（*Hypnerotomachia Poliphili*）**，Aldus Manutius 威尼斯印行、Francesco Griffo 刻字（大都会艺术博物馆藏品页 `https://www.metmuseum.org/art/collection/search/365341` / `https://www.metmuseum.org`）。
- **1981《平面设计中的网格系统》（*Grid Systems in Graphic Design / Rastersysteme für die visuelle Gestaltung*）**，Josef Müller-Brockmann 著，Arthur Niggli 出版。
- **1988 Aldus PageMaker 3.0**：正式引入自动文字绕排（Text Wrap）与避让距（Standoff）（1985 年 1.0 版尚无自动绕排）。
- **1992《字体排印风格要素》（*The Elements of Typographic Style*）**，Robert Bringhurst 著，Hartley & Marks 出版；以及 Ellen Lupton《字体设计思考》（*Thinking with Type*）关于行长（45–75 字符经验区间）的论述。
- **1996-12-17 W3C CSS Level 1 Recommendation §5.5.25 `float`**（Håkon Wium Lie & Bert Bos）：`https://www.w3.org/TR/REC-CSS1/`。
- **W3C CSS Exclusions Module Level 1（`wrap-flow`）**：`https://www.w3.org/TR/css3-exclusions/`。
- **W3C Requirements for Japanese Text Layout (JLReq) §4.3 图版配置**：`https://www.w3.org/TR/jlreq/`。
- **Adobe InDesign 官方文档「Wrap text around objects」**：`https://helpx.adobe.com/indesign/using/text-wrap.html`。

## 7. 练习设计
- **3 题单变量四选一**，选项只写中性标签 `方案 A / B / C / D` 与客观几何标注，绝不泄露好坏：
  1. **题 1（停靠与左缘锚点）**：同文同图（40% 宽），四版仅差水平停靠位（A 居中单流劈栏 / B 贴左单侧 / C 贴右单侧 / D 偏左 18% 留微缝）；正确答案 **C**（单栏长文护住从头到尾笔直的左起跑线，无跳槽也无回扫换轨）。
  2. **题 2（避让距与基线对齐）**：同贴右图块，四版仅差四边避让与底缘落点（A 四边 0px / B 内侧与底 16px、外缘 0px 齐栏边且底落基线 / C 四边 44px 孤立 / D 外缘内缩 16px 且底偏半行）；正确答案 **B**。
  3. **题 3（68% 宽图策略）**：宽幅建筑图入单栏，四版仅差绕排机制（A 贴右挤出 6 字侧条 / B 居中双侧各 3 字 / C 跳行排布上下留整行距 / D 强压成 15% 邮票图）；正确答案 **C**。
