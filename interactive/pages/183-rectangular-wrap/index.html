01

为什么矩形最耐看

MODULAR VISUAL ORDER

“矩形绕排是一种以矩形图块为核心的版式方法，文字根据图块的边界进行环绕排布，使内容与图形形成稳定的视觉关系，同时提升信息的阅读效率与层次感。” — 183 原海报总述

文字天生是按水平基线排成的矩形阵列，图片、摄影与图表也大多装着方形画框。当你用直线矩形把图文隔开，眼睛每读完一行向左回扫时，落脚点始终钉在一条笔直的竖线上——这是不规则曲线很难同时给到的阅读安定感。

在实际项目中，正如原海报所述，矩形图块既可以是摄影照片，也可以是纯色块、数据图或摘要信息容器。它与 182 轮廓绕排 最大的分野在于：轮廓绕排追求画面表情与有机趣味，而矩形绕排优先服务于长文效率与网格秩序。

海报图示简化了一点

细看本页底部 183 原海报的中央示范：那块黄金矩形居中夹在左右两段正文之间，每侧每行只有 5–6 个汉字。它之所以能读通，是因为左右本来放了两段独立短文而不是一句话跨图跳读；作为教学概念海报非常直观，但在真实杂志或网页长文里，5–6 字的窄条会让换行过于急促——实战中要么贴齐一侧栏边，要么像开场台的「双栏夹图解」那样给足每栏行宽。

02

四边避让与基线锁

STANDOFF & BASELINE LOCK

排印显微四边游标尺

分别调整贴右图块的四边避让距（px），观察外缘齐栏、文字气口与 CSS 映射。


            

          


          

            

              “在排版时，需注意图块与文字之间的间距、行长控制以及对齐方式，以保持版面的统一性与专业感。合理的留白与环绕节奏，是实现高质量矩形绕排的关键。”
              — 183 原海报细则
            

            
    
              
  • 
                1. 四边不等距，外缘归零：新手常给图块四边设同一个避让值，结果把贴边图块往版心里面推了一截。正确做法是「接触文字的面留 0.75em–1.5em（16px 正文下约 12–24px 经验值），贴齐页边或栏边的外缘设为 0px」。
              
    • 
              
  • 
                2. 顶齐帽高，底落基线：图块上缘对准旁边首行文字的方块顶（拉丁字母的帽高），而非行距顶部的空白；图块高度加上底部避让距凑成整倍行距，下方恢复通栏时就能丝滑落回 188 基线对齐 网格。
              
    • 
              
  • 
                3. 行长守底线（经验值）：西文长文舒适行长通常为 45–75 字符（Ellen Lupton 与 Robert Bringhurst 均作类似建议）；中文横排侧边绕排时，经验上至少守住 12 字/行，跌破 9–10 字时就应缩图或改用跳行排布。
              
    • 
              
  • 
                4. 窄绕用左齐，宽绕才两端：被图块挤窄的文字区优先配 176 左对齐右参差（右贴文字时亦可用 177 右对齐左参差 作短注）；若强开 179 两端对齐，窄行里极易撕出「白河」，更绝不可套用 180 强制两端对齐。
              
    • 
            

          

        

      

    


    
    

      

        

          03
          

            
单栏、双栏与中缝

            
COLUMNS & GUTTER WRAP

          

        


        

          原海报点名了矩形绕排最常见的三大战场：杂志内页、信息图表与课件内容页。真正的编辑排版很少在孤立单栏里硬塞居中图——随着栏数从 1 栏升到 2 栏、3 栏，矩形图块开始跨栏沟（gutter）借势，长出截然不同的空间呼吸。
        


        

          

            

              
              
              
            

            点击下方不同落位，查看矩形图块如何借栏线与中缝成立
          


          

          

        


        

          

            
杂志内页 · 跨中缝引语

            
在双栏正中跨过栏沟放一枚矩形引语块或竖图：左栏文字只避让左侧，右栏文字只避让右侧，绝无单句跨图跳读的风险。

          

          

            
信息图表 · 模块对齐栏沟

            
数据卡片与注释文字共享同一套矩形网格宽窄，图块外缘与栏线完全咬合，读者一眼分清「图示区」与「解读区」。

          

          

            
课件内容页 · 要点信息盒

            
把核心定义或公式装进高对比矩形色块并贴齐页面一侧，正文沿直线展开推导，投影远看层次依然清楚。

什么时候别用它

            
WHEN NOT TO USE IT

          

        


        

          

            

              矩形绕排再稳妥，也有明确的失效边界。凡是碰到下面五种情况，硬用矩形绕排只会帮倒忙：
            

            
    
              
  • 
                1. 手机窄屏强行侧绕：当容器窄于约 480px（经验阈值）时，图块旁的正文会立刻塌缩成 5–7 字碎行。网页设计应在窄屏断点主动取消 float，改回上下全宽堆叠。
              
    • 
              
  • 
                2. 多张小图左右交替排成「拉链」：读者刚适应左缘缩进，隔两行又突然右缘缩进，版面碎裂不堪；不如把小图合并成整块图组。
              
    • 
              
  • 
                3. 主体轮廓斜长且四角大块发空：遇到斜伸花枝、器物剪影或人物侧影，矩形外框会围出大片空三角，应改用 182 轮廓绕排。
              
    • 
              
  • 
                4. 编号列表、表格与公式块：依赖统一缩进对齐的条目（见 185 悬挂缩进 与 186 首行缩进）被侧边图块挤压后极易错行，应避开侧绕。
              
    • 
              
  • 
                5. 跨栏主标题或装饰造字：多栏统领标题交给 184 跨栏标题，视觉张力交给 181 非对称字体排版，造型字归 189 形状文字、190 图形诗排版 或 191 路径文字；东亚文稿的竖横流向与行末标点细节，可另见 192 垂直文字排版、193 水平文字排版、187 凸排标点 与 178 居中排版。
              
    •

海报五词拆解

            
183 原海报底沿用斜杠串起五个关键词——它们恰好对应矩形绕排从选块到落版的完整检查链：

            

              
区块
先把图片、色块或信息盒定为视觉核心，体量足够撑住层级但不吞没正文。

              
模块
让矩形四边与栏线、中缝、基线网格对齐，成为版面结构的一部分。

              
留白
面向文字的一侧留 12–24px 缓冲气口，外侧贴齐栏边归零不塌陷。

              
环绕
优先贴边单侧或双栏独立绕排，杜绝单句跨图劈栏与过窄牙签行。

              
秩序
最终回报是清晰的阅读路径、稳定的回扫左缘与克制专业的信息层次。

            


            

              
落版前四步快检

              
    
                
  • 图块是否贴齐栏边或跨中缝，避免单段正文跨图跳句？
    • 
                
  • 贴边外缘是否归零、面向正文一侧留足 12–24px（经验值）？
    • 
                
  • 最窄一侧正文是否守住 12 字/行以上，否则改用跳行？
    • 
                
  • 窄屏（< 480px）是否设置了断点自动取消浮动？
