# 308 净单人镜头（CLEAN SINGLE SHOT）互动页方案

> 所属分类：影视画面构图 / 视角与镜头覆盖  
> 原海报总述：「一人 · 一瞬 · 一画面 让主体清晰，画面有呼吸。ONE SUBJECT. ONE MOMENT. ONE FRAME. KEEP IT CLEAN. LET IT SPEAK.」

## 1. 一句话道理

净单人镜头通过清掉前景遮挡与背景竞争元素、拉开主体轮廓与底色的明暗分离并在视线前方留出呼吸余量，让观众的视觉系统把轮廓归属权唯一交给这一个人，从而把整个画面的情绪与注意力收束到「一人、一瞬」上。

> **对原海报的温和厘清（正文 01 与 05 节标注小签）**：
> - 原海报写「少即是多，净即有力」，这里温和补充两点实际情况：第一，「净」不是把背景删成棚拍白板，而是剔除与主体**争抢注意力或切断轮廓**的干扰；第二，「净」并不天然高于「脏」，需要强调两人对抗或空间联系时，应主动切去 [309 脏单人镜头](https://layout.xiaoxiaodong.ai/309/play/) 或 [305 过肩构图](https://layout.xiaoxiaodong.ai/305/play/)。

## 2. 开场玩具：片场清场与月轮逆光取景台

- **载体**：高帧率 2D Canvas（标 `data-perf-drag`），1:1 承袭 308 原海报的暖珊瑚杏纸底、四角酒红 L 形取景框、淡奶黄圆月光池与深黑左侧侧影剪影（原海报剧本直接从页内 `#poster` 提取无虚线纯净剪影透明蒙版，零重复内联图片；另备「暗台·剧场独白」与「静室·窗畔凝思」两套纯剪影剧本，绝不画五官）。
- **怎么玩**：
  1. **画布内直接点击清场**：点击画面左侧闯入的同伴黑肩、右侧徘徊的背景路人、从头顶穿出的竖杆叠线，或后墙杂乱亮灯画框，即可像片场摄影指导喊「清掉前景 / 撤灯 / 清群演」一样当场移出或放回。
  2. **画布横向拖动（`data-perf-drag`）**：直接横向拖动画面里的淡奶黄圆月光池，实时对准或错开主体侧影轮廓，观察明暗图底分离与轮廓清晰度变化（触屏自动区分横拖与竖滚，绝不阻塞页面滚动）。
  3. **镜头光圈、光池半径与主体呼吸落位**：使用下方紧贴的原生滑块与开关调节光圈景深（`f/1.4–f/11`）、主体水平落位（视线呼吸余量）、景别尺度与光池大小。
  4. **按 `Space` 或点「0.8s 读图验真」**：模拟 24fps 切镜瞬闪与前 300ms 视线落点轨迹——杂乱时目光在前景肩、路人、亮灯间弹跳失焦；清净达标后视线一拍锁住人物侧影并顺势舒展进前方留白。
  5. **点击左侧 5 枚原海报酒红圆徽**：同步在取景台上点亮对应几何检验图层（清场边界 / 景深杂讯 / 轮廓对比采样点 / 视线呼吸空间 / 一眼可读热区）。
- **一打开是什么状态（0/4 复合错态，绝不先给答案）**：
  - 前景左缘闯入一片同伴黑肩（退化为脏单人）；
  - 背景同时混入一名路人剪影、一盏杂乱亮框壁灯与一根穿头竖杆；
  - 奶黄圆月光池被推偏到画面最右侧（`haloX = 0.84`）且偏暗，导致主角脸部侧影轮廓陷进暗珊瑚影中（实测轮廓明度比不足）；
  - 主角被挤到偏左面壁位（`subjectX = 0.33`），目光前方呼吸空间窒息。
- **怎样算玩错、错了读数怎么说（单真源双向检出 9 类真错态）**：
  - `model.js` 从实际绘制的剪影包围盒、轮廓采样点真实像素亮度比、干扰物几何重叠与视线前方净空统一计算：
    1. **前景脏边入画**：提醒画面已滑向脏单人，观众开始分神猜「对面是谁」；
    2. **背景杂人分心**：同框出现第二人剪影，不再是「一人一瞬」；
    3. **穿头竖杆叠线（Merger）**：背景竖线直插发顶，肉眼把背景线条误粘成人物轮廓；
    4. **杂乱亮墙抢戏（且光圈过小未虚化）**：后墙高对比亮灯在 `f/4+` 下硬边抢走视觉入口；
    5. **光池偏离 / 暗底粘连**：脸部侧影处轮廓明度比跌破安全阈，剪影边缘糊进阴影里；
    6. **光池过曝刺眼**：圆月亮度过高淹没柔和层次；
    7. **面壁窒息（视线余量过窄）**：主角太靠左缘，目光撞墙失去呼吸；
    8. **贴右切影（轮廓裁缺）**：主角过偏右缘，发髻或后脑被右框截断；
    9. **景别失衡（过远蚁缩 / 过紧顶额）**：人物太小淹没于空场或顶框压抑情绪。
  - **认可多组合法 4/4 解**：提供「原海报解」「情绪特写解」「留白呼吸解」三组预设，同时也认可用户通过「实体清场」或「极浅景深 `f/1.4–f/2.0` 溶化背景轻纹 + 清掉硬穿头杆」达成的任意合法净单人组合。
- **与最近 12 页及同小类 305/306/307/309 的明显区隔**：
  - 305 是暗炭黑底双机位过肩切镜、306 是海风蓝底推门第一人称、307 是暖羊皮纸满宽建筑广场退距、309 是暗橄榄 2.39:1 宽银幕俯拍滑轨制造脏前景；176/221/052/140/262/088/340/051/139/261 分别为排字、旁注、星爆、斜切杂志、顶栏导航、3D 晶体、幻灯削字、盘螺、无出血印检、三段网页。
  - 308 独创**暖珊瑚杏纸 × 左侧 5 枚酒红虚线圆徽探针 × 右侧 L 框奶黄月轮剪影清场取景台 × 底部整宽圆角细框核心要点/拍摄提示诊单盒**，核心动词是**片场清场剔杂 + 拖移逆光圆月托起纯剪影轮廓 + 释放视线呼吸空间**。

## 3. 版式骨架

- **1440×900（桌面端，主宽 `1380px`；2560×1440 舒展至 `1640px`）**：不锁 `min-height: 100svh`。忠实转译 308 原海报的左右双区展板 + 底部圆角通栏框：
  - 左栏 `35%`：大标「净单人镜头」（「净」字配极轻奶黄圆晕自示范）+ `CLEAN SINGLE SHOT` + 酒红短横 + 原海报总述 + 纵向 5 枚酒红圆徽实时探针（细虚线分隔）。
  - 右栏 `65%`：顶部单行场景切签与读图按钮 + 开放式 L 角月轮剪影画布 + 紧底 2 行精控操轨（清场点选 + 光圈/光池/落位滑块 + 多解/试错）。
  - 通栏底部：1:1 复刻原海报 `10px` 圆角酒红细框双联匣——左半「核心要点」动态单真源诊单 | 竖线 | 右半「拍摄提示」原话配右下角陶土斜坡与三脚架摄影机小景。
- **1024×1366 & 768×1024（平板）**：自然流排，绝无 `100svh` 空洞；768 下取景台满宽置顶，下方 5 枚圆徽双列齐底接通栏诊单盒。
- **390×844（手机竖屏）**：压紧单行珊瑚顶栏（~54px）与场景切签，总述与 5 枚圆徽移至首屏操作之后；取景画布保持近方等比（圆月永远是正圆不压扁），稳占首屏 ≥ 46% 屏高，折线内直露快速清场按钮、一键校准与圆角诊单首句。
- **844×390（手机横屏）**：顶栏压至 ~32px 一行，下方左 `54%` 等比取景画布 × 右 `46%` 紧凑诊单首句、一键清场与核心滑轨并行，零横向溢出。

## 7. 练习设计

- **题目**：同一场窗外晨光独白，人物面向左侧，四帧画面均锁定纯净背景（零路人、零前景遮挡）、相同 `85mm f/2.0` 景别与紧贴轮廓的淡奶黄逆光圆月，**唯一变量是人物在画框内的水平落位**。哪一帧真正做到了「主体清晰，画面有呼吸」的净单人镜头？
- **四选项（答题前只显示中性标签 `构图 A` / `构图 B` / `构图 C` / `构图 D`，绝不透露优劣或数值）**：
  - `构图 A`（`subjectX = 0.25`）：严重面壁，鼻尖几乎贴死左框，视线前方仅剩约 11% 净空，背后空出大片无意义留白。
  - `构图 B`（`subjectX = 0.37`）：最具迷惑性的偏左构图，轮廓虽完整、鼻尖未触边，但前方视线空间（约 23%）仍窄于脑后空隙，观看时仍有隐约前堵感。
  - `构图 C`（`subjectX = 0.62`）：**正解**，主体稳落右侧三分呼吸位，顺着左侧目光展开约 48% 舒展净空，轮廓完整且光池托底明晰。
  - `构图 D`（`subjectX = 0.87`）：过分挤向右缘，后脑发髻已被右框切掉一截，破坏了边缘完整度。
