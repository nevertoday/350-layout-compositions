01

模块为何兼得秩序与自由

MODULE GRAMMAR & THREE-STEP BUILD

很多初学排版的人会把模块系统和相邻的 172 网格系统 混为一谈。两者的分水岭其实很直白：网格系统靠贯通全页的隐形纵横标线把文字对齐，容器本身常常不显形；而模块系统是把信息直接装进显性、可重复的标准几何单元里，让每个单元像一块建筑砖或乐高积木，靠统一的基准倍比与缝隙彼此咬合。

原海报把这套文法拆成三个关键词：模块（先定死 1×1 基准单位与缝隙）、组合（多块按整数倍拼接成清晰结构）、变化（调整比例、位置与层级拉开主次）。

边界提醒

原海报强调「保持模块尺寸与间距的一致性」，但一致指的是都出自同一个基准单位 x 的整数倍，绝不是把整版铺满一模一样的 1×1 格子。在上面的工作台里点一次「全 1×1 僵化」就能立刻看见：秩序拉满却毫无大小变化时，页面会退化成冷冰冰的空白表格。

03

格斯特纳的 58 单元魔法

MODULAR LINEAGE · FROM MOVABLE TYPE TO CSS GRID

1041–1048

北宋毕昇活字印刷

沈括《梦溪笔谈》（约 1088 年）记载毕昇用等高胶泥单字块在铁范内拼排、印完拆版复用——这是文字史上最早把版面拆成「可替换标准单元」的实践。

1948 / 1950

勒·柯布西耶《模度》

建筑师勒·柯布西耶出版《Le Modulor》，以人体尺度结合黄金比与斐波那契数列建立红蓝双模数尺，用少数标准预制构件生成千变万化的空间。

1962 / 1964

格斯特纳《Designing Programmes》

瑞士设计师卡尔·格斯特纳为德国《Capital》杂志造出 58 单元流动网格，并于 1964 年出版方法论专著，把排版从「画死一页」推进成「生成多解的程序」。

1981 → 2007 → 2017

从瑞士栅格到数字屏幕

米勒-布罗克曼《Grid Systems in Graphic Design》（1981）系统化了 8–32 格单元，金伯莉·伊拉姆《Typographic Systems》（2007）将模块系统独立归类，W3C CSS Grid（2017）让它在网页和便当盒界面里成为原生能力。

04

缝隙与留白的临近法则

OUTER GAP VS INNER PADDING

把大框切好只是第一步，真正决定模块读起来清不清爽的，是模块外缝隙（gap）与块内留白（padding）的相对比例。按照格式塔临近性原则，眼睛总是把距离更近的元素自动归成一组。

  • 外缝过窄（经验值 < 6px）：相邻模块边界贴死，左块末尾的字和右块开头的标题会互相粘连串行。
  • 内空远大于外缝：块里的标题和正文被大内边距推散，反倒显得隔壁模块离自己更近，分组关系彻底倒挂。
  • 稳妥甜区（经验值）：平面印刷与屏幕卡片常把基准外缝设为 10–18px，块内留白取 14–22px，让「块内文字行距 < 外缝隙 ≈ 内边距」，既稳住分组又保留呼吸。

MODULE 01

建筑模数与人因尺度

用同一把基准尺统领立面开窗、走廊宽度与室内家具，空间才不会在转角处突然失衡。

MODULE 02

信息容器的独立边界

每块只装一类完整语义，增删模块像插拔积木，不会牵连相邻栏目的折行与对齐。

MODULE 03

跨格拉开主次节奏

在 1×1 标准单元之外，把核心结论合并成 2×1 或 2×2，第一眼立刻分出主角与配角。

05

什么时候别用模块系统

WHEN NOT TO USE MODULES

模块系统擅长整理多组并列或可增删的独立信息块，但把它硬套在不合适的题材上，反而会亲手切碎阅读体验。点按任意卡片，对比「硬套模块」和「改用合适版式」的差别。

第一章

01 · 沉浸式长篇叙事

把小说、深度长文硬切进一个个小盒子，读者每读三四行就撞上框线与缝隙，连续思绪被切成碎片。

改用干净的单栏或双栏留白书页，只靠行距与页边距护航，让视线一气呵成读到底。

02 · 有机笔势与情绪海报

音乐节、戏剧或水墨海报依赖跨界张力与流动情绪，严整的模块网格会把气势切得四平八稳。

改用 171 随机系统 或 174 过渡系统，让字群与视觉流自然冲破方格边界。

03 · 只有单一主角的极简页

全页只有一个核心物件或一句宣言时，为了凑满模块硬塞五六个空框和装饰块，全是多余视觉杂音。

直接留出大面积呼吸空白，或转向 169 放射系统 / 175 双边系统 聚拢视线。

04 · 没有基准尺的「伪模块」

只学了画圆角边框，却没定共同基数和缝隙——每块宽高各凭感觉，既失去自由度，也没得到秩序。

要么彻底回归统一倍比与恒定缝隙，要么干脆撤掉无意义的方框线，靠留白和字号分层。

NO. 173 · 模块系统 MODULAR SYSTEM

「将版面划分为可重复的模块单元，通过组合与变化，实现有秩序、可扩展的设计布局。」

Divide the layout into repeatable modules, achieving orderly and scalable compositions through combination and variation.

核心三要素
模块（基础单位，定义尺寸与间距）· 组合（多个模块按规则组合，形成清晰结构）· 变化（调整模块的比例、位置或层级，创造不同的视觉效果）。
构建三步骤
① 建立基准网格（BASE GRID）→ ② 定义模块单元（DEFINE MODULE）→ ③ 应用间距系统（APPLY SPACING）。
