# 173 模块系统（MODULAR SYSTEM）互动页方案

## 1. 一句话道理
模块系统把版面拆成统一基准尺寸与统一缝隙的几何积木：靠「标准单元」锁住整体秩序，靠「跨格组合与比例变化」拉开主次层级，当内容增删或画幅变形时仍能严丝合缝地重新拼装。

## 2. 开场玩具：模块拼装与裂变工作台（Modular Matrix Synthesizer）
- **玩法**：直接嵌在首屏右侧（承袭 173 原海报右上 4×4 深松绿/赭金/金点阵拼图方阵）的开放 2D Canvas（标 `data-perf-drag`）。
  - **直接拖拽模块本体**：自由态下任意连续位移（可直观拖出叠压撞块或错牙漏缝）；开启「模数锁定」后沿 `u` 整数格顺滑吸附并与邻块动态换位。
  - **拖拉边缘/角部金柄，或点击下轨合并/拆分按钮**：改变选中模块的跨格尺寸（`1×1`、`2×1`、`1×2`、`2×2` 等）或切换材质角色（松绿金圆主角、赭金焦点、金点阵韵律、基础松绿信息块）。
  - **缝隙滑杆（0–24px）+ 模数锁定开关 + 扩展压力测试（`+1 模块`、画幅切 `4×4 方阵 / 3×5 竖海报 / 6×3 横展板`）**：把原海报「可扩展的设计布局」做成真实可验证的物理重组。
  - **键盘**：方向键微调/移格选中模块，`[` / `]` 缩扩格宽，`Space` 切换模数网格显隐。
- **开场状态（0/4 散尺乱拼错态）**：开场刻意关闭模数锁定与统一缝隙，模块宽高取非整数散尺（如 `1.38u × 0.82u`），两块直接重叠撞块、局部漏出 `26px` 宽缝与 `19%` 不可复用的碎残洞，且三块碎金抢戏导致最大/最小面积比仅 `1.28×`。
- **双向判错与单真源读数（`model.js`）**：全部读数直接由每块模块的实绘像素矩形 `(x, y, w, h)` 核算，拒绝写死常量，覆盖正向与反向错态：
  - 正向错态：非整数散尺错牙、模块重叠碰撞、缝隙宽窄不一、残洞过碎无法扩展、主次体量拉平。
  - 反向错态：**全员 `1×1` 棋盘僵化**（秩序满分但零变化）、**`0px` 糊死粘连**、**`> 20px` 缝隙过宽裂散**、**赭金铺满 > 45% 焦点过载**。
  - 读数说清「为什么」：例如缝隙不一致时直指「视觉分组失去共同节拍，相邻信息会被误认成同一组」，并给出下一步具体动作；同时接受原海报经典解、便当盒产品解、3×5 竖海报解、6×3 横展板解及用户自拼的任意合法 4/4 解。
- **与最近 12 页的差异**：与相邻 172（暖米纸 + 钴蓝朱红、6 栏竖向列轨与水平挂线对齐）彻底区分——173 以深松青暗底配赭金与骨白，玩法聚焦「显性几何单元的倍比咬合、跨格裂变、增块与换幅重组」，而非把散落图文贴齐隐形栏线；与 136/217/085/048/303/258/135/337/257/302/047 的杠杆、中轴、压平、椭圆、剧场、侧栏、对折、幻灯、三列、双人、星盘完全不同。

## 3. 版式骨架
- 忠实转译 173 原海报「深松青建筑制图展板」骨架（外层功能框用 10px 轻圆角细绿线，内部所有模块瓦片坚持 0px 锐利直角，绝不锁 `100svh` 避平板空洞）：
  - **1440×900**（主宽 `1380px`，2560 舒展至 `1680px`）：
    - 顶区非对称双栏严丝齐底：左 44% 为自示范 `1:1` 方格大标『模｜块｜系｜统』+ `MODULAR SYSTEM` + 招牌赭金短横杠 + 原海报中英总述 + 单真源诊断卡与四项实测读数；右 56% 为标本/画幅重组条 + 4×4 活体模块画布 + 紧贴式单行模块精控轨。
    - 紧接原海报招牌三列细线圆角大框（`模块 MODULE`｜`组合 COMBINATION`｜`变化 VARIATION`），每列带实时状态徽标与可点击联动微图式。
    - 底部收束于原海报招牌金灯泡 `要点 KEY POINT` 通栏横条。
  - **1024×1366 / 768×1024 平板**：自然流排，画布满宽、诊断卡与操作区齐底双栏，不留大段空带。
  - **390×844 手机竖屏**：首行压紧单行刊头（编号+标题+实时状态徽），总述与三柱框后置，让等比模块方阵稳占首屏 ≥ 46% 高度，折线内直露核心精控按钮与诊断单首句。
  - **844×390 手机横屏**：左 52% 等比模块画布 × 右 48% 精简刊头、诊断单与快捷控轨并行。

## 5. 节目录（共 7 节，相邻节零同构控件）
- **01 模块为何能兼得秩序与自由**（`MODULE GRAMMAR`，暖宣纸）：拆解原海报三大概念并对照 [172 网格系统](https://layout.xiaoxiaodong.ai/172/play/)，温和提示「一致不是全等」；交互为原海报 `模块构建 1→2→3` 三步分阶可点击动画蓝图（基准网 → `x×x` 单元 → 统一间距）。
- **02 一套模块拼出三种版面**（`SCALABLE EXAMPLES`，浅青瓷）：重现原海报右侧三幅应用示例并串联同小类 168–175 七页链接；交互为真实 DOM/CSS 响应容器（切 4/3/2/1 列宽、实时 `+1/−1` 增删模块、开关「混入散尺」看流式重组如何立刻崩坏）。
- **03 格斯特纳的 58 单元魔法**（`MODULAR LINEAGE`，深松青暗室）：考证历史脉络（北宋毕昇活字 → 柯布西耶《模度》→ 格斯特纳《Capital》58 单元 → 米勒-布罗克曼 1981 → 伊拉姆 2007 → CSS Grid 2017）；交互为 58 单元公倍数拆栏校验尺（1–6 栏即时叠层对比，肉眼验证 `n×w + (n-1)×2 = 58`）。
- **04 缝隙与留白的临近法则**（`GAP VS PADDING`，暖宣纸）：用经验值讲透「外缝隙 vs 块内留白」和单元粒度甜区；交互为双滑杆活体图文模块对照台，实时画出格式塔临近误连警示线。
- **05 什么时候别用模块系统**（`WHEN NOT TO USE`，暖赭砂纸）：四类典型反例（长篇叙事、有机情绪海报、单主角极简页、无基数伪模块）；交互为四例可翻转对照卡（「硬塞模块」⇄「改用合适版式」微缩视觉对比）。
- **06 小练习：挑出真模块版面**（`QUICK CHECK`，深松青暗室）：两轮单变量选择题（第 1 题考倍比与缝隙一致性；第 2 题考比例变化与焦点克制），选项仅标中性 `方案 A / B / C / D`，四幅精致 SVG 几何版面仅差一个变量，选后逐项解析。
- **07 原海报与关键语汇**（`ORIGINAL POSTER`，浅青瓷）：完整展示 `poster.webp`（点击打开可缩放/拖拽/Esc 关闭的灯箱，`draggable="false"`）+ 海报原文对照 + 关键语汇与同小类全览导航 + 标准页脚。

## 7. 练习设计
- **第 1 题（变量：倍比与缝隙一致性）**：四幅同样由 6 个松绿/赭金/点阵块组成的 4×4 版面，仅标 `方案 A / B / C / D`——A 缝隙混用 4px/18px；B 全整数倍 `u` 且缝隙恒定 10px（唯一正确）；C 缝隙恒定但中两块取 1.35u/0.65u 散尺错牙；D 局部 0px 粘连另侧 14px。
- **第 2 题（变量：比例变化与焦点克制）**：四幅均严格满足整数倍 `u` 与统一缝隙——A 全员 16 块等大 `1×1`（零变化）；B `2×2` 主块配 `2×1`/`1×2`/`1×1` 且金色占 25%（唯一正确）；C 大小有别但 75% 全涂赭金（焦点过载）；D `4×3` 单巨块压顶失去组合层次。
