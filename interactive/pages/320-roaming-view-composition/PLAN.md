# 320 游观式构图（ROAMING-VIEW COMPOSITION）设计方案

## 1. 一句话道理
人眼一次只能看清一小块画面；与其把所有信息平铺在眼前让人一眼望穿、很快失焦，不如用入口、曲径、遮蔽与停顿把画面拆成按时间顺序逐段展开的「移步换景」旅程，让视线在游走与停留之间自己把整幅画面拼成完整记忆。

## 2. 开场玩具
- **命名**：展卷游观编景台（Handscroll Roaming-View Staging Table）。
- **怎么玩**：
  - 全宽 2D Canvas 游观手卷上铺开 320 原海报五幕景观（`01 拱门入景 → 02 山林移步 → 03 楼阁停留 → 04 曲桥过渡 → 05 灯塔抵达`，并可切换「汴河长卷」「江南园林」三套母题）。
  - 画布带一个活体「游观取景视窗（Roaming Gaze Aperture）」，用户可在画布上直接横向拖动（`data-perf-drag`）、按键盘 `← / →` 键、点击顶部五幕进度带或开启「自动游走」，亲身从「起点 START」游走到「05 抵达」，即时看到当前视窗所见、实时步速节奏与观者体验。
  - 用户还可直接**点击画布上任意两座景致对调站序**、切换单个景致的停留权重（主停 / 次停 / 轻掠），并调节**起承序列、路径引导、节奏停留、藏露与余韵**四个维度。
- **一打开是什么状态（0/4 待编景，非答案）**：
  - 入口与终景倒置（把发光灯塔塞到第 1 站，开场即泄底）；
  - 路径拉成 `1.00×` 死直线（从起点一眼穿到终点）；
  - 5 站体量 1.0× 平权且等距机械排布（CV 0.00，无停留锚点）；
  - 0% 遮蔽全敞露且终点背向画外急刹（零悬念、零回望）；
  - 取景视窗初始停在 `24%` 处，开场第一眼就能看见活体视窗与这四处显眼错态。
- **怎样算玩错、读数怎么说「为什么」**：
  - `model.js` 从实绘五站坐标、路径总弧长、停留权重与遮蔽模型单真源实时诊出 8 类失误：`高潮前置泄底`、`景致雷同（移步未换景）`、`死直一眼穿`、`断脉迷途`、`平权等距（机械报站）`、`扎堆撞景（前挤后空）`、`全敞急刹无韵`、`过度闷堵（雾墙锁死）`。
  - 每条诊断先用白话点明「观者的眼睛此刻会怎样走偏或疲惫」，再给一步可逆调校动作；且接受多种合法解（原海报 S 径解、亭阁压轴之字盘升解、以及用户手调达标的任意合理布局）。
- **和最近 12 页的区别**：
  - 区别于 319（黑漆底五视点圆环散排）、113（深紫底单根丝带折角塑形）、318（暖纸三翼金字塔权重双游标）、236（包豪斯九卡砌墙宽尺）、235（竖向吸顶滚卷阅读器）：本页紧扣「游观」独有的**移动视窗展卷体验 + 藏露悬念 + 站序/曲径/停顿/余韵编景**，不能套用到其他任何编号。

## 3. 版式骨架
- 忠实承袭 320 原海报「暖米宣纸开放卷轴跨页 + 无重框细线底账」气质，不锁 `min-height: 100svh`：
  - **1440×900（主宽 1380px，2560 扩宽至 1760px）**：32px 细眉 → 不对称卷首刊头（左：随游径轻阶起伏的示范大标「游观式构图」+ 英文 + 细杠 + 总述；右：原海报绿环圆徽「视觉组织 / 进阶原理」+ 6×3 粉点阵 + 三母题切签）→ 全宽横向手卷舞台（顶五幕步进条 + 390px 高 2D Canvas 手卷，左沿嵌原海报 3×7 绿点阵）→ 底沿复刻原海报细线分隔双栏（左 46% 单真源白话诊单 + 原海报三彩圆核心要点实时灯 × 右 54% 四维编景调律行）→ 底部「游走 · 发现 · 联结」细线粉点收脚。
  - **1024×1366 / 768×1024 平板**：自然流式堆叠，全宽手卷下接双栏/单栏细线底账，无空白塌陷。
  - **390×844 手机竖屏**：单行压紧刊头 + 母题窄排，手卷画布切回忠于原海报 3:4 竖势的等比 S 盘升构图（高约 396px，稳占首屏 ≥ 46%，圆点严格 1:1 不压扁），横向滑动同样顺畅推进游观视窗，同屏露出白话诊单主句。
  - **844×390 手机横屏**：左 58% 横向手卷舞台 × 右 42% 紧凑刊头、诊单与快控并排。

## 5. 节目录
- `01` **移步五幕：从入口到回望** — 展开原海报 01–05 五幕原话，用可切选的「五幕剧场 + 拆幕对比开关」体验抽走任一幕的后果。
- `02` **一眼望穿与移步换景** — 区分静态全览与时间展卷，一句话链接 315–319 同类页；配「展卷窗宽滑杆」实时对比手卷逐段展观与整壁一览的发现曲线（示意）。
- `03` **藏露与路径：曲径的秘密**（深靛暗室）— 拆解原海报三大核心要点并温和校正「控制视线流向」的说法；配「暗室视线路径模拟台」实测直廊、屏风曲折、漏窗借景、死胡同四类障景。
- `04` **从画卷、园林到现代街景** — 宗炳、郭熙、张择端、王希孟、计成、戈登·卡伦五节点实证史脉；配「历史手卷尺幅等比对照卡」。
- `05` **何时适用，何时别用** — 讲清故事长卷/文旅导览与紧急标牌/高频仪表盘的边界；配「6 场景分诊翻转卡」。
- `06` **小练习：挑出好游观** — 四幅仅差一个变量的同画风 SVG 路线图（中性标签 A/B/C/D），判后逐项拆因。
- `07` **原海报与关键概念** — 原海报可缩放拖拽灯箱、四枚英文关键词与同小类链接。

## 7. 练习
- **题目**：你要做一张文旅景区导览长图，从「山门」出发，途经林径、古亭、石桥，最终登上灯塔观海。以下四套方案共用完全相同的五处景致，哪一套最符合游观式构图？
- **四选项（中性标签，仅差一个变量）**：
  - `方案 A`：起承有序、体量主次分明，但五站排在一条笔直横线上，无遮无拐（差在「直道一眼望穿」）。
  - `方案 B`：S 形曲径、藏露与主次均合理，但把发光灯塔错放第 1 站、山门移至末尾（差在「高潮前置泄底」）。
  - `方案 C`（正解）：山门强对比入景 → 曲径转折藏露 → 中段古亭放大停留 → 石桥过渡换拍 → 顶部灯塔回望收尾。
  - `方案 D`：曲径蜿蜒、起承有序，但五站大小完全一致且等距平铺（差在「节奏平权、缺少主停留节点」）。
