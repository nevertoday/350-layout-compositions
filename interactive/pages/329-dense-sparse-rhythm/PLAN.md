# 329 疏密相间构图（DENSE-SPARSE RHYTHM）设计方案

## 1. 一句话道理
同一批元素不增不减，只要把一部分聚紧成「密区」、把另一部分放开成「疏区」，并在密疏之间留出渐散坡度，眼睛就会自动读出强弱重拍与停顿呼吸，主角落进疏朗处便不争自显。

## 2. 开场玩具：「密疏点阵声谱 × 疏朗焦点调律台」
- **直接从 329 原海报长出来**：开放铺在原海报明姜黄纸面（`#F8C426`）上的无框 2D 画布（`data-perf-drag`），包含 330 颗真实可聚散的纯黑墨点阵、一颗可直接拖拽的克莱因蓝焦点圆、一枚可点置的 `+` 呼吸气眼，以及紧贴画布底沿、由当前画面 16 条垂直切片真实墨量驱动的**蓝色节奏波浪曲线与竖线拍谱**。
- **支持三题材切换**：原海报·墨点蓝圆 / 宋人长卷·疏林孤舟 / 现代版面·报刊图文。
- **开场初始状态（绝不先给答案）**：开场刻意停在「匀铺无律 + 焦点被吞」错态——330 颗黑点均匀等距铺满画面，蓝圆埋在点阵中左被黑点紧逼，底沿蓝色节奏波拉成一条平直死线。
- **怎么玩**：
  - 在画布空白或点阵区**左右横拖**（兼容触屏与 `perf.mjs`）：连续拉动聚散势（匀铺 → 渐散成韵 → 极端挤爆成墙）；
  - 直接**拖拽克莱因蓝圆**移入疏朗呼吸空域；
  - 键盘 `←/→` 调聚散势、`Shift + 方向键` 挪蓝圆；
  - 调总墨量、切换单峰渐散 / 双峰相间 / 边角走马章法，或点击试错对照。
- **怎样算玩错、读数怎么说（单真源实算）**：全部由 `model.js` 从当前实绘点阵坐标与蓝圆坐标在 24 切片 + 12×8 栅格上实算，捕获 7 类双向错态——匀铺无律（密谷比 < 2.4×，波形拉直）、密而迫塞（总覆盖 > 44% 或疏朗空域 < 22%）、疏而空松（总覆盖 < 6.5% 或最密区 < 20%）、硬劈断崖（过渡坡度 < 7% 死挤成墙）、等宽呆板（双峰峰宽比 < 1.15×）、焦点被吞（蓝圆护城河内侵入黑点 ≥ 3 颗）、焦点挤边（边距 < 8%）。接受单峰渐散、双峰相间、边角走马多组合法解。
- **与最近 12 页的差异**：摒弃最近多页普遍使用的「深色/白框诊单仪表盘 + 4 格数值卡 + 画布红贴条 + 橙色一步校准按钮」模板；首屏直接还原 329 原海报满幅明黄纸面、三枚纯黑圆徽实况列与左下蓝灯泡细线「知识提示」点评笺，玩法是独属 329 的颗粒密度场 + 实时节奏波形谱 + 焦点净空圈。

## 3. 版式骨架
- **不锁 `min-height: 100svh`**（避开平板竖屏 1024×1366 出现大块空白）。
- **1440×900（2560 舒展至 1760px）**：满幅明姜黄底面，顶沿为自示范「疏密字距大标」与随画面起伏的微型点阵标尺；主体采用忠实转译 329 原海报的左 31% 开放列（总述 + 三枚纯黑圆徽实时状态 + 细黑线蓝灯泡点评笺）× 右 69% 无框巨幅墨点蓝圆画布与底沿原海报三行实况图例、轻量墨线控条。
- **1024×1366 / 768×1024**：1024 下保持紧凑双栏自然收束，768 下转为「精简刊头 → 全宽画布 → 横排三徽与点评笺」，无空洞、无单栏先结束。
- **390×844**：单行精简刊头压紧高度，等比主画布稳占首屏 ≥ 48% 屏高（圆点与蓝圆严格等比绝不变椭圆），画布紧下即见点评笺第一句与横拖提示。
- **844×390 横屏**：切换为左 58% 等比画布 × 右 42% 刊头、点评笺核心句与快捷章法钮并排。

## 4. 配色和字体
- **逐像素采自 329 原海报**：
  - 标志明姜黄主底：`#F8C426`（正文柔和浅纸交替：`#FDFBF4` 亮宣白、`#F6ECCB` 淡姜黄雾、`#F9F5E8` 暖宣纸、`#F5E7B8` 浅姜黄纸）
  - 浓松烟黑主墨与 06 暗室：`#0B0907`（暗室 `#11100D` / 暗舱 `#1B1914` / 次墨 `#3D3629`）
  - 克莱因钴蓝焦点与 03 暗室：`#1F3BB6`（深靛蓝暗室 `#101D54` / 暗舱 `#182970` / 暗底亮蓝 `#8BB0FF`）
  - 克制状态色：朱砂暗赤 `#A82412`（明黄/浅纸对比度 > 5.5）、深松绿 `#0F5D42`（达标）
- **字体搭配（全部 5 款在最近 12 页 0 次使用，与 328 五款零重合）**：
  - `noto-serif-sc`（400 / 700 / 900）：中文厚重大标题与典雅正文（段内年份与人名同字体，杜绝混排跳动）
  - `bricolage-grotesque`（400 / 600 / 800）：原海报大写副标、节号与英文标识
  - `libre-baskerville`（400 / 700 + italic）：西文引文与来源注脚
  - `inter`（400 / 600）：表格/读数等宽数字（`tabular-nums`）与精控短签
  - `long-cang`（400）：仅用于 04 节传统画论题款八字（经 `npm run glyphs` 核验零缺字）

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻不同控件）
- **01 对比：均匀等于没有节奏** — 16 枚圆点「点击缝隙敲节拍」交互条，验证不增减数量只改间距即可自动编组。
- **02 节奏：密与疏之间留坡度** — 温和补全原海报没明说的「过渡缓冲带」，用「横向拖拽蓝色扫描探针」对比一刀切硬边 / 原海报渐散坡度 / 双峰相间波浪的视线速度曲线。
- **03 呼吸：把主角请进疏朗处** — 深克莱因蓝暗室；「可交互迷你活动海报排版重排卡」（点选信息聚拢与主区留白护城河开关），并一句划清与 326/327/328 的区别。
- **04 从哪来：画论、长卷与点阵** — 可点选「东西方疏密时间轴」配动态 SVG 结构图解（夏圭《溪山清远图》、沈宗骞 1781、邓石如/包世臣 1802、Wertheimer 1923、Kandinsky 1926）。
- **05 什么时候用，什么时候别用** — 等高双栏宜忌矩阵 + 4 张真实需求「点击翻牌诊断卡」。
- **06 小练习：哪版真正疏密相间？** — 墨黑暗室；同数量 28 枚黑点 + 1 颗蓝圆的 4 选 1 盲测（中性标签 A/B/C/D），选后揭晓各自真实密度波形与理由。
- **07 原海报与本类索引** — 原海报点击灯箱放大拖拽（`draggable="false"`、Esc 关）、关键词与知识提示原文、同小类 8 篇精准链接。

## 7. 小练习设计
- **唯一变量**：同样 28 枚黑点与 1 颗克莱因蓝圆、总面积相同，仅改变空间聚散分布与焦点所处空域。
- **四个选项（标签仅写 方案 A/B/C/D）**：
  - 方案 A：7×4 均匀网格铺满，蓝圆嵌入其中一格（整洁但无疏密落差，密度波平直）。
  - 方案 B：28 点全部硬压在最左窄带成黑墙、无渐散过渡，蓝圆挤贴右框（断崖割裂且焦点挤边）。
  - 方案 C：左右两簇密点形成疏密，但蓝圆埋在左侧密点堆正中（主角被密区吞噬，失呼吸焦点）。
  - **方案 D（正确）**：左密饱满经渐散过渡到右侧开阔疏域，蓝圆独落疏朗呼吸圈内并与密区遥相呼应。
