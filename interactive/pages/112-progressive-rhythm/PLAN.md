# 112 渐进节奏组织 · PROGRESSIVE RHYTHM 方案

## 1. 一句话道理
把可数的视觉节拍按**单向、等比可预期**的规律逐级放大（大小、间距、粗细、密度），人眼会自动推演下一拍的增量并被自然推向终点焦点；等差平加会尾端熄火，逆序凹坑会半路绊脚，双轨反向会彼此抵消。

## 2. 开场玩具
- **命名**：活体渐进阶梯谱台（1:1 复刻 112 原海报的钴蓝斜升双轨舞台：上方 9 枚金黄/暖米圆列 + 中段纯白实线斜箭 `推进 MOMENTUM` + 下方虚线斜坡与 9 根金黄/暖米竖柱阶梯 + 右下角原海报四维实时开关）。
- **玩法**：
  - 直接在钴蓝主画布上**横向拖动**（`data-perf-drag`，触屏设 `touch-action: pan-y` 保留纵向滚页）连续调节首尾跨度倍率 `span`（`1.0×–11.5×`）；
  - 直接**点击/轻触画布上的任意圆点或柱条**翻转该拍的破序凹陷状态（点中破损拍即抬回单调序列，点健康拍可人为制造踩空凹坑）；
  - 底部原海报两栏内切换**递进规律**（等差失速 / 等比递增 / 斐波那契 / 尾端急冲）、**拍数**（3–15 拍）、**柱阵方向**（同向协同 / 反向对冲）及原海报**四条递增维度**（大小 / 间距 / 粗细 / 密度）；
  - 全键盘支持（画布聚焦后 `←/→` 调跨度、`↑/↓` 调拍数、`Enter/Space` 补齐破拍，所有控件用原生 `<button>` / `<input>`）。
- **开场初始态（0 / 4 待调律，绝不先给答案）**：
  1. `递增 INCREASE`：跨度仅 `1.4×`（扁平如重复，看不出由弱到强）；
  2. `推进 MOMENTUM`：规律停在「等差失速」（前跳后僵，尾段每步相对增幅低于 10%）；
  3. `序列 SEQUENCE`：第 5 拍被人为压低 42%（带红虚圈逆序踩空）；
  4. `强化 EMPHASIS`：下轨柱阵设为「反向对冲」（上圆向右渐强、下柱向右渐弱，两股动势互掐）。
- **怎样算玩错、读数怎么说「为什么」**：由 `model.js` 单真源基于真实绘出的各拍尺寸、间距、相对增幅与方向向量实时诊出 8 类失误：`重复退化`（跨度 `< 2.5×`）、`头隐尾爆`（跨度 `> 9.5×` 或起拍过细）、`逆序踩空`（任意相邻拍倒挂）、`等差失速`（尾端相对步幅 `< 10%` 失去期待）、`前僵后爆`（前段停滞尾端骤冲）、`拍数不足`（`≤ 3` 拍仅成对比不成节奏）、`过密糊团`（`≥ 15` 拍空隙粘连）、`反向对冲`（双轨或维度方向打架）。支持等比经典解、斐波那契建筑解、温和版式解等多组合法解。
- **与最近 12 页的明显差异**：
  - 不同于 111（四道横贯黑白朱红交替带 + 底部相位条）、110（左书脊竖标 + 霞光坡面拖起止锚点 + 底部弧轨）、027（居中对称中轴 + 底部天平梁）、317（横向展卷轴尺）等带「画布下独立单条拖轨」的玩法；112 直接把海报本体的斜升双轨阶梯做成可横扫拉伸、可点修单拍的满幅钴蓝斜向谱台，且用原海报右下角四维微型图示栏做实时开关。

## 3. 版式骨架
- **1440×900 桌面**：极细 32px 深钴顶眉 → 忠实承袭 112 原海报「满幅电光钴蓝斜升双轨舞台（主宽 1380px，上方斜向留空三角内嵌实时白话诊单，与下方斜升圆列严格无重叠）→ 大号纯白逐字渐强示范大标 `渐进节奏组织` + 虚线延展 + `PROGRESSIVE RHYTHM` → 原海报同款竖虚线不对称双栏底座（左 52% 四枚带金杠关键词实时检核柱 + 规律/拍数/方向紧凑控参 × 右 48% 四维金圆图标实时开关与白线微图）→ 底部细白线 `由弱到强 ────→ 终点 / 焦点`」。不锁 `100svh`，平板不空洞。
- **2560×1440 宽屏**：主容器舒展至 1840px，钴蓝斜升舞台同比放大至 ~600px 高，画面磅礴不缩中。
- **390×844 手机竖屏**：顶眉 + 极紧单行标题与状态徽置顶 → 满幅无遮挡 10:9 钴蓝阶梯画布（稳占首屏 ≥ 45% 屏高，圆始终正圆不等比压扁）→ 紧接白话诊单与首行控参（全部点击区 ≥ 42px）。
- **844×390 手机横屏**：左 56% 钴蓝斜升舞台 × 右 44% 紧凑标题、诊单与核心控参并行。
- **正文八节底色节奏**：电光钴蓝（Hero）→ 素白象牙纸（01）→ 深蓝蓝图室（02）→ 暖砂米纸（03）→ 淡冰蓝纸（04）→ 素白象牙纸（05）→ 深夜钴蓝室（06）→ 暖砂米纸（07）→ 电光钴蓝原海报（08）→ 深海军蓝页脚。

## 4. 配色和字体
- **实采自 112 原海报色值**：电光钴蓝 `#0033BC` / 深蓝蓝图 `#002285` / 深夜蓝 `#051647`；信号金黄 `#FEC613`（浅底可读深赭金 `#8A5D00`）；暖砂米白 `#F6E8CD`（素白纸 `#FAF7F0` / 暖砂纸 `#F4EBDA` / 淡冰蓝纸 `#EAF0FB`）；纯白主字 `#F8F7F1`；浅底深钴墨 `#0A1638` 与 `#002B9E`；克制以珊瑚赤（暗底 `#FF8E72` / 浅底 `#B52617`）标错态、清荷青（暗底 `#6CF2CE` / 浅底 `#0B6B56`）标达标。
- **字体搭配**：`noto-sans-sc` + `syne` + `bricolage-grotesque` + `ibm-plex-mono`（全库唯一搭配；`syne`、`bricolage-grotesque`、`ibm-plex-mono` 三款西文在最近 12 页全部 0 次使用，且与相邻 111 零重合；中文正文内西文与年份沿用正文 `Noto Sans SC` 避免混排跳动）。

## 5. 节目录
- **01 · 四条递增的把手**（`THE FOUR LEVERS`）：拆解原海报大小/间距/粗细/密度四维，配 2×2 独立步进倍率切签对比卡与多维合力视图。
- **02 · 为什么等差会半路熄火**（`WHY MULTIPLICATIVE BEATS ADDITIVE`）：借韦伯-费希纳定律温和补正原海报「逐步增加」的说法（标「说多了一点」），配单滑杆联动的上下双轨相对增幅实测标尺。
- **03 · 心理物理、建筑与字号源流**（`ORIGINS & LINEAGE`）：从费希纳（1860）、柯布西耶/泽纳基斯（1948/1956–1960）、阿恩海姆（1954）、霍夫曼（1965）、王无邪（1972）到布林赫斯特（1992），配 5 枚年代历史图板切换（含拉图雷特修道院波形玻璃立面与音乐音程字号阶梯实时生成）。
- **04 · 同类节奏里它排在哪**（`RHYTHM FAMILY`）：用 1 条实时变形的 9 拍节律带对比 107–114 同小类页面，一句话链接各兄弟页不重讲。
- **05 · 版面与界面怎么用渐进**（`IN REAL LAYOUTS`）：新闻杂志字号阶梯、方案漏斗卡、活动海报三类真实小样，配统一倍率切签看 1.0×/1.28×/1.65× 的落地效果。
- **06 · 什么时候别用渐进节奏**（`WHEN NOT TO USE IT`）：四类反例场景切换器（平权数据表、长文沉浸阅读、少于 4 拍、高频随机入口），对照渐进误用与克制正解。
- **07 · 练一练：挑出稳健的渐进序列**（`VISUAL CHECK`）：4 枚纯中性标签 A/B/C/D 的 8 柱矢量题板，只差单一结构变量（等差尾熄 / 单拍微跌 / 等比协同正解 / 高增距缩互掐），作答后直接在四板叠加实测标注并解释。
- **08 · 原海报与关键词**（`ORIGINAL POSTER`）：原海报放大拖拽灯箱 + 四枚关键词 + 完整页脚。

## 7. 练习设计
- 题目：四组均为 8 根金米竖柱、起止高度接近，选出视线从左向右最平稳推向终点焦点的一组。
- 选项（纯中性 A/B/C/D）：
  - A：等差递进（前段陡跳、尾三柱增幅跌破 10% 而失速）；
  - B：等比 `1.24×` 但第 6 柱轻微回落（单拍逆序破律）；
  - C：等比 `1.24×` 且柱宽、柱距与柱高同向渐进（正解）；
  - D：柱高按 `1.24×` 递增但横向间距反向收紧（双维互掐致终点拥堵）。
