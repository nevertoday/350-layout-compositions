# 153 模块化页面 · 方案（PLAN）

## 1. 一句话道理
把整页信息拆成职责清晰、内结构同构、样式服从同一套规则的独立模块，并放进能随宽度与内容量增减自洽的网格架里，人眼才能靠「认出一次、通用全页」的扫描模式快速读懂页面，团队也才能低成本扩展而不走样。

## 2. 开场玩具
- **名字**：活体模块页面装配台 · 视口卡尺与系统契约联校（Live Modular Page Assembler & Responsive Caliper）
- **怎么玩**：
  1. **横向拖动顶沿「视口宽度卡尺」（标 `data-perf-drag`，亦支持键盘 ←/→ 与画框右侧手柄）**：在 `320px–840px` 之间连续拉宽或压窄活体模块页，2D Canvas 同步绘制实时网格轴线、列宽标尺、对齐偏差红箭与间距游标，页面里的 153 原海报真实模块（数据卡片 `7,860 ↑ 12.3%`、人物介绍 `张云策 | 产品设计师`、内容摘要模块、第二张数据卡片及可增减模块）实时重排或暴露挤压、过拉错态。
  2. **四维系统契约开关**：在右侧（窄屏下方）切换「网格架（散乱错位 / 单列 / 双列 / 卡片网格 / 响应自适）」「样式契约（各自为政 / 统一规范 / 极简抹平）」「复用模板（同卡异构 / 同构复用）」「主次与留白（主次倒挂 / 核心领衔 + 缝隙 0px / 14px / 28px）」。
  3. **直接点击活体模块卡**：点击任意卡片可将其提至首槽或调换优先级；底沿按钮可 `+ 增模块 / - 减模块`（2–6 个）实测扩展性，并可直接切「单列 / 双列 / 卡片网格」原海报组合原型。
- **开场初始态（0/4 未成体系）**：打开即为典型的「假模块化拼盘」错态——视口 `580px` 宽下放 4 张卡，网格处「散乱错位」（纵轴偏差 22px）、样式处「各自为政」（3 套圆角/内边距/竞色）、两张数据卡片处「同卡异构」（左图右数 vs 居中挤字）、内容主次「主次倒挂」（密文摘要挤占窄格，主指标被压到末位）。
- **怎样算玩错 & 读数怎么说「为什么」**：全部 8 类失误均由 `model.js` 从实际几何与系统规则单真源核算，支持多组正当解（单列窄屏解、双列中宽解、三列宽屏解、全宽响应式解）：
  1. `网格脱轴`：自由错位导致纵轴偏差 > 0px，眼睛每次换行都得重新找左边线。
  2. `窄屏硬塞多列`：固定双列/卡片网格拖到窄宽，实算单列宽跌破 `155px` 经验下限，指标与姓名被迫折行挤压。
  3. `宽屏单列拉成细条`：固定单列拖到 `> 680px`，单行过长且尾部留出大片死空，横扫费力。
  4. `样式各自为政`：3 套圆角、内边距与竞色同时出现，整页读起来像从三个网站剪来的拼贴。
  5. `过度抹平失层次`：反面陷阱「极简抹平」去掉字号差与珊瑚强调色，整页一致却死气沉沉，看不出 `7,860` 是主角。
  6. `同类异构伪复用`：两张数据卡长得完全不一样，读者刚学会怎么读第一张，到第二张又得重认一遍。
  7. `主次倒挂`：辅助说明抢占头槽、核心指标沉底，视觉顺序与阅读重点反着走。
  8. `零缝粘连 / 扩展断尾`：缝隙 0px 让模块边界粘成砖墙，或 3 列网格摆 4/5 张未跨槽卡留出刺眼空缺。
- **和最近 12 页的区别**：196 做的是空白 X×X 虚线格子上拖抽象色块；152 是暗房胶片四帧叠合；235/234 是滚动吸附与固定导航浏览器；279 是 6 月日历排期。153 专做「真实业务模块组件库 + 视口卡尺连续试压 + Canvas 网格透视 + 样式/复用/层级系统契约」，换成别的编号根本套不上去。

## 3. 版式骨架
- **忠实承袭 153 原海报视觉语法**：无深色仪表盘卡感、不锁 `100svh` 避开平板空洞。顶部薄石膏眉栏下，复刻原海报 `62% 暖燕麦纸大标区 × 38% 鼠尾草/深灰绿/珊瑚圆几何模块母题` 刊头；主体为纯白建筑制图舞台（左 65%：视口卡尺 + 活体模块页 + Canvas 网格透视 + 组合切签）贴合淡鼠尾草纸系统检核单（右 35%：白话实测诊单 + 四维契约控槽 + 原海报六原则实时徽列）。
- **2560×1440**：主容器舒展至 `1780px`，舞台与检核单等高舒展，右侧大画幅模块页清晰容纳 3 列网格。
- **1440×900**：主容器 `1380px`，紧致刊头（~138px）+ 等高左右舞台与检核单在首屏完整呈现、底边齐平。
- **1024×1366 / 768×1024**：自然流式展开，全宽舞台下接等高双栏检核与控参，无大块白洞。
- **390×844**：压紧单行刊头（右侧几何母题收为 44×44 角徽），48px 高视口卡尺与等比活体模块舞台稳占首屏 ≥47% 屏高，下方同屏露出白话诊单首句；所有控件 ≥40px 触控区，零横向溢出。
- **844×390**：左右并行（左 56% 视口卡尺与活体模块页 × 右 44% 紧凑刊头、白话诊单与核心切签）。

## 4. 配色和字体
- **逐像素实采自 153 原海报**：
  - 纸面体系：纯白舞台 `#FEFEFE`、暖燕麦刊头与正文纸 `#F7F6F2`、暖白卡片 `#FAF8F4`、淡鼠尾草检核与建议底 `#F0F1E8`、细线灰绿 `#D6D8CF`。
  - 鼠尾草橄榄主系：中鼠尾草块 `#919C84`、竖纹橄榄 `#8E977B`、浅灰绿底 `#DBDDCF`、深橄榄圆徽 `#616D52`、浅纸可读深橄榄字 `#4A563E`、达标深松绿 `#2B5B40`。
  - 炭绿墨与暗室：标题纯墨 `#111111`、正文石墨 `#1B1E1A`、次要石墨 `#464C42`、原海报深灰绿圆弧 `#3D403F`、03 节历史暗室 `#232721`（暗卡 `#2E332B`，象牙主字 `#F4F3EE`）。
  - 单点珊瑚信号：原海报珊瑚圆 `#E3715C`、浅纸高对比深珊瑚赭字 `#B53E2A`、暗底亮珊瑚 `#F28A76`。
- **字体搭配（全库唯一；三款西文在近 12 页全部 0 次使用；与 152 零重合）**：
  - `Noto Sans SC`（400–900，原海报本身为现代几何无衬线建筑排版）
  - `Archivo`（500–800，**近 12 页 0 次使用**，用于 `MODULAR PAGE`、指标大数字与英文节标）
  - `IBM Plex Sans`（400–600，**近 12 页 0 次使用**，用于模块化系统规范英文标牌）
  - `Space Mono`（400 / 700，**近 12 页 0 次使用**，用于编号、像素尺寸与网格参数）

## 5. 节目录
- **01 `六条原则，一套契约`**（暖燕麦纸）：完整引述原海报六条原则，配「缺一即塌」因果依赖点击矩阵，点击任意原则实时演示缺失后的局部崩塌。
- **02 `先定骨架，再装零件`**（纯白纸）：拆解原海报三大真实模块（数据/人物/摘要）与四条应用建议，配「内容涨缩压力器」（极短/标准/翻倍长文案 × 写死高度 vs 弹性槽位对照），绝不与开场宽尺重复。
- **03 `从铅字架到原子设计`**（深炭绿暗室）：梳理 1962–2016 真实脉络（格斯特纳、维涅里 Unigrid、穆勒-布罗克曼、布拉德·弗罗斯特），配「五层原子拆解步进器（原子→分子→组织→模板→页面）」，并温和补全原海报结语的边界。
- **04 `三种组合与同门辨析`**（淡鼠尾草纸）：配「任务-组合匹配台」（深度长文/参数对照/多品目录/周报看板对照单列、双列、卡片网格与扫视路径），并以一句话分别链接同小类 154–159 及 196。
- **05 `什么时候别用它`**（暖白纸）：列举情绪海报、沉浸线性叙事、一次性实验出版三大反例，配「强拆模块 vs 通幅整体」一键翻转对照剧场。
- **06 `练一练：哪版最合章法`**（纯白纸）：四选一单变量目测题（中性标签 A/B/C/D），网格与文案完全一致，分别隔离样式统一、同型复用与层级秩序。
- **07 `原海报与设计母题`**（暖燕麦纸）：可放大/拖动/Esc 关闭的原海报灯箱，拆解原海报图形结构并汇总六项核心关键词。

## 7. 练习
- **题目**：同一份「季度复盘」四卡内容，同样放在规整 2 列网格里，凭直觉选出最符合模块化页面章法的一版（A / B / C / D 四张缩微页纯中性标注，不剧透优劣）。
- **单变量差异**：
  - **A（正解）**：样式规则统一、两张数据卡内结构同构、数字指标与辅助文案主次分明。
  - **B**：仅破坏「可复用同构」——第二张数据卡把图标去掉、数字缩成小胶囊沉底，与第一张数据卡结构冲突。
  - **C**：仅破坏「样式契约」——四张卡混用三种圆角、三种边线与互相抢戏的强调色。
  - **D**：仅破坏「有序层级」——去掉字号梯度与珊瑚焦点，所有字一样灰一样大，一致却无重点。
