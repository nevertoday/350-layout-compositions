# 283 画布工作区布局 · 互动版设计方案

## 1. 一句话道理
画布工作区布局之所以高效，是因为它把屏幕最宝贵的中心面积留给创作对象（Canvas），把高频工具、图层结构与上下文属性按肌肉记忆分区并紧贴画布边缘收放，让眼睛和鼠标的绝大多数动作都留在作品本身，而不是消耗在翻菜单和躲弹窗里。

## 2. 开场玩具
- **怎么玩**：做成一个**真能用的迷你图形创作工作台**（1:1 承袭 283 原海报深炭灰软件窗壳 + 暖白 `#EDEBE7` 网格标尺画布 + 蓝圆/黄圆角方/绿半透明三角/紫小方/深靛圆拱五枚可编辑几何图形）：
  1. **直接拖动画布与右栏之间的青柠分隔条**（`#ws-splitter`，标 `data-perf-drag`），实时缩放右侧「图层与属性」停靠栏宽（支持拉宽挤压、回落 16%–26% 甜区或拖到最右贴边折叠）；
  2. **直接点按或拖动画布上的五枚几何图形**（支持标尺对齐吸附、实时暗色坐标浮标 `W / H / X / Y` 与左侧选择/抓手工具切换），并在右侧图层面板点选/显隐/锁定、在属性面板实时改宽高/旋转/不透明度；
  3. **直接点击挡在画布中央的浮动杂窗收起/停靠**，切换顶部工具栏与左侧工具轨形态、切换四区分工与上下文联动、切「视觉设计 / 插画绘制 / 视频包装」三套真实任务场景，以及按 `Tab` 一键进出专注预览态。
- **一打开的状态（0/4 失衡错态，绝不先给答案）**：双层臃肿顶栏 + 双列宽抽屉左栏 + 36% 巨宽右侧栏 + 一张「历史与色板」浮窗死死压在绿色三角与蓝圆正上方，导致画布净可视面积被挤成 **28%**；同时分区混杂、属性栏处于与画布断联的静态假面板、标尺与辅助线关闭。
- **怎样算玩错、读数怎么说**：由 `model.js` 从与实际渲染完全同源的布局几何比例实时核算 8 类工作区失误——包括画布被压扁（净占比 `< 58%`）、浮窗遮挡画布、右栏喧宾夺主（`> 28%`）、右栏半开成细缝（`5%–14%` 挤迫输入框）、四区混杂越界、属性与选中对象断联、过度撤空导致工具与属性双失联、以及缺乏标尺参照。每类错态都用白话讲清**为什么会让眼睛跳动或操作卡顿**，并给出下一步可试动作；接受「原海报四区均衡解」「右栏折叠极简解」及任意符合四原则的参数组合。
- **与最近 12 页的差异**：最近 12 页分别是滨海地图（282）、固定宽浏览器尺（238）、镉金相似性分拣（115）、红青 X 楔形（031）、暖米游观手卷（320）、橄榄递减圆（068）、午夜霓虹三层覆盖窗（237）、冷灰基线排印（198）、信号橙区块压机（154）、银灰十字轴（030）、青瓷随机散布（114）、冰蓝对话剧场（281）。本页独创「真实可编辑的暗壳亮纸图形创作 IDE 工作台」，以拖面板分隔条、收浮窗、改图形属性与图层显隐为核心动作，其他任何编号都无法套用。

## 3. 版式骨架
- **忠实承袭 283 原海报骨架**：深炭灰工作台外框包裹亮暖纸中央画布，不使用 `min-height: 100svh`（避免竖屏平板出现空洞）。
- **1440×900 / 2560×1440**：1440 主宽 1380px（2560 舒展至 1720px）。极细 34px 眉条下，左排双色自示范刊头「画布工作区**布局**」（外框带随画布净占比实时开合的矢量节点框）与原海报青柠竖线总述，右排原海报暗圆叠青柠点、4×4 点阵与三场景切签；中段全宽铺开完整五区工作台窗口（顶栏 + 左工具轨 + 亮纸标尺画布 + 可拖青柠分隔条 + 右图层/属性停靠栏 + 底沿辅助信息条）；紧接下方双栏单真源诊单/快控带与 1:1 承袭原海报的「布局原则 PRINCIPLES」四色圆环横列。
- **390×844（手机竖屏）**：压紧单行刊头与场景切签，将总述移到工作台之后，让完整的五区活体工作台稳占首屏 ≥ 46% 屏高（390px），右侧紧凑停靠栏与可拖青柠分隔条同屏可见并同见下方诊单首句。
- **844×390（手机横屏）**：切左 60% 活体工作台 × 右 40% 紧凑刊头、白话诊单与快控并行。
- **正文节奏**：七个编号小节在暖白纸（#F5F3EE）、微灰稿纸（#EAE7E0）、03 节深炭灰操作暗室（#11161A）、洁亮画纸（#F8F7F3）、柔暖草纸（#EFECE5）、06 节深板岩练习室（#13181D）与 07 节深炭灰原海报展厅（#0F1317）间明暗交替。

## 5. 节目录
- `01` **四区怎么分工**（Zone Blueprint）— 展开原海报四原则，配**可点四区蓝图探针**（点顶栏/左工具/中央画布/右侧栏高亮对应职责与鼠标高频流向）。
- `02` **屏幕一变，面板怎么让路**（Responsive Docking）— 3 档真实屏幕规格切换器（27寸 2560 / 13寸 1280 / 平板 768）× 停靠策略对比，动态演示如何把画布守在经验甜区，并温和补注「浮动面板」过头时的遮挡代价。
- `03` **就近操作，为什么手不累**（Fitts & Context）— 2D Canvas 交互式**指针往返路径与菲茨定律实验台**：切换「就近上下文 / 顶栏深菜单 / 对角远跳」并选择不同编辑任务，直观观察往返折线与难度指数（示意）。
- `04` **从光笔到浏览器画布**（Sixty Years of Canvas）— 1963 Sketchpad → 1983 直接操作 → 1984 MacPaint → 1990/1994 Photoshop → 2016 Figma 演变时间轴，配**可切换时代工作台微缩结构图**。
- `05` **什么时候用，什么时候别用**（When & When Not）— 原海报四大适用场景（视觉设计/插画绘制/排版设计/视频包装）预设对照 + 明确不适用边界（一句话链接到 269/273/274/275/278/279/282/284/285/287）+ 原海报四条快速提示与新手可见性补注。
- `06` **练一练：13 寸屏选哪套？**（Practice）— 同屏同画布四方案单变量对照选择（仅变面板组织方式，标签严格中性），选后展示面积占比与往返路径解析。
- `07` **原海报与关键词**（Original Poster）— 可放大拖拽的 283 原海报 + 六大原海报关键词清单。

## 7. 练习
- **场景**：1280×800 笔记本屏幕上的矢量图形编辑器，画布尺寸固定、左工具栏 44px 固定、顶栏 40px 固定。
- **四个选项（只差面板排布这一个变量，标签严格中性）**：
  - **A · 右侧单栏合并**（右侧 240px 单列内分上下两段放图层与上下文属性，画布净占比 73%，改属性与看画布距离最短）→ **最佳**。
  - **B · 左右对称双栏**（左 220px 常驻图层 + 右 260px 常驻属性，画布被夹成 55% 窄窗，选图层改属性需跨屏左右往返）。
  - **C · 顶栏下拉零侧栏**（彻底撤掉侧栏，所有属性藏进顶部下拉菜单；画布虽达 91%，但每次调值都要多次点开并遮挡上半画布）。
  - **D · 全幅画布双浮窗**（取消固定栏，用两张各 230px 浮窗悬停在画布右上与右下；标称全幅实则遮挡约 24% 创作区，拖图形易撞窗）。
