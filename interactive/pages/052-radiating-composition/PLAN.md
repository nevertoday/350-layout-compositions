# 052 放射式构图（RADIATING COMPOSITION）设计方案

## 1. 一句话道理
放射式构图靠「单源高能核心 + 三阶参差射线 + 暗空呼吸通道」同时锁住焦点与释放向外的视觉动势；一旦射线变成等宽等长的铁丝网、刺穿主标或失源散裂，爆发力就会塌陷成刺眼噪点。

## 2. 开场玩具：星尘光爆雕塑台（Nova Ray Sculptor，2D Canvas，标 `data-perf-drag`）
- **视觉承袭**：1:1 复刻 052 原海报深蓝紫夜空（`#190D2C`）、中央点阵微粒金光核（`#FBE387` → `#F0C632`）、深靛墨巨标「放射式 构图」、三阶射线（粗实金束 / 细实暖白线 / 外散星尘点轨）及外圈实心/空心几何卫星点，支持「原海报 · 星尘光爆」「漫画 · 集中线冲击」「发布 · 舞台光柱」三套标本。
- **怎么玩**：
  - **画布横拖**：连续雕刻射线节奏极差与外扩冲量（向右拉爆出粗细参差、长短错落与星尘暗隙，拖过头则会碎散失流）。
  - **拖核心虚线环 / 鼠标纵拖**：收放中央金光核心留白径（把刺穿文字的射线推出安全核外；拉过头则膨胀成巨核吞掉射线）。
  - **点击外圈任意射线扇区**：单束手雕切换「主金光束 → 星尘虚线 → 暗空留白」，实时改写实绘射线数组。
  - **点击核心或按 Space**：从真实发散源激发脉冲能量波，肉眼检验视线是否被单核锁住并沿主束利落外冲。
  - **键盘**：`←/→` 调节奏极差，`↑/↓` 调核心光晕，`[`/`]` 调外扩冲量，`Space` 激发脉冲。
- **开场状态（故意停在 0/4 复合坏态，绝不先给答案）**：
  - `节奏极差 1.05×`（36 根等宽等长硬条，陷入均纹车轮眩晕）+ `核心留白 5%`（射线直穿主标刺字）+ `源心离散 24%`（多点漂移断核）+ `外扩 52% 齐边硬堵`。
- **双向玩错与单真源读数（全部从 `model.js` 实绘 36 束射线几何实时核算）**：
  - 核心维度：过小 `<17%` → **射线刺字**；过大 `>42%` → **巨核吞光**（退化为 047 圆形构图）；源心偏散 `>12%` 或双核模式 → **散源断核**。
  - 节奏维度：极差 `<1.55×` → **均纹眩晕（电风扇/车轮病）**；有效束过少或最大暗隙 `>115°` → **稀散断流**；过密堵光 `>85%` → **噪点粘连**。
  - 扩散维度：外扩 `<64%` → **短促怯懦**；外端无渐隐与层次落差 → **齐边硬堵**。
  - 合法多解：认可「原海报星尘全爆」「偏心定向爆冲」「漫画集中线聚焦」及用户手雕达标组合，读数白话说明「眼睛会怎么看、为什么卡顿或爆发」，示意指数明确标注「示意」。
- **与最近 12 页的明显差异**：
  - 区别于 087（暖米纸机械星盘 16 臂折扇开合测重心力矩 ΔG）、051（暖米纸双带卷螺）、050（暖米纸黑环开合）、306/305（摄影/POV 视窗）、139/138（印前边距/裁刀）、261/260（网页三段/圣杯）、220/219（十字/竖排排字）、175（双翼镜像）：052 是全幅深蓝紫宇宙暗场上的「无重框放射星尘雕塑与单束手雕」，标题直接嵌在活体点阵金光核中，靠雕刻光束节奏、核晕留白与单源脉冲来驾驭爆发能量。

## 3. 版式骨架
- **1440×900（2560 舒展至 1640px）**：忠实转译 052 原海报「全幅深蓝紫无框五角星环绕构图」——顶行超精简深靛刊头（`NO. 052` + 标题 + 三标本 + 实时状态签）→ 主舞台居中无重框开放星尘画布，原海报 5 条要点（顶中「聚焦核心」、左上「向外扩散」、右上「强调方向」、左下「增强能量」、右下「节奏变化」）直接以原海报折线圆点引注形态环绕星爆（绝无左文右图/通用灰仪表盘感）→ 下方 1:1 复刻原海报薄金圆角胶囊诊单（左 8 线金日徽章 + 单真源白话诊断与动作键 | 右四轨雕刻控条 + 多解/试错对照）→ 底沿 1:1 复刻原海报「左应用提示+短金杠 | 右四栏细竖线金标读数（扩散/能量/聚焦/方向）」。不锁 `100svh`，避免 1024×1366 平板大空白。
- **390×844 竖屏**：压紧单行深靛刊头 + 标本条，让严格等比（1:1 近方）无框星尘画布稳占首屏 ≥46%，画布下折线内直露核心滑轨、薄金胶囊诊单首句与「校准光爆 / 激发脉冲」双键；5 条环绕要点与四栏金标优雅收束在下方，零挤压零扁圆。
- **844×390 横屏**：左 48% 严格等比星尘画布 × 右 52% 精简刊头、薄金胶囊诊单与一键动作并行。

## 5. 节目录（8 个 h2，明暗交替，相邻节交互控件零重复）
- **01 先分清：放射、向心与离心**（浅星光米纸）：四态矢量粒子流对照画布（放射 052 / 向心 053 / 离心 054 / 同心 055），带播放/暂停与流向反转，并一句话链接同小类兄弟页。
- **02 别画成电风扇：节奏极差实验**（深蓝紫暗室）：基于 Wilkins (1984) 纹眩研究的「三层开关剥离实验台」——独立开关粗细极差、长短参差、星尘暗隙，直观看均匀条纹如何变成有机爆发。
- **03 核心偏一点，张力往哪走？**（淡紫雾浅纸）：基于 Arnheim (1982)《中心的力量》的「3:4 画框落点轻点地图」——点击画布任意位置或 5 个典范机位，实时测算角线最长射线、标题安全区与双核撕裂。
- **04 海报上的五句话，实操怎么落地**（浅星光米纸）：原话引出 052 海报五要点与应用提示（温和校订「说多了一点」的普适边界），配「X-Ray 透视拉帘」对比 4 个真实设计成品（活动海报 / 科技发布 / 漫画分镜 / 放射信息图）背后的隐藏射线骨架。
- **05 这个方法从哪来**（深蓝紫档案室）：4 个可核实历史里程碑（哥特玫瑰窗 1194–1260 / 巴拉《街灯》c.1910–11 与博乔尼 1910 / 罗德琴科 1924 与康定斯基 1926 / 阿恩海姆 1982 与威尔金斯 1984），每段配极简几何图示与时间刻度。
- **06 什么时候别用**（淡紫雾浅纸）：4 张「反例翻改卡」（长文排版 / 多品横评 / 沉静工具界面 / 廉价均纹贴纸），点击每张卡当场切换「失效放射」与「克制替代版式」。
- **07 挑一挑：哪张放射式真的立得住？**（深蓝紫考场）：单一变量四选一视觉诊断练习（中性标签 方案 A/B/C/D，四个实绘新品海报只差节奏与核晕两个变量的精确组合），选完给出针对性解析。
- **08 原海报与关键词**（深蓝紫展墙 + 极深靛页脚）：可点击放大拖拽的原海报 `<img id="poster">`、原海报 4 组中英关键词与同小类全集索引链接。

## 7. 练习设计
- **题干**：为新品「星穹声学音箱」做一张发布会主视觉，四版方案配色、文案和主标字号完全一致，只改动了射线排布与核心留白，哪一版真正立得住？
- **四项差异（全中性标签：方案 A / 方案 B / 方案 C / 方案 D）**：
  - 方案 A：32 根等宽等长金色射线（留白 28%）——工整却落入均纹车轮眩晕，毫无节奏层次。
  - 方案 B：三阶长短粗细 + 星尘点线（留白 6%）——爆发够猛但射线直穿主标，焦点可读性崩塌。
  - 方案 C（正确）：三阶长短粗细 + 星尘点线 + 暗空呼吸间隙（留白 29%）——单源凝聚、焦点通透、外放富有张力。
  - 方案 D：三阶长短粗细 + 星尘点线（留白 54%）——核心光斑过大吞掉射线，退化成圆盘色块。
