# 050 环形构图（RING COMPOSITION）设计方案

## 1. 一句话道理
用一个有宽度、有层次、与中心隔开清晰呼吸缝的闭合环带把主体围在当中，大脑会凭格式塔「共同区域」与「闭合性」把环内划成独立视觉场域，视线绕环一周后自然收束并停留在中心焦点上。

## 2. 开场玩具：环带雕琢仪（Annular Field & Aperture Sculptor）
- **核心动作（专属于「环形」本身，无法套给其他构图）**：直接对一个由「中心黄核—白色呼吸缝—宽幅哑黑环带—环内多层级几何星体—外圈薄荷虚线箭头轨」组成的环形场域做**闭合开合、核环光圈比例、呼吸缝宽、多焦点剔除与层级拉开**五重雕琢。
  - **直接横拖画布 / 拖环带缺口柄**（标 `data-perf-drag`）：连续开合环带闭合角（`175°–360°`），并同步微旋环内几何星体，感受 C 形破环怎样「漏走」视线、闭环怎样在靠近 `360°` 时轻吸合拢。
  - **拖内环光圈柄**：连续改变中心黄核占比（`16%–68%`），实时体验中心过小被黑环吞噬、过大挤扁环带退化成实心圆的两端失衡。
  - **直接点按环带上的「抢戏黄圆」**：循环切换它的视觉权重（抢戏巨焦 `0.88×` → 偏亮干扰 `0.56×` → 克制点缀 `0.26×`），亲手消除「多焦点」分心。
  - **切换 4 个原海报「应用场景」模板**：原海报几何星环 / 产品展示腕表 / 界面设计 `72%` 环 / 摄影构图峰峦环窗；按空格或点按钮放行薄荷视线流，观察视线在破口外逃、被抢戏黄圆截胡或顺环归心。
- **开场初始坏态（0/4 复合错态，绝不先给答案）**：
  - 环带右下撕开仅剩 `218°`（闭合断裂 `142°` 缺口）；
  - 环带右上嵌着一枚 `0.88×` 抢戏巨黄圆（多焦点抢戏）；
  - 内环呼吸缝被压死为 `0px`，且环内元素占空高达 `64%`（拥挤贴死）；
  - 环内元素尺寸极差仅 `1.08×`（等大均排无层次）。
- **双向玩错与单真源读数**：所有读数（闭合角、核占比、呼吸缝、尺度极差、占空比、抢戏比）均由 `model.js` 从实绘几何尺寸同一份数据核算，覆盖 8 类双向错态（环带断裂、多焦点抢戏、中心塌陷、中心撑爆、呼吸缝贴死、呼吸缝过宽脱节、环带过挤、等大无层次/空洞失围），并认可「原海报经典解」「宽环深空解」「留气缺口解（≥310° 仍闭合）」及任意满足 4 项门槛的自调解。
- **与最近 12 页及 047 的明确区隔**：
  - 047 是深蓝夜空上的单线细圆轨拖 4 颗卫星；050 是暖纸底上的**哑黑实体宽环带 + 亮黄焦核 + 四角虚线引针海报**，玩的是**光圈核环比例、呼吸缝、环带闭合开合、多焦点消除与多层几何占空**；
  - 与 049（弯弧弓弦）、048（斜椭圆双焦）、086（3D 重门）、338/137/218/259/173/136/217/085/303 在开场动作、色板、骨架与字体上全部明显错开。

## 3. 版式骨架（忠实转译 050 原海报）
- **1440×900（主宽 1380px；2560×1440 舒展至 1640px）**：
  - 顶带左右双角刊头：左为自示范大标「环形构图」（「环」旁嵌随真实画布实时开合的微型环标）+ 翠绿 `RING COMPOSITION` + 绿短杠与原海报总述；右为原海报同款亮黄 `核心原理 ✦` 标签盒、原理原文、6 枚联动进度薄荷菱星与 4 场景切签。
  - 中带为 050 原海报标志性的**「左二 · 中巨环 · 右二」四角放射引针骨架**（左 24%「环绕」「层次」黑圆徽标 + 薄荷虚线引针 × 中 52% 开放无重框 1:1 正方环带雕琢画布 × 右 24%「聚焦」「闭合」黑圆徽标 + 虚线引针），绝不锁 `100svh`、无通用灰黑侧边仪表箱。
  - 底带 1:1 复刻原海报底部齐底双圆角细框匣：左 56% 薄荷切角签「环带雕琢 · 参数与试错」控台 × 右 44% 亮黄角标 `TIPS` 单真源诊单匣（含原海报 4 条实时绿勾/红叉要点 + 一键修复/视线流按钮 + 原海报右下 3 步活体演化微缩图）+ 底沿 `✦ ENCIRCLEMENT · FOCUS · CLOSURE · DEPTH ✦`。
- **1024×1366 / 768×1024 平板竖屏**：自然流排，满宽等比正方环带画布 + 2×2 四原则探针 + 双列齐底控台与诊单，无大片留白。
- **390×844 手机竖屏**：压缩单行刊头（编号 + 标题 + 实时状态章 + 场景快切），总述与核心原理后置，让严格 1:1 正方环带画布稳占首屏 ≥47%，折线内直接露出单真源诊单首句、闭合滑轨与一键修复键。
- **844×390 手机横屏**：左 46% 严格 1:1 环带画布 × 右 54% 紧凑刊头、单真源诊单与核心滑轨并行。

## 5. 节目录（共 8 节，相邻两节不用同一种控件做同一件事）
1. `01 环为何能锁住目光` — 讲清共同区域、格式塔闭合与中心力场（附温和纠偏「说多了一点」）；交互：**四态场域切换器**（散点 / 弧线 / 实心圆 / 环形带 + 视线引力层开关）。
2. `02 先定核，再建环带` — 拆解原海报 3 步建环顺序、核—缝—环经验比例与同小类 8 项构图一句话辨析链接；交互：**三步建环步进剧场 + 反序「先画环再塞核」对照开关**。
3. `03 层次节奏调音暗室`（深黑环暗室）— 讲清近大远小、虚实点阵与呼吸疏密如何把机械圆圈变成有深度的环带；交互：**12 扇区直点环形音序器**（直接点击 12 格切换空/微点/中块/大圆/抢戏黄，实算重心与层级）。
4. `04 四个落地场景拆解` — 还原原海报底部「海报设计 / 产品展示 / 界面设计 / 摄影构图」四类落地法则；交互：**可拖动双屏对比幕布（Before/After Split Curtain）**。
5. `05 从玫瑰窗到数据环`（从哪来）— 梳理 13 世纪沙特尔玫瑰窗、1513–1514 拉斐尔圆形画、1923 韦特海默、1982 阿恩海姆、1992 帕尔默到 2015+ 环形界面演进；交互：**时代结构力线叠印台**。
6. `06 什么时候别用环形`（什么时候别用）— 讲透长文本阅读、表格精密比对、多主体平行叙事与极窄竖条界面为何不能硬套环形；交互：**四类反例需求诊断卡**（点选切换错误硬套 vs 推荐替代方案）。
7. `07 挑出成立的环形构图`（小练习，深黑考场）— 三道单变量视觉辨析题（核缝呼吸 / 单焦层级 / 闭合阈值），四选项只标 `方案 A / B / C / D`；交互：**3 轮 A/B/C/D 视觉考题与逐项几何复盘**。
8. `08 原海报与核心关键词` — 展示原海报高清放大镜（支持点击放大、拖拽平移、`draggable="false"`、Esc 关闭）与 4 个原海报关键词释义，下接标准单行页脚。

## 7. 练习设计
- 三轮独立题目，每轮 4 个实时绘制的几何缩略图选项，按钮仅标注中性文字 `方案 A / B / C / D`（绝不泄露好坏）：
  - **第 1 题（单一变量：呼吸缝与环带节奏）**：A 缝死拥挤（0px / 58%）、B 呼吸与层次兼得（10% 缝 / 3.1× 极差 / 33% 占空，正确）、C 缝宽脱节（26% 缝 / 9% 稀疏）、D 等大机械齿轮（10% 缝 / 1.0× 均排）。
  - **第 2 题（单一变量：中心唯一性与环上亮度权重）**：A 环上抢戏大黄圆（0.86× 核）、B 中心核过小塌陷（16%）、C 焦点唯一且环带退居次层（42% 核 / 0.25× 点缀，正确）、D 中心撑爆只留发丝黑边（66% 核）。
  - **第 3 题（单一变量：闭合度与重心围合）**：A 仅 195° 半开大缺口漏气、B 360° 闭合但全部元素堆在右上导致重心偏移 38%、C 330° 轻留入口且环上重心平衡（正确）、D 150° 单侧短弧（已退化为弧形构图）。
