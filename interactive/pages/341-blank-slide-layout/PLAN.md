# 341 空白幻灯片版式（BLANK SLIDE LAYOUT）设计方案

## 1. 一句话道理
空白幻灯片不是「什么都不放」，而是撤掉所有预设占位符与多余装饰后，用大面积主动留白（图—底反差）和克制的边距、间距，把观众注意力自然收束到唯一核心内容上。

## 2. 开场玩具：空白页 · 留白雕琢与翻页实测台（2D Canvas，标 `data-perf-drag`）
- **核心动作（专属于空白幻灯片）**：
  - 在一张 1:1 承袭 341 原海报暖米画纸（`#FAF7ED`）、细石青灰虚线边距框与天蓝视觉焦点圆（`#A0CDF9`）的真实 **16:9 空白幻灯片** 上直接创作，底部联动 **3 页演播胶片条（01 密集前页 → 02 当前空白页 → 03 后续展开页）**。
  - **横拖画布空纸或虚线边距框**：连续雕塑「安全边距（2%–26%）」与整体呼吸尺度，实测空气走廊实时扩张或挤压。
  - **直拖天蓝主焦点与说明文字块**：自由定位并调节两者间的「呼吸距离」（允许偏右非对称、光学居中、左核右述等多组合法解，靠近黄金落点轻吸附）。
  - **点选画布上虚线框出的「填满焦虑」杂物块**（装饰边框、抢戏副徽章、边角备注）：逐件扫除或放回试错，体会从多焦混战到单一焦点的切换。
  - **按 `Space` 或点「翻页实测」**：先快闪 1.1 秒高密度「上一页数据表」，再干脆切进当前空白页，以淡蓝凝视波纹演播观众眼睛在切换瞬间的真实落眼路径（单焦即瞬间锚定；多焦或贴边则在两点间往复跳动）。
- **开场初始坏态（绝非答案）**：
  - 停在 `0/4 · 四维失衡` 的典型「害怕空白」反面现场：外边距被压到 `3.2%`（内容实测贴边 `2.4%`）贴边窒息、画布挂着 3 处多余杂物使有效留白跌至 `37%`、存在等重抢戏副徽章形成多焦拉扯、主焦点与说明文字间呼吸距仅 `2.0%` 紧贴粘连。
- **怎样算玩错（单真源双向错态，全部从实绘包围盒实时算出）**：
  1. 边距贴边（任一内容距边界 < 8%）→ 提示「贴边窒息，后排看边缘发紧」；
  2. 留白塌陷（有效空白占比 < 62%）→ 提示「杂物与色块挤占空间，留白退化成夹缝」；
  3. 焦点分裂（保留抢戏杂物或主次视觉权重比 < 1.8×）→ 提示「多处抢戏，视线来回跳」；
  4. 呼吸粘连 / 叠压（主视觉与说明净距 < 4.5%）→ 提示「元素贴死，信息糊成一团」；
  5. **反向过空错态**：边距内缩 > 24% 或主视觉缩到 < 4% → 提示「空洞失焦，像误留的空白母版」；
  6. **反向散架错态**：主焦点与说明间距 > 36% → 提示「孤岛散架，失去呼吸关联」；
  7. **偏沉失衡**：全部视觉重心挤向极角（偏心距 > 0.28）→ 提示「整页偏沉一角」。
- **合法解不唯一**：认可「原海报偏右蓝圆解」「光学居中禅意解」「左核右述编辑解」以及用户任意满足四维法则的自定义构图。
- **与最近 12 页的明显区别**：
  - 紧邻的 **340 仅标题** 是「删文字段、把 32 字长句削短成大字标题」；**341 空白版式** 完全不做句子改写，而是以零占位符 16:9 画布直接雕塑**边距、有效留白率、单一视觉焦点、元素呼吸距**四维空间耦合，并独创「密集前页 → 空白页」切换瞬间的凝视波纹实测。
  - 与 139（A4 物理打印机死区毫米检定）、051（螺旋卷绕）、050（环形闭合角）、087（放射极坐标）、260/261（网页框架）玩法与对象完全无交集。

## 3. 版式骨架（1:1 转译 341 原海报「单虚线框开放建筑展页」）
- **1440×900（主宽 1380px，2560 舒展至 1640px）**：
  - 整块开场包裹在原海报招牌的「暖米纸底 +  Generous 外留白 + 一道极细石青灰虚线框」内，零深灰顶栏、零厚重卡片仪表箱、绝不锁 `100svh`。
  - 顶沿非对称刊头：左 62% 自示范大标 `空白幻灯片版式`（底沿天蓝短杠宽度随实测留白率呼吸联动）+ `BLANK SLIDE LAYOUT` + 原海报总述；右 36% 场景剧本签（原海报宣言 / 数据转折 / 产品切片）+ `翻页实测 Space` + 四维状态章。
  - 中段三区开放舞台（无侧栏盒子！）：左 19% 复刻原海报开放纸面蓝箭探针（`留白 ──→` 与 `呼吸感 ──→`）× 中 62% 无黑框 16:9 空白幻灯片画布与底沿单行 3 页胶片切页坞 × 右 19% 复刻原海报 `← 边距`、`← 焦点` 蓝箭探针与右下 `[ + ]` 构图角标。
  - 底部齐通架构诊单条：左 62% 单真源白话诊单 + 精调滑轨（安全边距 / 主焦点尺度）× 右 38% 原海报左下三关键词宣言 + 一键雕琢/多解/双向试错键。首屏一次看全。
- **1024×1366 / 768×1024（平板）**：自然流高度无大空白，满宽 16:9 舞台，四枚蓝箭探针排成 2×2 细线阵，下方齐宽诊单与操轨。
- **390×844（手机竖屏）**：压紧单行刊头与场景签，将总述与四探针说明后置；画布采用「上等比 16:9 幻灯片 + 下内置留白标尺/杂物托盘/3 页胶片」一体构型，稳占首屏 ≥ 46% 高度且零变形，折线内直露白话诊单首句与一键雕琢按钮。
- **844×390（手机横屏）**：左 56% 16:9 空白画布 × 右 44% 紧凑刊头、白话诊单与一键操作并行。
- **正文七节明暗节奏**：01 柔亚麻纸 (`#F2EFE4`) → 02 演讲厅深岩暗室 (`#101720`) → 03 原海报暖米纸 (`#FAF7ED`) → 04 淡天雾蓝纸 (`#EFF5FB`) → 05 柔亚麻纸 (`#F2EFE4`) → 06 演讲厅暗室考场 (`#101720`) → 07 原海报暖米展墙 (`#FAF7ED`) + 极深岩青页脚 (`#0C1219`)。

## 5. 节目录（7 节，h2 均 ≤ 12 字，相邻节控件不重样）
- **01 留白是图底开关** (`FIGURE & GROUND`)：展开原海报 4 条要点，用鲁宾图底与迈耶一致性/冗余原则解释为什么空能帮人看清；交互为**同内容模板塞满↔空白版式分屏拉帘对比**。
- **02 从纸面到空白母版** (`ORIGINS`)：从 1915 鲁宾、1928 奇肖尔德、1987 PowerPoint 母版与空白版式，到 2003–2010 塔夫特/雷诺兹/杜阿尔特/原研哉的极简谱系；交互为**四时代建筑线框演进时间轴**。
- **03 四维空间缺一不可** (`FOUR SPATIAL FORCES`)：剖析边距、留白、焦点、呼吸感的耦合，温和纠正海报「少即是多」过头处（主动留白 vs 被动空洞）；交互为**四维独立故障开关矩（16 种实时构图组合）**。
- **04 同类版式怎么分工** (`SIBLING LAYOUTS`)：一句话定位并链接同小类 8 页（335–340、342–343），说明空白版式专攻的节奏断点与定制页；交互为**5 幕汇报场景路由器**。
- **05 什么时候别用空白** (`WHEN NOT TO USE`)：离线阅读文档、高密数据核对、多人赶稿母版、全套无起伏全空页四大反例；交互为**4 张可展开病例对照签**。
- **06 挑出成立的空白页** (`PRACTICE`)：暗室两题单变量识图测试（第一题只变边距×间距，第二题只变焦点尺度与数量），中性 A/B/C/D 标签，选后叠加虚线标尺拆解理由。
- **07 原海报与关键词** (`ORIGINAL POSTER`)：原海报单图内联 + 可缩放拖拽大图灯箱（`draggable="false"`、Esc 关）+ 原海报 3 组双语关键词与版面解构 + 规范单行页脚。

## 7. 练习设计
- **第 1 题（单一变量：安全边距 × 元素呼吸距）**：四张内容、色彩、字号完全一致的「复购率 78%」16:9 空白页：
  - A（边距 2.5% · 间距 24%：贴边窒息且图字脱节）
  - B（边距 12% · 间距 1.5%：四周虽空但字图紧贴粘连）
  - C（边距 12% · 间距 11%：外沿舒适、字图呼吸成组、76% 主动留白）✅
  - D（边距 26% · 间距 4%：四边过缩退化成中心邮票）
- **第 2 题（单一变量：焦点尺度与数量）**：四张同边距、同文案的「新架构零停机」16:9 空白页：
  - A（焦点仅占宽 4%：退化成空洞误页）
  - B（双等大天蓝焦块：多焦拉扯分散注意力）
  - C（单一占宽 20% 天蓝焦块 + 轻量化结论：74% 留白且一秒锁焦）✅
  - D（占宽 60% 巨型色块：吃掉主动留白退化成满幅色卡）
