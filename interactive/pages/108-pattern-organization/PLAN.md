# 108 图案组织 PATTERN ORGANIZATION — 设计与交互方案

## 1. 一句话道理
图案组织不是把单个零件机械复制铺满画面，而是先在一块方形母砖里安排圆、方、弧的边缘接口，再借可控的平铺规则（平移、错缝、镜像、旋转）让相邻母砖在接缝处咬合成更大的连续母题，并以局部密分打破死板壁纸感，长出可无限延展、自带主次层次的视觉系统。

## 2. 开场玩具：活体母砖织机（TILE LOOM）
- **玩法**：紧扣 108 号原海报「左侧三枚虚线金框标本 + 右侧深绿米白琥珀金整面图案织锦」的结构。
  1. 在 **2×2 活体母砖雕刻格**里点选任意象限切换形体（四分之一弧 / 琥珀金圆 / 琥珀金方 / 留空）或旋转弧向（每点击旋转 90°），右侧 6×4 织锦（含左右边缘半砖延展出血）立刻重绘；
  2. 切换四种平面平铺规则（`p1 纯平移`、`cm 半砖错缝`、`pmm 四向镜像`、`p4 四重旋转`）；
  3. 拖动织锦底沿的 **错缝推移轨（`data-perf-drag`）** 实时滑动奇数行水平错位（0%–100%，靠近 0% 对齐与 50% 半砖错缝时轻磁吸）；
  4. 直接点击织锦画布上任意一块宏观砖格，将其在 `1× 标准尺度` 与 `2× 局部密分子砖` 之间切换（复刻原海报右下角的密分层次）。
- **开场状态（0/4 待组织错态，绝非答案）**：
  - 母砖初始为 4 格塞满错配（左上朝右上的弧、右上金方、左下金圆、右下金方，墨色覆盖率 80% 过满发花）；
  - 平铺规则为 `p1 纯平移`；
  - 行错缝停在 `28%` 的歪斜阶梯位（既未对齐也未落到 50% 半砖错缝）；
  - 跨缝接口咬合率 `0%`（弧线全部撞死在邻砖边缘，画布标出珊瑚红断茬）；
  - 局部密分 `0 / 24` 块（整面同尺度，无节奏层级）。
- **怎样算玩错、读数怎么说（全部由 `model.js` 单真源从实绘几何算出）**：
  - **模块失衡**：覆墨过满（> 72%，经验参考带 32%–68%）报「绿底喘不过气、铺开直接发花」；覆墨过空（< 25%）报「退化成稀疏散点、撑不起骨架」；单一形体报「退回普通单元素重复，失去复合模块结构」。
  - **平铺错缝**：错缝卡在 6%–44% 或 56%–94% 报「奇数行歪斜滑移，砖墙出现阶梯感」。
  - **接缝断茬**：跨砖边界检测接口匹配度，连贯率 < 65% 或咬合点不足时标出珊瑚红断茬，并说明「弧口撞上死墙，视觉碎成孤立小砖」。
  - **密分失衡**：`0` 块密分报「24 块全等平铺，沦为单调墙纸」；密分超过 `50%`（> 12 块）报「高频碎砖漫过半幅，主次反转且易发花」。
- **与最近 12 页的差异**：
  - 107 是单圆点矩阵的对位归轨与 2×2 破格圆；146 是粗黑纸带比例切割与原色配重；024 是平行线散角梳轨；061 是邻近成簇引力；106 是清场孤立；108 独有**「母砖接口编辑 × 对称群变换 × 跨缝拓扑连通实测 × 织锦直点 2× 密分」**双层级生成系统，别的编号无法原样套用。

## 3. 版式骨架
- 忠实承袭 108 号原海报「深森林绿整幅底色 + 顶标金横杠 + 左侧三枚虚线金框标本 + 右侧大面积织锦图案」的现代主义建筑砖谱骨架，**不锁 `100svh`**（避免 1024×1366 竖屏平板留白空洞），零圆角 SaaS 仪表盘感。
- **1440×900 桌面（2560 舒展至 1840px）**：
  - 单行极细眉线 → 顶横带（左为底部嵌有随母砖实时同步的 4 格几何示范条的「图案组织」大标与原海报总述，右为原海报四枚几何金线徽标 `模块 | 平铺 | 连续 | 延展` 2×2 实时体检阵）；
  - 下接双翼工作台：左 37% 依次排 2×2 虚线金框母砖雕刻格、对称规则与密分控条、白话诊单；右 63% 铺 6×4 等比织锦画布与一体化底沿错缝推移轨。
- **1024×1366 / 768×1024 平板**：自然纵向收紧——顶眉与标题 → 满幅等比织锦画布与推移轨 → 下方两栏承接母砖操控与诊单。
- **390×844 手机竖屏**：压缩单行刊头（大标与 `0/4` 标同排，说明退到画布后），首屏直接落入 3:2 等比织锦画布 + 44px 错缝推移轨 + 精简 2×2 母砖微操与一句实时诊单，画布与主操控稳占首屏 ≥ 48%，所有圆形与 1/4 弧保持 1:1 等比绝不压扁。
- **844×390 手机横屏**：切为左 55% 等比织锦与推移轨 × 右 45% 标题、母砖按钮与诊单并行，无横向溢出。

## 4. 配色与字体
- **配色（像素实采自 108 原海报）**：
  - 主深底：深森林绿 `#012F21`（更深暗角 `#012419`、次墨绿面板 `#073A2A`、暗警报节 `#062319`）
  - 浅纸交替底：暖米宣纸 `#FAF5E8`、柔暖羊皮纸 `#EFE5CE`（源自海报米白弧色 `#F0E2C9` / `#EFE9D9` 提亮延展）
  - 标志主accent：琥珀金 `#F3BB2D`（海报实采 `#F2BC28` / `#F1BA2D`；在浅米纸上文字加深为 `#845700` 确保对比度 ≥ 5.5:1）
  - 浅纸主墨：`#0B291F`（次墨 `#354F44`）；深底主墨：`#F5E9D1`（次墨 `#B7CEBE`）
  - 错态警示：克制珊瑚赤陶（深底 `#FF8A6B` / 浅纸 `#B53518`），仅在断茬、过满发花与错缝时出现。
- **字体搭配（全库唯一，两款西文均为最近 12 页零使用）**：
  - `Outfit`（400 / 600 / 700 / 800）— 纯几何无衬线，近 12 页 **0 次使用**，与海报圆形/方形模块基因契合；
  - `DM Mono`（400 / 500）— 清晰几何等宽，近 12 页 **0 次使用**，用于对称群代号（`p1 / cm / pmm / p4`）、坐标与读数；
  - `Noto Sans SC`（400 / 500 / 700 / 900）— 中文正文与厚重无衬线标题。

## 7. 小练习设计
- **题目**：同一套深绿、米白与琥珀金四分之一弧模块，要铺作建筑季刊封面底纹（兼顾接缝连贯与视觉呼吸）。下面四版都用同样的颜色与元件，仅改变**组织方式**，哪一版最稳妥？
- **四选项（仅写中性编号 `方案 A` / `方案 B` / `方案 C` / `方案 D`，画布实时由 `model.js` 绘出，单变量差异）**：
  - **方案 A**：纯平移 + 错向弧口（接缝全部断开，只剩碎片）。
  - **方案 B**：弧口一致但奇数行落于 28% 歪斜偏位（砖墙阶梯错茬）。
  - **方案 C（正确答案）**：`pmm` 四向镜像让跨缝弧线咬合成完整星芒连拱，右下角做适度 2× 密分收束重心。
  - **方案 D**：`pmm` 接口咬合但全幅 100% 切碎成 4× 极密细纹（高频眩光、丧失层级）。
- **解析理由**：选中任意项即刻指出该版在「接口连贯、行缝规整、尺度层级」中卡在哪一环，并讲清方案 C 为什么同时成立。
