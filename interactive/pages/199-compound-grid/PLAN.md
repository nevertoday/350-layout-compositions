# 199 复合网格 · COMPOUND GRID — 互动页方案

## 1. 一句话道理
复合网格不是把几张网随便叠在一起，而是让两套以上具有公约关系的网格（如主栏栅与次模块）共用外框与基线，把长文、视觉与数据各自送进最合适的那条轨道，在统一秩序里容纳异质信息的复杂协作。

## 2. 开场玩具：复合网格透叠叠合台（Compound Grid Acetate Overlay）
- **核心玩法（专属复合网格、无法套用到其他编号）**：
  - 2D Canvas 1:1 化用 199 原海报的暖米纸《自然的秩序与生命力》出版跨页（并支持无缝切换原海报另两例：《城市与水》杂志专题、《年度增长概览》数据年报），在暖米纸上真实叠放三层透明网格底片：**主栏栅轨（孔雀青虚线）**、**次模块轨（薰衣草紫虚线）**与**基线轨（暖砂金横线）**。
  - **画布直拖（`data-perf-drag`）**：在暖米纸画布上横向拖动，如同手推覆盖在原稿上的半透明「次网格赛璐珞描图纸」，实时移动次层模块网相对主层栏栅网的水平相位（-44px ~ +44px）；当偏移拉近 `0px` 且两套网格满足公约条件时，共轨纵线自动磁吸落槽并亮起青紫叠合节点。
  - **顶沿活体复合公式栏**：把原海报底部的 `栏栅 + 模块 + 基线 = 复合网格` 升格为可点击配方引擎——切换主栏数（`4栏 / 5栏 / 6栏 / 12栏`）、次模块列数（`无次轨 / 3×4 / 4×3 / 5×3`）与基线步长（`脱钩 / 24pt / 20pt`）。
  - **直点画布内容块归轨**：直接点击画布里标红错配的版面块（导语长文、叶片图、72% 数据环、PATTERN 圆点、RHYTHM 湖山、GROWTH 鹦鹉螺），切换其绑定轨道（归主栏 / 归次模块 / 错轨悬空），观察内容与轨道匹配后的排版秩序。
  - 键盘支持：焦点落在画布时 `← / →` 微调描纸相位偏移（`Shift` 加速），`↑ / ↓` 轮换选中错位块，`Enter / Space` 执行归轨。
- **开场初始状态（0/4 网格打架错态，绝不先给答案）**：
  1. **互质网格冲突**：主轨 `5栏` 叠次轨 `4×3模块`（`gcd=1`，内部共轨 0 条，切出细碎窄缝噪音）。
  2. **描纸脱槽错位**：次模块描纸整体右偏 `+26px`，模块边缘悬离主栏外框与栏沟。
  3. **内容职能错配**：导语长文被错塞进狭窄模块格、数据环与图式块悬跨半栏。
  4. **基线节拍脱钩**：左右区域各用各的行距，文字底座错齿。
- **玩错反馈与多组合法解**：
  - 所有指标（内部共轨数、最窄碎片缝、描纸错槽像素、职能归轨数、基线同步度、8 类网格失误）全由 `model.js` 从真实绘制坐标单真源实算；做错时直白指出「人眼扫过这页为什么会发乱」（如互质碎缝、退化单网、描纸脱槽、过密割裂、满塞无边距、内容跨半栏等）。
  - 接受多组正当解：`6栏 + 3×4模块 + 24pt/20pt 基线`（原海报解）、`12栏 + 4×3模块`、`12栏 + 3×4模块`、`4栏 + 4×3模块`（同构细分）等，只要满足公约协同、描纸合槽、职能匹配、基线统一即达标。
- **与最近 12 页的明显区别**：
  - 区别于 198（单一基线调磅值对行）、197（拖界墙分四区面积）、153（视口宽度卡尺压四卡片）、154（撬槽涂色块）、237（拉遮罩透度）——本页是**两套网格底片透叠合槽 + 轨道公约数计算 + 异质内容按职归轨**。

## 3. 版式骨架
- 忠实承袭 199 原海报「冷薰衣草灰紫宣纸底 × 暖米纸复合解析台 × 顶部/底部引线标注 × 五枚紫圆核心要点 × 三套应用案例」建筑图谱骨架，0–2px 锐利细线，不锁 `100svh` 避开平板空洞。
- **1440×900（主宽 1380px；2560×1440 舒展至 1780px）**：
  - 32px 深孔雀青顶眉下，顶部非对称通栏排左 30% 嵌双轨线的厚黑大标「复合 网格」+ 英文副标与总述 × 右 70% 活体四段「栏栅 + 模块 + 基线 = 复合状态」配方公式带；
  - 主体左 69% 满幅暖米纸复合解析大画布（顶沿 3 根垂直圆点引线 + 底沿 2 根引线 + 场景切钮）× 右 31% 透明雾紫实测诊单匣下接原海报 5 枚紫圆实时检核灯与快捷压测/归位控钮。
- **1024×1366 / 768×1024 平板**：自然流式转排（刊头与配方条上下紧贴，暖米纸画布全宽居中，下方诊单与五要点双列平铺，零垂直空洞）。
- **390×844 手机竖屏**：单行紧凑顶眉与单行主标，精简 3 格配方芯片，让暖米纸复合画布占首屏 ≥47% 屏高且同屏露诊单首句与触控归槽钮。
- **844×390 手机横屏**：左 57% 暖米纸画布 × 右 43% 紧凑刊头、配方槽与白话诊单并行。

## 5. 节目录（7 节）
- `01` **一套网为何撑不住**（`Why One Grid Breaks`）：原海报 5 要点 + 同素材四网对照切换器（单栏/分栏/模块/复合）。
- `02` **共约密码与碎缝陷阱**（`Divisors & Grid Clash`）：A×B 双轨共倍数矩阵器 + Gerstner 58 单元标尺实测器。
- `03` **三张真实版面透视**（`Three Editorial Blueprints`）：深紫暗室工作台，1:1 复刻原海报「杂志专题 / 数据报告 / 活动海报」三例，支持五层印刷菲林逐层剥离检视。
- `04` **从瑞士杂志到 CSS**（`From Swiss Print to CSS`）：1962 Gerstner → 1981 Müller-Brockmann → 2002 Samara → 2019+ CSS Grid/Subgrid 四代交互式编年标本展柜。
- `05` **什么时候用，何时别用**（`When to Combine or Simplify`）：适用边界与四大劝退场景 + 三维项目体检判定器。
- `06` **小练习：找真复合网格**（`Quiz: Spot True Cohesion`）：四张同内容 SVG 方案（A/B/C/D 中性标，只差网格协作变量），选后亮出透视红绿线并解释缘由。
- `07` **原海报与关键词**（`Original Poster & Keywords`）：原海报点击缩放拖动灯箱 + 四组中英关键词 + 原海报使用建议引录。

## 7. 练习题设计
- **题目**：以下四份版面承载完全相同的「城市生态年报」内容（主标、长评、跨栏大图、三项核心指标），均只调整底层网格协作方式。哪一方案真正发挥了复合网格的协作秩序？
- **选项（中性编号，只差一个变量）**：
  - `A · 方案甲`：统一 4 栏单轨（3 项指标塞进 4 栏留出孤立空槽）
  - `B · 方案乙`：5 栏主轨叠加 4 列模块（互质轨道在版心交错切出碎缝）
  - `C · 方案丙`（正确）：6 栏主轨 + 3×4 模块次轨 + 统一 24pt 基线（左 2 栏排文，右 4 栏大图与 3 枚等宽指标沿共轨齐平）
  - `D · 方案丁`：6 栏主轨 + 3×4 模块次轨，但次区另起独立外框且基线脱钩（视觉割裂为两张拼贴小纸）
