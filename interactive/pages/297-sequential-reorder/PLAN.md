# 297 顺序重排（SEQUENTIAL REORDER）· 互动页方案（PLAN）

> 所属分类：网页与 UI / 响应式重排模式  
> 原海报总述：依据阅读优先级，对内容模块进行顺序切换，强化信息连贯与引导效率。

---

## 1. 一句话道理

读者扫读屏幕时，注意力从第一屏开始快速衰减；顺序重排把同一批内容模块按当前阅读目标的优先级重新排布——把最先需要判断的核心信息提到首位，把关键支撑紧接其后、把背景补充与扩展附录顺次后置——让视线沿着单向递进路径推进，不再来回折返寻找重点，同时在工程落地时守住「视觉顺序与 DOM / 键盘焦点顺序一致」的底线。

- **怎么玩（100% 紧扣「顺序重排」本身的动作，全站独有，无法套用到其他编号）**：

    2. **下方横向阅读序列轨（承袭原海报底部「应用示例」`原始顺序 → 重排后`）**：四张可直拖的蓝图模块卡一字排开（第 1 读位 → 第 4 读位）。

    - **切换重排工程方式（`同步 DOM（无障碍一致）` vs `仅 CSS order（视觉与焦点割裂）`）**：切到「仅 CSS order」后，即使视觉卡片排得整整齐齐，画布上会立刻浮现一道珊瑚红虚线 **`Tab 焦点轨迹 (1→2→3→4)`**，按原始 DOM 顺序在卡片间往返折跳，直观呈现 WCAG 1.3.2 / 2.4.3 的真实风险。
- **一打开是什么状态 & 怎样算玩错**：
  - **开场绝不直接给答案**：默认停在原海报底部亲自示范的 **`原始顺序（信息分散）`：`[▲ 产品背景, ● 产品优势, ■ 使用方法, ≡ 用户案例]`**——背景占了第 1 读位、把核心优势与使用方法都压到了后面，画布上出现 2 处逆序（`(▲,●)` 与 `(▲,■)`）及虚线待修框。
  - **五类真实错态（全部由 `model.js` 从当前排列数组与目标权重单真源算出，双向皆可玩错）**：
    1. **核心滞后（背景抢跑）**：`▲` 占首位、`●` 退居后排（原海报反例）。
    2. **主次倒置（附录占顶）**：`≡` 补充/扩展内容被拖到第 1 位，读者开篇即陷边缘细节。
    3. **起承断层（论据被隔开）**：核心 `●` 虽在首位，但关键支撑 `■` 与之隔着 `▲` 或 `≡`，刚抛结论却找不到支撑证据。
    4. **全盘逆序（倒叙迷宫）**：逆序对 ≥ 3 处，阶梯路径锯齿状往返跳跃。
    5. **视觉与焦点割裂（假重排）**：排序虽达标，但仅用 CSS `order` 视觉挪位，导致键盘 `Tab` 与读屏队列仍在卡片间折返跳线。
  - **多解兼容**：在每个阅读目标下，`model.js` 均支持主解与合理变体解（如「产品速览」既接受原海报标准阶梯 `●→■→▲→≡`，也认可先用案例强化信任的 `●→■→≡→▲` 为「可行实证变体」并说明取舍）。
- **读数说什么「为什么」（单一真源，绝无假精确）**：
  - `model.js` 从当前 4 格排列数组 `[slot0..slot3]` 实时算出**逆序跳变数（真实 Kendall 逆序对 `0–6` 处）**、**首读位命中状态**、**核心-支撑间距**与**焦点逆跳数**，同步驱动画布箭头、左侧单真源诊断文案与底部原海报四原则栏（`优先级前置 / 顺序切换 / 信息连贯 / 流程清晰`）。所有体验评价均用清晰档位（如「逆序 2 处 · 视线折返」）而非虚构百分数。
- **和最近做完的 12 页及相邻 296 的本质区别**：

## 7. 小练习设计（单变量，只变顺序，中性标签 `A / B / C / D`）

- **题目**：同一份移动端在线课程报名页的四个模块（`● 课程核心收获`、`■ 课程大纲与试看`、`▲ 讲师履历与背景`、`≡ 常见问题与售后`）文字、字号、配色与间距完全一致，**唯一不同的是纵向排列顺序**。面对「通勤上班族 15 秒决定是否继续了解」的阅读目标，哪一版最合理？
- **四个选项（仅标 `A` / `B` / `C` / `D`，打乱分布，避免居中猜中）**：
  - **A**（`▲ → ● → ■ → ≡`）：把讲师履历放在首位，等价于原海报「先背景后优势」的反例，读者最关心的核心收获与大纲都被压到后面（逆序 2 处）。
  - **B**（`● → ▲ → ≡ → ■`）：虽把核心收获前置，却把最直接证明「具体教什么」的课程大纲与试看推到最底，中间被履历和售后打断（逆序 2 处，起承断层）。
  - **C（正确答案）**（`● → ■ → ▲ → ≡`）：核心收获领头、大纲与试看紧接支撑、讲师背景顺势补充、售后问题兜底收束，逆序 0 处，阅读路径完全连贯。
  - **D**（`■ → ● → ≡ → ▲`）：开篇先抛大纲细节，读者尚未明白「学完能得什么」就被细节拦截，同时售后夹在讲师履历之前（逆序 2 处）。
