# 045 方形构图（SQUARE COMPOSITION）设计方案

## 1. 一句话道理
正方形四边等长、四角垂直，天生不存在横向延展或纵向攀升的方向偏见；把边界框住、四边留白调匀、模块按格位与对称轴排布，眼睛就能在一瞬间读出秩序、安定与可信赖的结构感。

## 2. 开场玩具：方格筑印台（Square Matrix & Border Bench）
- **核心玩法**：1:1 承袭 045 原海报的深墨绿厚方框、3×3 九宫格模块、四角苔藓绿重复块、中央深绿主核、四枚焦橙中轴定位钉与对角/中轴虚线，做成可交互 2D Canvas（标 `data-perf-drag`）：
  1. **横拖画布 / 拖拉外框侧边手柄**：连续校准外框纵横比（`1.36:1` 扁矩形 ↔ `1.00:1` 等边正方 ↔ `0.78:1` 竖矩形）并同步感受偏边切框的收束；
  2. **点按 3×3 任意方格**：像在印版格位上逐格落印，在「留白 / 苔藓次级模块 / 深绿核心 / 焦橙轴点」间切换，也可开启「四向镜像锁」体验对称铺砖；
  3. **拖拉边框厚薄与边距、切换 4 种原海报场景皮肤**（原海报结构 / 品牌标识 / 产品展示 / 海报版式）及 4 种合法构图法（中心聚焦 / 九宫结构 / 边框包围 / 重复对称）。
- **开场错态（绝非答案）**：刻意停在 `0/4` 复合失序态——外框被拉扁成 `1.34:1`、左侧边距仅 `3%` 而右侧达 `15%`（偏边贴框）、3×3 格内乱塞 7 块含多枚重块导致留白塌缩至 `20%`、重心左倾失衡、中央格反空无聚焦。
- **怎样算玩错、错了读数怎么说**：由 `model.js` 从当前实绘外框矩形、四边实测边距、实绘模块面积与视觉权重矩单真源核算 7 类双向错态（失方偏扁/偏长、边距失齐、满塞窒息、空荡失锚、对称倾覆、主次平权、失框散逸）。只要玩错，读数就用白话指出人眼此刻会先看到什么混乱（例如「左沿紧贴 3%、右沿空出 15%，整块网格像滑向纸边」），而不是只报冷冰冰的数字；同时接受中心聚焦、九宫结构、边框包围、重复对称多组合法解。
- **与最近 12 页的差异**：044 是 0°–90° 旋菱与拖四顶点；169 是极坐标旋转射线；299 是 CSS Grid 拖宽与改 SPAN；333 是推拉拱窗遮幕；132 是调单栏双虚线栏宽；213 是右起横幅波点牵引；254 是调图标文字亲密内距；043 是调倒三角顶展翼与落点；168 是平移贯通中轴；131 是调星图反差与跳点；212 是推齐左起文字行；081 是透视景深距离。045 独有「1:1 正方边界校准 + 3×3 方格落印铺块 + 四向镜像对称锁 + 边距框厚四维校验」。

## 3. 版式骨架
忠实转译 045 原海报结构，不锁 `min-height: 100svh`：
- **1440×900（2560 舒展至 1680px）**：顶部轻刊眉（无深色顶栏）→ 主舞台非对称双翼：左 34% 为「1:1 自示范田字格橙钉方印大标『方形 构图』+ 12 点横尺 + 5 枚核心关键词活体灯 + 单真源诊单匣（齐底无空洞）」，右 66% 为「■ 以方为本导语 + 左 65% 正方形活体筑印主画布 × 右 35% 原海报 4 条圆点虚线引出活体注记 + 底沿紧贴操轨」→ 满宽深墨绿 `TIPS` 对勾通栏条。
- **1024×1366 / 768×1024 平板**：自然折排，方印标题横置、等比正方形主画布居中撑满，四引注与诊单齐底 2×2 排列零空洞。
- **390×844 手机竖屏**：压缩单行刊头（迷你田字方印标 + 标题 + 状态签），导语与关键词后置，让 1:1 等比正方形画布稳占首屏 ≥ 45% 屏高且折线内直见诊单首句与一键纠偏。
- **844×390 手机横屏**：左 48% 严格 1:1 正方形画布 × 右 52% 刊头、诊单与核心快捷控件并行。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻交互不重复）
- **01 四个支柱，撑起方寸秩序**（亮宣纸）：展开原海报 4 要点与构建步骤 1→4；交互为**四步构建演进步进剧场**。
- **02 方形不是空箱，它自带力场**（鼠尾草雾纸）：拆解阿恩海姆正方形「隐蔽结构」与阿尔伯斯嵌套微移；交互为**2D 力场探测盘（点放圆片测隐蔽骨架拉力 + 阿尔伯斯下沉比例对照）**。
- **03 同一个方框，四种排法**（深森林暗室）：对照原海报中栏 4 种构图方法，并一言链接 `044/046/055/056`；交互为**四式并排联动留白/框厚分屏对比仪**。
- **04 方形构图从哪来**（暖米典籍纸）：1915 马列维奇 → 1929 Rolleiflex 6×6 → 1950 阿尔伯斯 → 1954/1974 阿恩海姆 → 1981 米勒-布罗克曼；交互为**年代碑牌切换 + 实时历史几何图式重构图版**。
- **05 什么时候用，什么时候别用**（亮宣纸）：展开原海报 4 大应用场景并温和补全 4 类反面情境；交互为**真实命题「方框 vs 换构图」切换诊断卡**。
- **06 小练习：挑出最站得住脚的那一方**（深森林考场）：3 道四选一单变量辨析题（中性 A/B/C/D 标签）；交互为**作答 + 视觉标尺叠层即时核验**。
- **07 原海报与核心关键词**（暖亚麻原纸 + 深墨绿页脚）：原海报全屏可拖拽缩放看图器、5 关键词与 4 TIPS 汇总、同小类跳转索引。

## 7. 练习设计
3 题均为四选一、严格中性 A/B/C/D 标签、每次只改变单一关键变量：
- **题 1（四边边距一致性）**：固定中心焦块与四角轻块，只改四边边距（A 四边均等 14% / B 偏边左 4% 右 24% / C 四边紧勒 3% / D 四边空缩 34%），正确为 A。
- **题 2（模块密度与主次层级）**：固定 1:1 均等方框与 3×3 网格，只改模块填充（A 中心 1 主核 + 4 对称次块 + 4 留白 / B 9 格满塞同等深色 / C 四角 4 枚深核抢戏中心反空 / D 单角 1 块孤立偏垂），正确为 A。
- **题 3（对称重心与 1:1 框比）**：固定 4 件器物单元，只改框比与对称排布（A 1:1 正方且四向重量对衡 / B 1:1 正方但重物全挤左半边 / C 框被拉扁成 1.35:1 偏斜矩形 / D 双层超厚粗框压扁主体空间），正确为 A。
