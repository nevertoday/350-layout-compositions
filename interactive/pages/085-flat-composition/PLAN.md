# 085 平面化构图（FLAT COMPOSITION）互动页方案

## 1. 一句话道理
主动抽掉消失点、立体阴影与繁琐细节，把景物压回二维纸面，靠清晰的轮廓、大面积纯色与适度重叠，让画面在远距离与复杂环境里一眼立住。

## 2. 开场玩具：三维压平压画台（The Flatness Press）
- **玩法**：1:1 复刻 085 原海报中部 2.25:1 宽幅地中海静物画（蓝天、朱红台面、左右奶白几何小屋、炭黑花瓶、蓝口白碗、朱红七叶枝、右下黑白棋盘格），并可切换「原海报·地中海」「马蒂斯·红室」「浮世绘·波桥」三套题材。
  - 在开放画布空白处左右横拖（`data-perf-drag`）：连续压缩三维空间透视（0% 立体消失点房间 ↔ 100% 正交二维纯平面），亲眼看斜桌面收平成纯红横带、立体侧墙折回平面立面。
  - 直接按住画布里的炭黑花瓶、奶白大碗或朱红叶枝左右拖动：调整二维重叠关系，体会「压平之后怎样靠跨界重叠建立前后层序」。
  - 配合原海报同款 2×2「如何实现平面化？」互动控制格，切换光影剥离（写实投影 / 半平涂 / 纯色平涂）、轮廓简形（繁琐写实 / 折中 / 极简剪影）、色彩平涂对比与装饰节奏（无节奏 / 棋盘格节奏 / 满屏噪乱）。
- **开场初始状态（坏态 0/4）**：刻意停在「透视未压平（压平度 22%，桌面倾角明显、消失点透视线外露）+ 立体明暗与长投影未除 + 写实繁琐轮廓 + 器物未有效重叠/或黑瓶偏位」的夹生立体态，绝不预先给答案。
- **怎样算玩错 & 读数怎么说（单真源双向核算）**：
  - `model.js` 算出每一件物体的真实 2D 投影轮廓、桌面透视倾角、两两包围盒重叠面积与相邻色块 WCAG 亮度比，渲染与诊单共用同一组数据：
    1. **透视残留 / 夹生立体**：压平度 < 85% 或桌面仍呈透视斜角，诊单报实测桌面倾角，说明「透视把眼睛往深处拽，和平面色块互相打架」。
    2. **体积光影未剥离**：残留明暗渐变或投影，说明「高光和投影还在暗示三维体积，削弱了色面的整体感」。
    3. **零重叠·真成贴纸平铺**：把花瓶、白碗、红叶拉开互不压边（跨界重叠 = 0 处），呼应原海报底沿「平面化不是简单的平铺」，指出「所有元素排排坐互不咬合，丢掉了二维里的前后层序」。
    4. **同色融死 / 切线撞死 / 过度叠压**：把黑花瓶拖去压住右屋黑拱门（纯黑叠纯黑，亮度比 1.00×）或与白碗互挡超过一半，画布当场标红圈出融死区，诊单报实测重合并说明「轮廓边界消失，剪影识别度塌了」。
    5. **装饰失序**：关掉节奏带留大片死空，或打开满屏杂乱花纹切碎纯色大底，诊单双向指出「过空无韵律」或「花纹太碎破坏纯色整体性」。
  - 接受「原海报经典解」「马蒂斯大面积平涂解」「极简三色高对比解」等多组合法 4/4 解。
- **与最近 12 页的区别**：最近 12 页覆盖三列栏缝（257）、双人 180° 机位（302）、圆轨星盘（047）、随机撒字（171）、三景景深剖片（084）、PPT 母版手术（336）、横直翻排（216）、双列脊线（256）、多栏 span 跨度（134）、矩形断裁（046）、单人摇镜（301）、演讲焦点（335）。本页是全库唯一的「三维透视空间连续坍缩成纯平版画 + 剥离光影建模 + 二维剪影防同色融死」压画工作台，且采用全库最近 12 页唯一的满幅阳光铬黄亮色现代主义海报展板。

## 3. 版式骨架
- 忠实转译 085 原海报「铬黄满幅现代主义平面展板」结构，绝不锁 `100svh` 避平板大空白，零通用深灰顶栏与悬浮仪表盘箱：
  - **1440×900**（主宽 1360px；**2560** 舒展至 1660px）：顶带左巨幅粗黑自示范大标「平面化构图」（「平」字底衬纯蓝水平基准杠）+ 中原海报总述与四枚竖虚线关键词 + 右原海报蓝圆日与奶白云（叠题材切换与状态印章）→ 中带满宽 2.25:1 无框压画台与紧贴式黑线压画操轨 → 底带左 54%「核心特征」四枚蓝红原海报活体圆徽 + 纯黑单真源白话诊单条，右 46% 齐底黑框「如何实现平面化？」2×2 互动控制格 → 底沿细黑线原海报星号宣言。
  - **1024×1366 / 768×1024 平板**：自然流排，画布满宽，底带双翼自然齐底或垂直承接，零大片空白。
  - **390×844 手机竖屏**：压紧单行刊头并把总述与四关键词后置至画布下方；画布切 4:3 等比构图稳占首屏 ≥ 46%（圆日与花瓶绝不变椭圆），折线内直露压平滑杆、诊单首句与一键纠偏。
  - **844×390 手机横屏**：左 56% 压画画布与滑杆 × 右 44% 紧凑标题、四步快切与诊单首句并行。
- 正文七节纸面明暗与纯色块交替：奶白原纸（01）→ 浅天青雾纸（02）→ 深国际蓝暗室（03）→ 淡铬黄柔纸（04）→ 纯白美术纸（05）→ 炭墨深灰考场（06）→ 铬黄原海报展墙 + 纯黑页脚（07）。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻控件零重复）
- **01 为什么扁平更有力**（*Why Flat Hits Harder*）：展开原海报总述、四特征与「低对比配色」温和补正。交互：**双联刮幕对比器**（拖竖向 VS 标尺横扫透视写实 vs 平面纯色 + 5 米退后缩略检视）。
- **02 平面里怎么分前后**（*Depth Without Perspective*）：引阿恩海姆重叠原理，拆解跨界遮挡、高视并置与色面分离，链接 082/083/084/086。交互：**剪纸图层叠压堆栈**（调整四层 Z 序 + 切换贴边平铺/跨界遮挡/切线粘连事故）。
- **03 浮世绘到画布觉醒**（*From Ukiyo-e to Flatness*）：深蓝暗室梳理浮世绘→1890 德尼宣言→1891 洛特雷克海报→1911 马蒂斯《红色画室》→1960 格林伯格平面性理论。交互：**四时期历史几何演进展台**（点年份切换画幅解剖演变）。
- **04 四个场景怎么落地**（*Four Practical Uses*）：对应原海报海报/插画/包装/图案四大场景与经验值参数，链接 077/078/079/080。交互：**四联实样工坊 + 色数压测与纯黑白剪影检视镜**。
- **05 什么时候别用它**（*When Not to Flatten*）：拆解 4 类不适合平面化的需求并指路 081/082/083/084/086。交互：**四项需求排查决策器**（勾选场景实时输出判定与替代构图）。
- **06 小练习：一眼辨高下**（*Quick Check*）：炭墨暗考场两道单变量选择题。交互：**A/B/C/D 矢量构图卡直选 + 实时标注复盘**。
- **07 原海报与关键词**（*Original Poster*）：展示原海报与四组关键词。交互：**灯箱放大、拖拽看细节、Esc 关闭**。

## 7. 小练习设计（单变量、中性标签）
- **题 1（变量：重叠与轮廓接触关系）**：四张同色同比例纯平静物，标签仅标 `方案 A / B / C / D`：A 零重叠一字排开、B 跨界重叠且轮廓独立（正确）、C 黑花瓶贴死右屋黑拱门（同色融死与切线粘连）、D 三件器物堆叠同轴互挡超半。
- **题 2（变量：纵深与明度语法一致性）**：四张同构图静物，标签仅标 `方案 A / B / C / D`：A 统一纯平色面与清晰明度分层（正确）、B 混入透视斜桌与收缩棋盘、C 混入写实高光与地面投影、D 色彩明度全部打平变灰糊。
