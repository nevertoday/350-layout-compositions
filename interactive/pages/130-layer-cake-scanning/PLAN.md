# 130 层蛋糕扫描模式 · 互动页方案

## 1. 一句话道理
当网页把内容切成清晰横带、每层挂上言之有物的小标题，读者就能像看千层蛋糕横切面一样先沿标题横扫筛选，只切开与自己目标相关的那一两层正文，避开整段盲读。

## 2. 开场玩具（千层剖面切片台）
- **怎么玩**：
  - 直接在深靛紫夜色背景上的 2D 开放画布（标 `data-perf-drag`）**左右横拖**：连续推拉「切层分离度（0%–100%）」，实时改变真实绘制的标题/正文比例、层间空气缝与五层奶油—桃橘—珊瑚横带剖面，同时实时驱动眼动光带在「F 型退化」「清晰层蛋糕横带」「碎裂断层」之间连续演变。
  - **直接点击画布里的任意一层**：展开或收起该层正文（「决定是否深入」）；点每层右侧的小阶梯按钮（`↑/↓`）或控台按钮，把倒置的五层排回由泛到细的阅读漏斗。
  - 配合紧贴画布底沿的切片控台，切换**标题写法**（`空话卖关子` / `前置信息型` / `全篇满加粗`）、**条带节奏**（`原海报条带` / `左锚齐眉` / `锯齿乱跳` / `8层过碎`）、**三套真实文档题材**（`能源报告·原海报` / `退换货指南` / `定价页对比`）与**眼动带 / 裸版**视图；键盘 `←/→` 调节切层分离度、`1–5` 展开对应层。
- **开场初始状态（刻意非答案）**：
  - 打开时落在复合错态：**切层分离度 16%（塌陷糊墙，标题仅正文 1.1×、层缝 3px）+ 标题卖关子（看不出哪层有答案）+ 层序倒置（第五层「决定行动」插队到第二层）**。此时眼动模拟光带退化成 F 型左缘漂移，读数栏与右侧「核心原则」五枚活体灯同步指明问题。
- **怎样算玩错、错了读数怎么说（双向可错，全部由 `model.js` 从实绘几何与文案状态单真源计算）**：
  1. **糊墙塌陷（分离度 < 36%）**：标题与正文糊成一块，视线无法横向逐层跳跃，被迫退回 F 型盲扫。
  2. **过宽断层（分离度 > 84%）**：层缝撑得过宽、标题臃肿，五层脱离同一视窗节奏，跳读反而费力。
  3. **标题失语（空话卖关子）**：横带虽然分明，但小标题没说出内容主题，读者仍得逐段钻进正文碰运气。
  4. **满屏高喊（全篇满加粗）**：正文和标题一样粗亮，「奶油留白」消失，视线在各处乱跳（斑点化噪声）。
  5. **层序倒置（行动越位 / 主标沉底）**：还没给出大意与依据就先推行动按钮，打断「由泛到细，逐步深入」。
  6. **节奏乱跳（锯齿错排）**：每层起点忽左忽右，眼睛每次下移都要重新找左对齐锚点。
  7. **过度切碎（8 层碎条）**：把短内容硬劈成过多细条，小标题比正文还吵，引发标题疲劳。
  - **多组合法解**：只要分离度处于健康窗（44%–78%，覆盖紧凑快扫、原海报标准、舒朗研报三档）+ 信息前置标题 + 一致条带节奏（原海报满幅条带或左锚齐眉条带）+ 合理漏斗顺序（标准 `1→2→3→4→5` 或先证后细 `1→2→4→3→5`），均判定层蛋糕成立并给出差异化评语。
- **读数说什么「为什么」**：不仅报「标题/正文比 1.85×」「层缝 18px」，还直接解释「这样摆为什么让眼睛先停在标题横带、跳过无关正文，或为什么被迫退回 F 型逐行搜寻」；涉及扫读耗时全部标注「（示意）」。
- **与最近 12 页的明显区别**：
  - 全部 12 页近期作品首屏都是浅纸/明黄/柔粉底，本页忠实承袭 130 原海报的**深靛紫夜色展面 + 五层暖奶油至珊瑚橙横切蛋糕条带**。
  - 与同小类 127（F 型：燕麦白纸 + 0–6s 时间轴拖拽 + 四区改稿）完全不同：本页不拖时间轴，而是**横拖切开/合拢五层蛋糕剖面、直点展开单层深读与重排五层漏斗顺序**，在画面里现场目睹同一篇文档在 F 型退化、斑点噪声与层蛋糕横带间的结构切换。

## 3. 版式骨架
- 忠实转译 130 原海报的深靛紫无框开放结构（零深色通用导航条、零仪表盘灰卡、绝不锁 `100svh` 避免平板空洞）：
- **1440×900（主宽 1380px，2560 舒展至 1680px）**：
  - 顶沿开放双区刊头：左置自示范层切大标「层蛋糕扫描模式」+ `LAYER-CAKE SCANNING` + 标志珊瑚短杠 + 原海报总述；右置分类标、实时状态签与三题材切签。
  - 主区左 69% 为深靛紫底上直铺的 5 层横切蛋糕开放舞台（含原海报左缘「第一层 抓住大意 → 第五层 决定行动」珊瑚虚箭梯）与底沿一体化深紫切片控台；右 31% 1:1 复刻原海报「核心原则」五枚珊瑚图符活体诊断脊（横向层读 / 标题驱动 / 节奏重复 / 快速定位 / 信息分层）及单真源白话研判笺。
  - 首屏底沿细线承接 4 枚原海报「带来的价值」实况条（高效浏览 / 抓住重点 / 阅读流畅 / 提升决策）。
- **390×844 竖屏**：压紧单行眉与单行主标，总述移至舞台之后，让等比 5 层蛋糕画布稳占首屏 ≥ 48% 高度，同时首屏内直见切层滑轨与研判首句。
- **844×390 横屏**：切换左 56% 等比切片舞台 × 右 44% 刊头、切签与研判控台并行。
- **1024×1366 / 768×1024 平板**：自然流排，画布保真比例，右侧五原则改为两列紧凑阵，上下贴合零大片留白。

## 4. 配色和字体
- **逐像素实采自 130 原海报**：
  - 深靛紫夜底：`#11082D`（主底）、`#150D33`（次深底）、`#1C123B`（暗室节底）、`#1F1833`（价值深卡面）、`#292045`（微升舱面）。
  - 五层蛋糕暖阶：第一层奶油 `#F6E5CF`、第二层浅杏 `#F3CCB3`、第三层珊瑚橘 `#F98F6F`、第四层蜜桃粉 `#FCB396`、第五层奶油收束 `#EFDECA`。
  - 信号珊瑚与暗/浅纸高对比字色：暗底主字 `#FEEEDD`、暗底次字 `#D8CEE8`、暗底珊瑚高亮 `#FF8468`（原短杠 `#F57865`）；正文浅纸（奶油纸 `#F7EFE2`、浅桃雾 `#FBF2EA`、象牙纸 `#FAF5EC`、杏砂纸 `#F4E6D6`）主字 `#140D2B`、次字 `#463D62`、浅纸安全深赤珊瑚字 `#B3371E`；成立状态深松翠 `#156348`（暗底 `#6EE0B2`）、警示赤 `#B3261E`（暗底 `#FF7A70`）。
- **字体搭配（全库唯一，三款西文/等宽在近 12 页全部 0 次使用，且与 127/128/129 零重叠）**：
  - `Noto Sans SC`（400, 500, 700, 900）——中文主标与正文，呼应原海报利落几何无衬线。
  - `Sora`（400, 600, 700，近 12 页 0 次使用）——宽阔几何英文标与大字标签（`LAYER-CAKE SCANNING` / `LAYERS` 等）。
  - `Young Serif`（400，近 12 页 0 次使用）——温润复古粗衬线，用于章节大编号 `01–07` 与编辑导语点缀。
  - `IBM Plex Mono`（400, 500, 600，近 12 页 0 次使用）——等宽工业数字与层级标尺读数。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻两节控件不重样）
- **01 蛋糕与奶油：扫读机制**（暖奶油纸）：解释眼动横带与跳过正文的原理，温和补充原海报「逐层顺序」的真实弹性；交互：**左右拉帘盲测对比镜**（拖动中缝对比无分层文本墙 vs 层蛋糕）。
- **02 一眼定去留：五层示例**（深靛紫底）：逐层拆解原海报「全球能源转型加速推进」报告示例与四项价值；交互：**五层 X 光显隐开关**（勾选任意层开关，实时在原海报暖奶油报告卡上观察缺层后果）。
- **03 标题怎么写：实词与层级**（浅桃雾纸）：讲清「信息气味」与视觉阶差缺一不可；交互：**3 秒限时真人扫读挑战**（亲自在悬念标题与信息前置标题两版长文中找答案，实测毫秒耗时差）。
- **04 从哪来：眼动实证脉络**（深紫暗室）：梳理由 1969 结构化分块至 2019 NN/g 命名与 WCAG 无障碍的实证史，并用一句话 + 链接区分同族 127/128/129/131；交互：**五节点年代步进器**（切换各年代对应的眼动模式图谱）。
- **05 什么时候用，什么时候别用**（象牙纸）：给出明确边界——悬疑叙事、法律医疗承诺通读、单屏艺术海报、超短提示都不该硬套层蛋糕；交互：**六场景需求分拣台**（点选不同项目需求，查看适用结论与版式示意）。
- **06 动手判一判：四选一练习**（杏砂纸）：四版同一售后文档只差「标题层设计」单一变量；交互：**四选一中性选项评测卡**（选后给出精准解析并可逐项核验）。
- **07 原海报与关键词**（深靛紫展墙）：完整原海报（可点开缩放、拖拽、`Esc` 关闭）与原海报核心词卡，附规范页脚。

## 7. 练习设计
- **题目**：同一份《智能门锁安装与售后说明》四节长文，用户只想在 5 秒内确认「电池没电怎么应急开锁」，以下哪一版最符合层蛋糕扫描模式？
- **四项只差「标题层写法与反差处理」一个变量（中性标签 A/B/C/D）**：
  - **方案 A**：标题字号粗大、留白清朗，但四条小标题全写文艺悬念语（「看不见的守护」等）——有层无意。
  - **方案 B**：四条小标题直写主题（「电池续航与应急供电」等），但字号几乎同正文、不加粗、上下等距——有意无层。
  - **方案 C（正确）**：四条小标题直写主题、前置关键词，且以清晰字重字号与「段上宽、段下紧」留白切开横带，正文保持克制——既切层又指路。
  - **方案 D**：小标题既具体又醒目，但正文六成句子同步加粗加底色——奶油被涂成蛋糕，全场高喊失去扫读反差。
