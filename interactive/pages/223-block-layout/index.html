        01
        

          
块级的三条铁律

          
THE THREE RULES · MODULE, CONTAINER & HIERARCHY

        

      


      
海报把块级布局凝练成三个核心概念：分块（将页面划分为独立模块）、容器（限定模块范围与内容）、层级（通过大小与位置建立优先级）。落到浏览器排版引擎里，它们对应着块级盒子最直白的三条力学规则：独占一行、撑满父宽、高度随内容自然生长。


      
      

        

          
          

            
分块 MODULE

            
「将页面划分为独立模块」——每个块级元素前后自动断行，像建筑里的独立房间，不会和上下邻居糊成同一行文字。

          

        

        

          
          

            
容器 CONTAINER

            
「限定模块范围与内容」——父容器划出可用宽度上限，子块在未指定宽度时默认填满这一整条水平通道。

          

        

        

          
          

            
层级 HIERARCHY

            
「通过大小与位置建立优先级」——由于块级盒子的宽高与四向边距全部生效，大面积主槽自然稳压小面积辅助块。

        05
        

          
什么时候用，什么时候别用

          
WHEN TO USE & WHEN TO HAND OFF

        

      


      

        

          
适合直接用块级布局

          
    
            
  • 文档大骨架与移动端单列：页眉、正文、侧栏、页脚自上而下排开，天然稳妥。
    • 
            
  • 不定高内容容器：评论卡、商品描述、表单分组，需要文字增多时顺流推开后续板块。
    • 
            
  • 外层职责隔离壳：就算内部要用弹性或网格，外层依然是块级容器负责划分区块边界。
    • 
          

        

        

          
什么时候别硬用纯块级

          
    
            
  • 文字内贴身元素：徽章、行内链接强行设 block 会撕断句子，交 224 行内布局。
    • 
            
  • 精密单轴 / 二维对齐：导航等距用 226 弹性盒，多行列对齐与跨格用 227 网格 与 228 子网格。
    • 
            
  • 过度分块套娃（Divitis）：短短两句话叠四层带框带影的容器，反而制造视觉碎裂与层级噪音。
    • 
            
  • 多端断点重排：全屏断点交 240 响应式布局，独立卡片按自身宽变阵交 242 容器查询。
    •
