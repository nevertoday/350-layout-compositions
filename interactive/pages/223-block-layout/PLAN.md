# 223 · 块级布局（BLOCK LAYOUT）互动页设计方案

## 1. 一句话道理
块级布局把一整屏零散信息装进边界清晰、默认纵向独占整行的矩形容器，让每块内容彼此隔离、各守其宽、随内容自然撑高，并靠尺度与嵌套建立主次层级。

## 2. 开场玩具
- **名称**：构成主义块级装配舱与盒尺 X-Ray 透视台（真 CSS 块级 DOM + 同步 2D Canvas 盒尺/折叠/溢出测绘层，朱红容器右壁拖柄标 `data-perf-drag`，且支持在舞台横向推拉容器宽度）。
- **视觉承袭**：1:1 转译 223 原海报的双重朱红 L 形嵌套外框（`容器 CONTAINER`）→ 暖白 `模块 MODULE` → 琥珀黄 `内容区 CONTENT`（内含朱红圆日与炭黑双峰）+ 右侧暖砂三叠区（`侧栏区 / 导航区 / 辅助区`）+ 炭黑底部模块；并支持切换「原海报 · 模块标本」「博客 · 长文骨架」「产品 · 后台面板」三套语境。
- **开场状态（0/4 四重块级翻车错态，绝非答案）**：
  1. 主内容块设为 `display: inline`（宽高失效、矩形结构塌成单行碎条）；
  2. 宽度策略设为 `width: 100%` + `box-sizing: content-box`（内距与边框把模块硬撑出朱红容器右墙）；
  3. 外层容器无 `padding/border` 且未隔离（首子块 `margin-top` 穿透父容器顶部拉出裂隙）；
  4. 辅助区写死 `height: 64px`（一旦点击 `+ 增块` 或现有模块超出即刻溢底撞上炭黑底部块）。
- **怎么玩与双向错态**：
  - 横拖容器朱红右墙（或拖动滑轨 / 方向键）在 `280px–680px` 连续改变父容器宽，实时观察七段水平恒等式与响应断行；
  - 直点画布标红病灶或下方属性刀闸，切换 `display`（`inline` / `inline-block` / `block`）、宽度盒模型（`100% content-box` / `100% border-box` / `auto`）、容器封口（无隔离 / 加内距边框 / `flow-root`）、辅助区高度（`64px` 定死 / `auto` 自适应）；
  - 真增删辅助模块（`+ 增块` / `- 删块`，1–7 块）验证「可扩展」，并可切换原海报 4 种组合结构（单栏 / 双栏 / 三栏 / 头+中+底）；
  - 按 `Space` 启动「盒尺透视 X-Ray 扫描」，Canvas 沿容器发射扫描线标出实时四层像素盒尺与七段水平等式。
  - **怎样算玩错**：`model.js` 从真实容器与模块几何单真源双向检出 8 类正反错态（行内塌陷、盒模型撑破右墙、顶边距穿透、定高爆盒、主次倒挂/扁平、过碎拆块 >6 块、内距过厚挤窄内容、窄容器硬塞三栏）。随便乱点不会过关；同时认可多组合法解（`width: auto` 原海报典范、`border-box` 严丝合缝解、窄屏单栏专注解、扩展长卷解）。
- **与最近 12 页的明显差异**：近 12 页多为纯 Canvas 排字、天平、焦点星图、破框/封框画作、眯眼滑幕或单列文档流；本页是以**真实 CSS 块级盒模型嵌套容器**为核心的建筑积木装配台，直接操作 `display`、`box-sizing`、`width: auto`、`height: auto` 与真实增删块并做双轨盒尺测绘，别的编号无法套用。

## 3. 版式骨架
1:1 转译 223 原海报的「构成主义顶标 + 左红框嵌套舞台 × 右纯黑分块原则竖板 + 通宽朱红底条」不对称拼版（绝不锁 `100svh`，避免平板大空白）：
- **1440×900（主宽 1380px；2560×1440 舒展至 1640px）**：顶部左 62% 巨黑自示范分块大标「块级布局」（四字落入随独立度微联动的独立块槽）对望右 38% 朱红 `BLOCK LAYOUT` + 总述 + 短红横杠；中部严格齐底 66% : 34%——左 66% 朱红双重 L 框装配舱与底沿单行刀闸轨，右 34% 深炭黑「分块原则」竖板（顶部单真源诊单 + 细白虚线分隔的红/黄/砂三原则实检探针 + 实时 4 行 CSS 窗）；底部以通宽朱红宣言条（左 3×3 白点阵、右细白圆）收口首屏。
- **1024×1366 / 768×1024 平板**：自然流排布，上满宽嵌套舞台、下炭黑原则板与诊单横向双栏齐底，零空洞。
- **390×844 手机竖屏**：压缩单行刊头、后置总述与次要原则描述，让朱红嵌套装配台稳占首屏 ≥46% 屏高，折线内直接可见容器宽滑轨、诊单首句与「一键校准 / 盒尺透视」双键；模块等比不压扁，控件高 ≥42px。
- **844×390 手机横屏**：切为左 56% 活体装配台 × 右 44% 紧凑刊头、诊单与核心刀闸并行，一屏完整可操。

## 7. 练习设计
- **题干**：一个 `600px` 宽的父容器里放一张独立说明卡，要求内边距 `24px`、边框 `4px`，既紧贴容器不横向溢出，又在文字增加时自动长高不遮挡底部块。以下四组写法哪一组最稳妥？
- **四选项（纯中性代码签，逐一暴露单个核心变量）**：
  - A：`width: 100%; box-sizing: content-box; height: auto`（多出 56px 撑破右墙）
  - B：`width: auto; box-sizing: content-box; height: auto`（**正确**：水平七段恒等式自动减去内距边框，净宽 544px、总宽严丝合缝 600px 且随内容自然生长）
  - C：`width: 100%; box-sizing: border-box; height: 120px`（宽虽稳，但定死高度违背可扩展，增字即溢底）
  - D：`display: inline; padding: 24px; border: 4px solid`（失掉块级独立占行，上下内距不推开邻居直接叠盖）
