# 201 方格网格（SQUARE GRID）互动页方案

## 1. 一句话道理
正方形是唯一在横竖两轴等刻度的基本单元：只要所有模块都按 1:1 正方格的整数倍拼接、咬死交点并统一横竖缝隙，版面就能在不重算比例的前提下任意组合、增删，依然保持一眼可见的均衡与秩序。

## 2. 开场玩具
- **名称**：8×8 方格拼装制图台（1:1 化用 201 原海报 8×8 坐标纸、绿色双箭行列尺、右侧「单元 / 模块 / 对齐」活体引线与底部四格图例，支持在「原海报 8×8 / 设计周海报 / 界面卡片」三套题材间实时映射）。
- **怎么玩**：
  - 在 8×8 画布空白格或顶部比例卡尺上**左右横拖**（`data-perf-drag` 标在主画布 `#hero-canvas`）：实时拉伸或压缩整张坐标纸的单元宽高比（`0.60:1`–`1.60:1`），同时标题「方格 网格」右侧的陶土方框同步变形。
  - **拖住任意模块主体**在 8×8 坐标纸内自由落位（靠近整数格交点时轻磁吸，离开磁吸带可故意停在半格脱轨）。
  - **拖住模块右下角橘红角标**拉伸/收缩其跨格尺寸（`1×1` 到 `4×4`），亲手从「满屏 1×1 瓷砖墙」拉出大小有别的节奏层级；点选模块后可用方向键移动、`Shift+方向键`改跨格。
  - 在下方四格鼠尾草绿控条里切换横竖缝隙倍数（`0` / `1/4u` / `1/2u` / `不等缝错态`）与一键压测（瓷砖墙、叠块、复原错态、多组合法解）。
- **开场初始状态（0/4 失序错态，绝非答案）**：
  - 单元宽高比拉扁为 `1.42 : 1`（正圆变扁、标题方框变扁）；
  - 横竖缝隙不等（列缝 `0.36u`、行缝 `0.06u`），导致跨格底边错台；
  - 4 个模块全缩成 `1×1` 或偏堆一侧、其中 2 块半格脱轨且发生模块压叠（0/4 项达标）。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 全部 9 类错态（扁格失真、瘦格失真、横竖缝失衡、缝宽散架、半格脱轨、模块压叠、瓷砖平权、过满窒息/空旷失格、重心倾覆）均由 `model.js` 从实绘模块坐标、单元宽高比、缝隙值单真源实算。
  - 读数直接用白话解释视觉后果（例如：为什么 1.42:1 让双轴刻度失效、为什么满屏 1×1 会退化成没有主次的瓷砖墙、为什么横竖缝不等会让 2×2 块与相邻单格对不齐），并接受任意符合四律的多组正当解（原海报解、设计周海报解、自拼解）。
- **与最近 12 页的不同**：
  - 200 拖垂直分栏轨调非对称 fr 比，199 推描图纸叠两套网格，116 横拖 48 点阵组间距，238 拖固定容器宽测五屏溢出，115 拖混排推镜归类标本；本页把「1:1 正方变形 + 8×8 整格拖拽落位 + 角标跨格合并与缝隙吞吐」做成方格网格专属制图拼装台，其他编号无法套用。

## 3. 版式骨架
- 忠实承袭 201 原海报的「左 34% 鼠尾草灰绿纸栏 × 右 66% 暖素白制图纸主台」双纸面纵向分栏画报骨架（无暗色仪表盘圆角侧栏，不锁 `min-height: 100svh` 避开平板空洞）。
- **1440×900**（主宽 1380px，2560×1440 舒展至 1760px）：左栏鼠尾草灰绿纸放自示范陶土方框大标「方格 网格」、`SQUARE GRID`、总述、原海报 4 枚绿色圆形要点实况章与无重框左杠诊单；右栏暖素白纸放「什么是方格网格？」、题材切签、8×8 活体画布与右侧三引线、底部四格鼠尾草绿微控图例带。
- **1024×1366 & 768×1024**：自然流式转为上下结构，紧凑刊头下直接全宽展开 8×8 制图台，再并排诊单与 2×2 要点章，零空洞。
- **390×844 竖屏**：压紧单行刊头（~80px），等比 8×8 制图台稳占首屏 ≥ 48% 屏高，紧接快控与诊单首句；画布设 `touch-action: pan-y` 保证上下滚动顺畅。
- **844×390 横屏**：切为左 54% 等比 8×8 制图台 × 右 46% 紧凑刊头、切签与诊单并行，零横向溢出。

## 5. 节目录（8 节，标题均 ≤ 12 字，相邻节零重复控件）
- **01 为什么必须是正方** (`Why 1 : 1 square`)：讲清 1:1 双轴同刻度与跨格缝隙公式 `n·u + (n-1)·g`，温和改正原海报小贴士「间距 = n 倍单元」说多了一点之处；交互为「跨格缝隙吞吐解剖器」（步进按钮 + 错算对照）。
- **02 破掉瓷砖墙的节奏** (`Breaking the tile wall`)：讲大小格混拼与留白；交互为「6×6 可点击合并/拆分节奏棋盘」与实时面积层级读数。
- **03 三种真实场景拆解** (`Application examples`，深松林暗室)：1:1 展开原海报三大应用示例（图标网格 / 海报分区 / 界面卡片）；交互为「三联场景切签 + 24×24 光学关键线透视开关」。
- **04 方格网格从哪来** (`Where it came from`)：按 1802 迪朗 → 1964 格斯特纳 → 1967 克鲁威尔 → 1981 米勒-布罗克曼与现代 24dp/CSS 脉络展开；交互为「年代时间轴切换 + 实时 SVG 网格构造图」。
- **05 什么时候别用方格** (`When not to use it`)：4 类反例（长文、宽银幕剧照、悬殊文本卡、先锋破格）并一句链接兄弟页（194/195/196/197/198/199/200/202/209/210/211）；交互为「强裁 1:1 vs 换对网格」对比切换镜。
- **06 写进 CSS 的方格网格** (`Square grid in CSS`)：讲 `aspect-ratio: 1 / 1`、`gap` 与跨格 `span` 对齐原理；交互为「列数/缝隙/跨度范围滑块 + 实时 CSS Grid 盒子与代码」。
- **07 小练习：挑最稳的方格** (`Quick check`)：A/B/C/D 四选一交互卡片，选完揭晓理由。
- **08 原海报与关键词** (`The original poster`)：点击可放大/拖动/Esc 关闭的 201 原海报与 5 枚原海报关键词。

## 7. 练习设计
- **题目**：用 6×6 方格网格排一张《城市建筑展》方形展讯页（主圆图 + 标题日期 + 3 个导览图标），A/B/C/D 配色与文案全同，仅网格与模块落位不同，选出最稳的一版。
- **四选项单一变量区分**（标签仅写 A / B / C / D）：
  - **A**：全齐但网格单元为 `1.32:1` 扁矩形（破坏 1:1 正方前提）。
  - **B**（正确）：严格 `1:1` 正方格 + 统一 `1/4u` 等缝 + `3×3` 主图配 `3×2` 标题与 `1×1` 图标，交点全齐、留白与重心平衡。
  - **C**：严格 `1:1` 与同跨格，但横缝 `1/2u`、竖缝 `1/10u` 不等，导致大块与小块底边错台。
  - **D**：严格 `1:1` 与等缝，但强行把所有模块做成 5 块同大 `2×2` 均等方块，陷入瓷砖平权、主次消失。
