# 243 堆栈 STACK · 互动页方案

## 1. 一句话道理
堆栈（Stack）把相邻模块之间的垂直间距从「每个子元素自己硬编码的 `margin`」收归到「父容器统一掌控的一条规则」，让垂直阅读顺序一目了然、任意增删或调换模块时上下边缘和节奏都不会塌陷或漏边。

## 2. 开场玩具
- **名称**：活体垂直堆栈装调台（Live Stack Assembly & Gap Caliper）
- **怎么玩**：
  - 在深橄榄绿海报主舞台上，还原 243 原海报三张带硬切偏移影的圆角色块卡（暖奶油「头部」、珊瑚粉「内容」、苔藓橄榄「操作区」），可切换「原海报三段 / 注册表单栈 / 文章阅读流」三套真实 UI 题材。
  - **横向直拖 2D 画布「间距与边距透视游标尺」（标 `data-perf-drag`）**，连续调节基准间距 `0px–48px`（同时支持键盘 `← / →` 微调），画布实时绘制纵轴剖面、间距楔块与外边距泄漏/塌陷红色警示纹，并同步驱动下方真实 CSS 堆栈卡。
  - **直接在每张堆栈卡上操作**：点击 `↑ / ↓` 调换模块顺序、点 `×` 删除模块、点 `+ 插入模块` 动态扩容；右侧操作台切换「间距归属（子项乱写 margin / 父容器 `* + *` / 父容器 `flex + gap` / 负边距撞车）」「容器高度（写死裁切 / 自然流 `auto`）」与「末项推底（`margin-block-start: auto`）」。
- **开场初始状态（0 / 4 失序散架态，绝不先给答案）**：
  1. **顺序倒错**：操作区被误放到最顶，头部被压到最底（`操作区 → 内容 → 头部`）；
  2. **间距归属错误**：开启「子项乱写 `margin`」，每块自带不均匀外边距，顶块外边距顶出容器顶边、底块拖出多余死白、相邻处出现外边距塌陷；
  3. **间距过密粘连**：基准间距停在 `4px`，模块撞在一起；
  4. **写死容器高度**：容器被锁死定高并开启 `overflow: hidden`，底块被赤红虚线剪刀线腰斩裁切，无法自由增删。
- **怎样算玩错、读数怎么说「为什么」**：
  - 把间距拉到 `< 10px` → 报「粘连糊墙」，说明相邻卡片与偏移阴影相撞，眼睛失去分组停顿；
  - 把间距拉到 `> 36px` → 报「断链散架」，说明空隙超过模块自身的视觉凝聚力，垂直阅读线被切断；
  - 保留「子项乱写 `margin`」或试错「负边距撞车」→ 报外边距泄漏/塌陷/遮字像素，说明为什么换序或删块会立刻弄乱全列；
  - 保持定高裁切或删到只剩 1 块 → 报裁切像素数或失去相邻关系，解释为何堆栈必须由内容自然撑高；
  - 接受多组合法解：`* + *` 与 `flex + gap` 均算正当，经验参考带 `12px–32px` 内任意数值、任意合法顺序的 `3–5` 个模块都可通关。所有几何坐标、泄漏量、塌陷值、裁切像素、生成 CSS 与诊单全部由 `model.js` 单真源实时算出。
- **与最近 12 页的区别**：
  - 242 是深靛紫三座容器横向拉宽；241 是朱红底三座并排模板与视口示波轨；283 是深炭黑图形软件工作区；200 是纯黑非对称分栏网格；156 是 68:32 燕麦纸/深蓝侧栏裁切；070/069 是透视灭点；117/116 是开放纸面点阵轨迹；033 是砖红 L 形角尺；321/322 是宣纸全景/江河。本页是**真实可增删调序的垂直 UI 模块堆栈 + 纵轴边距 X 光游标尺**，玩法完全绑定堆栈自身的垂直流动作，无法套到其他编号。

## 5. 节目录
- `01` **间距该归父容器管**（`PARENT OWNS THE SPACE`）：拆解原海报三支柱与「易于扩展 = SPACING」；交互为**三步维护实测器（删首块 / 插公告 / 调头尾）**，左右并排对比「子项 margin」与「父容器 Stack」的真实破损差异。
- `02` **用嵌套拉开主次**（`NESTED RHYTHM`）：解释为什么统一间距不等于全页等距，靠外疏内紧的双层堆栈建立层次，并一句链接 244 盒子、245 居中器；交互为**内外双轨嵌套比例调律台 + 2D 节奏标尺画布**。
- `03` **外边距塌陷暗室**（`MARGIN COLLAPSE X-RAY`）：深橄榄暗室里解剖 CSS 块级外边距塌陷、猫头鹰选择器 `* + *`、`flex + gap` 与末项 `margin-block-start: auto` 推底技巧；交互为**四档 CSS 规则切换镜 + 实时盒模型算式解剖图**。
- `04` **堆栈原语从哪来**（`ORIGIN & LINEAGE`）：核实过的 1998–2021 技术演进时间轴（CSS2 → 2014 猫头鹰选择器 → 2015 UIStackView → 2019 Every Layout / SwiftUI VStack / Figma Auto Layout / Braid → 2020 Margin considered harmful → 2021 Safari 14.1 Flexbox gap）；交互为**可点击年代卡片档案夹**。
- `05` **什么时候别用堆栈**（`WHEN NOT TO STACK`）：明确堆栈边界，温和标注原海报等大三卡「说多了一点」，一句话链接同小类 244–254 全部兄弟原语；交互为**四张真实 UI 场景判定翻卡**。
- `06` **挑出稳固的堆栈**（`PRACTICE`）：单变量四选一练习，四张同源迷你卡片只差间距归属与嵌套层级，中性标签 A/B/C/D。
- `07` **原海报与语法拆解**（`ORIGINAL POSTER`）：嵌入 `<img id="poster" src="poster.webp">`（支持灯箱缩放、拖拽、Esc 关闭）+ 原海报原文要点对照 + 页脚。

## 7. 练习设计
- **题目**：三段式通知卡片（已有外框内边距 20px），包含标题、两段说明与底部确认按钮。在后续随时增删段落、不改组件样式的前提下，哪份方案结构最稳固？
- **四选项（仅差「间距归属与嵌套层级」一个变量，中性标签）**：
  - **A（子项外边距 24px）**：每块自带 `margin-bottom: 24px`，按钮底下多出 24px 多余留白，且标题与正文距离等于区块距。
  - **B（外层 24px · 内嵌 8px）**：外层 Stack 控区块 `gap: 24px`，标题与正文再套内层 Stack `gap: 8px`，子项零外边距 → **正确**。
  - **C（单层统一 24px）**：外层 Stack 控 `gap: 24px`，不区分内外层，标题与正文隔得和按钮一样远，视觉归属松散。
  - **D（单层统一 6px）**：外层 Stack 控 `gap: 6px`，虽然上下齐平，但全块贴得过近，信息团成一坨难以扫读。
