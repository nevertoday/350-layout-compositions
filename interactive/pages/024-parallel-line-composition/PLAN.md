# 024 平行线构图 · 设计方案（PLAN）

## 1. 一句话道理
平行线构图不是把画面画满横杠，而是借助格式塔「相似性 + 连续性」让**一组方向齐一的线条**在人脑里自动聚合成平静、延伸的秩序场；真正决定成败的不是线多不多，而是四道分寸：**方向齐一**（差几度就滑向汇聚线）、**线数克制**（过少不成群、过密等宽跌进视觉眩晕）、**间距有呼吸**（机械等距沦为铁栅栏、拉过头则断层）以及**一个破局锚点**（在平行海里定住视线，才不变成空洞墙纸）。

## 2. 开场玩具：活体平行线谱与静景调律台（Parallel Score & Horizon Loom）
- **玩法**：直接化用 024 原海报的「通栏深黑蓝夜境 + 酸绿平行天空线 + 极简灰白建筑/水面倒影」宽幅视觉带，做成可直接在画布上触碰调律的平行线谱台：
  - **画布直拖**：在画布上下拖动直接拉开/收紧「疏密梯度」，左右拖动直接移位「破局锚点」（水岸静屋 / 帆影 / 廊道行人），按住左右边界齐平标把直接扳正「散斜扇角」。
  - **一体化底沿梳轨（`data-perf-drag`）**：紧贴舞台底沿的细线建筑标尺游标，左右滑动即可连续微调「疏密梯度比」，并支持键盘方向键精准步进。
  - **原海报四柱实检与调律**：复刻原海报底部的四竖栏细线分割（`重复 REPETITION`、`间距 SPACING`、`秩序 ORDER`、`韵律 CADENCE`），每栏顶部配有实时联动的动态图形徽标（散斜时秩序徽标真倾斜、改间距时双箭头真伸缩、调韵律时音阶圆点真跳动），下方内嵌本柱对应的轻量控件，并可切换全体朝向（水平 0° / 竖向 90° / 斜向 28°，非单一方向答案）与原海报三套静景题材（水岸静屋 / 帆影海面 / 廊道光门）。
- **开场错态（0/4 翻车态，绝不先给答案）**：
  - 组内散角 `+13.0°`（线条呈扇形汇聚，违背平行秩序）；
  - 线束 `32` 条（高反差细密排布，接近视觉炫光与莫尔刺眼区）；
  - 疏密比 `1.00×`（死板机械等距，防盗窗铁栅栏感）；
  - 破局锚点关闭且无韵律起伏（整幅沦为空洞条纹墙纸）。
- **玩错判定与「为什么」读数（`model.js` 单一真源，全部数值直接从实际绘制的线段数组实算）**：
  - 散角 `|Δθ| > 1.5°`：指出视线正在被扇形斜线拽向消失点，滑入「025 汇聚线构图」而非平行线；靠近 `0°`（`±1.2°` 内）轻磁吸锁直。
  - 线数 `< 9`：指出线条太稀疏、构不成格式塔群组；线数 `> 20`：指出等宽高频条纹触发类似 Wilkins（1984）描述的栅格眩晕与莫尔频闪风险（读数标注为经验带 / 示意频段）。
  - 疏密比 `< 1.25×`：指出「等距铁栅栏」缺乏呼吸；`> 2.45×`：指出「断层脱节」撕裂整体连贯性。
  - 锚点关闭：指出「墙纸效应」让视线顺线滑出画框；锚点贴边（距画框 `< 16%`）：指出视线被边缘截断；缺韵律起伏：提示开启线长/明暗微幅律动。
- **与最近 12 页的明显区别**：
  - 不同于 023 的白绿斜切轨道+单斜角配重、022 的暖米三栏移轴相机、021 的暖纸海平气泡尺、104 的深靛 3×3 九宫格弹射球、227 的钴蓝 CSS Grid 坐标盘；
  - 本页完全源自 024 原海报的「通栏深邃夜蓝板 + 满幅平行线景带 + 四细线竖栏图谱」，玩家调律的是**整组平行线的齐平度、群组密度、间距函数与破局锚点**，任何其他编号都无法照搬。

## 3. 版式骨架
- **1440×900**：不锁 `100svh`（避免平板空洞）。极细 34px 顶眉线 → 紧致双翼海报刊头（左：粗黑示范大标「平行线构图」配随散角联动的双平行酸绿线与 `PARALLEL-LINE COMPOSITION` 副标；右：原海报同款酸绿圆月 + 平行山脊线图腾与题材切签）→ 通栏宽幅 2D Canvas 平行线景带（宽至 1360px，高约 320px）→ 一体底沿间距梳轨（`data-perf-drag`）→ 原海报同款四等分细竖线「重复 / 间距 / 秩序 / 韵律」实时互动柱 → 底部通栏白话诊单条，首屏一气呵成。
- **2560×1440**：版心扩展至 `1840px`，宽幅平行线舞台同步舒展至约 460px 高，两侧无大片空洞。
- **1024×1366 / 768×1024**：自然流式纵排，四柱切为 2×2 细线矩阵，绝无 100svh 空条。
- **390×844（手机竖屏）**：顶眉与刊头压紧至 ~74px，等比平行线画布稳占首屏约 46% 屏高（约 385px，圆月永保正圆不变椭圆），底沿 `data-perf-drag` 梳轨与白话诊单同屏可见，下方四柱以触控友好的 2×2 卡片格（按钮高度 ≥44px）承接。
- **844×390（手机横屏）**：切为左 57% 舞台 + 梳轨、右 43% 精简刊头 + 四灯状态 + 诊断与核心控件并行，零裁切、零横向溢出。

## 4. 配色和字体
- **高保真实采自 024 原海报**：
  - 深夜蓝黑主底 `#060E17`（次深板 `#0B1622`、细线 `#25333E`）
  - 酸绿 / 柠檬橄榄主点缀 `#B4CC3B`（原海报主亮色 `#AEC316` / `#A9C33C`；浅底可读深苔橄榄 `#4A5E08`）
  - 矿物银白大字 `#EEF2F0`、混凝土浅灰 `#B8B8BA`、水面冷青灰 `#323D46` / `#526473`
  - 浅纸正文交替底色：矿物浅石白 `#F2F4F0`、柔和混凝土纸 `#E7EBE6`、净白 `#F7F8F5`（墨字 `#0B151E`），警示纠错克制辅以赤陶橘 `#E05E3E`（浅底 `#B33A1D`）
- **字体搭配（全站唯一，含两款最近 12 页均未用过的新西文字体）**：
  - `Noto Sans SC`（400 / 500 / 700 / 900）：稳重几何黑体中文标题与正文（正文内嵌人名年份同字体，杜绝混排跳动）
  - **`Archivo`**（400 / 600 / 700 / 800，最近 12 页未用）：理性现代主义建筑无衬线，用于英文主副标与大节小标
  - **`Space Mono`**（400 / 700，最近 12 页未用）：清晰水平笔画的几何等宽字，用于角度、线距比、频段与编号标尺

## 5. 节目录（8 节，每节标题 ≤12 字，相邻节绝不复用同一控件）
- **01 平行线为何让人静下来** (*Gestalt Grouping & Direction*)：连续「方向离散度滑尺」把 16 根杂乱短线实时梳平为平行场，验证韦特海默相似性与连续性规律。
- **02 不止横着画：三种平行与越界** (*Horizontal, Vertical & Diagonal*)：矩阵切卡 + 「透视偏折按钮」，区分 024 与 021 水平、022 垂直、023 对角线、025 汇聚线、026 交叉线的边界，并附同小类辨析索引。
- **03 从防盗窗到五线谱：间距韵律** (*From Bars to Musical Cadence*)：深色夜板上的可点按「平行音梳编排器」——切换等距 / 渐疏 / 交替 / 错落模式，并可直接点击每根线条开关强弱音拍。
- **04 原海报三示例与破局锚点** (*Three Motifs & The Focal Break*)：三联「抽层透视开关」（仅看平行线 / 仅看主体 / 完整画面）复刻原海报帆影、三拱建筑与廊道光门，并温和补充原海报 TIP 没说透的疏密与锚点条件。
- **05 平行线构图从哪来** (*Lineage & Optical Weight*)：核实史料时间轴（1857 广重、1923 韦特海默、1926 康定斯基、1958 密斯西格拉姆大厦、1964 莱利、1972 兰德 IBM、1973 马丁）+ 「黑白反色溢光实测开关」亲眼验证保罗·兰德 1972 线宽视觉补偿。
- **06 什么时候别用平行线** (*When Not to Use: Pattern Glare*)：深夜警示板，内置「栅格眩晕与莫尔频闪实验器」（调节密度、对比度、占空比并绘出 Wilkins 1984 视觉压力示意曲线），讲清三种失效场景及替代链接。
- **07 小练习：只差一个变量** (*Single-Variable Blind Test*)：两道单变量盲测（4 个纯中性标签 A/B/C/D 实时渲染小画幅），答后拆解成败原因并可切题重练。
- **08 原海报与核心关键词** (*Original Poster & Keywords*)：原海报完整图（点击放大、拖动平移、Esc 关闭，`draggable="false"`）+ 四大关键词汇总。

## 7. 小练习设计
- **题目 1**：同样是深蓝水岸静屋、同样 0° 水平、同样建筑落位，四版只差「线条数量与疏密分布」这一个变量：
  - `方案 A`：32 条 1:1 机械等距极密线（过密高反差引发栅格炫光与防盗窗压迫感）；
  - `方案 B`：14 条由水面至天际 1.85× 渐疏排布，留出清晰呼吸带（**正确**）；
  - `方案 C`：仅 3 条稀松横线（构不成重复群组节奏）；
  - `方案 D`：上半部堆紧、下半部 4.2× 陡然空断（断层割裂，破坏延展连贯性）。
- **题目 2**：同样是极简廊道平行壁面、同样疏密渐进，四版只差「方向一致性与破局锚点位置」：
  - `方案 A`：线束向右倾斜汇聚 12°（滑成汇聚线，破坏平静秩序）；
  - `方案 B`：删去全部破局人物与光门（沦为无焦点的条纹墙纸）；
  - `方案 C`：剪影人物紧贴画框最右 5% 边缘（视线被边框生硬截断）；
  - `方案 D`：0° 严格平行且人物稳落右侧 70% 呼吸区与酸绿门框呼应（**正确**）。
