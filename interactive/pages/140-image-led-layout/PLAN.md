# 140 图片主导版式（IMAGE-LED LAYOUT）设计方案

## 1. 一句话道理
人脑读图的速度远快于逐字解码，图片主导版式把画面最大份额交给一张强视觉主图，再用果断裁切放大尺度、让文字退入安静负空间并以细引线精准锚定，从而在第一眼建立压倒性的视觉入口与清晰层级。

## 2. 开场玩具：杂志封面裁切与引线排布台（2D Canvas，`data-perf-drag`）
- **玩法**：1:1 承袭 140 原海报「海青→钴蓝→午夜蓝大气渐变场 + 右缘出血深蓝明暗巨球 + 右下冰川斜切面 + 左下朱红锚点 + 四道柠檬黄细引线」，并支持切换 3 组封面题材（`原海报 · 蓝球斜切` / `建筑画报 · 螺旋穹顶` / `工业专刊 · 精密表盘`，均无人物五官）。
  - 在画布空场**横向拖动**（同步驱动 `data-perf-drag`）：连续缩放与破边裁切主图（从胆怯的 `0.44×` 邮票缩图 → `1.0×–1.4×` 破边主图 → `1.82×` 过裁失认）。
  - 直接**拖动冰川斜切刀缝**：改变右下斜切面切入深度（`6%–62%`），现场检验裁切张力与画面切割过度。
  - 直接**拖动画面上三枚注释文字块**（或点「文字退让边缘」）：把原本压在主图亮部的臃肿文案拖回四角安静负空间；黄色引线实时重连各自实景锚点，并在任意两条引线相交时红标打结坐标。
  - 直接**拖动左下朱红圆点**调视觉配重；按 **`Space` 或点「13ms 闪看验真」** 触发一次 1.6 秒快速扫视/失焦预览，展示读者第一眼先撞见主图还是被文字块截胡。
- **开场状态（0/4 四重错态，绝非答案）**：
  1. 主图缩在框内仅占约 **24%**（邮票病，违反「图像优先」）；
  2. 右下斜切退到角落仅 **6%** 且零破边（保守未裁，违反「裁切处理」）；
  3. 臃肿文案块直接压在主图左中亮部，遮挡主体约 **30%+** 且文案占地过大（喧宾夺主，违反「视觉中心」）；
  4. 注释块错序排列导致黄色引线**交叉 2 处**（引线打结，违反「注释引导」）。
- **双向玩错与单真源核算（`model.js`）**：
  所有读数均从画布实绘几何（球体/主体圆与裁切半平面实际像素占比、文字包围盒与主体交集面积、引线线段真实相交判定）单一来源算出，双向检错：
  - 图像优先：主图过小（`< 44%` 邮票缩图）或过满吞噬负空间（`> 86%` 窒息无处落字）均判错；
  - 裁切处理：零破边且斜切 `< 14%`（保守证件照感）或斜切/出框吃掉过多主体核心（剩余可辨轮廓 `< 36%` 过裁失认）均判错；
  - 视觉中心：文案遮挡主体 `> 4%`（文字盖图）或文案占比 `> 24%`（喧宾夺主）均判错；
  - 注释引导：任意引线交叉（`> 0` 处）或标注块互撞/越界均判错。
  - 认可**多组合法解**：`原海报经典解`、`特写大裁解`、`画廊留白解` 以及用户自由拖出的任意 4/4 状态。
- **与近 12 页的差异**：近 12 页分别做安全边距印检(139)、网页三段滚屏(261)、十字双轴排字(220)、双边对轴(175)、电影过肩机位(305)、环形闭合(050)、放射星盘(087)、圣杯伸缩(260)、满出血铡刀(138)、直排立柱(219)、四屏过渡(174)、对比配对(339)。本页聚焦**摄影/主图缩放裁切 + 负空间文字退让 + 动态注释引线防交叉路由 + 13ms 瞬闪眼动验真**，别的编号无法原样套用。

## 3. 版式骨架
- **全幅海青钴蓝斜切展台骨架**（不锁 `100svh`，杜绝平板大空白）：
  - **1440×900（2560×1440 舒展至 1680px）**：顶部紧致单行刊头（自示范 `图片主导版式` 巨标 + 实测图文面积对比条 + 3 题材切签 + 状态徽标）→ 主舞台左 62% 开放大气 4:3 裁切标注画布 × 右 38% 齐底午夜蓝编排工单（单真源白话诊单 + 核心精控 + 多解/试错）→ 底部 4 列原海报原则探针细线带（`图像优先` / `注释引导` / `裁切处理` / `视觉中心`）。
  - **1024×1366 / 768×1024**：自然流排——刊头 → 满宽 4:3 画布 → 齐底双栏诊单与精控 → 2×2 原则条。
  - **390×844 竖屏**：单行压紧刊头（副述后置），近正方画布（`aspect-ratio: 1 / 1.04`，严格等比渲染防压扁）稳占首屏 ≥ 46%，折线内直接露出单句诊断、一键校准与 13ms 闪看按钮。
  - **844×390 横屏**：左 54% 画布 × 右 46% 刊头诊单与主操作并行。

## 4. 配色与字体
- **配色（实采自 140 原海报 `poster.webp`）**：
  - 暗场大气渐变：海青 `#0C9C9B` / `#0091A2` → 钴蓝 `#00337F` → 午夜靛 `#001959` → 深渊蓝黑 `#020B24`（暗室舱 `#06183D`）
  - 亮场冰川斜切纸系：冰川极亮 `#F2F7FB` / 原海报斜切浅冰 `#D5E1EA` / `#E3EEF6` / 饱和天蓝 `#0970C6`（浅底主墨 `#041536`、次墨 `#334E73`）
  - 招牌强调色：注释柠檬黄 `#F8F026`（暗底高对比线/点/标，浅底压 `#041536` 墨字或以深海钴 `#00449E` / 深琥珀 `#755700` 代文字）、焦点朱红 `#E22F16`（浅底文字 `#B51F0B`，暗底亮朱 `#FF6F59`），达标以海碧翠 `#1ED4B5`（浅底 `#006B5E`）。
- **字体搭配（全库 0 重复，与 139/142 非中文零重合，三款西文/等宽在近 12 页全部 0 次使用）**：
  - `Noto Sans SC`（400–900 可变）：中文现代标题与正文（正文段落中人名年份共用同字体不跳动）
  - `Unbounded`（400–800 可变，**近 12 页 0 次**）：宽圆几何西文展标（呼应巨球几何）
  - `Instrument Serif`（400 正/斜，**近 12 页 0 次**）：杂志编辑部衬线副标与引语
  - `DM Mono`（400/500，**近 12 页 0 次**）：注释坐标、裁切比例与实时读数

## 5. 节目录（7 节，相邻节控件绝不重复）
- **01 · 视觉先于阅读**：为什么人眼先吃图像再读字（Shepard 1967 & Potter 2014）；交互：**快门瞬闪实验台**（`13ms / 80ms / 300ms / 常亮` 快门按钮 + 4 档图文比例卡，亲测一瞥识别）。
- **02 · 裁切制造张力**：用破边与斜切把主图撑出画框外的气势；交互：**四刀法对照与斜切角度直拖取景窗**（直接拖拽斜切角或点选 4 种裁法，实时算闭合张力与可辨识轮廓比）。
- **03 · 注释引导视线**：细引线如何做「第三效应」而不是糊在图上的标签贴；交互：**午夜暗室三开关配线盘**（锚点落点 × 线型语法 × 文案职能三组切换开关，直看视线序号重组）。
- **04 · 它从哪来**：从 1934 年 *Harper's Bazaar*、1936 年 *LIFE* 与 1952 年《Words and Pictures》、1959 年 *twen* 到现代认知实验的演进；交互：**时代跨页图谱切换卡**（点选 4 个历史节点，联动切换同期典型杂志跨页结构示意图）。
- **05 · 什么时候别用**：温和修正「永远图像优先」的边界，列出 4 类翻车场景与转投同小类版式建议；交互：**翻车案例诊改翻页卡**（点击切换「硬套图片主导」与「改用对应版式」结构对比）+ 同小类链接路标。
- **06 · 实战判断练习**：两道单变量四选一杂志封面判图题；交互：**A/B/C/D 视觉样张卡片组**（中性编号、同色同字只差一个版式变量，选完逐项解析）。
- **07 · 原海报与关键词**：原海报全尺寸灯箱放大（滚轮缩放、`draggable="false"` 拖拽、`Esc` 关闭）+ 原海报原文要点、关键词与实采六色卡 + 规范页脚。

## 7. 练习设计
- **第一题（建筑摄影展封面）**：A（36% 居中方框图 + 均分大标题，保守安全看似工整） / B（68% 破边斜切主图 + 左上安静负空间紧致标题 + 无交叉双引线，**正解**） / C（92% 过裁切碎穹顶识别轮廓 + 标题挤到亮边，看似前卫实则失认） / D（与 B 相同 66% 破边主图，但仅把文案块放大并压在穹顶高光焦点上，单变量暴露文字盖图）。
- **第二题（工业钟表特刊内页注释）**：四组同构图只改变注释与引线组织——A（两条黄引线跨主表盘交叉打结） / B（取消引线将三段注记堆在底部长栏，割裂图与字对应） / C（文案退守左右安静深蓝负空间，实/虚引线零交叉精准点向表冠与游丝边缘，**正解**） / D（把三枚色底胶囊标签直接贴在表盘正中三处，遮挡核心机芯）。
