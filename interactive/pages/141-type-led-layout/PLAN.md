# 141 文字主导 版式（TYPE-LED LAYOUT.）设计方案

## 1. 一句话道理
当画面没有大图替你抢注意力时，字号阶梯、字重反差、行距呼吸与统一对齐轴就是建筑骨架——它们替读者把一整页文字拆出第一眼、第二眼与停顿节拍，让信息不必靠大喊大叫就能在几秒内被读懂。

## 2. 开场玩具：排印层级声谱台（Type-Led Proof Sheet & Hierarchy Conductor）
- **玩法**：一张 1:1 承袭 141 原海报纯白印刷套准网格的 2D Canvas 活体印刷校样（标 `data-perf-drag`），包含 5 个文字层级（L1 主标、L2 紫括号/双引号导语、L3 真实折行正文、L4 紫角框三要点、L5 红点分隔元信息）与 1 块原海报同款浅灰静音配图占位块；支持三套印刷语境（原海报宣言校样 / 建筑展讯海报 / 学术长文导读）。
  - 在画布上**横拖**连续缩放字阶音阶比（1.00× 平权 → 1.62× 宏阔），**纵拖**调节正文行距（0.95× 撞行 → 2.55× 散架）；
  - 直接**点击画布内任意层级块**查看或单独微调其权重，**点击灰配图块**在喧宾夺主（42%）/ 静音配角（11%）/ 纯文字（0%）间切换；
  - 切换主/正字重差（0 / 300 / 500）与对齐轴（混杂乱轴 / 单轴左齐 / 居中 / 双栏齐）；
  - 按 `Space`（或点「扫读实测」）触发电光紫 + 朱砂红圆点视线演播，按单真源实测视觉权重依次标出 `① → ② → ③` 真实落眼顺序；右侧原海报同款的「紫色阅读节奏波浪线」随实测密度起伏实时变形。
- **开场初始状态（0/4 复合坏态，绝非答案）**：字阶比 `1.06×`（主/正仅 1.19× 平权）、字重差 `0`（全 500）、正文行距 `1.06×`（压死撞行）、对齐混杂乱飘、灰配图膨胀到 `34%`（喧宾夺主）。
- **怎样算玩错 & 单真源读数说什么「为什么」**：`model.js` 从实绘折行布局几何、各层字号/字重、行间空白、起线数、段距/行距比与配图面积比单真源双向检出 9 类错态（配图喧宾、层级平权/倒挂、字重同权、行距撞行、行距散架、对齐乱轴、行宽越界、亲密性错乱、重点过载），每条诊单直接说清「读者的眼睛此刻怎么被卡住或带偏」以及下一步调哪里；认可「原海报瑞士校样解」「纯文字社论长读解」「高反差展讯海报解」等多组合法解，并提供双向试错对照。
- **与最近 12 页及相邻页的差异**：
  - 不同于 `140`（海青蓝球主图裁切与引线）、`142`（单一大标题逐词划删 + 4:5 封面远观）、`176`（浅鼠尾草纸单段栏宽调白色河流）、`221`（旁注字号与注距）、`340`（幻灯片点删冗余块）。141 专攻**五级完整文本系统的层级倍率、行距节拍、对齐锚轴与配图静音退让**，联动实测阅读路径与原海报紫色波浪声谱。

## 3. 版式骨架
- **1440×900（主宽 1360px，2560 舒展至 1620px，绝不锁 `100svh`）**：
  - 顶部 1:1 复刻原海报自示范刊头：左大黑体「文字主导 版式」+ 窄高大写 `TYPE-LED LAYOUT` 配实心红句点 `.`，右侧电光紫瘦高弧括号 `( ... )` 裹住三行导语与语境/演播控件，底下一道 4px 电光紫通栏横杠；
  - 主舞台左 65% 开放白纸套准校样画布 + 紧贴底沿单行操控轨；右 35% 严丝齐底排原海报四枚红圆点+紫线实时探针（层级 / 行距 / 字号 / 阅读节奏 + 活体紫色波浪线）与紫色双引号 `“ ”` 单真源诊单卡（右下角嵌黑色十字套准标）；
  - 底部承接原海报三列紫色直角取景框 `┌ ┘` 要点实时读数卡 + `● CLEAR ● ORGANIZED ● EFFICIENT` 底条。
- **1024×1366 & 768×1024 平板**：自然流排不锁高，满宽画布下方双栏齐底排四探针与诊单，无大块空白。
- **390×844 竖屏**：压紧单行刊头（编号+标题+红点状态），后置紫括号导语与三列紫框卡，等比校样画布稳占首屏 ≥ 48% 屏高，折线内直露字阶横轨、紫色引号诊单首句与一键校准/扫读按钮。
- **844×390 横屏**：左 56% 等比校样画布 × 右 44% 紧凑刊头、单句诊单与字阶/行距双轨并行，零溢出。

## 5. 节目录（7 节，明暗交替，相邻节不复用同控件）
1. **01 为什么文字能自己说话**（柔白纸）：解释前注意视觉对比如何取代大图导引视线；交互为「眯眼失焦透视滤镜」对比平权壁与三阶层级。
2. **02 四把刻刀：号、重、距、轴**（淡紫雾纸）：拆解字号音阶、字重差、中文行距与对齐轴；交互为「四枚独立印刷拨动开关矩阵」，组合开关单刀验效。
3. **03 节奏波峰与留白停顿**（深紫黑暗室）：深化原海报第四关键词「阅读节奏」；交互为「版面节拍编排器（2D Canvas）」，换序与切态观察黑度密度直方图与紫色波浪线。
4. **04 从哪来：百年纯字排印史**（纯白纸）：1928 奇肖尔德 → 1967 鲁德尔 → 1992 布林赫斯特与 W3C 标准；交互为「活字年代抽屉」，点开各时代实排标本；温和校正原海报「让文字自己说话」，并用一句话链接区分 140、142、145、146、149。
5. **05 什么时候用，什么时候别用**（柔白纸）：交互为「6 场景印刷分诊翻牌」+ 过滤，明辨适用与禁区（附 140/142/143/151 链接）。
6. **06 小练习：挑出最清晰的一版**（深紫黑暗室）：A/B/C/D 四份纯中性标注的实排微校样（单变量控制），选后叠显紫色实测标尺解析。
7. **07 原海报与印检**（纯白纸 + 极墨页脚）：`<img id="poster" src="poster.webp" draggable="false">` 灯箱放大平移 + 原海报关键词与印检脚标。

## 7. 小练习设计
- **题目**：为「城市建筑双年展 · 开幕导览单」选择阅读路径最清晰的文字主导排版。
- **选项（仅标 A / B / C / D，内容完全相同，只差单一排印变量）**：
  - **A**：字号/字重/行距均达标，但段距（6px）小于行距且小标紧贴上段（亲密性倒置）。
  - **B（正确）**：30px/900 主标 → 16px/600 导语 → 13px/400 正文，行距 1.65×，段距 > 行距，单轴左齐，视线顺畅。
  - **C**：行距与段距均正确，但字阶收窄至 1.15× 且字重统一 500（层级平权）。
  - **D**：字号、字重与亲密性均正确，但正文行距压死至 1.05×（行间黏连串行）。
