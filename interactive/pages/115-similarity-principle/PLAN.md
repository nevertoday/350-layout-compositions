# 115 · 相似性原则（SIMILARITY PRINCIPLE）互动页面方案

## 1. 一句话道理
人眼处理复杂版面时会先按「颜色、形状、大小」等共同视觉属性把元素自动打包归类；只要组内共性清晰、组间差异明确且互不打架，即使元素在空间上被打散到版面各处，大脑仍能瞬间把同类连成整体。

## 2. 开场玩具：跨位编码分拣盘（活体 24 枚海报标本矩阵）
- **忠实化用 115 原海报**：全宽暖米白圆角标本板（`#F9F0DF`）浮于镉金黄主底（`#FEC412`）之上，内含 24 枚分属 A / B / C 三组真实语义类别的标本图形，底部紧贴原海报招牌的四枚彩色虚线大括号（`圆形组 / 方形组 / 三角形组 / 其他组`）及终端圆点，实时随盘面重算每组人数。支持在「原海报几何 / 地铁导视标 / 界面状态卡」三题材间切换。
- **怎么玩**：
  1. **横向直拖主画布（`data-perf-drag`）**：连续滑动「跨位混排度（`0%` 原海报三列聚拢 ↔ `100%` 全盘交错穿插）」，24 枚标本沿柔和轨迹滑行并实时画出视知觉归类弧线，亲眼验证「无关位置也能归为一组」。
  2. **直点画布上任意一枚叛徒标本**：直接点击掉进红括号「其他组」的孤立错色/错形元素，当场把它修复归队，观察归类弧线与底部大括号人数实时变化。
  3. **操控编码通道与检视**：切换形状编码（杂乱混形 / 同组同形 / 全同圆 / 色形打架）、颜色编码（杂乱花色 / 同组三色 / 全墨单色 / 双组撞色）、大小编码（全等大 / 同组三阶 / 随机杂大）以及「灰度色觉检视 / 归类连线」开关；键盘支持左右键调混排度、`1–3` 键切换题材、Tab+Enter 修复选中叛徒。
- **开场错态（绝非答案）**：开场刻意停在 **0/4 失群错态**——混排度 68% 跨位交错、形状杂乱、颜色花屏且含 5 枚跨组混涂，超过半数元素掉入朱红「其他组 · 不归类」虚线括号，顶部四枚原海报关键词与底部三枚黑圆徽标全亮告警。
- **怎样算玩错（8 类实测错态，全部由 `model.js` 单真源核算）**：
  1. `杂烩失群`：组内纯度不足，大量元素落入「其他组」；
  2. `漏网叛徒`：整体将齐，但仍有 1–4 枚孤立错码标本拖累纯度（可直点画布修复）；
  3. `撞衫混群`：不同语义组共用同一主编码（如两组同绿圆或全黑全圆），组间失去边界；
  4. `色形打架`：颜色按语义分、形状却按正交规则错配，两通道互相拉扯；
  5. `单色失明`：形状与大小全同、只靠三色区分，色觉受限/灰度打印下绿与沙明度逼近导致归类塌陷（WCAG 1.4.1）；
  6. `花屏过载`：叠加过多杂色与随机杂大，视觉样式超出瞬时归类上限；
  7. `尺差干扰`：未对齐语义的随机大小噪声破坏组内统一感；
  8. `借势邻近`：把混排度拖到 `< 25%` 仅靠空间聚拢抱团，未在跨位场景下验证相似性（提醒区分 [116 邻近性原则](https://layout.xiaoxiaodong.ai/116/play/)）。
- **多组正当解**：接受「原海报双维解（绿圆 / 黑方 / 沙三角）」「黑白同形解（全墨黑 · 圆/方/三角）」「色尺双维解（全圆 · 大绿/中黑/小沙）」以及用户自行组合并经跨位验证达标的任意 4/4 解。
- **读数为什么**：所有指标（组内纯度、组间区分、通道协同、跨位凝聚，示意指数明确标「示意」）均由 `model.js` 从 24 枚实绘标本的坐标与属性单真源计算，并用白话说明「人眼为什么在这里看散/看混」以及下一步操作方向。
- **与近期 12 页的差异**：近期 114（青瓷散布推笔）、281（对话气泡）、319（黑底五视点）、153（模块宽度卡尺）、113（深紫 S 丝带）、236（瀑布流砌墙）、067（重叠叠层）、197（暗绿层级墙）、029（暖杏双轴）、280（树形目录）、152（酒红蒙太奇）、318（3D 三远山水）均无全出血镉金海报底、均无「编码属性 × 跨位混排度推镜 × 四大括号实测归类」的玩法。

## 3. 版式骨架
- **1440×900（桌面）**：全出血镉金黄主底（`#FEC412`），不锁 `100svh`。极细 32px 顶眉 → 紧凑镉金刊头（左：自示范「相似性原则」大标、`SIMILARITY PRINCIPLE` 与原海报招牌四栏细竖线关键词实时状态 `归类 | 共性 | 识别 | 凝聚`；右：三题材切签与方案快钮）→ 全宽暖米白圆角标本板（`#F9F0DF`，主宽 1360px；2560 舒展至 1720px），上半为活体 24 枚标本画布与四枚原海报虚线大括号，下半紧接编码开关与单真源白话诊单 → 镉金底带完整复刻原海报下沿（左 46% 中英总述 | 细竖线 | 右 54% 三枚黑圆白图标实况徽）→ 通栏实心黑圆点加右箭头收脚。
- **390×844（手机竖屏）**：压紧单行大标与紧凑四词行，让暖米白标本板及等比无变形 2D Canvas 画布稳占首屏 ≥ 47% 屏高，并同屏呈现四大括号实时人数与白话诊单首句；编码开关与底部三圆徽自然流式下接，零横向溢出。
- **844×390（手机横屏）**：切为左 56% 暖米白标本画布舞台 × 右 44% 紧凑镉金刊头、诊单与快控并排，避免画布被压扁。
- **1024×1366 / 768×1024（平板）**：自然流式排布，不锁 `100svh`，上下节奏饱满零空洞。

## 4. 配色和字体
- **配色（逐像素实采自 `115.webp`）**：
  - 镉金主底 `#FEC412`（深金细线 `#D49D00`），纯黑主墨 `#111111` / `#1D1D1D`（对比度 > 12:1）。
  - 暖米标本板 `#F9F0DF`（浅素米纸 `#FCF8EF` / 暖沙次纸 `#F4ECE0` / 墨黑暗室 `#161715`）。
  - 标志翠绿 `#1B8A59`（米纸深翠可读字 `#146E46`，暗底亮翠 `#4ED89A`）。
  - 标志暖沙 `#E7C897`（米纸深赭可读字 `#7D5718`，暗底暖金 `#FFD038`）。
  - 标志朱红 `#F5491A`（米纸深朱可读字 `#B83210`，暗底亮珊瑚 `#FF8666`）。
- **字体搭配**：`Noto Sans SC`（400/500/700/900）+ **`Sora`**（500/700/800，近期 12 页 0 次使用）+ **`Libre Baskerville`**（400 正斜体，近期 12 页 0 次使用）+ **`DM Mono`**（400/500，近期 12 页 0 次使用）。全库唯一组合，与相邻 114（Space Grotesk + Chivo + Instrument Serif）零西文重合。正文中文段落统一无衬线字体，杜绝行内混排跳动。

## 5. 节目录（7 节，相邻节控件绝不重复）
- **01 · 海报上的三把标尺**（亮米素纸 `#FCF8EF`）：引原海报三要点并温和点破「说满了一点」的跨距前提；交互：**4×6 固定等距棋盘四维编码切盘 + 1 秒闪现/限时找同类扫寻测验**。
- **02 · 色形拔河：谁先抢眼**（暖沙纸 `#F4ECE0`）：解析色、尺、形、朝向的感知强弱与通道打架；交互：**6×6 格式塔行列对抗矩阵 + 双连续滑块（横行色差 / 竖列形尺差）与邻近偏置开关**，实算主导读向（示意）。
- **03 · 暗室验真：单色会失灵**（墨黑暗室 `#161715`）：拆解 WCAG 1.4.1 单色风险与超载花屏；交互：**活体城市线路图与任务看板照妖镜 + 四种色觉/灰度滤镜与编码策略切换**。
- **04 · 从哪来：百年格式塔**（亮米素纸 `#FCF8EF`）：溯源 1923 韦特海默、1935 考夫卡、1954 阿恩海姆、1980 特里斯曼、1998 昆兰与威尔顿、2012 瓦格曼斯；交互：**年代文献时间轴卡片切换 + 同步重绘对应经典视知觉点阵图**。
- **05 · 何时该用，何时别用**（暖米原纸 `#F6EFE2`）：等高双栏对照高频适用场景与四类致命误用，并一句话链接同小类 116–126；交互：**真实活动票务卡「假亲戚排雷」三处热区点击修复**。
- **06 · 小练习：挑出最稳编码**（亮米素纸 `#FCF8EF`）：四选一实战判卷（单变量差异、中性 A/B/C/D 标签、实时 SVG 预览与详尽解析）。
- **07 · 原海报与关键词**（回归镉金主底 `#FEC412`）：完整原海报（点击放大、拖动平移、Esc 关闭）+ 原海报四关键词与三要点 + 同小类延伸导航 + 标准页脚。

## 7. 小练习设计
- **题目**：一张按时间顺序锁死的 3 列 × 4 行活动日程卡片里混排了 12 场内容（不能按类别重排位置），需让读者一眼分清「主旨 / 工作坊 / 圆桌」三类，且兼顾黑白打印与色觉受限读者。哪一套方案最稳？
- **四个单变量选项（中性标签 A/B/C/D）**：
  - `A · 三色同形`：三类全用等大实心圆，只靠翠绿 / 墨黑 / 暖沙区分（缺陷：单维色码在灰度与红绿色弱下明度趋近，违背 WCAG 1.4.1）。
  - `B · 三色三形对齐`：主旨=翠绿圆、工作坊=墨黑方、圆桌=暖沙三角（**正确答案**：颜色负责彩视瞬时归类，形状在黑白与色弱下稳健兜底，双维对齐零打架）。
  - `C · 色分类、形分楼层`：三色标类型、三形同时标 1F/2F/3F 楼层（缺陷：两通道正交打架，扫视日程时需反复做特征联合检索）。
  - `D · 浅沙同色三形`：三类统一涂浅暖沙色，仅靠圆/方/三角加微弱字号差区分（缺陷：去掉强明度与色相通道后，跨 12 格扫寻速度骤降且在白底对比偏弱）。
