# 063 分支构图（BRANCHING COMPOSITION）设计方案

## 1. 一句话道理
分支构图用一个唯一主干确立阅读起点，再借由逐级分叉、同层对齐与体量/形色递减，把复杂的多层级从属关系压成一条无回环、无歧义的单向视觉路径，让眼睛自然从根部流向末端。

## 2. 开场玩具：活体分叉嫁接台（Branching Graft & Hierarchy Bench）
- **原海报同构**：直接在暖宣纸 2D Canvas 上铺开 063 原海报的 16 枚几何节点（1 枚橘红主干圆 `R` → 3 枚深森林绿二级方 → 6 枚珊瑚粉三级圆 → 6 枚深钴藏青末端方）与标志性深墨绿 45° 折转枝干，以及沿树图实时流动的「视线脉动」。
- **怎么玩**：
  1. **直接点击嫁接 / 断连**：画布上点选任意非根节点，再点另一节点把它改挂为子枝（或点「断开成孤岛」「添回环边」），亲手重连树的父子拓扑，也可点「理顺槽位」解开斜穿交叉；支持键盘 Tab / 方向键切换节点与调整。
  2. **横向延伸拉尺（`data-perf-drag`）**：沿画布底沿左右拖动橘红游标，实时拉开或压扁从主干到末端的横向跨度与 45° 折角斜率。
  3. **体量级差切换**：在 `倒挂`、`均等 1.0×`、`缓降 0.78×`、`原海报级差` 间切换，验证根→叶视觉权重递减的作用；可切 `抽象几何 / 咖啡冲煮树 / 设计系统` 三套语义标签。
- **开场状态（0/4 错态，绝不先给答案）**：开场刻意落在四重失序——横向展幅被压到仅 34%、节点体量平权（1.0× 主干失权）、主干扁平爆出过多直枝并夹杂 2 处枝线交叉、还有 1 枚末端节点断线成孤岛。视线脉冲在交叉点与断口受阻。
- **怎样算玩错、读数怎么说**：由 `model.js` 从同一组实绘坐标与拓扑实时核算，可触发并精准诊断七类失误：
  - `成环退化为网络`（形成闭环，越界到 064 网络构图，单向视流失效）
  - `断枝孤岛`（节点从根部不可达，失去归属线索）
  - `枝线交叉缠结`（CCW 实测线段相交，迫使视线中途停顿核对）
  - `扁平爆棚 / 单链退化`（单节点扇出过高变成射线炸开，或退成单串无分叉）
  - `主干失权 / 体量倒挂`（末端与主干同大或更大，视线从右侧倒着看）
  - `层级挤压 / 贴边截断`（横向展幅过窄致同级粘连，或拉满顶框）
  - `跨级直插`（三级/末端越过父层直接挂到更上层，同层纵列失序）
- **读数如何解释「为什么」**：原海报同款圆角黑框诊单不只报数字，还直接说明眼睛会如何被卡住、先修哪一步；四枚原海报底栏几何图腾（主干 / 分叉 / 层级 / 延伸）同步由单真源点亮或示警。
- **与最近 12 页的差异**：062 是黑场散点推波，061 是邻近引力收簇，274 是财务表格调列宽，107 是 9×8 矩阵点格破格，024 是平行线调散角，146 是蒙德里安纸带分格，191 是贝塞尔路径排字，229 是 CSS 多栏报样，273 是 24h 遥测仪表盘，106 是径向清场，312/313 是影视调度。本页是**有向树拓扑嫁接 + 真实边交叉/成环检测 + 45° 枝干延伸标尺**，玩法完全专属于 063。

## 3. 版式骨架
严格承袭 063 原海报的「顶部大标与橘红竖杠总述 → 全宽敞开四级分叉图谱纸 → 黑实线分割的左四图腾竖栏 × 右圆角单线黑框结论盒」结构（不锁 `100svh`，无深色仪表盘卡感）：
- **1440×900（2560×1440 扩宽至 1840px）**：顶部左置带橘红主干圆点与 45° 分叉引导线的示范大标「分支构图 / BRANCHING COMPOSITION」，右置带 6px 橘红粗竖杠的原海报总述；中段通栏 100% 宽度敞开铺开四级活体树图纸与底沿一体化「四色图例 + 横向延伸拉尺」；底部一条 2px 黑实横线分开，左 56% 排原海报同款四竖栏关键词实时图腾，右 44% 排原海报同款 18px 圆角单线黑框诊单与精简操控条。
- **1024×1366 / 768×1024 平板**：自然收紧高度，不留 100svh 空洞；768 下底部四图腾与圆角诊单上下叠排。
- **390×844 手机竖屏**：极薄顶眉 + 单行压紧标题与 `0/4` 徽标；首屏主体直接铺开等比 2D Canvas 活体树舞台 + 48px 横向延伸拉尺 + 精简模式钮（占首屏 ≥ 48% 屏高），紧接下方同屏露出圆角黑框诊单首行；总述移至玩具后。
- **844×390 手机横屏**：切为左 58%（紧凑顶标 + 树画布 + 延伸拉尺）× 右 42%（圆角黑框诊单 + 四图腾状态条 + 操控钮）并行，首屏完整可见不裁切。

## 5. 节目录（8 节，h2 ≤ 12 字，相邻不撞控件）
1. **01 一条主干，四重编码**（浅沙纸）：解构原海报「层级分明」——四通道视觉变量剥离开关（位置对齐 / 体量递减 / 方圆交替 / 四色区隔），直观体验逐层撤去编码后的解码退化。
2. **02 宽度与深度的拉锯**（暖宣纸）：解构「逐级分叉」并温和补全边界——4 张分叉拓扑卡片（1×12 扁平炸开 / 6×2 宽冠 / 3×2×2 均衡四级 / 2×2×3 窄深高枝），实时重构 12 个末端节点。
3. **03 枝干如何领着眼睛走**（深森林墨绿暗版）：解构「视线从主干向外延伸」——枝干几何（45° 折线 / 柔和曲线 / 直角阶梯 / 直线放射）× 生长方向（左→右 / 上→下 / 径向）2D Canvas 活体视流剧场。
4. **04 同小类里的位置**（微绿雾纸）：一句话厘清 057 / 058 / 059 / 060 / 061 / 062 / 064 各自边界并链接在线版；互动「添一根线变网络」演示 063 树与 064 网的一线之隔。
5. **05 从哪来**（暖宣纸）：四时代视觉史交互年表（波菲利《导论》c.270 → 达尔文 B 笔记本 1837 → 亨利·贝克伦敦地铁 45° 线路图 1931/1933 → Reingold–Tilford 1981 & Manuel Lima 2014），附精绘时代结构微图。
6. **06 什么时候用，什么时候别用**（浅靛蓝雾纸）：引用原海报应用建议 + 四类真实需求分诊卡（点选任务看「硬套分支」vs「顺应关系」微图对照），重点讲透多对多、平等无主、窄屏长文、单链流程四类禁用边界。
7. **07 挑一张最好读的分支图**（暖宣纸）：单变量控制四选一练习（方案 A/B/C/D 节点数与色板全同，各只改一个变量：同层错位 vs 规范解 vs 体量倒挂 vs 跨支交叉），即时判题拆解。
8. **08 原海报与关键词**（浅沙纸）：可放大拖动原海报灯箱 + 原海报四关键词矢量图腾 + 标准页脚。

## 7. 小练习设计
- **题干**：为 16 节点四级音频 App 功能导览选出最易读的横版分支图。
- **选项（只写方案 A/B/C/D，节点数、颜色与画幅完全一致，仅差一个结构变量）**：
  - **方案 A**：仅破坏「同层纵列对齐」——三级与末端交错错位。
  - **方案 B（正确）**：唯一主干居左、体量递减、零交叉 45° 折枝、四级纵列严整对齐。
  - **方案 C**：仅破坏「主干体量递减」——主干缩小而末端藏青方反而最大，造成倒序阅读。
  - **方案 D**：仅破坏「无边交叉」——中下两路三级枝跨槽斜穿打结，视线被迫中途回折。
