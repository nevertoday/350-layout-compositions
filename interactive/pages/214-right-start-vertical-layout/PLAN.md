# 214 直排右起（RIGHT-START VERTICAL LAYOUT）设计方案

## 1. 一句话道理
汉字天生是等宽方块，自上而下成列能稳住纵向视觉惯性，从最右列起读再向左推移，则把千年简牍与典籍的翻阅秩序转化为当代海报与书封的仪式感与层次节奏。

## 2. 开场玩具：「活字理列台 · Vertical Slip Loom」
- **怎么玩**：
  - 直接在 2D Canvas（标 `data-perf-drag`）上**左右拖动任意竖排字列**（像整理竹简或活字列条一样），把题签与正文列按「由右向左」重新排顺；拖动跨过邻列时实时换序，在空白列缝左右拖则连续微调列间距。
  - **上下拖动列底标尺**（或用单列字数微调）改变每列字数（6–22 字/列），画布按真实汉字实时重排分列。
  - 切换三套真实标本：**原海报·王维《山居秋暝》**、**展讯·秋山茶器展**、**书封·林泉清赏序**。
  - 切换天头对齐（齐天头 / 参差 / 居中悬空）、标点制式（直排右上标点 / 横排左下硬塞）、读序参考线，并可一键回放**粉金视线流动画**（沿每列自上而下流动，到底后向左上方回跳至下一列天头）。
  - 键盘支持：`←` `→` 移动当前选中竖列、`Tab` / 数字 `1–5` 切列、`↑` `↓` 调列距、`Space` 演练视线流。
- **开场状态（绝非答案）**：
  - 一打开停在 **0/4 复合错态**：① 题签「● 山居秋暝 王维」被错放最左端、诗句次序倒乱；② 四列天头高低参差（0 / +34 / +18 / +46 px）；③ 列间距紧挤到 `1.22×` 字宽（列缝仅 `0.22×`），邻列几乎粘连；④ 标点停在横排左下角，勾住左邻列。
- **怎样算玩错、读数怎么说**：
  - `model.js` 从画布实绘的列边界框、左右列序、天头高度极差、列缝/字宽比、每列字数与标点制式**单真源核算 8 类双向错态**：题签未坐最右、列序颠倒/左起、天头参差、竖列居中悬空、列缝挤粘串行（<0.45×）、列缝过散断气（>1.65×）、单列过碎（<6字）或过长（>24字）、横排标点错位。
  - 每一处报错都用白话讲清「眼睛会怎样迷路」（例如“最右列被第三联抢占，眼睛从右边落笔直接撞上中间句”），并接受多组合法解（经典古籍疏朗解、现代海报紧致解、展讯宽幅解），绝不要求唯一参数。
- **与最近 12 页的差异**：
  - 213 是樱粉横幅横向推拉焦点/波点；212 是钴蓝横行左齐回扫；254 是柿红 2×3 图标文字矩阵；332 是深松绿四圆镜 S 丝带；298 是松绿立体折页；168 是暖米建筑中轴；131 是黑底星图。本页是唯一一个**把中文竖列本身做成可物理左右抽换排序的竹简理列画布**，别人完全无法套用。

## 3. 版式骨架
- **忠实转译 214 原海报的「右重左轻三段式夜墨竖卷」**（绝不锁 `min-height: 100svh`，杜绝平板空洞）：
  - **1440×900（主宽 1380px）/ 2560×1440（舒展至 1680px）**：
    - **右柱（21%）**：1:1 复刻原海报最右侧竖落刊头——极右竖排总述「以右为始，秩序自成。」+ 粉圆点、巨幅竖排宋体大标「直排右起」（自示范 `writing-mode: vertical-rl`）、`RIGHT-START VERTICAL LAYOUT`、副题「传统与设计的现代表达」与右下角紫粉渐变圆月+同心细环+点阵。
    - **中主区（57%）**：顶部 1:1 复刻原海报 `四 ← 三 ← 二 ← 一` 粉圆实况序带 → 中间圆角细框「示例 EXAMPLE」活字理列画布 → 紧凑单行理列微调带。
    - **左栏（22%）**：细竖线分隔，1:1 复刻原海报「核心原则 KEY PRINCIPLES」5 枚几何图标实况灯 + 单真源白话诊单卡。
    - **底沿通栏**：粉细线下 1:1 复刻原海报「设计小贴士 TIPS」灯泡粉圆 + 四栏竖线隔开的实用建议与快捷解法对照。
  - **1024×1366 / 768×1024（竖屏平板）**：
    - 顶部收紧为横向刊头（保留圆月徽饰），下方全宽活字理列画布，其下等高双栏并排（左诊单、右控台与五原则灯），底沿四栏小贴士，齐底零空洞。
  - **390×844（手机竖屏）**：
    - 单行紧凑刊头（`NO. 214` + `直排右起` + 状态签，总述后移），让等比活字画布稳占首屏 ≥46% 高度，画布正下方在首屏内直接露出白话诊单首句与主操作按钮。
  - **844×390（手机横屏）**：
    - 左 56% 活字理列画布 × 右 44% 紧凑刊头、标本切换与实时诊单并行，一屏完整可操作。

## 4. 配色与字体
- **实采自 214 原海报的「夜墨靛紫 × 樱兰粉 × 紫粉渐变月 × 暖宣象牙」色系**：
  - 夜墨深靛底（Hero / 03 暗室 / 07 展墙）：`#0C0533` / 暗舱 `#150C44` / 极夜页脚 `#080324`
  - 樱兰粉点缀（圆徽、副标、高亮）：`#EF87AA` / 暗底亮粉 `#F59AB8` / 浅纸高对比深梅红 `#9E1F53`
  - 紫粉渐变圆月：`#E16CB6` → `#A64795` → `#6D2A7D`；细界栏线 `#6E4B82`
  - 暖宣象牙字与浅读纸系：暖宣白字 `#EFE5DA`；正文浅底在月白宣纸 `#F9F5F0`、兰雾浅纸 `#F2ECF6`、淡梅宣纸 `#EFE8F4` 间交替，配深靛主墨 `#130A3A` 与次墨 `#473D68`。
  - 语义反馈（克制）：翡翠绿（暗 `#76E2C0` / 浅 `#0E6B52`）标秩序成立；珊瑚赤（暗 `#FF867B` / 浅 `#B42336`）标错序串行。
- **全库唯一五字搭配（与 212、213 零重合，且三款在近 12 页 0 次使用）**：
  - `Noto Serif SC`（400 / 600 / 900）：巨幅竖排宋体大标与中文正文（段落内西文与年份同用，杜绝跳动）。
  - `LXGW WenKai`（400 / 500，**近 12 页 0 次**）：古典诗词、简牍标本与书卷引文。
  - `Chivo`（400 / 600 / 700，**近 12 页 0 次**）：海报同款利落英文小标与界面标签。
  - `Instrument Serif`（400 正斜体，**近 12 页 0 次**）：章节英文副题与出版注记。
  - `JetBrains Mono`（400 / 500，212/213 均未用）：列距比值与实时 CSS 代码读数。

## 5. 节目录（7 节，标题均 ≤12 字，相邻控件完全不同）
- **01 为什么先看右边**（Why Right Comes First）：展开海报前两条原则，温和校准「自然流畅」一说（引 Sun, Morita & Stark 1985 眼动研究）。交互：**双卷眼动扫视同步对比仪**（选三段文本，同屏对比直排右起、横排左起、直排左起的视线节拍）。
- **02 十六字列的呼吸尺**（Column Cadence & Whitespace）：展开海报后两条原则与「15–22 字/列（经验值）」。交互：**真 CSS `writing-mode: vertical-rl` 活体线装跨页 + 二维「列高×列距」XY 调版垫**（实时切换直排标点 `vert` 并输出可用 CSS）。
- **03 从竹简到浏览器**（From Bamboo Slips to CSS，夜墨暗室）：简牍→雕版→1955/1956 报刊改横→2004/2005 台湾公文改横与日台出版→2019 W3C `vertical-rl`。交互：**五时代卷轴步进器 × 可视器物变形台**。
- **04 什么时候用、别用**（When to Use & Avoid）：正面适用边界 + 明确反例禁区，一句话链接同小类 212/213/215/216/217/218/219/220/221。交互：**六类真实文案直排压力测试卡**（把诗歌、展签、URL 日志、价目表等真实塞进直排，一眼见好坏与替代方案）。
- **05 盲测：哪张才对**（Spot the True Order）：四选一小练习。交互：**A/B/C/D 四张微型直排请柬盲测**（两道独立单变量考题，选后在图上叠加红绿诊断标尺说明原因）。
- **06 四条贴士与海报细读**（Design Tips & Notes）：逐条实演原海报四条小贴士，并温和指出原海报左栏「右起排」箭头画反成 `→` 及末句字形细节。交互：**四层海报贴士实体开关校样台**。
- **07 原海报与关键词**（The Original Poster，夜墨展墙）：可放大/拖动/Esc 关闭的原海报灯箱 + 海报五个关键词原版几何图标。

## 7. 练习设计
- **第 1 题（秋山陶艺展请柬）**：四张微型请柬文案、字号、页边距完全相同，标签仅为中性的 `方案 A` / `方案 B` / `方案 C` / `方案 D`，各错项与正解 C 只差**一个变量**：
  - A：仅把列序反成从左向右（直排左起，题签掉到最左）；
  - B：仅把对齐改为上下居中（天头高低参差，换列回扫丢靶点）；
  - C（正解）：题签坐镇最右、自右向左推进、天头齐平、列缝约 0.85× 字宽；
  - D：仅把列间距压扁到 0.22× 字宽（邻列贴粘、纵扫串行）。
- **第 2 题（书封节选校样）**：同样四个中性方案只差一个变量（正解 vs 横排左下标点未转 / 单列 28 字过长 / 题签同号无层级），深化直排细节判断。
