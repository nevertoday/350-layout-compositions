# 033 L形构图（L-SHAPED COMPOSITION）设计方案

## 1. 一句话道理
L 形构图用左侧（或一侧）竖向实体钉住视觉入口，再用底部横向延伸兜住画面重力并把视线向右送出，从而在右上角腾出一整片高对比留白区，以「左重下稳、右上远悬小焦」的杆秤平衡，同时做到结构稳固与视线定向。

## 2. 开场玩具：「活体 L 形角尺构筑台」
- **核心动作（贴合 L 形自身物理动作，别的编号套不走）**：
  - 2D Canvas 1:1 化用 033 原海报的宣纸底（`#FAF7ED`）、朱褐红 L 形实心柱与底梁（`#A53625`）、灰橄榄孤焦方块（`#6E6944` + 暖沙圆晕 `#ECE4D2` + 虚线圆环）及双垂/横虚线导轨，并支持在**原海报角尺 / 山水孤松（马远风） / 静物书瓶**三套题材以及**左 L ∟ / 右反 L ⌋**方向间切换。
  - **直拖 1（`data-perf-drag` 绑在主画布）**：直接拖动 L 形内侧的**「直角拐肘把手」**，横向拉拽改变竖柱占宽（10%–52%）、纵向拉拽改变底梁厚度（8%–44%）；也可拖动底梁右端箭尖直接拉长/缩短水平延展跨度（32%–100%）。
  - **直操 2**：在右上开放留白区直接拖动**「灰橄榄视觉焦点」**，体会杆秤力矩与边界呼吸感；点击红虚框标出的**「拐角断口」**一键弥合 90° 转角，点击右上留白里的**「冗余杂块」**清出净空呼吸区。
  - **键盘**：画布可聚焦，`← / →` 调竖柱宽、`↑ / ↓` 调底梁厚、`[` / `]` 调底梁延展、`Space` 切换断口或清杂。
- **开场初始态（绝不先给答案）**：刻意停在 **0/4 失构翻车态**——左竖柱过肥占宽 47%（挤闷右上）、底梁裂开 8% 断缝且在 42% 处腰斩失延、右上留白塞进 2 块抢戏杂物（净空仅 24%）、灰橄榄焦点掉在左柱脚下 `(0.50, 0.72)` 贴实块失衡。
- **怎样算玩错 & 读数怎么说为什么**：全部 8 类失误（柱薄失锚、柱肥闷死、底断分家、底短失延、底厚压扁、空区堵死、焦陷实块或贴边跌出、杆秤失衡）全部由 `model.js` 从实绘几何坐标、面积占比、净空率与示意杆秤力矩单真源实算；白话诊单直接嵌在画面下沿的砖红横臂内，讲清「这样摆为什么让眼睛滑脱或憋闷」以及「下一步怎么修」，且接受原海报经典解、南宋大留白解、重柱海报解与右反 L 解等多组合法答案。
- **和最近 12 页的明显区别**：
  - 不同于 032（深海蓝对称三栏 T 门户 + 顶部横梁居中下坠）、不同于 031（左右对称双楔剪刀开合）、不同于 154（顶橙色块 + 左账本右黑框）、不同于 155（左 41% 浅纸右 59% 藏青夹页）、不同于 238（居中浏览框 + 双侧标尺）：033 的开场本身就是一只**真正围住右侧宣纸画布的巨型砖红 L 建筑角尺**，画布零黑框、直接长在温润宣纸上，且玩的是**直角折角、边宽柱厚、底延展与右上留白杆秤配重**。

## 3. 版式骨架
- **1440×900 / 2560×1440**：极轻 30px 宣纸顶眉之下，主容器宽 1380px（2560 舒展至 1720px），直接忠实转译原海报结构——左侧实心朱褐红竖柱（宽 216px，嵌随画布实算联动的顶天立地大白 `L`、竖排「形构图」与底部「构图原理」四项实时通断灯）无缝直角焊接到底部通栏砖红横臂（内嵌随底梁延展长度联动的白色长箭与单真源白话诊单）；巨 L 内湾右上展开清爽宣纸刊头行（「左强右空 · 下稳上扬」+ 三题材切签）与满幅 2D Canvas 角尺画布；红横臂下方 1:1 承接原海报四栏细垂直虚线脚座（红门框/橄榄箭/炭黑方/红三角四徽 + 四维滑杆微调），底沿细线收「核心作用 →」。不锁 `100svh`，平板（1024×1366 / 768×1024）零空洞。
- **390×844（手机竖屏）**：左侧红柱收成极紧单行砖红刊头（大白 `L` 徽 + `L形构图` + `0/4` 状态丸），下接一行题材与快修胶囊，紧接着等比 4:3.3 宣纸角尺舞台稳占首屏 ≥47% 屏高，紧贴画布下方直接露出砖红横臂诊单首句与关键微调条，圆与方严格等比零压扁。
- **844×390（手机横屏）**：切为左 54% 宣纸 L 舞台（含左缘红柱饰条）× 右 46% 精简刊头、砖红诊单与核心滑杆并行排布，零溢出。

## 5. 节目录（每节 h2 ≤ 12 字，相邻两节交互零重复）
- **01｜一条拐角，兜住视线**（`Anatomy of the L`）：引用原海报四要点并温和补充「左强右空」的阅读流前提；交互＝四步视线步进卡联动 SVG 力学剖面图。
- **02｜一杆秤与一片留白**（`Steelyard Balance`）：用 Poore 杆秤与 Arnheim 重力场讲清左下重实体如何与右上轻焦达成平衡，并链接 031/032；交互＝2D Canvas 活体视觉杠杆秤（直拖右侧焦块调力臂与体量看倾角与平衡档位）。
- **03｜四个方向的 L 怎么选**（`Four Orientations`，深赤暗室）：对比 `∟` / `⌋` / `⌜` / `⌝` 四种转向的稳定感与压迫感；交互＝90° 旋转方位盘 + 实景取景重构演示。
- **04｜它从哪来**（`Lineage & Sources`）：梳理南宋马远、歌川广重、惠斯勒、Dow、Poore、Payne 与 Arnheim 的可核实脉络；交互＝4 幅历史构图示意缩图 + 「结构透视滑块」渐显隐藏 L 骨架。
- **05｜四个真实场景怎么落地**（`Real-World Applications`）：展开原海报「核心作用」四条在海报、摄影、网页首屏、商品主图中的隐形用法，并链接 034/035/037；交互＝四场景模拟成品切换 + 「骨架透视开关」。
- **06｜什么时候别用 L 形**（`When Not to Use`）：拆解对称仪式、多主平权、窄竖流与连绵曲线（链接 036/038/039/040）四个反例；交互＝「强套 L 形 vs 换对骨架」三题材对照切换台。
- **07｜练一练：四张草图选哪张**（`Practice · Spot the L`）：同场景四张只差单一变量的练习选择 + 选后透视骨架与实测复盘。
- **08｜原海报与关键词**（`The Original Poster`）：原海报可放大拖拽灯箱 + 关键词与四项核心作用回望。

## 7. 练习设计
- **题目**：同一幅「海岸灯塔与防波堤」构图草图，只标 **A / B / C / D**（不剧透好坏），四个选项各差一个单一结构变量：
  - **A**：左灯塔过肥（占宽 46%）挤压右上天空，留白失呼吸；
  - **B（正确答案）**：左灯塔占宽 24% 立住边界、防波堤沿底延展 84% 托稳并向右引出、右上宽广净空中远帆落在杆秤平衡位；
  - **C**：竖柱与留白都正常，但底防波堤在 44% 处半途截断，失去横向延展；
  - **D**：竖柱与底防波堤都正常，但右上留白被大片乱云杂礁塞满，留白对比与远帆焦点被吞没。
