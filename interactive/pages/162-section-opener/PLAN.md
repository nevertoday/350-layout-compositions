# 162 栏目 开启页（SECTION OPENER）制作方案

## 1. 一句话道理
栏目开启页是大型多板块出版物里的「换挡路标」：用明确的书口出血色带、拉开阶梯的标题层级、克制的子目导览与指向翻页方向的单一视觉锚点，把读者从上一栏目的阅读惯性中干净切出，并顺势推入新板块正文。它不等于单本刊物的封面（160），也不等于书籍长叙事里静默降灰起笔的章节扉页（161），更不能堆成全刊总目录（164）。

## 2. 开场玩具：切口导流 · 活体栏目开启页排版台
- **玩法**：纯 2D Canvas 活体跨栏切面台（`data-perf-drag`），左缘露出上一栏冷灰尾页作隔离参照，主体为正在编排的本栏目开启页（1:1 化用原海报暖米纸、朱红构成主义方向箭头与右缘半圆弧豁口），最右侧带真实立体「书口阶梯出血切口」（可点击切换 `01 空间与尺度` / `02 建造与构造` / `03 纸上档案`，实时观察多栏目切口沿书口逐栏下移，并透过半圆豁口预览下页正文栏格）。
  - 在画布上**左右横拖朱红导流箭头**，实时调节视觉动势的朝向与贯通长度（从反指左页 ← 到直刺右豁口 ⟶），同时带动实时视线扫描光点与刊头微型活体箭徽；
  - 直接点击画布上标红的**干扰角标**或**过载密排子目块**就地清理，或点击右侧书口阶梯切换栏目；
  - 通过画布底沿单行直控调校：标题字号反差（1.1×–6.0×）、书口出血带（关 / 弱灰 / 朱红出血）、子目负载（8 篇伪目录 / 3 篇精炼路标 / 0 篇空壳），并在「建筑季刊 / 气候年报 / 器物画册」三题材间切换。
- **开场初始态（绝非答案）**：刻意停在 `0/3 失导错态`——箭头反指左页（-35° 拉回上一栏）且长度缩死；标题字号比仅 `1.18×` 与 8 篇全文密排摘要混成伪目录平灰一片；右侧书口出血切口关闭（0mm）；一枚高饱和促销角标与标题抢夺视觉第一落点（双焦冲突）。
- **怎样算玩错 & 读数如何说「为什么」**：由 `model.js` 从画布实绘几何矩形、箭头矢量、留白占比与字号比**单真源**计算，支持双向玩错——不仅能测出「反指回流」「目录化过载」「标题平灰」「书口隐身」「双焦冲突」，还能测出「标题 5.6×+ 撑爆版心」「0 子目无导语空壳失导」「箭头停滞居中零方向感」等 8 类真实错态，并实时说明读者视线为什么会被拽走或堵死；同时接受「构成箭解 / 瑞士大字解 / 色块切口解」多组合法解。
- **与最近 12 页的明显差异**：
  - 不同于 **161 章节扉页**（摊开双页书本卷页看灰度落差与天头沉降）：162 聚焦**多板块书口出血切口 + 向右导流方向箭 + 子目层级负载**，单页带右缘切口透窗；
  - 不同于 **160 封面版式**（黑绒三栏 + 2.5 米书店远距缩略镜）；
  - 不同于 **289 Hero**（网页折线与盲闪）、**122 简化**（左右双室大脑简译）、**205 嵌套网格**（双层蓝图分界脊）、**247 侧栏**（左侧固定松青侧栏）、**326 留白**（左墙签右白墙减法）。

## 3. 版式骨架
- 忠实转译 162 原海报「**左 74% 暖米构成主义大页 × 右 26% 通高朱红出血书口带（腰部切出巨幅半圆弧暖米白豁口）**」非对称出版结构，**0px 锐利切角**（仅半圆豁口与原海报圆符用纯几何圆），**绝不锁 `min-height: 100svh`** 避平板空洞：
  - **1440×900**（主宽 1380px，**2560×1440** 舒展至 1720px）：左 74% 暖米原纸承托单行眉标、粗黑自示范大标「栏目／开启页」（旁嵌活体朱红箭徽）与题材切签 → 全宽 2D 活体跨栏排版画布 → 单行直控带；右 26% 实底朱红书口带承托原海报三枚几何符号（● / ☰ / ◎）实况灯，下部半圆弧暖纸豁口自然过渡到单真源白话诊单与实测读数卡，左右齐收于首屏。
  - **1024×1366 / 768×1024 平板**：自然折排为全宽暖纸刊头 + 全宽活体画布 + 底部朱红三尺与诊单并列双栏，零纵向空洞。
  - **390×844 手机竖屏**：极紧凑单行眉标与主标，原海报总述后置，等比画布稳占首屏 ≥ 48% 高度，下方直见朱红诊单首句与关键纠错按钮。
  - **844×390 手机横屏**：左 56% 活体画布 × 右 44% 紧凑刊头 + 诊单与核心按钮并行，不压扁圆弧与画布。

## 4. 配色和字体
- **逐像素实采自 162 原海报**：
  - 暖米原纸 `#EFE4D1` / 亮读象牙纸 `#F7F1E5` / 暖砂浅纸 `#E7DAC4`
  - 构成主义朱红（色块/箭头/书口带）`#D63D1E` / 深朱红实底（保小字对比度 ≥ 5.5:1）`#BA3115` / 浅纸安全窑朱红文字 `#A52910` / 暗底亮朱红 `#F57256`
  - 厚重墨黑主字 `#121311` / 次墨 `#46433D` / 暗室深炭墨 `#171614` / 暗舱 `#22201D`
  - 克制辅助：成立松翠 `#156347`（暗底 `#6EE0B2`），警示深赤 `#9B1C16`（暗底 `#FF8A7A`），上栏冷灰 `#6A6F6D`
- **全库唯一字体组合**（近 12 页三款西文/等宽字体全部 0 次使用，且与 160 / 161 / 159 零西文重合）：
  - `Noto Sans SC`（400, 700, 900）— 原海报厚重粗黑标题与清晰正文
  - `Syne`（700, 800）— 构成主义前卫宽体英文展示标（近 12 页 0 次）
  - `Chivo`（400, 700）— 利落出版无衬线英文标签（近 12 页 0 次）
  - `Space Mono`（400, 700）— 书口页码、字号阶梯比与单真源读数（近 12 页 0 次）

## 5. 节目录（8 节，相邻节控件绝不重复）
- **01｜海报里的三把尺**（亮象牙纸）：引原海报三要点并厘清 160/161/164 边界；交互：**原海报三符号（●/☰/◎）单层 X 光透视切层图**。
- **02｜从书口切口到现代期刊**（暖米原纸）：1923 利西茨基 → 1959 弗莱克豪斯 → 1971 赫尔伯特 → 1974/1976 扬·V·怀特 → 1981 米勒-布罗克曼；交互：**年代标本轴切换动态 SVG 版式骨架**。
- **03｜书口色带：翻书盲找实验**（深炭黑暗室）：物理翻页切口定位机制；交互：**128 页厚刊书口「拇指速翻滑槽」实时翻页与切口方案对照**。
- **04｜方向与锚点：视线怎么滑**（亮象牙纸）：拆解原海报右指箭头与隐形导流力，温和纠偏「真画大箭头」误区；交互：**四向构图单选 + 2D 视线流束动势模拟**。
- **05｜四种刊物，四种开启页骨架**（暖砂浅纸）：杂志/年报/画册/设计规范的差异，并串链 163/165/166/167；交互：**四刊型双页比例蓝图与参数对照表**。
- **06｜什么时候别用栏目开启页**（深墨暗室）：四类反场景与经验边界；交互：**四条件出版决策诊断开关组**（实时输出整页/半页条/省去结论）。
- **07｜练一练：哪一版立得住？**（亮象牙纸）：四选一实战判图练习；交互：**四组纯中性编号（方案 A–D）微型开启页样张点选与逐项解析**。
- **08｜原海报与三枚符号**（暖米原纸 + 右朱红柱展墙）：原海报高清灯箱（放大/拖拽/Esc）与海报三符号、总述及波浪线原味呈现。

## 7. 练习设计
- 题目：120 页建筑季刊的「03 构造与材料」栏目含 4 篇文章，四稿共享同一纸张、同一字数与同一书口色带，仅差一个结构维度——选出能立刻建立频道切换与阅读方向的稿件。
- 选项纯中性标签（方案 A / 方案 B / 方案 C / 方案 D）：
  - A：主标仅 1.2× 且铺满 4 篇全文提要（错：层级塌陷 + 塞成目录）
  - B：主标 3.4×，但视觉楔块与导引线朝左指回上一栏（错：方向反推）
  - C：主标 3.4× + 精炼导语 + 3 条带页码路标 + 右缘半圆豁口向右导流（**正确**）
  - D：主标 3.4×，但中段左右两张等大高饱和块互抢焦点且无子目导览（错：双焦冲突 + 缺少导览）
