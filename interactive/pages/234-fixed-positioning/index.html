1. 什么是固定定位？

使用 CSS 的 position: fixed; 可将元素钉在视口中，页面滚动时它仍停在原处。

正文卡 · z-index: 20 滚过顶栏时，低层级导航会被我反压！

2. 基本用法

.element {
  position: fixed;
  top: 60px; right: 20px;
  z-index: 1000;
}
  • 相对于视口定位
  • 不占据文档流空间
  • 四边偏移 + z-index

OUT OF FLOW & VIEWPORT LOCK

        

      


      

        

          原海报 · 1. 什么是固定定位？
          
「使用 CSS 的 position: fixed; 可以将元素固定在视口的某个位置，即使页面滚动，该元素也始终保持在相同位置。」

        

        

          
在 CSS 定位家族里，固定定位并不是孤立存在的：W3C CSS2 规范直接把它定义为「绝对定位的子类」。它同时做了两件事——第一，把它从222 普通流布局里抽出来，后面的段落会立刻顶上去填补它的空位；第二，它不再听父容器的话，而是直接把坐标原点交给浏览器视口玻璃。

          
如果你只是想微调位置同时保留原位占位，去看232 相对定位布局；如果想钉在某张卡片或已定位祖先内部，归233 绝对定位布局；如果希望先跟着滚、滚到顶边再吸住并在离开父容器时松手，那是235 粘性定位布局的舞台。

        03
        

          
海报没说完的三件事

          
NUANCES & VIEWPORT BUDGET

        

      


      

        

          

            原海报：「相对于视口定位」
            漏了前提
          

          
默认确实如此，但一旦任意祖先带有非 none 的 transform、filter、perspective、backdrop-filter，或写了 contain: layout/paint、will-change: transform，那个祖先就会立刻截胡成为包含块。

        


        

          

            原海报：「z-index: 1000;」
            经验写法，非铁律
          

          
1000 只是教学示范数字。实战里到处手写 9999、999999 只会引发层叠军备竞赛；更稳妥是用集中式层叠阶梯（如 --z-nav: 100、--z-drawer: 200、--z-modal: 300）并在统一层叠上下文中管理。

        


        

          

            原海报：顶栏 + 侧轨 + 球 + 底栏同屏
            图解汇总，实战勿全开
          

          
原海报把四种常见位置画在同一屏里是为了教学一眼看齐（顺带一提，海报底部的「向上滚动查重更多内容」是「查看」的笔误）。真实页面若四面同时固定，阅读净区会迅速跌破舒适线，需按屏幕尺寸做减法。
