# 336 标题和内容 幻灯片版式 · 设计方案（PLAN.md）

## 1. 一句话道理
演示文稿里的「标题和内容」之所以是最耐用的工作母版，是因为它把观众的注意力拆成上下两段可预期的认知分工：顶部标题区先亮出唯一核心论断，下方内容区用「精炼文字 + 互补图形」在统一的边距、栏间距与对齐网格中彼此作证，避免大段文字和冗余插图争夺同一条视觉通道。

## 2. 开场玩具：母版手术台（Slide Master Surgery Workbench）
- **核心动作（专为 336 定制，其他编号无法套用）**：
  - 16:9 实时 2D Canvas 幻灯片母版画布（标 `data-perf-drag`），1:1 承袭 336 原海报的暖米纸面、左沿 `HEADER ▶ / CONTENT ▶` 虚线测绘标尺、钴蓝实心圆点要点、蓝圆白星 `TIP` 条与包豪斯几何/真实图表区。
  - **横拖画布中央虚线栏间距中缝**（或用滑轨 / 键盘 `← →`）：实时推拉「左文区 : 右图区」比例（24:76 至 76:24），左列真实逐字折行并实算每行字数与留白，右图按可用槽位实时重构。
  - **直接点击画布里的病灶区「就地动手术」**（或用快捷键 `1–4` / 下方精控按钮）：
    1. 点顶部「标题区」：在「目录标签（无结论） / 三行冗长题 / 结论先行论断句」间切换；
    2. 点左列「要点区」：在「6 条长段字墙 / 4 条精炼要点 / 3 条极简要点 / 1 条空洞散句」间切换；
    3. 点右侧「图形区」：在「冗余复读左文 / 无关装饰贴图 / 互补证据图 + 图注」间切换；
    4. 点左侧蓝色对齐错牙标（或点底沿克莱因蓝图例条的边距/栏间距控制）：修正左缘错位、外边距贴边与栏间距塌缩，并可开关原海报同款「边距 / 栏间距 / 内容区」虚线测绘层与播放 Z/F 型阅读动线演练。
  - 支持三套真实场景切换：**原海报·包豪斯母版**、**季报·复盘决策页**、**科研·论断证据页**。
- **开场初始状态（绝不先给答案）**：
  - 刻意停在 **0/4 灾难汇报页复合错态**：空洞目录标题（且题文比仅 `1.18×` 层级塌平）+ 6 条长段字墙 + 左缘错牙 + 74:26 左胖挤压右图 + 外边距仅 2.5% 贴边 + 栏间距仅 1.4% 串行 + 右图处于「冗余复读左文」且缺图注，四枚原海报原则灯全部告警。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 由 `model.js` 从画布实绘矩形（标题框、要点区、图形框、图注、实际留白像素比、实测每行汉字数）单真源双向核算 8 类真错态：左文过胖挤压右图（>64%）、右图过胖切碎左文（<32%）、外边距过窄防切失守（<5%）或过宽浪费版芯（>14%）、栏间距过窄横向串读（<3%）或过宽视觉断裂（>11%）、题文比塌平（<1.55×）或标题过巨挤压内容、信息过载字墙（≥5 条长句）、图文重复冗余/无关装饰/缺图注、以及左右基线/左缘错位。
  - 每种错态都说明「观众此刻眼睛会怎样卡顿或误读」，并给出具体修正动作；接受多组合法解（原海报均衡解 52:48、图主证据解 40:60、文主深讲解 58:42）。
- **与最近 12 页的明显区别**：
  - 335 是暗茄紫封面页拖焦点/快闪测验；133 是午夜蓝书刊双栏连读；255 是单列长文浏览器；300 是深靛紫组件响应式槽。336 是明亮的**克莱因钴蓝 + 暖米纸包豪斯幻灯片母版手术台**，玩法围绕「结论标题 × 左文要点 × 右图互补 × 母版边距/栏距/对齐」四维联合手术与真实演示动线演练，其他编号无法套用。

## 3. 版式骨架
- **完全承袭 336 原海报结构**（零通用深灰顶栏、零独立圆角仪表盘箱、绝不锁 `100svh` 避平板大空白）：
  - **1440×900（宽屏主宽 1380px；2560 舒展至 1680px）**：
    1. 顶沿通栏**克莱因钴蓝招牌刊头带**（左自示范双行粗黑大标配 `TITLE AND CONTENT LAYOUT`，中右细白竖线隔开明黄方块+三行口号+黄短杠，右上复刻出血明黄四分之一圆弧+5×6 白点阵与三题材切签）；
    2. 中段暖米纸**虚线解剖母版工作台**：左侧窄条原海报 `HEADER ▶ / CONTENT ▶` 动态对齐解剖轨（9%）+ 中央大气 16:9 实时母版手术画布（63%）+ 右侧与画布严丝合缝齐底的「蓝圆白星 TIP · 单真源诊单与微调舱」（28%）；
    3. 下沿 1:1 复刻原海报 **4 列等宽原则实况栏**（`01 图文关系` / `02 层级清晰` / `03 对齐与留白` / `04 阅读顺序`，带原海报同款蓝黄几何图符与淡灰大编号，点击切换画布对应测绘高亮）；
    4. 最底沿 **克莱因钴蓝通栏测绘图例条**（「版式结构参考 LAYOUT GUIDE | 边距 MARGIN | 栏间距 GUTTER | 内容区 CONTENT AREA」），图例项本身就是可点击切换的叠层按钮 + 多组合法解/试错直切。
  - **1024×1366 / 768×1024 平板**：自然折排，画布满宽居中、下方诊单与微调并排齐底，原则栏 2×2 均分，零大块空洞。
  - **390×844 手机竖屏**：压缩顶沿蓝色刊头为单行紧凑大标 + 三题材切签（口号后置），左侧解剖轨转置为画布顶沿超薄标签条，确保等比 16:9 手术画布+操作提示稳占首屏 ≥45% 且折线内直见蓝星 TIP 诊单首句与一键纠偏；圆和三角保持 1:1 几何比例不压扁。
  - **844×390 手机横屏**：切换左 58% 手术画布 × 右 42% 紧凑标题与诊单并行，横屏首屏直接上手。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻两节不用同一种控件）
1. **01 拆解这一页的骨架** (`Anatomy of the layout`) — 暖米纸。引出原海报四条要点、五条建议与蓝星 TIP 原话，并温和补充「5 条上限」建议。交互：**四层透视膜开关**（边距 / 栏间距 / 标题区 / 内容区 SVG 分层剥离解剖）。
2. **02 从 1987 年母版说起** (`Where it comes from`) — 浅蓝雾纸。核实脉络：明托 1978《金字塔原理》→ 1987 PowerPoint 1.0 母版 → 1994 AutoLayout 自动版式 → 2001–2008 迈耶/塔夫特/艾利视觉反思浪潮。交互：**年代演变切页卡**（1987 / 1994 / 2003 / 今日四代微缩幻灯片形态切换）。
3. **03 先说结论，再拿图作证** (`Assertion & complementarity`) — 深钴蓝暗室。用迈耶冗余原则与空间邻近原则解释为何不能图文复读、为何标题要写结论。交互：**三步改写步进翻片器**（第 1 稿字墙 → 第 2 稿提结论 → 第 3 稿左因右图互补，对比删改轨迹）。
4. **04 边距、栏距与后排视距** (`Margin, gutter & viewing distance`) — 淡柠暖纸。结合原海报底部图例讲清边距、栏间距、题文比与会场视距经验值（明确标明「经验值」）。交互：**视距与字阶压测滑轨台**（观众排距 2m–15m 与正文字号 12–28pt 连续压测 + 投影边缘裁切安全框模拟）。
5. **05 什么时候用，什么时候别用** (`When to use — and when not to`) — 亮米宣纸。明确 336 主场与边界，一句话链接同小类 335 / 337 / 338 / 339 / 340 / 341 / 342 / 343 在线版，并加入塔夫特书面评审简报边界。交互：**6 场景诊断选版器**（点选演示任务即刻判定该用 336 还是转场到对应编号）。
6. **06 练一练：四张汇报页怎么选** (`Practice · pick the working slide`) — 深钴蓝考场。同题材四张高水准微缩幻灯片 A/B/C/D，每张错项只差一个变量，选后叠加虚线测绘批注揭晓。交互：**四选一盲测判卷卡**。
7. **07 原海报与版式参考** (`The original poster`) — 暖米展墙 + 克莱因蓝页脚。1:1 呈现 `poster.webp`（可放大、拖动、Esc 关闭）与原海报底沿四枚版式结构参考图例。

## 7. 小练习设计（单变量控制）
- **题目**：同一份「手环续航翻倍至 14 天」产品复盘素材，做成四张 16:9 汇报页（仅标 A / B / C / D），哪一张最符合「标题和内容」版式的核心要求？
- **四项单变量差异**：
  - **A**：对齐、留白、右图曲线全对，**唯独标题写成空洞目录词「续航测试情况概览」**，核心结论藏在正文第 3 条里；
  - **B（正确答案）**：结论型标题「换装低功耗芯片后，手环续航从 7 天翻倍至 14 天」+ 左列 3 条精简归因 + 右侧 7 天 vs 14 天实测耗电折线图与图注，边距、栏距、左缘对齐均到位；
  - **C**：结论型标题、对齐、留白全对，**唯独右侧没有给数据证据图，而是用三个花哨方框把左列三条文字原样复读了一遍**（违反图文互补/冗余原则）；
  - **D**：结论型标题、左文与右图曲线全对，**唯独中缝栏间距塌缩至贴死、标题与内容区左缘错牙、外边距紧贴画框边缘**（违反边距、栏间距与对齐秩序）。
