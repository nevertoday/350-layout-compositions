01

框齐平，字脚为何飘？

BOUNDING BOX VS. TRUE BASELINE & OVERSHOOT

每个文字块在排版软件与浏览器里都包着一层矩形外框（em-box / 行框）：上到上升线，下到下降线。无论字块里有没有写 g、p、y，外框底下都预留着与当前字号成正比的下降部空间。

因此「底部看起来差不多齐」其实藏着两种截然不同的错法：框底对齐把各块外框底边压到一条线上，因为下降线随字号变大，字号越大的块基线反被抬得越高；字墨底对齐则把最底端真实笔画强按上线，结果 g、p、y 的降部尾巴尖端顶住了蓝线，把字母躯干顶离地平线。

更微妙的是人眼的几何错觉：如果把圆形字母 O、o 的底弧精确切平在基线上，视觉上会显得比平底的 H、A 更矮小。字体设计师通常会按约 1%–3% 的常见经验值（相对大写高或 x 字高，视字体而异）让圆弧略探出基线，称为光学过冲（overshoot）。

02

铅字垫纸到多文种基线

FROM STANDARD LINE (1894) TO OPENTYPE BASE

今天我们在排版软件里把不同字体、不同字号放在同一行，脚底自动站成一条直线，似乎理所当然。可在一百多年前的金属活字车间里，这曾是排字工每天最费神的体力活。

1894 · Inland Type Foundry 率先统一基线

1894 年，Carl Schraubstadter 的三个儿子 William A.、Oswald 与 Carl Jr. 在密苏里州圣路易斯创立 Inland Type Foundry。因为是新建铸字厂、没有旧式非统一基线活字的库存包袱，他们率先将同字号的所有字体铸造在同一基线上，并以「Standard Line Type」之名大力推广，免去了排字工混排不同字体时反复塞纸片垫高的繁琐工序。

03

中英混排的隐形错位

CLREQ §6.4 & OPENTYPE BASE TABLE

拉丁字母站在底部基线上、降部向下垂落；汉字却没有降部。据 W3C《中文排版需求》（CLREQ）§6.4「基线、行高等」，汉字拥有正方形的文字外框，内部居中嵌着略小的字面，字面与外框四周留有若干空白。

为了让不同文字体系在同一行里互不打架，Microsoft OpenType 规范用 BASE 表登记了多条基线坐标：拉丁字母用 romn，汉字方块外框底用 ideo，藏文与天城文等顶挂文字用 hang，数学公式用 math。

如果强行把汉字方块外框底（ideo）抬平到拉丁字母基线（romn），汉字字面底下那截衬空就会把整串中文顶得像上标般上浮。当前加载的 Noto Sans SC 经 TextMetrics 实测，其方块底需低于西文基线约 12.0%，汉字字面底才会与西文脚底稳稳齐平。关于直排与横排的书写轴线切换，另见 192 垂直文字排版 与 193 水平文字排版。

04

跨栏共线：基线网格

CROSS-COLUMN BASELINE GRID

单行排齐只是起点。Josef Müller-Brockmann 在 1981 年的《平面设计中的网格系统》里指出：多栏书籍与杂志应以正文行距为基本步长，铺设贯穿全页的基线网格。一旦左栏插进小标题或引语，如果它的总占高（字高加段前段后）不是网格步长的整数倍，左右两栏的正文行脚就会从此错开半行，页面立刻发颤。多栏中的跨栏标题与左右对齐细节，另见 184 跨栏标题、176 左对齐右参差 与 179 两端对齐。

网页里怎么对齐基线？

CSS INLINE LAYOUT & BOX ALIGNMENT

CSS 弹性布局默认最爱写 align-items: center——正是开场让你看到字脚飘浮的元凶。按 W3C CSS Inline Layout 3 与 Box Alignment 3 规范，行内文字可设 vertical-align: baseline，弹性容器可设 align-items: baseline（默认取首行 first baseline）；遇到左侧多行标题或右端双行小标需要齐底时，现代浏览器已原生支持 align-items: last baseline。

什么时候别硬对齐？

WHEN NOT TO FORCE BASELINE ALIGNMENT

基线对齐不是万能胶。遇到非文字图形、超高数字配多行说明、顶挂文字系统或刻意制造视觉跳跃的海报时，硬套底基线反倒更歪。点击下方四张场景卡，各自对比「死守基线」与「放手改用」的真实差别。

01 · 图标配单行按钮
立即检索

死守基线：图标底边压到文字基线上，整枚放大镜显得比文字高出一截，按钮视觉失衡。

02 · 超大数字配三行备注
94 本月校准通过率
覆盖六种测试视口
无一行横向溢出

死守首基线：三行备注的第一行贴到 94 的脚底，后两行悬空吊在数字下方，上下空出大洞。

03 · 顶挂文字混排
Hang Line

死守拉丁底线：天城文、藏文等文字以顶部横杠悬挂生长，强压底部会让顶杠高低失序。

04 · 表现型律动展报
JAZZ LIVE 2026

死守基线：音乐节或实验展报需要切分与跳动节奏，一味锁死水平基线反而磨平了表现力。
