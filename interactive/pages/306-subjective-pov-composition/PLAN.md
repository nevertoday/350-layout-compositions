# 306 主观视角构图 · 设计与实现方案

## 1. 一句话道理
当镜头严格占据角色的眼睛位置、用门框与双手等近景身体边界收束视域并藏起画外信息时，观众就会从「评判角色」切换为「替角色呼吸与判断」，有限的信息反倒放大了悬念和共情。

## 2. 开场玩具
- **名称**：第一人称入眼与推门视野台（`First-Person Doorway & Gaze Rig`，2D Canvas 轻量化 3D 透视投影，标 `data-perf-drag`）。
- **怎么玩**：
  - 在画布上**横拖/纵拖**直接转动角色的头（偏航 yaw `-45°..+45°`、俯仰 pitch `-18°..+18°`），带真实近大远小视差（前景木门、贴在门背的便签「今天，去看海。」、前景捧杯双手与窗外灯塔分层错动）。
  - 拖动门沿把手或推拉「推门开合」控制门扇开合角（`12°..110°`），实时控制「看到多少？」与框中框占比。
  - 点击画布下沿捧杯双手（或滑块）调节前景双手高度（无前景飘浮 ↔ 自然托杯 ↔ 举杯挡眼）。
  - 切换「入眼纯度 / 机位退距」实测从第一人称入眼滑向第三人称背影/过肩；调节等效焦段（`24mm..85mm`）感受视角松紧；支持「原海报·看海木屋 / 悬疑·暗廊推门 / 清晨·车窗出站」三套剧本。
  - 按 `Space` 或点「睁眼揭示」演播真实眨眼黑屏到视野缓缓展开的揭示节奏（回应原海报「何时看到？」）。
- **一打开是什么状态（绝非答案）**：刻意停在 `0/4` 复合破局态——机位退在角色背后（角色暗影背影入画，退成旁观者）、头向左拧偏 `-30°` 把灯塔甩到门框外、门只开了 `18°` 窄缝把海面压死、前景捧杯双手彻底缺失（无身体锚点）。
- **怎样算玩错、错了读数怎么说**：由 `model.js` 从画布实绘的门洞多边形、主体投影包围盒、前景双手遮挡交集与机位离眼距**单真源双向核算** 8 类错态：
  1. 机位退后漏背影（不再是本人视角） / 焦段极端畸变或长焦扁平；
  2. 偏头太左主体切出右沿 / 偏头太右主体撞死左门柱；
  3. 门缝过窄（框占 > 66%）视野窒息 / 推门太宽或迈出门外（框占 < 28%）框中框失守；
  4. 无前景身体锚点像漂浮无人机 / 前景手杯举太高（遮住主体 ≥ 12%）挡死目标。
  - 读数不仅报几何实测值（如「主体仅露 18%」「框边占 74%」「遮挡主体 26%」），同时用白话讲清「观众此刻为什么出戏 / 焦虑 / 抓不到焦点」与下一步怎么调。
  - 认可「原海报经典解」「紧框窥视解」「开阔看海解」及任意满足 4/4 的自定义组合。
- **与最近 12 页的区别**：305 是暗室双机位正反打过肩切镜与光圈虚化；086 是 3D 走廊纵深推拉与侧剖 X-Ray；050/087/049/174/260/138/219/339/304/338 均为平面/几何/网页/出版物。306 独有「第一人称转头视差 + 推门控制信息闸门 + 身体前景锚点 + 眨眼揭示节奏」，其他编号无法原样套用。

## 3. 版式骨架
忠实转译 306 原海报「海风天蓝全幅展板 × 左上橙色 L 形直角框大标 × 左主视窗与右五枚黑圆标橙色折线引注 × 底部整幅圆角暖米『关键要点』长匣 × 底沿灯泡 TIP 宣言条」（绝不锁 `100svh`，零通用深灰顶栏）：
- **1440×900**（2560 舒展至 1620px）：顶部左橙色 L 框刊头（`主观视角构图` + `SUBJECTIVE POV COMPOSITION ■`）× 右三剧本切换与「睁眼揭示 Space」键与状态章 → 主舞台左 68% 开放式第一人称推门画布 × 右 32% 原海报五枚黑圆图标实时探针列（带橙色折线与圆点指向画布，与画布齐底）→ 下方通宽圆角暖米长匣：上层左白话诊单 × 右单真源精控舱，下层 1:1 原海报五列「关键要点 KEY POINTS」实测栏 → 天蓝底沿灯泡 TIP 宣言条。
- **1024×1366 / 768×1024 平板**：自然流排不锁屏高，画布满宽、五枚黑圆标折排为紧凑横带、下方暖米长匣双列齐底，无大片空洞。
- **390×844 手机竖屏**：单行压紧橙框刊头（隐藏副总述至画布下方，五枚黑圆标后置），让 4:3 等比推门画布稳占首屏 ≥ 46% 屏高，折线内直接露出暖米诊单首句、一键入眼修复与睁眼揭示按钮。
- **844×390 手机横屏**：左 55% 第一人称推门画布 × 右 45% 刊头、白话诊单与核心快捷操作并行，不挤压画布。

## 5. 节目录（7 大节，相邻不用同类控件）
- **01 从魔灯窥镜到现代镜头**：电影史五个里程碑（1900 史密斯 → 1931 马莫利安 → 1946/47 蒙哥马利 → 1965/1984 理论 → 2007 施纳贝尔）｜交互：可点年代胶片索引卡 + 同步切换早期光学遮罩矢量演示。
- **02 同一小类五镜头怎么分**：一句定位并链接 305/307/308/309 在线版，讲清「眼位重合」与其它四位的边界｜交互：俯视片场机位图（SVG 直接点选五台机位看视锥与画面对照）。
- **03 信息闸门与揭示顺序**：展开原海报「何时看到？」「更少的展示带来更强代入」及布拉尼根前瞻式/回溯式视点｜交互：三镜剪辑顺序重排与节拍演播台（暗室深炭底）。
- **04 框中框与情绪焦段**：拆解不同物理前景框与焦段如何不靠台词传达心理状态，并温和修正原海报「越少越代入」的适用边界（标「说多了一点」）｜交互：5 种物理遮罩（门框/车窗/望远镜/百叶/面罩）× 焦段（24–85mm）实时光学画布。
- **05 什么时候别用主观视角**：四类明确禁区（看主角反应、长篇硬撑、复杂群戏调度、客观信息说明）｜交互：四张可切换「硬用主观 vs 改用正解」的解剖对照卡。
- **06 小练习：挑出成立的主观镜头**：两道单变量视觉四选一（暗室试镜厅）｜交互：中性 A/B/C/D 构图卡片点选与逐项讲理。
- **07 原海报与关键词档案**：展示原海报全图与全部原话、色票｜交互：点开大图灯箱（可缩放、拖动 `draggable="false"`、`Esc` 关闭）。

## 7. 练习设计
- **第 1 题（单一变量：框中框开合与前景遮挡）**：A 门缝过窄切掉主体 / B 门框约占四成且双手托杯在下沿不挡灯塔（正解）/ C 迈出门外彻底无门框 / D 门框合适但双手举高挡死灯塔。标签仅标 `A / B / C / D` 与中性画面编号，绝不泄露好坏。
- **第 2 题（单一变量：摄影机沿视线轴的入眼位置）**：A 侧面三米客观全景 / B 角色肩后过肩位 / C 镜头与角色双目重合仅见门沿手指（正解）/ D 脱离门沿贴近皮箱正上方俯拍道具特写。
