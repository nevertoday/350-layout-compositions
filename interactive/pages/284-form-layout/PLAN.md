# 284 表单布局（FORM LAYOUT）互动页设计方案

## 1. 一句话道理
表单不是静态陈列的格子，而是一场人机问答：当标签紧贴输入起点、相关字段用留白和边界自然归组、格式提示与错误反馈就在手边、主行动与次操作权重分明时，人的视线顺着一条几乎不折返的轨道往下走，填表快、不容易漏、填错了也能立刻修好。

## 2. 开场玩具：「活体表单 × 眼动扫视示波台」
- **怎么玩**：
  - 右侧纯白容器是一张**100% 真能填写、真能点「定位错误」自动聚焦手机号输入框、真能点「提交表单 →」触发完整校验闭环**的活体表单（1:1 承袭 284 原海报的「基本信息 / 项目信息 / 额外设置」3 组 9 字段，并可切换「原海报 · 项目立项 / 电商收货结算 / 线下活动报名」三套真实题材）。
  - 表单顶部嵌有一条带刻度线的 **2D Canvas 眼动扫视示波轨（标 `data-perf-drag`）**，表单上方叠有一层不挡点击的 **2D Canvas 真实 DOM 眼动路径层**。横向拖动示波轨探针（或按 `←` / `→` 键），蓝色/朱红注视光点实时沿着下方每个 `<label>` → `<input>` → 错误汇总 → 按钮的实际 DOM 坐标游走，直观标出横向裂口与 Z 字折返。用户点击或 Tab 切入任意输入框时，注视点也会立刻跟过去。
  - 表单底缘设四维调控组（对齐方式 / 分组结构 / 提示与校验 / 行动主次），点击切换立刻重排活体表单与眼动轨。
- **开场初始态（0/4 失序错态，绝不先给答案）**：
  - 对齐：`左置左对齐 + 双列交错`（标签到输入起点扯出 >90px 参差裂口，视线 Z 字来回跳）；
  - 分组：`平铺一锅粥`（去掉分组留白与色条，9 字段等距糊墙，组间/组内距比 1.00×）；
  - 提示：`边打字边报红（且缺失定位错误按钮）`（并保留 `仅占位符 + 哑巴红框` 可一键切换踩错，让开场能直接看见左置左对齐的真实红色虚线裂口，同时又能测试过早惩罚与打字失忆两类反模式）；
  - 行动：`三钮同色平权`（「清空重置」「取消」「提交表单」做成同样醒目的实心重色紧挨一起，极易误点清空）。
  - 同时手机号字段预置了一个格式错误值 `138-001`（呼应原海报错误提示「手机号格式不正确」），等待用户用「定位错误」聚焦修正或调正布局后提交验收。
- **怎样算玩错 & 错了读数怎么说**：
  - 不是点满就过关，每个维度都有可主动踩出的真实反模式（共 10 类失误）：
    1. 左置左对齐大裂口（标签尾到输入框距离参差，横向扫视剧增）；
    2. 全居中对齐双边锯齿（缺少统一左基准线，眼球每行重找起点）；
    3. 乱拆双列 Z 字折返（不相关字段硬排左右两列，易跳格漏填）；
    4. 右对齐遇长标签挤压（虽缩裂口但空间吃紧时挤扁输入框）；
    5. 平铺无分组（组间/组内间距比 ≈ 1.0×，一眼望去像一堵墙）；
    6. 每格一框过度割裂（框线噪声淹没层级，视觉碎片化）；
    7. 仅占位符无常驻标签（输入一敲字就失忆，违反 WCAG 3.3.2）；
    8. 边敲字边报红过早惩罚（还没输完就跳红错打断思路）；
    9. 行动同色平权或重置抢主（高风险操作和主操作等权，误触毁全表）；
    10. 主操作弱化且靠边隐身（填完找不到下一步落点）。
  - **支持多组合法正当解**：不仅接受「原海报解（顶对齐紧凑成对双列 + 左色条三组 + 常驻提示错误汇总 + 主蓝次框）」，也接受「单列精简解（GOV.UK 风格纯单列 + 留白分组 + 离焦校验 + 主蓝弱文字取消）」和「桌面紧凑右对齐解（短标签右对齐 + 色条分组 + 离焦校验 + 主次分明）」。
- **读数说什么「为什么」**：单真源 `model.js` 直接读取表单真实 DOM 坐标盒算出「标签→框平均跨越 px」「Z 字横向折返次数」「组间/组内间距比」「扫视阻滞档位（示意）」，并用白话解释人眼为什么会在这里卡住。
- **与最近 12 页的差异**：近 12 页多为几何画布拖轨（200/199）、图形软件工作台调停靠栏（283）、地图锚点连线（282）、视口宽度卡尺（241/238）或点阵分拣（116/115）；本页直接做出一张**可真实打字、聚焦、校验、提交的活体 Web 表单**，以真实 DOM 几何反算眼动轨迹，绝无法套用到别的编号。

## 3. 版式骨架
忠实承袭 284 原海报的「冰薄荷雾白原纸 + 左 34% 垂直四点检查脉络 × 右 66% 纯白圆角表单工作纸 + 底沿四色圆徽总结带」：
- **1440×900（主宽 1360px；2560×1440 舒展至 1720px）**：不锁 `100svh`。极细 32px 深午夜蓝顶眉下，左列放自示范大标（标题底带随当前对齐方式同步错位/卡齐的字段基准轨）、青竖杠总述、4 枚垂直虚线串联的实况徽章与单真源白话诊单；右列铺开纯白活体表单、顶缘眼动示波轨与四维快切；下方全宽白卡承接原海报四原则展开栏。
- **1024×1366 / 768×1024 平板**：自然流排，紧凑刊头置顶 → 全宽活体表单工作纸 → 下接双栏诊单与四点实况，杜绝平板大空洞。
- **390×844 / 360×740 手机竖屏**：顶眉 + 极紧单行标题压在 ~84px，总述移至表单后，让活体表单与可拖眼动示波轨稳占首屏 ≥ 48% 屏高，同屏露出诊单主句与快修入口。
- **844×390 手机横屏**：切左 58% 精简活体表单与示波轨 × 右 42% 刊头、四维快切与诊单并行。

## 4. 配色和字体
- **逐像素采自 284 原海报的冰薄荷 × 钴蓝 × 翠青单据体系**：
  - 冰薄荷原纸底 `#EDF9F7` / 柔薄荷纸 `#E6F5F3` / 纯白表单纸 `#FCFFFE` / 浅钴雾纸 `#EEF4FD` / 浅雾灰 `#F0F6F6`
  - 深午夜海军蓝主墨与 03 节暗室 `#001C48` / 暗室底 `#031836` / 暗舱 `#0A264E` / 正文深墨 `#0F2744` / 次墨 `#3B536E`
  - 皇室钴蓝 `#0848E8`（主按钮、左色条、实心小圆、副标；暗底亮钴 `#7EB0FF`）
  - 翡翠松青 `#00A8A0`（分组色条、总述竖杠、点阵 `#68CED2`、装饰大圆 `#B8E8E4`；小字高对比深松青 `#006B66`，白字实底 `#007C76`，暗底亮青 `#4BE0D6`）
  - 纠错朱红 `#EB2C38`（左红条、报错红点；浅粉底 `#FDF0F2`，高对比报错字 `#C41E2E`，暗底亮红 `#FF8690`）
- **字体搭配（全库唯一，与 282/283 零西文重合）**：
  - `Noto Sans SC`（400/500/700/900，清晰表单中文正文与粗标题）
  - **`Manrope`**（500/700/800，现代半圆几何无衬线，**近 12 页 0 次使用**）
  - **`Chivo`**（400/700 及 400 italic，利落新怪诞无衬线，**近 12 页 0 次使用**）
  - `DM Mono`（400/500，柔和等宽，用于坐标、px 实测值与编号）

## 5. 节目录（8 个编号小节 + 页脚，相邻两节控件绝不重复）
- **01 眼动路径决定填表快慢**（`01 / ALIGNMENT & SACCADES`）：展开「对齐」要点并温和校读原海报双列与左对齐表述；**交互：三联对齐方式并排对照 + 标签长度/多语言膨胀滑块**。
- **02 用留白和边界替大脑分块**（`02 / CHUNKING & GROUPING`）：展开「分组」要点与必填/可选标记策略；**交互：点击字段间虚线槽插拔分组边界 + 边界材质切换 + 实时 2D Canvas 密度标尺**。
- **03 好提示防错，坏校验打断**（`03 / CLARITY & VALIDATION`，深午夜蓝暗室）：展开「提示」要点、占位符风险与 WCAG 3.3；**交互：真实可打字邮箱/密码校验时机对战舱（支持一键模拟逐字输入对比 4 种校验策略）**。
- **04 按钮主次决定临门一脚**（`04 / ACTION HIERARCHY`）：展开「行动」要点、文案清晰度与破坏性操作隔离；**交互：按钮主次配置 + 3 秒盲点压力防误触测试**。
- **05 表单布局从哪来**（`05 / LINEAGE & EVIDENCE`）：梳理 1995–2018 可核实的标准与研究里程碑；**交互：时间轴里程碑卡片切换**。
- **06 什么时候用，什么时候别用**（`06 / WHEN TO USE & AVOID`）：对照标准表单适用边界与 5 个同小类页面的切换时机（带在线版链接：285、287、274、286、281）；**交互：场景条件筛选器（字段数/实时生效/批量录入/分支深度）自动给出布局建议**。
- **07 挑出最顺手的那一版**（`07 / PRACTICE`）：四选一单变量实战选择题，中性标签 + 完整原理解析。
- **08 原海报与设计关键词**（`08 / ORIGINAL POSTER`）：内联原海报 `<img id="poster">`（点开灯箱缩放/拖动/`Esc` 关闭）+ 5 枚关键词与四项原则原文。

## 7. 练习设计
- **题目**：手机与桌面通用的「团队活动报名表」（6 个必填项：姓名、手机号、邮箱、部门、餐饮偏好、是否住宿），四个方案颜色、字号、分组、错误汇总和提交按钮完全一致，只差一个结构变量，选出填起来最顺手的一版。
- **四选项（纯中性 `方案 A / B / C / D` + 客观结构描述，无优劣提示词）**：
  - **方案 A**：单列 6 项，常驻顶对齐标签（**正确答案**：单条垂直视线、标签在输入时始终可见、手机桌面通吃）。
  - **方案 B**：双列 3 行，常驻顶对齐标签（单变量差异：无关字段硬排双列，导致 Z 字折返和顺序歧义）。
  - **方案 C**：单列 6 项，框内占位符兼作标签（单变量差异：聚焦打字后标签消失，填完难回查且低对比度）。
  - **方案 D**：单列 6 项，左置左对齐标签列（单变量差异：2 字与 6 字标签混排扯出参差横向裂口，眼球反复横跳）。
