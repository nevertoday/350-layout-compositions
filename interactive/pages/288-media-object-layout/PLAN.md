# 288 媒体对象布局（MEDIA OBJECT LAYOUT）交互方案

## 1. 一句话道理
人脑分别用图像通道和语言通道加工信息，把画面与紧邻的说明、上下文锁在同一结构单元里，眼睛不用满屏找解释，既先看进画面，又立刻读懂、记得住。

## 2. 开场玩具
- **命名**：活体影音配对放映台（Live Media Object Screening & Pairing Stage）。
- **怎么玩**：在 1:1 承袭 288 原海报暗黑放映室（青→珊瑚渐变描边播放器 + 上指尖角珊瑚描边说明配对卡 + 右侧三条青/珊瑚虚线圆点引注）的 2D Canvas 活体放映画布（`data-perf-drag`）上：
  1. **横拖画布**连续拉展或压缩「画面视觉占比」（`16%–84%`），实时看见阿尔卑斯晨光播放器从缩角小图长成视觉主导大画幅，或膨胀压垮下方/侧边说明卡；
  2. **拖拽媒体框与说明卡之间的珊瑚距离标尺**（或下方间距控轨）把脱节的说明卡拉回 `8–24px` 空间邻近带，亲眼看见原海报招牌的「上指珊瑚尖角（`^`）」喀哒锁回播放器底边；
  3. **点击画面里的播放键**可真的播放/暂停晨光延时动画（`00:00–02:45`，珊瑚红日沿山脊升起并联动光影）；
  4. **切换三套真实题材**（原海报·阿尔卑斯晨光 / 纪录片·深海声呐片单 / 社区·嵌套评论流）、**三种排布方向**（上图下文·影院卡 / 左图右文·OOCSS / 右图左文·反转编辑），以及点击画布内红标或控件修复**层级倒挂**与**上下文缺失/过载**。
- **初始状态（绝不先给答案）**：刻意停在 **0/4 失配错态**——画面占比被挤到 22%（视觉失权）、说明卡漂离至 68px 外且尖角断联（邻近断裂）、标题/说明/细节平铺灰成一片（层级失效）、摄影师/地点/日期/分类上下文全空（缺乏语境），底沿原海报五相月蚀青圆处于暗态 `0/4`。
- **怎样算玩错 & 读数如何解释「为什么」**：`model.js` 从实绘几何框坐标、像素占比与单行可读字数单一数据源实时核算 **10 类媒体对象错态**：
  1. 画面过小失权（竖排 `<36%` / 横排 `<24%`）；
  2. 画面过胀压垮说明区（说明栏宽不够或折成碎条）；
  3. 间距过远断联（`>28px`，触发 Mayer 空间邻近违背，画布绘出红色眼跳折线）；
  4. 间距过近撞边（`<6px`，描边粘连窒息）；
  5. 经典浮动漏气绕排（横排未建 BFC/Flex 时正文钻到图片底端折成 L 形）；
  6. 层级平灰（标题与正文缺乏字重/明度落差，无阅读入口）；
  7. 层级倒挂（元数据/标签比主说明还抢眼）；
  8. 上下文空缺（失去拍摄者/时间/地点锚点，画面无法验证）；
  9. 上下文堆砌过载（9 枚标签挤占近半说明卡，稀释主句）；
  10. 说明卡与媒体边线错位脱齐。
  同时接受多组合法解（原海报影院解、OOCSS 左图右文解、右图左文编辑解及任意落在合理参数带内的自调组合），每修好一项，底沿 `KEY TAKEAWAY` 胶囊里的青色五相月蚀圆点亮一格，直至 4/4 全亮。
- **与近期 12 页的差异**：近期 12 页里 287 是冷灰三栏设置窗口、159 是淡紫浮动卡叠层、325 是暖宣折枝册页、036 是天蓝 C 弧、120 是象牙围栏圆点、245 是腮红居中轴、203 是深松石星盘、074 是暖米斜投影体块、286 是暖米搜索结果、324 是朱砂裁景刀窗、119 是藏青鲁宾花瓶、244 是明黄四层盒模型。本页独占「暗黑放映室影院播放器 + 尖角气泡说明配对卡 + 右侧三节点青/珊瑚虚线引注 + 底部月蚀青圆进度胶囊」，玩具动作是**配对影音画面与说明语境的视觉权衡、空间锁扣与层级校验**，别的编号无法套用。

## 3. 版式骨架
忠实承袭 288 原海报的暗黑放映室结构（零通用浅色导航条、绝不锁 `100svh` 避开平板大片空洞）：
- **1440×900（2560×1440 舒展至 1760px）**：顶部自示范暗黑刊头（左暖奶白超粗大标「媒体对象布局」直接压叠右上巨幅珊瑚红圆日与青色 `+` 十字标，下接青色英文 `MEDIA OBJECT LAYOUT`、珊瑚短杠与原海报总述）→ 主区左 63% 活体影音配对画布与底沿放映控坞 × 右 37% 忠实复刻原海报三条青/珊瑚圆点虚线引注脊（图像优先 / 说明配对 / 上下文，各带实时状态）与单真源诊单卡 → 下接原海报四栏竖虚线「布局原则」实况带 → 底沿青框 `KEY TAKEAWAY` 通栏胶囊与五相月蚀进度圆。左右两栏等高齐收，绝不留单边空白。
- **1024×1366 / 768×1024 平板**：自然流排，不锁 `100svh`，主画布居中满宽展开，下方紧接双栏诊单与三节点实况。
- **390×844 手机竖屏**：压紧单行刊头（缩收红日作右上角徽标，把长总述移到画布下方），让活体影音配对画布稳占首屏 ≥46% 高度，且在首屏同时看见单真源诊单首句与快修入口；所有圆形与画幅严格等比不压扁。
- **844×390 手机横屏**：切左 55% 活体放映画布 × 右 45% 紧凑刊头、诊单与核心快控并行。
- **正文 01–07 节色彩交替**：暗黑放映室开场 → 01 暖奶宣纸 → 02 淡青雾纸 → 03 暗黑暗房（历史胶片轴）→ 04 暖奶宣纸 → 05 暖珊瑚砂纸 → 06 淡青雾纸 → 07 暗黑原海报展墙与页脚。

## 5. 节目录（01–07，h2 ≤ 12 字，相邻不撞控件）
- **01 · 为什么图文要配对**（`Why Pairing Works`）：引入 Paivio 双重编码与 Mayer 空间邻近，并用**前后拖幕分割对比器 + 眼跳路径重播**对比「图文割裂」与「就近锁扣」。
- **02 · 画面多大才算主导**（`Visual Lead & Nuance`）：展开原海报「视觉主导」，标注「说多了一点」区分展示型媒体卡与紧凑评论行；配**三档容器宽度帧框切换器（宽栏 760 / 侧栏 360 / 窄屏 280）+ 实时 `@container` CSS 代码联动**，直看媒体对象随容器自动在横排与竖排间切换。
- **03 · 从 OOCSS 到现代布局**（`Origin & Evolution`）：暗房胶片时间轴梳理 1971 Paivio → 2001 Mayer → 2010 Nicole Sullivan OOCSS → MDN Grid `fit-content()` → `@container`；配**横向年代胶片步进器 + 2010 经典 float 漏气绕排 X 光开关**（在真实嵌套评论树里现切现看）。
- **04 · 层级清晰与一致关联**（`Hierarchy & Consistency`）：解析原海报 `标题 > 说明 > 细节` 与间距统一；配**3 条纪录片列表的 2×2 独立故障注入矩阵**（缩略图比例混排 / 左右乱跳 / 标签喧宾 / 间距粘连），点哪项立刻看清对齐参考线断在哪。
- **05 · 什么时候用，什么时候别用**（`When to Use & Avoid`）：明确适用边界并一句话链接同类页（269 信息流、270 卡片网格、274 数据表格、275 画廊、281 对话、289 Hero 主视觉）；配**6 张真实产品需求研判卡（点击翻揭结论与替代方案）**。
- **06 · 实战诊一题**（`Design Checkpoint`）：单一变量 4 选 1 视觉线框练习（方案 A/B/C/D）。
- **07 · 原海报与关键词**（`Original Poster`）：`<img id="poster" src="poster.webp">` 可放大拖拽查原图 + 四大关键词 + `KEY TAKEAWAY` + 规范页脚。

## 7. 练习设计
- **题目**：同一组 2 条连续纪录片媒体对象，图片尺寸、字体字号、颜色与元数据完全一致，**只改变「图—文内距」与「条—条组距」这一组空间变量**，选出最符合「邻近对齐」的一版。
- **四项中性标签（零剧透）**：
  - `方案 A`：内距 28px · 组距 14px（错：说明离下一条的图更近，发生跨组错归）
  - `方案 B`：内距 2px · 组距 40px（错：文字框紧贴图像边缘撞边窒息）
  - `方案 C`：内距 12px · 组距 36px（**正确**：内部有清晰呼吸缝，且外距为内距 3 倍，一眼锁死归属）
  - `方案 D`：内距 24px · 组距 24px（错：内外等距，图文边界消解成均质条纹）
