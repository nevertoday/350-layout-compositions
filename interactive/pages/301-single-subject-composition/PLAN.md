# 301 单人构图 · 页面设计方案

## 1. 一句话道理
当画框里只留下一个清晰主体时，观众不再需要分配注意力，任何多余亮斑、贴边挤压、视线堵墙或关节硬切都会立刻暴露——单人构图之所以有力，在于用减法、反差、留白与恰当景别，把整块画面的视觉重量全部收束到一个人物的处境与情绪上。

## 2. 开场玩具：单人机位取景器 × 景别接触印样台
- **玩法**：1:1 承袭 301 原海报的深松青开放取景框（四角米白取景折角 `┌ ┐ └ ┘` + 虚线三分辅助线 + 暖月孤崖单人剪影，2D Canvas 实时视差渲染，标 `data-perf-drag`）：
  1. **横拖画布摇镜（Pan）**：直接在取景器画布上左右拖动，连续平移镜头机位（带近崖/人物/远月轻视差），实时改变主体落点、视线前方空间与画面视觉重心；支持键盘 `← / →` 摇镜、`↑ / ↓` 调整俯仰留顶、`+ / -` 推拉景别、`1–5` 直切五档景别。
  2. **直点画面清场**：画面里混入的视觉干扰物（原海报场景的暖白航标灯塔与崖边撑伞路人；夜站场景的亮霓虹牌与停放滑板车；窗畔场景的杂乱海报与台灯）可以直接点击移除，也可以靠推近景别或摇镜将它们物理裁出取景框外——与真实片场「清场或换焦裁切」完全一致。
  3. **五格接触印样直切景别 + 连续焦距推拉**：画布下方 1:1 复刻原海报底部的五格暖米「景别参考 SHOT SCALE REFERENCE」（远景 / 全景 / 中景 / 近景 / 特写），点击任意印样格或拉动镜头推拉滑轨，连续从 `18mm` 远景推入 `135mm` 特写，同步改写人物画框占比、头顶留白与底部裁切解剖位。
  4. **三套导演意图场景 + 朝向切换**：支持「原海报·孤峰望月」「夜站·独行侧影」「窗畔·情绪凝视」三景及背影/朝左/朝右切换；点选左侧原海报同款 5 枚黑底米白圆徽原则（突出主体 / 引导视线 / 保持平衡 / 善用留白 / 选择合适景别），可在画布上高亮对应的几何诊断层。
- **开场坏态（绝不预先给答案）**：默认落在「原海报·孤峰望月」的 `0/5` 复合坏帧：
  - 主体被摇到最左边缘（约 `11%` 处），脱离明月背光区陷入深松青暗底（图底反差塌陷 + 贴边挤压）；
  - 两侧闯入 2 个干扰物（左缘航标亮灯 + 右缘撑伞路人剪影），破坏单一主体纯度；
  - 景别停在尴尬的 `46%` 处，下框沿恰好硬切在人物小腿/膝盖禁切带（关节硬切），且偏离「孤独环境氛围」所需的远/全景区间；
  - 人物与大块黑崖失衡，5 项海报速记要点全部告警。
- **双向可错与单真源核算（`model.js`）**：全部读数由 `model.js` 根据当前相机视口下实际绘制的人物包围盒、头顶坐标、底框解剖切位、有效干扰物可见性、明月重叠反差与像素级静空面积占比实时算出，双向捕获 **7 类真错态**：
  1. 多主体抢戏（干扰物仍在取景框内）；
  2. 贴边挤压（主体中心 `< 14%` 或 `> 86%`）；
  3. 视线堵墙（面朝左/右时前方视线空间 `< 36%`）；
  4. 削顶压迫 / 空顶下沉（非特写头顶留白 `< 4%` 或中近景 `> 40%`）；
  5. 关节硬切（底框刚好落在脚踝 / 膝盖 / 颈部禁切带）；
  6. 留白过挤或主体淹没（非特写静空 `< 50%`，或远景拉太远导致主体高 `< 5%` 难以辨认）；
  7. 景别与当前叙事意图背离（如氛围场景硬推特写，或情绪凝视硬拉远景），以及图底黏连（剪影离开亮月/亮窗隔离区）。
  - 同时承认多组合法解（原海报经典右偏望月全景、辽阔远景孤影、左三分留白解等均判定成立）。
- **与最近 12 页及 001 / 309 的区别**：不使用拖准星或把手对点的固定套路，也不是网页布局容器（300/299/255/132）、字体排印（214/213/169/254）、物理支点（334）或遮罩（333/082/044），而是以电影摄影师真实的「摇镜 + 推拉焦距 + 片场清场 + 接触印样切景别」操作还原单人镜头的五维成立条件。

## 3. 版式骨架
- **忠实转译 301 原海报「满幅深松青电影取景工作台」**：无深灰通用顶栏、无仪表盘侧箱、绝不锁 `100svh`（彻底规避平板竖屏大空白）。
- **1440×900（主宽 `1380px`，2560×1440 舒展至 `1680px`）**：
  - 顶沿极简刊头行（`NO. 301` 类别号 + 实时镜头诊断状态印章），下方直出巨幅暖米大标 `单人构图`（首字「单」外嵌米白取景微角标自示范单一焦点）与宽距大写 `SINGLE SUBJECT COMPOSITION` 及细线总述。
  - 上半主舞台非对称双栏：左 `29%` 1:1 复刻原海报五枚黑圆米白线徽原则实况脊；右 `71%` 开放式无重框电影取景画布（带四角 `┌ ┐ └ ┘` 与紧贴的机位操控条）。
  - 细横线之下 1:1 复刻原海报底带双栏齐底：左 `37%` 为原海报「构图要点速记」五项活体勾选与深松青单真源白话诊单；右 `63%` 为五格暖米「景别参考」可点接触印样条与灯泡 TIP。
- **1024×1366 & 768×1024（平板）**：上半自然收束为全宽等比取景画布，紧接横排紧凑原则状态带与双栏齐底诊单/景别条，零空洞。
- **390×844（手机竖屏）**：压紧单行刊头与大标，借 `order` 将总述与原则长文后置，让等比取景画布稳占首屏 ≥ 46% 屏高，折线内紧贴诊单首句与五档景别快切格，确保圆月与圆徽绝不被压成椭圆。
- **844×390（手机横屏）**：切为左 `56%` 等比取景画布 × 右 `44%` 精简刊头、诊单首句与景别快切并行。
- **正文七节色彩节奏**：`01 暖月米纸 #F7F0E2` → `02 浅青雾纸 #EBF1EE` → `03 深松青暗房 #033D3B` → `04 象牙暖纸 #FAF5EA` → `05 软玉砂纸 #EFE9DB` → `06 墨青考场 #092625` → `07 深松青原海报展墙 #024D4B` + 墨黑页脚 `#081C1B`。

## 5. 节目录（共 7 节，每节 h2 ≤ 12 字，相邻控件绝不重复）
1. **01 · 为什么一个人更难拍** (`THE ANATOMY OF A SINGLE`)：逐条引出并拆解海报五项原则，附「五维力场拆解切换卡」+ 同小类 [302 双人构图](https://layout.xiaoxiaodong.ai/302/play/)、[303 三人构图](https://layout.xiaoxiaodong.ai/303/play/)、[304 群像构图](https://layout.xiaoxiaodong.ai/304/play/) 一句话导航。
2. **02 · 从浪漫独影到银幕语法** (`WHERE IT COMES FROM`)：以 5 个已核实年代节点梳理单人构图从浪漫主义背影画到格式塔心理学与片场语法的演进，配「年代结构图谱步进器」。
3. **03 · 五档景别的情绪标尺** (`SHOT SCALE & EMOTION`)：结合海报底部的五档景别参考，温和修正「留白永远 ≥ 主体」在特写镜头里的边界；配独立「人体关节裁切标尺台」（直接在全身剪影上点选或上下拖动底框裁切线，即时对照右侧取景成片与禁切关节警告）。
4. **04 · 光影、反差与背景减法** (`FIGURE-GROUND ISOLATION`)：拆解「光影与色彩服务于主体」，配「四维分离开关灯棚」（明暗反差 / 景深虚化 / 色温隔离 / 环境减法 4 组片场独立开关，无滑块），实时评估第一眼锁焦清晰度。
5. **05 · 什么时候别用单人构图** (`WHEN NOT TO USE IT`)：4 类典型失效场景与反例对照翻页器（对话博弈→302/309、群体规模→303/304、复杂信息图、连镜审美疲劳）。
6. **06 · 挑出最稳的那一镜** (`FRAMING QUIZ`)：两道渐进单变量银幕选镜小测，选项标签严格中性（镜头 A/B/C/D），四幅剪影画只差一个变量，选后逐项解析。
7. **07 · 原海报与速记卡片** (`ORIGINAL POSTER & KEYWORDS`)：嵌入 `<img id="poster" src="poster.webp">` 支持点击放大、拖动（`draggable="false"`）与 Esc 关闭，并列海报五条要点速记与五档景别关键词及单行页脚。

## 7. 练习设计
- **第 1 题（水平落位与视线空间）**：海堤独行剪影面朝右侧，景别/光影/头顶留白完全一致，四选一仅变主体 X 坐标：A（82% 撞右墙）/ B（50% 正中均分）/ C（34% 左三分右留大空，**正确**）/ D（12% 挤贴左框）。
- **第 2 题（垂直裁切与关节避切）**：室内静候人物中近景过渡，水平落位与光影完全一致，四选一仅变垂向构图裁切：A（底框正切膝关节）/ B（头顶紧撞上沿削顶）/ C（胸上避开颈肩关节且头顶留白约 12%，**正确**）/ D（头沉至画框下半部形成过半空顶）。
