# 056 四象限构图（FOUR-QUADRANT COMPOSITION）互动页方案

## 1. 一句话道理
以画面中心交点为锚，用横竖两道轴线把平面切出四个秩序清晰的功能象限，再借**对角体量配重、形色纹理对比与跨象限呼应**，让静态十字格从「死板表格」升级为稳而不僵、有序又有张力的视觉结构。

## 2. 开场玩具：十字轴四象限编排台（Cross-Axis Quadrant Board）
- **原生动作（无法套用到其他编号）**：
  1. **推拉十字轴心交点**：横拖画布空白处或直接拖动双环轴心圆核 `(ax, ay)`，实时改变四个象限的面积分配与力矩支点（支持触屏 `touch-action: pan-y`，竖滑翻页、横拖流畅滑轴）。
  2. **四象限模块直拖归位**：直接拖动画布内四个几何/编辑模块，将其从越界串区拖回各自象限，或在四象限间换位配重。
  3. **点击模块雕刻对比**：单击任意象限模块切换其造型（实方 / 陶土四分之一弧 / 实心圆 / 松绿竖纹 / 点阵）与明度体量，建立大小、色彩、肌理梯次。
  4. **点切跨象限呼应桥**：点击轴心圆核旁的呼应开关（或下方按钮），切换「孤岛断联 / 对角回声 / 顺时针导引 / 杂乱交叉」，按 `Space` 发射视觉流光点按实测权重巡航验真。
  5. **三套实景标本**：`原海报·几何构成`（1:1 承袭 056 原海报松绿方/陶土弧/圆/点阵/条纹）、`编辑部·四格专刊`、`策略盘·2×2 矩阵`。
- **开场坏态（0/4，绝非答案）**：
  - 轴心偏塌至 `(65%, 62%)`，Q1 膨胀到 40% 而 Q4 被压成 13% 窄角；
  - 两个深松绿重块全堆在左侧，视觉重心大幅左倾；
  - Q2 模块物理横跨竖轴越界串区；
  - 四格清一色同尺寸方块，对比平坦且零呼应桥（孤岛断联）。
- **双向可玩错（model.js 单真源检出 9 类错态）**：
  `越界串区`、`空区挤堆`、`轴心偏塌`、`重心倾覆（精确报左/右/上/下方向）`、`轴心压死`、`均质死水（对比过弱）`、`巨块吞场（对比过激）`、`孤岛断联（零呼应）`、`杂乱交叉（过度连线噪点）`。
- **认可多组合法解（均达 4/4）**：`原海报经典解`、`对角张力解`、`主次专刊解`，以及用户手调满足四项单真源物理条件的一切组合。
- **读数讲「为什么」**：所有重心偏移、象限面积占比、权重极差、越界检测均由 `model.js` 从实绘包围盒与轴坐标一次算出；白话诊单直接说明「这样摆眼睛会怎么走、为什么会失稳/散架」，抽象感知量标明「示意」。
- **与近 12 页差异**：不撞 308 剪影清场、222 单列文档流、141 排印字阶、089 石碑水平仪、177 右轴配重、053 向心楔形、341 空白幻灯片、176 排字修边、307 3D 远距广场、221 旁注排字盘、052 星尘光爆、140 大气裁切；本页独有「横竖双轴切分 + 四象限模块跨区配重/形色雕刻/对角呼应」原生操作。

## 3. 版式骨架（1:1 转译 056 原海报建筑展板）
- **1440×900（主宽 1380px，2560 舒展至 1660px，绝不锁 100svh）**：
  - 顶沿紧凑自示范刊头：左侧黑体大标「四象限构图」+ 陶土短杠 + 英文副标，右侧无缝咬合 056 原海报招牌「右上深松绿四分之一巨弧 + 三道同心米白细弧 + 跨弧双色反相点阵」并内嵌标本切换与巡航键。
  - 首屏核心双区齐底：左 57% 开放式十字轴四象限编排画布（标 `data-perf-drag`）× 右 43% **1:1 复刻原海报细十字线与中心双环圆核的 2×2 活体探针矩阵**（四格实时亮显平衡稳定/分区组织/对比变化/关联呼应实测值，紧底配精控微调条，两栏严格齐底无空洞）。
  - 首屏底带 **1:1 复刻原海报标志性左右双分压脚条**：左 52% 深松绿底（`#1B5136`）配米白圆底灯泡图标与单真源白话诊单 + 校准/复原双键 × 右 48% 暖米纸配原海报四枚实心圆彩徽（松绿天平/陶土四格/松绿半月对比/燕麦链环）与多解/试错快选。
- **1024×1366 / 768×1024 平板**：自然流排布，不锁视口高，满宽画布 → 2×2 十字探针 → 深松绿诊单与四圆徽，零大片空白。
- **390×844 手机竖屏**：单行压紧刊头 + 标本切签（~92px），紧接等比近方画布（占首屏 ≥ 46% 屏高，圆形严格等比不压扁），折线内直露深松绿灯泡诊单首句、一键校准与巡航键；2×2 探针与精细调轨顺流置后。
- **844×390 手机横屏**：左 54% 满高画布 × 右 46% 紧致刊头、诊单与核心按钮并行，无横向溢出。

## 7. 练习设计
共 3 道单变量可视化选择题，选项均为纯中性 `方案 A / B / C / D`（无暗示好坏的标签）：
- **第 1 题（唯一变量：四象限体量与色彩对比）**：其余条件一致，仅变体量极差——A 均等死水、B 巨块吞场、C 梯次对比且对角稳（正解）、D 三格几近全空。
- **第 2 题（唯一变量：跨象限呼应与边界组织）**：A 四色割裂背离、B 对角回声与指向轴心呼应（正解）、C 元素越界压死中轴、D 缩至最远四角留出冷沟。
- **第 3 题（唯一变量：视觉重心与轴心落位）**：A 左侧堆重倾覆、B 对角配重稳咬中心圆核（正解）、C 顶部双压失重上浮、D 十字轴推至右缘 82% 挤扁右半。
