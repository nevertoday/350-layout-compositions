# 291 大体 流动模式（MACRO FLOW PATTERN）设计方案

## 1. 一句话道理
在中小屏上让内容块顺着屏幕宽度弹性流排并在窄屏收成单列，到了大屏则锁住内容最大宽、把多余空间交给两侧外边距——对容器是 **Mostly Fluid（大体流式）**，对视线则是顺畅不断裂的 **Macro Flow（引导 → 过渡 → 聚焦 → 延展输出）**。

## 2. 开场玩具：双镜联动 · 宏观流道视口拉阔台
- **怎么玩**：
  - **直接横拖活体视口（`data-perf-drag`，触屏 `touch-action: pan-y`）**：在 320px（手机）到 1680px（超大屏）之间连续拉动视口宽度，同时在顶部标尺上实时看见左侧/右侧「外边距缓冲带（Outer Margins）」如何出现与扩张，视口内部同步真实排布四块活体内容（引导 / 过渡 / 聚焦 / 延展输出），并在四块重心之间实时绘出 291 原海报的「皇家蓝 → 朱橘橙双轨 S 形流动带 + 右下输出支流」。
  - **直接点击画布里的区块或底沿四阶胶囊调整流序**：任意点选两块即可互换顺位，或点击画布上的红框告警标就地纠偏。
  - **调校 Mostly Fluid 三阀**：容器锁宽上限 `max-width`（无上限 / 560px 过窄 / 960px / 1120px / 1280px）、单列堆叠断点 `stackAt`（不堆叠 / 560px / 640px / 768px / 1100px 过早坍塌）、体量节奏（均分平铺 / 原海报主次流 / 紧凑出版流），并支持三套真实站点内容题材切换（原海报四阶段叙事 / 独立设计周刊 / 硬件新品发布页）。
- **开场初始状态（绝不先给答案）**：开场停在 `0/4 · 流动失控` 的四重错态：
  1. `max-width: none`（1440px 大屏全宽裸奔，外边距 0px，单行高达 ~94 字符，拉断节奏）；
  2. `stackAt: 0`（窄屏死守多列不堆叠，360px 检验下最小列宽跌至 152px 挤碎折行）；
  3. 宏观流序错置（把「延展与输出」塞在第一顺位，把「聚焦」埋在末尾，画布中 S 形流带折返打结出红色逆折线）；
  4. 节奏均分（四块等重平分，缺少主次与焦点峰）。
- **怎样算玩错 & 错了读数怎么说**：
  - 所有读数（宽屏外边距像素、单行估算字数、360px 窄屏最小列宽、768px 平板列数、流序折返角）全部由 `model.js` 基于同一套真实容器几何求解器计算，绝无写死常量：
    - 无锁宽或锁宽 >1360px → 报「大屏全宽拉扁：外边距归零，单行过长」；
    - 锁宽过窄（<640px）→ 报「大屏过窄孤岛：桌面端沦为细长手机条」；
    - 窄屏不堆叠（stackAt < 420px）→ 报「窄屏硬挤多列：360px 违反单向重排」；
    - 过早坍塌（stackAt > 1000px）→ 报「中屏过早塌单列：平板与小笔电浪费横向空间」；
    - 流序逆折 → 报「路径折返打结：未先引导过渡就强行索取输出」；
    - 均分平铺 → 报「四块等重无峰：缺少聚焦记忆点」。
  - 接受**多组合法解**：如原海报经典解（max 1120 / 堆叠 640 / 主次阶梯流）、紧凑阅读解（max 960 / 堆叠 600）、宽屏出版解（max 1240 / 堆叠 720）。
- **和最近 12 页的明显区别**：
  - 放弃「左画布右诊单侧栏」「深色指挥舱」「双室对比图版」「档案夹叠层」等近期套路；直接承袭 291 原海报的**暖奶油纸面 + 顶部左斜 -9° 超粗大标与朱橘弧尾迹 + 中央全宽活体视口拉阔流道 + 底部原海报四阶条与细黑十字单真源诊单**；玩法是真正拖动屏幕宽窄去检验响应式容器规则与宏观视线流路。

## 3. 版式骨架
- **1440×900**：不锁 `100svh`。主宽 `1360px`（**2560×1440** 下舒展至 `1720px`）。顶一行极细眉线 → 非对称斜标刊头（左斜跃大标+橙弧尾迹，右原海报三行总述与三题材切）→ 全宽活体流道画布（高 ~420px，带对称外边距标尺与蓝橙 S 流带）→ 紧贴四阶流序互换轨 → 双联底座（左三阀装调与多解/试错快钮，右原海报黑十字单真源诊单与实测四格）。
- **1024×1366 / 768×1024 平板**：自然流排，零大片空洞；768 下底座自动折成上下单列。
- **390×844 手机竖屏**：极度压紧顶眉与单行斜标，将原海报三行总述后置到画布之后，让等比活体画布高度 ≥ 395px（稳占首屏 ≥ 46%）并在首屏底沿直见诊单首句与实测结论。
- **844×390 手机横屏**：切为左 57% 活体画布 × 右 43% 紧凑标题与诊单首句并行，一屏见全貌且零横向溢出。

## 7. 小练习设计
- **题干**：内容型产品发布页在手机和平板端顺畅，但在 1920px 台式机大屏上一行字过长、图被拉虚；下列四套容器规则仅在「大屏宽度与排布约束」这一变量上不同，哪一套符合大体流动模式？
- **选项（标签仅写 A/B/C/D + 中性规则描述 + 同源 SVG 缩略图）**：
  - A：保留中小屏流式断点，容器设 `max-width: 1120px` 并居中对称留白（正确）
  - B：去掉流式百分比，将整站外层写死 `width: 1120px`（错：中小屏横向溢出）
  - C：保持不限最大宽，将 1920px 桌面端拆成 6 列等宽小格铺满（错：破坏四段节奏，均分零碎）
  - D：保持不限最大宽，将 1920px 桌面端也统一压成 560px 单列（错：浪费中大屏横向并行空间）
