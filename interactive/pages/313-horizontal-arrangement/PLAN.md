# 313 横向调度（HORIZONTAL ARRANGEMENT）设计方案

## 1. 一句话道理
横向调度不是把人或元素随便横排成一列，而是借一条稳定的水平轴线拉开宽幅视野，再用一致的视线朝向与疏密呼吸节奏，引导观众从一端自然扫向另一端，在开阔与安定中讲清连续关系。

## 2. 开场玩具：宽银幕横向推轨剪辑台 × 水平视流编排带
- **怎么玩**：
  - 通栏 2.39:1 宽银幕剧场中立有 4 组零五官剪影/海报色块节点（起程者·琥珀金、驻足者·暖沙、同行者·钢蓝、终站守门人·炭墨），沿宽银幕水平地平带铺展；
  - 既可在画布内直接横向拖拽 4 个节点调整落点与高度、点击单个节点翻转朝向（← / →），也可拖动底沿通栏「横向机位推轨滑轨」（标 `data-perf-drag`）让镜头沿 2.4 倍宽的走廊长卷平滑横移（三层视差：远景地平带、中景建筑格栅、前景标尺与视流光带同步重绘）；
  - 可切换画幅（`4:3 窄框` / `16:9 标准` / `2.39:1 宽银幕`）观察画幅对横向延展的决定作用，可切换表现壳（`片场剪影` / `海报色带`）验证影视镜头与 313 原海报的几何同构，也可一键体验「晾衣绳均分」反例或复原错态，并支持键盘方向键与 Tab 操作。
- **开场状态（0/4 错态，绝不先给答案）**：
  - 4 个节点全部缩挤在中右 34% 的窄带里（两侧大片空虚死区）；
  - 第 1、3 号角色逆向左看，视线在画内左右对撞；
  - 4 个角色重心上下剧烈跳脱（偏离共享水平基准带），失去地平稳定感；
  - 间距出现局部粘连且毫无宽幅呼吸感。
- **怎样算玩错、读数说什么「为什么」**（全部由 `model.js` 单一坐标真源实算，绝不硬编码）：
  1. **展幅塌缩 / 贴边 / 窄幅裁切**（横向展开）：总跨度 < 56% 报「缩成一团，宽银幕两侧空成死区」；> 88% 报「贴死画框边缘，视线还没停稳就滑出去了」；切 4:3 时报「窄框切掉了横向展开的余地」。
  2. **朝向对撞 / 视线冲出画外**（视线引导）：主朝向互相冲突时标出对撞区间并解释「眼睛刚要往右走就被迎面目光顶回来了」；最末位死盯右边框且离边太近时提示「末尾没有回望收口或前导留白，视线会顺着右框滑出去」。
  3. **上下脱轴 / 左右偏倾**（水平稳态）：纵坐标极差超阈值时画出红虚线脱轴标尺，说明「高低剧烈跳动把水平基准线撕碎了」；质量力矩偏心超 ±14% 时报重心倾向哪侧。
  4. **粘连撞叠 / 断链 / 晾衣绳均分陷阱**（宽幅节奏）：间距过小报粘连、过大报断链；**若用户把 4 人排成机械 1:1:1 等距，专门点名触发「晾衣绳均分陷阱」**，解释宽幅调度必须保留疏密分组才不会死板，逼着用户真正调出呼吸感而非机械排排站。
- **与最近 12 页的区别**：
  - 312 是左取景框+右俯视蓝图+环轨绕拍拼三角形；311 是正拍归正游标+四向虚线重心桌；310 是 Three.js 纵深 Z 轴三层景片；023 是斜轨倾角配重；145/272/228 是多面板/便当盒/CSS 子网格；105 是双联中缝天平；060 是斜瀑卡片叠压；190/189 是文字造型。
  - 313 首创「通栏宽银幕横向推轨长卷 + 节点水平落点/朝向/地平轴/疏密节奏四维联测」，直接承接横向调度的「水平横移、宽幅节奏、视线流动」本源动作，无法原样套用到任何其他编号。

## 5. 节目录（8 节，每节标题 ≤ 12 字，相邻两节控件不重复）
- **01 先拉出一条地平线**（`ESTABLISH THE HORIZON`）：拆解「横向展开」并温和修正前提；交互：**对称画幅遮幅拉帘**（1.33:1 → 1.85:1 → 2.35:1 → 2.55:1 实时对比横向视野）。
- **02 为什么不是「晾衣绳」**（`BEYOND THE CLOTHESLINE`）：拆解「宽幅节奏」与波德维尔「晾衣绳调度」误区；交互：**12 格水平音序节奏编排槽**（点选拍点实时绘制疏密波形与群像关系）。
- **03 视线如何沿横轴流动**（`LATERAL SIGHTLINES & FLOW`）：拆解「视线引导」、温和提醒左右方向语境、讲清前导空间与末位回望；交互：**单点人物朝向与目光锥切换器**。
- **04 从手卷到宽银幕**（`FROM HANDSCROLLS TO CINEMASCOPE`）：「从哪来」历史谱系（巴约挂毯、清明上河图、1953 CinemaScope《圣袍千秋》、1963 黑泽明《天国与地狱》）；交互：**容器内横向长卷展阅带 + 等比画幅尺度标尺**。
- **05 同一场戏，五种调度法**（`FIVE STAGING APPROACHES`）：横向调度与同小类 310/311/312/314 的清晰边界（各附一句话在线链接）；交互：**五枚几何结构透视切换卡**。
- **06 什么时候用，什么时候别用**（`WHEN TO USE — AND AVOID`）：适用场景与三大禁用边界（强压迫/竖屏硬裁/高速混乱打斗）；交互：**2.39:1 宽银幕 vs 9:16 竖屏硬裁崩坏对照开关**。
- **07 小练习：挑出最顺眼的一场**（`PRACTICE: PICK THE BEST FRAME`）：四选一辨析练习（见第 7 项）；交互：**四图选定后同步显影水平基线、间距尺与目光箭**。
- **08 原海报与关键词**（`THE ORIGINAL POSTER`）：高清原海报灯箱（点击放大、拖动、`draggable="false"`、Esc 关）+ 原海报 4 枚几何关键词徽标与用法要点。

## 7. 练习设计
- **题目**：同一场「四人海滨长廊宽银幕戏」，哪种横向调度站位最顺眼？（四个选项标签仅标 `A` / `B` / `C` / `D`，绝不泄露好坏）。
- **四选项只差一个核心变量**：
  - `A`：跨度、地平线与朝向均正确，**唯一差异：四人等距 1:1:1 排成「晾衣绳」**，缺少疏密分组节奏；
  - `B`（正确）：跨度 74% 留出左右余地、共享水平基准带、**2+1+1 有疏密呼吸分组**、前三向右流动且最右者微向左回望收住视线；
  - `C`：跨度、地平线与疏密分组同 B，**唯一差异：朝向混乱对撞**（左端看画外、中段背对背）；
  - `D`：跨度、朝向与疏密分组同 B，**唯一差异：重心高低剧烈脱轴**（锯齿状上下跳动破坏地平稳态）。
- **选后解析**：显影四张图的隐藏水平轴、间距尺与视线箭头，逐一说明所选项错在哪个变量以及 B 为何最连贯稳妥。
