01

先定正面，再拉斜深

Structure & Direction

  • 正面保持真实，作为视觉基准。
  • 深度沿斜线延展，方向一致。
  • 强化结构与空间，提升画面表现力。

斜投影能一口气把平面排版变成三维体块，靠的不是复杂的光学计算，而是极简的两步分工：先画一个一毫不差的正面，再把所有深度沿着互相平行的斜线向后拉出。

相比 069 线性透视 与 073 平行透视构图 里向远方不断收拢的消失点，斜投影把「投射线」设成一束永远平行的斜光——物体无论放得多靠后，正面大小都分毫不缩，正圆也永远是正圆。

补一句关键

原海报在斜角旁标了「约 45° / ABOUT 45°」。其实 45° 只是顺手画图的习惯角，并不是硬规矩：30°、45°、60° 甚至向左上方延展（135°）都同样成立。真正决定斜投影成败的，是同一张画面里所有斜线必须严格平行，以及下一节要讲的进深缩放比 k。

02

骑士与橱柜：
进深缩一半

Cavalier vs. Cabinet

国际制图标准 ISO 5456-3:1996 把最常用的两种斜投影分成 1:1 骑士投影与 1:2 橱柜投影。

按真实尺寸画一个立方体，把斜向进深也画成 1:1（称为骑士投影 Cavalier），眼睛却会一口咬定它「太长了，像块长方砖」。

原因出在我们的视觉习惯：在真实世界里，背离视线的边会因为透视和倾斜而变短；斜投影取消了近大远小，如果再把斜边画成全长，大脑就会把多余的长度错读成额外深度。于是 19 世纪家具制图师干脆把进深砍去一半（k = 0.50，投射线与画面约成 63.4°），这就是橱柜投影（Cabinet）——尺寸不再直接 1:1，体量反而一下子顺眼了。

除了把竖直立面摆正的立面斜投影，建筑师（如程大锦《建筑画法》中所分）还常用平面斜投影：让建筑的 90° 平面图正对画纸，再垂直拉出墙高，鸟瞰空间一目了然。

03

同一块体，换套投影看

Oblique vs. Siblings

同小类里还有前中后景、透视与轴测等兄弟页，各自擅场，这里只点明分工。

把同一块画着正圆的立方体放进四种投影体系，你会立刻明白为什么斜投影总被拿来做正面展示：它是唯一既不汇聚、又保住正面真圆与 90° 直角的立体画法。

若要三面均等、适合机械总装或沙盘，转向 075 等距构图 或更广义的 076 轴测构图；若要真实镜头的近大远小与街道沉浸感，改用 070 一点透视、071 两点透视 或仰俯宏伟的 072 三点透视；而画面层次还可结合 065 前中后景、066 前景框架、067 重叠空间 与 068 尺度递减 来叠搭。

04

从古卷、堡垒
到波尔克定理

Where It Comes From

东西方工匠、要塞工程师与数学家走过不同路径，却都在「平行斜线」里找到清晰度。

在单点透视统治欧洲绘画之前，平行斜向投影就已经是长卷绘画与军事工兵的实用语言；直到 19 世纪中叶，数学家才为它补上了严谨的定理根基。

北宋《清明上河图》与界画平行斜线

北宋张择端《清明上河图》（故宫博物院藏，纵 24.8 厘米、横 528 厘米）采用中国传统「界画」尺规作画，沿街楼阁、城门与桥梁多以平行斜向退深，没有固定单点消失点。

长卷需要边展边读：如果全卷锁死在一个消失点，画到几米之外建筑就会严重扭曲；平行斜线让观者无论停在哪一尺，屋檐与街面都保持平稳可辨。

18 世纪法军要塞与「骑士投影」得名

「骑士投影（Cavalier projection）」并非指骑马画画，而是取自欧洲筑垒术语 cavalier——筑在城墙内侧、高出主城垣的架炮高台。18 世纪法国军事工程师常以这种高视点画要塞图。

正墙尺寸和 45° 斜退城墙厚度全部维持 1:1，指挥官拿分规直接往图上一卡就能读出射界与墙厚；随后 19 世纪家具作坊为消除拉长错觉，把斜深缩半成「橱柜投影（Cabinet）」。

蒙日奠基与 1853 年波尔克定理

法国数学家加斯帕尔·蒙日（Gaspard Monge，1746–1818）在 1795 年巴黎讲义与 1799 年《画法几何》（Géométrie descriptive）中把投影制图正式建成独立数学学科。

1853 年，柏林画家兼几何教师卡尔·波尔克（Karl Wilhelm Pohlke）提出（1860 年刊于 Darstellende Geometrie），并由赫尔曼·施瓦茨（Hermann Amandus Schwarz）在 1864 年首次严密证明的波尔克定理指出：平面上从同一点出发、不共线的任意三条线段，都一定对应某个立方体三条等长正交棱的平行（斜或正）投影——它从数学上保证了任何斜角和缩深比都是合法的空间投影。

从 1923 年先锋建筑到 ISO 5456-3:1996

1919–1923 年，俄国构成主义者李西茨基（El Lissitzky）的 Proun 系列与风格派杜斯伯格、范·埃斯特伦（1923 年巴黎展）把工程斜投影和平面斜带进现代艺术与海报，刻意摆脱单一固定视点。

1975 年程大锦（Francis D. K. Ching）首版《建筑画法》（Architectural Graphics）系统普及了立面斜与平面斜的画法；1996 年国际标准 ISO 5456-3:1996 则正式将骑士、橱柜与平面斜投影纳入全球通用制图规范。

05

网页里的斜投影：
CSS 切变

Oblique on the Web

无需 3D 引擎，两块 CSS skew() 侧面就能让平面卡片立出硬朗的印刷体量。

斜投影天生适合网页与界面排版：正面保留 transform: none，中文小字与图标维持像素级锐利；只有顶面与侧面两个色块用 CSS skewX() 和 skewY() 沿同一斜角切出厚度。

在真实产品里，这种做法常见于复古杂志风按钮、实体书脊卡片、数据柱体与印刷感展览专题页——所有卡片共享同一个 skew 角度，页面就自带稳定的空间秩序。

06

什么时候别用斜投影

When Not to Use It

斜投影靠「放弃近大远小」换取正面保真。一旦你的画面真正需要的是镜头纵深、三面平等或长距透视，硬套斜投影立刻会显得僵硬甚至反常。

宏大街道与真实镜头感

斜投影没有近大远小，长街尽头的建筑和眼前一样大，大脑会错觉远处建筑「越往后越膨胀」。

需要强烈临场纵深时，改用 070 一点透视、071 两点透视 或 072 三点透视。

三面同等重要的工业件

斜投影天然偏心正面，顶面和侧面都会被缩半压缩；如果侧面同样装满按钮、接口或复杂开槽，信息会挤糊在一起。

三面同样需要清晰展示时，换 075 等距构图 或 076 轴测构图，让三个面平分画面权重。

把最长边朝后硬拉进深

斜向延展会放大视觉长度，如果把列车的车厢、长条展台等长边朝后推，哪怕用了 0.5× 橱柜缩深依然显得笨重拖沓。

制图经验口诀：永远把最复杂、最长的那面摆在正面，只让较短的厚度沿斜线向后退。

多元素各画各的斜向角

斜投影的安定感完全寄托在「全场平行」上。只要左侧图标往右上斜、右侧卡片往左上斜，版面就会立刻撕成两套空间。

排整套海报或信息图前，先定死全页唯一一组 (α, k) 向量，所有体块无一例外共用同一斜率。
