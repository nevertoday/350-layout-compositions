# 074 · 斜投影构图（OBLIQUE PROJECTION）互动页方案

> 所属分类：构图逻辑 / 空间层次与投影  
> 原海报总述：「斜投影是一种将物体的一个面保持真实形状，其余方向沿斜线延展的空间表达方法。」  
> *Use slant to express space and depth.*

---

## 1. 一句话道理

斜投影之所以既能像平面图一样直接量准正面，又能一眼读出立体厚度，是因为它把**「正面保真」与「斜线造深」彻底分工**：平行于画面的正立面（宽高、直角、正圆）一毫米都不变形，其余进深全部沿**同一组互相平行的斜线**向后延展，并通常把进深缩为一半（橱柜投影 `k = 0.50`）来抵消人眼的「斜等测拉长错觉」。

> **对原海报的温和补注（正文 01 节标小签「补一句关键」）**：074 号原海报在斜角处标了「约 45° / ABOUT 45°」。实际制图与排版中，斜投影并不锁死在 45°——30°、45°、60° 甚至向左上延展都完全合法，真正的两条硬底线是：**同一画面内所有斜线必须严格平行**，以及**进深缩放系数 `k` 不能失控**（按 ISO 5456-3:1996，1:1 骑士投影可量尺寸但肉眼显拉长，1:2 橱柜投影才最接近自然体量）。

## 2. 开场玩具：斜向拉深制图台（Oblique Extrusion Drafting Table）

### 怎么玩
- 直接在 074 原海报同款暖米制图纸上展开一块开放式 2D 矢量制图画布（纯 2D Canvas，不依赖 WebGL，零降级割裂），主图直接化用原海报的**朱红正面 + 鼠尾草灰绿斜向体块**，并配一座同台面副方块验证多体平行秩序；可在 **「原海报方块」**、**「真圆表盘收音机」**（用正面正圆刻度盘直证斜投影保真优势）、**「立面书架」** 三套题材间切换。
- **开场停在 `0/3` 破形错态（绝不先给答案）**：
  1. **正面切歪 `+14°`**：朱红正面的 90° 直角被压成 `76° / 104°`，白色十字定位线与收音机圆盘全被压扁成椭圆，违背「正面真实」。
  2. **斜向进深拉爆 `k = 1.35×` 且斜角过扁 `18°`**：鼠尾草绿后体拉成又扁又长的隧道梁，顶面挤成窄条，违背视觉体量秩序。
  3. **副体斜线偏航 `-28°`**：旁边的副方块往另一个方向伸出斜线，两个块体彼此撞车、像在画两套互相打架的假透视，违背「方向性：保持平行、方向一致」。
- **三种直觉物理手势（均在画布上直接操作，并配原生键盘滑块与按钮）**：
  1. **拖曳后角矢量手柄 / 画布横拖（`data-perf-drag`）**：直接抓住后顶右角橙点在纸面自由拉动，或横向扫拖画布，实时改变斜投影向量 `(α, k)` —— 角度决定顶面与侧面的露面分配，长度决定进深倍率 `k`（从 0 压扁到 0.50 橱柜、1.00 骑士直至 1.45 隧道畸变）。
  2. **拖曳正面顶棱手柄（或点画布「扳正正面」角标）**：把歪斜的朱红正面扳回 `0°` 严格正交，亲眼看着 `76°` 变回 `90.0°`、压扁的圆盘恢复正圆。
  3. **拖曳或点按副体赤色错轨角标**：把副方块的偏航斜线拉到与主体严格平行（`Δα = 0°`），也可故意扳歪观察「多体斜线打架」或「偷偷汇聚」。
- **怎样算玩错、错了读数怎么说（单真源 `model.js` 实算，绝无假精确）**：
  - `model.js` 仅存几何状态 `{ subject, frontShearDeg, angleDeg, depthRatio, companionOffsetDeg }`，一次 `computeObliqueScene(state, W, H)` 同步产出所有多边形顶点与四项实测读数：
    1. **正面左下内角**：直接由实绘正面四边形底边与左边向量点积算出（`76.0°` → `90.0°`）。
    2. **斜向延展角 α**：直接由主斜向向量 `atan2` 算出（提示 `过扁挤顶 / 自然斜角 / 过陡挤侧 / 坍缩为线`）。
    3. **进深缩放比 k**：实绘斜边长 / 正面边长（区分 `过薄扁平 <0.22`、`橱柜自然 0.38–0.75`、`骑士 1:1 可量略长 0.85–1.05`、`隧道拉爆 >1.05`）。
    4. **多体平行差 Δα**：副体斜向与主体斜向夹角差（`>2°` 即判「方向打架」）。
  - 接受**多组合法解**：经典 45° 橱柜解（`k = 0.50`）、30° 宽侧解（`k = 0.58`）、60° 高顶解（`k = 0.50`）、以及向左上方延展的 135° 镜像橱柜解（`k = 0.50`）；而 1:1 骑士投影明确标为「工程可量 · 肉眼略显拉长」并解释原因。

## 7. 小练习设计（单变量，同一几何函数生成）

- **题目**：下面四组版面里的三块朱红正面完全一致，只在**斜向延展的深度线条**上各差一项。选出最符合斜投影构图规则的一组。
- **选项（只标 `A` / `B` / `C` / `D`，绝不写好坏提示）**：
  - **A**：三块斜线各自偏转不同角度（左上 24°、中块 45°、右块 68°），方向不统一。
  - **B**：三块斜线朝右上方隐约收拢汇聚（夹角逐块收敛 14°），滑进了透视而非平行投影。
  - **C（正确答案）**：三块斜线严格保持 **45° 互相平行**，且统一采用 **0.50× 橱柜缩深**，正面保真、秩序利落。
  - **D**：三块斜线虽保持 45° 平行，但进深拉爆至 **1.35×**，正面方块被拉成细长通道梁，体量明显失真。
- **判题理由**：斜投影成立需同时满足三件事——正面真形、多体斜线平行一致、进深比例贴合人眼体量。A 破了方向一致，B 破了平行原则，D 犯了深度过长失真；唯独 C 三条兼得。
