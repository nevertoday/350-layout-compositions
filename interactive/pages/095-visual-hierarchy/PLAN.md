# 095 视觉层级 VISUAL HIERARCHY · 设计方案

## 1. 一句话道理
视觉层级是给版面上的多组信息排「叫号顺序」：利用前注意特征（字号尺度、明暗与色彩对比、空间留白与位置先后）建立清晰的三级视觉重量断层（主要 / 次要 / 第三层级），让眼睛不靠逐字通读，也能在三秒内按逻辑顺着「核心 → 支撑 → 细节」自然读完。

## 2. 开场玩具：层级叠石调音台 · 眯眼验序（Tiered Hierarchy Sculptor & Squint-Test Curtain）
- **核心动作（专属于 095，无法照搬给别的编号）**：把真实版面中的 5 组信息（主标题、时间/导语摘要、核心入口/视觉块、补充介绍、细则注脚）在原海报标志性的**三阶立体折面层台（主要层级 / 次要层级 / 次要次要层级）**之间升降分配，并直接横拖画布上的**「眯眼模糊滑幕」（Squint-Test Curtain，`data-perf-drag`）**，用真实高斯模糊滤掉字形细节，只留下明暗与体量团块，当场检验观者的第一眼、第二眼、第三眼究竟先落在哪里；按下 `Space` 触发「3 秒初看眼动实测」，按单真源算出的真实显著性顺序依次点亮 ①→②→③ 视线落点；右上角同步联动原海报**四枚叠石层级塔**（石块体量随三层权重实时伸缩，平权或倒挂时叠石失稳）。
- **三套真实语境切换**：`海报 · 秋季展演` / `界面 · 课程卡片` / `资讯 · 简报头版`。
- **一打开是什么状态（绝不给答案）**：刻意停在典型的**「平权乱序 + 注脚倒挂」坏态**：
  1. 核心标题被压在次要层级（字号偏小、权重不足）；
  2. 细则注脚/促销签被错推到主要层级并套上高饱和陶红高亮底块，抢走第 1 眼；
  3. 摘要与介绍段落也被拉到与标题接近的体量（一二级字号差不足 1.3×），全员互抢；
  4. 眯眼模糊滑幕默认停在画面 38% 处，让读者一进页面就从半模糊画面中直观看到「底部的红块比标题还刺眼」。
- **怎样算玩错 & 单真源读数如何说清「为什么」**：
  - `model.js` 从画布实际绘制的 5 个模块几何坐标、实绘字号、字重、与底色的相对亮度对比度（WCAG 亮度比）、暖色强调面积与纵向阅读起位计算每一块的视觉显著性，并据此排出实际 `1→5` 初看顺位，双向检出 **8 类错态**：
    1. `重点倒挂`（细节/注脚反超主标题抢走第 1 眼）；
    2. `主标缺席`（主要层级为空，画面没有视觉入口）；
    3. `主次打架`（主/次字号比 < 1.5× 或显著性断层不足 1.35×，全员同一音量）；
    4. `过度强调`（主要层级塞入 ≥3 块或高亮面积超 26%，触发「全员第一等于没有重点」）；
    5. `三级塌缩`（三层有空层，或次/细两级拉不开差，退化成两层）；
    6. `逆序回跳`（第 1 眼落点在画底、第 2 眼却跳回画顶，违背自上而下的阅读流）；
    7. `挤压失衡`（主层膨胀到挤压次层文字可读性）；
    8. `合法多解`（同时认可「经典三阶解」「视觉主焦解」「黑白克制解」及用户自行排出的任意达标三级秩序，绝不锁死唯一标准答案）。
  - 读数全部使用真实实绘值（如 `主/次字号比 1.2×`、`高亮占比 38%`、`第 1 眼落点：票务注脚`）与定性档位（`重点倒挂` / `主次打架` / `层级清晰（示意）`），拒绝假精确百分数。
- **与最近 12 页的明显区别**：
  - 不用「单画框 + 红色虚线点除标签 + 右侧探测列表 + 底部合法解/试错双排药丸」套路；
  - 区别于 141（单页字阶/行距滑杆排印校样）：095 的核心是把**多块不同语义的信息分进三阶层台**，并通过**物理眯眼模糊滑幕**剥离文字语义、直接用视觉团块验序；
  - 版式直接承袭 095 原海报的「左上暖金日光大圆弧 + 右上四石叠塔 + 左版面眯眼排演台并列右三阶 3D 斜切折面层台 + 底部深炭四栏设计要点带与陶红灯泡结语条」。

## 3. 版式骨架（不锁 100svh，六种视口自洽）
- **1440×900 / 2560×1440**：主宽 `1380px`（2560 舒展至 `1660px`）。
  - 顶部刊头直接转译 095 原海报上段：左 60% 暖金大圆弧承托 `◉ NO. 095`、`视觉层级`（900 特粗黑）、`VISUAL HIERARCHY`（陶红宽字距 Archivo）与短黑横杠总述；右 40% 暖米纸配 4×4 点阵、活体四石叠塔与三语境切换键。
  - 中段核心舞台严丝齐底左右咬合：左 52% 为无厚黑框的活体版面与眯眼模糊滑幕画布（`<canvas data-perf-drag>`），下方紧贴极简眯眼进度条与 3 秒扫读/预设快键；右 48% 1:1 转译原海报「三阶 3D 斜切折面层台」（炭黑主层 / 陶红次层 / 橄榄灰第三层），直接作为信息块升降分拣舱、级差调节与实时微型线框预览。
  - 底段紧接原海报标志性的深炭黑四栏「设计要点」实时读数带（阅读顺序 / 视觉显著性 / 扫视路径 / 适度强调）+ 陶红底米白灯泡单真源诊断结语条。
- **1024×1366 / 768×1024 平板**：自然文档流，绝不锁 `100svh`。顶部暖金圆弧刊头收紧 → 满宽等比眯眼排演画布 → 下接三阶折面层台 → 2×2 深炭设计要点卡 + 陶红诊单条。
- **390×844 手机竖屏**：极简单行暖金刊头（省去长总述与叠石，移到交互区下方），让接近正方形的等比高清晰度眯眼画布稳占首屏 ≥ 46% 高度；折线内紧接陶红单真源诊断首句、眯眼滑块与「3 秒扫读 / 校准三阶」双键，随后自然展开三阶折面层台。
- **844×390 手机横屏**：切为左 54% 等比眯眼画布 × 右 46% 紧凑刊头、诊单与核心快捷操控并行，一屏可玩。

## 4. 配色与字体（逐像素实采自 `site/public/p/095.webp`）

  - 暖米宣纸底：`#F9EDD5` / 亮象牙 `#FCF5E8` / 浅杏暖纸 `#F8E3CC` / 暖橄榄石纸 `#EDE5D3`
  - 招牌暖日光金：`#EFB231` / `#EDAE2D`（浅底高对比深琥珀文字 `#7D5600`，暗底亮金 `#F5C14B`）
  - 招牌陶土朱红：`#E1643C` / `#DB5A36` / 折面暗面 `#BB4C2D`（浅纸高对比深陶字 `#9F3514`，暗底亮陶 `#FF8A65`）
  - 招牌暖橄榄灰（第三层级）：`#686C64` / 折面暗面 `#52564E`（浅底安全深橄榄文字 `#454942`）
  - 招牌炭黑与暗室：`#191B1D` / `#212526` / 深炭带 `#11120D` / 暗舱 `#1D2021` / 主墨 `#1A1818`
  - 语义校验色：克制用深松青（`#1E6B52` 浅底 / `#6CE0B6` 暗底）标通过态，用深绯警报红标层级冲突。
- **字体搭配（全库 0 重复，三款非中文字体近 12 页全部 0 次使用）**：
  - `Noto Sans SC`（weights `400, 500, 700, 900`）：中文三级字重示范（900 主标 / 700 次标 / 400 正文与细节）。
  - `Archivo`（weights `500, 700, 800`，**近 12 页 0 次使用**）：厚实报刊几何无衬线，用于 `VISUAL HIERARCHY`、`PRIMARY / SECONDARY / TERTIARY` 与阶梯编号签。
  - `Fraunces`（weights `400, 700` 正斜体，固定 `opsz: 72, SOFT: 40, WONK: 0`，**近 12 页 0 次使用**）：富有温润编辑气质的高对比衬线，用于 01–07 章节大编号与经典引文/标本演示。
  - `DM Mono`（weights `400, 500`，**近 12 页 0 次使用**）：柔和精准的等宽字体，用于实时字号比、占比与眼动耗时读数。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻两节零控件复用）
- **01 `三级阶梯怎么分`**（Three Tiers of Importance）：拆解原海报主要/次要/次要次要层级（温和注明 Tertiary 在日常排版的通称），附**SVG 阶梯剥离解剖台**（点击独奏/剥离任意一级，观察原海报同款微型线框结构变化）。
- **02 `一眼抓人的六个杠杆`**（Six Levers of Saliency）：结合特里斯曼与格拉德（1980）特征整合理论讲前注意跳出效应，附**6×5 叠石前注意「跳出」计时小测**（亲手对比单一杠杆秒找 vs 多属性组合干扰慢找的真实毫秒耗时），并一句话链接同小类 096、099–103、106。
- **03 `F 与 Z 扫视的真相`**（Scan Paths: F, Z & Layer-Cake，深炭暗室）：拆解阅读顺序与扫视路径，温和纠偏原海报「符合 F/Z 型扫视习惯」的说法（引 NN/g 2006 与 2017 复核：F 型是缺少层级时的无奈捷径，好层级应引导「千层糕式」扫视），附**2D Canvas 模拟眼动热力与时间轴推演台**。
- **04 `从朱书抄本到瑞士网格`**（Where It Came From）：梳理中世纪朱书抄本 → 19 世纪大报多级标题 → 1928 奇肖尔德《新字体排印》→ 1967 鲁德尔《字体排印设计手册》→ 1980 特征整合理论与 2004 勒普顿《字体的思考》脉络，附**四时代同文重排标本切换器**。
- **05 `什么时候别拉太开`**（When Not to Force Hierarchy）：讲「适度强调」边界与真正需要刻意平权的场合（法务条款、沉浸长小说、客观并列对比表、漫游画册），附**「强调通胀」叠加勾选压力计**与协议/长文对照切换，一句话链接 097、105。
- **06 `小练习：挑出层级最稳的一版`**（Practice: Spot the Cleanest Hierarchy，深炭考场）：两道单变量四选一 SVG 实体卡片题（选项只标 `方案 A / B / C / D` 与中性排布说明，绝不剧透好坏），作答后四卡同步叠显 ①→②→③ 初看顺位并给出解析。
- **07 `海报原稿`**（Original Poster）：可点击放大/拖拽/Esc 关闭的 095 原海报、原海报结语与要点索引、同小类 096–106 一句话直链，以及标准页脚。

## 7. 练习设计
- **题 1（展览卡片三级层级）**：同一张「秋季陶艺展」信息卡，四个方案共享完全相同的文案、配色、留白与左对齐骨架，**唯一变量是三级视觉重量分配**：
  - `方案 A`：主标题大而沉、日期地点退居中等陶红次层、入场须知收为小号橄榄灰底座（正确：三阶步距清楚、强调 克制）；
  - `方案 B`：主标与副标字号接近且同用深黑粗块（错因：一二级权重打平、主次粘连）；
  - `方案 C`：主标够大，但底部「免费预约」标牌套上醒目陶红大色块与粗框（错因：细则反客为主、重点倒挂）；
  - `方案 D`：标题、副标、展期、导览条全部加上暖金/陶红高亮条（错因：过度强调、全员第一等于没有重点）。
- **题 2（长文导读的扫视秩序）**：同一段四节图文导读，四个方案共享相同栏宽与正文体量，**唯一变量是小标题与段落的层级信号**：
  - `方案 A`：连续无分段大段灰字，仅首句加粗（错因：逼出 F 型扫视，下半段大面积漏读）；
  - `方案 B`：每节独立清晰小标题 + 适度段前距，正文保持舒缓灰阶（正确：形成千层糕式扫视，读者可直达关心小节）；
  - `方案 C`：小标题与正文同字号同字重，只把小标题改成浅暖灰（错因：反层级，小标题反而更看不清）；
  - `方案 D`：每节正文中随机标红五个词，小标题却无留白（错因：散点高光割裂视线，干扰连贯扫读）。
