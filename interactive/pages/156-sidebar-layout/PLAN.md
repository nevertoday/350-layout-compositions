# 156 侧栏版式（SIDEBAR LAYOUT）互动页设计方案

## 1. 一句话道理
侧栏版式不是「把页面劈成两块」，而是用一条克制而清晰的专属边道承接导航、注释与延伸支持，把主内容从杂讯里解放出来，让视线一眼锁定主角，又能随时余光取用辅助信息而不打断主线阅读。

## 2. 开场玩具：活体分栏裁切台（Live Sidebar Sash & Hierarchy Workbench）
- **怎么玩**：
  - 在 2D Canvas 活体出版跨页（`data-perf-drag`）上直接横向拖动中间的**竖向分栏分割刃**，实时裁切主内容区与侧栏比例（侧栏 12%–66%，靠近 32% 原海报线与 26% 舒展线时轻微吸附），同步改变主文行宽、插图尺幅与侧栏排版状态。
  - **直接点击画布里的红框错置块**：把误塞进侧栏的核心主图解挪回主区，或清掉混进侧栏的促销噪点挂件。
  - 切换三套真实题材（原海报山日画册 / 技术文档 / 深度专栏）、左右边位（左侧栏 / 右侧栏）、四档对比体系、侧栏模块密度与 390px 移动端退场策略，也可一键开启「主次视线流」叠层。
- **开场状态（0/4 待理分栏错态，绝非答案）**：
  - 侧栏膨胀到 **54%**（主区仅剩 46%，喧宾夺主，主文被压成碎短行）；
  - 核心主图解被误塞进侧栏，且侧栏堆满 **6 个杂乱挂件（含 2 条促销噪点）**；
  - 对比设为「高饱和亮橘喧哗抢戏」，视觉刺激压过主文；
  - 移动端设为「390px 硬并排挤扁」，底沿实时 390px 预览条标红告警主文仅剩 ~179px。
- **怎么算玩错与诊单怎么说「为什么」**：
  - 单真源 `model.js` 从实绘几何直接核出 **8 类典型失误**：① 侧栏喧宾夺主（>36%）、② 侧栏过窄窒息（<20%，标签竖折断字）、③ 主核心错塞侧栏、④ 侧栏杂货铺过载（>4 组或夹带噪点）、⑤ 空栏占道浪费（<2 组却白占宽度）、⑥ 侧栏亮色抢戏、⑦ 同底无界糊成一团、⑧ 窄屏硬挤溢出或粗暴 `display: none` 丢信息（违背 WCAG 1.4.10）。
  - 接受**多组合法解**：原海报 68:32 深靛抽屉解、文档 75:25 柔纸堆叠解，以及任意满足四维条件（侧栏宽 20%–36% 经验参考带、核心归主区且侧栏 2–4 组无噪点、深靛或柔雾细线分界、抽屉折叠或流式下沉）的自调解。
- **与近期 12 页的差异**：
  - 155 是从暗袋抽拉黄色插页卡、199 是推赛璐珞复合网格描纸、282 是拖地图锚点与卡片、238 是调居中固定容器宽度、115 是混排几何标本、031 是开合红楔剪刀角；156 独有动作是**实时裁切主区与侧栏的权力边界、把跨界模块挪回各自阵营，并把页面开场本身做成 156 原海报的 68%:32% 真实侧栏结构**，别的编号无法套用。

## 3. 版式骨架
- **1440×900（桌面）与 2560×1440（超宽）**：忠实承袭 156 原海报「左 68% 暖燕麦纸主展面 × 右 32% 深普鲁士靛全高实色侧栏」双栏出版骨架（主容器宽 1380px，2560 舒展至 1760px，零通用深色仪表盘卡感、不锁 `min-height: 100svh`）。左主区排自示范比例大标「侧栏版式」、总述、题材与快控条、大尺寸活体分栏裁切画布与四维调律卡；右深靛全高侧栏直接承接原海报 5 枚灰蓝圆徽「侧栏功能」实时状态灯、斜贴橘色纸胶带的撕边米纸单真源诊单便签与底沿 5 枚圆角关键词胶囊，两栏底缘均衡对齐无单边空洞。
- **1024×1366 / 768×1024（竖屏平板）**：自然转排为上全宽暖纸裁切台 + 下深靛横向诊断功能带，不锁视口高，零大片空白。
- **390×844（手机竖屏）**：践行原海报「移动端可折叠或隐藏，按需呈现」——单行极简顶眉与紧凑刊头下，活体分栏画布稳占首屏 ≥46% 屏高，紧接撕边纸条诊单首句与快控按钮；深靛五项功能灯折入下方清晰面板。
- **844×390（手机横屏）**：切为左 57% 活体分栏画布 × 右 43% 紧凑刊头、撕边诊单与快控并行。

## 4. 配色和字体
- **实采自 156 原海报色系**：
  - 暖燕麦原纸 `#F6EBDC`（亮象牙 `#FBF5EC`、插图底 `#EFE4D5`、撕边便签 `#F1E3D5`、暖砂 `#EBDEC9`、纸边线 `#D5C6B0`）
  - 深普鲁士靛 `#061A36`（侧栏底 `#041A3A`、主标题深墨 `#010826`、暗室抬升 `#0D2443`、次墨 `#314257`）
  - 雾灰石板蓝 `#8EA7C5`（浅山 `#8DA6C4`、图标灰蓝圆 `#C5CDD7`、浅雾蓝节底 `#EAEFF4`、浅底深蓝字 `#2A4D73`、暗底浅蓝字 `#C5D5E8`）
  - 焦柿陶橘 `#D86817`（旭日 `#D37527`、斜胶带 `#E27D3B`、浅纸高对比深赭橘字 `#9B4008`、暗底亮杏橘 `#F2994A`）

- **字体搭配**：`Noto Sans SC`（正文与粗黑大标）+ `Archivo`（报刊无衬线，近 12 页 **0 次使用**）+ `Fraunces` 正斜体（出版光学衬线，近 12 页 **0 次使用**）+ `Space Mono`（几何等宽读数，近 12 页 **0 次使用**）。三款西文与近 12 页及相邻 155 零重合。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节不撞控件）
- **01 为什么分出一条边道**（亮象牙纸）：展开原海报五项侧栏功能，交互为**「混排插播 vs 剥离侧栏」实景抽离切换器**，把行内注释/标签/目录一键抽进边栏看阅读连续性变化；一句话链向 153 / 154 / 155。
- **02 左栏还是右栏**（浅雾蓝纸）：讲清左右注意偏置与「右栏盲视」，交互为**三类真实任务的「左栏 / 右栏 / 双侧栏」视线分布切台**（标明示意）；一句话链向 157 / 158 / 159。
- **03 从宽切口到内在弹性**（深普鲁士靛暗室）：核实出版与 Web 历史脉络（Bringhurst 1992 → Levine 2006 圣杯布局 → HTML5 `<aside>` 2014 → WCAG 2.1 Reflow 2018 → *Every Layout* 2019），交互为**无媒体查询容器宽尺（320–1120px 滑杆）+ 实时 CSS Flexbox 算法折行演示**。
- **04 四条要点与工程现实**（暖砂纸）：逐条引出原海报四条「设计要点」并温和补正两处简化（「隐藏」会丢信息、「纯百分比」在超宽屏会吹胖），交互为**超宽屏 `clamp()` 对比矩阵 + 迷你可滚动 `sticky` 伴读视窗**。
- **05 什么时候别用侧栏**（洁净米白纸）：列举 4 类反例（全出血叙事、单步结账表单、窄屏短卡、右栏埋核心入口），交互为**四张可翻转「强加侧栏 vs 专注单栏」线框解剖卡**。
- **06 小练习：挑出站得住的一版**（浅雾蓝纸）：中性 A/B/C/D 四版微型版面，**仅改变主栏与侧栏宽度比一个变量**，点击即时核验并讲清原因。
- **07 原海报与关键词**（暖燕麦纸）：完整 156 原海报灯箱（可缩放、拖动、Esc 关）+ 原海报五枚深蓝胶囊关键词 + 同类姐妹页快速导航。

## 7. 小练习设计
- **题目**：1280px 宽的深度专栏页（正文 1800 字，右侧放章节目录与 3 条术语简注）。四张版式色彩、字体、卡片数量完全相同，**只差主区与侧栏宽度比例**，哪一版最合理？
- **四选项（仅差「主栏:侧栏」比例，标签全中性）**：
  - **方案 A**：`86% : 14%`（主文单行过宽易串行，侧栏窄到术语折成 3 字竖条）
  - **方案 B**：`70% : 30%`（**正确答案**——主区行宽落在舒适阅读带，侧栏约 320px 完整容纳目录与简注，主次层次分明）
  - **方案 C**：`52% : 48%`（接近对半平分，深色侧栏凭借强对比反压主区，视觉主次塌陷）
  - **方案 D**：`40% : 60%`（侧栏面积超过主内容，彻底喧宾夺主）
