# 053 向心式构图（CENTRIPETAL COMPOSITION）设计方案

## 1. 一句话道理
向心式构图靠「外围多重方向势能同步指向同一中心 + 中心静谧留白环护住主角 + 外围无杂散抢戏」，顺应人眼的中心注视偏向与连续延伸规律，把分散的目光稳稳收束成不可移开的单一焦点；一旦指向歪斜、箭头反指画外、尖端刺穿文字或四角塞满杂项，向心力就会瓦解成压迫或散乱。

## 2. 开场玩具：向心矢量校准场（Centripetal Vector Funnel · 2D Canvas，标 `data-perf-drag`）
- **视觉承袭**：1:1 承袭 053 原海报暖矿石宣纸（`#EDE9E4`）、矿物孔雀青（`#138385` / `#038D8E`）、柿子朱橙（`#E85D26` / `#FC5E1F`）与石墨深炭（`#162228` / `#2F2F2F`）三色颗粒渐变楔形箭头、细建筑透视引线、中央孔雀青虚线静谧环与青/橙双色短横杠，支持「原海报 · 向心宣言」「产品展示 · 镜头光环」「演讲封面 · 核心主张」三套真实语境标本。
- **怎么玩（纯向心专属动作，无法套用到别的编号）**：
  - **画布横拖（主手势，同时驱动慢手机帧率实测）**：像拧动光学对焦收敛环一样，连续收束或拧散 8 支外围楔形的汇聚指向角（从 26° 散焦一路收准到 0° 同心锁焦，拖过头则反向拧歪）。
  - **直接点击任意一支外围楔形箭头**：单支翻转其方向（向内汇聚 ↔ 向外离心叛逃），立即观察反向箭头如何把视线拖拽出画框。
  - **直接点击外围 4 枚高饱和杂散噪点（角落干扰块）**：将角落干扰物逐一吸除（或再点放回），当场验证原海报第 3 条「减少分散元素，让画面紧凑统一」。
  - **拖动中央孔雀青虚线静谧环（或纵拖 / `↑` `↓` 键）**：收放焦点呼吸区半径，避开「箭尖刺核」与「空心断链」两极错态。
  - **按 `Space` 或点「放流检验」**：从四边同时释放 24 枚视线流珠，严格沿实绘 8 支楔形当前的真实方向向量滑行——指向歪斜或反指的流珠会擦肩偏飞或直接逃出画外，校准达标后全部丝滑汇入中央静谧圈并稳稳停驻。
  - **键盘**：`←/→` 拧动汇聚偏角，`↑/↓` 调静谧环净空，`[`/`]` 切换标本，`Space` 放流检验。
- **开场状态（故意停在 0/4 四重散焦坏态，绝不先给答案）**：
  - `指向偏角 +24°`（8 支楔形延长线错偏打架，交点散落）+ `右半侧 3 支箭头向外叛逃`（拖拽视线离画并造成四向力矩失衡）+ `静谧环净空 11%`（尖端直接刺入中央主标）+ `外围 4 处杂散噪点`（抢走第一眼注意）。
- **双向玩错与单真源读数（全部由 `model.js` 从实绘 8 支楔形几何、延长线垂距、圆环碰撞与干扰权重实时核算）**：
  - 汇聚维度：偏角 `> 9°` → **指向散焦**；存在 `≥ 1` 支反指画外 → **离心叛逃**（提示已滑向 054 离心式构图）。
  - 净空维度：静谧环 `< 18%` → **箭尖刺核**（压迫主体、干扰可读性）；静谧环 `> 41%` → **空心断链**（楔形缩在边缘，中央孤立无托举）。
  - 凝聚维度：外围强干扰 `> 0` 处 → **外围分心**（视线在半路被角落截流）。
  - 均衡维度：向内有效楔形 `< 4` 支，或四象限角跨度 `< 215°` / 合力偏移 `> 26%` → **单边倾覆**（退化成单侧推挤而非四面稳聚）。
  - 合法多解：认可「原海报 · 八向全聚解」「一点透视 · 微偏走廊解」「极简 · 四角精聚解」及任意用户手调 4/4 组合；读数白话讲清「眼睛现在怎么被带偏、为什么稳住」，示意性聚力分明确标「示意」。
- **与最近 12 页的明显差异**：
  - 对比紧邻的 052（深蓝紫夜空向外爆发点阵金核 + 五角环绕文字 + 胶囊底盒），053 是明亮暖矿石宣纸上的全幅宽景建筑绘图板、由外向内收锋的颗粒渐变楔形漏斗、支持单支反转向心/离心、点除角落杂散与四边放流检验；布局上不做 052 的深色居中星爆、不做 140/305/051/340 的左右两栏，也不做 088/139 的三栏框，而是「超精简自示范收敛刊头 → 全幅无侧栏宽景向心画布 → 紧贴底沿的水平绘图尺校准台 → 原海报底沿四竖线关键词实时标尺」。

## 3. 版式骨架
- **1440×900（2560 舒展至 1680px）**：
  - 顶沿 52px 自示范收敛刊头（两侧细青/橙尖角指向中央，配 `NO. 053`、三套标本签、实时状态徽与「放流检验 Space」按钮）→ 全幅 100% 宽开放式暖宣向心画布（约 `1380×470px`，2560 下舒展至 `1680×560px`，无侧栏挤压）→ 画布正下方融合一条齐底水平「建筑绘图校准坞」（左 46% 单真源白话诊单与一键校准/复原 | 右 54% 三轨精控、三合法解与四双向试错）→ 底沿 1:1 复刻原海报四竖线关键词实时探针带（`汇聚 CONVERGENCE | 聚焦 FOCUS | 凝聚 GATHERING | 向内 INWARD`）。绝不写 `min-height: 100svh`，避免 1024×1366 平板留白洞。
- **390×844 竖屏**：
  - 顶行压紧单行刊头（`NO. 053` + `向心式构图` + 实时状态签）+ 紧贴单行三标本签 → 等比近方高清向心画布稳占首屏 ≥ 46%（所有圆形严格等比不压扁）→ 折线内直露主汇聚滑轨、单真源诊单首句与「校准 / 放流」双键；四关键词在下方排成整齐 2×2 细线格。
- **844×390 横屏**：
  - 左 53% 严格等比向心画布 × 右 47% 精简刊头、单句诊单、主滑轨与「校准 / 放流」双键并行，零裁剪零溢出。

## 5. 节目录（7 个 h2，每标题 ≤ 12 字，明暗交替，相邻节控件零重复）
- **01 为什么视线会自动往里收**（亮象牙纸 `#F6F3EE`）：讲清中心注视偏向（Tatler 2007）+ 连续方向汇聚（Wertheimer 1923 / Arnheim 1982），温和补充原海报边界；配「四态矢量流场点击投珠台」（对比 053 向心 / 052 放射 / 054 离心 / 055 同心，点画布任意位置投放视线粒子，并一句话链接兄弟页）。
- **02 四种向心手法：不止画箭头**（浅矿青雾 `#E6ECEB`）：拆解透视汇聚、形体收锋、外圈剪影转向、明暗暗角四种真实设计手段；配「四通道叠层混音开关台」，独立开关与组合 4 层通道，实时查看不画一根箭头也能立住的向心引力。
- **03 静谧核与边界：别戳穿主体**（深矿岩暗室 `#101E24`）：原话引出原海报四条要点（引导汇聚/聚焦主体/增强凝聚/稳定有力），剖析尖端刺核、空心断链与角落抢戏三坑；配「三场景 X-Ray 对比拉帘」，左右拖帘实对比「散乱初稿 vs 向心终稿」，并可一键透视隐藏汇聚骨架。
- **04 这个方法从哪来**（亮象牙纸 `#F6F3EE`）：4 处可核实历史锚点（阿尔伯蒂 1435 *punto centrico* → 达·芬奇 1494–1498《最后的晚餐》→ 拉斐尔 1509–1511《雅典学院》→ 韦特海默 1923、阿恩海姆 1982/1988 与塔特勒 2007）；配「四纪元几何骨架演进图谱」切换查看各时期的向心几何构造。
- **05 什么时候用，什么时候别用**（暖砂纸 `#E5DFD6`）：承接原海报五大应用场景（海报设计/产品展示/演讲封面/核心信息页/摄影后期），并重点给出四类「别用」场景；配 4 张「反例翻改诊断卡」，点击原地切换「硬套向心翻车」与「对症替代版式」。
- **06 挑一挑：哪张向心真正立得住**（深矿岩考场 `#101E24`）：四选一单一变量视觉考题（中性标签 `方案 A / B / C / D`），实绘四版建筑展主视觉，选完即刻标注几何症结与解析。
- **07 原海报与同类构图**（暖矿石宣纸 `#EDE9E4` + 极深青炭页脚 `#0A1418`）：可点击放大拖拽的原海报 `<img id="poster" draggable="false">`、原海报 4 组中英关键词与同小类 041–056 一句话索引链接。

## 7. 练习设计
- **题干**：为建筑灯光展「静默光廊 · 2026」设计主视觉海报。四版方案底色、主标字号、字体与展期文案完全相同，只在向心引导结构的处理上有别，哪一版真正立得住？
- **四项差异（全中性标签：`方案 A` / `方案 B` / `方案 C` / `方案 D`）**：
  - `方案 A`：8 支向内楔形全准，但静谧圈压缩到 10%，尖端直刺标题笔画（箭尖刺核压迫主体）。
  - `方案 B`：静谧圈 28%、外围干净，但有 3 支主楔形尖端朝画外反指（离心叛逃，撕散视线）。
  - `方案 C`（正确）：6 支粗细有致的楔形从四周收锋指向中央、稳刹在 28% 静谧圈外、四角留白干净（指向精准 + 净空呼吸 + 凝聚统一 + 力矩均衡）。
  - `方案 D`：全部楔形向内且净空 28%，但四个角落堆满高饱和圆章、二维码与彩条（外围杂散抢戏，截断向心流）。
