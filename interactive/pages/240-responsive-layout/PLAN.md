# 240 响应式布局 · 方案（PLAN）

## 1. 一句话道理
同一份 HTML 内容源，在安全宽度内靠流体网格与弹性媒体顺滑伸缩，一旦内容接近撑破（单卡低于最小可读宽，或单行/单卡拉得过宽）就借媒体查询跨过内容驱动的断点主动重排骨架，让任意屏宽共用一套规则且各自可读。

## 2. 开场玩具
- **玩法**：**「内容驱动三端断点编排台（Content-Driven Multi-Device Breakpoint Loom）」**。顶部是一条 320–1440px 贯穿视口断点标尺（2D Canvas 绘制），标尺上直接按当前内容的 `minCardPx`、`maxCardPx` 与单列行宽上限算出两段浅色斜纹**内容安全带**（「2 列安全带」与「3/4 列安全带」），切换「原海报 3 卡 / 长文案加压 / 扩展 4 卡」时安全带实时移动；375px / 768px / 1200px 只作为抽样测试点标在下方。两把可拖可键盘步进的断点切刀 `BP1` / `BP2` 实时驱动下方带支架显示器、横放平板、带听筒竖长手机三台等比活体 DOM 设备，三台严格共用同一套 CSS 规则（无设备名特判）。
- **一打开是什么状态（绝不先给答案）**：初始故意把 `BP1` 设在 `340px`（远低于内容 2 列下限 556px）、`BP2` 设在 `1320px`（远高于内容 2 列舒适上限 1016px），且「参考校准」按钮隐藏至用户至少拖动或步进一次后才作为弱描边按钮出现。开场三台设备全部落入 2 列同一区间：375px 处单卡被压成 160px 竖条挤碎，1200px 处单卡被拉宽到 572px 且顶栏导航被迫收起。
- **读数说什么「为什么」**：全部由 `model.js` 同源算出每台测试点的单卡实测像素宽、每行字数、导航状态与安全带归属；底沿诊断带直接说明卡片为何在此宽度撑破或过宽，吸附与过关条件完全基于「单卡宽 ≥ 内容下限、行宽不过长」。
- **与最近 12 页的差异**：区别于 239（拖单窗右墙看流体三轨）与 295（抽屉拖进画布外舞台），本页通过「在内容安全带标尺上调媒体查询断点 + 同源三台真外形设备同步重排」演练响应式独有的多宽断点协同。

## 3. 版式骨架
- **1440×900 / 2560×1440**：忠实延续 240 原海报「暖象牙纸面 + 包豪斯几何徽标」头版气质。顶栏极简编号眉下，左侧排大标「响应式布局 / RESPONSIVE LAYOUT」与三几何图例条，右上配包豪斯绿扇蓝方点阵徽章，细虚线下全宽铺开标尺与按 `1200 : 768 : 375` 等比联排且顶部对齐的显示器、横放平板、带听筒竖长手机。
- **768×1024 / 1024×1366（平板）**：不锁 `100svh`；桌面显示器独占上行，平板（横放）与竖长手机在下行按 `768 : 375` 并列且严格顶部对齐，杜绝错落空洞。
- **390×844（手机竖屏）**：标题压紧单行，断点标尺置于 6 枚功能小签之上，按钮压成一行横向紧凑小签，下方为三端状态切签与保持竖长听筒比例的主检视手机框。
- **844×390（手机横屏）**：顶栏压缩，四层纵排标尺零文字碰撞，三台比例设备完整同屏呈现。

## 4. 配色和字体
- **配色（实采自 240 原海报 `poster.webp`）**：暖象牙纸 `#F9F5F0` / 纯白 `#FFFFFF` / 淡鼠尾草灰绿 `#E1E9DD` / 翡翠翠绿 `#11956D` / 包豪斯钴蓝 `#0C4DB7` / 纯印刷墨 `#111514` / 异常警示朱红 `#B4281E`。
- **字体搭配**：`Noto Sans SC`（400/500/700/900）+ **`Space Grotesk`**（500/700，用于原海报包豪斯几何英文字母、编号 `NO. 240` 与节号 `01`–`08`）+ **`Inter`**（400/500/600/700 + 等宽数字 `tabular-nums`，最近 12 页及开工前 12 页均未用，用于 `@media` 语法、2D Canvas 标尺刻度与像素规格）。整组搭配 `Inter + Noto Sans SC + Space Grotesk` 在全站唯一，彻底避开 295（`Rubik Mono One + IBM Plex Mono`）与 239（`Anton + JetBrains Mono`）。

## 5. 节目录（共 8 节，h2 均 ≤ 12 字，相邻节交互不重样）
- **01 一块内容，三副骨架**：引原海报三端要点，附「海报细读 · 配错了位」小签直指原海报 `REORDER` 与 `DEVICE` 中英错配及平板图三列瑕疵，链至 `238 / 239 / 241`。交互：三支柱拆柱故障注入开关。
- **02 从纸页幻觉到响应式**：2000 Allsopp → 2002 W3C CR → 2007 iPhone viewport → 2009–2011 Mobile First & Marcotte → 2012–2018 MQ L3 & WCAG 2.1 Reflow。交互：年代演进轨 + 手机历史视口镜。
- **03 按内容设断点，不按机型**：承接开场内容安全带，对照死背 768/1024 机型线与内容反推断点（链至 `227`）。交互：题材切换 + 连续测宽 PK 台。
- **04 重排不是隐藏，顺序定去留**：Luke Wroblewski 三模式（Mostly Fluid / Column Drop / Layout Shifter）与 CSS `order` 的 Tab 序陷阱（链至 `226`）。交互：三模式切宽矩阵 + Tab 焦点步进演示。
- **05 弹性媒体与视口声明**：`viewport meta` 与 `<picture>` 艺术指导（链至 `242`）。交互：2D Canvas 取景裁剪与 viewport 开关。
- **06 什么时候别硬套响应式**：多列数据表、二维画布工具、双端任务分叉、跨容器挂件（链至 `230 / 235 / 241 / 242`）。交互：四场景双栏几何示意对比簿。
- **07 小练习：哪组断点最稳？**：同变量断点像素算式四选一。
- **08 原海报与关键词**：可缩放拖拽灯箱 + 标明更正后英文与原海报错配注记的关键词卡 + 相邻编号索引。
