# 326 留白构图（NEGATIVE SPACE COMPOSITION）互动页方案

## 1. 一句话道理
空白不是画完主体后剩下的边角料，而是主动留出的整片呼吸空间——它把视觉噪音降下来、拉高主体对比，把视线稳稳引向主角，并建立安静清晰的秩序与层次。

## 2. 开场玩具：「美术馆光影减法台 · 空间呼吸雕塑场」
- **视觉母题**：1:1 承袭 326 原海报极净暖瓷白墙（`#FEF9F6`）、无描边纯白建筑拱门（`#FFFFFF`）、向斜下方渐隐的温灰长影（`#E2DADA` → `#F3EDEB`）与建筑钴蓝三符（`□` 空间、`●` 对比、`⌜⌟` 聚焦）及短杠孤点（`──── •`）。
- **怎么玩**：
  1. **横拖雕塑留白与体量（`data-perf-drag`）**：在画布空白处左右横拖（或拖主体的缩放边界 / 滑轨），实时伸缩核心主体的体量与白墙呼吸气口（主体占幅 2%–68%），纯白拱门斜影与刊头自示范大标「留白构图」字距、钴蓝短杠孤点间距同步呼吸。
  2. **画布直点做减法（或塞回试错）**：开场墙上硬塞了 5 件典型的「怕空病」冗余杂物（粗装饰外框、噪点细网格底、左上满角标、顶中抢戏促销条、右下争主副块），点击画布上的红标或杂件本体即可亲手撤白（或再塞回试错）。
  3. **拖拽主体改聚散与落位**：直接拖移纯白拱门（或寒江孤舟 / 展讯器物）在画框内的位置，实时观察「相同留白面积下，整片大白与碎缝假留白的天壤之别」，并可一键开启「最大连续留白连通域」钴蓝显影网。
  4. **三题材切换**：原海报·光影拱门 / 宋画·寒江独钓（只画孤舟与蓑笠剪影，绝不画五官）/ 现代海报·白墙展讯。
- **开场状态（绝非答案）**：刻意停在 **0/4 · 怕空塞满错态**——4 件冗余杂物开启（噪点网底 + 装饰死框 + 左上满角标 + 右下争主副块）、主体体量过大且略偏中，实测净留白仅约 32%、最大连续空白连通度极碎（约 18%）。
- **怎么算玩错与单真源读数**：由 `model.js` 对实绘网格（48×32 占据格点）与包围盒几何单真源核算，支持 8 类真实错态诊断：
  1. 拥挤窒息（净留白率 < 56%）
  2. 空洞失锚（净留白率 > 92% 或主体占幅 < 5%）
  3. 白被切碎（总留白够但最大连续空白连通域占比 < 60%）
  4. 噪底破净（细网格底纹仍在干扰对比）
  5. 副块争主（抢戏副块或冗余条仍在分流视线）
  6. 外框锁气（硬边装饰框截断空间延展）
  7. 撞边滑出（主体距画框外沿 < 7%）
  8. 居中僵滞（主体与斜影四等分白边、缺乏主次势能）
  - 读数始终同时解释「为什么这样看」（视觉呼吸、明度对比、聚焦去向），秩序评估标明「示意」档位，绝不造假精确百分比。
  - 接受多组合法解：原海报右偏解、下沉留天解、宋画一角孤韵解，左偏/右偏/下沉只要四项同时达标即成立。
- **与近 12 页的明显差异**：
  - 不同于 325 的宣纸三联古册页掰折枝、324 的朱砂裁景刀窗、036 的天蓝 C 弧开口、120 的粉彩胶囊围栏、245 的腮红视口居中器、203 的深松石绿星盘、074 的斜投影方块、286 的搜索结果页、119 的深藏青鲁宾花瓶、244 的明黄盒模型、158 的有机文字绕排、035 的红蓝 Z 轨——本页主打**「做减法撤白 + 连续留白连通域雕塑」**，是 326 留白构图独有的动作。

  - **1440×900**（主宽 `1380px`，2560×1440 舒展至 `1720px`）：

    - 下接 1px 细灰横线通栏白话诊单带（左 62% 单真源白话诊断与操作指引 × 右 38% 四枚无框细竖线实测读数）。

  - **390×844（手机竖屏）**：顶部压紧单行刊头（标题 + 蓝杠 + 状态印），总述后置，题材快切 1 行，光影画布稳占首屏 ≥ 48% 屏高且维持健康画幅比例（绝不压扁），首屏同见白话诊单标题与首句。
  - **844×390（手机横屏）**：切为左 56% 光影画布 × 右 44% 紧凑刊头 + 题材切 + 诊单首句并行。

## 7. 小练习设计
- **题干**：四张「青瓷器物展」极简展讯使用完全相同的暖瓷底、同尺寸器物轮廓、同套标题文字与字号，仅调整空白与主体的聚散及护边。哪一版最能发挥留白构图的秩序与聚焦？
- **四选项（中性命名，单变量控制）**：
  - 方案 A：器物偏右上贴边、标题落左下贴边，中间拉出大片空洞裂谷。
  - 方案 B：器物死居中轴、标题紧压下方，四周留白被四等分成等宽窄框。
  - 方案 C（正解）：器物稳落右下内安全区、标题收束左下同基线，上方与左上汇聚为一整片连贯呼吸大白。
  - 方案 D：器物与标题各自套上细方框居中并排，总空白相近但被框线切碎成格。
