# 221 旁注（Ruby）排版 · 互动版方案（PLAN）

## 1. 一句话道理
旁注（Ruby）之所以有效，在于它在主文之外开辟一条「低权重辅助音轨」：通过**约 50% 的字号反差、紧贴对应字符的居中挂接、克制一致的注距（且远小于跨行净空）以及清晰的层级对比**，让读者先顺着主文流无阻扫读，遇到难字或专名时视线轻跳一眼即获读音与释义，而不打断阅读节奏。

## 2. 开场玩具：旁注排字盘 · 活字试印台（Ruby Typesetting Galley）
- **核心动作（专属于 Ruby 排版，无法套用给其他编号）**：1:1 转译 221 原海报的 18px 圆角玫瑰红细框双区解剖图（左 78% 横排双行活字排字盘 + 细竖线 + 右 22% 联动「右侧旁注示例 SIDE RUBY EXAMPLE」），标 `data-perf-drag`：
  - **画布横拖（主手势）**：像推拉活字字阶游标尺一样连续缩放**旁注字号比（24%–95%）**，实时看见 2 假名或长拼音从糊死蚂蚁字舒展到 50% 半字黄金比，再膨大到 85% 顶撞相邻旁注并硬生生撑裂主文字距；
  - **画布纵拖旁注轨（或拖红虚导轨点）**：连续抬升/压低**注距（-0.04em 压顶粘连 ↔ 0.14em 呼吸距离 ↔ 0.48em 浮高撞上邻行底脚引发归属反转）**；
  - **点按单字旁注 / 切换挂接与层级**：支持切换三套标本（**原海报 · 日语振假名** `希望の未来` + 邻行参考 + 右侧 `山 やま` / **汉语拼音 · 宽窄音节** `参差霜叶` + 右侧注音示意 / **术语与古籍双释** `版心界栏` + 右侧古训）；支持在原海报模式点击假名助词 `の` 上多余红注开关「多余注音噪点」；支持切换挂接对齐（左偏错位 / 逐字居中 Mono / 熟语均分 Jukugo / 词组通排 Group）、字色层级（同黑过重 / 朱红轻注 / 素灰雅注 / 过淡失对比）与直排试印；
  - **按 `Space` 或点右上红日**：触发视线扫读光带演播，直观演示主文流畅扫读 vs 旁注过大/倒挂引起的视线剧烈跳行卡顿。
- **开场初始状态（绝不先给答案，0/4 四重错态）**：
  - 旁注字号比 `78%`（喧宾夺主，双假名 `ぼう` / `らい` 撑裂主文字距）；
  - 对齐处于 `偏右错位 +26%`（红注滑入两字夹缝，归属错位）；
  - 注距 `0.36em` 叠加偏紧行距 `1.80×`（旁注浮高，紧逼上一行底脚，格式塔接近律反转）；
  - 字色为 `主客同黑同粗`（两行黑杠抢戏糊连）。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 由 `model.js` 从画布实绘主字盒、旁注盒、上邻行底线、跨字溢出与实际对比度**单真源**双向检出 8 类错态（过大抢戏、过小糊死、压顶粘连、浮高倒挂贴上行、偏位失配、同黑等重、过淡失对比、长注撕裂豁口），读数不用假精确百分比，只给真实几何比例/像素实测与明确档位，并用白话讲清「眼睛会怎样误读」以及「先动哪一项」。
  - 认可**多组合法解**（原海报朱红半字解、文库黑白素墨解、儿童大行距拼音解，以及用户任意手调达标组合）。
- **与最近 12 页的明显差异**：
  - 近 12 页无一涉及「字间挂接注音、双行归属反转与悬挑撑裂」排字力学；摒弃任何仪表侧栏黑箱、无准星拖点、无左文右图套壳。

## 3. 版式骨架（忠实转译 221 原海报「和风现代主义单栏纵轴展报」）
- **1440×900（2560 舒展至 1600px，不锁 100svh 避免平板大空白）**：
  - 顶区：左自示范大标（朱红「旁注 (Ruby)」头顶微型活体旁注 + 墨黑「排版」+ 英文与短红杠）× 右原海报实心朱红圆日（可点触发扫读）、4×6 深灰点阵、实时状态签与三标本药丸；
  - 中区：满宽（1340px）18px 圆角玫瑰红细框开放画布（左横排活字盘 | 竖线 | 右侧旁注联动小窗）+ 紧底极薄单行精控操轨；
  - 下区：1:1 复刻原海报柔杏桃色（`#FDF4EC`）大圆角四栏探针卡（带原海报 4 枚红黑线绘图标 + 单真源实时徽章，点击联动高亮画布标尺）→ 底沿原海报实心黑圆灯泡单真源诊单条与多解/试错药丸。四部分总高控制在 ~860px，1440×900 首屏一镜尽览原海报完整神韵。
- **1024×1366 / 768×1024 平板**：自然流排零空白，四栏探针带在 768px 折为 2×2 严丝齐底。
- **390×844 手机竖屏**：压紧单行刊头（~72px），后置总述与 4×6 点阵；玫瑰红圆角排字画布切为近方舒展画幅稳占首屏 ≥46%（自动重排大号单行+上邻行与可点切直排，绝不压扁）；折线内直露黑圆灯泡诊单首句、一键校准、扫读与核心字号/注距滑轨。
- **844×390 手机横屏**：切为左 56% 排字画布 × 右 44% 紧致刊头 + 灯泡诊单 + 精控操轨并行。

## 5. 节目录（7 个编号大节，相邻节控件各不相同）
- **01 从 5.5 磅活字到 Web**：英国 5.5pt 宝石活字名、明治五号/七号活字与 JIS/W3C 标准演进，温和补正原海报连助词「の」也注音的细节；交互：**历史活字铅块 2:1 模数刻度切签**（SVG 铅字剖面）。
- **02 三种挂接：单字、熟语、词组**：对照 Mono-ruby / Jukugo-ruby / Group-ruby 的排法与断行差异；交互：**栏宽拉杆驱动的三列真实 DOM `<ruby>` 断行压力对照台 + 实时 CSS 源码**。
- **03 暗室解剖：行距与悬挑碰撞**（深漆黑暗室）：多行段落里垂直归属反转与长拼音横向撕裂白洞；交互：**多行段落红外防撞测绘 Canvas（开关悬挑、调行距/注距与注音密度，实时标红撞行热区）**。
- **04 四大场景与横竖变体**：对应原海报四枚药丸（日语振假名、汉语拼音与台湾右置注音、专业术语、古籍双侧旁注），并一句话链接 212/214/216/217/218/219/220；交互：**四场景活体书页样张切换器 + 隐显旁注对照开关**。
- **05 什么时候别用旁注**：1938 年 4 月山本有三「黑虫」之争与四大禁区（长解释、极小字、通篇高频字全注、可复制数据文本）；交互：**四张踩坑案例 Before → 替代方案翻牌急救卡**。
- **06 小练习：四选一排印审校**（深漆黑暗室）：2 道单变量审校题；交互：**中性方案 A/B/C/D 真实排版微缩卡单选与批注解析**。
- **07 原海报与同类版式索引**：原海报可放大拖动灯箱、原海报要点摘录、同小类 9 页导览及页脚。

## 7. 练习设计
- **题 1（变量唯一：注距与行距配比）**：同一双行日语诗句（50% 字号、居中、朱红轻注全部相同），四个中性方案 A/B/C/D 分别演示 0px 压顶 / 0.14em+2.0× 行距（正确）/ 0.46em 浮高倒挂贴上行 / 1.38× 窄行距上行压顶。
- **题 2（变量唯一：宽拼音挂接策略）**：同一句含宽音节 `shuāng` 的汉语词组 `参差霜叶`，四个中性方案 A/B/C/D 分别演示 26% 强缩糊死 / 80% 等大抢戏 / 50% 半字均码+轻度悬挑与微调字距（正确）/ 整句合并词组注音失单字对位。
