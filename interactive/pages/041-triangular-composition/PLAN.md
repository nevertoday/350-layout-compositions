# 041 三角构图 · TRIANGULAR COMPOSITION 互动页方案

## 1. 一句话道理
三角形是平面几何中唯一由三条边长锁定刚性的基本多边形：只要把视觉重心稳稳压在宽阔底边的支撑段内，两条收敛的斜边就会同时提供物理般的安定感与直指顶峰的视线导轨，并在顶点或内心处自然锁住焦点。

## 2. 开场玩具：拉绳起峰 · 活体三角力学骨架台
- **怎么玩**：
  - 1:1 承袭 041 原海报暖米宣纸底 `#F5ECDD`、深松黛绿 `#062B20` 雪山实景三角、顶端三光日轮金圆 `#D2971C`、底角双松绿锚圆、外围三条双向箭头虚线导轨以及内嵌琥珀金「焦点 FOCUS」主圆。
  - **画布开放区左右横拖（`data-perf-drag`）**：连续舒展或偏倾整座三角形的底宽与顶峰势态（从扁塌歪斜一路拉出端正等腰峰或蓄力斜峰），实时联动刊头「三角构图」旁的微型几何三角徽、重心 $G$ 垂直落线与右上 4×4 圆点矩阵。
  - **直接拖拽三枚顶点锚圆（顶峰金日 A、左下松绿点 B、右下松绿点 C）**：手调顶角锐度、底边宽度与底边倾角；若把顶点 A 拖到底边下方，画布实时识别为「倒置翻覆」，说明它已滑向 [043 倒三角构图](https://layout.xiaoxiaodong.ai/043/play/) 的悬垂张力。
  - **直接拖拽琥珀金「焦点」大圆**：在三角内心/重心、顶点高潮区、边界擦边与三角外部空地间自由移动，亲测视线沿斜边推进时焦点是否落位。
  - **三场景图标直切 + 显性/隐性框架开关 + 层级阶差控制**：1:1 复刻原海报右侧「风景摄影 / 人物构图 / 视觉设计」三图标直切舞台实景（人物严守剪影无五官），随时关闭辅助虚线检验隐性三角是否依然站得住。
- **开场初始状态（绝不先给答案）**：
  - 刻意停在 **0/4 塌陷歪基 + 焦点外逃错态**：顶角扁平达 131°、底边倾角 17.7° 且面积仅占 7%、三顶点大小层次拉平（1.0× 无梯级）、琥珀金焦点圆漂落在三角形左上外部。
- **怎样算玩错、读数怎么说「为什么」**：
  - 所有读数由 `model.js` 从当前实绘三顶点坐标 $(A,B,C)$、焦点坐标 $F$、重心 $G=(A+B+C)/3$ 及真实层级比单真源算出，支持往两头玩错，覆盖 **9 类双向错态**：
    1. 倒置翻覆（$A_y \ge \min(B_y, C_y)$）：已成倒三角悬垂结构，失去正置稳固底基；
    2. 扁塌钝顶（顶角 $\angle A > 112^\circ$）：斜边过于平缓，视线横向滑过，缺乏向顶引导；
    3. 针尖过锐（顶角 $\angle A < 28^\circ$ 或底宽 < 36%）：变成瘦长竖柱，左右晃动立不稳；
    4. 底基歪斜（底边倾角 > 14°）：底座倾斜，观者产生随时侧滑倾倒的不安感；
    5. 重心出界（重心垂线投影落出底边内安全段）：视觉重量偏离支撑区，结构失衡；
    6. 缩微孤弱或顶框爆边（三角面积占比 < 14% 或顶点贴边 < 4%）：撑不起画面或顶撞边界发紧；
    7. 层次扁平（层级体量比 < 1.25× 或高度跨度不足）：三个节点平分视觉重量，没有主次远近；
    8. 焦点脱框（焦点圆心在三角外部且远离顶峰）：斜边把视线引向顶点，却绕过了主角；
    9. 焦点贴边发紧（焦点距某边过近）：与轮廓线相互挤撞，打散聚能。
  - 接受**原海报等腰正峰解**、**斜冲叙事峰解**、**宽基登顶聚焦解**等多组合法解；稳态评估仅用档位并标「示意」，不写假精确百分比。
- **与最近 12 页的明显差异**：
  - 040 是黑底双刃闪电多拐点折线；124 是深绿切割垫出血落刀台；249 是镉黄 CSS 封面容器；291 是响应式视口拉阔流道；162 是朱红书口栏目箭；207 是樱粉固定列网格；039 是薄荷松石海浪周期；077 是 3D 鸟瞰绕飞沙盘；123 是暗房取景双屏；327 是玄墨拱门反拓；248 是克莱因蓝切换器；290 是六层切角档案夹。041 是唯一以**暖米宣纸×深松绿×日轮金三点力学骨架、实算顶角/底倾/重心落点/重心坐标，并可一键透视显性↔隐性三角及联动底部 1→2→3 活体图谱**的开放构图台。
