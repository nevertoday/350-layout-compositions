# 218 直排中西文转向（VERTICAL CJK & LATIN ROTATION）设计方案

## 1. 一句话道理
中文直排自上而下阅读，把行内的西文与长数字顺时针旋转 90°，让西文字母的阅读走向与中文的下行视线合并为同一条单向动线，既保住英文词形识别，又守住直排书页规整的纵列节奏。

## 2. 开场玩具：「直排铅字校样与 90° 转向盘」（Vertical Galley & Rotation Press）
- **形态**：直接铺在原海报暖米宣纸（`#FBF6EC`）上的无重框 2D Canvas（标 `data-perf-drag`），1:1 承袭原海报左下半的**巨幅朱红分度转向盘**（红圆 + 虚线十字轴 + 墨黑圆心轴点 ●）与右侧**四列虚线直排样张**（❶ 中文直排 `探索排版的秩序与美学` / ❷ 西文转向 `Design is thinking made visual.` / ❸ 数字转向 `2025 • 90%` / ❹ 标点居中 `、。• : ; ( ) 「 」`），支持「原海报四列 / 展讯票签 / 书籍内页」三套真实标本切换。
- **怎么玩**：
  - 在画布任意位置左右横拖（或拖转左下朱红分度盘指针），连续旋转西文转向角（`-90°` ↔ `0°` ↔ `+90°` ↔ `+180°`），靠近 `+90°` 时轻轻吸附；
  - 直接点按画布内第 3 列切换数字策略（直立叠排 / 顺时针 90° / 短数纵中横 / 逆时针 -90°），点按第 4 列切换竖排标点策略（横排原形未转 / 居中转形·港台海报 / 右上转形·大陆日文）；
  - 用微调轨调西文光学基线偏移（`-12px..+12px`）与中西视觉缩放（`70%..130%`），按空格或点「演播视线」释放朱红视线光点沿列实测阅读动线；方向键 `←/→` 精调转角、`↑/↓` 调基线。
- **开场状态（0/4 复合错态，绝非答案）**：
  - 西文被误设成新手最常踩的 **逆时针 `-90°`**（阅读被迫自下而上逆流，与中文下行迎面相撞）；
  - 数字停在 **直立叠排**（呼应原海报第 3 列的实排小瑕疵）；
  - 标点停在 **横排原形未转**（括号横躺、顿句号沉左下）；
  - 西文基线左偏 `-9px` 且比例过重 `124%` 撞向虚线列缝。
- **怎样算玩错、读数怎么说**：由 `model.js` 从画布实绘字框、转向角、中心轴偏距与列缝净空单真源核算 8 类双向真错态（逆时针逆流、斜角切缝、倒置颠倒、长句硬直立碎词、数字直立/逆转、标点横形未转、基线偏左或偏右脱脊、西文过巨撞缝或过小失衡），诊单直接指出「眼睛此刻怎么卡住」与「怎么改」，并接受「原海报经典解 / 出版纵中横解 / 大陆右上标点解」及任意符合规范的手动组合达标 4/4。
- **与最近 12 页的区别**：最近 12 页（136 跨页天平、217 中轴横带、085 透视压平、048 椭圆造景、303 剧场三人、172 瑞士网格、258 侧边栏网页、135 对折镜像、337 胶片片轨、257 三列网页、302 双人轴线、047 圆轨星盘）均无「汉字直排活字校样台 + 朱红角度转向盘」交互，玩法完全原生于 218「直排中西文转向」本身，别的编号无法套用。

## 3. 版式骨架
忠实转译 218 原海报「左侧通高真直排刊头脊 × 中央开放朱红分度盘与四列虚线校样画布 × 右侧核心规则与单真源排版诊单 × 细墨通栏线下原海报四枚朱红圆环原则实时探针带 × 底沿三角双语宣言」非对称直排样张骨架（零深灰通用顶栏，不锁 `100svh` 避平板大空白）：
- **1440×900（主宽 1380px，2560 舒展至 1680px）**：左 10% 真竖排大标『直排中西文转向』旁衬顺转 90° 朱红英标自示范，中 62% 开放校样画布，右 28% 核心规则与诊单齐底等高；下方 1.5px 墨线分隔四枚朱红圆环实时探针横带与底沿三角宣言，首屏完整呈现无截断。
- **1024×1366 / 768×1024**：顶部单行横置刊头与标本切签 → 满宽等比校样画布 → 双列齐底诊单与精控台 → 2×2 原则探针带，自然流排零大块空白。
- **390×844**：压紧单行刊头与标本栏，等比校样画布占首屏 ≥46%，折线内直接露出诊单首句与一键校准按钮；说明与四原则后置。
- **844×390**：左 56% 开放校样画布 × 右 44% 紧凑刊头、标本切签与诊单并行，零横向溢出。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节不复用同控件）
1. **01 为什么顺转九十度**（亮宣 `#FFFDF8`）— 三向视线向量对照仪（按钮切换 `-90° / 0° / +90°` + 实时动线与无五官颈偏图式，对比为何只有顺时针 90° 与中文下行同向）。
2. **02 数字与标点的四套规则**（暖羊皮 `#F4ECE0`）— Unicode UAX #50 字符矩阵分拣台（点击 8 枚代表字符查 `U/R/Tr/Tu` 与 `vert/vrt2` 属性 + 港台居中 vs 大陆日文右上标点实时对照 + 「原海报里的一处小细节」温和校注）。
3. **03 光学中轴与混排呼吸**（活字暗房 `#141210`）— 400% 显微字框放大画布（滑块调 x-height 光学中轴、中西比例与四分空 `1/4 em`，切换辅助线看基线与字框几何）。
4. **04 从活字到网络标准**（暖米原纸 `#FBF6EC`）— 竖向编年卷轴与 CSS/出版实操对照切签（铅字直排 → JIS X 4051 → JLReq → CLReq → UAX #50 → CSS Writing Modes L3）。
5. **05 什么时候用与别用**（浅石暖纸 `#EFEAE1`）— 场景卡片双面切换（书脊/展讯/文学书页/茶标 vs 长段英文技术文/密集数据表/移动端长文），一句话链接 212–221 同类各页。
6. **06 练习：挑出顺流样张**（暗房考场 `#171513`）— 双题单变量视觉辨析（第 1 题 4 枚中性标签样张 A/B/C/D 仅差「西文朝向」，第 2 题仅差「竖排标点处理」，作答后逐项绘出动线并讲清理由）。
7. **07 原海报与关键词**（暖米原纸 `#FBF6EC` + 浓墨页脚）— 原海报点击放大/拖动看图器（`draggable="false"`，`Esc` 关闭）与四枚原海报关键词。

## 6. 核实来源
- **JIS X 4051**（日本工业标准《日本語文書の組版方法》，1993 初版 / 1995 纳入纵排和欧文混排 / 2004 修订）：`https://www.w3.org/TR/jlreq/`
- **W3C JLReq**（*Requirements for Japanese Text Layout*，2009 年 6 月第一版 / 2012 年 4 月第二版）：`https://www.w3.org/TR/jlreq/`
- **W3C CLReq**（*Requirements for Chinese Text Layout*《中文排版需求》，2015 年 7 月首版草案）：`https://www.w3.org/TR/clreq/`
- **Unicode UAX #50**（*Unicode Vertical Text Layout*，2017 年 6 月随 Unicode 10.0.0 并入 UCD）：`https://www.unicode.org/reports/tr50/`
- **W3C CSS Writing Modes Level 3**（Elika J. Etemad、Koji Ishii 等编辑，2019 年 12 月 10 日 W3C 推荐标准）：`https://www.w3.org/TR/css-writing-modes-3/`
- **Microsoft OpenType `vert` / `vrt2` 规范**：`https://learn.microsoft.com/en-us/typography/opentype/spec/features_uz`

## 7. 练习设计
- **第 1 题（核心）**：同一段直排展讯「设计展 Design Week 2025」，给出中性标签 `样张 A / B / C / D`，字体、字号、标点、留白完全一致，**只差「西文与年份朝向」这一个变量**：
  - A：逆时针转 90°（`-90°`，文字自下而上逆着中文读）
  - B：顺时针转 90°（`+90°`，与中文自上而下阅读流完全统一 — **正确**）
  - C：西文逐字直立叠排（`0°`，英文词形碎裂，行高拉长）
  - D：西文横排硬插直列（单行撑破列宽，撞入邻列）
- **第 2 题（进阶）**：同一句直排书摘「读懂（直排）节奏。」仅差「标点处理」一个变量（横排原形未转 / 竖排居中转形正确 / 括号反转朝外 / 标点缩挤贴字），深化对 `vert` 替换与中轴对齐的直觉。
