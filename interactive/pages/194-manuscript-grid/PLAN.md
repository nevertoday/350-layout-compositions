# 194 手稿网格（MANUSCRIPT GRID）设计方案

## 1. 一句话道理
手稿网格用克制而合比例的四周边距，从纸面或屏幕里圈出一块专注、稳定、行宽合宜的单栏正文区（版心），让读者的眼睛不用在多栏与杂音之间做选择，安稳地沉浸在连续长文里。

## 2. 开场玩具：活体稿纸与双页版心裁定台
- **怎么玩**：
  - 直接在 194 原海报同构的暖宣稿纸 2D Canvas 上操作：既可以直接拖拽正文区（版心）的**上 / 下 / 左 / 右（对开时为内 / 外）四条实线边界**独立调节每一侧边距，也可以直接在版心区域内左右拖动（或触屏横向拖动，标为 `data-perf-drag`）同步收放左右留白、即时看真实中文散文在版心内重排换行。
  - 纸面上方单行提供「单页稿纸 / 双页对开」切换、「古典九分线（Van de Graaf 对角基准）」开关、「拇指握持区」开关与「复原错版」按钮；下方紧贴单行调参带调节行距（`1.18×–2.05×`）、内容纯度（`干扰插块 / 纯净正文`）与开本比例（`2:3 经典 / A4 1:√2 / 窄口袋本`）。
  - 右侧直接化用 194 原海报的「手稿网格的五个原则」古苔圆徽列（`01 留白为先` 至 `05 古典秩序`），每条实时显示实测判定，点击任一条会在稿纸上点亮对应几何结构；同时支持方向键微调选中边界。
- **一打开是什么状态（0 / 5 满版窒息错版）**：
  - 四周边距被压扁到 `上 5% / 下 5% / 左 5% / 右 5%`（总留白仅约 19%，正文面积占 81%），单行文字被拉长到约 44 字、行距压紧到 `1.18×`、下边距与上边距齐平（无视觉托举）、正文里塞进一块抢戏的装饰旁栏插块且底行页码撞进文字。此时 5 项原则全部标红（`0 / 5 待校版`）。
- **怎样算玩错、错了读数怎么说**：
  - 不会因为随便点满或往一边拉到底就过关；所有指标由 `model.js` 单真源实算，检出 6 类常见失误并白话解释「为什么」：
    1. **满版窒息**：任一边距 < 11% 或版心占比 > 66% → 文字贴边、手指一拿就遮字、视线缺少隔离缓冲。
    2. **孤岛缩水**：留白过大导致版心占比 < 26% 或单行 < 18 字 → 正文缩成窄条，眼睛频繁折行打断文意。
    3. **重心下坠（倒挂）**：下边距 ≤ 上边距 → 视觉中心比几何中心略高，下边托不住整块正文，显得往下滑。
    4. **左右失衡 / 订口反装**：单页左右差 > 5%，或双页对开时内边距 ≥ 外边距 → 摊开书页后两页内边距叠成双倍白河，中间裂开而外缘没处放拇指。
    5. **行宽与行距失配**：单行 > 36 字或 < 18 字，或行距 < 1.50×（灰墙粘连）/ > 2.10×（散行割裂）。
    6. **干扰破界**：正文区塞入装饰框或页码贴撞正文 → 破坏手稿网格唯一的沉浸阅读流。
- **与最近 12 页的差异**：
  - 193 调单条横排行长看眼动回扫弧线；192 调竖排卷轴行距；063 嫁接树节点；231 拖 CSS 浮块宽；275 拖画廊主图比例尺；108 雕 2×2 母砖；230/274 调数据表格列宽；062 推散星场。本页 194 的核心动作是**在真实书页/双页对开纸面上直接裁定四周边距与版心框**，亲手看到留白怎样决定行宽、拇指握持、订口合缝与古典九分几何。

## 3. 版式骨架
- **承袭 194 原海报**：顶部书卷眉首（左朱砂示范大标「手稿网格」嵌入实时随边距呼吸的比例框 + `MANUSCRIPT GRID` + 古苔短横杠与总述 × 右细竖线隔开的「有界之中 / 自成章法」、朱文方印与校版状态印）→ 中段左 54% 活体稿纸与底沿极简调参带 × 右 46% 校勘书签诊单 + 5 枚原海报同款古苔圆徽实时原则列（左右基线收齐，不锁 `100svh`，避免 1024×1366 平板竖屏留白洞）。
- **2560×1440**：主容器扩宽至 `1760px`，稿纸画布宽舒大气，正文与演示同比例展开，不缩在屏幕正中。
- **1440×900**：主容器 `1340px`，首屏完整呈现书卷眉首、稿纸舞台、调参条、校勘诊单与 5 条原则列。
- **390×844**：眉首压紧为单行标题 + 状态章，稿纸画布紧接置顶并等比占据 ≥ 46% 屏高（严禁压扁变形），首屏同时露出核心切换条与诊单首句。
- **844×390**：切换左 54% 等比稿纸画布 × 右 46% 紧凑眉首、调参控件与实时诊单双栏并行。

## 5. 节目录（8 节 + 页脚，相邻节不复用同款控件）
- `01` **留白不是剩下来的**（`Margins Are the Frame`）：讲边距的握持、隔绝与光学托举三大职责，并温和补足原海报「单页等距」与「双页对开内窄外宽」的差别。交互：**对开书页折叠与握持姿势检查器**（书页边距模式按钮 + 手持姿势切换，在真实 SVG 对开书页上显示拇指轮廓遮字实测与中缝白河）。
- `02` **一行多长、行距多宽**（`Measure & Leading`）：手稿网格如何借边距锁定经验行宽（中文约 24–36 字、英文 45–75 字符），并一句链接 [193](https://layout.xiaoxiaodong.ai/193/play/) 与 [198](https://layout.xiaoxiaodong.ai/198/play/)。交互：**实测 DOM 排版试读台**（4 张开本宽度卡片 + 3×3 字号/行距组合矩阵，用真实浏览器断行测算每行字数与回扫坡度）。
- `03` **古典九分与东西双轨**（`The Canon & East-West`，深墨橄榄暗室）：「从哪来」——中世纪针孔压线写本（Book of Kells）、威尼斯袖珍单栏书（Aldus Manutius, 1501）、20 世纪九分法与对角线版面法典（Van de Graaf 1946、Rosarivo、Jan Tschichold 1975/1991），并对照中国宋版古籍「天大於地」的眉批传统。交互：**分步几何作图动画画布**（步进按钮 1→4 步步绘制对角线与 2:3:4:6 版心，支持一键切「宋版天头」对照）。
- `04` **单块版心的弹性变奏**（`Anatomy & Variations`）：同一副手稿网格如何靠章节下沉、书眉、页码、外缘旁注与满宽跨图织出节奏而不破坏统一。交互：**三跨页书稿结构开关板**（复选切换 5 个版式部件，同步刷新 3 组缩微对开跨页）。
- `05` **在网格家族里的位置**（`In the Grid Family`）：手稿网格在「网格系统」18 种网格里的定位，一句一链指路 [195](https://layout.xiaoxiaodong.ai/195/play/)–[211](https://layout.xiaoxiaodong.ai/211/play/) 不重讲。交互：**出版物题材配对切换器**（选 4 类真实项目简报，看骨架预览与留任/换格理由）。
- `06` **什么时候别用它**（`When Not to Use It`）：4 类典型误用（多维对比后台、多线索杂志首页、宽屏不设上限、强冲击破序海报）+ 小插图线框。交互：**宽屏网页手稿 CSS 陷阱切换器**（对比「纯 15% 百分比留白」与「`max-width: 36em` 自动居中留白」在 1440px 屏幕上的行宽灾难与正解）。
- `07` **校版小练习**（`Editorial Practice`）：两道进阶眼力题（题一：双页对开四边距分配；题二：宽屏网页长文容器），选项只标中性 `方案 A/B/C/D`，仅差一个变量，选后逐一揭示实测数据与点评。
- `08` **原海报与要点**（`Original Poster`）：完整嵌入 `poster.webp`（点击打开 `<dialog>` 缩放拖拽、Esc 关闭）并收录原海报全部文字、应用示例与原则词签，接标准页脚。

## 7. 练习设计
- **第一题（双页对开边距分配）**：同一册 2:3 经典开本对开页、同字体同行距，四张缩微图只差四周边距比例：
  - `方案 A`：内 18% · 天 18% · 外 18% · 地 18%（看似规整的陷阱——双页拼缝成 36% 白河且上下等距显下沉）
  - `方案 B`：内 11% · 天 13% · 外 22% · 地 25%（**正解**：符合 `内 < 天 < 外 < 地`，两页内距合为 22% 恰好呼应外距，拇指有处可放，重心稳抬）
  - `方案 C`：内 22% · 天 23% · 外 11% · 地 13%（反装陷阱——中缝 44% 断层，外缘紧逼拇指）
  - `方案 D`：内 6% · 天 6% · 外 7% · 地 7%（满版窒息——单行过长且文字坠入装订缝）
- **第二题（宽屏网页手稿容器）**：同一篇中文长文在 1440px 桌面屏上只差行宽约束策略（`方案 A` 纯 15% 左右留白、`方案 B` 锁定 `max-width: 34em` 居中自适应留白、`方案 C` 极窄 `14em` 窄条、`方案 D` 全屏 94% 铺满），正解为 `方案 B`。
