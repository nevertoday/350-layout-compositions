# 311 平面调度（PLANAR ARRANGEMENT）设计方案

## 1. 一句话道理
把摄影机摆正或把元素压进同一二维平面后，透视纵深退场，画面好不好看完全取决于各元素在平面上的位置分布、阿恩海姆杠杆重量平衡、图底对比与疏密节奏能否同时成立。

## 2. 开场玩具
- **名字**：二维平面调度桌（立面归正 × 构成四维校调）
- **玩法**：
  1. 拖动舞台下方的**「镜头立面角游标」**（标有 `data-perf-drag`，从 `34° 斜拍` 到 `0° 垂直立面`，靠近 `0° ± 2°` 轻柔磁吸锁正），亲眼把斜角透视压平成垂直二维立面。
  2. 在画布上直接拖动原海报四大核心构件——**朱红大圆**（热色重焦点）、**米白穿孔圆**（深绿场域上的负形穿孔）、**朱红横条**（水平导向与远端杠杆配重）、**深绿竖条**（竖向结构与节奏承接）；支持鼠标、触屏与选中后的键盘方向键（`← → ↑ ↓` 微调，`Tab` 切件）。
  3. 顶部可一键切换**「海报构成」**与**「电影立面」**两套视觉外壳（共享同一 `model.js` 坐标、镜头偏角与物理重心算式，电影立面以无五官剪影人物、圆窗、红门楣与立柱呈现垂直机位场面调度）。
- **一打开的状态（错态，非答案）**：停在「斜拍挤堆」错态——机位偏斜 `26°`，四个构件挤在画板右侧偏下，米白穿孔圆滑出深绿块外、朱红横条撞压大圆、重心右偏约 `+19%`、对齐 `0` 组。四周四条原海报圆点虚线引注（上 `对齐 ALIGN` / 左 `平衡 BALANCE` / 右 `对比 CONTRAST` / 下 `节奏 RHYTHM`）实时亮出各自问题。
- **怎样算玩错与读数反馈**：不设一键通关按钮；提供「复原斜拍挤堆」与「试看死板均分」两个反面错态。`model.js` 单真源实时判定五类错误并按优先级输出白话诊断（说明「为什么」与下一步）：
  - 机位未归正（`|angle| > 2°`）：提示斜线透视把重心拉进纵深，尚未进入二维平面；
  - 图底/对比破损：米白圆移出深绿场域导致负形穿孔失效，或朱红条与朱红圆撞叠糊团；
  - 杠杆失衡：基于阿恩海姆视觉重量杠杆公式实测偏移方向与百分比，解释为何大暖块需靠远端小条拉长力臂配平；
  - 机械均分或局促挤堆：间距过于相等（变异系数过低）时明确报错「变成死板等距，缺少疏密呼吸」，而非当作平衡过关；
  - 散乱脱轴：共享对齐边/轴线少于 2 组时提示借深绿场域边缘建立秩序。
  - 五项同时成立后解锁「叠加 311 原海报轮廓」对照。
- **与最近 12 页的明显区别**：
  - 区别于 310（午夜紫暗室 Z 轴推拉纵深）：311 反向将斜角压平为 0° 暖亚麻纸平面，做二维立面构成与视觉力矩；
  - 区别于 102（2×2 四格图形雕琢）、020（黑底镜像轴）、188（白底五栏基线）、058（等轴四级台阶）、270（蓝底卡片网）、226（朱红 f Flexbox 栏）、103（3D 材质光影台）：本页为暖亚麻纸 + 深松林墨绿 + 陶红朱橘的无外框十字引注构成台，且首创「镜头 3D 斜角压平 → 2D 四向测绘虚线与杠杆平衡实算 + 抽象构成/电影立面同构」机制。

## 3. 版式骨架
- **承袭 311 原海报**：顶左厚重大标 + 英文 `PLANAR ARRANGEMENT` + 细横线总述，顶右原海报同款细单线正圆徽记（「视觉组织 / 基础原理」）；中央暖亚麻纸无外框十字开放舞台，四周直连四条带圆点端头的虚线引注；底沿细黑线承接游标、构件选槽与白话诊断。
- **1440×900**：整版纵落一屏收齐；画布宽约 `840px`（连两侧引注共 `1240px`），2560×1440 容器舒展至 `1840px`、画布放大至 `1180px` 宽，饱满不留空洞。
- **1024×1366 / 768×1024**：不锁 `100svh`，按内容自然收紧，避免平板竖屏留白。
- **390×844**：压紧顶栏与标题，正圆徽记缩小同行排布，主画布 + 四维状态条 + `data-perf-drag` 镜头游标稳占首屏 ≥ 48% 高度，等比绘制圆不变椭圆，按钮高度 ≥ 42px 不换行。
- **844×390（横屏）**：压单行顶带（42px），下方切为左 58% 等比画布 + 右 42% 游标、四维指标与白话诊断，无横向溢出。

## 4. 配色和字体
- **配色（实采自 311 原海报）**：
  - 暖亚麻主纸底 `#E5DDD2`、浅宣纸次底 `#F3EEE5`、次暖石 `#DAD0C2`
  - 深松林墨绿主色 `#1E3B2F`、正文深墨绿 `#0F1F18`、反白暗节底 `#162C22`
  - 陶红朱橘强调色 `#D95C3D`（浅纸小字加深至 `#A83B20`，保障高对比度；暗底提亮至 `#F07A5B`）
- **字体（全库唯一；两款西文均为最近 12 页未用）**：
  - `Noto Sans SC`（400 / 500 / 700 / 900）：原海报厚实方正大标与清晰中文正文（正文西文人名年份同字体，防混排跳动）
  - `Space Grotesk`（400 / 500 / 700，**最近 12 页未用**）：现代几何构成全大写标题、引注、关键词与标尺数字
  - `Libre Baskerville`（400 italic，**最近 12 页未用**）：仅用于英文总述斜体与独立理论引语副行

## 5. 节目录（8 节，标题均 ≤ 12 字，相邻节交互不重复）
- **01 压扁空间，换来秩序**（浅宣纸）：为什么影视场面调度有时刻意放弃纵深、将机位摆正；四档摄影机位与焦段胶片卡切换（24mm 斜角 / 50mm 半斜 / 85mm 正对立面 / 135mm 压缩平面），同步看俯拍机位几何图与成片立面框。一句话链接 310 与 314。
- **02 四维法则，一图同生**（深松林墨绿反白）：展开原海报三大核心要点与四条引注；原海报构图 X 光解剖镜，点击 4 枚原海报圆点层（对齐/平衡/对比/节奏）叠加或单看隐藏几何结构。
- **03 视觉重量，不是面积**（暖亚麻纸）：阿恩海姆杠杆原理与非对称平衡；物理视觉天平实验室，点击切换右侧砝码的形状、颜色与杠杆槽位（近/中/远），看真实物理倾角与经验力矩比（标明示意）。
- **04 疏密有喘息，才成节奏**（次暖石纸）：拆解「等距 ≠ 秩序」；8 格视觉节拍带点按切换（大块/细条/点阵/留白）与 3 组范式对比，实时画密度波与停顿节奏读数（标明经验值）。一句话链接 312 与 313。
- **05 从画框到银幕的脉络**（浅宣纸）：可核实历史源流（1915 沃尔夫林 → 1926 康定斯基 → 1954/1974 阿恩海姆 → 1997/2005 波德维尔与电影平面调度）；四时期时间轴切卡 + 同步演化平面结构图。
- **06 什么时候别用平面调度**（深松林墨绿警戒）：四类翻车边界（惊悚临场感、狭小空间广角畸变、强单点汇聚需求、杂乱背景粘连）；四场景翻车 vs 改法双画幅对照切卡，顺带链接 310/312/313/314。
- **07 小练习：挑出成立的一版**（暖亚麻纸）：A/B/C/D 四版同元素同尺寸方案的平面排布考题，选项标签全中性，仅差单一变量，选后在画布上叠画重心与对齐线并给详析。
- **08 原海报与关键词档案**（浅宣纸）：原海报可点开灯箱（缩放/拖动/Esc 关闭、`draggable="false"`）、核心要点三图标、五关键词与 7×7 陶红点阵、同小类互链与页脚。

## 7. 小练习
- **题干**：以下四幅 0° 垂直立面平面调度均使用完全相同的四件元素（深绿主墙、朱红大圆、米白穿孔圆、朱红细条），仅在位置安排上改变了一项变量。哪一版同时稳住了对齐秩序、非对称杠杆平衡与疏密节奏？
- **选项（全中性标签，各差一个变量）**：
  - `A · 右侧对齐方案`：对齐工整，但重心严重右坠（杠杆失衡）。
  - `B · 横向等距方案`：重心居中，但四件间距完全均等且穿孔圆移出深绿块外（失疏密节奏与图底对比）。
  - `C · 左远右近方案`（**正确答案**）：深绿场域与朱红大圆锚定中右，朱红细条左伸拉长力臂配平重心，米白圆在深绿内穿孔并对齐顶轴，聚散留白分明。
  - `D · 中心聚叠方案`：重心也居中，但朱红横条压入朱红大圆且边缘全脱轴（撞叠糊团、无对齐秩序）。
