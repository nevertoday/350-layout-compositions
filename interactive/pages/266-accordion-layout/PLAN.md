# 266 手风琴布局（ACCORDION LAYOUT）方案

## 1. 一句话道理
手风琴布局通过**渐进式折叠（Progressive Disclosure）**把纵向长内容收束为可扫描的标题目录，按需展开单一或少量面板，在压缩页面高度、建立收放节奏与保留上下文之间取得平衡；但每一次折叠都会付出可见性下降与点击成本，只有当用户只需查看其中部分条目、且标题本身自带明确信息气味时才有效。

## 2. 开场玩具：活体风琴折页台（Live Concertina Accordion Bench）
- **玩法**：由上方 1:1 转译原海报的**7 折朱橙/珊瑚橙双面风箱画布**（2D Canvas，标 `data-perf-drag`，两侧保留原海报 `••••• →` 与 `→ •••••` 导流箭）与下方**真实可点、完整 WAI-ARIA 键盘可达的 HTML 手风琴面板**双层实时联动。
  - 在朱橙风箱画布上**左右横拖**，物理拉展/收紧风琴折页展开幅（控制折页张开度与视口压缩节奏），折角明暗实时变化，大标题「手风琴布局」字距亦随张力微调；
  - **直点风箱任意折面**或**直点下方手风琴标题行**（也支持 `↑`/`↓`/`Home`/`End`/`Enter`/`Space` 键盘操作）真实展开/收合对应面板；
  - 切换 3 套真实界面语境（**售后 FAQ** / **产品长篇说明** / **系统偏好设置**），并通过四把真实设计杠杆调节：**展开策略**（互斥单开 / 多开并行 / 全摊不开 / 全闭锁死）、**标题气味**（模糊盲盒 vs 具体自解释）、**折标指示器**（无图标 / 右箭头 `→` / 加减号 `+/−` / 展开角标 `▾/▴`）、**嵌套层级**（单层平铺 vs 手风琴套娃）；
  - 按 **`Space`** 发射「视线流光验读」，沿 `••••• →`、各折页标题、展开面板与 `→ •••••` 走出真实扫视路径，并在错态处显影受阻回弹。
- **开场状态（绝非答案）**：刻意停在 **0/4 四重翻车态**——同时摊开 4/6 项（失去压缩意义）+ 模糊盲盒标题（「模块一·详情」「更多说明」等）+ 无折标图标（像跳转链接）+ 双层手风琴套娃（点击翻倍）。
- **双向玩错与单真源读数**：`model.js` 从当前真实展开数、标题可见占比、折叠幅宽、折标类型与层级深度单真源计算 4 项诊断（对应原海报「折叠 / 节奏 / 层级 / 延展」），双向检出 8 类错态：全摊退化、全闭盲盒（无气味全闭）、过度挤压（<24% 标题裁切）、拉平失褶、模糊标题、无折标、右箭头歧义、双层套娃。读数不报假精确分数，只给档位（示意）与白话解释「用户此刻会怎么看、为什么错」。同时认可**多组合法解**：经典互斥单开解、双面板多开对照解、强气味全闭索引解，均可达成 4/4。
- **与最近 12 页的差异**：近 12 页全是平面构图、绕排、对齐、行内/块级流或天平/尺度画布；本页是真实的**可折叠交互 UI 组件 + 物理风箱折页联动机构**，核心动作是「点折面展开收合 + 横拉风箱张弛 + 检验折标/气味/嵌套/策略对查找效率的影响」，任何其他编号都无法套用。

## 3. 版式骨架
1:1 转译 266 原海报「暖骨宣纸垂直风箱展页」骨架（绝不锁 `100svh`，杜绝平板空白）：
- **1440×900**（主宽 `1360px`；**2560×1440** 舒展至 `1580px`）：顶部紧致单行刊头（左自示范大标「手风琴布局」+ `ACCORDION LAYOUT` 与短黑线，右三语境切换与验读键）→ 全宽朱橙 7 折物理风箱画布（左右配原海报 `••••• →` 与 `→ •••••`）→ 齐底 62% : 38% 活体手风琴工作台 × 单真源白话诊单与杠杆台 → 1:1 复刻原海报四栏竖细线要点实时探针带（折叠 / 节奏 / 层级 / 延展）→ 底沿细线关键词条。
- **1024×1366 / 768×1024 平板**：自然文档流，无 `100svh` 锁高；全宽风箱画布 + 齐底手风琴与诊单 + 2×2 四栏要点带，零大块空白。
- **390×844 手机竖屏**：单行压紧刊头、后置导语长句，让全宽风箱画布 + 活体手风琴首两项 + 诊单首句与主操作键稳占首屏 ≥ 50%，触屏纵向顺畅滚动、横向拖风箱流畅。
- **844×390 手机横屏**：左 54% 风箱画布与紧凑活体面板 × 右 46% 标题与诊单快控并行，等比不压扁。
- **正文七节明暗交替**：亮奶白纸 → 暖燕麦纸 → **03 深焙炭咖暗室** → 暖骨原纸 → 亮奶白纸 → **06 深焙炭咖考场** → **07 暖骨原海报展墙 + 极深墨页脚**。

## 5. 节目录（01–07）
- **01 折叠与代价**（`FOLDING & INTERACTION COST`）：引原海报总述并温和补注「折叠省高度但增加点击与发现成本」；交互：**三类真实翻找任务对比器**（查单条 FAQ / 通读合同 / 横向对比套餐），实时对比手风琴与平铺单列（链向 255）的视口占比、点击税与 `Ctrl+F` 可达性。
- **02 折标与气味**（`SIGNIFIERS & SCENT`）：拆解 NN/g 2020 折标研究与标题信息气味；交互：**四类折标真手风琴试按台 + 整行/裂开点击区透视开关**（角标 `▾/▴`、加减 `+/−`、右箭 `→`、无图标）。
- **03 展开机制暗室**（`MOTION, ARIA & DETAILS`）：暗室剖析展开动效节拍、高面板收合防跳屏、WAI-ARIA 键盘契约与 2024 原生 `<details name>`；交互：**2D Canvas 折叠运动学与防跳屏实验舱 + 实时同步原生 `<details>` 代码窗**。
- **04 从经折装到网页**（`LINEAGE & EVOLUTION`）：从晚唐五代宋代「经折装」与 19 世纪风琴风箱/Leporello 折页，到 1984 Carroll & Carrithers「Training Wheels」、2006 Jakob Nielsen 渐进式披露、WAI-ARIA APG 与 2024 原生 `<details name>`；交互：**可展开折叠的五代形态史折页带**。
- **05 什么时候别用**（`WHEN NOT TO USE`）：明确 4 条禁用红线与同小类替代路线；交互：**四维项目分诊开关**，实时开出「保留 266」或改用 255 单列 / 258 侧边栏 / 265 标签页 / 267 列表—详情 / 263 导航抽屉的处方。
- **06 小练习**（`DIAGNOSTIC QUIZ`）：暗室两道单变量控制诊断题（中性标签方案 A/B/C/D，四项线框图视觉同工，每项只差一个变量），选完即出深度解析。
- **07 原海报与关键词**（`ORIGINAL POSTER`）：点击可放大拖拽的原海报展墙、原海报构图与色彩拆解、四组中英关键词与标准页脚。

## 7. 练习设计
- **题 1（手机端 6 条独立售后 FAQ，用户通常只查 1 条）**：四张等精致度微型手风琴线框卡，标签只写 `方案 A` / `方案 B` / `方案 C` / `方案 D`，每项仅改一个变量：
  - A（正解）：单层 6 项 + 具体自解释标题 + `▾/▴` 角标 + 首项展开；
  - B（错项）：仅将标题换成「条款一 / 更多详情」等模糊词（破坏信息气味）；
  - C（错项）：仅将角标换成右箭头 `→`（引发跳转新页歧义）；
  - D（错项）：仅把 6 项塞进两层嵌套母子手风琴（增加点击税与迷失感）。
- **题 2（5 节短篇租赁服务协议，要求用户通读全文并常按 `Ctrl+F` 检索条款）**：四张线框卡仅改变展开/披露策略：
  - A（正解）：全文自然展开单列分段配顶部锚点（255 思路——需要通读与全文搜索时不应用手风琴）；
  - B（错项）：互斥单开手风琴，默认只开第 1 节；
  - C（错项）：多开手风琴，默认全闭需逐条点开；
  - D（错项）：两层嵌套手风琴折叠全部条款。
