# 203 放射网格（RADIAL GRID）互动页方案

## 1. 一句话道理
正交网格让所有单元格生而平等，而放射网格先确立一个不可动摇的视觉圆心，再以同心环区分信息层级、以射线引导视线走向：离圆心越近权重越高，沿射线向外扩散既天然归纳从属关系，又带来等距直达与外向动势。

## 2. 开场玩具
- **名字**：活体星盘放射排布台（Radial Astrolabe Composer）—— 2D Canvas 1:1 化用 203 原海报的深松石绿星盘、四角星金日圆心、乳白主射线、细金副射线、同心金环与外环 8 枚金色模块徽章，并可一键切换「原海报星盘 / 用户中心图谱 / 环形快捷轮盘」三套真实题材。
- **怎么玩**：
  - **画布直操（`data-perf-drag` 标在星盘主画布上）**：在圆心区域或画布空白处左右横拖，直接连续缩放核心圆盘半径（`11%–42%`），实时观察圆心权重与周边模块的压迫/失权临界点；直接点击或拖拽画布上带赤红警示圈的漂移模块归回同心环与射线交点；直接点击画布中心交叉的乱弦红标切换为由圆心辐射的径向主线；也可拖动任意模块体验偏轨脱环或制造扇区偏聚。
  - **下方精控条**：直接切换主射线数（`3 / 6 / 8 / 12 / 16`）、扇区分布（`偏聚塌空 / 等分对称 / 韵律交替`）、外环模块尺寸衰减（`外强倒挂 / 平权无序 / 逐级递减`）与连线文法（`跨心乱弦 / 径向射线 / 射线+双环`），同时提供三组合法参考解与「复原 0/4 错态」。
  - **键盘操作**：选中星盘画布后 `← / →` 微调核心半径，`↑ / ↓` 增减主射线数，所有控件均为原生 `<button>` / `<input type="range">`。
- **一打开是什么状态（绝不先给答案）**：
  - 刻意停在 **`0 / 4 待校准`** 典型放射失序错态：
    1. 核心半径缩到 `13%`（核心面积仅为外环模块的 `0.7×`，**圆心失权**）；
    2. 主射线开到 `14` 路且向右侧挤压偏聚，左半环塌空、右半环挤撞（**过密 + 偏聚失衡**）；
    3. 外环模块尺寸反超内环呈 `1.26×` 倒挂，且 2 枚模块分别脱轨撞心、飞出环外（**层级倒置 + 偏轨漂浮**）；
    4. 连线采用跨心乱穿弦线而非径向放射（**视线打结断流**）。
- **怎样算玩错、错了读数怎么说**：
  - `model.js` 从真实绘制的圆心半径、同心环半径、射线角度序列、各模块坐标与边界距离单真源实时核算 **10 类几何失误**：圆心失权（核心面积比 `< 1.8×`）、圆心胀满吞环（`coreR > 33%`）、射线过密挤撞（`> 10` 主射线或最小弧距不足 `1.15×` 节点径）、射线过疏散架（`< 4` 路）、扇区偏聚塌空（最大/最小扇角比 `> 1.65` 且非对称韵律）、层级倒置（外环尺寸 ≥ 内环）、环距贴撞、模块偏轨脱环、跨心乱弦打结、节点超载拥挤。
  - 每次误操作都会在右侧原海报风格诊单中用白话讲清「为什么眼睛会看乱」（例如：圆心只占外圈圆盘 0.7 倍面积，视线进场先被边缘大圆拉走，失去「以中心为源」的起点），并给出一步可执行提示；接受「原海报八射线双环解」「六射线用户图谱解」「十二射线韵律交替解」及任意符合几何秩序的自调组合。
- **与最近 12 页的区别**：
  - 不同于 202（暖米宣纸 4×3 拖列行缝）、201（绿白分栏 8×8 拖方格宽高比）、034（暗李紫 V 形双翼聚光）、323（漆墨黑单角四分之一圆扇定向）、242/243（容器/垂直堆栈）、284/285（活体表单），本页以 **203 原海报独有的圆弧自示范拱形刊头 + 左三要点 / 中央正圆星盘 / 右三要点与实况诊单的星盘对称三翼展开** 为骨架，操作对象聚焦在放射网格独有的「圆心权比、射线疏密与扇区均度、同心环层衰减、径向辐射路径」。

## 3. 版式骨架
- **忠实承袭 203 原海报**：深松石绿全幅夜空星盘（`#013D35`，绝不锁 `100svh` 避平板空洞）→ 顶部弧形拱起的自示范大标 `放射网格` + 弧形 `RADIAL GRID`（大标拱度与两侧金星光翼随星盘秩序状态微调呼应）→ 中央 **三翼星盘展开**：左 24% 原海报三要点实况（层级 / 方向 / 动感 + 实时核心面积比徽标）、中 52% 正圆 1:1 活体星盘画布、右 24% 原海报三要点实况（中心 / 放射 / 模块 + 单真源白话诊单）→ 底沿细翠绿边框控槽带（呼应原海报底端双框与 `✦` 分隔线）。
- **1440×900 / 2560×1440**：1440 主宽 `1380px`，中央星盘约 `540×540px`，左右双翼高度与星盘自然平齐零留洞；2560 舒展至 `1720px`，星盘同步放大至约 `650×650px`。
- **1024×1366 / 768×1024（平板竖屏）**：自然流式转排——压缩拱形刊头 → 居中大号正圆星盘 → 下方双栏并排「单真源诊单 + 精控条」与「六要点 2×3 实况矩阵」，不锁 `100svh`，零上下空洞。
- **390×844（手机竖屏）**：单行紧凑刊头（约 72px）+ 精简题材切换行（约 36px）→ **1:1 正圆星盘画布（约 358×358px，稳占首屏 ≥ 45% 屏高，永不压扁成椭圆）** → 首屏底沿同屏可见诊单核心句与一键操作条；画布 `touch-action: pan-y` 保证上下滚动顺畅。
- **844×390（手机横屏）**：切左 50% 正圆等比星盘（约 `336×336px`）× 右 50% 紧凑刊头、单真源诊单与快选芯片并行，不裁切、不压扁。
- **正文七节明暗交替**：在古星图暖宣纸（`#F7F2E6`）、淡青瓷宣纸（`#E7F0EC`）、03 节深松石绿暗室（`#01322B`）、暖沙稿纸（`#EFE6D2`）与 07 节深松石绿原海报展墙（`#013D35`）之间交替推进。

## 7. 练习
- **题干**：以下四张「以用户为中心」的 6 节点产品图谱素材完全一致，仅改动了一项放射网格结构，哪一盘的视觉秩序最成立？
- **四个选项（标签仅写 A / B / C / D，不泄露好坏，每项只差一个受控变量）**：
  - **A**：6 节点等分 60° 落环、径向连线清楚，但中心圆与外环 6 圆直径几乎一致（`1.05×`），圆心缺乏视觉主权，7 个圆彼此抢戏。
  - **B**（**正确答案**）：中心圆直径为外环节点的 `2.1×`（面积 `4.4×`），6 节点沿 60° 等分射线落在同一外环，径向引导线直达各节点且标签水平直排，主次层级、方向引导与空间节奏同时成立。
  - **C**：中心圆大小合规、外环缩放得当，但 6 个节点全部偏聚在右半圆 150° 扇区内，左侧整片塌空，视觉重心严重偏斜。
  - **D**：中心圆够大且 6 节点等分外环，但连线放弃从圆心辐射，改成跨心互连的网状交叉弦线，视线在中央反复打结，无法读出从中心向外扩散的层次关系。
