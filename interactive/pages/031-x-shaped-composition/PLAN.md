# 031 X形构图 · 互动版方案（PLAN）

## 1. 一句话道理
两条反向对角线在画框内相交成 X：单条斜线偏离横竖稳态坐标、激发动势与失重张力，第二条反向斜线拉住倾倒趋势并在交点锁出强焦点，让画面同时拥有「动态张力」与「对冲平衡」。

## 2. 开场玩具：活体 X 剪刀楔形剪切台（Live X-Wedge Shear Arena）
- **玩法**：直接化用 031 原海报「左右双赤橘朱红楔块夹出暖米白 X 通道 + 深松石青双向虚线轴 + 居中焦圆」的独特图形语言。
  - 在全幅 2D Canvas 舞台（标 `data-perf-drag`）上**左右横拖**，像拉动光学剪刀连杆一样连续改变双对角线的**剪刀夹角**（16°–148°），双楔块、通道开口、视线流速度同步实时演进；
  - **直接拖动深松石青焦圆**定位交汇焦点，或拖动双楔配平标、点击清除右翼通道上的灰暗阻断块；
  - 切换三套真实题材视口（`原海报双楔` / `冲刺海报` / `城市天桥`），并与原海报下半「张力与平衡」四枚赤橘圆章实时联动；支持键盘 `←/→` 调夹角、`↑/↓` 调配平、`W/A/S/D` 移焦圆。
- **开场错态（绝不是答案，0/4 翻车态）**：
  - 夹角扁塌至 26°（近乎水平浅叉，毫无对角动势）；
  - 左赤橘楔肥大、右楔萎缩（面积比约 2.7:1，左右失衡倾覆）；
  - 深松石青焦圆脱位至左下象限（偏离交点 28%，交汇处空心）；
  - 右上通道被阻断条截断，视线粒子冲到一半撞墙折返。
- **怎样算玩错 / 读数说什么「为什么」**：
  - `model.js` 从实绘双楔顶点与交点坐标单真源实算 8 类失误：`扁塌退化`（夹角 < 36° 像横带）、`尖夹窒息`（夹角 > 112° 挤扁中心）、`单斜滑倒`（缺副对角线无互锁）、`平行不交`（双斜平行视线散逸）、`左右倾覆`（双楔面积比 > 1.38）、`通道闭塞`（通道留白 < 18% 或过宽 > 68%）、`焦点脱核`（焦圆偏离交点 > 9%）、`路径截断`（通道存在阻断块）。
  - 读数不仅报几何值（夹角、焦偏、双楔面积比、通道占比，凡心理体验档位均标「示意」），还用白话直说人眼此刻为什么会滑走、偏沉或失焦，并给出下一步调校动作。
  - **多组正当解**：同时认可「经典对称 X 解」「动感偏交 X 解（交点微上提或微偏但双楔稳衡）」「紧凑锋刃 X 解」。
- **与最近 12 页的区别**：
  - 区别于 030 十字构图（冷雾蓝正交轴角+四臂圆点配重+实蓝底带）：031 是**斜向双楔剪切负形通道 + 剪刀开合角 + 双侧赤橘楔面积对冲 + 沿四翼向心穿越的视线粒子流**；
  - 区别于 029（四象限方阵）、114（随机散布）、113（深紫 S 丝带）、067（包豪斯三层叠压）、152（暗房胶片咬合）、236（瀑布流砌墙）、197（四区面积分割）、281/280/153/319。

## 3. 版式骨架
忠实承袭 031 原海报「左大标右上徽不对称刊头 → 全幅出血左右双楔贯通式 X 舞台 → 下半 48% 实测诊单与三圆章 × 52% 深松石细框张力平衡检核盒 → 底沿圆点标语箭头收脚」（不锁 `100svh`，零深色圆角仪表盘感）：
- **1440×900**：主栏宽 1360px（X 舞台视觉满幅铺开），紧凑刊头 ~110px + 完整 X 剪切舞台 ~430px + 操控细轨 + 下半双栏头部自然落入首屏；**2560×1440** 舒展至 1820px，舞台与双栏在首屏全览，两侧不空。
- **1024×1366 / 768×1024**：自然流式排布，不锁屏高，零空洞。
- **390×844**：压紧单行刊头（仅大标、英文副标与题材切签，总述下移），近方等比 X 剪切舞台占首屏 ≥ 46% 屏高（圆真圆不拉扁），下方紧跟横向触控条与白话诊单主句。
- **844×390**：横屏切为左 55% 等比 X 舞台 × 右 45% 刊头、白话诊单与快控并行。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻控件不重复）
- **01 对角相交为什么锁人眼**（洁净稿纸）：拆解斜线效应与双斜对冲互锁机制；交互：**四阶步进力学解剖与脉冲发射**。
- **02 X 构图的四大变化参数**（暖燕麦原纸）：讲清夹角、偏交、显隐骨架与负形通道；交互：**2×2 实战海报样本切镜 + 显/隐 X 骨架剥离开关**。
- **03 张力失控的四种翻车现场**（深松石暗室）：拆解过扁/过尖、失衡、交点空心与五点抢戏；交互：**暗室病灶点检与原地翻牌对比诊台**。
- **04 从巴洛克到瑞士海报**（淡松石雾纸）：核实过的 1610–1972 历史演进脉络；交互：**四时代胶片轴切换与纯几何骨架复原**。
- **05 什么时候用，什么时候别用**（暖燕麦原纸）：原海报场景展开、温和补正、不适用反例及 032–040 同小类兄弟页分流链接；交互：**6 枚真实项目卡适用性分拣台**。
- **06 挑一挑：哪张 X 最立得住**（洁净稿纸）：两道单变量对比练习题；交互：**4 选 1 精绘 SVG 海报卡挑选题 + 视线箭头复核**。

## 7. 练习设计
- 两道递进选择题，选项标签只写中性描述（不泄露好坏），四个选项严格只差一个变量：
  - 题 1 考「焦点与交点关系」（中轴交汇 vs 左侧楔缘 vs 跨翼满铺 vs 四角分置）；
  - 题 2 考「夹角与双翼互锁」（18° 浅斜 vs 62° 互锁 vs 45° 单斜 vs 142° 锐夹）。
  - 选完当场展开白话理由，并在每张选项 SVG 上显露真实对角视线流与焦点锚点，让读者彻底明白对在哪、错在哪。
