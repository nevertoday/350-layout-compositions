# 114 随机节奏组织 · 设计方案（PLAN.md）

## 1. 一句话道理
随机节奏不是把元素随手乱丢，而是先立住 1–2 处视觉重心，再在最小呼吸间距与视觉配重的暗线约束下打破行列、拉开大小与疏密，让画面在看似自由的错落里依然稳重、透气、有呼吸感。

## 2. 开场玩具（活体随机散布编排台）
- **核心动作**：直接在无框青瓷宣纸主画布（`data-perf-drag`）上操作——
  1. **横拖 / 扫动「拨散推笔」**：在画布空白处拖动，用轻弹力排斥把锁死的行列推散、把扎堆粘连的碎形拨开；
  2. **直拖双重心锚点**：直接拖移大深青圆或大朱红圆，实时重设画面视觉重心与对角配重；
  3. **点击任意图形**：轮换尺度层级（小碎点 → 中节拍 → 大重心），配合底部四维快切钮（尺度层次 / 散布方式 / 色彩平衡 / 重心透视）、三题材切换（原海报几何 / 爵士节拍谱 / 星野海报墙）与键盘微调（`Tab`/`[` `]` 选形、方向键挪位、`+`/`-` 调级）。
- **开场初始态（0/4 经典翻车错态）**：开场绝不直接给答案。16 枚等大中号墨黑圆形锁死在左偏 4×4 机械网格里——`尺度跨比 1.0×`（全员等大）、`近邻距差 0.03`（死板等距）、`行列锁死 96%`（毫无破序）、`重心偏左 18% 且单墨闷平`（失衡无对比），读数与四列要点全部诚实标红待立律。
- **怎样算玩错 & 读数怎么说为什么**：全部数值由 `model.js` 从实绘图形几何坐标与面积单真源实算，覆盖 8 类错态：
  1. **全员等大**（跨比 `< 2.2×`）：眼睛找不到落脚的重心，整幅扫成平淡背景；
  2. **巨块霸屏**（大形过多 / 占比 `> 38%`）：重块互挤，失去轻重对比与呼吸空间；
  3. **机械等距**（近邻距变异系数 `CV < 0.18`）：间隔一模一样，退化成静态重复或底纹；
  4. **纯随机粘连扎堆**（点击「纯随机掷骰」即可主动踩坑！碰撞 `≥ 3` 处或单区扎堆）：展示为什么无约束的 `Math.random()` 会撞车留秃斑；
  5. **行列锁死**（对齐锁死率 `> 62%`）：坐标贴在横竖隐形轨道上，缺乏不确定与跃动感；
  6. **贴边空心 / 过稀散架**（中心掏空或总占比过低）：元素贴墙游离，彼此接不上话；
  7. **重心塌偏**（光学重心偏移 `> 14%`，点「单边堆重」可主动踩坑）：重块全压在一侧，画面像斜掉的托盘；
  8. **单色闷平**：缺少青/朱/黑对比，视觉重心与次要碎点拉不开层次。
  同时接受多种合法解（原海报双锚蓝噪解、单锚群星解、疏密双聚落解、换种子再撒解），靠看懂道理调成而非点满按钮。
- **与最近 12 页的差异**：最近 12 页分别是丝带样条（113）、瀑布流砌墙（236）、叠层 Z 序（067）、四区切墙（197）、双轴四象限（029）、树形目录（280）、胶片接缝（152）、三远山水（318）、渐进阶梯（112）、粘性滚卷（235）、模块化拼块（196）、偏轴圆窗（028）；本页是唯一基于「物理拨散推笔 + 泊松蓝噪/白噪对比 + 视觉重心力矩配平」的开放散布场，零撞车。

## 3. 版式骨架（忠实承袭 114 号原海报）
- **1440×900（宽屏 2560 扩宽至 1780px）**：整张首屏无缝铺在 `#E7F3DF` 青瓷宣纸底上（不锁 `100svh`，避免平板大白洞）。上方极细顶眉 → 上半双区开放融合：左 34% 排自示范跳动基线大标「随机节奏组织」、`RANDOM RHYTHM`、短墨杠、`随机 / 平衡 / 疏密 / 活力` 实况斜杠条、原海报中英总述与原海报招牌双联小窗「■ 疏与密的对比 SPARSE vs. DENSE」；右 66% 无重框铺开巨幅散布主画布与轻薄操控条 → 下半完全复刻原海报底带：左 65% 为「■ 关键要点」四列细竖线实检柱（各带原海报同款几何小图与实时单源指标），右 35% 为原海报标志性的**虚线圆角边框 + 朱红六角星 `*` 教学提示/白话实测诊单盒**。
- **1024×1366 / 768×1024 平板**：自然高度流式排布，单行刊头下全宽铺开散布画布，下接「疏与密双窗 + 虚线星号诊单盒」双栏与四列关键要点，绝无空洞。
- **390×844 竖屏**：压紧单行刊头，让无遮挡 6:5 等比散布画布直落首屏稳占 `≥ 47%` 屏高，紧接一行高触控快控钮与虚线星号诊单主句，首屏一眼看清玩什么、错在哪。
- **844×390 横屏**：左 56% 散布主画布与快控条 × 右 44% 紧凑刊头、斜杠实况与虚线星号诊单盒并行。

## 5. 节目录（01–08，标题全 ≤ 12 字，相邻两节零重复控件）
- **01 为什么真随机反而不像随机**（*White Noise vs. Blue Noise*）：白噪声扎堆 vs 泊松盘蓝噪声受控随机；交互：**左右可拖拉的同源分屏对比帘** + 同批种子重掷。
- **02 疏与密：快拍与长休止**（*Sparse vs. Dense Tempo*）：展开海报「疏与密的对比」与四要点，温和补注「让元素自由散布，节奏自然浮现」说轻了一点；交互：**三张画片 + 人眼节拍扫描模拟播放**（点击看视线在疏密间的停顿快慢）。
- **03 暗室实测：无形重心怎么配**（*Optical Weight & Counterweight*）：深墨青暗室讲 Arnheim 视觉重量与小高饱和抗衡大面积低饱和；交互：**可倾斜二维视觉力矩天平**（切换右侧配重块观摩杠杆摆动）。
- **04 从哪来：偶然与受控随机**（*From Dada Chance to Blue Noise*）：Arp 1916–17、Kandinsky 1923/1926、Arnheim 1954/1974、Bridson 2007 与 Lupton/Phillips 2008/2015；交互：**四时期年份档案抽屉**配极简构成图示。
- **05 同一小类：八种节奏分工**（*The Rhythm Family Map*）：107–114 从强秩序到自由节奏的光谱定位，每页一句话加在线版链接；交互：**设计诉求筛选高亮条**。
- **06 什么时候用，什么时候别用**（*When to Use & When Not*）：适用与禁用场景边界；交互：**音乐节海报 vs 航班登机牌双实景对照翻切**（一眼看出何时鲜活、何时灾难）。
- **07 小练习：挑出成律的一张**（*Spot the True Random Rhythm*）：中性 A/B/C/D 四图只差「空间散布与平衡」单变量；交互：**四选一实时叠加最小间距圈与重心线判卷**。
- **08 原海报与关键词**（*Original Poster & Keywords*）：原海报点击放大/拖动/Esc 关闭 + 四枚关键词徽章 + 标准页脚。

## 7. 练习题设计
- **题目**：四张同比例画片包含完全相同的 14 枚青/朱/黑几何元素与相同的 2 枚大重心圆，**只改变空间散布与重心平衡方式这一个变量**。哪一张真正形成了既有活力又稳得住的随机节奏？
- **四项差异（中性标签 A / B / C / D）**：
  - `A`：元素中心贴在隐形等距网格交叉点上（仅靠大小变化假装随机，间距僵直）；
  - `B`：纯白噪声 `Math.random()` 随机落点（右中部 5 枚元素粘连撞车，左上角留下大块失衡死白）；
  - `C`：**泊松蓝噪最小呼吸距 + 疏密双区起伏 + 青朱双锚对角配平（正确答案）**；
  - `D`：全部元素贴紧画框四边环绕，中央掏出大片空洞，视线无法在中间停留呼应。
- **揭晓反馈**：选中后四张小图立即叠加最小间距虚线圆与视觉重心偏移标，逐一说明 A 呆板、B 扎堆、D 空心，唯独 C 在破序中守住疏密呼吸与整体重心。
