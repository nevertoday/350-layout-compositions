# 206 子网格（SUBGRID）互动页设计方案

## 1. 一句话道理
普通嵌套网格像在母框里另起一套小尺子，一旦父列缩放或隔壁卡片文字变长就会参差错轨；子网格把父网格的行、列轨道直接接通到孙元素内部，既让跨模块、跨层级的内容严格锁在同一套全局秩序上，又允许每个局部按需调整跨度与内部细节。

## 2. 开场玩具
- **命名**：全幅克莱因蓝 12 列活体轨道晒图台（1:1 承袭并活化 206 原海报的 12 列贯通蓝图：顶黄通栏主标题 + 左 6 列三特性卡片 + 右 6 列动态实测对齐率大环 + 底部 01/02/03 列表，可切换「原海报蓝图 / 三栏定价卡 / 双栏嵌套表单」三套实景）。
- **怎么玩**：
  1. 在 2D Canvas 蓝图画布上直接左右横拖（`data-perf-drag`），实时改变父网格的栏距与非对称列轨偏置，亲眼观察没接通 `subgrid` 的孙元素如何迅速脱轨漂移、接通后又如何像磁吸一样紧贴 12 条贯穿父线同步伸缩；
  2. 直接点击卡片中的「特性二」拉长或缩短文字行数（1–3 行），测试不等高内容引发的跨卡行锯齿；
  3. 开关列继承（`columns: subgrid`）、行继承（`rows: subgrid`）、切换行跨度（`span 2` / `span 3` / `span 4`）与子网格局部栏距（继承父值 / 紧贴 0px / 减半微调 / 倒挂放大）；
  4. 支持方向键微调父栏距、`Tab` 切焦操作全部原生控件，点击画布红标或右侧原海报四枚要点徽可直接聚焦或定位错项。
- **开场初始态（绝不给答案）**：刻意停在 `0/4 跨层错轨` 错态——
  - 列轨独立嵌套（写死独立 `1fr` 加额外内边距，孙元素左缘相对父网格线偏差实测可达十几至二十余像素）；
  - 未开行继承且特性二已折成 3 行长文案，三张卡片的标题底线与正文底线出现明显阶梯落差；
  - 底部 01/02/03 列表脱离父网格列线；
  - 局部栏距错设为倒挂值，打乱跨模块节奏。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 所有读数均由 `model.js` 从当前实绘像素矩形与父轨道坐标单真源核算（零写死常量，连原海报的 `78%` 大环都改由实时跨层对齐率驱动，错态约 30%–45%，修齐后达 100%）。
  - 典型真实踩坑也会被当场诊出：例如开启了 `rows: subgrid` 但把卡片行跨度设为 `span 2`（小于卡片内部的 3 段内容），画布立即呈现第 3 段内容被挤进第 2 轨叠压的红色预警，诊单直接说明「显式行轨只有 2 条，子网格不会自动建第 3 条隐式轨」；把局部 `gap` 设成 `0px` 粘连或放大到超过父栏距，诊单会指出节奏断裂。
  - 接受多组合法解：标准全继承解（继承父 24px 栏距 + `span 3`）、紧凑微调解（局部减半栏距 12px 体现原海报第 4 条「局部灵活」）、非对称主次列轨解（非等宽父轨道下依旧 100% 穿透对齐）。
- **与最近 12 页的区别**：
  - 不同于 205（嵌套网格，拖中间竖脊调父子两区划分）、204（极坐标圆盘）、246（簇群聚类）、287（三栏设置页）等所有近期页：本页聚焦「跨容器轨道传导 + 不等长文案跨卡拉平 + `span` 轨数不足挤爆 + 实时联动 CSS Subgrid 代码匣」，没有任何其他编号能原样套用这套玩法。

## 3. 版式骨架
- 忠实转译 206 原海报的「通幅国际克莱因蓝 12 列透射晒图板（绝不锁 `100svh`，避开平板竖屏大片空洞）」：
  - **1440×900（宽屏主宽 1380px，2560 舒展至 1720px）**：顶三段自示范刊头（左 36% 巨幅纯白大标 `子网格 SUBGRID` 配黄杠 × 中 34% 亮黄标语与海报原句 × 右 30% 实时联动 12 列柱标仪与达标章）→ 主区左 69% 原海报白框「主内容区」2D Canvas 活体蓝图舞台 + 紧贴底沿的精密控轨 × 右 31% 单真源诊单 + 1:1 复刻原海报四枚黄徽教学要点 + 原海报右下活体 CSS 代码匣。左右等高收齐，零一边先结束的空洞。
  - **1024×1366 / 768×1024 平板**：顶刊头自然收为两行，主舞台与右栏诊单上下自然流排，诊单与四要点改为双列网格紧咬在舞台下方，无任何强撑空白。
  - **390×844 竖屏手机**：压紧单行刊头与精简顶标，确保蓝图画布稳占首屏 ≥46% 视口高度，且同屏露出诊单首句和状态章；原海报总述后置至诊单下方；所有触控按钮高度 ≥40px、不换行、不横向溢出。
  - **844×390 横屏手机**：切为左 57% 活体蓝图画布 × 右 43% 精简刊头与诊单/快捷控轨并行布局，首屏直接可拖可看。
  - **正文 7 节节奏**：浅冰蓝晒纸（01）→ 纯白工程纸（02）→ 深克莱因蓝暗室（03）→ 浅蓝雾纸（04）→ 暖淡黄晒纸（05）→ 浅冰蓝晒纸（06）→ 深克莱因蓝展墙（07）→ 极简一行页脚。

## 5. 节目录（全部 h2 ≤ 12 字，相邻节不同控件）
- **01 嵌套为何还是会错位**（`NESTED VS. SUBGRID`）：拆解 205 嵌套网格与 206 子网格边界；控件：真实 DOM 双栏实时 CSS 属性切钮（切换 padding/border/gap 看原生渲染偏轨与激光对齐线）。
- **02 一行折行，整排拉齐**（`CROSS-CARD ROW ALIGNMENT`）：讲清行子网格的双向尺寸协商机制；控件：可增减卡片文案行数的活体三卡排字台 + 模式切换条 + 实测基线落差标尺。
- **03 秩序里的四种局部自由**（`LOCAL FLEXIBILITY`）：深蓝暗室，展开单轴继承、局部覆写 gap、命名线叠加、内部自由跨列；控件：四枚结构蓝图模式片 + 动态 SVG 轨道剖析图。
- **04 从瑞士母网格到现代标准**（`ORIGINS & TIMELINE`）：「从哪来」，严格按核实历史串联 1981 瑞士印刷模数到 2017–2023 CSS Grid Level 2 演进，并一句话链接同小类伙伴；控件：四节点编年坐标滑步器。
- **05 什么时候用，什么时候别用**（`USE CASES & ANTI-PATTERNS`）：承接原海报提示并给 4 条「别用」红线，同时温和标注原海报 `78%` 为示意值；控件：场景诊断决策矩阵卡（点击 4 组真实案例切换判定）。
- **06 挑出真正对齐的排法**（`PRACTICE · SPOT THE SUBGRID`）：4 个单变量对比选项（A 独立网格 / B 跨度不足 `span 2` / C 正解 `span 4` / D 局部 `row-gap` 过大断裂），标签中性仅写选项代号与 CSS 声明，选完展示精确几何理由。
- **07 原海报与关键语汇**（`ORIGINAL POSTER`）：克莱因蓝展墙，原海报可点击全屏放大/拖拽/Esc 关闭灯箱 + 原海报完整文字与语汇标签。

## 7. 小练习设计
- **题目**：12 列父网格内并排 3 张各占 4 列的特性卡（每卡含图标、标题、说明、日期 4 段，卡二标题折为 3 行）。以下四种 CSS 写法中，哪一种能让跨卡的标题与底部日期精确拉平且不破坏卡片结构？
- **四项单变量设计**（中性标签，不泄露好坏）：
  - `A · grid-template-rows: auto auto 1fr auto`（未继承父行轨 → 内部分界线错开）
  - `B · grid-row: span 2; grid-template-rows: subgrid;`（跨度不足 2 < 4 → 后两段挤进末轨叠压）
  - `C · grid-row: span 4; grid-template-rows: subgrid;`（正解：共享 4 条父行轨，长标题统一撑高第 2 轨，全部水平基线误差 0px）
  - `D · grid-row: span 4; grid-template-rows: subgrid; row-gap: 48px;`（局部强覆写超大行距 → 组内断裂、破坏邻近一致性）
