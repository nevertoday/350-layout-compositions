# 055 · 同心式构图（CONCENTRIC COMPOSITION）设计方案

## 1. 一句话道理
以同一圆心嵌套多层闭合环带，借格式塔「共同区域」的层层包裹与由内而外的明度/步距退让，把分散的目光逐级收束并稳稳锁在唯一核心上。

## 2. 开场玩具：同心环仪·层环校轴台（Concentric Astrolabe & Layer Lathe）
- **载体**：开放式无框 2D Canvas（标 `data-perf-drag`），1:1 承袭 055 原海报深墨松黑底场、暖米核心圆（`核心 FOCUS`）、珊瑚陶粉内环、深墨点纹中环（配弧形排字「突出主体，强化焦点 / 形成包围，增强稳定感」）、哑光松石青绿外环、四向薄荷圆点与正交虚线轴，及最外圈细轨弧字（「层层递进，引导视线 / 外延扩展，建立节奏」）。支持三套标本切换：**原海报环层 / 天坛圜丘三坛 / 腕表同心表盘**。
- **怎么玩**：
  - 在画布中心区横拖（桌面支持二维拖动）：直接把偏心脱轴的内核与内环组滑回共圆心主轴，逼近圆心 2.5% 内产生轻微机械吸附；拖过头会滑向反侧偏心。
  - 直接拖动任意环缘（粉环 / 墨环 / 绿环 / 外轨）：单独拉宽或压窄该层环带，实时观察弧形文字随半径重排与环间净隙变化。
  - 单击画布上发亮抢戏的外环（或点击左翼环层条）：把喧宾夺主的高亮外环压回哑光退让态，或主动拉亮体验外环夺焦。
  - 按 `Space`（或点「回心波」）：从最外圈逐层向核心释放脉冲波纹，实测视线是否能顺着同心阶梯直抵核心，还是在偏心处偏折、在过密环处颤动。
- **开场初始态（绝不预先给答案）**：刻意停在 `0/4` 四重坏态——内核与内环向右上脱轴 `22%`（中心失守）、外环过亮抢戏压过核心（包围失守）、珊瑚内环膨大挤压深墨中环形成 `2.8×` 疏密乱拍（秩序失守）、外圈越界裁切画框并致四象限失衡（平衡失守）。
- **双向判错与读数**：全部由 `model.js` 从实际绘制的各层 `{ cx, cy, rInner, rOuter, lum }` 单真源实时算出，8 类双向错态均可触发并给出白话「为什么」：`偏心脱轴 / 核微失焦 / 巨核吞环 / 外环夺焦 / 环缘挤撞 / 高频眩晕(6-7层) / 单环失层(2层) / 破边截圆 / 缩核孤悬`。同时认可三组合法解：**原海报典范解（4层）、水波外扩解（4层递增）、三坛礼制解（3层疏朗）**。
- **与最近 12 页及同小类的区分**：047 拖 4 颗卫星绕单轨，050 开合单道厚黑环缺口，051 卷放对数螺线，052 雕 36 束放射线，053 扳 8 支向心楔形箭头；本页唯一动作是「多层嵌套环带的共轴对齐、逐环径向步距雕琢与由内向外明度退让」，别页无法原样套用。

## 3. 版式骨架（不锁 100svh，忠实转译 055 原海报）
- **1440×900（主宽 1380px；2560 舒展至 1660px）**：忠实转译 055 原海报「深墨松黑全幅天文展卷 × 底部圆角细线双栏匣」骨架：
  - 中段三翼齐底展开：左翼（27%）上置原海报招牌左上标题锁组（自示范活体同心小徽 + `同心式构图` + `CONCENTRIC COMPOSITION` + 薄荷短杠 + 总述）、下齐底落「四层物理环带检视条 + 多解/试错切换」；中央（44%）为无重框大尺寸 1:1 开放同心环画布（约 540×540px）；右翼（29%）上置原海报右上十字圆点徽与两行格言 + 标本/回心波键、下齐底落「单真源环层诊单与三项精控滑轨」。
  - 底沿完整呈现原海报灵魂部件：16px 圆角极细暖米线框双栏匣——左半「概念要点」并排 4 枚 1:1 定制活体圆形 SVG 徽标（中心 / 包围 / 秩序 / 平衡，随拖动实时切换几何与状态），中垂细线分隔，右半「应用提示」原话配一枚与主画布实时联动的微缩同心目标图。最底一行以双四角星夹原海报结语「中心汇聚力量 · 圆满即是平衡」。
- **1024×1366 / 768×1024 平板**：自然流排，取消三列挤压，顶部双角刊头 → 居中大号正方画布 → 双列齐底环层条与诊单 → 通宽双栏要点匣，绝无大片留白。
- **390×844 竖屏手机**：单行极紧刊头（`NO.055 同心式构图` + 实时状态徽）+ 三枚标本签 → 严格 1:1 正方画布（宽约 374px，含紧底操控带稳占首屏 ≥ 46%，圆绝不变椭圆）→ 折线内直露单真源诊单首句、同心偏轴主轨与「一键归心 / 回心波」双键；总述、四枚圆徽与完整层控顺流置后。
- **844×390 横屏手机**：左 43% 严格 1:1 正方画布（高约 322px 完整入屏）× 右 57% 紧致刊头、诊单首句与一键校准并行。

## 5. 节目录（7 节，相邻节控件绝不重复）
- **01 · 为什么层层环绕能锁眼**（`COMMON REGION & CENTRICITY`）：用「四步逐层剥离标签（裸点 → 单环 → 双层 → 四层同心）」驱动 SVG 视觉力场剖面，讲清 Palmer 共同区域嵌套与 Arnheim 中心场，并温和校准海报「圆满即是平衡」一语。
- **02 · 四条规矩：中心、包围、秩序、平衡**（`FOUR PILLARS ANATOMY`）：原海报四枚圆形徽标 1:1 拆解卡片，每卡自带独立「反例 ↔ 成立」拨动开关驱动卡内几何动态对照，并一句话链接辨析 `047/050/052/053`。
- **03 · 暗室调律：步距、层数与明度梯度**（`DARKROOM LAB`）：深墨暗室 2D Canvas 实验台，切换四种环距函数（等差 / 外扩波纹 / 内密外疏 / 乱序）并拖动明度坡度与层数（2–7 层），右侧实时同步绘制「径向明度横截面剖面图」与视觉舒适度分档（标明经验值，不用假精确百分数）。
- **04 · 从哪来：穹顶、坛台与色彩实验**（`HISTORICAL LINEAGE`）：四件可核验的建筑与艺术档案版画切换器（古罗马万神殿 125–128 CE / 北京天坛圜丘坛 1530 / 康定斯基 1913 / 贾斯珀·琼斯 1955），配精确 SVG 几何剖析图与原始馆藏出处。
- **05 · 什么时候用，什么时候别用**（`WHEN TO USE & AVOID`）：六枚真实设计需求诊断抽屉卡（点击切换「采用同心 / 改用他法」研判），原样引出海报「应用提示」中英文，并用单句链接指向 `047/050/051/052/053/054/056`。
- **06 · 实战测眼：选出最稳的一张同心海报**（`SINGLE-VARIABLE QUIZ`）：两道渐进视觉测验（题一单变「明度层级」、题二单变「共轴与步距」），四项仅用中性代号 A/B/C/D 与中性参数，选后即时逐项讲透原因。
- **07 · 原海报档案与关键词**（`ORIGINAL POSTER ARCHIVE`）：嵌入 `poster.webp`（`draggable="false"`），支持点击全屏灯箱滚轮缩放、拖拽平移与 Esc 关闭，并完整呈现海报四组关键词与结语。

## 7. 练习设计
- **题一（明度层级单变量）**：四张结构完全相同的 4 层同心海报（同圆心、同环宽、同边距），只改变各环明度分配：
  - 方案 A：四环明度拉平（均亮灰粉）
  - 方案 B：外环最亮、中心最暗（明度倒置）
  - 方案 C（正解）：核心最暖亮，由内向外经珊瑚、深墨、哑绿阶梯退让
  - 方案 D：高反差黑白等宽硬条纹（核被缩小）
- **题二（共轴与步距单变量）**：四张配色与四层明度完全一致的同心海报，只改变几何同心与环宽：
  - 方案 A：内三环向右偏移 14%（错心偏轴）
  - 方案 B（正解）：四层严格共圆心，环带自内向外温和递增，外缘完整留息
  - 方案 C：共圆心但中间两环几乎贴死、外侧留巨大断层
  - 方案 D：共圆心但整体放大至外绿环被左右画框裁平
