# 316 深远法（DEEP DISTANCE METHOD）设计方案

## 1. 一句话道理
深远法不是把主体推远就完事，而是借由层层重叠的前中景门框（或重峦）逐级缩尺、逐层衰减明度与对比，迫使视线穿过一道道门槛向内步步推进，在尽头落入微亮的远景，从而在二维平面上撬出真实的纵深空间感。

## 2. 开场玩具：「重门剖深台」（俯视 Z 轴剖面轨 × 正面重门穿透画框）
- **怎么玩**：
  - 舞台上方嵌一条原海报同源青蓝线条的 **Z 轴重门俯视剖面轨（`data-perf-drag`）**，从左端「视点 EYE」依次排布各重门框直至右端「远景 FAR」；支持水平拖动（或在下方主画框上水平拖动，也支持键盘 `← / →` 微调）直接把整排门框沿 Z 轴向深处拉开或压扁，并可在剖面轨上直接点击第 3 重门解锁堵墙。
  - 右翼忠实沿用原海报的**三枚串联青环圆徽**（`纵深推进` / `层层后退` / `视线深入`）外加 `远景归宿` 状态灯，配合精简四维建筑控参（重数 `2/4/5/7重`、明暗衰减 `同亮/重晦/烟岚/反相/死黑`、通道形态 `堵死/正轴/幽窥/错位`、尽头落点 `空洞/青月/炸亮`）与三套题材切换（`原海报重门 / 北宋重峦 / 江南漏窗`）。
- **开场初始状态（0/4 翻车错态）**：
  - 5 重暖石门框已现身但被压扁在 `14%` 浅纵深（像贴在墙面的平面嵌套框）、全部门框同亮无明度梯度（`ΔL 0%`）、第 3 重门被实墙堵死（`穿透率 0%`）、通道尽头为一片死黑空洞（无远山青月）。
- **怎样算玩错、读数如何解释「为什么」**：
  - 双向可错、且含多组合法解（如明暗可选「前明后晦」或「烟岚递淡」，通道可选「正轴套框」或「曲径幽窥」）：
    1. 纵深过浅（`<38%`）→ **门框贴扁**：近远框宽比不足，视线一步撞墙；拉过头（`>88%`）或塞到 7 重过密 → **井底针孔**：远窗缩成不足 7% 的细孔，夹逼窒息而非舒展深入。
    2. 明暗同亮 → **前后粘平**：缺少明度梯度，人脑读成平面嵌套线框；反相后亮 → **前暗后刺**：深处抢跳到前面造成前后倒置；死黑急坠 → **中段吞黑**：中景门框沉没，失去递进台阶。
    3. 中门堵死 / 错位断路 → **视线受阻**：透视通道截断或有效视窗塌陷，眼睛进不去。
    4. 尽头空洞 / 远景炸亮 → **无处落脚 / 喧宾压前**：深处无景可停，或过亮光团把前中景层次压平。
  - 所有读数（近远框宽比、远窗占宽、相邻明度差、视通道穿透率、纵深档位）全部由 `model.js` 从实际投影几何单一真源计算。
- **与最近 12 页的差异**：
  - 紧邻的 315（高远法）是素宣暖白三栏竖立轴 + 底部仰角横推尺；025（汇聚线）是左侧深蓝壁 + 暖米消失点钉针。本页完全承袭 316 原海报的**玄夜墨蓝 × 暖石重门 × 青蓝激光细线**视觉宇宙，且以**顶部俯视 Z 轴剖面轨联动正面重门视廊**为核心交互，无底部通用横推条、无准星拖点。

## 3. 版式骨架
- **1440×900（2560×1440 宽屏扩至 1780px）**：不锁 `100svh`。极细顶眉下，采用 316 原海报忠实骨架——顶部左排带活体嵌套框示范的大标「深远法」与 `DEEP DISTANCE METHOD`，右排原海报 5×4 青蓝点阵与题材切签；中段左 63% 铺开「Z 轴重门剖面轨 + 正面重门穿透大画布」，右 37% 排原海报同款竖向青线串联圆徽实检列、白话诊单与建筑控参；底沿承接原海报青蓝横条 + 四空心圆 + 细线 + 空心方收口。
- **1024×1366 / 768×1024 平板**：自然流式排布，满宽 Z 轴剖面轨与大画布居上，圆徽诊单与控参双栏紧随其下，零竖向空洞。
- **390×844 手机竖屏**：极紧单行标题配 `0/4` 状态章，Z 轴剖面轨与 4:3 等比重门主画布直落首屏占 ≥ 48% 屏高，同屏露出实时白话诊单首行与主控钮，全页零横向溢出、圆徽保持正圆。
- **844×390 手机横屏**：切左 54% 剖面轨+主画布 × 右 46% 紧凑刊头、诊单与控参并行。

## 7. 练习设计
- **题目**：同一座五重方拱夜廊、同一轮远山青月，以下四种排布（方案 A / B / C / D）仅各差一个视觉变量，哪一条真正把视线自然带入深处？
- **四项单变量差异**（选项签仅写中性编号，不剧透好坏）：
  - **方案 A**：五重门框保持完全相同的亮石色，缺失明度逐层重晦衰减，前后粘连成平面套框。
  - **方案 B（正确）**：五重门框由近到远稳步缩尺、明度逐层沉入重晦深蓝、地面光带按 `1/z` 递进，中轴敞通直达青月远山。
  - **方案 C**：缩尺与明度梯度正确，但第 3 重门洞被半高实墙横截，通道被拦腰打断。
  - **方案 D**：缩尺过激堆入 9 重密框，尽头远窗被挤成不足 5% 针孔，造成压迫窒息。
