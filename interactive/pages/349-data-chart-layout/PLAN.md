# 349 数据图表页 幻灯片版式（DATA CHART LAYOUT）设计方案

## 1. 一句话道理
把「结论」放在观众读图之前，用同一基线的图形编码承接数据对比，再用紧贴关键峰值的短标注点破原因，就能把十秒以上的读表解码压缩成三秒以内的观点认同。

## 2. 开场玩具（活体数据图表演播与口径验真台）
- **载体与动作**：1:1 转译 349 原海报四层分析展页（顶栏刊头与三原则探针 → 珊瑚红 `结论` 活体动作标题条 → 钴蓝 `图表` 全宽交互 2D Canvas 配右侧珊瑚虚线 `标注` 挂卡 → 纯白圆角 `重点数据` 三联 KPI 卡与单真源诊单）。
- **怎么玩**：
  1. 在 2D Canvas（标 `data-perf-drag`）空白区域左右横拖：连续推拉纵轴起点（`0 → 200`），实时体验 Tufte 谎言因子如何把 `2.76×` 真实差距拉成视觉假暴涨；
  2. 直接按住任意一根蓝柱（Q1–Q4 实际值）或红柱（目标值）柱顶上下拖动：实时修改底层数据，并立刻反向检验顶栏 `结论`、右侧 `标注` 与底部 `重点数据` 是否仍然自洽；
  3. 直接点击画布上的标红病灶标签、顶栏结论条、右侧珊瑚虚线标注框、左侧图表类型（分组柱 / 双折线 / 饼图 / 3D 透视柱）或下方视觉去噪/配色聚焦/口径开关原地手术改造；
  4. 按 `Space` 启动「3 秒观众扫视路径」动画，按当前画面的真实视觉权重依次点亮视线落点（错态下视线在彩虹柱与底图例间折返迷路，合法解在 3 秒内顺滑走完 `结论 → 峰值对比 → 珊瑚标注 → 重点数据`）。
  5. 内置三套真实剧本：`原海报 · 季度销售`、`SaaS · 季度留存`、`门店 · 复购客单`。
- **开场初始状态（绝不预给答案）**：刻意停在 `0/5` 灾难初稿——纵轴从 `160` 截断（谎言因子 `3.5×`）、空壳名词标题（「年度各季度销售数据统计」）、重网格 + 8 色彩虹柱 + 底图例（低数据墨水比）、缺峰值标注、且隐藏目标对比并堆满 6 张两位小数杂卡。
- **怎样算玩错、读数怎么说为什么**：由 `model.js` 从同一组实时数据、实绘像素柱高与包围盒几何单真源双向检出 11 类错态：
  - 纵轴截断（报出实算视觉倍率 vs 真实倍率与谎言因子，说明为何误导决策）；
  - 选错饼图或 3D 透视柱（指出角度与透视视差破坏同基线读取）；
  - 彩虹配色/重网格图表垃圾（指出眼球被迫在图例与柱间往返）；
  - 空壳名词标题（指出观众必须自己归纳立场）；
  - **拖改柱高导致结论或标注与数据自相矛盾**（例如把 Q4 拖低于 Q3 后仍写「Q4 达到全年峰值」，立刻标红指出逻辑穿帮）；
  - 缺少峰值标注或标注写成密字长段；
  - 隐藏目标对照锚点；
  - KPI 卡堆砌超载；
  - **口径错标陷阱**（可一键复现原海报将 Q4 vs Q3 环比 `+38%` 误标成「同比增长 Q4 vs Q1」的经典失误，温和教会读者核对口径）。
  同时认可 4 组合法解：`原海报蓝红对比解`、`Knaflic 灰蓝单峰聚焦解`、`双折线趋势增速解`、`极简无副卡高层解`。
- **和最近 12 页的区别**：最近 12 页多为暖米/深绿/深黑/朱橙色调且采用「左画布右诊单」或「侧栏/时间轴/手风琴/标签页/手机热区/块级与绕排」交互；349 采用全库少见的**冷银霜白报告纸 + 深午夜蓝 + 钴蓝/珊瑚红双对比色**，骨架 1:1 承袭原海报「左侧色块胶囊分类轨 × 四层自上而下分析展页」，玩法是数据图表专属的「纵轴基线谎言因子推拉 + 柱顶数值实改 + 结论/标注/KPI 逻辑一致性单真源验真」。

## 3. 版式骨架
- **1440×900（2560×1440 舒展至 1620px）**：不锁 `100svh`。主宽 `1380px` 居中，顶部为轻盈冷银白章节导览条（无厚黑顶栏）→ 刊头左 60% 自示范双行大标（旁嵌随实时数据起伏的微缩柱列）对望右 40% 原海报三枚深蓝图标实时探针 → 通宽 `结论` 活体动作标题与白话诊单条 → 通宽 `图表` 交互画布（左 15% 图表型/图例轨 × 右 85% 高清 2D Canvas 内含柱图与右挂珊瑚虚线 `标注` 卡）→ 通宽纯白圆角 `重点数据` 三联实时 KPI 卡片带与平齐精控条 → 底部五列竖细线 `教学笔记` 实时探针与 `设计提示` 珊瑚色胶囊带。
- **1024×1366 / 768×1024**：自然流排布，无留白空洞；图表画布维持宽幅等比，下方 KPI 与精控条双行齐整落位。
- **390×844 竖屏**：压紧单行刊头、后置三原则探针与五列教学笔记，让等比 2D 图表画布稳占首屏 ≥ 46%，折线内直接露出 `结论` 实时标题、白话诊单首句、纵轴基线滑尺与「校准原海报解 / 3秒扫视」双主钮。
- **844×390 横屏**：切换左 58% 交互图表画布 × 右 42% 紧致刊头、结论、白话诊单与双主钮并行。

## 4. 配色和字体
- **逐像素实采自 349 原海报**：
  - 纸面底色：冷银霜白 `#F1F3F5` / 纯白卡片 `#FFFFFF` / 柔和冰蓝雾纸 `#E8EDF4` / 细虚线 `#CFD6E1`；
  - 招牌深午夜蓝（标题、坐标、教学笔记深胶囊、03 与 06 暗室）：`#112243`（正文深墨 `#16233B`，次墨 `#4A5A75`，03/06 暗室 `#0D1931`，暗舱 `#152545`，极深页脚 `#091224`）；
  - 招牌钴蓝（实际值柱、图表/重点数据胶囊、+38%/121% 指标）：`#2467DC`（浅纸高对比深钴字 `#1850B8`，淡蓝圆底 `#DAE3F5`，暗室亮钴 `#78AAFF`）；
  - 招牌珊瑚红（目标值柱、结论/标注/设计提示胶囊、虚线标注框、Q4 高亮）：`#FC6A5D`（白字按钮安全珊瑚 `#D84339` 对比度 ≥ 4.3:1，浅纸高对比深珊瑚字 `#BF3228`，淡珊瑚圆底 `#FCE1DF`，暗室亮珊瑚 `#FF847A`）；
  - 克制使用松翠绿（`#0F7A5A` / 暗底 `#4DE0AE`）标 `5/5` 达标。
- **字体搭配（全库 0 重复，且 `IBM Plex Sans` 与 `Instrument Serif` 在近 12 页及 347/348 全部 0 次使用）**：
  - `Noto Sans SC`（400 / 500 / 700 / 900）：中文大标与理性正文（正文内嵌西文/年份同行同体不跳动）；
  - `IBM Plex Sans`（400 / 600 / 700）：`DATA CHART LAYOUT` 副标与节眉理性英文；
  - `Instrument Serif`（400 正/斜体）：编辑性引言编号与强调数字；
  - `DM Mono`（400 / 500）：坐标轴、谎言因子、实时百分比等宽数据读数。

## 5. 节目录（7 节，h2 均 ≤ 12 字，相邻两节零重复控件）
- `01` **三层阅读秩序**（纯白）：引用原海报三大要点，用**逐层剥离/叠加步进开关**演示数据→对比→结论标注的 3 秒转化，并附温和的「原海报口径小核对」揭开 `+38%` 环比与同比之别。
- `02` **别让编码和纵轴说谎**（冰蓝雾纸）：**盲测感知滑尺实验**（复刻 Cleveland & McGill 1984，用同一组数在柱/饼/气泡/色阶间让读者盲估倍率并算出误差）+ **Tufte 数据墨水五步瘦身刀闸**。
- `03` **五种会议室翻车现场**（深午夜蓝暗室）：**左右拖拽分屏帘幕对照器**，在截断纵轴 / 彩虹乱色 / 饼图过载 / 空壳标题 / 虚假双轴五组前后对比中一拉见分晓。
- `04` **从铜版画到现代演示**（纯白）：**五代里程碑图谱卡**（Playfair 1786 → Minto & Zelazny 1978–1987 → Tufte 1983 → Cleveland & McGill 1984 / Heer & Bostock 2010 → Knaflic 2015），点击切换对应的微缩 SVG 原理图版。
- `05` **什么时候别用图表页**（冷银霜白）：**场景分诊路由器**，点选 4 类真实汇报需求实时判断是否该用 349，并一句话链接到同小类 344、345、346、347、348、350 在线版。
- `06` **小练习：找出一处硬伤**（深午夜蓝考场）：两道单变量四选一 SVG 活体幻灯片题，选项仅标中性 `方案 A/B/C/D`，四项仅差一个核心变量，选后给出单真源解析。
- `07` **原海报与关键词索引**（冷银霜白 + 极深午夜蓝页脚）：原海报高清展墙（点击放大、拖动、`Esc` 关，`draggable="false"`）+ 原海报 5 关键词、5 教学笔记与 5 设计提示 + 规范单行页脚。

## 7. 小练习设计
- **第 1 题（数据真实与表达自洽）**：同一季度销售数据四页精良幻灯片，`方案 A`（正确：0 基线 + 结论先行 + 准确标注与口径）、`方案 B`（仅纵轴从 180 截断）、`方案 C`（仅标题退化为空壳名词）、`方案 D`（仅把环比 +38% 错标成同比 Q4 vs Q1）。
- **第 2 题（图表编码与视觉聚焦）**：同为 0 基线 + 结论先行，`方案 A`（改用双环饼图编码）、`方案 B`（正确：同基线分组柱状图 + 直接数值标签）、`方案 C`（改用 8 色彩虹配底图例）、`方案 D`（改用 3D 透视斜柱）。
