# 270 卡片网格布局（CARD GRID LAYOUT）设计方案

## 1. 一句话道理
卡片借格式塔「共同区域律」（Stephen Palmer, 1992）把异构信息（图、标题、元信息、操作）打包成独立可读的最小单元，再借二维网格的统一间距、受控层级与行内对齐，让读者在多条并行内容里快速扫读、比较与扩展。

## 2. 开场玩具：活体卡片网格编排台（失序网格抢修）
- **玩法**：直接承袭 270 号原海报的克莱因蓝底面 × 暖米白实体卡片 × 亮黄焦点卡视觉结构，把页面首屏做成一套真能用的「城市书展目录」活体卡片网格（默认 6 张带几何封面、变长标题、标签与按钮的实体卡 + 源自原海报 08「延展」的虚线 `+ 延展新卡` 槽位），并在顶栏右侧把原海报标志性的奶油白「布局要点」3×3 制图网格活体化（2D Canvas 实时同步当前列数、卡距、行对齐线与扫读动线，右侧四条原海报要点从真实 DOM `getBoundingClientRect()` 实时判定）。
- **开场初始态（不能是答案）**：开场故意停在真实的「新手翻车卡片墙」状态（0/4 未通过）——
  1. 桌面端强塞 5 列（390px 手机端强塞 3 列），且卡距压到 `4px`（小于卡内 `16px` 内边距），卡片粘连成墙且单卡被挤成细条；
  2. 行内处于「自由散排」，长短不一的标题与摘要导致同行卡片底栏参差错位（真实 DOM 实测基线偏差约 20–36px）；
  3. 6 张卡里有 4 张被涂成亮黄焦点（`4/6` 过载），全员抢戏导致层级崩溃。
- **怎么操作**：
  1. 直接在制图标尺轨的「卡距卡尺轨」（标 `data-perf-drag`）上左右拖动或用方向键，在 `2px–44px` 间连续调节外距，并在列数钮（桌面 1–5 列 / 手机 1–3 列）间切换；
  2. 点击任意卡片右上角的「焦点星标」，亲手取舍亮黄高亮卡（如原海报 03 号那样只保留 1 张焦点，而非全员加亮）；
  3. 在「自由散排 / 仅外框等高 / Subgrid 行轨锁齐」三档间切换，并可开启「对齐透视线」直观看标题与底栏的实时基线偏移；
  4. 点击网格末尾的虚线 `+ 延展新卡` 槽位增删卡片（6–9 张），观察网格扩展与末行孤卡现象。
- **怎样算玩错、错了读数怎么说**：
  - 卡距 `< 12px`（外距 < 内距）：报「卡片粘墙 · 归属失效」，解释邻卡边界比卡内行距还近，视觉上分不清图和字各归哪张卡；
  - 卡距 `> 32px`（多列态）：报「沟壑过宽 · 孤岛断联」，解释卡片失去群体关联且有效单卡宽被沟壑吃掉；
  - 列数过密（单卡实测宽度跌破可读下限）：报「列数过密 · 挤碎文案」，直接报出 DOM 实测单卡像素宽；
  - 宽屏单列（单卡实测过宽）：报「退化成通栏列表 · 浪费横向扫读面」；
  - 焦点卡 0 张：报「全员均质 · 缺少第一落眼点」；焦点卡 ≥ 3 张：报「焦点过载 · 全员高亮等于没有重点」；
  - 只开「外框等高」不开 Subgrid：明确揭示「外框齐了，但同行标题与底栏实测仍错位 N px」，只有切到 Subgrid 才让基线偏差归零。
- **与最近 12 页的差异**：最近 12 页无一使用「饱和克莱因钴蓝满幅底面 + 暖米白圆角实体卡片网格 + 亮黄焦点卡 + 实时 DOM 基线测量与 CSS Subgrid 切换 + 虚线延展槽位」；区别于 269（暖白底洋红 S 轨信息流）、240（三设备断点标尺）、296（宽屏转窄屏单列堆叠）、239（青蓝三轨流体拉伸）。

## 3. 版式骨架
- **1440×900 / 2560×1440**：克莱因蓝全幅开场（宽屏主体扩至 `min(92vw, 1480px)`），顶行承袭原海报「左大标总述 × 右奶油白活体 3×3 制图要点卡」，其下紧接紧凑制图标尺轨、满宽活体卡片网格（卡片直接铺满主宽度，不缩成小盒）与原海报同款细线底沿诊断条，首屏一屏完整可见；正文八节在暖米白、淡蓝制图白、克莱因深钴蓝、暖沙纸与浅黄图纸间交替。
- **390×844（手机竖屏）**：压紧顶栏与标题至 ~76px，紧接单行可拖卡距卡尺轨（`data-perf-drag` 全宽居中易拖）与列数/对齐钮，下方直接展开活体卡片网格（默认 3 列挤碎态，占首屏 50% 以上高度）与紧凑 4 项要点诊断条。
- **844×390（手机横屏）**：切左右双栏（左 34% 紧排标题、卡尺与实时诊断；右 66% 铺开活体卡片网格），一屏同见、零裁切。
- **1024×1366 / 768×1024**：开场不硬写 `min-height: 100svh`，高度随内容自然收束，紧接第 01 节无大块空洞。

## 4. 配色与字体
- **配色（严格采自 270 原海报）**：
  - 标志克莱因钴蓝底：`#023ACB`（深钴墨 `#0A1D56`、徽标蓝 `#1839B0`、柔蓝图条 `#5878D8` / `#BCC5E4`）
  - 暖米白卡片纸：`#F6EFE4` / `#FAF8F4`（暖沙辅底 `#EFE7D8`、冷蓝图纸 `#EEF2FB`）
  - 亮黄焦点与原理强调：`#F9CA29`（柔黄辅块 `#F3DFA4`、高对比深褐黄文字色 `#7A5600`）
- **字体搭配（全站唯一，且含两款最近 12 页完全未用的字体）**：
  - `Bricolage Grotesque`（weights 500, 800）— 英文大标、节号、`01–08` 圆形编号与大读数（**最近 12 页未用**）
  - `IBM Plex Sans`（weights 400, 600）— 英文副标、制图标注、代码与等宽数字（**最近 12 页未用**）
  - `Noto Sans SC`（weights 400, 700, 900）— 中文主标题与清爽界面正文

## 5. 节目录（8 节，h2 均 ≤ 12 字，相邻节交互不重样）
- **01 为什么框住才好读**（Why Cards Work）：用 Stephen Palmer 1992 共同区域律与外/内间距法则解释边界如何打包异构信息。交互：**4 态边界显影切换台 + 悬停/点击归属连线**（无框裸排 / 底色块 / 细描边 / 外距小于内距反例）。
- **02 原海报八条原则**（Eight Poster Principles）：完整引用并白话展开 270 原海报全部 8 条要点，同时温和修正 `03 扫读`（「说多了一点」：结合 NN/g 指出卡片网格擅长视觉浏览，纯文字快扫反而不如列表）。交互：**4×2 原海报微缩矩阵点选器 + 单条「正例 / 破功」对比翻牌**。
- **03 一行对齐的真难题**（Cross-Card Alignment）：拆解真实文案长短不一时外框等高为何仍显凌乱，展示 CSS Grid 与 Subgrid 行轨锁齐原理。交互：**单卡文案加压器（增行/增标签/缺图）+ 可上下拖动的水平激光基线尺**。
- **04 从卡片盒到网格**（Where It Came From）：按可核实史实梳理 1987 HyperCard → 1992 共同区域律 → 2012–2013 移动卡片浪潮（Google Now、Paul Adams）→ 2014 Material Design → 2017 CSS Grid & 2023 Subgrid。交互：**5 阶段历史标本时间轨（点击切换对应年代微缩界面结构图）**。
- **05 好用与别用的时候**（When to Use & Avoid）：区分适合卡片网格的场景与 6 类不该硬套卡片的场景，逐一给出同小类在线版链接（269/271/272/273/274/275/277/278/286/288）。交互：**5 类真实业务场景分诊台（切换场景即对比「硬用卡片网格 vs 更合适的版式」与扫读成本）**。
- **06 密度、宽度与孤卡**（Density & Orphans）：讲清经验单卡宽度带（标明经验值）、CSS `auto-fill / minmax` 自适应逻辑与 6/8/12 卡片数对末行孤卡的影响。交互：**2D Canvas 容器宽度滑块 × 卡片数量矩阵模拟器**。
- **07 练一练：选最稳网格**（Practice · Pick the Best）：同一组 6 张独立书店导览卡四选一。交互：**四套等尺寸中性标签方案卡点选判题 + 选后显影诊断线**。
- **08 原海报与关键词**（The Original Poster）：展示 270 原海报大图与底部四枚黄色图标关键词。交互：**原海报点击放大 / 拖动平移 / 滚轮与按钮缩放 / Esc 关闭灯箱**。

## 7. 练习题设计
- **题目**：同一组 6 张「城市独立书店导览」卡片放进 960px 桌面栏内，哪一套排布最容易扫读与比较？
- **四个选项（仅标 A / B / C / D 中性代号，每个错项相对正确答案只改坏 1 个核心变量）**：
  - **A（正确）**：3 列 · 卡距 20px（外距 > 内距）· 1 张亮黄焦点 · Subgrid 锁齐同行标题与底栏。
  - **B（仅坏卡距）**：3 列 · 卡距 6px（外距 < 内距，卡片横向与纵向粘连成墙）· 1 张亮黄焦点 · Subgrid 对齐。
  - **C（仅坏行内对齐）**：3 列 · 卡距 20px · 1 张亮黄焦点 · 标题与按钮未对齐（同行基线高低参差）。
  - **D（仅坏层级比例）**：3 列 · 卡距 20px · Subgrid 对齐 · 6 张里有 4 张涂亮黄（焦点通胀，失去主次锚点）。
- **判题理由**：选完后在 4 张微缩网格上同时显影标尺线/基线/焦点占比，逐一说明单一变量的视觉后果。
