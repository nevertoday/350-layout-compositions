# 155 插页式版式（INSERT PAGE LAYOUT）设计方案

## 1. 一句话道理
当人眼连续读过同构的正文页，注意力会滑入「自动驾驶」；插入一张纸色、材质或尺寸截然不同的二级纸张，靠物理叠层与孤立反差制造一次恰到好处的视觉刹车，让最关键的独立信息被一眼锁住，又不切断主文的整体连续性。

## 2. 开场玩具：活体夹页抽拉台与书脊剖面尺
- **怎么玩**：
  - 2D Canvas 1:1 化用 155 号原海报的深海藏青袋口（`#071731` / `#122847` + 薄荷半调点阵）、半圆指抠文件夹、侧边索引耳（明黄 `#ECDC40` / 藏青 `#041125`）与底沿实时「书脊纸层剖面尺」。
  - **画布横向直拖（`data-perf-drag`）**：捏住插页索引耳或在画布任意处左右拖，连续抽拉主插页露出宽度（`8%–94%`），同步牵动纸缘投影跨度、底层正文可见幅宽与底沿书脊 Z 轴剖面。
  - **画布直点交互**：点击主插页纸面直接循环切换纸材反差（同色隐身白纸 / 柠檬黄特种卡 / 半透薄荷硫酸纸 / 深藏青反色厚卡）；点击插页内红色警报条直接修复「截断正文半句 → 独立自洽摘要」。
  - **顶部与底沿快控**：切换「原海报夹层 / 建筑季刊 / 财经年报」三套真实出版题材；一键开启「剖面透视（标出覆盖幅宽、投影 Z 阶与视线停顿/回归动线）」；调节插页密度（0 张平铺 / 1 张单焦 / 2 张主次阶梯 / 4 张碎卡轰炸）与装订锚位（紧锁订口 / 袋口夹持 / 浮空无锚），以及支持键鼠方向键（`←/→` 抽拉露出宽、`1–4` 换纸材）。
- **开场初始状态（0 / 4 待校错态，绝不预给答案）**：
  - ① 露出宽 `82%`（喧宾夺主，盖死宿主两栏正文）；
  - ② 纸材为「同色平白零投影」（与底页融为一体，毫无二级纸张的叠层反差）；
  - ③ 内容为「半句腰斩正文」（硬把正文第 2 段截断一半塞进插页，破坏整体连贯）；
  - ④ 插页密度 `4 张`（三张冗余小卡满屏贴纸轰炸，稀释视觉焦点）。
- **怎样算玩错、错了读数怎么说**：
  - 由 `model.js` 单真源从实绘纸张几何实时诊出 9 类失误：缩进隐没（露出 `<14%`）、喧宾夺主（单卡 `>62%` 或总遮盖 `>58%`）、同纸失层（无色差无投影）、腰斩主文（截断正文半句）、插页文字墙（塞入过密长段）、满屏轰炸（`≥3` 张碎卡稀释孤立效应）、平面失焦（`0` 张无停顿）、双卡平权抢戏（两张同大强跳无主次）、悬空无锚（贴边浮空像弹窗而非夹页）。
  - 读数不说干瘪数值，而是直接讲清「为什么」——眼睛会怎么卡壳、为什么记忆点失效、以及下一步该往哪调；同时接受多种正当解（原海报双卡阶梯解、经典单页短幅黄卡解、硫酸纸轻柔叠层解、深藏青反色厚卡解与任意落在经验甜区内的手调解）。
- **与最近 12 页的明显区别**：
  - 不同于 154（平面色块沟槽压机）、153（视口宽度卡尺装配模块）、067（包豪斯自由几何叠形）、197（四区面积分割墙）、281（双轨气泡对话）、280（三栏目录树）——本页动作是出版物「把一张异质二级纸从宿主页/袋口抽拉出来并校准纸层、自洽内容与节制密度」的独有物理动作，无法套用到其他编号。

## 3. 版式骨架
- **忠实承袭 155 原海报「左斜切浅纸导览 × 右深海藏青袋口舞台」双质地跨页骨架**（零深色圆角仪表盘侧栏，不锁 `100svh` 避开平板空洞）：
  - **1440×900 / 2560×1440**：极细 34px 顶眉下，左 41% 冷薄荷浅纸（`#ECF0F1`）排自示范大标「插页式版式」（「页」字本身坐在一枚随画布露出宽与纸材反差联动的微型索引插页卡上）、`INSERT PAGE LAYOUT`、原海报总述、原海报五原则活体账本（配 5 枚薄荷圆底线框徽与虚线分隔）及左下折角青绿引言；右 59% 深海藏青主舞台（`#071731`）无缝承接题材切签、大画幅 2D Canvas 夹页工作台、四维纸材操控带与带黄色索引耳的白话单真源诊单卡。主内容宽 1380px（2560 舒展至 1760px）。
  - **1024×1366 / 768×1024**：自然流式排布，上为紧凑浅纸双栏刊头，下接全宽深海藏青舞台与诊单卡，底部 5 原则并列为 3+2 网格，零空洞。
  - **390×844**：压紧单行顶眉与单行浅纸标题条，让等比无压扁的深海藏青夹页舞台稳占首屏 ≥ 47% 屏高，同屏露出快控与诊单首句。
  - **844×390**：切为左 56% 等比夹页舞台 × 右 44% 紧凑标题与白话诊单操控并行，零横向溢出。

## 4. 配色与字体
- **逐像素实采自 155 原海报**：
  - 浅纸底色：`#ECF0F1`（冷薄荷浅纸）、`#F5F7F7`（洁白稿纸）、`#E9EFED`（浅薄荷文件夹）、`#F3F1EF`（暖白卡片）、`#F7F5E6`（浅黄雾纸）。
  - 深海藏青：`#071731`（主夜海底）、`#122847`（前景波浪袋口）、`#041125`（藏青索引耳与深眼徽）、`#03111E`（标题主墨）、`#35495E`（次墨）。
  - 标志柠檬黄：`#EFDE05` / `#ECDB2A`（插页主焦色）、`#ECDC40`（索引耳）；浅纸上的文字不直接用明黄，改用高对比深橄榄赭 `#6D5B00`。
  - 标志松绿与薄荷：`#2E7E6E`（英文副标与引号，浅纸小字用 `#1F6154` 保对比度）、`#3E907E`（左下折角）、`#B7D0C4` / `#BFDACC`（圆底徽与弧形纹）、`#B0CFBC`（半调圆点）。

## 5. 节目录（7 大节，每节标题 ≤ 12 字，相邻不重控件）
- `01` **五把标尺看插页**：引原海报五原则、三段边注与灵活应用，用**四层纸卡分解透视抽屉**（点击逐层分离底页/副夹/焦卡/袋口）拆解 155 原海报结构。
- `02` **为什么大脑会骤然停顿**：讲清冯·雷斯托夫孤立效应（1933）与稀缺性边界（「说多了一点」校正），用**12 页杂志翻页节拍条 + 间隔滑块**实时观察每 2/6/12 页插一张时的注意力衰减曲线（标「示意」）。
- `03` **从手贴铜版画到网页弹层**（深海藏青暗室）：梳理由来——手工刷胶贴页（Tipped-in Plate）与护纸、《The Studio》(1893)、《Verve》(1937)、《Colors》(1991) 到 HTML `<aside>`；用**四时代实体装订结构标本签**交互切换。
- `04` **纸上工艺与屏端转译**：印刷裁窄 20–30mm/锁订口/3mm 出血与屏端投影/反差转译，并一句话区分同小类 153/154/156/157/158/159 附在线链接；用**印品×屏端双镜对照尺**切看物理与 CSS 实现。
- `05` **什么时候别用插页**：四个明确禁区（强线性文本、逐行比对表、窄屏大遮罩、高频碎片化）；用**三处翻车现场切替对照台**一键切换「错用插页 vs 改用正途」。
- `06` **练一练：哪版插页最稳？**：同一跨页四个中性选项（A/B/C/D），每次只差一个变量，选后亮出结构解剖与理由。
- `07` **原海报与关键词**：内联 `poster.webp`（可点开缩放拖动、Esc 关闭）与原海报五个英文要点徽及收尾金句。

## 7. 练习题设计
- 题目：《城市旧厂改造报告》杂志跨页，需用插页突出「改造成本与回本周期」核心指标，A/B/C/D 四版只差一个变量：
  - **A**：40% 短幅、独立数据、单张——仅纸色与底页同白且无投影（缺失叠层反差）。
  - **B**：柠檬黄高反差、独立数据、单张——仅宽度拉至 82% 压死宿主两栏（遮盖过满喧宾夺主）。
  - **C（正解）**：柠檬黄高反差 + 清晰纸缘投影 + 40% 短幅露出 + 独立完整三项指标 + 单张聚焦，宿主双栏完整连贯。
  - **D**：柠檬黄高反差 + 投影 + 40% 短幅 + 单张——仅把正文第 2 段截断半句塞入插页（内容不自洽、打断正文流）。
