# 350 · 全图页 幻灯片版式（FULL-BLEED IMAGE LAYOUT）设计方案

## 1. 一句话道理
撤掉白边模板与文字墙，让一张裁切干净、焦点明确、覆字清晰的满幅主图接管整块银幕，把视觉通道留给情绪与记忆锚点，把解释权交还给讲者的声音。

## 2. 开场玩具：全图页满幅暗房导演台（Edge-to-Edge Full-Bleed Darkroom）
- **核心动作（本页专属，别的编号无法套用）**：
  1. **直接拖动全幅画布（`#hero-canvas`，标 `data-perf-drag`）**：按住画面空白处横向/自由移景，在画框里移动整幅暮谷风景（改变巨日与荧光河道的构图落点）；按住画布上的**覆盖文字卡片**拖动，直接把它搬到画面的亮区或暗区；拖动画面四角/下方的**满幅裁切轨**（68%–175%），亲眼把缩在白边模板里的配图拉破边框、裁掉边缘杂物，直到真正四边满幅出画。
  2. **真像素测光（单真源 `model.js`）**：场景画在离屏画布并同步采样 `96×54` 真实像素亮度表，每帧实时读取文字盒正下方真实像素亮度、叠加当前遮罩（无遮罩 / 单侧渐变 / 半透明磨砂块 / 全屏死黑幕）后，按 W3C WCAG 2.1 公式现算真实对比度，而不是写死常量。
  3. **多维操控 + 影院翻页**：在紧贴画布底沿的磨砂导演坞里切换 3 套情绪场景（原海报·暮谷巨日 / 晨雾独舟 / 中庭光柱）、调节满幅裁切倍率、文字体量（54 字密字列表 / 14 字精炼主副标 / 4 字极简金句）、半透明遮罩模式与焦点明暗层次；画布上 1:1 浮现原海报三枚折线引注（裁切 / 焦点 / 覆盖文字），直点即可定位修复；按 `Space` 或点「影院翻页」先闪播 0.8 秒常规项目符号旧页再切入当前全图页，验看 1.5 秒沉浸冲击。
- **开场初始坏态（绝不先给答案）**：
  - 开场停在 `0/4 · 缩框裸字` 四重典型翻车态：`bleed = 72%`（缩在丑陋企业白边与页眉角标里，边缘露出杂乱电线杆/无关贴纸）、文字处于 `54 字项目符号密字墙`、遮罩 `无遮罩` 且文字盒压在最亮的巨日与河湾上（实测对比度跌破 2:1 且遮挡主焦点）、焦点光影平淡无主次。
- **双向玩错机制与读数「为什么」**：
  - 不仅缺项报错，**过头也报错**，共检出 9 类正反错态并认可多组合法解（磨砂暗角解 / 渐变底压解 / 天然暗区无遮罩解 / 极简大标解）：
    - 裁切 `< 98%` →「还缩在白框里，边距切断了银幕沉浸感」；裁切 `> 155%` →「裁得太狠，主焦点被切残且投影会发虚」。
    - 遮罩不足且下方像素亮（WCAG `< 4.5:1`）→「实测对比度仅 X.X:1，白字被亮斑吞没」；遮罩选全屏厚黑幕（`> 70%`）→「黑幕盖得太死，对比度够了却把画面情绪糊没了」。
    - 文字盒压住主焦点坐标 →「文字直接挡住了画面主角，主图与标题互相打架」。
    - 密字墙（54 字）→「文字占掉过半画面，全图页退化成读稿文档」。
- **与最近 12 页的明显差异**：
  - 告别「浅色纸 + 居中框内 16:9 画布 + 右/下独立诊单卡」的套路，整块开场直接 100% 满幅通宽出画（无左右留边外框），将原海报的暮夜满幅图、三枚折线悬停引注与底部磨砂双山圆徽条融为一体；玩法围绕全图页独有的「破框出血裁切 + 真像素亮度测光 + 移景避焦 + 遮罩克制」，与 343 图文分栏、344 大数字、345 删词引语、346 时间线、347 流程完全不同。

## 3. 版式骨架
- **1440×900**：顶沿 `42px` 细磨砂导航轨 + 无缝深空刊头（`84px`）直连 **100% 通宽无边距满幅银幕画布**（`500px` 高，左右贴边满幅出血），底沿严丝融合原海报同款深海磨砂「教学要点与导演控台」（`250px`），首屏一屏尽收且无多余留白。
- **2560×1440**：画布全宽铺满 `2560px` 超宽视野（`760px` 高），底坞与正文区舒展至 `1580px` 主宽，彻底避免宽屏主体缩成小块。
- **1024×1366 / 768×1024 平板**：绝不写 `100svh`，画布按自然流定高（`520px` / `430px`）紧接磨砂控台与 01 节，零大片空白带。
- **390×844 手机竖屏**：压缩顶栏为单行 `36px` 导航 + `48px` 单行标题与三场景轻签，长总述后移至底坞内；满幅画布稳占首屏 `412px`（≥ 48.8% 屏高），折线内直接露出单真源白话诊单首句、实测对比度、满幅裁切主滑轨与校准/翻页双键。
- **844×390 手机横屏**：顶栏压至 `34px`，主体左右并行——左 `58%` 满幅画布 × 右 `42%` 紧凑标题、白话诊单与核心滑轨双键。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节交互不重样）
- **01 · 为什么满幅更有力**：双幕实景卷帘对比器（拖中缝卷帘在剧场剪影前直比「企业白边缩图模板」与「350 满幅全图页」）+ 原海报四要点实时点亮卡。
- **02 · 字压在图上怎么看清**：五种叠字遮罩切片实验室（裸字 / 单侧渐变 / 半透明磨砂块 / 天然暗区 / 过重黑幕）配三档背景明暗压测开关与 WCAG 2.1 标准标尺。
- **03 · 大胆裁切与焦点引导**：深宵暗房裁切构图台（3 张底片 × 4 种裁切取景切换 + 点击释放视线引导流光动画，并温和补足「分辨率与语境底线」）。
- **04 · 从杂志出血到全屏演讲**：1934–2008 核实源流年表（Brodovitch → Paivio → Standing → Mayer → Reynolds / Duarte）+ 演示小类 344–349 联动图谱。
- **05 · 什么时候别用全图页**：四类典型翻车情境翻牌分诊台（多维报表 / 无人离线文档 / 低清图库图 / 强光旧投影），点开看症结与替代页型链接。
- **06 · 练一练：哪张全图页最稳**：四张同图同文案 16:9 盲测题（仅标 A/B/C/D，单变量区分：压焦点 / 留模板边 / 正解 / 死黑幕），作答后同屏揭晓四项指标。
- **07 · 原海报与关键词**：350 原海报灯箱（点击放大、拖动平移、Esc 关闭）+ 原海报三组关键词（裁切 / 焦点 / 覆盖文字）与底部波浪宣言。

## 7. 小练习设计
- **题干**：同一场新品发布会转场页，同一张暮谷图、同一句 10 字主标「把时间还给真正重要的事」，四张草稿只差一个版面变量，哪一张上大屏最稳？
- **四项单变量设计（不露好坏字眼）**：
  - `A`：100% 满幅、磨砂块高对比，但文字卡居中压死在落日与河道主焦点正上方。
  - `B`：文字退在左侧暗区、对比清晰，但外圈仍套着企业白边模板框与顶底页眉，满幅断裂。
  - `C`（正确）：100% 四边满幅无框，大胆裁切把落日与荧光河道让到右侧三分之二，精简标题配克制半透明磨砂块稳落左侧暗部，读字与看图互不抢戏。
  - `D`：100% 满幅且左置文字，但全屏盖了一层 76% 浓黑遮罩，画面色彩与情绪被整体压死。
