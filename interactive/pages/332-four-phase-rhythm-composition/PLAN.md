# 332 起承转合构图（FOUR-PHASE RHYTHM COMPOSITION）设计方案

## 1. 一句话道理
把「时间」编进「空间」：先用简洁留白吸住眼睛（起），再顺势铺开信息层次（承），在情绪蓄满时用强烈反差制造转折高潮（转），最后收束回静留下回味余韵（合），画面便从平面陈列变成一段能走进去的故事。

## 2. 开场玩具：「四折观澜·气韵排谱台」（Four-Phase Rhythm Sequencer）
- **形态**：1:1 承袭 332 原海报的深松石墨绿底（`#014038`）、四枚暖米象牙白圆形画境（`#F6E2B5`）、蜿蜒 S 形暖米气韵丝带（`#F3E8BC`）与琥珀金圆珠（`#FABA40`），纯 2D Canvas 实时程序化绘境（无五官剪影，标 `data-perf-drag`）。
- **怎么玩**：
  - **直接点击或拖曳圆镜**：点选任意一折（起 / 承 / 转 / 合），在圆镜或选折滑轨上横拖即可连续推拉该折的「视觉张力 / 画面密度（0% 极简留白 ↔ 100% 怒涛高潮）」，圆镜里的山水浪月会随数值连续变景（孤月平波 → 叠山朝日 → 巨浪钩月 → 落日倒影）；也支持点按「起⇄转 互换」或拖动圆镜交换顺序，直观体验顺序倒置。
  - **画布横拖扫演视线游标**：在画布空白处左右横拖（或按播放/空格键），金色视线光珠沿 S 丝带从起→承→转→合走完四境，画布底沿实时绘出「节奏快慢波动曲线」。
  - **调弯 S 气韵丝带**：可拉直或加弯 S 丝带曲度，同时支持切换三套叙事题材（原海报·观澜四境 / 长卷·富春行旅 / 分镜·四格画帖）。
- **开场状态（非答案）**：刻意停在「先炸后平·倒置失序」复合坏态——起 `86%`（一入画就怒涛抢跑、缺留白入口）、承 `52%`、转 `26%`（高潮塌陷）、合 `68%`（末尾塞满杂浪收不住），且 S 丝带拉得过直（曲度 `0.14`）。
- **怎么算玩错与单真源读数**：由 `model.js` 从四枚实绘圆镜的张力向量 `[e0..e3]` 与圆心几何坐标单真源计算 7 类双向真错态：起笔过躁、四段平温、承接断层/抢戏、转折塌陷/抢峰、末尾塞满无余韵、结尾死寂断稿、路径僵直或盘绕打结。读数不仅报数值（示意档位标明「示意」），更直接解释「眼睛此刻为什么卡住、疲惫或断流」，并接受原海报经典解、清幽抒情解、戏剧强冲解多组合法解。
- **与最近 12 页的明显区别**：近 12 页里 331 是浅暖米折门透视、330 是暖麻三圆配重、252 是深海蓝横向卡片卷轴、080 是街景俯仰云台、127 是燕麦网页 F 扫描、210 是暖米 5×6 破格网格、294 是暖灰像素校对、079 是暖白圆形俯拍静物、165 是浅石书口索引、251 是暖杏三框比例、041 是暖米三角力学、126 是暖象牙 25 件分群。本页是唯一「深松绿东方诗画四折节拍编谱台 + 实时程序化圆镜变景 + S 丝带视线游走曲线」。

## 3. 版式骨架
- 忠实转译 332 原海报「深松石墨绿满幅卷面 + 右上极细框『核心逻辑』竖串金点卡片 + 中段左 S 丝带四折圆镜舞台 × 右单真源研判与原海报四金标/TIPS 实测带 + 底沿『DESIGN WITH RHYTHM』三关键词脚条」（绝无深色通用顶栏黑箱，绝不锁 `100svh` 避平板大空白）。
- **1440×900**（主宽 `1380px`，2560×1440 舒展至 `1680px`）：顶沿左 62% 自示范大标与题材切签 × 右 38% 原海报「核心逻辑」四点竖轨；中段左 64% 无框融底 S 丝带四折画布与一行微控轨 × 右 36% 研判笺 + 原海报四图符 2×2 实测格 + TIPS 四对勾实时检定卡（双栏收底齐平）；底沿通栏脚条。
- **1024×1366 / 768×1024 平板竖屏**：自然纵向流排，画布满宽等比展示，下方研判笺与 TIPS 并排两列齐底无空洞。
- **390×844 手机竖屏**：压紧顶栏成单行标号+状态签+紧凑大标与切签，总述与核心逻辑后置，确保 4:3 四折观澜画布稳占首屏 ≥ 47% 且圆镜保持真圆不压扁，首屏下方直见微调轨与研判首句。
- **844×390 手机横屏**：切为左 56% 四折画布 × 右 44% 紧凑刊头、切签与研判并行。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节不复用同款控件）
- `01` **四拍如何牵引视线** — 逐拍展开原海报「起承转合」原话；交互：**四拍抽离试验台**（开关任意一拍观察整条叙事弧线与四格卷轴的塌陷）。
- `02` **快慢与留白的呼吸** — 展开原海报四条 TIPS 并温和批注「说多了一点」；交互：**步幅与留白呼吸滑尺**（拖动调节步幅反差与段间留白，直看匀速流水账如何长出节奏）。
- `03` **单幅里的隐形四折** — 拆解不靠分格、在一张静画里埋进起承转合的方法；交互：**单幅画眼游走剖面仪**（在山水立轴 / 杂志海报 / 网页落地页三例上点按四个隐形区域，透视隐形动线，链接 326/330/331/333）。
- `04` **从绝句、长卷到关卡** — 追源元代诗论、宋元山水手卷、清代画论与当代四格/游戏关卡；交互：**四代媒介对照翻阅栏**（四枚时代卷签切换对齐结构图解）。
- `05` **什么时候别硬套四拍** — 拆解 4 类不宜用起承转合的反例与替代方案（链接 328/329/334）；交互：**场景直给 vs 四拍诊判卡**（逐卡投票并展开反例后果）。
- `06` **挑出节奏最对的一幅** — 四选一小练习；交互：**四幅同款微缩展讯卡盲选**（仅差四段密度曲线一个变量，选后叠加能量折线详评）。
- `07` **原海报与关键词** — 332 原海报灯箱（放大/拖拽/Esc）+ 海报三关键词 + 同小类其余 8 篇导览链。

## 7. 小练习
- **题干**：为一场「秋夜古琴雅集」排一幅四段长条展讯页。以下四稿的配色、字体与画幅完全相同，仅四段的视觉密度与张力分配不同，哪一稿最符合起承转合的阅读呼吸？
- **四个选项（标签仅写中性代号「方案 A / B / C / D」，只差四段张力分配一个变量）**：
  - 方案 A（48 / 52 / 55 / 50）：四段密度几乎拉平，工整却像报菜名，缺进入点与高潮。
  - 方案 B（88 / 62 / 44 / 25）：首段直接拉满大浪，后半程一路衰减，高开低走。
  - 方案 C（20 / 48 / 88 / 24，**正确答案**）：留白引目 → 铺陈信息 → 骤势转折 → 平波留白收束，慢→快→高潮→慢余韵完整。
  - 方案 D（20 / 48 / 86 / 78）：前三拍完整，唯独第四段塞满重墨元素与印章，有转无合、失了余韵（强干扰项）。
