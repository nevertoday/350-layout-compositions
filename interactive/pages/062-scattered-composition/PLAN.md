# 062 分散构图（SCATTERED COMPOSITION）互动页方案

## 1. 一句话道理
分散构图不是把元素随手乱扔，而是用「大中小三级显著性焦点 + 类似蓝噪声泊松盘的最小呼吸净距 + 跨留白的隐形呼应与杠杆配平」，拆掉单一中心的垄断，让视线在开放、轻盈、多向的留白间自在漫游却绝不散架。

## 2. 开场玩具
- **名字**：黑绒星场播撒与引斥雕刻台（无框全幅 2D Canvas 开放暗场 + 实时呼吸推波 + 062 原海报十元同构）。
- **怎么玩**：
  - 画布中无边界悬浮着 062 原海报的全部核心几何体：3 枚带动态白色虚线引注的焦点圆（**焦点 01** 明黄圆、`#F5C220`；**焦点 02** 薰衣草紫圆、`#9471CD`；**焦点 03** 橘红圆、`#EE5520`）以及 7 枚节奏伴形（暖白厚空环、翡翠绿方块、玫粉小方块、紫小圆、双 3×3 点阵、自动浮现在大留白处的空间十字星标）。
  - **直接拖拽元素**：鼠标、触屏或选中后按方向键拖动任意几何体，打破机械行列对齐、拉开冲突净隙、调整跨空重心。
  - **空白处扫拖「呼吸推波」**（画布标 `data-perf-drag`）：手指或光标在黑场空白处横向滑扫，发出一道柔和的排斥气波，把周围挤作一团或排成直线的元素轻轻推开出呼吸空隙；同时支持纵向滚屏不卡手（`touch-action: pan-y`）。
  - **雕琢体量级差**：点选 01/02/03 焦点圆，通过「放大 / 缩小」按钮或「主次级差」档位拉开大、中、小视觉层级；也可切三层实时分析透视（`视线跳轨`、`泊松净隙`、`重心支点`），并可一键跳转 4 种经典翻车态（`僵直棋盘`、`白噪结块`、`偏向倾覆`、`空心贴边`）亲自排错（不设一键过关作弊钮）。
- **一打开是什么状态（非答案态）**：
  - 开场刻意停在 **0/4「僵直棋盘 · 主次平权」错态**：三大焦点圆尺寸几乎相同（面积比仅 `1.0×`），全部几何件紧排在画布中偏左的整齐横竖格栅上，间距呆板且重心左沉；海报底沿同款的四色几何关键词灯（变化 / 节奏 / 呼吸 / 开放）亮 `0 / 4`。
- **怎样算玩错、错了读数怎么说**：全部指标由 `model.js` 单一归一化坐标与半径源实时算出，按明确优先级一次讲清主错与视觉原因：
  1. **结块撞车**（任意两件边界净隙 `< 2.6%` 或发生重叠）：「两枚元素已经贴边互吞，视线被粘成一团硬块，丢掉了分散构图最珍贵的呼吸缝。」
  2. **死板棋盘**（横纵对齐率过高或最近邻间距变异系数过低）：「元素排出了隐形横竖格栅，大脑立刻把画面读成死板的棋盘表，开放与轻盈感消失了。」
  3. **主次平权**（三大焦点最大/最小面积比 `< 2.4×` 或 01/02/03 阶梯未拉开）：「三个焦点大小几乎平起平坐，眼睛在黄、紫、橘之间来回打架，找不到第一落脚点。」
  4. **缩团未散**（包络展开跨度 `< 52%` 或有效象限不足）：「元素仍缩在画布局部，没有向四周敞开，变成了半成品的聚类构图。」
  5. **空心贴边**（超过半数元素紧贴外框边缘且中央空洞过大）：「元素全被挤到画框边沿，中间塌出一个冷冰冰的空洞，视线顺着边框滑出画面。」
  6. **偏沉倾覆**（阿恩海姆视觉权重重心偏离画心 `> 13%`）：「视觉重量倒向一侧，虽然元素分开了，整张画面却像失衡的天平向一边下坠。」
  - 四项指标全达标后进入「星图成立 · 4/4」，解锁「叠看原海报轮廓」对照开关。
- **读数说什么「为什么」**：不仅显示主次面积比、最小呼吸净隙、对齐乱度与重心偏移（均标注「经验参考带」），还解释人眼为什么会卡顿、打架或倾覆。
- **与最近 12 页的区别**：最近 12 页全为浅底（暖宣/薄荷/姜黄/抹茶/雾蓝）框式分栏 + 底沿滑轨或拼格操作；062 采用忠于原海报的**纯黑无框开放星场**，首创「直拖几何体 + 空白场呼吸推波排斥 + 三焦点级差雕琢」玩法，且在概念与动作上和紧邻的 061 聚类构图（由散聚拢）恰好成对立镜面。

## 3. 版式骨架
- **1440×900 & 2560×1440**：全幅 `#090909` 纯黑开放星场无外框展陈（不锁 `100svh`）。极细顶眉下，左 31% 自由悬浮示范大标「分散 / 构图」（上暖白下薰衣草紫，字距微散）+ 短紫杠总述 + 左下淡紫横线星图实时诊单与选中件缩放条；右 69% 无边框铺满黑绒星场画布，底沿衔接原海报同款四色几何图标验收带（变化/节奏/呼吸/开放）与错态体验条。2560 下版心舒展至 `1840px`，星场画布大尺度展开。
- **1024×1366 / 768×1024 平板**：不锁 `100svh`，自然纵排收紧：紧凑顶带（左大标、右四色验收灯）→ 满宽等比星场画布 → 下排双栏操控与实时诊单，零纵向空洞。
- **390×844 手机竖屏**：顶眉与标题压紧为单行（暖白「分散」+ 紫「构图」+ 实时达标丸），紧接满宽等比黑绒星场画布（高度约 385px，稳占首屏 ≥45%，正圆绝对等比），下接紧凑四色验收条、缩放/错态按钮与实时诊单首段，总述文字放在控制区之后。
- **844×390 手机横屏**：极简顶栏下切为左 56% 通高星场画布 × 右 44% 紧凑四灯、控制与实时诊单并行，单屏完成操控。

## 5. 节目录
1. **01 三个焦点的接力**（暖米白纸）— 引出原海报三大视觉焦点原文并附「说多了一点」纠偏（面积之外，明度反差与孤立度同样决定谁抢第一眼）；交互：三态显著性接力剧场（切换「层级递减 / 高对比反超 / 三角拉扯」+ 播放动态视线跳轨）。
2. **02 为什么乱扔不是分散**（纯黑星场）— 对比规则网格、纯随机白噪声与泊松盘蓝噪声三种空间分布，揭示「保底最小净距 + 不规则角度」才是自然呼吸的数学秘密；交互：2D Canvas 三机制活体撒点台（播撒数量与最小净隙双滑块 + 重新播撒 + 实时净隙分布直方图）。
3. **03 散而不散的隐形丝线**（浅宣米白）— 引出原海报「技巧提示」原话，拆解物理远离后靠什么维系整体感（色彩回声、形状家族、大小级差、跨空杠杆配平）；交互：四重隐形联系独立开关滤镜（逐项关掉后看同一批坐标瞬间沦为杂乱垃圾场）。
4. **04 它从哪来：百年去中心史**（深暮紫暗版）— 梳理平安时代「散らし書き」、康定斯基 1926、格林伯格 1948、阿恩海姆 1954、耶洛特 1983 与库克 1986 脉络，附同小类 7 页一句话链接；交互：五时期演进时间卷切页图解。
5. **05 真实场景怎么用**（暖米白纸）— 落地至独立艺术展海报、杂志情绪板开篇页与创意作品集首屏；交互：三实景切换 + 连续「密排 ↔ 开放散排 ↔ 过度空洞」留白松紧度形态推子。
6. **06 什么时候别用分散**（纯黑星场）— 明确四类禁忌边界（唯一高转化指令、严格先后步骤、密集同质对照、明确从属层级），分别给出对应兄弟编号链接；交互：四类失效现场翻卡对比（切换「分散翻车态」与「正确替代结构」）。
7. **07 练一练：哪版散得稳**（浅宣米白）— 四张中性标签（A / B / C / D）同元素单变量黑底海报辨析题；交互：点选即判并同时在四张小海报上叠加网格线、重心箭头、撞车环与平衡三角透视。
8. **08 原海报与关键词**（纯黑星场）— 展示 062 原海报（可放大、拖拽、`Esc` 关闭）与原海报四枚彩色几何图标关键词及技巧提示。

## 7. 练习
- **题目**：同一场「夏季爵士夜」黑底海报里的 7 件元素（标题字组、明黄大圆、薰衣草中圆、橘红小圆、日期标、绿方与点阵），颜色与体量完全相同，**只改变它们在画布上的散落排布**。哪一版做到了「分散开放、主次分明又整体平衡」？
- **四个选项（标签仅写 A / B / C / D，只差空间散落排布单一变量）**：
  - **A**：7 件元素严丝合缝落在 3 列 3 行的隐形横竖对齐线上，间距机械均一（死板棋盘格化）。
  - **B**：黄、紫、橘三个核心色块全扎在左上角彼此紧贴，右下大半片黑底完全空置（偏沉结块倾覆）。
  - **C（正确答案）**：明黄大圆稳立右上建立第一落点，薰衣草中圆与橘红小圆错落分置中左与中下形成非等边视线三角，绿方、点阵与标题跨留白呼应配平，无横竖死对齐且每两件留足最小呼吸净隙，整体视觉重心贴近画心。
  - **D**：7 件元素沿着四条画框外缘贴壁排成一圈，画面中央留出一大块毫无回应的死洞（空心贴边）。
