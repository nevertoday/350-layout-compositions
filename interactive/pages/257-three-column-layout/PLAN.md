# 257 三列页面 · 设计与实现方案（PLAN.md）

## 1. 一句话道理
三列页面把宽屏拆成「左翼 · 中轴 · 右翼」三个各司其职的功能槽：比单列省去漫长纵向滚屏，比双列多出「主焦居中、双翼衬托」或「三项并行对照」的奇数视觉节奏；但前提是单列宽度足够呼吸、双道列缝清晰止串、视觉对比集中在一处主角，并在窄屏及时折叠。

## 2. 开场玩具：三列分工与双缝配比工作台（Tri-Column Role & Dual-Track Studio）
- **玩法**：直接嵌入 257 原海报「钴蓝外框 × 暖米三列展纸」中的 2D Canvas 活体迷你三列网页（标 `data-perf-drag`），完整还原原海报「示例展示」的三大真实场景——**图文信息（编辑专题）**、**数据展示（方案对比）**、**人物介绍（嘉宾档案）**。
  - **双轨缝推拉 + 中轴窗滑移**：拖左轨缝调左/中占比，拖右轨缝调中/右占比，横向拖中列画布主体同步滑移中轴窗并实时重排三列中文折行、像素宽度与底部视觉重心标尺。
  - **点选调换列位与主焦归属**：直接点击画布顶部三列标题槽调换列序或切换视觉焦点归属，直观体验「角色与栏宽是否匹配」。
  - **双缝距、对比层级、一致性与视口压力阀**：连续调节双缝距（4–56px）、切换三列视觉对比（`全平无差` / `单主突显` / `三列互抢`）、切换顶沿一致（`齐顶` / `错位`）、切换模拟视口宽（`1280px` / `960px` / `680px 窄屏强撑`）。
- **一打开的状态（刻意坏态，0/4 项达标）**：
  - `图文信息` 场景、`1120px` 视口，三列配比停在 **47% : 23% : 30%**（左导航过胖、中列核心正文被挤窄到仅 ~11 字/行）、**双缝距 6px**（触发左右两道跨缝红弧串行）、**全平无差**（三列同底同重无主次）、**顶沿参差错位**（破坏一致性）。
- **怎样算玩错 / 读数怎么说「为什么」**：
  - 由 `model.js` 从实绘三列像素坐标、逐字折行实测每行汉字数、双缝/行距比与三列墨量重心矩单真源双向核算 **9 类错态**：窄缝串行（`<14px`）、宽缝割裂（`>44px`）、窄列碎字（`<175px` 或正文 `<14 字/行`）、过宽难扫（`>40 汉字/行` 触及 WCAG 1.4.8 上限）、视觉重心偏斜、角色与栏宽倒挂（核心正文塞进窄列）、无视觉主次（全平）、三列互抢过载（全员重色）、顶沿参差失序。
  - 读数始终先点破最致命的一条错因与眼睛的真实反应，并给出「怎么改」；支持 **对称主轴解 (24:52:24)**、**等宽对比解 (33:34:33)**、**左重主副解 (48:28:24)** 多组合法解，也提供 3 个反向试错陷阱按钮。
- **与最近 12 页的明确差异**：
  - 不同于 256 的暖米松绿单中脊双语纸面（257 是双轨缝联动 + 三列角色分工 + 对比过载与窄屏挤碎压力测试）；
  - 不同于 134 的翠绿 6/12 栏跨栏砖块、133 的午夜蓝双栏蓝图、300 的深紫双槽 Container Query、046 的暖石矩形断裁；
  - 版式直接长成 257 原海报的「钴蓝斜射橙芒刊头 × 钴蓝夹边暖米三列画纸 × 底沿橙蓝靶心宣言带」。

## 3. 版式骨架
- **1440×900**（主宽 `1380px`，2560×1440 舒展至 `1680px`）：
  - 顶部全幅钴蓝刊头（右上斜切原海报同款信号橙光束与橙色网点），左排自示范三柱切分大标「三列页面」与 `THREE-COLUMN LAYOUT`，右排三场景切签与单真源达标徽章。
  - 中部钴蓝夹边暖米展纸：第一带为原海报三列核心柱（`信息层次清晰` | `功能分区明确` | `视觉对比强烈`，竖钴蓝线隔开，每栏顶部配短橙杠与实时诊断徽标）；第二带为通栏三列活体浏览器画布；第三带 1:1 呼应原海报底部的三列布局（左 36% 深钴蓝单真源诊单舱 | 中 34% 双缝与视口控制轨 | 右 30% 对比、一致性与多解/试错台），三栏齐底零空洞。
  - 底沿复刻原海报「左橙点靶心 + 钴蓝标语带 + 右下斜切米角」。
- **1024×1366 / 768×1024**：绝不锁 `100svh`，三柱头保持横向 3 栏，底部诊单与操控自然排成齐底两行零留白。
- **390×844 竖屏**：压紧单行钴蓝刊头，将总述与三柱要点卡片移到画布下方；画布锁 `1.16:1` 稳占首屏 ≥46%，折线内直接露出深钴蓝诊单首句与一键修好按钮。
- **844×390 横屏**：左 57% 场景切签 + 等比三列画布，右 43% 精简刊头与实时诊单并行。

## 4. 配色与字体
- **逐像素实采自 257 原海报**：
  - 国际钴蓝主色：`#002EAA`（展头、外夹边、标题、圆徽），深钴暗室 `#001C6E` / `#002282`（03 历史暗室、06 考场、诊单舱）。
  - 信号朱橙强调：`#F36301` / `#F77B13`（右上斜射光束、短横杠、中轴焦点与靶心），浅纸高对比深橙字 `#B54300`，暗底亮橙 `#FF964A`。
  - 暖米底纸系：`#F9EED5`（原海报主纸）、亮象牙 `#FDF8EC`、冷天青雾 `#EEF3FB`、暖沙 `#F2E4C6`；深钴墨正文 `#0B1A4A`、次墨 `#34477B`、钴蓝细分隔线 `#2E4998`。
  - 诊断辅助色：松翠 `#0A7A5C`（暗底 `#55E3B8`）标成立；朱赤 `#C42419`（暗底 `#FF7E73`）标错态。
- **全库 100% 唯一且近 12 页零重合辅助字栈**：
  - `Noto Sans SC`（400/500/700/900）— 中文展示与正文统一不跳字
  - `Archivo`（600/700/800，近 12 页 0 次使用）— 英文大标与节标
  - `Outfit`（400/500/600/700，近 12 页 0 次使用）— 英文标签与图表说明
  - `Space Mono`（400/700，近 12 页 0 次使用）— 像素宽、栏比、字/行与 CSS 读数

## 5. 节目录（7 节，交替纸色与互不重复的交互控件）
- **01 为什么分成三列**（亮象牙）：还原原海报三组几何图式（钴蓝块/橙圆/点阵；三列线框；蓝半圆/橙块/蓝横条），点选切阅读动线与结构映射，并温和修正「均衡 ≠ 机械等宽」（「说多了一点」）。交互：几何图式点击切换 + 动线重播。
- **02 六大要点拆开看**（冷天青雾）：完整引出原海报下排六枚圆徽要点（节奏感/平衡感/模块化/对比/间距/一致性）。交互：6 枚独立开关破坏/修复一座实时三列线框页面，即时看缺哪一条会怎么塌。
- **03 三列从哪来**（深钴暗室）：核实史料四站——1958《Neue Grafik》三语三栏 → 1981 米勒-布罗克曼《Grid Systems》 → 2006 Matthew Levine《In Search of the Holy Grail》 → 2017 年 3 月 CSS Grid 原生上线。交互：四时代切签 + 对应历史版面活体标本与 CSS 演进。
- **04 屏幕变窄怎么折叠**（暖米原纸）：Web 三列最核心工程命题，结合 WCAG 1.4.8 与最低栏宽，用一根连续视口卡尺（1440px → 360px）实时对比「强撑三列 / 阶梯 3→2→1 / 侧栏抽屉收纳」三种真实折叠策略及生成 CSS Grid 代码。交互：视口宽卡尺 + 三策略单选切换。
- **05 什么时候别用三列**（亮象牙）：明确适用边界与四大禁用情境，一句话链接同小类兄弟页（255/256/258/259/260/261/262/263/265/266/267/268）。交互：6 张真实业务需求卡「合不合适」分诊判定器。
- **06 小练习：挑出稳的三列**（深钴暗室）：固定 1140px 桌面编辑专题页，四版内容/缝距/配色完全一致，只差三列宽比（`33:33:34` / `20:56:24` / `44:36:20` / `12:74:14`）。交互：中性四选一 SVG 版面考题 + 即时实测解析。
- **07 原海报与关键词**（暖米原纸 + 钴蓝夹边）：完整原海报放大拖动检视（Esc/点关闭）与四大关键词卡。

## 7. 练习设计
- **题干**：桌面端 `1140px` 宽的编辑专题页（左目录索引 / 中核心长文 / 右配图注释），四版缝距均 24px、字号配色完全一致，**只差三列宽比**，选最稳妥易读的一版。
- **四选项（中性标签，单变量）**：
  - 方案 A：`33 : 33 : 34`（机械均分，左目录浪费大量空位，中列正文仅约 17 字/行）
  - 方案 B：`20 : 56 : 24`（**正解**：左索引约 210px 紧凑不空，中列正文约 28 字/行稳落舒适带，右图注约 250px 从容承载）
  - 方案 C：`44 : 36 : 20`（目录宽于正文，视觉重心左倾、主次倒挂）
  - 方案 D：`12 : 74 : 14`（双翼挤成不足 135px 碎条，中列过宽失去三列分工）
