# 122 简化构图原则 · 设计与实现方案（PLAN.md）

## 1. 一句话道理
视觉系统处理画面时会自发压缩冗余信息，优先把重叠、零碎的形状解码成最少规则即可描述的基本几何组合；设计上主动剔除噪点并稳住骨架秩序，能让读者更快认出重点，但过度删减会连同辨识语义一并抹平。

## 2. 开场玩具：「双联构图减法解剖台（左：视觉输入 → 绿箭 → 右：大脑简译）」
- **核心动作**：1:1 化用 122 原海报标志性的「左繁 → 松绿右箭 → 右简」结构，构建通栏双室 2D Canvas（挂 `data-perf-drag`）。
  - **画布横拖（`data-perf-drag`）**：在画布空白处左右横拖连续调节「轮廓规整度（0%–100%）」，实时把毛刺锯齿轮廓收敛成基本几何形态。
  - **直接点击左室图形**：点击 3 枚干扰杂件（原海报深靛蓝斜叉条、暖灰底弧、杂乱修饰碎块）当场剥离或装回；也可以误点 3 枚核心基本形（朱橘圆、松绿方、樱粉三角）来测试「删掉骨架」的后果。
  - **直接拖拽核心三形**：在左室拖移橘圆、绿方、粉三角的位置，检验遮挡率、中心对齐与呼吸余量，也可点击预设按钮测试多组合法解（原海报竖塔解、横向等距解、品字均衡解）与两种典型错态（叠成一团、过度极简）。
  - **三题材切换**：`原海报几何塔`（默认，复刻 122 原海报圆/方/三角+蓝斜叉+灰弧）、`品牌徽标提炼`（日落灯塔咖啡徽标去冗余）、`移动卡片减法`（促销首屏卡去斜带杂框）。
- **开场状态（非答案）**：0/4 欠简化错态——3 枚原海报干扰件全部压在主体上、轮廓规整度停在 18%（17 处冗余折角）、三核心形重度遮挡（44% 叠压）且轴线散乱；右室实时呈现「大脑解码重影与多解冲突」，读数明确点出首要阻塞点。
- **怎样算玩错 & 读数如何说「为什么」**：支持双向玩错，绝不能拉满/点满过关：
  1. **欠简化错态（4 类）**：干扰杂件未剥（遮挡主体轮廓）、轮廓锯齿过碎（规整度 < 55%，编码折点过多）、主体叠压遮挡（遮挡率 > 22%，触发无形态补全歧义）、轴线失序贴边。
  2. **过度简化错态（2 类，反拉满陷阱）**：误删任一核心基本形（触发「骨架残缺」——大脑省力却丢掉语义）、把轮廓规整度硬推到 > 88%（触发「过度均质」——方与三角被磨成无差别的三个圆饼，辨识特征归零）。
  - 所有读数（实绘顶点数、干扰件数、遮挡面积比、骨架留存率、编码负荷示意档位）均由 `model.js` 从左室同一组实绘几何坐标单真源核算，并实时驱动右室大脑简译画布与底部四维标徽。
- **与最近 12 页的区别**：121 是全宽运动编队矢量流场 + 深靛底栏；120 是左 62% 围栏点阵 + 右 38% 三注卡；204 是午夜蓝极坐标圆盘；075 是薄荷青 3D 等角搭积木；287/286 是真实 UI 设置页与搜索页；159 是薰衣草浮动卡 + Z 轴剖面；325 是宣纸对开折枝卷；036 是晨空 C 弧；245 是腮红对称视口伸缩；203 是深松石星盘；074 是斜投影拉深台。本页独创「包豪斯双联解码报版（左输入 ⇄ 绿箭 ⇄ 右脑补实时同步）+ 双向过犹不及减法手术台」，无任何玩法撞车。

## 3. 版式骨架
- **1440×900（主宽 1360px）**：无深色顶眉、无圆角仪表盘侧栏。顶部为硬朗 2px 黑线包豪斯报头（左 54% 自示范实时坍缩徽标 + 大标「简化构图原则」× 右 46% 原海报朱橘竖杠总述与直角方格三题材切签）→ 中央通栏 2px 框双联画布（左室输入 → 松绿转换箭 → 右室大脑实时简译，高约 415px，整屏视野饱满）→ 下沿 1.5px 实黑分隔线下直承原海报底带格局（左 45% 四栏竖线 `简洁 ● | 规则 ⊞ | 秩序 ☰ | 易读 ▲` 实时状态格 × 中 24% 甜点刻度操控带 × 右 31% 原海报圆角细黑框橘勾单真源诊单），首屏完整收束且不锁 `100svh`。
- **2560×1440**：主容器舒展至 `1760px`，双联画布增高至 `520px`，版面呼吸大气不缩成窄柱。
- **1024×1366 / 768×1024 平板**：自然流排不锁 `100svh`，双联画布全宽展示下接四格状态与操控诊单，零大片留白。
- **390×844 手机竖屏**：压缩单行刊头并把总述文字后置到画布后，画布切换为等比上下双室（上室视觉输入 ↓ 下室大脑简译，高度约 395px，稳占首屏 ≥ 47%，圆始终保持真圆不压扁），画布正下方立即可见四维压缩条与诊单首句。
- **844×390 手机横屏**：切为左 58% 横向双联画布 × 右 42% 紧凑刊头、快速滑控与诊单首句并行，零纵向压爆。

## 5. 节目录（7 大节 + 页脚，所有 h2 ≤ 12 字，相邻控件完全不重样）
- `01` **大脑为何偏爱最简形**（亮象牙纸）：引原海报总述与两要点，设「说多了一点」温和修正 Koffka 的「条件所允许」边界；交互：**双解编码天平（SVG 爆裂拆分器）**，对比五环/三形叠加/十字矩形在「大脑简解」与「物理碎片」下的规则数与折点数差异。
- `02` **四根支柱拆出简与稳**（暖砂纸）：逐条展开原海报「简洁 / 规则 / 秩序 / 易读」四词；交互：**展讯卡片四开关逐级减法器**（含「过度删信息」陷阱开关），用户按任意顺序独立开关四项原则并实时观察层级与注视落点变化。
- `03` **信息压缩与视觉记忆**（深松绿暗室）：讲结构信息负荷与阿恩海姆的「拉平/锐化」；交互：**2D Canvas 瞬时闪现记忆台（Tachistoscope）**，调曝光时长或触发 350ms 瞬现，观察复杂歪形在短期记忆中如何自动被拉平为规则基本形。
- `04` **这套原则从哪来**（亮象牙纸）：梳理 1923 韦特海默 & 康定斯基 → 1935 考夫卡 → 1953 霍赫伯格/麦卡利斯特 & 1954 阿恩海姆 → 1969/1971 莱文伯格 SIT → 1970s 迪特·拉姆斯 / 2006 前田约翰 → 2012 瓦格曼斯百年综述；交互：**年代标本抽屉**，点击各年代节点切换右侧实时 SVG 历史实验图解（科弗曼立方体平面/立体双读、拉平锐化、SIT 编码序列）。
- `05` **什么时候用与别用**（极淡樱粉纸）：列出四大适用场景与四大典型失效场景（专业判读、过度同质失辨识、叙事丰饶艺术、界面伪极简藏风险），附同小类 115–126 一句话互链；交互：**三场景五档「简化临界刻度台」**（高速路标 / 地铁拓扑图 / 药品说明），拖动档位直观看到每类题材在几档触顶、在几档跌入信息失真红区。
- `06` **动手挑一挑**（深靛蓝暗室）：两道单变量四选一练习，选后当场给结构化理由并高亮差异。
- `07` **原海报与关键词**（暖象牙纸）：`<img id="poster" src="poster.webp">` 支持点击全屏灯箱放大、拖动、Esc 关闭；右侧列出原海报四关键词、用法原话与同小类速览。

## 7. 小练习设计（单变量、中性 A/B/C/D 标签）
- **题 1（标志提炼 · 单变量：辅助几何冗余与形态区分度）**：同一「日落灯塔」标志四方案（A 叠加斜叉灰弧外框、B 清晰三基本形竖轴排开、C 三形全磨成无差异圆饼、D 三形斜压重度叠咬），唯一正解为 **B**，兼考「欠简化」与「过度均质」。
- **题 2（活动入场券 · 单变量：装饰噪点与必要信息完整度）**：同一「周末建筑展」入场券四方案（A 单轴对齐留完整时间地点、B 为追求空白删掉时间地点只留两字、C 每行套彩框加斜纹角花、D 去装饰但同字号居中糊成一段），唯一正解为 **A**，考「去装饰不等于去信息与去层级」。
