# 066 前景框架构图 · 页面方案（PLAN）

## 1. 一句话道理
前景框架不是给画面套装饰边，而是用近处低干扰的前景遮罩主动裁去外围杂讯，把观者的视锥收束进一个干净的框口里——借着近远视差、明暗/纯平对比与边缘导向，让视线绕开外围、一眼落到被围合的主体上，同时建立清晰的「近框 → 留白 → 远景」空间层次。

## 2. 开场玩具：活体穿框取景台（Live Aperture Viewfinder & Parallax Stage）
- **核心动作（前景框架独有）**：
  - **横移机位产生真实近远视差**：在主画布上直接左右拖拽（`data-perf-drag`，`touch-action: pan-y` 保留竖屏滚动）或用键盘 `← / →` 移动摄影师在前景拱门后的站位 `stanceX`。前景框架距镜头近、位移幅度大，远方山峰与日轮距镜头远、位移幅度小，拖动时肉眼直接看见「透过前景拱门挪步把远山收入框口」的真实穿框视差；
  - **开合框口直径**：直接拖拽画布框口边缘拉环、底部贴合框口标尺或按 `↑ / ↓`，实时改变框口开度（面积 12%–84%）；
  - **清净框内与压静前景**：在右翼深酒红「运用要点」建筑竖柱内，一键清净框内杂枝干扰、切换前景明暗/纹理极性（花纹亮框反抢 / 纯平玫瑰海报框 / 深酒红暗框压亮 / 透明幽灵框），并切换视线引导线；
  - **四原型即换**：底部直接承袭原海报「形式示例」条，点击切换 4 种真实前景框架（`拱形框架` / `自然框架` / `几何框架` / `遮挡框架`）与 3 套远景题材（`原海报月门` / `苏园漏窗` / `暗室门廊`）。
- **开场初始态（0 / 4 翻车错态，绝不提前给答案）**：
  - 框口收窄成窒息针孔（开口面积仅 ~15%）；
  - 机位偏左（`stanceX = -0.34`），远方深酒红山峰被右拱壁直切 ~45%，且框内叠着两簇杂乱斜枝挡主；
  - 前景处于「亮色高对比斜纹花框」模式，比远山还花哨抢戏；
  - 视线几何落点与山峰主体重心错位明显。
- **怎样算玩错、读数怎么说「为什么」**（全部由 `model.js` 从实绘几何单真源算出）：
  1. **针孔窒息**：框口面积 < 24% → 前景吞掉四分之三画面，视线被憋在窄洞里；
  2. **边框消失**：框口面积 > 72% → 前景退成画幅最外一圈细边，穿框纵深感彻底瓦解；
  3. **切主残缺**：主体被前景边缘裁切 > 6% → 前景从「引路人」变成「挡路墙」；
  4. **贴边切线**：主体未裁但与框内缘最小净距 < 5% → 像卡在门框里动弹不得；
  5. **框内杂乱**：框内残留杂枝干扰 → 违背原海报「让框内空间简洁，避免干扰」；
  6. **前景抢戏**：前景高纹饰高反差 → 眼睛先被吵闹边框扣住，找不到画心；
  7. **框感苍白**：前景与背景明度差过低（幽灵半透 < 1.35:1）→ 分不清哪层在前哪层在后；
  8. **多组合法解**：4 种框架原型、3 套题材、以及「纯平玫瑰海报框」或「深酒红暗框」两种明暗极性，只要开口合宜、主体完整入框留呼吸、框内洁净且前景退让，均实算通过 4/4。
- **与最近 12 页的明显差异**：
  - 065 是 Three.js 3D 玻璃拆层盒 + 三道通栏色带；316 是玄夜 5 重嵌套门洞 Z 轴推深；315 是对称三列竖立轴仰角推尺；027 是对称中轴天平；148 是逆光剪影绕排。本页是「不对称穿框视差取景 + 实绘框口开合 + 4 原型形态切换 + 原海报右翼深酒红山形竖柱」，玩法、视觉与空间动作均独属 066。

## 3. 版式骨架（忠实承袭 066 原海报）
- **1440×900 桌面（容器 1360px；2560×1440 扩宽至 1760px）**：
  - 极细 30px 酒红顶眉下，右上角铺原海报标志性**粉玫瑰大圆弧（#EEAAA6）+ 3×3 梅红点阵**，左上排示范大标「前景框架 构图」（字旁嵌原海报双拱粉玫瑰徽记与活体联动微框）、英文标与原海报总述。
  - 首屏中段采用原海报标志性的**三区非对称建筑构成**（不锁 `100svh`，避免平板空洞）：
    - 左 19%：原海报三道水平虚线引注（`● 框口 FRAME` / `● 主体 ENCLOSE` / `● 视线导向 GUIDE`），实时回显单真源指标，点击可高亮画布对应几何测线；
    - 中 52%：大比例玫瑰拱门活体画布 + 底沿一体化框口标尺与视差提示；
    - 右 29%：原海报标志性的**尖顶深酒红建筑竖柱（#4D1A22）**，顶嵌浅粉圆点，内置细线框「实时诊单 + 运用要点」四项几何图标控台（□/●/▶/:::）。
  - 首屏底沿紧接原海报**竖排酒红标「形式示例」+ 四枚微缩框架标本按钮 + 题材与复原键**，最底配原海报**左玫瑰斜纹 + 右实心酒红条**。
- **1024×1366 / 768×1024 平板**：不锁屏高；三枚左引注自动收成画布上方三列精炼指示条，画布（58%）与深酒红竖柱（42%）自然并排，底接四标本条。
- **390×844 手机竖屏**：极紧单行刊头（~74px），紧跟等比 4:3 穿框画布（稳占首屏 ≥ 45% 屏高，圆形拱门绝不压扁成椭圆）+ 四标本快切条 + 首屏可见酒红诊单主句；左引注收至诊单下端，不挤首屏。
- **844×390 手机横屏**：切左 54% 活体穿框舞台 × 右 46% 紧凑标题、诊单与控参并行。
- **正文七节底色节奏**：暖白浅宣 `#FBF3EA` → 暖米原纸 `#F8EADC` → 03 节深酒红暗房 `#3A0B14` → 柔玫瑰雾纸 `#F2DFD1` → 暖白浅宣 `#FBF3EA` → 06 节深酒红测验工坊 `#4D1A22` → 07 节暖米原海报 `#F8EADC`。

## 5. 节目录（01–07，所有 h2 ≤ 12 字，相邻节零重复控件）
- **01 · 框口、主体与视线**（`Anatomy of a Frame`）：原海报三要素与四条运用要点白话拆解 + 辨析「框得越紧越聚焦」边界 + 链接兄弟页 065 / 067。交互：**三幕视线收敛对比剧场**（按钮一步切换「无框裸景 / 吵框反抢 / 沉静拱框」，动画回放视线首次落点与停留收敛路径）。
- **02 · 四种经典框架语言**（`Four Framing Archetypes`）：展开原海报底部「形式示例」的自然、几何、拱形、遮挡四类框架性格。交互：**四联换景标本墙**（跨题材切换：山居孤峰 / 街巷背影 / 窗台静物 / 封面字心，点击任意标本展开构造线与开口度解剖）。
- **03 · 前景明暗与虚实反差**（`Contrast & Depth of Field` · 深酒红暗室）：拆解「暗框亮主」「虚框实主」「纯平色框」三条不抢戏法则 + 链接兄弟页 068 / 069 / 070。交互：**光学暗房双维矩阵台**（光圈景深 3 档 × 前景明暗极性 3 档，2D 画布实时渲染前景焦外羽化与对比度读数）。
- **04 · 从画窗、园林到银幕**（`From Alberti to Cinema`）：核实过的 5 个历史节点（1435 阿尔贝蒂、1631/1634 计成《园冶》、1658 德·霍赫 & 约 1669–1670 维米尔、1857 歌川广重、1956 约翰·福特《搜索者》）。交互：**可点选的五幕构图蓝图灯箱**（每步重绘极简几何框架与视线流向结构图，无写实五官）。
- **05 · 什么时候用，什么时候别用**（`When to Use & When Not To`）：正面四景与四类明确失效反例（宏大广角全景、精密建筑/产品测绘、超小缩略图、无语义硬凑框）+ 链接兄弟页 071–076。交互：**四场景「套框 / 撤框」实地对照拨片**（一键对照同一真实任务加框与撤框的成败）。
- **06 · 挑一挑：哪张最成立？**（`Spot the Sound Frame` · 深酒红工坊）：两道精细单选题。第一题四张同场景古镇石拱图只差一个变量（狭口厚拱 / 匀阔沉拱 / 偏轴切峰 / 亮纹饰拱），中性命名绝不剧透；第二题考「哪种任务应该撤掉前景框」。选后即时高亮问题几何并逐项给理由。
