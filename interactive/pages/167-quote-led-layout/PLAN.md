# 167 · 引语主导版式（“排版不仅传递信息，也组织阅读。”）方案

## 1. 一句话道理
在全页文字海里，把最具观点分量的一句话从段落中抽离、放大、配以留白和精准断行，让这句话本身取代配图成为第一视觉锚点，并用引号、强调线与气口停顿替读者预设默读的轻重与节奏。

## 2. 开场玩具：活体引语断行与呼吸排印台（Live Quote Line-Break & Cadence Typesetter）
- **怎么玩**（1:1 承袭 167 原海报炭墨宣黑底、斜对角酸黄绿几何巨引号、暖奶白粗黑大字、干笔荧光笔刷线与下方「引用 / 强调 / 节奏」三栏竖线结构；2D Canvas 主印张标 `data-perf-drag`）：
  1. **横拖海报印张（或拉测度与尺度轨）**：连续推拉引语字号与行宽测度（`1.00×–3.00×`），亲眼看见原本淹没在密字里的普通句子被撑开成整张海报的视觉主角，也亲手把字拉爆到顶边窒息。
  2. **直点画布上的字间气口刀（`|` 断行锚点）**：自由在句中落刀换行或合行，手工编排三拍短顿（如原海报「排版不仅 / 传递信息， / 也组织阅读。」）、两行对仗或四行阶梯；故意在词中间落刀会立刻触发「劈词卡喉 / 孤字吊尾」真错误诊断。
  3. **调控引语四柱（全双向可错）**：
     - 尺度与留白（太小淹没灰海 / 太大挤死留白）
     - 引号与光学悬挂（机械直引号内缩啃左沿 / 无引号素排 / 斜对角悬挂巨引号 / 满屏巨引号压字抢戏）
     - 强调笔刷（零强调平铺 / 尾句干笔刷线 / 关键词亮色强调 / 全句满涂荧光）
     - 出处落款（同号同重抢主 / 缺失无源 / 破折号退让署名 / 长传记压底）
  4. **三套真出版标本切换 + 一键「阅读节拍光束」回放**：在「原海报 · 瑞士排印宣言」「杂志跨页 · 建筑访谈样本」「书封腰封 · 科学随笔样本」（后两套明确标为教学编辑样本，不假托名人）间切换；点按回放让一道酸黄绿节拍光束按实际断行与气口停顿匀速扫过，把「组织阅读」可视化。
- **开场初始状态（绝非答案）**：刻意停在 `0/4` 复合错态——字号仅 `1.12×` 淹没灰海、长行平摊零气口且第二行吊孤字、用机械直引号 `"` 内缩啃齐左沿、无强调笔刷、出处署名与引语同号同色抢主。
- **怎样算玩错、读数怎么说**：由 `model.js` 从实绘每行文本矩形、词界切分、引号边界、干笔高亮覆盖率与留白比例单真源核算 **10 类双向真错态**（淹没失焦、爆字窒息、劈词卡喉、孤字吊尾、超碎竖柱、直引号啃边、巨引号压字、零强调平铺、全句涂满失焦、署名抢主/无源/压底）。每次报错都用白话指出「这样摆读者眼睛会怎么读歪」，给出可执行的下一步动作。
- **多种合法解**：接受原海报三拍斜角巨引号解、杂志两行关键词亮色悬挂解、极简无引号高留白展墙解（印证 Butterick「独立大段引语可省冗余引号」原则），不是唯一预设。
- **与近 12 页的明显差异**：近 12 页分别玩图录标尺（166）、折门开合（331）、3D 街景俯仰（080）、横向卷轴（252）、6 秒眼动红带（127）、5×6 破格拖块（210）、3×3 Nudge 微距（294）、主宾三圆（330）、俯拍转盘（079）、辞书切口（165）、比例装裱框（251）、三角骨架（041）；167 独创**字间气口刀断行 + 光学悬挂引号 + 干笔强调 + 阅读节拍光束**的纯文字排印玩法，别的编号完全无法套用。

## 3. 版式骨架
- 忠实转译 167 原海报「炭墨宣黑全出血海报暗房 × 极简双翼眉（左上系列标 + 右上酸黄绿左竖线导语与波浪线）× 左 64% 活体海报大印张与测度标尺 × 右 36% 挂引号实况缩略卡与单真源批注控台 × 底沿酸黄绿通栏细线与三栏竖线『引用 / 强调 / 节奏』活体仪带」（零圆角仪表盘黑箱、不锁 `100svh` 避平板大空白）。
- **2560×1440**：主宽舒展至 `1680px`，大印张宽阔不缩成窄条。
- **1440×900**：主宽 `1360px`，顶眉紧凑，左 64% 活体海报印张 × 右 36% 诊单与四柱排印控台，底沿三栏竖线带自然衔接，首屏完整可见印张、诊单首句与操作控件。
- **1024×1366 / 768×1024 平板**：自然流排，全宽印张下接左右双列（诊单 × 控台），再接三栏竖线带，绝无空洞。
- **390×844 手机竖屏**：极度压紧单行刊头、将右上导语移到印张后，让等比活体海报印张稳占首屏 ≥ 48% 高度，下半屏直见单真源诊断首句、快捷节拍回放与测度滑轨。
- **844×390 手机横屏**：左 55% 等比活体印张 × 右 45% 刊头 + 单真源诊单 + 核心切签并行，不裁字、不压扁。

## 5. 节目录（7 节，每节 h2 ≤ 12 字，相邻两节交互零重复）
- **01 句子怎么变成画面**（`QUOTE AS VISUAL`）：引出原海报「引用 / 强调 / 节奏」原话；交互为**杂志实景双态帘幕滑杆（Split Curtain）+ 四步剥离按钮**，直观把一段普通正文拆解成引语主导版面。
- **02 引号的光学微差**（`OPTICAL ALIGNMENT`）：讲直弯引号区别与左沿悬挂标点；交互为**SVG 左沿光学垂线放大镜**，拖动检测垂线并切换「直引号 / 弯引号内缩 / 悬挂引号 / 独立省引号」，同步产出实时 CSS。
- **03 停顿就是阅读节奏**（`PACING & CADENCE`）：拆解断行与行距如何控制默读速度；交互为**2D Canvas 活体乐谱式阅读节拍器**，点按句中字缝自由切换「连读 / 轻顿 / 换气大顿」并换行距，实时绘制声波节拍条与排布。
- **04 从题词到杂志引语**（`WHERE IT COMES FROM`）：16 世纪卷首题词 → 1928 奇肖尔德 → 1934–1958 布罗多维奇 → 1981 米勒-布罗克曼 → 1992 布林赫斯特与 2004 卢普顿；附**「出处说明」温和纠偏卡**，诚实说明原海报引语为后人对米勒-布罗克曼理念的凝练转述而非公开逐字原句。交互为**年代文献切片手风琴卡**。
- **05 什么时候别用它**（`WHEN NOT TO USE`）：结合 NN/g 眼动打断深度阅读研究与 Butterick 反空洞引语批评，点选 4 类出版场景翻看失灵原因与对应同小类替代页面（一句话链接 160–166 全部 7 页）。交互为**四场景体检诊断切换台**。
- **06 四版校样挑一版**（`PROOFING PRACTICE`）：四选一小练习，仅改变「断行气口」这一个变量，中性标 `校样 A / B / C / D` 实绘 SVG 样张，选完逐一解析。
- **07 原海报与出处**（`ORIGINAL POSTER`）：`poster.webp` 放大拖动灯箱（`draggable="false"`、Esc 关闭）、海报全原文与三枚关键词，以及出版功能页面同小类索引。

## 7. 小练习
- **题目**：四份引语主导校样的文案（「好建筑先听懂风向，再决定墙立在哪。」）、字号、留白、配色与出处完全一致，**只改动了「断行气口」这一个变量**。哪一版最能组织清晰、顺畅的阅读节奏？
- **四选项（标签仅写 校样 A / B / C / D）**：
  - `校样 A`：按容器自然折满两行，末行孤零零吊出一个「哪。」且「决定墙」被拆开（孤字吊尾）。
  - `校样 B`：强凑等宽方块（6-6-5 字），把「风 / 向」「决 / 定」从词组中间硬劈断（劈词卡喉）。
  - `校样 C`（**正确答案**）：按语意三拍阶梯断行（`好建筑` / `先听懂风向，` / `再决定墙立在哪。`），立题—承接—收束三顿分明，无劈词无孤字。
  - `校样 D`：切得过碎成 6 行窄柱（每行 2–3 字），视线高频折返、吃掉上下留白。
