# 265 标签页布局 · 互动页方案

## 1. 一句话道理
标签页把同级、并行、互不要求同时对照的内容折叠进同一块画布，用「当前页签与面板视觉无缝连通」和「切换后留住位置与输入」换取高空间效率，让人不用跳转页面就能在几组视图之间轻松切换。

## 2. 开场玩具：「档案夹标签实境装配台」（Live Folder-Tab Workspace & Stress Bench）
- **怎么玩**：
  - 1:1 承袭 265 原海报的「紫色档案夹页签 + 紫框白底大面板 + 右侧豆绿设计要点卡 + 底部淡紫使用建议带」真实交互工作台，提供「原海报 · 项目工作台 / 电商 · 商品详情 / 设计系统 · 组件文档」三套真实语境。
  - **直接点击标签栏里的任意标签**（或用键盘 `←` / `→` / `Home` / `End` 真走 WAI-ARIA `tablist` 协议）切换当前视图；在「概览」视图里可以点击筛选芯片或在草稿栏键入备注，切去「数据 / 成员 / 设置」再切回，亲手验证「保持上下文」开/关带来的输入留存与清空差异。
  - **直接点标签上的 `×` 裁减冗余标签**或点 `+` 增补标签，体验从 7 个拥挤标签收束到 3–5 个（或故意删到只剩 1 个、加到 8 个）。
  - **直接左右拖动面板右缘紫色宽尺柄（标 `data-perf-drag`）**在 320–920px 间连续压测容器宽度，实时观察真实 DOM 标签栏折成两排、单槽缩窄裁切或稳稳排成单行的几何变化；面板内联 2D Canvas 同步绘制原海报同款紫色扇形饼图、波动曲线与按 `Space` 触发的「切页注意力与缝隙连通路径」验真动画。
  - 底部淡紫控制条提供标签命名长短、当前态连通方式（弱态断开 / 紫标档案夹连通 / 紫线底标）、上下文记忆开关、溢出策略（双排折行 / 单排约束 / 横向滚动），并支持一键试错与多组合法解。
- **开场初始状态（不能已是答案）**：
  - 打开即处于 **0/4 坏态**（直接复现原海报右下角「不佳示例」）：7 个冗长命名标签（`核心概览视图`…`其他杂项`）在双排折行下挤作两行、当前标签呈弱灰且被底边横线隔断（与内容区视觉断连）、上下文记忆关闭（切页清空筛选与备注）。
- **怎样算玩错 & 错了读数怎么说（单真源 `model.js` 双向检出 8 类错态）**：
  - 标签只剩 1 个 →「只剩 1 个标签，没必要用标签页」；
  - 标签 ≥ 6 个 →「7 个标签挤满顶栏，扫描成本陡增」；
  - 折成 ≥ 2 排 →「标签折成两排，点击后排会视觉跳层」；
  - 单槽窄于 72px →「单槽宽仅 XXpx，容易误触且文字裁切」；
  - 冗长标签名 →「标签名称过长，横向空间被文字吃空」；
  - 弱态断开 →「当前标签与内容区断连，找不到自己在哪」；
  - 上下文关闭 →「切页清空输入与筛选，任务流程断裂」；
  - 多余标签靠横滑硬塞 →「横向滚动藏起后半段标签，变成盲盒」。
  - 同时认可多组合法解：原海报 4 签档案夹解、极简 3 签底线解、5 签宽屏解、窄屏 3 签移动解。
- **与最近 12 页的区别**：
  - 183/224/223/178/179/181/180/097/099/098/096/094 分别是绕排画布、行内流道、块级盒尺、居中碑帖、两端排盘、非对称排印、强撑拉筋、视觉天平、巨微尺标、比例卡尺、主次引力盘与星图巡航；本页开场是一个**真正能切页、能输备注测状态留存、能现场删加标签、能拖右壁压测单双排折行的活体档案夹工作台**，任何其他编号都无法套用。

## 3. 版式骨架
- **1440×900 & 2560×1440**：忠实转译 265 原海报自上而下的「档案夹单轴展板」骨架（不锁 `100svh`，杜绝平板大片空白）。主宽 1360px（2560 舒展至 1580px）：顶部左 58% 巨黑自示范标题「标签页布局」配深绿 `TAB LAYOUT` 与总述、细竖线隔开右 42% 「分组 · 切换 · 上下文」与三枚豆绿圆徽实时探针 → 通宽活体档案夹主容器（顶排真实可点可删标签 + 紫框白底大面板内部左 63% 真切视图与拖宽柄 × 右 37% 豆绿「设计要点」单真源诊单卡，齐底对齐）→ 下接淡紫「使用建议与规则开关」实操带。
- **390×844（及 360×740）**：顶栏与主标压紧为一行标题 + 状态徽，将长导语和三枚圆徽挪至主舞台之后，确保活体档案夹工作台 + 诊单首句 + 主控件稳占首屏 ≥ 48%，圆图和画布严格等比不被压扁。
- **844×390 横屏**：首屏切为紧凑左 58% 活体档案夹工作台 × 右 42% 刊头、诊单与核心快捷按钮并行排布。
- **768×1024 & 1024×1366 平板**：自然流高度，无 `100svh` 留白；主容器内视图与豆绿诊单双栏并列齐底。
- 正文七节节奏：淡豆绿纸（01）→ 暖宣米纸（02）→ 深鸢尾紫暗室（03）→ 暖宣米纸（04）→ 柔淡紫雾（05）→ 深鸢尾紫考场（06）→ 暖宣米纸原海报展墙 + 招牌紫罗兰圆角宣言页脚（07）。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻节不复用同种交互控件）
1. **01 纸夹隐喻与连通**（`FOLDER METAPHOR & ANATOMY`）：讲清物理索引卡隐喻与四部件结构；交互：四种视觉形态切签（档案夹 / 底线 / 胶囊 / 竖签）+ 四处解剖热区点选聚光。
2. **02 多少个标签才不挤**（`TAB COUNT & LABEL BUDGET`）：引出海报「3–5 个」经验值并温和补充 2 签和宽屏边界；交互：复刻海报「良好示例 vs 不佳示例」的 2D Canvas 槽宽与折行实测仪（数量步进 2–9 + 视口档位 + 命名长短）。
3. **03 四个最常见的暗礁**（`FOUR COMMON PITFALLS`）：深紫暗室四诊台；交互：四张可亲手触发痛点再一键「看修复」的真实故障微场景（双排跳层、伪流程步骤、强拆对比、套娃嵌套）。
4. **04 从档案夹到浏览器**（`FROM INDEX CARDS TO ARIA`）：1982 WordVision → 1992 Quattro Pro → 1994 InternetWorks / 1995 Windows 95 → 1997 NetCaptor → 1998 Amazon → 2005–2024 设计模式与 W3C APG；交互：活体 WAI-ARIA 键盘焦点与 Roving `tabindex` 模拟器（支持真键盘与屏幕键帽，切换自动/手动激活）。
5. **05 什么时候用，何时换**（`WHEN TO USE & ALTERNATIVES`）：适用条件与禁用红线，并一句链接到同小类兄弟页（258/259/262/263/264/266/267/268）；交互：四题场景约束切换卡，实时给出「该用标签页」或「该换哪一页」的决策建议。
6. **06 眼力小练习**（`SPOT THE SOUND TAB BAR`）：深紫考场单选练习；交互：A/B/C/D 四张中性标签微缩图卡只差一个结构变量，选完给全部四项解析并支持重测。
7. **07 原海报与关键词**（`ORIGINAL POSTER & KEYWORDS`）：原海报高清放大拖看灯箱（`draggable="false"` + 缩放/拖动/Esc）+ 海报三关键词与结语 + 紫罗兰圆角宣言页脚。

## 7. 练习设计
- 题干：要在 420px 宽的项目卡片里组织「概览、数据、成员、设置」四组同级视图，以下四个方案仅在**当前态视觉与排布细节**上各差一个变量，哪一个最可靠？
- 四个选项（中性标 A / B / C / D，不透题）：
  - **A（正确）**：4 个简短单排标签，紫色当前标签底边与白底面板无缝连通，非当前标签呈柔和豆绿。
  - **B**：同样 4 个简短单排标签与紫色高亮，但当前标签下方保留粗分隔线并浮离内容框，切断与面板的从属连通。
  - **C**：同样紫标连通与色彩对比，但每个标签加上冗长前缀导致 420px 内折成错位两排。
  - **D**：同样 4 个简短单排标签，但反将 3 个未选中标签涂满深紫、当前标签留白灰，视觉主次倒置。
