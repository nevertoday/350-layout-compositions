# 302 双人构图（TWO-SUBJECT COMPOSITION）互动页方案

## 1. 一句话道理
当画框里出现两个人，构图的主角不再只是两个孤立的剪影，而是夹在两人之间那条看不见的「视线轴线、主次天平与呼吸负空间」——空间秩序立住了，关系和戏剧张力不用台词就能读出来。

## 2. 开场玩具：「双人走位 × 180° 轴线机位同步台」
- **怎么玩**：
  - **开放银幕画布（2D Canvas，标 `data-perf-drag`）**1:1 承袭 302 原海报的暖杏纸底、柔白穹顶光晕、陶橙梯形地板、两位无五官深褐侧影人物、虚线对话视线箭与 `+` 重心符号，并支持切换三套叙事情景（`原海报·双人沙龙` / `咖啡馆博弈` / `站台并肩`）。
  - **空白处/中段横向拖动**：沿 180° 弧形机位轨道平滑绕拍双人，画布按真实透视投影联动两人的屏幕横坐标、景深大小比例、地板透视斜率与光晕视差，同时同步转动一旁的**「俯视 180° 轴线机位盘」**。
  - **直接拖动人物 A 或人物 B**：横向改两人间距（测试呼吸负空间），纵向改身高/前后层次错位（建立主次或对角线关系）。
  - **点击人物切换朝向 / 拖动俯视机位盘上的副机位 B / 点「正反打切镜」**：亲眼体验 180° 轴线安全区与越轴穿帮（切镜瞬间两人左右身份翻转、视线全朝同侧看空）。
  - **点击底部原海报「常见双人构图形式」五格暖沙胶片卡**，一键演练 5 组截然不同的合法解（对称对话 / 错位对话 / 前后层次 / 同向观看 / 对角线构图）。
- **开场状态（刻意坏帧，绝不先给答案）**：
  - 打开即落在 `0/5` 复合错态：人物 A 与 B 挤撞在一起（负空间仅 5%，几乎膝盖碰膝盖）且整体偏向右侧造成重心右倾失衡，左人 A 抬头望向左外侧、右人 B 垂头错高导致对话轴线断裂，两人体量与明度完全平分抢戏，且副机位 B 越过 180° 轴线停在红色越轴禁区。
- **怎样算玩错，错了读数怎么说**：
  - `model.js` 从实绘几何（两人的屏幕投影包围盒、眼部坐标、面积权重、间距占屏宽比、边缘留白、重心力矩偏移、重叠遮挡比、机位轴线象限）单真源双向核算 7 类错态：
    1. 负空间过窄（<12% 挤撞窒息）或过宽（>64% 贴边割裂，像两张拼起来的独照）；
    2. 视线背离 / 眼线错高（未建立对话轴线，或同向观看时面朝短边撞框）；
    3. 机位过侧造成人物重叠遮挡（重影压脸）；
    4. 副机位越过 180° 轴线（切镜时屏幕方向左右颠倒穿帮）；
    5. 画面视觉重心严重偏斜（单侧空塌）；
    6. 非对称构图中主次体量拉平抢戏；
    7. 人物被推到画框边缘被硬裁。
  - 每条错态都以深褐导演白话诊单讲清「现在为什么难受 / 观众会误读成什么关系 / 怎么拖一笔就救回来」，所有数值来自实绘几何，主观关系态势只写档位并标注「示意」。
- **与最近 12 页的差异**：
  - 301 是深松青单人孤崖摇镜与焦段推拉；302 是暖杏陶橙双人银幕与实时双向耦合的「俯视 180° 轴线机位盘 + 双人独立走位 + 正反打切镜验证」，玩法完全植根于「两人关系与对话轴线」，绝无法套用到单人或其他任何一页。

## 3. 版式骨架
- **「暖杏编导台 × 双分镜连幕骨架」**（无深灰顶栏、无通用深色仪表盘箱、不锁 `100svh` 避平板大空白）：
  - **1440×900（主宽 1380px；2560×1440 舒展至 1680px）**：
    - 顶行自示范刊头：左为超粗深褐主标『双←→人构图』（双与人之间嵌实时呼应画布间距的微缩陶橙虚线轴与 `+` 号）+ 陶橙 `TWO-SUBJECT COMPOSITION` + 总述；右为情景切签、实时正反打切镜按钮与评定印章。
    - 中行主舞台非对称双联（左右齐底零空洞）：左 65% 为开放暖杏双人银幕画布与紧贴底沿的单行精控轨；右 35% 上半为实时联动的「俯视 180° 轴线机位盘」、下半为深褐导演白话诊单匣（两者高度合计严格对齐左侧舞台底边）。
    - 下行贯通陶橙细线 → 原海报五枚陶橙圆徽活体原则横带（点击开关画布诊断叠层）→ 原海报五格暖沙「常见双人构图形式」直切带与试错按钮 → 满宽深褐圆角胶囊 TIP 条（1:1 复刻原海报底条）。
  - **1024×1366 / 768×1024 平板**：自然折排，全宽银幕画布在下接 2 栏等高（左俯视机位盘 | 右深褐诊单），再接五格形式卡与 TIP 条，零大片留白。
  - **390×844 竖屏**：压紧单行刊头并把总述后置，让等比银幕画布稳占首屏 ≥46% 屏高，折线内紧接深褐诊单首句与一键纠偏/五式快切，俯视机位盘顺排其下；所有画布严格等比缩放绝不压扁。
  - **844×390 横屏**：左 56% 等比双人银幕画布 × 右 44% 紧凑刊头、深褐诊单首句与主控并行。

## 5. 节目录（共 7 节，标题均 ≤ 12 字，相邻控件互不重复）
1. **01 两人之间，先定关系** (`ESTABLISHING RELATIONSHIP`) — 引出原海报总述与五要点，讲清为什么两人的核心在于「关系空间」；配**四类戏剧潜台词关系矩阵切换器**（平等对谈 / 上下博弈 / 暗生隔阂 / 默契同行），联动展示人际距离与权力高度解剖图。
2. **02 五种常见双人形式** (`COMPOSITION VARIATIONS`) — 逐一拆解原海报底部五式；配**五格胶片分镜卡 + 骨架线显隐 + 左右角色互换开关**，观察不同形态如何改变对话节奏。
3. **03 180° 轴线与视线匹配** (`AXIS & EYELINE MATCH`) — 深褐暗房章节，硬核拆解对话轴线与视线接续；配**360° 可拖副机位环形沙盘 + 实时 A/B 正反打切镜监视器**（支持拖机位过轴、改俯仰眼高、手动/自动演练正反打跳切）。
4. **04 双人构图从哪来** (`WHERE IT COMES FROM`) — 溯源纵深调度、好莱坞连续性剪辑、小津 360° 例外与霍尔空间关系学；配**四节点历史胶片时间轴展开卡片与机位平面示意**。
5. **05 什么时候用，什么时候别用** (`WHEN TO USE & WHEN NOT TO`) — 给出同框与拆镜的导演判断尺，温和补充原海报小贴士，并一句话分流链接至 301 / 303 / 304；配**四类拍摄现场抉择开关**（同框反应 / 爆发特写 / 三角冲突 / 大空间对峙）。
6. **06 导演审片：挑出成立一帧** (`DIRECTOR'S QUIZ`) — 深褐考场四选一，四帧仅差单一变量（负空间 / 视线轴线 / 主次比例），中性编号无剧透。
7. **07 原海报与关键词** (`ORIGINAL POSTER & KEYWORDS`) — 302 原海报大图（点击缩放、拖拽、`Esc` 关，`draggable="false"`）+ 五个核心关键词与页脚。

## 7. 小练习设计
- **场景**：职场上下级谈判，需要左方上司占主导、右方下属倾听且保持自然对话秩序。
- **四项只差单一变量**（纯中性编号「方案 A / B / C / D」与客观构图参数，绝不写褒贬词）：
  - **方案 A（正解）**：前景略高略大 + 后景略低较小 + 34% 负空间 + 斜向视线相交。
  - **方案 B**：仅改变负空间（压窄至 4% 贴撞），其余同 A → 违反负空间呼吸感。
  - **方案 C**：仅改变右方视线（背离外望），其余同 A → 违反对话轴线与视线匹配。
  - **方案 D**：仅改变体量与高度（拉平至 1:1 完全对称），其余同 A → 抹平主次关系。
