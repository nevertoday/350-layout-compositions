# 060 级联构图（CASCADING COMPOSITION）交互页设计方案

## 1. 一句话道理
级联构图把「层叠的压边咬合」和「斜向的逐级下坠」拧成一条单向视觉河流：每一张新卡压住前一张的非核心尾角、同时完整露出自己的左上标题入口，借格式塔「好连续律」和阅读重力，把五段信息连成自然落下的故事流。

## 2. 开场玩具：五幕瀑布级联编排台 × 落水视流轨迹仪
- **怎么玩**：直接承袭 060 原海报的水墨瀑布与五幕卡片（`01 引入` / `02 展开` / `03 深化` / `04 过渡` / `05 总结`，青绿→钴蓝→青绿→钴蓝→珊瑚橘收束），用 2D Canvas 实时瀑布水雾与视流跃迁弧托起 5 张可直接操作的实体级联卡。用户能做三类级联本体操作：
  1. **理顺五幕顺序**：直接点击画布上两张卡互换位置、把卡片拖到目标槽位互换、或使用底部五幕槽与方向键（`← / →`）调整 `01→05` 的排列次序；
  2. **拖瀑布步距轨（`data-perf-drag`）**：沿底沿五点节奏标尺左右连续推拉卡片步距（同步联动横向步距 Δx 与纵向落差 Δy），实时测量相邻面积交叠率与前卡文字安全区遮挡率；
  3. **调叠压朝向与倾泻坡度**：切换「前压后 / 后压前」验证谁盖谁的标题区，切换「横平 8° / 斜瀑 34° / 陡叠 62°」观察斜向势能何时退化成横排或竖向手风琴。
- **开场状态（非答案，不自动修正）**：停在「反叠乱序 · 步距过紧」真实翻车态——五幕卡序被打乱为 `[01, 04, 02, 05, 03]`（视线来回折返 3 处），叠压朝向反置为「前卡压后卡」（前卡右下角直接压掉后卡左上编号与标题），步距也收得偏紧，原海报四枚关键词圆徽（流动 / 顺序 / 节奏 / 连贯）处于 `1/4` 未达标态。
- **怎样算玩错、读数怎么说为什么**：所有几何坐标、相交面积、文字安全区遮挡率、折返次数与倾泻斜角全部由 `model.js` 同一套归一化矩形算出，按严格优先级一次只报一条主错，并讲清人眼为什么会被卡住：
  - **反叠吞字**：前卡压在后卡左上角，正好遮住下一幕的编号与标题入口；
  - **叙事折返**：01→05 逻辑顺序和斜落方向打架，虚线路径折成回头结，故事流断裂；
  - **步距过紧 · 压住正文**：相邻交叠超过经验上限（34%）或压入前卡文字安全区，前一步读不全；
  - **步距过散 · 断链孤卡**：相邻交叠跌破经验下限（8%），压边咬合消失，瀑布散成五张互不相干的浮卡；
  - **坡度过平 / 过陡**：低于 18° 退成横向平排缺少下落势能，高于 50° 挤成垂直手风琴丢掉横向展开视野；
  - **4/4 顺流级联成立**：四枚圆徽全亮，水雾光珠沿 01→05 虚线弧连续轻跃落入 05 珊瑚橘收束潭。
- **与最近 12 页的区别**：区别于 059（静态四层纸雕 Z 序与 38° 侧剖）、058（四级无叠压等轴台阶高差）、143（墙面开窗裁景）、270（克莱因蓝网格卡片间距）、226（弹性盒顶栏）、188（五栏文字基线）、021（海平气泡水准）、309（宽银幕轨道机位）、310（3D 三层景深桥）、103（3D PBR 材质测光）、225（评论流 BFC 印章）与 142（封面词块裁切），本页专属「五幕对角叠加叙事流 + 标题安全区实时遮挡测算 + 序列折返检测 + 瀑布步距连续推演」。

## 3. 版式骨架
- 直接呼应 060 原海报的「左栏编排说明 × 右侧宽幅瀑布斜流」不对称轻透版式（不锁 `min-height: 100svh`，避开平板竖屏空洞）：
  - **1440×900 桌面**：顶沿单行细线刊头（左系列、右 `✦ NO. 060` 副语）；左栏 33% 排微级联阶落的深藏蓝示范大标 `级联构图`、`CASCADING COMPOSITION`、原海报四词点列与总述、四枚原海报圆徽实时达标灯、以及细线圆角诊断框；右栏 67% 铺开无重外框的浅雾水墨瀑布主舞台（约 880×520px）与底沿一体化五幕顺序槽 + 步距游标控制台。
  - **2560×1440 宽屏**：版心舒展至 1860px，瀑布主舞台同步扩至约 1220×660px。
  - **1024×1366 / 768×1024 平板竖屏**：自然纵排不强撑全屏，顶标与四圆徽横列成头栏，紧接满幅瀑布舞台、控制台与诊断框。
  - **390×844 手机竖屏**：压缩刊头与标题行，正文总述后置，让等比瀑布主舞台首屏直占 ≥45% 屏高（约 366×392px，卡面精简为编号+两字幕名+波浪装饰防裁切），同屏下方即见步距游标、快捷顺序切换与紧凑诊断条。
  - **844×390 手机横屏**：切为左 56% 通高瀑布舞台 × 右 44% 紧凑标题、控件与诊断并行。

## 4. 配色和字体
- **配色（逐点实采自 `060.webp` 并校准无障碍对比度）**：
  - 雾瓷浅蓝底 `#EDF4F7` / 纯净云白纸 `#F7FAFC` / 冰雾次底 `#E4EFF4`
  - 深海藏蓝主墨 `#061838` / 正文深靛灰 `#1A2D46` / 次级灰蓝 `#445B75`
  - 深海暗版带 `#081C3A`（用于 03 节历史脉络拉开整页明暗呼吸）
  - 翡翠青绿（01/03 步）：图形 `#0D948F` / `#169394`，浅底文字加深 `#076B68`，水雾洗 `#CFE9F2`
  - 钴蓝（02/04 步）：图形 `#114ECE` / `#0E50C4`，浅底文字 `#0D41B2`
  - 珊瑚橘红（05 总结收束 & 错态警示）：图形 `#F05E40` / `#F46749`，浅底文字加深 `#C1391E`
- **字体搭配（全库唯一，两款西文均在最近 12 页从未出现）**：
  - **`Sora`**（400 / 600 / 700 / 800，最近 12 页未用）：英文主副标、编号 `01–05`、关键词英签与等宽对齐读数；
  - **`Instrument Serif`**（400 正体 + 400 斜体，最近 12 页未用）：节号、瀑布引语与英文小节副标，给理性几何画面注入水流般的出版气息；
  - **`Noto Sans SC`**（400 / 500 / 700 / 900）：中文大标与统一正文（正文里的西文人名与年份跟正文同体，杜绝混排跳动）。

## 5. 节目录（01–08，每节 h2 ≤ 12 字，相邻控件不重复）
- **01｜一叠一落，视线才成河**：原话展开总述与五幕职责（引入/展开/深化/过渡/总结）。交互：五幕点击解剖台，点选任意一幕，SVG 剖析卡片「左上阅读安全区 vs 右下承接装饰角 vs 虚线跃迁弧」。
- **02｜四道红线：怎样才会断流**：拆解反叠吞字、过紧压文、脱节断链与坡度坍塌。交互：二维 Δx × Δy 步距矩阵坐标板 + 实时 2D Canvas 瀑布压边验算。
- **03｜从格式塔到级联窗口**：深藏蓝暗版，梳理 1923 韦特海默好连续律、1956 阿诺德阅读重力、1973 施乐 Alto 重叠窗与 1987 Windows 2.0 / Win32 `CascadeWindows`、1993 麦克劳德漫画补全、1994 CSS 级联命名。交互：复古桌面窗口「级联 Cascade / 平铺 Tile / 叠死 Stack」实操切换器。
- **04｜四种舞台，级联怎么干活**：对应原海报应用提示（演示汇报、故事讲述、产品功能介绍、时间线梳理）。交互：四场景切换 + `上一幕 / 下一幕 / 全展开` 逐层步进分镜器。
- **05｜它和七位邻居的分工**：一句话界定同小类 057、058、059、061–064 并附在线版直达链接。交互：「压叠强度 × 顺序强弱」二维坐标图 + 邻居聚焦切换卡。
- **06｜什么时候别用级联**：温和修正原海报「让信息像瀑布一样自然落下，轻松跟随思路」（标「说多了一点」）。交互：三类真实场景（套餐价格横评 / 紧急告警清单 / 长篇教程目录）的「硬套级联 vs 换平铺对照」前后切替板。
- **07｜练一练：哪版最顺流？**：四张同色同题材 SVG 级联小样（中性标签 A / B / C / D，仅差单一变量：A 顺序折返、B 反叠吞字、C 顺流正确、D 断链散开），选后浮现几何批注与拆解理由。
- **08｜原海报与关键词**：内联 `poster.webp`（点开放大、鼠标/触控拖动平移、Esc 收起）+ 四枚原海报实心圆关键词徽章（流动 / 顺序 / 节奏 / 连贯）+ 标准页脚。

## 7. 小练习设计
- **题目**：同一组五幕产品发布卡片（青绿→钴蓝→珊瑚收束），四张方案只改了一个级联变量，凭直觉选出视觉最顺流、信息最易读的一版。
- **四个选项（仅标 A / B / C / D，外观同等精致，零暗示词）**：
  - `A`：叠向与步距正确，但第 4 幕与第 2 幕位置互换，读完 01 必须跳过中段去找 02（单变量：**序列折返打结**）；
  - `B`：顺序与步距正确，但采用前卡压后卡，把 02–05 左上角编号与标题压去大半（单变量：**叠向反压吞字**）；
  - `C`（**正确**）：01→05 沿约 33° 斜瀑依次推进，后卡稳稳咬住前卡右下装饰角（交叠约 22%、阅读安全区 0% 被遮），05 珊瑚橘稳收底端；
  - `D`：顺序与叠向正确，但拉大步距让相邻卡完全脱离，留出宽白断缝（单变量：**零咬合断链**）。
