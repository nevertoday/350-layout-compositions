# 228 子网格布局 · SUBGRID LAYOUT 设计方案

## 1. 一句话道理
普通 CSS 网格的轨道止步于直接子元素，一旦卡片或模块多套一层语义标签，内部列与行便与全局脱节；`subgrid` 让嵌套容器直接继承父网格的轨道与沟槽，并把子项尺寸回传给父轨，使跨层级元素始终钉在同一套标尺上。

## 2. 开场玩具：「嵌套穿轨实验室 · Nested Subgrid Blueprint」
- **结构与玩法**：在忠实承袭 228 原海报的奶油制图纸卡内，放一套真实运行原生 CSS Grid / Subgrid 的双层界面：顶行是父网格直接子项 `A 标题区` 与 `B 侧边信息`（跨越 `1fr : x·fr : 1fr : x·fr` 四列轨道），下方是两个嵌套容器 `D 扩展模块` 与 `E 辅助模块`，各自包含两列三行真实孙级组件。顶沿 `1fr | 2fr` 分轨标尺带有可横向连续拖动的松绿滑柄（`data-perf-drag`），实时改变父网格列宽比例（`1.0fr–3.2fr`）；一旁的控制台切换列轨道继承（`独立 1fr 1fr` / `subgrid`）、行轨道继承（`独立 auto` / `subgrid`）、父行跨度（`span 1` / `span 2` / `span 3`）、子网格沟槽（`继承 12px` / `覆写 0px`）以及向 `D` 或 `E` 动态注入长文案。上方叠加 2D Canvas 实测层，直接读取真实 DOM `getBoundingClientRect()` 绘制贯通父子两层的竖向/横向虚线标尺、实心松绿交点与珊瑚红错位标注。
- **开场初始态（非答案）**：列轨独立 `1fr 1fr`、行轨独立 `auto`、行跨度 `span 1`、父轨比 `1 : 2.2fr`、且 `D` 模块载入两行长标题。结果列分界相对父轨 `A/B` 真实偏离约 `Δ 30–55px`，且 `D/E` 正文起线上下错位约 `Δ 18–26px`，4 枚原海报圆徽标点亮 `0/4`。
- **怎样算玩错、错了读数怎么说**（无一键通关钮，必须真正调对四项）：
  1. **跨度陷阱（Subgrid 特有真坑）**：开启 `rows: subgrid` 但行跨度仍停在 `span 1` 或 `span 2` 时，浏览器不会为子网格创建隐式轨道，3 层孙级块真实折叠挤压在同一条父行轨上；读数立刻标红报警「跨度不够：`subgrid` 不会自动补隐式轨，3 层内容挤进 1/2 条行轨」。
  2. **只开单轴**：只开列继承不开行继承，拖动父轨滑柄时纵线归零（`Δ列 0px`），但 `D/E` 水平正文线依然参差，读数明确指出仅打通列轨、行轨仍各自为政。
  3. **只开行继承不开列继承**：`D/E` 水平齐平，但一拖父轨滑柄，子列中缝立刻与父栏脱钩，读数报出实时 `Δ列 px`。
  4. **覆写 `gap: 0px` 粘连**：虽然轨道继承成立，但手动把子网格沟槽清零会破坏父网格呼吸节奏，读数提醒继承父沟槽与手动覆写的区别。
- **读数说明「为什么」**：所有数值（列偏差 `Δpx`、行偏差 `Δpx`、折叠项数、父轨实宽）均从真实 DOM 布局实测，并以白话解释「为何多套一层 DOM 会截断轨道」「为何子项长文案能反向撑大父行轨带动兄弟同步」。
- **与近 12 页的差异**：227 操控单层 6×4 区域移位跨格，226 操控一维顶栏伸缩，270 操控同构卡片外距与焦点，188 校对文字基线，其余页为摄影/3D/平面构图；本页独创「父子双层真实 CSS Subgrid 穿轨 + 实时 DOM 偏离测量 + `span` 隐式轨坍塌陷阱 + 动态注入文案双向撑轨」玩法，无法套用到任何其他编号。

## 3. 版式骨架
- **1440×900 桌面**：直接化用 228 原海报的「鼠尾草薄荷绿底纸 + 顶眉大标与四圆徽标 + 中央单张奶油蓝图制图纸卡」骨架（无独立侧栏仪表盘）：顶沿左 62% 排「子网格布局」示范标题（细虚线父轨垂直穿下对齐蓝图列）与原海报总述，右 38% 排原海报同款松绿/珊瑚交替四枚圆徽实时达标灯；中央整张 `#FAF3E5` 奶油圆角蓝图框内左 66% 铺满双层活体蓝图台与顶沿父轨拖拽尺，右 34% 承接紧凑控制台与原海报同款深松绿 `#116C54` 实底核心诊断卡。
- **2560×1440 宽屏**：外容器舒展至 `1760px`，蓝图舞台按比例放宽，父轨与嵌套模块清晰宽阔，无大块空边。
- **1024×1366 / 768×1024 平板**：不锁 `min-height: 100svh`，内容自然排布，避免中间空洞。
- **390×844 手机竖屏**：压缩单行刊头与 4 枚精简达标灯（~96px），奶油蓝图框直落首屏，双层活体蓝图与横向父轨拖柄稳占首屏 ≥ 45% 屏高，同屏露出深松绿实底诊断卡摘要，下方展开 ≥ 42px 触控切换钮。
- **844×390 横屏手机**：顶标压成 42px 单行条，下方切换左 56% 蓝图舞台与拖拽尺 × 右 44% 控制台与深松绿诊断卡并行。

## 5. 节目录（8 节）
- `01` **一道嵌套墙，截断父轨道**（THE NESTING BARRIER）：引原海报「核心思想」与对照要点，用可拖垂直剖幕对照「独立嵌套 vs Subgrid」并配 3 档文案压力测试，同时温和补全原海报速查代码里省略的 `span` 声明。
- `02` **单轴继承，还是双轴锁死**（SINGLE VS. DUAL AXIS）：用 2×2 轴向矩阵切换器在真实杂志模块上实时拆解仅行、仅列、双轴三种 `subgrid` 用法。
- `03` **反向撑大，与沟槽继承**（BIDIRECTIONAL SIZING & GAPS）：深松绿暗底蓝图节；逐行增减单卡标题行数并调节子网格 `gap` 与 `padding`，直观看清孙级内容如何反向撑大父轨带动兄弟同步。
- `04` **从二级草案到全员基线**（ORIGIN & TIMELINE）：交互式五节点时间轴（2017 Level 1 暂缓 → 2018-02-06 Level 2 首稿 → 2019-12-03 Firefox 71 → 2022-09-12 Safari 16 → 2023-09-12 Chrome/Edge 117 Baseline 2023），附核实人名与机构。
- `05` **什么时候用，什么时候别用**（WHEN TO USE & AVOID）：适用场景 + 四类反例，带真实 DOM 压力演示器（对比正常 3 项 / 塞入 5 项触发无隐式轨叠压 / 换成 `display: contents` 外框消失），并用一句话链接同小类 226、227、229、230、236、242。
- `06` **命名线穿透与 CSS 速查**（NAMED LINES & CHEAT SHEET）：交互式代码行点击高亮器，点选每一条真实 CSS 规则即在旁边蓝图高亮对应父轨、跨度包络、穿透线名与本地线名。
- `07` **练一练：四套嵌套，哪套真对齐？**（PRACTICE · SPOT THE TRUE SUBGRID）：四张实时渲染的同题三卡缩略图（中性标签 A/B/C/D），选后亮出隐藏辅助线与误差标注。
- `08` **原海报与关键词**（THE ORIGINAL POSTER）：可点击放大/拖动/Esc 关闭的 228 原海报与原海报四枚关键词徽标。

## 7. 小练习
- **题目**：三张并排产品卡各有「标题 / 简介 / 按钮」三层，中间卡标题折成两行；四套写法的唯一变量分别是嵌套机制，哪一套既保住每张卡的外框与留白，又让三层基线严丝合缝对齐？
- **四个选项（仅差一个变量，纯中性 A/B/C/D）**：
  - `A`：仅写 `grid-template-rows: subgrid` 而未写 `grid-row: span 3`（无隐式轨导致内容折叠压叠）
  - `B`：独立嵌套 `grid-template-rows: auto 1fr auto`（具强迷惑性：底栏齐了，但正文起线因中间双行标题发生错位）
  - `C`：**正确答案**：`grid-row: span 3; display: grid; grid-template-rows: subgrid;`（外框留白完好，三条横线跨卡零偏差）
  - `D`：卡片壳用 `display: contents`（对齐但外框、底色与独立盒模型全部丢失）
