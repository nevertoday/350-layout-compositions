# 102 形状对比（SHAPE CONTRAST）交互页方案

## 1. 一句话道理
即使剥离色彩与体量差异，不同轮廓族（圆/方、尖/钝、实/空、规则/自由）仍能走不同的视觉通道建立焦点与角色分工。

## 2. 开场玩具：原海报四组同台雕琢板（2D Canvas + 4 枚原生图形手柄）
- **构图与玩法**：不再拆成四根一维参数条，直接把 102 号原海报右栏的四组对话同屏摆进画台（桌面/平板/横屏为 2×2 四格画板，手机竖屏为贴合原海报的 1×4 竖叠），每组各有不同手势与独立节点手柄：
  1. **圆与方**（`⤢` 拖方块左上角斜向拉出直角）：开场停在过度倒圆的「双圆撞形」态，往外拉出 90° 直角成立。
  2. **尖与钝**（`↕` 拖三角顶角向上拔起锐峰）：开场停在压塌的钝角低坡，向上抬尖至 ≤ 50° 成立。
  3. **实与空**（`↔` 拖空心框内沿改壁厚墨量）：开场停在过细发虚的细线框，**正确答案在中间甜区**（左框实测墨量 40%–70%）；太细发虚不成立，填太粗逼近实心闷堵同样不成立。
  4. **规则与自由**（`↻` 拖右侧群落释放有机形态）：开场停在两侧同样刻板方正的「双侧死板」态，**正确答案也在中间甜区**（右侧舒展为有机自由群，同时左侧 5×5 点阵保持严格对齐）；拉过头会把左侧点阵一起冲散，同样不成立。
- **读数与过关**：顶栏实时显示「这幅版面成立 n/4 组对话」；所有读数只报真实几何量（圆角半径 px 与满圆占比、精确三角顶角度数、精确面积/油墨占比、精确点阵偏移 px）或明确档位，绝无凑数系数与静态错标签；每格左右图形标签随形变实时改名。`0` 键海报参考态与「抽成纯黑白验证」在 4/4 全部成立后才解锁，作为验证步骤而非捷径剧透。
- **与最近 12 页的区别**：129 是 2×2 报刊活字对调，101 是对称色环 + 灰度开关；本页是无色彩滤镜前提下的四重原生几何实体直接雕琢（圆角/顶角/壁厚/有机形变），四组各自有不同手势与中段甜区。

## 3. 版式骨架
- **2560×1440**：放开容器至 2160px（正文 1920px 辅以舒适行宽），右栏画台扩至约 1700px 宽，四组几何大形清晰舒展。
- **1440×900**：忠实复刻原海报左目右图双栏骨架，左栏竖叠「状含蓝点、比收橙方」题标与四枚暖沙圆徽状态目录，右栏承接 2×2 画板与下方真实几何读数槽，整套开场稳落首屏。
- **390×844**：压紧题标，画台切为忠实原海报的 1×4 竖叠四组，四枚 40px+ 触控节点清晰分隔不互压，开场整套稳落首屏。
- **844×390 横屏**：左栏下方空区承接当前组的结论、「为什么」解释与操作提示，右栏画板通高铺满，画布高度提升至约 305px。

## 4. 配色和字体
- **配色**：严格采自 102 原海报——暖米纸 `#f9eee0`、暖沙徽 `#f1e1c9`、群青蓝 `#1f49c1`、碳墨黑 `#131517`、朱橙点睛 `#e76b28`（04 节康定斯基红方改用正红 `#d63224`）。
- **字体**：`Rubik Mono One` + `EB Garamond`（最近 12 页均未使用，仅用于英文副题与引语）+ `Noto Sans SC`（正文与行内西文统一字形）。

## 5. 节目录（八节，相邻交互不重样）
- **01 海报里的五组对话**：引海报原句并配快捷定位至上方雕琢台对应节点。
- **02 并非所有异形都能一秒跳出**：视觉搜索 36 格实测——点「开始计时」后随机布点，三轮测完输出同尺毫秒对比条。
- **03 尖的警觉，圆的松弛**：布巴—奇奇直觉盲测 + 同一通知卡切换三套轮廓语气。
- **04 从哪来：包豪斯与风雪路标**：1923 康定斯基三形空白填色问卷（三形全填后解锁对照）+ 1968 维也纳路标去色/积雪剪影验证。
- **05 什么时候用：让轮廓分工**：实战展讯 UI 卡三方案切换（默认停在「方案 A · 统一圆角」，按钮中性描述，好坏留给读数）+ 同小类兄弟页串联。
- **06 什么时候别用：轮廓多成噪音**：1–5 类轮廓族滑块演示焦点稀释 + 四大禁用场景。
- **07 小练习：纯黑白展讯挑最佳**：四选一单变量控制对比——C 最佳，A 仅错在焦点数（双圆）、B 仅错在底部实空（双实按钮）、D 仅错在主视觉曲率（圆角方块）。
- **08 原海报与关键词**：原海报高清放大拖动灯箱与四枚关键词徽章。

## 7. 练习单变量设计
- **C（最佳）**：直角骨架 + 单实心正圆焦点 + 实心胶囊配细线空心方框。
- **A（仅变焦点数）**：中段改为两颗等大实心圆互抢焦点，其余同 C。
- **B（仅变底部实空）**：底部改为两枚等大实心胶囊难分主次，其余同 C。
- **D（仅变主视觉曲率）**：中段改为同面积圆角实心方块（与外框同属方形家族），底部保留 C 的实心胶囊 + 空心框。
