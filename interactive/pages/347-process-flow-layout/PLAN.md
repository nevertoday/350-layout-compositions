# 347 流程页幻灯片版式（PROCESS FLOW LAYOUT）设计方案

## 1. 一句话道理
流程页幻灯片把抽象的推进过程拆成 3–5 个有清晰起点（输入）、单向路径（箭头）、阶段转换（卡片）与明确终点（结果）的视觉组块，让听众在几秒内一眼看清「我们从哪里来、要到哪里去、如何到达」。

## 2. 开场玩具（活体流程管道沙盘与信号流演播台）
- **载体与动作**：1:1 承袭 347 原海报深森林绿底（`#002C1D`）、象牙米白圆角流程卡（`#F9F5E6`）、薄荷绿阶段胶囊与粗推进箭头（`#8ADDBA`）、左右输入/结果端锚与底部虚线「迭代优化」回环的通宽 2D Canvas 流水线沙盘（画布标 `data-perf-drag`）。内置 3 套真实职场剧本（原海报·四步闭环 / 课程教学·实验探究 / 方案策划·需求交付）。
- **怎么玩**：
  - **左右拖卡片**直接交换步骤顺序（按住空白区或节奏轨横拖，则连续推拉卡片留白呼吸距并推动信号流游标）；
  - **直点卡片间的箭头**在 `正向 →` / `逆向 ←` / `双向 ↔` / `断连 ✕` 之间切换；
  - **直点冗余卡片的 `×` 标**原地裁掉插队琐事，**直点左右端虚线缺口**原地补回「输入 / 结果」端锚；
  - **按 `Space` 或点「注入信号实测」**，发射一颗真实的「输入 → 转换 → 结果」信号核，沿着当前有向连线穿过各阶段并在每张卡里发生形态转换（若遇断链/逆流则当场撞墙弹红）。
- **开场初始态（绝不预先给答案）**：0/4 失守复合坏态——塞入 6 张步骤卡（含「临时对齐会」「二次抄送」两张非转化琐事），「执行」错排在「分析」之前，第 2→3 步箭头画反（←），左右「输入 / 结果」端锚缺失，阶段胶囊被隐藏且卡片密字拥堵（留白 < 20%）。
- **怎样算玩错、错了读数怎么说**：`model.js` 从实绘卡片包围盒与有向图邻接表单真源实时遍历检出 10 类正反错态（逆向断链、连线断开、全双向箭头失去方向、逻辑倒序、缺输入/结果端锚、步骤膨胀 ≥ 6、仅留 2 步硬套、密字墙、无阶段层级/拥挤、蛛网交叉回环或极端拉散），白话诊单直接指出具体哪一步卡死、听众会怎么迷路、下一步该动哪里；同时认可「原海报四步闭环」「三步高管极简」「五步直推交付」「S 形阶梯推进」多组合法解。
- **与最近 12 页及相邻页的差异**：342/343/344/346 均为左画布右诊单卡，345 为四角引注环绕居中卡；本页 347 完全忠于原海报，采用**深森林墨绿通宽全幅水平流水线展台**（无左右侧栏挤压）+ 顶部原海报同款五要素检视匣 + 底部原海报圆角细绿框双区舱；核心交互是「修通一条有向转换流水线并注入信号核沿图穿行演播」，只属于流程页，无法套用到时间线或图文页。

## 3. 版式骨架
- **1440×900（主宽 1360px；2560 舒展至 1600px）**：顶栏左 58% 自示范大标（标下自带随状态亮灭的细薄荷推进轨）+ 剧本切签，右 42% 原海报同款细绿框「五要素实时检视匣」→ 中段 100% 通宽 2D Canvas 活体流水线沙盘 → 底部 1:1 复刻原海报大圆角细绿框双区舱（左 54% 单真源白话诊单 + 4 枚原海报圆徽探针，右 46% 手术控制刀闸 + 多解/反向试错快钮）。绝不锁 `100svh`。
- **1024×1366 / 768×1024 平板**：自然流满宽通轴，顶栏五要素收成紧凑横带，画布保持清晰横比，底部双区自然对齐。
- **390×844 竖屏**：压紧单行刊头与精简总述，后置五要素匣与剧本扩展，让等比流水线画布稳占首屏 ≥ 46%，折线内直露诊单首句、呼吸留白主滑轨与「一键校准 / 注入信号」双主键；所有卡片与圆形图标保持等比绘制不压扁。
- **844×390 横屏**：左 60% 流水线画布 × 右 40% 紧凑刊头、白话诊单与校准/信号双键并行，首屏一屏尽收。

## 5. 节目录（7 大节，h2 均 ≤ 10 字，相邻节交互控件各异）
- `01 流程五件套`（浅象牙纸）：拆解原海报右上「步骤/方向/关系/转换/结果」；交互：**五枚可开关剥离按钮**，拆掉任一项实时看演示页如何失效。
- `02 拓扑选型图`（淡薄荷纸）：对比线性直推、底部闭环迭代、条件分叉、跨部门泳道四种结构，并链接区分 [346 时间线页](https://layout.xiaoxiaodong.ai/346/play/) 与 [348 矩阵页](https://layout.xiaoxiaodong.ai/348/play/)；交互：**4 格拓扑展台切签 + 动态有向 SVG 信号轨**。
- `03 记忆四组块`（深森林暗室）：借 Cowan (2001) 4 组块容量与 Mayer 信号/分段原则讲为何 3–5 步是甜点；交互：**步骤打包滑块（2–9 步）+ 2D Canvas 5 秒听众扫读留存模拟（示意）**。
- `04 流程从哪来`（浅象牙纸）：1921 Gilbreth → 1939 Shewhart → 1947 Goldstine & von Neumann → 1985 ISO 5807 脉络，并温和补注原海报四步模型的适用前提；交互：**四段年代碑卡展开对照**。
- `05 什么时候别用`（淡薄荷纸）：4 类勿用流程页的场景，并引导至 344/345/346/348/349/350；交互：**场景分诊卡点击判别（硬套流程图 vs 推荐版式对比）**。
- `06 小练习验真`（深森林暗室）：单变量四选一测验；交互：**4 幅同风格 SVG 幻灯片单选与逐项白话解析**。
- `07 原海报与索引`（深森林展墙 + 极深页脚）：原海报点击放大拖动看图 + 关键词与 4 枚使用场景徽章 + 标准页脚。

## 7. 小练习设计
- **题干**：季度复盘会上，你要用一页幻灯片说明「老客复购优化流程」（输入：沉默会员名单 → 目标：复购率提升），下面四版方案文字相近，哪一版最便于观众 5 秒看懂推进逻辑？
- **四个选项（中性标签 `方案 A`–`方案 D`，仅单一变量不同）**：
  - `方案 A`：4 步齐整有输入输出，但步骤间全部画成**双向箭头 `↔`**（错在方向失去单向推进性）；
  - `方案 B`：4 步单向箭头明确，有输入/结果端锚与底部轻虚线迭代回环，阶段胶囊与 3 条短动词主次清楚（**正确答案**）；
  - `方案 C`：单向箭头与端锚完整，但硬拆成 **7 张细碎卡片**挤在一排（错在步骤超载突破 4 组块视觉上限）；
  - `方案 D`：4 步单向箭头清楚，但缺失「输入/结果」端锚且把「执行」错排在「分析」之前（错在逻辑倒序与缺起止锚）。
