# 135 对称跨页 SYMMETRICAL SPREAD · 互动页方案

## 1. 一句话道理
对称跨页把翻开的左右两页视为围绕物理装订脊展开的一整幅镜像画卷：以中缝为轴完成**反射镜像（而非平移复制）**、为订口弯折留出安全净空、并让左右跨缝基线与视觉量级相互呼应，从而在书刊与画册中建立沉稳、庄重且一览无余的整体秩序。

## 2. 开场玩具
- **命名**：墨黑对开书卷镜像与装订校准台（Open-Book Symmetrical Spread & Fold-Proof Bench，纯 2D Canvas，标 `data-perf-drag`）。
- **视觉承袭**：1:1 承袭 135 原海报的曜石墨黑展面（`#050606`）、深孔雀松绿半圆与竖块（`#0A6554`）、珊瑚玫红双圆与错位象牙细环（`#F2486A`）、暖骨象牙中轴虚线与空心圆点 `○`（`#EFE6D2`）、底部开卷书脊弧线（`╭─╯╰─╮`）及四角三点玫红记号，支持切换「原海报·几何典籍」「建筑画册·双页展」「古典书卷·双页章」三套标本。
- **怎么玩**：
  - **横拖画布（`data-perf-drag`）**：直接横向推拉右页（Recto）版芯距装订中轴的偏置，实时联动订口弯折阴影侵蚀量、外切口拇指留白与书脊底部的光学天平指针；靠近镜像齐平位时轻吸附。
  - **纵拖右页（或 `↑/↓` 键）**：实时校准跨缝水平基线差 `ΔY`，体验跨中缝错牙与齐平的瞬间切换。
  - **点击中轴 `○`（或按 `Space`）**：触发动态「对折验镜（Fold-Over Ink Proof）」，左页轮廓以三维透视余弦折叠盖到右页上，肉眼一眼看穿「平移复制」与「轴线镜像」的重叠差异。
  - **点击右页珊瑚玫红圆**：调节右页视觉量级（或通过滑块连续调节），观察底部光学天平倾角。
  - **切换构造模式与装订方式**：在「平移复制（错） / 中轴镜像 / 异形等重」与「胶装紧订 / 骑马订 / 锁线平摊」间切换——装订越紧、书脊弯折阴影越宽，安全订口门槛同步动态抬高。
- **开场状态（绝非答案）**：刻意停在 `0/4` 复合错态——构造模式误设为「平移复制」、装订为「胶装紧订」、右页被向左拽进书脊弯折阴影区（订口塌缩吞噬）、跨缝基线错牙 `+22px`、右页玫红主圆缩至 `0.66×` 导致左侧偏重倾塌。
- **怎样算玩错 & 读数怎么说**：`model.js` 从实绘左/右页几何坐标、订口阴影宽度、基线差与视觉力矩单真源核算 **8 类双向真错态**（平移未镜像、订口过窄吞字、订口裂谷过宽、偏轴失衡、跨缝基线错牙、右页过轻左倾、右页过重右倾、切口压边窒息）。读数全部用白话说清「为什么读者眼睛会出问题」并给出可操作指引；同时认可「原海报经典镜像解」「异形等重对称解」「古典书卷宽边解」等多组合法解。
- **与近 12 页的区别**：近 12 页有翠绿多栏拼版（134）、深蓝双栏栏距（133）、暖纸矩形裁切（046）、深青单人取景（301）、茄紫幻灯片（335）、李紫同心环（170）、亚麻浅景深（083）、铬黄直排（215）、亚麻方格印（045）、深紫容器查询（300）、夜紫右起直排（214）、朱橘敧正斜碑（334）。本页独有「物理对开书籍中缝弯折 + 对折叠印验镜 + 平移 vs 反射镜像对比 + 光学天平」机制，绝不能套用到任何其他编号。

## 3. 版式骨架
- **「曜石墨黑中轴对开书卷展台」**：一条贯通的暖骨象牙垂直中轴（带空心圆节点 `○`）从页面正中贯穿整个首屏：
  - 顶部刊头严格左右镜像分列于中轴两侧，`对称 ┆ 跨页` 大字居中骑跨装订中轴实现自示范，`SYMMETRICAL SPREAD` 与原海报四色短杠（玫红/象牙/象牙/松绿）呼应，四角复刻三点与玫红圆点。
  - 中段为居中满宽开放式对开书卷画布（1440 下主宽 1360px，2560 下舒展至 1680px），绝不锁 `100svh` 避免 1024×1366 平板留大块空白。
  - 底部沿中轴严格 50% / 50% 等高平分双舱：左页（Verso）安放原海报「轴线 / 平衡」实时探针与单真源白话诊单；右页（Recto）安放「镜像 / 秩序」实时探针与跨页校准控件，两栏天然齐底不留空洞。
- **390×844 竖屏**：刊头压缩为极简单行骑脊大标与标本切签，等比对开书卷画布稳占首屏 ≥46%（所有圆形严格保持正圆、绝不压成椭圆），首屏折线内即可直见左页诊单首句与「对折验镜 / 一键校准」按钮。
- **844×390 横屏**：切换为左 56% 对开书卷画布 × 右 44% 紧凑刊头、诊单与核心按钮并行布局。
- **正文七节明暗交替**：01 典籍米纸 → 02 松绿雾纸 → 03 曜石装订暗室 → 04 羊皮暖纸 → 05 浅玫扉页纸 → 06 曜石考场暗室 → 07 曜石原海报展墙 + 深墨页脚。

## 7. 练习设计
- **第 1 题（装订与镜像基准）**：为 320 页无线胶装建筑精装画册选一对对称跨页，四个中性方案 A/B/C/D 画面元素完全一致，各自只变一个变量：A 为平移复制（非镜像）、B 为中轴镜像且订口避开胶装弯折且基线齐平（正确）、C 订口过窄被书脊吃掉内弧、D 右页基线明显下沉错牙。
- **第 2 题（异形等重对称）**：当左页是整幅摄影图版、右页是章节正文时，如何在不机械复制的前提下保持对称跨页的平衡？A 仅靠缩小左图留大白边、B 保持镜像边距框架+跨缝水平基准线+以右页大号字块与玫红章印匹配左图视觉量级（正确）、C 把右页正文紧贴中缝缩成窄条、D 取消右页外边距做满幅出血打破双页对称框。
