# 171 随机 系统 RANDOM SYSTEM — 互动页方案

## 1. 一句话道理
随机系统不是放弃规则的胡乱堆放，而是放弃对单次落点的逐一锁死，改用**概率分布、层级反差与避碰边界**来约束整体形态——单次落点不可精确预测，但整张版面的视觉重心、疏密节奏与阅读入口稳定成立（「关注分布，而非单点结果」；「随机 ≠ 混乱」）。

## 2. 开场玩具：随机排字与落点概率台（Stochastic Type-Drop & Distribution Bench）
- **核心动作（贴合 171 专属机制，他页不可套用）**：
  - 画布承袭 171 原海报「输入 INPUT → 虚线随机过程盒 → 输出 OUTPUT」与贴纸/胶带便签质感，内含 10 枚真实排印字片与 171 散点/十字标（支持切换「原海报实验 / 音乐节海报 / 独立刊物」三套真实排印题材），盒顶与盒右附带实时计算的 X/Y 边际概率密度曲线。
  - **画布横向拖动（`data-perf-drag`）**：连续调节「随机扰动度（0%–100%）」，肉眼看见同一组排印从 0%「完全有序（僵硬齐行）」→ 适度随机（错落有致、重心稳、无撞字）→ 95%+「完全随机（狂转叠压、裁边难读）」。
  - **直接点选 / 拖移任意单枚字片（阿尔普「辅助偶发」）**：拖移字片可直接人工微调落点并用蓝/红半透明胶带钉死（pinned），点击或双击切换胶带锁定状态，体验「先由随机生成、再由人手收束」。
  - **按空格或「再撒一版」**：在当前规则（概率分布律 + 扰动度 + 层级反差 + 避碰护栏）下更换随机种子，未锁定的字片轻盈重落，亲证「每次落点都不同，但好规则下每一版都可读」。
- **开场初始状态（刻意停在 0/4 混乱错态，绝非答案）**：
  - 默认 `扰动度 94%` + `均匀放任` + `层级同号拉平（1.1×）` + `避碰护栏关闭`，开场直接呈现多处红斜线「撞字叠压」、超 45° 失控倾角、字片撞出外框裁边、视觉入口缺失的 0/4 混乱态。
- **怎么算玩错、双向错态与单真源读数**：
  - `model.js` 从实际绘制的 10 枚旋转矩形（OBB）与边界实算 7 类双向错态：
    1. **过度混乱·撞字叠压**（两两 OBB 真实重叠加总面积占比 > 8% 或 ≥ 2 对撞字）→ 解释遮挡如何毁掉识读；
    2. **倾角过激·难以辨读**（主字倾角 > 26° 或辅条 > 34°）→ 解释倾斜动势的辨读底线；
    3. **完全有序·僵化成表**（扰动度 < 14% 或位置/角度离散度过低）→ 反向错态！说明一味归零会彻底丧失随机系统的灵活性与动势；
    4. **同号拉平·没有入口**（主副尺度比 < 1.55×）→ 无网格时全靠尺度反差提供第一落眼点；
    5. **重心坠边·版面翻车**（实算视觉质心偏离安全均衡区 > 14%，如指数偏尾把文字全压在一侧）；
    6. **触边裁切·呼吸窒息**（任意字片侵入 4.5% 安全边距）；
    7. **过密挤团或中空散架**（包围盒占幅过小或四散丢心）。
  - 接受多组合法解：正态聚焦随机解、莫尔纳微扰韵律解、以及用户手拖贴胶带收束的「辅助偶发解」。
- **与最近 12 页的明显差异**：
  - 不同于 170（同心圆环扩张）、335（幻灯片拖拽与视距）、083（薄透镜推焦）、215/214（直排纵列理序）、045/044（正方形/立菱几何框）、133（蓝图双栏栏距）、300（容器查询分槽）、334（刚体正斜力学）、255（单列行宽）、082（五层山岚散射）；本页以「随机种子撒落 + 边际概率分布曲线 + 胶带固定辅助偶发 + 离散/连续/马尔可夫/蒙特卡洛活体实验室」为核心，是唯一围绕概率分布与受控随机排印构建的互动台。

## 3. 版式骨架（忠实转译 171 原海报实验手账拼贴语言）
- **1440×900（主宽 1380px；2560×1440 舒展至 1680px）**：
  - 无深色通用顶栏、不锁 `100svh`。
  - 顶部非对称刊头：左 36% 复刻 171 自示范巨标（`随机` 配右上酸柠方块 → 半宽钴蓝粗横杠 → `系统` 配右上黑针点 + `RANDOM SYSTEM`，字块随扰动度做克制微移微倾）；右 64% 上半为酸柠竖杠总述与动态散点星云，下半虚线分隔 4 枚彩点活体特征栏（`偶发 / 变化 / 不规则 / 动势`）。
  - 主实验台：左 63% 为 171 虚线盒「输入 → 随机过程画布 → 输出」+ 贴底单行精控轨；右 37% 为与画布严格齐底的「钴蓝胶带白卡片单真源诊单」+「折叠黑角酸柠绿便签核验清单」。
  - 底沿紧接 171 招牌「随机 ≠ 混乱」双向箭头活体光谱尺。
- **平板竖屏（1024×1366 / 768×1024）**：画布满宽居中，蓝胶带诊单与酸柠折角便签在下方等高双栏并排齐底，零空洞。
- **手机竖屏（390×844）**：压紧单行刊头与题材切换，利用 `order` 将总述与 4 特征栏移至画布后，使近方形画布稳占首屏 ≥ 46% 屏高，下方折线内直露扰动推杆、再撒按钮、诊单首句与一键纠偏。
- **手机横屏（844×390）**：切为左 54% 画布与主控 × 右 46% 刊头、诊单首句与快控并行，零挤压溢出。

## 5. 节目录（7 节，h2 均 ≤ 12 字，相邻节控件形态不重复）
- **01 为什么随机不是瞎摆**（`WHY RANDOM ≠ CHAOS`）：解读「不预测每一次，而是理解整体趋势」「四项特征」「我们能知道什么」与「随机 ≠ 混乱」。控件：迷你高尔顿落珠与三态（完全有序 / 适度随机 / 完全随机）投珠触发台（单投 / 连投 120 颗 / 清空）。
- **02 三种分布决定版面性格**（`THREE DISTRIBUTIONS`）：把海报「正态 / 指数 / 均匀」三种概率分布与「典型现象」转译为版面疏密法则，并温和勘正海报对指数分布「越久未发生越可能发生」的口误（实际为无记忆性）。控件：三大曲线标本卡直选 + 样本量滑杆实时重绘 PDF 与散点对照。
- **03 四种建模暗室**（`FOUR STOCHASTIC MODELS`）：深炭暗室演绎海报「离散随机变量 / 连续随机变量 / 马尔可夫过程 / 蒙特卡洛模拟」四类建模如何驱动视觉生成。控件：4 枚原海报彩底图标瓦片切模 + 单步/连跑 + 可点按 3×3 马尔可夫转移矩阵格。
- **04 从达达剪报到算法扰动**（`WHERE IT CAME FROM`）：1889 高尔顿 → 1913 马尔可夫 → 1916 阿尔普 & 1920 查拉 → 1949 蒙特卡洛 → 1974 莫尔纳 → 1992 卡森 & 2007 伊拉姆（含 168–175 同类链接）。控件：年代档案抽屉卡切换 + SVG 历史原理图谱。
- **05 什么时候用，什么时候别用**（`WHEN TO USE & AVOID`）：171 招牌钴蓝圆角四栏「理解随机系统的原则」+ 明确适用与禁用边界。控件：4 份真实设计载体卡片 + 物理拨动开关「套用随机系统」压力测试。
- **06 挑出真正可控的随机**（`SPOT CONTROLLED RANDOMNESS`）：深炭考场，中性 A/B/C/D 四选项只改「分布与扰动规则」一个变量，避开一眼排除。控件：四格实时绘出的微型海报单选卡 + 全选项解析。
- **07 原海报与关键词**（`ORIGINAL POSTER`）：高清原海报点击放大/拖拽/滚轮缩放/Esc 关 + 核心概念标签 + 同类七系统导航 + 标准页脚。

## 7. 练习设计
- 题干：为一场实验音乐展制作竖版海报，四版文案、字号层级与配色完全一致，仅空间分布与扰动规则不同。哪一版真正体现了可控的随机系统？
- 选项（纯中性标签「方案 A / B / C / D」，只差分布与扰动规则一个变量）：
  - `方案 A`：0% 扰动、齐行死锁（无叠压但僵硬无动势，退化成网格列表）
  - `方案 B`：44% 适度扰动 + 正态聚焦 + 避碰护栏（错落有致、重心稳、无撞字、有清晰主入口 — **正解**）
  - `方案 C`：44% 扰动无叠压，但重心坠向右下角、左上大片空洞（隐蔽分布失衡，考验整体分布意识）
  - `方案 D`：82% 剧烈扰动 + 倾角失控 + 关键标题与日期叠压（把混乱当随机）
