# 111 交替节奏组织 · 设计与开发方案

## 1. 一句话道理
交替节奏组织（Alternating Rhythm）靠「两种明确可辨的视觉状态（A 与 B）按可预期周期轮换」成立：它打破纯重复（[107](https://layout.xiaoxiaodong.ai/107/play/)）带来的适应性倦怠，又用周期律与克制的变量数挡住杂乱无序，让视线在一呼一应的对比切换里自动走出稳定节拍。

## 2. 开场玩具：活体四轨交替编排台（4-Track Alternating Loom）
- **怎么玩**：
  - 直接化用 111 原海报标志性的四道全宽交替带——**01 条纹轨（Stripes）、02 圆点轨（Circles）、03 三角轨（Triangles）、04 双波轨（Double Wave）**——铺在原海报炽朱红 `#FC4E0B` 满幅画布上。
  - **画布直点翻拍**：点击四轨任意节拍位置（或底部原海报胶囊框内的 8 拍 `A ↔ B` 按钮带），直接把该拍在 **墨黑 A** 与 **米白 B** 之间翻转；选中后支持键盘方向键移动与 Space/Enter 翻拍。
  - **横向拖移层间相位轨（`data-perf-drag`）**：拖动画布底沿全宽「层间相位轨」（或在圆点/三角/双波轨上直接横向拖滑），把第 3、4 轨相对第 1、2 轨从 `0° 同相齐列` 拖到 `180° 原海报反相咬合`，实时看到上下轨从竖直齐列、歪牙卡齿到棋盘互锁的变化。
  - **反差与拍宽微调**：调节「A/B 亮度反差」（从发闷灰黑 `1.3:1` 拉开到原海报墨黑/米白 `16.9:1`）、「A:B 拍宽占比」（从 `78:22` 一边倒调回 `50:50` 均衡或 `60:40` 轻重拍），以及切换「8 拍原海报 / 24 拍过密眩光 / 4 维乱切」压测边界。
- **开场初始状态（0 / 4 待调拍，绝非答案）**：
  - 8 拍序列初始为断裂错拍 `A-A-B-A-A-A-B-B`（真无周期，含连续 3 个 A 撞车，交替 ✗）；
  - A/B 亮度反差压低至 `1.6:1`（B 沦为浑浊深褐 `#352E28`，对比 ✗）；
  - 层间相位卡在 `64°` 错牙歪位（切换 ✗）；
  - A:B 拍宽失衡至 `78:22`（A 吞没 B 成细缝，秩序 ✗）。
- **怎样算玩错、错了读数怎么说（全部由 `model.js` 单真源按实绘坐标/色值算出）**：
  1. **单调重复（0 次交替）**：全 A 或全 B → 说明已退化成 107 重复原则，视觉适应发钝。
  2. **周期断裂（不规则连拍）**：连拍长短忽 1 忽 3 → 说明大脑无法预测下一拍，节拍中断。
  3. **A/B 数量失衡**：如 6A:2B → 说明 B 退化为偶发点缀，双极跷跷板翘空。
  4. **对比发闷（亮度比 < 3.5:1）**：A/B 糊成暗团 → 说明排法再齐也看不出两极切换。
  5. **层间错牙（25°–155°）**：上下轨半途错位 → 说明圆点与三角互别，破坏垂直咬合。
  6. **拍宽强吞弱（< 34% 或 > 66%）**：一边极宽一边成细缝 → 说明空间占比失衡。
  7. **过密高频眩光（24 拍高对比）**：空间频率逼近人眼不适带 → 画面发抖刺眼。
  8. **多维乱切（4 通道各自跳变）**：形/色/尺/角无主次同变 → 秩序坍塌为视觉噪点。
  - **多组正当解**：`ABABABAB`、`BABABABA`、`AABBAABB`、`BBAABBAA` 均可通过周期检核；相位接受 `180° 反相咬合`（推荐）与 `0° 同相齐列`（稳重行进）两种合法解并说明观感差异。
- **与最近 12 页的差异**：最近 12 页无一使用「满幅炽朱红海报底 + 四道横贯几何交替轨 + 拍位直点翻转 + 层间相位错动 + 原海报胶囊公式控台」；区别于 109（曜黑 30° 斜柱疏密重音）与 110（暖米左书脊 + 紫粉橘梯度坡面），玩法 100% 紧扣 A↔B 周期交替、双极对比与层间相位。

## 3. 版式骨架
- **桌面 1440×900（容器 1380px；2560×1440 舒展至 1860px）**：不锁 `100svh`。极细 32px 墨黑顶眉下，通幅炽朱红 `#FC4E0B` 展开三段垂直节奏——① 开放双栏刊头（左：字块真按 A/B 交替的示范大标「交替节奏组织」；右：`ALTERNATING RHYTHM` + 原海报总述 + 四枚原海报图形实况徽）；② 100% 全宽四轨交替画布 + 底沿一体化层间相位轨（`data-perf-drag`）；③ 原海报同款 1.5px 黑线圆角大胶囊底座（左 52% 米白实底白话诊单与四项实测数 × 右 48% 8 拍 `A ↔ B` 活体公式排与三项精简控件）。
- **平板 1024×1366 / 768×1024**：自然流式排布，不锁整屏高度无空洞；刊头、全宽画布与双栏胶囊底座紧凑衔接，紧接 `01` 节。
- **手机竖屏 390×844**：压紧单行刊头（~72px），16:11 等比四轨画布 + 44px 相位拖轨 + 8 拍按钮带稳占首屏 ≥ 48% 屏高，且同屏露出米白诊单首行；所有圆保持正圆不变形。
- **手机横屏 844×390**：切为左 56% 四轨画布与相位拖轨 × 右 44% 紧凑刊头、诊单与公式控台并行。
- **正文 8 节底色交替**：炽朱红（开场）→ 浅米纸（01）→ 墨黑暗室（02）→ 暖羊皮纸（03）→ 深炭暗厅（04）→ 洁米纸（05）→ 暖砂纸（06）→ 墨黑考场（07）→ 炽朱红原海报档案（08）→ 墨黑页脚。

## 5. 节目录（8 节，h2 均 ≤ 12 字，相邻节不复用同款控件）
- `01` **一呼一应，立住节拍** — 引出原海报两条核心原则并点名同小类 107–114；交互：**三态节拍显微镜（AAAA / ABAB / AABA）与视线弧线切换器**。
- `02` **五种常用交替维度** — 拆解明暗、形态、方向、体量、虚实五类双极通道；交互：**五通道多选叠加矩盘 + 实时 2D 预览与通道过载表**。
- `03` **拍型与相位：不止 1:1** — 拆解 AB / AAB / AABB / ABBA 拍型及原海报圆点与三角的 180° 反相秘密；交互：**拍型选择器 + 机械翻转相位杆（0° ↔ 180°）SVG 双轨织机**。
- `04` **从哪来：织机到光效应** — 串联 1093 达勒姆大教堂、1907 登曼·罗斯、1964 布里奇特·莱利、1965 安妮·阿尔伯斯、1972 王无邪与 1979 程大锦；交互：**五时代标本抽屉与建筑/织机几何图示**。
- `05` **把交替放进真版面** — 落地页 Z 字图文、宽表斑马纹、画册跨页呼吸三套真实 DOM 版面；交互：**实战标本切换 + 每个真实界面内建「关 / 恰当 / 过头」三档活体开关**。
- `06` **什么时候别用交替** — 温和补全原海报前提，详解高频眩光（Wilkins 1984）、连续长文与单向递进误区；交互：**阅读背景条纹频率/对比压测滑杆（实时压测真实中文段落可读性）**。
- `07` **练一练：哪份交替稳？** — 同场景四选一；交互：**四张纯中性标签（方案 A/B/C/D）同构视觉考题卡，作答后叠加四项单真源诊断标注**。
- `08` **原海报与关键词** — 展示 111 原海报（点击放大/拖拽/Esc 收起）与原海报四枚定制几何图标及底部 `A ↔ B` 公式带。

## 7. 练习题设计（单一变量对照，纯中性标签）
- **题目**：四份 8 格双层展板排布（同一朱红底、同一画幅与边距，仅改变一个交替变量），凭直觉选出节拍最稳的一份。
- **选项（标签仅写 方案 A / B / C / D）**：
  - `方案 A`：周期、相位、拍宽皆稳，唯独 **B 极明度过暗（对比仅 1.5:1）**，双极糊成暗块。
  - `方案 B`：对比、相位、拍宽皆稳，唯独 **拍序断律（`AABABBBA`）**，出现 3 连 B 堵拍。
  - `方案 C`：**正确答案** — 周期（`ABABABAB`）、对比（墨黑/米白 16.9:1）、层间 180° 反相咬合、50:50 均衡拍宽四项同时成立。
  - `方案 D`：周期、对比、相位皆稳，唯独 **A:B 拍宽失衡（82:18）**，B 被挤成细缝。
