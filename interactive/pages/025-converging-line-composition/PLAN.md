# 025 汇聚线构图 · 设计方案（PLAN）

## 1. 一句话道理
汇聚线构图利用单点线性透视与地表递进压缩，把现实里平行的道路、廊柱或光束在二维平面上收束向同一个消失点，迫使人眼顺线向纵深推进并锁定唯一视觉焦点；它成败的关键不在“斜线画得多不多”，而在四道门槛：**汇点唯一且落在画内安全区**（不散成多点打架、不飞出画框）、**汇聚夹角落在有效透视带**（太窄退化成平行线、太宽变成广角畸变）、**沿线结构遵循 `1/z` 递进疏密**（拒绝平面等距假透视）、以及**真正的主体坐镇汇点**（绝不让全部线条替一片空白打工）。

## 2. 开场玩具：活体透视长廊 · 消失点直绘台（Vanishing-Point Drafting Chamber）
- **玩法**：直接把 025 原海报的「左斜深海蓝标题壁 + 暖宣建筑制图纸 + 右翼柱列长廊 + 底部朱红汇聚通途 + 原海报底沿四柱核心要点」做成一整块活体单点透视制图台：
  - **画布直拖「朱红消失点钉针」**：像达·芬奇在《最后的晚餐》壁面钉定位钉拉线那样，直接拖动画面里的朱红圆钉（或点击画布任意落点、用方向键微调），整座建筑廊道、远景公路或光影射线实时重算单点透视，支持正中对称、偏心三分、高视平俯瞰、低视平仰望等多种合法解（非单一坐标答案）。
  - **一体化底沿「汇点收拢尺」（`data-perf-drag`）**：紧贴舞台底沿的建筑比例标尺滑轨，左右拖动可把左壁、朱红通途、右翼柱列三条引导束的虚拟汇点从「多点撕裂散开」连续收拢至「单点精确锁汇」（靠近 0% 离散时轻磁吸）。
  - **镜头焦段、递进压缩与焦点主体三联操控**：切换 `14mm 超广畸变 / 28mm 建筑纵深 / 50mm 人眼自然 / 135mm 长焦压平` 亲眼看到汇聚张角如何连续变化（拉到 135mm 直接退化为 024 平行线！）；切换 `平面等距贴图` 与 `1/z 透视递进` 亲眼对比层次塌扁与立体纵深；切换焦点目标 `留空 / 偏位 / 坐镇汇点` 并可在原海报三套经典题材（`建筑廊道 / 远景公路 / 光影射线`）间无缝切换。
- **开场状态（0/4 翻车错态，绝不先给答案）**：
  - 汇点离散度 `68%`（左墙、朱红地面、右廊柱各自指向不同假汇点，画面撕裂打架）；
  - 镜头焦段 `135mm`（汇聚主夹角被压窄到约 `14°`，透视深度塌平）；
  - 沿线节奏 `等距贴图`（窗柱与路标近远间距比 `1.00×`，缺少 `1/z` 透视递进）；
  - 焦点目标 `留空`（线条尽头空无一物，视觉能量漏空）。
- **玩错判定与「为什么」读数（`model.js` 单一透视投影真源，全部数值直接从实绘射线与窗柱坐标算出）**：
  - **汇点散乱**：三组引导束最大落点偏离 `> 3.5%` 画宽 → 指出视线半途分叉打架，无法聚力；
  - **汇点贴边 / 出画**：圆钉落进外缘 `< 14%` 或 `> 86%` 禁区 → 指出汇聚线反而成了把眼睛送出画框的滑梯；
  - **长焦压平**：主汇聚夹角 `< 20°` → 指出纵深感塌成扁平平行带，滑入 024 平行线构图的领域；
  - **超广畸变**：主汇聚夹角 `> 96°` → 指出边缘拉伸变形、射线刺眼，产生眩晕压迫；
  - **等距假透视**：近远间隔比 `< 2.0×`（等距贴图模式） → 指出大脑一眼识破只是平面斜三角，立不起前后层次；
  - **汇点放空 / 目标脱轨**：终点无主体或主体偏离消失点 `> 14%` → 指出线条替空白打工或与主角互相抢戏。
- **与最近 12 页的明显区别**：
  - 024 是深夜蓝通栏平行线调律梳轨，313 是宽银幕横向推轨剪影，146 是蒙德里安黑框正交格墙，191 是贝塞尔路径排字台，229 是 CSS 多栏报样桌，273 是暗底三层遥测仪表盘，106 是冷白展墙径向清场台，061 是紫调引力成簇场，312 是片场三角走位俯视双联，145 是五面板二分拼版板，228 是鼠尾草绿 CSS Subgrid 双层轨，023 是白绿斜切高速单斜轨；
  - 本页完全生长自 025 原海报的**普鲁士深蓝左壁 × 暖宣透视长廊 × 朱红通途**，核心动作是**单点透视钉针牵引 + 三束射线离散收拢 + 焦段夹角伸缩 + `1/z` 透视递进验证**，任何其他编号都无法套用。

## 3. 版式骨架
- **1440×900**：不锁 `100svh`。极细 34px 制图顶眉线 → 整体围于 1.5px 深海蓝建筑图框内的「原海报非对称宽版跨页」：左翼 29% 普鲁士深蓝建筑墙（承托 `汇聚线` 米白大字 + `构图` 朱红大字 + `CONVERGING-LINE COMPOSITION` + 总述 + 三题材切签 + 复原错态），右翼 71% 敞开暖宣纸活体透视画布（约 960×470px）；其下通栏紧接「汇点收拢尺（`data-perf-drag`）+ 焦段/递进/目标三联制图控件」；最底复刻原海报下半幅的「左 54% 四栏细竖线 `核心要点` 实时灯 × 右 46% 实况白话诊单」。首屏紧凑完整，一眼尽览。
- **2560×1440**：版心舒展至 `1840px`，右翼透视舞台同步放大至约 `1280×590px`，两侧绝无空洞。
- **1024×1366 / 768×1024**：自然文档流排布，不设 `100svh` 留空；768 以下顶翼转为深蓝通栏刊头，下方满幅 4:3 透视画布与 2×2 要点栏流畅衔接。
- **390×844（手机竖屏）**：顶眉与深蓝刊头压紧至单行标题 + 三题材切签，近似方幅等比透视画布稳占首屏约 46% 屏高（约 375px，圆钉与落日恒保正圆不变椭圆），紧贴画布下方同屏呈现 48px 触控友好的「汇点收拢尺（`data-perf-drag`）」与实况诊单，总述与四柱要点自然顺排其后。
- **844×390（手机横屏）**：切换左 56% 透视画布 + 收拢尺、右 44% 精简深蓝刊头 + 控件 + 诊单并行，零横向溢出、零裁切。

## 5. 节目录（8 节，每节标题 ≤12 字，相邻两节不用同一种控件）
- **01 线条为何能变出纵深** (*Why Lines Create Depth*)：展开原海报四条标注（消失点、引导、深度、方向），内置 **「庞佐错觉卡尺对比仪」**（连续夹角滑杆 + 一键「放上卡尺平移重叠」按钮），亲眼见证两条等长横杠在汇聚线里被大脑看成一长一短。
- **02 消失点放哪，情绪怎么变** (*Vanishing Point Placement*)：温和辨析原海报「唯一视觉中心」并非只能钉在正中，内置 **「3×3 方位与视平高程矩阵点选盘」**（侧视机位高程剖面 + 正面实时透视图联动），并一句话链接 016 居中、017 偏心、018 对称、021 水平构图。
- **03 真透视靠疏密，不止靠斜线** (*Foreshortening & Depth Layers*)：普鲁士深蓝暗板，拆解原海报「透视构建 / 层次增强」，内置 **「三层透视剥离独立开关 + 柱列跨数阶梯」**，关掉 `1/z` 递进柱列即可目睹三维隧道瞬间塌成平面三角形。
- **04 公路、廊道与光束：海报三例** (*Three Poster Archetypes*)：原样还原并拆解原海报右下三幅竖版示例（道路远景 / 建筑纵深 / 光影聚焦），每幅配有独立 **「画面 / 透视骨架 / 受力拆解」三段透视切镜**，并附与 024 平行线、023 对角线、026 交叉线的边界速查表。
- **05 从佛罗伦萨到银幕：它从哪来** (*Origins of Linear Perspective*)：核实史料时间轴（约 1415 布鲁内莱斯基、1435/1436 阿尔贝蒂《论绘画》、1495–1498 达·芬奇《最后的晚餐》、18 世纪江户浮绘、1911 庞佐、1950 吉布森）+ **「历史拉线几何复原标签台」**（按年代切换并开关透视辅助拉线）。
- **06 什么时候别用汇聚线** (*When Not to Use It*)：普鲁士深蓝警示板，温和补正原海报 TIP 说过头之处，内置 **「三类错用病例翻牌对照」**（双品并列对比 / 建筑正立面档案 / 群像平视合影），一键把强行透视切回恰当构图并说明原委。
- **07 练一练：哪幅真聚住了视线** (*Practice · Single-Variable Test*)：两道单变量盲测，四张实时绘制的中性标签小图（`方案 A` / `方案 B` / `方案 C` / `方案 D`），选完立即在四幅图上叠加透视校验射线并逐幅讲透成败。
- **08 原海报与核心关键词** (*Original Poster & Keywords*)：原海报完整图（点击放大、滚轮与按钮缩放、鼠标/触控拖动平移、Esc 关闭，`draggable="false"`）+ 四大关键词图标详注 + 原海报底部深蓝 TIP 横幅。

## 7. 小练习设计
- **第 1 题（单变量：汇聚一致性与主体落位）**：同为 35mm 暗蓝建筑石廊、`1/z` 递进柱列、同一偏心落区，四版只差线条汇点与朱红门洞的位置关系：
  - `方案 A`：顶梁、柱底、地砖线各自指向不同假汇点（汇点散乱，视线半途打架）；
  - `方案 B`：线条严密汇于中右一点，但终点一片空白（汇点放空，聚力落空）；
  - `方案 C`：所有线条精准汇入中右消失点，朱红门洞与剪影正坐镇汇点核心（**正确**）；
  - `方案 D`：线条精准汇向右方，朱红主角却孤零零塞在左下角（指东打西，结构与主体互抢）。
- **第 2 题（单变量：汇聚夹角与纵深递进节奏）**：同为远景公路、同一中右偏心落日与主体落位，四版只差镜头焦段与标段疏密：
  - `方案 A`：135mm 长焦将道路压成近乎平行的窄带，纵深感坍塌；
  - `方案 B`：35mm 夹角清晰，但路面标段与路标按平面等距排列（近远 `1.00×`），呈二维贴纸感；
  - `方案 C`：14mm 超广角把路面拉伸成刺眼放射尖刺，前景边缘严重畸变；
  - `方案 D`：35mm 自然汇聚夹角配合真实 `1/z` 由疏到密递进节奏，视线平稳深入落日（**正确**）。
