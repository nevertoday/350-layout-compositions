# 200 非对称网格（Asymmetric Grid）设计方案

## 1. 一句话道理
非对称网格不是放弃网格、随手乱摆，而是把页面切成**不等宽、不等高的隐性轨道**，再借元素的尺寸落差、色彩分量与距中心支点的杠杆距离，在不均等中重新找回稳定、张力与明确的视线动线。

## 2. 开场玩具：非对称网格拉轨平衡台（Live Asymmetric Grid Blueprint Stage）
- **怎么玩**：
  - 在 1:1 化用 200 号原海报黑底白虚线「结构示意」的 2D Canvas 蓝图台上，直接**横向拖拽垂直主栏轨 V1**（`data-perf-drag` 标在主画布上；也可拖动次栏轨 V2、水平挂线 H1 与青色配重竖条，键盘 `←/→` 调 V1、`↑/↓` 调 H1、`Tab` 或快捷键切选轨/块）。
  - 直接**点击画布中的红框脱轨模块**把它磁吸锁回网格线，或点击任意模块切换其跨轨尺度权重，拉出主次层级。
  - 可在原海报自带的三个视觉语境间实时切换：**结构蓝图**（原海报四块 X 线框 + 青竖条/黄横条/白圆点/青虚线动线）、**杂志跨页**（原海报《城市的另一种呼吸方式》跨页排版）、**演艺海报**（原海报 `SOUND LAB` 构图）；画布底沿嵌一根随实绘几何实时倾斜的**视觉杠杆标尺（示意）**。
- **初始状态（绝不先给答案）**：
  - 开场停在 **0/4 待立序错态**：三栏死均分 `33% : 33% : 34%`（`1.0×` 无张力对称）、重块与亮色锚全挤在左侧导致视觉杠杆左倾翻船（偏左 `-16%`，示意）、四块面积接近 `1.1×` 主次平权打架、且其中 2 块故意脱轨漂移（`+20px` / `-16px`）造成无序杂乱。
- **怎样算玩错、读数怎么说「为什么」**：
  - 所有指标由 `model.js` 从实际绘制的轨道坐标、模块边界与配重块位置单真源实算，可主动踩出 **8 类具体失误**：`均分死对称`、`窄轨挤碎（<12%）`、`左倾翻船`、`右倾翻船`、`主次平权打架`、`脱轨真乱`、`塞满窒息`、`镜像伪平衡`。
  - 每次出错，白话诊单直接讲清「眼睛会怎么看、为什么会滑向失衡或杂乱」并给出可立刻动手的修正提示；支持原海报经典解、杂志 2:5:3 解、大留白 1:3:2 解以及任意用户自调达标解。
- **与最近 12 页的区别**：
  - 199 是推两层透明描纸找公约数、198 是调行距对齐基线、154 是扩黑沟槽涂四块色、237 是调遮罩透度与 z-index 层叠、030/031 是转十字/开合剪刀楔。本页独有的动作是**拉偏 CSS/出版不等分栏轨 + 跨轨立主次 + 借视觉杠杆配重找回非对称平衡**，无法套用到别的编号。

## 3. 版式骨架
- **忠实承袭 200 号原海报黑底包豪斯建筑图谱骨架**（0px 锐利直角、不锁 `100svh` 避开平板空洞）：
  - **1440×900（2560 舒展至 1760px）**：34px 极细墨黑顶眉下，首屏直接按 `36% : 64%` 非对称双轨排布，右缘保留原海报满出血电光青竖条：左轨排嵌原海报明黄大圆弧与圆点的动态示范标题「非对称 网格」（两行随实时 V1 轨道比例错位）、总述、实时白话诊单与原海报五枚黄青交替圆章要点灯；右轨排原海报 `结构示意` 青线标题、6×6 点阵（单枚青点破对称）、全幅蓝图互动舞台（底嵌视觉杠杆尺）与精简单行控条。左右两轨对齐收底，无大片留白。
  - **1024×1366 / 768×1024**：自然流式转排，刊头压缩后全宽展开蓝图舞台，下方双栏并排诊单与五要点。
  - **390×844 竖屏**：压紧单行刊头与场景切换胶囊，让等比蓝图舞台 + 杠杆标尺稳占首屏 ≥ 46% 屏高，并在首屏底沿同见实时诊单主句。
  - **844×390 横屏**：切换左 56% 蓝图舞台 × 右 44% 紧凑刊头、实时诊单与快控并行。

## 4. 配色和字体
- **逐像素采自 200 号原海报**：
  - 墨黑主底 `#070707` / 抬升暗舱 `#121417` / 深青暗室 `#0A1418`
  - 暖骨纸底 `#F2EDE3`（取自原海报巨大暖白圆与 SOUND LAB 纸面）/ 冷杂志纸 `#E6E9EC`（取自原海报《城市》跨页）
  - 标志明黄 `#EFE642`（浅纸高对比深橄榄金字 `#5C5300`，黑字压明黄实底 `#090A0B`）
  - 标志电光青 `#17B3D3` / 暗底亮青 `#2AC8E8`（浅纸高对比深青字 `#006378`）
  - 克制错态赤红（暗底 `#FF7575` / 浅纸 `#A81E2B`），达标松青（暗底 `#3BE0B5` / 浅纸 `#0A6A55`）
- **字体搭配**：`Noto Sans SC`（400/700/900）+ **`Syne`**（600/800）+ **`Archivo`**（400/600）+ **`Space Mono`**（400/700）。
  - 三款西文 `Syne`、`Archivo`、`Space Mono` 在最近 12 页全部 **0 次使用**，与相邻 199 页零西文重合，全库唯一组合。

## 5. 节目录（7 大节，h2 均 ≤ 12 字）
- `01` **不对等，为什么反而更稳**（暖骨纸）：展开原海报五条核心要点；配「视觉杠杆天平」互动——拖动小块青/黄配重臂长与明度去平衡大暖白块。
- `02` **从风格派到瑞士网格**（墨黑底）：1917 风格派 → 1928 奇肖尔德《新排版术》→ 1935/1967《非对称排版》→ 1954 阿恩海姆《艺术与视知觉》→ 1981 穆勒-布罗克曼《网格系统》→ CSS Grid `fr`；配「年代版式切换图版」与「海报说多了一点」温和校准。
- `03` **三件应用示例拆解**（深青黑室）：1:1 复原原海报底沿 `FUTURE FORUM`、`城市的另一种呼吸方式`、`SOUND LAB`；配「X 光剥层开关（隐性轨/重量支点/动线）」与「一键压回居中对称」对比。
- `04` **不等轨怎么切，网页怎么写**（暖骨纸）：真 DOM CSS Grid 比例切片台（`1fr 2fr`、`2fr 5fr 3fr`、`1fr 3fr`、`1fr 1fr 1fr`、`1fr 8fr`）+ 视口宽度滑块压测窄屏折行 + 同类网格一页一句外链。
- `05` **什么时候别用非对称网格**（冷杂志纸）：价目对比表、严肃法律文书、长篇纯文、极窄竖屏硬拆三栏；配「反例现场对比开关」逐项切回合适结构。
- `06` **练一练：哪张草图最稳**（暖骨纸）：A/B/C/D 四张中性标签展讯海报，仅差单一变量（死对称 / 达标正解 / 同侧压重翻船 / 脱轨真乱），选后显出隐性轨道与杠杆判据。
- `07` **原海报与五要点总览**（墨黑底）：可点击放大、拖拽平移、Esc 收起的 `poster.webp` 与原海报五枚黄青圆章检核卡片。

## 7. 小练习设计
- 题目：四张同题材展讯海报草图（仅标 `A / B / C / D`），哪一张同时成立了非对称张力、杠杆平衡与锁轨秩序？
- 四个选项单一变量对照：
  - `A`：三栏 `1:1:1` 均分居中对称（工整但零非对称张力）。
  - `B`（正确）：`2:5:3` 不等分三栏，左侧大焦块 + 右侧远处明黄/电光青轻锚平衡杠杆，全部元素严格锁轨。
  - `C`：沿用 B 的 `2:5:3` 轨道，唯独把黄/青配重锚挪回重块同一侧（左倾翻船、右栏空悬）。
  - `D`：沿用 B 的 `2:5:3` 轨道与右锚，唯独 2 个次级块脱轨偏位 14–20px（失控杂乱）。
