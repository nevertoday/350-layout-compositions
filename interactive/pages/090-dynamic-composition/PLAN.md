# 090 动态构图（DYNAMIC COMPOSITION）互动页方案

## 1. 一句话道理
人眼把水平线与垂直线当成“静止与重力的基准”，一旦版面用**统一方向的斜势轴线**打破对称，再叠加**大小体量反差**与**疏密加速节拍**，静止的图形就会在视觉上产生明确的运动方向、推进节奏与聚焦爆发力——但它仍需受控的“动态平衡”，否则只是散乱的噪音。

## 2. 开场玩具：斜势弹道编排台（Kinetic Diagonal Sequencer）
- **载体**：2D Canvas（标 `data-perf-drag`），1:1 承袭 090 原海报暖米纸底、亮橙主箭、深石油青闪电、大小对比圆球、白切速度线与半调网点尾迹；支持三套真实场景切换：**原海报·动势编排**、**运动赛事·冲刺海报**（纯剪影无五官奔跑者）、**音乐节·声浪主视觉**。
- **怎么玩**：
  1. **横拖/斜拖画布**（或调「动势倾角」轨 / 键盘 `←` `→`）：把被锁死在 0° 水平面上的构图主轴连续掰向斜势（`-55°` 至 `+75°`），观察整个箭矢、球列、速度切线与半调喷点一起挣脱水平重力。
  2. **直点画布上标红的逆冲元素**（逆向深青闪电 / 反向小箭）：把与主方向对冲抵消的图形扳回顺势，也可以故意再点一次制造「逆势对冲」体验能量内耗。
  3. **直点任意圆球**（或调「体量对比」与「节拍加速」轨 / 键盘 `↑` `↓`）：把均权等大的圆球拉开大—中—小落差，把等距呆板的步距推成「蓄势→冲刺」的递增节拍。
  4. **按 `Space` 或点「脉冲放流」**：沿实绘元素的真实几何中心释放能量脉冲流，验证视线能否一气呵成冲向主焦点；若仍平躺、逆冲或挤角，脉冲会在画面中真实卡停、撞弹或溃散。
- **开场状态（0/4 僵死静止错态，不是答案）**：
  - 轴线锁死在 `0°`（水平静止，滑向 089 静态构图）；
  - 三枚圆球体量几乎均等（大小比 `1.1×`），无主次张力；
  - 间距完全均匀（步距比 `1.0×`），无加速节奏；
  - 深青闪电与辅助箭矢反向对冲（2 处逆冲）且速度切线关闭。
- **怎样算玩错、错了读数怎么说（`model.js` 实绘坐标单真源双向检出 9 类错态）**：
  - 轴线过平（`|角| < 12°`）：指出视线落入水平基准，滑回静态构图，没有前进势头；
  - 轴线过陡（`|角| > 72°`）：指出斜轴退化成竖柱，前进张力消散；
  - 逆势对冲（仍有反向元素）：指出两股方向互相顶牛，动能原地抵消；
  - 均权平铺（大小比 `< 1.6×`）：指出大球小球拉不开落差，眼睛不知道终点在哪；
  - 巨块窒息（主球过大挤占画框 >42% 或切边）：指出视觉重量压垮路径，流动被堵死；
  - 等拍呆板（步距比 `< 1.45×`）：指出间距像表格列队，缺少由慢到快的推进律动；
  - 挤角叠撞（加速拉爆导致元素堆在边缘或互撞）：指出图形扎堆成团，速度通道被堵；
  - 缺速度线索（斜轴与对比偏弱且速度切线关闭）：指出缺少动态拖影与方向引导；
  - 散乱噪点（倾角乱配且逆冲）：指出动感滑向杂乱。
  - 认可**多组合法解**：`海报上扬 54°`、`极速俯冲 -34°`、`蓄势爆发 38°` 以及用户自己调出的任意 4/4 达标状态。
- **读数说什么「为什么」**：每条诊断不只报角度和倍数，而是直接解释“为什么这么摆眼睛会停住/撞车/顺流冲向焦点”；动能等级以定性档位（`僵死静止 / 逆冲内耗 / 初具动势 / 强动势流（示意）`）呈现，不做伪精确百分数。
- **与最近 12 页的明显差异**：
  - 对比刚做完的 **089 静态构图**（暖石膏纸+石板蓝、建筑水平仪把倾斜调回 0°）：本页是其完全镜像——暖亮米纸 + 亮橙/深石油青撞色、斜切楔形骨骼、把 0° 水平僵局掰成斜向冲势，并直接点除逆冲冲突与拉出疏密加速；
  - 对比 **053 向心式构图 / 052 放射式构图 / 055 同心式构图**：不做中心汇聚/辐射/同心圆，而是斜穿全幅的定向动能轨迹 + 1:1 复刻 090 原海报右侧 5 枚圆徽引线探针与底部深石油青斜切楔形诊单座；
  - 对比 **308/307/341/222/221/177/176/141**：无通用圆角仪表盘，以 090 原海报的尖锐斜切楔形、双色斜体标题与亮橙五连点构成全新视觉系统。

## 3. 版式骨架
- **1440×900（主宽 1380px，2560 舒展至 1660px，绝不锁 `100svh`）**：
  - 顶沿紧凑斜势刊头：左置 090 原海报同款箭头徽章 + 自示范微斜双色大标「动态（橙）构图（深青）」配深青笔触底线与 `DYNAMIC COMPOSITION`；右置场景切换签、「脉冲放流 Space」键、实测状态章与原海报右上角 5 枚竖排亮橙圆点。
  - 中段不对称主舞台：左 66% 为锐角无黑框开放式 2D Canvas 斜势编排画布 + 紧贴底沿的单行操轨坞（倾角/体量/节拍三轨、快捷校准与多解/试错芯片）；右 34% 1:1 复刻原海报右侧 **5 枚深青/亮橙交替实心圆徽 + 折线虚线引线 + 橙色端点**，作为五个实时单真源探针（点击可高亮对应画布物理维度）。
  - 首屏底沿 1:1 复刻原海报标志性的**深石油青斜切大楔形（`#00373B`）** + 右下亮橙速度斜切边，内嵌左半单真源白话诊单与一键激发/复原键、右半原海报「核心要点」原话与 5 枚白色矢量图标。
- **1024×1366 & 768×1024**：自然流排零空白——满宽画布与操轨坞 → 5 枚圆徽探针以均衡网格排布 → 深青斜切诊单楔形。
- **390×844（手机竖屏）**：压紧单行刊头 + 场景切换，4:3 等比高清画布稳占首屏 ≥46% 高度，折线内直露白话诊单首句、核心倾角滑轨与「激发原势 / 放流」双键；5 枚详细探针与完整要点紧随折线下方。
- **844×390（手机横屏）**：左 56% 画布与精简底轨 × 右 44% 刊头、诊单与快捷操作并排。

## 5. 节目录（7 节，每节标题 ≤12 字，相邻两节交互不同）
- **01 五股推力，拧出流动**（The Five Kinetic Forces）— 引出原海报 5 条原话，配「五维剥离器」复选按钮，逐一开关方向/张力/节奏/速度/能量，在实时矢量版面上看到少掉任何一股后会怎样泄气。
- **02 斜线为何天生带冲力**（Why Diagonals Move）— 讲清人眼对水平/垂直的「斜线效应」与视觉失衡，配「角度重力坡道」分段步进/拉杆对比器（0° / 18° / 38° / 54° / 75° / 90°）并一言链接到 [089 静态构图](https://layout.xiaoxiaodong.ai/089/play/)。
- **03 动感不是满屏乱飞**（Flow vs Visual Noise）— 在深石油青暗室中用「左右拉帘对照台」实测同一张音乐节海报：左侧满屏多方向斜字乱撞、右侧单轴统一斜势+静区留白，讲清「动中有锚」。
- **04 从哪来：百年的斜势脉络**（Origins of Dynamism）— 核实史料：1913 博乔尼未来主义雕塑 → 1919–1920 利西茨基构成主义海报《用红楔子打击白军》→ 1928 扬·契肖尔德《新排印》→ 1954/1974 阿恩海姆《艺术与视知觉》与 1972 阿佩尔《斜线效应》；配「四代构图图谱切换卡」用纯几何 SVG 拆解四代动势逻辑。
- **05 什么时候用，什么时候别用**（When to Use & Avoid）— 配「真实项目分诊卡」（点击翻查适用/慎用判断与反例拆解），温和修正原海报「目标不是“平衡”，而是“流动”」（标「说满了一点」：打破的是对称，仍要靠动态平衡兜底），并各用一句话链接同小类全部 7 页（087、088、089、091、092、093、094）。
- **06 练一练：哪张真动起来了**（Practice · Spot True Flow）— 深石油青考场，四张同题材、同配色、同文案的跑鞋海报（中性标签 `方案 A / B / C / D`），只差一个变量，选完后全部显出动势矢量线并给出逐项解析。
- **07 原海报与五个关键词**（The Original Poster）— 可点击放大/拖拽/Esc 关闭的原海报 `poster.webp` 与 5 枚原海报同款白色/深青关键词徽章。

## 7. 小练习设计
- **题目**：同一双橙青配色的竞速跑鞋新品海报，四张方案字体、色盘、文案完全相同，哪一张真正成立了“动态构图”？
- **四个选项（标签仅写 `方案 A / 方案 B / 方案 C / 方案 D`，零剧透词，只差单变量）**：
  - **方案 A**：0° 水平居中排布，体量均等、步距均匀（变量差异：无斜势轴线与不对称张力）。
  - **方案 B（正确答案）**：52° 右上斜势统一推进，主鞋大特写与三枚小节奏点拉开约 3× 大小差、间距前疏后密递增、同向速度切线收束于右上主标。
  - **方案 C**：同样 52° 斜势，但四个元素大小雷同、间距等距（变量差异：只有斜角外壳，缺少体量对比与节拍加速）。
  - **方案 D**：同样 52° 斜势与大小对比，但两条主引导箭与文字块方向相反、在中段正面对撞（变量差异：方向逆冲导致视觉能量互相抵消）。
