# 082 空气透视构图 · 方案（PLAN）

## 1. 一句话道理
空气并非完全透明：悬浮其中的气体分子与微小颗粒会一边衰减远景直射光、一边向视线叠加明亮而柔和的天空散射光（空气光），使远物逐层提亮、去饱和、降反差并隐去琐碎边缘，人眼由此在二维平面里读出几公里外的纵深与氛围。

## 2. 开场玩具
- **命名**：大气散射光学台 · 五层山岚调气工坊（纯 2D Canvas，标 `data-perf-drag`，由 `model.js` 内的科施米德空气光公式 $L(d)=L_0 e^{-\beta d}+L_\infty(1-e^{-\beta d})$ 单真源驱动）。
- **怎么玩**：
  - 在开放山岚画布上**左右横拖**，直接推拉大气散射浊度 $\beta$（从真空 $0.00\text{ km}^{-1}$ 到浓雾白茫 $0.45\text{ km}^{-1}$），实时观察 5 层地景（0.2 km 近景松崖 → 1.4 km 近中山脊 → 4.2 km 中景湖岭 → 9.5 km 远景城廓 → 18 km 极远山影）的明度、彩度与反差演变。
  - **直点画布上的任意一层**（或底沿五层深度条）选中该层，再用**纵拖 / 键盘 ↑↓ / 层级明度滑块**独立压深或提亮该层，亲手制造或修复「远比近深」的深度倒挂。
  - 切换三类场景（`原海报·山岚远城` / `水墨·平远江山` / `晚霞·暖雾峡谷`）、四类散射天光（`瑞利蓝紫` / `米氏乳雾` / `金晖晚霞` / `真空无气`）与细节锐度模式（`自然递减` / `全景过锐` / `近景失焦`）。
- **开场初始态（刻意处于复合错态）**：
  - 浊度 $\beta = 0.00\text{ km}^{-1}$（零空气散射，五层粘成扁平贴纸）+ L4 远景城廓被刻意压深并高饱和（明度低于 L3 中景湖岭，形成前后倒挂）+ 全景锐化过头（远山带硬锯齿轮廓，违背「远山无皴」）。
- **怎样算玩错、读数怎么说「为什么」**：
  - `model.js` 从实际渲染到画布的 5 层 RGB 计算感知明度 $L_1\dots L_5$、彩度 $S_1\dots S_5$、层间阶差 $\Delta L$ 与能见度，双向判定 7 类真错态：真空贴纸粘连、白雾过度吞没、远景比近景更深（明度倒挂）、远景彩度抢戏、近景锚点发灰、远景过度锐化、近景失焦糊散。
  - 每次报错都用白话指出「哪一层出了什么光学矛盾、为什么眼睛会把远近读反」，并同时接受清岚原海报解、晴日薄雾解、烟雨浓岚解、晚霞暖雾解等多组合法解。
- **与最近 12 页的差异**：
  - 081 是走廊针孔投影测物距比例，043/168/131/212/332/298/167/253/042/130/211 分别是冰山漏斗、建筑轴线、斑点星图、横排左起、四折观澜、双面折页、活体引语、Z 轴浮层、筑塔叠层、千层切片与断层网格；082 独有的「横拖注气调浊度 + 逐层调明度破/修空气透视 + 瑞利/米氏/晚霞散射切光」完全长在空气光学规律本身，无法移植给任何其他编号。

## 7. 练习设计
- **第 1 题（晴日远山高塔）**：四幅完全相同构图与轮廓的画框，标签仅写中性「方案 A / B / C / D」，**只改变四层山体的明度与彩度梯度**：
  - A：四层明度贴齐（24%–31%），像无空气贴纸；
  - B（正解）：近 20% → 中 44% → 远 70% → 极远 86%，彩度同步递减；
  - C：远塔压深到 26% 低于近中景，发生深度倒挂；
  - D：中远三层过早洗白挤入 82%–93%，中间层次断档。
- **第 2 题（日落晚霞峡谷）**：同样只改空气光色温与远近梯度，检验读者是否识破「晚霞里强加冷蓝雾」的生硬套路，理解远景应向当下天光（暖金霞光）靠拢。
