# 092 封闭式构图（CLOSED COMPOSITION）制作方案

## 1. 一句话道理
通过清晰的四向边界、向内倾斜的引导形体与由外而内的嵌套呼吸余量，把本会滑出画框的视线稳稳折回画面核心，使主体获得自足、专注、秩序与可信度。

## 2. 开场玩具：「四门合围·藏室封界仪」（Architectural Enclosure Vault，2D Canvas 标 `data-perf-drag`）
- **原型来源**：1:1 承袭 092 原海报深柏墨绿方框、四向内指三角门楔、四面古铜鎏金斜切内壁、墨绿外环与细金内环、暖白内庭菱形、鎏金方座与核心金珠的层叠藏室结构，并提供三套真实语境：**原海报·叠院藏核** / **徽章·品牌印记** / **书封·框景珍藏**。
- **怎么玩**：
  1. **横拖画布（`data-perf-drag`）**：连续推进或敞开四向围合度（20% 敞口泄气 ↔ 82%–96% 稳重合围 ↔ 118% 粗墙窒息），同时实时联动斜切内壁倾角与外框壁厚；移动端 `touch-action: pan-y` 保留纵向滚动。
  2. **直点四面门闸（北 / 东 / 南 / 西）**：当场封门或凿开缺口；缺口处立即可见光线与视线粒子破边外逃。
  3. **直点四角斜切导引楔**：在「向外发散」与「向内收束」之间翻转，观察角落死区如何把注意力拽离中心。
  4. **直点闯边逃逸块 & 调核心尺度 / 嵌套层阶**：把压在破口边缘抢戏的逸出块收回内庭，并用卡尺滑轨雕琢核心体量（过小失焦 vs 过胖顶框）与圆穹/方框形态。
  5. **按 `Space` 或点「放飞视线」**：从四边与内庭放飞 16 枚金砂视线流光，按真实几何物理碰撞围墙、沿斜切壁折返或从敞口泄漏，肉眼验真是否锁住核心。
- **开场初始状态（绝不先给答案）**：刻意停在 **0/4 破界失核态**——东门与南门两道围墙敞开缺口、合围度仅 38%、四向斜切导引外翻发散、有一枚闯边杂块卡在东侧破口处，且内庭核心萎缩至 12%。
- **怎样算玩错 & 读数如何解释「为什么」**：`model.js` 从实际绘制的墙体多边形、门阀开度、斜切矢方向、核心半径与留白环宽同一数据源双向演算，检出 8 类正反错态（包含「敞口漏气」「过封窒息成牢笼」「导引外翻挂死角」「闯边抢戏」「核心过小沉底」「核心过胖顶墙」「层阶断链」「对比糊成一片」），读数永远先用白话解释「视线此刻为何跑掉或发闷」，再用档位标明「围合状态（示意）」，绝不报假精确评分。
- **认可多组合法解**：不仅认「原海报·叠院合围」，同样认可「疏朗·细框留气」（轻边框+大呼吸余量）与「圆穹·团扇环封」（无直角硬框的圆弧围合），且用户手动调到任意满足四项几何条件的组合都能 4/4 通过。
- **与最近 12 页的明显区别**：
  - 对比 **091 开放式构图**：091 是拆掉围栏把元素推向画外世界；092 则是封补四向门阀、调校内斜壁折返视线，并反向警惕「过封成笼」的窒息边界。
  - 对比 **055 同心式构图 / 053 向心式构图**：055 是拖偏心圆环归圆心、053 是拧箭头夹角吸噪点；092 聚焦「边界围合 + 门阀泄气/回弹物理 + 框核呼吸余量」这一封闭构图独有命题，其他编号无法原样套用。

  - 底部无缝承接全宽深柏墨绿压脚底座：左 38% 鎏金太阳徽与原海报「核心要点」，右 62% 四栏竖线「关键词」（围合 / 收束 / 聚焦 / 统一）实时映射单真源读数。
- **1024×1366 / 768×1024（平板）**：取消强制首屏高度，自然流排——满宽等比正方画布配 2×2 齐底圆徽与诊单，无大片空白。
- **390×844（手机竖屏）**：压紧单行刊头与三语境签，后置总述文字与四圆徽，让严格 1:1 等比正方画布（约 358×358px）稳占首屏 ≥46% 高度且永不压扁，折线内同时露出合围主滑轨、一键合围/放飞视线双键与诊单首句。
- **844×390（手机横屏）**：切为左 44% 等比正方画布 × 右 56% 刊头、诊单首句与主操轨并行布局，单屏即可完整操作。

## 7. 小练习设计（单变量严苛判题）
- **题目**：同一张美术馆青铜器特展封面（相同底色、相同中央器物剪影、相同标题字号与留白区），仅改变「边界围合与导向关系」这一个变量。四版中性标签 `A` / `B` / `C` / `D`，哪一版成立了最稳妥的封闭式构图？
- **四选项差异（全部外观工整，无一眼假标签）**：
  - **A**：外框右侧大幅敞开缺口，且内侧细金折角朝右外张，引导视线滑出画框。
  - **B**：四边虽已封合，但粗重斜切黑绿框壁向内挤压，核周几乎零呼吸缓冲，陷入「过封窒息」。
  - **C（正确答案）**：四边完整稳合且保留约 20% 舒朗内庭留白，四枚隐约金角轻度向内指核，视线落定中央器物而不觉压抑。
  - **D**：保留极细外框，但两枚高亮装饰角标贴死在左下与右上对角边缘，把注意力生生拽向四角而非聚向中心。
- **正确答案理由**：封闭式构图必须同时满足「边界闭环不泄气」「导引向内不挂角」「框核之间留出呼吸余量」三件事；A 漏气、B 憋闷、D 挂角，只有 C 在围合与呼吸之间取得均衡。
