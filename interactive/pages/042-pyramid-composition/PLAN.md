# 042 金字塔构图 · PYRAMID COMPOSITION 互动页方案

## 1. 一句话道理
金字塔构图不是把元素塞进一个空心三角框，而是把信息按「基座 → 支撑 → 次要 → 顶点」自下而上逐层收窄、并配合「底重顶轻」的体量与明暗递进，让底层稳稳托住视觉重量，同时迫使视线沿阶梯斜坡自然攀升，最终汇聚到唯一的顶峰核心。

## 2. 开场玩具：筑塔叠层台 · 四级金字塔立体砌筑
- **怎么玩**：
  - 1:1 承袭 042 原海报暖沙宣纸底（`#F8EBD6`）、深绛红基座（`#501215`）→ 陶土红支撑层（`#82362B`）→ 砂岩赭次要层（`#B68B55`）→ 炽金顶点（`#B37612`）与七芒金日（`#BF8116`）的四级立体截锥石阶，以及右侧随斜边实时转向的「视线轨迹」折线箭头。
  - **拖任意单层石阶左右边缘把手**：独立调宽或收窄该层体量（18%–94%），实时改变阶梯收窄比、悬挑状态与视觉重心高度。
  - **在金字塔主体开放区左右横拖（`data-perf-drag`）**：连续调节整座金字塔的收束坡度（从倒扣悬挑 → 直筒平柱 → 经典金字塔 → 陡峻尖塔），联动右侧「视线轨迹」动态折射与底部四步构建图。
  - **点按任意两层（或点层上 ↑/↓ 按钮 / 键盘方向键）互换层级位序**：亲手把埋在中层的金色「顶点 / 重点」抬上塔尖、把悬在半空的深绛「基础层」压回底座，观察语义顺序与几何收敛如何协同。
  - **明暗重量开关（底重顶轻 / 明暗拉平 / 顶重底轻）与层间砌缝（贴合砌筑 / 微缝呼吸 / 断裂飘散）**：直接验证原海报底部设计提示「保持底部“重”、顶部“轻”，注意元素的大小、间距、色彩与明暗对比」。
  - **原海报五大应用场景直切**：`原海报`、`风景摄影`、`演讲演示`、`建筑与空间`、`团队与组织`，切换各层真实业务角色文案与图标。
- **开场初始状态（绝不先给答案）**：
  - 刻意停在 **0/4 错序悬挑 + 顶重底轻复合错态**：底层窄而浅（44%），三层向外悬挑（68%），顶层宽且深重（60%），金色「顶点 / 重点」被压在第 3 层而「基础层」悬在第 2 层，整体视觉重心上浮至 59%（头重脚轻），右侧视线轨迹在悬挑台阶处受阻折返。
- **怎样算玩错、读数怎么说「为什么」**：
  - `model.js` 从当帧实绘 4 块立体石阶的真实宽度数组、层序数组、有效明暗视觉重量与层间距单真源计算：底顶宽比、最大悬挑量、视觉重心高度（距底边 %）、外轮廓斜坡角，并实时驱动左侧 4 枚原海报圆徽（层级/稳定/聚焦/引导）与底部「构建步骤 ①→②→③→④」。
  - 覆盖 **8 类双向错态**：
    1. 悬挑倒扣（上层宽于下层）：视觉如倒立积木随时翻覆，已滑向 [043 倒三角构图](https://layout.xiaoxiaodong.ai/043/play/) 的险峻失衡；
    2. 顶重底轻（明暗重量倒置）：即使轮廓下宽上窄，深重顶块仍把视觉重心拉高，产生压迫感；
    3. 主次错位（顶点沉底或基础悬顶）：内容逻辑与空间收束方向打架，读者到塔尖找不到核心；
    4. 直筒平柱（底顶宽比 < 1.45× 或相邻层几乎等宽）：退化成矩形堆叠，视线竖直滑过无法向顶汇聚（对比 [046 矩形构图](https://layout.xiaoxiaodong.ai/046/play/)）；
    5. 针塔失稳（底基宽 < 50%）：底座过窄，支撑力不足，立面显晃；
    6. 扁坛瘫塌（顶层宽 > 44% 或坡度过缓）：顶面过宽导致焦点发散；
    7. 层次粘连（明暗拉平）：四层混成一块平面剪影，丧失逐级阶梯感；
    8. 断裂散架（层距过宽）：石阶断开飘浮，视线沿斜坡爬升时中途脱节。
  - 接受**原海报经典四级解**、**高耸纪念碑解**、**宽坛微缝解**以及任意满足几何与视觉重量稳态的手调方案；状态档位标注「示意」，不造假精确得分。
- **与最近 12 页（尤其紧邻 041）的明显差异**：
  - 紧邻的 041 是暖米×深松绿三列博物图谱、拖平面三角形三顶点与外置圆焦点；042 是**暖沙纸×深绛红×陶红×砂赭×炽金**的**四层立体石阶砌筑与换序工作台**，玩法围绕「逐层调宽、纵序换位、底重顶轻明暗重力与四步筑塔」，绝无任何同款套皮。

## 3. 版式骨架

## 7. 练习
- **题干**：为「古建营造特展」设计四级递进主视觉。四张草图的暖沙纸底、四级文案、总高度与顶峰日轮完全一致，**唯一变量是四层石阶的宽度递进与明暗重量排布**。
- **四个严格中性选项（无剧透形容词）**：
  - `方案 A`（宽度逐层收窄，但明暗倒置为顶深底浅 → 视觉重心上浮，头重脚轻）
  - `方案 B`（明暗底重顶轻，但第 2 层宽度向外凸出大于第 3 层 → 中层悬挑，攀升视线在半途受阻）
  - `方案 C`（**正解**：宽度 84% → 65% → 47% → 28% 逐级收窄，明暗深绛 → 陶红 → 砂赭 → 炽金底重顶轻，视觉重心稳落 36%，视线直贯顶峰）
  - `方案 D`（明暗顺序正确，但四层宽幅几乎拉平 68% → 64% → 60% → 56% → 近似方柱堆叠，顶部缺乏唯一聚焦）
