# 212 横排左起（LEFT-START HORIZONTAL LAYOUT）设计方案

## 1. 一句话道理
在自左向右的横向阅读中，读者每读完一行都要做一次长距离「换行回扫（Return Sweep）」去寻找下一行开头；把所有文字锚定在同一条垂直左起基准轴上，并控制合适的行宽与行距，眼睛就不必每行重新找落点，阅读路径最省力、最清晰。

## 2. 开场玩具：「左起校排轨 × 实测回扫仪」
- **怎么玩**：全宽钴蓝排字校样台（2D Canvas，标 `data-perf-drag`）直接呈现真实中英双语段落（支持切换「原海报文案 / 产品说明书 / 双语展签」三份标本）。
  - **直接横拖画布上的任意错位文字行**，把散乱起行的各行向左推齐到金黄色垂直「左起基准轴」（靠近 ±6px 自动轻吸附，也可向右拖出制造错位）；
  - **拖动画布右缘的金色行宽标尺**（或使用下方行宽滑杆）在 `10–44 字/行` 间连续改变栏宽，画布内文字实时逐字重排，并同步重绘从每行真实最右字到下一行真实最左字的**眼动回扫弧线**；
  - 切换对齐方式（散乱错起 / 左起齐左 / 居中排 / 右起齐右）、行距档位（紧 `1.15×` / 适中 `1.65×` / 过松 `2.55×`）及眼动轨迹显隐，顶部原海报同款「阅读动线」四阶箭轨同步亮灭。
- **开场初始状态**：停在原海报右侧「错误示例 POOR EXAMPLE」的复合错态——各行左起点散乱参差（左缘散差 > 70px），眼动回扫折线反复越界找行，顶部阅读动线停滞于第 1 阶段，绝不提前给出答案。
- **怎样算玩错、读数怎么说**：由 `model.js` 从实绘逐行文字外接框 `(x, y, w, h)` 单真源核算 7 类双向错态：
  1. 左缘参差散乱（`scatterPx > 6`）：读数指出具体最大偏离像素，说明每换行眼睛都要左右摸索起点；
  2. 多行居中排（`align === "center"`）：指出左缘随字数凹凸，回扫落点每行都在变；
  3. 右对齐长段（`align === "right"`）：指出把平齐边放在行尾而不是起读端，起读端反而呈锯齿；
  4. 单行过宽（`charsPerLine > 38`）：即使左对齐，回扫跨度过长容易串行或漏行；
  5. 行宽过窄（`charsPerLine < 13`）：刚读几个字就折行，节奏被频繁打断；
  6. 行距过挤（`leading < 1.30`）：上下行紧贴，回扫极易误落到邻行；
  7. 行距过松（`leading > 2.25`）：整段被拉散成孤立横条，失去段落整体感。
  同时接受多种合法解（窄栏速读解、原海报标准解、桌面宽栏精读解），读数用分档定性评价（绝不用假精确百分比）。
- **与最近 12 页的区别**：
  - 区别于 297（深蓝+电光黄绿、33:67 左诊单右四阶梯卡片换序）：212 采用原海报通栏四段式钴蓝标牌骨架（满幅顶眉+金色阅读动线箭轨+通栏开放排字校样画布+底沿横条诊单与校排轨），配色是纯正标牌钴蓝 `#002DA2` + 暖信号金黄 `#F6CA0C`（非黄绿），玩的是真实文字逐行对齐、实时重排与换行回扫，而非模块换序；
  - 区别于 211（淡青描图纸 68:32 断层劈网）、127（燕麦暖白 F 型眼动时间轴改稿）、252（深海蓝横向卷轴片窗）、294（暖灰 1px 字形微调放大镜）。

## 3. 版式骨架
- **1440×900 & 2560×1440**：忠实转译 212 原海报「通栏垂直四段钴蓝标牌」结构（零深色顶栏导航箱、零左右侧栏仪表盘、不锁 `100svh` 避平板空洞）。1440 主宽 `1380px`，2560 舒展至 `1680px`：顶沿左置自示范左起金轴巨标「横排左起」+ 右置金色圆形「阅读起点」活体锚徽与三标本切签 → 第二带通栏复刻原海报「阅读动线 READING FLOW」四阶金箭轨 → 第三带通栏全宽水平校排画布 → 第四带复刻原海报「应用建议 TIPS」黄块横条承载左单真源诊单 + 右精简校排控轨。正文七节在净白制图纸、冷蓝雾纸、03 深钴暗室、暖象牙纸、净白制图纸、06 深钴考场、07 浅蓝雾纸+深钴页脚间交替推进。
- **390×844（手机竖屏）**：压紧刊头为单行标题+紧凑起点徽+三切签，将总述移到画布之后，紧凑化动线带，让等比全宽排字校样画布稳占首屏 ≥ 46% 高度且同屏直见诊单首句；全部交互按钮点击区 ≥ 44px。
- **844×390（手机横屏）**：切为左 58% 排字画布 + 右 42% 紧凑刊头、切签与单真源诊单并行，一屏直玩直看。

## 4. 配色与字体
- **配色（实采自 `poster.webp`）**：
  - 标志标牌钴蓝：`#002DA2`（主底）/ `#083BBF`（亮面）/ `#061E68`（03 暗室）/ `#04164D`（06 考场与页脚）
  - 招牌暖金黄：`#F6CA0C` / `#FFDA14`（暗底高反差金线与实心徽；浅纸配深琥珀金 `#8A6500` 或深钴底金字保证对比度 ≥ 5.5:1）
  - 纯白与淡靛灰：`#FFFFFF`（暗底主字）、`#C5D1FA`（暗底次字）、`#8F9AE6`（错误示例弱化态）
  - 浅色阅读纸系：`#F6F8FE`（净白制图纸）、`#EBF0FC`（冷蓝雾纸）、`#FAF8F0`（暖象牙纸），配深钴墨字 `#0A1A4A` 与次墨 `#3A4A72`
  - 语义辅助：暗底警报珊瑚 `#FF7D66` / 浅纸深赤 `#B82A14` 标回扫错位；暗底亮青绿 `#5CE0B8` / 浅纸深松绿 `#0D6B50` 标回扫顺畅
- **字体搭配（全库唯一；三款辅助字体在最近 12 页全部 0 次使用）**：
  - `noto-sans-sc` (400–900 可变)：清晰现代无衬线中文主标题与正文（贴合 212 原海报理性现代黑体气质）
  - `outfit` (400–800 可变，近 12 页 0 次)：干净几何无衬线英文大标与 UI 标签
  - `dm-mono` (400 / 500，近 12 页 0 次)：柔和精准等宽数字、像素坐标与 CSS 属性
  - `eb-garamond` (400 / 600 正体 + 400 斜体，近 12 页 0 次)：独立英文小节副题与典籍排印引文点缀（绝不混入中文正文行内）

## 5. 节目录
- `01` **左起为什么省眼力**（10 字）：引出原海报 5 条核心要点，借 Inhoff & Liu (1998) 与 Rayner (1998) 知觉广度及回扫研究讲透原因；交互：**滑动阅读窗（Moving-Window）**实时体验「左 1 右 3 汉字 / 左 3–4 右 14–15 字母」的不对称预览窗。
- `02` **好坏一眼见分晓**（7 字）：忠实演绎原海报「正确示例 vs 错误示例」；交互：**横向透视拉帘 + 辅助线图层开关**（基准轴 / 回扫折线 / 悬挂标点框）逐像素透视微错位如何破坏秩序。
- `03` **汉字怎么变成横排的**（9 字）：梳理 1915《科学》、1917 钱玄同《新青年》、1955《光明日报》、1956《人民日报》到 2019 W3C CSS Writing Modes / CLREQ 的真实脉络；交互：**五时代版式标本时间轴**切换观察算式与横排演进。
- `04` **五类组件的左起规矩**（9 字）：展开原海报「应用建议」五类元素并温和修正「说多了一点」之处（表格数值列应右齐等宽、行首全角标点挤压、CSS `text-align: start` 逻辑属性）；交互：**五组件实操切换台 + 真属性对比开关**。
- `05` **什么时候别死守左起**（9 字）：讲清边界并一句话链接同小类 213–221 其他 9 页；交互：**四类反例场景翻转验真卡**（阿拉伯语、传统竖排、双行请柬、财报数表）。
- `06` **练一练：哪栏最好读？**（10 字）：单变量对照练习；交互：**四方案盲测点选 + 选后揭示全套左轴与回扫透视**。
- `07` **原海报与关键词**（7 字）：可放大拖动的 `poster.webp` 检视器 + 原海报四大关键词递进链与页脚。

## 7. 练习设计
- **题目**：同一段双语活动通知，在相同字号、配色与卡片尺寸下排成四个版本（中性标签 `方案 A / B / C / D`），选出最利于连续阅读的一栏。
- **单变量差异**：
  - `方案 A`：左对齐但单行拉宽至约 44 字 + 1.18× 紧行距（回扫跨度过大易串行）；
  - `方案 B`（正确答案）：左起对齐 + 约 24 字适中行宽 + 1.65× 行距 + 标题正文信息同轴；
  - `方案 C`：行宽与行距适中，仅将对齐改为居中（每行左起随字数锯齿跳动）；
  - `方案 D`：左起齐左、行宽与行距适中，仅将标题/正文/注脚拆成三档错开缩进（破坏共享左轴）。
- **选后反馈**：四卡同步叠出金色左轴与眼动回扫弧线，明确指出所选方案与最优解的单变量差距。
