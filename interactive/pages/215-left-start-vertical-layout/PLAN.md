# 215 · 直排左起（LEFT-START VERTICAL LAYOUT）互动页方案

## 1. 一句话道理
直排左起让单列沿重力自上而下阅读、列与列按现代左→右动线依次展开；只有当「列距明显大于字距（避免格式塔横串）」且「左端起点信号足够强（压住中文竖排默认右起的惯性）」时，视线才会顺着左起路径稳步向右推进。

## 2. 开场玩具
- **名称**：左起直排·纵横栅格与视线校准台（直接嵌在 215 原海报铬黄中轴舞台的 2D Canvas，标 `data-perf-drag`）。
- **怎么玩**：
  - 在画布开放区**左右横拖**（或拖红虚线列距卡尺）连续拉开/压窄五列竖排的**列距**；
  - 上下拖拽第 1 列旁的**字距卡尺**（或键盘 `↑/↓`）实时调节单列内的**字距**，亲眼看到格式塔临近性在「纵列成柱」与「横向串行」之间翻转；
  - 直接**点击画布顶部的红点起点锚（起点）或五枚编号圆标**，切换左起正序 `1→5` / 右起反序 `5←1` / 无起点提示，并可切换「首句加粗定锚 / 全列同重 / 右列过重倒吸」与「原海报五柱 / 展览墙年表 / 蒙汉左起书页」三套标本；
  - 点击「演练视线流」或按 `Space`，让朱红视线光珠按当前真实排版重演读者眼动（正常时逐列下行右跳，错态时直观暴露横向串读或从右倒读）。
- **开场初始状态（不是答案）**：停在 `0/5` 复合错态——列距被压得比字距还窄（实测列距 < 字距，横串红线当场穿行于五列之间）、起点红锚错落在右端且列序倒排为 `5←4←3←2←1`、首句加粗层级拉平。
- **怎样算玩错、错了读数怎么说**：支持 8 类双向失误——① 列距≤字距触发**横串读错**（报实测像素与 `列距/字距` 比，明示眼睛会横读第一行）；② 列距过大触发**孤柱断链**；③ 字距过挤触发**上下撞字**；④ 字距过散触发**单字漂浮**；⑤ 起点偏右或列序反排触发**逆向冲撞（误读成直排右起）**；⑥ 隐藏起点标与编号触发**缺起点引导**；⑦ 首句同重触发**无入口层级**；⑧ 右列抢重触发**右重倒吸**。同时接受「原海报经典解 / 紧致刊物解 / 疏朗展墙解」等多组合法参数区间。
- **读数单真源**：`model.js` 从画布实际绘制的每个字盒坐标算出真实像素级 `字距 / 列距 / 纵横比 / 视觉入口重心`，实时驱动黑底诊单条与右脊 5 枚原海报几何原则灯，不写死常量、不造假精确百分比。
- **与最近 12 页的区别**：
  - 不同于 214（夜墨紫底、右锚、拖拽五条竹简排序）：215 忠实取自铬黄×朱红×墨黑左锚海报，核心操作是**纵横二维字距/列距格式塔临界校准 + 左端起点信号压制右起惯性**，并非排序玩具；
  - 不同于 299（明黄瑞士网格、容器拉宽+卡片 SPAN 装箱）：215 为左翼巨幅竖标 + 左下朱红四分之一大圆弧 + 中轴五柱直排舞台 + 右脊五枚红黑几何原则卡 + 通栏黑底适用场景条，并带有醒目信号朱红起点体系。

## 3. 版式骨架
- **1440×900（主宽 1380px，2560 舒展至 1680px，绝不锁 `100svh` 避平板空洞）**：完整转译 215 原海报三栏左锚结构——左 22%（左上朱红起点圆+细红垂线+巨幅竖排大标「直排左起」+ 竖向英文 `LEFT-START VERTICAL LAYOUT` + 总述 + 左下角出血朱红四分之一圆弧）| 中 56%（`排版示例 EXAMPLE` + 三标本切签 + 2D 纵横校准画布 + `◎起点 →→→→ ●终点` 实时阅读路径条 + 原海报同款实黑底黄字单真源诊单与精控条）| 右 22%（1px 黑竖线分隔的原海报五枚核心原则几何图标实况灯）→ 底部通栏黑底黄字「适用场景」与 2×7 黄点阵。

- **390×844 手机竖屏**：压缩单行铬黄刊头（`NO.215` + 红圆 + `直排左起` + 状态签），说明与五原则后置，让等比 2D 校准画布稳占首屏 ≥ 46% 屏高，折线内同时直见黑底诊单首句与主操作钮。
- **844×390 手机横屏**：左 56% 校准画布 × 右 44% 紧凑刊头、黑底诊单与主控并排。

## 7. 小练习设计
- **题干**：某美术馆自左向右延伸的展墙导览牌采用「直排左起」，四版文案、左端红点起点与 `1→4` 编号完全相同，仅改变**列距与字距配比**。哪一版最不容易串行、读起来最顺？
- **四选项（中性标签 方案 A / B / C / D，单变量仅差纵横间距比）**：
  - 方案 A：列距小于字距（横串成行，视线滑向横向）
  - 方案 B：列距与字距近乎等宽（棋盘方阵，纵横引力拉锯）
  - **方案 C（正解）**：字距紧凑、列距约为字距 2 倍（纵列凝聚成柱、列间留呼吸通道，顺着红点自左向右推进）
  - 方案 D：列距拉得极宽（四列撕裂成孤岛，扫读换行跨度过大导致语义断链）
