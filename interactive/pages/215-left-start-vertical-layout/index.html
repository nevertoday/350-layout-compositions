01

为什么先竖后右

DUAL-AXIS FLOW & FOUR-WAY COMPASS

单列内顺着重力往下读，列与列之间顺着现代阅读惯性往右推——这就是「直排左起」在东亚与现代版面之间搭起的一座桥。

文字排版其实由两条轴决定：行内方向（每个字排成一行或一列的方向）与行间推进方向（读完一行/列后，下一行/列往哪边长）。绝大多数中文书刊用横排左起或直排右起，而直排左起把「纵落」的仪式感与「左→右」的现代空间秩序拼在了一起。

这也是它最容易翻车的地方：只要列距不够宽、或者版面左侧没立住清晰的起点标志，眼睛就会在「向下读」和「向右扫」之间打架，甚至因为中文竖排的千年惯性，直接跳到右上角倒着读起来。

同小类另外三种基础流向各有专页：212 横排左起、213 横排右起与214 直排右起，此处只做方位对照，不重复展开。

02

从草原卷轴到 CSS

ORIGINS: 1204 TO W3C VERTICAL-LR
几何溯源实验 · 90° 逆时针旋转 90°（直排左起）

直排左起并不是设计师拍脑袋发明的叛逆版式，它在世界文字史上已经稳稳活了八百多年。

  1. 约 1204

    回鹘式蒙古文（胡都木文）

    成吉思汗在征讨乃蛮部后，命畏兀儿学者塔塔统阿（Tata-tonga）以古回鹘字母记录蒙古语。古回鹘字母源自自右向左横写的粟特字母；它在受东亚竖写影响而逆时针旋转 90° 后，原本「从上往下换行」的顺序在几何上自然变成了「从左往右换列」，成为传统蒙古文独树一帜的直排左起行款。

  2. 1269

    八思巴字（蒙古新字）

    元世祖忽必烈命吐蕃国师八思巴创制用以统拼多语种的方形字母，并于 1269 年颁行。八思巴字虽脱胎于横排左起的藏文字母，行款却沿袭传统蒙古文，采用自上而下、由左向右的直排左起，常见于元代圣旨、碑刻、牌符与纸币。

  3. 1599

    满文（无圈点老满文）

    努尔哈赤命额尔德尼与噶盖借传统蒙古文字母创制满文，同样自左向右直排。清代大量满汉合璧诏书与典籍由此诞生了奇特的双轨页式：满文从左侧向右直排，汉文从右侧向左直排，两种竖排在版面中缝相向汇合。

  4. 1999 & 2019

    Unicode 3.0 与 W3C CSS Writing Modes Level 3

    1999 年 9 月发布的 Unicode 3.0 正式收录蒙古文区块（U+1800–U+18AF，涵盖传统蒙古文、托忒文、满文与锡伯文）；2006 年 Unicode 5.0 收录八思巴字区块（U+A840–U+A87F）。2019 年 12 月 10 日，W3C 将《CSS Writing Modes Level 3》确立为正式推荐标准，以 writing-mode: vertical-lr 规范了网页端的直排左起，并由国际工作组持续维护《蒙古文排版需求》（MLREQ）与《中文排版需求》（CLREQ）。

03

节奏与防串行

SPACING RATIO & NATIVE CSS LIGHTBOX

直排左起能不能顺畅读下去，靠的不是把字竖起来，而是同时管好两件事：列距与字距的反差，以及不可错认的左起信号。

经验上，直排多列正文若希望一眼成柱而不横向串行，列距（两列字盒之间的空白）至少应达到竖向字距的 1.6 倍以上（经验值；CSS 里常见组合为 line-height: 1.75–2.2 配合 letter-spacing: 0.06em–0.18em）。再宽于 2.2 倍字宽的列缝，则会把关联段落割裂成互不往来的孤岛。

一旦直排里混入横排标题、两位数字、拉丁单词或注音，还涉及另外几套专门规则——请见同小类专页：216 横直混排、217 纵中横排、218 直排中西文转向、219 直排中西文直立、220 双向文字排版与221 旁注（Ruby）排版。

起点在左 · 拖选下方文字可直测真实阅读序

一、先立起点：浏览器原生的 vertical-lr 会把第一列钉在容器最左侧，后续新列自动向右生长。

二、顺势右推：用鼠标在框内拖选文字，选区高亮的推进方向就是真实的阅读顺序。

三、中西混排：留意 W3C CSS 2019 这串字母与年份在不同 text-orientation 下的朝向变化。

04

真实落地与边界

REAL CONTEXTS & HONEST CALIBRATION
说多了一点 原海报写着：「适用场景：书籍内页 / 报刊杂志 / 宣传册 / 海报 / 长文排版」

这句话对传统蒙古文、满文的书籍与报刊完全准确——对这些文字而言，直排左起本就是天经地义的长文版式。但放回中文环境就要分开说：超过十列的中文小说或报纸长文，读者根深蒂固的直排习惯仍是右起（见 214 直排右起），或直接用现代横排（见 212 横排左起）。中文里的直排左起，最出彩的是短到中等篇幅、且物理动线本就自左向右的场景。
