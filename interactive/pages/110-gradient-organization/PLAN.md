# 110 渐变组织（GRADIENT ORGANIZATION）互动页方案

## 1. 一句话道理
把原本彼此孤立的视觉元素按可预测的连续级差（大小、明透、色相、形态、疏密）逐步推演，人眼就会自动把离散图形连成一条由远及近、由轻入重的坡面，在平面上生出自然的过渡、层次与明确的方向感。

## 2. 开场玩具：活体梯度坡面与流向罗盘台
- **玩法**：直接化用 110 原海报的「8 排斜向渐进几何阵 + 右上黑圆白箭罗盘 + 右下导向白箭」。
  - 在 2D Canvas 霞光渐变坡面上直接拖拽「起点轻端锚（○）」与「终点重端锚（◉）」改写渐变轴方向与跨度（支持方向键微调）；
  - 直接左右拖拽嵌入画布底沿的「渐进变化率弧点」（`data-perf-drag`），实时弯折尺寸与间距推进曲线（从头重断崖 ↔ 均匀指数带 ↔ 尾端爆冲）；
  - 直接点击画布中带警示虚环的逆序错阶把它理顺，并可切换步阶数（3–14 阶）、尺寸纵深跨比（1.1×–9.0×）、色彩插值空间（sRGB 灰泥 / Oklab 透亮 / 补色对撞）与几何编排（原海报全几何阵 / 圆径纵深阵 / 形变演进阵）。
- **开场状态（0/4 翻车错态）**：3 阶生硬台阶且第 2 阶顺序倒挂、尺寸跨比仅 1.10× 且透明度齐平无纵深、渐变轴跨距过短且方向压平、色域走 sRGB 在丁香紫与炽橙之间生出灰泥带。
- **怎么算玩错与读数说明**：全部坐标、步阶碰撞、尺寸跨比、轴向跨距与 Oklab 彩度留存均由 `model.js` 单真源实算，可诊出逆序折返、断层硬切（≤4 阶）、过密粘连（≥11 阶或重叠 >12%）、头重断崖 / 尾端爆冲（变化率指数失衡）、平权扁平（跨比 <2.0×）、起点隐身（跨比 >6.5×）、跨距受挤/贴边溢出、中段灰泥/色振发抖 8 类失误；读数不只报数，始终解释「为什么人眼会卡顿或发灰」并给出下一步操作建议。
- **与最近 12 页的差异**：最近 12 页里没有一页采用「左 23% 暖米白竖排书脊 × 右 77% 全出血紫粉橘斜向霞光坡面」的非对称画册双联骨架，也没有直拖起止梯度轴锚 + 变化率幂曲线折弯 + sRGB/Oklab 实时色域插值的核心交互。

## 3. 版式骨架
- **1440×900（2560 扩宽至 1840px）**：34px 极细暖米顶眉下，无锁 `100svh`；左 23% 暖米纸书脊竖排「渐/变/组/织」示范大标（四字自上而下呈可读色温微渐变 + 旁置四枚同步渐变阶标）、细线、英文副标、原海报四枚紫→粉→橘→金渐变短杠实时指标与 6×4 丁香紫点阵；右 77% 全出血紫粉橘霞光坡面，右上浮原海报同款黑圆白箭实时罗盘与总述，中铺大幅活体几何坡面 Canvas 与一体底沿变化率弧轨，底承浅暖米实底白话诊单与精简两行控钮，左右双栏等高齐底。
- **1024×1366 / 768×1024 平板**：顶书脊收为横排刊头与四列色杠指标带，下方全宽 16:10 霞光坡面与双列诊单控钮，无大段空洞。
- **390×844 手机竖屏**：极紧单行刊头让等比 4:3 渐变坡面与 44px 变化率拖轨直落首屏（占屏高 ≥46%），同屏可见白话快诊与核心切换；图形始终按实际像素等比绘制，绝不压扁成椭圆。
- **844×390 手机横屏**：左 56% 渐变坡面与底沿拖轨 × 右 44% 紧凑刊头、白话诊单与主控并行。

## 4. 配色和字体
- **配色（逐像素采自 110 原海报）**：暖米书脊 `#F6EFE3`（浅宣 `#FAF6EE`、淡紫雾 `#F3EEF9`、暖杏纸 `#F6EBDC`）；霞光渐轴 浅丁香 `#D0B1EE` → 玫瑰粉 `#EBCBE4` → 蜜桃 `#FE9162` → 暖杏金 `#FDCE87`；元素主色 紫 `#9B72CF`（可读深紫 `#56308F`）、玫粉 `#E97C93`（可读深莓 `#A6264E`）、炽橘 `#F55B1E`（可读深橘 `#B53408`）、暖金 `#EEAC4A`（可读深赭 `#855300`）；主墨 `#141218`；03 与 06 节用深暮茄紫 `#1B1326` 暗版拉开正文节奏；校准达标色 `#116A58`（暗底 `#6EE0C5`）。
- **字体搭配**：`Noto Sans SC` + `Fraunces`（正斜体，SOFT=60）+ `IBM Plex Sans` + `Space Mono`。全库唯一，且 `Fraunces`、`IBM Plex Sans`、`Space Mono` 三款西文在最近 12 页全部 0 次使用。

## 5. 节目录（共 8 节，标题均 ≤ 12 字，相邻节交互各异）
- **01 渐变不是拉一条背景色**：拆解六大渐变维度（王无邪体系）；交互为「六维梯度叠层实验室」（6 枚维度复选叠层 + 过载失控警示）。
- **02 为什么渐变自带空间感**：讲透 Gibson 纹理梯度与近等比步进；交互为「平面折成纵深斜坡画板」（倾角/步进模式实时透视投影 + 纯平面网格验真开关）。
- **03 同样两色，为何有的脏灰**（深暮紫暗节）：剖析 sRGB 灰泥坑与 Oklab 感知均匀插值；交互为「光谱解剖台」（点选配色对 + 点击中间阶梯取样放大 + 实时 L/C 剖面图）。
- **04 画面从哪来，就往哪流**：对比线性斜向、中心放射、双向对冲与形态演进，并一句话串联同小类 107/108/109/111/112/113/114；交互为「四类拓扑路径与视线光珠模拟」。
- **05 它从哪来：从木刻到欧普**：核实史料编年（Escher 1939–40 / Gibson 1950 / Albers 1963 / Vasarely 1969 / Wucius Wong 1972 / Ottosson 2020）；交互为「脉络主题筛选器」。
- **06 什么时候用，什么时候别用**（深暮紫暗节）：温和校正滥用误区 + 4 宜 4 忌；交互为「4 场景实战体检对照机」（左右同框比对 + 实时 WCAG 正文对比度读数）。
- **07 眼力小练习**：单变量 4 选 1 盲测（只标方案 A/B/C/D）；交互为「4 枚实时绘图选项卡 + 选中逐项解析」。
- **08 原海报与关键词**：原海报灯箱（可缩放拖动、Esc 关闭）+ 四枚渐变短杠关键词卡片 + 规范页脚。

## 7. 练习
- **题目**：同一段由丁香紫向炽橙推进的 7 阶圆阵（起止颜色、最小与最大半径、间距跨度全部锁定），哪一条在视觉上过渡最匀速自然？
- **四个选项（单变量：仅改变 7 阶尺寸步进曲线，标签仅写方案 A / B / C / D）**：
  - 方案 A：线性等差（$p = 1.00$，前段跃升显陡、后段偏平）
  - 方案 B：尾端陡爆（$p = 2.85$，前 4 阶近乎缩平、末 2 阶猛涨撞挤）
  - 方案 C：近等比指数（$p = 1.48$，相对倍率均匀递增，目视步幅最流畅）— **正确答案**
  - 方案 D：中段平台（第 3–5 阶尺寸停滞相同，过渡在半路卡顿）
