# 339 比较幻灯片版式（COMPARISON LAYOUT）设计方案

## 1. 一句话道理
比较幻灯片版式通过中央「比较轴」将两套并列方案锁定在同一水平基准线上，用「形色双码」瞬间区分差异阵营、以水平「视线匹配」让观众逐项对读可对齐差异，最后用通栏「共性」底带托出共同前提，把口头拉扯变成一眼可判的决策界面。

## 2. 开场玩具
- **名称**：双案对读·比较轴与维度配对放映台（Comparison Axis & Row-Pairing Slide Bench，开放 2D Canvas，标 `data-perf-drag`）。
- **怎么玩**：
  - **直接上下拖行卡换序配对**：抓住右侧（或左侧）任意对比行卡上下拖移，把错序的维度拉回与对岸正对的水平位置（靠近目标行槽轻吸附），原本交叉打结的红色斜线即时拉直成穿过黑圆节点的水平虚线 `────●────`。
  - **直接横拖画布 / 轴距调节**：在画布上左右拖动，连续调节两列围绕中央比较轴的**眼动耦合跨度（对读跳距）**，既防推到两边形成视线断谷，又防挤撞中轴压文字。
  - **直点交互**：点顶部方案标牌或蓝圆/绿方切换阵营双码（同码混糊 / 蓝圆×绿方 / 蓝圆×墨框 / 弱灰×主推绿 / 双红互搏）；点中缝切换比较轴形态（无轴 / 细黑轴+圆节点 / 粗黑隔墙）；点底沿切换共性带位置（缺失 / 通栏鼠尾草共性带 / 塞入右栏偏袒）；支持「原海报·效率与质量」「产品选型·自研与采购」「教学复盘·迭代前后」三套演讲剧本。
  - **键盘与视线演播**：方向键 `←/→` 微调眼动跨度、`↑/↓` 校准行齐平 ΔY、`Tab`/`Enter` 切换选项、**空格键**发射水平视线脉冲逐行检验 `A1 → ● → B1 → ↓ → A2 → ● → B2 → ↓ → A3 → ● → B3 → 共性带`（错序或断轴处当场显出折返绕路的距离与撞断警示）。
- **一打开的状态（绝不先给答案）**：开场刻意停在 `0/4` 复合错态——右栏 3 条维度顺序错位（`[2, 0, 1]`）叠加 `+22px` 纵向错牙导致虚线交叉 2 处；双阵营退化为同色同形灰方（失码）；中央比较轴隐藏且两栏贴边拉出 `54%` 宽的视线断谷；底部共性带缺失。
- **怎样算玩错 & 双向错态核算**：由 `model.js` 单真源几何引擎从实绘矩形框、实测跳距 px、虚线交点数、行差 ΔY 与阵营编码同步算出 9 类双向错态（维度交叉、行基线错牙、跨度过宽断谷、跨度过窄撞轴、双阵营同码混糊、双红互搏告警过载、无比较轴失轨、粗黑隔墙割裂、共性缺失或塞进右栏偏袒）。认可原海报经典解、高对比色盲友好解（蓝实心圆×墨描边方）、主推决断解（弱灰旧案×翠绿主推）多组合法解。
- **读数说什么「为什么」**：每条诊断不只报数字，还直接解释观众在投影前为什么扫丢、为什么把两栏看成鸡同鸭讲，并给出可立即动手的下一步动作。
- **与最近 12 页的明显区隔**：
  - 紧邻的 **338 两项内容** 玩的是「左右宽比 66:34 推拉 + 顶齐 ΔY + 卡片明暗配重天平」（柔粉宣纸×波尔多酒红）；**339** 始终保持 A/B 等宽对等，核心动作是**跨比较轴逐行维度换序配对 + 水平眼动跳距耦合 + 蓝圆/绿方形色双码 + 底部通栏共性带收敛**，与 338 及 259（纯黑/酸绿分屏比例）、172（6 列网格拼版）等玩法完全不同且不可移植。

## 3. 版式骨架
忠实转译 339 原海报「暖羊皮宣纸瑞士海报版面」骨架（绝不用通用深灰顶栏，绝不锁 `100svh` 避平板大空白）：
- **1440×900（宽屏，2560 舒展至 1640px）**：
  - 顶带左 72%（钴蓝 `NO. 339` 标签 + 实时状态章 + 自示范带微蓝圆/绿方对标徽记的粗黑大标 `比较幻灯片版式` + `COMPARISON LAYOUT` + 原海报总述与三剧本切换）× 右 28%（1:1 复刻原海报右上四行图例键：`差异 / 共性 / 比较轴 / 视线匹配` 活体实时探针）。
  - 中段全宽开放式 2D 比较幻灯片画布（直出原海报蓝/绿双条 + 黑圆 `VS` + 蓝圆/绿方 + 三行虚线匹配轴 + 底部鼠尾草共性带）。
  - 下段 1:1 复刻原海报底部的 `1.5px` 纯黑双室线框盒（左 50% 带眼睛虚箭图标的单真源白话诊单与实测四数 × 右 50% 带天平图标的比较轴精控台与多解/反向试错按钮，两栏严丝齐底）。
  - 底部原海报双横线居中宣言 `清晰对比 • 突出重点 • 支持决策`。
- **1024×1366 / 768×1024（平板）**：自然流排零空白；顶带 768 下折为单列 + 2×2 紧凑图例探针；全宽等比画布；黑框双室盒在 1024 保持双列齐底、768 自然堆叠。
- **390×844（手机竖屏）**：压紧单行刊头（`NO. 339` + 状态 + 演练键 + 大标 + 剧本切签），将总述与四行图例后置；画布自动切换为竖屏友好的紧凑等比排布（保持蓝圆 1:1 正圆、文字清晰），稳占首屏 ≥47% 高度，且折线内直露黑框左室的单真源白话诊单首句与一键校准按钮。
- **844×390（手机横屏）**：切为左 56% 等比画布 × 右 44% 紧凑刊头+实况诊单与一键校准并行排布，无横向溢出。

## 5. 节目录（7 节，H2 均 ≤ 12 字，相邻节控件不重样）
- **01 `先对齐，差异才看得见`**（亮宣白）：讲透为什么并列对齐能瞬间揭示差异与共性（结构对齐与空间邻近原理）；交互：**三模式眼动回溯计时对比台**（翻页串联 vs 错行并列 vs 同轴齐平，点选决策问题即时动画实测视线跳数与折返路程）。
- **02 `四根骨架撑起一页对比`**（浅鼠尾草雾）：逐条展开原海报四要素（差异、共性、比较轴、视线匹配）与两句原话用法，温和补充对称权重与色盲双编码边界；交互：**四层骨架 X 光叠片开关**（逐层剥离蓝圆绿方/比较轴/虚线匹配/共性带，直观看到缺一层怎样塌架）。
- **03 `从双栏表到母版标准`**（深墨松青暗室）：核实的演进史（Tufte 1990 → Palmer 1992 → Gentner & Markman 1994/1997 → ECMA-376 `twoTxTwoObj` 2006 / ISO 29500 2008 / Duarte《slide:ology》2008）+ 同小类 335–343 一句话分界链接；交互：**年代里程碑展开轨 × `338 twoObj` 与 `339 twoTxTwoObj` 线框结构实时对比切换**。
- **04 `什么场景该用，别硬套`**（暖羊皮纸）：四类高胜率场景 + 四类「什么时候别用」及改用指引；交互：**场景分诊滑块工作台**（调对象数 2–5、维度数 2–8、逻辑关系 对照/并列/时序/趋势，实时输出是否该用 339 与替代版式线框）。
- **05 `四类常见翻车怎么救`**（浅钴蓝雾）：鸡同鸭讲、只踩不托、唯色辨别、字墙拉斜四大真实病历；交互：**可拖动前后拉帘对比 + 一键灰度/投影褪色模拟开关**。
- **06 `实战挑错：哪一页能直接上台`**（深墨松青考场）：四张同字同色同边距、仅差一个空间变量的幻灯片草图小练习（中性选项 A/B/C/D，即时解析）。
- **07 `原海报与关键词档案`**（暖羊皮原纸）：原海报点击缩放平移灯箱（`draggable="false"`）+ 四大关键词图标卡 + 标准 CC BY 4.0 页脚。

## 7. 练习
- **题干**：向评审团队呈现「离线批处理 vs 实时流计算」决策页，每侧 3 项维度，底部交代共同目标。四张草图字数、字号、配色、页边距完全一致，仅改变一项版面结构变量，选出最符合比较幻灯片版式原则的一页。
- **四个中性选项（只差一个变量）**：
  - `A · 构图甲`：双阵营蓝圆/绿方对称、有中轴与底部共性带，但右栏 3 条维度顺序错位，水平虚线呈斜向交叉。
  - `B · 构图乙`（正确答案）：双阵营蓝圆/绿方对称、中央细黑 VS 比较轴串起 3 个黑圆节点、3 组同维度严格水平齐平且虚线直连、底部通栏鼠尾草共性带承接双方。
  - `C · 构图丙`：同维齐平且有共性带，但撤去中央比较轴并将两栏推向左右外缘，形成宽阔中缝断谷。
  - `D · 构图丁`：同维齐平且有中轴，但删去底部通栏共性带，把共同目标并入右栏底部。
- **正确答案理由**：`B · 构图乙` 同时守住形色双码区分（差异）、同维度水平直连（视线匹配）、中央导读轨道（比较轴）和通栏共同基线（共性），让观众沿中轴逐行横扫即可完成对比与决策。
