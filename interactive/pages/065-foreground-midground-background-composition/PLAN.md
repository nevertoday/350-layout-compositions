# 065 前中后景构图 — 互动页面方案

## 1. 一句话道理
平面画布本身没有厚度，大脑靠**前后遮挡、近大远小、对比由强到弱的逐层衰减**来估算距离；把画面分成前景（着陆入口）、中景（叙事主体）与背景（空间远端）三片景深层次，视线就能从近处自然步入深处，平纸立刻生出可走进去的三维秩序。

## 2. 开场玩具：活体多平面景片盒 · 三层纵深取景台
- **玩法（独特且贴合 065 本身的物理动作）**：
  - 主舞台是一个真 3D 多平面玻璃景片盒（Three.js WebGL，禁用 WebGL 时由共用 `model.js` 与 `artwork.js` 的 2D 透视景片画布无缝接管），1:1 化用 065 原海报的深松绿叶丛（前景）、钢青蓝丘陵小径小屋与圆树（中景）、雾灰蓝远山与浅金日轮（背景），支持在「原海报山居 / 林径孤舟 / 街巷灯影」三套场景间切换。
  - **直接横向拖拽主舞台画布（`data-perf-drag`）**（或按 `←` / `→` 键）：把机位从 `0° 正视成品` 平滑甩到 `±42° 侧斜 3D 拆层视角`，像站在迪士尼多平面摄影机旁亲眼看见三片玻璃景片在 Z 轴上的真实间距、重叠遮挡与视线穿透顺序；点「推演视线 1→2→3」会沿 `前景 → 中景 → 背景` 射出一道浅金视线轨迹。
  - **原海报三道标志性通栏实色带本身就是调控台**：深松绿「前景 LAYER 1」带调前景覆盖占比与让路排布（居中堵门 / 单侧压角 / 双侧让路）、钢青蓝「中景 LAYER 2」带调三层 Z 轴间距与焦点落位（全层平权 / 焦落中景 / 焦落前景 / 焦落背景）、雾灰蓝「背景 LAYER 3」带调远景空气退让（对比衰减）。
- **开场初始状态（0/4 翻车错态，绝不先给答案）**：
  - 开场进入时故意停在 0/4 扁平堵路错态：前景占比 48% 且居中堵门（实测遮住中景主体约 60%+）、三层 Z 轴间距压到 0.06（贴扁如同一张纸）、远景空气退让仅 12%（远山画得又黑又硬反抢前景）、焦点停在「全层平权」导致无主次入口。开场 0.9s 缓动从 `22°` 侧斜玻璃盒轻轻回摆至 `12°` 微斜角，既一秒展示 3D 多平面身份，又把四处错态摊开在眼前。
- **怎样算玩错 & 读数如何解释「为什么」**：
  - `model.js` 单一真源直接按实绘前景多边形面积算「前景占比」、按像素采样算「中景主体遮挡率」、按三层实绘色值算对天空底色的真实相对亮度对比度（`前 : 中 : 后`），实时诊出 **8 类失误**：①前景堵路遮主、②缺前景着陆点（拉到 <9% 变成无前景平贴）、③三层贴扁零纵深（Z 距 <0.30）、④纵深过散断层（Z 距 >1.28 失去中景衔接）、⑤背景深硬反抢戏（对比倒挂或过近）、⑥背景发白消失（与天空对比 <1.18:1 退化成两层）、⑦全层平权无主、⑧焦落模糊背景落空。
  - 支持多组正当解：只要前景占比落在经验带 11%–32% 且主体遮挡 ≤22%（单侧压角或双侧让路皆可）、Z 间距 0.45–1.20、对比呈明确递减阶梯（空气退让 38%–84%）、焦点明确落在「中景主角」或「前景入口」，即通过 4/4，并在白话诊单里区分说明两种聚焦路径的观感差异。
- **与最近 12 页的明显区别**：
  - 最近 12 页（064/315/232/026/148/276/193/063/231/275/108/147）全是 2D 画布或纯 DOM 平面排布，没有一页是 Three.js 3D 多平面玻璃景片拆层；也完全避开「拖把手挪主体 + 右侧参数列」套路，而是用**全宽全景 3D 拆层 + 原海报三道通栏实色景片带直控**。

## 3. 版式骨架
忠实承袭 065 原海报「**暖米宣纸全景天窗 → 紧接三道通栏实色层带（深松绿 / 钢青蓝 / 雾灰蓝）→ 底沿浅麻纸诊单与四项线性徽标 + 斜纹底边**」的纵向三明治全景骨架（不锁 `100svh`，绝不在 1024×1366 竖平板留空洞）：
- **1440×900 桌面（内容宽 1360px；2560×1440 舒展至 1820px）**：32px 细线顶眉 → 紧凑暖米纸刊头（左三色纵深示范大标「前中后景构图」+ 英文副标与总述，右 6×3 松绿点阵 + 场景与视角切签）→ 全宽 3D 多平面全景舞台（高约 350–380px，底沿嵌简洁的 `0° 正视 ↔ ±42° 3D 拆层` 视角提示条）→ 紧贴无缝衔接的三道通栏实色调控带（深松绿前景带、钢青蓝中景带、雾灰蓝背景带，左保留原海报米白圆形图标与 3/2/1 点阵权重，右为本层唯一物理控参）→ 浅麻纸单真源白话诊单与原海报 4 枚线性关键词徽（深度/层次/距离/焦点）+ 左斜纹右松绿收脚带。首屏完整呈现舞台、三层控带与诊单。
- **390×844 手机竖屏**：极紧单行刊头（压缩总述到舞台下方说明或精简为一行），让等比 3D 全景舞台稳占首屏 ≥45% 屏高（约 385px），紧接一行白话快诊与三色紧凑景片控带，圆徽与画布严格等比绝不压扁。
- **844×390 手机横屏**：切为左 55% 满高 3D 多平面舞台 × 右 45% 紧凑三色层带与白话诊单并行，一屏可控。
- **正文 7 节节奏**：在洁净浅宣纸 `#FAF5EC`、暖米原纸 `#F4E7D3`、浅麻雾纸 `#ECEEE6` 与 `03` 节深松林暗室 `#0C2E23` 之间交替推进。

## 5. 节目录
1. `01` **三层各自干什么**（`THREE DEPTH PLANES`）：原话拆解海报前景/中景/背景与构图要点，温和修正「在前景设置焦点」的「说多了一点」；交互为**剥洋葱逐层开关透视台**（独立开关前景/中景/背景，实时看缺任一层如何坍塌）。
2. `02` **遮挡、虚实与对比梯子**（`CONTRAST & ATMOSPHERE`）：讲清遮挡、对比递减、空气透视与光学景深如何联手让平面长出纵深；交互为**光圈景深与点击移焦光学台**（切换 f/2.0 浅景深 / f/8 平衡 / f/22 深焦、三套天光雾气，直接点击画中前/中/后景移焦，看实时明暗对比柱状读数）。
3. `03` **从三色风景到多平面镜头**（`ORIGIN & LINEAGE`，深松暗室节）：追溯达·芬奇空气透视、帕蒂尼尔三色世界风景、克劳德·洛兰推远法、1937 迪士尼多平面摄影机与 1941《公民凯恩》深焦调度；交互为**历史四幕空间机制切板**（2D 示意画布动态演示四代纵深机制）。
4. `04` **真实场景怎么用**（`WHERE IT WORKS`）：覆盖旅拍海报、叙事分镜、横版游戏与网页首屏，并用一句话链接同类其他 11 页（066–076）；交互为**机位横移视差滑轨**（在三套真实应用模板里左右推机位，支持开关视差锁死对比差异）。
5. `05` **什么时候别用**（`WHEN NOT TO USE`）：拆解电商白底图、工程轴测图、极简图标与生硬「伪前景」四类反例；交互为**伪前景剥离对比诊所**（切换三类典型翻车案例并一键剥离多余前景前后对照）。
6. `06` **小练习：挑出纵深最立得住的一幅**（`QUICK CHECK`）：严格单变量控制练习，四幅图只差「三层明暗对比与空气退让」一个变量，配第二题（前景占比单变量）可选进阶。

## 7. 练习设计
- **主练题（唯一变量：三层对比度与远景空气退让）**：四幅山谷步道指南封面草图具有完全一致的构图位置、18% 前景占比与画幅，标签只写中性「方案 A / B / C / D」：
  - **方案 A**：前、中、后三层保持相近的高对比深重色调（对比平权，远山往前扑）。
  - **方案 B（正确）**：前景沉实高对比、中景清晰中调突显小屋主角、背景按空气透视柔和退远（对比由强到弱递减，秩序清晰）。
  - **方案 C**：前景偏淡灰、背景远山压得最深最重（对比前后倒挂，远景喧宾夺主）。
  - **方案 D**：前景与中景清晰，但背景淡化到几乎融进天空底色（第三层消失，退化为两层）。
- **进阶题（唯一变量：前景占比与开合位置）**：同样对比阶梯下，比较无前景（0%）、居中堵主（46%）、双侧让路适中（19%，正确）与四周全框挤死（62%）。
