# 322 一河两岸式构图（RIVERBANK COMPOSITION）互动页方案

## 1. 一句话道理
以一条有曲直收束的中心「河道」把画面自然分开，让左右两岸在体量、高低、疏密与浓淡上异形呼应、近实远虚，眼睛既不会在画面正中被硬物挡死，也不会在无序满铺里迷失，而是顺着水脉由近及远流动、在两岸间从容往返。

## 2. 开场玩具（活体「拨水理岸」画卷台）
- **玩法**：忠于 322 原海报的「左岸 — 中心河道 — 右岸」结构。
  1. **横拖活河（`data-perf-drag` 直接标在主画布 `#hero-canvas`）**：手指或鼠标在河道上左右拖动，实时改变河脉 S 形弯度与开合流势；按键盘 `← / →` 微调弯度、`↑ / ↓` 调整河道宽窄。
  2. **直点移障与置岸配景**：点击河心错置的「堵心阁」即可把它移去左岸或右岸还水于中；点击画布上左右两岸共 6 处岸位（远 / 中 / 近），或用两侧与原海报同源的「左岸元素 / 右岸元素」竖列按钮，自由增减/替换山体、古树、亭阁、扁舟（无五官剪影）或留白。
  3. **虚实递进与三母题切换**：调节近实远虚雾阶与河道宽幅；可在「原海报水墨江岸 / 城河夜航航拍 / 双栏对比画册」三套母题间切换，验证「河流」既可以是真水系，也可以是城市河道或版面留白中缝。
- **开场初始态（非答案）**：刻意停在未理顺的错态——河道笔直僵硬（弯度 0%、上下几乎同宽）、一座重阁硬塞在河心堵住水流、左岸挤满三处重景而右岸全空、远近墨色一样浓重毫无虚实递进。
- **怎样算玩错、读数怎么说**：全部状态由 `model.js` 单真源从实绘河岸坐标、各景物实际体量与力臂、左右镜像相似度、近远实绘墨度差实时算出，绝非「点满即过关」：
  - **主体堵心**：河心被景物占住，分隔线变成障碍物，视线刚入河口就撞停。
  - **死直一刀劈**：弯度接近 0%，画面像拿尺子硬切两半，呆板无韵律。
  - **急弯折断挤压**：河道过弯，内岸被压扁，水势梗阻。
  - **河缝过窄 / 宽峡割裂**：河宽太窄致两岸粘连，或过宽致两岸孤悬无法照应。
  - **单岸偏沉倾覆**：左右力矩失衡，画面朝重岸歪斜。
  - **机械镜像呆板**：左右岸同景、同高、同重完全照镜子复制，虽稳却死板（温和点破原海报英文「SYMMETRY」在实战中应理解为「异形均衡呼应」）。
  - **远近同实平涂 / 近虚远实倒挂**：远岸与近岸墨色无层次或倒挂，拉不出纵深。
- **多组合法解**：只要清通河心、河宽与收束得当、河势微弯有度、左右岸力矩均衡且非机械镜像、近实远虚清晰，无论左弯还是右弯、亭配树还是山配舟，均判定为「两岸成章」。
- **与最近 12 页的差异**：
  - 区别于 321（横向全景开合门闸）、320（手卷五站游观视窗）、069（建筑灭点射线广场）、032（深海蓝圆角三栏 T 梁）、155（夹页抽拉纸卡）、199（复合网格描纸对齐）、282（滨海地图锚点连线）、238（固定宽浏览器五屏压测）、115（镉金黄标本分拣盘）、031（赤红双楔 X 剪刀）、068（橄榄圆列对角衰减）、237（午夜光学遮罩弹窗）。
  - 本页既不采用通用 32px 深色顶栏与「0/4 仪表盘卡片」，也非拉框或挪单点，而是以「拨河塑势 + 左右两岸异形配重 + 移走河心堵物」的传统理水造景动作为核心。

## 3. 版式骨架
- **总体气质**：1:1 承袭 322 原海报「烟雨冷宣纸底 + 居中青墨渐变大标与波浪副标 + 三青圆徽竖线带 + 左岸/中心活河/右岸三翼开放画卷 + 底部细线圆角『实时诊岸 / 构图要点』框（含左灯泡徽、中白话诊单、右实时联动缩略图）」。不锁 `min-height: 100svh`，平板端零大片空洞。
- **1440×900（2560×1440 舒展至 1720px）**：开放烟雨宣纸刊头（大标「一河」「两岸式构图」间留出随实时河势呼吸的活水微隙）→ 三翼河流舞台（左岸 240px 暖金圆徽虚线导引 × 中央 1fr 高清 2D 水墨画布 × 右岸 240px 暖金圆徽虚线导引）→ 底部贴合的细线圆角「实时诊岸 + 活体缩略图」带。首屏完整呈现标题、活河画卷、控件与诊单。
- **390×844（手机竖屏）**：压紧刊头与题材条，让近方等比活河画布稳占首屏 ≥ 46% 屏高，紧接诊单主句与「河势 / 左岸 / 右岸」三叶切换槽，不挤扁、不变形，触控区均 ≥ 42px。
- **844×390（手机横屏）**：切为左 55% 活河画布 × 右 45% 刊头、诊单与精简控槽并行，零横向溢出。
- **1024×1366 / 768×1024（平板）**：自然流排，768 宽下画布全宽置顶、左右岸控槽并排两列于下，避免一边先结束留大片空白。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节交互不重样）
- **01 曲直开合：河道如何带路** — 展开原海报「视线流动」「开合有度」，配四态河道视线轨迹 SVG 对比台（切换死直 / 微弯 / 急弯 / 宽峡，观看视线路径与停顿节奏差异）。
- **02 异形呼应：均衡不是照镜子** — 展开原海报「中心分隔」「对称呼应」，温和补充原海报 `SYMMETRY` 一词的实战语义；配真实杠杆力矩「两岸视觉天平」交互实验（点击切换配景或微调单岸体量，看天平梁实算倾角与镜像度）。
- **03 两脉渊源：从倪瓒到现代画幅** — 深江夜暗室节。对照传统山水画史的「上下三段一河两岸」与当代版式的「纵贯通道分两岸」；配双脉交互对照卡（点击切换画史名作与现代构图脉络），并一句话链接同小类 321、323、324、325 在线页。
- **04 跨界应用：万物皆可成河** — 说明「河流」不止是真实水流，可以是石径、留白中缝或数据导轨；配三场景「水脉显影卷帘」（拉动显影滑杆看摄影、杂志跨页、对比界面背后的河道与两岸骨架）。
- **05 边界警示：什么时候别用** — 明确四类不适用场景（单主角特写、狭长窄幅、强冲撞戏剧、多极并列网格），每类配精简反例示意框。
- **06 练一练：给右岸配一处呼应** — 单变量视觉选择题，四个方案共享完全相同的河道与左岸钟楼，仅右岸配景不同，标签中性（方案 A / B / C / D），选后展开逐项理由。
- **07 原海报与关键词** — 展示 322 原海报（点击放大、拖动、`Esc` 关闭，`draggable="false"`）及海报原话要点与三组关键词。

## 7. 练习设计
- **题干**：杂志跨页表现「老城与新岸」对话，中央微弯河道与左岸近景厚重钟楼均已固定，只改**右岸**配景，哪一幅既稳住两岸又有流动节奏？
- **四选项（单变量：仅右岸配景变化，标签不含好坏提示）**：
  - 方案 A：右岸同高同距放置体量与轮廓几乎完全一致的阁楼（错因：机械镜像，稳但死板呆滞）。
  - 方案 B：右岸近中景全空，仅远岸角落留一笔极淡山影（错因：左重右轻，视觉重心左倾失衡）。
  - 方案 C：右岸中远景错落安排舒展疏林与两叶淡墨扁舟，体量稍轻但横向舒展、高低错开（**正解**：异形等重、高低错落、兼顾近实远虚与视线余韵）。
  - 方案 D：将新建筑架作横跨河心的廊桥压在画面正中（错因：主体占住河心，打断中心分隔与视线流动）。
