02

从辞书、排字工手册
到网页标准

Where it comes from

悬挂缩进不是现代软件发明的新花样，它诞生于最朴素的检索刚需：在纸张昂贵、条目稠密的年代，怎么不浪费一整行空隙，又让读者一秒定位词头？

  1. 1755
    双栏辞书的早期实践

    塞缪尔·约翰逊（Samuel Johnson）出版双栏对开本《英语词典》（A Dictionary of the English Language）。对照 1755 年初版原书扫描可见：全大写词头顶格贴紧栏左缘，词条释义与编号义项的后续各行均向内退缩，下方书证引文再另起分段缩进，使读者能顺栏缘按字母纵扫词头。

  2. 1901 / 1904
    正式写入排字规范

    美国印刷大师西奥多·洛·德·文尼（Theodore Low De Vinne）在《排版实践》系列的《规范排版》（Correct Composition, 1901）与《现代图书排字法》（Modern Methods of Book Composition, 1904）中系统界定了 hanging indention，指明它专用于辞书、目录、索引与价目清单。

  3. 1992
    纳入现代版式语法

    罗伯特·布林赫斯特（Robert Bringhurst）在《字体排印风格要素》（The Elements of Typographic Style, 1992）里把外探式条目（flush-and-hung / outdented）当作页面结构器件讨论，强调它主动在版心左缘「刻出入口」。

  4. 2015–2024
    中外学术标准固化

    APA 第 7 版（2019）、MLA 第 9 版（2021）与《芝加哥格式手册》第 17/18 版（2017/2024）均统一规定参考文献采用 0.5 英寸（1.27 cm）悬挂缩进；中文期刊与学位论文参照 GB/T 7714-2015《信息与文献 参考文献著录规则》排版时，通常配合顺序编号使用约 2 字符的悬挂缩进。

  5. 2021–2026
    浏览器陆续支持 CSS hanging

    W3C CSS Text Module Level 3 定义了 text-indent: 2em hanging 关键字，2021 年起主流浏览器才陆续实装（Safari 15、Firefox 121、Chrome / Edge 146），网页终于不必再靠负缩进加左内边距去曲线模拟。

和相邻几种排法的界线 Related layouts

  • 186 首行缩进方向正好相反——首行内缩、续行顶格，服务的是小说与长文的连续分段。
  • 187 凸排标点只把引号、句号等细小标点探出栏边做视觉修边，不改变整条续行的左界。
  • 176 左对齐右参差 / 179 两端对齐管的是整段左右边缘怎么收口；悬挂缩进管的是左缘首行与续行的台阶。
  • 184 跨栏标题跨过多栏搭建宏观层级，悬挂缩进则在单栏内部替每一条长出索引。

03

缩多少才刚好？
看栏宽与深度的拉锯

Measure vs. indent depth

词头字数整齐时可以对齐释义首字，可真实书目里作者姓氏长短不一——从 Lupton 到 Hochuli & Kinross 差出两三倍。这时真正决定成败的不是去迁就最长姓氏，而是版心栏宽和缩进深度的比例：论文宽栏里舒服的缩进，搬到手机窄栏就会把续行挤成细长烟囱。

别敲空格硬凑：
一收窄就会当场散架

Real CSS & paragraph rules vs. fake spaces

新手做悬挂缩进，最常犯的错是在当前栏宽的行尾手动按回车，再给下一行敲两格空格。在 100% 原始宽度下它能伪装得和真缩进一模一样；可只要栏宽稍微收窄、或字号调大 1 号，整段文字就会当场崩成锯齿残片。往左拖滑块看看差别。

排版软件里的对应入口

  • Word / WPS：段落 → 特殊格式选「悬挂缩进」→ 设 2 字符或 1.27 cm。
  • InDesign：左缩进设为 +2em，首行缩进设为 −2em（两数绝对值相等）。
  • LaTeX：用 \hangindent=2em \hangafter=1 或 enumitem / biblatex 宏包。

什么时候用，
什么时候千万别用

When it works · When to skip it

说多了一点

原海报底部写着「通过悬挂缩进，信息更易扫描、比较与检索，提升学习与工作效率」。这句话对查找型信息成立，但不代表所有文字都该用它——若把长篇散文或故事正文排成悬挂缩进，每段首行都会生硬地顶出栏外，反复打断沉浸阅读的顺滑感。

适合用悬挂缩进 Use it

  • 参考文献与书目APA / MLA / 芝加哥 / GB/T 7714 文献表，按姓氏或序号纵扫最快。
  • 词典、术语表与索引条目密、无大段距，靠词头外探把释义自然劈开。
  • 多行项目列表与法条圆点、数字或条款号留在左通道，续行对齐正文首字。
  • 目录与年表清单年份或章节号顶格，右侧展开多行提要，节奏清晰。

别用或慎用 Skip it

  • 长篇叙事与评论正文沉浸阅读不需要每段弹出一把「检索手柄」，改用 186 首行缩进 或段距。
  • 极窄卡片与小屏徽章栏宽不足十来个字时，缩进会吃掉大块空间，让续行碎成孤字。
  • 全都是单行的短列表没有折行就永远看不到续行退让，徒增不必要的样式负担。
  • 对称标语与中心构图强居中视觉该看 178 居中排版，悬挂缩进依赖清晰的左侧基线。

海报关键词 Keywords

  • 条目

    把每条独立信息的入口固定在首行最外侧，天然划清彼此边界。

  • 检索

    视线贴着左基线垂直滑落即可命中关键词，不必逐字读完上一条。

  • 列表

    多行项不再回折到符号底下，圆点与序号列成一条笔直的秩序栏。

  • 节奏

    一探一退的锯齿阶梯赋予版面可预期的韵律，读完即知下一条起点。

  • 结构

    用两条隐藏的垂直基准线同时组织「词头层」与「释义层」，零噪音分明主次。
