01

续行退一步，
首行长出「检索把手」

Anatomy of the overhang

「首行顶格，后续各行内缩，便于条目、目录与术语检索。」

原海报 · 总述

人看小说和查词典，眼球的走法完全不同。看小说是一行接一行横着读下去；查词典、扫书目、对条款，视线先贴着左边缘竖着一路往下滑，直到撞见要找的词头或姓氏，才拐进去读解释。

悬挂缩进干的事非常干脆：把每一条的后续各行整体往右推，只在首行下面空出一条干净的垂直走廊。于是所有词头都像文件夹的标签一样探了出来——不用加粗框、不用拉大段距，单靠几何错位就把条目和释义劈成两层。

同一份原海报五词条 · 切换排法
  • 版式　在有限空间中组织文字与图形的方式与逻辑，以建立信息层级与视觉秩序，提升可读性与专注度。
  • 对比　通过大小、粗细、色彩、形状等差异突出重点，引导视线并强化信息的层级关系。
  • 对齐　将元素沿同一基线或边缘对齐，建立稳定与统一，减少视觉噪音，令版面更清晰。
  • 留白　有意识地保留空白区域，为内容提供呼吸感，增强可读性，并传达简洁与克制的气质。
  • 层级　用大小、位置与对比区分主次关系，帮助受众快速理解信息结构与阅读路径。

02

从辞书、排字工手册
到网页标准

Where it comes from

悬挂缩进不是现代软件发明的新花样，它诞生于最朴素的检索刚需：在纸张昂贵、条目稠密的年代，怎么不浪费一整行空隙，又让读者一秒定位词头？

  1. 1755
    辞书定型

    塞缪尔·约翰逊（Samuel Johnson）出版《英语词典》（A Dictionary of the English Language）。18 世纪大型辞书与百科广泛以「词头顶格、释义续行内缩」编排，使读者能顺左缘按字母纵扫。

  2. 1901 / 1904
    正式写入排字规范

    美国印刷大师西奥多·洛·德·文尼（Theodore Low De Vinne）在《排版实践》系列的《规范排版》（Correct Composition, 1901）与《现代图书排字法》（Modern Methods of Book Composition, 1904）中系统界定了 hanging indention，指明它专用于书目、目录、索引与注释。

  3. 1992
    纳入现代版式语法

    罗伯特·布林赫斯特（Robert Bringhurst）在《字体排印风格要素》（The Elements of Typographic Style, 1992）里把外探式条目（flush-and-hung / outdented）当作页面结构器件讨论，强调它主动在版心左缘「刻出入口」。

  4. 2015–2024
    中外学术标准固化

    APA 第 7 版（2019）、MLA 第 9 版（2021）与《芝加哥格式手册》第 17/18 版（2017/2024）均统一规定参考文献采用 0.5 英寸（1.27 cm）悬挂缩进；中文期刊与学位论文参照 GB/T 7714-2015《信息与文献 参考文献著录规则》排版时，通常配合顺序编号使用约 2 字符的悬挂缩进。

  5. 2021–2026
    CSS 原生关键字落地

    W3C CSS Text Module Level 3 写入 text-indent: 2em hanging（Safari 15、Firefox 121、Chrome/Edge 146 陆续实装），终于不必再靠负缩进加左内边距去曲线模拟。

和相邻几种排法的界线 Related layouts

  • 186 首行缩进方向正好相反——首行内缩、续行顶格，服务的是小说与长文的连续分段。
  • 187 凸排标点只把引号、句号等细小标点探出栏边做视觉修边，不改变整条续行的左界。
  • 176 左对齐右参差 / 179 两端对齐管的是整段左右边缘怎么收口；悬挂缩进管的是左缘首行与续行的台阶。
  • 184 跨栏标题跨过多栏搭建宏观层级，悬挂缩进则在单栏内部替每一条长出索引。

缩多少才刚好？
看深度与栏宽的拉锯

Depth vs. line measure

悬挂缩进没有放之四海皆准的死数值，因为它永远夹在两件事之间：探出太浅，左缘扫不出台阶；内缩太深，续行被挤成细长烟囱。经验值上，中文纯文字条目常用 1.5–2.5 em，带编号列表则让续行精确对齐正文首字；英文学术书目按规范取 0.5 英寸（窄栏屏幕按比例收紧）。

When it works · When to skip it

说多了一点

原海报底部写着「通过悬挂缩进，信息更易扫描、比较与检索，提升学习与工作效率」。这句话对查找型信息成立，但不代表所有文字都该用它——若把长篇散文或故事正文排成悬挂缩进，每段首行都会生硬地顶出栏外，反复打断沉浸阅读的顺滑感。

适合用悬挂缩进 Use it

  • 参考文献与书目APA / MLA / 芝加哥 / GB/T 7714 文献表，按姓氏或序号纵扫最快。
  • 词典、术语表与索引条目密、无大段距，靠词头外探把释义自然劈开。
  • 多行项目列表与法条圆点、数字或条款号留在左通道，续行对齐正文首字。
  • 目录与年表清单年份或章节号顶格，右侧展开多行提要，节奏清晰。

别用或慎用 Skip it

  • 长篇叙事与评论正文沉浸阅读不需要每段弹出一把「检索手柄」，改用 186 首行缩进 或段距。
  • 极窄卡片与小屏徽章栏宽不足十来个字时，缩进会吃掉大块空间，让续行碎成孤字。
  • 全都是单行的短列表没有折行就永远看不到续行退让，徒增不必要的样式负担。
  • 对称标语与中心构图强居中视觉该看 178 居中排版，悬挂缩进依赖清晰的左侧基线。

原海报与关键词

The original poster

海报关键词 Keywords

  • 条目

    把每条独立信息的入口固定在首行最外侧，天然划清彼此边界。

  • 检索

    视线贴着左基线垂直滑落即可命中关键词，不必逐字读完上一条。

  • 列表

    多行项不再回折到符号底下，圆点与序号列成一条笔直的秩序栏。

  • 节奏

    一探一退的锯齿阶梯赋予版面可预期的韵律，读完即知下一条起点。

  • 结构

    用两条隐藏的垂直基准线同时组织「词头层」与「释义层」，零噪音分明主次。
