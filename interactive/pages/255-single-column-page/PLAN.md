# 255 单列页面（SINGLE-COLUMN PAGE）设计方案

## 1. 一句话道理
把页面收束进一条有界宽度的垂直阅读轴，用统一的左边界、舒适的行宽、清晰的留白停顿与由重到轻的模块顺序替读者省去「下一步看哪」的分岔决策，让注意力自然顺流而下。

## 2. 开场玩具：活体单列网页视口排印台（Single-Column Viewport Bench）
- **怎么玩**：在贴合 255 原海报暖米书纸的 2D Canvas（标 `data-perf-drag`）内渲染一个真实可滚、可实时折行排版的浏览器单列网页视口（支持「专栏长文 / 产品发布页 / 结账表单」三套网页题材，及 1280 桌面 / 768 平板 / 390 手机视口切换）：
  - **左右横拖画布**（或拖视口内藏青列宽界标手柄、或底部「控制行宽」滑轨）：连续推拉单列正文容器宽度（从 22% 窄条到 96% 满屏），画布实时以 `measureText` 逐字重排段落，单真源输出实测每行汉字数、左右留白占比与眼动回扫跨越路径。
  - **点击画布里的网页模块**：选中模块后通过 `↑` / `↓` 按钮或键盘方向键调整其在垂直轴上的先后次序（把倒挂的附注/次要项挪回下方，让核心导语回到前排）。
  - **上下微拖滚动条 / 点击进度节拍**：在模拟视口内真实滚动页面，联动右侧原海报同款 `① 纵向阅读 → ② 节奏留白 → ③ 层级递进` 垂直动线箭头。
  - **原海报「设计要点 KEY POINTS」四栏实况控带**：直接在暖沙四栏带内调对齐方式（齐左单轴 / 混排锯齿 / 全文居中）、列宽、段距留白与层级反差、以及旁路干扰挂件（纯单轴 vs 双侧分心栏）。
- **一打开是什么状态（四重复合坏态，绝不先给答案）**：
  - 模拟 1280px 桌面视口，列宽 92% 通栏爆宽（实测约 55 字/行，远超 WCAG 40 字 CJK 上限）；
  - 段落留白紧缩黏连（字墙窒息）；
  - 层级拉平（标题/正文仅 1.15×）且模块倒序（次要附注压在核心导语前）；
  - 边界锯齿（标题居中、正文齐左、引文右齐，左边界散差大）。
- **怎样算玩错 & 读数如何讲「为什么」**（`model.js` 从实绘每一行折字框与模块矩形单真源核算 8 类双向真错态）：
  1. 通栏过宽（> 40 字/行）：扫完行尾折返左缘跨越太长，极易跳行或重读同一行；
  2. 面条过窄（< 16 字/行）：每半秒就要换行，词组频繁被斩断，阅读节奏碎裂；
  3. 黏连字墙（段距过紧）：段落与模块紧贴成灰块，缺少消化停顿；
  4. 假底线断层（段距过宽）：单处空白吃掉半屏以上，读者误以为页面已结束；
  5. 层级拉平（字号比 < 1.35×）：标题与正文重量相同，入口模糊；
  6. 主次倒序（附注压过导语或行动先于价值）：单列按顺序强迫阅读，前置细枝末节会挡住核心信息；
  7. 边界锯齿（对齐摇摆或长文全文居中）：左侧缺少稳定回扫基准轴；
  8. 双侧分心（开启两侧悬浮干扰栏）：破坏单列「一条轴线零分岔」的专注红利。
  - 接受**经典书页解 / 紧凑杂志解 / 宽幅图文解 / 手机窄屏解**等多组合法解。
- **与最近 12 页的差异**：最近 12 页多为深色/浓艳海报舞台、几何构图或纯排字行校正（254 柿红 2×3 图标矩阵、212 钴蓝单句行对齐、130 深紫横切条带、298 松绿双折页）；255 回归浅米书纸本色，直接做一个**完整的浏览器网页文档视口与四栏设计要点实况工作台**，聚焦单列网页独有的「视口宽度 vs 内容列宽、真实折行字数、纵向模块顺序与假底线节律」，其他编号无法套用。

## 3. 版式骨架
忠实转译 255 原海报「浅米暖纸 + 顶眉圆点星芒细线 + 左标题右文档藏青半圆徽标 + 纵轴动线 + 暖沙四栏设计要点带 + 底部深藏青宣言横幅」出版骨架（零通用深色导航顶栏、不锁 `100svh` 避平板大空白）：
- **1440×900（2560 舒展至 1640px）**：主宽 1360px；顶眉细线 → 非对称刊头（左自示范单列大标、橄榄短杠、总述与三关键词 × 右活体单列纸页藏青半圆徽标 + 三题材切签）→ 主舞台左 68% 活体单列视口画布 × 右 32% 与画布等高齐底的「①②③ 纵轴实时探针 + 单真源白话诊单」→ 全宽暖沙底「设计要点 KEY POINTS」四栏实况控带 → 深藏青「单列的力量」实况底带。
- **1024×1366 / 768×1024 平板**：自然流排，视口画布全宽居上，探针与诊单双栏并排齐底居下，零大片空洞。
- **390×844 手机竖屏**：顶眉单行压紧，刊头去冗余并将总述文字退至画布之后，等比单列视口画布稳占首屏 ≥ 48% 高度，且首屏下半直接露出白话诊单首句与主操作钮。
- **844×390 手机横屏**：切为左 56% 单列视口画布 × 右 44% 紧凑刊头、诊单首句与快捷控件并行，无横向溢出。

## 4. 配色和字体
- **逐像素实采自 255 原海报**：
  - 书纸底：`#FAF2E7` / 亮象牙 `#FDF9F2` / 暖沙要点带 `#F4EBDC` / 浅橄榄雾纸 `#F1F2E8` / 浅蓝雾纸 `#EDF2F7` / 细纸线 `#D5C7AE`
  - 墨色：主黑 `#0B0B0A` / 正文炭墨 `#1F201D` / 次墨 `#4E4C44`
  - 苔藓橄榄绿（圆点、短杠、①②③ 圆徽、引号、粗竖杠）：`#53582B` / `#585C29`（浅纸安全深橄榄字 `#434820`，暗底亮橄榄 `#C6D46B`）
  - 书脊藏青钢蓝（半圆、行宽/动线图符、底栏宣言、03/06 暗室）：`#315178` / `#3E6089`（暗室背景 `#192B42`、暗舱 `#223856`、暗底亮蓝 `#9CC5F4`）
  - 态色：错态陶锈赤（浅 `#A8321A` / 暗 `#FF8E72`），通过松青绿（浅 `#265C3A` / 暗 `#8CE0A9`）
- **字体搭配（全库 0 重复，与 254/253 零西文/等宽重合）**：
  - `Noto Sans SC`（400, 500, 700, 900）：大标与清晰中文正文（正文西文与数字同体防跳动）
  - `Archivo`（400, 600, 700, 800）：**最近 12 页 0 次使用**，报刊感厚实西文副标与要点英文标
  - `Instrument Serif`（400 正体 + 400 斜体）：**最近 12 页 0 次使用**，原海报大引号、节号与出版引文
  - `JetBrains Mono`（400, 500, 600）：标尺数字与实时 CSS 读数

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻两节不同控件）
- **01 纵向阅读为何省脑**（亮象牙纸）：引海报「纵向阅读」并温和修正「单列不自动等于好读」；**真实 DOM 行宽亲眼实测器**（四档宽度按钮 + 实时 DOM `Range` 折行逐行统计 + 中/英切换）。
- **02 节奏留白与层级递进**（浅橄榄雾纸）：引海报「节奏留白 / 层级递进」及双引语；**三枚独立排版改造拨片开关**（层级字号 / 留白分隔 / 齐左锚点 + 假底线试错切换）实时重构真实 DOM 迷你单列页。
- **03 单列从哪来**（深藏青暗室）：1501 威尼斯八开本 → 1991 CERN 首页 → 1992 Bringhurst / W3C WCAG 1.4.8 → 2009–2011 Mobile First & RWD；**四节点可点击历史书脊卡 + 同步缩放版式比例图**。
- **04 单列最拿手的场景**（浅蓝雾纸）：长文阅读、单列表单、叙事落地页；**单列 vs 双列表单实时 SVG 视线折线挑战器**（点击任意输入框追踪眼动路径与跳格风险）。
- **05 什么时候别用单列**（暖沙纸）：对照比较、高密度工作台、海量内容检索三大失效边界，一句话带链接指向同小类 256–268；**4 个产品场景需求分流诊断卡片**。
- **06 小练习：挑出好读的一列**（深藏青暗室）：双题 Tab 单变量考题（第 1 题只变列宽、第 2 题只变模块纵序），中性标签 `方案 A/B/C/D`，选完逐项讲清原理。
- **07 原海报与关键词**（暖米原纸）：`<img id="poster" src="poster.webp" draggable="false">` 可点击放大、拖拽、滚轮缩放、Esc 关闭 + 原海报三大关键词（COLUMN / RHYTHM / ORDER）+ 页脚。

## 6. 核实来源
- **W3C WCAG 2.1 Success Criterion 1.4.8 Visual Presentation**（明确 CJK 行宽 ≤ 40 字、拉丁 ≤ 80 字、行距 ≥ 1.5、段距 ≥ 1.5× 行距）：`https://www.w3.org/WAI/WCAG21/Understanding/visual-presentation.html`
- **Robert Bringhurst**, *The Elements of Typographic Style*（首版 1992，Hartley & Marks，单栏 45–75 字符、66 字符理想均值）与 **Baymard Institute** 行宽及单列表单可用性研究：`https://baymard.com/blog/line-length-readability`
- **Tim Berners-Lee / CERN**, 1991 年 8 月世界首张纯单列文档流网页：`https://info.cern.ch/hypertext/WWW/TheProject.html`
- **Ethan Marcotte**, "Responsive Web Design", *A List Apart*, May 25, 2010：`https://alistapart.com/article/responsive-web-design/`
- **Luke Wroblewski**, "Mobile First"（2009 博文 / 2011 A Book Apart 成书）：`https://www.lukew.com/ff/entry.asp?933`

## 7. 练习设计
- **第 1 题（唯一变量：正文容器宽度）**：1280px 桌面排 2000 字中文深度长文，17px 齐左、层级与段距一致，四张等比微缩线框只差容器宽度：`方案 A（1180px）`、`方案 B（260px）`、`方案 C（560px）`、`方案 D（940px）`。标签不含任何好坏提示词；选 **方案 C** 为最佳（约 30 字/行，落在中文 26–38 字舒适区且低于 WCAG 40 字上限），其余三项分别过宽（66 字/行）、过窄（13 字/行）或偏宽（52 字/行）。
- **第 2 题（唯一变量：模块纵向顺序）**：同一张单列产品发布页，列宽与字号完全相同，只改 4 个模块（主标题与定位、核心价值证据、常见问题细则、行动按钮）的垂直排布顺序；中性标签 `方案 A–D`，选出「先重要，后细节」顺流递进的一张。
