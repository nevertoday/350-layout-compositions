# 103 质感对比（TEXTURE CONTRAST）互动页方案

## 1. 一句话道理
人眼不需要伸手触碰，就能从表面高光锐度、微影起伏与局部纹理元密度读出粗糙、光滑、颗粒、纸感与金属；不同质感彼此并置时才产生触觉张力与空间层差，但同时需要留出安静的休止面，对比才不会滑向满屏噪点。

## 2. 开场玩具：触感标本配对台（WebGL 3D PBR 浮雕光影桌台 + 2D 同源降级）
- **怎么玩**：台面按原海报 103 摆出五块真实叠放的雕塑级材质标本（大圆底盘、方砖中层、纸页衬底含 10×6 触点阵、右上球体、前景三角）。
  1. **拖动顶部弧轨上的黄铜测光灯把手**（`data-perf-drag`，支持鼠标/触摸横拖与键盘 `← →`），改变侧光入射角与方位，实时观察低角度掠射光如何让砂岩凹坑起影、拉丝钢面扫出各向异性光泽、漆球滚出利落高光；
  2. **点选台面上任意一块标本（或底栏标本签），再从五种原海报实体材质样本匣（粗糙砂岩 / 光滑漆面 / 粗粒陶土 / 手工棉纸 / 拉丝冷钢）中换料**，实时配出既有张力又协调的质感组合。
- **开场初始态（非答案）**：五块标本全裹在相近的高粗糙哑光浅纸/灰泥里（粗糙度挤在 0.82–0.88，零金属、零光滑高光），且测光灯停在 74° 顺平顶光——画面立显「同质发平 · 缺反差」，五块叠放发闷发黏。
- **怎么算玩错（四类真错法）**：
  1. **同质发平**：粗糙度跨度 < 0.45 或全为静面材质 → 读数指出「五块表面粗糙度挤在一起，高光与微影拉不开，视线滑过抓不住焦点」。
  2. **堆料发噪（破协调）**：五块全塞进粗糙/颗粒/金属，安静休止面（纸感/光滑）为 0 → 读数指出「全屏高密肌理互相抢戏，缺少安静底面托举，反差退化成噪点——打破了原海报第二条『协调』」。
  3. **邻接撞材（破层次）**：虽有跨度，但直接重叠的相邻块（共 6 处真实接触缝）用了同种材质 → 读数点名哪两块交界粘连、空间前后层差消失。
  4. **顺光压平**：配方成立但灯光抬到 > 66° 顶平光 → 读数提示把测光灯拉低到侧光区，才能让凹凸微影与光泽差显现。
- **成立条件**：真实粗糙度跨度 ≥ 0.60、安静休止面占 1–2 块、6 处叠放邻接缝中至少 5 处材质分离、且侧光入射角 ≤ 64°。不锁死唯一配方，也提供「原海报配方」与「重置错态」。
- **与最近 12 页的明显区别**：最近 12 页里没有一页做「物理 PBR 材质配对 + 实时掠射侧光扫照」；和 102（四格纯色几何轮廓拉柄）、101（居中双色大圆色相轨）、019（包豪斯配重托盘）、072（暗黑玻璃塔透视仰角）玩法完全不重叠。

## 3. 版式骨架
- 延续 103 原海报的「暖棉纸博物馆材质标本台」气质，但告别 101 的左右三标对称柱和 102 的左目右图双栏：采用**上下双层标本工作台（页顶紧凑铭牌 + 三指标实况条 → 通栏无深色仪表框的暖纸 3D 实体光影桌台与原海报同款折线引注 → 底沿双分「材质样本匣 × 实时诊断带」）**。
- **1440×900 / 2560×1440**：宽屏容器放开至 `min(1820px, 92vw)`，首屏 3D 光影桌台占满主视觉且整套首屏（标题+桌台+样本匣+诊断）一屏落全；不用 `min-height: 100svh`，避免 1024×1366 平板中间留白。
- **390×844**：压紧页头与标题，3D 桌台保持等比正方形感占首屏 44% 以上，紧接单行标本选择、5 枚大触控材质片与精简结论，首屏直见可玩。
- **844×390 横屏**：切换为左 54% 满高 3D 桌台 + 右 46% 标题/选料/诊断并排，不裁不挤。
- 正文八节在暖棉纸 `#FAF4EB`、暖亚麻 `#EFE2CF`、深褐漆黑 `#211A14` 与原海报米纸 `#F2E5D4` 间交替推进。

## 4. 配色和字体
- **配色（严格取自 103 号原海报实测）**：
  - 暖米纸底 `#F2E5D4` / 浅棉纸 `#FAF4EB` / 亚麻砂底 `#EFE2CF`
  - 深褐墨字 `#1F1B17` / 次墨 `#595046` / 深褐漆暗节 `#211A14`（配暖象牙字 `#F2E5D4`）

  - 砂岩 `#B9A081`、冷拉丝钢 `#66686A`、深咖漆 `#3D2614`

## 5. 节目录（8 节，h2 均 ≤ 12 字，相邻控件不重复）
- **01 眼能摸到：为什么画面有触感**（`Eye as fingertip`）：去色同形双面剖检仪（2D Canvas 拖动竖向剖检拉幕 + 底部微影剖面波，证明去掉颜色与形状差异后质感依然成立）。
- **02 五个维度：海报上的五条法则**（`Five dimensions`）：复刻原海报底部的五列虚线分栏排布（对比/协调/层次/关注/情绪），点任一列在下方实景展览册封面上实时演示该维度的效果差异。
- **03 质感梯度：不画透视线也能出纵深**（`Texture gradient`）：吉布森纹理梯度 3 层景深实验台（`<input type="range">` 调前后肌理落差 +「颠倒远粗近滑」破功按钮）。
- **04 情绪转译：同字同版，换料换性格**（`Material mood`）：真实「秋分器物展」邀请卡双轴配料矩阵（底材 × 主材交叉点选），说明情绪来自材质配对而非单一标签。
- **05 从哪来：从包豪斯到纹理元**（`Where it comes from`）：核实史料时间线 + 莫霍利-纳吉 *Struktur / Textur / Faktur* 三层剖面切换图解。
- **06 什么时候用，什么时候别用**（`When to use — and when not`）：温和修正海报说多之处，附「正文小字与微图标底噪实测开关」，直观看粗糙底纹在小尺幅上如何损毁清晰度。
- **07 小练习：哪一版质感最成立？**（`Quick check`）：同一张「器物志」海报 4 组中性标签选项（方案 A/B/C/D），只差「材质搭配」一个变量。
- **08 原海报与六个关键词**（`The original poster`）：可点开放大拖动、Esc 关闭的原海报 + 6 枚定制肌理图形关键词卡 + 标准页脚。

## 7. 练习设计
- 场景：同一版「器物志 · AUTUMN CRAFT」小型展览海报，字号、构图、暖色系完全一致，只改变「底面 / 中层色块 / 焦点圆徽」三层材质：
  - **方案 A**：全哑光棉纸与浅粉泥（同质发平，无粗糙度跨度，焦点消失）。
  - **方案 B**：粗砂底 + 粗粒赤陶块 + 重拉丝钢徽（全粗堆料，无休止面，干扰文字边缘）。
  - **方案 C（正确）**：柔和棉纸底 + 粗粒赤陶中块 + 深褐光滑漆圆徽（一静一粗一滑，跨度拉开、相邻分离、静面护字、高光定焦）。
  - **方案 D**：高反光拉丝钢铺满整底 + 粗砂中块 + 淡哑纸圆徽（主次倒挂，背景最抢光、焦点最发虚）。
