# 250 自适应 网格原语（ADAPTIVE GRID PRIMITIVE）互动页方案

## 1. 一句话道理
自适应网格原语不是靠写死一堆媒体查询断点去切换三套静态页面，而是只给模块立一条「最小列宽（`--min`）」与「统一间隙（`gap`）」，让容器通过 `repeat(auto-fit, minmax(min(100%, var(--min)), 1fr))` 自动决定放几列、模块随内容自然伸高，从而让结构随屏幕与内容伸缩，而列轨、行基线与间隙节奏始终如一。

## 2. 开场玩具
- **命名与形态**：活体自适应网格构造室（1:1 承袭 250 原海报深翠松绿虚线格缝 × 暖米锐角 Bento 纸片矩阵）。主舞台是 2D Canvas 复刻原海报「自适应网格示意」的 7 枚包豪斯几何模块（可切原海报几何 / 商品图录 / 知识卡片三题材），右侧通高实时联动原海报「响应变化 FLEX」的桌面（980px）/ 平板（640px）/ 手机（360px）三端同步缩略预览。
- **怎么玩**：
  1. 在画布任意处或容器右缘朱橘红把手左右横拖（`data-perf-drag`），在 `240px–1040px` 连续伸缩容器宽度，实时目睹无媒体查询自动折列；键盘 `←/→` 微调宽度。
  2. 直接点击画布里任意模块追加或收起内容行数，亲眼测试内容增长时是等高拉伸还是被固定高度裁断；点击画布上的红标告警可直接定位对应参数。
  3. 调校列轨算法（写死 4 列 / 裸 `minmax` / `auto-fit + min(100%)` / `auto-fill + min(100%)`）、最小列宽 `--min`（`110–360px`）、间隙 `gap`（`0–44px`）、高度策略（固定高裁切 / 内容等高 / 基线对齐）、统一对齐开关与卡片数量（2–7 张）。
- **开场初始状态（绝非答案）**：停在 `420px` 窄视口的「0/4 伪自适应坏网格」——列轨写死 `repeat(4, 1fr)`（单列挤碎至 `105px`、手机 `360px` 更压缩至 `90px` 细条）、`gap: 0px` 粘连、高度写死 `height: 86px` 致 2 号加长卡底部裁切、子卡各写乱 `margin-top` 致基线错齿。
- **双向可玩错与读数「为什么」**：不只开场错，用户调参也会从两头踩坑——切了 `minmax` 却漏 `min(100%, …)` 在 `260px` 窄端立刻横向爆框溢出；`--min` 过小（`<155px`）在手机挤碎文字、过大（`>330px`）让平板提前退回单列；`gap > 32px` 挤压内容；少卡用 `auto-fit` 会拉扁单卡。所有读数（当前列数、实测单列宽、三端最差宽/溢出像素、基线落差、裁切像素、生成 CSS）均由 `model.js` 从同一套真实网格算法与实绘模块矩形计算，白话解释「观者看过去哪里难受、为什么破坏秩序」，接受 `auto-fit` 弹性解、`auto-fill` 目录等宽解、基线紧凑解、宽舒展示解等多组合法解。
- **与近期 12 页的差异**：近期 249（镉黄封面垂直伸缩）、291（奶油底斜标宏流道）、207（樱粉 6 列拖拽拼块）、206（克莱因蓝 12 列子网格）、248（克莱因蓝切换器胶囊）均无「深翠格缝暖米纸片 Bento 矩阵 + 横拖容器宽自动无断点折列 + 三端同步实算缩略 + 点卡扩充内容验等高与基线」玩法。

## 3. 版式骨架
- **桌面 1440×900**（主宽 `1380px`，2560 舒展至 `1680px`，绝不锁 `100svh`）：满幅深翠底 `#11754F` 配浅绿虚线格缝，复刻原海报 Bento 纸片结构：
  - Row 1：左 72% 暖米刊头块（自示范「自适应 / 网格原语」超粗黑大标 + 随实时列数变形的活体钴蓝/朱橘网格徽 + 三题材切签） × 右 28%「核心思想 CORE IDEA」块（2×2 虚线方圆活体徽 + 实时折列公式）。
  - Row 2：左 70%「自适应网格示意」开放式拉阔舞台画布与底沿精控槽 × 右 30% 通高暖米块（上承原海报「响应变化 FLEX」桌面/平板/手机三端活体缩略 + 下承单真源白话诊单、四维读数与实时 CSS 匣）。
  - Row 3：全宽四等分原海报支柱实况带（灵活伸缩 / 统一对齐 / 节奏与间距 / 内容驱动），每格带实时状态角标。
  - Row 4：深翠压脚带（3×3 白格徽 · `模块 · 对齐 · 响应` · 四角扩展徽）。
- **平板 1024×1366 / 768×1024**：自然流折排，Row 2 上舞台下「三端缩略 + 诊单」双栏并排，无空洞。
- **手机竖屏 390×844**：压紧单行翠绿暖米刊头（把总述退后），让等比自适应网格画布稳占首屏 ≥ 47% 且首屏即可看到单真源诊单首句；画布始终按容器宽度等比计算高度不压扁。
- **手机横屏 844×390**：切为左 56% 活体网格舞台 × 右 44% 紧凑刊头、三端灯与诊单并行。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻控件零重复）
- **01 · 少写断点，多立规矩**（`Core principle`）：拆解海报「核心思想」与模块伸缩/对齐基线/响应变化三柱，交互为点击 3 张原海报解剖卡联动右侧动态 SVG 图解（2×2→4×2、`A g` 基线、三端临界宽表）。
- **02 · 一行 CSS 的四道机关**（`The algorithm`）：拆解 `repeat(auto-fit/auto-fill, minmax(min(100%, --min), 1fr))`，交互为真 DOM CSS Grid 上下双轨实测槽（容器宽拖条 + 卡片数 `1–6` 步进器 + `min(100%)` 开关）。
- **03 · 对齐基线与等高节奏**（`Baseline & rhythm`，深翠暗室）：阐明 `A g` 基线、等高行轨、子网格对齐与统一 `gap`，交互为可增减文案行数的三卡实景基线对齐台（实时测量真实 DOM 坐标绘出贯穿钴蓝基线与像素落差）。
- **04 · 从印刷格到内在网格**（`Where it came from`）：核实历史演进（1981 → 2010 → 2016/2017 → 2018 → 2019），交互为四纪元时间轴切换底层网格构造蓝图与代码对照。
- **05 · 什么时候别用它**（`When not to use it`）：温和修正海报「内容决定形态」容易引发的误解，并用 4 场景错配诊断器（一键切换「硬套等宽网格」vs「换对侧栏/切换器/簇群/横向卷轴原语」）讲透边界并互链同小类其他编号。
- **06 · 挑一套扛得住缩屏的网格**（`Quick check`）：四选一中性选项小练习（只差列数固定 / 固定高裁切 / 零缝错齿三个单变量），选后显露隐藏网格线与逐项解析。
- **07 · 原海报与关键词**（`The original poster`，深翠展墙）：原海报可放大拖动灯箱 + 三大关键词（模块/对齐/响应）几何徽与海报原话索引。

## 7. 小练习
- **场景**：把 6 张信息卡片放进 `580px` 宽的平板侧栏，单卡需 `170–260px` 宽才易读，且第 2 张卡标题比其余卡片多出两行。
- **四个纯中性选项（A/B/C/D，只差一个变量）**：
  - **A**：写死 `repeat(4, 1fr)`，统一 `gap: 16px`，内容自动伸高（单变量缺陷：写死 4 列，580px 下单列压到 133px 挤碎文字）。
  - **B**：`repeat(auto-fit, minmax(min(100%, 210px), 1fr))`，统一 `gap: 16px`，内容自动伸高（**正解**：自动落 2 列 × 282px，第 2 张长卡带动同行等高齐底，缩至 200px 也不溢出）。
  - **C**：`repeat(auto-fit, minmax(min(100%, 210px), 1fr))`，统一 `gap: 16px`，写死 `height: 84px; overflow: hidden`（单变量缺陷：定高裁断第 2 张长卡）。
  - **D**：`repeat(auto-fit, minmax(min(100%, 210px), 1fr))`，`gap: 0px` 且单卡各自加不等 `margin-top`（单变量缺陷：粘连且破坏统一基线对齐）。
