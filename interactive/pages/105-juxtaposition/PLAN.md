# 105 并置（JUXTAPOSITION）互动页方案

## 1. 一句话道理
把两个原本独立的元素放进同一条视觉边界两侧，大脑不会把它们当作两件事分开看，而是被迫在「中缝」处寻找差异、建立共性桥梁，并在对立之中读出单个元素原本不存在的第三层意义。

## 2. 开场玩具：双联中缝并置天平台
- **长相与物理**：直接化用 105 号原海报的标志性画面——暖米纸底上，左联为浅枯玫瑰粉底（`#F1A3A6`）、右联为深黛松绿底（`#2F483B`），整幅双联版画真实架在底部的黑色等边支点三角（`▲`）天平横梁上；桌面端左右两翼按原海报布局排布六枚带圆点虚线引线的原则灯（左：邻接 / 对照 / 冲突；右：对话 / 关联 / 平衡）。
- **怎么玩**：
  1. 拖动天平下方的横向「中缝拉距轨」（标 `data-perf-drag`），或在双联画布内直接左右拖动左、右两个几何形，改变它们跨过中缝的距离与各自力臂；聚焦后可用键盘方向键 `←/→` 微调。
  2. 分别切换左、右两个主体的几何形态（直方 / 柔圆 / 锐角）。
  3. 切换跨缝色彩关系（各自同系 / 各用异色 / 互为底图）。
  4. 调节右形尺度配重滑块（65%–135%，或键盘微调），在明暗密度不同的异形之间找回天平动态平衡。
- **开场初始错态（绝非答案）**：
  - 初始停在「同形隔断 · 失衡错版」（0 / 6 成立）：左、右均为直方（同形无对照）；色彩停在「各自同系」（粉底暗粉方、绿底灰绿方，跨不过中缝）；两者退居外缘使中缝空出 24% 宽沟（邻接失联）；左侧体量偏大且力臂偏远，天平横梁肉眼可见向左倾倒约 `-6.6°`。
- **怎样算玩错、读数怎么说「为什么」**：
  全部状态与诊断由 `model.js` 单一真源按优先级实算，一次只报一条主错，并同步点亮/警示六柱原海报灯：
  1. **中缝失联**（跨缝间距 > 12%）：「两边退到各自角落，视线跨不过中间的空沟，变成了两张互不相干的画（那是隔离原则的效果）。」
  2. **越缝混叠**（跨缝间距 < -2%）：「左右越过中缝叠压在一起，边界糊成一团，并置退化成层叠，彼此立场看不清。」
  3. **同形复读**（左形 = 右形）：「两边都是同一种几何形，只是平行摆放，缺少轮廓与气质差异，激发不出冲突与对话。」
  4. **各自同系**（同系低对比）：「粉留在粉里、绿留在绿里，明暗和色相都待在自己那一侧，画面发平，抓不住第一眼焦点。」
  5. **硬拼无桥**（各用异色）：「硬塞进不搭界的明黄与冷蓝虽然刺眼，却把两半撕成四色噪点——只剩冲突、没有共性桥梁，看不出为什么放一起。」
  6. **天平倾倒**（`|倾角| > 2.2°`）：「深色直方天生比浅色柔圆更有视觉分量（或力臂偏外），横梁向一侧压沉了 X°，靠移近力臂或补偿另一侧尺度，才能在对立里站稳动态平衡。」
  7. **六柱全亮（成立）**：紧邻中缝（0%–8%）＋异形对照＋互为底图共性桥＋横梁归平（`|倾角| ≤ 2.2°`），天平磁吸锁平，中缝亮起对话脉络，解释为何「1 + 1」在此刻生出第三层张力与秩序。
- **与最近 12 页的差异**：
  - 不同于 104（深靛蓝九宫格+极坐标发射）、227（蓝图 6×4 CSS Grid）、022（三纵栏建筑移轴相机）、271（瀑布流砌墙）、059（四层剪纸 Z 轴景箱）、143（墙面开窗裁景）、310（3D 景深走位）、226（弹性盒顶栏）、103（3D 材质光影标本桌）、021（海平水准气泡）、188（五栏文字基线校对）、058（四级等轴筑阶）。本页是**双联跨缝天平力学 + 异形互借底图关系**，只有「并置」能用这个玩具。

## 3. 版式骨架
- **1440×900 桌面端**：顶部居中的示范刊头——「并」「置」二字分别托起深松绿直方与枯玫瑰圆弧、紧贴一条细中缝展开，下配宽距 `J U X T A P O S I T I O N` 与原海报总述；中段直接复刻 105 原海报标志性的「左三柱引注（22%）× 中双联天平画布（56%）× 右三柱引注（22%）」对称三翼展览骨架（不锁 `100svh`，自然完整落入首屏）；画布下紧接通栏中缝拉距轨、精简双联控制台与原海报底栏式实时白话诊断带。
- **2560×1440 宽屏**：主容器舒展至 `1820px`，双联天平与两侧引注同步放大舒展，不缩在中间留大片空边。
- **1024×1366 / 768×1024 平板竖屏**：不锁 `100svh`，双联天平居中铺宽，六柱原则收成画布下方紧凑 3×2 状态带，零中间空洞。
- **390×844 手机竖屏**：顶栏压成单行紧凑示范标；双联天平画布保持严格等比（圆绝不压扁）占首屏约 46% 屏高；同屏紧接满宽触控中缝拉距轨、6 柱状态点与诊断卡，触控按钮高度均 ≥ 44px。
- **844×390 手机横屏**：切为左 52% 双联天平画布与拉距轨 × 右 48% 紧凑控件与实时诊断并排，一屏内即可操作全套动作。

## 4. 配色和字体
- **配色（像素实采自 105 原海报 `site/public/p/105.webp`）**：
  - 暖米纸底 `#F5E8D8`（次浅纸 `#FAF4EB`、淡粉纸 `#F6E2DF`）
  - 枯玫瑰粉 `#F1A3A6` / `#EFA9AA`（点缀玫瑰红 `#E57F86` / `#DA7076`；浅底小字加深为 `#9C303A` 确保对比度 ≥ 6.8）
  - 深黛松绿 `#2F483B` / `#2F4839`（深炭绿暗版 `#1B2822`）
  - 墨黑主字与支点三角 `#161817` / `#181A1C`
- **字体搭配**（全库唯一；三款西文均在最近 12 页中未用过）：
  - `Noto Sans SC`（400 / 700 / 900）：原海报同款厚重几何黑大标与清爽正文
  - `Syne`（600 / 800，近期未用）：宽展建筑感西文展示大标（`JUXTAPOSITION`、章节英文标）
  - `Fraunces`（400 / 700 + 400 italic，近期未用）：柔和人文衬线，与硬朗 `Syne` 形成字形上的并置对照，用于独立副题与标本卡
  - `IBM Plex Mono`（400 / 500，近期未用）：等宽读数与参数标尺

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻不重复控件）
- **01 一加一，生出第三层意思**（暖米纸）：拆解并置与单纯对比的差别——左图锁死无表情侧影，右侧四张场景卡切换（热汤 / 空椅枯枝 / 盛放花枝 / 倾颓时钟），直观验证库里肖夫式的「含义在缝间诞生」；一句话链接 100–104 五种单一对比页。
- **02 从蒙太奇到图像图谱**（深黛松绿暗版）：核实过的五段思想史节点（库里肖夫、韦特海默、瓦尔堡、爱森斯坦、伯格与唐迪斯），点选年代片签切换对应的极简几何图解；并温和补充海报六要点的成对牵制关系，链接 106 隔离原则。
- **03 中缝的尺度：近到多近？**（淡粉纸）：连续滑块把中缝从 0% 紧咬拖到 28% 隔断，观察格式塔邻近分组弧线与视线跨缝跃动何时从「并置对话」滑入「各自隔离」（标注经验参考值）。
- **04 四种并置骨架，用在哪？**（暖米纸）：四类真实应用场景标签切换（今昔前后对照 / 双栏立场对话 / 跨界隐喻海报 / 图文反向互注）＋「显出桥梁与冲突轴」透视开关，分别一句话链接 096、098、099。
- **05 什么时候别用并置**（深炭绿暗版）：三张翻车对照卡（多方混战 / 生硬无桥 / 过度对比），每张独立「看错版 ↔ 换解法」翻转开关，指出何时应改用 095 视觉层级、097 平衡原则或 106 隔离原则。
- **06 挑出真正成立的并置**（暖象牙纸）：同题材「古木刻 × 今电路」四方案 A/B/C/D 练习，中性标签、每项与正确答案仅差单一结构变量（A 缺邻接 / B 缺平衡 / C 成立 / D 缺共性桥梁），选后显出结构标注与完整解析。
- **07 原海报**（暖米纸）：可点开放大拖动与 Esc 关闭的原海报，配原海报六条完整要点与底句铭文。

## 7. 小练习设计
- **题材**：同一主题双联展板「木刻（古）× 电路（今）」，四个选项全部只标中性字母 `A`、`B`、`C`、`D`。
- **单变量控制**：
  - `A`：方圆对照、互为底图、体量平衡均对，**仅中缝拉宽至 26%**（推到外缘，邻接断裂）。
  - `B`：中缝紧邻、方圆对照、互为底图均对，**仅左块体量过大右圆过小**（天平严重左倾，失衡）。
  - `C`（**正确答案**）：中缝紧邻、方圆对照、互为底图共性桥、视觉配平四项同时成立。
  - `D`：中缝紧邻、方圆对照、体量平衡均对，**仅放弃互为底图改用无关明黄与冰蓝**（只剩刺眼冲突，缺少共性桥梁）。
