# 038 曲线构图（CURVILINEAR COMPOSITION）设计方案

## 1. 一句话道理
曲线构图不局限在某个固定字母形状里，而是用**一条主曲线定调、几条伴随细弧顺势呼应、粗细与疏密有节奏变化，且把曲线终点稳稳收进视觉焦点**的多股自由弧线，顺应人眼偏爱连续圆润轮廓的本能，把分散元素编织成柔和、连贯又有呼吸感的有机画面。

## 2. 开场玩具：丝带流束织曲台（Curvilinear Ribbon & Focus Choreographer）
- **核心动作（专属于 038 曲线构图的多股丝带编排，无法套用到其他编号）**：
  - 在 1:1 承袭 038 原海报暖杏宣纸与柔桃拱顶的开放 2D Canvas（`data-perf-drag`）上，嵌入直接从 `<img id="poster">` 裁出的**真实陶瓶红花圆窗照片**（零额外体积），配 3 股变宽桃粉丝带与 5 枚原海报圆徽（自然联系 / 柔性引导 / 节奏延展 / 空间流动 / 视觉焦点）及深酒红细虚线弧箭。
  - **画布左右横拖（`data-perf-drag`）**：连续「熨曲 / 折硬」，把生硬尖角折线实时柔化为连续变曲率曲线（0% 尖折 → 100% 流畅有机曲率），同时驱动顶部酒红毛笔大标**「曲线构图」与珊瑚副标「CURVILINEAR COMPOSITION」从僵平状态同步拱起为原海报的优雅圆弧**。
  - **直拖陶瓶焦点圆窗或丝带终点磁针**：自由拖移视觉焦点或终点落位，实测三股丝带终点到焦点的偏距与入焦角度，验证「曲线终点落焦」与「脱焦滑出画框」。
  - **直点画布红标理顺逆流打结**：把逆向横穿主丝带的伴随副弧一键理顺成顺势流束，或在下方 1:1 原海报「构图要点 KEY POINTS」卡片里自由调校方向、主副粗细比、疏密间距与终点落位，并可在「原海报·陶瓶花艺 / 护肤瓶·流丝主视觉 / 流线展馆·画展海报」三题材间切换。
- **开场初始错态（绝不先给答案）**：打开停在 **`0/4 待理顺`** 四重复合错态——① 线条尖折生硬（柔滑度仅 18%，刊头大标平直未拱起）；② 伴随副弧逆向横穿主丝带打结成毛线团；③ 三股丝带几乎同粗（1.1×）且等距贴挤失去呼吸感；④ 丝带终点偏离陶瓶焦点 31% 斜冲右下画角。
- **怎样算玩错、读数怎么说「为什么」**：`model.js` 对当前实际绘制的主丝带（72 点）与两条伴随弧（各 56 点）做单真源几何采样，实算最大折角、切向一致度与交叉次数、主副线宽比与锥度、相邻带最小间距与疏密呼吸比、终点到焦点偏距与边界安全距，可诊出 9 类具体失误（尖角硬折、死直无弧、逆流打结、同粗抢主次、粗带堵屏、平行死轨、挤撞粘连、终点脱焦、焦点撞边），用白话讲清「视线为什么在这里被卡住、绕晕或带偏」，并接受多组合法解（原海报环抱解、对角舒展解、轻盈细丝解及任意手动拖出的达标状态）。
- **与最近 12 页的差异**：037 是深松夜绿单条 S 河道弯幅与曲率正负波形；036 是晨空蓝单弧 C 开口定向；325 是宣纸对开折枝剪叶；203/204 是深色放射星盘与极坐标测绘；121/120 是粒子流场与 3×3 围栏；245 是居中器视口墙；159 是 4 卡浮升；287 是三栏设置页；075/074 是等角与斜投影立方体。本页是柔和柔桃×深酒红多股变宽丝带流束编排 + 真实原海报圆窗照片 + 拱形毛笔字实时随曲率弯拱。

## 5. 节目录（7 节，每个 h2 ≤ 12 字，相邻节交互不重复）
1. **01 曲线凭什么让人放松**（洁白宣纸）：引原海报总述与 5 大原理，拆解大脑偏好曲线的机制并温和修正「海报说多了一点」之处；交互为**尖角→曲线连续变形观测台**（拖一条变形轨看器物/拱廊/按钮轮廓软化，附同小类 031–040 一句话外链）。
2. **02 从鞭梢线到脑科学**（柔桃浅纸）：梳理 1893 塔塞尔公馆、1894 穆夏《吉斯蒙达》、1926 康定斯基《点、线、面》、2006/2007 巴尔与内塔实验、2013 瓦尔塔尼安与 2016 贝尔塔米尼研究；交互为**年代文献切换器 + 康定斯基单力直线 vs 复合变力曲线力学图解**。
3. **03 粗细与间距的呼吸账**（深酒红暗室）：展开原海报「曲线粗细」与「曲线间距」；交互为**3×3 粗细×间距质感标本矩阵点选台**，点任意格实时重绘大幅曲线标本并实算疏密与负空间。
4. **04 给软弧配一根直骨头**（暖杏原纸）：拆解全屏软弧发腻发飘的通病与刚柔对照法则；交互为**海报刚性锚点装配开关板**（独立开关细线框、日期竖标、直线短杠、圆角软壳，实看版面重心稳度变化）。
5. **05 什么时候别用曲线**（淡陶土宣纸）：列出精密风控看板、急读导视标牌、硬核工程规格单三类慎用场景；交互为**三组场景「硬套柔弧 vs 换回直线骨架」切换对比卡**。
6. **06 眼力小测：哪张最耐看**（洁白宣纸）：四幅中性标签（方案 A / B / C / D）花艺海报，仅差「曲线粗细、疏密与终点收束」单一几何变量，作答后逐项给理由并支持重测。
7. **07 原海报与关键词索引**（深酒红展墙）：原海报灯箱放大拖拽与 Esc 关闭、原海报四要点速查、同小类其余 9 篇横向导览与标准单行页脚。

## 7. 小练习设计
- **题目**：同一张「初夏陶艺花事」竖幅展讯（主题文案、陶瓶红花主图、配色和字号层级完全一致），四幅方案只差「多股曲线的粗细、疏密与终点收束」这一项设计处理。哪一幅真正做到了「柔和、连贯、有呼吸感」？
- **选项（全中性标签：方案 A / 方案 B / 方案 C / 方案 D）**：
  - 方案 A：三条等宽平行弧带像铁轨一样齐刷刷穿过画框，粗细无主次、间距等宽死板，缺乏韵律与呼吸。
  - 方案 B：三条弧线逆向交叉缠绕成毛线团，且一条粗弧横切压过陶瓶花朵，视线在中央打结。
  - 方案 C（正确答案）：主丝带粗细渐收领跑、两条细副弧一疏一密顺势伴随，终点温柔收进陶瓶花艺焦点，左下角配克制细线展期文字块作刚柔锚定。
  - 方案 D：曲线弧度与粗细对比都流畅，但所有曲线终点集体滑出右上与右下画角，彻底绕开中央花艺主体。
