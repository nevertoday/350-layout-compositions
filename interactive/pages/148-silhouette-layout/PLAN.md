# 148 剪影 版式 · SILHOUETTE LAYOUT 设计方案

## 1. 一句话道理
剥离主体内部纹理与杂乱背景，只留高对比的单一外轮廓，视觉注意会被封闭轮廓的凹凸拐点瞬间锁住；再把文字顺着形体凹谷展开、守住均匀的轮廓呼吸缝，就能在极简画面里同时拿下强记忆点与清晰层级。

## 2. 开场玩具：「剪影暗房排字台 · 逆光去噪 × 活体轮廓绕排」
- **怎么玩**：
  1. **横向拖拉舞台底沿「逆光显影推光杆」（`data-perf-drag`，也支持键盘 ←/→ 与画布内直接横向拉帘）**：把 22% 灰雾杂景写真态连续推向 78%–100% 纯黑硬边剪影态，实时剥离人物内部明暗杂纹与背景斜纹，提升图底明度对比度（1.9:1 → 13.5:1），并让原海报同款反白叶枝浮现。
  2. **画布直点剪除杂影 / 切换形体数量**：直接点击画布里抢戏的多余小剪影（左上飞鸟、左下尖塔）将其「咔嚓剪掉」，或通过控件回归单一形体。
  3. **文字绕排模式 + 轮廓呼吸缝调节**：在「矩形硬切」与「沿轮廓绕排」间切换，并调节呼吸缝隙（-20px 至 +56px），观察 `model.js` 逐行对剪影真实贝塞尔轮廓函数 `xEdge(y)` 求交并重新排布大标、副标与导语。
  4. **剪影体量（18%–74% 面积占比）+ 三题材切换（原海报人像侧影 / 飞羽侧鸟 / 复古提琴）+ 邮票缩影盲测视图 + 内镂空叶枝开关**；同时允许水平微调剪影重心。
- **一打开的状态（0/4 翻车态，绝不是答案）**：
  - 逆光显影停在 22%（灰扑扑的内部噪点 + 背景杂纹，实测图底对比度约 2.1:1）；
  - 场上挤着 3 个剪影（主侧影 + 2 块抢戏杂影），违背「单一形体」；
  - 左侧文字停在硬矩形框直排，直接冲入黑影轮廓（最小净距为负值，撞断鼻尖与唇线 3–4 行）；
  - 剪影占地 61%，把暖白留白挤压窒息。
- **怎样算玩错、读数怎么说「为什么」**：
  `model.js` 从真实绘制的轮廓曲线与文字行边界单一真源实测 8 类错态，全部用白话讲清观众眼睛的真实反应：
  1. **低对比灰影**（图底对比度 < 6:1）：影块和底纸融在一起，第一眼抓不住封闭边界；
  2. **多影抢戏**（形体数 > 1）：多个轮廓同时向眼睛招手，记忆点被拆散；
  3. **撞影压字**（最小净距 < 0px）：文字切碎鼻尖/唇线等关键识别拐点，且骑在黑白交界上难以辨读；
  4. **紧贴窒息**（开了绕排但净距 < 12px）：字边黏在黑影上，轮廓和字都在抢同一条空气缝；
  5. **离影脱节**（净距 > 44px）：文字退缩到最左窄边，与剪影断掉呼应，版面裂成互不搭界的两截；
  6. **黑压过满**（剪影面积 > 56%）：大块黑墨吃掉暖白留白，整页发闷喘不过气；
  7. **孤影过小**（剪影面积 < 26%）：主角缩成角落小记号，撑不起版面视觉统御力；
  8. **硬框呆排**（未撞黑但未随轮廓展开）：矩形直边与有机弧线之间留出尴尬锯齿死角。
  - 全部 4 项进入连续经验甜区（对比 ≥ 7:1、单一形体、沿轮廓绕排且净距 14–38px、剪影占比 32%–54%）即达标（多题材、多合法体量与缝隙组合均成立，不是单一死答案）。
- **和最近 12 页的区别**：
  - 147 是木活字字号跳差压杆与倾角排戏台；025 是单点透视射线汇点收拢；314 是五层景片视差；192 是竖排宣纸列距卷轴；230/274 是真实数据表格；062 是星场呼吸推波；107 是 9×8 点阵秩序与 2×2 破格；024 是平行线散角与间距梳轨；313 是 2.39:1 横向推轨人物调度；146 是蒙德里安粗黑纸带与三原色点格；191 是 S 形贝塞尔路径排字。
  - 本页独有：**逆光去噪压黑显影 + 实时剪除干扰杂影 + 逐行依剪影外轮廓曲线动态绕排与呼吸缝实测**，别的编号无法原样套用。

## 3. 版式骨架
忠实承袭 148 原海报的「暖白底纸 × 炭黑剪影 × 右上橄榄绿弧角展签」三色美术馆展陈语言，零圆角深色仪表盘感，绝不锁 `min-height: 100svh`：
- **1440×900（2560 舒展至 1840px）**：
  - 极细 32px 炭黑顶眉下，采用「双材质弧切展陈刊头」：左 64% 暖米宣纸放沿剪影弧线微收的示范大标「剪影 版式」与总述，右 36% 橄榄绿切角展墙呼应原海报右上角，排原海报 3 条白色竖线实况点检灯（单一形体 / 围绕轮廓 / 留白呼吸）与状态章。
  - 中段核心工作台：左 60% 为大幅 2D Canvas 活体剪影海报舞台 + 无缝底沿「逆光显影推光尺」（`data-perf-drag`），右 40% 为上炭黑暗房实测诊单 × 下暖石纸精炼控台；底沿通栏接原海报 4 枚点虚线橄榄绿关键词徽（轮廓/留白/对比/识别）与左下 5×4 橄榄绿点阵印记。
- **1024×1366 / 768×1024**：刊头自然收紧，画布与推光尺满宽居中（保持等比不拉扁），下方暗房诊单与控台双列并排，无空洞留白。
- **390×844（手机竖屏）**：单行极紧顶标（仅留「剪影 版式」与状态章），紧接着等比 4:3 活体剪影舞台、46px 逆光显影推光尺与一行炭黑快诊条，首屏稳占 ≥ 48% 屏高且同屏即见白话诊断与操作入口；其下展开完整诊单、控台与橄榄三要点。
- **844×390（手机横屏）**：切左 54% 剪影舞台与推光尺 × 右 46% 紧凑诊单与核心控件并行，画布等比完整可见不裁切。

## 5. 节目录（共 7 节，标题均 ≤ 12 字，相邻节交互不重复）
- **01 · 邮票盲测：轮廓凭什么被记住** (`SILHOUETTE RECOGNITION`)：3 组剪影对比卡 +「去细节压黑」开关 + `100% 近看 / 40% 街角 / 16% 邮票` 三档视距缩影台。
- **02 · 绕影排字的四条分水岭** (`CONTOUR WRAPPING`)：四态解剖切签（矩形硬切 / 死贴窒息 / 呼吸绕排 / 反白内嵌）+ 互动标注解剖图；温和补充原海报「文字围绕形体」的长文边界。
- **03 · 图底反转：黑影也是容器** (`FIGURE-GROUND REVERSAL` · 深炭暗房节)：鲁宾图底正负一键翻转 + 4 组真实对比度色板验看 + 内部反白叶枝镂空占比调节器（亲证切破外轮廓如何毁掉剪影）。
- **04 · 从讽刺绰号到现代海报** (`HISTORICAL ARCHIVE`)：5 纪元美术馆档案切签（1759 西鲁埃特 / 1915 鲁宾图底 / 1926 赖尼格剪影片 / 1955–1959 索尔·巴斯电影海报 / 2003 Apple iPod 剪影广告）+ 同步切换极简图版 SVG。
- **05 · 什么时候用，什么时候别用** (`WHEN TO USE & AVOID`)：6 枚真实设计需求快筛卡片（点选即判适配或劝退，并附同小类兄弟页推荐链接）+ 明确四条停用红线。
- **06 · 小练习：选出立得住的版面** (`VISUAL PRACTICE`)：同题材同色同文案「秋夜爵士黑胶独奏会」四方案盲选，仅改变「文字绕排与呼吸缝」单一变量。
- **07 · 原海报与同小类十二邻** (`ORIGINAL POSTER & SIBLINGS`)：原海报点击放大/缩放/拖动灯箱 + 原海报关键词与要点摘录 + 同小类其余 12 页一句话带链接导览。

## 7. 小练习设计
- **题目**：同一张「秋夜独奏 · 爵士黑胶现场」海报，底色、剪影尺寸与文案完全一致，仅调整了左侧文字与剪影轮廓的绕排关系与呼吸缝，哪一张最立得住？
- **四个中性选项（仅标 方案 A / B / C / D，单变量对比）**：
  - **方案 A**：左侧硬矩形直排，最大行右端逼近喇叭口边缘（净距过近且下方留出尴尬死角）。
  - **方案 B（正确）**：文字顺着帽檐、吹嘴到喇叭口的自然凹弧错落收放，全程守住均匀呼吸缝，外轮廓关键拐点完整无遮。
  - **方案 C**：文字贪求紧扣形体，局部压入黑影边缘并切碎吹嘴与鼻尖拐点，轮廓识别与字迹对比同时受损。
  - **方案 D**：过度害怕碰影，把文字挤成最左极窄竖条、离影过远，标题被迫碎折，主体与文字断联成两块孤岛。
