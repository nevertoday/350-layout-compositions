# 182 轮廓绕排 CONTOUR WRAP — 设计方案

## 1. 一句话道理
让水平排布的正文按异形主体的真实边缘逐行避让，既消除了矩形围框的死白，又把主体的起伏曲线直接转译成可读的阅读韵律——但前提是护住呼吸距、保住齐整起行、绝不夹出孤字或劈栏跳读。

## 2. 开场玩具
- **命名**：活体书页绕排排字台（Live Contour Wrap Galley，2D Canvas 标 `data-perf-drag`）。
- **玩法**：页面直接呈现一张融入暖棉纸的活体杂志单页/双栏排印稿，主角是 1:1 承袭原海报的柿红有机剪影（可在右下原海报同款圆角虚线框内一键切「器物轮廓·长颈陶瓶 / 自然元素·龟背竹叶 / 抽象形态·三瓣流形」）。
  - 在画布上**直接拖动异形主体**，它在真实汉字段落间穿行，每一行中文按当前真实轮廓的左右交点实时重排、断行、绕流；
  - **直接拖动主体边缘的柿红虚线缓冲环**（或底沿排印尺滑柄），实时调节绕排间距（`0px`–`44px`），亲眼见证啃边咬字 ↔ 呼吸贴边 ↔ 脱形退化；
  - **切换栏式**（单栏 / 双栏中缝夹嵌）、**绕排引擎**（轮廓绕排 182 / 矩形盒绕排 183 / 原海报环边对照）与**凹口桥接**（封堵深裂口防叶隙吞孤字）；
  - 按 **`Space`** 放飞一束柿红视线流光，沿实绘逐行汉字基线与换行回扫虚线走一遍，直观暴露左缘锯齿与跨图断句。
- **一打开的初始状态（绝非答案）**：
  - 陶瓶偏移压在单栏中偏左位置（`x = 0.42`），造成**跨图劈栏夹字** + **左起行剧烈锯齿** + **右缝挤出 2 字孤行** + **绕排边距 `0px` 文字直接啃进瓶身（碰撞标红）**，四重常见绕排事故同场显现。
- **怎样算玩错与读数解释（单真源）**：
  - 由 `model.js` 对**真正画出来的每一行文字区间和起止 X 坐标**逐行检测，双向捕捉 7 类正反错态：
    1. **啃边撞字**（边距 `< 6px`）：文字笔画贴进主体红边，图文粘连成一团；
    2. **脱形失联**（边距 `> 30px`）：缓冲区把凹凸弧度撑平，绕排只剩远距离白洞；
    3. **跨图劈栏**（同一行被图形左右截成两截）：迫使视线越过主体跳读，打断语意连贯；
    4. **左缘锯齿**（非双栏中缝时，多行左起点横向抖动过大）：横排中文靠齐整左缘接住换行回扫，左缘歪斜让眼睛每行都重找起点；
    5. **窄缝孤字**（最短残行 `< 5` 字，或龟背竹叶深裂口未桥接被塞进 1–3 字）：碎词卡死在凹口里，节奏卡顿；
    6. **退化方框**（切到矩形绕排 183 或边线斜率近直墙）：四边留下死白三角，失去轮廓呼应；
    7. **环边失读**（原海报单行旋转对照模式）：适合极短装饰标语，但多行长文会倒挂转圈无法阅读。
  - **多组合法解**：右置陶瓶典范解（左齐右绕 + 14px 呼吸距）、双栏中缝夹嵌解（双栏各护内缘、绝不跨图连读）、龟背叶桥接疏朗解（开启凸包桥接封住深裂口 + 16px 呼吸距）。
- **与最近 12 页的区别**：
  - 180 拉伸双行字框，097 跷跷板称重，099 巨圆与小人，098 比例卡尺，096 主次权重盘，094 四星轨道，093 压背景噪点，092 封四门，095 眯眼三阶层，091 推框破边，090 掰斜轴，054 甩离心圆。
  - 本页**不做抽象几何仪表台**，而是直接在暖棉纸杂志排印稿里做**逐行真文字几何碰撞重排 + 可拖缓冲包络环 + 眼球换行回扫验证**，且直接把原海报右下角圆角虚线框做成主体剪影切盘，彻底跳脱近期页面的硬线框仪表盘范式。

## 3. 版式骨架
- **桌面端（1440×900 主宽 1360px / 2560 舒展至 1640px）**：1:1 转译 182 原海报「开放暖棉纸杂志对开页」——顶部仅留轻盈刊号眉题与轻目录，**绝不用沉重顶部暗条和 0px 硬仪表框**；左 58% 为融入棉纸的活体排印书页画布紧贴底沿极简排印尺与原海报左下「大橘圆 + 三行宣言 + 细橘箭」落款；右 42% 严格齐底排布自示范大标「轮廓绕排」配左侧微弧、原海报总述、斜杠关键词实时标、**三条向左指向画布的橘红虚线箭头实时批注（贴边流动 / 图文避让 / 阅读节奏）**、轻诊单与**原海报同款圆角橘红虚线框「应用示例」三剪影切换器**。
- **平板竖屏（1024×1366、768×1024）**：不锁 `100svh`，自然流排：紧凑刊头 → 全宽等比排印画布与底部排印尺 → 三条虚线批注横排三列与圆角虚线应用切换并列，零大片空白。
- **手机竖屏（390×844）**：单行极简刊头（`182` + `轮廓绕排` + 状态徽），总述与三条详注后置，让**等比排印画布稳占首屏 ≥ 48% 屏高**，首屏折线内直露诊单首句、绕排边距主滑轨、三剪影快切与校准/扫视双键。
- **手机横屏（844×390）**：左 55% 排印画布 × 右 45% 紧凑刊头 + 诊单首句 + 主滑轨与双键并行。

- `01 贴边、避让与节奏`：把原海报三条要点讲透，并温和辨析原海报单行环边与多行正文绕排及 183/189/191 的边界｜**交互：双面卷帘刮开对比台（183 矩形盒 vs 182 轮廓绕排，实算死白面积节省与回扫偏移）**。
- `02 四个绕排暗礁`：解剖绕排边距、深凹陷吞字、跨图劈栏与左缘锯齿四大实操雷区与经验阈值｜**交互：4 枚标本解剖台 +「修补一刀」前后切片开关（配实绘排印剖面）**。
- `03 曲线如何牵动视线`（深窑暗室）：对比自然元素、器物轮廓、抽象形态三种边缘的行长起伏与阅读节律｜**交互：三形态行长韵律波形仪 + 单步/连播视线节拍器 + 紧贴/平滑包络切换**。
- `04 从威尼斯铅字到网页`：梳理 1499 活字木刻、1934 杂志剪影、1987/1999 桌面出版到 2014 CSS Shapes 演进｜**交互：4 代工艺手风琴折页卡（点击展开该时代物理/算法绕排机理示意）**。
- `05 何时该用，何时别用`：明确原海报三类应用示例的适用前提与四大禁用红线｜**交互：4 份真实商业排印稿翻牌诊断卡（点击翻看崩溃现场与替代方案链接）**。

## 7. 练习设计
- **题一（单变量：绕排边距 `shape-margin`）**：同一张右置长颈陶瓶的中文杂志稿，A/B/C/D 四版字号、行距、位置完全一致，**只改绕排边距**：A 为 `0px`（啃边碰撞）、B 为 `4px`（标点擦边压迫）、C 为 `14px`（约 0.9 字宽，呼吸清晰且忠实呈现瓶颈与瓶腹弧线）、D 为 `40px`（撑成近直墙，曲线失联）。正确项 C。
- **题二（单变量：主体落位与栏型）**：同一只长颈陶瓶与 `14px` 边距，A/B/C/D **只改落位**：A 为居中劈开单栏（双侧跨图跳读 + 窄缝孤字）、B 为压在左缘起行侧（锯齿破坏换行回扫）、C 为靠右缘左齐右绕（左缘笔直稳固、右缘随瓶身呼吸）、D 为紧贴右缘但侵入 72% 栏宽（右侧把正文压成 3 字碎条）。正确项 C。
