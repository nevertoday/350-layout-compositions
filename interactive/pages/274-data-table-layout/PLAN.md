# No. 274 数据表格布局（DATA TABLE LAYOUT）互动页设计方案

## 1. 一句话道理
数据表格不是把文字塞进格子，而是用**固定的二维坐标（行是对象、列是属性）**、**锁死位值的垂直数字轴**、**克制的线框信噪比**与**克制的焦点高亮**，把原本需要逐字阅读的复杂数字，压缩成一眼可扫、可比、可核验的视觉结构。

## 2. 开场玩具（活体账簿检校台 · Live Tabular Audit Desk）
- **形态与载体**：整幅 6 列实体 HTML 数据表格（直接复现 274 原海报的 5 个消费品类 + 合计行数据），上叠同步的 **2D Canvas 光学小数轴与横扫视线透视层**，右上附带与表格校准度联动的原海报标志性 **3×3 绿海军矩阵徽章**，底沿通栏承接原海报四柱验收标（结构 / 对齐 / 比较 / 精准）。
- **怎么玩**：
  1. **直接拖动表格顶沿与列缝上的可调列宽滑尺（`data-perf-drag`）**：实时拉伸或压缩「项目 / 数值列」比例，观察 Canvas 上的横向扫视跨距标尺与实测列宽状态（拖太窄会触发折行/挤断，拖太宽会拉出过宽「白河」导致串行丢行）。
  2. **点击真实表头排序（↕ / ↑ / ↓）或锁定焦点对比列**：把乱序行排成单调序列；切换焦点列模式（无高亮 / 单列聚焦「环比增长」 / 全表涂色失焦）。
  3. **结构与对齐、精准校准**：把混在数据行中间的「合计」行归位到底部汇总栏、把牢笼重网格减为清透横细线（或切到全无界线看串行失误）、在「全居中 / 全左对齐 / 左文右数」与「比例数字 / 等宽数字 tabular-nums」间切换（Canvas 实时读取真实 DOM 文本节点 `Range.getBoundingClientRect()` 绘制个位/小数点垂直折线与偏移 `Δpx`）、开启嵌入式「占比」迷你条、把杂乱精度（4 位小数噪音或过度取整）与原海报自带的「占比和仅 92.2%」核校到统一千分位与 100.0% 平账。
- **开场状态（0/4 翻车错态）**：开场绝不给出答案——行序打乱、「合计」混在第 3 行、全黑重框牢笼网格、数值全左对齐且关闭等宽数字、表头灰平无焦点列、占比无内嵌条、数值格式位数不一且 5 项占比之和仅 92.2% 与合计 100.0% 矛盾。
- **怎样算玩错、错了读数怎么说**：不设「点满就赢」或一键通关作弊按钮；下列每一种失误都会由 `model.js` 单一真源结合实时 DOM 测量直接判错并说明视觉因果：
  - 列宽过窄挤断文字/数字 →「列宽压扁，数值折行破坏逐行对照」；
  - 列宽拉得过宽（列缝空隙过大） →「横向白河过宽，眼睛扫向右侧目标达成时容易串行」；
  - 选「牢笼全黑框」→「非数据墨水过重，黑线比数字更抢眼」；选「全无界线」→「缺少水平导轨，长行易串行」；
  - 「合计」留在行中 →「汇总行混入样本，读者会拿合计与单项并列比大小」；
  - 选「全左对齐」→「980 的 9 对齐在 1,280 的 1 下方，千位与百位错位造成量级误判」；选「全居中」→「个位与小数点呈锯齿晃动（实测 Δpx），仅适合装饰海报，不利实务比大小」；选「右对齐但比例数字」→「数字 1 比 8 窄，同位数字仍微幅错开」；
  - 选「全表涂色」或高亮过多列 →「全员高亮等于没有重点，差异重新被抹平」；
  - 选「4 位小数噪音」→「多余尾数拖慢短时记忆（Ehrenberg 法则）」；选「未平账 92.2%」→「分项之和 92.2% ≠ 合计 100.0%，动摇读者信任」。
- **读数说什么「为什么」**：每项诊断不仅报实时 DOM 测出的 `小数轴偏 Δpx`、`横扫跨距 px`、`墨水效率档位（示意）`、`占比合计数`，更直接用一句话解释人眼为何会看错、该改哪一处。
- **与最近 12 页的明显差异**：
  - 不同于 273 暗黑遥测雷达仪表盘（深底三层卡片 + 24h 时间轴拨尺），本页是极净白底建筑账簿表页；
  - 不同于 272 抹茶圆角便当盒、106/061/312/023/190/105/060/311 的图形构图画布，本页的开场主角是一张**真正可排序、可拖列宽、可实测 DOM 字符像素偏移的活体财务数据表**，别的编号完全无法套用。

## 3. 版式骨架
- **承袭 274 原海报的「通栏账簿检校页」无侧栏垂直骨架**（零圆角、不锁 `min-height: 100svh`）：
  - **1440×900**：主体容器 `max-width: 1320px`。极细顶眉下，刊头左置带微刻度表尺的「数据表格布局」示范大标与总述，右置原海报同款 3×3 活体矩阵徽章与 `0/4` 审计章；中段通栏铺开 6 列活体账簿表 + 顶沿列宽游标（`data-perf-drag`）+ Canvas 光学轴线覆盖层；表底紧接精炼单带调控条、实时白话诊单与原海报同款四栏底沿原则验收条（1440×900 首屏完整收束，无大块空洞）。
  - **2560×1440**：版心扩展至 `1820px`，表格字体与列距同步舒展，主体扎实铺满宽屏。
  - **1024×1366 / 768×1024**：自然流式高度（绝不锁 `100svh`），顶部紧凑，表格完整全宽展示。
  - **390×844（手机竖屏）**：顶眉与刊头压缩到极简两行，紧接活体数据表（首屏可见 ≥ 46% 屏高，窄屏按核心 4 列紧凑排布 + 顶沿横向列宽拉轨 `data-perf-drag` 仅拦截横向拖动、保留竖向滚屏，零横向溢出）与首屏可读诊单，确保一眼上手、圆与图标绝不压扁。
  - **844×390（手机横屏）**：左右双栏（左 60% 活体账簿表与列宽拉轨 × 右 40% 精简控件与实时诊单），整块首屏可操作。

## 4. 配色和字体
- **配色（像素实采自 274 原海报）**：
  - 账簿纸白 `#FCFAF8`、浅翠雾底 `#F2F7F5`、浅石纸 `#F5F6F4`、焦点列浅薄荷 `#EFF6F3`、合计行淡绿 `#E8F2EF`；
  - 标志账簿翡翠绿 `#018868`（浅底文字加深 `#01694F` 保障对比度 ≥ 6.0）；
  - 标志审计海军蓝 `#002252`（深海暗节 `#051A36`，反白字 `#F5F8F7`）；
  - 印刷墨黑 `#0D1112`、次墨 `#3E4A47`、细水平线 `#D4DDD9`、细虚竖线 `#C3CECA`；
  - 仅用于错态校验与告警的克制朱赤 `#B83227`（暗节亮珊瑚 `#FF7A6B`）。
- **字体搭配（全库唯一，其中三款西文均在最近 12 页零使用）**：
  - `noto-sans-sc`（400 / 700 / 900）：标题与中文正文、表格项；
  - `ibm-plex-sans`（400 / 600 / 700，钉住 `wdth: 100`）：理性工业无衬线，**最近 12 页未用**；
  - `dm-mono`（400 / 500）：清晰等宽数字与代码标注，**最近 12 页未用**；
  - `dm-serif-display`（400 正体 + 斜体）：大节编号与出版级展示衬线，**最近 12 页未用**。

## 5. 节目录（8 节，标题均 ≤ 12 字，相邻两节不同控件）
1. **01 `四根柱子撑起一张表`**（`The Four Pillars`）：原样引出海报四要点（结构/对齐/比较/精准），温和点出原海报自身的两个教学彩蛋（数字居中与占比合计 92.2%）；交互为**四柱结构透视解剖图（点切区域高亮 + 海报版/实务版对照）**。
2. **02 `对齐为什么能省一半眼力`**（`Why Alignment Saves Sight`）：拆解 Stephen Few 与 `tabular-nums` 的位值垂直扫描原理；交互为**「3 秒找最大数」限时微测 + 2D Canvas 数字游标卡尺放大镜**（实时量化 `1` 与 `8` 宽度差并测反应毫秒数）。
3. **03 `少画线，数字反而更清楚`**（`Data-Ink Ratio` · 深海军蓝暗节）：拆解 Tufte 数据墨水比与 Ehrenberg 有效数字舍入；交互为**五段连续滑杆「去墨剥离器」**（`input[type="range"]` 逐级卸除牢笼黑框、深斑马、重复单位与冗余小数）。
4. **04 `排个序，规律自己浮出来`**（`Reorder to Reveal`）：拆解 Jacques Bertin 可重排矩阵与单元格内嵌微图形；交互为**可点击互换/重排的 6×5 活体矩阵 + 热力/条形视觉编码开关**。
5. **05 `从威尼斯账簿到电子表`**（`Where Tables Come From`）：可核实的历史脉络（1494 Pacioli → 1967 Bertin → 1977 Ehrenberg → 1979 VisiCalc → 1983 Tufte / 2004 Few / NN/g）；交互为**五代账簿标本切换器**，用同一组数据即时切换五个时代的表格形态。
6. **06 `窄屏折中与何时别用表`**（`Mobile & When Not to Use`）：手机端三种响应策略对照 + 明确反例边界与同小类兄弟页单句链接（273 / 270 / 275 / 278 / 280 / 277 / 269 / 272）；交互为**窄屏宽度模拟器（320px ↔ 960px 预设切换 + 冻结首列/折叠次列/转卡片对比）**。
7. **07 `挑一挑：哪张表最好读`**（`Spot the Readable Table`）：单变量四选一小练习（仅差「对齐与数字字体」一维，中性标签版本 A/B/C/D，选后叠绘红色/绿色实测垂直位值轴揭晓答案）。
8. **08 `原海报`**（`The Original Poster`）：可点击放大、拖动、Esc 收起的 274 原海报与四个关键词徽章。

## 7. 小练习设计
- **题目**：下面四张季度大区营收表使用了完全相同的数据、排序、千分位格式与轻横线，只在**对齐方式与数字字形**这一项上有差别。哪一张最利于眼睛沿纵列一眼比出大小？
- **四个单变量选项（中性标签，不泄露好坏）**：
  - **版本 A**：文字左齐 + 数值左齐（千位与百位混齐，940 与 12,480 首字对齐造成量级误判）。
  - **版本 B**：文字左齐 + 数值右齐，但表头居中且用比例数字（`1,110` 偏窄导致逗号与位值轻微漂移，且表头右缘脱节——强干扰项）。
  - **版本 C（正确答案）**：文字左齐 + 数值与数值表头同步右齐 + 等宽数字 `tabular-nums`（个位、逗号、小数点形成笔直垂直轴，扫视比大小最快最稳）。
  - **版本 D**：文字居中 + 数值居中（两边参差、小数点左右漂移，牺牲了纵向可比性）。
