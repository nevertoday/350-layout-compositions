# 196 模块化网格（MODULAR GRID）互动页方案

## 1. 一句话道理
在竖向分栏之上再切出等步长的横向行线（flowlines），用同一枚基础单元 `X × X` 及其恒定缝隙 `g` 跨格合并成大小各异的内容区域，让看似自由的变化共享同一套对齐骨节。

## 2. 开场玩具
- **玩法**：2D Canvas 实绘的「活体 X × X 积木拼版台」。用户直接在虚线矩阵上拖移 5 块真实内容模块（主视觉、正文块、引用块、数据块、徽章块）、拖拉模块右下角缩放柄跨格合并（如 `3×3`、`3×2`、`2×2`、`2×1`）、开关网格吸附、调节矩阵粒度（`4×3` / `6×4` / `8×6` / `10×7`）与模块缝隙 `g`，并可在原海报同款的「海报 / 名片 / 看板」三套场景间即时变身；支持键盘方向键移位、`Shift+方向键` 跨格伸缩、`Tab` 切块。
- **开场初始状态**：刻意停在 **0 / 5 翻车错态**——吸附关闭，5 块模块全歪在半格缝里（脱格 0.18X–0.38X），缝隙为 `0.00X` 贴死粘连，全员接近 `1×1` 平权豆腐块，正文与主视觉被挤扁截断，重心塌向左上角且大面积空荒（主视觉模块恰好覆盖画布中心，确保首拖即中）。
- **怎样算玩错、错了读数怎么说**：由 `model.js` 单真源从 5 块实绘坐标实时核算 9 类错态：
  1. `重叠撞车`（两块压叠，标赤红斜纹撞车区）；
  2. `脱格散架`（模块边线未对齐 X 网格交点）；
  3. `零缝粘连`（缝隙 `g < 0.08X`，块与块糊成一团）；
  4. `宽缝散架`（缝隙 `g > 0.25X`，视觉割裂成孤岛）；
  5. `粒度过粗`（`4×3` 格子太少，难以区分层级）；
  6. `平权豆腐块`（最大/最小面积跨比 `< 2.0×` 或全员同尺寸，缺乏主次）；
  7. `独大窒息` / `满版窒息`（单块 > 55% 或整体留白 `< 12%`）；
  8. `窄条断行` / `内容挤扁`（正文块过窄或主视觉/数据块面积低于内容下限）；
  9. `重心塌角` / `稀疏散落`（加权视觉重心偏移 `> 0.16` 或留白 `> 52%`）。
  底部诊单带按优先级用白话讲清「眼下错在哪、大脑为什么觉得乱/闷/呆、下一步亲手调什么」，且接受多组不同正当拼法（绝非唯一死答案）。
- **与最近做完的 12 页的明显区别**：
  - 区别于 195（国际蓝左柱 + 拖竖向栏缝）、194（手稿稿纸拖四边距）、278（看板跨列拖卡片）、233（酸黄 CSS 绝对定位坐标）、150（看图猜成语点格切图文）、110（竖排书脊紫粉渐变坡面）、065（3D 多平面景片三色层带）、027（居中对称天平）、316（玄夜重门剖深）、149（丁香巨型字母骨架）、277（暖杏时间线游标）、109（曜黑 16 拍斜轴乐谱）。本页聚焦二维 `X × X` 单元格上的「拖块落位 + 跨格合并（Span） + 双轴模数咬合」。

## 3. 版式骨架
忠实承袭 196 原海报的「暖乳米白纸面 × 左 28% 示范大标与五枚动态微图解原则列 × 右 72% X×X 虚线模块拼版台 × 底沿全宽焦糖橘虚线大圆角 TIP 诊单带」出版画册骨架，不锁 `100svh`。
- **1440×900（2560×1440）**：顶眉 34px，主容器宽 1380px（2560 舒展至 1820px）；左列排嵌有实时缩微 `X×X` 基准块的超厚黑示范大标「模块化 / 网格」、焦糖橘副标与总述、及 5 条带实时联动 SVG 小图的模块化原则；右列排深茄胶囊栏、场景/粒度/缝隙控件与 16:10 大幅拼版画布；下接全宽焦糖橘虚线圆角诊单带。两栏高度自然对齐。
- **1024×1366 / 768×1024**：不锁高度，顶收为横排刊头，中铺全宽等比画布与单行操控，下接虚线诊单带与双列五原则。
- **390×844**：极紧单行刊头（≤ 68px），紧接 5:4 等比主画布（单元格始终 1:1 正方形不变形）与快捷跨格条，画布+操控稳占首屏 ≥ 48% 屏高，首屏同见诊单首句；触屏竖滑放行滚页、横拖或按住模块/角柄触发移动。
- **844×390 横屏**：左 55% 铺等比主画布与底沿单行快控，右 45% 排紧凑刊头、实时诊单与当前块跨格微调。

## 5. 节目录（共 7 节，h2 均 ≤ 12 字，相邻节控件各异）
- **01 小单元长出大结构**（`ONE UNIT, MANY ZONES`）：讲清横向行线与二维空间区域，温和纠偏原海报「模块越小越灵活」的经验边界；交互：**二维单元格涂抹合并矩阵（Paint-to-Merge）**，直拖划选格块并实时验证 `n·X + (n-1)·g` 吃缝公式。
- **02 为什么 58 格能万能分栏**（`GERSTNER'S 58-UNIT CODE`）：追溯 1103 北宋《营造法式》材分制 → 1962/1964 卡尔·格斯特纳 *Capital* 58 单位活动网格 → 1981 米勒-布罗克曼《平面设计中的网格系统》→ 2004 勒普顿与 2017 W3C CSS Grid；交互：**58 单位分栏数学解算器**（点选 1–6 栏与切换总宽 57/58/60 对比整除与余数）。
- **03 四个积木，三种真场景**（`ONE MATRIX, THREE ARENAS`，深茄暗室节）：复刻原海报四类内容模块与「未来生活节海报 / 林予安名片 / 业务数据看板」三案例；交互：**X 光骨架透视切帘滑幕 + 积木同步高亮灯**，剥开三张成品直看底层共同的 `X×X` 矩阵。
- **04 缝隙与基线的双轴咬合**（`GUTTER & FLOWLINE MATH`）：解释为什么图片底边常与右侧正文最后一行差半行，揭示横缝等于整倍行距的数学约束；交互：**步进器（Stepper）基线咬合检视器**（调每块行数 `k` 与横缝行数 `0.5 / 1 / 1.5 / 2` 实看图底与字脚齐平或错位）。
- **05 什么时候别硬套模块**（`WHEN TO BREAK OR SKIP`）：明确适用边界与三大禁用/慎用场景，一句话链接 194、200、210、211；交互：**四场景反例对比切换卡**（点切「硬套模块版 ↔ 对路版式」）。
- **06 四选一：挑最稳的模块方案**（`LAYOUT CRITIQUE QUIZ`）：同主题同素材 8×6 年报封面四方案盲选，只写中性标签 A/B/C/D，选完展开逐项剖析。
- **07 原海报与关键词**（`ORIGINAL POSTER & KEYWORDS`）：可点开放大/拖动/Esc 关闭的 196 原海报、设计小贴士原话、同小类其他编号一句话索引与页脚。

## 7. 练习设计
- **题目**：一份 `8×6` 模块化设计年报封面需排入主图、导语、关键数据与脚注四块内容。以下四份方案素材与配色完全相同，哪一份的模块化组织最稳？
- **四选项（仅差一个结构变量，中性标签）**：
  - `方案 A`：严守网格与缝隙，但四块均分为四个 `4×3`（面积比 1:1:1:1，平权呆板、无视觉主次）。
  - `方案 B`：主次面积分明，但上下横缝一宽一窄且右列数据块左缘脱格半格（破缝失序）。
  - `方案 C`（**正确**）：主图 `5×4` 定重心、右列 `3×2` 导语与 `3×2` 数据对齐、底行留 1 格呼吸白承托 `5×1` 脚注，横竖齐咬、疏密有度。
  - `方案 D`：对齐且有大小差，但用装饰块硬填满全部空格致留白仅 4%（满版窒息、主图被挤闷）。
