# 019 非对称构图（ASYMMETRICAL COMPOSITION）· 互动页方案（修订稿）

> 所属分类：构图逻辑 / 重心、线条与轴线  
> 原海报总述：通过不均衡的元素配置，在视觉上达到平衡与张力。

---

## 1. 一句话道理

眼睛判断画面稳不稳，靠的不是左右「长得一模一样」，而是**视觉重量（面积、色彩冷暖/明度、形状锐度、疏密纹理与距轴力臂的综合分量）**能否互相托住；用**不同体量、不同冷暖、不同形态**的异质元素换来平衡，既不歪倒失衡，又能借反差制造出对称构图没有的方向感与张力。

## 2. 开场玩具：包豪斯异形配重画板（Asymmetric Counterbalance Canvas）

- **怎么玩**：
  - 主体是一整张贴合 019 原海报铬黄纸面的通栏 2D Canvas 构图画板，示范大标题「非对称构图 / ASYMMETRICAL COMPOSITION」直接压在画板左上角，真实作为左上基础配重参与计算；右上角锚定大号朱砂红主圆，中间 45° 黑色点线随左侧配重承接状态动态拉紧或断开，底沿内置一条极简无度数的包豪斯视觉支点平衡条（仅以图形微倾和五档平衡态呼应原海报第一个天平图标，**绝不出现度数或百分比偏移**）。
  - 画板下方左侧横跨原海报同款三段诊断带，右侧并排一枚 **6 件包豪斯异形零件料盒**（`粗黑字群`、`群青斜角`、`密集点阵`、`要点三圆`、`冷蓝小圆`、`红大圆`——绝不在名称里写「镜像」或「陷阱」）。
  - 用户可直接**点选或拖拽**零件投入画板（支持在画板内拖动调整位置与力臂、聚焦后用键盘方向键微调、`Delete / Backspace` 撤回、`R` 重置），并可切换三组命题（`原海报 · 红圆压顶` / `杂志跨页 · 巨图配细栏` / `展讯海报 · 粗字压角`）或点击「原海报解法」对照。
- **一打开是什么状态（绝不先给答案）**：
  - 默认打开「原海报 · 红圆压顶」的**刻意右沉失衡态**：右上锚定大号朱红主圆，画板内仅有一颗孤零零的冷蓝小圆与左上基础标题压角，平衡档落在 **「重度右沉」**（原海报五条对比只亮了 2 项：大小、色彩），45° 黑色点线因左侧托不住而呈松散断线，等待用户从料盒挑入异形件或拖动调距把画面压平。
- **读数说什么「为什么」（全部由同一份 `model.js` 权重表算出，不出度数）**：
  - **平衡档（五档、不出度数）**：`重度右沉` / `略微右沉` / `视觉持平` / `略微左沉` / `重度左沉`，并标明 **「模型示意」**。
  - **原海报底部三段带实时联动**：
    1. **重量对比示例**：左/右两区重量以原海报同款实心黑圆点 `●●●●●` 实时显示（同一 `model.js` 权重表换算）。
    2. **对比关系五线实时点亮**：`大小对比（大与小）`、`色彩对比（暖与冷）`、`形状对比（圆与角）`、`位置对比（偏与中）`、`疏密对比（密与疏）` 五条黑线词条逐一亮灭。
    3. **构图小法则三勾实时检验**：`明确视觉主体`、`合理运用留白`、`建立视觉动线` 三枚圆底黄勾随当前画板状态实时打勾。
  - **三类核心结论（说清哪几种对比在抵消红圆）**：
    - **过关（动态平衡成立）**：`视觉持平` **且** 至少 **3 项** 对比成立。读数点名当前起效的具体对比组合（如「当前靠**大小、色彩、形状、疏密** 4 项对比合力托住右上朱红大圆……」）。
    - **持平但 0 项对比（放入「红大圆」镜像压平）**：左右重量虽然达到 `视觉持平`，但与右上红圆等大、同色、同圆、同疏密、镜像对位，导致五条对比全灭（`0/5`）——读数直指这已退回[对称构图](https://layout.xiaoxiaodong.ai/018/play/)，平却失去了方向与张力。
    - **未平（偏沉失衡）**：点明当前偏沉方向、已点亮的对比词条，以及还缺哪类异形分量来托住红圆。
- **和最近做完的页不同在哪**：
  - 区别于 **016 居中构图**（双轴天平度数 `9.0°` + 清杂物裁卡纸框）和 **017 偏心构图**（合成重心 + 力臂抵消百分比 + 原地改圆半径）：019 全程**零角度数字、零重心偏离%**, 聚焦「从料盒挑不同形态零件凑足对比去托住主块」，并用五档平衡 + 原海报五线对比词条点亮作为核心读数；也完全不同于 **018 对称构图** 的对折铰链、**101** 的分色大圆与 **239/184/185/267/268** 的 UI 工具台。

## 7. 小练习设计（严格单一变量，由统一 `model.js` 算出）

- **题目**：下面四版 3:4 展览海报，**左上粗黑标题**、**右上朱砂红主圆**以及**左下冷群青直角辅块的色彩、形状与中心位置**完全相同，唯一改变的是**左下群青辅块的面积大小**。哪一版最接近非对称动态平衡？
- **四个选项（标签仅标 `A` / `B` / `C` / `D`，不泄露好坏）**：
  - **A**（极小面积）→ 由 `model.js` 实时算得「重度右沉」（太轻，左方重量点不足，压不住右上红圆）。
  - **B**（偏小面积）→ 由 `model.js` 实时算得「略微右沉」（仍偏轻，画面重心还向右上倾）。
  - **C（正确答案，适中面积）** → 由 `model.js` 实时算得「视觉持平」且多项对比成立（刚好，小体量冷色直角辅块在远位力臂上稳稳托住右上暖红大圆）。
  - **D**（超大面积）→ 由 `model.js` 实时算得「重度左沉」（太重，左下群青块反压过去，失衡且吃掉留白呼吸感）。
- **单一数据源**：四张海报预览的辅块尺寸、揭晓后的平衡档标签、左/右 `●●●●●` 刻点以及各选项解析文案，全部由 `model.js` 实时计算渲染，正文不写死数值。
