# 189 形状文字（SHAPED TEXT）互动页方案

## 1. 一句话道理
几何轮廓替眼睛先画出了“这是一张图”的整体边界，文字再顺着每一行的几何弦宽自然收放、填满内壁，文字群本身就成了图形——读者先被轮廓抓住，再顺行读进内容，把“看图”和“读字”合二为一。

## 2. 开场玩具
- **命名**：活体几何灌字台（基于原海报翡翠绿卵形水滴的 2D Canvas 扫描线逐行排字引擎）。
- **怎么玩**：
  - 拖动紧贴舞台的**字号标尺滑柄**（`data-perf-drag`，也支持方向键微调）改变字号；
  - 拖动**内壁呼吸距滑柄**调整安全内距（`padding`）；
  - 切换 4 种几何容器（**水滴[原海报] / 正圆 / 菱形 / 六边形**）与排列方式（**随形排 / 矩形硬叠**）；
  - 点按**「脱壳验形」**（或按住空格键）隐藏翡翠绿底壳，检验拿掉色块后文字自身边界能否稳稳撑出几何轮廓。
- **开场状态（非答案）**：停在原海报翡翠绿水滴 + 原海报 107 字正文的**「容积超载 · 贴壁溢流」错态**（字号 24.5px 偏大、内壁距 0px 贴壁），实测末尾约 25–30 字直接冲破底尖溢流到绿壳外，且汉字方角紧啃两侧圆弧边缘。
- **怎样算玩错 & 读数怎么说「为什么」**（单真源扫描线实测 + 严格优先级只报主错）：
  1. `矩形硬叠`：字块四角戳破水滴轮廓，实测 N 个字角越界，图和字各说各话。
  2. `容积超载（溢出 > 0）`：字号太大或内距挤占太狠，最后 N 字被截出底尖，信息腰斩。
  3. `贴壁啃边（内壁 < 0.42em 经验下限）`：方块汉字顶撞弧线边缘，视觉上像被剪刀剪毛。
  4. `半空塌底（垂向填满 < 78%）`：字号太小只装了上半截，底壳空出死绿，脱壳后下半轮廓直接塌掉。
  5. `尖角孤字（首/末行仅 1 个汉字）`：收尖处行宽太窄，眼睛一进来就被孤字绊住。
  6. `内缩过深（内壁 > 1.35em 且占积过小）`：壳大字孤，文字退回中间一小团失去图文一体感。
  - 只有同时做到 0 溢流、安全内壁（0.42–1.25em 经验甜区）、垂直填满 ≥ 78%、无 1 字孤行、随形排列，三组原海报折线引注才全部转为成立态。
- **与最近 12 页的区分**：近 12 页无薄荷绿纸 + 翡翠绿主形，无居中雕塑式放射折线引注舞台，更无基于扫描线弦宽实测的“定容灌字 + 贴壁检定 + 脱壳验形”玩法。

## 3. 版式骨架
- **1440×900 / 2560×1440**：忠实延续 189 原海报的「薄荷青纸全幅通栏 + 左上大标与总述 + 中央无外框大翡翠绿水滴 + 左右三组原海报折角细虚线实测活注 + 底沿操控轨与原海报中点尖角细线收口」骨架（2560 放宽容器至 1520px，水滴舞台同步放大不留两边大片空）。无侧栏、无深色仪表盘卡。
- **390×844 手机竖屏**：压缩顶栏与大标，让等比大翡翠绿水滴直接占首屏主体（舞台高度 ≥ 45% 屏高），下方紧接两行 ≥ 40px 触控滑轨与单句白话诊断，一屏同见容器、控件与诊断。
- **844×390 手机横屏**：切换左 52% 等比翡翠绿水滴舞台 × 右 48% 紧凑标题、滑轨操控与诊断，不压扁圆弧。
- **1024×1366 / 768×1024 平板竖屏**：不锁 `100svh`，内容按自身高度自然贴合，避免大段留白。

## 4. 配色和字体
- **配色（实采自 189 原海报）**：
  - 薄荷青纸底 `#D8EADB`（辅纸 `#EEF6F0`、`#F6FBF7`、`#E4F1E7`）
  - 翡翠绿容器 `#0C9468`（高对比加深翠 `#086E4D` / 深翡翠节底 `#084734`）
  - 容器浅叶白字 `#F4FCF6` / `#FFFFFF`
  - 印刷墨黑 `#0B140E`（次墨 `#2D3F34`）
  - 警示朱红（仅用于咬边/溢流标注）`#C93326`（深红底标 `#A82419`）
  - 原海报细线灰青 `#7B9281`
- **字体搭配（全库唯一）**：
  - **`Unbounded`**（最近 12 页未用）：宽圆几何展示无衬线，用于英文主标 `SHAPED TEXT`、大节号 `01`–`08`、英文小标。
  - **`DM Mono`**（最近 12 页未用）：柔和几何等宽，用于几何读数、弦宽与填充率标尺、技术标签。
  - **`Noto Sans SC`**（400–900）：忠实原海报敦实几何黑体气质，用于中文大标、正文与容器内排字。

## 5. 节目录（8 节，标题均 ≤ 12 字，相邻控件完全不重复）
- **01 框叠字，还是字成框？**：拆解原海报总述——交互为**可拖分界对比帘**（左矩形硬叠 / 右弦宽随形，实时透视每行弦线）。
- **02 哪种形状适合装字？**：对比凸形与深凹/锐角形——交互为**六形筛选器 + 断流扫描**（点圆/水滴/菱形/六边形/五角星/月牙，高亮凹口跨沟劈行与尖端孤字）。
- **03 内壁余量与行内对齐**：深翡翠绿锚点节，讲清安全内壁与居中 vs 两端强齐行——交互为**双态切换 + 4× 局部显微放大圈**（链接 178 居中、179 两端对齐、180 强制两端对齐）。
- **04 入壳、外绕、沿线怎么分？**：划清同小类兄弟编号边界——交互为**四空间关系动态剖面卡**（一句话链到 182 轮廓绕排、183 矩形绕排、190 图形诗排版、191 路径文字）。
- **05 从古希腊蛋诗到区域文字**：核实史实四节点——交互为**年代切签联动活体历史排印样张**（前 300 年西米亚斯 / 1499 威尼斯《寻爱绮梦》/ 1918 阿波利奈尔《图画诗集》/ 2014–今 W3C CSS Shapes `shape-inside`）。
- **06 什么时候用，什么时候别用**：温和修正原海报“适用标题、摘要、引导语等多种场景”说得偏宽处——交互为**三段真实业务字量压测器**（8 字短标 / 78 字展签导语 / 252 字多段长文一键灌入水滴实测）。
- **07 小练习：挑出最稳的一版**：实战选型——交互为**A/B/C/D 四版同圆实排盲测 + 一键四版脱壳验证**。
- **08 原海报与五个关键词**：展示 `poster.webp`（点击打开滚轮缩放、鼠标/触摸拖动、`Esc` 关闭灯箱）与原海报五个翠绿圆点关键词。

## 6. 来源（全部核实）
- **罗得岛的西米亚斯（Simias of Rhodes，约公元前 300 年）**：《斧》《蛋》《翼》等图画诗（*technopaegnia*），收入《希腊诗选》（*Greek Anthology*）第 15 卷。核实来源：`https://www.britannica.com/topic/Greek-Anthology`、`https://www.loebclassics.com/view/simias-technopaegnia/1912/pb_LCL028.497.xml`。
- **阿尔杜斯·马努提乌斯（Aldus Manutius，1499 年 12 月，威尼斯）**：《寻爱绮梦》（*Hypnerotomachia Poliphili*）中的圣杯与倒三角（*cul-de-lampe*）活字造型段落。核实来源：`https://www.metmuseum.org/art/collection/search/365354`、`https://en.wikipedia.org/wiki/Hypnerotomachia_Poliphili`。
- **纪尧姆·阿波利奈尔（Guillaume Apollinaire，1918 年 4 月，巴黎 Mercure de France）**：《图画诗集》（*Calligrammes*）。核实来源：`https://www.britannica.com/topic/Calligrammes`、`https://en.wikipedia.org/wiki/Calligrammes`。
- **现代矢量与 Web 标准**：Adobe Illustrator 区域文字（Area Type），以及 W3C CSS Shapes Module Level 1（2014 年 3 月候选推荐，`shape-outside`）、CSS Shapes Module Level 2 与 SVG 2 草案（`shape-inside`）。核实来源：`https://www.w3.org/TR/css-shapes-1/`、`https://drafts.csswg.org/css-shapes-2/`、`https://www.w3.org/TR/SVG2/text.html`、`https://helpx.adobe.com/illustrator/desktop/design-with-text/add-manage-text/add-text-to-vector-artwork.html`。

## 7. 练习
- **题目**：美术馆特展导视牌要做一枚圆形 58 字展签，要求不靠重边框、隐去色底也能一眼认出圆形且近读顺畅。下面四版同圆同字，只差一个变量，哪一版最稳？
- **四选项（标签仅写 A / B / C / D，只差一个变量）**：
  - **A**：字号 16.5px，内壁 0px（装得满但四角啃圆弧，贴壁毛糙）。
  - **B**：字号 13.5px，内壁 11px（安全不咬边但底部空出约 30%，脱壳后下半轮廓塌陷）。
  - **C（正确）**：字号 16.5px，内壁 11px，随形居中（0 溢流、安全内壁约 0.67em、填满约 90%、无 1 字孤行，脱壳仍是饱满正圆）。
  - **D**：字号 16.5px，内壁 11px，两端强齐行（字数与内壁同 C，但窄行字距被硬扯出刺眼白河，阅读节奏断裂）。
