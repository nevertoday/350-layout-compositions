# 259 分屏布局（SPLIT-SCREEN LAYOUT）互动方案

## 1. 一句话道理
分屏布局不是给一页画条竖线，而是把单一视口切分成左右两个视觉极性分明却语义呼应的独立场域——借明暗/色彩反差立住分区边界，借中缝桥接与齐行建立跨屏对话，借动态比例守住视觉张力，借半屏克制保证一眼读懂。

## 2. 开场玩具
- **命名**：双极分屏中缝调度台（Dual-Polarity Split Seam Workbench），开放式 2D Canvas（标 `data-perf-drag`，`touch-action: pan-y`），1:1 承袭 259 原海报的纯黑 `#0F0F0F` × 建筑炭灰 `#404040` × 混凝土浅灰 `#D6D6D6` × 酸青绿 `#BEEB4B` 工业视觉体系，内置原海报三大标本：
  1. **`VS 优势 / 挑战`**（1:1 复刻原海报右中上示例：深黑左屏配绿勾/火箭/靶心/协作 vs 浅灰右屏配黑叉/时钟/警示/乱序，中缝骑跨圆形 `VS` 桥接标）；
  2. **`& 自然 / 设计`**（1:1 复刻原海报右中下示例：深黑左屏配酸绿日轮、缓坡与树 vs 浅灰右屏配黑灰现代几何建筑体块，中缝骑跨圆形 `&` 桥接标）；
  3. **`↔ 极性图式`**（1:1 复刻原海报左中标志图：黑底绿圆 `↔` 绿底黑圆的阴阳反转对位图）。
- **怎么玩**：
  - 在画布上**左右横拖中缝虚线（或画布任意横向拖动）**，实时推拉分屏比例（`18:82` 至 `82:18`），左右两屏内真实图文、图标行与几何插画同步重排缩放，靠近 `50:50`、`40:60`、`60:40` 时轻柔吸附；
  - **直接点击左右两屏的底色区（或下方极性钮）**切换四套原海报极性表面（纯黑 / 炭灰 / 浅灰 / 酸绿），实测 WCAG 亮度对比度与视觉极性；
  - **直接点击中缝桥接徽章**在「无桥错行（错）」「对齐桥接 `VS`/`&`/`↔`（对）」「厚墙割裂（错）」间切换；
  - 切换**信息密度**（克制 3 组 vs 满塞 6 组过载）与**模拟视口**（桌面 `1280px` vs 手机 `390px` 硬切分屏/上下堆叠）；
  - 按 `←`/`→` 精调分屏比例、`↑`/`↓` 切中缝模式、`Space` 演播「跨缝视线对读脉冲」。
- **一打开是什么状态（刻意停在 0/4 四重复合错态）**：
  - 比例停在 **`74 : 26`**（左屏过肥挤压右屏，退化成畸形侧边栏）；
  - 左右底色同为接近炭灰（`#444542` vs `#4E4F4B`，亮度反差仅 `1.1:1`，完全看不出双极分区）；
  - 中缝处于**断联错行态**（无 `VS` 桥接标、右屏对照行整体下沉 `+28px`）；
  - 内容处于**满塞过载态**（半屏塞入 6 组密排项与干扰角标，实测留白跌破 22%）。
- **怎样算玩错、错了读数怎么说（`model.js` 单真源，覆盖 8 类双向错态）**：
  - **对比 CONTRAST**：同底糊灰（两屏亮度比 `< 2.6:1`）判错；双侧同时满铺高饱和酸青绿（`lime + lime` 荧光互炸）也判反向错态。
  - **对话 DIALOGUE**：无桥接且对照行错开 `+28px` 判错；中缝砌成 `44px` 粗墙硬切两张孤立海报也判反向错态。
  - **张力 TENSION**：左偏 `> 65%` 挤碎右屏、或右偏 `< 35%` 挤碎左屏均判错，直接报实绘窄屏像素宽与折行压力；接受 `50:50`（对称交锋）、`42:58` / `58:42`（非对称主次）多组合法解。
  - **清晰 CLARITY**：半屏满塞 6 组字墙（留白 `< 28%`）判错；手机 `390px` 仍强行左右硬分屏（单侧 `< 195px` 挤成竖条）同样判错。
- **和最近 12 页的区别**：
  - 256 双列页面在同一张米纸上调栏距、基线与墨量配重；258 侧边栏页面刻意要把侧栏压到 18%–26% 做从属导航；259 分屏布局恰恰相反——要求左右双极势均力敌、明暗极性反差、中缝语义桥接与窄屏折叠堆叠，开场直接用原海报「纯黑×炭灰」双全出血双翼结构承托 2D 分屏中缝工作台，玩法、骨架、配色、字体与近 12 页及 256/257/258 全部拉满差异。

## 3. 版式骨架
忠实转译 259 原海报自身「左 44% 纯黑极性翼 × 右 56% 建筑炭灰工作翼」通高双全出血分屏骨架（零通用灰顶栏、零独立悬浮仪表箱、绝不锁 `100svh` 避平板空洞）：
- **1440×900（主宽 1380px，2560 舒展至 1680px）**：双底色沿 44% 处无缝全出血切分；左翼放自示范大标「分屏 / 布局」+ 实时分屏比律动条 + 精炼总述 + 4 枚交替酸绿/炭灰圆徽实时探针 + 底部原海报同款酸绿细框灯泡单真源诊单盒；右翼放三标本与视口切签 + 开放式 2D 分屏中缝画布 + 紧凑细线极性/桥接/多解控轨 + 底部深炭圆角宣言条，左右双翼齐底零空白。
- **1024×1366 & 768×1024**：自然流排，顶部紧凑纯黑刊头 → 满宽建筑炭灰分屏画布与控轨 → 下方双列齐底（左：酸绿框单真源诊单盒；右：2×2 四要点圆徽探针）。
- **390×844**：顶部压紧单行纯黑刊头（标题 + 实时评定标）+ 紧凑三标本切签 → 等比 2D 分屏画布稳占首屏 ≥ 46% → 折线内直接露出酸绿框诊单首句与一键纠偏钮；总述文字与四要点详情自然置后，零压缩变形。
- **844×390 横屏**：左 56% 标本切签与等比画布 × 右 44% 精简刊头、单真源诊单与纠偏按钮并行。

## 4. 配色和字体
- **逐像素实采自 259 原海报（纯无彩色建筑工业黑灰 + 招牌酸青绿）**：
  - 纯黑左翼与暗室：`#0F0F0F`（深底 `#080908`、暗舱 `#181917`、暗线 `#2B2D28`）
  - 建筑炭灰右翼与考场：`#3D3E3B` / `#404040`（深炭底条 `#262624`、炭舱 `#2E2F2C`）
  - 混凝土浅灰与阅读浅纸：`#D6D6D6`（画廊白 `#F4F5F1`、混凝土浅雾 `#E6E8E2`、卡片白 `#FFFFFF`）
  - 招牌酸青绿：`#BEEB4B` / `#C2EC4C`（暗底高亮字 `#BEEB4B`；浅纸安全高对比深苔绿字 `#314D00` 或黑字 `#0F0F0F` 压在 `#BEEB4B` 实体标块上）
  - 信号警示赤：`#C42B23`（浅纸）/ `#FF6B61`（暗底）；通过翠绿：`#1D6E42`（浅纸）/ `#6CE09E`（暗底）
- **字体搭配（全库 0 重复，与 258 零西文/等宽重合，且 3 款西文/等宽在近 12 页 0 次使用）**：

  - `Unbounded`（500 / 700 / 800，**近 12 页 0 次使用**）：英文展示大标、章节序号与中缝 `VS` / `&` 徽标
  - `Bricolage Grotesque`（400 / 600 / 700，**近 12 页 0 次使用**）：英文副标、标本栏标与结构术语
  - `DM Mono`（400 / 500，**近 12 页 0 次使用**）：分屏比例、WCAG 对比度、模拟像素宽与 CSS 代码

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻节不复用同款交互控件）
- `01` **为什么一分为二更省脑力** (`WHY POLARITY SHARPENS CHOICE`)：解释同屏并行对比如何降低工作记忆往返负荷，并一句话链接 `256 双列页面`、`258 侧边栏页面`。交互：串行长页 vs 极性分屏三任务对照模拟器（带实时视线折返次数示意）。
- `02` **四种分屏关系与中缝语法** (`FOUR SPLIT ARCHETYPES`)：拆解原海报四种用法对应的网页结构（50:50 双极对照、图文对仗、Sticky 固屏叙事、前后拉帘）。交互：四型可操作微界面（含真实可滚 Sticky 固屏与横向拉帘滑块）+ 对应 CSS 声明。
- `03` **反差的度：别做成双屏互炸** (`POLARITY LIMITS & TRAPS`)：纯黑暗室，温和修正原海报「对比呼应，价值加倍」的「说多了一点」——过高饱和双亮底与双主 CTA 会引发视觉疲劳与选择瘫痪。交互：双屏底色矩阵搭配器 + 双主 CTA 抢戏开关与实时 WCAG 亮度对比表。
- `04` **分屏布局从哪来** (`FROM DIPTYCH TO CSS GRID`)：约 1395–1399 威尔顿双联画 → 1913 洛伊斯·韦伯《悬疑》银幕分格 → 1968 恩格尔巴特 NLS 动态分窗 → 2017–2018 W3C CSS Grid/Flexbox 与 Sticky。交互：四纪元横轴切页与可切换 SVG 建筑结构图。
- `05` **什么时候用，什么时候别用** (`WHEN TO SPLIT & WHEN TO STACK`)：明确适用场景与五条禁用红线（一句话链接 255 / 256 / 257 / 258 / 265 / 267 / 268），重点说明移动端强行分屏的弊病。交互：360px–1440px 连续断点拉尺（切换「响应式折叠」vs「窄屏硬撑分屏」实时观察文字挤碎）。
- `06` **小练习：挑出最稳的分屏** (`PRACTICE · SPOT THE SOUND SPLIT`)：炭灰暗场考区，单变量四选一实战。交互：A/B/C/D 独立微缩图谱选项卡与结构级解析。
- `07` **原海报与同族布局** (`ORIGINAL POSTER & SIBLINGS`)：可点击放大、滚轮缩放、拖拽浏览、Esc 关闭的原海报，配双语关键词与 255–268 同小类全员链接导航及合规页脚。

## 7. 练习
- **题干**：桌面端（1280px）产品定价页准备用分屏布局并列呈现「团队标准版」与「企业定制版」，帮访客在首屏快速对比。以下四版骨架一致，但在**左右底色反差、分屏比例与半屏信息量**上每次只改变一个变量，哪一版最稳？
- **四选项（中性字母与客观参数标签，只差一个变量，答案在 B）**：
  - **A**：比例 50:50 · 左右底色 `#464644` / `#50504E` · 中缝 `VS` 齐行 · 每侧 3 条要点（仅极性反差不足，1.15:1 同灰糊成一片）。
  - **B**：比例 50:50 · 左右底色 `#0F0F0F` / `#D6D6D6` · 中缝 `VS` 齐行 · 每侧 3 条要点（**正确**：明暗两极分明、比例对等、中缝桥接呼应、信息克制好扫）。
  - **C**：比例 76:24 · 左右底色 `#0F0F0F` / `#D6D6D6` · 中缝 `VS` 齐行 · 每侧 3 条要点（仅比例极偏，右屏被压成窄条失去平等对比张力）。
  - **D**：比例 50:50 · 左右底色 `#0F0F0F` / `#D6D6D6` · 中缝 `VS` 齐行 · 每侧 9 条密排细则（仅信息过载，半屏塞满长清单导致清晰度崩塌）。
