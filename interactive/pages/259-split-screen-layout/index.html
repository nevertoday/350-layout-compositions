01

为什么一分为二更省脑力

WHY POLARITY SHARPENS CHOICE

原海报点出核心价值：「通过左右分区的对比与呼应，增强信息的组织力、说服力与视觉秩序。」在认知层面，当读者需要在两个方案、正反论点或前后状态之间做判断时，上下长页逼人把前一段塞进工作记忆里再往下翻；而把两者压进同一视口左右并置，比较就从「凭记忆回想」变成了「眼球水平扫视」。Nielsen Norman Group 对产品对比表的研究也指出，并列对照之所以有效，在于它帮用户把属性对齐到同一视野里，省去反复来回切换的认知成本。

它和同家族的另外两种双区结构有明确分工：256 双列页面是在同一张底纸上把连续正文折成两栏，重点是缩短行长与防跨栏串行；258 侧边栏页面刻意让导航栏退居约 18%–26% 的从属窄条；唯有分屏布局让左右两极势均力敌、底色反差鲜明，用一条中缝把整屏变成双极舞台。

03

反差的度：别双屏互炸

POLARITY LIMITS & VISUAL TRAPS

说多了一点

海报写「对比呼应，价值加倍」「色彩、明暗、大小对比，强化视觉冲击」。反差确实是分屏的灵魂，但对比不是越刺眼越有效：当左右两屏同时铺满高饱和荧光色，或两边都挂着同等强度的主行动按钮，读者视线会在两极之间反复弹跳，反而产生选择瘫痪与视觉疲劳。真正耐看的分屏遵循「一极高光或深沉锚定 + 另一极中性灰白退让」，且两屏内部正文都必须守住 W3C WCAG 2.1 最低文本对比度标准（正文 ≥ 4.5:1，大号字 ≥ 3:1）。

04

分屏布局从哪来

FROM DIPTYCH TO CSS GRID

把视野沿一条垂直轴一分为二，并不是网页时代的新发明。从十四世纪的铰链橡木双联画、默片银幕的多线并置，到 1968 年第一块动态切分的计算机屏幕与现代 CSS Grid，分屏一直在解决同一件事：如何让两套独立叙事在同一刻对话。

05

什么时候用，什么时候别用

WHEN TO SPLIT & WHEN TO STACK

适合用

两极明确、内容精炼的决策屏

  • 双入口分流：首页让两类受众（如个人版 vs 团队版、买方 vs 卖方）第一时间各走各路。
  • 优劣与前后对照：左右逐行对齐呈现两套方案差异，或用拉帘呈现改造前后。
  • 强视觉 + 简短宣言：一侧锁定品牌主图或产品立体展示，另一侧配不超过三段的精炼叙述与行动钮。
  • 双观点并置：像原海报的「自然 & 设计」，用视觉极性强化概念张力。
别硬用

这五种情况请立刻换布局

  • 只有一条连贯主线：没有真正的第二极，强拆两半只剩空洞配图 → 改用 255 单列页面。
  • 长文深度阅读或目录跳转：需要长距离滚读与常驻索引 → 改用 256 双列页面 或 258 侧边栏页面。
  • 三个及以上并列维度：把屏幕硬切成三四条会迅速压碎行宽 → 改用 257 三列页面 或 265 标签页布局。
  • 高频筛选列表与主辅工作台：左选右看详单或附加检查器 → 改用 267 列表—详情布局 或 268 辅助窗格布局。
  • 手机竖屏强行左右硬分：小屏已经够窄，再腰斩会让两半都无法阅读；跨过窄屏断点必须改为上下堆叠。
