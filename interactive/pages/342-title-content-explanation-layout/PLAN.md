# 342 内容与标题说明 幻灯片版式 · 设计与交互方案

## 1. 一句话道理
解释型幻灯片之所以能在 5 秒内让观众听懂并信服，靠的不是把文字塞满页面，而是用「一句核心论断标题 → 由总到分的三步逻辑链（01 提出观点 → 02 解释说明 → 03 总结升华）→ 精选短句支持模块 → 全页唯一强色收口」四层秩序，把演讲者的推理骨架直接显形在屏幕上。

## 2. 开场玩具：活体幻灯片解释架构台 · 5 秒演讲预演器
- **承袭与专属动作**：1:1 承袭 342 原海报鼠尾草绿底纸、左侧四枚深苔藓绿圆徽探针、细竖虚线解剖树与右侧象牙米白圆角幻灯片实卡，内置三套演讲剧本（`原海报 · 沟通结构` / `产品复盘 · 留存分析` / `工程方案 · 架构演进`）与前后三页演讲翻页语境（`01 节标题 337` / `02 本页 342` / `03 图片说明 343`）。
- **怎么玩**：
  1. **画布直接横拖（`data-perf-drag`）**：拖起 `01 / 02 / 03` 任意逻辑卡片横向滑动并实时互换顺序，感受逻辑顺流与倒挂的区别；在卡片之外横拖或推拉底部滑尺，连续调节左对齐错牙与呼吸留白密度。
  2. **画布内原地点击手术**：直接点击幻灯片上的「标题区」「三步连接箭头」「支持模块 4 槽」「底部赤陶核心提示」，在常见坏写法与清晰结构之间切换。
  3. **按 `Space` 或点「5 秒扫视」**：发射模拟观众真实 5 秒扫视光晕与目光停留路径（路线严格由 `model.js` 根据实绘字号层级、色块吸引权重与逻辑顺序实时算出），验真观众 5 秒内是否抓得住主旨。
  4. **点左侧 4 枚原海报圆徽探针（层级 / 对齐 / 阅读节奏 / 强调重点）**：聚焦高亮对应区域并显示单真源诊断。
- **开场状态（不是答案）**：刻意停在 `0/4` 灾难初稿态——干瘪名词空标题（字号塌平）+ 三步顺序倒挂成 `03 → 01 → 02` 且左缘参差错牙 + 支持区 4 槽塞满密字 + 全页多处乱涂赤陶强调色 + 留白窒息。
- **怎样算玩错、读数怎么说**：`model.js` 从实绘几何包围盒、层级比、逻辑序列、支持槽负荷与强调色面积占比单真源双向检出 9 类正反错态（名词空标题 / 长段标题塌平层级 / 逻辑倒挂 / 退化平铺列表 / 左缘参差错牙 / 留白窒息 / 留白过空挤碎卡片 / 证据密字超载或空洞无据 / 强调色泛滥或通篇平淡），不仅报状态档位（示意），还用白话说清「观众此刻视线会卡在哪里、为什么读不懂」。
- **多解认可**：不逼唯一死答案，认可「原海报典范解（4 槽精简短句）」「极简聚焦解（精选 2 槽证据 + 宽留白）」「数据主攻解（重数据与行动双证）」等多组合法解。
- **与最近 12 页及同小类的差异**：区别于 336 的左文右图双栏拉比、337 的三页换气胶片、341 的空白画布摆焦点，也完全不同于最近 12 页的绕排、抽屉、行内、块级与天平；342 独家围绕「可拖换三步逻辑卡 + 四层解释手术 + 5 秒演讲扫视测时」展开，别的编号无法原样套用。

## 3. 版式骨架
- **1440×900（主宽 1360px）与 2560×1440（舒展至 1620px）**：1:1 转译 342 原海报展页骨架，绝不锁 `100svh`。顶部鼠尾草纸开放刊头（赤陶短杠 + 自示范双行大标 + 宽距英文对望右上淡圆弧、点阵与三剧本切签）；中段左 24% 融纸四枚深苔藓圆徽实时探针（左缘半露赤陶大圆）× 细竖虚线解剖树 × 右 76% 象牙米白圆角幻灯片实卡（顶沿三页翻页条 + 高清 2D Canvas + 内嵌单真源白话诊单与精控条，左右齐底）；底沿还原圆角黑线「设计建议」长胶囊与右下 6 道等距阶梯细线。
- **1024×1366 / 768×1024 平板**：自然流满宽呈现象牙幻灯片实卡，四枚圆徽探针折排为 4 列（或 2×2）轻横带，杜绝竖屏大片空白。
- **390×844 手机竖屏**：极度压紧顶部单行刊头，把三剧本与四探针移到幻灯片卡下方，让等比缩放的高清幻灯片画布稳占首屏 ≥47% 视口高度，且折线内直接露出单真源白话诊单首句、对齐留白主滑尺与「一键校准 / 5 秒扫视」双键。
- **844×390 手机横屏**：左 57% 等比活体幻灯片画布 × 右 43% 紧凑刊头、白话诊单与核心按钮并行，无横向溢出。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻控件绝不重复）
- `01` **四根结构柱**：展开原海报左列「层级 / 对齐 / 阅读节奏 / 强调重点」四原则。交互：**四层 X-Ray 透视剥离灯箱**（单选或叠加剥离四层结构线，看见缺任一层即崩塌）。
- `02` **标题先给结论**：讲清「主题名词标 vs 一句断言标」，并温和修正「标题简短 ≠ 空壳四字」。交互：**三幕台词改写对照拨盘**（切换 3 种标题写法，实时看后排观众 3 秒复述气泡变化）。
- `03` **证据别抢主线**（深苔藓暗室）：剖析上层三步叙事链与下层支持模块的权责主次。交互：**证据载荷配重与认知流向切片机**（自由增删 0–4 类支持槽并调文字密度，动态 Canvas 呈现注意力流向与负荷警戒示意）。
- `04` **它从哪来**：串联 1978–1987 金字塔原理、1987 PowerPoint 1.0、2001 多媒体认知理论与 2003–2005 断言-证据模型。交互：**四时期幻灯片标本翻页镜**（点击年代节点切换对应时期的微型幻灯片实景标本）。
- `05` **什么时候别用**：给出 4 类明确禁用场景并分流到同小类兄弟页（335/336/337/338/339/340/341/343 均带在线链接）。交互：**四场景分诊决策卡**（点场景亮出红绿分诊牌与匹配兄弟版式骨架）。
- `06` **小练习：一页定高下**（深苔藓暗室）：单一变量四选一实战判题。交互：**四张等文案微型幻灯片 SVG 盲选判题卡**（中性标签，选后逐项拆解）。
- `07` **原海报与索引**（鼠尾草展墙 + 极深苔藓页脚）：展示原海报并支持点击放大灯箱、拖拽平移、缩放与 Esc 关闭，附完整原话索引与同小类全览导航。

## 7. 练习设计
- **题目**：你要在 45 秒内向决策层讲清「新版引导流程将首日留存推升至 48%」。下面四张幻灯片文案素材、配色、左对齐与留白比例完全一致，只差**信息层级与强调结构**这一个变量，选出传达最清晰的一页。
- **四个中性选项**（卡片标签仅中性描述版式形态，不泄露好坏）：
  - 选项 A（短词标题 · 四点列表）：顶部写主题词「引导流程优化」，下方四条无编号平铺要点。
  - 选项 B（单句标题 · 三步单色，正确）：顶部一句话断言结论，中段 `01→02→03` 递进展开，下层精选两枚短句证据，赤陶色仅用于底部核心提示。
  - 选项 C（单句标题 · 四区暖色）：顶部一句话断言结论，中段 `01→02→03` 递进展开，但标题、三步徽章、支持模块与底部横幅四处同涂赤陶高光。
  - 选项 D（三行标题 · 三步单色）：顶部塞入三行 48 字长段说明，中段 `01→02→03` 递进展开，底部单色核心提示。
- **正确答案理由**：方案 B 同时守住「结论先行、纵深有秩、证据克制、唯一强调」四条结构柱；A 缺结论与逻辑链，C 因多处高亮导致重点自我抵消，D 因标题区膨胀压塌了标题与内容的字号层级差。
