# 245 居中器 CENTERER · 互动版设计方案

## 1. 一句话道理
居中器不是把所有元素和文字死钉在画面 50%，而是用「可读行宽上限（`max-inline-size`）+ 自动对称余白（`margin-inline: auto`）+ 窄屏护边（`padding-inline`）+ 溢出安全纵轴（`safe center`）」，让内容从宽屏到手机始终稳居视觉焦点，既不横向拉散、也不贴壁或被矮屏吞掉顶边。

## 2. 开场玩具：活体居中器视口伸缩台（Axial Viewport Calibrator）
- **怎么玩**：
  - 在 1:1 承袭 245 原海报腮红暖纸、四角珊瑚定位角标、X/Y 虚线标尺与四组珊瑚点阵的开放十字轴舞台上，用户直接**左右横拖模拟视口边墙（`data-perf-drag`）**，把模拟浏览器视口在 `320px–1320px` 间连续伸缩，实时观察左右 `margin-inline: auto` 呼吸翼、深松绿居中盒与窄屏护边如何响应；
  - 可切换 **3 套真实题材**（原海报靶盒 / 长文专栏 / 居中弹窗）、调节模拟视口高度（桌面高窗 vs 横屏矮窗）、直点画布红标纠错或调节下方三栏参数（行宽上限 `max-inline-size`、内护边 `padding-inline`、水平与文字策略、垂直溢出策略），亦支持键盘方向键微调。
- **开场初始状态（0 / 4 待校准，绝不提前给答案）**：
  - 模拟视口处于 `1140px × 268px`（宽而偏矮的压力测试窗），同时预埋 4 处真实工程错态：
    1. 未设行宽上限（`max-inline-size: none`），宽屏内容被横拉到 `1140px`（≈ 71 汉字/行），左右 X 轴自动余白归零；
    2. 内护边 `padding-inline: 0px`，窄屏检查零缝贴壁；
    3. 正文误开 `text-align: center`，把「块体居中」与「文字居中」混为一谈，左右边缘锯齿跳动；
    4. 垂直采用 `unsafe center`（裸 `align-items: center`），在当前矮窗下盒顶被推入负坐标裁切，无法向上滚回。
- **怎样算玩错、错了读数怎么说**：
  - 所有几何尺寸、单行字数、360px 窄屏剩余芯宽、顶边负坐标裁切量、CSS 代码全部由 `model.js` 单真源实时算得；
  - 玩错时（如行宽拉超 `780px` 引发宽屏拉丝、压窄低于 `280px` 引发狭缝碎行、护边设为 `0px` 导致窄屏贴壁、护边过大导致窄屏芯宽不足、改用写死 `margin` 导致 390px 横向溢出、打开正文居中造成行首锯齿、或用 `unsafe center` 导致矮屏顶边溢出不可滚），画布立刻浮出对应珊瑚红警示纹与偏移量，中栏诊单用白话说清「用户眼睛或滚动条会发生什么」并给出下一步尝试方向；
  - 接受标准阅读解、紧凑卡片解、宽版图文解等多组合法解，只要四项准则同时达标即判定 `4 / 4 已校准`。
- **与最近 12 页的差异**：
  - 开场交互以「横拖伸缩模拟浏览器视口边墙验证响应式居中策略」为核心动作，不同于 244（盒模型四层剥层）、243（堆栈插删调序）、202（网格间距）、285（分步表单切点）、035/034/071/073/118/157/158/323 的任何一页；别的排版原语无法原样套用这套视口边墙伸缩 + `safe center` 矮屏吞顶检验台。

## 3. 版式骨架
- 直接承袭 245 原海报的「**全幅腮红暖纸 × 四角珊瑚定位角标（┌• ┐• └• ┘•）× 顶沿 Y 轴虚线居中刊头 × 满宽十字轴视口舞台 × 底部细竖线三栏实况带（水平居中 ALIGN | 垂直居中 CENTER | 对齐焦点 FOCUS）**」对称骨架（不设暗色顶栏、不设左右仪表盘侧栏、不锁 `100svh` 避开竖屏平板空洞）：
  - **1440×900 / 2560×1440**：主宽 `1360px`（2560 舒展至 `1680px`）；顶沿 Y 轴虚线贯入「居中器」自示范大标（左右珊瑚标尺随当前居中宽实时张合），其下满宽居中舞台，底沿等高三栏将「水平控轨 / 单真源白话诊单与实算 CSS / 焦点题材与多解切换」自然归位原海报三要点。
  - **390×844（手机竖屏）**：顶刊压紧为单行标题 + 状态徽标与紧凑题材切换，等比十字轴画布稳占首屏 ≥ 46% 屏高，首屏底沿直接露出中栏诊单首句；下方三栏顺次纵向排开。
  - **844×390（手机横屏）**：切为左 56% 交互舞台 × 右 44% 紧凑刊头、白话诊单与核心快捷控槽并行，无纵向挤压与横向溢出。
  - 正文 01–07 节在亮腮红纸 `#FFF7F4`、淡松雾纸 `#EDF4F0`、03 节深松绿暗室 `#06281C`、原海报腮红纸 `#FEECE7` 与暖玫瑰砂纸 `#F7E2DB` 间明暗交替。

## 7. 小练习设计
- **题干**：一栏中文技术长文需在 1440px 宽屏与 390px 手机上共用同一居中器（16px 正文），下面四份 CSS 哪个在两端都不会出问题？
- **四选项（仅标 方案 A / B / C / D，纯中性代码与双屏示意图，只差「行宽上限 + 护边」组合）**：
  - 方案 A：`max-inline-size: none; padding-inline: 24px; margin-inline: auto;`（宽屏失控拉到 1392px）
  - 方案 B：`max-inline-size: 38ic; padding-inline: 0; margin-inline: auto;`（手机零缝贴壁）
  - 方案 C：`max-inline-size: 38ic; padding-inline: 24px; margin-inline: auto;`（**正解**：宽屏封顶 38 汉字，手机自动收缩并保留 24px 护边）
  - 方案 D：`width: 608px; padding-inline: 24px; margin-inline: auto;`（把上限错写成定宽，390px 手机横向溢出撑爆）
- **正解理由**：同时具备「弹性上限 `max-inline-size`（而非定宽 `width`）」与「非零内护边 `padding-inline`」，既守住宽屏阅读行长，又让窄屏按容器自动收缩且不贴壁。
