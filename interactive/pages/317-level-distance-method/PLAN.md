# 317 · 平远法（LEVEL DISTANCE METHOD）互动页方案

## 1. 一句话道理
人眼双眼横向视域（约 180°–200°）天然宽于纵向（约 135°），当画面以稳定平直的眼平地平线为轴、借近重远淡的空气明晦与舒展横带横向推开空间时，视线不再被迫仰冲或钻洞，而是顺着水平基线缓缓铺展，从而生出开阔、安定、冲融缥缈的空间秩序。

## 2. 开场玩具：平远手卷展平与横带排布台
- **怎么玩**：
  - 全宽通栏「青灰素宣平远长卷」2D Canvas 舞台 + 贴合画布底沿的**手卷展平轴尺（`data-perf-drag`）**，忠实化用 317 原海报的通幅水平线、淡烟多层远岫、归鸿飞鸟、落日朱阳、水波虚线倒影及三道横带（深松近岸长条 / 烟灰中洲细条 / 朱橙点睛方条），支持切换「原海报平远 / 宋元江渚 / 宽银幕原野」三种题材。
  - **拖展卷轴**：左右拖动底沿展平轴尺（或在画布左右绫边直接横向拖拉，亦支持键盘 `←/→` 微调），把被挤压的窄画幅顺滑展成开阔宽卷。
  - **直拖地平线与调平**：在画布拖拉地平线高低或旋转调平端钮，把倾歪的地平线校至水平 `0°`（±1.8° 内轻吸附），并调到舒适的平视带（34%–66%）。
  - **拨动三道横带**：直接在画布上左右拖动深松近岸、烟灰中洲、朱橙点睛三条横带，拉开疏密错落、不挤叠的水平韵律（接受多种合法解：原海报左重右轻、一河两岸高平水阔、低平开天、镜像平衡均可过关）。
  - **点除竖向杂障 & 调远近明晦**：直接点击画布中刺破地平线的 3 处竖向杂障将其撤去；推动远近明晦滑杆，将僵硬焦黑的远山化成「有明有晦、冲融缥缈」的空气层次。
- **一打开是什么状态（0/4 翻车错态，绝不预给答案）**：
  - 卷轴被左右绫边挤成 `0.68:1` 窄竖条（平阔未展）；
  - 地平线倾歪 `+9.0°` 且高悬在 `24%` 处（既失水平又呈高俯压迫）；
  - 画布中插着 3 处刺断地平线的竖向杂障，三道横带撞叠在中央；
  - 远山与近岸同为生硬重墨（空气淡化 6%），全幅贴扁无远近感。
- **怎样算玩错、错了读数怎么说**（全部由 `model.js` 从实绘几何与色值单一真源实时核算）：
  - `窄幅憋闷`（展幅宽比 < 1.50:1）：视线刚起步就撞上左右绫边，横势拉不开。
  - `地平倾斜`（|倾角| > 1.2°）：哪怕偏斜 3° 以上，前庭与视觉系统都会把水面读成晃动与不安。
  - `高俯压迫`（地平线 < 32%）/ `仰望转高远`（地平线 > 68%）：前者把画面压成俯视地图，后者滑向 315 高远法的仰视节奏。
  - `杂竖断线`（竖向干扰 > 0）：水平线被竖块斩成碎段，宁静延续被打断。
  - `横带挤叠`（三横带碰撞重叠或展宽 < 68%）：色块扎堆在同一侧，水平基底失衡。
  - `远山焦黑`（空气衰减 < 32%）：远山和近岸一样黑硬，十里烟波贴成一堵纸墙。
  - `白雾吞山`（空气衰减 > 86%）：远山化进白底消失无踪，失掉「望远山」的远景锚点。
- **和最近 12 页的区别**：
  - 不同于 316（暗底 Z 轴重门穿透）、315（居中竖立轴 + 仰角推尺）、194（书页四边裁边距）、277（卡片时序排序）、109（30° 斜轴脉冲乐谱）、064（圆点拓扑连线）、276（卡片轮播露边）、193（横排文字行长校样）——317 是**通幅满屏横向展卷 + 调平地平线 + 拨排水平色带 + 空气明晦分层**，玩法直接长自平远法手卷本身。

## 3. 版式骨架
- 忠实承袭 317 原海报「青灰素宣通栏横展」开放骨架（零圆角深色仪表盘侧栏感，不锁 `100svh` 避开平板大片留白）：
  - **1440×900**：极细 34px 眉条 → 开放刊头（左：随展幅同步轻扩字距的示范大标「平远法」+ `LEVEL DISTANCE METHOD` + 总述；右：原海报同款细圆印章「视觉组织/方法」+ 实况态章 + 题材切签）→ **通栏无外框满幅 2D Canvas 平远长卷舞台** + 紧贴底沿的**手卷展平轴尺** → 下接原海报标志性的**细竖线三栏原则实检与控参列**（深松圆点·平阔展开 / 烟灰圆点·地平线感 / 朱橙圆点·宁静延伸）→ 底部承接原海报同款左 `7×3` 点阵+关键词 × 右**右下折角矩形实测诊单笺**。主栏宽 1380px，长卷舞台可舒展至通栏。
  - **2560×1440**：主容器舒展至 1840px，长卷舞台通栏开阔，三栏与折角笺比例饱满。
  - **1024×1366 / 768×1024**：自然流式排布，不锁 `100svh`，三栏在 768 保持紧凑或折为清晰网格。
  - **390×844**：压紧单行刊头，让等比长卷舞台 + 48px 手卷展平轴尺稳占首屏 ≥46% 屏高，并在首屏下方同步露出折角诊单首句与状态，所有圆点保持正圆不变形。
  - **844×390 横屏**：切换左 58% 长卷舞台+展平轴尺 × 右 42% 刊头、折角诊单与精简控参并行，首屏完整可用。

## 7. 小练习设计
- **题目**：同一张「秋水江南」宽幅海报，四稿的画幅宽比（2.2:1）、水平地平线（0°、52% 高度）、山峦轮廓与右端落日完全一致，唯独「近中远三层的明晦深浅关系」不同。哪一稿最符合平远法？
- **四个选项（单变量，中性标签 方案 A / B / C / D）**：
  - **方案 A**：近岸、中洲、远山全用同等深墨（全深平贴，缺远距空气衰减）。
  - **方案 B（正确）**：近岸深松压脚、中洲烟灰过渡、远山淡青融雾、朱橙落日点睛（正合「有明有晦」，空间逐层推远）。
  - **方案 C**：近岸极浅、远山最黑（明晦倒挂，远山反扑到眼前）。
  - **方案 D**：三层全为极浅淡雾、近处无深墨锚点（全幅发飘，失去尺度参照）。
