# 160 封面版式（COVER LAYOUT）互动页设计方案

## 1. 一句话道理
封面版式不是内页内容的缩略目录，而是信息世界的第一扇门：靠「识别身份 → 锁住视觉焦点 → 明确主题标题 → 留出呼吸入口」四级视觉漏斗，让读者在 2 米远距与 3 秒扫视里一眼看懂并愿意翻开。

## 2. 开场玩具：「推门见封 · 活体封面打样与 2.5 米书架验视台」
- **怎么玩**：
  - 舞台中央是一张 3:4 真实出版装帧比例的 2D Canvas 活体封面（自带书脊压槽、出血裁切参考线、金箔颗粒质感与可推开的透视门扉光毯），支持三套题材切换：**「原海报 · 入口之门」**（1:1 承袭 160 原海报箔金日轮、酒红月、象牙门扉与金斜线）、**「建筑季刊」**（现代杂志刊头 + 建筑剪影门廊）、**「文学平装」**（企鹅/典籍结构 + 站酷小薇书名）。
  - **画布直操**：在主封面画布（标 `data-perf-drag`，`touch-action: pan-y` 保证手机竖向可滚）上，直接左右横拖滑移视觉焦点重心（箔金日轮与入口门）或直接拖拽标题框调整落位；点击封面上抢戏的冗余宣传语条和「重磅推荐」贴纸逐条清除，每清掉一处杂讯，象牙白入口门就向外推开一寸、光毯亮起一分。
  - **联动操控**：可连续调节「主标/副标字号比（1.0×–4.8×）」与「视觉焦点体量（12%–68%）」，切换「识别带位置（右下躲藏 / 贴边危险 / 左上安全 / 顶栏通栏）」，以及一键开启**「报摊叠放遮挡线」**（显示书架前排邻书会挡住右侧与底部的真实禁区）。
  - **专属副镜**：旁边紧贴一个实时同步降采样渲染的**「2.5 米书店远距缩略验视镜」**，把当前封面实时画成缩略虚焦状态，让读者亲眼看到 30cm 桌案上看似饱满的字，在 2.5 米外怎么糊成一团。
- **一打开是什么状态（绝不先给答案）**：
  - 刻意停在 **0/4「失焦杂封 · 门扉紧闭」** 错态：主副标字号比仅 1.15×、主标落于亮金高光区对比度不足 2.5:1、4 条冗余卖点与促销贴纸堵在门洞前、出版识别标缩在会被书架挡死的右下角、焦点与标题框互相冲撞。入口门几乎闭合，远距验视镜一片混沌。
- **怎样算玩错？错了读数怎么说？**
  - `model.js` 作为唯一真源，从实绘像素框、字号比、真实 WCAG 相对亮度对比度、焦点/主标重叠面积比、杂讯条数与书架叠放区露出率实算诊出 **8 类封面错态**：层级平权、对比融底、杂讯堵门、图字互殴、识别被挡、主标过胀撞边、焦点怯小失势、焦点盖死刊头。
  - 每种错态都给出一句直白人话（说明读者在 2 米外会怎么看偏）和一步可操作的指引，并接受「原海报入口解」「观念大图解」「报摊安全解」多组合法解。
- **和最近 12 页的区别**：
  - 避开了 159 浮动卡片、325 折枝对开、036 C 弧、120 围栏点阵、245 居中拉伸、203 星盘、074 斜投影、286 搜索页、324 裁景刀窗、119 鲁宾双关、244 盒模型、158 绕排。聚焦出版封面独有的「推门入口隐喻 + 封面杂讯减法 + 书架叠放安全区 + 2.5m 远距缩略验视」。

## 3. 版式骨架
- **1440×900（主宽 1380px，2560 舒展至 1760px，不锁 `100svh`）**：黑绒暗室三栏出版打样台——左 31% 原海报级大标「封面版式」（旁嵌随过关进度推开的微型金门自示范徽）+ 五枚金圈竖排实况列；中 40% 3:4 活体封面主台与底沿一行精控条；右 29% 2.5 米远距缩略验视镜 + 暖象牙纸硬边单真源诊单（宛如门洞透出的象牙光面）。
- **1024×1366 / 768×1024**：紧凑顶刊头 → 左 56% 活体封面 × 右 44% 远距镜与象牙白诊单 → 底沿五要素横带，自然流排零大片空洞。
- **390×844 手机竖屏**：极简双行刊头（总述后置），3:4 活体封面稳占首屏 ≥ 46% 屏高且严格等比不压扁，其下首屏完整呈现 2.5 米远距缩略验视镜与四项核心实测。
- **844×390 手机横屏**：左 46% 等比活体封面 × 右 54% 刊头 + 远距实况 + 诊单首句并行。

## 4. 配色和字体
- **逐像素采自 160 原海报**：黑绒暗室 `#14120E`（暗舱 `#1E1A14`）、箔金日轮 `#C79545` / 亮金 `#E5B763` / 浅纸深青铜字 `#7B4F0F`、深绛酒红 `#5F0F0C` / 浅纸深酒红 `#7D1714` / 暗室酒红舱 `#280C0B` / 暗室警示绯 `#F27B72`、门扉象牙纸 `#EFE3CE` / 亮象牙 `#FAF4E8` / 暖羊皮 `#F3E9D7` / 淡金砂 `#EFE6D5`、纯墨 `#16130F`、达标松绿（浅 `#185C3E` / 暗 `#6FD9A6`）。
- **字体搭配（全库唯一，其中 Outfit 与 DM Mono 在近 12 页均 0 次使用，且与 159 零辅助字体重合）**：`Noto Sans SC`（正文与超粗大标）+ `ZCOOL XiaoWei`（出版书封宋标）+ `Playfair Display`（正斜体，杂志刊头与编号）+ `Outfit`（近 12 页 0 次，宽字距几何标）+ `DM Mono`（近 12 页 0 次，实测参数与 ISBN）。

## 5. 节目录（7 节，标题均 ≤ 12 字，相邻节不重复控件）
- **01 · 一张封面的五道门闩**（亮象牙纸）：引出海报五要素并辨析「先声夺人」；交互：**5 印版分色开关 X 光剥层仪**（独立开关底框/焦点/识别/标题/留白，实时看缺失后果）。
- **02 · 视线怎么从封面滑进内页**（暖羊皮纸）：拆解四种经典封面骨架并一句话链接同小类 161–167；交互：**4 骨架立体样书卡片 + 金丝视线路径回放画布**（点击节点读停留原因）。
- **03 · 三种距离的生死考验**（黑绒暗室）：拆解缩略图、2 米书架叠放与 30cm 手持三道关；交互：**5 本真实竞争书架/电商列表连续视距模拟器**（推拉距离与切换书架/电商/桌案场景）。
- **04 · 从企鹅三段到观念封面**（淡金砂纸）：1935 企鹅三段 → 1934–58 杂志革命 → 1941–48 抽象书衣 → 1947 奇肖尔德规范 → 1962 马伯网格 → 1962–72 Esquire 单焦观念；交互：**历史封面年份印章时间轴 + 实时几何比例蓝图**。
- **05 · 什么时候用，什么时候别用**（亮象牙纸）：适用场景经验参数 + 三类绝对别硬套封面的场景；交互：**6 张真实需求翻牌诊断卡片**。
- **06 · 小练习：挑出立得住的一稿**（深酒红暗室）：四选一严格单变量实测；交互：**A/B/C/D 同题材单变量封面样张选判 + 2.5m 缩略复验开关**。
- **07 · 原海报与核心关键词**（黑绒暗室）：原海报可放大拖动灯箱、五枚关键词与收尾句及页脚。

## 7. 练习
- **题目**：同一本建筑随笔《城市光学笔记》要上实体书店展台与线上列表，以下四稿配色、纸底与图案完全相同，各自只动了一个排版变量，哪一稿最立得住？
- **四项只差一个变量（中性 A/B/C/D 标签）**：
  - **A**：主副标字号比仅 1.25×，层级糊成一片；
  - **B**：主标足够大（2.7×），但落在亮金日轮与象牙门高光区（对比度 ~2.1:1），字被底图吃掉；
  - **C（正确）**：主标清晰（2.7×）稳落暗底负空间（对比度 > 12:1），左上安全区设系列标，焦点门洞完整让道，无多余卖点；
  - **D**：主标大小、对比度与识别带都和 C 一致，但门洞与底缘硬塞三条红底卖点与腰封堵死呼吸入口。
