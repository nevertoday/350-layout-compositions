# 046 矩形构图 · RECTANGULAR COMPOSITION 设计方案

## 1. 一句话道理
矩形通过不等长的横纵边建立明确的方向势能（横向延展叙事、纵向延展纵深），再以正交隔断在框内切出大小有别的功能分区，在「框定秩序」与「留白呼吸」之间同时实现稳重感与流动叙事。

## 2. 开场玩具：矩形断裁叙事台（Rectangular Guillotine Partition Bench）
- **形态与材质**：1:1 承袭 046 原海报的暖灰岩画廊纸面（`#F7F3ED`）、满宽锋利黑框（`#1C1C1C`，0px 直角）、朱红「视觉焦点」块、直接从 `#poster` 裁取实景画面的「红墙行者」建筑主图、深靛灰「信息支撑」满高竖柱、底沿暖米「引导视线」虚箭导流带，以及框外左侧「纵向延展」与底部「横向延伸」朱红虚线标尺和右上角实时联动的迷你蒙德里安构图徽章。
- **怎么玩**：
  - 在画布开放区直接左右横拖（`data-perf-drag`），实时推拉主隔断刃改变焦点区与建筑视窗的横向权重配比；也可直接抓拖三条内部正交隔断线（左竖刃 `x1`、右竖刃 `x2`、底横刃 `y1`）自由重塑四个嵌套子矩形的面积层级。
  - 拖动外框拉尺或下方滑轨连续调整矩形画幅长宽比（从 `0.62:1` 竖向海报穿过 `1.00:1` 暧昧方框，一直延展到 `2.35:1` 宽银幕长卷）。
  - 调节「框内呼吸缝（Gutter）」与「外框边距」，亲手把「0px 铁笼闷死（有框而拘）」调到「有框而不拘」，或故意拉大到散架触发失守警告。
  - 点击任意子矩形或底部快捷按钮切换主焦区位、开关外框与叙事虚箭，并在四套真实场景标本间切换：「原海报·红墙行者」（实裁自 `poster.webp`）、「建筑特刊跨页」、「宽银幕走廊分镜」、「品牌器物展陈」。
- **一打开的状态（刻意错态，0/4 待校，绝不先给答案）**：
  - 外框停在 `1.08:1` 暧昧近方比例（既无 045 正方的等边中立，又拉不开矩形的延展方向势能）；
  - 内部隔断接近平分（四个子矩形面积几乎打平，最大区占比仅 ~29%，焦点与信息柱抢戏平权）；
  - 框内呼吸缝与外框边距压成 `0px`（色块硬贴边框，直观呈现原海报 TIPS 警告的「有框而拘」）；
  - 焦点块落位与导流箭向冲突，视线受阻。
- **怎样算玩错（单真源 `model.js` 双向核算 8 类真错态）**：
  1. `暧昧近方`（框比落入 `0.85–1.24:1`，延展方向失效）；
  2. `极扁/极瘦裂缝`（框比 `> 2.65:1` 或 `< 0.45:1`，单向挤压变形）；
  3. `四格均分平权`（最大子区面积 `< 36%` 或最大/次大面积比 `< 1.32×`，没有主次）；
  4. `巨块吞噬/信息窒息`（最大区 `> 76%` 或辅助/导流区被挤到 `< 8.5%` 或窄于易读底线）；
  5. `有框而拘（铁笼贴死）`（呼吸缝 `< 5px` 或外框内边距 `< 3%`，色块窒息）；
  6. `缝宽散架/框定失守`（呼吸缝 `> 28px` 或关掉外框，画面解体成零散卡片）；
  7. `叙事逆流`（导流方向与主焦—主图—辅柱阅读动线反向）；
  8. `重心偏塌`（实绘四区视觉重量矩偏离平衡带过远）。
- **多组合法解**：只要四个原海报核心柱（框定 / 延展 / 分区 / 叙事）同时达标即成立，支持原海报经典横幅解（`1.92:1`）、电影宽银幕解（`2.35:1`）、竖向画报解（`0.72:1`）及非对称建筑跨页解（`1.50:1`）。
- **与近 12 页的区别**：045 是 1:1 等边方框 + 3×3 九宫格点击落印；133/255/132 是文字折行栏宽；299 是 CSS Grid 卡片跨列装箱；044 是旋转立菱顶点雕塑。046 独创「正交隔断刃（Guillotine Partition）推拉嵌套子矩形 + 横/竖长宽比延展 + 框内呼吸缝」的矩形空间构筑机制，换到任何其他编号都无法套用。

## 3. 版式骨架（忠实转译 046 原海报「满宽建筑画廊展板」）
- **1440×900（主宽 1380px，2560×1440 舒展至 1680px）**：
  - 顶部刊头带：左侧 6px 朱红竖杠 + 巨幅深岩灰 `矩形构图` 与朱红 `RECTANGULAR COMPOSITION`；右侧实时联动的迷你矩形分区徽章 + 4×5 浅灰点阵 + 状态印章 + 四场景切换签。
  - 第二带：左 38% 原海报总述 | 右 62% 细竖线分隔的四枚原海报线框核心柱实时探针（`框定 FRAMING` / `延展 EXTENSION` / `分区 ZONING` / `叙事 NARRATIVE`）。
  - 第三带：**满宽锋利黑框主舞台**（无深色通用顶栏、无左右挤压仪表盘、不锁 `100svh` 避免 1024×1366 平板空洞），画布左配「纵向延展」朱红虚线尺、右配「信息分区」虚引线、下配「横向延伸 扩展叙事空间」朱红虚线尺。
  - 第四带：紧贴横尺下方的 45%/55% 齐底双舱（左单真源建筑诊单与实测参数匣 × 右正交隔断/比例/呼吸缝/方案精控台）。
- **390×844 竖屏**：压紧单行刊头（朱红竖杠 + 标题 + 迷你徽章 + 状态签），把总述与四柱探针用 CSS `order` 后置，让满宽矩形构图画布稳占首屏 ≥ 46% 屏高，并在折线内直见诊单首句与一键纠偏钮。
- **844×390 横屏**：左右分屏并行——左 56% 矩形舞台 × 右 44% 紧凑刊头、诊单首句与核心控轨。

## 5. 节目录（7 节，每节 h2 ≤ 12 字，相邻两节不用同类控件）
- **01 矩形为什么自带方向**（`DIRECTIONAL FIELD` · 净白纸）：引用原海报「框定边界」「延展视线」，对比 045 方形构图与矩形长短轴势能；交互：**五画幅实景切窗器**（点选 `1:1 / 4:3 / 16:9 / 2.39:1 / 3:4` 实时裁剪同一红墙行者画面并叠加阿恩海姆骨架线与视线矢）。
- **02 框内分区与叙事秩序**（`ZONING & NARRATIVE` · 羊皮纸）：引用原海报「分区组织」「构建叙事」与「如何运用矩形构图」四步法；交互：**四步建构推演台**（逐步步进原海报 1→4 步动效线框，并可切换「均分死表 vs 主次错落」对比）。
- **03 有框而不拘的临界尺**（`BREATHING & TENSION` · 深靛岩暗室）：引用原海报 TIPS「有框而不拘」；交互：**二维拘散相空间触控板**（在 2D X/Y 坐标系拖动/点选「框内呼吸 × 边界约束」，右侧实时渲染对应海报落位并标出四象限临界态）。
- **04 矩形构图从哪来**（`HISTORICAL LINEAGE` · 暖灰岩纸）：考据 1435 阿尔伯蒂《论绘画》「敞开之窗」、1921 蒙德里安风格派非对称切分、1922 波斯特曼 DIN 476（1975 ISO 216）√2 纸张、1954/1974 阿恩海姆结构骨架与 1981 米勒-布罗克曼《网格系统》；交互：**四幅历史几何标本展板**（点击切换并演示 √2 对折自相似、非对称面积平衡、透视窗与网格模数）。
- **05 适用场景与什么时候别用**（`USE CASES & BOUNDARIES` · 净白纸）：引用原海报四大适用场景（经验值标注）+ 温和补正原海报「方向性」说法 + 何时改用同小类其他编号（附一句话链接至 `041–045`、`047–056`）；交互：**场景参数速查卡组**（点选海报/网页/影像/品牌四场景展开对应框比、分区法与避坑线）。
- **06 实战辨识：选出顺流矩形**（`VISUAL DRILL` · 深靛岩暗室）：两道视觉诊断练习题（横幅展览海报 + 竖幅画册封面），每题四个中性标签方案 `方案 A/B/C/D`，素材配色完全一致，每项只差一个结构变量，选完给出单真源原理解析。
- **07 原海报与关键词**（`ORIGINAL POSTER` · 暖灰岩原纸 + 深靛岩页脚）：完整原海报（点击放大灯箱、拖拽平扫、滚轮/按钮缩放、Esc 关闭）、原海报四组关键词徽章与 TIPS 原文，以及标准页脚。

## 7. 练习设计
- **题 1（横幅展览主视觉，16:9）**：四项同素材同配色，只变单一变量：
  - `方案 A`：四区面积接近均分（各 24%–26%），呼吸缝正常 → 主次拉平，焦点失效。
  - `方案 B`：主次面积比合理（50% / 24% / 16% / 10%），但内缝与外边距 0px 铁笼贴死 → 有框而拘。
  - `方案 C`：主次面积比合理 + 12px 均匀呼吸缝 + 清晰的红块起势→建筑延展→导流箭→信息柱顺序 → **正确答案**。
  - `方案 D`：面积比同 C，但撤去外框且间距炸开到 36px，导流中断 → 框定失守、散落脱节。
- **题 2（竖幅画册封面，3:4）**：同套红墙建筑主题转竖幅，考察竖向延展与重心稳固：
  - `方案 A`：画幅压成近方 1.04:1 塞入竖封面区，上下大片死白失联 → 框比暧昧、未建纵向延展。
  - `方案 B`：3:4 竖框内上主图占 56%、下左朱红主标占 26%、下右深灰刊号占 18%，均匀呼吸缝，视觉重心下沉稳固 → **正确答案**。
  - `方案 C`：3:4 竖框但切成四条等高横带（各 25%）→ 均分条纹打断纵向势能。
  - `方案 D`：3:4 竖框但主图被压缩到顶部 18% 细条，下方纯文字占 82% → 焦点被辅信息吞噬。
