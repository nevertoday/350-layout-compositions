# 334 欲正关系构图（敧正关系构图）TILT-UPRIGHT COMPOSITION — 互动页方案

## 1. 一句话道理
人眼以水平—垂直作为感知重心与秩序的默认坐标系（斜效应与格式塔结构骨架）；只有当稳重的正向结构先稳住画面重量，一笔恰当的倾斜元素才能借角度反差制造动势与张力，并在支点与重心落回底基支撑区时达成「险中求平、敧正相安」的动态平衡。

## 2. 开场玩具：敧正力学·正柱斜碑平衡台（Tilt-Upright Fulcrum & Counterbalance Stage）
- **形态与材质**：1:1 承袭 334 原海报炽烈朱橘面（`#FA4E06`）、暖宣米白正立巨柱（`#F4E7D5`）配顶底黑方垂直虚线轴、纯黑倾斜巨碑（`#131313`）、底部纯黑滚球支点、纯白斜向贯通长箭与右上角虚线角度弧尺；支持切换四套场景：**原海报·碑柱平衡 / 山水·奇松倚壁 / 海报·斜切宣言 / 建筑·悬挑塔楼**。
- **怎么玩**：
  - 在开放画布上**左右横拖**（`data-perf-drag`）直接扳动黑色倾斜巨碑绕底球支点旋转（`-45°` 至 `+48°`），实时联动白色视线动势箭、右上角度弧尺、顶部自示范标题倾角、重心垂线与倾覆力矩；
  - **直接拖移底部纯黑滚球支点**沿地平基线滑动，检验支点偏空或压死接缝对平衡的影响；
  - **点击米白正立巨柱或切换姿态阀**，故意把正柱也弄歪（「全斜失锚」）或削薄（「正轻斜压」），亲眼验证没有稳正参照系时倾斜立即沦为晕眩失衡；
  - 键盘支持 `←`/`→` 调倾角、`↑`/`↓` 滑支点、`Space` 演播斜箭动势回流光束、`R` 复原开场错态。
- **开场初始状态（绝不先给答案）**：刻意停在 **「2° 似正非正 + 支点右脱」** 复合错态——黑碑几乎和米白正柱平行直立，却又尴尬微歪 2°（落入最令大脑难受的「没摆齐」错觉死区），黑球滑在右端未托底，五枚左脊徽章亮出待校状态。
- **怎样算玩错、错了读数怎么说**（全部由 `model.js` 从实绘几何顶点、面积份量、质心与支撑区间单真源实时核算，标明档位/示意，不写假精确）：
  1. **全正僵死（`0° ≤ |θ| < 1°`）**：两块笔直并列，角度差归零，画面沉闷静止、视线无出口；
  2. **似正非正（`1° ≤ |θ| < 8°`）**：微斜不足以宣告意图，视皮层仍按垂线校准，只觉「贴歪了」；
  3. **过斜倾覆（`|θ| > 34°`）**：倾角过大、合成重心冲出底基安全支撑区，力矩倾覆失稳；
  4. **全斜失锚（正柱倾角 `|φ| > 4°`）**：作为参照系的正向骨架自己倒了，正斜对比塌缩，整幅画面像歪斜拍片；
  5. **正轻斜压（正柱视觉份量 `< 38%`）**：骨架过单薄，托不住斜体推力，头重脚轻；
  6. **支点脱空（黑球远离黑碑底心超阈）**：斜体悬空缺承托，力学逻辑断开。
- **多组合法解**：接受「原海报经典解（正 0° / 斜 +20° / 稳托）」「险中求平解（加厚正柱 / 斜 +28° / 右支抵矩）」「反势清雅解（正 0° / 斜 -14° / 左支承托）」。
- **与最近 12 页的明显区别**：
  - 区别于 333（黑曜石电光蓝拱窗遮挡拉幕）、332（深松绿四圆镜 S 丝带）、132（暖米书纸双虚线单栏排字）、168（暖米建筑轴线挂块）；
  - 区别于同为红橘底的 254（254 是通栏 2×3 奶油圆标图标网格 + 三虚线公式盒调图字亲密性；334 是刚体倾倚角度×滚球支点静力平衡实验，左竖脊五黑圆徽 | 右无框巨幅开放舞台 + 实黑碑基诊单 + 底沿通栏五项公式框）。

## 7. 练习设计
- **题目**：同一场「秋季现代建筑双年展」海报，文案、暖宣米底、纯黑主字与左栏竖向导览块完全一致，只改动黑色斜切主视觉块的角度与底托关系——哪一版真正做到了「敧正相生、有势又稳」？
- **四个选项（单变量差异，标签全部中性：方案 A / B / C / D，无好坏剧透）**：
  - **方案 A**：倾角 `0°`，两块严格垂直平行并立；
  - **方案 B**：倾角 `4°`，主块仅微斜出一点边缘；
  - **方案 C（正确答案）**：倾角 `18°`，右倾靠借稳正主栏，下方实心圆锚落在重心投影旁托住动势；
  - **方案 D**：倾角 `44°`，巨幅黑块急剧斜切腰斩正栏，重心越出右缘无托点。
- **正确答案理由**：只有方案 C 避开了 0° 的静止呆板、4° 的「似正非正误歪区」与 44° 的倾覆失稳，以明确 18° 夹角让端正栏担起秩序、斜向块引领视线、底端锚点收住力矩，在对比中达成平衡。
