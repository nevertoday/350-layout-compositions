# 142 · 大标题 版式（HEADLINE LAYOUT）互动页方案

> 所属分类：平面、出版与广告 / 图文主导与表现型版式  
> 原海报副标：「以标题建立视觉主导」  
> 原海报总述：「利用超大标题确立视觉焦点， 迅速传达核心信息。 辅助信息弱化处理，形成清晰层级， 适用于封面、章节页与重点页。」  
> 原海报关键词：`层级 HIERARCHY` · `聚焦 FOCUS` · `节奏 RHYTHM` · `留白 SPACE`

---

## 1. 一句话道理

眼睛进入版面时最先抓住墨量最重、体量最大的视觉锚点；把精炼到几字的核心标题放大成压倒性主角，同时把副标、期号等辅助信息退后到次级（降噪弱化但守住近看可读下限），再用充裕留白托住这份反差，读者退后三米扫一眼就能在 1 秒内读懂重点，走近后再顺着层级读清细目。

> **对原海报的温和补充（正文 01 节以小签「容易误读的一点」展开）**：原海报强调「利用超大标题确立视觉焦点」，实战中最常见的两种误读一是以为「字越大越好、把长句硬吹大就行」，二是以为「辅助信息弱化就是缩到看不见」。实际上，大标题版式成立依赖四件事同时成立：**词句先剪短提纯、主辅字号拉出经验级差、辅助信息退后但保近看可读、纸面留出呼吸留白**。

## 2. 统一规则常量（`model.js` 单一数据源）

全页（开场活体封面读数、四关键词体检灯、02 节正文与实验、07 节小练习判题）全部引用 `model.js` 导出的一套常量，页面上以档位呈现并注明为实务经验值，杜绝多源打架：

| 常量 | 数值（实务经验值） | 含义与统一归口 |
| --- | --- | --- |
| `RATIO_FLAT_MAX` | `2.2×` | 主标 ÷ 最大辅文字号 `< 2.2×` 判为「平权贴近 / 无焦」 |
| `RATIO_MIN_PASS` | `3.5×` | 主辅字号倍率经验起步线，`3.5×–6.0×` 为「焦距稳健（经验区）」 |
| `RATIO_SWEET_MAX` | `6.0×` | 超过 `6.0×` 易压迫版面或挤干留白 |
| `WHITESPACE_MIN` | `42%` | **净留白**定义：`1 - (DOM 行框矩形并集面积 ÷ 封面总面积)`；低于 `42%` 判「留白不足 / 过载撑爆」，经验呼吸区 `42%–72%` |
| `CHARS_MIN` / `CHARS_MAX` | `3–7` 字 | 精炼大标题经验字数（超过 `7` 字为长句过载） |
| `LINES_MAX` | `2` 行 | 封面主标题理想折行上限（`≥ 3` 行会拆散视觉块） |
| `AUX_MIN_RENDER_PX` | `11px` | 辅文近看可读字号下限（按实际渲染像素计量；渲染保护硬底 `10px` 防小屏碎字） |
| `AUX_MIN_CONTRAST` | `4.5:1` | 辅文近看可读对比度下限（WCAG AA 正文标准；弱化是退后不是删掉） |

> **统一几何来源**：净留白由真实 DOM `Range.getClientRects()` 导出的行框矩形集合（刊期若挂实底蓝块则取该实底矩形）经精确二维矩形并集算出；**三米远观实测窗**的模糊墨团与第一眼落点直接由**同一组矩形按 `面积 × 字重/实底权重`** 绘制和判定，不另做离屏像素扫描。

## 3. 开场玩具：封面层级活体排印台（Live Cover Dominance Bench）

### 怎么玩（全部动作只属于「大标题版式」本身）
舞台承接一张真实 `4:5` 杂志特刊封面活体校样（《旧船厂再生》冬季特刊，直承 142 原海报暖米纸、穿蓝圆 45° 黑斜线与右下出血蓝三角），旁侧配一块 **2D Canvas「三米远观实测窗」**（直接由封面实时 DOM 行框矩形按面积×字重绘出低通墨团）。用户做平面设计师排大标题封面的三个原生动作：

1. **点词剪标题**：主标题是一句可逐块划删的 14 字报告长句——`[年度]` `[旧船厂]` `[工业遗址]` `[空间]` `[再生]` `[观察报告]`。点击或回车词块划删，收进底沿校对废字槽（随时点废字签还原），提纯为 `3–7` 字核心大标（如 `旧船厂 / 再生`）。
2. **拖角标改字号**：选中封面上的**主标题层**、**副标导语层**或**刊期元数据层**，拖动该层右缘印刷裁切缩放柄（主标柄标 `data-perf-drag`，仅缩放柄设 `touch-action: none` 不挡页面竖滚；键盘选中后 `↑ / ↓` 步进），封面真实折行并实时更新行框几何。
3. **调辅文墨重档（强 / 弱化 / 过弱）**：副标导语与刊期元数据各提供三档墨重——**强档**（粗黑 / 实底钴蓝大块，抢戏）、**弱化档**（暖炭灰 `#524F4A`，对比度 `7.3:1 ≥ 4.5:1`，退后但近看清晰）、**过弱档**（浅灰 `#837E75`，对比度 `3.6:1 < 4.5:1`，故意发虚演示「辅文消失」反例）。

### 一打开是什么状态（绝不先给答案）
- 初始落于 **「错态 4 · 平权无焦」** 错版：主标保留 14 字未剪短（基准 `28px`），副标 `21px` 粗黑强档（倍率仅 `1.33×`），刊期 `17px` 挂实底钴蓝大块抢戏；远观窗里几条墨带平摊，找不到唯一焦点。

### 严格优先级七类错态（每次只报一条主诊断）
按结构严重度从高到低依次判定，命中第一条即作为主诊断（绝不并列堆砌）：

| 优先级 | 错态名称 | 统一常量判定条件 | 画面与读数怎么说「为什么」 |
| --- | --- | --- | --- |
| **1** | **剪丢核心** | 核心主体词「旧船厂」被删，或保留字数 `< 3` | 版面空了，但核心主体被剪没——大标题要先「迅速传达核心信息」。 |
| **2** | **本末倒置** | 辅文渲染字号 `≥` 主标字号，或辅文墨团权重压过主标 | 配角被拉到主角头上，三米外第一眼读到的是副文或期号。 |
| **3** | **辅文消失** | 副标或刊期实际渲染字号 `< 11px` 或对比度 `< 4.5:1`（过弱档） | **弱化是退后，不是删掉**——压过近看可读下限会让封面丢掉导语与刊期信息。 |
| **4** | **平权无焦**（初始态） | 主辅倍率 `< 2.2×` | 主标与辅文体量太近，远观窗糊成平铺条带，眼睛抓不住头号锚点。 |
| **5** | **长句硬放大** | 主标字数 `> 7` 且倍率已达 `≥ 2.2×` 或折成 `≥ 3` 行 | 把 14 字报告句直接吹大只会筑起黑字墙——先点掉冗余修饰词再放大。 |
| **6** | **过载撑爆** | 净留白 `< 42%`，或主标折成 `≥ 3` 行，或撞入辅文安全区，或倍率 `> 6.5×` | 超大标题需要留白缓冲，撑满纸面会把冲击力变成压迫感。 |
| **7** | **喧宾夺主** | 副标/刊期仍停在强档，或主辅倍率仍在 `2.2×–3.49×` | 主标立起来一半，粗黑副标或实底刊期块还在抢戏，次级信息未退让。 |
| **过关** | **焦点确立** | 以上 7 项全清零：含核心词且 `3–7` 字、`1–2` 行 + 倍率 `≥ 3.5×` + 辅文弱化且 `≥ 11px`、`≥ 4.5:1` + 净留白 `≥ 42%` + 第一眼锁主标 | 远观窗浮现唯一清晰的巨标墨团锚点，原海报四关键词全部点亮。 |

### 和最近做完的 12 页不同在哪
- 避开 129（报版四格调位）、187（拖标点跨虚线）、296（拖入单列调序）、240（双刀切三端列数）、019（配重画板）、295（抽屉拉手）、072（3D 仰俯角）、186（字盘拖蓝铅空）、018（蝶翼对折）、239（拖右墙拉流体）、128（Z 轨节点）、101（分色圆色相轨）：
  - **142 独创「封面逐词划删 + 印刷裁切角标拖缩放 + 辅文三档墨重（含近看可读下限保护）+ DOM 同源矩形远观窗」**，零撞车、零角落小蓝圆+点阵刊眉、零双巨标抢焦点。

## 4. 版式骨架（严守单焦点原则与全尺寸 `4:5` 等比）

- **单焦点原则**：首屏左栏 `<h1>` 「大标题 / 版式」克制在 `56–62px`（桌面 1440 下约 `58px`，2560 下约 `64px`），不与右侧封面巨标（放大后 `100–140px`）抢第一眼；视觉母题严格采用原海报三大件——**出血钴蓝大三角**、**45° 黑斜线穿钴蓝正圆**、**平涂钴蓝块与粗蓝短杠**，摒弃与 186/101 撞车的角落小圆点+点阵刊眉。
- **1440×900（桌面）**：自然高约 `830px`（不锁 `100svh`）。左侧 `43%` 放克制页标、蓝英标+粗蓝杠、副标总述、三米远观窗（`4:5`）与四关键词灯+主诊断；右侧 `57%` 铺 `520×650`（严格 `4:5`）活体封面校样与紧凑底沿微条。
- **2560×1440（超宽）**：容器放宽至 `min(88vw, 1840px)`，封面等比舒展至 `680×850`（`4:5`），绝不居中缩成一小块。
- **1024×1366 / 768×1024（竖屏平板）**：自然纵流，紧凑顶标 + 居中大幅 `4:5` 封面（`500×625` / `460×575`）+ 并排远观窗与诊断带，下直接 01 节，零空白断层。
- **390×844（手机竖屏）**：顶栏压紧至 ~66px；**严格 `4:5` 活体封面宽 `332px` × 高 `415px`**（占首屏 `49.2%` 高度，缩放比 `0.755`，辅文弱化默认实测 `≥ 11.3px`，词块与缩放柄触控区 `≥ 44px`）；下方同屏紧接迷你远观窗、四灯与主诊断一句。
- **844×390（手机横屏）**：左侧 `36%` 放单行压紧标题、迷你远观窗与主诊断；右侧 `64%` 放 **宽 `440px` × 高 `550px`（`1:1` 基准宽、严格 `4:5`）活体封面**（可在视口内顺滑纵向滚动看全底沿），副标与刊期始终以 `15–21px` 真像素渲染，词块宽大精准、绝不缩成 4–5px。
- **正文八节**：在暖米白纸 `#F7F2EA`、次级浅纸 `#EEE8DD`、午夜群青 `#061E6B`（03 节）与浓墨黑 `#111214`（06 节）间交替推进；双栏节使用 `sticky` 伴随或平衡分栏，杜绝一边先结束留空。

## 8. 小练习设计（全四档 > 3×、乱序排列、统一常量实测）

- **统一规格**：四张 `4:5` 建筑季刊第三章扉页（逻辑尺寸 `280×350`，内栏宽 `232px`，暖米纸底、`Noto Sans SC 900`、行高 `1.04`、左下 `17px` 弱化副标 `#524F4A`、右下出血钴蓝三角），**唯一变量是主标题「冬日港口」字号**，四档均 `> 3×` 且**乱序呈现**（绝不按从小到大排列）：
  - **方案 A（`72px`，实测倍率 `4.2×`）**：倍率与留白都合格，但 `3×72 ≤ 232 < 4×72` 导致自动折成 `冬日港 / 口`，把词组「港口」拦腰折断并留下孤字「口」。
  - **方案 B（`104px`，实测倍率 `6.1×`）**：虽折成两行 `冬日 / 港口`，但已超出 `model.js` `6.0×` 经验上限，且实测 DOM 净留白跌破 `42%`（约 `37%`），巨字直压副标呼吸区。
  - **方案 C（`88px`，实测倍率 `5.2×` — 正确答案）**：落进统一 `3.5×–6.0×` 经验区，`2×88 ≤ 232 < 3×88` 利落折成两行 `冬日 / 港口` 词义完整，实测 DOM 净留白约 `51%`（稳居 `42%–72%` 呼吸区），主角体量压稳右下蓝三角。
  - **方案 D（`56px`，实测倍率 `3.3×`）**：四字挤成单条细横行 `冬日港口`，虽超 `3×` 但仍略低于统一 `3.5×` 起步线，纸面留白超 `78%`，在整页开阔空间里重心反被右下大块蓝三角分走。
