# 216 横直混排 · 设计方案

## 1. 一句话道理
横排靠稳定的水平扫视承载主信息与说明段落，竖排靠垂直截断制造视觉锚点、导航标签与节奏停顿；只有当两者分工明确（横主竖辅或清晰主从）、主次占比不五五开、交界处留出过渡媒介且拉足字号粗细反差时，混排才会产生秩序与节奏，而不是互相抢戏的视觉噪音。

## 2. 开场玩具
- **名字与形态**：**正交版面拼排桌（Orthogonal Editorial Composer）**——1:1 承袭 216 原海报素白暖宣、深松绿/豆青十字坐标轴与《城市的更新与未来》活体版面卡的无框 2D Canvas（标 `data-perf-drag`），内置 6 个真实按东亚字盒逐字折行的出版模块（主标题、导语副标、长正文段、城市插画、侧边导视栏、底沿要点带），支持切换原海报《城市更新》、美术馆《展讯海报》、建筑《留白特刊》三套标本。
- **怎么玩**：
  1. **直点任意模块**：将其在横排（H）↔ 竖排（V）之间即时翻转并重新按真实字盒折行；
  2. **左右横拖画布或中央十字绿轴**：连续拉动横流主区与纵流强调区的占比（15%–85%），实时改变正文行宽、纵栏宽窄与上方十字交点圆环；
  3. **切换过渡媒介与层级反差**：在「无过渡撞车 / 细界线 / 原海报斜线带 / 宽留白」与「层级拉平 / 清晰反差」间切换，并可点击「演练视线路径」沿实绘几何播放阅读动线、直接暴露 90° 转向折返次数。
- **一打开的状态（绝不是答案）**：刻意停在 `0/5` 复合错态——长正文段被错排成竖排、侧边导视被放成横排、横纵占比僵持在 50% : 50% 五五开、过渡媒介设为「无过渡（交界贴脸净空 4px）」、且层级被拉平（尺度比 1.18×）。
- **怎样算玩错 & 错了读数怎么说**：由 `model.js` 从 6 个模块的实绘像素矩形、字盒行宽、最小交界净空与视线 90° 转折次数单真源核算 7 类双向真错态：
  1. 退化单向（全横或全竖）→ 指出已退化为单一方向，失去横直对比；
  2. 主次分裂（横区 44%–58% 五五开）→ 指出横纵平分秋色，视线不知先顺哪条轴；
  3. 长文错竖（说明长段设成竖排）→ 指出连续长文竖排折行碎裂，违背横载信息、纵做引导的分工；
  4. 交界贴脸撞车（实测净空 < 14px）→ 画布红标咬合线，指出横行行尾直接撞进竖列侧腰；
  5. 横区过窄/纵栏挤瘪（横区 < 55% 或纵区 < 15%）→ 指出主文每行仅剩个位字或纵栏被压扁；
  6. 方向切碎过频（扫描路径 90° 急转 ≥ 3 次）→ 指出眼球反复横纵急拐，节奏沦为杂音；
  7. 层级拉平（尺度比 < 1.5×）→ 指出只换方向不拉大小粗细，板块散架。
  - 同时接受原海报经典解、竖标领衔解、双竖夹心解、宽境留白解及用户自由达标解多组合法解。
- **与近 12 页的区别**：215 是单向左起直排栅格调列/字距，214 是单向右起直排拖列理序，133/255 是纯横排分栏/单列宽度，045/044/170/334/335/300/083/082 均非双方向正交文字排版；216 独有的「单块点击横竖翻转 + 正交占比拖轴 + 交界过渡缝实测 + 视线 90° 转折次数核算」只能属于横直混排，别的编号无法原样套用。

## 3. 版式骨架
忠实转译 216 原海报「素白暖宣十字坐标轴 × 深松绿左竖旗 × 杂志双翼」建筑骨架（零深灰通用顶栏、零笨重圆角卡片、绝不锁 `100svh` 避平板大空白）：
- **1440×900（2560 舒展至 1720px）**：顶沿左 44% 为粗松绿顶杠 + 双色自示范大标（`横直` 黑 / `混排` 深松绿）+ 紧邻的真竖排两列导语与标志朱红圆点 + 窄高英文；右 56% 为绿字标语、海报总述、三标本切签与单真源徽章。下方贯通原海报招牌「十字交叉信息流坐标轴（豆青实心圆 + 同心细圆环随横纵比联动）」。主舞台左 36% 复刻深松绿实心竖旗『设计要点』配 5 枚原海报几何图符实时探针与齐底单真源白话诊单匣；右 64% 为正交版面拼排桌 Canvas 与单行精控轨。底沿通栏原海报结语与 `→ ● ● ○` 印记。
- **1024×1366 / 768×1024**：取消强锁屏高，主舞台折排为上方全宽等比拼排画布 + 下方左诊单 × 右 5 项设计要点齐底两栏，零空洞。
- **390×844**：压紧单行双色刊头（后置总述与竖排导语），让正交拼排画布稳占首屏 ≥ 46% 高度且比例不压扁，画布正下方折线内直露单真源诊单首句与一键纠偏按钮。
- **844×390 横屏**：切左 55% 拼排画布 × 右 45% 紧凑刊头+实况诊单并行。

## 5. 节目录（每节 h2 ≤ 10 字，相邻不同控件）
- **01 横纵分工怎么立**（亮宣白）：讲清横向载文、纵向引导的视觉生理分工，并链接 212–215；交互：6 项出版元素的双轴角色分拣台 + 实时样页预览。
- **02 交界处怎么过渡**（浅豆青雾纸）：拆解横直十字路口的防撞与过渡手法（留白、细线、斜线带），并链接 217–221；交互：可横向拖动的交界缝放大标尺 + 4 种过渡介质对比剖面。

## 7. 练习
- **题目**：同一份《城南茶事展》海报，四版文案完全一致，只有一处关键排版变量不同。哪一版横直混排真正读得顺？
- **选项**（中性标签 `方案 A` / `方案 B` / `方案 C` / `方案 D`，四图均由 SVG 真实绘制，单变量差异）：
  - **方案 A**：横主 72% × 竖导 28% + 斜线过渡 + 层级清晰，唯独**角色倒置**（60 字介绍硬塞竖排右栏，4 字口号横排）。
  - **方案 B**：角色与层级都对，唯独**主次五五开（50:50）且交界零过渡**（横排末尾紧贴竖排撞车）。
  - **方案 C（正确答案）**：横排主标/长文占 72%、竖排展期与短口号占 28%、斜线带清晰过渡、字号粗细层次拉开、视线仅顺转 1 次。
  - **方案 D**：角色、占比与过渡都对，唯独**层级拉平**（主标、正文、竖排导视字号粗细几乎一样）。
