# 164 目录 版式（CONTENTS LAYOUT）设计方案

## 1. 一句话道理
目录不是把页码抄整齐的清单，而是整本出版物的「结构地图」：用合理分组压缩认知负担、用字级与留白区分主次、用稳固的对齐轴与近距页码连结视线，让读者在 3 秒内建立全局心智模型并零串行直达目标章节。

## 2. 开场玩具：活体目录编排台 × 扫读寻页实测镜
- **玩法**：
  - **2D Canvas 活体目录印张**（`data-perf-drag`），1:1 承袭 164 原海报浅薰衣草纸面（`#E3DFF7`）、克莱因电光蓝（`#0F1BE6`）与纯墨黑（`#000000`）设计语言，内置三套真实出版物素材：**原海报·课程目录**（直接使用海报上的 `01 导言 / 02 案例 / 03 方法 / 04 练习 / 05 拓展` 与全部 15 条子目）、**建筑年刊·画册**、**技术手册·文档**。
  - **横拖画布上的电光蓝竖分栏尺**：连续推拉左主标题栏与右子目/页码区的分栏比例（`22%–82%`），实时观察文字挤折与跨栏断眼之间的平衡。
  - **直点画布上的任意条目**：发射一条真实的电光蓝扫读视线轨迹（章签 → 几何章徽 → 主标题 → 跨栏飞跃 → 目标页码），实测视线能否直达目标页码还是在空白鸿沟处串行偏离。
  - **直接调校目录四维编排参数**：信息分组（未分组 15 条流水账 / 3 粗组 / 5 组经典 / 15 碎块过拆）、主次字级比（`1.00×–2.65×`）、页码连结方式（右端孤悬无引线 / 疏朗点线引导 / 紧贴标题右侧 / 左置等宽页码栏）、导视锚点（关闭 / 燕尾蓝签+几何章徽 / 过载花哨徽章）。
- **开场状态（非答案）**：
  - 开场刻意停在真实初学者排目录的复合错态：**15 条未分组流水账** + **1.00× 主次拍平** + **分栏拉偏导致页码右端孤悬无引线（实测跨栏空白鸿沟超标，扫读射线明显向下串行）** + **关闭 `01–05` 燕尾蓝签与章节横线**。
- **怎样算玩错 & 读数如何说清「为什么」**：
  - 所有读数与诊断均由 `model.js` 的 `evaluateContentsLayout()` 根据当前帧真实绘制的像素矩形与坐标单真源核算，支持**双向玩错**：
    1. **未分组流水账（1 组 15 条）** ↔ **过度拆分碎块（15 独立细框）**：前者超过短时记忆 4±1 组块上限，后者把页面切成碎片、破坏连续扫读。
    2. **层级拍平（字级比 < 1.25×）** ↔ **主标巨化撑爆（> 2.30×）**：前者章节与子目混成一团，后者主标挤垮行高、压迫子目。
    3. **主栏过窄挤折（分栏 < 34%）** ↔ **跨栏空白断眼（孤悬右齐且空白鸿沟占比 > 24%）**：前者标题撞栏断行，后者视线横跨空白时极易滑落到相邻行页码。
    4. **导视锚点缺失** ↔ **花哨徽章噪点过载**：前者扫读无抓手，后者视觉噪声喧宾夺主。
  - 接受多组合法专业解：**原海报五栏燕尾解**、**经典书刊紧贴页码解**、**瑞士左置等宽页码解**、**疏朗点线跨栏解**。
- **与最近 12 页的明显差异**：
  - 彻底跳脱 163（深松绿跨页缩放）、292（炭黑重力落列）、040（曜石黑折线）、124（松绿出血裁刀）、249（镉黄封面高度弹簧）、291（暖米视口宽拉阔）、162（右朱红切口导流箭）、207（樱粉固定网格拼块）、039（薄荷海浪）、077（暖米 3D 鸟瞰）、123（深蓝暗房裁切）、327（玄墨刻白反拓）。
  - 本页开场玩具源自目录排版独有的**组块聚散、字级层级、跨栏页码连结与真实扫读寻页测试**，其他编号无法原样套用。

## 3. 版式骨架
- 忠实转译 164 原海报的**不对称左导视脊 × 右五带目录图谱 + 底部 1px 电光蓝细框快速导航盒**（不锁 `100svh`，彻底避免平板大块空洞；无通用深色导航栏）。
- **1440×900（2560×1440 舒展至 1720px）**：
  - 左 30% 导视脊：原海报标志电光蓝巨型 L 折角框住自示范堆叠黑大标「目录 / 版式」与 `CONTENTS LAYOUT` → 左侧出血电光蓝巨型四分之一圆环与向右黑箭 `→`（内嵌三套出版物题材切换）→ `设计目标 DESIGN GOAL` 与三枚电光蓝圆点实时柱灯（`信息分组` / `层级清晰` / `导航明确`）及单真源白话诊单。
  - 右 70% 主区：原海报顶眉 `分组 / 层级 / 导航` + 电光蓝波浪线 `~` + 竖蓝杠总述 + 右上 3×3 电光蓝点阵 → 开放式 2D Canvas 活体目录印张（可横拖竖尺、直点行目测扫读）→ 紧贴单行紧凑编排台。
  - 底沿通栏 1:1 复刻原海报电光蓝 1px 细框「`* | 快速导航建议 → | 点阵`」——它同时就是本页 01–07 节真正可点击跳转的自示范目录！
- **1024×1366 / 768×1024 平板**：左脊与右台按断点顺滑重排，零留白黑洞。
- **390×844 手机竖屏**：极简单行刊头（微型电光蓝 L 折角「目录 版式」+ 状态签 + 三题材切），让等比活体目录画布稳占首屏 ≥ 47% 并直见诊单首句；原海报总述自然置后。
- **844×390 手机横屏**：左 57% 活体目录画布 × 右 43% 刊头、诊单与核心控件并行。

## 4. 配色和字体
- **配色**（逐像素采自 `164.webp`）：
  - 原海报浅薰衣草纸底 `#E3DFF7`、亮读纸 `#F5F4FD`、纯静白纸 `#FAF9FF`、薰衣草柔雾 `#EAE7FA` / `#E7E4F8`
  - 标志克莱因电光蓝 `#0F1BE6`（悬停深蓝 `#0A13B3`，浅纸安全深蓝字 `#0C17CC`）
  - 纯黑主墨 `#000000` / 深靛炭墨 `#111322` / 次墨 `#3D4058` / 细格线 `#8F8CA6`
  - 03 暗室与 07 原海报展墙：深午夜靛蓝 `#0A1047` / 暗舱 `#121A63` / 暗底明薰衣草字 `#F1F0FF` / 暗底亮蓝 `#8C9BFF`
  - 语义克制双色：错态朱红（浅底 `#C2232A` / 暗底 `#FF8A8E`）、达标松碧（浅底 `#0B6B4F` / 暗底 `#66E3B8`）
- **字体搭配**（全库唯一；三款西文/等宽在近 12 页全部 0 次使用，与 163 零辅助重合）：
  - `Noto Sans SC`（400 / 700 / 900）— 现代瑞士出版黑体，承袭原海报大标与中文正文（正文西文与数字跟随正文防跳动）
  - `Bricolage Grotesque`（400 / 600 / 800）— **近 12 页未用**，富有建筑张力的英文展示标题与章节标牌
  - `EB Garamond`（400 / 600 正体 + 400 斜体）— **近 12 页未用**，经典书籍出版衬线，用于历史标本、出版名言与典籍斜体标注
  - `DM Mono`（400 / 500）— **近 12 页未用**，温润等宽数字，用于等宽页码（folio）、分栏标尺与单真源读数

## 5. 节目录（01–07，相邻两节交互零重复）
- **01 信息分组：把散点聚成地图**（亮读纸 `#F5F4FD`）— 交互：**真实 3 秒「找章节」计时扫读测试**（用户亲手在「15 条流水账」和「5 组集群目录」中点击寻找指定子目，实时对比自己的真实耗时秒数）。
- **02 层级与对齐：眼睛读懂主次**（薰衣草柔纸 `#EAE7FA`）— 交互：**四类真实出版物目录标本切换台 + 对齐轴线/等宽数字透视开关**（古典书刊 / 现代杂志 / 学术报告 / 网页文档）。
- **03 断眼暗室：页码为何会串行**（深午夜靛蓝暗室 `#0A1047`）— 交互：**2D Canvas 跨栏眼动偏差实验台**（直切四种经典目录错态，动态绘出扫读射线偏差角，并温和指出原海报静态清单未明言的跨栏串行风险）。
- **04 从简牍总目到网页导览**（净白书纸 `#FAF9FF`）— 交互：**五幕目录演变历史标本翻页卡**（公元前 26 年汉代《别录》《七略》→ 公元 77 年老普林尼《自然史》卷一 → 1470 年科隆首印叶码 → 1956/2001 认知组块研究 → 1992 与当代网页扫读规范）。
- **05 边界与分工：何时别放目录**（薰衣草雾纸 `#E7E4F8`）— 交互：**六场景逐卡分诊翻牌（该用/慎用/禁用）** + 同小类 `160–167` 一句话分工链接矩阵。
- **06 随堂实战：挑出最好扫读的一版**（亮读纸 `#F4F3FC`）— 交互：**严格单变量四选一排版判卷（方案 A / B / C / D）**，四张微缩目录标本除「页码排布与跨栏连结方式」外完全一致，中性选项不剧透，选后逐一拆解理由。
- **07 原海报与核心关键词**（深午夜靛蓝展墙 `#0A1047`）— 交互：**原海报高清灯箱（点开缩放、拖拽、Esc 关闭）** + 海报母题解剖与三枚关键词复盘。

## 7. 小练习设计
- **题目**：同一本 120 页建筑年刊的 5 章目录，文案、字号、字体、分组和页宽完全一致，仅改变「页码排布与跨栏连结方式」。快速寻页时，哪一版最不容易串行且版面最克制？
- **四选项（仅差一个变量，纯中性标签「方案 A / B / C / D」）**：
  - **方案 A**：标题左齐、页码推到最右端，中间大片裸白无引线（常见默认模板误区：跨距过宽，视线易滑到上一行或下一行）。
  - **方案 B**：标题左齐、页码推到最右端，用粗密实心点线填满整行（常见旧式误区：密集黑点形成横条纹噪点，喧宾夺主盖过章名）。
  - **方案 C（正确）**：页码采用等宽数字列在标题左侧紧邻位置，形成清晰垂直锚轴（零跨栏跳距、零引导线噪点，扫读章名时顺眼即得页码）。
  - **方案 D**：整行居中排布、页码换行压在标题正下方（装饰感强但破坏左侧扫读基线，每换一行眼睛都要重新找起点）。
