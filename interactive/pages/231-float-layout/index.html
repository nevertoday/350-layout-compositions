            01
            
脱离块流，只让行盒绕道

          

          HALF OUT OF FLOW · CSS 2.1 §9.5
        


        

          原海报开篇写道「浮动使元素脱离文档流」，但真正读懂浮动，必须把这句话再拆细一层：和完全悬浮在独立图层上的233 绝对定位布局不同，浮动是「半脱离」——它对223 块级布局的盒子边框与背景隐身，却对224 行内布局里的文字行盒（Line Box）完全显形。所以后一段的背景色会直直钻到浮块底下，只有里面的字会自动缩短绕开。
        


        

          

            
          

          

            

              
              
            


            

              

              

              
            


            

              三层叠在一起时可以清楚看到：最底层淡蓝块盒稳稳占满 100% 容器宽度、无视浮块存在；而顶层文字行盒遇到中层朱红浮块的 margin 边界立刻缩短，直到跨过浮块底边才重新拉回整行宽度。
            

          

        

      

    


    
    

      

        

          

            02
            
三式图解与多浮块卡钩

          

          LEFT, RIGHT & FLOAT SNAG
        


        

          原海报中部用三张白卡展示了左浮动、右浮动与多个浮动元素，并在总述中提到「常用于图文混排、卡片布局、媒体对象等场景」说多了一点。在早期没有现代网格的年代，前端确实只能用多浮块横排卡片；但只要其中一张卡片多出哪怕一行文字，下一排浮块往左贴边时就会被高出的卡片底边勾住，引发著名的 Float Snag（浮动卡钩）——今天排多列卡片，请直接交给227 网格布局或226 弹性盒布局。

            04
            
不止矩形：沿轮廓包裹

          

          SHAPE-OUTSIDE & EDITORIAL RUNAROUND
        


        

          既然卡片网格交给 Grid、组件对齐交给 Flexbox，今天为什么浮动还不可替代？因为唯有配合 float 与 W3C CSS Shapes Module Level 1 的 shape-outside，正文才能贴着圆形、斜切多边形或大号首字的轮廓自然流动，呈现杂志级的有机版面节奏。
        


        

          

            
FLOAT

            

              在活字印刷与现代杂志版面里，文字不必永远拘泥于生硬的九十度直角矩形。当你为浮动元素声明 shape-outside 时，浏览器不再只看它的矩形边界盒，而是按你指定的圆弧、椭圆或斜切多边形轮廓逐行计算行盒起点。每一行汉字都会像沿着河岸流淌的溪水一样，自动贴合图形的起伏顺势折行；一旦流过图形底端，正文立即自然恢复完整栏宽，不需要任何手工断行或把正文切成两半。配合 shape-margin，你还能精准控制轮廓外沿到文字笔画之间的呼吸气口。

从铅字绕图到 CSS 三十年

          

          ORIGIN & EVOLUTION · 1995–TODAY

何时该浮，何时换方案

          

          WHEN TO USE & WHEN TO AVOID
        


        

          用对地方，浮动两行代码就能写出流畅杂志感；用错地方，你会在卡钩错位、高度塌陷和垂直居中里耗掉整个下午。点击六类真实界面需求，立刻查看该不该用浮动以及现代首选替代方案。
