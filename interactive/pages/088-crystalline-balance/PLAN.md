# 088 晶体式平衡（CRYSTALLINE BALANCE）互动页方案

## 1. 一句话道理
晶体式平衡不是简单把多边形镜像粘贴，而是让多面体模块沿同一套晶格对称轴严丝合缝咬合、从晶核向外按比例有序生长，并用不同倾角的切面把同一束光折出明暗韵律——对称与咬合锁住秩序稳定，切面折光破除僵硬呆板。

## 2. 开场玩具
- **名字与形态**：**3D 晶格结晶与棱镜折射台**（Three.js 实时 3D 多面体晶体引擎，关 WebGL 时自动降级为共用 `model.js` 同一套 3D 顶点、切面法线与投影矩阵的 2D Canvas 晶体着色器，舞台标 `data-perf-drag`）。1:1 承袭 088 原海报冷冽冰白宣纸、深钴蓝六方晶核、四向主双锥棱晶、四斜向蓝紫切面柱晶、悬浮外延晶芽与淡蓝测角虚线骨架，支持「原海报 · 六方雪晶 / 冰川 · 棱面展馆 / 品牌 · 晶体标志」三套真实语境标本。
- **怎么玩**：
  - 在 3D 晶体画布上**横向拖动**：连续旋转 3D 平行光源方位角（也可切至「旋看晶簇」模式自由察看立体棱面），实时改变每一块晶面的明暗受光与折射光阶；
  - **直接点击晶体上缺失/错位的晶臂锁点**：逐支补全或切开晶臂，验证对称轴平衡；
  - **直接推拉外围晶臂 / 精控轨**：调节「晶核咬合缝（-14% 互穿挤爆 ↔ 0% 严丝咬合 ↔ +34% 脱节散架）」、「切面棱高（10% 扁平死片 ↔ 55% 立体折光 ↔ 100% 过刺碎裂）」、「晶芽生长比（0% 枯萎 ↔ 48% 递减有序 ↔ 125% 外重倒挂）」及点群晶系（`偏侧断轴 / D2 双轴 / D4 四方 / D6 六方`）；
  - 按 **Space**（或点按钮）：从晶核发射一束「偏振折射光脉」，沿切面实时演示光束在多面体之间的折射流动（切面扁平或脱节时，光脉在断缝处散失或呆直穿过）。
- **一打开是什么状态（绝不是答案）**：
  开场停在 **0/4 散架断轴的伪晶体坏态**：① 晶核咬合脱节 `+28%`（棱晶悬空不咬合）；② 对称轴破缺（缺左侧主臂与左上斜晶共 2 臂且错角 17°，实测重心偏移 ΔG 25%）；③ 切面棱高被压平至 `12%`（实测明暗光差 19%，一片死蓝无折射韵律）；④ 外延晶芽反胀到主棱晶的 `1.18×`（外重内轻比例倒挂）。
- **怎样算玩错、读数怎么说**：
  全部几何与光学读数由 `model.js` 单真源实时计算，**双向 9 类真错态**都会精准报出原因与纠正动作：脱节散架（缝 > 10%）、互穿挤爆（缝 < -8%）、对称断轴/缺臂偏载（对称度 < 88% 或重心偏 > 8%）、死平无折（切面明度极差 < 22%）、过刺眩碎（棱高与光比过度导致高光爆白 > 78%）、外重倒挂（晶芽比 ≥ 0.85×）、外延枯萎（晶芽比 < 18%）、主斜死等（主斜长度完全 1:1 缺乏主次层次）以及无核空心。支持「原海报六方雪晶解」「纯 D6 冰花解」「D4 建筑晶塔解」及任意达标自定义解（均 4/4）。
- **与最近 12 页的区别**：
  紧邻 087 是暖米酒红 2D 极坐标折扇射线；086 是暖米深松青 3D 建筑纵深门框推拉；其余 10 页皆为 2D 平面/网页/幻灯片/剪纸/印前。本页以**冰霜冷白 × 深钴蓝 × 薰衣草冰紫**的 3D 多面体结晶与真实法线光路折射为核心动作，玩法、配色、材质与版式骨架完全不同。

## 7. 练习
- **第 1 题（晶体核心构型）**：四幅同为六方冷蓝紫晶簇的方案，仅标 `方案 A / B / C / D`，只差一个变量：
  - A：咬合脱离（外围棱晶与六方核留出 22% 散缝）；
  - B（正确）：棱晶咬合紧实、六轴镜像精准、切面受光明暗阶梯分明、外延晶芽约为主晶 0.52× 有序递减；
  - C：咬合与对称正确，但所有切面压缩成均质单色扁片，毫无折光层次；
  - D：咬合与折光正确，但外延晶芽胀大至主晶 1.2×，外重内轻倒挂。
- **第 2 题（展板版式运用）**：四幅同主题「光学展主视觉」草图，仅标 `方案 A / B / C / D`，只差一个变量：
  - A：主视觉晶体居中，但文字块无序斜插切碎对称轴；
  - B：晶体退缩为角落小装饰，整体退化为常规左文右图；
  - C（正确）：以中心六方晶格轴线对齐主副标题与四隅引线注释，切面明暗托住文字层级；
  - D：整页铺满等大高反差碎棱，无主晶核、无留白停顿，视线过载。
