# 238 固定宽度布局（FIXED-WIDTH LAYOUT）互动页设计方案

## 1. 一句话道理
把内容容器锁定在人类眼睛扫读最省力的最大宽度以内，用左右均分的留白承接宽屏多余空间，并在窄屏下优雅退回流体护栏，才能让阅读路径、视线回扫与视觉重心始终保持稳定。

## 2. 开场玩具
- **命名**：活体固定容器制图台 × 五屏同步压测剖面带（2D Canvas 1:1 承袭 238 原海报双侧毫米标尺、贯通虚线导轨、橘色斜纹「左右留白」带、顶骑「固定容器」深海蓝药丸的浏览器画框，底嵌 375 / 768 / 1024 / 1440 / 1920px 五屏同步剖面）。
- **怎么玩**：
  - 在主制图画布（`data-perf-drag`）直接**左右拖动**实时拨调固定容器的目标宽度（420–1380px，经过 680 / 960 / 1120px 等经典档位时轻微吸附），也可按方向键 `← / →` 微调（`Shift` 加速）。
  - 点击画布底部的 **375 / 768 / 1024 / 1440 / 1920px 五屏剖面**，把任意屏幕拉到主画布放大检视，其余四块剖面始终实时联动，一眼看清同一条 CSS 在不同屏宽下的真实表现。
  - 在下方控台切换 **3 套真实题材**（原海报三栏图谱 / 单栏长文专栏 / 产品官网着陆页）、**宽度锁法**（硬锁 `width` / 上限 `max-width` / `CSS min()`）、**水平对齐**（贴左 `margin:0` / 居中 `auto` / 贴右）与 **内边距护垫**（`0px` / `24px` / `36px` / `88px`）。
- **初始错态（0/4 待校容器，绝不先给答案）**：
  - 容器硬锁 `width: 1280px`、水平 `margin: 0` 贴左、内边距 `0px` 贴壁。主视口 1440px 下左 0px / 右 160px 失衡且单栏过宽；底部五屏剖面里 375px、768px、1024px 三块同时亮起朱红横向溢出警报与真实横向滚动条（375px 截断超 70% 内容）。
- **怎样算玩错、错了读数怎么说**：
  - `model.js` 从同一组几何坐标实算 8 类失误：硬宽横滚溢出（直报溢出像素与违背 WCAG 1.4.10）、左/右贴边偏沉（直报左右留白差 Δpx）、超宽串行（按当前题材动态核算每行字数，长文题材宽于 760px 依然报错）、过窄挤碎（三栏单列被压窄且两侧大面积空洞）、零垫贴壁（文字直接顶死边框与屏幕玻璃）、巨垫吞栏（手机端内边距吃光正文区）、超宽孤岛提醒。
  - 读数不只是报数字，还会用白话讲清**眼睛和手指会遇到什么麻烦**，并给出下一步调校方向；接受 960 经典解、1120 宽版解、长文 680 专注解及任意落入合理带的自定义解。
- **与近期 12 页及相邻 237 / 239 的区别**：
  - 239 流体布局玩的是单视口右墙手柄拉伸三条百分比弹性轨道；本页玩的是**固定容器宽幅标定 + 五种真实设备屏宽同步剖面对比**，直击固定宽度在宽屏稳重心、在窄屏会溢出的双面机制。
  - 放弃 237 / 319 / 113 / 114 / 197 的暗室或左栏右台侧栏骨架，回归 238 原海报标志性的**暖米宣纸居中建筑制图单页**。

## 3. 版式骨架
- **1440×900**：暖米制图纸（`#F6EFE2`）左右缘嵌原海报垂直毫米刻度尺，中心铺开 1320px 宽建筑制图主框——顶部极简 32px 眉条 + 紧致居中刊头（大标「固定宽度布局」自带动态宽度标尺括号，配 `FIXED-WIDTH LAYOUT` 与朱橘短杠）→ 全宽主画布（上 74% 原海报浏览器固定容器与斜纹留白带 + 下 26% 五屏同步剖面）→ 紧接双栏直框诊单控台与原海报底沿三圆实况图例带。不锁 `100svh`。
- **2560×1440**：主制图框舒展至 1680px，两侧毫米标尺与虚线导轨依然完整框住主体，不显孤小。
- **1024×1366 / 768×1024**：自然流式排布，不留空白大洞。
- **390×844**：压紧单行刊头与题材切换，使主制图画布稳占首屏 ≥46% 屏高，同屏露出白话诊单主标题；侧边装饰标尺收窄为细刻度线，零横向溢出。
- **844×390**：横屏切为左 58% 主制图画布 × 右 42% 紧致刊头、诊单与快控并行，等比绘制不压扁。

## 4. 配色和字体
- **逐像素实采自 238 原海报**：
  - 暖米图纸底：`#F6EFE2` / 象牙亮纸 `#FAF5EA` / 暖砂纸 `#EFE5D3` / 线灰 `#D7CCB9`

  - 炭墨主字：`#0F0F0D`（大标与正文）、次墨 `#3E4856`

## 5. 节目录（7 节，每节 h2 ≤ 12 字，相邻节不复用同款交互）
- `01` **海报拆解：三根支柱**（Three Structural Pillars）：引出 238 原海报三条要点，温和补正「硬固定在窄屏会溢出的前提」，配三支柱交互建筑剖面图卡。
- `02` **为什么限宽才好读**（Measure & Eye Sweep）：从眼动回扫与 Bringhurst / WCAG 行长带讲清限宽价值，配真实排版段落字号×容器宽实时行长测算台（中英可切）。
- `03` **硬锁与护栏的生死线**（Width vs. Max-Width，深海蓝暗室）：对比 `width` / `max-width` / `min()` 三种写法，配 WCAG 1.4.10 的 100%–400% 缩放真实内嵌滚动压测框。
- `04` **从表格像素到 960 网格**（Origin & Evolution）：梳理 1996 Siegel → 2000 Allsopp → 2008 960.gs → 2010 Marcotte → 2018 WCAG 2.1，配 960 整除因子列网剖分交互尺。
- `05` **什么时候用，什么时候别用**（When to Use & Avoid）：明确适用与禁用边界，并一句话外链 239 流体、240 响应式、241 自适应、242 容器查询、227 网格、226 弹性盒，配 6 类真实业务场景选型诊断器（含全宽破格示范）。
- `06` **小练习：选出最稳容器**（Practice: Pick the Container）：四选一单变量对比题（A 硬锁溢出 / B 正解 / C 超宽串行 / D 左贴失衡），带双屏示意图与分项解析。
- `07` **原海报与关键词**（Original Poster & Keywords）：原海报点击放大拖拽灯箱（`draggable="false"`、Esc 关闭）+ 原海报三组关键词对照 + 页脚。

## 7. 小练习
- 题干：为一个同时面向桌面与手机用户的中文技术长文专栏（16px 正文）选容器样式，哪一套方案既护住阅读行长又不让手机横向滚动？
- 四个选项标签只写中性 `方案 A / B / C / D` 与真实 CSS：
  - **A**：`width: 720px; margin-inline: auto; padding-inline: 24px`（仅差锁法：硬锁致手机溢出）
  - **B**：`width: 100%; max-width: 720px; margin-inline: auto; padding-inline: 24px`（正确答案）
  - **C**：`width: 100%; max-width: 1360px; margin-inline: auto; padding-inline: 24px`（仅差上限：桌面超宽串行）
  - **D**：`width: 100%; max-width: 720px; margin: 0; padding-inline: 24px`（仅差居中：桌面左贴失衡）
