# 293 布局切换模式（LAYOUT SWITCHING PATTERN）设计方案

## 1. 一句话道理
当屏幕尺寸或使用任务发生质变时，只靠拉宽边距或机械折行会让信息层级塌陷；布局切换模式在关键断点主动重组模块的空间位置与主次权重，同时守住模块身份与阅读序，让信息在不同容器里都保持清晰。

## 2. 开场玩具
- **名称**：双态重组蓝图台（Live Split-Curtain & Modular Grid Shifter，2D Canvas `data-perf-drag`）。
- **视觉承袭**：1:1 承袭 293 原海报「左暖米 `#FAF2E9` 切换前线性顺序｜右柔樱粉 `#F5C3D4` 切换后模块重组」满幅 50/50 对开画幅，四枚核心模块保持原海报几何标识（`01 ●`、`02 ■`、`03 ▲`、`04 ⬢`），中缝立起玫粉 `切换 SWITCH →` 拉帘与 `重组 ADAPT / 响应 REFRAME` 虚线脊。
- **怎么玩**：
  1. **横拖拉帘/画布（`data-perf-drag`）**：在 `360px ↔ 1200px` 连续推拉当前视口宽与切换进度，亲眼看四枚模块沿平滑 FLIP 弧线跨断点完成从「线性顺序」到「模块重组」的形变与移位；窄屏（<720px）下画布自身也切换为单镜连续帘幕变形台，避免双屏压扁。
  2. **直点交换 `AFTER` 模块槽位**：直接点选蓝图里任意两块模块互换角色（如把抢占主位的 `04` 换回底通栏、把 `01` 扶正为主视觉焦点），或切换四种宽屏蓝图（`纯拉宽线性`、`原海报 1+2+1`、`左主右三`、`双列错落`），同步刷新真实 CSS `grid-template-areas`。
  3. **调校断点与连续性开关**：拖动切换断点（`340px–1240px`），开关「保留 01–04 身份锚点」与「Tab 焦点路径叠加」。
- **一打开的状态（刻意不是答案）**：停在复合错态——目标宽屏处于「主次倒挂」（`04 ⬢` 占顶通栏主位、`01 ●` 被挤入底条，视觉序与 DOM 序产生 5 处逆序）、切换断点误设在 `350px`（375px 手机屏也被硬挤出 127px 碎卡）、且模块身份锚点关闭（换壳变色）。
- **怎样算玩错 & 读数怎么说「为什么」**：由 `model.js` 从当前配置算出的真实 375px / 1080px / 当前视口实绘矩形单真源核算 5 类失误：
  - 伪切换（宽屏仍为单列拉伸、主副面积比 `< 1.25×`）→ 指出只拉长了行宽，未形成层级重组；
  - 断点过低（`bp ≤ 520px` 导致 375px 手机最小卡宽 `< 175px`）→ 指出窄屏多列硬挤、单卡折行破碎；
  - 断点过高（`bp > 1040px`）→ 指出常规桌面端一直锁死在单列里切不动；
  - 主次倒挂 / 焦点逆跳（实绘阅读序相对 DOM `01→02→03→04` 逆序数 `> 0` 或 `01` 未居主位）→ 指出键盘 Tab 焦点与视线折返跳动；
  - 身份断锚（关闭编号形色锁定）→ 指出切换后用户认不出旧模块去了哪里。
  - 接受「原海报 1+2+1」、「左主右三」、「双列错落」且断点落在 `560–960px`、零逆序、留锚点的多组合法解。
- **与最近 12 页的区别**：
  - 不使用 `0/4` 红色打勾诊单盒或通用仪表盘侧栏（区别于 292/040/124/249/291/162/207/039/123/327/248）；
  - 玩法聚焦「跨断点结构重组 + 模块槽位直换 + FLIP 连续性 + 真实 `grid-template-areas`」，无法移植给 291（边距流动）或 292（重力落列）或任何非响应式构图编号。

## 3. 版式骨架
- **1440×900 / 2560×1440**：全幅 50% 暖米｜50% 柔樱粉垂直对开首屏（不锁 `100svh`），无深色顶栏；主内容宽 `1360px`（2560 舒展至 `1680px`）。超粗黑大标「布局切换模式」横跨中缝 → 宽幅双态重组画布 → 紧贴精简视口/断点/蓝图操控轨 → 原海报圆角细框三步演进研判胶囊 → 通栏玫粉底白字横幅收脚。
- **1024×1366 / 768×1024**：自然流排不锁高，避免中段空洞。
- **390×844 竖屏**：顶部压紧单行刊头与三题材切换，说明文字后置，让等比单镜连续帘幕画布稳占首屏 ≥47% 且首屏直露结构研判首句。
- **844×390 横屏**：切换为左 56% 连续变形画布 × 右 44% 刊头、核心控轨与结构研判并行。
- **正文七节**：在暖米纸 `#FAF2E9`、浅樱雾 `#FBEBF1`、03 节玄墨暗室 `#110E11`、亮米白 `#FFFBF6`、柔樱粉 `#F8DAE6`、暖米纸与 07 节玄墨暗室间明暗交替推进。

## 5. 节目录（7 节，h2 均 ≤ 12 字，相邻控件零重复）
1. **01 不止是折行，是换骨架**（What switching means）：阐明 293 与 291/292/294/296 的本质区别，温和指出原海报“说多了一点”的边界；交互：**三模式跨屏对比台**（同 4 模块在 291/292/293 间按视口切档实绘比较）。
2. **02 从 2012 五模式走来**（Where it comes from）：核实 2010 RWD → 2012 Layout Shifter → 2015 FLIP → 2016/2017 CSS Grid → View Transitions & `reading-flow` 谱系；交互：**编年史折叠细节卡片**（`<details>` 轻查阅）。
3. **03 一行区域图，整页换结构**（Grid areas & focus · 玄墨暗室）：剖析 `grid-template-areas` 与 WCAG 1.3.2 阅读/焦点顺序；交互：**4×3 活体区域涂色器 + 单步 Tab 焦点路径检视**。
4. **04 切得稳，守住心理地图**（Continuity across shifts）：拆解视觉锚点、FLIP 过渡窗口与减动降级；交互：**2D Canvas 双窗同步切换剧场**（可调瞬切/经验窗口/拖沓三档并实播位移轨迹）。
5. **05 什么时候用，什么时候别用**（When to switch — or not）：列出四类高收益场景与四类禁区，附同小类 294/298/299/300 一句话跳转；交互：**场景速判翻转卡**（点选检验“该切/别切”与替代方案）。
6. **06 练一练：哪套切换最稳？**（Practice · pick the sound switch）：单变量四选一练习；交互：**四组双端微型蓝图选卡 + 选后透视诊断层**。
7. **07 原海报与关键词**（The original poster · 玄墨暗室）：原海报灯箱（点击放大、拖动、缩放、Esc 关）+ 切换/重组/响应三枚几何印章。

## 7. 练习设计
同一套 4 模块页面（窄屏均为 `01→02→03→04` 线性序列），呈现四个中性标签的宽屏切换方案（A / B / C / D），各方案仅在一个核心变量上区分：
- **A**：仅横向拉宽线性堆叠（无结构重组，主副面积比 `1.0×`）
- **B（正确）**：`720px` 断点重组为 `1+2+1` 模块网，`01` 居主视觉位，阅读序与 DOM 零逆序，保留 `01–04` 锚点
- **C**：同样 `1+2+1` 与 `720px` 断点，但将 `04` 放主位、`01` 放右下角（DOM 焦点逆跳 3 处）
- **D**：同样 `1+2+1` 与正确顺序，但断点设在 `340px`（375px 窄屏强行双列致单卡压碎至 135px）
