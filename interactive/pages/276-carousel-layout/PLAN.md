# 276 轮播布局（CAROUSEL LAYOUT）互动页方案

## 1. 一句话道理
轮播布局把一组同级内容沿水平轨道排成序列，靠「居中放大聚焦」锁定当前唯一主角，靠「两侧露出一角」提供天然的可滑线索（Affordance），让用户用有限的视口宽度连续探索多条内容，前提是把翻页节奏交还给用户。

## 2. 开场玩具：活体轮播视口 × 实时露边光学测绘台
- **玩法**：主角本身就是一条真正可上手横拖、轻弹吸附（spring snap）的 5 卡水平轮播轨道（`data-perf-drag` 直接标在活体轮播轨道上），完全复刻 276 原海报的孔雀青深山圆月、淡薄荷晨丘、奶油杏黄方丘等现代几何景观序列。用户既可以在轨道上直接左右拖拽/点侧卡/按方向键 `← →`/点骑边圆箭与分页点切帧，又可以实时调校 4 个核心架构参数：
  1. **侧卡露边（主卡宽度比例 44%–100%）**：支持双向玩错——过宽（主卡 ≥ 90%，露边 < 5%）闷死无提示；过窄（主卡 ≤ 50%，露边 > 24%）碎成三列小卡片墙、失去单主焦点；经验舒适带为主卡 54%–82%（单侧露边 8%–22%）。
  2. **居中聚焦差（缩放 1.00×–1.38× + 侧卡柔淡）**：支持双向玩错——1.00× 平权无主次；≥ 1.32× 过度夸张把侧卡压成细纸条；经验舒适带 1.08×–1.24×。
  3. **导航与进度（全隐藏 / 仅圆点 / 骑边箭+5点 / 12帧过载点）**：可体验无入口盲翻、仅微点难按、12 帧小米点过载与原海报标准「骑边圆箭 + 5 枚分页点 + 帧计数」。
  4. **播放节奏（1.8s 狂飙自播 / 5s 慢播+悬停暂停 / 用户手动）**：亲身感受自动切页抢读打断与交还掌控权的差异（`prefers-reduced-motion` 下冻结动画展示静止警示条）。
- **开场状态（0/4 翻车错态）**：主卡 100% 占满视口（露边 0px 闷死）、居中聚焦 1.00× 平权、导航全隐藏、1.8s 狂飙自播进度条推进——四个维度全错，绝不先给答案。
- **读数与「为什么」**：顶部叠加 2D Canvas 实时露边光学测绘尺，与底部浅薄荷说明板的白话诊单、四柱原则检核（聚焦展示 / 连续浏览 / 预览提示 / 导航控制）全部共享 `model.js` 单一真源，根据真实视口像素宽度算出单侧露边 px、露边占比、主侧面积比，并用白话说明「这样摆用户会怎么看、为什么会误判或放弃」。
- **与最近 12 页的差异**：
  - 275（相邻编号）是深梅紫双栏画廊（大画+下方缩略阵+顶部比例尺）；
  - 108/147/025/314/192/062/107 均为左右双栏配独立滑尺或拖拽图元；
  - 230/274 是财务数据表；024 是深夜蓝平行线横带；313 是 2.39:1 电影横卷；
  - 276 首创「暖米白全宽通栏活体水平轮播视口 + 原海报浅薄荷圆角说明横板」，直接拖动轮播卡片轨道本身，配合温润圆角浮卡与孔雀青+杏黄清爽 UI 质感，与全部近 12 页完全区分。

## 3. 版式骨架
- **1440×900（桌面）** & **2560×1440（超宽）**：不锁 `100svh`。主体宽 `1360px`（2560 下扩至 `1780px`）。结构自上而下严格复刻 276 原海报：极细 34px 顶眉 → 双翼刊头（左：内嵌实时联动三联微缩徽标的示范大标「轮播布局」+ `CAROUSEL LAYOUT` + 青竖杠总述；右：原海报大浅薄荷圆 + 孔雀青小圆 + 4×4 点阵）→ 通栏活体轮播舞台（顶沿 2D Canvas 露边测绘尺 + 5 卡可拖轨 + 骑边圆箭 + 分页点）→ 单行精炼调校条 → 原海报标志性浅薄荷圆角横板（左 40% 孔雀青双卡圆徽与实时白话诊单 | 竖虚线 | 右 60% 原海报 2×2 四原则活体检核阵）。
- **1024×1366 & 768×1024（平板）**：自然紧凑排布无大片空洞，调校条整齐折成 2×2，浅薄荷说明板上下排布。
- **390×844（手机竖屏）**：单行压紧顶标（标题+态标一行，省去右上装饰圆，总述下移），活体轮播舞台（含测绘尺、等比卡片、分页点）稳占首屏 ≥ 48% 屏高，同屏可见露边滑控与诊单首行；卡片比例随屏宽等比计算不压扁。
- **844×390（手机横屏）**：切为左 58% 活体轮播舞台与分页点 × 右 42% 精简刊头、主控与实时诊单并行。

## 5. 节目录（8 节）
1. **01 · 为什么两侧必须露出一角**（`THE PEEK AFFORDANCE`）：讲格式塔完形与可滑线索；交互为多设备（390/768/1280）可调「视口遮幅实验窗」，对比 0% 闷死、假边缘陷阱、舒适露边与碎卡墙。
2. **02 · 居中放大，是怎么定主次的**（`CENTER FOCUS HIERARCHY`）：拆解缩放、浮影与旁卡退让三要素；交互为三维度独立开关 + 2D Canvas 视觉权重示意曲线对照台。
3. **03 · 从幻灯圆盘到九成盲区**（`ORIGINS & ATTENTION DECAY`）：深海暗室讲 Kodak Carousel（1961）、Cover Flow（2006）、Erik Runyon（2013）与 Jakob Nielsen（2013）实证；交互为 5 帧内容排位沙盘，实时按 2013 年实测衰减比例展示第 1 帧 vs 后置帧的触达落差。
4. **04 · 自动播放为什么最容易翻车**（`WHY AUTOPLAY BACKFIRES`）：讲移动靶打断、横幅盲视与 WCAG 2.2.2 / W3C APG 暂停规范；交互为真实「28 字限时读卡」体验器（2s 狂飙抢读可真点错 vs 5s 悬停即停 vs 手动）。
5. **05 · 什么时候用，什么时候别用**（`WHEN TO USE & AVOID`）：先引原海报四适用场景并温和辨析「多项对比」的边界，再一句话链接同类页（269/270/271/272/274/275/289）；交互为 4 类真实产品需求分诊卡。
6. **06 · 原生 CSS 就能写的轻轮播**（`MODERN CSS SCROLL SNAP`）：讲 W3C CSS Scroll Snap（2016 CR / 2021 Snapshot）与无障碍角色；交互为原生水平滚动捕捉微型沙盒 + 实时联动 CSS 声明块。
7. **07 · 挑一版最合理的手机轮播**（`QUICK PRACTICE`）：四选一客观单变量练习，只差主卡占宽与边缘露法。
8. **08 · 原海报与关键词**（`ORIGINAL POSTER`）：原海报可缩放拖动灯箱（`draggable="false"`）+ 四组原海报中英关键词与点阵章。

## 6. 来源核实
- **Kodak Carousel（1961）**：独立发明人 Louis Misuraca 构想圆形片匣；Kodak 1961 年推出 Model 550；工业设计师 David E. Hansen 获美国外观设计专利 USD201106（1965-05-11 授权），2004 年 6 月停产。核实：`https://en.wikipedia.org/wiki/Carousel_slide_projector`
- **Apple Cover Flow（2004–2006）**：2004 年底 Andrew Coulter Enright 构想、Jonathan del Strother 开发，2006 年 9 月 12 日随 iTunes 7 发布。核实：`https://en.wikipedia.org/wiki/Cover_Flow`
- **Erik Runyon（2013）**：*Carousel Interaction Stats*（University of Notre Dame，2013 年 1 月原发、7 月半年 370 万访问更新，首页点击率约 1%，第 1 帧占约 84%）。核实：`https://erikrunyon.com/2013/01/carousel-interaction-stats/` 与 `https://erikrunyon.com/2013/07/carousel-interaction-stats/`
- **Nielsen Norman Group（2013）**：Jakob Nielsen *Auto-Forwarding Carousels and Accordions Annoy Users and Reduce Visibility*（2013-01-19）；Kara Pernice *Carousel Usability: Designing an Effective UI for Websites with Content Overload*。核实：`https://www.nngroup.com/articles/auto-forwarding/` 与 `https://www.nngroup.com/articles/designing-effective-carousels/`
- **W3C WAI & CSS 标准**：W3C WAI-ARIA APG Carousel Pattern (`https://www.w3.org/WAI/ARIA/apg/patterns/carousel/`)、WCAG 2.1 Understanding 2.2.2 Pause, Stop, Hide (`https://www.w3.org/WAI/WCAG21/Understanding/pause-stop-hide.html`)、W3C CSS Scroll Snap Module Level 1 (`https://www.w3.org/TR/css-scroll-snap-1/`，首个 CR 2016-11-02，CR Snapshot 2021-03-11)。

## 7. 小练习设计
- **题目**：手机竖屏（390px 宽）展示 4 款手冲壶推荐轮播，四版都采用居中放大与手动切换，唯一差别是「主卡宽度与两侧露边」。哪一版最合理？
- **四个选项（标签仅写 方案 A / B / C / D + 客观宽度参数，不剧透好坏，只差主卡占宽一个变量）**：
  - **方案 A（100% 占宽）**：左右无露边，像一张孤立单图，隐藏了后续内容。
  - **方案 B（76% 占宽，两侧各露约 10%）**：**正确答案**——主卡留出充裕阅读空间，左右清晰探出相邻图文提示可滑。
  - **方案 C（48% 占宽，三卡并挤）**：同时挤进三张窄卡，每张正文折行拥挤，居中焦点失效。
  - **方案 D（90% 占宽，边沿恰落空白缝）**：虽然留了 10% 边距，但恰好停在卡片间空白缝（False Edge），看不到邻卡内容，提示落空。
