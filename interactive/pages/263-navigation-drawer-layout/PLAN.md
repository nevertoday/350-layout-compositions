# 263 导航抽屉 布局（NAVIGATION DRAWER LAYOUT）设计方案

## 1. 一句话道理
把低频或多层级的次级路径收进屏幕侧沿，需要时一次侧滑展开、选完即收，在有限视口与复杂信息架构之间换出最大的主内容净空——前提是别把高频少数入口也藏进去，也别在窄屏里硬挤正文。

## 2. 开场玩具：侧滑抽屉实境试拉台（Interactive Slide-Out Drawer Bench）
- **形态**：2D Canvas（标 `data-perf-drag`），1:1 承袭 263 原海报「深勃艮第酒红左侧抽屉 + 玫瑰粉右缘拉手封边条 + 暖杏奶油主内容区 + 虚线推进箭头 `····→`」的实境微应用窗口，支持原海报「知识探索」、多模块 SaaS 后台、移动商城分类三套真实语境。
- **怎么玩**：
  - 在画布中**直接横拖玫瑰粉抽屉竖边手柄**（或左右拖动）实时拉开/推进抽屉并调节物理展开宽度（140–360px）；
  - **直接点击画布内抽屉的任意导航项**真正切换右侧主页面与面包屑；**点击「分类 ▾」**当场展开/折叠二级子菜单；**点击右侧暗层遮罩（Scrim）或按 `Esc`** 验真覆层退场闭环；
  - 切换设备视口（375px 手机 / 768px 平板 / 1120px 桌面或连续拖屏宽）、抽屉物理模式（覆盖 Modal / 推挤 Push / 迷你轨 Mini-Rail / 常驻 Standard）、入口数量（3–15 项）、层级深度（1–4 层）、分组分隔线、背景暗层与当前页高亮；
  - 按 `Space` 启动「跨频道寻路模拟」，指针从主内容出发完成「打开抽屉 → 扫视分组 → 进入二级目标 → 退场释放主区」，实时计算步数、净空释放比与阻塞卡点。
- **开场状态（0/4 复合错态，绝不先给答案）**：
  - 停在 375px 手机竖屏 + 错用「推挤 Push」模式 + 抽屉宽拉到 342px（占屏 91%，主区被压成 33px 竖条，即便切覆盖也仅留 33px < 56px 退场缝）+ 关暗层遮罩 + 13 项无分组平铺 + 3 层深嵌套缩进撞墙 + 无当前高亮，四项核心维度实算全部失守（0/4）。
- **怎样算玩错 & 读数如何说「为什么」**：
  - `model.js` 从实绘几何尺寸与层级树单真源双向检出 11 类错态：窄屏推挤/常驻压扁主区、抽屉过宽吞掉 56px 退场缝、抽屉过窄裁断标题、侧滑抽屉在中小屏缺暗层遮罩导致边界糊连、宽屏仅少量入口却藏进汉堡（NN/g 反模式）、中小屏锁死常驻、超过 2 层深嵌套缩进撞墙、7 项以上不分组形成文字墙、缺少当前位置高亮、入口 ≤4 项杀鸡用牛刀或 ≥13 项塞成杂物间。
  - 同时认可多组合法解（移动覆盖解 / 平板迷你轨解 / 桌面常驻解 / 任意满足 4/4 的配置），绝非唯一答案。
- **与最近 12 页的区别**：
  - 最近 12 页涵盖块级盒尺（223）、居中/两端/强制两端/非对称排字（178/179/180/181）、平衡/比例/尺度/主次/焦点/封闭构图（097/098/099/096/094/093/092）。本页独创「页面自身即是真可收折导航抽屉壳 × 侧边物理滑出抽屉实境微应用 × 抽屉内真切页与二级折叠树」玩法，别的编号完全无法套用。

## 3. 版式骨架（1:1 转译 263 原海报自示范结构）
- **1440×900**：页面自身就是一只活着的导航抽屉布局——左侧常驻 232px 原海报同款深勃艮第酒红真抽屉（带玫瑰粉右缘拉手条、本页章节直达、二级分组折叠与当前高亮带，且可点击粉边条或按 `M` 键真折叠收起释放全宽）；右侧暖杏奶油主纸区展开首屏：顶栏刊头（酒红巨标 + 右侧活体粉弧圆核与 7×5 点阵）→ 满宽侧滑抽屉实境试拉画布与精控条 → 原海报四列圆底优势实时探针 → 底部深酒红圆角灯泡单真源诊单带。不锁 `min-height: 100svh`，自然流排。
- **2560×1440**：左侧常驻酒红抽屉 272px，右侧主纸区内容舒展至 `1580px`，画布与图表等比放大，无大块空边。
- **1024×1366 / 768×1024**：左侧页面真抽屉自动收折为顶沿纤细酒红条（点击 `≡ 目录` 真的滑出覆层模态抽屉 + 暗层遮罩），下方单栏自然流排无空洞。
- **390×844**：顶部 48px 酒红自示范条（真抽屉按钮 + 编号 + 实时状态徽章）→ 单行酒红标题（后置导语）→ 等比近方画布稳占首屏 ≥47% 高度 → 折线内直接露出深酒红灯泡诊单首句、核心宽度滑轨与「一键校准」按钮。
- **844×390**：顶部 38px 紧凑酒红条 → 首屏左 56% 试拉画布 × 右 44% 紧凑标题、诊单与核心操控并行。

## 4. 配色和字体
- **配色（逐像素采自 263 原海报 `site/public/p/263.webp`）**：
  - 深勃艮第酒红抽屉与暗室：`#5B1426` / `#500E21`（大标与深墨） / `#3C0B19`（暗室节底） / `#2B0712`（页脚）
  - 暖杏奶油宣纸系：`#FFF4E5`（主纸） / `#FFF9F1`（亮纸） / `#FBEEDE`（暖桃雾） / `#F8DFD2`（柔桃卡） / `#FBDACC`（图符圆底）
  - 招牌玫瑰珊瑚粉：`#F38292` / `#EB798B`（高亮带、边条、点阵、暗底强调） / `#F17E8D`（图框顶条） / `#F9788D`（7×5 波点）
  - 浅纸高对比深莓果红文字：`#A41A3B` / `#8A1431`（确保浅奶油纸上的彩字对比度 ≥ 5.5:1）
  - 克制语义色：达标松青绿（浅底 `#1B664C` / 暗底 `#73E4B8`）、警示绯红（浅底 `#B52128` / 暗底 `#FF8A90`）
- **字体（全库 0 重复，与 262 零非中文重合，`DM Serif Display` 在近 12 页及 255–270 全部 0 次使用）**：
  - `Noto Sans SC`（400 / 500 / 700 / 900，中文标题与正文）
  - `DM Serif Display`（400 正体与斜体，近 12 页 0 次使用，英文大节序数、年代标与编辑点睛标）
  - `Sora`（400 / 600 / 700，UI 界面西文副标与模式标签）
  - `JetBrains Mono`（400 / 600，像素宽度、步数与模式读数）

## 5. 节目录（7 大节，标题 ≤ 12 字，相邻两节不重复控件）
- **01 藏起与呼出，省在哪**（`HIDE & REVEAL` · 亮奶油纸）：引用原海报四优势并温和修正「提升访问效率」的适用条件（NN/g 2016）；控件：**四类导航布局面积天平对比器**（在 375/768/1280px 下横向对比 263 抽屉 vs 262 顶栏 vs 258 固定侧栏 vs 264 底部导航的内容占比与入口容量）。
- **02 四种滑出方式怎么选**（`DRAWER MODES` · 柔桃雾纸）：Material Design 3 覆盖 / 推挤 / 迷你轨 / 常驻的断屏边界与无障碍退场；控件：**四联实体设备同步滑出矩阵** + 断屏宽度滑杆，一键同步拉开/合上四台微型设备，直看推挤与覆层的本质差别。
- **03 抽屉里面怎么分才不乱**（`INTERNAL ANATOMY` · 深勃艮第暗室）：拆解原海报 7 项菜单为何分组、留细线、只放一级展开箭头；控件：**抽屉信息架构手术台**（4 枚结构治理拨片，实时重组深红抽屉并联动 SVG 扫描眼动折线与认知负荷档位）。
- **04 从施乐三道杠到自适应**（`ORIGIN & EVOLUTION` · 亮奶油纸）：梳理 1981 Xerox Star → 2011 Path 2.0 / Facebook → 2012–2013 Off-Canvas 与 Android DrawerLayout → 2015–2024 NN/g 反思与自适应规范；控件：**可点击年代切片档案轨**（切换 4 个历史年代的微型界面结构图与原委）。
- **05 什么时候千万别用抽屉**（`WHEN NOT TO USE` · 柔桃浅纸）：4 类经典反模式 + 同类替代布局在线链接（264 底部导航、262 顶部导航、258 侧边栏、267 列表—详情、268 辅助窗格、265 标签页）；控件：**3 组真实产品分诊卡片**（切不同业务场景看「强用抽屉」vs「正确替代」的双图对决）。
- **06 小练习：哪一版站得住**（`QUICK CHECK` · 深勃艮第暗室）：375px 手机 9 频道知识库抽屉四选一（仅单一变量差异，中性标签 + SVG 缩略界面图），即时判分与四项逐一拆解。
- **07 看看原海报**（`ORIGINAL POSTER` · 暖奶油纸 + 深勃艮第页脚）：原海报高清放大灯箱（支持缩放/拖拽/Esc）+ 海报核心要点对照与同小类全览导航 + 标准页脚。

## 7. 小练习设计
- **题干**：一台 **375px 手机竖屏** 上的知识库应用需要承载 **9 个核心频道**（分属「阅读 / 整理 / 系统」三组）。以下四个导航抽屉方案每次只改一个关键决策，哪一版最站得住？
- **四个选项（纯中性标签 + 精确缩略图，零暗示）**：
  - **方案 A**：覆层展开 · 宽 352px（右侧露边 23px 暗层）· 3 组细线分隔 · 高亮当前项（仅差「过宽吞掉 ≥56px 退场缝」）
  - **方案 B**：覆层展开 · 宽 280px（右侧露边 95px 暗层）· 3 组细线分隔 · 高亮当前项（**正确**）
  - **方案 C**：推挤展开 · 宽 280px（主区同步缩至 95px）· 3 组细线分隔 · 高亮当前项（仅差「窄屏误用推挤，正文压断」）
  - **方案 D**：覆层展开 · 宽 280px（右侧露边 95px 暗层）· 9 项连续排布 · 无当前项高亮（仅差「内部无分组、无当前定位」）
