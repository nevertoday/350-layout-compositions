# 348 矩阵页 幻灯片版式 · 互动版方案（PLAN）

## 1. 一句话道理
矩阵页把单列清单升级为「两个独立维度相乘」的二维决策坐标系：通过正交双轴完成分类与对比，再用唯一的高亮象限锁死听众视线，让会议在 5 秒内看清取舍与下一步动作。

## 2. 开场玩具
- **名字**：活体四象限决策工作台（Live 2×2 Matrix Slide Desk，全宽 2D Canvas 标 `data-perf-drag`，无右侧仪表盘侧栏）。
- **怎么玩**：
  - 在画布中心或竖向中轴门槛线上**左右横拖**（及底部门槛滑轨、键盘 `←/→`）：连续滑动 X 轴判定门槛（18%–82%），实时重算 6 枚待决策筹码归属、各象限面积比与分类均衡度。
  - **直接拖拽画布内任意议题筹码**跨象限移动，测试归类与堆叠失衡。
  - **直接点击四个象限块**切换信号黄 `#F9CB15` 高亮涂色（可涂 0、1、2、3 或 4 格）。
  - **直接点击轴端标签或顶栏剧本签**切换 3 套正交商业剧本（原海报紧急×重要 / 产品排期投入×影响 / 波士顿份额×增速）与错误轴态（同义假双轴 / 失向无标），并切换格内文案密度（密字报表 / 三行精炼 / 空壳无策）。
  - 按 `Space` 触发 **5 秒会议扫视验真**：视线光束按当前版面的轴向与亮区真实轨迹扫读，验看是否能在 5 秒内锁定决策焦点。
- **开场初始坏态（0/5 失守，绝不预给答案）**：
  - 双轴设为「同义假双轴（重要性 × 价值度）」且缺失四端方向标，6 枚筹码沿对角线塌陷；
  - 竖向门槛偏右至 74%，右侧两格被挤扁成窄条；
  - 四格全部涂满信号黄（4/4 全屏争亮，毫无焦点）；
  - 格内塞满 188 字密字报表。
- **双向玩错与单真源读数**：`model.js` 从实绘象限矩形、筹码归属、高亮格数、双轴正交性与格内字数单真源检出 9 类正反错态（同义假双轴、坐标失向、门槛偏左/偏右压扁、全蓝失焦、多格争亮、高亮空区、格内字墙、空壳缺策、单格堆叠失衡），每条读数明确说出「观众看这页时会发生什么」与「下一步改哪里」；同时认可多组合法解（原海报抢险右上亮解、柯维战略左上亮解、产品排期速赢左上亮解、波士顿明星/现金牛解）。
- **与近期 12 页的差异**：344 是朱橙满幅大数字字阶剥离台、343 是深黑图文分界推拉台、342 是鼠尾草三步重排卡、345 是雾紫删词雕琢仪、266/265/264/263 是 UI 组件实操台、182/183 是文字绕排台、224/223 是 CSS 盒模型流道、178 是深绛中轴碑帖。本页采用**全宽皇家钴蓝蓝图单轴矩阵展板**（零右侧诊断侧栏），玩法独属 2×2 矩阵的**双轴正交校验 × 跨象限筹码门槛归类 × 唯一象限信号黄点亮**，无法照搬到任何其他编号。

## 3. 版式骨架
- **1440×900（主宽 1280px；2560×1440 舒展至 1560px）**：1:1 转译 348 原海报通幅钴蓝单轴展板——顶部左 62% 自示范白字双行巨标（`矩阵` 嵌入随门槛联动的细白 2×2 坐标框）+ `MATRIX LAYOUT` + 短黄杠 + 五词标，右 38% 5×3 白点阵 + 深蓝圆纹 + 剧本切签；中段 **100% 通宽 2×2 活体矩阵画布**；底沿 1:1 复刻原海报**虚线边框大胶囊**（左 36% 黄圆靶标白话诊单 × 右 64% 五栏黄点实时探针 `分类/对比/象限/维度/聚焦`）与精控条、底沿斜线 `///////`。绝不锁 `100svh`。
- **1024×1366 / 768×1024**：自然流高度，零空白断层；矩阵画布保持清晰比例，下方虚线胶囊折为上诊单、下五项网格。
- **390×844（手机竖屏）**：压紧单行刊头与精简剧本条，隐藏顶部装饰点阵，让近方等比矩阵画布稳占首屏 ≥ 47%（~405px），折线内直接露出诊单首句、门槛滑轨与校准/扫视双键；五项探针与次要试错条放折线下方。
- **844×390（手机横屏）**：切为左 58% 矩阵画布 × 右 42% 紧致刊头、实时诊单与操作键并行。

## 7. 小练习设计
- **题干**：产品季度评审要在 2 分钟内拍板「下月优先开发哪批需求」（按**开发投入**与**业务影响**评估）。下面四张草图（方案 A / B / C / D）文字量与版式框架相同，但各自只改了一个关键变量——哪一张能让听众一眼拍板？
- **四选项（标签仅写方案 A/B/C/D，绝不剧透好坏，四图等比 SVG）**：
  - 方案 A：投入×影响正交双轴 + 方向标齐全，但**四个象限全部铺满信号黄**（失焦）。
  - 方案 B：仅高亮右上角 + 方向标齐全，但**双轴写成了「重要性 × 价值度」**（同义假双轴）。
  - **方案 C（正解）**：投入×影响正交双轴 + 四端高低方向标齐全 + **仅高亮左上「低投入·高影响」速赢区**。
  - 方案 D：投入×影响正交双轴 + 仅高亮左上速赢区，但**省略了四端高低极性与轴端箭头**（方向失锚）。
- **正解理由**：矩阵页成立必须同时满足「双轴正交」「方向明确」「单区聚焦对应决策目标」三项。方案 C 的横轴（投入低→高）与纵轴（影响低→高）相互独立，且明确标出四端极性，并精准点亮「低投入·高影响」左上象限，与「先拿速赢」的评审目标一一对齐。
