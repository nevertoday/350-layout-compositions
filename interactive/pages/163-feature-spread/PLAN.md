# 163 特写 跨页（FEATURE SPREAD）互动版方案

## 1. 一句话道理
把对开两页合成一块跨过书脊的宽银幕，只押注一个能讲完故事的局部细节，用大幅放大与干脆的跨边裁切制造画外张力，让简洁文字退守静区、让图像主导第一眼阅读节奏。

## 2. 开场玩具
- **命名**：杂志编辑部看样灯台 · 活体对开特写跨页排印台（全幅 2D Canvas，标 `data-perf-drag`）。
- **视觉母题**：忠实承袭 163 原海报的深松黛绿底（`#013230`）、暖奶白巨环与镉金黄斜楔，内嵌三套风格统一、无五官细节的杂志跨页题材：`原海报 · 巨环几何`、`器物特写 · 曜变茶碗`、`建筑纪实 · 穹顶天窗`。画布呈现实体对开双页（左页 P.42 / 物理书脊中缝折痕 / 右页 P.43）、四角裁切线与 3mm 红色/金色出血线。
- **怎么玩**：
  - 在摊开的杂志跨页上**左右横拖**（`data-perf-drag`），连续推拉特写放大倍率（`0.50×` → `2.45×`），同步观察图像跨边出血与画面张力变化；
  - 拖动跨页底沿的**中缝避让标尺**（或键盘 `A / D`、底部按钮）横向平移主图焦心，亲眼看焦心跨过书脊中缝时被装订槽吞没；
  - 点击画布上浮现的**编辑部红笔看样批注**可就地逐项修错；
  - 切换**出血模式**（留白装框 ↔ 跨边满幅出血）、**文字负载**（240 字长文压图 / 精炼标题短注 / 无字纯图）、**文字落位**（静区留白 ↔ 硬叠焦区）与**装订方式**（骑马钉 4mm 浅缝 ↔ 胶装 14mm 深缝）。
- **开场初始状态（明确未达标）**：`0/3 破功态`——主图缩到 `0.62×` 且锁在留白框内（仅占跨页 24%、0 边出血，缩成普通插图邮票），焦心正压在 `14mm` 胶装中缝线上被劈开，左侧与底部堆着两栏 `240 字`密排长文压死节奏。
- **双向可玩错与单真源读数（全部由 `model.js` 从实绘几何坐标与像素边界实时核算）**：
  - **放大焦点（FOCUS）**：太小（主图面积 < 48%）报「缩成插图邮票，图像主导不了节奏」；太大（倍率 > 2.22× 或主体可辨识轮廓 < 28%）报「放大过头失认，局部沦为抽象色块」。
  - **裁切张力（CROP）**：0 边出血报「四边全包无张力」；边缘擦边未干脆出血（距裁切边 0.5%–3.5%）报「擦边发紧，像没裁干净」；主图焦心落入当前装订方式的中缝吞图带（骑马钉 ±4mm / 胶装 ±14mm）报「关键焦心被中缝吞噬劈裂」。
  - **图文协同（CAPTION）**：长文模式报「密排长文喧宾夺主，压扁视觉主导」；0 字模式报「彻底无字失锚，读者缺少主题入口」；文字强压高对比主图区报「文字撞焦，对比度与呼吸双失」。
  - **接受多组合法解**：原海报右页巨环三边出血解、左页特写右页题注解、跨页四边全出血偏焦解均能同时通过三枚原海报金徽校验。
- **与最近 12 页的区别**：
  - 区别于 123（裁切构图）：123 是暗房取景器切单幅几何并看框外虚线；163 聚焦**实体杂志双页装订（中缝吞图、骑马钉/胶装折痕、3mm 印刷出血、图文静区退让）**与跨页放大叙事。
  - 区别于 161（章节扉页）：161 是暖牛皮纸单卷翻页测上下章降灰；163 是深松黛绿编辑部满幅宽屏看样灯台，核心动作是推拉特写放大倍率、越过裁切线出血、把焦心移出中缝吞图槽。
  - 区别于 162（栏目开启页）：162 是暖米纸左工作台+右朱红出血书口带调方向箭；163 无侧边栏，主舞台为全宽对开杂志跨页。

## 3. 版式骨架
- **整体原则**：不锁 `100svh`（避免 1024×1366 平板出现大片空洞），无独立深色通用导航栏，无圆角仪表盘黑箱；采用 163 原海报的锐利 0px 出版切角、深松黛绿与暖奶白大跨度明暗交替、镉金黄细线与圆徽语言。
- **1440×900（宽屏主宽 1360px；2560×1440 舒展至 1720px）**：
  - 极紧凑刊头带（单行眉标 + 自示范「特写 跨页」大标与原海报镉金黄短杠/波浪徽 + 3 题材切签 + 实时看样结论章，总高 ≤ 100px）；
  - 中央**全宽 100% 满幅对开杂志看样画布**（宽敞直观，左右两页比例真实，高约 450px，占据视觉绝对主角）；
  - 下方无缝承接**三段松绿编辑台账带**（左 32% 单真源白话诊单 + 一键提示 | 中 40% 实体看样控台与多解/试错快钮 | 右 28% 1:1 复刻原海报三枚镉金黄圆徽 `放大焦点 FOCUS / 裁切张力 CROP / 图文协同 CAPTION` 实时状态灯）。
- **390×844（手机竖屏）**：刊头压紧为单行刊号+大标+题材切（≤ 96px），说明文字后置，等比例对开跨页画布占据首屏 ≥ 46% 高度（圆形严格等比不压扁），紧随画布首屏直接露出看样诊单首句与修错按钮。
- **844×390（手机横屏）**：切为左 58% 对开跨页画布 × 右 42% 紧凑刊头、诊单首句与核心控轨并行，一屏可控不溢出。

## 4. 配色和字体
- **配色（逐像素采自 163 原海报 `poster.webp`）**：
  - 深松黛绿（主暗底 / 03 与 06 暗室）：`#013230`、深槽 `#002523`、浮层 `#08403D`、松绿细线 `#185854`、深绿正文墨 `#042422` / `#2E4A47`。
  - 暖奶白原纸（巨环与浅纸阅读节）：`#F1E7D4`（原海报巨环）、亮纸 `#F7F1E4`、暖砂纸 `#EAE0CC`、纸纹框线 `#D4C6AA`。
  - 镉金黄（斜楔与圆徽点睛）：`#F0AF03`、亮金 `#F5C438`、深金 `#C99200`；浅纸安全文字色压深为深琥珀棕 `#7D5300`（保证对比度 > 5.5:1）。
  - 语义状态色：暗底错态珊瑚朱 `#FF8168` / 暗红章 `#9E2517`，暗底成立青翠 `#6FE3B5`；浅纸错态深赤 `#A32617`，成立深翠 `#0B6148`。
- **字体搭配（全库唯一，且三款西文/等宽在近 12 页与 160–162 全部 0 次使用）**：
  - `Noto Sans SC`（400–900 可变，中文粗黑大标与净读正文）
  - `Big Shoulders`（700–800，近 12 页 0 次使用，杂志高窄展示西文标）
  - `Instrument Serif`（400 正体与斜体，近 12 页 0 次使用，时尚/人文杂志典雅衬线副标与年号）
  - `IBM Plex Mono`（400 / 600，近 12 页 0 次使用，印刷裁切刻度、毫米标尺与等宽数据）

## 5. 节目录（共 7 节，每节标题 ≤ 12 字，相邻节交互不重样）
- **01 · 什么是特写跨页**（亮纸）：引原海报总述与三要点，温和补注「大≠特写」；交互为**三跨页翻页节奏条**（切换无特写平铺 / 单页爆点 / 连排三特写，看杂志连页灰度节奏曲线）；一句话链接 160 / 161 / 162。
- **02 · 放大与裁切的刻度**（暖砂纸）：讲清从全貌、擦边尴尬到干脆破框与过切失认的边界；交互为**四格摄影接触表印样检视器**（点选四档裁切印样，对照实印成品与脑补画外轮廓 SVG 图解）。
- **03 · 中缝与出血的物理账**（深松黛绿暗室）：讲透实体装订中缝吞图与 3mm 裁切出血；交互为**2D Canvas 书脊开合与断面物理透视机**（切骑马钉 / 锁线精装 / 厚刊胶装 + 焦心跨缝/避缝切换，同步绘制俯视压缩变形与侧面书页拱折弧度）。
- **04 · 图文协同：文字何时退让**（亮纸）：拆解图像占主角时标题与短注的职责和静区落位；交互为**四种图文落位与字阶对比器**（实算对比度、静区占用与视线顺序 ①→②→③）；一句话链接 167。
- **05 · 从哪来：特写跨页简史**（暖砂纸）：查证过的现代出版史五站（1929–1930 M.F. Agha《Vogue》、1934–1958 Alexey Brodovitch《Harper's Bazaar》、1936《Life》创刊摄影报道、1959–1971 Willy Fleckhaus《twen》、1971 Allen Hurlburt《Publication Design》与 1974 Jan V. White《Editing by Design》）；交互为**年代卷宗切签**配微型历史跨页线框蓝图。
- **06 · 什么时候别用与终审挑错**（深松黛绿暗室）：四类禁用场景（一句话链接 164 / 165 / 166 / 167）+ **编辑部四选一终审练习**。
- **07 · 原海报与同类索引**（亮纸）：原海报高清灯箱（可缩放、可拖动 `draggable="false"`、Esc 关闭）、原海报三要点解析、160–167 同类直达索引与标准页脚。

## 7. 练习设计
- **题干**：240 页无线胶装工艺季刊《手工铜壶锤纹》特写跨页终审，四稿共用同一把铜壶实景、同一配色与字号，仅在一个关键变量上不同。
- **四项中性标贴**：
  - `方案 A`（居中大特写 · 满幅出血）：放大与文字俱佳，唯独把壶嘴核心正压在 14mm 胶装中缝上。
  - `方案 B`（偏右大特写 · 三边出血）：**正解**——放大占跨页约 68%，三边干脆出血，核心距中缝 42mm 安全避脊，左页深松静区配简洁标题与短注。
  - `方案 C`（偏右留框 · 全貌展示）：避脊且文字克制，但整把铜壶缩在白框内（0 边出血），丧失特写张力。
  - `方案 D`（偏右大特写 · 双栏长评）：放大、出血与避脊皆过关，但双栏长文塞满左页并侵占呼吸区，压垮图像主导节奏。
