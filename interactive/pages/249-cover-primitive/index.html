        01
        

          
一寸弹簧：居中魔法

          
AUTO-MARGIN MECHANICS · W3C FLEXBOX 8.1

        

      


      

        

          很多人写全屏封面时，习惯给主标题套 position: absolute; top: 50%，或者靠拍脑袋写死 padding-top: 220px。屏幕一变矮、标题多折一行，标题立刻撞进顶栏或被底沿切掉。封面原语之所以成为「布局原语」，靠的正是 W3C Flexbox 第 8.1 节定义的一条极简规则：把封面设为纵向弹性容器，给唯一主角加上 margin-block: auto。
        

        

          按照规范，弹性容器里所有尚未被内容占用的正向剩余空间，都会优先被 auto 外边距平分吸收；一旦内容自身超过容器最小高度，auto 自动退回 0，由 min-block-size 顺势撑高容器，永不重叠也不裁切。需要控制内部段落纵向节奏时，再嵌套 243 堆栈；要限制大标题水平行宽，则交给 245 居中器。

Cover 原语：flex-direction: column + margin-block: auto

            

            
不管视口拉高还是压矮，也不管标题从两行变成四行，顶部入口、居中主标题和底部预告始终留在同一条文档流里，永远不会互相踩踏。

  display: flex;
  flex-direction: column;
  min-block-size: 100svh;
  padding: 1.5rem;
}
.cover > .principal {
  margin-block: auto;
}

三件足够：减法秩序

          
MINIMUM ELEMENTS · SUBTRACTIVE CLARITY

        

      


      

        

          
「封面不是装饰，而是结构的起点。」

          
原海报同时写下公式：好封面 = 明确目的 + 强烈层级 + 简洁表达——用最少的组件把「主题是什么、为什么继续看」交代明白。

        


        

          

            说多了一点
            核实原海报「一秒内理解」
          

          

            原海报写着「让观者在一秒内理解：这份内容，值得继续看」。严格来说，认知研究区分了审美第一印象与语义理解：Gitte Lindgaard 等（2006，《Behaviour & Information Technology》）发现，用户在 50 毫秒内就会形成对页面美感与秩序的直觉判断，但真正读完主标题并判断内容是否相关，经验上通常需要 0.5 至 2 秒。也正因如此，封面每多塞一件无关装饰，就在把宝贵的半秒注意力耗光在噪音上。

        03
        

          
视口暗礁：svh 与 dvh

          
VIEWPORT HEIGHT TRAPS · CSS VALUES LEVEL 4

        

      


      

        

          封面原语在教学例子里常写 min-block-size: 100vh，一放到真机浏览器就容易踩坑：手机浏览器顶部地址栏和底部工具栏展开时，老式 100vh 仍按「工具栏收起后的最大高度」结算，导致封面底沿的预告和按钮直接滑到工具栏后面看不见。
        

        

          2022 年起落地主流浏览器的 W3C CSS Values & Units Level 4 引入了三组新视口单位：svh（工具栏展开时的最小可视高，最稳妥）、lvh（工具栏收起时的最大高）与 dvh（随工具栏显隐动态伸缩）。而在竖屏平板（如 1024×1366）上盲目锁死 100svh，又会撑出大片尴尬空洞——这时改用带上下限的 clamp() 才是正解。

        04
        

          
从哪来：百年封面筋骨

          
HISTORICAL LINEAGE · 1928 – 2024

        

      


      

        「封面原语」这个名字虽然诞生在 2019 年的现代 CSS 布局方法论里，但它的两根骨头——用极少元素和比例留白立住层级、让封面按规则而非手工微调自洽——沿着平面排版与浏览器规范走过将近一个世纪。
      


      

        

          
          
          
          
          
        


        

          

          

            

              1928 · 柏林
              Die neue Typographie
            

            
从对称装饰转向功能层级

            
德国排版师扬·奇肖尔德在 1928 年出版《新排版》（Die neue Typographie），把包豪斯与构成主义的平面实验总结为日常排版法则：封面不再把花边和居中对称当作默认，而是通过无衬线字体大小、黑白色块对比与有意识的留白，让观者一眼看清主题层级。

            
留给 249 号的基因：今天海报里「封面不是装饰，而是结构的起点」正是这一路现代主义排版的直系延续。

          

        

      

    

  


  
  

    

      

        05
        

          
原语拼装与禁区

          
PRIMITIVE COMPOSITION & WHEN NOT TO USE

        

      


      

        
跟同族布局原语怎么分工

        

          封面原语只管一件事：容器纵向至少多高、谁停顶底、谁居中。遇到别的布局问题，交给同一小类的其他原语拼装，不把所有代码塞进封面里：
        

        
    
          
  • 主槽内部竖排标题与副标间距，用 243 堆栈；需要外框与统一内边距的独立封面卡，套 244 盒子；想限制主标题最大水平行宽，包一层 245 居中器。
    • 
          
  • 顶槽或底槽里的横排标签与多按钮组，交给 246 簇群；状态与视图切换条交给 248 切换器；底沿带箭头的引导短语用 254 图标文字组合。
    • 
          
  • 如果页面需要常驻侧边目录而非独立开篇，应换 247 侧栏原语；多卡并列用 250 自适应网格原语，锁定图幅比例用 251 比例框，横向连看多张封面用 252 横向卷轴，弹窗覆盖层交给 253 悬浮层。
    • 
        

      


      

        

          
什么时候用封面原语

          
    
            
  • 专题、报告、演示与作品集开篇：需要第一屏先立住主题气氛与阅读期待。
    • 
            
  • 空白态、登录页与 404 引导屏：整页只有一个核心焦点，用 margin-block: auto 稳稳托住。
    • 
            
  • 带顶底元信息的封面卡片：不限于全屏，高度 360px–480px 的课程卡、期刊卡同样受用。
    • 
            
  • 多屏幕比例混用场景：手机横屏、桌面宽屏与卡片容器共享一套零媒体查询的弹性骨架。
    • 
          

        

        

          
什么时候别用封面原语

          
    
            
  • 高频效率工作台首屏：邮箱、数据看板、代码工具一进来就要干活，别用一屏大封面挡路。
    • 
            
  • 长文资讯与新闻详情页：大号全屏封面会把正文第一段推到折叠线外，徒增滚动阻力。
    • 
            
  • 没有单一主角的并列列表：商品墙、目录索引、检索结果应直接上网格或堆栈，不必硬造封面。
    • 
            
  • 极扁横幅（高宽比过小）：容器本身只有 140px 高时硬塞三槽，只会把字压碎。
