# 249 封面原语（COVER PRIMITIVE）互动页方案

## 1. 一句话道理
封面不是堆装饰的广告画，而是用最少元素（顶槽入口 + `margin-block: auto` 垂直居中的主标题核心 + 底槽预告）与 `min-block-size` 弹性高度，在任意屏幕尺寸下瞬间立住层级与结构起点的最小布局原语。

## 2. 开场玩具
- **名称**：活体封面原语构造室（2D Canvas 1:1 承袭 249 原海报鲜明包豪斯镉黄底 `#FCC810`、1.5px 纯黑框暖米白内页 `#EFE2D0`、标志性底部切角大黑圆、左侧三道带实心黑点水平引线与下方纯黑三栏图标带 + 黄色检查清单）。
- **怎么玩**：
  1. 在暖米封面画布上直接左右横拖（`data-perf-drag`，手机上 `touch-action: pan-y` 保留竖向滚屏），连续伸缩模拟封面容器高度 `260px ↔ 760px`，实时观察 `margin-block: auto` 上下弹性弹簧带吸收剩余空间、左侧三道引线实时追随三槽纵坐标，或看固定 `height` 锁死时的红色裁切溢出。
  2. 直接点击画布上多余的红标冗余杂件（促销角标、6 条参数副卡、多按钮栏）逐一剥离，让封面回到「最少元素」的三槽结构；也可点击下方纯黑三栏（首屏吸引 / 标题主导 / 信息预告）高亮对应槽位。
  3. 旁侧精控条可切换三题材（原海报几何封面 / 网页首屏专题 / 卡片登录封面）、高度策略（固定 `height` vs `min-block-size`）、主元素分配（顶堆 vs `margin-block: auto`）、槽位组合（三槽完整 / 双槽极简 / 单核宣言 / 误删主标题试错）、内边距与主副字号比，并实时输出 5 行真实 CSS。
- **开场初始态（不给答案）**：停在 `0/4` 四重复合错态——① 3 处冗余杂件塞满封面（6 件超载）、② 主元素未设 `margin-block: auto` 挤在顶部留底空洞、③ 固定 `height` 锁死 + `padding: 0` 导致底沿预告被裁且贴框、④ 主副字号比压平至 `1.15×`。
- **怎样算玩错 / 读数怎么说**：由 `model.js` 按真实 Flexbox 垂直布局算法单真源核算 9 类错态（含双向陷阱：固定高度截断、`noPad` 贴边、内边距过大挤碎主角、顶堆留死空、冗余超载、主副比过平、主标题失控爆框、误删主标题成空壳、缺少入口预期），读数直白指出错因与视觉后果，并接受三槽经典解、双槽极简解、单核居中解与紧凑卡片解等多组合法解。
- **与近 12 页的差异**：区别于 248（克莱因蓝顶轨四卡切换器）、247（深松青左脊水平折行侧栏）、289（暖象牙钴蓝斜切 Hero 转化盲闪）、160（黑绒三栏书店 2.5 米缩略封面），本页是**以垂直弹性空间分配与最小三槽骨架为核心的 CSS 封面原语构造台**，采用 249 原海报专属镉黄/暖米/纯黑三段垂直建筑版式。

## 3. 版式骨架
- **1440×900（2560 舒展至 1680px）**：满幅镉黄首屏页（绝不锁 `100svh`，避平板空洞）→ 极细顶眉 + 自示范刊头（大黑字 `封面原语` 配随过关进度稳固的微型切角黑圆徽 + 三题材方钮）→ 全宽建筑主框（左 16% 活体三引线脊 + 中 54% 暖米封面画布 + 右 30% 单真源白话诊单与精控槽）→ 通栏纯黑三栏图标带（◎ / ▲ / ⣿）→ 通栏黄色检查清单与向右箭。
- **1024×1366 / 768×1024**：自然流排零空洞，左侧引线收拢为顶部三态标尺，诊单与控制两栏并列于画布下方。
- **390×844**：压紧单行刊头与题材切，等比暖米封面画布稳占首屏 ≥ 46% 且紧接诊单首句；画布内黑圆严格等比绘制绝不拉扁。
- **844×390**：横屏切左 55% 活体封面画布 × 右 45% 刊头、诊单与快捷开关并行。

## 4. 配色和字体
- **配色（逐像素实采自 249 原海报）**：镉黄原底 `#FCC810`（浅纸安全深赭金字 `#7A5600`）、暖米封面纸 `#EFE2D0`（亮米 reading `#FAF5EC`、暖砂 `#E7DAC5`、浅白 `#FFFDF8`）、绝对纯黑与深炭暗室 `#050604` / `#0B0C09` / `#181A15`、正文炭墨 `#151612` / 次墨 `#47453D`，克制以朱赤（浅 `#9E1B11` / 暗 `#FF7E70`）标错、深松绿（浅 `#0E6240` / 暗 `#6FE0A8`）标成立。
- **字体**：`Noto Sans SC`（400/500/700/900）+ **`Syne`**（700/800，近 12 页 0 次使用）+ **`Chivo`**（500/700/900，近 12 页 0 次使用）+ `IBM Plex Mono`（400/600），全库唯一且与 247/248 西文零重合。

## 5. 节目录（7 节，每节标题 ≤ 12 字，纸面明暗交替）
- `01` **一寸弹簧：居中魔法**（亮米纸）— Flexbox 第 8.1 节 `margin-block: auto` 与 4 种 CSS 写法压力对比台（切实现 + 压屏高/加行数实时看崩坏）。
- `02` **三件足够：减法秩序**（暖米原纸）— 解读原海报「最少元素」与「说多了一点」校正（引 Lindgaard 2006 50ms 美感 vs 理解耗时）+ 6 件封面元素点剥减法板。
- `03` **视口暗礁：svh 与 dvh**（纯黑暗室）— 移动端地址栏与竖屏平板留白陷阱 + 活体手机/平板浏览器视口单位切换器（`100vh / 100svh / 100dvh / clamp` + 展开/收起地址栏）。
- `04` **从哪来：百年封面筋骨**（暖砂纸）— 从 1928 奇肖尔德到 2019 *Every Layout* 再到 2024 W3C Level 4 的五站演进 + 可点年代切图谱板。
- `05` **原语拼装与禁区**（亮米纸）— 与同小类 243–254 的一句式链接分工 + 什么时候用 / 什么时候别用 6 场景分诊矩阵。
- `06` **眼力测验：挑一版好封面**（暖米原纸）— 两轮 4 选 1 单变量中性标签封面审稿练习（方案 A/B/C/D 仅差一个结构变量）。
- `07` **原海报与关键词**（深黑展墙）— 249 原海报可缩放拖动灯箱 + 原海报完整文字与结构关键词档案。

## 7. 练习设计
- 两轮单变量 4 选 1，选项标签仅写中性「方案 A / B / C / D」，视觉质感统一，拒绝一眼排错：
  - 第 1 轮（垂直弹性结构与内边距）：同内容同字号，对比 A（`margin-block: auto` + `24px` 护边，正解）、B（全顶堆留死空）、C（`noPad` 贴死黑框）、D（`space-between` 遇高顶栏致主标重心下偏）。
  - 第 2 轮（主副层级与最小元素预算）：同容器同居中，对比 A（主副比仅 `1.2×` 失焦）、B（三槽精炼 + `2.6×` 标题主导，正解）、C（塞入角标/四格卖点/双等重按钮致元素过载）、D（标题字号失控四行折行挤出底槽预告）。
