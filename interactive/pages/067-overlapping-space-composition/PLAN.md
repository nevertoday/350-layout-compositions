# 067 重叠空间构图 · 页面方案（PLAN）

## 1. 一句话道理
重叠空间构图不需要透视灭点或阴影，单靠前景形体的连续轮廓截断后景轮廓（形成 **T 形节点**）或半透明片层贯穿两层轮廓（形成 **X 形节点**），就足以让视觉系统在毫秒内触发非模态补全，把扁平的二维色块组织出清晰的前、中、后三维纵深与主次秩序。

## 2. 开场玩具：活体包豪斯叠层透视雕刻台（Live Bauhaus Occlusion & X-Junction Stage）
- **核心动作（重叠空间构图独有）**：
  - **画布直拖形体实测遮挡（`data-perf-drag`）**：在还原 067 原海报「暖米左纸 × 钴蓝右壁」的 2D Canvas 舞台上，直接拖拽 5 枚包豪斯几何体（焦点蓝圆、透叠磨砂玻片、明黄方、炭黑大圆、黄半圆底基）改变相对位置；移动端以 `touch-action: pan-y` 保留竖屏滚动，横向拖滑直接驱动当前选中形体跨越邻形，并支持方向键微调与 `Tab` / 点击切选形体；
  - **原海报三栏活体层槽（前层 / 中层 / 后层）**：直接把原海报中段的「前层（突出重点）· 中层（连接过渡）· 后层（建立背景）」三栏做成活体 Z 序控制槽——可把任意形体调至前/中/后层、切换中层「实色遮挡 / 透叠玻片 / 假透明灰泥 / 隐形断开」、调节三层对比阶梯与整体形体舒展度（留白比例）；
  - **T/X 节点实时透视 & 轴测 Z 轴拆层**：一键叠加显示由 `model.js` 实时几何求交算出的每一处 **T 形节点**（遮挡交点）、**X 形节点**（透叠交点）与 **擦边切线陷阱**，并可切换 **0° 正视 ↔ 28° 轴测拆层**，亲眼看到前中后三片几何板在 Z 轴上拉开；
  - **三套题材 + 原海报「对比示例」快闪**：支持切换 `原海报几何 / 包豪斯展报 / 卡片叠层` 三套同结构视觉题材，底部直接承袭原海报黑标「对比示例」条，一键对照「无重叠（平面单薄）↔ 当前构图 ↔ 原海报参考解」。
- **开场初始态（0 / 4 翻车错态，绝不提前给答案）**：
  1. **序位倒置（大形反压）**：原属后层的巨幅炭黑圆被误置在最前层（Z=3），反压吞掉了中层玻片与黄色结构块；
  2. **擦边断链（焦形零叠）**：前层深蓝焦点圆偏离孤立在左侧，与邻形边缘仅距数像素形成「切边陷阱」，未产生有效 T 形遮挡节点；
  3. **对比发闷（平权同调）**：三层明暗被压成相近灰调（对比阶梯不足 1.4:1），且中层磨砂玻片处于不透明闷堵态；
  4. **拥挤窒息（留白不足）**：形体过度膨胀（`1.28×`），整体占用率突破 81%，净留白跌破 19%。
- **怎样算玩错、读数怎么说「为什么」**（全部由 `model.js` 从实绘几何坐标、64×48 栅格实采覆盖率与精确轮廓求交单真源算出）：
  1. **全散无叠**：零有效重叠对（T/X 节点为 0）→ 图形退化成墙面贴纸，彻底失去前后进深；
  2. **擦边切线**：两形边界相距仅 1–12px 却未咬合 → 边界归属含糊，视觉在接缝处卡紧塌陷；
  3. **大形反压**：大面积背景形位于小焦形之前且遮挡焦形 → 违背「大形在后、小形在前」，主角被埋；
  4. **过度遮死**：上层把下层轮廓遮盖超过 78% → 下层失去非模态补全所需的可辨轮廓，退化为单块；
  5. **对比发闷**：前/中/后明度差过小 → 即使几何相叠，眼睛仍分不清主次入口；
  6. **透叠失真**：中层切为违背梅泰利明度极性的「假透明」或隐形断开 → 过渡层断裂或发脏；
  7. **拥挤塞爆**：净留白跌破 24% → 画面被色块堵满，边界互相顶撞；
  8. **过度缩微**：净占比低于 16% → 画面空散，重叠体量感消失。
  - 接受**多组合法解**：三套题材下，无论是「透叠玻片（X 节点）」还是「高反差实色锐叠（纯 T 节点）」，只要前小后大、焦点完整露面、形成清晰 3 层遮挡链、无擦边陷阱、对比阶梯清晰且留白落在 24%–62% 经验带，均实算达标 `4 / 4`。
- **与最近 12 页的明显差异**：
  - 066 为粉玫瑰月洞门视差穿框；151 为手撕毛边棉纸拼贴与纸材对撞；065 为松绿/钢蓝 Three.js 风景多平面盒；195 为左 30% 瑞士蓝立柱配四栏网格。本页是 **左暖米纸 × 右钴蓝壁的包豪斯纯几何重叠雕刻台 + 精确 T/X 节点实时检测 + 原海报三栏活体层槽 + 轴测 Z 拆层**，玩法、视觉和构图逻辑独属 067。

## 7. 练习设计
- **第 1 题**：同一组四几何元素（深蓝焦圆、镉黄方、磨砂玻片、炭黑大圆），四项仅差一个重叠变量：`A` 全员分离无叠压 / `B` 焦圆与黄方边缘 2px 擦边切线 / `C` 炭黑大圆反压最前遮住半个焦圆 / `D` 大形沉底、磨砂玻片中层透叠、蓝焦圆完整领前且留白适度。标签仅写 `A / B / C / D` 与中性编号，正确答案 `D`。
- **第 2 题**：四个真实版面任务（`A` 独立音乐节主视觉海报 / `B` 航空机舱紧急出口指示牌 / `C` 杂志专题大标题压人物肩线 / `D` 音乐应用专辑卡片叠层轮播），判断哪一项**不宜使用重叠空间构图**。正确答案 `B`（应急导视要求零歧义识别，遮挡会延误关键信息读取）。
