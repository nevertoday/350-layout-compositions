# 312 三角调度 TRIANGULAR ARRANGEMENT · 设计方案

## 1. 一句话道理
三点不共线才能围出面：当导演用演员站位、高低姿态差与机位环轨把三个（或以上）视觉主体组织成底宽顶窄的正三角、上宽下尖的倒三角或偏轴斜三角，两条汇聚斜线便在不切镜头的前提下同时锁住视线路径、权力层级与画面重心。

## 2. 开场玩具：双联片场调度台（实时摄影机取景框 ↔ 俯视片场走位蓝图）
- **玩法**：
  - 上/左为主体「宽银幕取景框（2D Canvas 3D 针孔投影）」，底沿踩在 312 原海报同款厚黑水平基座上；右/下联动一块真实的「俯视片场走位图（Overhead Blocking Floorplan）」。
  - 拖动俯视图中的三名无五官剪影演员（**A 主角 / B 左配角 / C 右配角**）改变空间坐标 `(X, Z)`，点选姿态钮切换每人高低（**坐 1.15m / 站 1.72m / 登台 2.15m**），或直接拖动下方**机位环轨滑柄（`-55°` 至 `+55°`，标 `data-perf-drag`）**让摄影机沿片场弧线绕行，同时可切 `35mm / 50mm / 85mm` 焦段与 `海报原型叠加` 透视层；在取景框里也可直接拖拽角色或滑动背景绕拍，全控件支持键盘操作。
  - 顶部支持三套导演脚本：**稳固正三角**（对应原海报底宽顶窄）、**压迫倒三角**（两侧高大压迫底部孤立主角）、**偏心斜三角**（顶点偏轴制造权力倾斜）。
- **开场状态（0/4 错态，绝不先给答案）**：
  - 打开即停在「一字排开 · 失序平权」错态：A、B、C 三人以相同站姿（1.72m）并排在同一直线（`Z = 0`），机位正对 `0°`。镜头中三颗头顶连成扁平水平线，三角高度 0%、两腰无汇聚斜线、无人占据顶点。
- **真实可玩错的六类错态（均由 `model.js` 单一投影真源算出）**：
  1. **塌成一字**：三角有效高度 `< 14%` 或顶角 `> 135°`（三点近乎共线）。
  2. **角色互挡**：镜头投影中任意两人横向间距 `< 9%`（前后重叠挡死，缺一条边）。
  3. **挤成窄针**：底边跨度 `< 26%` 或顶角 `< 28°`（像细针，撑不起底盘）。
  4. **平头争顶**：最高（或倒三角最低）两人高度差 `< 7.5%`（双峰平权，无法确立唯一顶点）。
  5. **方向相反 / 对称过正**：正三角脚本下摆出倒三角、倒三角脚本下摆成正三角，或偏心脚本下顶点死贴中轴（偏心 `< 11%`、两腰倾角差 `< 10°`）。
  6. **切边出画**：角色滑出安全框或顶缘切头，斜线断在框外。
- **读数为什么这么说**：不只报底宽百分比、顶角与领高差，而是直接说清「观众眼睛为什么会在三人之间打转 / 为什么被压得喘不过气 / 为什么立刻锁定 A」，所有经验阈值一律标明「经验值」。
- **与最近 12 页的差异**：
  - 不同于 310（深紫 3D 水桥 + Z 轴纵深条），312 聚焦三点几何围合、高低姿态差与环轨机位角；
  - 不同于 311（暖亚麻 + 墨绿单一平面块 + 0° 压平机位与四向悬浮虚线），312 是双视口同步片场导演台（俯视走位蓝图 ↔ 镜头取景框）且采用暖象牙纸 + 斜切朱红报头 + 厚黑基座；
  - 不同于 226（巨幅朱红小写 f 框 + 一维 Flexbox 栏），312 以斜切角几何、双视口镜头投影和三角形视觉力场为核心。

## 3. 版式骨架
- **1440×900（2560×1440 放宽至 1760px）**：顶眉细线 + 左上标志性 312 原海报「斜切朱红角」刊头（厚重黑体「三角调度」压破朱红斜角，旁置总述与脚本切换/原型叠加钮）；中段左 60% 宽银幕取景框 + 机位环轨滑柄、右 40% 俯视片场走位图 + 导演实况诊单；底沿全宽铺开原海报四原则（稳定/引导/层级/焦点）带图标实时检核带。不锁 `100svh`，平板竖屏（1024×1366 / 768×1024）自然收束无空带。
- **390×844（手机竖屏）**：压紧顶标（总述顺移到舞台后方），首屏直接落入完整等比取景框 + 44px 触控机位环轨（`data-perf-drag`）+ 紧凑俯视走位图（三者合力占首屏 ≥ 48% 屏高）并同屏见实况诊断。
- **844×390（手机横屏）**：顶标压缩为单行 34px 眉条，左 56% 取景框与机位环轨、右 44% 俯视走位图与诊单并列，无裁切、无溢出。

  - 印刷炭黑 `#11100E`（采样 `#070803`，用于厚重大标、底部厚黑基座、角色剪影）、次墨 `#4B463F`
  - 暗房黑底 `#151311`（用于 03、06 两节片场暗房，暖黑非冷灰）配浅纸字 `#F4EADC`

## 5. 节目录（8 节 + 页脚，标题均 ≤ 12 字，相邻节控件不重样）
- **01 拆开原海报的四道力** (`ANATOMY OF THE POSTER`)：原话引出 312 海报四条要点与三条结构注记，配**点击式海报几何解剖图**（四项原则徽标点选高亮对应力线与解析）。
- **02 从祭坛画到电影片场** (`HISTORICAL LINEAGE`)：梳理达·芬奇、拉斐尔、阿恩海姆与卡茨/布洛克/波德维尔脉络，配**四时代胶片卡片切换 + 矢量结构演变图**。
- **03 三种三角，三种权力** (`THREE ORIENTATIONS`)：暗房版，温和补充原海报侧重正三角之外的倒三角与偏心斜三角，配**重力倾角轮盘拖动实验**（单指拖拽连续改变倾角/倒置并实测重心垂线）。
- **04 一镜之内如何换主角** (`POWER SHIFT IN ONE TAKE`)：讲动态三角如何免剪辑移交主角权，并一句话链接 310 / 311 / 313 / 314；配**三拍长镜头时间轴滑杆 + 播放/暂停器**（连动迷你俯视图与画面重排）。
- **05 没三个人也能凑三角** (`IMPLIED TRIANGLES`)：道具、光锥与视线如何充当第三顶点；配**三枚独立开关合成台**（勾选前景台灯 / 顶部光锥 / 视线汇聚逐一补齐隐形三角）。
- **06 什么时候别用三角调度** (`WHEN NOT TO USE IT`)：暗房版，四类禁忌场景（双人 50/50 僵持、失控混乱群像、极短特写快切、僵硬等腰摆拍感）；配**四场景对照切卡**（硬套三角 vs 更优构图双图对照）。
- **07 导演小练习：挑对这一镜** (`DIRECTING DRILL`)：四选一视觉构图测验，四个中性标签方案只差单一变量（三名角色的相对高低与前后站位），作答后叠加几何三角线并逐项讲透理由。
- **08 原海报与关键词** (`ORIGINAL POSTER & KEYWORDS`)：展示 `poster.webp` 原海报（支持灯箱缩放、拖动、`draggable="false"`、Esc 关闭）与全部原海报中英文关键词和注记。

## 7. 小练习设计
- **题目**：剧本要求一镜拍出「三人谈判，主角 A 牢牢掌控局面，B 与 C 在两侧听从」。以下四个镜头水平间距、灯位与焦段完全相同，**只改变三人的高低姿态与前移位置**，哪一镜最符合要求？
- **四项中性标签（仅差一个变量：三点高低与顶角朝向）**：
  - 方案 A：三人齐高横排（一字平权，无汇聚斜线与主次）
  - 方案 B（正确）：A 居中立于高点，B、C 分坐前景两侧低位（正三角，底宽稳固、两侧斜线直指 A）
  - 方案 C：B、C 站于两侧高点，A 坐于中央低位（倒三角，两侧高大轮廓倒压主角 A，拍成受审态）
  - 方案 D：B 居左最高、A 居中次高、C 居右最低（单向阶梯斜坡，焦点溜给配角 B 且重心偏左）
