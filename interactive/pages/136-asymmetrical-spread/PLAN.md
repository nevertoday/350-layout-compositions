# 136 非对称跨页（ASYMMETRICAL SPREAD）设计方案

## 1. 一句话道理
对称跨页靠中轴两侧的镜像等量达成安静的静态稳定，而非对称跨页把体量庞大、沉静的主视觉故意压向一侧，在另一侧留出主动呼吸空白、错落阶梯文字与高饱和暖色小配重——借助「视觉重量 × 距书脊支点力臂」的光学杠杆，在不对称的张力里稳住动态平衡。

## 2. 开场玩具
- **命名**：跨页视觉杠杆与配重编排台（Asymmetrical Torque & Counterweight Spread，纯 2D Canvas，标 `data-perf-drag`，由 `model.js` 单真源从实绘图形像素面积、色彩前进系数与书脊支点力矩核算）。
- **怎么玩**：
  1. 在开放跨页画布上直接**横拖左页群青蓝弧前沿（或在画布开放区横向拖动）**，连续推拉主视觉压入深度与跨缝侵入量（22%–68%），底部实体光学天平梁实时倾转；
  2. 直接**拖动右页的珊瑚朱红配重圆**（改写力臂远近）或**拖动右页暖灰图像框**（改写图白位置关系与垂直错落）；
  3. **点按画布构件**切换状态：点朱红配重圆切换配重体量（关 / 细点 / 适中半圆 / 过重红海），点右页正文阶梯切换文字密度（疏朗阶梯 / 满塞字墙 / 退回居中），按 `Space` 或点按钮沿原海报「橙点→蓝方」动线演练跨页视线路径；
  4. 切换三套出版标本：`原海报·蓝弧对开`、`摄影画册·留白叙事`、`建筑年刊·跨缝错位`。
- **开场初始状态**：刻意停在 `0/4 · 左坠失衡` 复合错态——左页群青大弧压过中缝吞住右页文字、右页关掉珊瑚朱红配重、暖灰图框紧贴书脊力臂过短、右页塞满死字墙（实测留白约 16%），天平梁明显向左沉坠。
- **怎样算玩错（8 类双向真错态）**：
  1. 伪对称退化（左右体量近 1:1 且重心偏移过小，失去非对称张力）；
  2. 左坠失衡（净视觉力矩向左倾沉超出稳态阈）；
  3. 右倾反噬（暖色配重过大或右页过满，反压主视觉）；
  4. 中缝压字/吞脊（文字跨入装订折弯区 46%–54%）；
  5. 留白窒息（主动空白不足，图像失去留白对话空间）；
  6. 空荡散架（过度空白且元素太远，跨页断成两张孤立单页）；
  7. 图文叠撞（实测几何框相交或死齐僵平）；
  8. 主次平权（主副视觉面积比不足，无视觉起跳点）。
- **读数说什么「为什么」**：单真源诊单直接指出当前最高优先级错态的视觉感知机制（为何会左坠、为何退化成伪对称、为何文字掉进书脊）与具体操作建议；多组合法解均可通过 4/4（原海报经典解、跨缝牵引解、右重反拍解）。所有力矩和张力指数均标明「示意」或档位，不假精确。
- **与最近 12 页的明显差异**：
  - 紧邻的 135 是曜石黑底居中 50/50 镜像对折验镜台；136 彻底转为**暖米棉纸底 × 左侧群青深蓝巨弧溢出 × 实心黑圆支点 ● × 物理光学杠杆配重**；
  - 不同于 256/257/134 的分栏切缝、不同于 046 的矩形断裁、不同于 047 的星盘圆轨、不同于 171 的随机撒字、不同于 336/337 的幻灯片母版/转场。

## 3. 版式骨架
忠实转译 136 原海报本身「左重蓝弧 ┆ 虚线支点 ● ┆ 右阔暖米白纸 + 阶梯排版 + 底沿朱红配重」的非对称跨页架构（绝不锁 `100svh`，绝无深灰通用顶栏与仪表盘黑箱）：
- **1440×900（主宽 1380px；2560×1440 舒展至 1680px）**：
  - 顶沿极简不对称刊头行：左翼「非对称」暖白字落在群青弧角上，右翼「跨页」深墨字跨过虚线支点落在暖米纸上，标题自示范重心偏移；右缘带原海报三颗珊瑚橙圆点 `● ● ●`、三标本切签与实时评定印章。
  - 首屏主区非对称双翼齐底：`28% 群青巨弧左舱（左页蓝弧视觉锚、原话总述、左下珊瑚对角框与单真源诊单）` ┆ `1.5px 虚线书脊与中央实心黑圆支点 ●` ┆ `72% 暖米开放跨页舞台（顶沿原海报四栏红细竖线实时探针 + 超大跨页杠杆画布 + 底沿 1宽2窄原海报阶梯精控与多解/试错条）`。
- **1024×1366 / 768×1024 平板竖屏**：自然流排，顶部紧缩群青斜弧刊头，中段满宽等比跨页杠杆画布，下段双栏齐底单真源诊单与四探针精控，无大块留白。
- **390×844 手机竖屏**：压缩单行群青角标刊头并后置总述与四探针，让等比跨页画布稳占首屏 ≥ 46% 高度且折线内直接露出单真源诊单首句与一键配平纠偏按钮。
- **844×390 手机横屏**：左 58% 等比跨页画布 × 右 42% 精简刊头与诊单并行，首屏完整可见。

## 4. 配色和字体
- **逐像素取自 136 原海报**：
  - 暖米原纸 `#EFE8DD`、亮宣纸 `#F7F3EC`、浅群青雾 `#E9EEF8`、柔暖灰 `#E6E0D5`
  - 群青蓝弧 `#2250CD`、浅纸安全深群青 `#173BA3`、03/06 深群青暗室 `#0D1D4A`（暗舱 `#152961`、页脚 `#091333`）
  - 珊瑚朱红配重 `#ED6042` / 圆点 `#F06D55`、浅纸安全深朱红 `#B83519`、暗底亮珊瑚 `#FF8A70`
  - 暖灰图框 `#DDDAD0` / 山影 `#C7C3BE`、深墨主字 `#091928`、次墨 `#3D495C`
- **字体搭配（全库 0 重复，与 135 五款 100% 零重合）**：
  - `Noto Sans SC`（400/500/700/900）— 中文主字与大标
  - `Chivo`（400/700/900）— **近 12 页 0 次使用**，瑞士新怪诞无衬线英文主副标
  - `Playfair Display`（400/700 + italic 400）— **近 12 页 0 次使用**，杂志编辑引言衬线
  - `IBM Plex Mono`（400/500/600）— 标尺、力矩与等宽读数

## 5. 节目录（共 7 节，标题均 ≤ 12 字，相邻控件互异）
- `01 视觉杠杆：不对称如何稳住` — 解析视觉重量、力臂与色彩配重原理；交互：**SVG 材质筹码×力臂杠杆实验器**。
- `02 图像与留白：呼吸如何造势` — 展开原海报三大要点（图像与留白对话、细节与节奏、引导视线）；交互：**双页卷帘对比幕（对称填满 vs 非对称透气）+ 三模式切换**。
- `03 跨缝的学问：破脊还是避脊` — 深群青暗室；讲清胶装/锁线/骑马订的书脊吞噬区与跨缝规则；交互：**2D Canvas 书脊弯折透视模拟器**。
- `04 从哪来：百年非对称革命` — 梳理 1928–1981 现代主义非对称跨页源流并链接同小类 7 个兄弟页；交互：**年代印章文献展柜 + 版式骨架缩略图**。
- `05 什么时候别用非对称跨页` — 温和纠偏「非对称万能论」，给出 4 类反例场景；交互：**出版物特征体检选择器（实时推荐适配版式）**。
- `06 小练习：挑出真平衡的一版` — 深群青暗室考场；四选一中性选项测验，仅差重心与配重单一变量；交互：**四联微型跨页选择卡 + 逐项解析**。
- `07 原海报与关键词` — 展示原海报灯箱（点击放大、拖动、Esc 关闭）与全部四组关键词、要点及规范页脚。

## 7. 小练习设计
- **题干**：某建筑摄影专刊采用锁线平摊跨页，左页已有占版面 62% 的深蓝主视觉图块。以下 A / B / C / D 四版只改变了右页配重的位置、体量与留白分配，哪一版最符合非对称跨页的「重心偏移 + 动态平衡」？
- **四项差异（单一变量：右页配重与留白配置，选项标签纯中性 A/B/C/D）**：
  - A：右页图文全挤在书脊内侧、外缘大空且无暖色锚点（左坠失衡）；
  - B：把左页主图缩成中等矩形并让右页等高镜像（退化为对称）；
  - C（正确）：右页保留大块主动留白、中图微错位、底缘外切角压一颗小而高饱和的珊瑚朱红配重块拉长力臂（重心偏左而力矩平衡、节奏明快）；
  - D：右页放同样巨大的朱红块并塞满文字行（左右互抢、留白窒息）。
