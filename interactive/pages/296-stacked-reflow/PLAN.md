# 296 堆叠重排（STACKED REFLOW）· 互动页方案（PLAN）

> 所属分类：网页与 UI / 响应式重排模式  
> 原海报总述：内容模块纵向堆叠，顺序清晰，结构自适应。

---

## 1. 一句话道理

当可用水平宽度收窄（手机竖屏或桌面 400% 放大到 320 CSS px）时，强行保留横向并列要么触发双向滚动、要么把栏宽挤碎；堆叠重排直接撤销横向依赖，把独立内容模块按自然优先级落进**唯一一条纵向阅读路径**，并在模块内保持「标题优先、信息跟随」、在模块间守住等距呼吸节奏，让信息完整保留且一眼扫清。

---

## 2. 开场玩具：窄屏挤爆 → 按优先级逐块拖入单列并列内调序台（Stacked Reflow Drop Bench）

- **怎么玩**：
  - 舞台承袭 296 号原海报右侧的双蓝图并列母题：**左侧是「横向并列（宽屏）」2×2 乱序原稿**，**右侧是固定 375px 逻辑宽度的「堆叠重排（375px）」实操视口**（容器窄于 375px 时用 `transform: scale()` 等比缩放，所有屏幕下的真实 DOM `scrollWidth - clientWidth` 实测溢出完全一致）；顶部工具栏可切换两套真实中文 UI 标本（`产品介绍页` / `电纸书商品页`），附 `重置横挤` 与 `按宽屏原序全堆`（一键演示溢出归零但顺序倒挂的反例），下方紧接一句明确的**「场景任务」**。
  - **核心互动动作（拖拽 + 点击 + 键盘 + 列内调序，首张可拖模块标 `data-perf-drag`）**：
    - 宽屏 2×2 与窄屏挤爆行按宽屏视觉位置乱序排列（最左第一格是次要项，主任务在第二格且在 375px 视口内完整可见，不提前印 `01–04` 剧透答案）。
    - 用户逐个把模块拖入下方单列（或点击 / 按 `Enter` 落位），落入单列后才赋予实时的 `01–04` 次序并就地翻成「标题优先」；已落位模块支持**单列内直接上下拖动调序**或点 `↑` / `↓` 调序、点 `放回` 退回横排。
- **一打开是什么状态 & 怎样算玩错**：
  - 开场 4 个模块全挤在 375px 顶部一行里产生 `+297 px` 实测溢出（3 处横向跨列），诊断文案不提前点名答案。
  - 若用户机械从左到右把 4 块依次点满（或点「按宽屏原序全堆」），虽然溢出归零，但次要项占了 01、主任务被压在 02，诊断带立即触发**「溢出清零 · 但顺序倒挂」**警示并逐条说明为什么；只有让主任务领头 01、次核心紧随 02，状态才转为**「单列就位 · 顺序清晰」**并由 Canvas 绘出流畅竖向箭头。
- **读数说什么「为什么」（单一数据源）**：
  - 实时显示四组真实读数：**状态**、**已入单列（`0 / 4` → `4 / 4`）**、**375px 实测溢出（全尺寸严格一致 `+297 px` → `0 px`）**、**主任务位次（`横排中` / `02 位 · 未领头` / `01 位 · 领头`）**，删去写死的折返对照表，仅按实际剩余横排跨列数 `max(0, remaining - 1)` 说明并解释为什么。
- **和最近做完的页不同在哪**：
  - 彻底摆脱 **295 画布外模式**（单 375 手机视口 + 底部横拉轨拉出两侧抽屉）、**239 流体布局**（拖右墙拉宽看百分比与正弦波）、**268 辅助窗格**（拖中缝调定宽侧栏）、**184/185/186**（报刊活字跨栏与标尺缩进）及 **017/018/072/100/101/128**。开场没有底部滑轨，而是直接上手把被窄屏挤爆的横向模块逐一拖进纵向单列，动作本身就是「堆叠重排」四字，无法套用到任何其他编号。

## 3. 版式骨架

严格承袭 296 号原海报「左半静态编辑原理清单 + 右半同比例双蓝图并列 + 下沿浅杏桃价值四栏」的瑞士工业说明书骨架：

- **1440×900 桌面端（及 2560×1440 宽屏）**：
  - 顶部极简 1px 暖灰眉线（左分类 `网页与 UI / 响应式重排模式`，右 `NO. 296 · STACKED REFLOW`）。
  - 开场主体采用与原海报呼应的 **32% : 68% 非对称等高双栏**（1440 容器 `min(1380px, 94vw)`，2560 放宽至 `min(1820px, 86vw)`，杜绝宽屏缩在中间）：
    - **左栏（32%）**：原海报粗黑大标「堆叠重排」+ `STACKED REFLOW` + 粗朱橙短横 + 总述，下方以细横线承接原海报**静态五条「核心原理」列表**（保留原海报五枚朱橙几何图标与双行文案，不做达标/待修状态灯），高度与右栏自然齐平。
    - **右栏（68%）**：满栏铺开**同比例并排的双蓝图舞台**——左侧「横向并列（宽屏）」参考蓝图与右侧「堆叠重排（375px 窄屏）」实操视口并肩铺满右侧 68% 空间，中间以原海报 `→` 与 Canvas 对应轨迹相连。
  - **双栏下方通栏承接**：紧接**统一诊断带**（集中呈现已入单列计数、真实 `scrollWidth` 溢出读数、折返次数示意与白话「为什么」），其下以原海报标志性**橙色虚线折角引线**连入浅杏桃色四栏「带来的价值」（`结构稳定` / `高效适配` / `易读易扫` / `信息完整`）。
- **390×844 手机竖屏**：
  - 页面自身示范堆叠重排：顶部压紧为单行 `堆叠重排` + `STACKED REFLOW` 与短横（总述与五条核心原理移到舞台与诊断带之后），紧接满宽 **375px 实操视口**（占首屏 ≥ 50% 高度），被挤爆的横排严格在舞台内裁切（`overflow: hidden`），整页绝不出现横向滚动；其下紧接紧凑诊断带，再顺次往下排宽屏对照摘要、五条核心原理与四栏价值。
- **844×390 手机横屏**：
  - 顶眉压至 28px，首屏切为满高左右双栏：左 42% 放紧凑标题、标本/重置键与实时诊断带；右 58% 以 **1:1 不缩放** 呈现 375px 手机视口，4 个模块在手机视口内部支持垂直滚动，并在视口内标出清晰的虚线**「首屏线 · FOLD」**，零缩放变形、零遮挡、零整页横滚。

  - 不锁 `min-height: 100svh`，避免大片空带；顶部标题与精简原理横排起头，下方宽幅铺开双蓝图舞台（768 下改为上横宽屏参考条 + 下全宽 375px 实操视口）、通栏诊断带与浅杏桃四栏价值。
- **正文八节底色节奏**：
  - 在**暖象牙纸 `#FBF4E8`**、**温润浅米纸 `#F4ECE0`**、**浅杏桃纸 `#FCEEE3`** 与两处**暖炭墨深版 `#191715`**（03、06 节）之间交替推进，全程零蓝调、零深色科技仪表盘感。

## 7. 小练习设计（严格单变量考「节奏一致」，由统一 `model.js` 同源算出）

- **题目**：下面四张 375px 单列手机页面展示同一组四个并列模块（`01 ●`、`02 ▲`、`03 ■`、`04 ≡`）：**模块尺寸、标题优先结构、块内距（`12px`）、以及 `01–02` 与 `03–04` 的外距（均为 `24px`）全部完全相同**，唯一变化的是**中间 `02–03` 的外距**。哪一版的堆叠节奏最一致、不会偷偷把内容切错组？
- **四个选项（标签严格只写 `A` / `B` / `C` / `D`，作答前不泄露数值与好坏，且打破单调顺序避免居中蒙对）**：
  - **A**（`02–03` 间距 `32px`，三缝为 `24 / 32 / 24 px`）：中缝比上下多出 `8px`——按韦特海默（Wertheimer）邻近律，更近的元素会先被看成一家，页面会在无标题、无分隔线的情况下自成「`01+02`」与「`03+04`」两组。
