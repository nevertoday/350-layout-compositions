# 195 · 分栏网格（COLUMN GRID）互动页方案

## 1. 一句话道理
当页面宽度超过单栏舒适行长，或同一页需要并列对比、区分主次信息时，用等宽或成比例的垂直栏位与大于行距的栏缝把版面切成清晰的视觉通道，再让图文严丝合缝地对齐栏线，读者就能一眼分清主次、顺畅扫读而不跨栏串行。

## 2. 开场玩具（活体瑞士分栏拼版台）
- **玩法**：2D Canvas 活体出版画板（忠实承袭 195 原海报暖象牙纸 + 淡蓝紫垂直栏柱 + 蓝虚线页边距/基线 + 金黄重点块）。用户可：
  1. 直接在画布上**按住任意蓝色栏缝竖轨左右拖拽**（`data-perf-drag` 绑在画布主体，触屏仅横向接管、竖向留给滚屏），实时改变相邻两栏宽度比例（如拖出 `1 : 1`、`1 : 2 : 1`、`1 : 1 : 1 : 1`）；
  2. 切换**栏数（1 / 2 / 3 / 4 栏）**与**四种真实题材（杂志图文 / 产品三栏 / 数据四栏 / 新闻报道）**；
  3. 拖动**栏间距（Gutter）**与**页边距（Margin）**滑块，观察栏缝与正文行距（20px）的接近律临界关系；
  4. 点击画布内内容块或底部开关，在**「脱栏悬空」与「贴齐栏线 / 跨栏」**间切换，并可用键盘 `←/→` 微调选中栏轨、`Tab` 切换栏轨。
- **开场状态（0 / 4 待理栏错版）**：开场选定「杂志图文专题」，但刻意排在 4 项全翻车的错态：
  1. **栏缝压扁至 6px**（小于正文行距 20px），触发赤朱色「跨栏串行误读折线」；
  2. **栏宽被扯歪成畸形 4 栏（`1.6 : 0.45 : 0.45 : 1.5`）**，中两栏仅 4–5 汉字断行锯齿，且 4 栏与杂志长文题材错配；
  3. **主图与金黄引语框脱栏偏移 +18px**，跨卡在栏缝正中，破坏垂直秩序轴；
  4. **页边距压扁至 3% 贴边窒息**。
- **怎样算玩错、读数怎么说「为什么」**：所有数值（每栏实宽、每行汉字数、栏缝/行距比、最大/最小栏宽比、内容块脱栏偏移 px、页边距占比）均由 `model.js` 单一真源从同一份版面几何算出。玩错时明确诊出 8 类错态：
  - `gutter-narrow`（栏缝 < 行距：左右两行比上下两行更近，眼睛容易跨栏串行）；
  - `gutter-split`（栏缝 > 2.4× 行距或占栏宽过宽：一页裂成互不相干的孤柱）；
  - `col-cramped`（最窄栏 < 8 字：文字碎成锯齿、标点挤爆）；
  - `col-wide`（最宽栏 > 36 字：回扫路太长，失去分栏缩短行长的意义）；
  - `off-grid`（主图或引语偏离栏线停在栏缝里：垂直轴断掉，版面发飘）；
  - `margin-tight`（页边距 < 6%：文字顶到纸边，缺少呼吸感）；
  - `margin-excess`（页边距 > 22%：版心被挤成细条）；
  - `topic-mismatch`（栏数/比例与当前题材的信息结构不匹配，例如数据对比硬压 1 栏，或杂志双栏长文硬切 4 栏）。
  只有当 4 项（灵活适配、精准对齐、可读栏宽、节奏留白）全部同时进入各自合理区间时才亮起 `4 / 4 秩序就位`，且允许每个题材拥有多种合法比例解（如杂志双栏 `1:1`、`3:2` 或三栏 `1:2:1` 均合理）。
- **与最近 12 页的明显差异**：
  - 194 手稿网格是单栏拖四条页边距看拇指区；193 水平排字是拖右缘改单栏行长；232 是 CSS 四卡相对定位偏移；149 是字母建筑笔画。
  - 本页 195 专属动作是**多栏分轨直拖栏比 + 栏缝与行距接近律串行诊断 + 内容块吸附栏线与跨栏拼版**，其他编号无法套用。

## 3. 版式骨架
- **1440×900 & 2560×1440**：
  - 忠实承袭 195 原海报的**「左 30% 国际瑞士蓝实心建筑立柱 × 右 70% 暖象牙纸活体拼版舞台 + 底沿通栏国际蓝四栏验收带」**非对称瑞士拼版骨架（0px 锐利边角，无深色圆角仪表盘感，不锁 `100svh`）。
  - 1440 下容器宽 `1380px`，2560 下扩宽至 `1800px`，主体始终饱满充实。
  - 左蓝立柱内叠排纯白示范大标「分栏 / 网格」（中间嵌实时随舞台栏数切分的金黄微缩栏尺）、金黄 `COLUMN GRID`、总述、深蓝内嵌白话实测诊单与标志金黄实心圆；右暖纸区铺开 16:10 活体分栏拼版台与底沿单行精简操控槽；底沿通栏国际蓝实底承接原海报同款金黄灯泡圆徽与 4 列细白竖线活体验收带。
- **1024×1366 & 768×1024 平板**：不锁 `100svh`；左蓝柱转为顶部紧凑国际蓝双列刊头（标题 × 诊单），下方满宽等比铺开活体分栏画布、操控槽与 2×2 蓝底验收带。
- **390×844 手机竖屏**：极紧单行顶眉 + 紧凑蓝底刊头条，紧接等比（4:3）满宽活体分栏画布与简洁栏数/栏距操控，稳占首屏 ≥ 48% 屏高，同屏下方直接可见深蓝诊单首句。
- **844×390 手机横屏**：切回左 56% 活体画布 × 右 44% 蓝底刊头、诊单与核心控参并排。

## 5. 节目录（8 节，每节标题 ≤ 10 字，换底色与交互）
1. **01 · 为什么分栏更好扫读**（洁白纸）：引用海报核心概念，解释宽幅行长失控与视觉通道；交互为「宽幅单栏 vs 三栏视线扫描动画对决（一键发射视线光标对比回扫跨度与定位步数）」。
2. **02 · 解剖五条分栏基准线**（暖象牙纸）：覆盖海报 5 关键词（页边距、栏间距、栏、内容区、基线），重点讲「栏缝 ≥ 行距」的接近律与跨栏包缝规则；交互为「五层 X 光结构图例点选解剖 + 栏缝/行距安全阀三档切换」。
3. **03 · 双栏、三栏与四栏怎么选**（深国际蓝暗室）：引用原海报三大模式与建议比例，用「说多了一点」小签温和校正比例并非写死；交互为「12 栏母网格交互切分板（直接点击 12 格断点自由合栏/分栏，理解 12 为何同时整除 2/3/4/6）」。
4. **04 · 四种版面怎么落栏**（淡冰蓝紫带，承袭海报下段）：活化海报 4 张示例（杂志双栏、产品三栏、数据四栏、新闻三栏）；交互为「原配栏 / 单栏塌陷 / 过密碎栏 压力切换 + 一键叠显蓝紫网格透视层」。
5. **05 · 屏幕变窄时栏怎么折叠**（洁白纸）：展开海报「响应式思维」；交互为「视口宽度推尺（1440px ↔ 360px）双机实时对比（死扛 4 栏缩碎 vs 按最小栏宽 4→2→1 折叠）」。
6. **06 · 分栏网格从哪来**（暖象牙纸）：古登堡《四十二行圣经》（约 1455）→ 卡尔·格斯特纳《Designing Programmes》（1964）→ 米勒-布罗克曼《平面设计中的网格系统》（1981）→ Timothy Samara（2002）→ 960 Grid System（2008）→ W3C CSS Grid（2017），配实绘栏格缩微图示。

## 7. 练习设计
- **题干**：排一页桌面宽（1200px）的三栏新闻专题，正文 15px、行距 24px。下面四个方案字号与内容完全相同，只改了一个分栏结构变量，哪一版既清晰耐读又不串行？
- **四个选项（标签仅写 A/B/C/D + 中性客观参数）**：
  - **A**：`1 : 2 : 1` · 栏距 `12px` · 贴齐栏线（隐蔽坑：栏距小于行距 24px，读者极易跨栏串行）
  - **B**：`1 : 2 : 1` · 栏距 `32px` · 贴齐栏线（**正确**：栏距 1.33× 行距，主辅分明、对齐完整）
  - **C**：`1 : 2 : 1` · 栏距 `96px` · 贴齐栏线（坑：栏距达行距 4 倍，页面割裂成三根孤柱）
  - **D**：`1 : 1 : 1` · 栏距 `32px` · 引语居中压缝（坑：内容块脱栏停在栏缝中央且主次未分）
