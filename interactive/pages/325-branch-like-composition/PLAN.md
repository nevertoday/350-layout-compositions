# 325 折枝式构图 · 互动页方案（PLAN.md）

## 1. 一句话道理
折枝式构图不画整株花木，而是只从画边斜向探入一枝，借中段「一转」缓住视线的滑势、再以枝端孤立主景与大片留白承接视觉停顿——用极简的斜线骨架和偏心落点，换出远大于实绘面积的画外空间与诗意风骨。

## 2. 开场玩具：「活体折枝写生卷 · 拐势与枝端定势台」
- **怎么玩**：在无缝铺开的宣纸 2D 画布（`data-perf-drag`）上直接动手作画：
  1. **横拖画布 / 拖拽中段「折节」**：实时掰动折枝的拐角与节奏，从僵直死棍掰出刚柔并济的「折枝一转」，也能拉过头体验「死折断气」；
  2. **拖拽枝端「胭脂花心」**：任意挪动端点落位，枝干从根到梢随笔势自然收细，叶片、落瓣与原海报同款三条虚线引注（`端点聚焦` / `斜向引导` / `留白呼吸`）实时跟随；
  3. **点击画布剪枝 / 换出枝角**：直点枝干中段冗余乱叶或抢戏副花即可亲手修剪，或在四角出枝位与「无根居中」间切换，也可一键切换「原海报 · 胭脂折枝 / 宋人册页 · 寒梅来禽 / 现代编排 · 诗集书封」三套题材。
- **开场状态（非答案）**：刻意停在初学最易犯的 `0/4 呆直居心` 错态——枝干呈 0° 直棍毫无折转、主花死锁画心 `(50%, 50%)` 违背「不居中央」、中段丛生繁叶与一枚抢戏副花挤闷留白。
- **怎样算玩错、读数怎么说**：由 `model.js` 从实绘几何 `(root, joint, tip)`、花晕半径与疏密枝叶单真源实算 8 类错态：无根浮枝、直棍无转、死折断气、横平/竖直失势、端点居中死滞、花晕撞边压框、双端争主/繁叶抢焦、枝怯太短或留白憋闷。每种错态都用白话指出「观者的眼睛此刻会卡在哪或滑向哪」，并给出一步可改方向；接受四角入画、仰枝/悬枝/险势等多组合法解。
- **读数说什么「为什么」**：四项均由实绘几何单真源算出——`斜势倾角`（实测根至端倾角）、`折转折角`（下段与上段实测转角）、`枝端偏心`（花心距画心百分比）与`净留白比`（扣除墨枝/叶片/花晕后的宣纸净面积占比，配合`舒朗 / 适中 / 憋闷（示意）`档位），不编假精确分数。
- **与最近 12 页及同组 321–324 的区别**：324 是朱砂红底双 L 裁切刀窗、323 是漆黑夜幕边角扇弧旋向、322 是烟雨冷宣拨弯中轴河道、321 是全景开合宽幕；其余近期页为正负形、盒模型、绕排、Z 轨、等距矩阵、分步表单、透视、堆栈、闭合、V 形聚光。本页是唯一以**宋人宣纸对开册页 + 中缝竖排诗句脊 + 活体双节水墨折枝塑形与剪枝**为核心动作的页面，无法套用到任何其他编号。

## 3. 版式骨架
- **1440×900（主宽 1380px；2560×1440 舒展至 1760px）**：零深色顶眉、零圆角仪表盘、不锁 `100svh`。顶部极细丝绫眉条（卷号与朱印状态签）下，直接展开**宋人册页对开式双页**：左笺（`36%`）承接原海报左栏语汇（自示范带动态折枝底痕的粗墨大标 `折枝式构图`、`BRANCH-LIKE COMPOSITION`、苍苔短横杠、总述、单真源朱印诊单、四项实测表、原海报三枚细线核心知识点实况与底沿纹饰 `≈ | ● ○ 🍃`）｜中缝（`36px`）以 `writing-mode: vertical-rl` 竖排原海报诗句「折枝一转，意在枝端；不居中央，方见风骨。」｜右画心（`~61%`）铺展巨幅宣纸活体折枝画布、顶部题材页签与底沿单行调枝墨池栏。
- **1024×1366 & 768×1024 平板**：自然流转为立轴纵排（紧致标题与横排诗句 → 满宽 4:3 宣纸大画心与调枝栏 → 并排诊单与三核心知识点），绝无 100svh 空洞。
- **390×844 手机竖屏**：标题压紧为单行（大标 + 朱印状态签），紧接三题材页签与约 1:1 比例的大画布（稳占首屏 ≥47% 屏高，圆晕保持正圆不压扁），同屏直见朱印诊单首句；下方顺排调枝控件与核心要点。
- **844×390 手机横屏**：切为左 `56%` 宣纸画布 × 右 `44%` 精简刊头、诊单首句与快控并行，零横向溢出。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻控件互不重复）
- **01 一转一停，如何引眼**：拆解原海报三条核心知识点并温和辨析「折」与「直斜线」的本质差异；交互：**三态眼动轨迹对比板**（点击切换直杆滑出 / 一转停端 / 满枝迷路，实时动画演示视线滑速与枝端驻留）。
- **02 折枝从哪来**：梳理唐边鸾、北宋赵昌、南宋院体小品（林椿、马麟、马远）至清《芥子园画传》《小山画谱》的实证脉络，并一句话链接 321–324 区分分工；交互：**四代画幅形制卷轴页签**（点选四代查看对应构图骨架演变）。
- **03 墨砚暗室：折势与虚实**（深松烟墨暗室）：深入邹一桂「势如勾股」「转枝切忌蛇形」「花间集鸟，必在空枝」三律；交互：**题款与印章对角配重台**（切换题款落位与留白迎势热区开关，实算画面视觉重心偏移）。
- **04 从国画到现代设计**：将「出枝—折转—端停—留白」转译到书封包装、静物摄影、展览海报与网页首屏四类现代实景；交互：**四联实景 X-Ray 骨架显影开关**（一键在四张实景版式上显隐隐藏的折枝骨线）。
- **05 什么时候别用折枝**：诚实界定折枝的四大禁区（高密度信息列表、庄严对称、多主体平权、极窄小幅）；交互：**错配场景压力测试对比器**（切换 3 个真实需求，对比硬套折枝与改换合适构图的高下）。
- **06 练一练：四枝定势**：单变量四选一实战判图；交互：**A / B / C / D 中性四图卡片判答**（选后在四图同步显出拐角弧线与画心偏距并逐项释疑）。
- **07 原海报与关键词**：呈现原海报（点击放大拖拽、Esc 关闭）及海报全部原文、三项引注与底沿草木纹饰图解。

## 7. 练习设计
- **题目**：同一张宣纸、同一处左下出枝、同一朵主花与两枚疏叶，以下 A / B / C / D 四种走枝，哪一张最能做到「折枝一转，意在枝端」？
- **单一变量**：仅改变**枝干折转与端点落位**，四图画幅、出枝根位、花晕大小、叶片数完全一致，标签仅写中性字母 A / B / C / D：
  - **A**：笔直斜穿无折转，视线顺直杆滑向右上角难停；
  - **B（正确）**：中下段自然一转（约 22°），枝端停在右上约 74%×29% 处，偏离画心又留出从容边框呼吸带；
  - **C**：有折转但枝端停在画幅正中 `(50%, 50%)`，落入居中死滞，四周空域被切碎；
  - **D**：有折转但枝势冲过头，花晕顶死右上框边，视觉停顿被边缘压迫窒息。
