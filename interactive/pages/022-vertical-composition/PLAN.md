# 022 垂直构图 · 方案（PLAN.md）

## 1. 一句话道理
地心引力沿垂线作用，加上人眼存在「竖线天然比等长横线显长」的垂直—水平错觉（Fick 1851），所以只要竖向骨架严格立直、底部稳固扎根、顶部留出向上呼吸空间并以宽窄高低形成退台节奏，画面就能立刻唤起高耸、庄重与有序上升的力量感。

## 2. 开场玩具
- **名字**：大画幅建筑移轴与垂直立面构图台（纯数学 3D 针孔相机与移轴投影渲染到 2D Canvas，复刻 022 原海报墨绿 × 暖米 × 哑金纪念碑建筑群 + 实体底座俯仰拨尺 + 侧沿铜金移轴竖轨）。
- **初始状态（绝非答案，开场 0/4 翻车态）**：打开即停在最常见的三重垂直构图翻车态——
  1. 机背仰角 `+18.0°`（仰拍使建筑竖线向天顶内倾汇聚约 `6.8°`，整座大厦像要向后倒塌，左栏标题旁的细金铅垂线同步歪斜）；
  2. 镜头前组移轴停在 `0%`（未移轴，仰拍下仍显憋顶，拉平机背至 `0.0°` 后主塔顶部立刻冲出画框上沿被削顶截断）；
  3. 柱列节奏处于「等宽栅栏」模式，7 根竖柱几乎等宽等高，死板像铁栏杆，缺少主峰与层次。
- **怎么玩**：
  1. 左右拖动底沿「机背仰角拨尺」（标 `data-perf-drag`，或直接在画布上左右拖、按 `←` / `→` 键）将俯仰角从仰拍 `+15°` 校平至 `0.0°`（`±0.8°` 内轻磁吸锁直，标题旁细金垂线同步归正）；
  2. 上下拖动紧贴画框右侧的「前组移轴竖轨」（或在画布上上下拖、按 `↑` / `↓` 键）模拟大画幅相机 Rising Front，把建筑群拉进既保住底部阶梯稳基（≥ 14% 支撑区）又在主峰上方留出 10%–26% 呼吸留白的甜区；
  3. 切换「柱列节奏」（等宽栅栏 / 散乱无序 / 退台主峰）体验从条形码到交响韵律的跨越；
  4. 切换原海报底部三套真实题材（纪念碑建筑群 / 针叶树林 / 音乐海报琴键）与三种画幅（3:4 竖幅 / 1:1 方幅 / 16:9 横幅），不设「一键通关」按钮，只提供「复原错态」。
- **怎样算玩错、错了读数怎么说**：
  - `|pitch| > 1.2°`（仰拍正角或俯拍负角）→ 报「垂线汇聚倾倒」或「俯拍倒梯塌缩」，由同源投影坐标实算最外侧主柱顶底倾角，说明为何庄重感瞬间瓦解；
  - 垂线已直但顶部净留白 `< 8%` → 报「塔尖憋顶截断」，说明视线刚往上提就被上框撞死；
  - 垂线已直但移轴推过头、底座离开底边或基座占比 `< 12%` → 报「底部失根发飘」，呼应原海报 TIP 强调底基稳定感；
  - 仍停在「等宽栅栏」或「散乱无序」→ 报「等宽铁栅栏 · 缺乏节奏」或「高低断轴 · 失去秩序」；
  - 切到 `16:9 横幅` → 报「横框腰斩竖势」，实测画幅竖向延展比折损。
- **读数说什么「为什么」**：右侧通高深松绿柱（窄屏在画布下方）将原海报四枚哑金圆环徽记（上升 / 庄重 / 秩序 / 节奏）化作实时同源检验灯，并按优先级单报一条主因与下一步动作。
- **与最近 12 页的区别**：不用 021 的海平滚转气泡仪与横线切天地、不用 058 的四块阶梯拖高、不用 020 的镜像轴尺；独创「3D 建筑投影俯仰汇聚校直 + 大画幅前组移轴（底稳与顶白博弈）+ 退台柱列节奏」，完全长自垂直构图本身。

## 3. 版式骨架
- **1440×900 宽屏**：忠实承袭 022 原海报标志性的「三纵栏纪念碑骨架」——极细 36px 顶部档案眉线之下，直接并列三柱：① 左栏（约 28%，暖米纸）置「垂直 / 构图」站酷小薇竖势示范大标（配随仰角联动的细金铅垂线）、原海报总述与题材/节奏/画幅切换；② 中栏（约 44%，直立通高舞台）嵌 3:4 活体立面画布、右侧实体移轴竖轨与底沿俯仰拨尺；③ 右栏（约 28%，通高深松针墨绿 `#10372E`）复刻原海报右侧深绿柱，竖排四枚细哑金圆环实时指标与白话诊断。2560×1440 宽屏容器放宽至 1920px 同步舒展。
- **390×844 手机竖屏**：压缩顶眉与单行大标，下方居中呈现 3:4 等比立面画布 + 侧边移轴竖轨（占首屏约 47% 屏高），紧接底沿俯仰拨尺（`data-perf-drag`）与深松绿四灯精简诊断带，首屏同屏可见舞台、拨尺与结论；题材/节奏/画幅切换紧随其下，圆日与方柱严格等比不变形。
- **844×390 横屏手机**：单行超紧凑顶眉之下切左右双栏——左 48% 放等比立面舞台与移轴轨，右 52% 放俯仰拨尺与深松绿诊断栏，无横向溢出。
- **1024×1366 / 768×1024 平板竖屏**：不锁 `100svh`，按内容自然贴合高度，杜绝大片空洞。

## 5. 节目录（8 节，标题均 ≤ 12 字，相邻控件不重复）
1. **01 为什么竖线显高又显重**（`THE VERTICAL BIAS`）：从 1851 年菲克垂直—水平错觉与直立重力轴讲透生理成因；**交互**：倒 T / L / 方框「菲克错觉亲手量」盲测台，手调等长后亮出毫米尺核验高估率。
2. **02 底座稳住，头顶才升得起**（`BASE AND HEADROOM`）：拆解原海报 TIP 并以「说多了一点」小签温和纠偏（竖线也能向下坠）；**交互**：四组独立视觉重力开关（底基/顶白/收分/明暗流向）实时翻转视觉矢量。
3. **03 别把竖线排成铁栅栏**（`RHYTHM OVER BARS`）：深松绿底，剖析原海报要点 03「秩序与对齐」与 04「节奏与层次」；**交互**：呼应原海报钢琴键的「7 柱点按节奏编排器」，点柱改宽窄与景深，实时生成节奏波形。
4. **04 仰拍怎么不让大楼倒下**（`KEEPING VERTICALS TRUE`）：讲清建筑摄影垂线汇聚畸变、大画幅前组升移（Rising Front）与移轴校正及「适度保留汇聚」的例外；**交互**：侧视光路剖面 + 取景结果的双窗三机位切换器。
5. **05 垂直构图从哪来**（`ORIGIN & LINEAGE`）：1851 菲克、1896 路易·沙利文三段式摩天楼宣言、1926 康定斯基《点线面》、1958 密斯西格拉姆大厦；**交互**：四年代竖碑切换联动极简建筑/几何分析图解。
6. **06 什么时候用，什么时候别用**（`WHEN TO USE & AVOID`）：炭墨深底，结合原海报三示例讲清适用域与四类翻车禁区，链接 021/023/024/025/027；**交互**：四组现实场景「误套 vs 改方」左右诊所切签。
7. **07 小练习：挑出立得住的稿**（`QUICK PRACTICE`）：双题单变量四选一测验（管风琴音乐厅竖海报 + 城市建筑展封面），标签严格中性 `方案 A/B/C/D`，选后叠出校验铅垂线与留白尺逐项复盘。
8. **08 原海报与同族索引**（`ORIGINAL POSTER`）：完整原海报与可缩放拖动灯箱（`draggable="false"`, `Esc` 关）、原海报四关键词与四要点原文档案、同小类 14 个编号一句导览链接与规范页脚。

## 7. 练习设计
- **第 1 题（3:4 管风琴音乐会竖幅海报）**：同一套墨绿/暖米/哑金管风琴音管与标题，A/B/C/D 标签中性、视觉完成度一致，只差一个垂直结构变量：
  - 方案 A：7 根音管完全等宽等高平顶排列（错在死板栅栏、缺乏主峰与节奏）；
  - 方案 B：柱列退台但整体呈 12° 向内汇聚倾斜（错在垂线失守、破坏庄重秩序）；
  - 方案 C（正确）：主竖线 0° 铅直、宽窄高低退台有主峰、底部稳固台阶托底、主峰上方保留 18% 留白与金圆；
  - 方案 D：铅直且退台，但音管顶死上框（留白 0%）且管脚悬空离开底座（错在憋顶+失根）。
- **第 2 题（3:4 建筑双年展特刊封面）**：同一套竖向立面色块与题字，考「底座稳基与方向暗示」——四个方案仅差重心与留白分布（方案 B 正确：深色厚基座落底 + 中段挺拔主柱 + 上端约 20% 留白；其余三项分别单一破坏为上重下轻倒悬、顶死截断、横向粗腰带拦腰斩断竖线）。
