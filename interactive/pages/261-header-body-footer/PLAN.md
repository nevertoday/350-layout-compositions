# 261「页眉—主体—页脚 HEADER · BODY · FOOTER」设计方案

## 1. 一句话道理
页眉—主体—页脚把一张网页的阅读旅程拆成「定位（Framing）—序列（Sequence）—闭合（Closure）」三份契约：页眉负责让读者一进来就认出坐标与入口，主体按主次层次承载核心叙事，页脚在底部提供次级出口、信任凭据与收束安全网；三段各守其责且在滚动时互不抢戏，信息才能有序呈现、读起来轻松。

## 2. 开场玩具：三段式网页装配与滚动验真仪（Three-Band Live Page & Scroll Inspector）
- **玩法**：
  - 画布（2D Canvas，标 `data-perf-drag`）1:1 承袭 261 原海报的微网页视觉语言（暖黄顶条配深金圆与两道菜单杠、主体黑夜金日双波山峦与金圆/黑三角/金方三联卡片及双列列表、虚线隔断、暖沙页脚配深金圆与三黑点），右侧内置一条与网页实时联动的「全长滚动视口剖面窗（Viewport Cutaway）」。
  - **跨段拖曳分拣**：直接拖动 6 张真实网页部件卡（`品牌与主导航`、`站内搜索入口`、`主图与核心叙事`、`三联特性卡片`、`订阅与次级链接`、`版权与隐私条款`）在页眉、主体、页脚三段间重新归位（亦支持点击选中→点目标段迁徙，或键盘 `1–6` 选部件 + `↑/↓` 跨段移动）。
  - **边界推拉与滚动验真**：上下拖曳页眉底线/页脚顶线调节三段垂直预算；拖动右侧剖面取景窗或在画布横向滑动（兼容 `perf.mjs` 触控横拖），实时驱动页面垂直滚动并透视「640px 视口」内到底看到了多少主体内容、吸顶页眉遮住了多少像素、短页下页脚有没有脱底悬空；按 `Space` 自动放行从顶到底的完整滚动视线巡检。
  - 支持切换三套真实页面语境（原海报·编辑门户 / 产品官网·SaaS / 深度阅读·出版刊）、三档吸顶策略（随滚收起 / 紧凑吸顶 / 臃肿死锁）与短页/标准/长文篇幅。
- **开场初始态（非答案）**：刻意停在 0/4 复合失格态——`版权与隐私条款` 错塞进页眉、`品牌与主导航` 掉进页脚、`订阅与次级链接` 横插主体顶部；页眉高达 168px 且开启「臃肿死锁吸顶」压扁主体视口；页脚粘底关闭导致短页悬空。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - `model.js` 从实绘矩形、模块归属与 640px 视口裁切几何单真源核算 10 类双向错态：职责串台（版权上眉/导航落脚/核心入脚）、无头失向（清空页眉）、无尾断崖（清空页脚）、页眉压顶（>118px 或占视口 >20%）、吸顶吞屏（吸顶高 >86px 遮挡阅读区）、页眉挤扁（<44px 触控失灵）、垃圾场页脚（堆入 ≥5 个块喧宾夺主）、主体首屏不足（有效可见 <55%）、短页悬空（页脚离底 >28px）。
  - 读数不只报 px 和百分比，每条都直接解释视觉与交互后果（例如「页眉死锁占掉 168px，滚动时主体被切成窄缝，视线被迫反复绕过顶栏」）。认可经典静态三段、紧凑吸顶文档、极简落地页等多组合法解（全达 4/4）。
- **与最近 12 页的差异**：
  - 玩法独属 261「三段职责分工 + 滚动视口剖面」，区别于 260（拖视口宽与左右侧栏）、255（拖单列宽）、256（拖中缝分栏比）、267（切工单）、268（拖右辅窗宽）以及 050/087/138/219/174/339/304/049/086/338/137 等几何构图或对比滑杆玩具。

## 3. 版式骨架
- **整页开场即自示范三段通栏建筑**（1:1 转译 261 原海报，绝不锁 `100svh`，无深色悬浮仪表盒）：
  - 顶段通栏亮芥末金黄 `#F6B719`（底沿中央 `▼` 三角楔指向主体）：左自示范三段比例徽标 + 大标「页眉—主体—页脚」+ 总述；虚线右栏复刻原海报黑圆页眉图标与 `定位与引导 FRAMING` 实时探针。
  - 中段通栏暖燕麦宣纸 `#F4EBDE`：左 24%（虚线分隔）复刻 3×3 点阵图标与 `内容与层次 SEQUENCE` 实时探针 + 语境切换与部件快捷归位栏；右 76% 开放细灰框主角 2D Canvas（微网页装配台 + 右侧滚动视口剖面）。
  - 底段通栏深曜炭墨 `#171A16`（顶沿中央 `▲` 深墨三角楔咬合主体，底沿 8px 亮金压脚线）：左金圈三杠 `总结与闭合 CLOSURE` 实时诊断；中虚线隔开四条金点协同验真灯 + 多解与复原键；右原海报四分之一扇面 + 5×5 点阵动态进度徽标。
- **1440×900 / 2560×1440**：主内容宽 1380px（2560 舒展至 1660px），首屏三段建筑一屏尽览、左右严丝齐底。
- **1024×1366 / 768×1024 平板**：自然流排布，主体左栏转为画布上方横排紧凑状态条，画布占满宽，绝无大块空白。
- **390×844 手机竖屏**：金黄顶带压紧为单行编号+标题+状态章（总述与探针卡片后置），等比画布稳占首屏 ≥48%，折线内直露深墨底带核心诊断首句与一键归位按钮。
- **844×390 手机横屏**：切为左 55% 主角画布 × 右 45% 紧凑金黄刊头+深墨诊断并行，横屏一屏即可畅玩。

## 5. 节目录（7 节，H2 均 ≤ 12 字，相邻控件零重复）
- **01 三段各管什么事**（亮象牙宣）：原引海报三要点与四协同原则，温和校正「页脚总结要点」的常见误读；交互＝**三层视角解剖切签（视觉层 / 信息心智层 / HTML 语义层）**。
- **02 从书眉到语义地标**（暖燕麦原纸）：追溯印刷书眉（Bringhurst 1992）→ 表格与无语义 `div` → 2014 WAI-ARIA 1.0 地标与 HTML5 `<header>/<main>/<footer>` 推荐标准；交互＝**年代轴 + 读屏跳转步数实测模拟器**。
- **03 吸顶页眉与粘底页脚**（深曜炭墨暗室）：拆解吸顶吞屏成本（NN/g 2021）与短页页脚悬空的 CSS 解法；交互＝**真实可滚动双端微视口 + 4 档吸顶策略 & CSS 粘底实时切换**。
- **04 哪种页脚配哪种页面**（暖浅沙宣）：基于 NN/g 2019 四类页脚模式（极简 / 门垫 / 迷你 / 语境）并链接同小类兄弟页（255–260、262–268）；交互＝**4 场景任务×页脚蓝图匹配工坊**。
- **05 什么时候别用三段式**（亮象牙宣）：全屏画布、无限滚动信息流、单步转化结账、双屏并行工具 4 大反例；交互＝**「硬套三段 vs 破局解法」双态翻转对照卡**。
- **06 看图挑出稳的三段**（深曜炭墨暗室）：2 道单变量精辨练习（题 1：吸顶吞屏与高度预算；题 2：部件跨段职责归位）；交互＝**双题单选线框诊判题**。
- **07 原海报与关键词**（暖燕麦原纸 + 深炭墨金边页脚）：`<img id="poster">` 放大拖动灯箱 + 海报全部原话与关键词交互高亮。

## 7. 练习设计
- **题 1（单一变量：页眉滚动形态与尺寸预算）**：390px 手机文章页滚动中段，A/B/C/D 四张中性标注矢量线框图：A 死锁臃肿吸顶（156px 吞屏）、B 随滚收拢为 52px 紧凑吸顶且主体舒展（正确）、C 彻底删掉页眉与页脚失去坐标与兜底、D 压缩至 28px 挤扁文字且触控区不足。
- **题 2（单一变量：部件跨段职责落位）**：等高的四套三段式官网结构 A/B/C/D：A 法律条款与电话占页眉、主导航落主体下；B 品牌与主导航在页眉、主叙事与主行动在主体、次级链接与版权在页脚（正确）；C 18 条友情链接塞满页眉双行；D 唯一主行动按钮埋进页脚最末行。
