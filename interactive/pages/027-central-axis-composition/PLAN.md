# 027 中轴构图（CENTRAL-AXIS COMPOSITION）互动页设计方案

## 1. 一句话道理
中轴构图不是把左右画成一模一样的复印件，而是先立下一条贯穿画面的垂直视觉脊梁，把核心主体稳稳骑在轴上，再让左右两翼按「视觉重量 × 距轴距离」在支点两侧达成力矩平衡，从而生出安定、秩序与专注的凝聚力。

## 2. 开场玩具：通天中轴天平剧场
- **核心动作（贴合原海报三步法 `确定轴线位置 → 放置主体元素 → 检查左右平衡`）**：
  1. **拖轴定中（主拖柄 `data-perf-drag`）**：画布顶沿朱橘轴锤与底沿机械天平支点滑槽联动，支持直接在画布或底沿滑槽横向拖动，调整构图中轴位置（同时可切换轴线垂直 / 倾斜 8°），从尴尬的假中轴偏移中亲手把轴线校准归中（靠近 50% 轻磁吸），并与页眉贯通而下的居中虚线上下咬合。
  2. **拖主骑轴**：直接拖动画面核心主体（原海报同款「朱橘落日 + 双面雪山 + 正中白帆」，也可一键切「海岸灯塔」或「典藏瓶标」），把它拖离或稳稳骑回轴线正中。
  3. **两翼配重与真实杠杆天平**：画布两侧的松林（或灯塔光束/辅助器物）均可直接左右拖动改变力臂，也可按控件增减左右翼件数或切换双面光影。画布底部托着一根**真实响应杠杆力矩的机械天平横梁**，按 $\Delta M = \sum w_i (x_i - x_{\text{axis}})$ 实时倾摆。既能调出左三右三镜像对称解，也能调出「近重远轻、异形等重」的多重合法解。
- **开场初始状态（绝不先给答案，严格停在 0 / 4 翻车态）**：
  - 轴线偏在 `58%`（最致命的「差一点假中轴」偏移 +8%）且带 `5°` 歪斜；
  - 落日雪山主体脱轴向左飘离 `-11%`，中轴空戳在右山坡上；
  - 左翼仅 1 株松树贴近轴心、右翼 4 株高松压在外缘，力矩严重右倾，底部机械天平向右沉斜；
  - 四角混入抢戏杂云/游离块，中心聚敛被打散。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 轴偏 2.5%–10% → 诊出「尴尬的假中轴」：像没摆正的印刷失误，人眼反复核对却无法安定；
  - 轴偏超过 10% → 诊出「已滑入偏轴构图（028）地带」：此时不再靠中轴稳定，需改按偏轴逻辑经营留白；
  - 轴线倾斜 → 诊出「重力基准失稳」：竖轴歪斜后，左右再对称也立不住庄重感；
  - 主体脱轴 → 诊出「轴主分离」：视线在虚拟轴线与偏置主体间来回扯皮，失去集中焦点；
  - 力矩倾倒（左重或右重超过经验容差）→ 诊出「左右力矩失衡（左沉/右沉）」：指出是重量还是力臂过长把画面压歪，提示把重翼往轴心收或给轻翼补重/拉远力臂；
  - 杂件抢戏或两翼清空贴边 → 诊出「外围分神 / 退化为孤立居中点（016）」。
- **与最近 12 页的不同**：
  - 彻底告别「左画布右参数面板 / 左面板右画布」的套路与纯滑块调参；采用 027 原海报独有的通天居中纪念碑式竖向中轴骨架，核心玩法是「铅垂轴锤 + 主体骑轴 + 视觉重量×力臂杠杆天平」三合一物理直操，与 026（双斜梁旋转）、025（消失点收拢）、018（蝶翼对折）、016（裁卡纸留白）均不同源。

## 3. 版式骨架
- **1440×900 桌面**：不锁 `100svh`（避开平板空洞）。极细 32px 深海军蓝顶眉下，顶中朱橘实心圆点引出贯通刊头的垂直虚线，居中剖开大标「中轴 ┃ 构图」与副标 `CENTRAL-AXIS COMPOSITION`，左右对称挂三题材切签与辅线/复原钮；中段全宽（容器 1320px）居中铺开活体山水舞台与底沿一体机械天平横梁及单行对称配重条；紧接原海报四枚深蓝实心圆徽（对称 / 平衡 / 集中 / 稳定）四栏实时检核带；底沿通栏无缝承接原海报同款深海军蓝实底 TIP 诊单横幅（左白话诊单 × 右三步流程进度与四项实测值）。
- **2560×1440 宽屏**：容器优雅舒展至 `1760px`，画布按原比放大，正文双栏宽舒饱满，不缩在中间一条。
- **390×844 手机竖屏**：极紧单行顶眉与单行居中大标，把总述精炼收束，使等比活体画布与底沿天平横梁稳占首屏 ≥ 48% 屏高，同屏露出核心快控钮与深蓝 TIP 诊单首条；四圆徽转 2×2 紧排；绝不对画布做不等比压扁。
- **844×390 手机横屏**：首屏自动切为紧凑左右构型——左 56% 满高活体舞台与底沿天平轨 × 右 44% 极紧标题、配重微操与深蓝诊单，首屏一屏看全、零横向溢出。

## 4. 配色和字体

  - 克制达标清海青：浅纸 `#0E665E`、暗底 `#6CD6C8`；错态警示赤红：浅纸 `#B62614`、暗底 `#FF8570`

  - `space-mono`（400 / 700，**近 12 页未用**）：轴线坐标、倾角、力矩标尺等宽读数

## 5. 节目录（7 个编号大节 + 开场，h2 均 ≤ 12 字）
- **开场**：通天中轴天平剧场（直拖铅垂轴锤/主体/左右配重松林 + 机械天平梁）
- **01 对称不是唯一平衡**（浅洁纸）：拆解原海报「对称 / 平衡」与阿恩海姆视觉力矩原理。交互：**视觉砝码配平槽**（点击选筹码放入近/中/远三档槽位，与左翼建筑块做异形等重配平）。
- **02 差一点最显歪斜**（暖沙纸）：讲清中轴偏移盲区、几何中心与视觉重心差异，并一句区分居中（016）/ 对称（018）/ 偏轴（028）。交互：**肉眼定轴盲测仪**（隐藏中轴，用户凭直觉排正三种不对称外形后再落垂线验真）。
- **03 从礼制都城到书扉**（深海蓝暗室）：维特鲁威、北京 7.8km 中轴线（2024 UNESCO）、帕拉第奥 1570、奇肖尔德 1928→1947 的世纪转折。交互：**四时代蓝图剖视切换器**（4 枚年代碑刻签切换实绘建筑与扉页蓝图）。
- **04 原海报四景怎么立轴**（暖宣纸）：逐一拆解原海报建筑灯塔、无五官人像、瓶身产品、平面海报四景，并温和纠正原海报说多了一点之处。交互：**四场景图层剖视台**（切换骨架轴线 / 重量热区 / 视线路径图层）。
- **05 什么时候别用中轴**（浅洁纸）：4 类明确失效场景（长段正文、高速冲刺、偏重表单、纵深/交错冲突），指向 019/023/025/026/028/029 等兄弟页。交互：**强行中轴翻车对照闸**（3 组真实版面一键切换「硬套中轴」vs「换用更合适构图」）。
- **06 挑一挑：哪张立得稳**（暖沙纸）：2 道渐进实战四选题（选项仅标 A/B/C/D，单变量差异，选中后按 `model.js` 给出拆解理由）。
- **07 原海报与构图谱系**（深海军蓝底）：高清原海报灯箱（可缩放拖动、Esc 关）+ 海报原文归档 + 同小类 14 页快速链接 + 标准页脚。

## 7. 练习设计
- **第 1 题（建筑博物馆特展海报，四图仅标方案 A / B / C / D）**：
  - 方案 A：中轴 50%、主体骑轴，但左侧塞入重徽章与密树林而右侧仅留一株细树，力矩严重左倾；
  - 方案 B：两侧松树镜像对称，但落日与建筑尖顶整体右漂 6%（假中轴错位）；
  - **方案 C（正确）**：标题、落日、展馆尖顶同骑 50% 中轴，左翼近轴大松与右翼远轴小松达成异形等重力矩平衡，底栏简洁收口；
  - 方案 D：主图完全中轴对称，但底部 6 行长介绍硬做居中对齐，行首锯齿漂移、下盘失稳。
- **第 2 题（手工器皿产品海报，四图仅标方案 A / B / C / D）**：
  - 方案 A：瓶身与中轴对齐，但右侧加了一块超大纯黑促销圆章压沉右翼；
  - **方案 B（正确）**：瓶身与朱橘圆标稳骑中轴，左右浅灰倒影与微差光影托出空间透气感，底部信息分列轴线两翼平衡呼应；
  - 方案 C：瓶身连同光影向左偏出 5%，与上方居中品牌字错开半格；
  - 方案 D：瓶身缩得太小且四角塞满四枚同权重标签，视觉向边缘撕裂、中心失焦。
