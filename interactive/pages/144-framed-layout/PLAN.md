# 144 框架 版式（FRAMED LAYOUT）设计方案

## 1. 一句话道理
人脑读图时会自动把「落在同一封闭边界内」的元素归为一组（格式塔共同区域律），且这套边界归组能压过单纯的距离接近；框架版式用一道统一的外框与克制的内部边界建立完整、稳定的视觉秩序，但一旦「逢物必加框」，边框就会抢走内容主权并制造 1+1=3 的视觉噪点。

## 2. 开场玩具
- **命名与载体**：**展陈说明页装框审校台（Live Spec-Sheet Framing Bench）**——一张真实可拆装的「山海展亭 · 观展说明与清单页」（含整页外框 + 展图日山徽记 + 展陈主旨 + 4 条观展清单 + 预约必看提示），配实时 SVG/2D Canvas 边界度量与 1+1=3 冲突透视层。
- **怎么玩**：
  1. 直接点击说明页上的外框或任意 4 个内容分区（或在旁侧边界审校单中点选），为整页外框切换 `无外框 / 细线外框 / 定锚外框（原海报角块锁角）`，为各分区切换 `去框 / 细线框 / 重墨框 / 赭橙色块`，并可开/关「清单子项套框」。
  2. 左右拖动说明页底沿的**内距呼吸卡尺（`data-perf-drag`）**（支持鼠标、触摸与键盘方向键），把框内留白在 `2px–32px` 之间连续调节，页面真实内距与标注尺寸实时联动。
  3. 可开启「1+1=3 噪点透视」高亮显示紧贴的相邻重框与套娃夹缝。
- **开场初始状态（绝非答案）**：刻意停在最常见的 **「满框套娃 + 窒息内距 + 缺总框」错版**：整页无总外框、4 个内部分区全套 `重墨框`、清单 4 条子项也各自套小框、内距卡尺压在 `4px`（呼吸比 `0.3×`）、无色块强调，原海报四德体检灯仅亮 `0/4`。
- **怎样算玩错与读数解释**（全部由 `model.js` 同一几何状态实时算出，按严格优先级单报主错并解释「为什么」）：
  - `错态 · 满框套娃`：嵌套超过 2 层或开启子项套框或重框过多 → 指出所有区域都在喊重点等于没有重点，并产生 1+1=3 夹缝噪点。
  - `错态 · 窒息贴边`：内距 `< 10px`（经验呼吸比 `< 0.75×` 正文字号）→ 指出框壁顶住文字，边界从容器变成牢笼。
  - `错态 · 散落无界 / 缺总外框`：整页无外框 → 指出内部碎片各自飘浮、四角缺乏收束与稳定感。
  - `错态 · 色块滥用`：强调色块 `≥ 2` 处 → 指出多个高饱和色块互抢第一眼，强调失效。
  - `错态 · 内距过宽`：内距 `> 28px`（经验呼吸比 `> 2.0×`）→ 指出文字被挤窄折碎，框与内容脱节。
  - `错态 · 平权无重点`：外框、减框与内距都达标，但 4 个分区语气全平、没有唯一的强调区（`3/4`）→ 引导用 1 处赭橙色块或唯一重墨框点亮「强调」。
  - `成立 · 秩序合拢（4/4）`：多种合理搭配均可成立（不设唯一死答案、不设一键通关作弊钮），点亮原海报四枚几何徽标 `边界 □ / 收束 ▣ / 稳定 ■ / 强调 ◎`。
- **与最近 12 页的差异**：紧邻 143 是在实墙上开洞裁景、142 是划删封面大标题字词、270 是等尺寸卡片网格改列距与 Subgrid、226 是 Flexbox 一维弹性分配；144 专注「边界的加法与减法」——在一张异构说明清单页上拆掉套娃框、建立外框收束、调出框内呼吸留白并用单处色块锚定重点，别的编号无法原样套用。

## 3. 版式骨架
- **整体母题**：直接以 144 原海报的「暖米纸底 + 深青实线定锚外框 + 右上/左下两块压框赭橙方块 + 右下深青 45° 三角」作为整页开场的建筑外框骨架，绝不做通用深色圆角仪表盘卡片。
- **1440×900**：定锚外框宽 1340px 居中，内部三横带——顶带左置带细线角括的示范大标「框架 版式」与总述、右置原海报竖向赭橙点阵与四德实况灯；中带左 64% 铺开活体展陈说明页与底沿内距呼吸卡尺、右 36% 为无圆角细线「边界审校单」；底带直接承袭原海报虚线分隔的 4 栏几何关键词栏。
- **2560×1440**：定锚外框放宽至 1840px，活体说明页按等比舒展至 ~1120px 宽，不缩成中间窄条。
- **1024×1366 / 768×1024**：不锁 `min-height: 100svh`，内容自然收紧，消除平板底部空洞。
- **390×844**：压紧单行顶标（约 68px），紧接着满幅活体展陈说明页 + 宽轨内距卡尺稳占首屏 ≥ 48% 高度，下方同屏露出快捷区控与实时诊断结论。
- **844×390**：切为左 56% 活体说明页 + 紧凑卡尺、右 44% 顶标 + 诊断与快捷切换，避免横屏纵向压扁。

## 4. 配色和字体
- **配色（实采自 `144.webp`）**：
  - 暖米纸底 `#F9F0E3`、次级暖沙纸 `#EFE3D1`、浅米白纸 `#FDF8F0`
  - 深青墨主色 `#032D35`（深版暗青底 `#032D35` / `#072026`、正文深墨 `#08242A`）
  - 赭橙强调色 `#C05C21`（浅纸小字加深至 `#A34714` 确保对比度 ≥ 5.5:1；深青底亮赭橙 `#EE8A4D` 确保对比度 ≥ 5.0:1）
  - 细线灰青 `#8A9B9C` / 暖褐辅线 `#CBBBA5`
- **字体搭配**（全站唯一，且含两款最近 12 页均未用过的字体）：
  - `noto-sans-sc`（400 / 600 / 900）：中文标题与理性说明正文
  - `outfit`（400 / 600 / 800，**最近 12 页未用**）：几何无衬线英文大标 `FRAMED LAYOUT`、节号、等宽感读数与建筑标注
  - `libre-baskerville`（400 / 700 + italic 400，**最近 12 页未用**）：典籍出处、版面引语与展签斜体点缀

## 5. 节目录（7 节 + 08 原海报，每节标题 ≤ 12 字，相邻控件互异）
- **01 边界为何先于距离**（`COMMON REGION`）：格式塔共同区域律（Palmer 1992）与 Arnheim 边界力场。交互：2D Canvas 点阵间距连续滑块 × 框线强度切档。
- **02 线框与色块的四种语气**（`FOUR GRAMMAR MODES`）：拆解原海报四关键词「边界 / 收束 / 稳定 / 强调」。交互：点击 4 枚原海报几何徽标切换同一产区说明卡的 4 种装框手法与视线顺序。
- **03 框越多，噪点越吵**（`THE 1+1=3 TRAP`）：深青墨印暗版，讲 Tufte「1+1=3」与「最小有效差异」。交互：4 枚剥离开关逐层拆掉日程表的冗余框线，实时看非数据墨量下降（示意）。
- **04 框内留白与破框张力**（`PADDING & BREAKOUT`）：内距呼吸甜区与原海报 144 的「95% 守框 + 5% 压角破框」技巧。交互：2D Canvas 原海报几何重构板，调内距档与角块压框位（全闭 / 压角 / 脱框）。
- **05 从古籍边栏到现代版框**（`HISTORICAL LINEAGE`）：868《金刚经》与宋版边栏 → 1896 凯尔姆斯特《乔叟》→ 1928 奇肖尔德《新字体排印学》→ 1982–1997 感知与信息设计。交互：4 时代典籍切换卡驱动建筑版式 SVG 剖面图变形。
- **06 何时该框，何时拆框**（`WHEN TO SKIP`）：深墨青版，列出适用/慎用场景、温和修正原海报「说多了一点」之处，并一句话链接 140/141/142/143/145/146 与 014。交互：4 类真实稿件「场景试纸」点选并翻转「套框 / 去框」对比。
- **07 挑出最好的一版**（`PRACTICE QUIZ`）：4 版仅差「装框策略」单变量的展期说明卡练习。交互：A / B / C / D 选版与逐项解析。
- **08 原海报与关键词**（`ORIGINAL POSTER`）：高清原海报灯箱（点击放大、拖拽、Esc 关闭）+ 原话引述 + 四词图解 + 页脚。

## 7. 练习设计
- **题干**：四版「冬季建筑展日程卡」文字、字号、配色、留白基线完全一致，**只改了装框方式**。选出最符合框架版式四项原则（边界、收束、稳定、强调）的一版。
- **选项（仅标 A / B / C / D，绝不泄露好坏）**：
  - **A**：无外框，内部四个区块全套粗重实线框（错因：缺整体收束，且满框套娃导致边界互抢、产生 1+1=3 噪点）。
  - **B**：有定锚外框，内部四个区块全套等重细线框（错因：边界与稳定到位，但四个分区语气全平，没有「强调」落点）。
  - **C（正确答案）**：有定锚外框收束整卡，主旨与日程正文去框靠留白呼吸，仅用 1 处赭橙实色块突出预约时间，内距舒展（同时满足边界、收束、稳定、强调四项要求）。
  - **D**：有定锚外框，但把标题、主旨与预约三处同时涂成赭橙色块（错因：色块滥用，强调面铺满后反而失去焦点与稳定感）。
