# 315 高远法（HIGH DISTANCE METHOD）设计方案

## 1. 一句话道理
高远法的核心不是把地平线抬高，而是把观者的立足点压低到山脚（低处为辅）、仰望视线沿主峰垂直拉升至画幅高处（高处为主），再借「烟霞锁腰」切断近中远粘连、用低处微小的松木与行旅反衬体量，让二维竖幅生出「自山下而仰山巅」的突兀崇高感。

## 2. 开场玩具：宋画立轴造势台（仰角卷轴推尺 × 画心直拖 × 侧视仰角剖面仪）
- **玩法**：
  - 承袭 315 原海报的青黛棱面峭峰、山脚石阶、云岚锁腰、金色虚线中轴箭柱与顶沿古金日轮，在中央竖向绢本立轴画心内构建可实时操控的山水透视模型；支持一键切换三套同源题材：`原海报孤峰`、`北宋溪山`（无五官行旅剪影）、`现代摩天`（街角路灯与竖向巨构）。
  - **底沿一体化「仰角卷轴横推尺」（`data-perf-drag`）**：像立轴底木轴一样左右推拉观者仰视角（`-18°` 俯视 → `0°` 平视 → `+58°` 极度仰望），实时联动压低山脚地平线、拉升视线倾角与近远视差；横推操作在触屏上不与页面竖向滚动冲突。
  - **立轴画心内直接拖动**：可直接在画布里拖拽「山脚基线」「主峰顶」「云烟锁腰带」三个物理节点（亦支持右侧精调控件与键盘方向键逐级微调），并可切换低处尺度参比（`巨树遮山` / `空脚无尺` / `矮松拾级`）与结构导视线。
  - **右翼「侧视仰角剖面仪」**：与主画心同源实时绘制观者侧影、仰视视锥、近坡/云带/主峰三段距离关系，直观解释为什么「抬头仰视时地平线反而下沉到画底」。
- **开场状态（0/4 错态，绝不先给答案）**：
  - 仰角停在 `-10°` 俯视态，山脚基线抬高到画幅中上方 `38%`（正好对应对原海报「抬升视平线」字面误解的翻车态）；
  - 主峰拔势压扁在 `36%`，峰体垂直升程极短、矮钝无力；
  - 烟霞锁腰停在 `0%`「全山尽出」，近中远三层山脉贴成一块实心块面；
  - 低处参比停在 `巨树遮山`，近景巨树顶到半山腰，喧宾夺主把主峰比矮。
- **怎样算玩错、读数说什么「为什么」**（全部由 `model.js` 同一投影真源实时计算）：
  1. **俯视倒置（地平线偏高）**：当山脚基线高于画幅 `66%`（仰角 `< 14°`）时，画布标红当前为俯视/平视态，点明「地平线抬高是在往下看，压低山脚、抬高仰角视线才算高远」。
  2. **矮峰乏势（升程不足）**：主峰垂直跨度 `< 44%` 画高时，提示视线刚起就被截断，缺乏「高远之势突兀」。
  3. **峰顶撞框（天头窒息）**：仰角或峰高拉过头导致峰顶距上缘 `< 9%` 画高、压碎顶沿金日与气口时，报警「顶天憋闷」，说明立轴顶部必须留出 `11%–24%` 经验天头余气。
  4. **全山尽出（山势粘连）**：烟霞锁腰 `< 22%` 时，引郭熙「山欲高，尽出之则不高，烟霞锁其腰，则高矣」，指出缺少云雾断层会让三层山石粘成平面。
  5. **浓雾吞峰（失却清明）**：烟霞锁腰 `> 68%` 时，引郭熙「高远之色清明」，指出过浓云雾会吃掉峰脊清明轮廓，使崇高变成混沌。
  6. **低处喧宾 / 无尺不显高**：前景巨树压过山脚或山脚空无参照物时，说明大脑靠「低处为辅」的小尺度参照物反推巨峰高度；唯有切换为低处矮松、浅石阶与微渺行旅才拉出体量反差。
  7. **4/4 高远成势**：四项同达经验舒适带时，原海报中轴金色箭柱、双侧金色仰视导视线与右沿「高处为主 / 低处为辅」标尺完整点亮。

## 7. 练习设计
- 场景：同一青黛孤峰山水立轴，四项仅标 `方案 A` / `方案 B` / `方案 C` / `方案 D`（零好坏剧透词），每项相较正确答案只改变**一个**变量：
  - **方案 A**：山脚压低、低处矮松石阶与天头留白均同 C；**唯一变量**：撤去山腰烟霞（全山尽出，近中远三层贴成平板）。
  - **方案 B**：山脚压低、烟霞锁腰与低处比例尺均同 C；**唯一变量**：主峰尖拉高至紧顶画框上缘（天头余气仅 2%，顶天窒息）。
  - **方案 C（正确）**：山脚压低至画幅下部、烟霞轻锁山腰形成清明断层、主峰拔地而起并留出舒朗天头、山脚微小矮松与石阶衬出高差。
  - **方案 D**：烟霞锁腰、低处比例尺与天头留白均同 C；**唯一变量**：将山脚地平线抬高至画幅中上方（44% 处），整体塌成高机位俯瞰矮坡。
