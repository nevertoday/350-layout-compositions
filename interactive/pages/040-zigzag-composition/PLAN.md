# 040 锯齿形构图 · ZIGZAG COMPOSITION 互动页方案

## 1. 一句话道理
锯齿形构图用**连续、急促、长短错落的锐角转折**打破水平/垂直的静止平衡，迫使视线沿着斜线反复加速、急刹、再折返推进，并在最锐利的转折拐点汇聚注意力，天然释放速度、冲突与爆发力。

## 2. 开场玩具：高压闪电折轨锻造台 × 拐点落焦能量阵
- **怎么玩**：
  - 1:1 承袭 040 原海报曜石黑底、斜灰暗带、双刃电光黄 `#F7D304` + 电光青 `#03BED7` 闪电折轨与双环九芒星主焦点。
  - **画布空白处左右横拖（`data-perf-drag`）**：连续拉扯整条折轨的横向振幅与锐度（从接近直线的平缓微折 → 45°–85° 锐利锯齿 → 过锐打结刺团），同步驱动顶部大标「锯齿形构图」五字的锯齿错落律动。
  - **直接拖拽折线上的各个切角拐点**：手工调整局部折角与每段长短，亲自把死板的机械等距锯条调出「长冲—短折—长刺」的节奏跳跃。
  - **直接拖拽双环星芒焦点（或点按任意拐点吸附）**：验证焦点在黑空脱轨、在直段滑过与卡扣在强拐点聚能引爆的差别。
  - **场景切换与折数增减**：在原海报几何闪电 / 运动赛事冲刺 / 音乐演出电脉冲三题材间切换；增减拐点数（2 折 V/Z 退化 ↔ 3–5 折标准锯齿 ↔ 7–8 折高频碎齿），直点红标可单步纠偏。
- **开场初始状态（绝不先给答案）**：
  - 刻意停在 **0/4 复合错态**：7 个极浅等距钝折（最锐内角约 158°，段长比 1.04×，既不锐、又机械均等、又显碎），同时双环星芒焦点漂在左上黑空完全脱轨。
- **怎样算玩错、读数怎么说「为什么」**：
  - 所有读数由 `model.js` 从当前实绘拐点数组与焦点坐标向量单真源实时算出，可往两头玩错，覆盖 **8 类双向失误**：
    1. 扁平钝折（最锐内角 > 125°）：视线一滑而过，失去急刹张力；
    2. 过锐自交/刺团（最锐内角 < 24° 或折段自交）：角度夹死成针刺噪音，视线无法推进；
    3. 折数不足（< 3 拐点）：退化为 034 V 形或 035 Z 形，缺乏「连续折线层层推进」；
    4. 折数过密（> 6 拐点）：切碎背景，变成工业齿轮边或高频噪点；
    5. 机械等距（长短段比 < 1.32×）：每段等长像木匠尺，缺少「节奏跳跃」；
    6. 毛刺短节（最短段 < 10% 总长）：出现打断流向的无意义微颤；
    7. 焦点脱轨（星芒离强拐点 > 阈值）：视线沿折线冲出画面，看不到主角；
    8. 焦点落弱拐（星芒卡在钝角弱折点上）：两侧向量夹角不足，聚能微弱。
  - 接受**原海报斜冲四折解**、**陡峭竞速三折解**、**舞台脉冲五折解**等任意满足几何规则的多组合法解；张力仅标档位「示意」，不写假精确百分比。
- **与最近 12 页的明显差异**：
  - 039 是浅薄荷水平圆润潮汐浪；077 是米纸 3D 鸟瞰沙盘；123 是白底暗房裁切双屏；327 是禅意黑白拱门反拓；248 是电光蓝 UI 切换控制台；290 是暖米六层档案夹；206 是克莱因蓝 12 列子网格；161 是双页翻书台；038 是柔桃丝带流束；289 是暖象牙 Hero 网页；122 是包豪斯简译双室；247 是深松青量子侧栏。040 是唯一以**暗黑双色电光闪电斜切几何、徒手拖拽多段折线顶点并锻造角点节奏与焦点卡扣**的构图实验台。

## 3. 版式骨架
- 忠实转译 040 原海报「曜石黑全幅高能斜切版式 + 0px/45° 切角框 + 平行四边形黄青斜牌 + 底沿黄线双尖角标语带」，绝不锁 `100svh`。
- **1440×900（主宽 1380px；2560×1440 舒展至 1720px）**：顶沿自示范斜体纯白大标 + 右侧「构图原理」与斜切场景切签 → 主区左 62% 闪电锻造画布（下贴精控切角条） × 右 38% 上承原海报风格黄/青斜切四要点实况牌、下承 45° 切角青框单真源诊单与四格实测读数 → 底沿通栏复刻原海报黄线折框 + 青色 `<<` `>>` 双尖角四关键词亮灯带。
- **1024×1366 / 768×1024 平板**：自然流排，画布占满宽，右栏双列紧贴其下，零黑洞留白。
- **390×844 手机竖屏**：极紧凑单行斜体大标（总述后置），等比闪电画布稳占首屏 ≥ 47% 高度，下方直见微操按钮与诊单首句。
- **844×390 手机横屏**：左 55% 闪电锻造画布 × 右 45% 刊头、切签与诊单并行，无裁切无挤压。

## 5. 节目录（8 节，每节标题 ≤ 10 字，相邻不用同一种控件）
- **01 折线为何抓眼**（亮霜灰）：从波浪到尖折，滑杆+四态挡位切换台，对比曲直唤醒差异与 Bar & Neta 锐角警觉机制（带链 038/039）。
- **02 拐点即聚能场**（淡青雾）：解释 Persike & Meinhardt (2017) 拐点救活轮廓整合；三位置直点切换器（黑空/直段/拐点）查看视线热力停留。
- **03 节奏跳跃密码**（深炭暗室）：原海报五要点深度拆解 + 四拍「长/中/短」段长积木排拍器，实时看死板锯条变成有顿挫的斜冲骨架。
- **04 从八桥到红楔**（暖硫灰）：考据时间轴（尾形光琳八桥屏风 → 利西茨基红楔 → 阿恩海姆与弗里曼）可切线稿透视层 + 同小类构图辨析（链接 031–039）。
- **05 四大实战场景**（冷白纸）：1:1 承袭原海报运动/商业/活动/音乐四应用，四景海报模拟器 + 骨架透视开关。
- **06 什么时候别用**（暖黄警示纸）：温和校正「冲击力并非总越好」，四张禁忌翻卡（母婴疗愈/长文阅读/信任文档/繁杂实景）点开看替代方案。
- **07 眼力测验**（亮冷雾）：4 选 1 单变量构图考题，中性选项 A/B/C/D 辨别唯一合法锯齿节奏。
- **08 原海报与索引**（深曜石展墙）：原海报可放大拖动灯箱、原海报右下青框「核心特征」四图标与规范页脚。
