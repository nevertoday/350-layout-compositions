# 338 两项内容幻灯片版式（TWO-CONTENT LAYOUT）设计方案

## 1. 一句话道理
在一句共享总标题下，用独立成区、基准齐平、明暗有主次且光学配重均衡的双模块并置两项关键信息，让观众在一次横向扫视里同时看清「各自独立」与「彼此呼应」，避免把两件事揉成一堵长列表字墙。

## 2. 开场玩具：双卡装配与配重放映台（2D Canvas，标 `data-perf-drag`）
- **核心动作（源于两项内容幻灯片本身）**：
  - 1:1 承袭 338 原海报的 `┌── 双模块结构 ∨ ──┐` 括号顶梁、左浅米 `01` × 右深酒红 `02` 双模块卡片、中央香槟沙 `┆ (+) ┆` 中缝把手、卡片内几何图解与底部原海报同款三角支点配重天平（`●───▲───●`）。
  - **直接横拖中央 `+` 中缝把手（或在画布开放区横拖）**连续调整左右宽比（26:74–74:26）；**直接纵拖右卡 02 顶边抓手**体验水平对齐基准线错牙与吸附；**直点卡片内明暗卡头 (`01`/`02`) 或要点/图解区**就地切换浅米/深酒红/无界裸排与精炼/字墙/空壳内容密度；支持切换「原海报·双模块 / 季报·增长与提效 / 方案·痛点与重构」三套演讲页，并按空格或按钮运行「3 秒观众视线扫描演练」。
- **初始错态（0/4 复合翻车汇报页）**：
  - 宽比 `66:34`（左肥右窄）、中缝仅 `4px`（双区贴缝粘连）、右卡顶线错降 `+28px` 且左齐/居中混排、双卡无界裸排拉平无主次、左卡塞满 7 行字墙而右卡仅 1 条短字（支点左坠约 -44% 示意）。
- **怎样算玩错 & 双向错态核算**：
  - 由 `model.js` 从实绘两卡坐标、真实折行行数、色块明暗面积权重与支点力矩单真源双向核算 8 类错态：中缝过窄粘连（< 16px）↔ 过宽裂谷脱节（> 86px）；窄栏挤碎（< 35%）；顶线错牙（|ΔY| > 4px）或栏内对齐混排；无界平铺无主次 ↔ 双深酒红互抢压迫；左重右空 ↔ 右重左轻 ↔ 看似对称实则双满字墙超载 ↔ 双空失料。
  - 同时认可「原海报经典明暗解 (50:50)」「左图右结论 (56:44)」「左深主轴 (46:54)」「双浅主副 (58:42)」四组合法解，绝不靠单一按钮「点满通关」。
- **与近期 12 页的区别**：
  - 近期 337 是跨三页胶片推演、257 是三列网页与斜光束、136 是左蓝巨弧出版跨页、135 是黑底对折镜像、172 是 6×2 坐标网格、258 是深焙侧边栏网页。本页聚焦**单张 16:9 演示母版内两块内容的边界、对齐、明暗主次与光学配重**，配原海报独有的 `+` 中缝把手、明暗对映双卡和三角支点天平。

## 3. 版式骨架
- **1440×900（主宽 1380px，2560 舒展至 1660px，不锁 `100svh` 避平板大空白）**：
  - 顶行：左 74% 自示范标题 `两项｜内容 幻灯片版式`（浅米框与深酒红框自示范双卡明暗对映）+ 原海报酒红短横杠 + `TWO-CONTENT LAYOUT` + 总述与三剧本切换；右 26% 1:1 复刻原海报右上叠层四分之一圆与 4×5 点阵徽章 + 实时状态章。
  - 中行：`┌──── 双模块结构 ∨ ────┐` 括号顶梁下通栏开放 16:9 放映装配台画布（含底沿实体三角支点配重天平）。
  - 下行：原海报底沿开放四角 L 括号（`┌ ┐ └ ┘`）四栏实时探针条（双模块 / 对齐 / 主次 / 信息平衡，含 4 枚原海报几何图符）→ 紧贴**左浅米 01 精控舱 × 右深酒红 02 单真源诊单舱**齐底双卡 → 原海报底沿灯泡胶囊「设计提示」通栏。
- **390×844 手机竖屏**：单行压缩粉红刊头（总述与四栏探针后置），三剧本切签紧凑成一行，等比 16:9+天平画布稳占首屏 ≥46%，折线内直接露出深酒红单真源诊单首句与一键校准按钮。
- **844×390 手机横屏**：左 58% 剧本切签与等比放映画布 × 右 42% 精简刊头、单真源诊单与一键校准并行。

## 4. 配色与字体
- **逐像素实采自 338 原海报**：
  - 柔粉宣纸底 `#FDE7E3`（交替浅读纸：暖米乳白 `#FFF8F0`、暖羊皮 `#F9F0E7`、淡玫雾纸 `#F7ECEB`、胶囊暖粉 `#F1DBD5`）
  - 招牌波尔多深酒红 `#6D1E29` / `#7C232F`（03 与 06 深酒红暗室 `#380D14`、暗舱 `#4F151E`、页脚极深酒墨 `#26080D`、浅底高对比深酒红字 `#6B1925`）
  - 招牌香槟暖沙 `#E1C4A7` / `#EEDBC8`（浅纸文字用深古铜 `#7C4E22`，暗底暖沙字 `#F0D6BC`）
  - 干枯玫瑰点缀 `#BB4C56`（暗底亮玫 `#F28E97`）与温润炭墨 `#1D1315` / 次墨 `#594145`，克制以松青绿标成立、赤红标失衡。
- **字体搭配（全库 0 重复，与 337/336 西文等宽 0 重合，3 款西文/等宽在近 12 页均为 0 次使用）**：
  - `Noto Sans SC`（400/600/900）：几何厚黑中文大标与清晰无衬线正文
  - `Manrope`（500/700/800，近 12 页未用）：现代半圆几何无衬线，承接原海报 `TWO-CONTENT LAYOUT` 气质
  - `Fraunces`（600 正体 + 500 斜体，近 12 页未用）：高辨识温润编辑衬线，用于章节序号与优雅点缀
  - `DM Mono`（400/500，近 12 页未用）：精确参数、比例读数与 `twoObj` 规范标签

## 5. 节目录（7 节，每节 `h2` ≤ 12 字，相邻两节交互零重复）
- **01 拆解两项内容骨架**（浅米 `#FFF8F0`）：引用原海报要点并温和辨析「视觉平衡 ≠ 机械对称」→ **四型结构 SVG 透视切卡**（并列双柱 / 图文互补 / 总分深化 / 因果推演）。
- **02 从哪来：九大母版源流**（暖羊皮 `#F9F0E7`）：PowerPoint 4.0 AutoLayout (1994) → ECMA-376 `twoObj` 九大母版 (2006/2007) → Kosslyn (2007) 与 Duarte (2008)，串联 335–343 兄弟页链接 → **年代线框演进切签 + 3×3 九大母版矩阵定位图**。
- **03 配重与视线暗室实验**（深酒红暗室 `#380D14`）：拆解光学重量差与 Chandler & Sweller (1992) 分离注意效应 → **2D Canvas 视线乒乓测试仪**（切换「割裂图例 vs 就地标注」与「全出 vs 01→02 分步显现」，实时统计跨缝往返次数）。
- **04 四个真实演示场景**（浅米 `#FFF8F0`）：图表+结论、痛点+方案、双引擎并列、原则+案例 → **拉幕式改稿前后对比（Before/After 拖动幕布）** + 3 枚手术标注。
- **05 什么时候别用双内容**（淡玫雾 `#F7ECEB`）：拆穿四大误用（逐项对比归 339、单列硬拆归 336、塞入 3–4 项、高情绪单图归 343/340/341）→ **四张演讲解题分诊卡（点选判断 + 即时路由）**。
- **06 实战诊断小练习**（深酒红暗室 `#380D14`）：单变量 4 选 1 视觉盲测（第 1 题测中缝/对齐/宽比单变量组，可切第 2 题测明暗主次单变量组），中性选项 A/B/C/D。
- **07 原海报与关键词**（原海报柔粉 `#FDE7E3`）：原海报可缩放拖拽灯箱 + 四关键词原话卡片 + 九大基础幻灯片兄弟导航 + 极深酒墨页脚。

## 7. 练习设计
- **题目 1（空间结构单变量测试）**：四张内容、明暗配色、文字条数完全相同的「季度增长与提效」两项内容幻灯片（中性标签 方案 A / B / C / D），只改变空间结构：
  - `方案 A`：50:50 · 中缝 6px · 齐顶（中缝过窄导致横扫串行）
  - `方案 B`：54:46 · 中缝 32px · 齐顶（**正解**：独立呼吸中缝 + 齐平基准线 + 图宽文收的光学均衡）
  - `方案 C`：54:46 · 中缝 32px · 右降 26px（顶线错牙破坏水平扫视连续性）
  - `方案 D`：70:30 · 中缝 32px · 齐顶（右栏被挤成碎行，左右失衡）
- **进阶题 2（主次明暗单变量测试）**：四张结构、宽比、字数完全相同的双卡，只改变卡片表面明暗处理（双无界裸排 / 双全深酒红 / 左浅米配右深酒红 / 左浅米配无框灰字），直观检验 Kosslyn 显著性与分辨度原则。
