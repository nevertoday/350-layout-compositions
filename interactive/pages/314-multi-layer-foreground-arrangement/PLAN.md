# 314 多层前景调度（MULTI-LAYER FOREGROUND ARRANGEMENT）设计方案

## 1. 一句话道理
多层前景调度是在镜头与主体之间依次叠加两层以上的前景遮挡物与中层画框，借助单眼叠压（interposition）、明度阶梯、焦段虚实与运动视差，把二维画面逐级推开成可穿行的纵深空间，同时将观众的目光精准收束进深处焦点。

## 2. 开场玩具：多平面景片剧场 × 机位视差滑轨 × 侧剖面光学监视器
- **玩法**：
  - 1:1 承袭 314 原海报标志性的 5 层建筑与植物纵深场景（`L1 极前景棕榈暗叶 · 1.1m` → `L2 近前景深松阶墙 · 2.3m` → `L3 中层陶红拱门框 · 4.8m` → `L4 阶台焦点球/片场人物剪影 · 6.6m` → `L5 远景暖砂日盘与宣纸天幕 · 14.0m`），支持一键切换「原海报建筑」与「片场走廊（无五官剪影）」。
  - **直接拖景片**：在画布内点选或通过景片栏选中 `L1 棕榈叶 / L2 深松阶墙 / L3 陶红拱门 / L4 阶台焦点`，直接拖动调整空间位置与高度（键盘方向键可按步微调）；
  - **底沿通栏「机位视差滑轨」（`data-perf-drag`）**：左右拖动滑块横向平移机位（`-100%` 至 `+100%`），由 `model.js` 单一透视投影引擎按各景片真实物理 Z 距重算视差位移、遮挡交界与拱框边距——既让用户切身感受多层视差纵深，也会在拱门余量不足时当场暴露「横移穿帮撞框」；
  - **右侧上方「侧剖面多平面监视器」与「光学对焦环」**：实时绘出 5 块玻璃景片的纵向排布、镜头视锥与当前对焦平面（`L1 前景叶 / L3 拱门框 / L4 焦点层 / 全景深`），调节对焦时各层按离焦距离实时改变清晰度与柔焦程度。
- **开场状态（0/4 错态，绝不先给答案）**：
  - `L1 棕榈暗叶` 斜抬至画面中央，直接横切遮住焦点球约 35% 的面积（前景遮死焦点）；
  - `L2 深松阶墙` 抬得过高，几乎吞掉拱门下半部并迫近焦点基座；
  - `L3 陶红拱门` 左偏，导致 `L4 焦点球` 落到拱洞之外、紧贴右门柱切边相切；
  - 光学对焦错误落在 `L1 前景叶`，前景叶片锐利抢戏而深处焦点虚化。
- **怎样算玩错、读数说什么「为什么」**（全部由 `model.js` 同一投影几何真源实时实算）：
  1. **前景遮死焦点**（`前景遮挡`）：`L1` 或 `L2` 在画框投影上覆盖 `L4` 焦点面积 ≥ 6% 时，标红冲突区域并指出具体遮挡比例，说明「前景只负责搭门槛，一旦跨过焦点轮廓就会变成挡镜头」。
  2. **前景全撤 / 平面断链**（`景层递进`）：把 `L1` 或 `L2` 拖出画外或拉成互不重叠的贴纸（`L1∩L2` 或 `L2∩L3` 交界断链），指出当前叠压链断在何处，解释「没有前景叠压，人眼收不到单眼遮挡线索，纵深立即塌回平面」。
  3. **前景过满窒息**（`前景遮挡`）：`L1 + L2` 暗景总占地超过画幅 56% 时报警，说明前景吞没过半画幅会让画面变成狭缝偷窥而非呼吸感纵深。
  4. **中框跑偏 / 切边相切**（`中层框架`）：焦点中心跌出拱门内洞，或焦点边缘距拱门内柱净隙 < 3.5% 画宽时，画布标出红色切边线，说明「门柱与主体轮廓相切会把前后两个景深面粘在同一平面上」。
  5. **对焦错落前景**（`视觉聚焦`）：焦点环停在 `L1` 前景叶或 `L3` 拱门而主体失焦时，指出观众视线被卡在前景枝叶，需把对焦面推回 `L4 焦点层`（或开启暗前景全景深）。
  6. **视差穿帮**：静止居中勉强没挡，但拖动机位视差滑轨时拱门边柱切入焦点，提示把拱门对准留足左右余量。
  7. **四层成立（4/4）**：前景叠压链完整、焦点零遮挡、拱门留有呼吸余量、对焦稳落主体——原海报四条虚线引注逐一亮起，并支持叠加原海报结构线对照。
- **与最近 12 页的差异**：
  - 313 是通栏 2.39:1 横向推轨与四组水平剪影朝向；312 是左上斜角朱红+俯视平面蓝图拼三角形；311 是正拍立面归正；310 是 3D 水桥推拉三名演员 Z 轴；146/145/228/229/273/106/061/191/023/190 均为不同版式域。
  - 本页首创「多层玻璃景片直拖 + 底沿物理视差滑轨 + 侧剖面多平面光学监视器 + 焦点环虚实控制」，直击多层前景「前后叠压遮挡 × 中层画内框 × 焦平面分离」的专属动作，无法原样套用到任何其他编号。

## 3. 版式骨架（承袭 314 原海报「暖米宣纸顶眉 × 深松阶台基座」双材质建筑骨架）
- **1440×900（2560×1440 宽屏版心放宽至 1840px）**：
  - 极细顶眉（34px） → 暖米宣纸开放式示范刊头：左 64% 排带浅层叠落意象的「多层前景调度」厚重深松大标、`MULTI-LAYER FOREGROUND ARRANGEMENT`、右侧带陶红圆点收尾的标志横细线与总述；右 36% 嵌原海报 6×8 陶红点阵与阶梯状四原则实时验收灯（`前景遮挡 / 中层框架 / 景层递进 / 视觉聚焦`）。
  - 主舞台采用无圆角建筑分舱（不锁 `100svh` 避开平板空洞）：左 65% 为 16:10 宽幅多平面剧场画布，底沿无缝融合通栏深松「机位视差滑轨」（标 `data-perf-drag`，右端嵌原海报八道陶红竖条徽）；右 35% 呼应原海报「上暖纸 × 下深松」阶台分割——上半暖米纸置「侧剖面景片监视器 + 景片选层与对焦环」，下半深松绿实底基座（`#18322E`，米白字 + 陶红横杠）置白话实况诊单与四项实测读数，左右两列齐底紧凑无空白。
- **1024×1366 / 768×1024 平板竖屏**：自然纵排不锁 `100svh`，满幅剧场画布与视差滑轨居上，其下双列并排侧剖面控制舱与深松诊断基座。
- **390×844 手机竖屏**：极简顶眉与单行压紧标题（总述退至舞台下方），让 4:3 等比多平面剧场（圆球绝不压扁）+ 44px 触屏视差滑轨 + 紧凑景片切换与深松诊单首行直落首屏，核心互动区占首屏 ≥ 48%。
- **844×390 手机横屏**：顶眉压至 26px，切为左 56% 等比多平面舞台与视差轨 × 右 44% 景片选层、对焦环与深松诊单并行。

2. **02 景层递进的三把尺子**（`VALUE, FOCUS & PARALLAX` · 深松暗版）：拆解明度阶梯、光学景深虚实与运动视差三要素｜**交互：连续光圈 f 值与明度差双滑块（`<input type="range">`）+ 实时明度分布图 Canvas**。
3. **03 中层框架：替眼睛开一扇窗**（`APERTURE FRAMING` · 暖米纸）：细讲画内框（aperture framing）、切边相切陷阱与框占比情绪｜**交互：四种建筑框架模式单选切签组 + 视线隧道与切边预警 Canvas**。
4. **04 从油画压角到多平面摄影机**（`FROM REPOUSSOIR TO MULTIPLANE` · 暖砂阶石）：梳理 17 世纪维米尔压角法、1937 迪士尼多平面摄影机、1956《搜索者》门框与 1950–2005 视觉/电影理论｜**交互：四段年代胶片轴卡片 + 对应构造动态剖面演示 Canvas**。
5. **05 五种调度，各有分工**（`FIVE STAGING APPROACHES` · 极深松影）：用俯视机位 + 画幅轮廓厘清 310/311/312/313/314 边界，逐一附一句话在线链接｜**交互：五号调度法对比索引矩阵（切换俯视与成片双联简图）**。

## 7. 练习设计
- 场景：庭院拱门多层前景实拍构图（前景棕榈暗叶、深松阶墙、中层陶红拱门、深处背光人物剪影），四个选项仅标 `A` / `B` / `C` / `D`，每次仅改变一个变量：
  - **A**：四层齐全且拱门对正，唯一差异：前景暗叶斜插遮挡人物剪影头部与肩部（前景遮死焦点）。
  - **B**：焦点无遮挡且明度清晰，唯一差异：各层彼此分离无接触交界（缺少前后叠压链，画面扁平）。
  - **C（正确）**：前景叶轻压左下并叠压深松阶墙，阶墙斜切叠压拱门底座，拱门以均衡余量框住清晰人物，叠压链完整、焦点无阻。
  - **D**：前景叠压与明度均同 C，唯一差异：拱门右偏使门柱内缘紧贴人物肩线相切（中框切边相切，前后层粘连）。
