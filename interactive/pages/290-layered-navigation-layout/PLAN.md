# 290 分层导航布局 · 方案（PLAN.md）

## 1. 一句话道理
分层导航把庞杂信息按「全局 → 局部 → 分区 → 详情」自上而下逐层收束，并始终亮出路径与当前定位，让用户看清全貌、知道身在何处，又不用一次性扫完所有选项。

## 2. 开场玩具
- **名字与形态**：「活体六层档案夹导航台」（1:1 承袭 290 原海报带 45° 切角与右侧突出耳签的 `L1`–`L6` 实体档案夹堆叠结构，直接就是一个真能点、真能切、真能调的六层导航微系统，支持「原海报·在线课程 / 设计系统文档 / 开源代码仓库」三套真实数据，并内置 Steve Krug「后备箱空降测验」）。
- **怎么玩**：
  - **直接点活体导航**：点击 L1 面包屑回到上级、点击 L2 主导航与 L3 次导航观察真级联刷新、点击 L5 切角档案耳签切换 L6 详情内容。
  - **横拖 `data-perf-drag` 画布**（内嵌在 L4 墨绿主柜里的 2D 层级透视与导航占位切面画布）：左右横拖连续调节分层深度与导航权重分布（从左侧过度扁平 1 层塞 16 项 → 中间合法的 2 层轻量解 / 3 层经典解 / 4 层专业解 → 右侧过度嵌套 5–6 层导航帽压屏）。
  - **直接修正/破坏四项架构规律**：切换层序（倒置 / 错位 / 自上而下）、路径模式（历史脱节 / 隐藏 / 结构位置同步）、定位亮标（无高亮 / 双项抢亮 / 单点定位）、权重阶梯（同重打架 / 喧宾夺主 / 主次递减），或点击「后备箱空降测验」随机空降到深层页面实测 6 项定位题。
- **开场初始态（绝非答案）**：停在 `0/4 迷航错态`——L5 分区层错叠在 L2 主导航之上（层序倒置）、L1 面包屑显示脱节的历史路径、L2/L3 丢失当前定位高亮、导航各层等高同重且过深占去 52% 屏高，后备箱测试仅 1/6 通过。
- **怎样算玩错 & 读数怎么说「为什么」**：
  - 4 个核心维度（层级贯通 / 路径可溯 / 定位明确 / 权重平衡）均由 `model.js` 从真实渲染的层序、像素行高、导航占屏比与每栏条目数单真源算出，存在 10 类具体错态（层序倒置、扁平过载、深度套娃、历史路径脱节、路径缺失、定位盲区、双项抢亮、层层同重、面包屑喧宾夺主、导航压屏）。
  - 玩错时，L1–L6 左侧标尺与 L6 浓缩咖啡诊单会直接指出「眼睛此刻会发生什么」（例如为什么扁平 16 项会迫使逐个硬扫、为什么历史型面包屑会误导空降用户），而不是只报冷数字；接受 2 层轻量解、原海报 3 层解与 4 层紧凑解等多组合法解。
- **与最近 12 页的差异**：最近 12 页里 289/122/247/205/160/076/326/288/246/037/121/204 均围绕独立画框 + 拖比例/坐标/聚散 + 旁边读数卡展开；290 把开场本身做成一台真能用的 6 层切角档案夹导航界面（`L1–L6` 实体叠层 + 右侧耳签 + 后备箱空降测试），别的编号完全无法套用。

## 3. 版式骨架
- **全页原则**：零深色顶导黑箱、不锁 `min-height: 100svh`（避免平板竖屏留白洞），忠实转译 290 原海报「暖米宣纸底 + 左侧 `L1–L6` 虚线坐标脊 + 中央切角档案夹叠层 + 右侧突出索引耳签 + 底部五步动线链」档案夹架构。
- **1440×900（2560 舒展至 1720px）**：单行轻刊头（~50px）→ 全宽六层切角档案夹主柜（主宽 1380px，L1/L2/L3 紧凑叠落 → L4 墨绿展示柜左置 `[ 分层导航布局 ]` 与三柱实况、右置 2D 透视切面拖轨画布 → L5 切角分区标签 → L6 深咖详情与单真源诊单三联）→ 底沿五步路径链；整台六层装置在首屏完整入画。
- **390×844 竖屏**：压紧单行刊头与场景切换，保留真实可点的 L1/L2/L3 切角导航条 + L4 墨绿标题与等比 16:10 切面画布（所有按钮触控高度 ≥ 40px），活体装置稳占首屏 ≥ 50%，并直见 L5 标签与 L6 诊单首句。
- **844×390 横屏**：左 56% 为紧凑活体叠层导航与切面画布，右 44% 为刊头标题、L6 单真源诊单与快捷装调按钮，并行无挤压。
- **正文节奏**：七大编号小节在暖米原纸 `#F1E8D7`、亮宣纸 `#F8F2E6`、03 节墨绿暗室 `#0D3B2B`、暖砂纸 `#E7DEC9` 与 07 节深咖展墙 `#2B2010` 间明暗交替。

## 5. 节目录（每节 H2 ≤ 12 字，相邻节不复用同控件）
1. **01 为什么分层能省脑力**（`COGNITIVE ECONOMY`）：引原海报三要点并温和修正「层越多越清晰」的常见误解；交互：**64 节点宽深树形推演台**（连续滑块 + 实时 SVG 树状图，重现 Kiger 1984 宽深权衡）。
2. **02 三大核心与权重阶梯**（`WEIGHT & ORIENTATION`）：拆解层级/路径/定位与「层级与权重的平衡方法」；交互：**四层视觉权重调音矩阵**（直点四层切换权重模式与高亮策略，实时算对比度与导航占屏比）。
3. **03 从档案夹到信息架构**（`ORIGINS & STANDARDS`·深绿暗室）：梳理竖立档案夹 → Miller 1981 / Kiger 1984 → Rosenfeld & Morville 1998 / Larson & Czerwinski 1998 → Pirolli & Card 1999 / Krug 2000 → W3C APG & NN/g；交互：**五代演进档案签 + 语义 HTML/ARIA 对照检视器**。
4. **04 级联联动与响应折叠**（`CASCADE & RESPONSIVE`）：讲解父子级联重置、位置型 vs 历史型面包屑，以及跨端防吸顶挤屏策略；交互：**桌面 / 平板 / 手机三端视口切换与折叠模式对比器**。
5. **05 什么时候用与别用**（`WHEN TO USE & AVOID`）：明确适用场景与 5 类禁用边界，一句链接到 289/285/280/283/281 等同小类页面；交互：**6 张产品场景诊断翻牌器**。
6. **06 小练习：挑出稳健方案**（`ARCHITECTURE QUIZ`）：四套同样整洁的 64 节网课分层方案（仅差单变量、纯中性标签 A/B/C/D + SVG 线框示意图），选后给出逐项拆解。
7. **07 原海报与关键词**（`ORIGINAL POSTER`·深咖展墙）：展示可放大拖拽的 290 原海报、`你将学到` 与底部五枚关键词动线解析。

## 7. 练习设计
- 题目：64 节课程站（4 模块 × 4 专题 × 4 节），学习者常从搜索空降「布局策略 03」，四套干净线框图挑最稳健方案。
- 四个选项（中性标签，各自只差一个核心变量）：
  - `方案 A · 顶栏平铺`：1 层塞 12 项、无次导航与面包屑（扁平扫描过载）。
  - `方案 B · 递减三级联`：L1 轻字位置面包屑 + L2 主导航单亮 + L3 次导航下划线 + L5 局部签，总高占 28%（**正确**）。
  - `方案 C · 等重全亮`：三层齐全但 L1/L2/L3/L5 同高同饱和度，总高占 49%（权重打架 + 导航压屏）。
  - `方案 D · 历史轨迹`：层高阶梯合适，但 L1 显示点击历史顺序且 L2 无高亮定位（路径失真 + 定位盲区）。
