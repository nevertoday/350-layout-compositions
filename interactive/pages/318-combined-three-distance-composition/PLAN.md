# 318 三远综合构图 · 制作方案

## 1. 一句话道理
把仰望的高远、穿入的深远与横展的平远放进同一画幅，视觉空间才同时拥有高度、纵深与广度；但三种空间方向彼此拉扯，必须「一主二辅、三轴统合、烟岚通脉、留白让口」，才能化散为整而不是硬拼三张贴画。

## 2. 开场玩具
- **名字与玩法**：**三远立体金字塔合成台 × 底沿等式双游标权重分配尺**（Three.js 实时 3D 棱面山水，关 WebGL 自动切 2D Canvas 共用 `model.js` 几何坐标）。
  - 用户横向拖动底沿原海报公式胶囊里的「双游标三远权重分配尺」（`data-perf-drag`），实时调配 `高远 + 深远 + 平远 = 100%` 的空间占比；
  - 直接在中央 3D/2D 山水画布点/拖偏歪的高远峰尖、跑偏的深远谷口与斜坠的平远水岸，把撕裂的三轴校准为「中轴三角」或「北宋 S 脉」；
  - 在左右两翼调校烟岚接缝浓度与前景退让留白，并可一键切「正视成画 / 三维剖轴（Y↑ 高远 · Z→ 深远 · X↔ 平远）」看透三轴空间关系，切换「原海报三远 / 郭熙早春 / 青绿长卷」三组题材。
- **开场状态（0 / 4 待统筹 错态）**：
  - 权重均分打架（高远 34% / 深远 33% / 平远 33%，顶右三圆点亮成 `● ● ●` 失衡警告）；
  - 三轴错位撕裂（峰尖左偏 `-16%`、谷口右甩 `+18%`、水岸歪斜 `+7°`）；
  - 接缝硬切断层（烟岚 0%，三层之间红虚割线暴露拼贴感）；
  - 前景堵口挤顶（朱橙圆块硕大堵在谷口正中、天头余气仅 3%）。
- **怎样算玩错（8 类实时诊断，全部由 `model.js` 单真源从实绘几何算出）**：
  1. 三权均分打架（最大占比 < 44%，三轴拔河）；
  2. 单远孤立退化（任一远 < 12% 或最大 > 74%，退化为纯高远/深远/平远）；
  3. 三轴错位撕裂（峰轴、谷心、水岸倾角失准）；
  4. 三截硬切拼贴（烟岚衔脉 < 22%，过渡断层）；
  5. 浓雾吞山失骨（烟岚过浓 > 76%，吞没深远山势）；
  6. 前景堵口截道（前景块居中过大遮挡深远通道）；
  7. 主峰顶天窒息（天头余气 < 7%，高远气势撞框）；
  8. 散碎空壳无势（前景与中景定标过弱，底部发飘）。
- **多解验收**：接受高远主统、深远主统、平远主统三种主次配方，以及中轴三角 / S 形龙脉两种统合轴向，并非唯一答案。
- **与最近 12 页的明显区别**：
  - 不同于 317（底沿拉展手卷幅宽 + 删杂障）、316（顶沿 Z 轴推门剖面轨）、315（竖立轴仰角卷轴）、065（拖拽旋转 3D 玻璃拆层 + 三道通栏滑块）、027（铅垂轴锤与天平）——318 独创「底沿等式双游标三元权重分配尺 + 三翼拱卫三维金字塔山水 + 轴线与烟岚接缝直调」，只能用在「三远综合」一页。

## 3. 版式骨架
- 忠实承袭 318 原海报「暖宣纸三翼拱卫中央三角图式 + 右上圆印与三主次圆点 + 底沿圆角细线视觉等式框」出版图谱骨架（零深色仪表盘卡感、不锁 `100svh`）。
- **1440×900**（主栏 1380px；**2560×1440** 舒展至 1820px）：顶部单行极细眉栏 + 紧凑刊头（左活体示范大标「三远综合构图」× 右双峰圆印与活体 `● ○ ○` 主次点）→ 左 23% 高远翼 × 中 54% 三远 3D/2D 立体画布 × 右 23% 深远翼（三列等高无悬空）→ 底沿平远横展与原海报大圆角等式双游标分配尺 + 白话实测诊单。
- **1024×1366 / 768×1024**：自然流式堆叠，全宽画布居中，三翼收为横向三列紧凑面板，无大片空洞。
- **390×844**：极紧单行刊头让等比 3D/2D 舞台占首屏 ≥ 46% 屏高，紧接 52px 双游标权重尺与诊单首行同入首屏，圆形严守等比不压扁。
- **844×390**：横屏切左 55% 舞台与权重尺 × 右 45% 刊头诊单与快捷调校并行。

## 5. 节目录（7 节，每节标题 ≤ 12 字，相邻控件不重复）
- **01 一幅画里的三重空间**（亮素宣）：展开海报「高远 / 深远 / 平远」三要点，一句话链接 315/316/317/319/320；交互：**三远叠层 X 光复选开关板**（任意开关三层观视效变化）。
- **02 为什么必须一主二辅**（淡薰衣草雾宣）：温和提醒海报等式不可平分，给经验参考带；交互：**二维三元重心三角罗盘**（点拖三角形内坐标，联动三套主远构图与失衡区）。
- **03 从北宋《林泉高致》来**（深靛暗室）：核实郭熙《林泉高致》（1117 许光凝序）、《早春图》（1072）、王希孟《千里江山图》（1113）、韩拙《山水纯全集》（1121）；交互：**名画视游路径步进播放器**（切立轴/长卷 + 步进滑块动态追踪三远视线轨迹）。
- **04 怎么把三远揉成一体**（暖杏米纸）：讲烟岚断腰、设色阶梯与轮廓收束，示范四类现代跨界媒介；交互：**2×2 跨界样张画廊 + 三远骨架 X 线切换开关**。
- **05 什么时候用，什么时候别用**（暖宣米纸）：明晰适用边界与小图/快消/看板四大禁区；交互：**画幅缩放压力测试滑块**（1200px 巨幅缩至 160px 小卡，对照三远糊团与单远简版）。
- **06 眼力小测：谁真统合三远**（淡薰衣草雾宣）：两道单变量四选一测验（辨主次与轴向 / 辨烟岚与前景让口），中性选项 A/B/C/D 不透题，选后叠显解析。
- **07 原海报与关键词**（暖宣米纸）：可放大/拖动/Esc 关的原海报灯箱（`draggable="false"`）+ 全部 6 组中英关键词与原海报图式拆解。

## 7. 练习设计
- **第 1 题（主次与统一轴向）**：同一组紫靛山川剧场海报，4 个方案元素与配色完全相同，唯一变量是三远占比与轴向关系：A（33/33/34 均分打架）、B（高远 84% 吞没另两远退化为单远）、C（**正确**：高远 54% 主统 + 深远 24% + 平远 22%，三轴合入三角骨架）、D（52/25/23 占比达标但峰左偏、谷右甩、水岸斜切导致空间撕裂）。
- **第 2 题（气脉衔接与留白）**：同一组高远主统山水卡，唯一变量是交界过渡与前景位置：A（两条直切硬缝割裂三层）、B（浓雾 80% 吞没中景深远）、C（前景大圆与方块居中堵死谷口）、D（**正确**：轻岚微断山腰、前景错落退让两侧，气脉贯通）。
