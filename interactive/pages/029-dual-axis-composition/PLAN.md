# 029 双轴构图 · 设计方案（PLAN.md）

## 1. 一句话道理
双轴构图以垂直轴建立由上而下的层级顺序、以水平轴拉宽版面并平衡左右视觉重量，两条正交轴自然切出各司其职的四个象限，并在交汇处凝成明确焦点，使复杂信息既稳如建筑框架又一目了然。

## 2. 开场玩具：「活体双轴四象限排布台」
- **怎么玩**：
  - 直接在 1:1 承袭 029 原海报视觉语法的 2D Canvas 四象限画布（`#hero-canvas`，标 `data-perf-drag`）上操作：横向拖拽平滑滑动**垂直轴 X**（`16%–84%`，触屏以 `touch-action: pan-y` 保持纵向滚页顺畅），鼠标拖动中心交点可二维同时微调 **X / Y 双轴**；滑动画布底沿专设的**水平轴 Y 标尺**调节上下层级切分；焦点在画布上时支持键盘 `← / → / ↑ / ↓` 微调轴位（`Shift` 步进 5%）。
  - **直接点击画布上的任意象限卡**，在 `重块深蓝（主内容）` → `轻块暖杏（辅内容）` → `空置塌陷` 间轮换配重，亲手试验左右重量平衡与对角互锁；一键切换核心焦点状态（`脱轴漂移` / `锁回双轴交点` / `隐去焦点`）、切换上下层级顺序（`层级倒置` / `由上而下`），并在三套真实场景间切换：**原海报·几何四区**、**山海孤帆·风景双轴**、**展讯海报·信息编排**。
- **一打开是什么状态（0 / 4 待立双轴，绝不先给答案）**：
  - 垂直轴挤偏到 `X = 24%`、水平轴沉底到 `Y = 76%`；两块深钴蓝重卡同时堆在右侧（`Q2 + Q4`）致左右严重右倾；左下 `Q3` 留空塌陷而右下 `Q4` 越界挤叠；上下层级倒置；标志性的钴蓝金心焦点圆脱出交点飘到右上角落。原海报四项原则徽标全部标错态。
- **怎样算玩错 & 错了读数怎么说（`model.js` 单真源实算 8 类错态）**：
  1. **轴线贴边挤爆**（`axisX < 30%` 或 `> 70%`，或 `axisY < 30%` 或 `> 70%`）：一侧象限被压成狭缝，四区分工瘫痪。
  2. **水平轴左右倾覆**（左右实绘视觉重量比偏差超过阈值）：重块堆在同一边或轴偏无配重补偿，版面像天平一样向重侧沉斜。
  3. **垂直层级倒置**（主标题/核心内容被压到水平轴下方，或上下全无主次）：视线不知该从哪起读。
  4. **分区空洞或越界**（任一象限空置塌陷，或内容溢出撞断轴缝）：破坏「分区有序、各归其位」。
  5. **四区全重窒息**（四个象限全塞满深钴蓝重块）：失去深浅节奏与呼吸留白，层级与分区同时模糊。
  6. **焦点脱轴漂移**（蓝金焦点圆离开双轴交点）：交点处空荡无锚，视觉重心与轴线骨架打架。
  7. **焦点空心缺席**（关闭中心焦点）：双轴交汇成无着落的空白十字，注意力四散。
  8. **底重头轻倒挂**（两块深蓝重块全压在底部 `Q3 + Q4`）：重心下坠发沉，上区发虚。
- **多组合法达标解**：接受 `50% / 50%` 经典对角蓝杏（`Q1+Q4` 深蓝或 `Q2+Q3` 深蓝），也接受在健康区带内（如 `42% / 44%`）利用「窄侧深蓝重块 × 宽侧暖杏轻块」抵消面积差实现非镜像双轴均衡，同时焦点落交、四区满岗、层级由上而下，即亮起 `4 / 4 双轴成立`。
- **读数说什么「为什么」**：全部几何量（交点 `X% / Y%`、最小区占比 `%`、焦点偏轴 `%`）与明确标注「（示意）」的左右配重比，统一由 `model.js` 的 `evaluate(state)` 实时计算；下方皇室蓝诊单始终用两句白话解释「人眼此刻会怎样迷路或停稳」并提示下一步可调方向。
- **与最近 12 页的明显区别**：
  - 不同于 028 左出血圆窗单轴横移与朝向杠杆、066 视差月洞门穿框、151 手撕纸片叠层拼贴、111 四轨黑白交替拍、234 固定定位迷你浏览器、279 六月日历排期、317 平远手卷展平、195 瑞士分栏拖缝、150 看图猜成语谜面、233 绝对定位坐标框、278 五列看板与 110 梯度坡面；029 独创**双正交轴同步切分 × 四象限体量点击互换 × 交点焦点落位校验**，直指「水平均衡 × 垂直层级 × 四区分工 × 交点聚焦」四维联动。

## 3. 版式骨架
- **桌面 1440×900（主容器 `1380px`，2560×1440 舒展至 `1800px`）**：严格复刻 029 原海报的对称出版画幅骨架——极细 32px 深藏青顶眉下，暖杏纸面顶刊为左 60% 示范大标「双轴构图」（内置随画布 X/Y 轴实时联动的微缩蓝金双轴徽标）× 右 40% 原海报标志性的钴蓝远山、金黄旭日、白帆水影插画与三题材切签；中段铺开**对称三翼双轴舞台**：左翼 21% 为「层级清晰」「分区有序」两枚海报圆徽实时卡（中夹 `← 水平轴` 指向标）、中栏 58% 为巨幅四象限 2D 画布与极简底沿水平轴标尺及快控键、右翼 21% 为「均衡稳定」「焦点明确」两枚圆徽实时卡（中夹 `拓展宽度与稳定 →`）；底沿通栏无缝承接原海报同款**皇室钴蓝实底带**（左 46% 单真源白话实测诊单 × 右 54% 原海报四枚白圆图标「应用建议」实时联动列），再收于极细暖纸「双轴并行，万物有序 · + + +」版权尾条。不设 `min-height: 100svh`，避免竖屏平板留白空洞。
- **手机竖屏 390×844**：压紧单行刊头（标题 + 进度胶囊 + 英文副标），让等比四象限画布直落首屏顶部并稳占 ≥46% 屏高（所有圆与方严格按实测像素等比绘制绝不压扁），紧接紧凑触控条（水平轴 Y 滑轨 + 焦点/一键配重钮）与皇室蓝诊单首句，四原则徽卡收成 2×2 迷你方阵接在下方。
- **手机横屏 844×390**：切为左 54% 满高四象限画布 × 右 46% 紧凑刊头、触控条与皇室蓝诊单并行，横握单手即可流畅拖动与读诊单。

## 7. 小练习设计
- **第 1 题（单一变量：四象限深浅重量排布）**：四张缩略图轴线全部锁定在 `50% / 50%`、蓝金焦点均位于正交中心，仅改变两块深钴蓝重块所占象限——方案 A（全压左侧 `Q1+Q3` 致左倾）、方案 B（全压底部 `Q3+Q4` 致上虚下沉）、方案 C（对角互锁 `Q1+Q4` 深蓝配 `Q2+Q3` 暖杏，正解）、方案 D（四区全涂深蓝失呼吸与主次）。
- **第 2 题（单一变量：双轴交点与焦点落位）**：四张缩略图均采用对角蓝杏配重，仅改变轴位比例与焦点圆位置——方案 A（轴线正常但焦点圆漂离交点至右上）、方案 B（轴线贴边 `18% / 80%` 压扁两区）、方案 C（轴线居中但交点空心无焦点）、方案 D（轴线微偏 `46% / 48%` 且蓝金焦点稳落交汇点，正解，打破「必须死卡正中 50%」的误区）。
