# 253 悬浮层 FLOATING LAYER · 互动页方案

## 1. 一句话道理
悬浮层通过把关键任务从常规文档流中沿 Z 轴独立抬升，借助**层级叠序、海拔光影、表面明度阶梯与背景适度退让**建立清晰的前后景秩序，让用户在不离开当前页面的前提下立刻聚焦于最高优先级信息。

## 2. 开场玩具（Z 轴剖视浮层工坊 · Peel-Open Z-Axis Layer Workbench）
- **核心动作**：自定义轻量 2D Canvas 真三维透视投影引擎（标 `data-perf-drag`），1:1 承袭 253 原海报的深梅紫展面与三层实体卡片（暖白焦点层 + 粉圆、浅青次级层 + 暖白三角、灰紫背景层 + 点阵与同心弧），并支持切换 `原海报三层`、`确认弹窗 Modal`、`商品浮卡 Popover` 三种真实界面载体。
  - **横拖画布 (`data-perf-drag`)**：连续旋转并「剥开」Z 轴视角（`0° 正视界面` ↔ `52° 侧视剖析`），实时拉出三层之间的 Z 轴空气间距、高程标尺与随虚拟主光源物理偏移的三层投影（Umbra/Penumbra/Ambient）。
  - **直点画布卡片或左下原海报轴测菱形堆叠**：直接选中或置顶某一层；左下三片轴测菱形实时镜像当前真实叠序与层距。
  - **下方精控轨**：调整焦点层/次级层叠序、焦点海拔 `0dp–36dp`、背景遮罩 `0%–92%`、次层海拔（稳贴 `6dp` / 争焦 `20dp`）以及多解预设。
- **开场状态（复合真错态，绝不先给答案）**：
  1. **层级倒挂**：暖白焦点层被压在次级浅青层之下（`zFocus < zSecondary`），实测被次级层直接遮挡约 27% 面积。
  2. **零海拔贴地**：海拔差为 `0dp`，无投影、无高低层次感。
  3. **背景零退让**：背景遮罩 `0%`，底层点阵与三层卡片抢眼。
- **怎样算玩错（双向真错态，全由 `model.js` 从实绘投影矩形与参数单真源核算）**：
  - `inverted`：焦点层不在最顶层（被次层或背景遮挡）；
  - `flat`：海拔 `< 6dp` 且缺乏遮罩与投影，贴地难分前后；
  - `muddy`：海拔推过 `28dp`（如 `34dp–36dp`），投影散成一片脏雾、脱离承托面；
  - `blackout`：遮罩压暗超过 `78%`，背景与次层完全黑死，违背「背景承托」失去页面上下文；
  - `competing`：次级层也被抬高至 `≥ 14dp` 且与焦点海拔差 `< 6dp`，出现「双浮层争焦」；
  - `detached` / `swallowed`：焦点卡片偏移至零重叠（退化成并排分栏，不再是悬浮叠加）或几乎全遮次层（吞没承托）。
- **多组合法解**：支持 `原海报三阶解`（16–22dp + 适度遮罩）、`模态确认解`（20–24dp + 40–65% 遮罩）与 `轻量浮卡解`（8–14dp + 0–18% 轻遮罩，靠亮暗与投影分离而不锁死背景）。
- **与最近 12 页的区别**：最近 12 页分别为横向卷轴（252）、比例裁切框（251）、F 型眼动热图（127）、5×6 破格模块（210）、1px 微调放大镜（294）、三圆主宾配重（330）、圆形顶视转盘（079）、辞书书口索引（165）、三角顶点骨架（041）、25 件四群分拣（126）、330 点疏密声谱（329）和双态断点切帘（293）；本页首次以**网页 UI Z 轴三维剥离剖视 + 叠序/海拔/遮罩实时单真源诊断**作为开场动作，只适用于「悬浮层」这一布局原语。

## 3. 版式骨架
- **1440×900（主宽 1380px；2560×1440 舒展至 1680px）**：忠实转译 253 原海报深梅紫细框展板双栏结构（绝不锁 `100svh`，零通用深色顶栏与圆角仪表盘黑箱）——左 34% 开放排布自示范分层大标「悬浮层」+ 短粉杠 + 原海报三点无框纵列（带实况读数签）+ 左下活体轴测三层菱形图；右 66% 排布题材/视角切签 + 全宽 3D 浮层主舞台画布 + 细线精控条 + 原海报右下圆角细框三形图例合并单真源白话诊单与实时 CSS 匣。两栏底边齐平，无单边留白。
- **1024×1366 / 768×1024 平板竖屏**：自然折排，零 `100svh` 空洞。
- **390×844 手机竖屏**：顶沿压紧为单行刊头（~72px），紧接题材切签与等比 3D 浮层主画布（稳占首屏 ≥ 48% 高度，绝不压扁变形），首屏底沿直露单真源诊断首句与一键修复/主控条；三点解说与轴测图顺接其下。
- **844×390 手机横屏**：切换为左 56% 主舞台画布 × 右 44% 刊头、诊断与主控并行。

## 4. 配色和字体
- **配色（逐像素实采自 253 原海报）**：
  - 外框暗梅紫 `#211632`、深梅紫原底与暗室 `#2D1F42` / `#231836` / `#1F1530`；
  - 焦点层暖瓷白 `#ECE6E0`（浅读纸 `#F6F2EE`）、墨炭主字 `#1F1D1B`、焦点玫瑰粉 `#EC72A2`（浅纸安全深莓红 `#B02A62`）；
  - 次级层鼠尾草浅青 `#A8C8BB`（浅青雾纸 `#EDF4F0`、浅纸安全深松绿 `#19604B`）；

- **01 · 为什么浮得起来**（暖瓷白纸）：展开海报三要点并温和勘正海报印刷笔误「突层→次层」；交互：**四通道深度剥离开关**（重叠/投影/表面提亮/遮罩独立开关）。
- **02 · 五类悬浮原语**（浅青雾纸）：区分模态/非模态与锚定/居中，附同小类页面一句话链接；交互：**真实可用迷你应用沙盒**（点击触发真 Tooltip / Popover / Dropdown / Drawer / Modal / Toast，支持 Esc 与点外关闭）。
- **03 · 为什么 9999 会输**（深梅紫暗室）：拆解 CSS 层叠上下文与原生 Top Layer；交互：**活体 DOM 层叠陷阱开关 + 一键破狱入 Top Layer**。
- **04 · 暗底与亮底的阴影**（浅紫雾纸）：对比亮纸物理投影与暗底「色调海拔 + 1px 高光边」；交互：**昼夜切换 × 0–24dp 海拔阶梯卡尺**。

## 7. 练习
- **题干**：在暗梅紫底色的协作工具里弹出「删除项目」确认悬浮层，四套方案的文案、尺寸与按钮排布完全相同，只改变**海拔投影、表面明度与遮罩策略**。哪一张能同时守住「悬浮焦点」与「背景承托」？
- **四项（中性标签，单变量差异）**：
  - 方案 A：暖白高反差焦点卡 + 18dp 柔和投影 + 42% 半透明压暗遮罩（正确：前景聚焦锐利，底层页面语境仍可辨识）。
  - 方案 B：暗紫低反差焦点卡 + 36dp 极重黑雾投影（错：暗底纯黑影融进底色，表面未提亮且大影发脏）。
  - 方案 C：暖白焦点卡 + 18dp 投影 + 94% 实黑遮罩（错：把背景完全涂黑，切断来源语境，违背背景承托）。
  - 方案 D：暖白焦点卡与次级侧栏同时抬至 18dp 高亮浮起（错：双浮层争抢第一眼，焦点被一分为二）。
