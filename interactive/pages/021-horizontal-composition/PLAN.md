# 021 水平构图 · 方案（PLAN.md）

## 1. 一句话道理
重力永远垂直向下，水平面是唯一不再滑坠的休止面，加上人眼视觉皮层对 0° 主轴极度敏感，所以调平且连贯的水平线能瞬间让画面稳定、横向延伸并安抚情绪。

## 2. 开场玩具
- **名字**：通栏海平水准与地平构图台（2D Canvas 活体宽银幕海天版画 + 实体气泡水准仪长轨 + 贯穿全幅可上下拖动的白色海平线）。
- **初始状态（绝非答案）**：打开即处于双料翻车态——海平线向右倾斜 `+5.2°`（整片海天溜水，刊头大标题下的水平基准线同步歪斜，下方气泡水准仪的朱陶红气泡偏至左高端），同时海平线卡在 `50%` 正中死对半（山、日、帆俱全却上下五五抢主次）。
- **怎么玩**：
  1. 左右拖动紧贴舞台下沿的「实体气泡水准尺」（标 `data-perf-drag`，或按 `←` / `→` 键、在画布上横向滑）旋转画面调平倾角（`-8.0° ~ +8.0°`），靠近 `0.0°`（`±0.55°` 内）轻磁吸锁平；
  2. 上下拖动贯穿海面的白色海平线两侧 `↕ 海平` 滑钮（或按 `↑` / `↓` 键、点直达刻度）重分天地比例（`16% ~ 84%`）；
  3. 切换 4 套实景标本（原海报海帆 / 海岸灯塔 / 草原长屋 / 极简空海特例）与 3 种画幅（宽银幕 / 标准 4:3 / 竖框截断 3:4）。
- **怎样算玩错、错了读数怎么说**：
  - `|tilt| > 0.6°` → 报「海面倾斜 · 水往低处滑」，并指出超出人眼对 0° 基准线的敏感阈值；
  - 调平但多元素标本停在 `44%–56%` 正中 → 报「已调平，但正中死对半，上下抢主次」；
  - 调平但海平落于 `< 20%` 或 `> 80%` → 报「海平贴边窒息，失去天地呼应」；
  - 调平但切至 `3:4 竖框截断` → 报「竖框裁断水平线，延伸张力折半」；
  - 切至「极简空海」标本时，判定规则真实切换：抽离山、日、帆后，唯有 `0.0°` 调平 + `50%` 正中才成立（「空海特例 · 正中成镜面静默」），打破死教条。
- **读数说什么「为什么」**：底部深海蓝诊断带与微型水平框始终由同一模型状态算出，说清当前倾角、天地占比与画幅会如何牵动视线与情绪。
- **与最近 12 页的区别**：不用任何拖十字瞄准器/中轴翻折/卡片堆叠/响应断点/3D 塔；以「实体气泡水准调平 + 贯穿白线升降切分天地 + 极简特例证伪」直击水平构图独有的物理本质。

## 5. 节目录（8 节，标题均 ≤ 12 字，相邻控件不重复）
1. **01 为什么人眼一看就怕歪**（`WHY HORIZONTAL CALMS`）：用重力休止面（Arnheim 1954）与斜向效应（Appelle 1972）讲清人眼对水平线的生理敏感；**交互**：5 题直觉盲测仪（点「平的 / 歪了」实测自己能察觉的最小倾角并叠线校验）。
2. **02 一根线干五件事**（`FIVE PRINCIPLES ON ONE LINE`）：完整引出原海报五要点（稳定、延伸、引导、地平、节奏）与 TIP 原话；**交互**：原海报同款五列竖线矩阵，点任一列展开 2D Canvas 活体动态解剖，其中「节奏」支持直接点画布 5 颗红点切换等距与疏密呼吸。
3. **03 地平线放哪：低中高的讲究**（`LOW, CENTER, OR HIGH`）：拆解低地平、高地平与正中 50% 教条的温和纠偏（「说多了一点」小签），衔接 001/018/020；**交互**：繁景 vs 极简双境切换 + 连续滑轨实时看 50% 从割裂转为静默对称。
4. **04 水平构图从哪来**（`ORIGIN & LINEAGE`）：四段经核实的跨媒介史（1670–1675 鲁伊斯达尔《哈勒姆远眺》、1908–1910 赖特罗比住宅、1953《圣袍千秋》2.55:1 CinemaScope、1980 起杉本博司《海景》）；**交互**：横向编年时间带联动等比变形 SVG 构图骨架图。
5. **05 打破沉闷：横线配竖锚**（`BREAKING MONOTONY`）：展开原海报三幅「应用示例」（灯塔、红门白墙、麦田行树），讲清竖锚与节奏如何防止平淡，链接 022/024/030；**交互**：2D Canvas 重绘三幅场景，一键拆掉/放回竖向锚点并切换落点节奏。
6. **06 什么时候别用水平构图**（`WHEN NOT TO USE IT`）：深墨海反底，列举高耸崇高、冲刺动势、竖屏腰斩、等距条纹四类翻车区，链接 022/023/025/072；**交互**：四组「翻车原图 → 改方构图」对照切换卡。
7. **07 小练习：选一张稳下来的稿**（`QUICK PRACTICE`）：双题单变量同构选图（第 1 题海滨长屋展横幅；第 2 题极简雾海特例），标签仅写方案 A/B/C/D，选后叠出基准虚线逐项解析。
8. **08 原海报与同族索引**（`ORIGINAL POSTER`）：原海报全貌与点击灯箱放大拖动（`draggable="false"` + `Esc` 关），海报完整原文、同小类 14 个编号链接与规范页脚。

## 7. 练习设计
- **第 1 题**：海滨美术馆冬季静思展横幅主视觉（含海面、远山、低矮长屋与红门），A/B/C/D 四幅完全同色同景，只差一个构图变量：
  - 方案 A（正确）：0.0° 水平 + 低地平 34% + 连贯无遮挡，长屋顺岸低伏、红门轻锚视线；
  - 方案 B：仅海平线抬到 50% 死对半，天地各占一半互相抢主次；
  - 方案 C：仅海平线微倾 +3.4°，海水隐约向右溜出；
  - 方案 D：仅中央立一根黑灰粗竖柱，将水平线与视线延伸拦腰斩断。
- **第 2 题**：极简雾海主题（仅有天与海两块柔调），A/B/C/D 同样只差一个变量（50% 水平 / 34% 水平 / +3.2° 倾斜 / 压底 14%），考是否理解「极简无物时 50% 正中反而是最静谧的镜面平衡」。
