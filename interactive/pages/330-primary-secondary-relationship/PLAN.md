# 330 主宾关系构图 · 设计方案（PLAN）

## 1. 一句话道理
人的视野一次只能对准一个重心；主宾关系构图通过把体量、色彩、位置与留白四根杠杆向「主体」集中、让「次要元素」与「细节点缀」按阶梯退让并沿视线弧呼应，让读者不用犹豫就能完成「先主、次宾、终细节」的阅读顺序。

## 2. 开场玩具
- **名称**：主宾星轨·三阶引力配重台（直接融在 330 原海报 `#E7E3E0` 暖麻展纸上的无框 2D Canvas，标 `data-perf-drag`）。
- **怎么玩**：
  - **画布横向拖动（`data-perf-drag`）**：连续推拉「主宾体量反差」（扩大主体并收束陪体，或反向把陪体推大导致喧宾夺主），实时联动三圆面积比、虚线视线引导弧与底沿微缩示意图。
  - **直接拖移三枚元素本体**：拖动「主体」「次要元素」「细节点缀」改写位置与呼吸留白，观察虚线引导弧如何顺畅承接、碰撞挤占或拉断失联。
  - **三阶角色与色彩切换**：切换当前精调层级、单独试错「次要元素抢占朱砂主色（双红争主）」、一键「主宾易位」，并可在「原海报三圆 / 宋画群峰 / 展讯海报」三题材间无缝切换。
  - **键盘操作**：选中任意层级后，方向键移动位置、`[` / `]` 增减体量、数字键 `1/2/3` 切层，全程支持 `:focus-visible`。
- **一打开是什么状态（绝非答案）**：
  - 停在「喧宾夺主 · 双强争眼」复合错态：主体收缩（仅约 1.2× 次要元素面积）、次要元素既膨胀又抢用了同款朱砂红、细节点缀也偏大且挤进主体护城河，视线顺位读作 `1? ⇄ 1? 争焦`，虚线引导弧呈冲突警示态。
- **怎样算玩错、错了读数怎么说**：
  - 由 `model.js` 从当帧实绘像素几何 `(cx, cy, r)` 与色阶单真源实时核算 8 类双向错态：
    1. **平分秋色 / 喧宾夺主**（主/次面积比 `< 2.6×`）：指出两块视觉重量拉不开，视线来回拉锯。
    2. **双红争主**（次要元素或点缀启用朱砂主色）：指出色彩频道撞车，缩小也照样抢第一眼。
    3. **细节点缀反客为主 / 层级倒挂**（次/点面积比 `< 2.4×` 或点缀显著度反超次要元素）：指出三阶塌成两阶混战。
    4. **宾体湮没**（主/次面积比 `> 32×` 或次要占幅过微）：指出过度悬殊让陪体消失，画面退化成孤单红点，失去辅助延伸。
    5. **满幅窒息**（主体占画幅 `> 52%` 或护城河留白不足）：指出没有留白衬托，再大也会闷死。
    6. **贴身互挤**（元素圆心距过近、核心区碰撞）：指出缺乏边界喘息，主宾粘连。
    7. **切边挤压 / 气脉断离**（元素紧顶画框或宾体远逃对角孤岛）：指出视线弧线崩断，主宾失联。
    8. **三阶未拉齐**：所有数值均来自同一几何状态，并标明综合显著度档位为「示意」。
  - **多组合法解**：除「原海报经典解」外，同样接受「宋画正峰解」「留白孤主解」及用户自行拖出的任意合理三阶构图。
- **与最近 12 页的明显差异**：
  - 329 玩点阵聚散波形、328 玩半透明玉屏穿插、293/209/250/208/292 玩响应式断点网格、164 玩目录分栏、125 玩磁聚粒子、078 玩 3D 仰拍透视、163 玩跨页裁切出血、040 玩闪电折角；本页专做「三阶视觉权重分配 + 色彩归属争夺 + 视线弧线连贯」的主宾关系调衡，别的编号无法原样套用。

## 5. 节目录（7 节，h2 均 ≤ 12 字，相邻节控件各不相同）
- **01 为什么眼睛先看「主」**（`WHY THE EYE ANCHORS FIRST`）：拆解原海报核心与温和纠偏「主宾不只是比面积」；交互：**四杠杆独立开关台**（体量/色彩/位置/留白 4 枚复选开关，实时改写等大三元素海报的视觉重心与视线序）。
- **02 三阶梯队：主、宾、点**（`THREE-TIER CASCADE`）：展开原海报「主体 / 次要元素 / 细节点缀」三阶分工与经验比例；交互：**阶梯形态分段对比台**（在四阶乱战 / 双强平分 / 标准三阶 / 孤主无宾间切换，同屏联动比例尺与活体展讯卡片）。
- **03 从主峰朝揖到视觉层级**（`HISTORICAL LINEAGE` · 深黛青暗室）：考据郭熙、王概、邹一桂、沈宗骞与阿恩海姆；交互：**古今三境 X 光骨架透视镜**（三幅古今版式切换 + 骨架/视弧透视叠加开关）。
- **04 什么时候用，什么时候别用**（`WHEN TO USE & AVOID`）：明确适用边界与四大禁用场景，并用一句话链接同小类 326–334 编号；交互：**四组场景对照翻检卡**（每卡可独立切换「强主宾版 vs 均等网格版」线框预览对比利弊）。
- **05 常见翻车：四类失衡现场**（`FOUR CLASSIC BREAKDOWNS`）：对应原海报「注意事项」三条铁律；交互：**病版 / 救版拉帘对照台**（选 4 类真实海报翻车现场，拖动中缝对比帘直看修复前后差异）。
- **06 小练习：哪版立住了主宾**（`PRACTICE QUIZ` · 深黛青暗室）：4 选 1 单变量盲测题，仅标「方案 A / B / C / D」；交互：**四版盲测单选卡片**，提交后逐项拆解单一变量成败原因。
- **07 原海报与关键词**（`ORIGINAL POSTER` · 原海报暖麻底）：展示 330 原海报（可点开缩放拖动、Esc 关闭）、完整要点、注意事项与单行页脚。

## 7. 小练习设计
- **题干**：四张「秋日茶器展」海报文字内容、版面底色与三要素落位完全相同，只改变主宾关系中的一个关键变量。哪一版最能建立「先主、次宾、终细节」的清晰视觉层级？
- **四选项（中性标签，单变量差异）**：
  - `方案 A`：面积与留白合理，但次要展期块也涂成与主器物同等的朱砂红（**变量破绽：色彩争主**）。
  - `方案 B`（正确答案）：主器物以朱砂红与充裕体量立核，次要展期以深黛青稳妥退居二阶，右下小印章作赭金点缀，主核四周有清晰留白缓冲。
  - `方案 C`：色彩归属正确，但次要块放大至与主体面积比仅约 1.3×（**变量破绽：体量差异不足**）。
  - `方案 D`：色彩与比例均拉开，但主体过度撑满顶边与右边、次要块被顶到左下角，主核丧失留白且主宾失联（**变量破绽：留白窒息与气脉断裂**）。
