# 143 图片 窗口版式（IMAGE WINDOW LAYOUT）方案

## 1. 一句话道理
页面本身是一堵素面「墙」，窗口是在墙上挖出的「开口」——它借**遮挡**裁掉杂景、只露一截关键局部，触发大脑的**非模态补全**（让人在有限洞口里补全墙外全貌，产生预览感），同时靠**窗口数量节制与主次面积级差**把视线按先后引向焦点（形成聚焦路径）。

## 2. 开场玩具：「墙面开窗裁景台」（2D Canvas 实体凹槽素墙 + 连续墙后画卷 + 透视墙后）
- **核心机制**：整块青灰素墙背后隐藏着一整幅取自 143 原海报的连续山水画卷（高光暖白日轮、暗松青山脊、鼠尾草曲径溪流）。用户在素墙上直接**封窗 / 开窗**、**在窗内拖动移窗取景**（窗洞在画卷上方滑动，画卷不动）、**拖右下角拉框柄改变主次比例**、**一键切换窗型（圆角方 / 拱形 / 横条 / 月洞）**，并可按住「透视墙后」（或空格键）令素墙变半透明，直视被遮挡的完整世界。
- **开场错态（不能一打开就是答案）**：默认呈现新手最常犯的「碎窗平权 + 窗棂劈主」错版——墙面被 6 扇大小完全一样的 2×3 矩形窗均分（主次面积比 1.0×），且中间横墙梁正好把暖白日轮拦腰劈开（单窗仅露约 56%），四枚原海报体检灯仅亮 1 枚，读数直指错因。
- **玩错反馈（单源几何计算 `model.js`，七类严格优先级诊断）**：
  1. 素墙全封（0 扇窗）；
  2. 窗棂坍塌（两窗重叠或墙骨净距不足）；
  3. 全墙掏空（总开窗占比 > 64% 经验上限，滑向全幅大图 140）；
  4. 针孔过闭（总开窗 < 22% 或最大窗 < 12%，信息不足无法触发补全）；
  5. 主焦被埋 / 窗棂劈主（日轮主焦未完整落入任一单窗 ≥ 78%）；
  6. 窗数过碎（> 4 扇）或主次平权（最大/次大面积比 < 1.65×）；
  7. 成立态（单窗独焦 / 多窗聚焦路径成型，按实测视觉权重描出 01→02→03 视线路径）。
- **与最近 12 页的差异**：既非排字缩放（142）、几何手柄（102）、镜像轴（020）、信息流 S 轨（269）、报版对调（129）、凸排挂点（187）、响应式堆叠（296）、断点切刀（240）、配重平衡（019）、抽屉越界（295）、3D 塔体透视（072），也非铅空缩进（186）；而是独属于窗口版式的「素墙开洞 + 滑动洞口透视连续世界 + 封窗塑级差」。

## 3. 版式骨架
- **桌面 1440×900**：极简顶栏下采用「左 50% 巨幅实景青灰素墙（固定 0.96 等比，约 600×625px，下附单行轻工具条）| 右 50% 示范型大标 + 原海报总述 + 实测窗表与诊单 + 四关键词体检灯」骨架，与紧邻的 142（左文右封面）左右彻底反转。
- **宽屏 2560×1440**：容器放宽至 1840px，左侧素墙画布等比延展至约 820×854px，主体宏阔不缩中。
- **平板 1024×1366 / 768×1024**：不锁 `100svh`，自然纵排——顶标横条下直铺大画幅等比素墙，再双栏承接诊断与窗表，无大片空白。
- **手机竖屏 390×844**：压紧顶栏与单行大标，366×382px（固定 0.96 等比，占屏高约 45.3%）素墙画布直落首屏，同屏见单行操控条与主诊断，零横向溢出、圆不变椭圆。
- **手机横屏 844×390**：30px 极简标题条下切左右分屏——左 50% 通高素墙画布（约 312×325px），右 50% 诊断与快捷窗型/封窗控制。
- **正文八节交替底色**：浅雾白 `#F2F4F3` → 青灰素墙 `#E6E9E8` → 深松青暗房 `#19393C` → 暖米砂纸 `#EAE5DC` → 浅雾白 `#F2F4F3` → 鼠尾草淡绿 `#D9E4DF` → 青灰素墙 `#E6E9E8` → 浅雾白 `#F2F4F3`。

## 4. 配色与字体
- **配色（实采自 `143.webp` 原海报）**：
  - 青灰素墙底 `#E6E9E8` / 浅雾白 `#F2F4F3` / 鼠尾草浅底 `#D9E4DF`
  - 深松青主色 `#367876`（小字高对比深青 `#215351`） / 幽暗松影 `#19393C` / 深岩青 `#2B4249`
  - 鼠尾草山色 `#9FBEB3` & `#B9CDC2` / 暖白日轮 `#E8E3DA` / 碳灰主墨 `#232829`
  - 克制陶红警示 `#A94435`（暗底提亮 `#F09A89`）
- **字体搭配（全库唯一，含三款最近 12 页均未使用的字体）**：
  - `Noto Sans SC`（400 / 500 / 700 / 900）：承接原海报厚重利落的现代黑体大标与清晰中文正文。
  - `Manrope`（500 / 700 / 800，**近 12 页未用**）：几何圆润现代无衬线，呼应原海报 `IMAGE WINDOW LAYOUT`。
  - `Space Mono`（400 / 700，**近 12 页未用**）：建筑制图感等宽字，用于编号、开窗比例与实测窗表读数。
  - `DM Serif Display`（400 斜体，**近 12 页未用**）：仅用于章节英文副注与历史术语点缀，不混入中文正文段落。

## 5. 节目录（共 8 节，h2 均 ≤ 12 字，相邻节控件不重样）
- **01 少露一点，反而想看更多**（*Amodal Completion*）：遮挡拉帘对照滑轨 + 三类场景切换（产品/案例/导入页），演示「全图直露 vs 适度遮挡 vs 针孔过闭」对非模态补全的影响。
- **02 窗形决定观看的情绪**（*Aperture Geometry*）：四型取景镜切换卡（圆角方 / 拱形 / 横条 / 月洞），同景异窗直观看轮廓对主体形态的呼应与错配。
- **03 数量与主次：窗多必乱**（*Hierarchy & Count*）：深松青暗房内以离散窗数步进钮（1/2/3/4/6/9 窗）+「均等 vs 悬殊」开关驱动 2D Canvas 视线落点热区模拟。
- **04 三类真实场景怎么开窗**（*Applied Spreads*）：产品详情 / 建筑案例 / 视觉导入三联真实排版校样台，配「错误开窗 ↔ 合理开窗」一键翻转对照。
- **05 窗口从哪里来**（*Historical Lineage*）：五代开窗编年图谱切换（1435 阿尔伯蒂 → 1631–1634 计成 → 1963/1983 奥格威 → 1968 穆纳里 → 1979/1981 卡尼萨与穆勒-布罗克曼）+ 海报「补一句实话」。
- **06 什么时候别用窗口**（*When Not to Use*）：四块反例对比板（说明书全貌 / 大合影图表 / 极窄微图 / 极简孤立物），点击翻看失误原因，并一句话链向同小类兄弟版式。
- **07 动手挑一版：哪张开窗最准？**（*Practice Quiz*）：同底图、同文字、同窗数的四版青釉瓶视觉导入页（标签仅写方案 A/B/C/D），单变量考校比例、遮挡与裁切。
- **08 原海报与关键词**（*Original Poster*）：原海报可点开缩放/拖拽灯箱（`draggable="false"`）+ 四关键词解说 + 原海报教学提示 + 单行规范页脚。

## 7. 小练习设计
- **题目**：手工陶瓷展「青釉长颈瓶」视觉导入页四版方案（A / B / C / D），文字、底图位置、窗口总数全部锁定一致，仅改变**窗口面积级差、开窗占比与主体裁切落点**。
- **A（错）**：三窗等大（1.05×），瓶口、瓶腹、瓶底平权争夺第一眼。
- **B（错）**：主窗铺满右侧 86%，几乎吃光素墙且装入整瓶，退化成无悬念边框大图。
- **C（正）**：大拱形主窗（主次 2.6×，总开窗 54%）完整框出瓶肩釉光与优雅曲线，配两扇小辅窗 preview 局部器底与窑变，预览感与聚焦路径兼得。
- **D（错）**：主次比（2.5×）与留白（45%）均达标，但主窗上框刚好劈断瓶口与主高光，犯「窗棂劈主」错。
