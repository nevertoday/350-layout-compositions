# 137 通版跨页（FULL-SPREAD LAYOUT）设计方案

## 1. 一句话道理
对称跨页（135）把中缝当镜面，非对称跨页（136）把中缝当杠杆支点；而**通版跨页（137）的核心是消解书脊带来的物理割断——让一条贯穿左右页面的主视觉通流（色带、全景摄影或跨脊标题）把两张独立的竖幅单页焊接成一块连续宽银幕，依托格式塔「良好连续性」让视线跨过装订线一气读完，同时用装订工艺与字位避脊保住中缝可读性**。

## 2. 开场玩具
- **命名**：跨缝通流·装订接缝台（Continuous Ribbon & Spine Bridge Bench，纯 2D Canvas，标 `data-perf-drag`，由 `model.js` 单真源从实绘贝塞尔色带几何、逐字字符包围盒与物理书脊折谷宽度核算）。
- **怎么玩**：
  1. 在深紫靛原海报跨页画布上直接**左右横拖主色带/画布中央开放区**，连续拉展或收缩跨页贯穿延展度（36%–100%），体验视觉流从「框死页内」到「直抵外切边」的叙事张力变化；
  2. 直接**上下拖动中缝处的「接缝节点」**，实时校正或主动制造正向/反向中缝错牙（`-78mm` 至 `+78mm`），靠近 `0mm` 时轻轻吸附咬合；
  3. 直接**左右拖动跨页大标**沿粉红 S 色带滑行，把关键字符移出（或拖进）装订折谷，实时观察物理书脊阴影对字符的挤压吞噬；
  4. **点按右页底场**切换「双页底场割裂 / 统一深紫靛通底」，**点按书脊顶部工艺签**循环切换「胶装紧订 14mm / 骑马订 5mm / 锁线平摊 1.5mm」，按 `Space` 或点「推演跨页流向」发射薄荷光流沿色带中心线穿脊实测（若中缝错牙，光流在中缝台阶处当场撞断；若贯通无阻则从左切边一气滑至右切边）；
  5. 支持切换三套出版标本：`原海报·粉带通流`、`地理摄影·冰川全景`、`建筑展册·长卷立面`。
- **开场初始状态**：刻意停在 `0/4 · 四重断裂` 复合错态——右页接缝下错 `+48mm` 断流、左右底场割裂（左深靛右灰褐）、色带缩死在 `56%` 框内未延展、胶装紧订 `14mm` 折谷正咬住大标里的「跨」字且细小正文硬穿中缝，底部实体纸弧剖面清楚标出被压碎的暗谷。
- **怎样算玩错（8 类双向真错态，单真源实算）**：
  1. 中缝下错断流（`ΔY > +6mm`）；
  2. 中缝上错反折（`ΔY < -6mm`，反向错态）；
  3. 过细断气（通流带宽 `< 14%`，撑不起跨页骨架）；
  4. 过肥窒息（通流带宽 `> 46%` 或底场留白 `< 34%`，反噬叙事呼吸）；
  5. 框内止步（贯穿延展 `< 84%`，未抵达外切边）；
  6. 底场割裂（左右底色不统一，退化成两页拼贴）；
  7. 要害压脊（逐字包围盒落入当前装订死区或细正文硬跨胶装）；
  8. 偏缩单页（标题拖离主通流 `> 24%`，双页不成一体）。
- **读数说什么「为什么」**：单真源诊单按严重度只说当前最紧要的几何/装订机制（为何错牙会打断格式塔连续性、为何胶装 14mm 暗谷会吞掉中缝字符）与就地改法，所有经验区间与叙事连贯分档明确标注「经验值 / 示意」。接受「原海报经典解」「锁线平摊全景解」「胶装避脊肩排解」多组合法解。
- **与最近 12 页的明显差异**：
  - 紧邻的 135 是曜石黑底中轴镜像对折验镜台，136 是暖米纸左弧右配重物理天平杠杆台；137 彻底转为**深紫靛通底 × 贯穿 S 形玫红丝带 × 跨缝咬合接缝 + 实体书脊剖面吞缝实验室**；
  - 玩法、画幅、配色、版式骨架和字体与 136/135/217/085/048/303/172/258/337/257/302/047 全部明显不同。

## 3. 版式骨架
忠实转译 137 原海报「深紫靛满幅通底 + 贯穿通顶虚线书脊 + 左上自示范『通版▬跨页』巨标总述 + 右上薄荷双波浪与四词宣言 + 宽屏左 64% 超大跨缝通流画布与实体纸弧剖面 × 右 36% 齐底诊单与 2×2 原海报薄荷探针 + 底沿满宽四滑块精控条与左下 8×4 薄荷点阵」骨架（零深灰通用顶栏、绝不锁 `100svh` 避平板大空白）：
- **1440×900（主宽 1380px；2560×1440 舒展至 1680px）**：双角对望刊头 → 主工作台左 64% 超大跨缝通流画布 × 右 36% 严丝齐底的单真源诊单与 2×2 薄荷探针 → 底沿满宽四滑块与装订/试错精控条，首屏完整尽览。
- **1024×1366 / 768×1024 平板竖屏**：自然流排，双角刊头紧缩，满宽等比画布配双列齐底诊单与四探针，零纵向空洞。
- **390×844 手机竖屏**：顶沿压紧单行紫靛刊头并后置总述与双波浪；画布切换等比上下结构（上方真实比例开本跨页 + 下方实时书脊纸弧剖面），整块画布稳占首屏 `≥ 46%` 屏高且不拉扁任何几何，折线内直见诊单首句与一键纠偏键。
- **844×390 手机横屏**：左 `58%` 等比跨页画布 × 右 `40%` 精简刊头、单真源诊单与一键纠偏并行。

## 7. 练习设计
- **题干**：某城市地理画册采用**厚本无线胶装**，准备设计跨页开篇「海岸公路专题」。下方 **方案 A / B / C / D** 使用完全相同的色彩与素材量，仅改变了**跨缝衔接与标题落位**，哪一版在真实成书翻开时既保留通版连续叙事，又不被装订折谷破坏？
- **四项差异（单一变量：跨缝与落位，中性标签 A/B/C/D）**：
  - 方案 A：公路色带连续跨缝，但标题正中汉字与海岸主角压在胶装中缝折谷上（翻开后中字与主角被吞噬折断）；
  - 方案 B：左右页各自保留精致细框与内订口，公路色带在中缝断开留白走廊（工整却退化成两张孤立单页）；
  - 方案 C（正确）：宽阔公路色带无缝斜穿中缝直抵左右外切边，标题落于右页宽肩区避开 14mm 胶装折谷（兼具贯穿连贯与物理可读性）；
  - 方案 D：色带跨缝时为避让正文突然下错台阶，且右页换为浅灰底（错牙断流 + 底场割裂）。
