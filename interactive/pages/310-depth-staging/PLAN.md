# 310 深度调度 DEPTH STAGING — 设计与交互方案

## 1. 一句话道理
深度调度把角色与线索沿镜头纵深 Z 轴铺到前、中、后三个不同景层，借近大远小的透视差与错开的视线走廊，让观众在一帧之内不靠剪辑就看清谁主导当下、谁牵动中场、谁在远处埋下伏笔。

## 2. 开场玩具：「三层纵深排演台」（Three.js 3D 水桥片场 + 同源 2D 透视降级 + 纵深剖面景片轨）
- **玩法**：复刻 310 原海报的午夜紫靛跨水长桥片场（全员极简剪影零五官），镜头正对纵深水桥与远岸圆月，三块建筑感立牌（`FOREGROUND` / `MIDDLE GROUND` / `BACKGROUND`）按深度立在空间里。用户在下方**纵深剖面景片滑轨（原海报左下 DEPTH LAYERS DIAGRAM 活体化）**上直接左右拖移三名角色（A 执信者 / B 中间人 / C 远影）改变其纵深距离 Z（2.8m–26m，主角滑块标 `data-perf-drag`），也可直接在摄影机画面里拖拉人物微调左右横向通道 X，并切换镜头焦段（24mm / 35mm / 85mm / 135mm）与三套脚本策略（层次对话 / 由远及近 / 由近及远）。
- **开场初始态（绝非答案）**：三名角色刻意全挤在 9.5–11.8 m 中景平面带且横向几乎贴近，画面读不出景层与主次，最大/最小人物投影身高比仅约 1.2×，触发「平面挤成一团」诊断。
- **能玩错 & 读数说清「为什么」**：由 `model.js` 同一套透视投影引擎（根据各角色 $(x_i, z_i)$、真实焦段等效视角与近远投影包围盒）严格判定：
  1. **平面挤墙**：三人都挤在同一景层，近远身高比 < 1.9× → 指出当前 Z 跨度与身高比，提示拉近 A 进前景、推远 C 进后景。
  2. **前后挡死**：深度拉开但横向投影重叠率 > 45% → 画面亮起警戒遮挡红橙框，提示深度不是叠成一串糖葫芦，需左右挪出「视线走廊」。
  3. **长焦压扁**：站位拉开但误选 135mm 长焦（空间压缩或前景出框） → 指出焦段抹平了纵深透视，需切回广角或标准焦段。
  4. **中景断档**：只占前+后两层、漏掉中景「承上启下」带 → 提示补入中景衔接层。
  5. **三层成立**：前/中/后三层齐备、近远身高比 ≥ 2.5×、无遮挡撞车、焦段未压扁 → 三条海报同款圆点虚线引注逐一亮起，说明观众视线如何沿三层自然推进。
- **与最近 12 页的差异**：309 是暗橄榄绿 2.39:1 窗边咖啡馆横向推摄影机轨（单人跨视线轴做前景遮挡）；本页是午夜紫靛×亮青 3D/2D 纵深建筑剧场，直接沿 Z 轴把三名角色推入三片立体景层并错开视线走廊，和 225/142/102/020/269/129/187/296/240/019/295 在玩法与骨架上完全不同。

## 3. 版式骨架
- **1440×900 & 2560×1440 宽屏**：紧贴 310 原海报「左 28% 深紫标题与导演调度台 × 右 72% 跨栏通顶深境剧场」骨架，大标「深度调度」示范纵深层叠跨过左紫与右幕边界；右区上部为等比宽阔 3D 透视画面（1440 下宽约 950px、2560 下放开容器至 2040px 让画面宽至约 1380px），画面右侧嵌原海报三条圆点虚线景层引注，正下方紧咬「镜头眼睛 + 三片透视景片 Z 轴滑轨」；左栏装脚本、焦段切签与实时深度体检单，与右栏自然齐底无大片空白。
- **1024×1366 / 768×1024 竖屏平板**：不锁 `100svh`，自然纵排，透视舞台居中满宽、紧接纵深滑轨与双列控制诊断带。
- **390×844 手机竖屏**：标题压紧两行，紧接满宽透视舞台（高约 215px）与横向可拖纵深景片滑轨（高约 152px，核心互动区占首屏 > 45% 且触屏横向滑不拦纵向滚页），其下紧凑单行诊断与焦段按钮，首屏齐见。
- **844×390 手机横屏**：切为左 58% 透视舞台+精简 Z 轴导轨、右 42% 紧凑标题与诊断控制条。

## 4. 配色与字体
- **配色（实采自 `site/public/p/310.webp`）**：午夜紫靛 `#1A0E40` / `#130C2F`、暮空淡紫 `#9A84B4` / 紫景片 `#503A7B`、深海蓝青 `#183256` / `#1B5972` / `#1A6064`、前景亮青与薄荷青 `#71B1BC` / `#177D92` / `#79B6AD`（暗底高对比提亮 `#8AD6CB`）、暖月米白 `#ECDDCB` / `#F5ECE0`、剪影墨黑 `#04071A`；正文交替采用暖月米纸 `#F3ECE2` 与淡雾青灰 `#E6EFF1`。
- **字体（全库唯一，两款西文均为最近 12 页未用）**：
  - `Bebas Neue`（400，最近 12 页**未用**）：建筑立体景层字、节号、大副标与深度大读数；
  - `DM Mono`（400, 500，最近 12 页**未用**）：米距、焦距、视锥刻度与场记标号；
  - `Noto Sans SC`（400, 500, 700, 900）：大标与无衬线正文（正文内西文人名年份沿用正文体，不跳动）。

## 7. 练习设计
- 场景：傍晚水桥三方戏（前景执信主角、中景观察中间人、后景远岸将离去的背影），四张图同构同景同焦段，选项仅标 A / B / C / D：
  - **A**：横向错开，但三人挤在中景同一深度带（缺深度跨度）；
  - **B**：深度拉开，但前景人物挡住中景大半轮廓（缺视线走廊）；
  - **C（正确）**：前 3m / 中 10m / 后 22m 层次清晰且横向留出视线走廊；
  - **D**：前景挤入两人、远岸一人，中景整层空缺断档（缺中景衔接）。
