# 337 节标题幻灯片版式 · 设计方案（PLAN.md）

## 1. 一句话道理
节标题页不是「少写了字的内容页」，而是插在两段高密度信息之间的**认知换气阀**——用高反差底色、明确章号方向与大面积留白制造事件边界，让观众收拢上一章、空出工作记忆，再干净地走进下一章。

## 2. 开场玩具：「节标题转场片轨」（2D Canvas，`data-perf-drag`）
- **玩法**：1:1 承袭 337 原海报深石油青底、右侧炽橙竖带弯折成底部横轨与暖米圆球的视觉语言。主舞台是一条活体三帧演示胶片带：`SLIDE 04（前章高密收尾）` → `SLIDE 05（当前节标题剪辑位，16:9 主画幅）` → `SLIDE 06（新章高密开场）`。
  - **左右横拖画布**（或拖底沿炽橙横轨上的暖米圆球）：连续推演 `04 → 05 → 06` 的翻页转场，画布下方同步绘制一条基于三页真实渲染密度计算的**视觉负荷 / 换气波形**。
  - **直点画布内 05 号节标题页元素**（点标题区改精炼度、点章号锚点、点正文区削掉冗赘议程、点背景切反色转场），或配合下方精控区调标题字号、情绪版式与一键播完 3 页转场（空格键）。
- **开场状态（刻意错态 0/4，绝不先给答案）**：05 号页初始停在四重典型汇报坏态——与前后页完全同底的浅米白底（明度差 ΔL = 0，隐形转场）、25 字三行公文长标题（30pt 偏弱）、无章号、下方硬塞 5 条议程字墙（实测留白跌至约 41%），波形一路高压无喘息。
- **怎样算玩错 & 读数怎么说「为什么」**：所有读数（实测留白、相邻明度差 ΔL、标题字数/行数与预计扫读秒数、章号方向完整性）均由 `model.js` 从画布真实绘制的几何矩形与三页像素亮度单真源核算，双向检出 7 类错态：
  1. 同底隐形转场（ΔL < 0.25）：连翻三页几乎无光暗顿挫，观众误以为仍是正文；
  2. 塞满议程字墙（实测留白 < 62%）：把目录或提纲硬搬进节标题，剥夺认知换气；
  3. 公文长题难扫（> 14 字或 ≥ 3 行）：观众低头默读，错过讲者口头过渡；
  4. **少过头失方向**（只留 `PART 02` 无主题名）：专门对应海报「少即是多」的边界——删掉论据不是删掉路标，观众依然不知道下一章讲什么；
  5. 标题偏小平权（< 44pt）：后排辨识不足，立不住章节气场；
  6. 巨字越出投影安全边（边距 < 7%）；
  7. 花哨噪底伤对比与统一感。
  同时认可「深青反色解」「炽橙满铺解」「进度锚点解」等多组合法解。
- **与近 12 页的差异**：335 是单页封面拖视觉焦圆、336 是单页左文右图拖栏缝；337 紧扣节标题「必须夹在两段内容之间才成立」的本质，做成**跨三页胶片推演 + 认知负荷波形 + 局部直点改稿**，且右缘通高炽橙弯带架构与近 12 页完全不同。

## 3. 版式骨架
- **1440×900（2560 舒展至 1720px）**：忠实转译 337 原海报「左 88% 深石油青开放舞台 × 右 12% 炽橙通高竖带（嵌深青三角 `▶`、真竖排中英标签、三套剧本切签）→ 底沿炽橙 J 形弯折横带托暖米圆球 → 下方双栏齐底（左 46% 单真源白话诊单配细弧橙点 | 右 54% 紧凑四维控舱）」。不锁 `min-height: 100svh`，首屏一次完整呈现标题、四枚橙线探针、三页片轨画布与诊单。
- **390×844（手机竖屏）**：右炽橙竖带收拢为顶部细炽橙条（含三角 `▶`、编号与状态），单行压紧主标题后立即呈现等比 3 页片轨画布（占首屏 ≥ 46%，中帧严格保持 16:9 不压扁），折线内直接露出单真源诊单首句与一键纠偏钮；四探针与详细控舱顺次排在下方。
- **844×390（手机横屏）**：左 56% 胶片推演画布 × 右 44% 精简刊头、诊单首句与快控并行，零溢出。

## 5. 节目录（7 节，h2 均 ≤ 12 字，相邻不同控件）
- **01 为什么需要喘一口气**（暖宣骨白）：12 页演示进度带与认知负荷曲线切换器（无节标题 / 合理 3 节 / 过碎 6 节），讲清分段效应与事件边界。
- **02 一页只留四样东西**（浅青雾纸）：原海报四枚橙符互动解剖蓝图（点击开关图层：章节提示 / 转场 / 情绪建立 / 信息留白）+ 温和补正原海报「少即是多」边界。
- **03 四种转场变体对比**（深石油青暗室）：放映厅四构图实时投影切台 + 「前排 3m / 后排 15m」光学视距切换，比较纯色反色 / 巨号编排 / 进度高亮 / 意境留白。
- **04 从哪来：书页到银幕**（暖砂纸）：四时代横向脉络卡片切换（古典书籍篇章页 → 1855/1947 少即是多与幕间卡 → 2001/2007/2009 认知分段研究 → 2008/2010 演示革命与 PowerPoint 分节），并一句话链接同小类 335/336/338–343。
- **05 什么时候别用**（暖宣骨白）：四类真实演讲场景分诊器（电梯路演 / 邮件文档型 / 40 分钟复盘 / 闪电单线），点选即看该插还是该省及替代手法。
- **06 小练习：挑一张真转场**（深石油青考场）：四套 16:9 夹帧 SVG 方案（中性标签 A/B/C/D，仅各差一个变量），选后逐项揭示原因。
- **07 原海报与关键词**（暖宣骨白 + 深石油青页脚）：`<img id="poster">` 点击灯箱放大拖拽（`draggable="false"`、Esc 关）+ 原海报四组关键词与结语。

## 7. 小练习设计
- **题干**：前页（04）与后页（06）都是浅底高密度数据页，下面四张 05 号节标题方案都讲同一章「02 · 渠道破局」，哪一张真正完成了章节转场？
- **四选项（中性标签，各只差一个关键变量）**：
  - **方案 A**：深青反色 + 充足留白 + 巨号 `02`，唯独删去章节主题词只写 `SECTION TWO`（缺章节方向提示）；
  - **方案 B**（正解）：深青反色 + `02 · 渠道破局` + 一句短导语 + 约 74% 留白 + 细橙标线（四项全成立）；
  - **方案 C**：浅米同底 + `02 · 渠道破局` + 一句短导语 + 约 74% 留白（唯独缺底色明度反差，混入内容页）；
  - **方案 D**：深青反色 + `02 · 渠道破局` + 下方塞满 5 条本章要点（唯独破坏信息留白，抢正文工作）。
